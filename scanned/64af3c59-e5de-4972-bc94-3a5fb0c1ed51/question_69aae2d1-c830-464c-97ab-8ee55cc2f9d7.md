In core/src/verifier.rs update_finalized_payouts, the operator_xonly_pk attributed to a payout is derived purely by parse_op_return_data(&output.script_pubkey) on the FIRST OP_RETURN output of the payout tx found on-chain (get_first_op_return_output). Can an attacker who broadcasts their own payout-shaped transaction spending the exact withdrawal_utxo (using the withdrawer's own SinglePlusAnyoneCanPay signature, which permits ANYONE to add inputs/outputs since only the withdrawal input+its paid output are covered) add an OP_RETURN pushing an arbitrary 32-byte value equal to a targeted honest operator's xonly_pk, so payout_payer_operator_xonly_pk gets set to that operator without that operator ever funding or broadcasting the tx? Precondition: SinglePlusAnyoneCanPay sighash flag on withdrawal input, victim operator's xonly_pk is public (published via GetParams). Call sequence: attacker builds tx with withdrawal_utxo as input, victim script_pubkey signature reused, OP_RETURN=victim_xonly_pk, broadcasts and mines; update_finalized_payouts writes payout_payer_operator_xonly_pk = victim; PayoutCheckerTask::run_once later calls handle_finalized_payout crediting victim as payer. Breaks ATTRIBUTION: operator credited/reimbursed for withdrawal i == party whose funds paid that payout. Impact: Critical - an operator that never funded a payout is credited (or conversely the true funder, if any, is never credited) and can attempt Reimburse for a payout it never funded, OR an honest operator who DID front the withdrawal via a legitimate second payout tx after the attacker's fake one is now permanently blocked from Reimburse because is_utxo_spent(withdrawal_utxo) is already true. Proof idea: cargo test under core/src/test broadcasting a hand-crafted transaction that spends the registered withdrawal_utxo with the user's original signature but a substituted OP_RETURN naming a victim operator xonly_pk who never called withdraw(), then asserting operator_db.get_first_unhandled_payout_by_operator_xonly_pk returns this payout for the victim.
