# Q2048: accrue via collateral-remove: satisfy the freshness gate with a timestamp the gate was n

## Question
Does `collateral-remove` (mainnet/contracts/market/v0-4-market.clar:1107) let an unprivileged attacker who controls whether the position has any enabled debt row (the has-debt branch) reach `accrue` (mainnet/contracts/vault/v0-vault-stx.clar:835) in a state where it satisfy the freshness gate with a timestamp the gate was never meant to accept?
