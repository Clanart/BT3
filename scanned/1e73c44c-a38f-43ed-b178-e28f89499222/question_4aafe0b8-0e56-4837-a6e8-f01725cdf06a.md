Target: `Verifier::sign_optimistic_payout` amount/message binding (core/src/verifier.rs) combined with sighash construction reused from `builder/sighash.rs`'s `TapTweakData`/sighash calculation helpers. Attacker action: submit `OptimisticPayoutParams` with `input_outpoint` = the withdrawal UTXO of deposit D1, but `agg_nonce` computed by the aggregator from a `create_nonce_streams` call that was actually initiated for a DIFFERENT concurrent optimistic-payout request for deposit D2 (attacker races two aggregator RPCs so the second request's `agg_nonce` byte string happens to be echoed into the first request body it forges by hand against the public gRPC port, bypassing the aggregator entirely). Preconditions: attacker can call the verifier's `optimistic_payout_sign` gRPC directly (it is a normal unauthenticated verifier endpoint per `Interceptors::Noop`), not just through the aggregator. Call sequence: verifier parses `agg_nonce` bytes into `AggregatedNonce::from_byte_array`, parses `nonce_session_id`, looks up its OWN local session (not the aggregator's), pops its own secnonce N, and calls `musig2::partial_sign(deposit_data.get_verifiers(), None, N, agg_nonce_from_D2_flow, keypair, Message::from_digest(sighash_D1))`. Binding to test: the `agg_nonce` used in `partial_sign` must equal the aggregate of public nonces actually contributed by all participating verifiers FOR THIS SPECIFIC sighash_D1, i.e., `agg_nonce_used == aggregate_nonces(pub_nonces_for_D1)`. Impact: Critical — supplying a foreign `agg_nonce` lets an attacker obtain a partial signature over sighash_D1 that is cryptographically incompatible with any real N-of-N aggregate, but if it validates enough to get counted, it can be combined with other verifiers' partials from D2's honest flow to forge a signature authorizing an unfronted payout. Proof idea: cargo test issuing a raw `optimistic_payout_sign` gRPC call with a mismatched `agg_nonce` from an unrelated session and asserting the resulting partial signature does NOT `partial_verify` against sighash_D1 with the honest key-agg cache, closing the 'message signed == nonce/agg_nonce used' binding.
