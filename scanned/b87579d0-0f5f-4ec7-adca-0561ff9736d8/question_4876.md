# Q4876: accrue-user-collateral via accrue: attach a price resolved for one asset to a different asset

## Question
Does `accrue` (mainnet/contracts/vault/v0-vault-stx.clar:835) let an unprivileged attacker who controls the utilization the rate is interpolated at reach `accrue-user-collateral` (mainnet/contracts/market/v0-4-market.clar:270) in a state where it attach a price resolved for one asset to a different asset in the position? Given that it accrues only rows that `is-ztoken` recognises, skipping everything else, the invariant that each callcode preserves magnitude and sign and cannot be moved by the caller in the same transaction breaks and the result is direct theft of another user's collateral.
