# Q1769: ManualCompound.compound - caller sets the conversion ratio for value that is not theirs

## Question
rewards/ManualCompound.sol - compound() forwards the caller's _convertRatio into IConverter(_convertor).convertFor(receivedBalance, _convertRatio, _minRec, msg.sender, 2) where receivedBalance is the whole contract balance, so one caller decides how another user's value is routed through the AMM.
