# Q5896: get-position via collateral-remove: satisfy the freshness gate with a timestamp the gate was n

## Question
Does `collateral-remove` (mainnet/contracts/market/v0-4-market.clar:1107) let an unprivileged attacker who controls whether the position has any enabled debt row (the has-debt branch) reach `get-position` (mainnet/contracts/market/v0-4-market.clar:466) in a state where it satisfy the freshness gate with a timestamp the gate was never meant to accept? - Expected Immunefi impact: Critical - direct theft of user funds at rest or in motion
