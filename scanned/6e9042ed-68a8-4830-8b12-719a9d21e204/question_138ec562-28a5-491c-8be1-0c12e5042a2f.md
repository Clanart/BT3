Attacker action: broadcast a low-fee decoy transaction spending the same withdrawal UTXO with a forged/absent OP_RETURN before the operator's RBF replacement of its own payout tx propagates, exploiting that `copy_witnesses` blindly copies any S+AP-tagged witness from `initial_tx` without verifying which OP_RETURN accompanies it in the newly-built PSBT. Preconditions: operator has queued a payout tx for RBF fee-bumping; attacker can see the initial low-fee tx in the mempool. Call sequence: attacker's replacement (with different OP_RETURN) is accepted by miners over the operator's own RBF bump because both carry a byte-identical S+AP witness on input 0 and `copy_witnesses` never binds witness reuse to a specific OP_RETURN commitment. Binding: the OP_RETURN operator identity in the transaction whose witness is reused by `copy_witnesses` == the OP_RETURN operator identity in the operator's originally-queued transaction. Scoped impact: Critical - an honest operator that funded (or was about to fund via RBF) a payout is permanently unable to be reimbursed once attacker's replacement with mismatched attribution confirms first and consumes the withdrawal UTXO.
