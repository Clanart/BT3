Target: `Verifier::update_finalized_payouts` (core/src/verifier.rs) resolving `operator_xonly_pk` purely from `get_first_op_return_output(&circuit_payout_tx)` on the mined payout transaction, independent of any check that the OP_RETURN pubkey is the same operator recorded as having received the withdrawal request. Attacker action: broadcast a payout transaction spending the legitimate withdrawal UTXO (input) but whose OP_RETURN output embeds operator B's x-only pubkey, while operator A is the one whose signed payout the withdrawer actually authorized/received funds from off-chain. Preconditions: attacker controls tx construction fee/witness once they have operator A's payout witness (front-running/replacing before confirmation is out of scope, but a *distinct* payout tx spending the same UTXO with different OP_RETURN can be attacker-crafted using operator A's `user_sig`+`input_utxo`, since `create_payout_txhandler`'s witness only commits to the key-spend of the withdrawal input, not the OP_RETURN output). Call sequence: `update_finalized_payouts` parses OP_RETURN -> `update_payout_txs_and_payer_operator_xonly_pk` sets `payout_payer_operator_xonly_pk = B` -> `get_first_unhandled_payout_by_operator_xonly_pk(operator_xonly_pk=B)` lets operator B claim reimbursement for a payout operator A actually funded (if B is dishonest this is out of scope, but the *binding break itself* is reachable by the unprivileged attacker rewriting OP_RETURN). Binding: `payout_payer_operator_xonly_pk` recorded for withdrawal i must equal the xonly pubkey of the party whose funds actually reached the user in the confirmed payout tx's principal output, counted exactly once (ATTRIBUTION). Impact: Critical, an operator credited/reimbursed for a payout it never funded. Proof idea: cargo test crafting a payout tx with the withdrawal's real key-spend witness but attacker-chosen OP_RETURN xonly pubkey, feeding it through `update_finalized_payouts`, and asserting the recorded `payout_payer_operator_xonly_pk` cannot diverge from the address that received/funded the user output.
