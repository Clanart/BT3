Attacker action: attacker submits a `payout_spv.block_header: CircuitBlockHeader` with a correct `merkle_root` matching a `mid_state_txid` obtained from a mid-state tree constructed over a set of transactions the attacker fabricated (not the block's real txdata), while reusing the real block's other header fields (`prev_block_hash`, `time`, `bits`, `nonce`) so `compute_block_hash()` equals a hash that IS present in the honest MMR (because it's copied from a genuinely mined block), but the `merkle_root` field was swapped to one consistent with the attacker's fabricated transaction set. Call sequence: `SPV::verify` -> `block_merkle_root = self.block_inclusion_proof.get_root(mid_state_txid)` equals the forged `merkle_root` field by construction -> `block_hash = self.block_header.compute_block_hash()` computed from the tampered header (with swapped merkle_root) -> `mmr_guest.verify_proof(block_hash, mmr_inclusion_proof)`.
