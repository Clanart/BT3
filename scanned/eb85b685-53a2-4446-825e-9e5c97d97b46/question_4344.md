# Q4344: accrue-collateral-asset via call-ststx-ratio: attach a price resolved for one asset to a different asset

## Question
Does `call-ststx-ratio` (mainnet/contracts/market/v0-4-market.clar:1015) let an unprivileged attacker who controls whether the ratio is fetched before or after other state changes in the block reach `accrue-collateral-asset` (mainnet/contracts/market/v0-4-market.clar:273) in a state where it attach a price resolved for one asset to a different asset in the position? - Entrypoint: `call-ststx-ratio` (`mainnet/contracts/market/v0-4-market.clar:1015`), unprivileged and publicly callable
