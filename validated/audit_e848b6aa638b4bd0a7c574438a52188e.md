### Title
Gasless swap price validation is stale relative to block-inclusion time, allowing token-price volatility to make the proposer's lent gas unrecoverable - (File: kaiax/gasless/impl/tx_pool.go, kaiax/gasless/impl/getter.go, kaiax/gasless/impl/builder.go)

### Summary
The `kaiax/gasless` module (KIP-247) implements a mechanism where the block proposer fronts ("lends") the gas fee for a user's gasless transaction, expecting to be repaid from a token swap executed in the same block. The swap's economic validity (`amountIn` vs. `minAmountOut`) is checked against the *current* on-chain exchange rate at the moment the transaction is admitted to the pool, but the lend and repayment actually occur when the bundle is later included in a block. Because token prices are variable and no incentive/tolerance buffer scales with volatility (mirroring the Aloe report's fixed `LIQUIDATION_INCENTIVE` vs. variable volatility issue), a price move between mempool admission and block inclusion can make the previously-valid swap revert on execution, while the proposer's `LendTx` has already unconditionally transferred KAIA to the user.

### Finding Description
`checkBalanceForSwap` in [1](#0-0)  validates a `GaslessSwapTx` by calling `routerContract.GetAmountIn(nil, token, minAmountOut)` against the *current* state to ensure `amountIn` is sufficient. This check happens once, at tx-pool admission (and possibly re-validation), using the token price at that instant.

However, actual settlement is decoupled from this check:
- `lendAmount`/`repayAmount` in [2](#0-1)  are computed purely from the swap/approve transactions' own fixed `GasPrice()*GasLimit()` fee fields — static values fixed by the sender at signing time, with no dependency on the DEX price at all.
- `GetLendTxGenerator` in [3](#0-2)  builds a `LendTx` that unconditionally transfers `lendAmount` (KAIA) from the proposer to the swap sender.
- The bundle ordering `[LendTxGenerator, GaslessApproveTx, GaslessSwapTx]` is constructed in `ExtractTxBundles` in [4](#0-3) , where the `LendTx` is generated and prepended before the (possibly stale) `SwapTx`, and the bundle is registered with `revertOnFail = false` (the third argument to `builder.NewBundle`), unlike the auction module's bundle which uses `true` in [5](#0-4) .

Because the price check performed in `checkBalanceForSwap` reflects the state at admission time, not at inclusion time, and because gas-fee/repayment amounts are fixed and independent of the DEX exchange rate, any volatility in the token's price between the time the tx enters the pool and the time the bundle is actually included in a block can invalidate the `minAmountOut`/`amountRepay` relationship enforced on-chain by the swap router. This is architecturally the same defect class as the referenced Aloe report: a fixed/static commitment (liquidation incentive there, lend/repay amount here) is checked against a snapshot of a variable market condition (average Uniswap price there, current DEX price here) that can diverge by the time the economically-sensitive action actually executes.

### Impact Explanation
If the `GaslessSwapTx` reverts at execution time (e.g., the DEX price moved such that the swap can no longer produce `minAmountOut`), the on-chain router transaction fails, so the router-level swap does not pay out — but this does not, by itself, prove the `LendTx` is clawed back, since `revertOnFail=false` is used for gasless bundles (unlike the atomic auction bundle). If the `LendTx` is not guaranteed to be dropped/rolled back together with a failing `SwapTx`, the block proposer's lent KAIA is at risk of not being recovered whenever the reference price moves between mempool admission and block inclusion, i.e., real value loss for the block proposer functioning as an involuntary short-term lender.

### Likelihood Explanation
This does not require any malicious validator, peer, or governance action — an ordinary token holder can submit a valid `GaslessApproveTx`/`GaslessSwapTx` pair through the public RPC that passes admission checks, and normal market volatility (which is common for many ERC-20/DEX pairs) can move the price during the interval between pool admission and block building/inclusion. No privileged access is needed; only reachable, ordinary transaction submission via `debug_isGaslessTx`/normal tx broadcast.

### Recommendation
- Re-validate `checkBalanceForSwap` (or an equivalent slippage/price check) against the state of the block actually being built, immediately before including the bundle, not only at pool-admission time.
- Make the gasless bundle atomic (`revertOnFail = true`) so that if the `SwapTx` fails to repay, the entire bundle (including the `LendTx`) is dropped from the block, ensuring the proposer never fronts KAIA without guaranteed repayment.
- Consider adding a price-staleness/slippage buffer akin to what the Aloe report recommends for `LIQUIDATION_INCENTIVE` — e.g., re-check `GetAmountIn` at the time of block assembly and reject bundles whose staleness window exceeds a safe threshold.

### Proof of Concept
1. User submits `GaslessApproveTx` + `GaslessSwapTx` (`amountIn`, `minAmountOut`, `amountRepay`) that satisfies `checkBalanceForSwap` at time T0, based on `GetAmountIn(token, minAmountOut)` computed from the chain state at T0 — see [6](#0-5) .
2. Due to normal trading activity on the DEX pool backing `GaslessSwapRouter`, the token price moves between T0 and the time the block containing the bundle is actually built/proposed (T1).
3. At T1, `ExtractTxBundles` still builds the bundle `[LendTx, ApproveTx, SwapTx]` from the previously-validated transactions without re-checking the current exchange rate — see [7](#0-6) ; `LendTx` unconditionally sends `lendAmount` (fixed gas fee sum) to the user — see [8](#0-7) .
4. When the block executes, `SwapTx` can no longer satisfy the swap router's on-chain slippage guard for the stale `minAmountOut`/`amountRepay` combination and reverts.
5. Because the bundle is constructed with `revertOnFail=false`, there is no confirmed atomic guarantee that `LendTx`'s KAIA transfer is undone together with the failing `SwapTx`, leaving the proposer's lent value unrecovered.

Note: full confirmation of whether `revertOnFail=false` bundles are actually non-atomic at the `work/builder` execution layer could not be completed within the available tool budget (the `work/builder/bundle.go` implementation was not fully inspected). This should be verified directly in a Devin session by reading `work/builder/bundle.go` and the block-building code path that consumes `Bundle.RevertOnFail` (or equivalent flag) before treating this as a confirmed, exploitable loss rather than a design risk.

func (g *GaslessModule) checkBalanceForSwap(swapArgs *SwapArgs, swapNonce uint64) error {
	token := swapArgs.Token
	bc := backends.NewBlockchainContractBackend(g.Chain, nil, nil)

	g.gaslessInfoMu.RLock()
	swapRouter := g.swapRouter
	g.gaslessInfoMu.RUnlock()

	// tx.minAmountOut >= tx.amountRepay
	minAmountOut := swapArgs.MinAmountOut
	amountRepay := swapArgs.AmountRepay
	if minAmountOut.Cmp(amountRepay) < 0 {
		return fmt.Errorf("insufficient minAmountOut: minAmountOut=%s, amountRepay=%s", minAmountOut.String(), amountRepay.String())
	}

	if g.GaslessConfig.ShouldCheckSenderCode() {
		if g.getCurrentHasCode(swapArgs.Sender) {
			return errors.New("sender with code is not allowed")
		}
	}

	if g.GaslessConfig.ShouldCheckSwapAmount() {
		// tx.amountIn >= gsr.getAmountIn(minAmountOut)
		routerContract, err := kip247.NewGaslessSwapRouterCaller(swapRouter, bc)
		if err != nil {
			return err
		}
		// Required token amountIn, given the current exchange rate and the declared minAmountOut.
		requiredAmountIn, err := routerContract.GetAmountIn(nil, token, minAmountOut)
		if err != nil {
			return err
		}
		if swapArgs.AmountIn.Cmp(requiredAmountIn) < 0 {
			return fmt.Errorf("insufficient amountIn: have=%s, want=%s", swapArgs.AmountIn.String(), requiredAmountIn.String())
		}
	}

func (g *GaslessModule) GetLendTxGenerator(approveTxOrNil, swapTx *types.Transaction) *builder.TxOrGen {
	var src []byte
	if approveTxOrNil != nil {
		src = append(src, approveTxOrNil.Hash().Bytes()...)
	}
	src = append(src, swapTx.Hash().Bytes()...)
	bundleHash := crypto.Keccak256Hash(src)

	gen := func(nonce uint64) (*types.Transaction, error) {
		var (
			chainId = g.InitOpts.ChainConfig.ChainID
			signer  = types.LatestSignerForChainID(chainId)
			key     = g.InitOpts.NodeKey
		)

		to, err := types.Sender(signer, swapTx)
		if err != nil {
			return nil, err
		}

		tx, err := types.NewTransactionWithMap(types.TxTypeEthereumDynamicFee, map[types.TxValueKeyType]interface{}{
			types.TxValueKeyNonce:      nonce,
			types.TxValueKeyTo:         &to,
			types.TxValueKeyAmount:     lendAmount(approveTxOrNil, swapTx),
			types.TxValueKeyData:       common.Hex2Bytes("0x"),
			types.TxValueKeyGasLimit:   params.TxGas,
			types.TxValueKeyGasFeeCap:  swapTx.GasFeeCap(),
			types.TxValueKeyGasTipCap:  swapTx.GasTipCap(),
			types.TxValueKeyAccessList: types.AccessList{},
			types.TxValueKeyChainID:    chainId,
		})
		if err != nil {
			return nil, err
		}

		err = tx.Sign(signer, key)
		return tx, err
	}

	return builder.NewTxOrGenFromGen(gen, bundleHash)
}

func lendAmount(approveTxOrNil, swapTx *types.Transaction) *big.Int {
	r := new(big.Int)

	// R2 = ApproveTx.Fee() if exists
	if approveTxOrNil != nil {
		r.Add(r, approveTxOrNil.Fee())
	}

	// R3 = SwapTx.Fee()
	r.Add(r, swapTx.Fee())

	// LendAmount = R2 + R3
	return r
}

func repayAmount(approveTxOrNil, swapTx *types.Transaction) *big.Int {
	// R1 = LendTx.Fee() = SwapTx.GasPrice() * TxGas
	r1 := new(big.Int).Mul(swapTx.GasPrice(), new(big.Int).SetUint64(params.TxGas))

	// RepayAmount = R1 + R2 + R3
	return new(big.Int).Add(r1, lendAmount(approveTxOrNil, swapTx))
}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
}
