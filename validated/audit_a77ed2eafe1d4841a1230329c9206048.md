### Title
`RegisterPointerDisabled` governance param is bypassable via the EVM pointer precompile - (File: precompiles/pointer/pointer.go)

### Summary
The chain exposes a governance-controlled parameter, `RegisterPointerDisabled`, meant to globally disable creation of new CW↔ERC pointer contracts. This is enforced in `x/evm/keeper/msg_server.go`'s `RegisterPointer` message handler, but the equivalent functionality reachable through the on-chain EVM pointer precompile (`0x000000000000000000000000000000000000100b`) never checks this flag, letting any EVM caller create new pointers even while the feature is supposedly disabled.

### Finding Description
`x/evm/keeper/msg_server.go`'s `RegisterPointer` handler checks `params.RegisterPointerDisabled` before allowing pointer registration, and returns an error ("registering CW->ERC pointers has been disabled") when the governance parameter is set [1](#0-0) . This is exercised via `MigrateDisableRegisterPointer`, which is the mechanism operators use to disable pointer registration [2](#0-1) .

However, `precompiles/pointer/pointer.go`'s `PrecompileExecutor.Execute`/`AddNative`/`AddCW20`/`AddCW721`/`AddCW1155` methods — the code path that lets any EVM transaction sender or contract call `addNativePointer`, `addCW20Pointer`, `addCW721Pointer`, or `addCW1155Pointer` at the precompile address — perform no check of `RegisterPointerDisabled` at all before calling `p.evmKeeper.UpsertERCNativePointer`/`UpsertERCCW20Pointer`/`UpsertERCCW721Pointer`/`UpsertERCCW1155Pointer` [3](#0-2) [4](#0-3) . This is the same class of "incorrect authorization" bug as the GitLab report: an access-control/feature-disable setting is enforced on one entry point but a second, equally reachable entry point to the same underlying capability skips the check entirely.

### Impact Explanation
When an operator (via governance) disables pointer registration — e.g., in response to a discovered exploit involving malicious pointer contracts, or during an incident requiring a freeze on new pointer creation — any unprivileged EVM caller can still register new CW20/CW721/CW1155/native pointers through the precompile, defeating the intended safety control. Because pointer contracts are used system-wide to bridge CW and ERC representations of tokens, an attacker could continue creating pointer mappings (e.g., to spoof or front-run legitimate token pointer registration) during a window that governance believed was locked down, undermining the chain's ability to halt this attack surface and potentially enabling fund-affecting token/pointer spoofing that the disable was meant to prevent.

### Likelihood Explanation
High likelihood of reachability: the precompile is a standard, always-live EVM precompile at a fixed address, callable by any EVM transaction/contract without special permission, and the bypass requires no special conditions beyond invoking `addNativePointer`/`addCW20Pointer`/`addCW721Pointer`/`addCW1155Pointer` while `RegisterPointerDisabled` is true.

### Recommendation
Add an explicit check of `RegisterPointerDisabled` (via `p.evmKeeper.GetParams(ctx)`) at the top of `PrecompileExecutor.Execute` (or in each of `AddNative`/`AddCW20`/`AddCW721`/`AddCW1155`) in `precompiles/pointer/pointer.go`, mirroring the check already present in `x/evm/keeper/msg_server.go`'s `RegisterPointer`, so that the same governance-controlled restriction is enforced consistently across both the Cosmos message and EVM precompile entry points.

### Proof of Concept
1. Governance sets `RegisterPointerDisabled = true` (e.g. via the same mechanism as `MigrateDisableRegisterPointer`).
2. Confirm via `MsgRegisterPointer` that registration is rejected, matching `TestRegisterPointerDisabled` [5](#0-4) .
3. From any EVM account, send a transaction calling `addCW20Pointer(cwAddr)` (or `addNativePointer`/`addCW721Pointer`/`addCW1155Pointer`) at precompile address `0x...100b`.
4. Observe that `PrecompileExecutor.AddCW20` proceeds to call `p.evmKeeper.UpsertERCCW20Pointer` and successfully deploys/returns a new pointer contract address [6](#0-5) , despite `RegisterPointerDisabled` being set — demonstrating the bypass of the governance-disabled control.

func (p PrecompileExecutor) Execute(ctx sdk.Context, method *ethabi.Method, caller common.Address, callingContract common.Address, args []interface{}, value *big.Int, readOnly bool, evm *vm.EVM, suppliedGas uint64, hooks *tracing.Hooks) (ret []byte, remainingGas uint64, err error) {
	if readOnly {
		return nil, 0, errors.New("cannot call pointer precompile from staticcall")
	}
	if ctx.EVMPrecompileCalledFromDelegateCall() {
		return nil, 0, errors.New("cannot delegatecall pointer")
	}

	switch method.Name {
	case AddNativePointer:
		return p.AddNative(ctx, method, caller, args, value, evm, hooks)
	case AddCW20Pointer:
		return p.AddCW20(ctx, method, caller, args, value, evm, hooks)
	case AddCW721Pointer:
		return p.AddCW721(ctx, method, caller, args, value, evm, hooks)
	case AddCW1155Pointer:
		return p.AddCW1155(ctx, method, caller, args, value, evm, hooks)
	default:
		err = fmt.Errorf("unknown method %s", method.Name)
	}
	return
}

func (p PrecompileExecutor) AddNative(ctx sdk.Context, method *ethabi.Method, caller common.Address, args []interface{}, value *big.Int, evm *vm.EVM, hooks *tracing.Hooks) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}
	if err := pcommon.ValidateArgsLength(args, 1); err != nil {
		return nil, 0, err
	}
	token := args[0].(string)
	metadata, metadataExists := p.bankKeeper.GetDenomMetaData(ctx, token)
	if !metadataExists {
		return nil, 0, fmt.Errorf("denom %s does not have metadata stored and thus can only have its pointer set through gov proposal", token)
	}
	name := metadata.Name
	symbol := metadata.Symbol
	var decimals uint8
	for _, denomUnit := range metadata.DenomUnits {
		if denomUnit.Exponent > uint32(decimals) && denomUnit.Exponent <= math.MaxUint8 {
			decimals = uint8(denomUnit.Exponent)
			name = denomUnit.Denom
			symbol = denomUnit.Denom
			if len(denomUnit.Aliases) > 0 {
				name = denomUnit.Aliases[0]
			}
		}
	}
	contractAddr, err := p.evmKeeper.UpsertERCNativePointer(ctx, evm, token, utils.ERCMetadata{Name: name, Symbol: symbol, Decimals: decimals})
	if err != nil {
		return nil, 0, err
	}

	ret, err = method.Outputs.Pack(contractAddr)
	remainingGas = pcommon.GetRemainingGas(ctx, p.evmKeeper)
	return
}
