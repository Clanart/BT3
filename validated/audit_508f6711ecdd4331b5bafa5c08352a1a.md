### Title
Reward-per-token is minted instantly against current `totalSupply` in `DelegateVoteRewardPool`, allowing flash-stake/unstake to snipe bribe yield - ([File: rewards/DelegateVoteRewardPool.sol])

### Summary
`_manageRewards()` → `_queueNewRewardsWithoutTransfer()` credits newly-harvested bribe rewards to `rewardPerTokenStored` based solely on the **instantaneous** `totalSupply` at the moment `harvestAll()` executes, with no time-weighting or vesting period. Because staking into this pool is permissionless (any account can call `WombatBribeManager.vote(delegatedPool, +X)`, which invokes `stakeFor` on `DelegateVoteRewardPool`) and unstaking is immediate (`unvote` → `withdrawFor(..., claim=true)`), an attacker can stake right before `harvestAll()`/`castVotes()` runs and unstake immediately after, capturing a share of previously-accrued bribes proportional to their instantaneous balance rather than their time-weighted contribution.

### Finding Description
- `DelegateVoteRewardPool.harvestAll()` is `external` with no access control: ` [1](#0-0) `. It is also triggered unconditionally at the end of every `WombatBribeManager.castVotes()` call: ` [2](#0-1) `.
- `_manageRewards()` deducts `protocolFee` and forwards the remainder to `_queueNewRewardsWithoutTransfer()`: ` [3](#0-2) `.
- `_queueNewRewardsWithoutTransfer()` adds the entire harvested amount to `rewardPerTokenStored` divided by the **current** `totalSupply`, with no notion of a reward stream/duration: ` [4](#0-3) `. This differs from a proper streaming model (e.g. Synthetix `rewardRate * timeElapsed`); here the entire lump sum is priced into `rewardPerTokenStored` at a single block.
- Staking into `DelegateVoteRewardPool` is reachable by any unprivileged account: calling `WombatBribeManager.vote([delegatedPool], [+X])` calls `IBribeRewardPool(pool.rewarder).stakeFor(msg.sender, X)` where `pool.rewarder == delegatedPool`: ` [5](#0-4) `. `stakeFor` immediately mutates `_balances`/`totalSupply` and snapshots the caller's `rewardPerTokenStored` baseline via the `updateRewards` modifier: ` [6](#0-5) `.
- Unstaking with immediate claim is available via `unvote()` → `withdrawFor(msg.sender, amount, true)`: ` [7](#0-6) `, ` [8](#0-7) `.
- No cooldown, minimum holding period, or same-block vote/unvote restriction was found gating stake→unstake on the delegate pool.

Exploit flow: an attacker monitors for an imminent `castVotes()`/`harvestAll()` call (or calls it themselves), front-runs with `vote([delegatedPool], [+X])` to inflate their share of `_balances`/`totalSupply` at that instant (optionally timed to when `totalSupply` is naturally low, e.g., right after other voters `unvote`), triggers/observes `harvestAll()` executing in the same or next block, and then immediately calls `unvote(delegatedPool)` to withdraw principal and claim the reward that was priced into `rewardPerTokenStored` using their inflated balance — despite having contributed none of the vlMGP voting weight that generated the bribes being harvested (those bribes accrued from votes cast by prior/other stakers over the preceding epoch).

### Impact Explanation
This constitutes theft of unclaimed yield belonging to the delegate pool's genuine, time-weighted voters: an attacker with no meaningful time-weighted contribution can capture a disproportionate (up to nearly 100%, if they become the dominant or sole staker at the harvest instant) share of bribe rewards that were earned by other users' sustained voting weight, diluting/stealing rewards from long-term delegate-pool participants. This matches the "theft of unclaimed yield" impact class.

### Likelihood Explanation
Feasibility is high: staking and unstaking into the delegate pool are fully permissionless public functions (`vote`/`unvote` on `WombatBribeManager`), `harvestAll()` is callable by anyone, and `castVotes()` (which triggers `harvestAll()`) can be called by any address as documented ("gas intensive, hence a fee is given to the caller"). Capital requirements are only whatever vlMGP the attacker holds/controls, and the attack is repeatable every time bribes are queued (each `castVotes()` invocation). The main variable determining profit magnitude is the attacker's ability to dominate `totalSupply` at the exact harvest block, which is easier when `totalSupply` is naturally low (e.g., shortly after other participants unvote), as described in the question.

### Recommendation
Replace the instantaneous lump-sum crediting model in `_queueNewRewardsWithoutTransfer()` with a time-weighted/streaming distribution (reward-rate over a fixed duration, à la Synthetix `StakingRewards`), or impose a minimum staking/lock duration and/or a snapshot mechanism so that only balances held for the full accrual period (i.e., since the previous `castVotes()`/harvest) are eligible for that reward tranche. Alternatively, disallow same-block or near-immediate stake-then-unstake around `harvestAll()` calls (e.g., a cooldown between `vote()` and `unvote()` on the delegate pool).

### Proof of Concept
Foundry test plan:
1. Deploy `DelegateVoteRewardPool`, mock `IWombatBribeManager` operator returning a configurable `claimAllBribes` amount, and set `protocolFee`/`feeCollector`.
2. Stake `stakerA` (long-term holder) with balance `B` via `stakeFor` at time `t0`.
3. Advance time; simulate bribes accruing for `stakerA`'s vote weight.
4. Immediately before calling `harvestAll()`, have `attacker` call `stakeFor` (via `vote`) with balance `A >> B` (or wait until `stakerA`'s balance is temporarily reduced by another unvote) so `attacker`'s share of `totalSupply` dominates.
5. Call `harvestAll()` to trigger `_queueNewRewardsWithoutTransfer`.
6. Immediately call `withdrawFor(attacker, A, true)` (via `unvote`) in the same/next block.
7. Assert: `attacker`'s claimed reward / total reward >> attacker's time-weighted share of votes that generated the harvested bribes (e.g., attacker contributed 0 seconds of voting weight but claims >90% of the reward), while `stakerA`, who held the position throughout accrual, receives a disproportionately small share.

    function _manageRewards(
        address[] memory rewardTokensList,
        uint256[] memory earnedRewards
    ) internal {
        uint256 length = rewardTokensList.length;
        for (uint256 index = 0; index < length; ++index) {
            uint256 fees = (protocolFee * earnedRewards[index]) / DENOMINATOR;
            if (fees > 0 && feeCollector != address(0)) {
                earnedRewards[index] = earnedRewards[index] - fees;
                IERC20(rewardTokensList[index]).safeTransfer(
                    feeCollector,
                    fees
                );
            }
            if (earnedRewards[index] > 0) {
                _queueNewRewardsWithoutTransfer(
                    earnedRewards[index],
                    rewardTokensList[index]
                );
            }
        }
    }

    function _queueNewRewardsWithoutTransfer(
        uint256 _amountReward,
        address _rewardToken
    ) internal {
        if (!isRewardToken[_rewardToken]) {
            rewardTokens.push(_rewardToken);
            isRewardToken[_rewardToken] = true;
        }
        Reward storage rewardInfo = rewards[_rewardToken];
        rewardInfo.historicalRewards =
            rewardInfo.historicalRewards +
            _amountReward;
        if (totalSupply == 0) {
            rewardInfo.queuedRewards += _amountReward;
        } else {
            if (rewardInfo.queuedRewards > 0) {
                _amountReward += rewardInfo.queuedRewards;
                rewardInfo.queuedRewards = 0;
            }
            rewardInfo.rewardPerTokenStored =
                rewardInfo.rewardPerTokenStored +
                (_amountReward * 10 ** this.stakingDecimals()) /
                totalSupply;
        }
        emit RewardAdded(_amountReward, _rewardToken);
    }

        if (_lps.length != _deltas.length)
            revert LengthMismatch();

        int256 totalUserVote;

        for (uint256 i; i < length; i++) {
            Pool storage pool = poolInfos[_lps[i]];
            if (!pool.isActive)
                revert PoolNotActive();
            int256 delta = _deltas[i];
            totalUserVote += delta;
            if (delta != 0) {
                if (delta > 0) {
                    pool.totalVoteInVlmgp += uint256(delta);
                    userVotedForPoolInVlmgp[msg.sender][pool.poolAddress] += uint256(delta);
                    IBribeRewardPool(pool.rewarder).stakeFor(msg.sender, uint256(delta));
                } else {
                    pool.totalVoteInVlmgp -= uint256(-delta);
                    userVotedForPoolInVlmgp[msg.sender][pool.poolAddress] -= uint256(-delta);
                    IBribeRewardPool(pool.rewarder).withdrawFor(msg.sender, uint256(-delta), false);
                }
            }
        }

        if (msg.sender != delegatedPool) {
            if (totalUserVote > 0) {
                userTotalVotedInVlmgp[msg.sender] += uint256(totalUserVote);
                totalVlMgpInVote += uint256(totalUserVote);
            } else {
                userTotalVotedInVlmgp[msg.sender] -= uint256(-totalUserVote);
                totalVlMgpInVote -= uint256(-totalUserVote);
            }
        }

        if (userTotalVotedInVlmgp[msg.sender] > getUserVotable(msg.sender))

    }
