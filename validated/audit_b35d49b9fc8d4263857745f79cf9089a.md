### Title
Unrecovered Go panic in pointer precompile `AddCW20Pointer`/`AddCW721Pointer` from attacker-controlled CosmWasm query response - (File: precompiles/pointer/pointer.go)

### Summary
`pointer.AddCW20` and `pointer.AddCW721` (and all versioned variants under `precompiles/pointer/legacy/*/pointer.go`) query an arbitrary, caller-specified CosmWasm contract address for `token_info`/`contract_info` and then do unchecked type assertions `formattedRes["name"].(string)` and `formattedRes["symbol"].(string)` on the decoded JSON response [1](#0-0) . Because the queried contract is caller-controlled (any deployed CosmWasm contract, including one written specifically to answer this query), the "name"/"symbol" fields can be absent, `null`, or of a non-string JSON type (number, object, array), making the untyped `interface{}` hold something other than a `string`. A bare `.(string)` type assertion in that case panics with `interface conversion: interface {} is nil, not string` (or "... is float64, not string"), analogous to the HFS+ WARN_ON()-on-bogus-length crash — attacker-crafted structured data reaching a hard failure path with no graceful validation.

### Finding Description
The call chain is: EVM transaction → pointer precompile `addCW20Pointer`/`addCW721Pointer` method → `PrecompileExecutor.Execute` → `AddCW20`/`AddCW721` → `wasmdKeeper.QuerySmart(...)` on the caller-supplied `cwAddr` → `json.Unmarshal` into `map[string]interface{}` → unchecked `.(string)` assertions [2](#0-1) . The dynamic-gas precompile dispatcher `RunAndCalculateGas` in `precompiles/common/precompiles.go` (and its legacy siblings, e.g. `precompiles/common/legacy/v67/precompiles.go`) wraps only `HandlePrecompileError`/error conversion in its `defer`, with no `recover()` for panics [3](#0-2) . Unlike the p256 precompile's `verify` function, which explicitly wraps a `recover()` around its logic to convert panics into errors [4](#0-3) , the pointer precompile's `AddCW20`/`AddCW721` executors have no such guard. A CosmWasm contract deployed by any wasm user can implement a `token_info`/`contract_info` query handler that returns `{"name": null, "symbol": 123}` (or omits the fields entirely), and any subsequent EVM transaction that calls `pointer.addCW20Pointer(cwAddr)` / `pointer.addCW721Pointer(cwAddr)` against that contract will hit the unchecked type assertion and panic.

### Impact Explanation
An unrecovered Go panic raised deep inside precompile execution, unless caught by some outer recovery layer in the ABCI/OCC transaction-execution pipeline, will crash the block-processing goroutine. Given the precompile itself provides no boundary recovery (unlike other precompiles in this codebase that explicitly guard against exactly this class of bug, per the `integration_test/precompile_tests` guard noted as "a consensus-relevant guard inherited from the legacy suite" against Go panics leaking from precompile execution) [5](#0-4) , this is a deviation from the codebase's own documented invariant that precompile execution must never let a Go panic escape. If the panic is not caught elsewhere in `ProcessBlock`/`ProcessTXsWithOCCGiga`, this can halt block processing on every validator that processes the transaction (deterministic panic replicated across all nodes since it is derived from committed CW contract state), producing a chain halt — a High-severity, consensus-relevant crash reachable by any unprivileged EVM transaction sender pointing the pointer precompile at a contract they control.

### Likelihood Explanation
High likelihood: deploying a CosmWasm contract with a crafted `token_info`/`contract_info` query handler is a normal, permissionless action available to any wasm user, and calling `pointer.addCW20Pointer`/`addCW721Pointer` against it is a normal, permissionless EVM transaction. No special privileges, timing, or validator collusion are required.

### Recommendation
Replace unchecked type assertions (`formattedRes["name"].(string)`) in `AddCW20`/`AddCW721`/`AddCW1155` executors across `precompiles/pointer/pointer.go` and all `precompiles/pointer/legacy/*/pointer.go` variants with the safe comma-ok form (`name, ok := formattedRes["name"].(string)`) and return a normal error (e.g., `"invalid or missing name in token_info response"`) when `ok` is false, mirroring the defensive pattern already used in `p256.verify`'s `recover()` wrapper. As defense in depth, add a top-level `recover()` in `Precompile.Run` / `DynamicGasPrecompile.RunAndCalculateGas` that converts any panic from `executor.Execute` into `vm.ErrExecutionReverted`, consistent with the "never leak a Go panic" guarantee already documented for other precompiles.

### Proof of Concept
1. Deploy a CosmWasm contract whose `token_info` query handler returns `{"decimals":18,"name":null,"symbol":null,"total_supply":"0"}` (or a numeric type instead of a string for `name`/`symbol`).
2. As any unprivileged account, send an EVM transaction calling `pointer.addCW20Pointer(<contract_address>)` on precompile `0x...100b`.
3. Execution reaches `AddCW20` → `json.Unmarshal` succeeds → `formattedRes["name"].(string)` panics because the value is `nil`/non-string.
4. Because neither the precompile executor nor the dynamic-gas `Run`/`RunAndCalculateGas` wrapper recovers from panics, the panic propagates out of precompile execution into block/transaction processing, matching the "crafted input causing a WARN_ON()/hard-failure crash" bug class from the reference CVE.

func (p PrecompileExecutor) AddCW20(ctx sdk.Context, method *ethabi.Method, caller common.Address, args []interface{}, value *big.Int, evm *vm.EVM, hooks *tracing.Hooks) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}
	if err := pcommon.ValidateArgsLength(args, 1); err != nil {
		return nil, 0, err
	}
	cwAddr := args[0].(string)
	cwAddress, err := sdk.AccAddressFromBech32(cwAddr)
	if err != nil {
		return nil, 0, err
	}
	res, err := p.wasmdKeeper.QuerySmartSafe(ctx, cwAddress, []byte("{\"token_info\":{}}"))
	if err != nil {
		return nil, 0, err
	}
	formattedRes := map[string]interface{}{}
	if err := json.Unmarshal(res, &formattedRes); err != nil {
		return nil, 0, err
	}
	name := formattedRes["name"].(string)
	symbol := formattedRes["symbol"].(string)
	contractAddr, err := p.evmKeeper.UpsertERCCW20Pointer(ctx, evm, cwAddr, utils.ERCMetadata{Name: name, Symbol: symbol})
	if err != nil {
		return nil, 0, err
	}

	ret, err = method.Outputs.Pack(contractAddr)
	remainingGas = pcommon.GetRemainingGas(ctx, p.evmKeeper)
	return
}

func (d DynamicGasPrecompile) RunAndCalculateGas(evm *vm.EVM, caller common.Address, callingContract common.Address, input []byte, suppliedGas uint64, value *big.Int, hooks *tracing.Hooks, readOnly bool, isFromDelegateCall bool) (ret []byte, remainingGas uint64, err error) {
	operation := fmt.Sprintf("%s_unknown", d.name)
	defer func() {
		HandlePrecompileError(err, evm, operation)
		if err != nil {
			fmt.Printf("precompile %s encountered error: %v\n", d.name, err)
			err = vm.ErrExecutionReverted
		}
	}()
	ctxer := state.GetDBImpl(evm.StateDB)
	if ctxer == nil {
		return nil, 0, errors.New("cannot get context from EVM")
	}
	// Resolve the target method from the 4-byte selector only. The argument
	// payload is intentionally NOT decoded yet: ABI decoding of attacker-
	// controlled calldata can cost far more than len(input) (a single string can
	// be referenced by many array/tuple slots), so it must be paid for out of the
	// gas the caller supplied. The static-precompile path charges RequiredGas in
	// vm.RunPrecompiledContract before running; that step is skipped for
	// dynamic-gas precompiles, so we apply the equivalent charge here.
	methodID, err := ExtractMethodID(input)
	if err != nil {
		return nil, 0, err
	}
	method, err := d.MethodById(methodID)
	if err != nil {
		return nil, 0, err
	}
	operation = method.Name

	ctx := ctxer.Ctx()
	// Install the gas meter derived from the supplied EVM gas, then charge for
	// decoding the calldata BEFORE decoding it. A call that cannot afford the
	// decode is rejected here, before the parse/allocation work is performed.
	// chargeDecodeGas scopes the out-of-gas recovery to just these charges, so an
	// executor that later exhausts its gas keeps its normal (propagating)
	// out-of-gas semantics.
	gasLimit := d.executor.EVMKeeper().GetCosmosGasLimitFromEVMGas(ctx.WithGasMeter(sdk.NewInfiniteGasMeterWithMultiplier(ctx)), suppliedGas)
	ctx = ctx.WithGasMeter(sdk.NewGasMeterWithMultiplier(ctx, gasLimit))
	if err = d.chargeDecodeGas(ctx, method, input); err != nil {
		return nil, 0, err
	}

	args, err := method.Inputs.Unpack(input[4:])
	if err != nil {
		return nil, 0, err
	}
	em := ctx.EventManager()
	ctx = ctx.WithEventManager(sdk.NewEventManager())
	ctx = ctx.WithEVMPrecompileCalledFromDelegateCall(isFromDelegateCall)
	ret, remainingGas, err = d.executor.Execute(ctx, method, caller, callingContract, args, value, readOnly, evm, suppliedGas, hooks)
	if err != nil {
		return ret, remainingGas, err
	}
	events := ctx.EventManager().Events()
	if len(events) > 0 {
		em.EmitEvents(ctx.EventManager().Events())
	}
	return ret, remainingGas, err
}
