### Title
Gasless swap admission relies on a manipulable spot-price check while KAIA is lent unconditionally and non-atomically - ([File: kaiax/gasless/impl/tx_pool.go])

### Summary
The `kaiax/gasless` module (KIP-247) lends KAIA gas fees to a user via a separate `LendTx` before the user's `GaslessApproveTx`/`GaslessSwapTx` bundle executes. The decision to admit the swap into the bundle is gated by `checkBalanceForSwap`, which queries the DEX router's *current* spot price via `GetAmountIn` on the swap router contract. Because this price check is read from the head state at admission time and is not re-verified atomically with the same transaction that performs the token swap, an attacker can manipulate the DEX reserves used by `GetAmountIn` between admission and execution (or simply choose `AmountIn`/`MinAmountOut` values that pass the mempool heuristic but fail during actual on-chain execution), while the `LendTx` unconditionally transfers KAIA to the user regardless of whether the subsequent swap later succeeds and repays the proposer. [1](#0-0) 

### Finding Description
`GaslessModule.checkBalanceForSwap` is the only pre-admission "solvency" check for a `GaslessSwapTx`. When `ShouldCheckSwapAmount()` is enabled, it calls the swap router's `GetAmountIn(token, minAmountOut)` — a live, spot-price-derived read from the DEX pool's current reserves — and compares it against the user-declared `AmountIn`: [2](#0-1) 

This is structurally the same class of bug as the WooFi incident: a settlement-relevant amount is derived from a spot price that is read once, outside of the atomic operation it is meant to protect, and can diverge from the price that will actually apply when the protected operation (the swap) executes. In WooFi, `sPMM` adjusted the price based on trade value with a check that didn't correctly bound WOO's price, letting a flash loan push the price out of range before the pool was drained. In `kaiax/gasless`, the analogous "protection" is `GetAmountIn`'s spot read, but it:

1. Is evaluated against the current chain head at tx-pool admission time (`bc := backends.NewBlockchainContractBackend(g.Chain, nil, nil)`), not against the exact state right before the bundle executes in the block being built.
2. Has no atomicity with the value that is actually transferred to the user. The `LendTx` generated by `GetLendTxGenerator` sends `lendAmount()` KAIA to the swap sender unconditionally, and this amount is derived purely from the transactions' declared gas fees, independent of whether the swap will actually succeed or produce sufficient output to repay: [3](#0-2) [4](#0-3) 

Because `LendTx` and `GaslessSwapTx` are two independent Kaia transactions bundled together (not one atomic EVM call), if the `GaslessSwapTx` later reverts or otherwise fails to repay `AmountRepay` back to the proposer (e.g., because the DEX price moved between the tx-pool's spot check and actual execution, or because reserves were manipulated by a transaction ordered earlier in the same block), the `LendTx` payment to the user is not rolled back. The user receives free KAIA from the block proposer with no corresponding repayment — a direct value-extraction path reachable by any gasless/public swap-tx submitter, matching the "unauthorized value movement" impact class from the WooFi-style spot-price manipulation.

I was unable to inspect the Solidity source of `GaslessSwapRouter.swapForGas` (only compiled Go bindings are indexed in this repo), so I cannot confirm from source whether `swapForGas` enforces `minAmountOut` strictly enough to always revert cleanly on manipulated prices, or whether any edge case (e.g., partial execution, non-reverting failure path, or rounding in `GetAmountIn` vs. the router's actual swap function) allows the swap to under-repay without reverting. This is a gap in available context; a background engineer with full repo/file access should review `contracts/*/GaslessSwapRouter.sol` (source, not just bindings) to confirm exact repay enforcement.

### Impact Explanation
If the swap can be caused to fail (or repay less than `AmountRepay`) after the `LendTx` has already unconditionally paid out KAIA, this is a direct theft of value from the block proposer, reachable by any unprivileged party who can submit a `GaslessApproveTx`/`GaslessSwapTx` pair to the public mempool and who can also influence the DEX pool's reserves (e.g., via their own prior trade, a partner-submitted trade, or natural price movement) between tx-pool admission and block inclusion. This satisfies the "gasless or auction settlement theft" and "unauthorized value movement" impact classes.

### Likelihood Explanation
Likelihood is Medium: the attacker needs to (a) get their `GaslessSwapTx` admitted while `checkBalanceForSwap`'s spot check happens to pass (attacker controls their own declared `AmountIn`/`MinAmountOut`, so they can tune this), and (b) ensure the swap under-delivers or reverts at execution time relative to the check. Since `GetAmountIn` is read once at admission against a state that can shift by the time the block containing the bundle is produced (especially under load, multiple pending gasless bundles, or attacker-controlled DEX activity), this is achievable without needing to compromise any validator or peer — purely through ordinary transaction submission, well within the "gasless user" trust boundary defined in scope.

### Recommendation
- Re-validate `checkBalanceForSwap`'s solvency condition (including the `GetAmountIn` check) against the exact state immediately preceding bundle execution during block assembly, not only at tx-pool admission time.
- Make the lend-and-repay flow atomic (or fail-safe) with respect to swap failure: e.g., have `LendTxGenerator`/bundle logic verify, at the point of building the block, that the swap will indeed produce at least `AmountRepay` given the current, in-block state, and drop the bundle (not send `LendTx`) if this cannot be guaranteed.
- Add a hard on-chain assertion in the swap-settlement path that reverts the entire bundle (or otherwise guarantees repayment) if actual swap output is insufficient, and ensure this is enforced against manipulation within the same block (e.g., using TWAP-like guards or reserve-manipulation resistant pricing rather than pure spot `getAmountIn`).

### Proof of Concept
Conceptual PoC (concrete parameters would require live DEX reserves and block-builder timing, which are not available in this static review):
1. Attacker (as the gasless-swap sender) crafts a `GaslessApproveTx` + `GaslessSwapTx` pair with `AmountIn`/`MinAmountOut` values chosen so that, given the DEX pool's state read by `checkBalanceForSwap` at admission time, the check in `kaiax/gasless/impl/tx_pool.go:135-141` passes.
2. Before the block containing this bundle is finalized, the attacker (or a colluding party) shifts the DEX pool's reserves (e.g., via another swap on the same pair, submitted and included earlier in the same block) so that the router's actual output for `AmountIn` is now below `MinAmountOut`/`AmountRepay`.
3. The block proposer includes the bundle: `LendTxGenerator` (kaiax/gasless/impl/getter.go:273-313) unconditionally sends `lendAmount()` KAIA to the attacker's address.
4. `GaslessSwapTx` executes with the now-unfavorable price, reverts (or returns less than `AmountRepay`) inside `swapForGas`; because `LendTx` and `GaslessSwapTx` are separate, non-atomic transactions, the KAIA already sent by `LendTx` is not clawed back.
5. Net effect: attacker retains the lent KAIA without repaying the proposer.

Note: full confirmation of step 4 (that `swapForGas` cannot itself claw back or otherwise guarantee proposer repayment on failure) requires the Solidity source of `GaslessSwapRouter`, which is not present in the indexed codebase (only ABI-generated Go bindings were available). This should be verified directly against the contract source before treating this as fully proven.

func (g *GaslessModule) checkBalanceForSwap(swapArgs *SwapArgs, swapNonce uint64) error {
	token := swapArgs.Token
	bc := backends.NewBlockchainContractBackend(g.Chain, nil, nil)

	g.gaslessInfoMu.RLock()
	swapRouter := g.swapRouter
	g.gaslessInfoMu.RUnlock()

	// tx.minAmountOut >= tx.amountRepay
	minAmountOut := swapArgs.MinAmountOut
	amountRepay := swapArgs.AmountRepay
	if minAmountOut.Cmp(amountRepay) < 0 {
		return fmt.Errorf("insufficient minAmountOut: minAmountOut=%s, amountRepay=%s", minAmountOut.String(), amountRepay.String())
	}

	if g.GaslessConfig.ShouldCheckSenderCode() {
		if g.getCurrentHasCode(swapArgs.Sender) {
			return errors.New("sender with code is not allowed")
		}
	}

	if g.GaslessConfig.ShouldCheckSwapAmount() {
		// tx.amountIn >= gsr.getAmountIn(minAmountOut)
		routerContract, err := kip247.NewGaslessSwapRouterCaller(swapRouter, bc)
		if err != nil {
			return err
		}
		// Required token amountIn, given the current exchange rate and the declared minAmountOut.
		requiredAmountIn, err := routerContract.GetAmountIn(nil, token, minAmountOut)
		if err != nil {
			return err
		}
		if swapArgs.AmountIn.Cmp(requiredAmountIn) < 0 {
			return fmt.Errorf("insufficient amountIn: have=%s, want=%s", swapArgs.AmountIn.String(), requiredAmountIn.String())
		}
	}

// L1. LendTx.type = 0x7802 (TxTypeEthereumDynamicFee)
// L2. LendTx.from = proposer
// L3. LendTx.to = SwapTx.from

func (g *GaslessModule) GetLendTxGenerator(approveTxOrNil, swapTx *types.Transaction) *builder.TxOrGen {
	var src []byte
	if approveTxOrNil != nil {
		src = append(src, approveTxOrNil.Hash().Bytes()...)
	}
	src = append(src, swapTx.Hash().Bytes()...)
	bundleHash := crypto.Keccak256Hash(src)

	gen := func(nonce uint64) (*types.Transaction, error) {
		var (
			chainId = g.InitOpts.ChainConfig.ChainID
			signer  = types.LatestSignerForChainID(chainId)
			key     = g.InitOpts.NodeKey
		)

		to, err := types.Sender(signer, swapTx)
		if err != nil {
			return nil, err
		}

		tx, err := types.NewTransactionWithMap(types.TxTypeEthereumDynamicFee, map[types.TxValueKeyType]interface{}{
			types.TxValueKeyNonce:      nonce,
			types.TxValueKeyTo:         &to,
			types.TxValueKeyAmount:     lendAmount(approveTxOrNil, swapTx),
			types.TxValueKeyData:       common.Hex2Bytes("0x"),
			types.TxValueKeyGasLimit:   params.TxGas,
			types.TxValueKeyGasFeeCap:  swapTx.GasFeeCap(),
			types.TxValueKeyGasTipCap:  swapTx.GasTipCap(),
			types.TxValueKeyAccessList: types.AccessList{},
			types.TxValueKeyChainID:    chainId,
		})
		if err != nil {
			return nil, err
		}

		err = tx.Sign(signer, key)
		return tx, err
	}

	return builder.NewTxOrGenFromGen(gen, bundleHash)
}

func lendAmount(approveTxOrNil, swapTx *types.Transaction) *big.Int {
	r := new(big.Int)

	// R2 = ApproveTx.Fee() if exists
	if approveTxOrNil != nil {
		r.Add(r, approveTxOrNil.Fee())
	}

	// R3 = SwapTx.Fee()
	r.Add(r, swapTx.Fee())

	// LendAmount = R2 + R3
	return r
}
