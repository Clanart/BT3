`from_private` in `stacks-common/src/util/secp256k1/wasm.rs` derives a public key from a private key using `LibSecp256k1PublicKey::from_secret_key_with_context` [1](#0-0) . This function is only invoked when a party holding a private key wants to compute the corresponding public key (e.g., during signing/keychain operations) — it is not part of the `consensus_deserialize`/parsing path for an incoming transaction at all.

When a node receives a raw transaction via `/v2/transactions`, the auth verification path recovers the public key from the signature and message hash using `Secp256k1PublicKey::recover_to_pubkey` / `recover_to_pubkey_possibly_with_low_s_verification`, which calls `secp256k1_recover`, not `from_private` [2](#0-1) . `from_private` has no code path reachable from parsing/deserializing/verifying attacker-supplied transaction bytes — it requires possession of the private key, which the verifier never has for a transaction it is validating.

Since `from_private` cannot be reached through `consensus_deserialize` or transaction verification of attacker-posted bytes, there is no way for this function to cause a `serialize(deserialize(b)) != b` divergence for an accepted transaction. The claimed exploit path (attacker POSTs a tx that round-trips differently because of `from_private`) has no corresponding code path in this repository.

    #[cfg(not(feature = "wasm-deterministic"))]
    fn recover_to_pubkey_possibly_with_low_s_verification(
        msg: &[u8],
        sig: &MessageSignature,
        verify_low_s: bool,
    ) -> Result<Secp256k1PublicKey, &'static str> {
        if verify_low_s {
            let signature = LibSecp256k1Signature::parse_standard_slice(&sig[..64])
                .map_err(|_| "Invalid signature: incorrect length")?;
            let mut sig_low_s = signature;
            sig_low_s.normalize_s();
            if signature != sig_low_s {
                return Err("Invalid signature: high-S");
            }
        }
        let secp256k1_sig = secp256k1_recover(msg, sig.as_bytes())
            .map_err(|_e| "Invalid signature: failed to recover public key")?;

        Secp256k1PublicKey::from_slice(&secp256k1_sig)
    }
