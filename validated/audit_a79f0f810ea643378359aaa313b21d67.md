### Title
Single bundle incorporation failure discards all valid bundles for the block - (File: work/builder/builder.go)

### Summary
`ExtractBundlesAndIncorporate` aggregates bundles from every registered `TxBundlingModule` (gasless swaps, auction bids) and calls `IncorporateBundleTx` to splice them into the transaction list. `IncorporateBundleTx` iterates over all bundles and applies `incorporate` one at a time; if any single bundle's `TargetTxHash` is not found (`ErrFailedToIncorporateBundle`), the whole call errors out and the caller discards every bundle, falling back to plain flattened transactions. ### Finding Description
`ExtractBundlesAndIncorporate` calls each registered `TxBundlingModule.ExtractTxBundles` (e.g. the gasless module for lend/approve/swap bundles and the auction module for bid bundles), collects non-conflicting bundles, then calls `IncorporateBundleTx(arrayTxs, bundles)` to insert them into the pending tx ordering [4](#0-3) .

`IncorporateBundleTx` loops sequentially over every bundle and calls `incorporate` for each; on the **first** error it returns `nil, err` for the entire batch [5](#0-4) . `incorporate` returns `ErrFailedToIncorporateBundle` whenever a bundle's `TargetTxHash` is not present among the input `txs` (`targetFound` stays false) [6](#0-5) .

Back in `ExtractBundlesAndIncorporate`, when `IncorporateBundleTx` errors, the function silently discards *all* extracted bundles and returns only the flattened, un-bundled transaction list [7](#0-6) . This is directly analogous to the reported Notional bug: a batch operation over logically independent units (here, independent gasless-swap and auction-bid bundles from potentially many different unrelated senders) fails as a whole because one unit's precondition is not met, even though the other units are perfectly valid and would have succeeded in isolation.

A target tx can plausibly go missing from the incoming `txs` array due to legitimate, attacker-influenceable conditions — e.g., a target transaction being reordered/dropped between mempool snapshot and bundle incorporation (block size limits, `FilterTxs` truncation by the auction module's early-deadline logic, or a conflicting/duplicate target hash race between gasless and auction bundle target coordination via `coordinateTargetTxHash`). Because `coordinateTargetTxHash` chains bundle target hashes together when multiple modules share a target, an inconsistency introduced by one module's bundle (e.g. an auction bid bundle whose target tx was filtered out) can cause `incorporate` to fail for that bundle, and the failure propagates to wipe out unrelated gasless-swap bundles for other senders in the same block-building pass.

### Impact Explanation
When triggered, a legitimate gasless-swap user's lend+approve+swap bundle or an auction winner's bid bundle can be silently dropped from block construction even though it was valid, simply because some unrelated bundle failed to incorporate. For gasless users this means the proposer-funded lend transaction and repayment swap are not atomically included as intended (potential loss of the lender's funds if the flattened re-ordering breaks the gasless nonce/target assumptions), and for auction winners this means their paid-for bid execution silently fails to be honored for the block despite being a valid, won auction — a denial-of-service/settlement-theft vector against gasless and auction users triggerable by any other bundle-producing transaction in the same block.

### Likelihood Explanation
This code path executes on every block-building pass whenever `txBundlingModules` produce more than zero bundles, which happens routinely once gasless or auction transactions are present in the pool. Triggering the failure only requires getting one bundle's target transaction to be absent from the incorporation input (e.g., via the auction `FilterTxs` early-deadline truncation, block size limits, or a conflicting-target race between gasless and auction bundles) — conditions reachable by ordinary transaction senders and auction bidders without any privileged access.

### Recommendation
Change `IncorporateBundleTx`/`ExtractBundlesAndIncorporate` to process bundles independently: if `incorporate` fails for one bundle, skip/drop only that bundle (and mark its underlying tx(s) as unexecutable/log it) rather than propagating the error to discard the entire flattened result. Return the successfully incorporated bundles/txs plus an explicit list of dropped bundle target hashes for observability.

### Proof of Concept
Conceptual sequence (block-building path, `work/worker.go` → `builder.ExtractBundlesAndIncorporate`):
1. Pending pool contains: Gasless user A's `[Approve_A, Swap_A]` (valid, target hash empty) and Auction winner B's bid bundle targeting `TargetTx_B`.
2. Auction module's `FilterTxs` (early-deadline logic) truncates `TargetTx_B` out of the per-sender tx list for that block due to timing [8](#0-7) , but the auction bundle for `TargetTx_B` was already extracted before filtering, or a race causes `TargetTx_B` to be absent from `arrayTxs` at incorporation time.
3. `ExtractBundlesAndIncorporate` builds bundles list `[GaslessBundle_A, AuctionBundle_B]` and calls `IncorporateBundleTx(arrayTxs, bundles)`.
4. `incorporate` processes `GaslessBundle_A` successfully (empty target, placed at front), then processes `AuctionBundle_B`; since `TargetTx_B` is not in `txs`, `targetFound` remains false and it returns `ErrFailedToIncorporateBundle`.
5. `IncorporateBundleTx` returns `nil, err` immediately — **discarding `GaslessBundle_A`'s already-successful incorporation as well**.
6. `ExtractBundlesAndIncorporate` catches the error and returns plain `flattenedTxs, nil`, meaning gasless user A's lend/repay bundle is not honored as a bundle for this block, purely because of an unrelated auction bundle's failure.

func IncorporateBundleTx(txs []*types.Transaction, bundles []*Bundle) ([]*TxOrGen, error) {
	ret := make([]*TxOrGen, len(txs))
	for i, tx := range txs {
		ret[i] = NewTxOrGenFromTx(tx)
	}

	for _, bundle := range bundles {
		var err error
		ret, err = incorporate(ret, bundle)
		if err != nil {
			return nil, err
		}
	}
	return ret, nil
}

// incorporate assumes that `txs` does not contain any bundle transactions.
func incorporate(txs []*TxOrGen, bundle *Bundle) ([]*TxOrGen, error) {
	ret := make([]*TxOrGen, 0, len(txs)+len(bundle.BundleTxs))
	targetFound := false

	// 1. place bundle at the beginning
	if bundle.TargetTxHash == (common.Hash{}) {
		ret = append(ret, bundle.BundleTxs...)
		targetFound = true
	}

	// 2. place bundle after TargetTxHash
	for _, txOrGen := range txs {
		// if tx-in-bundle, the tx will be appended when target is found.
		if bundle.Has(txOrGen) {
			continue
		}
		ret = append(ret, txOrGen)
		if txOrGen.Id == bundle.TargetTxHash {
			targetFound = true
			ret = append(ret, bundle.BundleTxs...)
		}
	}

	if !targetFound {
		return nil, ErrFailedToIncorporateBundle
	}

	return ret, nil
}

func ExtractBundlesAndIncorporate(arrayTxs []*types.Transaction, txBundlingModules []TxBundlingModule) ([]*TxOrGen, []*Bundle) {
	// Detect bundles and add them to bundles
	bundles := []*Bundle{}
	flattenedTxs := []*TxOrGen{}
	if txBundlingModules == nil {
		for _, tx := range arrayTxs {
			flattenedTxs = append(flattenedTxs, NewTxOrGenFromTx(tx))
		}
		return flattenedTxs, nil
	}

	for _, txBundlingModule := range txBundlingModules {
		newBundles := txBundlingModule.ExtractTxBundles(arrayTxs, bundles)
		for _, newBundle := range newBundles {
			isConflict := false
			// Check for conflicts with all previous bundles
			for _, prevBundle := range bundles {
				isConflict = prevBundle.IsConflict(newBundle)
				if isConflict {
					break
				}
			}
			// Not allowing empty bundles
			if !isConflict && len(newBundle.BundleTxs) > 0 {
				bundles = append(bundles, newBundle)
			}
		}
	}

	// Coordinate target tx hash of bundles. It assumes the Gasless and Auction modules only currently.
	// This reordering does not break the execution result.
	// For example, if bundle reordering breaks the nonce ordering, the execution result will be different.
	bundles = coordinateTargetTxHash(bundles)

	incorporatedTxs, err := IncorporateBundleTx(arrayTxs, bundles)
	if err != nil {
		return flattenedTxs, nil
	}

	return incorporatedTxs, bundles
}

func (a *AuctionModule) FilterTxs(txs map[common.Address]types.Transactions) {
	if atomic.LoadUint32(&a.bidPool.running) == 0 {
		return
	}

	curBlock := a.Chain.CurrentBlock()
	if curBlock == nil {
		return
	}

	targetTxHashMap := a.bidPool.getTargetTxHashMap(curBlock.NumberU64() + 1)
	edOffset := a.AuctionConfig.EDOffset

	now := time.Now()
	deadline := now.Add(-edOffset)
	// filter txs that are after the auction early deadline
	for addr, list := range txs {
		for i, tx := range list {
			if tx.Time().After(deadline) && !a.isGaslessTx(tx) {
				// if the tx is a target tx, skip it
				if _, ok := targetTxHashMap[tx.Hash()]; ok {
					continue
				}

				if i == 0 {
					// if first transaction exceeds deadline, remove the address
					delete(txs, addr)
				} else {
					// keep only transactions before the deadline
					txs[addr] = list[:i]
				}
				break
			}
		}
	}
