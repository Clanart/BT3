### Title
Unrecovered `sdk.Dec` Overflow Panic in Oracle Cross-Rate Division Can Halt the Chain - (File: x/oracle/abci.go)

### Summary
The Sherlock report describes an arithmetic-overflow issue in a price oracle contract where `int256 price * 1e10` can overflow without validation. The analogous, concretely reachable issue in sei-chain is in the Oracle module's `MidBlocker`, which performs an un-recovered `sdk.Dec.Quo()` division when converting a denom's cross-exchange-rate back to its base form. Unlike the two other overflow-prone arithmetic operations in the same tally pipeline, this specific division has no panic recovery, and a validator/feeder-controlled price vote can drive it into an overflow panic that occurs deterministically in `MidBlocker`/`EndBlocker`, which is unrecoverable ABCI lifecycle code (not per-tx `runTx`, which does recover panics).

### Finding Description
`MidBlocker` computes a reference-denom exchange rate, then for every other whitelisted denom computes a cross rate and converts it back to the base form: [1](#0-0) 

The critical line is:
```go
if denom != referenceDenom {
    exchangeRate = exchangeRateRD.Quo(exchangeRate)
}
``` [2](#0-1) 

`sdk.Dec.Quo` computes the quotient and calls `assertInValidRange()`, which panics if the result exceeds the maximum representable `Dec` (this is the same pattern used by `MulInt`/`MulInt64`, which explicitly call `assertInValidRange()` after arithmetic): [3](#0-2) 

Crucially, the codebase already demonstrates awareness of overflow risk in this exact tally pipeline, but the mitigation is incomplete:
- `ExchangeRateBallot.ToCrossRate` wraps its own `Quo` call in a `recover()` that resets the vote to a zero rate/zero power on overflow: [4](#0-3) 
- `StandardDeviation` similarly wraps its computation in a `recover()`: [5](#0-4) 

However, the second, outer `Quo` call performed directly in `abci.go` (line 94, `exchangeRateRD.Quo(exchangeRate)`) has **no such recovery**. `exchangeRateRD` is the reference denom's weighted-median vote value, which is bounded only by the loose check in `MsgAggregateExchangeRateVote.ValidateBasic`:

```go
if exchangeRate.ExchangeRate.BigInt().BitLen() > 255+sdk.DecimalPrecisionBits {
    return sdkerrors.Wrap(ErrInvalidExchangeRate, "overflow")
}
``` [6](#0-5) 

This bound still permits `exchangeRateRD` to be close to `Dec`'s maximum representable value. Meanwhile `exchangeRate` (the post-cross-rate, post-`Tally` value for a non-reference denom) only needs to be a small nonzero `Dec` (as small as the smallest representable unit, `1e-18`) to pass the `exchangeRate.IsZero()` filter at line 87. Dividing a near-maximum `exchangeRateRD` by a near-minimum nonzero `exchangeRate` overflows `Dec`'s valid range and panics inside `assertInValidRange()`.

### Impact Explanation
`MidBlocker`/`EndBlocker` run deterministically on every validator during block processing, not inside the per-transaction `runTx` execution path that recovers panics. An unrecovered panic here crashes every validator identically at the same height, producing a full network halt (all nodes crash in the same deterministic state transition), which matches the accepted "validator halt" / "block delay beyond 2.5 seconds" impact class. This is reachable purely through oracle vote admission — an authorized price feeder submitting an `AggregateExchangeRateVote` with an extreme (but individually valid, per `ValidateBasic`) exchange rate for the reference denom together with a vote that cross-rates to a very small nonzero value for another whitelisted denom.

### Likelihood Explanation
The existing repository tests (`TestOverflowAndDivByZero`, `TestTallyOverflow`) show the team specifically tested overflow/div-by-zero scenarios in this tally pipeline and added `recover()` protection in `ToCrossRate` and `StandardDeviation`, indicating this is a known bug class in this exact code path. However, those tests exercise the *inner* `Quo` (inside `ToCrossRate`), not the *outer* `Quo` in `abci.go` line 94, which remains unguarded. Exploitability additionally depends on precise selection of vote values (extreme reference-denom rate + a cross rate that truncates to a very small nonzero `Dec` rather than exactly zero) to bypass the `IsZero()` filter, which requires some precision but is achievable by a validator/feeder who controls the exact decimal string submitted in `MsgAggregateExchangeRateVote`.

### Recommendation
Wrap the outer `exchangeRateRD.Quo(exchangeRate)` call in `x/oracle/abci.go` in the same `recover()`/bounds-check pattern already used in `ToCrossRate` and `StandardDeviation`, treating an overflow result the same way — dropping/skipping that denom's update for the current vote period instead of panicking. Additionally, consider tightening the `BitLen` check in `MsgAggregateExchangeRateVote.ValidateBasic` to a materially smaller bound relative to `Dec`'s max, since the current check still allows values large enough to overflow downstream arithmetic combined with legitimately-small quotient values.

### Proof of Concept
1. Feeder A (delegate for an active validator) submits `MsgAggregateExchangeRateVote` where the reference-denom rate is chosen as a `Dec` string just under the `BitLen` limit enforced in `ValidateBasic` (e.g., close to `Dec`'s maximum, as used in `TestOverflowAndDivByZero`'s `overflowRate`).
2. The same/other feeders submit votes for a second whitelisted denom crafted so that, after `ToCrossRate` (`refRate / voterRate`), the resulting weighted median in `Tally` is a very small nonzero `Dec` (e.g. `1e-18`), not exactly zero — this passes the `exchangeRate.IsZero()` check at `x/oracle/abci.go:87`.
3. At the end of the `VotePeriod`, `MidBlocker` executes `exchangeRateRD.Quo(exchangeRate)` at `x/oracle/abci.go:94`, computing `hugeReferenceRate / 1e-18`, which exceeds `Dec`'s valid range and panics in `assertInValidRange()`.
4. Because this occurs in `MidBlocker`, invoked identically by every validator processing the block, the panic crashes the entire validator set at the same height, halting the chain. [7](#0-6)

// ToCrossRate return cross_rate(base/exchange_rate) ballot
func (pb ExchangeRateBallot) ToCrossRate(bases map[string]sdk.Dec) (cb ExchangeRateBallot) {
	for i := range pb {
		vote := pb[i]

		if exchangeRateRT, ok := bases[string(vote.Voter)]; ok && vote.ExchangeRate.IsPositive() {
			// Quo will panic on overflow, so we wrap it in a defer/recover
			func() {
				defer func() {
					if r := recover(); r != nil {
						// if overflow, set exchange rate to 0 and power to 0
						vote.ExchangeRate = sdk.ZeroDec()
						vote.Power = 0
					}
				}()
				vote.ExchangeRate = exchangeRateRT.Quo(vote.ExchangeRate)
			}()
		} else {
			// If we can't get reference Sei exchange rate, we just convert the vote as abstain vote
			vote.ExchangeRate = sdk.ZeroDec()
			vote.Power = 0
		}

		cb = append(cb, vote)
	}

	return
}

// StandardDeviation returns the standard deviation by the power of the ExchangeRateVote.
func (pb ExchangeRateBallot) StandardDeviation(median sdk.Dec) (standardDeviation sdk.Dec) {
	if len(pb) == 0 {
		return sdk.ZeroDec()
	}

	defer func() {
		if e := recover(); e != nil {
			standardDeviation = sdk.ZeroDec()
		}
	}()

	sum := sdk.ZeroDec()
	for _, v := range pb {
		deviation := v.ExchangeRate.Sub(median)
		sum = sum.Add(deviation.Mul(deviation))
	}

	variance := sum.QuoInt64(int64(len(pb)))

	floatNum, _ := strconv.ParseFloat(variance.String(), 64)
	floatNum = math.Sqrt(floatNum)
	standardDeviation, _ = sdk.NewDecFromStr(fmt.Sprintf("%f", floatNum))

	return
}

// ValidateBasic implements sdk.Msg
func (msg MsgAggregateExchangeRateVote) ValidateBasic() error {
	_, err := sdk.AccAddressFromBech32(msg.Feeder)
	if err != nil {
		return sdkerrors.Wrapf(sdkerrors.ErrInvalidAddress, "Invalid feeder address (%s)", err)
	}

	_, err = sdk.ValAddressFromBech32(msg.Validator)
	if err != nil {
		return sdkerrors.Wrapf(sdkerrors.ErrInvalidAddress, "Invalid operator address (%s)", err)
	}

	if l := len(msg.ExchangeRates); l == 0 {
		return sdkerrors.Wrap(sdkerrors.ErrUnknownRequest, "must provide at least one oracle exchange rate")
	} else if l > 4096 {
		return sdkerrors.Wrap(sdkerrors.ErrInvalidRequest, "exchange rates string can not exceed 4096 characters")
	}

	exchangeRates, err := ParseExchangeRateTuples(msg.ExchangeRates)
	if err != nil {
		return sdkerrors.Wrap(sdkerrors.ErrInvalidCoins, "failed to parse exchange rates string cause: "+err.Error())
	}

	for _, exchangeRate := range exchangeRates {
		// Check overflow bit length
		if exchangeRate.ExchangeRate.BigInt().BitLen() > 255+sdk.DecimalPrecisionBits {
			return sdkerrors.Wrap(ErrInvalidExchangeRate, "overflow")
		}
	}
	return nil
}

func TestOverflowAndDivByZero(t *testing.T) {
	input := setup(t)
	params := input.OracleKeeper.GetParams(input.Ctx)
	params.Whitelist = types.DenomList{
		{Name: utils.MicroAtomDenom},
		{Name: utils.MicroEthDenom},
	}
	input.OracleKeeper.SetParams(input.Ctx, params)

	// Set vote targets
	input.OracleKeeper.ClearVoteTargets(input.Ctx)
	input.OracleKeeper.SetVoteTarget(input.Ctx, utils.MicroAtomDenom)
	input.OracleKeeper.SetVoteTarget(input.Ctx, utils.MicroEthDenom)

	// Test overflow case
	overflowRate := sdk.MustNewDecFromStr("7896044618658097711785492504343953926634992332820282019728792003956564819967.999999999999999999")
	smallRate := sdk.MustNewDecFromStr("0.000000000000000001")
	overflowVote := sdk.DecCoins{
		sdk.NewDecCoinFromDec(utils.MicroAtomDenom, overflowRate),
		sdk.NewDecCoinFromDec(utils.MicroEthDenom, smallRate),
	}
	makeAggregateVote(t, input, overflowVote, 0)
	makeAggregateVote(t, input, overflowVote, 1)
	makeAggregateVote(t, input, overflowVote, 2)

	// This should not panic
	oracle.MidBlocker(input.Ctx, input.OracleKeeper)
	oracle.EndBlocker(input.Ctx, input.OracleKeeper)

	// Verify no exchange rates were set for overflowed one
	rate, _, _, err := input.OracleKeeper.GetBaseExchangeRate(input.Ctx, utils.MicroAtomDenom)
	require.NoError(t, err)
	require.Equal(t, overflowRate, rate)
	_, _, _, err = input.OracleKeeper.GetBaseExchangeRate(input.Ctx, utils.MicroEthDenom)
	require.Error(t, err)

	input.Ctx = input.Ctx.WithBlockHeight(1)

	// Test divide by zero case
	zeroVote := sdk.DecCoins{
		sdk.NewDecCoinFromDec(utils.MicroAtomDenom, smallRate),
		sdk.NewDecCoinFromDec(utils.MicroEthDenom, overflowRate),
	}
	makeAggregateVote(t, input, zeroVote, 0)
	makeAggregateVote(t, input, zeroVote, 1)
	makeAggregateVote(t, input, zeroVote, 2)

	// This should not panic
	oracle.MidBlocker(input.Ctx, input.OracleKeeper)
	oracle.EndBlocker(input.Ctx, input.OracleKeeper)

	// Verify no exchange rates were set for either case
	rate, height, _, err := input.OracleKeeper.GetBaseExchangeRate(input.Ctx, utils.MicroAtomDenom)
	require.NoError(t, err)
	require.Equal(t, smallRate, rate)
	require.Equal(t, int64(1), height.Int64())
	_, _, _, err = input.OracleKeeper.GetBaseExchangeRate(input.Ctx, utils.MicroEthDenom)
	require.Error(t, err)
}
