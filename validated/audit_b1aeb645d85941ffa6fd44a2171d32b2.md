The claim rests on `translate_signers` accepting an attacker-controlled `program_id`, but the code shows this parameter is always the invoking program's own key, not attacker input.

In `cpi_common`, `caller_program_id` is fetched directly from the transaction context's current instruction context — `instruction_context.get_program_key()?` — which reflects the actual executing program (the real caller), and this value (not anything supplied by the attacker) is passed into `translate_signers` for PDA derivation via `Pubkey::create_program_address(&seeds_bytes, program_id)`. [1](#0-0) 

`translate_signers` itself only ever derives addresses using this passed-in `program_id`; there is no parameter in the syscall ABI (`signers_seeds_addr`/`signers_seeds_len`) that lets an attacker specify a different target `program_id` for derivation. [2](#0-1) 

Consequently, an attacker's program can only produce seeds that derive PDAs under its *own* program ID (the true caller), never under some other program's ID — `create_program_address` will simply produce a different (non-matching) address or fail with `PubkeyError` if the seeds don't correspond to a valid PDA of the actual caller. The subsequent privilege check in `prepare_next_cpi_instruction` (`signers.contains(account_key)`) only grants signer status for keys in this correctly-derived `signers` vector. [3](#0-2) 

The equivalent native path (`native_invoke_signed`) enforces the same binding explicitly and is documented as making it "structurally impossible for a builtin to vouch for a non-PDA address... as a signer," and the existing test `test_translate_signers` confirms derivation is always bound to the passed-in (real caller) `program_id`. [4](#0-3) [5](#0-4) 

There is no reachable path where `signers_seeds` can be validated against a `program_id` different from the actual `caller_program_id`, so the described forged-signer scenario is not possible.

pub fn translate_signers(
    program_id: &Pubkey,
    signers_seeds_addr: u64,
    signers_seeds_len: u64,
    invoke_context: &InvokeContext,
) -> Result<Vec<Pubkey>, Error> {
    let check_aligned = invoke_context.get_check_aligned();
    let memory_mapping = invoke_context.memory_contexts.memory_mapping()?;
    if signers_seeds_len > 0 {
        let signers_seeds = translate_slice::<VmSlice<VmSlice<u8>>>(
            memory_mapping,
            signers_seeds_addr,
            signers_seeds_len,
            check_aligned,
        )?;
        if signers_seeds.len() > MAX_SIGNERS {
            return Err(Box::new(CpiError::TooManySigners));
        }
        Ok(signers_seeds
            .iter()
            .map(|signer_seeds| {
                let untranslated_seeds = translate_slice::<VmSlice<u8>>(
                    memory_mapping,
                    signer_seeds.ptr(),
                    signer_seeds.len(),
                    check_aligned,
                )?;
                if untranslated_seeds.len() > MAX_SEEDS {
                    return Err(Box::new(InstructionError::MaxSeedLengthExceeded) as Error);
                }
                let seeds_bytes = untranslated_seeds
                    .iter()
                    .map(|untranslated_seed| {
                        translate_vm_slice(untranslated_seed, memory_mapping, check_aligned)
                    })
                    .collect::<Result<Vec<_>, Error>>()?;
                Pubkey::create_program_address(&seeds_bytes, program_id)
                    .map_err(|err| Box::new(CpiError::BadSeeds(err)) as Error)
            })
            .collect::<Result<Vec<_>, Error>>()?)
    } else {
        Ok(vec![])
    }
}

            .collect::<Result<Vec<Pubkey>, solana_pubkey::PubkeyError>>()
            .map_err(|e| e as u64)?;
