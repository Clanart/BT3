### Title
Gasless swap deadline is validated only once at tx-pool admission and never re-checked before block inclusion, allowing stale/expired swaps to be bundled and executed - (File: kaiax/gasless/impl/getter.go)

### Summary
The `kaiax/gasless` module decodes a `Deadline` parameter from every `GaslessSwapTx` (`swapForGas(token, amountIn, minAmountOut, amountRepay, deadline)`) [1](#0-0) , but the function that actually gates whether a swap is executable and eligible for bundling into a block, `VerifyExecutable`, never checks this field [2](#0-1) . The only place `Deadline` is ever compared against the current time is `checkBalanceForSwap`, which runs once when the transaction is first admitted to the transaction pool [3](#0-2) . This is the same bug class as the reported issue: a value intended to bound the validity window of an off-chain-constructed instruction (a signature in the original report, a user-specified `deadline` here) is checked once and then treated as valid indefinitely afterward, because the re-validation path (`IsExecutable`/`VerifyExecutable`, used both for tx-pool readiness and for actual block-building bundle extraction) omits the check entirely.

### Finding Description
`SwapArgs.Deadline` is populated by `decodeSwapTx` [4](#0-3)  and is meant to represent a user-imposed expiration for the swap (matching the KIP-247 `swapForGas(... , deadline)` interface). It is validated exactly once, in `GetCheckBalance()` → `checkBalanceForSwap()`, at the moment the transaction is accepted into the pool [5](#0-4) .

However, `IsExecutable`/`VerifyExecutable` — the function that:
- determines transaction-pool readiness for promotion (`isApproveTxReady`, `isSwapTxReady`) [6](#0-5) ,
- and gates bundle extraction at block-building time (`ExtractTxBundles`) [7](#0-6) 

only checks sender consistency (AP1), token consistency (SP1), approve-amount sufficiency (SP2), nonce sequencing (SP3), and repay-amount correctness (SP4) [8](#0-7) . Deadline is conspicuously absent from this list even though the doc comment enumerates all the conditions the function is supposed to enforce.

Because `IsReady`/`isReady` is re-evaluated by the tx-pool on every promotion attempt and by `ExtractTxBundles` during actual block assembly (potentially long after the original admission check, especially once combined with block-proposal timing/reorgs), a swap transaction whose `deadline` has since elapsed can still be judged "ready" and bundled with a `LendTxGenerator` transaction that unconditionally transfers KAIA to the sender to cover the swap's gas cost [9](#0-8) .

### Impact Explanation
The `LendTxGenerator` transaction pays out KAIA to the sender before the swap's actual on-chain repayment step executes. If the bundled `GaslessSwapTx` later fails or is disadvantageous to the proposer because its `deadline` has already passed by the time of inclusion (price/state could have moved, or the swap logic on the deployed `GaslessSwapRouter` contract may revert on an expired deadline), the module's own admission-time check provides no protection at that later point, since the node-side readiness/bundling logic (`VerifyExecutable`) never re-validates it. This can lead to the proposer lending KAIA for a swap that no longer meets the user's own declared time constraint, undermining the gasless settlement guarantee that repayment is guaranteed by construction. This is the direct on-chain analogue of the original M-9 issue: an expiration value is decoded/known but never enforced at the point where enforcement actually matters, effectively giving the transaction unbounded validity from the module's perspective.

### Likelihood Explanation
The precondition is straightforward and reachable by any unprivileged sender who can submit gasless transactions: submit a valid `GaslessApproveTx`/`GaslessSwapTx` pair whose `deadline` is set to expire shortly after admission, then rely on normal tx-pool/mempool timing (queue/pending timeouts of 10–30s, or slower/backed-up block production) for the deadline to lapse before the transaction is finally promoted and bundled at block-building time [10](#0-9) . No special privileges, node compromise, or consensus-message manipulation are required — only crafting an EOA transaction with a short deadline, which is the "public-RPC / gasless-user" reachable path explicitly in scope.

### Recommendation
Add a deadline check to `VerifyExecutable` in `kaiax/gasless/impl/getter.go`, comparing `swapArgs.Deadline` against the current chain time at the moment of readiness evaluation/bundle extraction (not just at initial pool admission), mirroring the check already present in `checkBalanceForSwap`. This ensures deadline enforcement happens at every point the transaction is judged executable, consistent with the fix pattern used for the original report (validating the time-bound condition at the point of actual use rather than only at initial acceptance).

### Proof of Concept
1. Attacker/user constructs a `GaslessApproveTx` + `GaslessSwapTx` pair where `SwapArgs.Deadline` is set to `now + 2 seconds`.
2. The pair is submitted to a node; `GetCheckBalance()` → `checkBalanceForSwap()` passes because `deadline >= currentBlock.Time()` holds at admission [3](#0-2) .
3. Due to normal network/mempool latency (or if the transaction sits in queue/pending state up to the `QueueTimeout`/`PendingTimeout` windows) [10](#0-9) , the deadline elapses before the transaction is actually promoted or included in a block.
4. When the proposer later calls `IsReady`/`isSwapTxReady` → `IsExecutable` → `VerifyExecutable`, none of SP1–SP4 fail, so the transaction is still judged "ready" and bundled via `ExtractTxBundles` with an unconditional `LendTxGenerator` payout [11](#0-10) [12](#0-11) , even though the user-declared deadline has already expired.

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

// MakeLendTx creates a transaction with following properties:
// L1. LendTx.type = 0x7802 (TxTypeEthereumDynamicFee)
// L2. LendTx.from = proposer
// L3. LendTx.to = SwapTx.from
// L4. LendTx.value = LendAmount(approveTxOrNil, swapTx)
func (g *GaslessModule) GetLendTxGenerator(approveTxOrNil, swapTx *types.Transaction) *builder.TxOrGen {
	var src []byte
	if approveTxOrNil != nil {
		src = append(src, approveTxOrNil.Hash().Bytes()...)
	}
	src = append(src, swapTx.Hash().Bytes()...)
	bundleHash := crypto.Keccak256Hash(src)

	gen := func(nonce uint64) (*types.Transaction, error) {
		var (
			chainId = g.InitOpts.ChainConfig.ChainID
			signer  = types.LatestSignerForChainID(chainId)
			key     = g.InitOpts.NodeKey
		)

		to, err := types.Sender(signer, swapTx)
		if err != nil {
			return nil, err
		}

		tx, err := types.NewTransactionWithMap(types.TxTypeEthereumDynamicFee, map[types.TxValueKeyType]interface{}{
			types.TxValueKeyNonce:      nonce,
			types.TxValueKeyTo:         &to,
			types.TxValueKeyAmount:     lendAmount(approveTxOrNil, swapTx),
			types.TxValueKeyData:       common.Hex2Bytes("0x"),
			types.TxValueKeyGasLimit:   params.TxGas,
			types.TxValueKeyGasFeeCap:  swapTx.GasFeeCap(),
			types.TxValueKeyGasTipCap:  swapTx.GasTipCap(),
			types.TxValueKeyAccessList: types.AccessList{},
			types.TxValueKeyChainID:    chainId,
		})
		if err != nil {
			return nil, err
		}

		err = tx.Sign(signer, key)
		return tx, err
	}

	return builder.NewTxOrGenFromGen(gen, bundleHash)
}

func (g *GaslessModule) isApproveTxReady(approveTx, nextTx *types.Transaction) bool {
	addr, err := types.Sender(g.signer, approveTx)
	if err != nil {
		return false
	}
	nonce := g.getCurrentStateNonce(addr)

	if approveTx.Nonce() != nonce {
		return false
	}
	if nextTx == nil || !g.IsSwapTx(nextTx) {
		return false
	}

	return g.IsExecutable(approveTx, nextTx)
}

// isSwapTxReady assumes that the caller checked `g.IsSwapTx(swapTx)`
func (g *GaslessModule) isSwapTxReady(swapTx, prevTx *types.Transaction) bool {
	addr, err := types.Sender(g.signer, swapTx)
	if err != nil {
		return false
	}
	nonce := g.getCurrentStateNonce(addr)

	var approveTx *types.Transaction
	if swapTx.Nonce() == nonce {
		approveTx = nil
	} else if swapTx.Nonce() == nonce+1 {
		if prevTx == nil || !g.IsApproveTx(prevTx) {
			return false
		}
		approveTx = prevTx
	} else {
		return false
	}

	return g.IsExecutable(approveTx, swapTx)
}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
}
