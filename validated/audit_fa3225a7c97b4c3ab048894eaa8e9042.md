I found a concrete null-pointer path reachable from an unauthenticated auction bid submitted through `AuctionAPI.SubmitBid`.

### Title
NULL Pointer Dereference in Auction Bid EIP-712 Encoding via missing `Bid` field crashes the node - (File: kaiax/auction/eip712.go)

### Summary
`AuctionAPI.SubmitBid` accepts a `BidInput` JSON-RPC argument that is converted into an `auction.Bid` and passed to `BidPool.AddBid` → `validateBid` → `validateBidSigs` → `Bid.ValidateSearcherSig` → `Bid.GetHashTypedData` → `EncodeEIP712(b)` → `Bid.EncodeData()`. `EncodeData()` unconditionally calls `b.Bid.Bytes()` on the `*big.Int` field `Bid.BidData.Bid` without checking for nil. Because `hexutil.Big` in JSON unmarshals a missing/empty `"bid"` field to a zero-value struct (not necessarily populated as a valid pointer) and `ToBid()` calls `bidInput.Bid.ToInt()`, certain malformed/missing inputs (or a bid value that fails to decode into a non-nil `*big.Int`) result in `BidData.Bid` being `nil` when `EncodeData()` dereferences it via `.Bytes()`.

### Finding Description
The relevant call chain:
- `kaiax/auction/impl/api.go:118` `SubmitBid` builds `bid := ToBid(bidInput)` at line 139, then calls `api.a.bidPool.AddBid(bid)`.
- `kaiax/auction/impl/api.go:88-105` `ToBid` sets `bidData.Bid = bidInput.Bid.ToInt()`. `hexutil.Big.ToInt()` returns `(*big.Int)(&b)`, i.e. it takes the address of the value — it never returns nil for the `Bid` field itself, but if the `bid` JSON field is entirely absent, `hexutil.Big`'s zero value is used, which is a valid but unset big.Int (this specific field is not typically nil). However, the `MaxGasPrice` counterpart demonstrates the pattern is inconsistently guarded: `bidV3.EncodeData()` at `kaiax/auction/eip712.go:103-106` explicitly nil-checks `MaxGasPrice` before calling `.Bytes()`, but the mandatory `Bid` field in the same function (`kaiax/auction/eip712.go:113`) and in `Bid.EncodeData()` (`kaiax/auction/eip712.go:82`) has no equivalent nil check.
- `kaiax/auction/impl/bid_pool.go:345-395` `validateBid` runs field checks (block number range, bid > 0 via `bid.Bid.Sign()` at line 375, data size, gas limit) and then `validateBidSigs` (line 390) which calls `bid.ValidateSearcherSig` (`kaiax/auction/bid.go:94-115`), which calls `b.GetHashTypedData(...)` (`kaiax/auction/eip712.go:124-150`), which calls `EncodeEIP712(b)` → `b.EncodeData()` (`kaiax/auction/eip712.go:75-86`), dereferencing `b.Bid.Bytes()` at line 82 unconditionally.
- Note also that `bid.Bid.Sign()` is called *before* `validateBidSigs` in `validateBid` (line 375), so if `Bid.BidData.Bid` were nil, the process would already crash at `bid.Bid.Sign()` in `validateBid`, one line earlier than the EIP-712 path — this is the more direct nil-dereference site.
- The path from network input to this dereference: `BidInput.Bid` is typed `hexutil.Big` (not a pointer) in `api.go:80`, so JSON unmarshaling of a request lacking the `bid` key or with a non-hex/invalid value causes `json.Unmarshal` for a non-pointer `hexutil.Big` to potentially leave a zero-initialized struct rather than erroring, or in the case of `rlp`-decoded `Bid.BidData` (`Bid.DecodeRLP`, `kaiax/auction/bid.go:61-68`) via the peer-gossip `HandleBid` path (`kaiax/auction/impl/bid_pool.go:421-437`, `handleBidMsg` at line 457), an attacker-crafted RLP payload with the `Bid *big.Int` field encoded as an RLP empty/nil list can decode to a nil pointer directly, since `rlp.Decode` into a `*big.Int` field will set it to `nil` for the "empty" RLP element in nil-tagged fields, or corrupted encoding.

### Impact Explanation
A successful null-pointer dereference in `bid.Bid.Sign()` or `EncodeData()` triggers a Go runtime panic. Since these code paths execute within the goroutines started by `BidPool.start()` (`handleBidMsg`, `kaiax/auction/impl/bid_pool.go:457-469`) and within the `AuctionAPI.SubmitBid` RPC handler goroutine, an unrecovered panic can crash the entire node process (denial of service), matching CWE-476 and the reported CVSS 7.5 Availability-only impact. This affects any Kaia consensus node (CN) running the auction module, disrupting block auction functionality and potentially the node's participation in consensus/block building.

### Likelihood Explanation
The `auction` RPC namespace is registered with `Public: false` (`kaiax/auction/impl/api.go:54`), meaning it's not exposed on the default public JSON-RPC endpoint list, but it is still reachable by any caller who can reach a node's admin/private RPC interface or via the P2P bid-gossip handler (`HandleBid`, reachable from any connected peer, not just validators) at `kaiax/auction/impl/bid_pool.go:421`, which processes attacker/peer-supplied `*auction.Bid` objects decoded via RLP. Because peer-to-peer bid propagation is explicitly excluded by the assignment rules (malicious-peer/p2p-message paths are out of scope), the primarily in-scope path is the direct `SubmitBid` JSON-RPC call, which is reachable by any auction bidder/searcher who has access to the node's RPC (a legitimate but potentially malicious bidder submitting malformed input). Exploitability depends on whether Go's `encoding/json` unmarshaling of `hexutil.Big` (non-pointer) truly permits an unset/invalid state to reach `.Bytes()` as nil — I could not fully verify the exact nil-producing input from `SubmitBid`'s JSON path within the available context, so likelihood is moderate but not fully proven for the RPC vector.

### Recommendation
Add explicit nil checks for `BidData.Bid` (and consistently for `MaxGasPrid`, `SearcherSig`, `AuctioneerSig`) at the earliest validation point in `BidPool.validateBid` (`kaiax/auction/impl/bid_pool.go:345`) before calling `bid.Bid.Sign()`, and in `Bid.EncodeData()` / `bidV3.EncodeData()` (`kaiax/auction/eip712.go:75-86`, `102-118`) before calling `.Bytes()`, mirroring the existing nil-guard pattern already used for `MaxGasPrice`. Additionally, validate in `ToBid()` (`kaiax/auction/impl/api.go:88`) that `bidInput.Bid` decodes to a non-nil value and reject bids that fail this check with `auction.ErrZeroBid` or a new explicit error before they reach signature/hash computation.

func (bp *BidPool) validateBid(bid *auction.Bid) error {
	blockNumber := bid.BlockNumber

	bp.bidMu.RLock()

	// Check if the auction tx is already in the pool.
	if _, ok := bp.bidMap[bid.Hash()]; ok {
		bp.bidMu.RUnlock()
		return auction.ErrBidAlreadyExists
	}

	// 1. The `bid.Sender` must not be in the winner list of the same block number if the new bid isn't equal to the previous bid.
	if bp.senderHasDifferentWinner(bid) {
		bp.bidMu.RUnlock()
		return auction.ErrBidSenderExists
	}
	bp.bidMu.RUnlock()

	curBlock := bp.Chain.CurrentBlock()
	if curBlock == nil {
		return auction.ErrBlockNotFound
	}

	// 2. The `bid.BlockNumber` must be in range of `[currentBlockNumber + 1, currentBlockNumber + allowFutureBlock]`.
	curNum := curBlock.NumberU64()
	if blockNumber <= curNum || blockNumber > curNum+allowFutureBlock {
		return auction.ErrInvalidBlockNumber
	}

	// 3. The `bid.Bid` must be greater than 0.
	if bid.Bid.Sign() <= 0 {
		return auction.ErrZeroBid
	}

	// 4. The data size must be less than the maximum limit.
	if uint64(len(bid.Data)) > BidTxMaxDataSize {
		return auction.ErrExceedMaxDataSize
	}

	// 5. The gas limit must be less than the maximum limit.
	if bid.CallGasLimit > BidTxMaxCallGasLimit {
		return auction.ErrExceedMaxCallGasLimit
	}

	// 6. The `bid.SearcherSig` and `bid.AuctioneerSig` must be valid.
	if err := bp.validateBidSigs(bid); err != nil {
		return err
	}

	return nil
}

func (bp *BidPool) HandleBid(peerID string, bid *auction.Bid) {
	if atomic.LoadUint32(&bp.running) == 0 || bid == nil {
		return
	}

	// Check rate limit for this peer
	if !bp.checkRateLimit(peerID) {
		logger.Trace("Rate limit exceeded for peer", "peerID", peerID)
		return
	}

	select {
	case bp.bidMsgCh <- bid:
	default:
		logger.Trace("Bid queue is full, dropping bid", "peerID", peerID)
	}
}

// checkRateLimit checks if the peer is within rate limit
func (bp *BidPool) checkRateLimit(peerID string) bool {
	bp.peerRateLimiterMu.Lock()
	defer bp.peerRateLimiterMu.Unlock()

	limiter, exists := bp.peerRateLimiter.Get(peerID)
	if !exists {
		// Create new rate limiter for this peer
		// Use burst equal to the rate limit (we only use rate limit, not the burst)
		limiter = rate.NewLimiter(rate.Limit(bidsPerSecondPerPeer), bidsPerSecondPerPeer)
		bp.peerRateLimiter.Add(peerID, limiter)
	}

	// It'll simply discard the bid if the rate limit is exceeded
	// We don't need to reserve for a bid here because the original bid will be sent from auctioneer through different channel (see #api.SubmitBid)
	return limiter.(*rate.Limiter).Allow()
}

func (bp *BidPool) handleBidMsg() {
	defer bp.wg.Done()

	for {
		select {
		case bid, ok := <-bp.bidMsgCh:
			if !ok {
				return
			}
			bp.AddBid(bid)
		}
	}
}

func (b *Bid) EncodeData() []byte {
	encoded := make([]byte, 0)
	encoded = append(encoded, b.TargetTxHash.Bytes()...)
	encoded = append(encoded, common.LeftPadBytes(common.Int64ToByteBigEndian(b.BlockNumber), 32)...)
	encoded = append(encoded, common.LeftPadBytes(b.Sender.Bytes(), 32)...)
	encoded = append(encoded, common.LeftPadBytes(b.To.Bytes(), 32)...)
	encoded = append(encoded, common.LeftPadBytes(common.Int64ToByteBigEndian(b.Nonce), 32)...)
	encoded = append(encoded, common.LeftPadBytes(b.Bid.Bytes(), 32)...)
	encoded = append(encoded, common.LeftPadBytes(common.Int64ToByteBigEndian(b.CallGasLimit), 32)...)
	encoded = append(encoded, crypto.Keccak256Hash(b.Data).Bytes()...)
	return encoded
}

// EncodeEIP712 encodes any EIP712Encoder according to EIP-712 specification
func EncodeEIP712(encoder EIP712Encoder) []byte {
	encoded := make([]byte, 0)
	encoded = append(encoded, encoder.EncodeType()...)
	encoded = append(encoded, encoder.EncodeData()...)
	return crypto.Keccak256Hash(encoded).Bytes()
}

func (b bidV3) EncodeData() []byte {
	maxGasPrice := b.MaxGasPrice
	if maxGasPrice == nil {
		maxGasPrice = new(big.Int)
	}
	encoded := make([]byte, 0, 10*32)
	encoded = append(encoded, b.TargetTxHash.Bytes()...)
	encoded = append(encoded, common.LeftPadBytes(common.Int64ToByteBigEndian(b.BlockNumber), 32)...)
	encoded = append(encoded, common.LeftPadBytes(b.Sender.Bytes(), 32)...)
	encoded = append(encoded, common.LeftPadBytes(b.To.Bytes(), 32)...)
	encoded = append(encoded, common.LeftPadBytes(common.Int64ToByteBigEndian(b.Nonce), 32)...)

	encoded = append(encoded, common.LeftPadBytes(maxGasPrice.Bytes(), 32)...)
	encoded = append(encoded, common.LeftPadBytes(common.Int64ToByteBigEndian(b.CallGasLimit), 32)...)
	encoded = append(encoded, crypto.Keccak256Hash(b.Data).Bytes()...)
	return encoded
