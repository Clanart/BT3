### Title
Gasless settlement theft via non-atomic Lend/Swap bundle allowing unrepaid gas advances - (File: kaiax/gasless/impl/builder.go)

### Summary
The 88mph incident stemmed from a minting/settlement contract (`MPHMinter`) that let an attacker extract real value (LP-pool ETH) without the accompanying accounting/repayment constraint being enforced atomically. The closest reachable analog in this codebase is Kaia's gasless-transaction (KIP-247) settlement flow, where the proposer's `LendTx` unconditionally transfers real KAIA to a gasless-swap sender, and the borrower's repayment is expected to occur inside a *separate*, non-atomically-linked `GaslessSwapTx`. Structural/nonce validation (`VerifyExecutable`) is checked at bundling time, but the economic pre-conditions (`checkBalanceForSwap`) that guarantee the swap will actually succeed and repay the loan are only enforced during **mempool promotion**, not re-verified at the point the bundle is built into a block.

### Finding Description
`GetLendTxGenerator` in [1](#0-0)  creates a real-value transaction (`LendTx.value = lendAmount(...)`) from the proposer to the gasless-swap sender, funded purely from `approveTxOrNil.Fee() + swapTx.Fee()`. The bundle `[LendTxGenerator, GaslessApproveTx, GaslessSwapTx]` is assembled in `ExtractTxBundles` [2](#0-1) , gated only by `g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx)`.

`IsExecutable`/`VerifyExecutable` [3](#0-2)  only checks structural conditions: token/router whitelisting, sender matching, nonce sequencing, and that `AmountRepay` arithmetically equals `repayAmount(...)`. It does **not** check the sender's current token balance, current allowance, or the DEX's current quoted `amountIn` for the declared `minAmountOut` — those economic checks live only in `checkBalanceForSwap`, which is wired to `GetCheckBalance()` for **tx-pool admission** [4](#0-3) , and are further gated by an operator-configurable `BalanceCheckLevel` [5](#0-4) .

Because `LendTx` and `GaslessSwapTx` are two independent top-level transactions bundled together rather than a single atomic call, the KAIA transfer in `LendTx` commits to state regardless of whether the subsequent `GaslessSwapTx` succeeds. If the swap reverts on-chain — e.g., because the sender's token balance/allowance changed after mempool admission but before inclusion (TOCTOU), or the DEX price moved past `minAmountOut` between promotion and block building — the repayment logic inside `swapForGas` (which is expected to pull `AmountRepay` worth of output token/KAIA back to the router/proposer) never executes, yet the sender has already received the lent KAIA. There is no re-validation of `checkBalanceForSwap` conditions at `ExtractTxBundles` time, only the weaker `VerifyExecutable` structural check.

### Impact Explanation
An unprivileged gasless-swap sender (a normal transaction submitter, fully in-scope as a "gasless user") can obtain real KAIA (funded by the block proposer via `LendTx`) while ensuring or engineering the paired `GaslessSwapTx` fails to repay it — draining proposer-advanced gas funds. This is a concrete instance of "gasless … settlement theft" as defined in the validation rubric: unauthorized value movement from the proposer to the attacker without the offsetting repayment being enforced atomically.

### Likelihood Explanation
Medium. The attacker fully controls timing of their own balance/allowance changes (e.g., transferring away tokens or revoking approval immediately after their `GaslessApproveTx`/`GaslessSwapTx` pair is admitted to the pool but before the proposer includes the bundle), and pool-to-block latency naturally creates the TOCTOU window described. Exploitation requires no special privilege — only submitting a standard gasless approve+swap bundle and racing a follow-up transaction, both of which any public-RPC caller can do.

### Recommendation
- Re-verify all `checkBalanceForSwap`/`checkBalanceForApprove` economic preconditions (balance, allowance, DEX quote) at bundle-build time in `ExtractTxBundles`, not only at pool admission.
- Make `LendTx` and `GaslessSwapTx` execution atomic/conditional — e.g., only broadcast/include the generated `LendTx` if a simulation of the paired `GaslessSwapTx` against the block-building state succeeds, or structure repayment so a failed swap cannot leave the lend transfer un-reverted.
- Consider forcing `BalanceCheckLevel = BalanceCheckLevelAll` (i.e., ignore the operator-tunable flag for this specific value-transfer path) since disabling these checks directly enables the unrepaid-lend scenario.

### Proof of Concept
Conceptual (not executed against a live node — I could not verify the exact revert semantics of `GaslessSwapRouter.swapForGas`'s bytecode from the index, so this should be validated with a testnet run):
1. Attacker acquires a small amount of an allowed ERC20 token and approves the `GaslessSwapRouter`.
2. Attacker submits `GaslessApproveTx` + `GaslessSwapTx` with `minAmountOut`/`amountRepay` computed to pass `VerifyExecutable` and `checkBalanceForSwap` at admission time.
3. Once promoted to pending (and thus eligible for bundling via `ExtractTxBundles`), attacker immediately transfers away the approved token balance (or revokes allowance) in a separate transaction.
4. Proposer builds the block: `LendTxGenerator` fires, sending `lendAmount(...)` KAIA to attacker's address [6](#0-5) ; the `GaslessSwapTx` then reverts on-chain due to insufficient balance/allowance.
5. Attacker keeps the lent KAIA; the proposer absorbs the loss with no repayment, as `ExtractTxBundles` did not re-check economic balance conditions before including the bundle [7](#0-6) .

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

// MakeLendTx creates a transaction with following properties:
// L1. LendTx.type = 0x7802 (TxTypeEthereumDynamicFee)
// L2. LendTx.from = proposer
// L3. LendTx.to = SwapTx.from
// L4. LendTx.value = LendAmount(approveTxOrNil, swapTx)
func (g *GaslessModule) GetLendTxGenerator(approveTxOrNil, swapTx *types.Transaction) *builder.TxOrGen {
	var src []byte
	if approveTxOrNil != nil {
		src = append(src, approveTxOrNil.Hash().Bytes()...)
	}
	src = append(src, swapTx.Hash().Bytes()...)
	bundleHash := crypto.Keccak256Hash(src)

	gen := func(nonce uint64) (*types.Transaction, error) {
		var (
			chainId = g.InitOpts.ChainConfig.ChainID
			signer  = types.LatestSignerForChainID(chainId)
			key     = g.InitOpts.NodeKey
		)

		to, err := types.Sender(signer, swapTx)
		if err != nil {
			return nil, err
		}

		tx, err := types.NewTransactionWithMap(types.TxTypeEthereumDynamicFee, map[types.TxValueKeyType]interface{}{
			types.TxValueKeyNonce:      nonce,
			types.TxValueKeyTo:         &to,
			types.TxValueKeyAmount:     lendAmount(approveTxOrNil, swapTx),
			types.TxValueKeyData:       common.Hex2Bytes("0x"),
			types.TxValueKeyGasLimit:   params.TxGas,
			types.TxValueKeyGasFeeCap:  swapTx.GasFeeCap(),
			types.TxValueKeyGasTipCap:  swapTx.GasTipCap(),
			types.TxValueKeyAccessList: types.AccessList{},
			types.TxValueKeyChainID:    chainId,
		})
		if err != nil {
			return nil, err
		}

		err = tx.Sign(signer, key)
		return tx, err
	}

	return builder.NewTxOrGenFromGen(gen, bundleHash)
}

func lendAmount(approveTxOrNil, swapTx *types.Transaction) *big.Int {
	r := new(big.Int)

	// R2 = ApproveTx.Fee() if exists
	if approveTxOrNil != nil {
		r.Add(r, approveTxOrNil.Fee())
	}

	// R3 = SwapTx.Fee()
	r.Add(r, swapTx.Fee())

	// LendAmount = R2 + R3
	return r
}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
}

func (g *GaslessModule) GetCheckBalance() func(tx *types.Transaction) error {
	return func(tx *types.Transaction) error {
		if approveArgs, ok := decodeApproveTx(tx, g.signer); ok {
			return g.checkBalanceForApprove(approveArgs)
		}
		if swapArgs, ok := decodeSwapTx(tx, g.signer); ok {
			return g.checkBalanceForSwap(swapArgs, tx.Nonce())
		}
		return errors.New("not a gasless transaction") // should not happen because IsModuleTx is called before GetCheckBalance
	}
}
