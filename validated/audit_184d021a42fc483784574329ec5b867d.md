### Title
Gasless swap deadline is not re-validated when bundling and executing the transaction, allowing lending of KAIA after `SwapArgs.Deadline` has expired - ([File: kaiax/gasless/impl/getter.go])

### Summary
The Kaia gasless-transaction feature lends KAIA to a user (via `GetLendTxGenerator`) so that an approve+swap (or standalone swap) transaction pair can be executed without the user holding native gas. The user-supplied `SwapArgs.Deadline` is checked only in `checkBalanceForSwap`, which is invoked from `GetCheckBalance` at tx-pool admission time. The function that actually decides whether a swap is executable and should be bundled/lent gas — `VerifyExecutable`/`IsExecutable` in `kaiax/gasless/impl/getter.go` — never inspects `Deadline` at all. Because block building (`ExtractTxBundles` in `kaiax/gasless/impl/builder.go`) and promotion readiness (`isSwapTxReady`/`isApproveTxReady` in `kaiax/gasless/impl/tx_pool.go`) both rely on `IsExecutable`/`VerifyExecutable`, a swap transaction that was valid (deadline in the future) when it entered the pool can still be bundled, lent gas, and executed once its deadline has already passed, as long as it survives in the pool/queue long enough. This mirrors the reported bug class: an expiry/validity window is enforced in one place but a downstream value-transferring code path fails to re-check it, letting stale, "expired" state still be honored for value extraction.

### Finding Description
`kaiax/gasless/impl/tx_pool.go`'s `checkBalanceForSwap` explicitly enforces `tx.deadline >= currentTimestamp`: [1](#0-0) 

This check, however, is only wired through `GetCheckBalance`, which is a one-time gate used somewhere in the tx-pool admission flow: [2](#0-1) 

The actual authorization logic used to decide whether an approve/swap pair is a valid, executable gasless transaction — `VerifyExecutable` — enumerates conditions Sx, Ax, AP1, SP1–SP4, but there is no condition that checks `swapArgs.Deadline` against the current block time: [3](#0-2) 

This same `VerifyExecutable`/`IsExecutable` function is the sole gate used to:
- Decide bundling during block assembly (`ExtractTxBundles`), which calls `g.IsExecutable(approveTxs[addr], tx)` before constructing the lending bundle and generating the KAIA-lending transaction via `GetLendTxGenerator`: [4](#0-3) 
- Decide promotion readiness of queued swap/approve transactions (`isSwapTxReady`/`isApproveTxReady`), which also call `g.IsExecutable(...)`: [5](#0-4) 
- Answer the public `gasless_isGaslessTx` RPC, which calls `VerifyExecutable` directly without any prior deadline gate: [6](#0-5) 

Because `checkBalanceForSwap`'s deadline check runs once (at the moment the tx is first validated for pool admission), and the deadline is never re-verified at the point the block proposer actually decides to lend gas and bundle the transaction, a swap transaction can sit in the pool (subject only to `QueueTimeout`/`PendingTimeout`/`KnownTxTimeout`, which are wall-clock timers unrelated to the user's chosen `Deadline` value) and still be bundled and executed by `ExtractTxBundles` after `block.timestamp > swapArgs.Deadline`.

### Impact Explanation
If exploited, an unprivileged transaction sender could get a stale swap executed (and gas lent to them via `GetLendTxGenerator`) after their own declared deadline, defeating the deadline safety mechanism that is meant to protect the sender/router from unfavorable price movement (the underlying `swapForGas` DEX call presumably still enforces `minAmountOut`, but the deadline is a distinct protection against stale price execution and against holding open a lending commitment past its intended window). This constitutes acceptance of a transaction that should have been rejected per its own declared time-bound validity, and forces execution of value-moving code (KAIA lending + token swap) using state that the check was designed to invalidate — directly analogous to the reported StakingRewards issue where an unrelated code path continued to honor a validity window that had already expired elsewhere.

### Likelihood Explanation
Likelihood is moderate: the deadline is user-supplied, so triggering the discrepancy requires only that a swap transaction be submitted, admitted into the pool (deadline still valid at submission), and then remain pending/queued (e.g., due to network delay, low-fee competition, or an approve tx not yet promoted) until after the deadline elapses, after which the proposer's `ExtractTxBundles` path can still pick it up since `VerifyExecutable` performs no deadline check. No special privileges are needed; a single unprivileged sender-crafted transaction pair is sufficient to reach this code path.

### Recommendation
Add an explicit deadline check (`swapArgs.Deadline >= currentBlockTime`) inside `VerifyExecutable` in `kaiax/gasless/impl/getter.go`, so that the same authorization function used for tx-pool readiness, block-bundling (`ExtractTxBundles`), and the `gasless_isGaslessTx` RPC consistently rejects expired swaps, rather than relying solely on the one-time `checkBalanceForSwap` gate.

### Proof of Concept
1. Craft and submit a valid `approve` + `swapForGas` transaction pair with `deadline = currentBlockTime + 5`.
2. Ensure the pair is admitted to the pool (passes `checkBalanceForSwap`) but is not immediately promoted/bundled (e.g., by having the approve tx delayed, or by network conditions), so it remains queued past the 5-second deadline while still within `QueueTimeout`/`PendingTimeout` (10s).
3. Once `block.timestamp > deadline`, the proposer's `ExtractTxBundles` (`kaiax/gasless/impl/builder.go`) still calls `IsExecutable`/`VerifyExecutable`, which does not check `Deadline`, so the bundle (lend tx + approve + swap) is still constructed and included in a block, executing the swap after its declared deadline.

	return func(tx *types.Transaction) error {
		if approveArgs, ok := decodeApproveTx(tx, g.signer); ok {
			return g.checkBalanceForApprove(approveArgs)

		return errors.New("not a gasless transaction") // should not happen because IsModuleTx is called before GetCheckBalance
	}
}

// isApproveTxReady assumes that the caller checked `g.IsApproveTx(approveTx)`
func (g *GaslessModule) isApproveTxReady(approveTx, nextTx *types.Transaction) bool {
	addr, err := types.Sender(g.signer, approveTx)
	if err != nil {
		return false
	}
	nonce := g.getCurrentStateNonce(addr)

	if approveTx.Nonce() != nonce {
		return false
	}
	if nextTx == nil || !g.IsSwapTx(nextTx) {
		return false
	}

	return g.IsExecutable(approveTx, nextTx)
}

// isSwapTxReady assumes that the caller checked `g.IsSwapTx(swapTx)`
func (g *GaslessModule) isSwapTxReady(swapTx, prevTx *types.Transaction) bool {
	addr, err := types.Sender(g.signer, swapTx)
	if err != nil {
		return false
	}
	nonce := g.getCurrentStateNonce(addr)

	var approveTx *types.Transaction
	if swapTx.Nonce() == nonce {
		approveTx = nil
	} else if swapTx.Nonce() == nonce+1 {
		if prevTx == nil || !g.IsApproveTx(prevTx) {
			return false
		}
		approveTx = prevTx
	} else {
		return false
	}

	return g.IsExecutable(approveTx, swapTx)
}

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
}
