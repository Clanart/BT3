### Title
Removing a Wombat pool via `removePool` never decrements MasterMagpie's `totalAllocPoint`, permanently diluting yield for all other stakers - ([File: wombat/WombatStaking.sol])

### Summary
`WombatStaking.removePool()` only flips a local `isActive` flag on the `Pool` struct and never calls back into `MasterMagpie` to zero out the removed pool's `allocPoint`. Because `MasterMagpie.totalAllocPoint` is the denominator used every time rewards are calculated for *any* pool, the stale allocation weight of the "removed" pool stays baked into the denominator forever, permanently reducing the MGP emissions every other staker earns. This is the same root-cause class as the referenced Sherlock report M-6, where blacklisting a protocol decreased `currentAllocations[_protocolNum]` but never decremented the aggregate `totalAllocatedTokens`, permanently deflating yield for everyone else.

### Finding Description
`removePool` is defined as: [1](#0-0) 

It sets `pools[_lpToken].isActive = false` and emits `PoolRemoved`, but it never touches `MasterMagpie`. There is no `remove`/zero-out counterpart in `MasterMagpie` itself — the only functions that mutate `totalAllocPoint` are `add`, `set`, and `updatePoolsAlloc`: [2](#0-1) [3](#0-2) 

`totalAllocPoint` is the shared denominator used in every `updatePool` call across every registered staking token: [4](#0-3) 

Since `removePool` never invokes `MasterMagpie.set(receiptToken, 0, ...)` (or any equivalent) to zero the dead pool's `allocPoint`, that pool's weight remains counted inside `totalAllocPoint` indefinitely. Every subsequent `updatePool` call for every other live pool divides `mgpReward` by an inflated `totalAllocPoint`, so `accMGPPerShare` — and therefore every user's accrued/claimable MGP — is permanently understated. This mirrors the audited bug exactly: an admin-facing "deactivate" action decrements a per-item allocation but omits the corresponding decrement of the shared total used in the reward formula.

### Impact Explanation
This causes a permanent, protocol-wide reduction of MGP emissions to every staker across every active pool, for as long as the protocol operates (i.e., forever, once a pool has ever been removed). This is a permanent freezing/loss of a portion of unclaimed yield for all ordinary depositors, since the correct proportional share of emissions can never be recovered — the dead pool's `allocPoint` cannot be un-counted from `totalAllocPoint` through any existing external function.

### Likelihood Explanation
`removePool` is a normal, expected lifecycle operation (deprecating a pool whose underlying Wombat asset is retired or migrated) rather than a malicious action, so it will be exercised in ordinary protocol operation. Once triggered, the miscalculation affects all subsequent reward accruals system-wide with no additional preconditions, making the likelihood of occurrence high and the resulting effect unconditional and irreversible.

### Recommendation
When `removePool` (or any pool deactivation path) is executed, also call `IMasterMagpie(masterMagpie).set(pool.receiptToken, 0, pool.helper, pool.rewarder, ...)` (after `massUpdatePools()`/`updatePool` to settle pending rewards) so that `totalAllocPoint` is decremented by the removed pool's `allocPoint`, keeping the shared denominator consistent with only active pools.

### Proof of Concept
1. MasterMagpie has pools A and B, each with `allocPoint = 100`, so `totalAllocPoint = 200`.
2. Owner calls `WombatStaking.removePool(A)` to deprecate pool A after its Wombat asset is sunset. `pools[A].isActive` becomes `false`, but `tokenToPoolInfo[A].allocPoint` in `MasterMagpie` is untouched and `totalAllocPoint` remains `200`.
3. Pool B stakers continue calling `updatePool(B)`; `mgpReward = multiplier * mgpPerSec * 100 / 200`, i.e., they only receive half of the emissions that should now be entirely theirs (since pool A no longer has any live stakers/rewarder activity).
4. There is no external function that ever recomputes/decrements `totalAllocPoint` for the deactivated pool A, so pool B (and any future pools) permanently earn diluted rewards for the lifetime of the contract.

```text
    function updatePool(address _stakingToken) public whenNotPaused {
        PoolInfo storage pool = tokenToPoolInfo[_stakingToken];
        if (block.timestamp <= pool.lastRewardTimestamp || totalAllocPoint == 0) {
            return;
        }
        uint256 lpSupply = _calLpSupply(_stakingToken);
        if (lpSupply == 0) {
            pool.lastRewardTimestamp = block.timestamp;
            return;
        }        
        uint256 multiplier = block.timestamp - pool.lastRewardTimestamp;
        uint256 mgpReward = (multiplier * mgpPerSec * pool.allocPoint) / totalAllocPoint;
        
        pool.accMGPPerShare = pool.accMGPPerShare + ((mgpReward * 1e12) / lpSupply);
        pool.lastRewardTimestamp = block.timestamp;

        emit UpdatePool(
            _stakingToken,
            pool.lastRewardTimestamp,
            lpSupply,
            pool.accMGPPerShare
        );
    }    
```

```text
        uint256 _allocPoint,
        address _stakingToken,
        address _rewarder,
        address _helper,
        bool _helperNeedsHarvest
    ) external _onlyPoolManager {
        if (!Address.isContract(address(_stakingToken)))
            revert InvalidStakingToken();

        if (!Address.isContract(address(_helper)) && address(_helper) != address(0))
            revert MustBeContractOrZero();

        if (!Address.isContract(address(_rewarder)) && address(_rewarder) != address(0))
            revert MustBeContractOrZero();

        if (openPools[_stakingToken])
            revert PoolExsisted();

        massUpdatePools();
        uint256 lastRewardTimestamp = block.timestamp > startTimestamp
            ? block.timestamp
            : startTimestamp;
        totalAllocPoint = totalAllocPoint + _allocPoint;
        registeredToken.push(_stakingToken);
        tokenToPoolInfo[_stakingToken] = PoolInfo({
            stakingToken: _stakingToken,
            allocPoint: _allocPoint,
            lastRewardTimestamp: lastRewardTimestamp,
            accMGPPerShare: 0,
            rewarder: _rewarder,
            helper: _helper,
            helperNeedsHarvest: _helperNeedsHarvest
        });
        openPools[_stakingToken] = true;
        emit Add(_allocPoint, _stakingToken, IBaseRewardPool(_rewarder));
    }
```

```text
    function set(
        address _stakingToken,
        uint256 _allocPoint,
        address _helper,
        address _rewarder,
        bool _helperNeedsHarvest
    ) external _onlyPoolManager {
        if (!Address.isContract(address(_rewarder)) 
            && address(_rewarder) != address(0))
            revert MustBeContractOrZero();

        if (!Address.isContract(address(_helper)) 
            && address(_helper) != address(0))
            revert MustBeContractOrZero();            

        if (!openPools[_stakingToken])
            revert OnlyActivePool();

        massUpdatePools();

        totalAllocPoint = 
            totalAllocPoint - 
            tokenToPoolInfo[_stakingToken].allocPoint +
            _allocPoint;

        tokenToPoolInfo[_stakingToken].allocPoint = _allocPoint;
        tokenToPoolInfo[_stakingToken].rewarder = _rewarder;
        tokenToPoolInfo[_stakingToken].helper = _helper;
        tokenToPoolInfo[_stakingToken].helperNeedsHarvest = _helperNeedsHarvest;

        emit Set(
            _stakingToken,
            _allocPoint,
            IBaseRewardPool(tokenToPoolInfo[_stakingToken].rewarder)
        );
    }
```
