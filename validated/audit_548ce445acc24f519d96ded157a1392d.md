## Title
Wire-type-mismatched `debug_redact` fields are stored as `UnknownFieldSet` and printed unredacted by the "safe" `TextFormat`/`DebugString` printers - (`File: src/google/protobuf/text_format.cc`)

## Summary
The Ansible report's failed invariant is: a mechanism explicitly opted into by a developer to mask sensitive data (`no_log`) is bypassed because a different, earlier code path (argument validation) processes the attacker/user-controlled input *before* the masking logic has a chance to associate the value with its "sensitive" tag, so the raw value is disclosed in a downstream sink (verbose logs).

Protobuf has a direct analog for this bug class in its redaction feature (`debug_redact = true` field option, consumed by `TextFormat`'s "safe" printers and `Message::DebugString()`). Redaction is applied by looking up the *known* `FieldDescriptor` for a field and checking `GetRedactionState()`/`TryRedactFieldValue()`. However, when parsing bounded, attacker-controlled binary protobuf, any field whose wire type on the wire does not match the wire type implied by the schema for that field number is intentionally routed into the message's `UnknownFieldSet` rather than being assigned to the known (and potentially `debug_redact`-tagged) field. `TextFormat`'s unknown-field printer has no concept of field-level sensitivity annotations — it prints unknown fields generically by tag number and raw wire value. Consequently, an attacker who controls the wire bytes of a message containing a `debug_redact = true` field can force that specific field's value to be classified as "unknown" and have it printed in full by the very "safe"/redacting debug formatters that a downstream application relies on to keep the value out of logs.

## Finding Description
Redaction correctness in `TextFormat::Printer` depends entirely on identifying, for a given serialized byte range, which `FieldDescriptor` it belongs to, so that `TryRedactFieldValue()` can consult `TextFormat::GetRedactionState(field)` (built from `field->options().debug_redact()`, see `descriptor.proto` lines 776-778 and `edition_unittest.proto`/`unittest.proto` `RedactedFields` test messages) and substitute `"[REDACTED]"` for the value: [1](#0-0) 

That substitution logic is only reachable through `PrintField`/`PrintFieldValue`, which operate on `FieldDescriptor*` obtained from the message's known field list: [2](#0-1) [3](#0-2) 

But the C++ wire-format parser explicitly diverts a field into the `UnknownFieldSet` whenever the wire type on the wire does not match the wire type the schema expects for that field number (i.e. the "known field, wrong wire type" case), which is a normal, well-formed input class, not a corruption error: [4](#0-3) 

This is confirmed to be by-design ("wrong wire type" fields are "treated like unknown fields") in the existing test suite: [5](#0-4) 

Once a `debug_redact` field's bytes land in `UnknownFieldSet` instead of the known field slot, printing that message — even through the "safe"/redacting text-format path used by `Message::DebugString()`/`internal::StringifyMessage()` (which explicitly sets `SetRedactDebugString(true)`) — will print the value via the generic, tag-number-based unknown-field printer, which has no `debug_redact` awareness at all, because it never consults `FieldDescriptor::GetRedactionState()`: [6](#0-5) 

The Java implementation shows the same test-observed behavior pattern (mismatched-wire-type fields are treated identically to genuinely-unknown fields and are excluded from any field-specific processing such as `no_log`-equivalent handling): [7](#0-6) 

## Impact Explanation
This is a **Medium**-severity confidentiality issue, mirroring the CVSS vector of the Ansible report (`C:H/I:N/A:N`, local/low-privilege observer of logs). A downstream application that:
1. Defines a schema with a field marked `debug_redact = true` for a credential/secret, and
2. Relies on protobuf's "safe" `DebugString()`/`TextFormat::Printer` with redaction enabled to keep that value out of application logs/traces,

can have that guarantee silently defeated by an attacker who controls the raw bytes of the bounded, attacker-supplied binary payload (e.g., a gRPC/protobuf request body) that is later merely logged via `DebugString()`. Sending the sensitive field with a mismatched wire type (e.g. a `string` field's tag encoded with wire type `WIRETYPE_VARINT` instead of `WIRETYPE_LENGTH_DELIMITED`) forces the runtime to route the field into `UnknownFieldSet`, and when the application later prints/logs the parsed message using the "safe" debug format, the value is emitted in full (as a raw varint/bytes dump under the tag number) rather than being redacted. No exception is thrown, the message parses successfully, and application code has no signal that the redaction guarantee was bypassed.

## Likelihood Explanation
Likelihood is **moderate**: the attacker needs no special access — only the ability to construct a bounded, hand-crafted binary protobuf payload targeting a schema field number with an intentionally wrong wire type, which is trivial and well within "ordinary client sending bounded binary Protobuf through a supported public parse API." The precondition (application relying specifically on `debug_redact`-based redaction of `DebugString()`/safe `TextFormat` for logging, rather than, e.g., structured logging that never serializes the whole message) narrows real-world exposure somewhat, but this is exactly the intended use case documented for the `debug_redact` feature.

## Recommendation
- Document explicitly (if not already) that `debug_redact` does not protect field values that end up in `UnknownFieldSet` due to wire-type mismatches, so application authors are aware this specific escape path exists.
- Consider having `TextFormat`'s "safe"/redacting printers cross-reference unknown-field tag numbers against the message's own `Descriptor` to detect known-but-wire-type-mismatched field numbers, and redact/flag them (at minimum warn or drop) when the corresponding known field is `debug_redact = true`, analogous to how Ansible was fixed by moving `no_log` masking earlier, before validation short-circuits.
- Alternatively/additionally, consider optionally rejecting (rather than silently accepting into `UnknownFieldSet`) wire-type mismatches for fields explicitly marked `debug_redact = true`, since silently accepting them undermines the redaction contract.

## Proof of Concept
1. Define (trusted) schema:
```proto
message Secret {
  string token = 1 [debug_redact = true];
}
```
2. Construct an attacker-controlled binary payload where field 1 is encoded with the wrong wire type, e.g. as a varint instead of length-delimited bytes: bytes `0x08 0x01` (tag = field 1, wire type `VARINT`, value 1) instead of the correct `0x0A <len> <data>` (wire type `LENGTH_DELIMITED`).
3. Parse via the public API: `Secret msg; msg.ParseFromString(payload);` — this succeeds (`ParseFromString` returns true), and per `wire_format.cc` `_InternalParseAndMergeField` (lines 826-902) and the confirmed behavior in `unknown_field_set_unittest.cc` (`WrongTypeTreatedAsUnknown`), the value is stored in `msg.unknown_fields()` rather than `msg.token()`.
4. Application logs `msg.DebugString()` (the "safe"/redacting path per `text_format.cc` lines 118-148, `internal::StringifyMessage` with `SetRedactDebugString(true)`).
5. Expected (intended) behavior: `token: [REDACTED]` never appears at all, and no raw value is printed.
   Actual: the log output contains the raw unknown-field entry (e.g. `1: 1` in `PrintUnknownFields` generic format) exposing the value that the developer intended to redact via `debug_redact`.

Note: I was not able to directly execute this PoC (no code execution tool access in this environment) — this reproduction is derived from static analysis of `wire_format.cc`'s field-dispatch logic, the redaction call sites in `text_format.cc`, and the existing `unknown_field_set_unittest.cc`/`UnknownFieldSetTest.java` tests that confirm wire-type-mismatched known fields are treated as unknown fields with generic printing. void TextFormat::Printer::PrintField(const Message& message,
                                     const Reflection* reflection,
                                     const FieldDescriptor* field,
                                     BaseTextGenerator* generator) const {
  if (use_short_repeated_primitives_ && field->is_repeated() &&
      field->cpp_type() != FieldDescriptor::CPPTYPE_STRING &&
      field->cpp_type() != FieldDescriptor::CPPTYPE_MESSAGE) {
    PrintShortRepeatedField(message, reflection, field, generator);
    return;
  }

  int count = 0;

  if (field->is_repeated()) {
    count = reflection->FieldSize(message, field);
  } else if (reflection->HasField(message, field) ||
             field->containing_type()->options().map_entry()) {
    count = 1;
  }

  if (generator->failed()) return;
  bool is_map = field->is_map();
  const internal::MapEntries map_entries =
      is_map
          ? internal::MapFieldPrinterHelper::SortMap(message, reflection, field)
          : internal::MapEntries();

  for (int j = 0; j < count; ++j) {
    if (generator->failed()) return;
    const int field_index = field->is_repeated() ? j : -1;

    PrintFieldName(message, field_index, count, reflection, field, generator);

    if (field->cpp_type() == FieldDescriptor::CPPTYPE_MESSAGE) {
      if (TryRedactFieldValue(message, field, generator,
                              /*insert_value_separator=*/true)) {
        break;
      }
      const FastFieldValuePrinter* printer = GetFieldPrinter(field);
      const Message& sub_message =
          field->is_repeated()
              ? (is_map ? *map_entries.all_entries[j]
                        : reflection->GetRepeatedMessage(message, field, j))
              : reflection->GetMessage(message, field);
      printer->PrintMessageStart(sub_message, field_index, count,
                                 single_line_mode_, generator);
      generator->Indent();
      if (!printer->PrintMessageContent(sub_message, field_index, count,
                                        single_line_mode_, generator)) {
        Print(sub_message, generator);
      }
      generator->Outdent();
      printer->PrintMessageEnd(sub_message, field_index, count,
                               single_line_mode_, generator);
    } else {
      generator->PrintMaybeWithMarker(MarkerToken(), ": ");
      // Write the field value.
      PrintFieldValue(message, reflection, field, field_index, generator);
      if (single_line_mode_) {
        generator->PrintLiteral(" ");
      } else {
        generator->PrintLiteral("\n");
      }
    }
  }
}

bool TextFormat::Printer::TryRedactFieldValue(
    const Message& message, const FieldDescriptor* field,
    BaseTextGenerator* generator, bool insert_value_separator) const {
  TextFormat::RedactionState redaction_state =
      DescriptorPool::MemoizeProjection(
          field, [](const FieldDescriptor* field) {
            return TextFormat::GetRedactionState(field);
          });
  if (redaction_state.redact) {
    if (redact_debug_string_) {
      IncrementRedactedFieldCounter();
      if (insert_value_separator) {
        generator->PrintMaybeWithMarker(MarkerToken(), ": ");
      }
      generator->PrintString(kFieldValueReplacement);
      if (insert_value_separator) {
        if (single_line_mode_) {
          generator->PrintLiteral(" ");
        } else {
          generator->PrintLiteral("\n");
        }
      }
      return true;
    }
  }
  return false;
}

const char* WireFormat::_InternalParseAndMergeField(
    Message* msg, const char* ptr, internal::ParseContext* ctx, uint64_t tag,
    const Reflection* reflection, const FieldDescriptor* field) {
  if (field == nullptr) {
    // unknown field set parser takes 64bit tags, because message set type ids
    // span the full 32 bit range making the tag span [0, 2^35) range.
    return internal::UnknownFieldParse(
        tag, reflection->MutableUnknownFields(msg), ptr, ctx);
  }
  if (WireFormatLite::GetTagWireType(tag) !=
      WireTypeForFieldType(field->type())) {
    if (field->is_packable() && WireFormatLite::GetTagWireType(tag) ==
                                    WireFormatLite::WIRETYPE_LENGTH_DELIMITED) {
      Arena* arena = msg->GetArena();

      switch (field->type()) {
#define HANDLE_PACKED_TYPE(TYPE, CPPTYPE, CPPTYPE_METHOD)           \
  case FieldDescriptor::TYPE_##TYPE: {                              \
    ptr = internal::Packed##CPPTYPE_METHOD##Parser(                 \
        reflection->MutableRepeatedFieldInternal<CPPTYPE>(          \
            msg, field,                                             \
            Reflection::GetRepeatedFieldIntent::kHiddenOrInternal), \
        arena, ptr, ctx);                                           \
    return ptr;                                                     \
  }

        HANDLE_PACKED_TYPE(INT32, int32_t, Int32)
        HANDLE_PACKED_TYPE(INT64, int64_t, Int64)
        HANDLE_PACKED_TYPE(SINT32, int32_t, SInt32)
        HANDLE_PACKED_TYPE(SINT64, int64_t, SInt64)
        HANDLE_PACKED_TYPE(UINT32, uint32_t, UInt32)
        HANDLE_PACKED_TYPE(UINT64, uint64_t, UInt64)

        HANDLE_PACKED_TYPE(FIXED32, uint32_t, Fixed32)
        HANDLE_PACKED_TYPE(FIXED64, uint64_t, Fixed64)
        HANDLE_PACKED_TYPE(SFIXED32, int32_t, SFixed32)
        HANDLE_PACKED_TYPE(SFIXED64, int64_t, SFixed64)

        HANDLE_PACKED_TYPE(FLOAT, float, Float)
        HANDLE_PACKED_TYPE(DOUBLE, double, Double)

        HANDLE_PACKED_TYPE(BOOL, bool, Bool)
#undef HANDLE_PACKED_TYPE

        case FieldDescriptor::TYPE_ENUM: {
          auto rep_enum = reflection->MutableRepeatedFieldInternal<int>(
              msg, field,
              Reflection::GetRepeatedFieldIntent::kHiddenOrInternal);
          if (!field->legacy_enum_field_treated_as_closed()) {
            ptr = internal::PackedEnumParser(rep_enum, arena, ptr, ctx);
          } else {
            return ctx->ReadPackedVarint(
                ptr, [rep_enum, field, reflection, msg, arena](int32_t val) {
                  if (field->enum_type()->FindValueByNumber(val) != nullptr) {
                    rep_enum->AddWithArena(arena, val);
                  } else {
                    WriteVarint(field->number(), val,
                                reflection->MutableUnknownFields(msg));
                  }
                });
          }
          return ptr;
        }

        case FieldDescriptor::TYPE_STRING:
        case FieldDescriptor::TYPE_GROUP:
        case FieldDescriptor::TYPE_MESSAGE:
        case FieldDescriptor::TYPE_BYTES:
          ABSL_LOG(FATAL) << "Can't reach";
          return nullptr;
      }
    } else {
      // mismatched wiretype;
      return internal::UnknownFieldParse(
          tag, reflection->MutableUnknownFields(msg), ptr, ctx);
    }
  }
