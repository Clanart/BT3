### Title
Gasless module `Disable` flag is not enforced in the transaction-processing path, allowing fee-delegation (lending) to continue after the module is disabled - (File: `kaiax/gasless/impl/tx_pool.go`, `kaiax/gasless/impl/builder.go`, `kaiax/gasless/impl/getter.go`)

### Summary
The gasless module exposes `IsDisabled()` which is meant to gate the entire KIP-247 gasless flow (proposer-funded gas lending), but the actual transaction-pool and block-building logic that decides whether a transaction is treated as gasless, is promoted, bundled, and lent gas for, never calls `IsDisabled()`. This mirrors the reported bug class: one code path enforces a status/enabled check while a functionally equivalent path that performs the sensitive operation (taking on obligations/transferring value) omits it.

### Finding Description
`GaslessModule.IsDisabled()` simply returns the configured `Disable` flag [1](#0-0) , and this flag is set either from the `--gasless.disable` CLI flag or automatically when a consensus node lacks sufficient balance to act as a lender [2](#0-1) .

However, the functions that actually decide whether an incoming transaction is treated as part of the gasless flow — `IsModuleTx` (used by the tx pool to classify the tx) [3](#0-2) , `GetCheckBalance` (used to skip the normal balance check) [4](#0-3) , `IsReady`/`isReady` (used to promote the tx from queue to pending) [5](#0-4) , and `ExtractTxBundles`/`GetLendTxGenerator` (used to build the block bundle and generate the proposer-funded lend transaction) [6](#0-5) [7](#0-6)  — never check `g.IsDisabled()`. The only place `IsDisabled()` is consulted is the read-only `debug_gaslessInfo` RPC display [8](#0-7) .

This is structurally identical to the reported bug: `update_position_internal()` checked `pool.enabled` before moving tokens while `adjust_position_internal()`/`update_position()` (reachable via a different call path performing the same class of value-transfer) omitted the check. Here, the module-level "disabled" gate is checked in one place (info API) but omitted from every path that actually classifies, promotes, bundles, and lends against gasless transactions.

### Impact Explanation
If an operator disables the gasless module via `--gasless.disable` (or it gets auto-disabled due to insufficient lender balance), the intent is that the proposer stops lending gas fees to users for gasless swaps. Because the disable flag is not enforced in `IsModuleTx`/`IsReady`/`ExtractTxBundles`/`GetLendTxGenerator`, a submitted `GaslessApproveTx`/`GaslessSwapTx` pair from any public RPC caller would still be classified as gasless, promoted, bundled, and would still trigger `GetLendTxGenerator` to construct a proposer-funded lend transaction from the node's own key [7](#0-6) . In the auto-disable case (insufficient CN balance) this can cause the lend transaction to fail mid-block or drain the remaining balance unexpectedly; in the operator-disable case it defeats the intended safety control entirely, continuing fee-delegation exposure that the operator explicitly opted out of.

### Likelihood Explanation
Reachable by any unprivileged user simply submitting a valid `GaslessApproveTx`/`GaslessSwapTx` pair to a node whose operator has set `--gasless.disable` (or whose CN lender balance is low) — no special privileges required, matching the "gasless user" and "public-RPC caller" threat profile explicitly in scope.

### Recommendation
Enforce `g.IsDisabled()` at the entry points that gate gasless processing — specifically in `IsModuleTx` (or `PreAddTx`) so disabled transactions are never admitted, and in `ExtractTxBundles`/`GetLendTxGenerator` so no lend transaction is generated when the module is disabled — consistent with how `debug_gaslessInfo` reports the disabled state.

### Proof of Concept
1. Start a node with `--gasless.disable` (or let a CN auto-disable due to `balance < GaslessLenderMinBal`).
2. Submit a valid `GaslessApproveTx` followed by a `GaslessSwapTx` pair satisfying all `VerifyExecutable` conditions.
3. Because `IsModuleTx`, `isReady`, and `ExtractTxBundles` never call `g.IsDisabled()`, the pair is still classified as gasless, promoted together, and bundled with a `LendTxGenerator`-produced lend transaction funded by the proposer's key, despite the module being configured/auto-disabled.

func (g *GaslessModule) IsReady(txs map[uint64]*types.Transaction, next uint64, ready types.Transactions) bool {
	g.knownTxsMu.Lock()
	defer g.knownTxsMu.Unlock()

	tx, ok := txs[next]
	if !ok {
		return false
	}

	if !g.isReady(txs, next, ready) {
		return false
	}

	if g.IsBundleTx(tx) {
		// If prev tx is bundle tx, there's no need to check the knownTxs limit because it has been checked in the previous `IsReady()` execution.
		isPrevTxBundleTx := len(ready) != 0 && g.IsBundleTx(ready[len(ready)-1])
		if isPrevTxBundleTx {
			g.knownTxs.add(tx, TxStatusPending)
			return true
		}

		maxBundleTxsInPending := g.GetMaxBundleTxsInPending()
		if maxBundleTxsInPending != math.MaxUint64 {
			numExecutable := uint(g.knownTxs.numExecutable())

			numSeqTxs := uint(1)
			for i := next + 1; i < next+uint64(len(txs)); i++ {
				if tx, ok := txs[i]; ok && g.IsBundleTx(tx) {
					numSeqTxs++
				} else {
					break
				}
			}

			// false if there is possibility of exceeding max bundle tx num
			if numExecutable+numSeqTxs > maxBundleTxsInPending {
				logger.Trace("Not promoting a tx because of exceeding max bundle tx num", "tx", tx.Hash().String(), "numExecutable", numExecutable, "maxBundleTxsInPending", maxBundleTxsInPending)
				return false
			}
		}

		g.knownTxs.add(tx, TxStatusPending)
	}

	return true
}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
}

func (g *GaslessModule) GetLendTxGenerator(approveTxOrNil, swapTx *types.Transaction) *builder.TxOrGen {
	var src []byte
	if approveTxOrNil != nil {
		src = append(src, approveTxOrNil.Hash().Bytes()...)
	}
	src = append(src, swapTx.Hash().Bytes()...)
	bundleHash := crypto.Keccak256Hash(src)

	gen := func(nonce uint64) (*types.Transaction, error) {
		var (
			chainId = g.InitOpts.ChainConfig.ChainID
			signer  = types.LatestSignerForChainID(chainId)
			key     = g.InitOpts.NodeKey
		)

		to, err := types.Sender(signer, swapTx)
		if err != nil {
			return nil, err
		}

		tx, err := types.NewTransactionWithMap(types.TxTypeEthereumDynamicFee, map[types.TxValueKeyType]interface{}{
			types.TxValueKeyNonce:      nonce,
			types.TxValueKeyTo:         &to,
			types.TxValueKeyAmount:     lendAmount(approveTxOrNil, swapTx),
			types.TxValueKeyData:       common.Hex2Bytes("0x"),
			types.TxValueKeyGasLimit:   params.TxGas,
			types.TxValueKeyGasFeeCap:  swapTx.GasFeeCap(),
			types.TxValueKeyGasTipCap:  swapTx.GasTipCap(),
			types.TxValueKeyAccessList: types.AccessList{},
			types.TxValueKeyChainID:    chainId,
		})
		if err != nil {
			return nil, err
		}

		err = tx.Sign(signer, key)
		return tx, err
	}

	return builder.NewTxOrGenFromGen(gen, bundleHash)
}

func (s *GaslessAPI) GaslessInfo() *GaslessInfoResult {
	s.b.gaslessInfoMu.RLock()
	defer s.b.gaslessInfoMu.RUnlock()

	at := []common.Address{}
	for addr := range s.b.allowedTokens {
		at = append(at, addr)
	}
	return &GaslessInfoResult{
		IsDisabled:    s.b.IsDisabled(),
		SwapRouter:    s.b.swapRouter,
		AllowedTokens: at,
		MaxBundleTxs:  s.b.GetMaxBundleTxsInPending(),
	}
}
