### Title
Double payout of GET-request relayer fee via stale non-membership timeout proof after response already delivered - ([File: evm/src/core/HandlerV2.sol])

### Summary
`handleGetRequestTimeouts` in `HandlerV2.sol` never checks whether a GET response has already been delivered to this host before processing a timeout, unlike the Substrate implementation which explicitly guards against this (`Error::GetResponseAlreadyReceived`). Combined with the fact that any previously-stored, still-within-history `StateCommitment` can be used to satisfy the non-membership check, an attacker can pay out the same GET-request fee twice: once via `dispatchIncoming(GetResponse,...)` (relayer reward) and once via `dispatchTimeOut(GetRequestTimeout,...)` (payer refund).

### Finding Description
`dispatch(DispatchGet)` charges a fee and stores it in `_requestCommitments[commitment] = FeeMetadata({sender, fee})`: [1](#0-0) 

When a `GetResponse` is delivered via `handleGetResponses` → `dispatchIncoming(GetResponse,...)`, the relayer is paid the fee from `_requestCommitments[commitment].fee`, but **`_requestCommitments[commitment]` is never deleted**: [2](#0-1) 

Separately, `handleGetRequestTimeouts` fetches `meta = host.requestCommitments(commitment)` and only checks `meta.sender == address(0)` (i.e., that a request commitment still exists) plus a non-membership proof of the response-receipt key against **any historically stored** `StateCommitment` at `message.height` — it never checks whether *this host's own* `_responseReceipts[commitment]` was already populated by a prior `handleGetResponses` call: [3](#0-2) 

`host.stateMachineCommitment(message.height)` only requires a challenge period elapsed and a non-zero stored root for that height — it does not require the height to be the latest one, so an attacker can pick an **older** height H1 (before Hyperbridge had relayed the response) where:
- `state.timestamp` at H1 already exceeds `request.timeout()` (satisfies `MessageNotTimedOut` check), and
- the response-receipt key is genuinely absent at H1 (valid non-membership proof),

even though a newer, valid `GetResponse` was already delivered and paid out at a later height. `dispatchTimeOut(GetRequestTimeout,...)` then unconditionally refunds `meta.fee` to `meta.sender` because the request commitment metadata was never cleared by the earlier successful `dispatchIncoming(GetResponse,...)` call: [4](#0-3) 

This mirrors exactly the guard that exists on the Substrate/`ismp-core` side but is missing on the EVM side — proof that the invariant ("no timeout processing once a response is already known") is a recognized protocol requirement that was simply not implemented for `HandlerV2.sol`: [5](#0-4) 

### Impact Explanation
This is a direct loss-of-funds / double-claim bug on the fee token held by `EvmHost`. Both the relayer (via `dispatchIncoming`) and the original requester (via `dispatchTimeOut`) can be paid the same fee for a single GET request, draining the host's fee-token balance by the duplicated amount, and additionally invoking `onGetTimeout` on the application after `onGetResponse` already fired — producing contradictory application-level state (a request being simultaneously "fulfilled" and "timed out").

### Likelihood Explanation
The entrypoint `handleGetRequestTimeouts` is explicitly documented as permissionless ("can be called by anyone"). All inputs needed — the `GetRequest` struct, historical `StateCommitment`s already stored on `EvmHost` (`stateMachineCommitment(height)`), and a Merkle/trie non-membership proof against a historical (still-retained) root — are public on-chain data; no relayer, prover, governance, or admin collusion is required. The only requirement is that the request had a nonzero fee and that a response was eventually delivered after an earlier state height existed where the response was still absent, which is the normal/expected relaying flow.

### Recommendation
Add a check to `handleGetRequestTimeouts` (and `dispatchTimeOut(GetRequestTimeout,...)`) that rejects processing if `_responseReceipts[commitment]` already exists on this host, mirroring the Substrate `GetResponseAlreadyReceived` guard. Additionally, `dispatchIncoming(GetResponse,...)` should clear/mark `_requestCommitments[commitment]` (or otherwise mark the request as finalized) so a stale non-membership proof from a height preceding response delivery cannot be replayed against `handleGetRequestTimeouts`.

### Proof of Concept
1. User calls `dispatch(DispatchGet{..., fee: F, timeout: T})` on `EvmHost` (source chain); `_requestCommitments[commitment] = {sender: user, fee: F}`.
2. Time passes; at Hyperbridge height H1, the response has not yet been relayed, and `state(H1).timestamp > T` (request is "timed out" per H1's clock). This `StateCommitment` for H1 is stored and its challenge period elapses.
3. Later, at Hyperbridge height H2 > H1, the GET response is legitimately relayed: a relayer calls `handleGetResponses` → `dispatchIncoming(GetResponse,...)`, which pays fee `F` to the relayer. `_requestCommitments[commitment]` is left untouched (fee still `F`, sender still `user`).
4. Attacker (or anyone) now submits `handleGetRequestTimeouts` referencing the *old* height H1 with a valid non-membership proof (constructed before step 3 occurred, from public archived state) for the response-receipt key at H1.
5. `handleGetRequestTimeouts` passes all checks (`meta.sender != 0`, `request.timeout() <= state(H1).timestamp`, valid non-membership proof against H1's still-stored root) and calls `host.dispatchTimeOut(GetRequestTimeout(...), meta, commitment)`.
6. `dispatchTimeOut` calls `onGetTimeout` on the app and then refunds `F` a second time to `user`, completing the double payout. [3](#0-2) [6](#0-5)

    function dispatchIncoming(GetResponse memory response, address relayer) external restrict(_hostParams.handler) {
        // replay protection
        bytes32 commitment = response.request.hash();
        _responseReceipts[commitment] = ResponseReceipt({
            relayer: relayer,
            responseCommitment: response.hash()
        });

        (bool success,) = _bytesToAddress(response.request.from)
            .call(abi.encodeWithSelector(IApp.onGetResponse.selector, IncomingGetResponse(response, relayer)));

        if (!success) {
            // so that it can be retried
            delete _responseReceipts[commitment];
            return;
        }

        // reward the relayer fee
        uint256 fee = _requestCommitments[commitment].fee;
        if (fee != 0) {
            IERC20(feeToken()).safeTransfer(relayer, fee);
        }
        emit GetRequestHandled({commitment: commitment, relayer: relayer});
    }

    /**
     * @dev Dispatch an incoming GET timeout to the source module.
     * @notice Does not refund any protocol fees.
     * @param timeout - timed-out get request bundled with the relayer that submitted the timeout proof
     * @param meta - fee metadata for the original request
     * @param commitment - request commitment
     */
    function dispatchTimeOut(
        GetRequestTimeout memory timeout,
        FeeMetadata memory meta,
        bytes32 commitment
    ) external restrict(_hostParams.handler) {
        // replay protection
        delete _requestCommitments[commitment];
        (bool success,) = _bytesToAddress(timeout.request.from)
            .call(abi.encodeWithSelector(IApp.onGetTimeout.selector, timeout));

        if (!success) {
            // so that it can be retried
            _requestCommitments[commitment] = meta;
            return;
        }

        if (meta.fee != 0) {
            // refund relayer fee
            IERC20(feeToken()).safeTransfer(meta.sender, meta.fee);
        }
        emit GetRequestTimeoutHandled({commitment: commitment, dest: string(timeout.request.dest)});
    }

    function handleGetRequestTimeouts(IHost host, GetTimeoutMessage calldata message) external notFrozen(host) {
        uint256 delay = block.timestamp - host.stateMachineCommitmentUpdateTime(message.height);
        uint256 challengePeriod = host.challengePeriod();
        if (challengePeriod != 0 && challengePeriod > delay) revert ChallengePeriodNotElapsed();

        // fetch the state commitment
        StateCommitment memory state = host.stateMachineCommitment(message.height);
        if (state.stateRoot == bytes32(0)) revert StateCommitmentNotFound();
        uint256 timeoutsLength = message.timeouts.length;

        for (uint256 i = 0; i < timeoutsLength; ++i) {
            GetRequest memory request = message.timeouts[i];
            // timed-out?
            if (request.timeout() > state.timestamp) revert MessageNotTimedOut();

            bytes32 commitment = request.hash();
            FeeMetadata memory meta = host.requestCommitments(commitment);
            if (meta.sender == address(0)) revert UnknownMessage();

            bytes[] memory keys = new bytes[](1);
            keys[0] = bytes.concat(RESPONSE_RECEIPTS_STORAGE_PREFIX, commitment);

            // verify state trie non-membership proofs
            PolkadotTrie.StorageValue memory entry = PolkadotTrie.VerifyProof(state.stateRoot, message.proof, keys)[0];
            if (entry.value.length != 0) revert InvalidProof();

            host.dispatchTimeOut(GetRequestTimeout(request, _msgSender()), meta, commitment);
        }
    }
