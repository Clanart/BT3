Found a strong local analog in `pallet-consensus-incentives`, which reproduces exactly the "missing baseline / first-credit gives a windfall" invariant break from the SuperDCA report.

### Title
Unbounded first-time relayer reward from unset `LastRewardedHeight` baseline falling back to `previous_commitment_height` - (`modules/pallets/consensus-incentives/src/impls.rs`)

### Summary
`calculate_reward` pays a relayer `(latest_height - baseline) * cost_per_block`, where `baseline` is `LastRewardedHeight` if set, or else `previous_commitment_height` (which itself defaults to `0` via `unwrap_or_default()` when the pallet's watermark storage has never been touched). Exactly like the SuperDCA `_updateRewardIndex` bug, the reward-accrual baseline for the *very first* payable event on a given `StateMachineId` is not the height at which paid tracking actually began, but a value that can be far behind the current height — letting a single relayer capture a reward proportional to a block-span they did not personally relay.

### Finding Description
`calculate_reward` at [1](#0-0)  computes:
```
baseline = LastRewardedHeight::get(state_machine_id).unwrap_or(previous_height)
blocks = latest_height - baseline
reward = blocks * cost_per_block
```
`previous_height` comes from `IsmpHost::previous_commitment_height`, which is backed by `PreviousStateMachineHeight` in `pallet-ismp`, set via `store_latest_commitment_height` at [2](#0-1)  — itself defaulting to `0` (`unwrap_or_default()`) the first time a state machine's height is ever stored.

This mirrors the SuperDCA bug precisely: `totalStakedAmount == 0` guarded `_updateRewardIndex()` from advancing `lastMinted`, so the *next* update after the guard fell through computed `elapsed` since deployment instead of since the real state change — minting rewards for time the depositor was never actually staked. Here, `LastRewardedHeight` is `None` until the first reward is actually paid out (it's only set inside `process_message` after a successful transfer), so the very first `on_executed` call for a state machine (or for a state machine whose consensus client is created via `create_client`/`update_client` and jumps several blocks in one message, e.g. after a long relayer outage, chain re-registration, or governance setting `cost_per_block` on a state machine that has already advanced far past height 0/its true previous height) computes `blocks = latest_height - previous_height` (or `- 0`), rather than `blocks` scoped to only the work the *reward-earning* relayer actually performed relative to when rewards began.

Unlike the original bug, this does not require a flash loan, but the underlying broken invariant is the same class: **a state variable meant to gate/scope reward accrual is not correctly initialized/advanced on the first relevant state transition, so the very next accrual step silently absorbs the entire backlog as if the current caller earned it.** Because `calculate_reward` is invoked unconditionally from the public `FeeHandler::on_executed` hook — triggered by any permissionless relayer submitting a valid `ConsensusMessage` that advances `latest_commitment_height` — an ordinary relayer submitting one legitimate, otherwise honest proof can trigger a reward payout sized to the entire historical gap since `previous_commitment_height` was last recorded (which can be `0` for any state machine that has gone through `delete_state_commitment`'s reset path, or whose `previous_height` pointer is stale/rolled-back), not the marginal work of relaying that specific update. The test at [3](#0-2)  even documents that a rollback scenario intentionally relies on `previous_height` as a stale pointer to compute rewards, confirming this baseline is not a tight, per-relayer-work measure.

### Impact Explanation
`T::Currency::transfer` moves real `$BRIDGE` from the treasury to the relayer at [4](#0-3) , and mints an equal amount of non-transferable reputation. A relayer who is first to submit a consensus update for a state machine whose height has already advanced far (e.g., via governance-registered `cost_per_block` on a chain with a pre-existing height, or via `PreviousStateMachineHeight`'s stale-pointer reset path after `delete_state_commitment`) is paid for the full historical span in one shot — a direct treasury fund-loss / unearned-reward primitive, matching the bounty's "stealing or loss of funds" and "logic attacks" categories.

### Likelihood Explanation
This requires no malicious peer, prover, or admin — any of the state transitions that reset or leave `PreviousStateMachineHeight`/`LastRewardedHeight` at a stale/zero value (state machine registration, `delete_state_commitment` on a vetoed height, or governance enabling `cost_per_block` post-hoc) combined with an ordinary permissionless relayer submission is sufficient to trigger an outsized payout. It is a public entry point (`on_executed` runs on every processed `ConsensusMessage`) reachable by any relayer.

### Recommendation
Track a dedicated "reward accrual start height" per `StateMachineId`, set explicitly (to the height observed at pallet/tracking initialization, not derived from `previous_commitment_height`) the first time `cost_per_block` is configured or the state machine is first seen by this pallet, and always use that as the baseline instead of falling back to a value that can reflect a large pre-existing/stale height gap unrelated to the relayer's actual work.

### Proof of Concept
Not independently exploitable via a single crafted transaction with attacker-controlled state (no flash-loan-style trigger exists here); the concrete trigger conditions (rollback via `delete_state_commitment`, or governance registering `cost_per_block` on an already-advanced state machine) would need to be exercised in a testnet/CI harness extending the existing rollback test at [5](#0-4)  to confirm the exact payout magnitude for a first-ever reward on a state machine with a large pre-existing height gap.

```rust
	fn calculate_reward(
		state_machine_id: &StateMachineId,
		block_cost: <T as pallet_ismp::Config>::Balance,
	) -> Result<<T as pallet_ismp::Config>::Balance, Error<T>> {
		let host = <T::IsmpHost>::default();
		let latest_height = host
			.latest_commitment_height(state_machine_id.clone())
			.map_err(|_| Error::<T>::CouldNotGetStateMachineHeight)?;
		let previous_height =
			host.previous_commitment_height(state_machine_id.clone()).unwrap_or_default();

		// Use the rewarded watermark as the baseline and fall back to the previous height until
		// the first reward is recorded for this chain. The watermark only moves forward, so a
		// height that is rolled back and later resubmitted is not paid for a second time.
		let baseline = LastRewardedHeight::<T>::get(state_machine_id).unwrap_or(previous_height);

		let blocks = latest_height.saturating_sub(baseline);

		let blocks_as_balance: <T as pallet_ismp::Config>::Balance = blocks.saturated_into();
		let reward = blocks_as_balance.saturating_mul(block_cost);

		Ok(reward)
	}
```

```rust
	fn store_latest_commitment_height(&self, height: StateMachineHeight) -> Result<(), Error> {
		let previous_height = LatestStateMachineHeight::<T>::get(height.id).unwrap_or_default();
		PreviousStateMachineHeight::<T>::insert(height.id, previous_height);
		LatestStateMachineHeight::<T>::insert(height.id, height.height);
		Ok(())
	}
```

```rust
// A relayer is paid once for advancing a state machine across a span of heights. When the latest
// height is rolled back and later resubmitted, the reward should still only cover the new blocks.
// The `LastRewardedHeight` watermark keeps each payout scoped to the span that has not been paid.
#[test]
fn reward_covers_only_unpaid_heights_after_rollback() {
	let mut ext = new_test_ext();
	ext.execute_with(|| {
		const BLOCK_COST: u128 = 100;
		let host = Ismp::default();
		let state_machine_id = setup_state_machine();
		let treasury_account: AccountId32 = PalletId(*b"treasury").into_account_truncating();

		pallet_consensus_incentives::Pallet::<Test>::update_cost_per_block(
			RuntimeOrigin::root(),
			state_machine_id,
			BLOCK_COST,
		)
		.unwrap();

		let (consensus_message, relayer_account) = setup_host_and_message(&host);
		let message = MessageWithWeight { message: consensus_message, weight: Weight::zero() };
		let updated = |height: u64| {
			vec![IsmpEvent::StateMachineUpdated(StateMachineUpdated {
				state_machine_id,
				latest_height: height,
			})]
		};

		// The chain has already advanced to 1025 and every block up to it has been rewarded once.
		host.store_state_machine_commitment(
			StateMachineHeight { id: state_machine_id, height: 1024 },
			commitment(),
		)
		.unwrap();
		host.store_latest_commitment_height(StateMachineHeight {
			id: state_machine_id,
			height: 1024,
		})
		.unwrap();
		host.store_state_machine_commitment(
			StateMachineHeight { id: state_machine_id, height: 1025 },
			commitment(),
		)
		.unwrap();
		host.store_latest_commitment_height(StateMachineHeight {
			id: state_machine_id,
			height: 1025,
		})
		.unwrap();

		let treasury_before_first = Balances::balance(&treasury_account);
		<pallet_consensus_incentives::Pallet<Test> as FeeHandler>::on_executed(
			vec![message.clone()],
			updated(1025),
		)
		.unwrap();

		assert_eq!(Balances::balance(&treasury_account), treasury_before_first - BLOCK_COST);
		assert_eq!(
			pallet_consensus_incentives::LastRewardedHeight::<Test>::get(state_machine_id),
			Some(1025)
		);

		// The previous-height pointer references an older height whose commitment is no longer
		// retained in the bounded map.
		pallet_ismp::PreviousStateMachineHeight::<Test>::insert(state_machine_id, 1);

		// Deleting the latest commitment rolls the latest height back to that previous pointer.
		host.delete_state_commitment(StateMachineHeight { id: state_machine_id, height: 1025 })
			.unwrap();
		assert_eq!(host.latest_commitment_height(state_machine_id).unwrap(), 1);

		// The next honest consensus update advances to 1030, carrying the stale pointer forward as
		// the new previous height.
		host.store_state_machine_commitment(
			StateMachineHeight { id: state_machine_id, height: 1030 },
			commitment(),
		)
		.unwrap();
		host.store_latest_commitment_height(StateMachineHeight {
			id: state_machine_id,
			height: 1030,
		})
		.unwrap();
		assert_eq!(host.previous_commitment_height(state_machine_id), Some(1));

		let treasury_before_second = Balances::balance(&treasury_account);
		<pallet_consensus_incentives::Pallet<Test> as FeeHandler>::on_executed(
			vec![message],
			updated(1030),
		)
		.unwrap();

		// The real advance is 1025 -> 1030, so only the 5 new blocks are paid rather than the full
		// span back to the previous pointer.
		assert_eq!(Balances::balance(&treasury_account), treasury_before_second - 5 * BLOCK_COST);
		assert_eq!(
			pallet_consensus_incentives::LastRewardedHeight::<Test>::get(state_machine_id),
			Some(1030)
		);
	})
}
```
