### Title
Empty aggregate signatures verify as valid - (File: crypto/schnorr/src/aggregate.rs)

### Summary
`SchnorrAggregate::read` permits a serialized aggregate with a zero nonce count, while `SchnorrAggregate::verify` only checks that the decoded nonce count equals the supplied key/challenge count. For an empty signer set and `s = 0`, verification reduces to the identity equation and returns `true`.

### Finding Description
`SchnorrAggregator::complete` explicitly refuses to produce an aggregate when no signatures were added, establishing non-emptiness as an intended protocol invariant. The deserializer does not enforce the same invariant: a four-byte zero length followed by a zero scalar produces `Rs = []` and `s = 0`. `verify` accepts this object whenever `keys_and_challenges` is empty because its multiexp contains only `-0 * G`, which is the identity.

### Impact Explanation
A party who can submit an aggregate signature and cause verification against an empty signer set can obtain a successful verification without any valid signer signature. This is a signature-verification acceptance condition not producible through the legitimate aggregation API.

### Likelihood Explanation
The encoded input is six field-independent bytes plus a canonical zero scalar: the attacker does not need a private key, nonce, valid signature, or hash preimage. Exploitability depends on the calling protocol reaching aggregate verification with an empty signer set; Serai's normal aggregation path cannot construct this object.

### Recommendation
Reject empty aggregates in `SchnorrAggregate::read`, and additionally return `false` or an error from `SchnorrAggregate::verify` when `keys_and_challenges.is_empty()`. This keeps deserialization aligned with `SchnorrAggregator::complete`, which already refuses empty aggregation.

### Proof of Concept
For any `C: Ciphersuite` whose scalar encoding of zero is accepted by `C::read_F`:

```rust
let mut encoded = 0u32.to_le_bytes().to_vec();
encoded.extend(C::F::ZERO.to_repr().as_ref());

let aggregate = SchnorrAggregate::<C>::read(&mut encoded.as_slice()).unwrap();
assert!(aggregate.verify(dst, &[]));
```
