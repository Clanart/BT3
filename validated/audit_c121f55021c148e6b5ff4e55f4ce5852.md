### Title
Optional `aggregator_verification_address` Leaves `Withdraw` RPC Unauthenticated at Application Layer, Allowing Any mTLS-Passing Caller to Force Operator BTC Payout — (`core/src/rpc/operator.rs`)

---

### Summary

The `Withdraw` RPC handler on the operator server contains an application-level ECDSA authorization check that is **entirely skipped** when `aggregator_verification_address` is `None`. Because this field is `Option<Address>` and its absence is a valid runtime configuration, any caller that can reach the gRPC endpoint (and pass the equally-optional mTLS layer) can force the operator to fund and broadcast a payout transaction from its own Bitcoin wallet for any legitimately-registered Citrea withdrawal.

---

### Finding Description

In `core/src/rpc/operator.rs`, the `withdraw` handler checks the aggregator's ECDSA signature only when `aggregator_verification_address` is `Some`:

```rust
// if verification address is set in config, check if verification signature is valid
if let Some(address_in_config) = self.operator.config.aggregator_verification_address {
    // ... recover address from ECDSA sig, compare to config
} // else: no check at all — fall through to operator.withdraw(...)
``` [1](#0-0) 

The field is declared as `Option<alloy::primitives::Address>` and is parsed from the optional env-var `AGGREGATOR_VERIFICATION_ADDRESS`: [2](#0-1) [3](#0-2) 

The transport-layer guard (`client_verification`) is equally optional. When `client_verification = false`, the interceptor is `Noop` — no certificate is checked: [4](#0-3) 

The `Interceptors::Noop` variant performs zero authentication: [5](#0-4) 

When both guards are absent, the call reaches `operator.withdraw()` unconditionally. That function:
1. Looks up the withdrawal UTXO from the DB (must match a Citrea-registered withdrawal — this check holds).
2. Calls `self.rpc.fund_raw_transaction(...)` — **adds inputs from the operator's own Bitcoin wallet** to cover the payout amount plus fees.
3. Signs and broadcasts the funded transaction to the Bitcoin network. [6](#0-5) 

The payout transaction spends the operator's wallet UTXOs to pay the withdrawal recipient: [7](#0-6) 

---

### Impact Explanation

An attacker who can reach the operator's gRPC port (when `client_verification = false` and `aggregator_verification_address = None`) can:

1. **Drain the operator's BTC wallet** by replaying all pending valid Citrea withdrawals simultaneously, forcing the operator to front the full bridge amount for each one.
2. **Force high-fee spending**: the operator calls `get_fee_rate_kvb` at the moment of the forced call; in a congested mempool the operator pays inflated fees it did not choose to incur.
3. **Starve other bridge operations**: the operator's wallet funds collateral, kickoff UTXOs, and fee bumps. Draining it breaks bridge liveness even though the operator will eventually be reimbursed via the kickoff/reimbursement path.

The operator is reimbursed only after completing the full kickoff → challenge-timeout → reimbursement cycle, which can span hundreds of Bitcoin blocks. During that window the operator's capital is locked and unavailable.

---

### Likelihood Explanation

The `aggregator_verification_address` field is documented as an "extra verification … to force citrea to check withdrawal params manually **during some time after launch**", explicitly signalling it is intended to be disabled post-launch. The `client_verification` flag defaults to `false` when the env-var is absent. Both conditions being `false`/`None` simultaneously is therefore a realistic production state, not a misconfiguration edge case. [2](#0-1) [8](#0-7) 

---

### Recommendation

1. **Make `aggregator_verification_address` mandatory** (change `Option<Address>` to `Address`) so the ECDSA check is always enforced, or at minimum emit a startup error/warning when both `client_verification` and `aggregator_verification_address` are absent.
2. **Enforce `client_verification = true` in production** by failing startup when it is `false` and no `aggregator_verification_address` is set.
3. **Rate-limit or deduplicate** calls to `operator.withdraw()` per `withdrawal_id` so that even an authenticated caller cannot trigger the same payout multiple times.

---

### Proof of Concept

**Precondition**: operator deployed with `CLIENT_VERIFICATION` unset (defaults `false`) and `AGGREGATOR_VERIFICATION_ADDRESS` unset.

```
# 1. Observe a valid Citrea withdrawal registration (withdrawal_id=0, utxo, user_sig)
# 2. Call Withdraw directly on the operator gRPC port — no cert, no ECDSA sig needed:
grpcurl -plaintext \
  -d '{
    "withdrawal": {
      "withdrawal_id": 0,
      "input_signature": "<user_taproot_sig_hex>",
      "input_outpoint": {"txid": {"txid": "<txid_bytes>"}, "vout": 0},
      "output_script_pubkey": "<user_p2tr_spk_hex>",
      "output_amount": 999670000
    }
  }' \
  operator-host:port clementine.ClementineOperator/Withdraw
```

The operator's Bitcoin wallet is debited immediately; the attacker pays nothing. The operator's wallet balance drops by `bridge_amount` (≈1 BTC per call) plus miner fees, and the operator cannot recover funds until the full reimbursement cycle completes on-chain. [9](#0-8) [10](#0-9)

        ))?;
        let (withdrawal_id, input_signature, input_outpoint, output_script_pubkey, output_amount) =
            parser::operator::parse_withdrawal_sig_params(withdraw_params)?;

        tracing::warn!(
            "Parsed withdraw rpc params, withdrawal id: {:?}, input signature: {:?}, input outpoint: {:?}, output script pubkey: {:?}, output amount: {:?}, verification signature: {:?}", withdrawal_id, input_signature, input_outpoint, output_script_pubkey, output_amount, params.verification_signature
        );

        // if verification address is set in config, check if verification signature is valid
        if let Some(address_in_config) = self.operator.config.aggregator_verification_address {
            let verification_signature = params
                .verification_signature
                .map(|sig| {
                    PrimitiveSignature::from_str(&sig).map_err(|e| {
                        Status::invalid_argument(format!("Invalid verification signature: {e}"))
                    })
                })
                .transpose()?;
            // check if verification signature is provided by aggregator
            if let Some(verification_signature) = verification_signature {
                let address_from_sig =
                    recover_address_from_ecdsa_signature::<OperatorWithdrawalMessage>(
                        withdrawal_id,
                        input_signature,
                        input_outpoint,
                        output_script_pubkey.clone(),
                        output_amount,
                        verification_signature,
                    )?;

                // check if verification signature is signed by the address in config
                if address_from_sig != address_in_config {
                    return Err(BridgeError::InvalidECDSAVerificationSignature).map_to_status();
                }
            } else {
                // if verification signature is not provided, but verification address is set in config, return error
                return Err(BridgeError::ECDSAVerificationSignatureMissing).map_to_status();
            }
        }

        let payout_tx = self
            .operator
            .withdraw(
                withdrawal_id,
                input_signature,
                input_outpoint,
                output_script_pubkey,
                output_amount,
            )
            .await?;

        tracing::info!(
            "Withdraw rpc completed successfully for withdrawal id: {:?}",
            withdrawal_id
        );

        Ok(Response::new(RawSignedTx::from(&payout_tx)))
    }

    pub async fn withdraw(
        &self,
        withdrawal_index: u32,
        in_signature: taproot::Signature,
        in_outpoint: OutPoint,
        out_script_pubkey: ScriptBuf,
        out_amount: Amount,
    ) -> Result<Transaction, BridgeError> {
        tracing::info!(
            "Withdrawing with index: {}, in_signature: {:?}, in_outpoint: {:?}, out_script_pubkey: {}, out_amount: {}",
            withdrawal_index,
            in_signature,
            in_outpoint,
            out_script_pubkey,
            out_amount
        );

        // Prepare input and output of the payout transaction.
        let input_prevout = self.rpc.get_txout_from_outpoint(&in_outpoint).await?;
        let input_utxo = UTXO {
            outpoint: in_outpoint,
            txout: input_prevout,
        };
        let output_txout = TxOut {
            value: out_amount,
            script_pubkey: out_script_pubkey,
        };

        // Check Citrea for the withdrawal state.
        let withdrawal_utxo = self
            .db
            .get_withdrawal_utxo_from_citrea_withdrawal(None, withdrawal_index)
            .await?;

        if withdrawal_utxo != input_utxo.outpoint {
            return Err(eyre::eyre!("Input UTXO does not match withdrawal UTXO from Citrea: Input Outpoint: {0}, Withdrawal Outpoint (from Citrea): {1}", input_utxo.outpoint, withdrawal_utxo).into());
        }

        let operator_withdrawal_fee_sats =
            self.config
                .operator_withdrawal_fee_sats
                .ok_or(BridgeError::ConfigError(
                    "Operator withdrawal fee sats is not specified in configuration file"
                        .to_string(),
                ))?;
        if !Self::is_profitable(
            input_utxo.txout.value,
            output_txout.value,
            self.config.protocol_paramset().bridge_amount,
            operator_withdrawal_fee_sats,
        ) {
            return Err(eyre::eyre!("Not enough fee for operator").into());
        }

        let user_xonly_pk = &input_utxo
            .txout
            .script_pubkey
            .try_get_taproot_pk()
            .wrap_err("Input utxo script pubkey is not a valid taproot script")?;

        let payout_txhandler = builder::transaction::create_payout_txhandler(
            input_utxo,
            output_txout,
            self.signer.xonly_public_key,
            in_signature,
            self.config.protocol_paramset().network,
        )?;

        // tracing::info!("Payout txhandler: {:?}", hex::encode(bitcoin::consensus::serialize(&payout_txhandler.get_cached_tx())));

        let sighash = payout_txhandler.calculate_sighash_txin(0, in_signature.sighash_type)?;

        SECP.verify_schnorr(
            &in_signature.signature,
            &Message::from_digest(*sighash.as_byte_array()),
            user_xonly_pk,
        )
        .wrap_err("Failed to verify signature received from user for payout txin. Ensure the signature uses SinglePlusAnyoneCanPay sighash type.")?;

        let fee_rate = self
            .rpc
            .get_fee_rate_kvb(
                self.config.protocol_paramset.network,
                &self.config.mempool_api_host,
                &self.config.mempool_api_endpoint,
                self.config.tx_sender_limits.mempool_fee_rate_multiplier,
                self.config.tx_sender_limits.mempool_fee_rate_offset_sat_kvb,
                self.config.tx_sender_limits.fee_rate_hard_cap,
            )
            .await?;

        // send payout tx using RBF
        let funded_tx = self
            .rpc
            .fund_raw_transaction(
                payout_txhandler.get_cached_tx(),
                Some(&bitcoincore_rpc::json::FundRawTransactionOptions {
                    add_inputs: Some(true),
                    include_unsafe: Some(false),

                    change_position: Some(1),

                    replaceable: None,
                    conf_target: None,
                    estimate_mode: None,
                }),
                None,
            )
            .await

pub fn create_payout_txhandler(
    input_utxo: UTXO,
    output_txout: TxOut,
    operator_xonly_pk: XOnlyPublicKey,
    user_sig: taproot::Signature,
    _network: bitcoin::Network,
) -> Result<TxHandler<Signed>, BridgeError> {
    let txin = SpendableTxIn::new_partial(input_utxo.outpoint, input_utxo.txout);

    let output_txout = UnspentTxOut::from_partial(output_txout.clone());

    let op_return_txout = op_return_txout(PushBytesBuf::from(operator_xonly_pk.serialize()));

    let mut txhandler = TxHandlerBuilder::new(TransactionType::Payout)
        .with_version(NON_STANDARD_V3)
        .add_input(
            NormalSignatureKind::NotStored,
            txin,
            SpendPath::KeySpend,
            DEFAULT_SEQUENCE,
        )
        .add_output(output_txout)
        .add_output(UnspentTxOut::from_partial(anchor_output(
            NON_EPHEMERAL_ANCHOR_AMOUNT,
        )))
        .add_output(UnspentTxOut::from_partial(op_return_txout))
        .finalize();
    txhandler.set_p2tr_key_spend_witness(&user_sig, 0)?;
    txhandler.promote()
