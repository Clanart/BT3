### No vulnerability found for this question.

The claimed binding — `payment_block.header.compute_block_hash() == block_hash_bytes[payment_block_height - genesis_block_height]` — is in fact enforced, just not via an explicit equality check but cryptographically via the MMR inclusion proof itself.

`create_spv` builds the `SPV` from `payment_block.header` and the MMR proof for leaf index `payment_block_height - genesis_block_height`, then immediately calls `spv.verify(mmr_guest)` before returning `Ok` [1](#0-0) . `SPV::verify` recomputes `block_hash = self.block_header.compute_block_hash()` from the attacker-supplied `payment_block.header` and feeds that hash into `mmr_guest.verify_proof(block_hash, proof)` [2](#0-1) . `MMRGuest::verify_proof` replays the sibling path starting from that leaf hash and checks the resulting subroot against the MMR's stored subroots at `subroot_idx` [3](#0-2) .

Because the subroot recomputation starts from the leaf value itself, supplying a `payment_block` whose header hash differs from the true `block_hash_bytes[0]` produces a different starting hash and (barring a SHA-256 preimage/collision, which is out of scope) a different computed subroot that will not match the MMR's actual subroot at that index — regardless of how many peaks/subroots the MMR has, since `subroot_idx`/`internal_idx` only select *which* subroot and position to check, not bypass the hash chain. So `spv.verify` returns `false` and `create_spv` returns `Err("SPV verification failed during creation...")` [4](#0-3) .

Even if this self-check were somehow bypassed, `prove_bridge_circuit` independently re-verifies `bridge_circuit_input.payout_spv.verify(...chain_state.block_hashes_mmr...)` against the header-chain circuit's own MMR before proceeding [5](#0-4) , and additionally cross-checks the SPV's block hash against the light-client circuit's committed L1 block hash [6](#0-5) . Both are independent, redundant checks of the same equality, so a forged `payment_block`/`payment_block_height` combination that diverges from the actual MMR leaf is rejected at multiple layers, not silently accepted.

    pub fn verify_proof(&self, leaf: [u8; 32], mmr_proof: &MMRInclusionProof) -> bool {
        let mut current_hash = leaf;
        for i in 0..mmr_proof.inclusion_proof.len() {
            let sibling = mmr_proof.inclusion_proof[i];
            if mmr_proof.internal_idx & (1 << i) == 0 {
                current_hash = hash_pair(current_hash, sibling);
            } else {
                current_hash = hash_pair(sibling, current_hash);
            }
        }
        self.subroots.get(mmr_proof.subroot_idx) == Some(&current_hash)
    }
