### Title
Missing privilege check lets any EVM caller force-redeploy an already-registered native ERC20 pointer contract, bypassing the previous gov-proposal-only overwrite gate - (File: precompiles/pointer/pointer.go)

### Summary
The current `pointer` precompile's `AddNative` handler no longer enforces the "pointer already exists" guard that earlier precompile revisions (`v552`, `v555`, `v562`) used to gate updates to already-registered native ERC20 pointers behind a governance proposal. Any unprivileged EVM transaction sender can now call `addNativePointer` on a token that already has a pointer and force the keeper to redeploy/overwrite the pointer contract's bytecode, a state-persisting operation that was previously reserved for the `AddERCNativePointerProposalV2` governance path.

### Finding Description
Legacy precompile revisions explicitly rejected `AddNative` calls when a pointer for the token already existed at version ≥ 1, returning an error unless the caller went through governance: [1](#0-0) 

The current (non-legacy) `pointer` precompile removed this guard entirely. `AddNative` only checks that bank denom metadata exists, then unconditionally calls `p.evmKeeper.UpsertERCNativePointer`, with no ownership/admin/gov check on the caller: [2](#0-1) 

`UpsertERCNativePointer` is designed to be invoked from the governance handler `HandleAddERCNativePointerProposalV2`: [3](#0-2) 

but is now also reachable directly by any EVM caller through the public precompile method. Inside the keeper, `UpsertERCPointer` detects the pointer already exists and overwrites the deployed bytecode in place via `k.SetCode`, without checking who the caller is: [4](#0-3) 

This is structurally the same bug class as the OpenClaw advisory: a write path (`AddNativePointer`, reachable by any operator/holder of `operator.write`-equivalent capability — any EVM sender) reaches a persistence route (`UpsertERCPointer` → `k.SetCode`/`setter`) that was intended to be admin/governance-gated (`operator.admin`-equivalent — only reachable via `AddERCNativePointerProposalV2`).

### Impact Explanation
Any address can trigger redeployment of an already-registered native-token pointer contract's bytecode whenever bank denom metadata is present for that token, without going through the governance process that was the only sanctioned route for updating an existing pointer in earlier code. This lets an unprivileged caller repeatedly force pointer-contract code churn for tokens it does not own or administer, undermining the intended "governance-controlled, stable" property of registered ERC20 native pointers that other contracts/integrators rely on. While the underlying contract storage (e.g., balances/allowances tracked by the bank module) is not directly stolen, the authorization boundary that was supposed to require elevated (governance) privilege to persist changes to an existing pointer registration is bypassed — the same class of "write persists admin-only config" issue described in the report.

### Likelihood Explanation
Trivial to trigger: any account can submit a single EVM transaction calling `addNativePointer(token)` on the precompile at `0x000000000000000000000000000000000000100b` for any token that already has bank denom metadata and an existing pointer, with no additional authorization required.

### Recommendation
Restore the existing-pointer guard in `AddNative` (and the analogous CW20/CW721/CW1155 handlers) so that once a native pointer is registered, only the governance path (`HandleAddERCNativePointerProposalV2`) can update/redeploy it, mirroring the version check present in legacy revisions `v552`/`v555`/`v562`.

### Proof of Concept
1. Governance or a tokenfactory admin sets denom metadata and a native pointer is created for `token` via `addNativePointer` (creates pointer, version recorded).
2. Any unrelated, unprivileged address calls `addNativePointer(token)` again on the current `pointer` precompile.
3. `AddNative` in `precompiles/pointer/pointer.go` skips any existing-pointer/admin check and calls `UpsertERCNativePointer`, which detects the pointer exists and calls `k.SetCode` to overwrite the deployed bytecode at the existing pointer address — succeeding where legacy versions (`v552`/`v562`) would have reverted with `"pointer at %s with version %d exists..."`.

func (p PrecompileExecutor) AddNative(ctx sdk.Context, method *ethabi.Method, caller common.Address, args []interface{}, value *big.Int, evm *vm.EVM, hooks *tracing.Hooks) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}
	if err := pcommon.ValidateArgsLength(args, 1); err != nil {
		return nil, 0, err
	}
	token := args[0].(string)
	metadata, metadataExists := p.bankKeeper.GetDenomMetaData(ctx, token)
	if !metadataExists {
		return nil, 0, fmt.Errorf("denom %s does not have metadata stored and thus can only have its pointer set through gov proposal", token)
	}
	name := metadata.Name
	symbol := metadata.Symbol
	var decimals uint8
	for _, denomUnit := range metadata.DenomUnits {
		if denomUnit.Exponent > uint32(decimals) && denomUnit.Exponent <= math.MaxUint8 {
			decimals = uint8(denomUnit.Exponent)
			name = denomUnit.Denom
			symbol = denomUnit.Denom
			if len(denomUnit.Aliases) > 0 {
				name = denomUnit.Aliases[0]
			}
		}
	}
	contractAddr, err := p.evmKeeper.UpsertERCNativePointer(ctx, evm, token, utils.ERCMetadata{Name: name, Symbol: symbol, Decimals: decimals})
	if err != nil {
		return nil, 0, err
	}

func HandleAddERCNativePointerProposalV2(ctx sdk.Context, k *keeper.Keeper, p *types.AddERCNativePointerProposalV2) error {
	decimals := uint8(math.MaxUint8)
	if p.Decimals <= uint32(decimals) {
		// should always be the case given validation
		decimals = uint8(p.Decimals) //nolint:gosec
	}
	return k.RunWithOneOffEVMInstance(
		ctx, func(e *vm.EVM) error {
			_, err := k.UpsertERCNativePointer(ctx, e, p.Token, utils.ERCMetadata{Name: p.Name, Symbol: p.Symbol, Decimals: decimals})
			return err
		}, func(s1, s2 string) {
			logNativeV2Error(ctx, p, s1, s2)
		},
	)
}

func (k *Keeper) UpsertERCPointer(
	ctx sdk.Context, evm *vm.EVM, typ string, args []interface{}, getter PointerGetter, setter PointerSetter,
) (contractAddr common.Address, err error) {
	pointee := args[0].(string)
	evmModuleAddress := k.GetEVMAddressOrDefault(ctx, k.AccountKeeper().GetModuleAddress(types.ModuleName))

	var bin []byte
	bin, err = artifacts.GetParsedABI(typ).Pack("", args...)
	if err != nil {
		panic(err)
	}
	bin = append(artifacts.GetBin(typ), bin...)
	// GetDeploymentCode / Create take EVM snapshots that Freeze() Multistore layers.
	// Exists-lookup and commits must use the live unfrozen top (sdb.Ctx): cachekv
	// forbids writing a frozen layer, and same-tx readers that skip frozen-empty
	// parents would miss those writes. The precompile Prepare `ctx` is that top at
	// Prepare time, but is frozen once this Upsert snapshots. Always attach the
	// caller's gas meter (finite precompile meter in deliver) — sdb.Ctx() alone
	// carries the infinite EVM meter.
	sdb := state.GetDBImpl(evm.StateDB)
	liveCtx := func() sdk.Context {
		if sdb == nil {
			return ctx
		}
		return sdb.Ctx().WithGasMeter(ctx.GasMeter())
	}
	existingAddr, _, exists := getter(liveCtx(), pointee)
	suppliedGas := k.getEvmGasLimitFromCtx(ctx)
	var remainingGas uint64
	if exists {
		var ret []byte
		contractAddr = existingAddr
		ret, remainingGas, err = evm.GetDeploymentCode(evmModuleAddress, bin, suppliedGas, utils.Big0, existingAddr)
		if err != nil {
			return
		}
		// Only write on success: a failed GetDeploymentCode can leave ret as nil or
		// revert data, which must not clobber live pointer bytecode (even transiently).
		writeCtx := liveCtx()
		k.SetCode(writeCtx, contractAddr, ret)
		if sdb != nil {
			sdb.RefreshCodeCache(contractAddr, ret)
		}
	} else {
		_, contractAddr, remainingGas, err = evm.Create(evmModuleAddress, bin, suppliedGas, uint256.NewInt(0))
	}
	if err != nil {
		return
	}
	ctx.GasMeter().ConsumeGas(k.GetCosmosGasLimitFromEVMGas(ctx, suppliedGas-remainingGas), "ERC pointer deployment")
	if err = setter(liveCtx(), pointee, contractAddr); err != nil {
		return
	}
