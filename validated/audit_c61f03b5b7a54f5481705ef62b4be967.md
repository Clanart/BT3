### Title
First consensus-incentive reward for a newly onboarded state machine drains the treasury by paying for its entire pre-hyperbridge history - ([File: modules/pallets/consensus-incentives/src/impls.rs])

### Summary
`pallet-consensus-incentives::calculate_reward` computes a relayer reward as `(latest_height - baseline) * cost_per_block`, falling back to `previous_commitment_height` when no `LastRewardedHeight` watermark exists yet [1](#0-0) . But `previous_commitment_height` is unconditionally seeded to `0` the very first time a state machine's height is ever recorded, regardless of what real height that state machine started at [2](#0-1) . This is the same class of bug as the Ajna report: a "first time" code path (zero debt / zero prior height) silently resets an accrual baseline to zero instead of to the true starting point, so the very first reward computation is charged against the entire history instead of only the newly-delivered span.

### Finding Description
`IsmpHost::store_latest_commitment_height` is the single place `PreviousStateMachineHeight` is maintained:

```rust
fn store_latest_commitment_height(&self, height: StateMachineHeight) -> Result<(), Error> {
    let previous_height = LatestStateMachineHeight::<T>::get(height.id).unwrap_or_default();
    PreviousStateMachineHeight::<T>::insert(height.id, previous_height);
    LatestStateMachineHeight::<T>::insert(height.id, height.height);
    Ok(())
}
``` [2](#0-1) 

For a state machine that has never had `LatestStateMachineHeight` written before (i.e. the state machine was just onboarded, typically at a real-world height that is already large, e.g. Ethereum's current block number), `previous_height` is computed as `unwrap_or_default()` → `0`. That `0` is stored as `PreviousStateMachineHeight`, even though the state machine's actual starting height (`height.height`) may be millions of blocks in.

`pallet-consensus-incentives::calculate_reward` then does:

```rust
let latest_height = host.latest_commitment_height(state_machine_id)...;
let previous_height = host.previous_commitment_height(state_machine_id).unwrap_or_default();
let baseline = LastRewardedHeight::<T>::get(state_machine_id).unwrap_or(previous_height);
let blocks = latest_height.saturating_sub(baseline);
let reward = blocks_as_balance.saturating_mul(block_cost);
``` [3](#0-2) 

Because `LastRewardedHeight` is also unset on the very first reward for this `state_machine_id`, `baseline` falls back to `previous_height`, which is `0` from the flaw above. `blocks = latest_height - 0 = latest_height`, i.e. the entire starting height of the just-onboarded chain, multiplied by the governance-configured `cost_per_block`. `process_message` then unconditionally transfers this reward from `TreasuryAccount` to the relayer identified from the consensus message signature, with no bound check against the actual number of blocks genuinely relayed by that message:

```rust
T::Currency::transfer(
    &T::TreasuryAccount::get().into_account_truncating(),
    &relayer_account,
    reward,
    Preservation::Expendable,
)
``` [4](#0-3) 

The existing test suite only covers the *rollback* case, where `LastRewardedHeight` is already set and the previous-height pointer becomes stale after a veto — it re-derives the correct partial span [5](#0-4) . There is no test or guard for the "never-rewarded, never-recorded" onboarding case, which is exactly the scenario this report's bug class targets: an initial/zero state that skips proper baseline initialization.

### Impact Explanation
Any relayer (unprivileged, no special trust required) who is first to submit a valid `ConsensusMessage` for a newly registered state machine after governance sets `StateMachinesCostPerBlock` for it collects a reward sized to the chain's *entire* starting block height rather than the blocks actually advanced by their proof. Since real-world chains being onboarded typically start at heights in the millions, and `cost_per_block` is denominated per real block, this can drain the `TreasuryAccount` of far more than intended in a single extrinsic — a direct, one-shot loss of protocol funds triggered by ordinary, permissionless relayer activity.

### Likelihood Explanation
This triggers deterministically, not probabilistically, whenever: (1) a new state machine is added to Hyperbridge, (2) governance configures a non-zero `cost_per_block` for it (an expected, routine operational step, not a bug), and (3) the first consensus update for that state machine is submitted. No colluding relayer, prover, or admin action is required beyond normal reward configuration — the exploit is simply "be the first (any) relayer to deliver a consensus update for a freshly onboarded chain," which is a completely ordinary, permissionless action.

### Recommendation
When a state machine's height is recorded for the first time (no prior `LatestStateMachineHeight`), `PreviousStateMachineHeight` should be seeded to the *same* initial height rather than `0`, so the first `blocks` span is `0` and rewards only start accruing from genuine subsequent advances:

```rust
fn store_latest_commitment_height(&self, height: StateMachineHeight) -> Result<(), Error> {
    let previous_height = LatestStateMachineHeight::<T>::get(height.id)
        .unwrap_or(height.height); // no prior height ⇒ nothing to reward yet
    PreviousStateMachineHeight::<T>::insert(height.id, previous_height);
    LatestStateMachineHeight::<T>::insert(height.id, height.height);
    Ok(())
}
```
Additionally, `calculate_reward` should explicitly initialize `LastRewardedHeight` to `latest_height` (not compute a reward) the first time a state machine is seen, mirroring the Ajna fix of caching state "before execution" so the baseline reflects reality rather than an arbitrary zero.

### Proof of Concept
1. Governance registers a new EVM state machine on Hyperbridge whose real chain height is already `20,000,000` and calls `update_cost_per_block(state_machine_id, 100)`.
2. A relayer submits the first valid `ConsensusMessage` bringing the state machine's commitment to height `20,000,000`. `IsmpHost::store_latest_commitment_height` runs: `LatestStateMachineHeight` was `None` → `previous_height = 0` → `PreviousStateMachineHeight = 0`, `LatestStateMachineHeight = 20,000,000`.
3. `FeeHandler::on_executed` fires for the batch, calling `calculate_reward`: `latest_height = 20,000,000`, `previous_height = host.previous_commitment_height(...) = Some(0)`, `LastRewardedHeight` is `None` → `baseline = 0`.
4. `blocks = 20,000,000 - 0 = 20,000,000`; `reward = 20,000,000 * 100 = 2,000,000,000` transferred from `TreasuryAccount` to the relayer for a single, first-ever consensus submission — as confirmed by the transfer call in `process_message` [6](#0-5) .

	fn process_message(
		state_machine_height: StateMachineHeight,
		state_machine_id: StateMachineId,
		relayer_account: T::AccountId,
	) -> Result<(), Error<T>> {
		if let Some(block_cost) = StateMachinesCostPerBlock::<T>::get(state_machine_id) {
			let reward = Self::calculate_reward(&state_machine_id, block_cost)?;

			if reward.is_zero() {
				return Ok(());
			}

			T::Currency::transfer(
				&T::TreasuryAccount::get().into_account_truncating(),
				&relayer_account,
				reward,
				Preservation::Expendable,
			)
			.map_err(|_| Error::<T>::RewardTransferFailed)?;

			Self::deposit_event(Event::<T>::RelayerRewarded {
				relayer: relayer_account.clone(),
				amount: reward,
				state_machine_height,
			});

			T::ReputationAsset::mint_into(&relayer_account, reward.saturated_into())
				.map_err(|_| Error::<T>::ReputationMintFailed)?;

			LastRewardedHeight::<T>::mutate(state_machine_id, |watermark| {
				*watermark = Some(watermark.unwrap_or_default().max(state_machine_height.height));
			});
		}
		Ok(())
	}

#[test]
fn reward_covers_only_unpaid_heights_after_rollback() {
	let mut ext = new_test_ext();
	ext.execute_with(|| {
		const BLOCK_COST: u128 = 100;
		let host = Ismp::default();
		let state_machine_id = setup_state_machine();
		let treasury_account: AccountId32 = PalletId(*b"treasury").into_account_truncating();

		pallet_consensus_incentives::Pallet::<Test>::update_cost_per_block(
			RuntimeOrigin::root(),
			state_machine_id,
			BLOCK_COST,
		)
		.unwrap();

		let (consensus_message, relayer_account) = setup_host_and_message(&host);
		let message = MessageWithWeight { message: consensus_message, weight: Weight::zero() };
		let updated = |height: u64| {
			vec![IsmpEvent::StateMachineUpdated(StateMachineUpdated {
				state_machine_id,
				latest_height: height,
			})]
		};

		// The chain has already advanced to 1025 and every block up to it has been rewarded once.
		host.store_state_machine_commitment(
			StateMachineHeight { id: state_machine_id, height: 1024 },
			commitment(),
		)
		.unwrap();
		host.store_latest_commitment_height(StateMachineHeight {
			id: state_machine_id,
			height: 1024,
		})
		.unwrap();
		host.store_state_machine_commitment(
			StateMachineHeight { id: state_machine_id, height: 1025 },
			commitment(),
		)
		.unwrap();
		host.store_latest_commitment_height(StateMachineHeight {
			id: state_machine_id,
			height: 1025,
		})
		.unwrap();

		let treasury_before_first = Balances::balance(&treasury_account);
		<pallet_consensus_incentives::Pallet<Test> as FeeHandler>::on_executed(
			vec![message.clone()],
			updated(1025),
		)
		.unwrap();

		assert_eq!(Balances::balance(&treasury_account), treasury_before_first - BLOCK_COST);
		assert_eq!(
			pallet_consensus_incentives::LastRewardedHeight::<Test>::get(state_machine_id),
			Some(1025)
		);

		// The previous-height pointer references an older height whose commitment is no longer
		// retained in the bounded map.
		pallet_ismp::PreviousStateMachineHeight::<Test>::insert(state_machine_id, 1);

		// Deleting the latest commitment rolls the latest height back to that previous pointer.
		host.delete_state_commitment(StateMachineHeight { id: state_machine_id, height: 1025 })
			.unwrap();
		assert_eq!(host.latest_commitment_height(state_machine_id).unwrap(), 1);

		// The next honest consensus update advances to 1030, carrying the stale pointer forward as
		// the new previous height.
		host.store_state_machine_commitment(
			StateMachineHeight { id: state_machine_id, height: 1030 },
			commitment(),
		)
		.unwrap();
		host.store_latest_commitment_height(StateMachineHeight {
			id: state_machine_id,
			height: 1030,
		})
		.unwrap();
		assert_eq!(host.previous_commitment_height(state_machine_id), Some(1));

		let treasury_before_second = Balances::balance(&treasury_account);
		<pallet_consensus_incentives::Pallet<Test> as FeeHandler>::on_executed(
			vec![message],
			updated(1030),
		)
		.unwrap();

		// The real advance is 1025 -> 1030, so only the 5 new blocks are paid rather than the full
		// span back to the previous pointer.
		assert_eq!(Balances::balance(&treasury_account), treasury_before_second - 5 * BLOCK_COST);
		assert_eq!(
			pallet_consensus_incentives::LastRewardedHeight::<Test>::get(state_machine_id),
			Some(1030)
		);
	})
}
