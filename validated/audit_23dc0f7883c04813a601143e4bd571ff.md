### Title
Unauthenticated payout OP_RETURN lets anyone credit an arbitrary operator for a payout they never funded - ([File: core/src/verifier.rs])

### Summary
The payout transaction that fronts a Citrea withdrawal is signed by the funding party only over the withdrawal input and the user's payout output (`TapSighashType::SinglePlusAnyoneCanPay`). The OP_RETURN output that names "the operator who fronted this payout" is completely outside that signature, so anyone who can fund and broadcast a valid payout transaction can put **any** operator's x-only pubkey in the OP_RETURN. `Verifier::update_finalized_payouts`/`is_kickoff_malicious` and `PayoutCheckerTask::run_once` trust that unauthenticated byte string as the sole proof of "who paid", allowing an attacker to make an honest operator get reimbursed `bridge_amount` for a payout that operator never funded or even knew about.

### Finding Description
The binding that must hold is:

`credited_operator(withdrawal_idx) == funding_party(withdrawal_idx)`

where `funding_party` is whoever actually supplied the value that pays the user's withdrawal output.

`create_payout_txhandler` builds the payout tx with a single signed input (the withdrawal UTXO) and a `user_sig`, but only signs output 0 (the user payout) because the sighash type enforced in `parse_withdrawal_sig_params` is `TapSighashType::SinglePlusAnyoneCanPay`: [1](#0-0) 
This sighash flag leaves the anchor output and, critically, **the OP_RETURN output that names the crediting operator** completely unsigned and freely modifiable by whoever assembles/broadcasts the final transaction: [2](#0-1) 

On the verifier side, `update_finalized_payouts` derives `operator_xonly_pk` purely by parsing this unauthenticated OP_RETURN push from the mined payout tx, with no check that the named key actually produced any signature in that transaction: [3](#0-2) 
That value is persisted verbatim as `payout_payer_operator_xonly_pk`: [4](#0-3) 

`Verifier::is_kickoff_malicious` only checks that this stored (attacker-controlled) key matches the kickoff's operator key and that the committed blockhash matches - it never verifies that the named operator actually signed or funded the payout input: [5](#0-4) 

`PayoutCheckerTask::run_once` on operator O's side blindly picks up "the first unhandled payout" keyed by O's own xonly pubkey (populated from the same unauthenticated field) and calls `handle_finalized_payout`, which starts a kickoff and eventually leads to `Reimburse`: [6](#0-5) 

Because the attacker only needs to (a) fund/control the withdrawal UTXO's key (they can be the party that registers the withdrawal on Citrea and picks/owns the input UTXO/signature per the threat-model's stated capabilities) and (b) append any OP_RETURN before broadcasting, they can name honest operator O instead of themselves. `is_kickoff_malicious` and `PayoutCheckerTask` will treat this exactly like a legitimate fronted payout by O, because both rely solely on the OP_RETURN bytes, which carry zero cryptographic binding to O.

### Impact Explanation
`bridge_amount` BTC leaves the move-to-vault UTXO and is paid to operator O via the `Reimburse` transaction even though O supplied none of the capital that funded the withdrawal payout output - the actual funder receives no reimbursement. This is repeatable for every withdrawal and against any operator whose x-only pubkey is public (all operator pubkeys are discoverable via `GetXOnlyPublicKey` or deposit data), so an attacker can target any operator on any withdrawal, at will. This matches the explicitly listed Critical category: "an operator reimbursed for a payout it never funded."

### Likelihood Explanation
The only preconditions are the ones explicitly granted to the unprivileged attacker: ability to deposit into the bridge, call Citrea's `withdraw`, choose the withdrawal UTXO bytes, and pick a Schnorr signature/sighash flag, plus generic Bitcoin broadcast capability. No verifier/operator/aggregator privilege, key compromise, or majority hashrate is required. The attacker's cost is exactly one payout amount (the funds used to complete the withdrawal transaction, which they do not recover) plus miner fees - the attack is reproducible at will against any operator and any withdrawal index; it does not require racing against the network in the classical sense since attacker only needs to build/broadcast a valid, sighash-compliant completion once, then let it confirm to finality before any legitimate operator's own competing payout tx does.

### Recommendation
Bind the credited operator cryptographically to the payout transaction instead of trusting a free-form OP_RETURN push. Options: (1) require the sighash to cover the OP_RETURN output (e.g. use `TapSighashType::Single` without `AnyoneCanPay`, or a fixed second signature from the operator over the OP_RETURN byte contents) so that only the actual funder/signer can name themselves; or (2) require an additional operator signature (e.g. over `deposit_id || operator_xonly_pk`) checked by `is_kickoff_malicious`/`update_finalized_payouts` before attributing a payout to that operator, so the named operator must have consented/cosigned to being credited.

pub fn create_payout_txhandler(
    input_utxo: UTXO,
    output_txout: TxOut,
    operator_xonly_pk: XOnlyPublicKey,
    user_sig: taproot::Signature,
    _network: bitcoin::Network,
) -> Result<TxHandler<Signed>, BridgeError> {
    let txin = SpendableTxIn::new_partial(input_utxo.outpoint, input_utxo.txout);

    let output_txout = UnspentTxOut::from_partial(output_txout.clone());

    let op_return_txout = op_return_txout(PushBytesBuf::from(operator_xonly_pk.serialize()));

    let mut txhandler = TxHandlerBuilder::new(TransactionType::Payout)
        .with_version(NON_STANDARD_V3)
        .add_input(
            NormalSignatureKind::NotStored,
            txin,
            SpendPath::KeySpend,
            DEFAULT_SEQUENCE,
        )
        .add_output(output_txout)
        .add_output(UnspentTxOut::from_partial(anchor_output(
            NON_EPHEMERAL_ANCHOR_AMOUNT,
        )))
        .add_output(UnspentTxOut::from_partial(op_return_txout))
        .finalize();
    txhandler.set_p2tr_key_spend_witness(&user_sig, 0)?;
    txhandler.promote()
}

    /// Checks if the operator who sent the kickoff matches the payout data saved in our db
    /// Payout data in db is updated during citrea sync.
    async fn is_kickoff_malicious(
        &self,
        kickoff_witness: Witness,
        deposit_data: &mut DepositData,
        kickoff_data: KickoffData,
        dbtx: DatabaseTransaction<'_>,
    ) -> Result<bool, BridgeError> {
        let move_txid =
            create_move_to_vault_txhandler(deposit_data, self.config.protocol_paramset())?
                .get_cached_tx()
                .compute_txid();

        let payout_info = self
            .db
            .get_payout_info_from_move_txid(Some(dbtx), move_txid)
            .await?;
        let Some((operator_xonly_pk_opt, payout_blockhash, _, _)) = payout_info else {
            tracing::warn!(
                "No payout info found in db for move txid {move_txid}, assuming malicious"
            );
            return Ok(true);
        };

        let Some(operator_xonly_pk) = operator_xonly_pk_opt else {
            tracing::warn!("No operator xonly pk found in payout tx OP_RETURN, assuming malicious");
            return Ok(true);
        };

        if operator_xonly_pk != kickoff_data.operator_xonly_pk {
            tracing::warn!("Operator xonly pk for the payout does not match with the kickoff_data");
            return Ok(true);
        }

        let wt_derive_path = WinternitzDerivationPath::Kickoff(
            kickoff_data.round_idx,
            kickoff_data.kickoff_idx,
            self.config.protocol_paramset(),
        );
        let commits = extract_winternitz_commits(
            kickoff_witness,
            &[wt_derive_path],
            self.config.protocol_paramset(),
        )?;
        let blockhash_data = commits.first();
        // only last 20 bytes of the blockhash is committed
        let truncated_blockhash = &payout_blockhash[12..];
        if let Some(committed_blockhash) = blockhash_data {
            if committed_blockhash != truncated_blockhash {
                tracing::warn!("Payout blockhash does not match committed hash: committed: {:?}, truncated payout blockhash: {:?}",
                        blockhash_data, truncated_blockhash);
                return Ok(true);
            }
        } else {
            return Err(eyre::eyre!("Couldn't retrieve committed data from witness").into());
        }
        Ok(false)
    }

    /// Sets the given payout txs' txid and operator index for the given index.
    pub async fn update_payout_txs_and_payer_operator_xonly_pk(
        &self,
        tx: Option<DatabaseTransaction<'_>>,
        payout_txs_and_payer_operator_xonly_pk: Vec<(
            u32,
            Txid,
            Option<XOnlyPublicKey>,
            bitcoin::BlockHash,
        )>,
    ) -> Result<(), BridgeError> {
        if payout_txs_and_payer_operator_xonly_pk.is_empty() {
            return Ok(());
        }
        // Convert all values first, propagating any errors
        let converted_values: Result<Vec<_>, BridgeError> = payout_txs_and_payer_operator_xonly_pk
            .iter()
            .map(|(idx, txid, operator_xonly_pk, block_hash)| {
                Ok((
                    i32::try_from(*idx).wrap_err("Failed to convert payout index to i32")?,
                    TxidDB(*txid),
                    operator_xonly_pk.map(XOnlyPublicKeyDB),
                    BlockHashDB(*block_hash),
                ))
            })
            .collect();
        let converted_values = converted_values?;

        let mut query_builder = QueryBuilder::new(
            "UPDATE withdrawals AS w SET
                payout_txid = c.payout_txid,
                payout_payer_operator_xonly_pk = c.payout_payer_operator_xonly_pk,
                payout_tx_blockhash = c.payout_tx_blockhash
                FROM (",
        );

        query_builder.push_values(
            converted_values.into_iter(),
            |mut b, (idx, txid, operator_xonly_pk, block_hash)| {
                b.push_bind(idx)
                    .push_bind(txid)
                    .push_bind(operator_xonly_pk)
                    .push_bind(block_hash);
            },
        );

        query_builder
            .push(") AS c(idx, payout_txid, payout_payer_operator_xonly_pk, payout_tx_blockhash) WHERE w.idx = c.idx");

        let query = query_builder.build();
        execute_query_with_tx!(self.connection, tx, query, execute)?;

    async fn run_once(&mut self) -> Result<Self::Output, BridgeError> {
        let mut dbtx = self.db.begin_transaction().await?;
        let unhandled_payout = self
            .db
            .get_first_unhandled_payout_by_operator_xonly_pk(
                Some(&mut dbtx),
                self.operator.signer.xonly_public_key,
            )
            .await?;

        if unhandled_payout.is_none() {
            return Ok(false);
        }

        let (citrea_idx, move_to_vault_txid, payout_tx_blockhash) =
            unhandled_payout.expect("Must be Some");

        tracing::info!(
            "Unhandled payout found for withdrawal {}, move_txid: {}",
            citrea_idx,
            move_to_vault_txid
        );

        let deposit_data = self
            .db
            .get_deposit_data_with_move_tx(Some(&mut dbtx), move_to_vault_txid)
            .await?;
        if deposit_data.is_none() {
            return Err(eyre::eyre!("Fronted withdrawal for move tx {move_to_vault_txid} found, but the signatures for the deposit are not found in the db.").into());
        }

        let deposit_data = deposit_data.expect("Must be Some");

        let kickoff_txid = self
            .operator
            .handle_finalized_payout(
                &mut dbtx,
                deposit_data.get_deposit_outpoint(),
                payout_tx_blockhash,
            )
            .await?;

        // fetch and save the LCP for if we get challenged and need to provide proof of payout later
        let (_, payout_block_height) = self
            .operator
            .db
            .get_block_info_from_hash(Some(&mut dbtx), payout_tx_blockhash)
            .await?
            .ok_or_eyre("Couldn't find payout blockhash in bitcoin sync")?;

        let _ = self
            .operator
            .citrea_client
            .fetch_validate_and_store_lcp(
                payout_block_height as u64,
                citrea_idx,
                &self.operator.db,
                Some(&mut dbtx),
                self.operator.config.protocol_paramset(),
            )
            .await?;

        #[cfg(feature = "automation")]
        self.operator.end_round(&mut dbtx).await?;

        self.db
            .mark_payout_handled(Some(&mut dbtx), citrea_idx, kickoff_txid)
            .await?;

        dbtx.commit().await?;

        Ok(true)
    }
