### Title
Reward distribution during block finalization halts entirely if the injected MultiCall contract call to the AddressBook fails - ([File: kaiax/staking/impl/getter.go])

### Summary
This is the same bug class as the QuickSwap/StellaSwap M-03 finding: a core, per-transaction/per-block operation makes a synchronous external contract call whose failure is not tolerated, and that failure blocks a critical path (there, swapping; here, block reward finalization). In Kaia, `StakingModule.GetStakingInfo` synchronously calls into a system contract (`AddressBook`/`MultiCall`) via a full EVM execution, and any error from that call is propagated up and aborts `RewardModule.FinalizeState`, which is invoked as part of `Process`/block finalization for every block.

### Finding Description
`RewardModule.FinalizeState` runs at the end of every block's processing to accredit block rewards [1](#0-0) . It calls `r.GetDeferredReward(header, txs, receipts)`, and on the `ProposerPolicy == WeightedRandom` path it also calls `r.GetRewardAddress` → `r.StakingModule.GetStakingInfo(num)` [2](#0-1) .

`StakingModule.GetStakingInfo` reads cached/DB data when available, but when neither is present it falls through to `getFromStateByNumber` → `getFromState`, which performs a genuine external contract call: it injects the `MultiCall` contract bytecode into a copy of the state and executes an EVM call against the `AddressBook` contract (`contract.MultiCallStakingInfo` / `MultiCallStakingInfoPermissionless` / `MultiCallDPStakingInfo`) [3](#0-2) . This call is implemented via `ContractCallerForMultiCall.CallContract`, which sets code at `MultiCallAddr` and calls `blockchain.ApplyMessage(evm, msg)` — a real EVM execution that can revert or otherwise error [4](#0-3) .

Any error from these calls (`ErrAddressBookCall`, `ErrCLRegistryCall`, `ErrMultiCallCall`) is returned unchanged up the call chain [5](#0-4) [6](#0-5) , and `RewardModule.FinalizeState` propagates that error directly without any fallback or retry logic [2](#0-1) .

This is structurally identical to the AlgebraPool/AlgebraVirtualPool pattern in the external report: a core state-transition step (swap execution there, block reward finalization here) makes a push-style, synchronous call into another contract whose implementation is not controlled by (and can be independently broken relative to) the calling logic, and any revert/error in that call is not handled gracefully — it fails the entire operation instead of degrading gracefully (e.g., falling back to non-staking-weighted rewards).

### Impact Explanation
If the `AddressBook`/`MultiCall`/`CLRegistry` system contracts are misconfigured, contain a bug that causes their view functions to revert, or return data that fails Kaia's post-processing sanity checks (`parseCallResult`/`parsePermissionlessCallResult` return `ErrAddressBookResult`/`ErrCLRegistryResult` on malformed data) [7](#0-6) , then `GetStakingInfo` errors, which causes `RewardModule.FinalizeState` to fail for every subsequent block. Since `FinalizeState` is part of the mandatory block finalization pipeline invoked from `Process`/`state_processor.go`, an error here would prevent block finalization network-wide (all honest nodes execute the same deterministic logic and would hit the same error), effectively halting block production/finalization until the underlying contract issue is fixed — analogous to swapping being fully blocked in the QuickSwap/StellaSwap case.

### Likelihood Explanation
This path is reachable purely through normal protocol operation (no privileged access needed): any block that requires state-based staking-info lookup (cache miss, e.g., after a restart or on the Kaia hardfork boundary as shown in the `TestStateReexec` test which explicitly forces the state-trie lookup path) [8](#0-7)  will exercise the vulnerable call chain. Because the `AddressBook`/`Registry` contracts are configurable system contracts (addresses/format can be updated via governance or admin transactions), a misconfiguration, storage-layout mismatch, or unexpected revert condition in those contracts is a plausible and impactful trigger, matching the acknowledged-but-unmitigated nature of the original finding.

### Recommendation
Short term: In `RewardModule.FinalizeState`/`GetRewardAddress` and `StakingModule.getFromState`, handle failures from the injected `MultiCall`/`AddressBook` EVM calls gracefully (e.g., fall back to a safe default distribution, such as "all reward to proposer," rather than aborting block finalization) similar to how the "all to proposer" fallback is already assumed elsewhere in the codebase for missing staking info [9](#0-8) . Long term: decouple correctness of state-transition/reward logic from the liveness of external system-contract calls — e.g., validate/cache AddressBook data ahead of time and treat on-the-fly EVM calls purely as a performance optimization with a defined, deterministic fallback rather than an operation whose failure can propagate into consensus-critical state transition errors.

### Proof of Concept
1. Deploy/replace the `AddressBook` (or `Registry`/`CLRegistry`) system contract such that a call to `getAllAddress()` (as wrapped by `MultiCallStakingInfo`) reverts, or returns malformed type/address lists causing `len(types) != len(addrs)` in `parseCallResult` [10](#0-9) .
2. Trigger a state lookup path for `GetStakingInfo` (e.g., after a cache purge/restart, or right at the Kaia-fork boundary when `WeightedRandom` proposer policy is active) [11](#0-10) .
3. Observe `getFromState` return `staking.ErrAddressBookCall`/`staking.ErrAddressBookResult`, which propagates through `GetStakingInfo` → `GetRewardAddress`/`GetDeferredReward` → `RewardModule.FinalizeState`, causing block finalization to fail for that and all subsequent blocks until the contract issue is resolved [12](#0-11) .

// Distribute the deferred rewards at the end of block processing.
func (r *RewardModule) FinalizeState(header *types.Header, state *state.StateDB, txs []*types.Transaction, receipts []*types.Receipt) error {
	if r.GovModule.GetParamSet(header.Number.Uint64()).ProposerPolicy == uint64(istanbul.WeightedRandom) && common.EmptyHash(header.Root) {
		qualified, err := r.ValsetModule.GetQualifiedValidators(header.Number.Uint64())
		if err != nil {
			return err
		}
		useRewardAddress := valset.NewAddressSet(qualified).Contains(r.NodeAddress)

		if rewardAddr := r.GetRewardAddress(header.Number.Uint64(), r.NodeAddress); useRewardAddress && rewardAddr != (common.Address{}) {
			header.Rewardbase = rewardAddr
			logger.Trace("Use reward address for nodeValidator", "header.Number", header.Number.Uint64(), "nodeAddress", r.NodeAddress, "rewardbase", header.Rewardbase)
		} else {
			logger.Trace("No reward address for nodeValidator. Use node's rewardbase.", "header.Number", header.Number.Uint64(), "nodeAddress", r.NodeAddress, "rewardbase", header.Rewardbase)
		}
	}

	spec, err := r.GetDeferredReward(header, txs, receipts)
	if err != nil {
		return err
	}
	if err := spec.Validate(); err != nil {
		return err
	}
	for addr, amount := range spec.Rewards {
		state.AddBalance(addr, amount)
	}
	return nil
}

// Efficiently read addresses and balances from the AddressBook in one EVM call.
// Works by temporarily injecting the MultiCallContract to a copied state.
func (s *StakingModule) getFromState(header *types.Header, statedb *state.StateDB) (*staking.StakingInfo, error) {
	isForPrague := s.ChainConfig.IsPragueForkEnabled(new(big.Int).Add(header.Number, common.Big1))
	isForPermissionless := s.ChainConfig.IsPermissionlessForkEnabled(new(big.Int).Add(header.Number, common.Big1))
	num := header.Number.Uint64()

	// Bail out if AddressBook is not installed.
	// This is a common case for private nets.
	if statedb.GetCode(system.AddressBookAddr) == nil {
		logger.Trace("AddressBook not installed", "sourceNum", num)
		return emptyStakingInfo(num), nil
	}

	// Now we're safe to call the MultiCall contract.
	contract, err := system.NewMultiCallContractCaller(statedb, s.Chain, header)
	if err != nil {
		return nil, staking.ErrMultiCallCall(err)
	}

	callOpts := &bind.CallOpts{BlockNumber: header.Number}

	// Helper to read CL registry info, shared by permissioned and permissionless paths.
	// Permissionless is ordered after Prague (Randao <= Kaia <= Prague <= Permissionless),
	// so permissionless blocks always need CL registry info too.
	readCLInfo := func() (clRegistryResult, error) {
		var clRes clRegistryResult
		// If Registry is not installed, do not handle CL staking info.
		// In private network, Randao and Prague hardfork can be activated at the same block.
		// It leads to staking info inconsistency between block processing and rpc query since the Registry hasn't been installed when finalizing the header.
		// Note that Randao can't be activated after Prague according to fork ordering (Randao <= Kaia <= Prague).
		if statedb.GetCode(system.RegistryAddr) == nil || s.ChainConfig.IsRandaoForkBlockParent(header.Number) {
			logger.Trace("Registry not installed", "sourceNum", num)
			return clRes, nil
		}
		// Note that if CLRegistry is not registered in Registry,
		// it will return empty result and no error.
		clRes, err = contract.MultiCallDPStakingInfo(callOpts)
		if err != nil {
			return clRes, staking.ErrCLRegistryCall(err)
		}
		return clRes, nil
	}

	// Permissionless: read from AddressBookV2 (effective stake, reward-eligible only).
	if isForPermissionless {
		res, err := contract.MultiCallStakingInfoPermissionless(callOpts)
		if err != nil {
			return nil, staking.ErrAddressBookCall(err)
		}
		clRes, err := readCLInfo()
		if err != nil {
			return nil, err
		}
		return parsePermissionlessCallResult(num, res.Profiles, res.StakingAmounts, res.KefAddr, res.KifAddr, res.KpfAddr, clRes)
	}

	// Permissioned: read from legacy AddressBook.
	abRes, err := contract.MultiCallStakingInfo(callOpts)
	if err != nil {
		return nil, staking.ErrAddressBookCall(err)
	}

func parseCallResult(num uint64,
	types []uint8,
	addrs []common.Address,
	amounts []*big.Int,
	clRes clRegistryResult,
	spareAddr common.Address,
) (*staking.StakingInfo, error) {
	// Sanity check.
	if len(types) == 0 && len(addrs) == 0 {
		// This is an expected behavior when the AddressBook contract is not activated yet.
		logger.Trace("returning empty staking info because AddressBook is not activated", "sourceNum", num)
		return emptyStakingInfo(num), nil
	}
	if len(types) != len(addrs) {
		logger.Error("length of type list and address list differ", "sourceNum", num, "typeLen", len(types), "addrLen", len(addrs))
		return nil, staking.ErrAddressBookResult
	}
	if len(clRes.NodeIds) != len(clRes.ClPools) || len(clRes.NodeIds) != len(clRes.StakingAmounts) {
		logger.Error("length of CL registry result fields differ", "sourceNum", num, "nodeLen", len(clRes.NodeIds), "poolLen", len(clRes.ClPools), "amountLen", len(clRes.StakingAmounts))
		return nil, staking.ErrCLRegistryResult
	}

// CallContract injects a multicall contract code into the state and executes the call.
func (caller *ContractCallerForMultiCall) CallContract(ctx context.Context, call kaia.CallMsg, blockNumber *big.Int) ([]byte, error) {
	gasPrice := big.NewInt(0) // execute call regardless of the balance of the sender
	gasLimit := uint64(1e8)   // enough gas limit to execute multicall contract functions
	intrinsicGas := uint64(0) // read operation doesn't require intrinsicGas

	// call.From: zero address will be assigned if nothing is specified
	// call.To: the target contract address will be assigned by `BoundContract`
	// call.Value: nil value is acceptable for `types.NewMessage`
	// call.Data: a proper value will be assigned by `BoundContract`
	// No need to handle access list here

	// Set the code of the multicall contract
	err := caller.state.SetCode(MultiCallAddr, MultiCallCode)
	if err != nil {
		return nil, err
	}

	msg := types.NewMessage(call.From, call.To, caller.state.GetNonce(call.From),
		call.Value, gasLimit, gasPrice, nil, nil, nil, call.Data, false, intrinsicGas, nil, nil, nil, nil, nil)

	blockContext := blockchain.NewEVMBlockContext(caller.header, caller.chain, nil)
	txContext := blockchain.NewEVMTxContext(msg, caller.header, caller.chain.Config())
	txContext.GasPrice = gasPrice                                                                // set gasPrice again if baseFee is assigned
	evm := vm.NewEVM(blockContext, txContext, caller.state, caller.chain.Config(), &vm.Config{}) // no additional vm config required

	result, err := blockchain.ApplyMessage(evm, msg)
	return result.Return(), err
}

func (s *StakingModule) PostInsertBlock(block *types.Block) error {
	isKaia := s.ChainConfig.IsKaiaForkEnabled(block.Number())
	if !isKaia {
		// Make sure the staking info for the new block is persisted.
		// The StakingInfo(sourceNum) will be persisted here, even if GetStakingInfo is never called elsewhere.
		if _, err := s.GetStakingInfo(block.NumberU64()); err != nil {
			return err
		}
	}
	return nil
}
