### Title
Public HTTP/WS JSON-RPC exposure of internal node IP address and peer connection metadata via `admin_nodeInfo`/`admin_peers` marked `Public: true` - ([File: node/node.go])

### Summary
The `admin_nodeInfo` and `admin_peers` RPC methods are registered with `Public: true` in the node's default API list, meaning they are exposed on public HTTP and WebSocket RPC endpoints by default (i.e., when no explicit `--rpcapi`/`--wsapi` module whitelist is supplied), even though these methods belong to the `admin` namespace and disclose the node's internal/listening IP address, enode, and peer connection endpoints. This mirrors CVE-2021-3024, where HashiCorp Vault disclosed the internal IP address of the node in response to unauthenticated HTTP requests.

### Finding Description
`node/node.go` registers `AdminNodeAPI` (which implements `Peers()` and `NodeInfo()`) with `Public: true`: [1](#0-0) 

`AdminNodeAPI.NodeInfo()` and `AdminNodeAPI.Peers()` return the server's `p2p.NodeInfo` (including `IP`, `ListenAddr`, `Enode`) and `[]*p2p.PeerInfo` (including each peer's `LocalAddress`/`RemoteAddress` TCP endpoints): [2](#0-1) [3](#0-2) [4](#0-3) 

The RPC endpoint registration logic in `networks/rpc/endpoints.go` registers any API whose `Public` field is `true` on HTTP/WS when the operator has not set an explicit module whitelist (`len(whitelist) == 0`): [5](#0-4) [6](#0-5) 

Because `admin_nodeInfo`/`admin_peers` are flagged `Public`, unlike the rest of the `admin` namespace (e.g. `AdminNetworkNodeAPI`, which is registered without `Public: true` and is therefore admin-namespace gated), any node operator who does not explicitly restrict `--rpcapi`/`--wsapi` to a specific module list will unintentionally expose these methods to any unauthenticated caller on the public HTTP/WS RPC port. A caller can query `admin_nodeInfo`/`admin_peers` and obtain the node's internal listening IP address, TCP/UDP ports, and the remote/local addresses of all connected peers — internal network topology information that should not be available to an anonymous public-RPC caller, directly analogous to the Vault CVE-2021-3024 disclosure of internal IP via an unauthenticated endpoint.

### Impact Explanation
Disclosure of a Consensus Node's or Endpoint Node's internal IP address, listen address, and connected peer addresses to any public, unauthenticated RPC caller enables network reconnaissance that can facilitate targeted network-level attacks (e.g., DoS, eclipse attempts, or targeting a specific CN's real IP behind a load balancer/proxy) against the Kaia network's consensus/validator infrastructure. This is an information-disclosure issue reachable by any public RPC caller without any transaction or privileges — matching the "public RPC" surface allowed in scope. It does not by itself cause fund loss, but leaks operationally sensitive infrastructure data that undermines the network's IP-address secrecy assumptions (particularly relevant for CNs, which are expected to keep their IPs private from the broader validator/public network).

### Likelihood Explanation
Likelihood depends entirely on node operator configuration: if an operator does not pass an explicit `--rpcapi`/`--wsapi` module list (leaving `whitelist` empty), all `Public: true` APIs — including `admin_nodeInfo`/`admin_peers` — are exposed automatically. Given that many operators run nodes with default RPC module settings, and that this behavior is not obviously communicated (the `admin` namespace is generally assumed to require explicit enabling), unintentional exposure of internal IPs is plausible in real-world deployments, especially on nodes exposing HTTP/WS to the public internet for read RPC purposes.

### Recommendation
Remove `Public: true` from the `AdminNodeAPI` registration in `node/node.go` (and any other `admin`-namespace registrations that carry it, e.g., `node/sc/mainbridge.go`, `cmd/kbn/node.go` if applicable), so that `admin_nodeInfo`/`admin_peers` are only exposed when an operator explicitly whitelists the `admin` module via `--rpcapi`/`--wsapi`, consistent with the rest of the `admin` namespace. Alternatively, strip `IP`/`ListenAddr`/peer `LocalAddress`/`RemoteAddress` fields from responses served over public (non-IPC) transports, or gate `NodeInfo()`/`Peers()` behind `IPCOnly` similar to sensitive `debug` methods.

### Proof of Concept
1. Start a Kaia node (`kcn`/`ken`) with `--http --http.addr 0.0.0.0` and no explicit `--http.api` module list (default modules).
2. As an unauthenticated remote caller, send:
```
curl -X POST --data '{"jsonrpc":"2.0","method":"admin_nodeInfo","params":[],"id":1}' http://<node-ip>:8551
curl -X POST --data '{"jsonrpc":"2.0","method":"admin_peers","params":[],"id":1}' http://<node-ip>:8551
```
3. Observe that the response contains the node's internal `ip`/`listenAddr`/`enode` (from `AdminNodeAPI.NodeInfo` → `server.NodeInfo()`, `node/api_admin.go` lines 74–98, `networks/p2p/server_base.go` lines 980–1007) and each connected peer's `localAddress`/`remoteAddress` (`node/api_admin.go` line 47–53, `networks/p2p/peer.go` lines 684–719) — disclosed without any authentication, purely because these APIs are flagged `Public: true` in `node/node.go` lines 729–757.

// NodeInfo retrieves all the information we know about the host node at the
// protocol granularity.
func (api *AdminNodeAPI) NodeInfo() (*NodeInfoOutput, error) {
	server := api.node.Server()
	if server == nil {
		return nil, ErrNodeStopped
	}

	var (
		nodeKey  = api.node.config.NodeKey()
		nodeAddr = crypto.PubkeyToAddress(nodeKey.PublicKey)

		blsPriv = api.node.config.BlsNodeKey()
		blsPub  = blsPriv.PublicKey().Marshal()
		blsPop  = bls.PopProve(blsPriv).Marshal()
	)

	info := &NodeInfoOutput{
		NodeInfo:    *server.NodeInfo(),
		NodeAddress: nodeAddr.Hex(),
		BlsPublicKeyInfo: BlsPublicKeyInfoOutput{
			PublicKey: hex.EncodeToString(blsPub),
			Pop:       hex.EncodeToString(blsPop),
		},
	}
	return info, nil
}

// NodeInfo represents a short summary of the information known about the host.
type NodeInfo struct {
	ID    string `json:"id"`   // Unique node identifier (also the encryption key)
	Name  string `json:"name"` // Name of the node, including client type, version, OS, custom data
	Enode string `json:"kni"`  // Enode URL for adding this peer from remote peers
	IP    string `json:"ip"`   // IP address of the node
	Ports struct {
		Discovery int `json:"discovery"` // UDP listening port for discovery protocol
		Listener  int `json:"listener"`  // TCP listening port for RLPx
	} `json:"ports"`
	ListenAddr string                 `json:"listenAddr"`
	Protocols  map[string]interface{} `json:"protocols"`
}

// NodeInfo gathers and returns a collection of metadata known about the host.
func (srv *BaseServer) NodeInfo() *NodeInfo {
	node := srv.Self()

	// Gather and assemble the generic node infos
	info := &NodeInfo{
		Name:       srv.Name(),
		Enode:      node.String(),
		ID:         node.ID.String(),
		IP:         node.IP.String(),
		ListenAddr: srv.ListenAddr,
		Protocols:  make(map[string]interface{}),
	}
	info.Ports.Discovery = int(node.UDP)
	info.Ports.Listener = int(node.TCP)

	// Gather all the running protocol infos (only once per protocol type)
	for _, proto := range srv.Protocols {
		if _, ok := info.Protocols[proto.Name]; !ok {
			nodeInfo := interface{}("unknown")
			if query := proto.NodeInfo; query != nil {
				nodeInfo = proto.NodeInfo()
			}
			info.Protocols[proto.Name] = nodeInfo
		}
	}
	return info
}
