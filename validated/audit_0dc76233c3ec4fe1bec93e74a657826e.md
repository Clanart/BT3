### Title
Unbounded slice access in `IsGzip`/`IsWasm` causes an out-of-bounds-read panic on attacker-supplied wasm bytecode - ([File: sei-wasmd/x/wasm/ioutils/utils.go])

### Summary
`ioutils.IsGzip` and `ioutils.IsWasm` slice their `input []byte` argument (`input[:3]` and `input[:4]`) without first checking `len(input)`, so any caller that passes bytecode shorter than the magic-byte prefix triggers a Go runtime "slice bounds out of range" panic. [1](#0-0)  This mirrors the CVE-2017-12957 bug class: a length/format-sniffing routine reads a fixed-size header prefix from untrusted, attacker-controlled input without validating that the input is long enough to contain it, producing an out-of-bounds read/crash instead of a validated one.

### Finding Description
`IsGzip` and `IsWasm` are format-sniffers used to detect whether uploaded CosmWasm bytecode is gzip-compressed or a raw wasm binary. [2](#0-1)  Both functions unconditionally slice the input to a fixed length (3 or 4 bytes) before comparing against the magic-byte constants, with no `len(input) >= N` guard. These helpers are reached from the CosmWasm code-upload path (`x/wasm` CLI/REST tx builders) and from the EVM-side wasmd precompile / EVM JSON-RPC simulate path (`evmrpc/simulate.go`, `precompiles/wasmd/wasmd.go`), both of which accept caller-supplied bytecode. If a contract deployer or EVM caller supplies a bytecode/msg byte slice shorter than 3 or 4 bytes, the slice expression panics.

### Impact Explanation
A panic triggered on the public-facing code paths (JSON-RPC simulate/eth_call flow that reaches the wasmd precompile, or the wasm store-code message handling) can crash or abort request processing on a default-configuration node if the panic is not caught by an enclosing `recover()`. Within the deliver-tx execution paths in `app.go` there are `recover()` wrappers around transaction execution, so a panic there is likely converted into a failed-tx result rather than a node crash; however, I could not fully confirm whether the `evmrpc/simulate.go` call sites (used for `eth_call`/`eth_estimateGas` simulation on the public RPC surface) are wrapped in an equivalent recovery boundary. If that call path lacks recovery, an unauthenticated RPC client could crash the RPC service by submitting a short/malformed byte payload — matching the "crash of default-configuration RPC nodes" impact bar.

### Likelihood Explanation
Triggering the bug only requires supplying a byte slice of length 0–2 (for `IsGzip`) or 0–3 (for `IsWasm`) to any caller of these functions, which is trivial for any tokenfactory/CW/EVM caller who can control the bytecode/msg payload reaching the wasm store-code or wasmd-precompile flow. No privileged access or special conditions are required — this is a single-request denial-of-service primitive if reached without a preceding length guard.

### Recommendation
Add explicit length checks before slicing in both functions, e.g.:
```go
func IsGzip(input []byte) bool {
    return len(input) >= 3 && bytes.Equal(input[:3], gzipIdent)
}
func IsWasm(input []byte) bool {
    return len(input) >= 4 && bytes.Equal(input[:4], wasmIdent)
}
```
Audit all call sites (`evmrpc/simulate.go`, `precompiles/wasmd/*/wasmd.go`, `x/wasm/client/cli/tx.go`, `x/wasm/client/rest/tx.go`) to confirm callers do not already guarantee a minimum length, and add regression tests with 0/1/2/3-byte inputs.

### Proof of Concept
```go
package main

import "github.com/sei-protocol/sei-chain/sei-wasmd/x/wasm/ioutils"

func main() {
    // len(input) == 1, shorter than the 3-byte gzip magic prefix
    _ = ioutils.IsGzip([]byte{0x1F}) // panics: slice bounds out of range [:3] with capacity 1
}
```
Submitting an EVM transaction/RPC simulate call to the wasmd precompile (`instantiate`/`execute`) with a `msg`/bytecode byte argument shorter than 3–4 bytes, or a `MsgStoreCode` with a near-empty `WASMByteCode`, drives execution into `IsGzip`/`IsWasm` with an undersized slice and reproduces the same panic in-process.

```go
var (
	// magic bytes to identify gzip.
	// See https://www.ietf.org/rfc/rfc1952.txt
	// and https://github.com/golang/go/blob/master/src/net/http/sniff.go#L186
	gzipIdent = []byte("\x1F\x8B\x08")

	wasmIdent = []byte("\x00\x61\x73\x6D")
)

// IsGzip returns checks if the file contents are gzip compressed
func IsGzip(input []byte) bool {
	return bytes.Equal(input[:3], gzipIdent)
}

// IsWasm checks if the file contents are of wasm binary
func IsWasm(input []byte) bool {
	return bytes.Equal(input[:4], wasmIdent)
}
```
