Audit Report

## Title
Unstaked/unverified QUIC connection attempts can exhaust the global TPU connection-rate token bucket before stake is known, starving staked validators of new connections - (File: `streamer/src/nonblocking/quic.rs`)

## Summary
`run_server()` and `setup_connection()` in the TPU QUIC server gate every incoming connection with a single, node-wide `overall_connection_rate_limiter` token bucket (`TOTAL_CONNECTIONS_PER_SECOND = 2500`, burst `1000`) that is shared by staked and unstaked peers alike. This bucket is consumed immediately after a QUIC handshake completes, but before the peer's stake/identity is evaluated (`qos.build_connection_context()` / `get_connection_stake()` run afterward). An attacker who owns no stake can therefore keep this shared global bucket empty, causing the server to `incoming.ignore()` legitimate connection attempts from staked validators.

## Finding Description
In `run_server()`, incoming connections are first checked against the global bucket (`streamer/src/nonblocking/quic.rs:347-357`) and a per-IP bucket, then the QUIC handshake is performed. After a successful handshake, `setup_connection()` consumes both the per-IP limiter and the global `overall_connection_rate_limiter` (`streamer/src/nonblocking/quic.rs:495-508`) — still before the peer's stake is determined. Only afterward does `qos.build_connection_context(&new_connection)` (line 512) resolve the peer's stake via `get_connection_stake()` (lines 416-428), and only then does `try_add_connection()` (in `SwQos`) decide whether the connection is staked or unstaked. The `overall_connection_rate_limiter` is a single `TokenBucket::new(MAX_CONNECTION_BURST, MAX_CONNECTION_BURST, TOTAL_CONNECTIONS_PER_SECOND)` created once per server (lines 277-281) and shared across all callers regardless of stake. The existing per-IP `ConnectionRateLimiter` guard does not stop this, because it only bounds connections per source IP; an attacker distributing handshake attempts across many source IPs stays under every per-IP limit while still keeping the shared global bucket empty.

## Impact Explanation
When `overall_connection_rate_limiter.current_tokens() == 0` or `consume_tokens(1)` fails, the connection is dropped (`incoming.ignore()` or closed with `CONNECTION_CLOSE_CODE_DISALLOWED`), with no distinction between staked and unstaked callers at that gate. This lets a stakeless/unprivileged actor deny staked validators the ability to establish new TPU QUIC connections used to submit transactions/votes to a leader, degrading transaction/vote propagation to leaders network-wide — a non-RPC remote-exhaustion condition in QUIC/TPU.

## Likelihood Explanation
The attack requires no stake, no validator identity, and no privileged access — only the ability to open QUIC handshakes to a public TPU endpoint from a modest number of distinct source IPs to defeat per-IP limiting while sustaining >2500 handshakes/sec system-wide (with burst headroom of 1000) to keep the shared bucket empty. This is achievable by any unprivileged network participant with basic distributed infrastructure, though it requires sustained bandwidth/connection throughput rather than a single low-rate request.

## Recommendation
Reserve a portion of the global connection-rate budget exclusively for staked/known-identity peers (or apply the global rate limiter only to the unstaked path), and/or move stake resolution (`get_connection_stake`) earlier — e.g., during/right after the TLS handshake via the peer certificate — so admission decisions and any shared/global budget consumption can be split into separate staked and unstaked token buckets, analogous to how `max_staked_connections`/`max_unstaked_connections` are already partitioned in `SwQosConfig`.

## Proof of Concept
1. Deploy N attacker-controlled hosts across distinct source IPs, each staying below `DEFAULT_MAX_CONNECTIONS_PER_IPADDR_PER_MINUTE` (and its 10x burst) for its own IP.
2. Collectively drive QUIC handshake attempts against the validator's TPU port at a sustained rate above `TOTAL_CONNECTIONS_PER_SECOND` (2500/s) plus burst (`MAX_CONNECTION_BURST` = 1000), all as unstaked/no-identity clients.
3. Observe `overall_connection_rate_limiter.consume_tokens(1)` in `setup_connection()` (`streamer/src/nonblocking/quic.rs:495`) failing for new legitimate staked-validator connection attempts, and `stats.connection_rate_limited_across_all` incrementing, while the attacker's own connections never hit their per-IP caps.
4. Confirm staked validators attempting fresh TPU connections during this window are dropped via the same shared-bucket check in `run_server()` (`streamer/src/nonblocking/quic.rs:347`) before their stake is ever evaluated.

    fn build_connection_context(&self, connection: &Connection) -> SwQosConnectionContext {
        let remote_address = connection.remote_address();
        get_connection_stake(connection, &self.staked_nodes).map_or(
            SwQosConnectionContext {
                peer_type: ConnectionPeerType::Unstaked,
                total_stake: 0,
                remote_pubkey: None,
                in_staked_table: false,
                remote_address,
                stream_counter: None,
                last_update: Arc::new(AtomicU64::new(timing::timestamp())),
            },
            |(pubkey, stake, total_stake)| {
                // The heuristic is that the stake should be large enough to have 1 stream pass through within one throttle
                // interval during which we allow max (MAX_STREAMS_PER_MS * STREAM_THROTTLING_INTERVAL_MS) streams.

                let peer_type = {
                    let max_streams_per_ms = self.staked_stream_load_ema.max_streams_per_ms();
                    let min_stake_ratio =
                        1_f64 / (max_streams_per_ms * STREAM_THROTTLING_INTERVAL_MS) as f64;
                    let stake_ratio = stake as f64 / total_stake as f64;
                    if stake_ratio < min_stake_ratio {
                        // If it is a staked connection with ultra low stake ratio, treat it as unstaked.
                        ConnectionPeerType::Unstaked
                    } else {
                        ConnectionPeerType::Staked(stake)
                    }
                };

                SwQosConnectionContext {
                    peer_type,
                    total_stake,
                    remote_pubkey: Some(pubkey),
                    in_staked_table: false,
                    remote_address,
                    last_update: Arc::new(AtomicU64::new(timing::timestamp())),
                    stream_counter: None,
                }
            },
        )
    }
