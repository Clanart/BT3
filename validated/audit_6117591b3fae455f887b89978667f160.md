### Title
Empty aggregate Schnorr signature verifies for an empty signer set - ([File: crypto/schnorr/src/aggregate.rs](crypto/schnorr/src/aggregate.rs))

### Summary
`SchnorrAggregate::verify` accepts an aggregate containing zero nonces whenever the supplied signer/challenge list is also empty and `s == 0`, even though `SchnorrAggregator::complete` deliberately refuses to produce an empty aggregate. [1](#0-0) [2](#0-1) 

### Finding Description
`SchnorrAggregate::read` parses an attacker-controlled `u32` count, then reads that many `R` values followed by a canonical scalar `s`. [3](#0-2)  During verification, the implementation checks only that `Rs.len() == keys_and_challenges.len()`, queues one pair per supplied challenge, and finally adds `-sG` to the multiexp. [1](#0-0)  With zero `R` values, zero keys/challenges, and `s = 0`, the resulting pair list is exactly `[(-0) * G]`, which evaluates to identity and returns `true`. [4](#0-3)  This acceptance path is not intended by the implementation’s own aggregator, which returns `None` when no signatures were aggregated. [2](#0-1) 

### Impact Explanation
An unprivileged caller can serialize a forged aggregate signature that verifies for an empty authorization set without possessing any private key or signature share. [3](#0-2) [4](#0-3)  This creates a valid-by-verification signature for a case the signing API refuses to produce, enabling downstream authentication bypass wherever an empty signer list is treated as an authorized policy. [2](#0-1) 

### Likelihood Explanation
The complete malicious input is only a four-byte zero length plus a canonical zero scalar, and it reaches `SchnorrAggregate::verify` entirely through public bytes. [3](#0-2) [1](#0-0)  Exploitation is conditional on a caller invoking aggregate verification with an empty signer/challenge list, so it does not by itself bypass verification for a nonempty quorum. [1](#0-0) 

### Recommendation
Reject empty aggregates in `SchnorrAggregate::read` or at the start of `SchnorrAggregate::verify`, matching `SchnorrAggregator::complete`, and require callers to reject empty signer policies before invoking the verifier. [1](#0-0) [2](#0-1) 

### Proof of Concept
