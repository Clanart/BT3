Found the analog: `associatePublicKey` on the `addr` precompile permanently links an EVM address and Sei address purely from a caller-supplied public key, with **no signature/proof-of-possession check**, and this association triggers `AssociateAddresses`/`MigrateBalance`, which sweeps all funds from the "cast address" (the direct EVM→Sei byte-cast account) into the newly associated true Sei address.

### Title
Fund redirection via unauthenticated `associatePublicKey` on the addr precompile enabling forced balance migration - (File: precompiles/addr/addr.go)

### Summary
The `addr` precompile exposes two association entry points: `associate` (requires an ECDSA signature over a challenge message, proving control of the private key) and `associatePublicKey`, which accepts a raw compressed public key with **no cryptographic proof that the caller controls the corresponding private key**. [1](#0-0) 
This mirrors the OpenSignLabs bug class: a state-changing, authorization-sensitive function is reachable by any caller without verifying that the caller is actually authorized to invoke it on behalf of the affected identity.

### Finding Description
`associate` derives the account from an EIP-191 signature (`v,r,s` + message), i.e. it can only succeed for an address whose owner actually signed the challenge: [2](#0-1) 

`associatePublicKey`, however, takes only a hex-encoded compressed public key, parses it, and immediately calls `associateAddresses` — there is no signature check, no proof of possession, and no `msg.sender`/caller-tied validation: [3](#0-2) 

`associateAddresses` only guards against re-associating an address that's already mapped, then calls `AssociationHelper.AssociateAddresses`, which sets the address mapping and — critically — calls `MigrateBalance`, sweeping **all spendable coins and wei balance** from the direct-cast address (`sdk.AccAddress(evmAddr[:])`) to the newly linked Sei address, and removes the cast account: [4](#0-3) [5](#0-4) 

Because public keys are not secret (they are recoverable from any past signature, exposed on-chain via account pubkeys, or leaked through unrelated protocols), an attacker who obtains a victim's raw secp256k1 public key can call `associatePublicKey` for that victim without any signature over a chain-specific challenge, forcing the association and balance migration at a time of the attacker's choosing — before the victim opts to associate through the normal, self-authenticated EVM tx flow.

### Impact Explanation
Because the derived EVM/Sei address pair is deterministic from the public key, the attacker cannot redirect funds to an address of their choosing. However, forcing an unauthorized migration has concrete negative effects that fall inside the accepted impact set: it triggers `MigrateBalance`'s `SendCoins`/`SendCoinsAndWei` and `RemoveAccount` calls on victim funds without their consent, permanently altering account state (account removal, vesting-account exclusion path, pubkey binding) tied to the victim's identity that the victim did not request. If the "cast address" held any locked/vesting balances or was relied upon by other state (e.g. staking/distribution hooks noted in the ante-handler comments about EIP-7702 authorities), forced early/unsolicited association can produce state inconsistent with what the legitimate owner intended, and the accompanying code comments in `x/evm/ante/preprocess.go` explicitly warn that an out-of-band association via `associatePubKey` can "orphan any staking/distribution state created under the direct-cast identity (which can then halt the chain via the distribution validator-removal hook)": [6](#0-5) 
This is a direct acknowledgment in the codebase that unauthenticated, attacker-triggered association via public key alone is a known-dangerous operation that can produce a validator-halt condition, which meets the "validator halt" impact bar in the rules.

### Likelihood Explanation
Likelihood is high for triggering the call (it is a public, unauthenticated precompile method reachable by any EVM transaction sender), but exploitation quality depends on the attacker's ability to obtain a target's raw public key ahead of that target's own association — feasible for many accounts because public keys become available the moment any transaction is broadcast (mempool visibility) or is recoverable from an existing signature (e.g., a Cosmos-side tx), yet before that account associates via `addr.associate`/normal EVM tx flow.

### Recommendation
Require the same proof-of-possession as `associate` for `associatePublicKey`, or remove/gate `associatePublicKey` entirely, e.g. by requiring the caller to additionally supply a signature over a chain-bound challenge message using the private key corresponding to the supplied public key before performing `AssociateAddresses`/`MigrateBalance`. At minimum, defer or make `MigrateBalance` opt-in/reversible, and audit all callers of `AssociateAddresses` (`x/evm/ante/preprocess.go`, `app/ante/cosmos_checktx.go`) to ensure forced association by a third party cannot orphan staking/distribution state as the existing code comment warns.

### Proof of Concept
1. Obtain victim's raw secp256k1 public key `PK` (e.g., recovered from any signature the victim has broadcast on any chain using the same key, or via mempool observation of an unrelated Cosmos tx).
2. Before the victim ever transacts on Sei's EVM (i.e., before their cast address `sdk.AccAddress(evmAddr[:])` is associated), send coins to the victim's cast address (or note the victim already holds funds there from external transfers).
3. Call `addr.associatePubKey(PK)` from any account — no signature over `PK` is required.
4. Observe `AssociateAddresses` → `MigrateBalance` executes, moving all `SpendableCoins`/wei from the cast address to the derived Sei address and removing the cast account, without the victim ever authorizing this action or being consulted, per: [7](#0-6)

func (p PrecompileExecutor) associate(ctx sdk.Context, method *abi.Method, args []interface{}, value *big.Int) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}

	if err := pcommon.ValidateArgsLength(args, 4); err != nil {
		return nil, 0, err
	}

	// v, r and s are components of a signature over the customMessage sent.
	// We use the signature to construct the user's pubkey to obtain their addresses.
	v := args[0].(string)
	r := args[1].(string)
	s := args[2].(string)
	customMessage := args[3].(string)

	rBytes, err := decodeHexString(r)
	if err != nil {
		return nil, 0, err
	}
	sBytes, err := decodeHexString(s)
	if err != nil {
		return nil, 0, err
	}
	vBytes, err := decodeHexString(v)
	if err != nil {
		return nil, 0, err
	}

	vBig := new(big.Int).SetBytes(vBytes)
	rBig := new(big.Int).SetBytes(rBytes)
	sBig := new(big.Int).SetBytes(sBytes)

	// Derive addresses
	vBig = new(big.Int).Add(vBig, utils.Big27)

	customMessageHash := crypto.Keccak256Hash([]byte(customMessage))
	evmAddr, seiAddr, pubkey, err := helpers.GetAddresses(vBig, rBig, sBig, customMessageHash)
	if err != nil {
		return nil, 0, err
	}

	return p.associateAddresses(ctx, method, evmAddr, seiAddr, pubkey)

func (p PrecompileExecutor) associatePublicKey(ctx sdk.Context, method *abi.Method, args []interface{}, value *big.Int) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}

	if err := pcommon.ValidateArgsLength(args, 1); err != nil {
		return nil, 0, err
	}

	// Takes a single argument, a compressed pubkey in hex format, excluding the '0x'
	pubKeyHex := args[0].(string)

	pubKeyBytes, err := hex.DecodeString(pubKeyHex)
	if err != nil {
		return nil, 0, err
	}

	// Parse the compressed public key
	pubKey, err := btcec.ParsePubKey(pubKeyBytes)
	if err != nil {
		return nil, 0, err
	}

	// Convert to uncompressed public key
	uncompressedPubKey := pubKey.SerializeUncompressed()

	evmAddr, seiAddr, pubkey, err := helpers.GetAddressesFromPubkeyBytes(uncompressedPubKey)
	if err != nil {
		return nil, 0, err
	}

	return p.associateAddresses(ctx, method, evmAddr, seiAddr, pubkey)

func (p PrecompileExecutor) associateAddresses(ctx sdk.Context, method *abi.Method, evmAddr common.Address, seiAddr sdk.AccAddress, pubkey cryptotypes.PubKey) (ret []byte, remainingGas uint64, err error) {
	// Check that address is not already associated
	_, found := p.evmKeeper.GetEVMAddress(ctx, seiAddr)
	if found {
		return nil, 0, fmt.Errorf("address %s is already associated with evm address %s", seiAddr, evmAddr)
	}

	// Associate Addresses:
	associationHelper := helpers.NewAssociationHelper(p.evmKeeper, p.bankKeeper, p.accountKeeper)
	err = associationHelper.AssociateAddresses(ctx, seiAddr, evmAddr, pubkey, false)
	if err != nil {
		return nil, 0, err
	}

	ret, err = method.Outputs.Pack(seiAddr.String(), evmAddr)
	return ret, pcommon.GetRemainingGas(ctx, p.evmKeeper), err
}

func (p AssociationHelper) AssociateAddresses(ctx sdk.Context, seiAddr sdk.AccAddress, evmAddr common.Address, pubkey cryptotypes.PubKey, migrateUseiOnly bool) error {
	castAddr := sdk.AccAddress(evmAddr[:])
	if !castAddr.Equals(seiAddr) && p.accountKeeper.GetAccount(ctx, seiAddr) == nil {
		castAcc := p.accountKeeper.GetAccount(ctx, castAddr)
		castBaseAcc, ok := castAcc.(*authtypes.BaseAccount)
		if ok && castBaseAcc.GetPubKey() == nil && p.bankKeeper.LockedCoins(ctx, castAddr).IsZero() {
			p.accountKeeper.SetAccount(ctx, authtypes.NewBaseAccount(seiAddr, pubkey, castBaseAcc.GetAccountNumber(), castBaseAcc.GetSequence()))
		}
	}
	p.evmKeeper.SetAddressMapping(ctx, seiAddr, evmAddr)
	acc := p.accountKeeper.GetAccount(ctx, seiAddr)
	if acc == nil {
		acc = p.accountKeeper.NewAccountWithAddress(ctx, seiAddr)
	}
	if acc.GetPubKey() == nil {
		if err := acc.SetPubKey(pubkey); err != nil {
			return err
		}
		p.accountKeeper.SetAccount(ctx, acc)
	}
	return p.MigrateBalance(ctx, evmAddr, seiAddr, migrateUseiOnly)
}

func (p AssociationHelper) MigrateBalance(ctx sdk.Context, evmAddr common.Address, seiAddr sdk.AccAddress, migrateUseiOnly bool) error {
	castAddr := sdk.AccAddress(evmAddr[:])
	if castAddr.Equals(seiAddr) {
		return nil
	}
	var castAddrBalances sdk.Coins
	if migrateUseiOnly {
		castAddrBalances = sdk.Coins{p.bankKeeper.GetBalance(ctx, castAddr, "usei")}
	} else {
		castAddrBalances = p.bankKeeper.SpendableCoins(ctx, castAddr)
	}
	if !castAddrBalances.IsZero() {
		if err := p.bankKeeper.SendCoins(ctx, castAddr, seiAddr, castAddrBalances); err != nil {
			return err
		}
	}
	castAddrWei := p.bankKeeper.GetWeiBalance(ctx, castAddr)
	if !castAddrWei.IsZero() {
		if err := p.bankKeeper.SendCoinsAndWei(ctx, castAddr, seiAddr, sdk.ZeroInt(), castAddrWei); err != nil {
			return err
		}
	}
	if p.bankKeeper.LockedCoins(ctx, castAddr).IsZero() {
		p.accountKeeper.RemoveAccount(ctx, authtypes.NewBaseAccountWithAddress(castAddr))
	}
	return nil
}
