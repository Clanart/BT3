### Title
Bank precompile `send`/`sendNative` bypass the tokenfactory denom allow-list check enforced at the bank `MsgSend` layer - ([File: precompiles/bank/legacy/v600/bank.go])

### Summary
TeamPass's bug (CVE-2024-50701) is a broken access-control pattern where an authorization check ("is this folder in the user's allowed list") exists in the system but is not applied consistently on every code path that retrieves/uses the resource. The sei-chain analog is the tokenfactory `DenomAllowList` mechanism: the check `IsInDenomAllowList` is enforced only in the Cosmos `x/bank` `MsgSend`/`MsgMultiSend` handlers, but the EVM bank precompile calls `bankKeeper.SendCoins` / `SendCoinsAndWei` directly, skipping that authorization check entirely.

### Finding Description
The `AllowList`/`DenomAllowList` feature lets a tokenfactory denom admin restrict a denom's transfers to a defined set of addresses. Enforcement is implemented as an explicit, separate check `IsInDenomAllowList`, invoked only inside the `x/bank` message handlers: [1](#0-0) [2](#0-1) 

The core `SendCoins` keeper function itself does not perform this allow-list check - the check purely lives in the msgServer wrapper, meaning any caller that invokes `SendCoins` (or `SendCoinsAndWei`) directly, bypassing `MsgSend`/`MsgMultiSend`, will skip the allow-list authorization entirely. [3](#0-2) 

The EVM `bank` precompile's `send` and `sendNative` functions do exactly this: they call `p.bankKeeper.SendCoins(...)` / `p.bankKeeper.SendCoinsAndWei(...)` directly, with no call to `IsInDenomAllowList` anywhere in the precompile: [4](#0-3) [5](#0-4) 

This is the same class of bug as the TeamPass advisory - a resource (denom/funds) that is supposed to be gated by an admin-defined allow list is retrievable/transferable through an alternate code path that never checks that list, exactly like TeamPass checking folder access rights inconsistently across code paths.

### Impact Explanation
An address explicitly excluded from a tokenfactory denom's `DenomAllowList` by that denom's admin can still send or receive that denom by routing the transfer through the EVM `bank` precompile's `send`/`sendNative` methods instead of a native `MsgSend`. This defeats the intended access-control guarantee of the tokenfactory allow-list feature and lets a disallowed EVM caller move restricted-denom funds that the module was specifically designed to prevent them from moving - an unauthorized transfer via a Cosmos precompile, directly reachable from a single EVM transaction.

### Likelihood Explanation
Trivial to trigger: any account (associated or not) can call the `bank` precompile's `send(from, to, denom, amount)` method (subject to needing sufficient balance and, for `send`, being the registered ERC20 native pointer contract) from an EVM contract or via `eth_sendRawTransaction`/`eth_call` against the well-known precompile address `0x0000000000000000000000000000000000001001`, with no additional privilege required beyond owning the funds/allowance already needed for a normal transfer.

### Recommendation
Move the `IsInDenomAllowList` check into `BaseSendKeeper.SendCoins` / `SendCoinsAndWei` (or add an explicit call to it) so that every caller of these keeper functions - including the bank precompile, other precompiles, and any module code - is subject to the same tokenfactory allow-list enforcement that `MsgSend`/`MsgMultiSend` currently apply.

### Proof of Concept
1. Denom admin creates a tokenfactory denom `factory/<admin>/restricted` and calls `SetDenomAllowList` restricting transfers to a specific allow-listed set of addresses (e.g. only `addrA`).
2. `addrB` (not in the allow list) holds/receives `factory/<admin>/restricted` balance through some initial funding.
3. `addrB` calls the EVM `bank` precompile at `0x...1001` `send(from=addrB, to=addrC, denom="factory/<admin>/restricted", amount=X)` (via the ERC20 native pointer contract associated to that denom, as required by the `pointer.Cmp(caller)` check).
4. The precompile calls `bankKeeper.SendCoins` directly; the transfer succeeds even though neither `addrB` nor `addrC` are in the denom's allow list - whereas the same transfer attempted via `MsgSend` would fail with `"is not allowed to send/receive funds"`.

// IsInDenomAllowList checks if the given address is allowed to send the given coins.
// The check is performed only fot token factory denoms. For each token factory denom,
// it checks if there is allow list for the given denom. If there is no allow list,
// the address is allowed to send the coins. If there is an allow list, the address is
// allowed to send the coins only if it is in the allow list.
func (k BaseSendKeeper) IsInDenomAllowList(ctx sdk.Context, addr sdk.AccAddress, coins sdk.Coins, cache map[string]AllowedAddresses) bool {
	for _, coin := range coins {
		// Skip if denom does not contain the token factory prefix
		if !strings.HasPrefix(coin.Denom, TokenFactoryPrefix) {
			continue
		}

		allowedAddresses := k.getAllowedAddresses(ctx, cache, coin.Denom)
		// skip if there is no allow list for the denom
		if len(allowedAddresses.set) == 0 {
			continue
		}

		if !allowedAddresses.contains(addr) {
			return false
		}
	}
	return true
}

func (p PrecompileExecutor) send(ctx sdk.Context, caller common.Address, method *abi.Method, args []interface{}, value *big.Int, readOnly bool) ([]byte, error) {
	if readOnly {
		return nil, errors.New("cannot call send from staticcall")
	}
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, err
	}

	if err := pcommon.ValidateArgsLength(args, 4); err != nil {
		return nil, err
	}
	denom := args[2].(string)
	if denom == "" {
		return nil, errors.New("invalid denom")
	}
	pointer, _, exists := p.evmKeeper.GetERC20NativePointer(ctx, denom)
	if !exists || pointer.Cmp(caller) != 0 {
		return nil, fmt.Errorf("only pointer %s can send %s but got %s", pointer.Hex(), denom, caller.Hex())
	}
	amount := args[3].(*big.Int)
	if amount.Cmp(utils.Big0) == 0 {
		// short circuit
		return method.Outputs.Pack(true)
	}
	senderSeiAddr, err := p.accAddressFromArg(ctx, args[0])
	if err != nil {
		return nil, err
	}
	receiverSeiAddr, err := p.accAddressFromArg(ctx, args[1])
	if err != nil {
		return nil, err
	}

	if err := p.bankKeeper.SendCoins(ctx, senderSeiAddr, receiverSeiAddr, sdk.NewCoins(sdk.NewCoin(denom, sdk.NewIntFromBigInt(amount)))); err != nil {
		return nil, err
	}

	return method.Outputs.Pack(true)
}

func (p PrecompileExecutor) sendNative(ctx sdk.Context, method *abi.Method, args []interface{}, caller common.Address, callingContract common.Address, value *big.Int, readOnly bool, hooks *tracing.Hooks, evm *vm.EVM) ([]byte, error) {
	if readOnly {
		return nil, errors.New("cannot call sendNative from staticcall")
	}
	if ctx.EVMPrecompileCalledFromDelegateCall() {
		return nil, errors.New("cannot delegatecall sendNative")
	}
	if err := pcommon.ValidateArgsLength(args, 1); err != nil {
		return nil, err
	}
	if value == nil || value.Sign() == 0 {
		return nil, errors.New("set `value` field to non-zero to send")
	}

	senderSeiAddr, ok := p.evmKeeper.GetSeiAddress(ctx, caller)
	if !ok {
		return nil, errors.New("invalid addr")
	}

	receiverAddr, ok := (args[0]).(string)
	if !ok || receiverAddr == "" {
		return nil, errors.New("invalid addr")
	}

	receiverSeiAddr, err := sdk.AccAddressFromBech32(receiverAddr)
	if err != nil {
		return nil, err
	}

	usei, wei, err := pcommon.HandlePaymentUseiWei(ctx, p.evmKeeper.GetSeiAddressOrDefault(ctx, p.address), senderSeiAddr, value, p.bankKeeper, p.evmKeeper, hooks, evm.GetDepth())
	if err != nil {
		return nil, err
	}

	if err := p.bankKeeper.SendCoinsAndWei(ctx, senderSeiAddr, receiverSeiAddr, usei, wei); err != nil {
		return nil, err
	}
	accExists := p.accountKeeper.HasAccount(ctx, receiverSeiAddr)
	if !accExists {
		defer metrics.SafeTelemetryIncrCounter(1, "new", "account")
		p.accountKeeper.SetAccount(ctx, p.accountKeeper.NewAccountWithAddress(ctx, receiverSeiAddr))
	}
	if hooks != nil {
		newCtx := ctx.WithGasMeter(sdk.NewInfiniteGasMeterWithMultiplier(ctx))
		remainingGas := pcommon.GetRemainingGas(newCtx, p.evmKeeper)
		if hooks.OnEnter != nil {
			hooks.OnEnter(evm.GetDepth()+1, byte(vm.CALL), caller, p.evmKeeper.GetEVMAddressOrDefault(newCtx, receiverSeiAddr), []byte{}, remainingGas, value)
		}
		defer func() {
			if hooks.OnExit != nil {
				hooks.OnExit(evm.GetDepth()+1, []byte{}, 0, nil, false)
			}
		}()
	}

	return method.Outputs.Pack(true)
}
