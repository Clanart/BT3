### Title
Unbounded `Metadata.Name`/`Symbol`/`Description`/alias length in `MsgSetDenomMetadata` permanently poisons the `bank.DenomsMetadata` query surface - ([File: sei-cosmos/x/bank/types/metadata.go])

### Summary
`Metadata.Validate()`, used as the sole "defense in depth" check in `x/tokenfactory`'s `SetDenomMetadata` handler, never bounds the length of `Name`, `Symbol`, `Description`, denom-unit `Denom`, or `Aliases`. Any tokenfactory denom admin can therefore submit a single transaction that permanently stores an arbitrarily large metadata blob under their own denom. Because `x/bank`'s `DenomsMetadata` gRPC/REST query (also exposed through the `bank` precompile's `denomsMetadata` EVM method) unconditionally paginates and returns *every* stored `Metadata` record without any per-field or per-response size cap, this oversized record is served back to every future caller of that endpoint, on every node, forever — closely mirroring the MantisBT bug class where an unbounded user-submitted field is persisted and then permanently breaks a shared listing view for all users.

### Finding Description
`Metadata.Validate()` only checks that `Name`/`Symbol` are non-blank, that `Base`/`Display` are valid denoms, and that denom units are well-formed/sorted — it never enforces any maximum length on any string field: [1](#0-0) [2](#0-1) 

`MsgSetDenomMetadata.ValidateBasic()` calls `Metadata.Validate()` but adds no length bound either: [3](#0-2) 

The tokenfactory message handler re-validates with the same unbounded `Validate()` (labelled "defense in depth"), checks only that the caller is the denom's admin, and then persists the metadata verbatim via `bankKeeper.SetDenomMetaData`: [4](#0-3) 

`SetDenomMetaData` performs a raw KV-store `Set` with no size limit: [5](#0-4) 

The public `DenomsMetadata` gRPC query iterates the entire metadata prefix store and appends every record, unmarshalled in full, into the response with no cap on individual record size: [6](#0-5) 

This query is reachable both via the standard gRPC-gateway REST route `/cosmos/bank/v1beta1/denoms_metadata` and via the `bank` precompile's `denomsMetadata`/`denomMetadata` EVM view methods, which forward the request straight to the same `bankQuerier.DenomsMetadata`/`DenomMetadata`: [7](#0-6) 

Since a denom's tokenfactory admin (an unprivileged, on-chain reachable actor who only needs to have created a `factory/{creator}/{subdenom}` denom) can submit this via `MsgSetDenomMetadata`, and the resulting record is never pruned or size-checked, the payload is permanently embedded in chain state and re-served on every subsequent call to `DenomsMetadata`/`DenomMetadata` by any public RPC node, wallet, block explorer, or `bank` precompile caller.

### Impact Explanation
A single denom admin can, in one transaction (bounded only by the node's configured max tx bytes / block gas limit, not by any application-level cap), inflate a `Metadata` record to a large multi-hundred-KB or MB-scale size. Because `DenomsMetadata` returns *all* stored metadata per page with no per-entry size guard, every default-configuration public RPC/REST/gRPC node that serves this widely-used, unauthenticated query endpoint (and the equivalent `bank` precompile view calls reachable from any EVM contract) will build and marshal oversized responses on every call. This degrades or crashes that shared query path for all future callers, permanently, since the bloated record can never be organically corrected once written — the same "permanently broken shared read path" impact pattern as the source MantisBT advisory.

### Likelihood Explanation
Any account that creates a tokenfactory denom automatically becomes its admin and can call `MsgSetDenomMetadata` with no additional privilege. The `Validate()` defense-in-depth check gives a false sense of protection while doing nothing to bound field size, so this is trivially reachable by an ordinary transaction sender with no special setup.

### Recommendation
Add explicit maximum-length validation (e.g., a few hundred bytes) for `Metadata.Name`, `Symbol`, `Description`, each `DenomUnit.Denom`, and each `Aliases` entry inside `Metadata.Validate()` in `sei-cosmos/x/bank/types/metadata.go`, and/or enforce a maximum serialized size for the whole `Metadata` message in `x/tokenfactory/keeper/msg_server.go`'s `SetDenomMetadata` handler before calling `SetDenomMetaData`. Additionally, consider capping total response size (not just entry count) in `BaseKeeper.DenomsMetadata`.

### Proof of Concept
1. Create a tokenfactory denom as any account: `MsgCreateDenom{Sender: A, Subdenom: "x"}` → denom `factory/A/x`.
2. As admin `A`, submit `MsgSetDenomMetadata{Sender: A, Metadata: {Base: "factory/A/x", Display: "factory/A/x", Name: <hundreds-of-KB string>, Symbol: <hundreds-of-KB string>, Description: <large string>, DenomUnits: [...]}}`.
3. `msgServer.SetDenomMetadata` calls only `msg.Metadata.Validate()` (no length checks) and `bankKeeper.SetDenomMetaData` persists it unmodified.
4. Any client subsequently calling `GET /cosmos/bank/v1beta1/denoms_metadata` (or the EVM `bank` precompile's `denomsMetadata`) triggers `BaseKeeper.DenomsMetadata`, which unmarshal/marshals this oversized record into every paginated response, permanently degrading that public query surface.

// Validate performs a basic validation of the denomination unit fields
func (du DenomUnit) Validate() error {
	if err := sdk.ValidateDenom(du.Denom); err != nil {
		return fmt.Errorf("invalid denom unit: %w", err)
	}

	seenAliases := make(map[string]bool)
	for _, alias := range du.Aliases {
		if seenAliases[alias] {
			return fmt.Errorf("duplicate denomination unit alias %s", alias)
		}

		if strings.TrimSpace(alias) == "" {
			return fmt.Errorf("alias for denom unit %s cannot be blank", du.Denom)
		}

		seenAliases[alias] = true
	}

	return nil
}

func (server msgServer) SetDenomMetadata(goCtx context.Context, msg *types.MsgSetDenomMetadata) (*types.MsgSetDenomMetadataResponse, error) {
	ctx := sdk.UnwrapSDKContext(goCtx)

	// Defense in depth validation of metadata
	err := msg.Metadata.Validate()
	if err != nil {
		return nil, err
	}

	authorityMetadata, err := server.GetAuthorityMetadata(ctx, msg.Metadata.Base)
	if err != nil {
		return nil, err
	}

	if msg.Sender != authorityMetadata.GetAdmin() {
		return nil, types.ErrUnauthorized
	}

	server.bankKeeper.SetDenomMetaData(ctx, msg.Metadata)

	ctx.EventManager().EmitEvents(sdk.Events{
		sdk.NewEvent(
			types.TypeMsgSetDenomMetadata,
			sdk.NewAttribute(types.AttributeDenom, msg.Metadata.Base),
			sdk.NewAttribute(types.AttributeDenomMetadata, msg.Metadata.String()),
		),
	})

	return &types.MsgSetDenomMetadataResponse{}, nil
}

// DenomsMetadata implements Query/DenomsMetadata gRPC method.
func (k BaseKeeper) DenomsMetadata(c context.Context, req *types.QueryDenomsMetadataRequest) (*types.QueryDenomsMetadataResponse, error) {
	if req == nil {
		return nil, status.Errorf(codes.InvalidArgument, "empty request")
	}

	ctx := sdk.UnwrapSDKContext(c)
	store := prefix.NewStore(ctx.KVStore(k.storeKey), types.DenomMetadataPrefix)

	metadatas := []types.Metadata{}
	pageRes, err := query.Paginate(ctx, store, req.Pagination, func(_, value []byte) error {
		var metadata types.Metadata
		k.cdc.MustUnmarshal(value, &metadata)

		metadatas = append(metadatas, metadata)
		return nil
	})

	if err != nil {
		return nil, query.WrapGRPCError(err)
	}

	return &types.QueryDenomsMetadataResponse{
		Metadatas:  metadatas,
		Pagination: pageRes,
	}, nil
}

func (p PrecompileExecutor) denomsMetadata(ctx sdk.Context, method *abi.Method, args []interface{}, value *big.Int) ([]byte, uint64, error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}

	if err := pcommon.ValidateArgsLength(args, 1); err != nil {
		return nil, 0, err
	}

	req := &banktypes.QueryDenomsMetadataRequest{
		Pagination: &query.PageRequest{
			Key: args[0].([]byte),
		},
	}

	resp, err := p.bankQuerier.DenomsMetadata(sdk.WrapSDKContext(ctx), req)
	if err != nil {
		return nil, 0, err
	}

	metadatas := make([]Metadata, 0, len(resp.Metadatas))
	for _, metadata := range resp.Metadatas {
		metadatas = append(metadatas, convertMetadataToPrecompileType(metadata))
	}
	var nextKey []byte
	if resp.Pagination != nil {
		nextKey = resp.Pagination.NextKey
	}

	bz, err := method.Outputs.Pack(metadatas, nextKey)
	if err != nil {
		return nil, 0, err
	}
	return bz, pcommon.GetRemainingGas(ctx, p.evmKeeper), nil
}
