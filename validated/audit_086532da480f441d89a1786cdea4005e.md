### Title
Gasless swap deadline check can be bypassed at block-building time, letting a proposer execute an expired `SwapTx` - (File: kaiax/gasless/impl/tx_pool.go, kaiax/gasless/impl/getter.go, kaiax/gasless/impl/builder.go)

### Summary
The reported Y2K bug is a class of "dual validation paths, only one enforces a critical precondition" issue: `triggerEndEpoch` produces the same state-resolving effect as `triggerDepeg` but omits the depeg check, so a user can race to the unchecked path and skip an obligation. The Kaia `kaiax/gasless` module has the same structural flaw around the `SwapTx.deadline` field: the deadline is validated only once, at tx-pool admission (`checkBalanceForSwap`), but the promotion/bundling path that actually causes the swap to be executed in a block (`IsReady` → `isSwapTxReady`/`isApproveTxReady` → `IsExecutable` → `VerifyExecutable`, and `ExtractTxBundles`) never re-checks it.

### Finding Description
`checkBalanceForSwap`, which is wired as `GetCheckBalance()` and invoked when a `SwapTx` is first added to the pool, is the only place that checks `tx.deadline >= currentTimestamp`: [1](#0-0) 

The function that actually decides whether the transaction is executable and gets promoted/bundled, `VerifyExecutable`, only checks sender/token/nonce/amount consistency (Ax/Sx/AP1/SP1-SP4) — it has no deadline check at all: [2](#0-1) 

`isSwapTxReady`/`isApproveTxReady`, used by `IsReady` to promote a queued tx to pending, call `g.IsExecutable`, which wraps `VerifyExecutable` — again with no deadline check: [3](#0-2) 

Finally, `ExtractTxBundles`, which is what the block builder calls right before including the transaction in a block bundle (prepended with the proposer-funded `LendTxGenerator`), also relies solely on `IsExecutable`: [4](#0-3) 

Because `GetCheckBalance` (the only place the deadline is checked) runs once at admission time and is not re-invoked on promotion or bundling, a `SwapTx` that was valid when added to the pool remains "executable" from the module's point of view even after its `deadline` has elapsed, as long as it survives the pool's unrelated `QueueTimeout`/`PendingTimeout` (10s each — a purely liveness-oriented timer, not tied to the user-specified `deadline`): [5](#0-4) 

### Impact Explanation
The `AmountRepay` a user must repay is fixed at submission (`R1 + R2 + R3`, derived from gas price and TxGas), independent of the token exchange rate: [6](#0-5) 

If a proposer/block-builder delays inclusion of a queued `SwapTx` past its declared `deadline` (deliberately, e.g., by congesting the pool with the target sender's other transactions, or simply through normal block-production ordering), the module will still treat the transaction as valid and bundle it with the proposer's `LendTx`, executing the swap under stale, no-longer-consented-to timing/price conditions while the user's fixed repay obligation is unconditionally extracted. This mirrors the reported pattern: an obligation-bearing check (`triggerDepeg`'s strike-price validation / here, the deadline validation) is enforced on one code path (admission) but is silently skippable via the other path (promotion/bundling) that produces the same on-chain effect.

### Likelihood Explanation
Every `SwapTx` passes through the pool queue before being promoted and bundled, so this gap is on the default, always-exercised path for gasless transactions — it does not require any special privilege beyond being (or colluding with) the block proposer that assembles bundles, which is a role explicitly reachable through the normal gasless/block-building flow described in the module's own bundling rules.

### Recommendation
Re-validate `SwapTx.Deadline` against the timestamp of the block actually being built (not only the pool-admission-time chain head) inside `VerifyExecutable` (or immediately before bundling in `ExtractTxBundles`), so a transaction whose deadline has elapsed is rejected from promotion/bundling regardless of how long it has resided in the pool.

### Proof of Concept
1. User submits `SwapTx` with `deadline = T`; it passes `checkBalanceForSwap` (`tx_pool.go:175-179`) at submission time `t0 < T` and enters the pool queue.
2. Before promotion, the proposer/builder delays processing (e.g., fills blocks with higher-priority/self transactions) until current time `t1 > T`, while the tx remains within `QueueTimeout`/`PendingTimeout` (10s) so it is not dropped.
3. When the builder promotes and bundles the transaction via `IsReady`→`isSwapTxReady`→`IsExecutable`→`VerifyExecutable` (`getter.go:203-266`) and `ExtractTxBundles` (`builder.go:28-72`), none of these re-check `Deadline`, so the stale `SwapTx` is accepted into a bundle with the `LendTx` and executed on-chain past its intended deadline, forcing the fixed `AmountRepay` extraction from the user under conditions they no longer consented to.

// isApproveTxReady assumes that the caller checked `g.IsApproveTx(approveTx)`
func (g *GaslessModule) isApproveTxReady(approveTx, nextTx *types.Transaction) bool {
	addr, err := types.Sender(g.signer, approveTx)
	if err != nil {
		return false
	}
	nonce := g.getCurrentStateNonce(addr)

	if approveTx.Nonce() != nonce {
		return false
	}
	if nextTx == nil || !g.IsSwapTx(nextTx) {
		return false
	}

	return g.IsExecutable(approveTx, nextTx)
}

// isSwapTxReady assumes that the caller checked `g.IsSwapTx(swapTx)`
func (g *GaslessModule) isSwapTxReady(swapTx, prevTx *types.Transaction) bool {
	addr, err := types.Sender(g.signer, swapTx)
	if err != nil {
		return false
	}
	nonce := g.getCurrentStateNonce(addr)

	var approveTx *types.Transaction
	if swapTx.Nonce() == nonce {
		approveTx = nil
	} else if swapTx.Nonce() == nonce+1 {
		if prevTx == nil || !g.IsApproveTx(prevTx) {
			return false
		}
		approveTx = prevTx
	} else {
		return false
	}

	return g.IsExecutable(approveTx, swapTx)
}

func (g *GaslessModule) IsExecutable(approveTxOrNil, swapTx *types.Transaction) bool {
	err := g.VerifyExecutable(approveTxOrNil, swapTx)
	if err != nil {
		return false
	}
	return true
}

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

func lendAmount(approveTxOrNil, swapTx *types.Transaction) *big.Int {
	r := new(big.Int)

	// R2 = ApproveTx.Fee() if exists
	if approveTxOrNil != nil {
		r.Add(r, approveTxOrNil.Fee())
	}

	// R3 = SwapTx.Fee()
	r.Add(r, swapTx.Fee())

	// LendAmount = R2 + R3
	return r
}

func repayAmount(approveTxOrNil, swapTx *types.Transaction) *big.Int {
	// R1 = LendTx.Fee() = SwapTx.GasPrice() * TxGas
	r1 := new(big.Int).Mul(swapTx.GasPrice(), new(big.Int).SetUint64(params.TxGas))

	// RepayAmount = R1 + R2 + R3
	return new(big.Int).Add(r1, lendAmount(approveTxOrNil, swapTx))
}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
}
