### Title
Unvalidated `ErcAddress` in `MsgRegisterPointer` Allows Permanent Squatting on CW20/CW721/CW1155 Pointers for Non-Existent or Future EVM Contracts - (File: `x/evm/keeper/msg_server.go`)

### Summary
`RegisterPointer` in `x/evm/keeper/msg_server.go` accepts an arbitrary `ErcAddress` string from `MsgRegisterPointer` and, without ever checking that the address has deployed EVM contract code, instantiates a CW pointer wasm contract targeting it and permanently records the mapping in the pointer registry.

### Finding Description
`MsgRegisterPointer.ValidateBasic` only checks that `ErcAddress` is syntactically a valid hex address: [1](#0-0) 

The handler `RegisterPointer` then looks up whether a pointer already exists for that address and, if not (or the existing version is stale), directly instantiates a CW wasm pointer contract that wraps `msg.ErcAddress`, without ever querying the EVM state for code at that address: [2](#0-1) 

It then persists the mapping permanently via `SetCW20ERC20Pointer` / `SetCW721ERC721Pointer` / `SetCW1155ERC1155Pointer`: [3](#0-2) 

This is the direct analog of the reported `addPools` bug: a user-supplied identifier (`feeTiers_[i]` there, `ErcAddress` here) is used to create a permanent on-chain association without validating that it actually corresponds to something real. Notably, the codebase itself demonstrates awareness of this exact validation pattern in the opposite direction — the ERC→CW pointer precompile (`AddCW20`/`AddNative`) explicitly validates the target before creating a pointer, e.g. by querying `token_info` on the CW20 contract or `GetDenomMetaData` for native denoms and failing if it doesn't exist: [4](#0-3) 

No equivalent check (e.g. `evmKeeper.GetCode(ctx, ercAddress)` / `len(code) > 0`) exists for the CW→ERC direction in `RegisterPointer`. Tests confirm this: `MockAddressPair()` (an address with no EVM code at all) is accepted and a pointer is created successfully: [5](#0-4) 

### Impact Explanation
Because `RegisterPointer` blocks re-registration once `existingVersion >= currentVersion` (line 269-271), an attacker can front-run/pre-register a pointer for an address that does not yet contain a contract — for example a deterministic `CREATE2` address that a legitimate ERC20/ERC721/ERC1155 project intends to deploy to later. Once registered, that identity is permanently reserved with a non-functional pointer wasm contract that forwards to a non-existent contract, and the legitimate project's real contract deployed later at the same address can never get a correct CW pointer through the sanctioned `RegisterPointer` path. This is a permanent freezing of the pointer registry entry for that address, denying interoperability between the CosmWasm and EVM environments for that contract — a griefing/DoS on a specific reachable, permissionless entry point available to any transaction sender.

### Likelihood Explanation
Any account can submit `MsgRegisterPointer` for any syntactically valid hex address with no permission checks and no cost beyond gas, and no EVM contract-code check exists to reject non-existent targets, making this trivially and cheaply exploitable by an unprivileged transaction sender.

### Recommendation
In `RegisterPointer` (`x/evm/keeper/msg_server.go`), before instantiating/migrating the pointer contract, verify that `msg.ErcAddress` has deployed EVM bytecode (e.g., check `len(k.GetCode(ctx, common.HexToAddress(msg.ErcAddress))) > 0`) and reject the message otherwise, mirroring the validation already performed for the reverse (ERC→CW) pointer direction in `precompiles/pointer/pointer.go`.

### Proof of Concept
1. Compute or guess a `CREATE2` address that a legitimate token contract will later be deployed to (or simply pick any arbitrary unused hex address).
2. Submit `MsgRegisterPointer{PointerType: PointerType_ERC20, ErcAddress: <address with no code>}` from any account.
3. Observe `RegisterPointer` succeeds, instantiates a CW20 pointer wasm contract wrapping the empty address, and calls `SetCW20ERC20Pointer`, matching the behavior exercised in `TestRegisterPointer` where `pointee` is a bare `MockAddressPair()` address with no contract code.
4. When the legitimate contract is later deployed to that exact address, any attempt to `RegisterPointer` again for it fails because `existingVersion >= currentVersion`, permanently denying a correct CW pointer for that contract.

func (msg *MsgRegisterPointer) ValidateBasic() error {
	_, err := sdk.AccAddressFromBech32(msg.Sender)
	if err != nil {
		return sdkerrors.Wrapf(sdkerrors.ErrInvalidAddress, "Invalid sender address (%s)", err)
	}

	if !common.IsHexAddress(msg.ErcAddress) {
		return sdkerrors.ErrInvalidAddress
	}

	return nil
}

func (server msgServer) RegisterPointer(goCtx context.Context, msg *types.MsgRegisterPointer) (*types.MsgRegisterPointerResponse, error) {
	ctx := sdk.UnwrapSDKContext(goCtx)
	if server.GetRegisterPointerDisabled(ctx) {
		return nil, fmt.Errorf("registering CW->ERC pointers has been disabled")
	}
	var existingPointer sdk.AccAddress
	var existingVersion uint16
	var currentVersion uint16
	var exists bool
	switch msg.PointerType {
	case types.PointerType_ERC20:
		currentVersion = erc20.CurrentVersion
		existingPointer, existingVersion, exists = server.GetCW20ERC20Pointer(ctx, common.HexToAddress(msg.ErcAddress))
	case types.PointerType_ERC721:
		currentVersion = erc721.CurrentVersion
		existingPointer, existingVersion, exists = server.GetCW721ERC721Pointer(ctx, common.HexToAddress(msg.ErcAddress))
	case types.PointerType_ERC1155:
		currentVersion = erc1155.CurrentVersion
		existingPointer, existingVersion, exists = server.GetCW1155ERC1155Pointer(ctx, common.HexToAddress(msg.ErcAddress))
	default:
		panic("unknown pointer type")
	}
	if exists && existingVersion >= currentVersion {
		return nil, fmt.Errorf("pointer %s already registered at version %d", existingPointer.String(), existingVersion)
	}
	payload := map[string]interface{}{}
	switch msg.PointerType {
	case types.PointerType_ERC20:
		payload["erc20_address"] = msg.ErcAddress
	case types.PointerType_ERC721:
		payload["erc721_address"] = msg.ErcAddress
	case types.PointerType_ERC1155:
		payload["erc1155_address"] = msg.ErcAddress
	default:
		panic("unknown pointer type")
	}
	codeID := server.GetStoredPointerCodeID(ctx, msg.PointerType)
	moduleAcct := server.accountKeeper.GetModuleAddress(types.ModuleName)
	var err error
	var pointerAddr sdk.AccAddress
	if exists {
		bz, _ := json.Marshal(map[string]interface{}{})
		pointerAddr = existingPointer
		_, err = server.wasmKeeper.Migrate(ctx, existingPointer, moduleAcct, codeID, bz)
	} else {
		bz, jerr := json.Marshal(payload)
		if jerr != nil {
			return nil, jerr
		}
		pointerAddr, _, err = server.wasmKeeper.Instantiate(ctx, codeID, moduleAcct, moduleAcct, bz, fmt.Sprintf("Pointer of %s", msg.ErcAddress), sdk.NewCoins())
	}
	if err != nil {
		return nil, err
	}

func TestRegisterPointer(t *testing.T) {
	k, ctx := testkeeper.MockEVMKeeper(t)
	sender, _ := testkeeper.MockAddressPair()
	_, pointee := testkeeper.MockAddressPair()

	// Test register-pointer for ERC20
	res, err := keeper.NewMsgServerImpl(k).RegisterPointer(sdk.WrapSDKContext(ctx), &types.MsgRegisterPointer{
		Sender:      sender.String(),
		PointerType: types.PointerType_ERC20,
		ErcAddress:  pointee.Hex(),
	})
	require.Nil(t, err)
	pointer, version, exists := k.GetCW20ERC20Pointer(ctx, pointee)
	require.True(t, exists)
	require.Equal(t, erc20.CurrentVersion, version)
	require.Equal(t, pointer.String(), res.PointerAddress)
