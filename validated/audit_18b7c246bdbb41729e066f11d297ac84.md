Based on my research, I found a solid structural analog to the reported bug class: **an invariant is enforced on one governance-write path but not on the other**, allowing an inconsistent/invalid parameter state to be accepted that affects consensus-critical fee computation on every node.

### Title
KIP-71 base-fee bound invariant (`LowerBoundBaseFee <= UpperBoundBaseFee`) is enforced only for header-vote governance, not for contract governance - ([File: kaiax/gov/contractgov/impl/getter.go])

### Summary
The Sherlock report flags a case where a critical cross-domain consistency invariant is validated on one execution path (L2 `rebase`) but not on the sibling path (L1 `rebase`), letting the two systems diverge. Kaia has the analogous split for the KIP-71 base-fee bounds: `headergov`'s `checkConsistency` in `kaiax/gov/headergov/impl/header.go` enforces `LowerBoundBaseFee <= UpperBoundBaseFee` for votes written into block headers, but `contractgov`'s `GetParamSet` in `kaiax/gov/contractgov/impl/getter.go` applies values read from the on-chain `GovParam` contract via `ParamSet.Set()` with no such cross-field check.

### Finding Description
`headerGovModule.checkConsistency` explicitly rejects a vote for `Kip71LowerBoundBaseFee` if it exceeds the current `UpperBoundBaseFee`, and vice versa for `Kip71UpperBoundBaseFee`: [1](#0-0) 

This check is only invoked from `VerifyVote`, which validates `header.Vote` entries: [2](#0-1) 

In contrast, contract governance (`GovParam` contract, reachable post-Kore via `setParam`/`setParamIn`) computes `ParamSet` purely by decoding stored bytes and calling `ret.Set(k, v)`, with no equivalent cross-parameter consistency check between `LowerBoundBaseFee` and `UpperBoundBaseFee`: [3](#0-2) 

`ParamSet.Set` only performs a type assertion per field — it has no notion of comparing `LowerBoundBaseFee` against `UpperBoundBaseFee`: [4](#0-3) 

Post-Kore, `gov.GetParamSet` merges contract-governance values over header-governance values, so an inverted bound set only through the contract path becomes the effective, node-wide parameter set: [5](#0-4) 

These bounds directly drive `KIP71Config.NextMagmaBlockBaseFee`, the function every node uses to compute the next block's base fee (used for tx admission pricing, KIP-71/Magma fee market): [6](#0-5) 

### Impact Explanation
If `LowerBoundBaseFee` is set greater than `UpperBoundBaseFee` through the `GovParam` contract (the intended, KIP-71-native governance path post-Kore), the invariant that headergov guarantees for header votes is silently broken for contract governance. `NextMagmaBlockBaseFee` clamps `parentBaseFee` between the (now inverted) bounds and computes deltas against `gasTarget`/`baseFeeDenominator`, which can yield an incoherent or perpetually stuck base fee shared by the entire network — this affects fee-market pricing and pool admission (KIP-71 pricing) for every transaction on the chain, a consensus-relevant divergence risk between the intended invariant and actual accepted state, matching the "acceptance of an invalid ... parameter" / state-divergence class called out in the validation criteria.

### Likelihood Explanation
Setting contract governance parameters requires calling `GovParam.setParam`/`setParamIn`, which is restricted to the contract's authorized governance caller(s) (an `Ownable`-style access-controlled contract), so this is not achievable by a fully unprivileged actor — it requires the governance-parameter-setting role. However, "governance parameters" is explicitly listed as an in-scope reachable surface, and unlike header-vote governance (bounded by `checkConsistency`), no code path stops the governance owner (or a compromised/careless governance transaction) from writing an inconsistent bound pair through the contract, whereas the equivalent header-vote action would be rejected. This is a genuine asymmetry/gap rather than a theoretical one.

### Recommendation
Apply the same `Kip71LowerBoundBaseFee`/`Kip71UpperBoundBaseFee` cross-consistency check inside `kaiax/gov/contractgov/impl/getter.go`'s `GetParamSet` (or in the shared `ParamSet.Set`/`PartialParamSet.Add` path) that is currently applied only in `headergov`'s `checkConsistency`, so that an inverted bound pair from the `GovParam` contract falls back to defaults (or is rejected) the same way an inconsistent header vote is rejected.

### Proof of Concept
1. Deploy/enable `GovParam` contract (post-Kore, `GovernanceGovParamContract` set as in `tests/gov_contract_test.go`).
2. Call `GovParam.setParamIn("kip71.upperboundbasefee", true, <bytes for e.g. 25e9>, 1)` and `setParamIn("kip71.lowerboundbasefee", true, <bytes for e.g. 30e9>, 1)` so that, once activated, `LowerBoundBaseFee (30e9) > UpperBoundBaseFee (25e9)`.
3. `kaiax/gov/contractgov/impl/getter.go`'s `GetParamSet` will happily set both fields (no `checkConsistency`-equivalent check), unlike the header-vote path in `kaiax/gov/headergov/impl/header.go` (`checkConsistency`, lines 188-201) which would return `ErrLowerBoundBaseFee`/`ErrUpperBoundBaseFee` for the equivalent vote.
4. `params.KIP71Config.NextMagmaBlockBaseFee` (`params/kip71_config.go`, lines 58-129) then operates with inverted bounds, producing base-fee results outside the intended monotonic bound semantics for the whole network.

// (2) integrity of the voter (the voter must be the block proposer),
// (3) the vote value must be consistent compared to the latest ParamSet.
func (h *headerGovModule) VerifyVote(header *types.Header) error {
	if len(header.Vote) == 0 {
		return nil
	}

	var (
		vb       headergov.VoteBytes = header.Vote
		blockNum                     = header.Number.Uint64()
	)

	vote, err := vb.ToVoteData()
	if err != nil {
		logger.Error("ToVoteData error", "num", blockNum, "vote", vb, "err", err)
		return err
	}

	if gov.DeprecatedAt(vote.Name(), h.ChainConfig.Rules(header.Number)) {
		logger.Error("Vote is deprecated", "num", blockNum, "name", vote.Name())
		return ErrDeprecatedVote
	}

	council, err := h.ValSet.GetCouncil(blockNum)
	if err != nil {
		return err
	}

	// check if the voter is in council
	if !slices.Contains(council, vote.Voter()) {
		return ErrInvalidKeyValue
	}

	// check if Voter is the block proposer.
	author, err := h.Chain.Sealer().Author(header)
	if err != nil {
		return err
	}
	if author != vote.Voter() {
		return ErrInvalidVoter
	}

	// In single mode, only the governing node can write header.Vote after Permissionless.
	params := h.GetParamSet(blockNum)
	if h.ChainConfig.IsPermissionlessForkEnabled(new(big.Int).SetUint64(blockNum)) &&
		params.GovernanceMode == "single" &&
		vote.Voter() != params.GoverningNode {
		return ErrVotePermissionDenied
	}

	return h.checkConsistency(blockNum, vote)
}

// GetParamSet returns default parameter set in case of the following errors:
// (1) contractgov is disabled (i.e., pre-Kore or GovParam address is zero)
// (2) GovParam address is not set
// (3) Contract call to GovParam failed
// Invalid parameters in the contract (i.e., invalid parameter name or non-canonical value) are ignored.
func (c *contractGovModule) GetParamSet(blockNum uint64) gov.ParamSet {
	m, err := c.contractGetAllParamsAt(blockNum)
	if err != nil {
		return *gov.GetDefaultGovernanceParamSet()
	}

	ret := *gov.GetDefaultGovernanceParamSet()
	for k, v := range m {
		err = ret.Set(k, v)
		if err != nil {
			return *gov.GetDefaultGovernanceParamSet()
		}
	}

	return ret
}

func (kc *KIP71Config) NextMagmaBlockBaseFee(parentHeaderNumber *big.Int, parentHeaderBaseFee *big.Int, parentHeaderGasUsed uint64) *big.Int {
	// governance parameters
	lowerBoundBaseFee := new(big.Int).SetUint64(kc.LowerBoundBaseFee)
	upperBoundBaseFee := new(big.Int).SetUint64(kc.UpperBoundBaseFee)
	makeEvenByCeil(lowerBoundBaseFee)
	makeEvenByFloor(upperBoundBaseFee)

	// If the parent is the magma disabled block or genesis, then return the lowerBoundBaseFee (default 25ston)
	if parentHeaderNumber.Cmp(new(big.Int).SetUint64(0)) == 0 || parentHeaderBaseFee == nil {
		return makeEvenByFloor(lowerBoundBaseFee)
	}

	var baseFeeDenominator *big.Int
	if kc.BaseFeeDenominator == 0 {
		// To avoid panic, set the fluctuation range small
		baseFeeDenominator = new(big.Int).SetUint64(64)
	} else {
		baseFeeDenominator = new(big.Int).SetUint64(kc.BaseFeeDenominator)
	}
	gasTarget := kc.GasTarget
	upperGasLimit := kc.MaxBlockGasUsedForBaseFee

	// check the case of upper/lowerBoundBaseFee is updated by governance mechanism
	parentBaseFee := parentHeaderBaseFee
	if parentBaseFee.Cmp(upperBoundBaseFee) >= 0 {
		parentBaseFee = upperBoundBaseFee
	} else if parentBaseFee.Cmp(lowerBoundBaseFee) <= 0 {
		parentBaseFee = lowerBoundBaseFee
	}

	// upper gas limit cut off the impulse of used gas to upper bound
	parentGasUsed := min(parentHeaderGasUsed, upperGasLimit)
	if parentGasUsed == gasTarget {
		return makeEvenByFloor(parentBaseFee)
	} else if parentGasUsed > gasTarget {
		// shortcut. If parentBaseFee is already reached upperbound, do not calculate.
		if parentBaseFee.Cmp(upperBoundBaseFee) == 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		// If the parent block used more gas than its target,
		// the baseFee of the next block should increase.
		// baseFeeDelta = max(1, parentBaseFee * (parentGasUsed - gasTarget) / gasTarget / baseFeeDenominator)
		gasUsedDelta := new(big.Int).SetUint64(parentGasUsed - gasTarget)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := math.BigMax(x.Div(y, baseFeeDenominator), common.Big1)

		nextBaseFee := x.Add(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(upperBoundBaseFee) > 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	} else {
		// shortcut. If parentBaseFee is already reached lower bound, do not calculate.
		if parentBaseFee.Cmp(lowerBoundBaseFee) == 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		// Otherwise if the parent block used less gas than its target,
		// the baseFee of the next block should decrease.
		// baseFeeDelta = parentBaseFee * (gasTarget - parentGasUsed) / gasTarget / baseFeeDenominator
		gasUsedDelta := new(big.Int).SetUint64(gasTarget - parentGasUsed)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := x.Div(y, baseFeeDenominator)

		nextBaseFee := x.Sub(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(lowerBoundBaseFee) < 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	}
}
