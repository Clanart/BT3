### Title
Unvalidated CosmWasm event attributes are trusted as system-generated EVM Transfer/Approval logs via the CW→EVM pointer bridge - (File: `app/receipt.go`)

### Summary
`app.AddCosmosEventsToEVMReceiptIfApplicable` (the `DeliverTx` hook wired in `app/legacyabci/deliver_tx.go` and `sei-cosmos/baseapp/baseapp.go`) scans every `wasm` module event in a transaction, and for any event whose `_contract_address` attribute matches a registered CW20/CW721/CW1155 pointer, it converts attacker-controllable wasm-event *attributes* directly into synthetic ERC20/721/1155 `Transfer`/`Approval` logs that are written into the transaction's EVM receipt. There is no verification that the "action" (mint/burn/transfer/etc.) and its `from`/`to`/`amount` fields correspond to any real state change in the CW20/CW721/CW1155 contract — they are simply parsed off event attributes emitted by the contract itself. This mirrors the OpenClaw bug class: externally supplied, unsanitized data (arbitrary wasm event attributes emitted by a CosmWasm contract under attacker control) is silently upgraded into a "trusted system event" (a synthetic EVM log embedded in the canonical receipt), which is exactly the trust-boundary violation described in GHSA-7g8c-cfr3-vqqr.

### Finding Description
`AddCosmosEventsToEVMReceiptIfApplicable` pulls every `wasmtypes.WasmModuleEventType` ("wasm") event out of the transaction result and, for each one whose `_contract_address` matches a pointer that already exists (`GetERC20CW20Pointer` / `GetERC721CW721Pointer` / `GetERC1155CW1155Pointer`), calls `translateCW20Event` / `translateCW721Event` / `translateCW1155Event`. [1](#0-0) 

`translateCW20Event` builds an ERC20 `Transfer`/`Approval` log purely from the `action.Type`, `action.From`, `action.To`, and `action.Amount` fields returned by `GetActionsFromWasmEvent`, which just parses the wasm event's attributes: [2](#0-1) 

These synthetic logs are then written straight into the block's `TransientReceipt` / shell EVM receipt that gets served over the public `eth_getLogs` / `eth_getTransactionReceipt` RPC surface: [3](#0-2) 

Because the wasm event's *contents* (its attributes, and therefore the action type, `from`, `to`, and `amount`) are entirely determined by the CosmWasm contract's own `Response.add_attribute` calls at execution time, any contract can emit whatever attributes it wants regardless of whether a genuine balance mutation happened. The only gating condition is that the emitting contract address must be a *registered* CW20/CW721/CW1155 pointer target, e.g. via `SetERC20CW20Pointer`/`SetERC721CW721Pointer`/`SetERC1155CW1155Pointer` in `x/evm/keeper/pointer.go`, which record only an address mapping with no on-chain enforcement that emitted `wasm` events must reflect real transfers: [4](#0-3) 

Pointer creation for a CW20/CW721/CW1155 contract is a normal user-reachable action through the wasmd precompile (`precompiles/wasmd/*.go` call these `Get*Pointer` functions when deciding whether to create a new pointer for an arbitrary CosmWasm contract). An attacker who deploys their own malicious CW20/CW721/CW1155-shaped contract, gets a pointer created for it, and then triggers an `execute` message on that contract emitting a hand-crafted `wasm` event with `action=transfer`/`mint` and arbitrary `from`/`to`/`amount` attributes — without moving any real token balance — will cause Sei to fabricate a legitimate-looking ERC20 `Transfer` log at the pointer's canonical EVM address inside the transaction's receipt.

### Impact Explanation
Any off-chain or on-chain consumer that treats `eth_getLogs`/`eth_getTransactionReceipt` output for a CW20/CW721/CW1155 pointer address as authoritative proof of a token movement (bridges, exchanges, custody systems, other smart contracts that only check log topics/addresses rather than re-querying `balanceOf`) can be deceived into crediting deposits, mints, or approvals that never actually occurred on the underlying CosmWasm contract. This satisfies the "unauthorized transfer via … pointer" acceptance criterion — the pointer bridge itself becomes a vector for fabricating trusted transfer evidence without any real value movement, directly enabling fund-loss scenarios for systems that rely on pointer-address logs.

### Likelihood Explanation
The attack path requires only: (1) deploying an arbitrary CosmWasm contract (unprivileged, permissionless), (2) obtaining a CW20/CW721/CW1155→ERC20/721/1155 pointer for it (a normal, user-triggerable operation via the wasmd precompile), and (3) executing a message on that contract that emits a custom `wasm` event with attacker-chosen attributes. All three steps are reachable by any unprivileged CosmWasm/EVM user with no special permissions, making likelihood high for anyone motivated to spoof deposit-style logs against systems that trust pointer-contract event data without independent verification.

### Recommendation
Do not use raw wasm-event attribute values as ground truth for synthesizing EVM logs. Because the exact permission checks performed by the wasmd precompile when creating a CW20/CW721/CW1155 pointer (`Set*Pointer`) were not fully inspected in this review, it is not confirmed whether any code-shape/authenticity validation currently exists there — this should be verified. Regardless, the event-translation logic in `app/receipt.go` should cross-check the claimed action against the contract's actual state (e.g., re-query `balanceOf`/`ownerOf` before/after, or restrict trusted translation to attributes that are provably derived from the CW20/721/1155 reference implementation's standard execution path) rather than trusting arbitrary attribute values emitted by arbitrary contract code.

### Proof of Concept
1. Deploy a CosmWasm contract that superficially satisfies whatever pointer-creation requirements exist (this exact gate was not fully verified in this session and should be confirmed) and register it as a CW20 pointer via the wasmd precompile, so `GetERC20CW20Pointer` returns a valid `pointerAddr`.
2. Send an `execute` message to the malicious contract that performs no real balance change but calls `Response::add_attribute` to emit a `wasm` event with `action="transfer"`, `from=<victim/bridge address>`, `to=<attacker address>`, `amount=<large value>`.
3. Observe via `eth_getLogs`/`eth_getTransactionReceipt` against the pointer's EVM address that a synthetic ERC20 `Transfer` log for the fabricated amount is now embedded in the transaction's canonical EVM receipt, indistinguishable from a genuine pointer-bridged CW20 transfer, as produced by `AddCosmosEventsToEVMReceiptIfApplicable`/`translateCW20Event`. func (app *App) AddCosmosEventsToEVMReceiptIfApplicable(ctx sdk.Context, tx sdk.Tx, checksum [32]byte, response sdk.DeliverTxHookInput) {
	// hooks will only be called if DeliverTx is successful
	wasmEvents := GetEventsOfType(response, wasmtypes.WasmModuleEventType)
	if len(wasmEvents) == 0 {
		return
	}
	logs := []*ethtypes.Log{}
	// Note: txs with a very large number of WASM events may run out of gas due to
	// additional gas consumption from EVM receipt generation and event translation
	wasmToEvmEventGasLimit := app.EvmKeeper.GetDeliverTxHookWasmGasLimit(ctx.WithGasMeter(sdk.NewInfiniteGasMeter(1, 1)))
	wasmToEvmEventCtx := ctx.WithGasMeter(sdk.NewGasMeterWithMultiplier(ctx, wasmToEvmEventGasLimit))
	// unfortunately CW721 transfer events differ from ERC721 transfer events
	// in that CW721 include sender (which can be different than owner) whereas
	// ERC721 always include owner. The following logic refer to the owner
	// event emitted before the transfer and use that instead to populate the
	// synthetic ERC721 event.
	ownerEvents := GetEventsOfType(response, wasmtypes.EventTypeCW721PreTransferOwner)
	ownerEventsMap := map[string][]abci.Event{}
	for _, ownerEvent := range ownerEvents {
		if len(ownerEvent.Attributes) != 3 {
			logger.Error("received owner event with number of attributes != 3")
			continue
		}
		ownerEventKey := getOwnerEventKey(string(ownerEvent.Attributes[0].Value), string(ownerEvent.Attributes[1].Value))
		if events, ok := ownerEventsMap[ownerEventKey]; ok {
			ownerEventsMap[ownerEventKey] = append(events, ownerEvent)
		} else {
			ownerEventsMap[ownerEventKey] = []abci.Event{ownerEvent}
		}
	}
	cw721TransferCounterMap := map[string]int{}
	for _, wasmEvent := range wasmEvents {
		contractAddr, found := GetAttributeValue(wasmEvent, wasmtypes.AttributeKeyContractAddr)
		if !found {
			continue
		}
		pointerAddr, _, exists := app.EvmKeeper.GetERC20CW20Pointer(wasmToEvmEventCtx, contractAddr)
		if exists {
			for _, log := range app.translateCW20Event(wasmToEvmEventCtx, wasmEvent, pointerAddr, contractAddr) {
				log.Index = uint(len(logs))
				logs = append(logs, log)
			}
			continue
		}
		// check if there is a ERC721 pointer to contract Addr
		pointerAddr, _, exists = app.EvmKeeper.GetERC721CW721Pointer(wasmToEvmEventCtx, contractAddr)
		if exists {
			for _, log := range app.translateCW721Event(wasmToEvmEventCtx, wasmEvent, pointerAddr, contractAddr, ownerEventsMap, cw721TransferCounterMap) {
				log.Index = uint(len(logs))
				logs = append(logs, log)
			}
			continue
		}
		// check if there is a ERC1155 pointer to contract Addr
		pointerAddr, _, exists = app.EvmKeeper.GetERC1155CW1155Pointer(wasmToEvmEventCtx, contractAddr)
		if exists {
			for _, log := range app.translateCW1155Event(wasmToEvmEventCtx, wasmEvent, pointerAddr, contractAddr) {
				log.Index = uint(len(logs))
				logs = append(logs, log)
			}
			continue
		}
	}

func (app *App) translateCW20Event(ctx sdk.Context, wasmEvent abci.Event, pointerAddr common.Address, contractAddr string) (res []*ethtypes.Log) {
	defer func() {
		if r := recover(); r != nil {
			fmt.Printf("[Error] Panic caught during translateCW20Event: type=%T, value=%+v\n", r, r)
		}
	}()

	for _, action := range app.GetActionsFromWasmEvent(ctx, wasmEvent) {
		switch action.Type {
		case "mint", "burn", "send", "transfer", "transfer_from", "send_from", "burn_from":
			if action.Amount == nil {
				continue
			}
			res = append(res, &ethtypes.Log{
				Address: pointerAddr,
				Topics: []common.Hash{
					ERC20TransferTopic,
					action.From,
					action.To,
				},
				Data: common.BigToHash(action.Amount).Bytes(),
			})
		case "increase_allowance", "decrease_allowance":
			topics := []common.Hash{
				ERC20ApprovalTopic,
				action.Owner,
				action.Spender,
			}
			ret, err := app.WasmKeeper.QuerySmart(
				ctx,
				sdk.MustAccAddressFromBech32(contractAddr),
				[]byte(fmt.Sprintf(
					"{\"allowance\":{\"owner\":\"%s\",\"spender\":\"%s\"}}",
					app.EvmKeeper.GetSeiAddressOrDefault(ctx, common.BytesToAddress(action.Owner[:])).String(),
					app.EvmKeeper.GetSeiAddressOrDefault(ctx, common.BytesToAddress(action.Spender[:])).String())),
			)
			if err != nil {
				continue
			}
			allowanceResponse := &AllowanceResponse{}
			if err := json.Unmarshal(ret, allowanceResponse); err != nil {
				continue
			}
			res = append(res, &ethtypes.Log{
				Address: pointerAddr,
				Topics:  topics,
				Data:    common.BigToHash(allowanceResponse.Allowance.BigInt()).Bytes(),
			})
		}
	}
	return
}

// ERC20 -> CW20
func (k *Keeper) SetERC20CW20Pointer(ctx sdk.Context, cw20Address string, addr common.Address) error {
	return k.SetERC20CW20PointerWithVersion(ctx, cw20Address, addr, cw20.CurrentVersion(ctx))
}

// ERC20 -> CW20
func (k *Keeper) SetERC20CW20PointerWithVersion(ctx sdk.Context, cw20Address string, addr common.Address, version uint16) error {
	if k.cwAddressIsPointer(ctx, cw20Address) {
		return ErrorPointerToPointerNotAllowed
	}
	err := k.setPointerInfo(ctx, types.PointerERC20CW20Key(cw20Address), addr[:], version)
	if err != nil {
		return err
	}
	return k.setPointerInfo(ctx, types.PointerReverseRegistryKey(addr), []byte(cw20Address), version)
}

// ERC20 -> CW20
func (k *Keeper) GetERC20CW20Pointer(ctx sdk.Context, cw20Address string) (addr common.Address, version uint16, exists bool) {
	addrBz, version, exists := k.GetPointerInfo(ctx, types.PointerERC20CW20Key(cw20Address), cw20.CurrentVersion(ctx))
	if exists {
		addr = common.BytesToAddress(addrBz)
	}
	return
}

// ERC20 -> CW20
func (k *Keeper) DeleteERC20CW20Pointer(ctx sdk.Context, cw20Address string, version uint16) {
	addr, _, exists := k.GetERC20CW20Pointer(ctx, cw20Address)
	if exists {
		k.deletePointerInfo(ctx, types.PointerERC20CW20Key(cw20Address), version)
		k.deletePointerInfo(ctx, types.PointerReverseRegistryKey(addr), version)
	}
}
