### Title
Missing domain separation in `addr` precompile's `associate` lets replayed signatures force address association and balance migration - (File: `precompiles/addr/addr.go`)

### Summary
`PrecompileExecutor.associate` in `precompiles/addr/addr.go:160-203` verifies only that `(v,r,s)` is a valid ECDSA signature over an attacker-supplied `customMessage`, hashing it with a bare `crypto.Keccak256Hash([]byte(customMessage))` — no chain ID, contract address, purpose string, or nonce is baked into the hash on-chain. This mirrors the reported class of bug: signature verification that omits a binding/freshness check, enabling replay of a signature captured/observed in an unrelated context.

### Finding Description
The `associate` method reconstructs the signer's public key purely from `Ecrecover(keccak256(customMessage), sig)` via `helpers.GetAddresses` (`utils/helpers/address.go:44-51`), then calls `associateAddresses` (`precompiles/addr/addr.go:239-255`), which — after only checking the derived `seiAddr` isn't already associated — calls `AssociationHelper.AssociateAddresses` (`utils/helpers/associate.go:34-55`). That helper unconditionally sets the EVM↔Sei address mapping and invokes `MigrateBalance`, which sweeps all spendable coins and wei balance from the EVM-cast Cosmos address to the newly linked Sei address (`utils/helpers/associate.go:57-83`).

Because the precompile does not require `customMessage` to equal a fixed, chain-specific association string (the fixed "Please sign this message to link your EVM and Sei addresses..." text only exists in client-side test code/tooling — `contracts/test/EVMPrecompileTest.js:70`, `integration_test/precompile_tests/precompiles/addr.spec.ts:26-28` — not enforced on-chain), any valid `(v,r,s,message)` triple signed by a victim for a wholly unrelated purpose can be submitted by any third party to force association for that victim.

### Impact Explanation
Once replayed, `AssociateAddresses` permanently sets the address mapping and immediately triggers `MigrateBalance`, moving all of the victim's spendable `usei`/wei balance from their pre-association cast address into the newly derived Sei account. This is an unauthorized, attacker-triggered transfer/migration of victim funds without the victim intending or authorizing the association action at that time, matching the "unauthorized transfer via precompile" acceptance criterion.

### Likelihood Explanation
Exploitability requires the attacker to obtain a signature blob and the exact plaintext message the victim signed elsewhere (e.g., an off-chain personal_sign payload from another dApp) that happens to be recoverable via `crypto.Ecrecover`. This is a real but non-trivial precondition — it depends on victims reusing/exposing raw ECDSA signatures outside the association flow — so likelihood is moderate rather than trivially exploitable by any transaction sender against an arbitrary victim without such exposure.

### Recommendation
Enforce a fixed, on-chain-checked domain-separated message template (e.g., require `customMessage` to equal a canonical string embedding `address(this)`/precompile address, and ideally a nonce or expiry) before deriving addresses and performing association, so arbitrary externally-signed payloads cannot be repurposed to trigger association and balance migration.

### Proof of Concept
1. Victim signs an arbitrary message `M` with signature `(v,r,s)` for an unrelated off-chain purpose (e.g., signing into a dApp with `personal_sign`).
2. Attacker (or anyone) observes `(v,r,s,M)` and calls the `addr` precompile's `associate(v,r,s,M)` at `0x0000000000000000000000000000000000001004`.
3. `associate` in `precompiles/addr/addr.go:160-203` recovers the victim's pubkey from `keccak256(M)` and `(v,r,s)`, deriving `evmAddr`/`seiAddr`.
4. `associateAddresses` (`precompiles/addr/addr.go:239-255`) finds no existing association and proceeds, calling `AssociateAddresses` (`utils/helpers/associate.go:34-55`), which sets the mapping and calls `MigrateBalance` (`utils/helpers/associate.go:57-83`), sweeping the victim's `usei`/wei balance from the cast EVM address to the Sei address — all without the victim ever intending to call `associate`. func (p PrecompileExecutor) associate(ctx sdk.Context, method *abi.Method, args []interface{}, value *big.Int) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}

	if err := pcommon.ValidateArgsLength(args, 4); err != nil {
		return nil, 0, err
	}

	// v, r and s are components of a signature over the customMessage sent.
	// We use the signature to construct the user's pubkey to obtain their addresses.
	v := args[0].(string)
	r := args[1].(string)
	s := args[2].(string)
	customMessage := args[3].(string)

	rBytes, err := decodeHexString(r)
	if err != nil {
		return nil, 0, err
	}
	sBytes, err := decodeHexString(s)
	if err != nil {
		return nil, 0, err
	}
	vBytes, err := decodeHexString(v)
	if err != nil {
		return nil, 0, err
	}

	vBig := new(big.Int).SetBytes(vBytes)
	rBig := new(big.Int).SetBytes(rBytes)
	sBig := new(big.Int).SetBytes(sBytes)

	// Derive addresses
	vBig = new(big.Int).Add(vBig, utils.Big27)

	customMessageHash := crypto.Keccak256Hash([]byte(customMessage))
	evmAddr, seiAddr, pubkey, err := helpers.GetAddresses(vBig, rBig, sBig, customMessageHash)
	if err != nil {
		return nil, 0, err
	}

	return p.associateAddresses(ctx, method, evmAddr, seiAddr, pubkey)
}

func (p PrecompileExecutor) associateAddresses(ctx sdk.Context, method *abi.Method, evmAddr common.Address, seiAddr sdk.AccAddress, pubkey cryptotypes.PubKey) (ret []byte, remainingGas uint64, err error) {
	// Check that address is not already associated
	_, found := p.evmKeeper.GetEVMAddress(ctx, seiAddr)
	if found {
		return nil, 0, fmt.Errorf("address %s is already associated with evm address %s", seiAddr, evmAddr)
	}

	// Associate Addresses:
	associationHelper := helpers.NewAssociationHelper(p.evmKeeper, p.bankKeeper, p.accountKeeper)
	err = associationHelper.AssociateAddresses(ctx, seiAddr, evmAddr, pubkey, false)
	if err != nil {
		return nil, 0, err
	}

	ret, err = method.Outputs.Pack(seiAddr.String(), evmAddr)
	return ret, pcommon.GetRemainingGas(ctx, p.evmKeeper), err
}

func (p AssociationHelper) AssociateAddresses(ctx sdk.Context, seiAddr sdk.AccAddress, evmAddr common.Address, pubkey cryptotypes.PubKey, migrateUseiOnly bool) error {
	castAddr := sdk.AccAddress(evmAddr[:])
	if !castAddr.Equals(seiAddr) && p.accountKeeper.GetAccount(ctx, seiAddr) == nil {
		castAcc := p.accountKeeper.GetAccount(ctx, castAddr)
		castBaseAcc, ok := castAcc.(*authtypes.BaseAccount)
		if ok && castBaseAcc.GetPubKey() == nil && p.bankKeeper.LockedCoins(ctx, castAddr).IsZero() {
			p.accountKeeper.SetAccount(ctx, authtypes.NewBaseAccount(seiAddr, pubkey, castBaseAcc.GetAccountNumber(), castBaseAcc.GetSequence()))
		}
	}
	p.evmKeeper.SetAddressMapping(ctx, seiAddr, evmAddr)
	acc := p.accountKeeper.GetAccount(ctx, seiAddr)
	if acc == nil {
		acc = p.accountKeeper.NewAccountWithAddress(ctx, seiAddr)
	}
	if acc.GetPubKey() == nil {
		if err := acc.SetPubKey(pubkey); err != nil {
			return err
		}
		p.accountKeeper.SetAccount(ctx, acc)
	}
	return p.MigrateBalance(ctx, evmAddr, seiAddr, migrateUseiOnly)
}

func (p AssociationHelper) MigrateBalance(ctx sdk.Context, evmAddr common.Address, seiAddr sdk.AccAddress, migrateUseiOnly bool) error {
	castAddr := sdk.AccAddress(evmAddr[:])
	if castAddr.Equals(seiAddr) {
		return nil
	}
	var castAddrBalances sdk.Coins
	if migrateUseiOnly {
		castAddrBalances = sdk.Coins{p.bankKeeper.GetBalance(ctx, castAddr, "usei")}
	} else {
		castAddrBalances = p.bankKeeper.SpendableCoins(ctx, castAddr)
	}
	if !castAddrBalances.IsZero() {
		if err := p.bankKeeper.SendCoins(ctx, castAddr, seiAddr, castAddrBalances); err != nil {
			return err
		}
	}
	castAddrWei := p.bankKeeper.GetWeiBalance(ctx, castAddr)
	if !castAddrWei.IsZero() {
		if err := p.bankKeeper.SendCoinsAndWei(ctx, castAddr, seiAddr, sdk.ZeroInt(), castAddrWei); err != nil {
			return err
		}
	}
	if p.bankKeeper.LockedCoins(ctx, castAddr).IsZero() {
		p.accountKeeper.RemoveAccount(ctx, authtypes.NewBaseAccountWithAddress(castAddr))
	}
	return nil
}
