The reported issue is specific to a Synthetix-style staking rewards contract where `rewardPerToken()` divides accumulated rewards by a mutable `totalSupply` that any depositor can inflate at will, diluting other stakers' rewards. Chia-blockchain has no equivalent mechanism reachable by an unprivileged actor:

- Pool/farming rewards are fixed per-block amounts determined purely by block height via `calculate_pool_reward()` and `calculate_base_farmer_reward()` [1](#0-0) , not a shared reward pool divided by a user-manipulable "total staked supply."
- Plot NFT / pool wallet reward claiming (`claim_pool_rewards`, `forward_pool_reward`) processes individually farmed reward coins tied to specific block heights and singleton lineage, not a pooled ratio calculation that a large depositor could dilute [2](#0-1) .
- `create_absorb_spend` reconstructs reward coins deterministically from consensus-defined `calculate_pool_reward(height)`, with no notion of "total supply" of stakers that participants could inflate [3](#0-2) .

There is no reachable path in this codebase (mempool, CLVM, standard puzzles, CAT/CR-CAT/VC, offers, clawback, plotnft/pool transitions, or Data Layer) that replicates a stake-weighted reward-per-token formula vulnerable to total-supply inflation griefing.

def calculate_pool_reward(height: uint32) -> uint64:
    """
    Returns the pool reward at a certain block height. The pool earns 7/8 of the reward in each block. If the farmer
    is solo farming, they act as the pool, and therefore earn the entire block reward.
    These halving events will not be hit at the exact times
    (3 years, etc), due to fluctuations in difficulty. They will likely come early, if the network space and VDF
    rates increase continuously.
    """

    if height == 0:
        return uint64((7 / 8) * 21000000 * _mojo_per_chia)
    elif height < 3 * _blocks_per_year:
        return uint64((7 / 8) * 2 * _mojo_per_chia)
    elif height < 6 * _blocks_per_year:
        return uint64((7 / 8) * 1 * _mojo_per_chia)
    elif height < 9 * _blocks_per_year:
        return uint64((7 / 8) * 0.5 * _mojo_per_chia)
    elif height < 12 * _blocks_per_year:
        return uint64((7 / 8) * 0.25 * _mojo_per_chia)
    else:
        return uint64((7 / 8) * 0.125 * _mojo_per_chia)
