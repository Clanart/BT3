Based on my investigation, I found a plausible analog in the `kaiax/gasless` module, though with some confirmed uncertainty about the on-chain contract side that I could not fully verify.

### Title
Gasless swap deadline check enforced only at tx-pool admission time, not re-validated before block inclusion — (File: kaiax/gasless/impl/tx_pool.go)

### Summary
The Flarum bug pattern is: an expiry check is enforced only in one code path (form rendering) but not in the actual state-mutating path (`SavePasswordController::handle()`), letting an attacker skip the checking layer and submit directly to the processing endpoint with a stale/expired token. In Kaia's gasless module, the swap `deadline` field is validated in exactly one place — `checkBalanceForSwap` — which is wired in only as the tx-pool admission hook via `GetCheckBalance()`. The function that actually decides whether a swap (and its paired approve tx) is executable and gets bundled into a block for real settlement, `VerifyExecutable`/`IsExecutable` in `kaiax/gasless/impl/getter.go`, does not check `Deadline` at all.

### Finding Description
`checkBalanceForSwap` explicitly documents and enforces `tx.deadline >= currentTimestamp` [1](#0-0)  and performs the comparison against `g.Chain.CurrentBlock().Time()` [2](#0-1) . This function is only reachable through `GetCheckBalance()`, which is registered as a tx-pool module hook [3](#0-2) , i.e. it runs once, at the moment the transaction is admitted to the pool.

The separate function that actually determines whether a swap transaction (alone or paired with an approve tx) is "executable" and gets bundled for on-chain settlement — `VerifyExecutable` — checks sender match, token match, approve amount, nonce sequencing, and repay amount (`AP1`, `SP1`, `SP2`, `SP3`, `SP4`), but contains no deadline/timestamp check whatsoever [4](#0-3) . This same `VerifyExecutable`/`IsExecutable` path is what `ExtractTxBundles` calls when actually assembling the bundle of transactions (`LendTx` + approve + swap) that gets included in a block [5](#0-4) , and it is also what gates promotion from queue to pending (`isApproveTxReady`/`isSwapTxReady`) [6](#0-5) .

This mirrors the Flarum bug class precisely: the expiry/deadline constraint is enforced only at a "gatekeeping" moment (pool admission / form render) but is absent from the actual code path that performs the state-changing action (block bundling and settlement / password change).

### Impact Explanation
If a swap transaction is admitted to the pool while its `deadline` is still valid, but sits queued (e.g., behind an approve tx, or delayed by block production/mempool conditions) until the chain's current block time passes the declared deadline, nothing in the bundling/execution path re-checks the deadline before the transaction is packaged into `ExtractTxBundles` and settled via `GetLendTxGenerator`. This could let a swap execute against exchange-rate/repay parameters that were only valid up to the (now-passed) `Deadline`, potentially resulting in unfavorable settlement for the router/lender or unintended value transfer inconsistent with the user's declared time-bound intent — a fee-delegation/gasless settlement integrity issue reachable purely by a normal gasless user's own transaction timing, no privileged access required.

### Likelihood Explanation
Moderate-to-uncertain. I could not confirm from the indexed files whether the underlying `GaslessSwapRouter` (KIP-247) contract itself independently enforces `deadline` on-chain — a search for `deadline` across `.sol` files in the repo returned no matches, but this may reflect index coverage limits rather than an authoritative absence of the check in the actual bound contract (`kip247` bindings reference an external contract whose source may not be fully indexed). If the on-chain router does enforce deadline itself, this Go-level gap is a defense-in-depth issue only. If it does not, this becomes a genuine reachable divergence between admission-time and execution-time validation.

### Recommendation
Add an explicit deadline check inside `VerifyExecutable` (or `IsExecutable`) in `kaiax/gasless/impl/getter.go`, so that the expiry constraint is re-validated immediately before a swap is included in `ExtractTxBundles`, not only once at pool admission via `checkBalanceForSwap`. Additionally, verify and, if absent, add an on-chain deadline check in the `GaslessSwapRouter` contract itself as the ultimate source of truth, consistent with the Flarum fix of moving the expiry check into the actual processing/settlement code path rather than trusting a check performed earlier at a different layer.

### Proof of Concept
Conceptual (I could not execute this against the repo in ask-only mode):
1. Submit a valid `approveTx` + `swapTx` gasless pair with `Deadline = currentBlockTime + N`, satisfying `checkBalanceForSwap` at admission.
2. Delay promotion (e.g., have the approve tx or swap tx remain in queue/pending across several blocks — feasible if nonce ordering or other pool conditions stall it) until chain time exceeds `Deadline`.
3. Once conditions unblock promotion, `isSwapTxReady`/`ExtractTxBundles` call `IsExecutable`→`VerifyExecutable`, which does not re-check `Deadline`, so the pair is still bundled via `GetLendTxGenerator` and settled on-chain despite the declared deadline having passed. [3](#0-2) [4](#0-3) [5](#0-4)

func (g *GaslessModule) isApproveTxReady(approveTx, nextTx *types.Transaction) bool {
	addr, err := types.Sender(g.signer, approveTx)
	if err != nil {
		return false
	}
	nonce := g.getCurrentStateNonce(addr)

	if approveTx.Nonce() != nonce {
		return false
	}
	if nextTx == nil || !g.IsSwapTx(nextTx) {
		return false
	}

	return g.IsExecutable(approveTx, nextTx)
}

// isSwapTxReady assumes that the caller checked `g.IsSwapTx(swapTx)`
func (g *GaslessModule) isSwapTxReady(swapTx, prevTx *types.Transaction) bool {
	addr, err := types.Sender(g.signer, swapTx)
	if err != nil {
		return false
	}
	nonce := g.getCurrentStateNonce(addr)

	var approveTx *types.Transaction
	if swapTx.Nonce() == nonce {
		approveTx = nil
	} else if swapTx.Nonce() == nonce+1 {
		if prevTx == nil || !g.IsApproveTx(prevTx) {
			return false
		}
		approveTx = prevTx
	} else {
		return false
	}

	return g.IsExecutable(approveTx, swapTx)
}

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
}
