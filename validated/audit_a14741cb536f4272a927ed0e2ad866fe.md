Kaia does not implement the Cosmos SDK/CometBFT ABCI++ vote extension mechanism (`ValidateVoteExtensions`, `ExtendedCommitInfo`, `PrepareProposal`/`ProcessProposal`) that this report describes. Kaia's consensus uses Istanbul BFT with `PREPREPARE`/`PREPARE`/`COMMIT` phases and round-bound committed seals [1](#0-0) , and its only "vote" concept is the unrelated governance parameter voting embedded in `header.Vote`/`header.Governance`, verified by `VerifyVote`/`checkConsistency` against the validator council [2](#0-1) . There is no analogous code path where a proposer injects a vote/commit set whose aggregate power or round value is trusted without independent validation by the receiving node — committed seals are individually verified against the committee and, post-permissionless fork, bound to the specific round via `PrepareCommittedSealWithRound`, preventing replay of stale-round seals [3](#0-2) . Additionally, this class of issue involves a validator/proposer-controlled consensus message path, which is explicitly out of scope per the rules (malicious-validator/consensus-message analogs are rejected).

### Consensus phases

Istanbul uses three voting phases.

1. `PREPREPARE`
   - The proposer broadcasts a block proposal for the current `(sequence, round)`.
2. `PREPARE`
   - Committee members vote for the proposal digest and parent hash.
3. `COMMIT`
   - Committee members attach committed seals for the proposal hash.

When enough `COMMIT` messages are collected, the core asks the backend to commit the proposal. If progress stalls, the core sends `ROUND CHANGE` messages and starts a higher round.

// VerifyVote checks the following:
// (1) voter must be in valset,
// (2) integrity of the voter (the voter must be the block proposer),
// (3) the vote value must be consistent compared to the latest ParamSet.
func (h *headerGovModule) VerifyVote(header *types.Header) error {
	if len(header.Vote) == 0 {
		return nil
	}

	var (
		vb       headergov.VoteBytes = header.Vote
		blockNum                     = header.Number.Uint64()
	)

	vote, err := vb.ToVoteData()
	if err != nil {
		logger.Error("ToVoteData error", "num", blockNum, "vote", vb, "err", err)
		return err
	}

	if gov.DeprecatedAt(vote.Name(), h.ChainConfig.Rules(header.Number)) {
		logger.Error("Vote is deprecated", "num", blockNum, "name", vote.Name())
		return ErrDeprecatedVote
	}

	council, err := h.ValSet.GetCouncil(blockNum)
	if err != nil {
		return err
	}

	// check if the voter is in council
	if !slices.Contains(council, vote.Voter()) {
		return ErrInvalidKeyValue
	}

	// check if Voter is the block proposer.
	author, err := h.Chain.Sealer().Author(header)
	if err != nil {
		return err
	}
	if author != vote.Voter() {
		return ErrInvalidVoter
	}
