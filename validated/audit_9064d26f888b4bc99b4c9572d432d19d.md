## Analysis

The reported bug class — creating a token wrapper for an address with no contract code, silently "succeeding" on transfers with no actual value movement — has a direct analog in sei-chain's pointer-registration path.

### Title
Unvalidated `ErcAddress` in `MsgRegisterPointer` lets anyone permanently register a CW pointer for a non-existent EVM contract, causing silent no-op transfers and broken accounting - (File: `x/evm/keeper/msg_server.go`)

### Summary
`MsgServer.RegisterPointer` instantiates a CosmWasm pointer contract that wraps an arbitrary EVM address supplied by the caller (`msg.ErcAddress`), without ever checking whether that address has associated EVM bytecode.

### Finding Description
`RegisterPointer` only checks `ValidateBasic`, which merely verifies the string is a well-formed hex address via `common.IsHexAddress` — it does not check contract existence. [1](#0-0) 

The handler then directly proceeds to instantiate a CW wasm pointer contract keyed to that (unverified) address and permanently records the pointer mapping: [2](#0-1) 

This is confirmed by an existing unit test that registers a pointer for the literal zero address (`0x0000000000000000000000000000000000000000`), which trivially has no code, and the call succeeds without error: [3](#0-2) 

Contrast this with the *opposite* direction (EVM `pointer` precompile creating an ERC20/CW20 pointer for a CW contract), which explicitly validates the target by querying `token_info` on the wasm contract before instantiating anything — proving the codebase is aware this validation is necessary and does it elsewhere: [4](#0-3) 

Because `SetCW20ERC20Pointer`/`SetCW721ERC721Pointer`/`SetCW1155ERC1155Pointer` are effectively "set once" per version (a second `RegisterPointer` call for the same `ErcAddress` at the same or lower version is rejected), a bogus pointer registered against a non-existent address permanently occupies that pointer slot.

### Impact Explanation
Once a wasm CW20/CW721/CW1155 pointer is deployed pointing at an address with no EVM code, any downstream call the pointer contract makes into the EVM (e.g., `transfer`, `balanceOf`, `transferFrom` via the precompile bridge) targets code-less storage. EVM `CALL`/`STATICCALL` to an address with no code returns success with empty return data rather than reverting, so wasm-side logic built around these calls can misinterpret empty responses as valid state (zero balances, "successful" transfers that moved nothing). Any protocol or user that trusts the pointer as a faithful CW wrapper of a real ERC20/721/1155 token will observe messed-up accounting — transfers that appear to succeed while moving no value, and permanently broken balances — matching the "loss of funds due to messed accounting" impact described in the source report. The pointer slot for that `ErcAddress` is also effectively bricked, since it can't be re-pointed to a legitimate future deployment except via a version bump.

### Likelihood Explanation
`MsgRegisterPointer` is a fully permissionless message — any unprivileged transaction sender can submit it with any hex string as `ErcAddress`, including addresses that are provably empty (like `0x0`) or addresses that simply haven't been deployed to yet. No special privileges, precompile access, or governance action is required, making this trivially and repeatedly reachable.

### Recommendation
Before instantiating the pointer contract in `RegisterPointer`, verify `msg.ErcAddress` has non-empty EVM bytecode (e.g., via the EVM keeper's `GetCode`/state DB code-length check), mirroring the existing `QuerySmart`/contract-existence validation already performed in the `AddCW20`/`AddCW721` precompile handlers for the reverse (EVM→CW) direction. Reject the message if no code is present at that address.

### Proof of Concept
1. Submit `MsgRegisterPointer{PointerType: ERC20, ErcAddress: "0x000000000000000000000000000000000000ff"}` (or any address with no deployed bytecode) from any account.
2. Observe the message succeeds: a CW20 pointer contract is instantiated and `SetCW20ERC20Pointer` permanently records the mapping — exactly as demonstrated for the zero address in `TestMigrateCWERC20Pointers`. [5](#0-4) 
3. Any subsequent `transfer`/`balanceOf` interaction with this pointer routes through wasmd→EVM calls against the code-less address, silently no-oping instead of failing, corrupting any accounting that treats the pointer as backed by a real token.

func (msg *MsgRegisterPointer) ValidateBasic() error {
	_, err := sdk.AccAddressFromBech32(msg.Sender)
	if err != nil {
		return sdkerrors.Wrapf(sdkerrors.ErrInvalidAddress, "Invalid sender address (%s)", err)
	}

	if !common.IsHexAddress(msg.ErcAddress) {
		return sdkerrors.ErrInvalidAddress
	}

	return nil
}

func (server msgServer) RegisterPointer(goCtx context.Context, msg *types.MsgRegisterPointer) (*types.MsgRegisterPointerResponse, error) {
	ctx := sdk.UnwrapSDKContext(goCtx)
	if server.GetRegisterPointerDisabled(ctx) {
		return nil, fmt.Errorf("registering CW->ERC pointers has been disabled")
	}
	var existingPointer sdk.AccAddress
	var existingVersion uint16
	var currentVersion uint16
	var exists bool
	switch msg.PointerType {
	case types.PointerType_ERC20:
		currentVersion = erc20.CurrentVersion
		existingPointer, existingVersion, exists = server.GetCW20ERC20Pointer(ctx, common.HexToAddress(msg.ErcAddress))
	case types.PointerType_ERC721:
		currentVersion = erc721.CurrentVersion
		existingPointer, existingVersion, exists = server.GetCW721ERC721Pointer(ctx, common.HexToAddress(msg.ErcAddress))
	case types.PointerType_ERC1155:
		currentVersion = erc1155.CurrentVersion
		existingPointer, existingVersion, exists = server.GetCW1155ERC1155Pointer(ctx, common.HexToAddress(msg.ErcAddress))
	default:
		panic("unknown pointer type")
	}
	if exists && existingVersion >= currentVersion {
		return nil, fmt.Errorf("pointer %s already registered at version %d", existingPointer.String(), existingVersion)
	}
	payload := map[string]interface{}{}
	switch msg.PointerType {
	case types.PointerType_ERC20:
		payload["erc20_address"] = msg.ErcAddress
	case types.PointerType_ERC721:
		payload["erc721_address"] = msg.ErcAddress
	case types.PointerType_ERC1155:
		payload["erc1155_address"] = msg.ErcAddress
	default:
		panic("unknown pointer type")
	}
	codeID := server.GetStoredPointerCodeID(ctx, msg.PointerType)
	moduleAcct := server.accountKeeper.GetModuleAddress(types.ModuleName)
	var err error
	var pointerAddr sdk.AccAddress
	if exists {
		bz, _ := json.Marshal(map[string]interface{}{})
		pointerAddr = existingPointer
		_, err = server.wasmKeeper.Migrate(ctx, existingPointer, moduleAcct, codeID, bz)
	} else {
		bz, jerr := json.Marshal(payload)
		if jerr != nil {
			return nil, jerr
		}
		pointerAddr, _, err = server.wasmKeeper.Instantiate(ctx, codeID, moduleAcct, moduleAcct, bz, fmt.Sprintf("Pointer of %s", msg.ErcAddress), sdk.NewCoins())
	}
	if err != nil {
		return nil, err
	}
	switch msg.PointerType {
	case types.PointerType_ERC20:
		err = server.SetCW20ERC20Pointer(ctx, common.HexToAddress(msg.ErcAddress), pointerAddr.String())
		ctx.EventManager().EmitEvent(sdk.NewEvent(
			types.EventTypePointerRegistered, sdk.NewAttribute(types.AttributeKeyPointerType, "erc20"),
			sdk.NewAttribute(types.AttributeKeyPointerAddress, pointerAddr.String()), sdk.NewAttribute(types.AttributeKeyPointee, msg.ErcAddress),
			sdk.NewAttribute(types.AttributeKeyPointerVersion, fmt.Sprintf("%d", erc20.CurrentVersion))))
	case types.PointerType_ERC721:
		err = server.SetCW721ERC721Pointer(ctx, common.HexToAddress(msg.ErcAddress), pointerAddr.String())
		ctx.EventManager().EmitEvent(sdk.NewEvent(
			types.EventTypePointerRegistered, sdk.NewAttribute(types.AttributeKeyPointerType, "erc721"),
			sdk.NewAttribute(types.AttributeKeyPointerAddress, pointerAddr.String()), sdk.NewAttribute(types.AttributeKeyPointee, msg.ErcAddress),
			sdk.NewAttribute(types.AttributeKeyPointerVersion, fmt.Sprintf("%d", erc721.CurrentVersion))))
	case types.PointerType_ERC1155:
		err = server.SetCW1155ERC1155Pointer(ctx, common.HexToAddress(msg.ErcAddress), pointerAddr.String())
		ctx.EventManager().EmitEvent(sdk.NewEvent(
			types.EventTypePointerRegistered, sdk.NewAttribute(types.AttributeKeyPointerType, "erc1155"),
			sdk.NewAttribute(types.AttributeKeyPointerAddress, pointerAddr.String()), sdk.NewAttribute(types.AttributeKeyPointee, msg.ErcAddress),
			sdk.NewAttribute(types.AttributeKeyPointerVersion, fmt.Sprintf("%d", erc1155.CurrentVersion))))
	default:
		panic("unknown pointer type")
	}
	return &types.MsgRegisterPointerResponse{PointerAddress: pointerAddr.String()}, err
}

func TestMigrateCWERC20Pointers(t *testing.T) {
	k := testkeeper.EVMTestApp.EvmKeeper
	ctx := testkeeper.EVMTestApp.GetContextForDeliverTx([]byte{}).WithBlockTime(time.Now())
	params := k.GetParams(ctx)
	params.RegisterPointerDisabled = false

	msgServer := keeper.NewMsgServerImpl(&k)

		PointerType: types.PointerType_ERC20,
		ErcAddress:  "0x0000000000000000000000000000000000000000",
	})
	require.Nil(t, err)
	require.Nil(t, migrations.MigrateCWERC20Pointers(ctx, &k))
	// address should stay the same
	addr, _, _ := k.GetCW20ERC20Pointer(ctx, common.HexToAddress("0x0000000000000000000000000000000000000000"))
	require.Equal(t, res.PointerAddress, addr.String())
}
