### Title
Gasless module credits an attacker-declared repay amount without verifying actual token-swap value movement, allowing proposer fund lending against phantom collateral - ([File: kaiax/gasless/impl/getter.go])

### Summary
The AllbridgeCCTP exploit's root cause was that a router credited a "deposit" purely from an attested message's self-declared `amount` field, without ever checking that value had actually moved (no mint/balance-change check). The `kaiax/gasless` module exhibits the same class of trust: the block proposer (fee lender) commits a real, unconditional KAIA transfer (`LendTx`) to a gasless-swap sender based solely on values *decoded from the sender's own transaction calldata* (`amountRepay`, gas price, gas limit), with no verification that the referenced ERC20-to-KAIA swap will actually produce that value for the proposer.

### Finding Description
`GetLendTxGenerator` in [1](#0-0)  builds and signs a real value-transfer transaction from the block proposer's `NodeKey` to the gasless sender, funded by `lendAmount(approveTxOrNil, swapTx)`, which is computed purely from `tx.Fee()` values (i.e., `GasPrice * GasLimit`) taken from the sender-signed transactions: [2](#0-1) 

Before this lending happens, `VerifyExecutable`/`IsExecutable` performs a purely syntactic/self-consistency check: it decodes `swapForGas(token, amountIn, minAmountOut, amountRepay, deadline)` straight from calldata and only checks that the declared `amountRepay` equals a formula computed from the *same self-declared* gas parameters (SP4), and that `token`/`router` addresses are whitelisted (S1/S3): [3](#0-2) 

Crucially, none of these checks establish that the swap will actually produce `amountIn` worth of tokens converted into enough output to repay the proposer — the entire repayment guarantee is deferred to the external `GaslessSwapRouter` contract's `swapForGas` execution, whose Solidity source is not present in this repository (only Go bindings exist, e.g. `contracts/bindings/kip247/GaslessSwapRouter.go`) and therefore cannot be audited here. The pool-level balance check for gasless transactions is explicitly weakened/omitted as documented: [4](#0-3) 

This mirrors the CCTP flaw precisely: a privileged actor (there, the messenger; here, the block proposer via the module) extends real value based on a counterparty-supplied declaration of intended value movement, verified only against internally-consistent metadata (message shape / gas-fee arithmetic) rather than an actual, independently observed transfer of value.

### Impact Explanation
If the external `GaslessSwapRouter` contract (out of scope for this repo, but the trust boundary originates here) fails to enforce that `swapForGas` actually delivers `amountRepay` KAIA to the block proposer/coinbase before completing — e.g., a revert-swallowing path, a token that fails silently, or any check bypass in the swap logic — the proposer's `LendTx` KAIA transfer executes unconditionally as the first transaction in the bundle, and the sender can walk away with lent KAIA while returning no real value. Because bundling constructs `[LendTxGenerator, ApproveTx, SwapTx]` and the lend transfer is a plain value transfer executed before the swap outcome is known, a failure or manipulation in the swap step downstream does not automatically claw back the lent KAIA. This is direct unauthorized value movement from the block proposer, a form of fee-delegation/gasless-settlement theft.

### Likelihood Explanation
Reaching this path only requires submitting a syntactically valid `GaslessApproveTx`/`GaslessSwapTx` pair as an ordinary, unprivileged transaction sender — no special access is needed, matching the "any transaction sender" reachability required for a valid analog. The likelihood of full exploitation depends on properties of the external swap router contract that are not in this repository's scope, so it cannot be fully confirmed as reachable end-to-end from the kaiax code alone; however, the trust assumption itself (self-declared amount validated only against self-declared gas metadata, no on-chain checked value movement at the module layer) is a structurally weaker analog of the CCTP root cause and is concretely present in `kaiax/gasless`.

### Recommendation
- Do not rely solely on calldata-declared `amountRepay` self-consistency; require the module (or block-building logic) to verify, after simulating/executing the bundle, that the block proposer's coinbase/lender balance actually increased by at least `amountRepay` as a result of `SwapTx` before finalizing/broadcasting the bundle.
- Make the `[LendTx, ApproveTx, SwapTx]` bundle atomic with an explicit "must succeed and must net-repay" condition, reverting the entire bundle (including the lend) if the swap does not deliver the promised value.
- Audit the external `GaslessSwapRouter` contract (not present in this repo) to ensure `swapForGas` cannot complete without actually transferring `amountRepay` to `block.coinbase`/proposer, and add repository-level integration tests that simulate a malicious router/token pair to confirm no phantom repayment scenario exists.

### Proof of Concept
Not independently reproducible from this repository alone because the value-movement guarantee is implemented in the external `GaslessSwapRouter` contract, whose source is not included here (only bindings in `contracts/bindings/kip247/GaslessSwapRouter.go`). The reachable, provable weakness demonstrated purely from in-scope code is: any unprivileged sender can get `VerifyExecutable` to pass, and thus get the proposer's `GetLendTxGenerator`-produced KAIA transfer executed, using only self-declared, attacker-controlled transaction fields validated against a self-referential formula (`repayAmount`) — see [5](#0-4)  and [2](#0-1)  — with no on-chain check, at the kaiax module layer, that real value was ever returned to the proposer.

// IsGaslessPattern checks following conditions:
// Ax. IsApproveTx conditions (if ApproveTx != nil)
// Sx. IsSwapTx conditions
// AP1. ApproveTx.from == SwapTx.from
// SP1. ApproveTx.to == SwapTx.token
// SP2. ApproveTx.amount >= SwapTx.amountIn
// SP3. ApproveTx.nonce+1 == SwapTx.nonce and Gasless transactions are head for nonce
// SP4. SwapTx.amountRepay = RepayAmount(ApproveTx, SwapTx)
func (g *GaslessModule) IsExecutable(approveTxOrNil, swapTx *types.Transaction) bool {
	err := g.VerifyExecutable(approveTxOrNil, swapTx)
	if err != nil {
		return false
	}
	return true
}

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

func (g *GaslessModule) GetLendTxGenerator(approveTxOrNil, swapTx *types.Transaction) *builder.TxOrGen {
	var src []byte
	if approveTxOrNil != nil {
		src = append(src, approveTxOrNil.Hash().Bytes()...)
	}
	src = append(src, swapTx.Hash().Bytes()...)
	bundleHash := crypto.Keccak256Hash(src)

	gen := func(nonce uint64) (*types.Transaction, error) {
		var (
			chainId = g.InitOpts.ChainConfig.ChainID
			signer  = types.LatestSignerForChainID(chainId)
			key     = g.InitOpts.NodeKey
		)

		to, err := types.Sender(signer, swapTx)
		if err != nil {
			return nil, err
		}

		tx, err := types.NewTransactionWithMap(types.TxTypeEthereumDynamicFee, map[types.TxValueKeyType]interface{}{
			types.TxValueKeyNonce:      nonce,
			types.TxValueKeyTo:         &to,
			types.TxValueKeyAmount:     lendAmount(approveTxOrNil, swapTx),
			types.TxValueKeyData:       common.Hex2Bytes("0x"),
			types.TxValueKeyGasLimit:   params.TxGas,
			types.TxValueKeyGasFeeCap:  swapTx.GasFeeCap(),
			types.TxValueKeyGasTipCap:  swapTx.GasTipCap(),
			types.TxValueKeyAccessList: types.AccessList{},
			types.TxValueKeyChainID:    chainId,
		})
		if err != nil {
			return nil, err
		}

		err = tx.Sign(signer, key)
		return tx, err
	}

	return builder.NewTxOrGenFromGen(gen, bundleHash)
}

func lendAmount(approveTxOrNil, swapTx *types.Transaction) *big.Int {
	r := new(big.Int)

	// R2 = ApproveTx.Fee() if exists
	if approveTxOrNil != nil {
		r.Add(r, approveTxOrNil.Fee())
	}

	// R3 = SwapTx.Fee()
	r.Add(r, swapTx.Fee())

	// LendAmount = R2 + R3
	return r
}

func repayAmount(approveTxOrNil, swapTx *types.Transaction) *big.Int {
	// R1 = LendTx.Fee() = SwapTx.GasPrice() * TxGas
	r1 := new(big.Int).Mul(swapTx.GasPrice(), new(big.Int).SetUint64(params.TxGas))

	// RepayAmount = R1 + R2 + R3
	return new(big.Int).Add(r1, lendAmount(approveTxOrNil, swapTx))
}
