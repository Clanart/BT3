### Title
Gasless bundle-tx queue admission can be DOS'd by unprivileged senders spamming fake approve/swap transactions - (File: kaiax/gasless/impl/tx_pool.go)

### Summary
The `kaiax/gasless` module admits any transaction that structurally matches an `approve`/`swapForGas` call against a whitelisted token/router into a shared, capacity-limited bundle queue (`MaxBundleTxsInQueue`) before any economic validity (token balance, allowance, swap feasibility) is checked. An unprivileged sender can submit cheap, worthless "gasless" transactions that pass the structural whitelist check but will never actually settle, filling the shared queue and causing legitimate users' real gasless bundle transactions to be rejected with `ErrBundleTxQueueFull`. This mirrors the reported OpenQ bug class: a shared, capacity-bounded acceptance mechanism can be saturated with fake/worthless items by an unprivileged actor, denying service to legitimate participants.

### Finding Description
`GaslessModule.PreAddTx` is invoked for every transaction entering the node's tx pool via the pool-module hook [1](#0-0) . For any transaction it classifies as a "bundle tx" (`IsBundleTx` = `IsApproveTx` or `IsSwapTx`), it only checks whether the shared queue counter is below `MaxBundleTxsInQueue` and, if so, adds it — with **no balance, allowance, or swap-feasibility check** at this stage: [2](#0-1) 

`IsApproveTx`/`IsSwapTx` only validate structural/whitelist conditions (token address in `allowedTokens`, spender is the whitelisted `swapRouter`, approval amount is `MaxUint`, etc.) — they do not verify that the sender actually holds or can transfer the token: [3](#0-2) 

The real economic checks (token balance/allowance, swap amount feasibility) are only performed later, during promotion in `IsReady`/`checkBalanceForSwap`, not at admission time: [4](#0-3) 

The queue capacity (`MaxBundleTxsInQueue`, default 200) and pending capacity (`MaxBundleTxsInPending`, default 100) are global, shared across all senders, and configured at the node level, not per-account: [5](#0-4) 

Because admission to the queue only requires constructing a syntactically valid `approve`/`swapForGas` call against a whitelisted token/router — which costs nothing more than crafting a transaction (no real token holdings, no real swap capability needed) — an attacker can trivially fill the shared queue to its cap. Once full, `PreAddTx` returns `ErrBundleTxQueueFull` for every subsequent bundle tx, including from legitimate senders with real balances, effectively denying them entry into the gasless flow: [6](#0-5) 

This is directly analogous to the reported vulnerability: a shared, capacity-limited acceptance surface (bounty funding slots there; gasless bundle-tx queue slots here) can be exhausted by an unprivileged party using worthless/fake entries that pass only superficial whitelist checks, blocking legitimate participants from the same resource.

### Impact Explanation
Any endpoint node or RPC-facing node running the gasless module can have its gasless bundle-tx queue permanently saturated by garbage transactions from unprivileged senders. This denies legitimate users' gasless swap/approve transactions from ever being queued/promoted, breaking a core user-facing feature (gasless transactions) network-wide (or per-node, depending on deployment) as long as the attacker sustains submission faster than the queue's `QueueTimeout` (10s) eviction, which is a cheap and repeatable action.

### Likelihood Explanation
High reachability: the flow is triggered by ordinary transaction submission through the public tx pool / RPC, requires no special privilege, no real token balance, and no allowance — only knowledge of the whitelisted token and swap router addresses, which are public (`gasless_getGaslessInfo` / `GaslessInfo` API exposes `AllowedTokens`) [7](#0-6) . Sustaining the attack only requires resubmitting fake calls faster than the 10-second `QueueTimeout` eviction.

### Recommendation
1. Perform at least a lightweight economic pre-check (e.g., a minimal on-chain balance/allowance snapshot check) in `PreAddTx` before admitting a tx into the bounded bundle queue, not only the structural whitelist match.
2. Apply per-sender admission limits (in addition to/instead of a purely global cap) so a single attacker (or small set of Sybil accounts) cannot exhaust the entire shared queue.
3. Consider requiring the submitter to pay for admission (e.g., normal gas-priced tx, rejecting free/zero-cost spam) or rate-limiting bundle-tx submissions per sender/IP at the RPC layer.

### Proof of Concept
1. Query `gasless_getGaslessInfo` to obtain the whitelisted `AllowedTokens` and `SwapRouter` addresses.
2. Craft `MaxBundleTxsInQueue` (default 200) distinct transactions from different (unfunded-of-the-token) accounts, each calling `approve(swapRouter, MaxUint256)` on a whitelisted token (satisfies `IsApproveTx` structural checks) or `swapForGas(token, ...)` on the whitelisted router (satisfies `IsSwapTx` structural checks). Each account only needs enough KAIA to pay for tx submission (or use fee-delegation with an unrelated payer), not any token balance.
3. Submit all transactions to the node's tx pool; `PreAddTx` admits each until `g.knownTxs.numQueue() >= MaxBundleTxsInQueue`.
4. A genuine user's real gasless approve/swap transaction (with actual token balance) submitted after the queue is full receives `ErrBundleTxQueueFull` from `PreAddTx`, confirming denial of service on the gasless feature, as directly exercised by the existing unit test `TestPreAddTxQueueLimit` [8](#0-7) .

func (g *GaslessModule) PreAddTx(tx *types.Transaction, local bool) error {
	g.knownTxsMu.RLock()
	defer g.knownTxsMu.RUnlock()

	if knownTx, ok := g.knownTxs.get(tx.Hash()); ok && knownTx.elapsedPromotedOrAddedTime() < KnownTxTimeout {
		return ErrUnableToAddKnownBundleTx
	}

	if g.IsBundleTx(tx) {
		if uint(g.knownTxs.numQueue()) >= g.GetMaxBundleTxsInQueue() {
			return ErrBundleTxQueueFull
		}
		g.knownTxs.add(tx, TxStatusQueue)
	}
	return nil
}

// Check promotion condition and enforce pending pool flow control.
func (g *GaslessModule) IsReady(txs map[uint64]*types.Transaction, next uint64, ready types.Transactions) bool {
	g.knownTxsMu.Lock()
	defer g.knownTxsMu.Unlock()

	tx, ok := txs[next]
	if !ok {
		return false
	}

	if !g.isReady(txs, next, ready) {
		return false
	}

	if g.IsBundleTx(tx) {
		// If prev tx is bundle tx, there's no need to check the knownTxs limit because it has been checked in the previous `IsReady()` execution.
		isPrevTxBundleTx := len(ready) != 0 && g.IsBundleTx(ready[len(ready)-1])
		if isPrevTxBundleTx {
			g.knownTxs.add(tx, TxStatusPending)
			return true
		}

		maxBundleTxsInPending := g.GetMaxBundleTxsInPending()
		if maxBundleTxsInPending != math.MaxUint64 {
			numExecutable := uint(g.knownTxs.numExecutable())

			numSeqTxs := uint(1)
			for i := next + 1; i < next+uint64(len(txs)); i++ {
				if tx, ok := txs[i]; ok && g.IsBundleTx(tx) {
					numSeqTxs++
				} else {
					break
				}
			}

			// false if there is possibility of exceeding max bundle tx num
			if numExecutable+numSeqTxs > maxBundleTxsInPending {
				logger.Trace("Not promoting a tx because of exceeding max bundle tx num", "tx", tx.Hash().String(), "numExecutable", numExecutable, "maxBundleTxsInPending", maxBundleTxsInPending)
				return false
			}
		}

		g.knownTxs.add(tx, TxStatusPending)
	}

	return true
}

// IsApproveTx checks following conditions:
// A1. tx.to is a whitelisted ERC20 token.
// A2. tx.data is `approve(spender, amount)`.
// A3. spender is a whitelisted SwapRouter contract.
// A4. amount is MaxUint.
func (g *GaslessModule) IsApproveTx(tx *types.Transaction) bool {
	args, ok := decodeApproveTx(tx, g.signer)
	return ok && g.isApproveTx(args)
}

func (g *GaslessModule) isApproveTx(args *ApproveArgs) bool {
	g.gaslessInfoMu.RLock()
	defer g.gaslessInfoMu.RUnlock()

	return g.allowedTokens[args.Token] && // A1
		g.swapRouter == args.Spender && // A3
		args.Amount.Cmp(abi.MaxUint256) == 0 // A4
}

// IsSwapTx checks following conditions:
// S1. tx.to is a whitelisted SwapRouter contract.
// S2. tx.data is `swapForGas(token, amountIn, minAmountOut, amountRepay)`.
// S3. token is a whitelisted ERC20 token.
func (g *GaslessModule) IsSwapTx(tx *types.Transaction) bool {
	args, ok := decodeSwapTx(tx, g.signer)
	return ok && g.isSwapTx(args)
}

func TestPreAddTxQueueLimit(t *testing.T) {
	log.EnableLogForTest(log.LvlError, log.LvlTrace)

	newModule := func(maxQueue uint) *GaslessModule {
		cfg := *gasless.DefaultGaslessConfig()
		cfg.MaxBundleTxsInQueue = maxQueue
		g := NewGaslessModule()
		dbm := database.NewMemoryDBManager()
		backend := backends.NewSimulatedBackendWithDatabase(dbm, testAllocStorage(), testChainConfig)
		nodekey, _ := crypto.GenerateKey()
		require.NoError(t, g.Init(&InitOpts{
			ChainConfig:   testChainConfig,
			GaslessConfig: &cfg,
			NodeKey:       nodekey,
			Chain:         backend.BlockChain(),
			NodeType:      common.ENDPOINTNODE,
		}))
		return g
	}

	bundleTx := func() *types.Transaction {
		privkey, _ := crypto.GenerateKey()
		return makeApproveTx(t, privkey, 0, ApproveArgs{Spender: common.HexToAddress("0x1234"), Amount: abi.MaxUint256})
	}

	// --gasless.max-bundle-txs-in-queue <= 0 maps to the math.MaxUint64 "no limit"
	// sentinel (config.go).
	t.Run("no limit sentinel accepts on empty queue", func(t *testing.T) {
		g := newModule(math.MaxUint64)
		tx := bundleTx()
		require.True(t, g.IsBundleTx(tx))
		require.NoError(t, g.PreAddTx(tx, false))
		require.Equal(t, 1, g.knownTxs.numQueue())
	})

	t.Run("finite limit still enforced", func(t *testing.T) {
		g := newModule(1)
		require.NoError(t, g.PreAddTx(bundleTx(), false))
		require.ErrorIs(t, g.PreAddTx(bundleTx(), false), ErrBundleTxQueueFull)
	})

type GaslessInfoResult struct {
	IsDisabled    bool             `json:"isDisabled"`
	SwapRouter    common.Address   `json:"swapRouter"`

	MaxBundleTxs  uint             `json:"maxBundleTxs"`

func (s *GaslessAPI) GaslessInfo() *GaslessInfoResult {
	s.b.gaslessInfoMu.RLock()
	defer s.b.gaslessInfoMu.RUnlock()

	at := []common.Address{}
	for addr := range s.b.allowedTokens {
		at = append(at, addr)
	}
	return &GaslessInfoResult{
		IsDisabled:    s.b.IsDisabled(),
		SwapRouter:    s.b.swapRouter,
		AllowedTokens: at,
		MaxBundleTxs:  s.b.GetMaxBundleTxsInPending(),
	}
}
