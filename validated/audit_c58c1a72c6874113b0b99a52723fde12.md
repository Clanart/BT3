### Title
Out-of-bounds buffer read (unhandled `IndexError`) in mempool CLVM canonical-encoding check via truncated atom length prefix - ([File: chia/full_node/mempool_manager.py])

### Summary
`is_clvm_canonical()` and its helper `is_atom_canonical()` in `chia/full_node/mempool_manager.py` parse the length-prefix byte(s) of every CLVM atom in an attacker-supplied `puzzle_reveal`/`solution` without first checking that the declared number of prefix bytes actually exists in the buffer. This mirrors the FLAC `bitreader.c` bug class in the source report: a multi-byte header field declares a length/prefix size, and the parser advances into the buffer to consume that length without validating remaining buffer size first, causing an out-of-bounds read.

### Finding Description
`is_atom_canonical()` reads the current byte to determine how many additional prefix bytes to consume (`prefix_len`, up to 5 for the `0b11111100` pattern), then loops `prefix_len` times indexing `clvm_buffer[offset]` with no bound check against `len(clvm_buffer)`: [1](#0-0) 

`is_clvm_canonical()` calls this helper for every atom while walking an untrusted buffer, again with no length check before dereferencing `clvm_buffer[offset]`: [2](#0-1) 

This function is invoked directly on attacker-controlled bytes — the `puzzle_reveal` and `solution` of every `CoinSpend` in a submitted `SpendBundle` — during mempool admission in `MempoolManager.validate_spend_bundle()`, which is on the path reached by any unprivileged spend-bundle submitter (wallet RPC, `push_tx`, peer relay of a transaction): [3](#0-2) 

A truncated multi-byte atom header (e.g. a buffer ending immediately after a lone `0xFC` byte, which declares a 5-byte extended length prefix) causes the `for i in range(prefix_len)` loop to index past the end of `clvm_buffer`, raising an unguarded Python `IndexError` instead of the intended `INVALID_COIN_SOLUTION` rejection path.

### Impact Explanation
The intended behavior of this code path is to reject non-canonical/malformed CLVM encodings gracefully with `Err.INVALID_COIN_SOLUTION`: [4](#0-3) 

Because the bounds check is missing, a crafted spend bundle triggers a Python-level `IndexError` inside `validate_spend_bundle()` before that graceful error path is ever reached. This is a spend-triggered exception in the mempool admission pipeline that a single unprivileged spend-bundle submitter can trigger for every peer/node that processes the bundle, matching the accepted "spend-triggered transaction-processing halt" impact class if the exception is not caught by a sufficiently broad handler upstream (this could not be fully confirmed with the available tool budget — the immediate caller chain up through `add_spend_bundle()`/RPC dispatch was not fully traced for a catch-all `except Exception` that would downgrade this to a benign rejection).

### Likelihood Explanation
High reachability: this check runs unconditionally on every coin spend's `puzzle_reveal` and `solution` bytes during ordinary mempool admission, for spend bundles submitted by any user/wallet/peer — no special privilege, height, or soft-fork gating is required. Constructing the trigger bytes requires only a single truncated atom-length-prefix byte at the end of the puzzle or solution blob.

### Recommendation
Add explicit bounds checks in `is_atom_canonical()` before indexing `clvm_buffer[offset]` in the prefix-consuming loop (mirroring the bounds checks already present elsewhere in the codebase, e.g. in `chia/full_node/full_block_utils.py`'s `skip_bytes`/`skip_list`), and raise/return a controlled "not canonical"/malformed result instead of allowing an `IndexError` to propagate. Add a regression test with a truncated multi-byte atom header (single `0xFC`, `0xF8`, etc. byte with no following bytes) as `puzzle_reveal`/`solution` input to `is_clvm_canonical`.

def is_atom_canonical(clvm_buffer: bytes, offset: int) -> tuple[int, bool]:
    b = clvm_buffer[offset]
    if (b & 0b11000000) == 0b10000000:
        # 6 bits length prefix
        mask = 0b00111111
        prefix_len = 0
        min_value = 1
    elif (b & 0b11100000) == 0b11000000:
        # 5 + 8 bits length prefix
        mask = 0b00011111
        prefix_len = 1
        min_value = 1 << 6
    elif (b & 0b11110000) == 0b11100000:
        # 4 + 8 + 8 bits length prefix
        mask = 0b00001111
        prefix_len = 2
        min_value = 1 << (5 + 8)
    elif (b & 0b11111000) == 0b11110000:
        # 3 + 8 + 8 + 8 bits length prefix
        mask = 0b00000111
        prefix_len = 3
        min_value = 1 << (4 + 8 + 8)
    elif (b & 0b11111100) == 0b11111000:
        # 2 + 8 + 8 + 8 + 8 bits length prefix
        mask = 0b00000011
        prefix_len = 4
        min_value = 1 << (3 + 8 + 8 + 8)
    elif (b & 0b11111110) == 0b11111100:
        # 1 + 8 + 8 + 8 + 8 + 8 bits length prefix
        mask = 0b00000001
        prefix_len = 5
        min_value = 1 << (2 + 8 + 8 + 8 + 8)

    atom_len = b & mask
    for i in range(prefix_len):
        atom_len <<= 8
        offset += 1
        atom_len |= clvm_buffer[offset]

    return 1 + prefix_len + atom_len, atom_len >= min_value
```

def is_clvm_canonical(clvm_buffer: bytes) -> bool:
    """
    checks whether the CLVM serialization is all canonical representation.
    atoms can be serialized in more than one way by using more bytes than
    necessary to encode the length prefix. This functions ensures that all atoms are
    encoded with the shortest representation. back-references are not allowed
    and will make this function return false
    """
    assert clvm_buffer != b""

    offset = 0
    tokens_left = 1
    while True:
        b = clvm_buffer[offset]

        # pair
        if b == 0xFF:
            tokens_left += 1
            offset += 1
            continue

        # back references cannot be considered canonical, since they may be
        # encoded in many different ways
        if b == 0xFE:
            return False

        # small atom or NIL
        if b <= 0x80:
            tokens_left -= 1
            offset += 1
        else:
            atom_len, canonical = is_atom_canonical(clvm_buffer, offset)
            if not canonical:
                return False
            tokens_left -= 1
            offset += atom_len

        if tokens_left == 0:
            break

    # if there's garbage at the end, it's not canonical
    return offset == len(clvm_buffer)
```
