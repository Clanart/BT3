Both `newNewRelicHTTPHandler` (`networks/rpc/http_newrelic.go`) and `newDatadogHTTPHandler` (`networks/rpc/http_datadog.go`) call `getRPCRequests(r)`, which reads the entire request body with `io.ReadAll(r.Body)` and no size cap, before the wrapped handler chain (which eventually reaches `validateRequest`/`newHTTPServerConn`'s `io.LimitReader(r.Body, common.MaxRequestContentLength)`) ever runs. This is the confirmed root cause of the analog.

### Title
Unbounded `io.ReadAll` on request body in NewRelic/Datadog RPC middleware bypasses `MaxRequestContentLength`, enabling memory-exhaustion DoS via understated/absent Content-Length - ([File: networks/rpc/http_newrelic.go])

### Summary
Kaia's JSON-RPC HTTP server enforces a `MaxRequestContentLength` limit (default 512KB) via `validateRequest()` checking `r.ContentLength` and via `io.LimitReader(r.Body, ...)` in `newHTTPServerConn` [1](#0-0) [2](#0-1) . However, when the optional NewRelic or Datadog APM middleware is enabled (via `NEWRELIC_APP_NAME`/`NEWRELIC_LICENSE` or `DD_TRACE_ENABLED` environment variables), the outermost handler calls `getRPCRequests(r)` before any content-length validation occurs [3](#0-2) . `getRPCRequests` reads the full body with `io.ReadAll(r.Body)` without any `io.LimitReader` or length cap [4](#0-3) .

### Finding Description
`NewHTTPServer` builds the handler chain as `cors -> vhost -> TimeoutHandler -> newNewRelicHTTPHandler -> newDatadogHTTPHandler`, so the NewRelic/Datadog wrapper's `ServeHTTP` runs first for every incoming request [5](#0-4) . Inside it, `getRPCRequests(r)` is invoked to extract the method name for tracing purposes, and it unconditionally does `io.ReadAll(r.Body)` [6](#0-5) , identical logic is duplicated in the Datadog handler [7](#0-6) . This read happens irrespective of the `Content-Length` header value: an attacker can send a request with `Transfer-Encoding: chunked` (no `Content-Length`) or a small/understated `Content-Length`, and the actual body streamed can be arbitrarily large — Go's `http.Server` will happily deliver all the bytes via `r.Body` regardless of the declared length. Only after this unbounded read completes does control reach `handler.ServeHTTP(dupW, r)`, which eventually invokes `validateRequest` and the `io.LimitReader`-bounded codec that the rest of the RPC pipeline relies on [8](#0-7) . This mirrors the Django CWE-130 issue: a size guard that is supposed to bound memory use is bypassed because the code path trusts (or ignores) the length metadata rather than enforcing a hard cap while streaming the body.

### Impact Explanation
An unprivileged public-RPC caller can send a single (or repeated) HTTP POST request with a chunked/oversized body to a Kaia node that has NewRelic or Datadog APM tracing enabled — a supported, documented production configuration (`cmd/utils/flaggroup.go`/environment-var driven, no special privilege required) — forcing the node to buffer the entire attacker-controlled payload in memory via `io.ReadAll`, far exceeding the intended `common.MaxRequestContentLength` (512KB default) [9](#0-8) . Repeated/concurrent requests can drive memory pressure and cause service degradation or crash of the RPC endpoint, a public-RPC availability impact.

### Likelihood Explanation
Any external caller reaching the node's public RPC HTTP endpoint can trigger this without authentication, as soon as the operator has enabled either APM integration (a common and reasonable operational choice for node monitoring). No race condition or privileged access is required — a single crafted HTTP request bypasses the size guard.

### Recommendation
Wrap `r.Body` with `io.LimitReader(r.Body, int64(common.MaxRequestContentLength))` (or reuse the existing `newHTTPServerConn` bound) before calling `io.ReadAll` in `getRPCRequests`, and/or perform the `validateRequest` content-length/size check before invoking the NewRelic/Datadog tracing wrappers so the guard cannot be bypassed by chunked or falsified `Content-Length` requests.

### Proof of Concept
1. Start a Kaia node with HTTP RPC enabled and set `NEWRELIC_APP_NAME`/`NEWRELIC_LICENSE` (or `DD_TRACE_ENABLED=true`) so `newNewRelicHTTPHandler` (or `newDatadogHTTPHandler`) wraps the RPC handler.
2. Send a POST request to the RPC endpoint using `Transfer-Encoding: chunked` (omitting `Content-Length`) with a body far larger than `common.MaxRequestContentLength` (e.g., several hundred MB of JSON padding).
3. Observe that `getRPCRequests` -> `io.ReadAll(r.Body)` fully buffers the oversized body in memory before `validateRequest`'s length check is ever reached, unlike a direct request without the APM middleware which is rejected early with HTTP 413 per `TestHTTPErrorResponseWithMaxContentLength` in `networks/rpc/http_test.go` [10](#0-9) .

// ServeHTTP serves JSON-RPC requests over HTTP.
func (s *Server) ServeHTTP(w http.ResponseWriter, r *http.Request) {
	// Permit dumb empty requests for remote health-checks (AWS)
	if r.Method == http.MethodGet && r.ContentLength == 0 && r.URL.RawQuery == "" {
		return
	}
	if code, err := validateRequest(r); err != nil {
		http.Error(w, err.Error(), code)
		return
	}
	// All checks passed, create a codec that reads direct from the request body
	// untilEOF and writes the response to w and order the server to process a
	// single request.
	ctx := r.Context()
	ctx = context.WithValue(ctx, "remote", r.RemoteAddr)
	ctx = context.WithValue(ctx, "scheme", r.Proto)
	ctx = context.WithValue(ctx, "local", r.Host)
	if ua := r.Header.Get("User-Agent"); ua != "" {
		ctx = context.WithValue(ctx, "User-Agent", ua)
	}
	if origin := r.Header.Get("Origin"); origin != "" {
		ctx = context.WithValue(ctx, "Origin", origin)
	}

	w.Header().Set("content-type", contentType)
	codec := newHTTPServerConn(r, w)
	defer codec.close()
	s.ServeSingleRequest(ctx, codec)
}

// getRPCRequests copies a http request body data and parses RPC requests from the data.
// It returns a slice of RPC request, an indication if these requests are in batch, and an error.
// Ethereum returns []*jsonrpcMessage, which replaces []rpcRequest
func getRPCRequests(r *http.Request) ([]*jsonrpcMessage, bool, error) {
	reqBody, err := io.ReadAll(r.Body)
	if err != nil {
		logger.Error("cannot read a request body", "err", err)
		return nil, false, err
	}

	r.Body = io.NopCloser(bytes.NewReader(reqBody))
	conn := &httpServerConn{Reader: io.NopCloser(bytes.NewReader(reqBody)), Writer: bytes.NewBufferString(""), r: r}

	codec := NewCodec(conn)

	defer codec.close()

	return codec.readBatch()
}

	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {

		reqParam := ""

			if isBatch {
				reqMethod += "_batch"
			}
			encoded, _ := json.Marshal(reqs[0].Params)
