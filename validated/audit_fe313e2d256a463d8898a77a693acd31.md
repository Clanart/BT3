### Title
Server-Side Request Forgery via unauthenticated DataLayer mirror creation forces arbitrary outbound HTTP requests from any node's DataLayer service - (File: chia/data_layer/data_layer_wallet.py)

### Summary
Any wallet user can submit a normal, unprivileged spend bundle that creates a DataLayer "mirror" coin advertising an arbitrary URL for an arbitrary (not necessarily self-owned) `launcher_id`/store id. Every node that subscribes to or owns that store will subsequently read the mirror URLs from chain and have its local DataLayer service issue outbound HTTP requests to them, with no restriction on scheme, host, or destination (including internal/loopback/link-local addresses). This mirrors CVE-2017-1000237's bug class: attacker-controlled input drives a server-initiated outbound request (SSRF) with no destination validation.

### Finding Description
`DataLayerWallet.create_new_mirror()` builds a completely standard XCH coin spend whose memo simply contains `[launcher_id, *urls]`, with **no check that the calling wallet owns or created the `launcher_id`'s singleton**: [1](#0-0) 

This is exposed via the `dl_new_mirror` wallet RPC, which passes the request straight through without ownership validation: [2](#0-1) 

Once the mirror coin is confirmed on chain, any DataLayer service that is watching that `store_id` (as owner or subscriber) pulls these attacker-chosen URLs via `get_mirrors()`/`update_subscriptions_from_wallet()`: [3](#0-2) 

and merges them into its local subscription server list (`DataStore.update_subscriptions_from_wallet`): [4](#0-3) 

On the periodic management loop, `fetch_and_validate()` iterates over these `servers_info` URLs (attacker-controlled) and performs an HTTP request against each one via `insert_from_delta_file` → `download_file` → `http_download`, or via `get_downloader()`'s plugin `handle_download` POST which itself forwards the mirror URL: [5](#0-4) [6](#0-5) [7](#0-6) 

None of these code paths validate the URL's host against internal/private ranges, cloud-metadata addresses, or restrict the scheme; they only check the `filename` naming convention, not the destination of the request itself. `subscribe`/`add_mirror` client-facing paths confirm any local RPC caller can also directly set arbitrary subscription URLs for a store id: [8](#0-7) , and the CLI/RPC/test coverage shows mirrors are added purely by URL and store id with no ownership gate: [9](#0-8) 

### Impact Explanation
Because mirror creation only requires a normal XCH spend (no relationship to the target store's singleton owner is enforced), an attacker can force any DataLayer node in the network that tracks a given store to issue outbound HTTP requests to attacker-chosen destinations — including internal services, cloud metadata endpoints (e.g., `169.254.169.254`), or other hosts on the node operator's private network — purely by getting a mirror transaction confirmed on chain. This is a classic SSRF primitive: the request originates from the victim's server with the victim's network position/credentials context, and the attacker fully controls the destination URL and can observe timing/response behavior through subsequent `get_mirrors`/error logs. Combined with `get_downloader`'s plugin POST relaying the URL to configured downloader plugins, this can also be leveraged to probe or interact with internal plugin/management endpoints.

### Likelihood Explanation
Likelihood is high for any operator running a DataLayer service that subscribes to third-party stores or that owns stores which any wallet can add mirrors for: creating the mirror coin requires only a small XCH amount and a fee, is fully unprivileged, and needs no cooperation from the store owner. The periodic `periodically_manage_data()` loop (default 60s) automatically triggers the outbound request without any user interaction, similar in kind to the automated request triggered by `ajaxsupplement.php` in the reference CVE.

### Recommendation
- Restrict `create_new_mirror`/`dl_new_mirror` to launcher_ids the wallet's DID/DL wallet actually owns, or otherwise require an authenticated relationship to the target store before advertising mirror URLs.
- Validate and sanitize all mirror/downloader/uploader URLs before making outbound requests: enforce allow-listed schemes (http/https only), resolve and reject requests to private/loopback/link-local/multicast IP ranges, and consider making outbound mirror fetching opt-in per store or require operator confirmation.
- Apply the same validation in `get_downloader()`/`get_uploaders()` plugin dispatch and in `http_download`/`download_file` so that neither the direct HTTP path nor the plugin-relay path can be pointed at internal infrastructure.

### Proof of Concept
1. Attacker crafts a normal XCH spend bundle via `dl_new_mirror`/`create_new_mirror`, setting `launcher_id` to any existing, actively-subscribed DataLayer store id (not owned by the attacker) and `urls=["http://169.254.169.254/latest/meta-data/"]` (or an internal RPC/admin endpoint). [10](#0-9) 
2. Attacker submits/broadcasts the transaction; once confirmed, the mirror coin's memo is publicly readable on chain.
3. Any node that owns or subscribes to that `store_id` runs `periodically_manage_data()` → `update_subscription()` → `update_subscriptions_from_wallet()`, pulling the attacker's URL into its local `subscriptions` table.
4. On the next cycle, `fetch_and_validate()` iterates `servers_info` (now including the attacker URL) and issues an HTTP request to it via `http_download`/`get_downloader`, causing the victim node to contact the attacker-chosen destination. [11](#0-10)

    async def get_downloader(self, store_id: bytes32, url: str) -> PluginRemote | None:
        request_json = {"store_id": store_id.hex(), "url": url}
        for d in self.downloaders:
            async with aiohttp.ClientSession() as session:
                try:
                    async with session.post(
                        d.url + "/handle_download",
                        json=request_json,
                        headers=d.headers,
                        timeout=self.client_timeout,
                    ) as response:
                        res_json = await response.json()
                        if res_json["handle_download"]:
                            return d
                except Exception as e:
                    self.log.error(f"get_downloader could not get response: {type(e).__name__}: {e}")
        return None

    async def update_subscriptions_from_wallet(self, store_id: bytes32, new_urls: list[str]) -> None:
        async with self.db_wrapper.writer() as writer:
            cursor = await writer.execute(
                "SELECT * FROM subscriptions WHERE from_wallet == 1 AND tree_id == :tree_id",
                {
                    "tree_id": store_id,
                },
            )
            old_urls = [row["url"] async for row in cursor]
            cursor = await writer.execute(
                "SELECT * FROM subscriptions WHERE from_wallet == 0 AND tree_id == :tree_id",
                {
                    "tree_id": store_id,
                },
            )
            from_subscriptions_urls = {row["url"] async for row in cursor}
            additions = {url for url in new_urls if url not in old_urls}
            removals = [url for url in old_urls if url not in new_urls]
            for url in removals:
                await writer.execute(
                    "DELETE FROM subscriptions WHERE url == :url AND tree_id == :tree_id",
                    {
                        "url": url,
                        "tree_id": store_id,
                    },
                )
            for url in additions:
                if url not in from_subscriptions_urls:
                    await writer.execute(
                        "INSERT INTO subscriptions(tree_id, url, ignore_till, num_consecutive_failures, from_wallet) "
                        "VALUES (:tree_id, :url, 0, 0, 1)",
                        {
                            "tree_id": store_id,
                            "url": url,
                        },
                    )

async def download_file(
    data_store: DataStore,
    target_filename_path: Path,
    store_id: bytes32,
    root_hash: bytes32,
    generation: int,
    server_info: ServerInfo,
    proxy_url: str | None,
    downloader: PluginRemote | None,
    timeout: aiohttp.ClientTimeout,
    client_foldername: Path,
    timestamp: int,
    log: logging.Logger,
    grouped_by_store: bool,
    group_downloaded_files_by_store: bool,
    max_delta_file_size: int,
) -> bool:
    if target_filename_path.exists():
        return True
    filename = get_delta_filename(store_id, root_hash, generation, grouped_by_store)

    if downloader is None:
        # use http downloader - this raises on any error
        try:
            await http_download(
                target_filename_path, filename, proxy_url, server_info, timeout, log, max_delta_file_size
            )
        except (asyncio.TimeoutError, aiohttp.ClientError, MaxDeltaFileSizeExceededError):
            new_server_info = await data_store.server_misses_file(store_id, server_info, timestamp)
            log.info(
                f"Failed to download {filename} from {new_server_info.url}."
                f"Miss {new_server_info.num_consecutive_failures}."
            )
            log.info(f"Next attempt from {new_server_info.url} in {new_server_info.ignore_till - timestamp}s.")
            return False
        return True

    log.info(f"Using downloader {downloader} for store {store_id.hex()}.")
    request_json = {
        "url": server_info.url,
        "client_folder": str(client_foldername),
        "filename": filename,
        "group_files_by_store": group_downloaded_files_by_store,
        "max_delta_file_size": max_delta_file_size,
    }
    try:
        async with aiohttp.ClientSession() as session:
            async with session.post(
                downloader.url + "/download",
                json=request_json,
                headers=downloader.headers,
                timeout=timeout,
            ) as response:
                res_json = await response.json()
                assert isinstance(res_json["downloaded"], bool)
                return res_json["downloaded"]
    except (asyncio.TimeoutError, aiohttp.ClientError) as e:
        log.error(f"download_file could not get response from plugin {downloader}: {type(e).__name__}: {e}")
        return False
