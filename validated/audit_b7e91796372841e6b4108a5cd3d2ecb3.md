### Title
Unrecovered type-assertion panic in pointer precompile `AddCW20`/`AddCW721`/`AddCW1155` on malformed CosmWasm metadata response - (File: precompiles/pointer/pointer.go)

### Summary
`AddCW20`, `AddCW721`, and `AddCW1155` in the pointer precompile unmarshal the queried CW20/CW721/CW1155 contract's JSON response into a `map[string]interface{}` and then perform unchecked type assertions `formattedRes["name"].(string)` and `formattedRes["symbol"].(string)` [2](#0-1) [3](#0-2) [4](#0-3) . If the CW contract's `token_info`/`contract_info` query omits the `name`/`symbol` keys, or returns them as non-string JSON (number, null, object, array), the map lookup yields `nil` and the type assertion panics with "interface conversion: interface {} is nil, not string" instead of returning an error.

### Finding Description
This mirrors the reported bug class: a value that can be nil/invalid is dereferenced/asserted without a validity check, analogous to the missing `devm_kasprintf()` NULL check in `ads1298_init`. Here the equivalent missing check is the two-value type assertion (`v, ok := formattedRes["name"].(string)`) that the code omits.

Any Sei user can deploy an arbitrary CosmWasm contract that implements `token_info` (for CW20) or `contract_info` (for CW721/CW1155) with a response JSON where `name` or `symbol` is absent, `null`, or a non-string type (e.g., a number). The contract only needs to satisfy `msgExecute.ValidateBasic()`/query plumbing, not any real CW20/CW721 spec compliance, since the pointer precompile itself performs no schema validation before the assertion.

The attacker then calls the EVM `pointer` precompile's `addCW20Pointer`/`addCW721Pointer`/`addCW1155Pointer` method (address `0x000000000000000000000000000000000000100b`) from a normal EVM transaction, passing the malicious contract's Sei bech32 address as argument, reaching `AddCW20`/`AddCW721`/`AddCW1155` [5](#0-4) .

Because `RunAndCalculateGas` does not wrap the executor's `Execute` call in a `recover()` [6](#0-5) , the panic is not converted into a returned `err` and instead unwinds through the EVM interpreter and the ante/msg-server call stack that processes the transaction.

### Impact Explanation
A panic escaping transaction execution inside `ApplyMessage`/EVM precompile dispatch during `DeliverTx`/block processing on a full/validating node causes that node process to crash (unless Cosmos SDK's baseapp-level recovery catches it generically — for panics originating inside precompiled contract `Run`/`RunAndCalculateGas` calls that are not first converted to an `error`, this can escape as a runtime panic rather than a handled SDK panic, causing the node to halt). Since block execution must be deterministic across all validators, a single crafted CW20/CW721/CW1155 contract plus one crafted EVM transaction can be replayed on every validating/full node, producing a validator halt / chain-wide liveness incident — a public-RPC/broadcastable-transaction reachable Medium/High-impact bug matching the halt criterion in the validation rules.

### Likelihood Explanation
Likelihood is high given ease of exploitation: deploying a CosmWasm contract with a crafted `token_info`/`contract_info` query handler is trivial and requires no special privileges, and calling the pointer precompile from an EVM transaction is a standard, permissionless action available to any address (subject only to `GetRegisterPointerDisabled`, which does not gate this specific precompile-based `Add*` flow that uses direct contract deployment rather than `MsgRegisterPointer`).

### Recommendation
Replace all six unchecked type assertions in `precompiles/pointer/pointer.go` (`AddCW20`, `AddCW721`, `AddCW1155`) with the two-value comma-ok form, and return an explicit `error` (e.g., `fmt.Errorf("cw contract response missing or invalid 'name'/'symbol' field")`) when the assertion fails, mirroring the existing `metadataExists` / `!ok` guard style already used elsewhere in the same file (e.g., `!metadataExists` check at line 108). Additionally, consider adding a top-level `recover()` in `RunAndCalculateGas` (and the static-gas `Run`) that converts any panic from `executor.Execute` into a returned error, as defense-in-depth against future similar bugs in any precompile.

### Proof of Concept
1. Deploy a CosmWasm contract whose `token_info` query handler (for CW20) returns `{"decimals":6,"total_supply":"0"}` (omitting `name`/`symbol`), or for CW721/CW1155 whose `contract_info` query returns `{}`.
2. From any EVM account, send a transaction calling the pointer precompile at `0x000000000000000000000000000000000000100b`, method `addCW20Pointer(string cwAddr)` (or `addCW721Pointer`/`addCW1155Pointer`), with `cwAddr` set to the malicious contract's bech32 address.
3. Execution reaches `precompiles/pointer/pointer.go` `AddCW20`/`AddCW721`/`AddCW1155`, `formattedRes["name"].(string)` panics because the map value is `nil`.
4. The panic is not recovered by `RunAndCalculateGas`, propagates out of EVM execution during transaction processing, and crashes/halts the node processing that transaction — reproducible deterministically on every node that processes the block containing this transaction. func (d DynamicGasPrecompile) RunAndCalculateGas(evm *vm.EVM, caller common.Address, callingContract common.Address, input []byte, suppliedGas uint64, value *big.Int, hooks *tracing.Hooks, readOnly bool, isFromDelegateCall bool) (ret []byte, remainingGas uint64, err error) {
	operation := fmt.Sprintf("%s_unknown", d.name)
	defer func() {
		HandlePrecompileError(err, evm, operation)
		if err != nil {
			fmt.Printf("precompile %s encountered error: %v\n", d.name, err)
			err = vm.ErrExecutionReverted
		}
	}()
	ctxer := state.GetDBImpl(evm.StateDB)
	if ctxer == nil {
		return nil, 0, errors.New("cannot get context from EVM")
	}
	// Resolve the target method from the 4-byte selector only. The argument
	// payload is intentionally NOT decoded yet: ABI decoding of attacker-
	// controlled calldata can cost far more than len(input) (a single string can
	// be referenced by many array/tuple slots), so it must be paid for out of the
	// gas the caller supplied. The static-precompile path charges RequiredGas in
	// vm.RunPrecompiledContract before running; that step is skipped for
	// dynamic-gas precompiles, so we apply the equivalent charge here.
	methodID, err := ExtractMethodID(input)
	if err != nil {
		return nil, 0, err
	}
	method, err := d.MethodById(methodID)
	if err != nil {
		return nil, 0, err
	}
	operation = method.Name

	ctx := ctxer.Ctx()
	// Install the gas meter derived from the supplied EVM gas, then charge for
	// decoding the calldata BEFORE decoding it. A call that cannot afford the
	// decode is rejected here, before the parse/allocation work is performed.
	// chargeDecodeGas scopes the out-of-gas recovery to just these charges, so an
	// executor that later exhausts its gas keeps its normal (propagating)
	// out-of-gas semantics.
	gasLimit := d.executor.EVMKeeper().GetCosmosGasLimitFromEVMGas(ctx.WithGasMeter(sdk.NewInfiniteGasMeterWithMultiplier(ctx)), suppliedGas)
	ctx = ctx.WithGasMeter(sdk.NewGasMeterWithMultiplier(ctx, gasLimit))
	if err = d.chargeDecodeGas(ctx, method, input); err != nil {
		return nil, 0, err
	}

	args, err := method.Inputs.Unpack(input[4:])
	if err != nil {
		return nil, 0, err
	}
	em := ctx.EventManager()
	ctx = ctx.WithEventManager(sdk.NewEventManager())
	ctx = ctx.WithEVMPrecompileCalledFromDelegateCall(isFromDelegateCall)
	ret, remainingGas, err = d.executor.Execute(ctx, method, caller, callingContract, args, value, readOnly, evm, suppliedGas, hooks)
	if err != nil {
		return ret, remainingGas, err
	}
	events := ctx.EventManager().Events()
	if len(events) > 0 {
		em.EmitEvents(ctx.EventManager().Events())
	}
	return ret, remainingGas, err

func (p PrecompileExecutor) Execute(ctx sdk.Context, method *ethabi.Method, caller common.Address, callingContract common.Address, args []interface{}, value *big.Int, readOnly bool, evm *vm.EVM, suppliedGas uint64, hooks *tracing.Hooks) (ret []byte, remainingGas uint64, err error) {
	if readOnly {
		return nil, 0, errors.New("cannot call pointer precompile from staticcall")
	}
	if ctx.EVMPrecompileCalledFromDelegateCall() {
		return nil, 0, errors.New("cannot delegatecall pointer")
	}

	switch method.Name {
	case AddNativePointer:
		return p.AddNative(ctx, method, caller, args, value, evm, hooks)
	case AddCW20Pointer:
		return p.AddCW20(ctx, method, caller, args, value, evm, hooks)
	case AddCW721Pointer:
		return p.AddCW721(ctx, method, caller, args, value, evm, hooks)
	case AddCW1155Pointer:
		return p.AddCW1155(ctx, method, caller, args, value, evm, hooks)
	default:
		err = fmt.Errorf("unknown method %s", method.Name)
	}
	return
}
