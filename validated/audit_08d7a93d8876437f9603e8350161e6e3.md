Confirmed: the `source_digest` is computed purely from the source `.move`/manifest files by hashing their bytes [1](#0-0) , and the `PackageMetadata` embeds this digest plus gzipped source text independently of the actual compiled bytecode that gets published on-chain [2](#0-1) . ### Title
On-chain `PackageMetadata` (source/source_digest) is never bound to the deployed module bytecode, letting publishers spoof `aptos move verify-package` with mismatched code - (File: aptos-move/cli/src/stored_package.rs)

### Summary
Aptos code publishing stores two independent things at a package's `PackageRegistry`: (1) the actual compiled module bytecode (in `0x1::code::PackageRegistry.packages[].modules` write-set entries used by the VM/loader) and (2) self-reported `PackageMetadata`, including gzipped Move source text and a `source_digest` that is a SHA-256 hash computed only over the publisher's own source files [1](#0-0) . Nothing in `code::publish_package` or the native publish path cross-checks that the metadata's `source`/`source_digest`/`manifest` actually correspond to the bytecode being published — `check_upgradability`, `check_coexistence`, and `check_dependencies` only look at module *names* and upgrade policy, never source-vs-bytecode consistency [5](#0-4) . The native `request_publish`/`request_publish_with_allowed_deps` layer validates compatibility, dependency allow-lists, and bytecode verification, but likewise never validates that `expected_modules`/bundle bytes match the previously-stored `ModuleMetadata.source` [6](#0-5) .

The Aptos CLI's `aptos move verify-package` — the tool third parties are meant to use to confirm on-chain code matches published source — compounds this: it creates a `CachedPackageRegistry` with `with_bytecode=false` (bytecode is never even downloaded) and its `verify()` method only diffs `name`, `deps`, `modules` (name/source/source_map metadata, not bytecode), `manifest`, `upgrade_policy`, `extension`, and `source_digest` against the locally recompiled metadata [7](#0-6) [4](#0-3) .

### Finding Description
A publisher can construct a `publish_package_txn`/`object_code_deployment::publish` transaction where the `PackageMetadata.modules[].source` (gzipped, human/tool-readable source) and `source_digest` correspond to a legitimate, benign, or previously-audited Move source tree, while the actual `code: vector<vector<u8>>` bundle passed alongside contains different, malicious compiled bytecode. Since:
- `source_digest` is derived only from local source files supplied by the publisher's own compiler run [1](#0-0) , and
- the on-chain publish path never recompiles or hashes the bundle bytecode to compare against the declared source [8](#0-7) ,

there is no enforced binding between "the source code shown/verifiable in `PackageMetadata`" and "the bytecode that will actually execute." Anyone who trusts `aptos move verify-package`'s "Successfully verified source of package" result — wallets, marketplaces, auditors, or automated tooling gating fund flows on verified source — is misled, because that command never fetches or diffs the deployed bytecode at all [9](#0-8) . Note `CachedPackageRegistry::get_bytecode`/`with_bytecode` plumbing exists in the codebase but is simply not invoked by the `VerifyPackage` command [10](#0-9) .

### Impact Explanation
This breaks the code-metadata/committed-bytes invariant called out in the Publish Impact Gate ("Mismatch between verified bytes, package metadata, dependency declarations, and committed module bytes"). It is high severity because it undermines the only on-chain/tooling mechanism for proving deployed-bytecode-matches-published-source, enabling a publisher to present fabricated "verified" source for a malicious module (e.g., claim it's an audited DEX/vault contract) while running arbitrary logic, deceiving any party (user, integrator, or automated scanner) that relies on `aptos move verify-package` or on reading `PackageMetadata.modules[].source` as ground truth for what's executing on-chain.

### Likelihood Explanation
High likelihood: no signer privilege or race condition is required — a single unprivileged publisher constructing a normal publish transaction with intentionally decoupled `metadata` and `code` arguments to `code::publish_package_txn` (or `object_code_deployment::publish`) suffices, since both are plain transaction arguments under the caller's control and are never cross-validated by Move or native code.

### Recommendation
Bind the published bytecode to the declared metadata before/at publish time: e.g., have the native `request_publish`/`request_publish_with_allowed_deps` layer (or a new dedicated check) recompute a bytecode-derived digest and reject publication if it disagrees with a hash of `ModuleMetadata.source`, or alternatively stop treating `source`/`source_digest` as a verifiable artifact and make `aptos move verify-package` fetch actual on-chain bytecode (`with_bytecode = true`) and diff it (post local recompilation) against the retrieved modules, not just against the metadata blob.

### Proof of Concept
1. Author benign, well-known source `Foo.move` and compile it, producing metadata `M` (with correct `source`, `source_digest`) and bytecode `B_good`.
2. Separately compile a malicious module `Foo` with an identical public API but a backdoored function body, producing bytecode `B_evil` (structurally/linking-compatible so it still satisfies `Compatibility::check`/verifier).
3. Submit `code::publish_package_txn(metadata_serialized = bcs(M), code = [B_evil])` (or via `object_code_deployment::publish`) — this succeeds since `publish_package` and the native publish path never compare `M.source`/`source_digest` to `B_evil` [8](#0-7) .
4. A third party runs `aptos move verify-package --account <addr>` against the local benign source `Foo.move`. The tool recompiles to get `compiled_metadata` (matching `M`), fetches only the on-chain `PackageRegistry` metadata (`with_bytecode=false`), and `CachedPackageMetadata::verify` succeeds since it never looks at bytecode, printing "Successfully verified source of package" [11](#0-10)  — despite `B_evil` running on-chain, not the verified `Foo.move` source.

pub fn compute_digest(paths: &[PathBuf]) -> Result<PackageDigest> {
    let mut hashed_files = Vec::new();
    let mut hash = |path: &Path| {
        let contents = std::fs::read(path)?;
        hashed_files.push(format!("{:X}", Sha256::digest(&contents)));
        Ok(())
    };
    let mut maybe_hash_file = |path: &Path| -> Result<()> {
        match path.extension() {
            Some(x) if MOVE_EXTENSION == x => hash(path),
            _ if path.ends_with(SourcePackageLayout::Manifest.path()) => hash(path),
            _ => Ok(()),
        }
    };

    for path in paths {
        if path.is_file() {
            maybe_hash_file(path)?;
        } else {
            for entry in walkdir::WalkDir::new(path)
                .follow_links(true)
                .into_iter()
                .filter_map(|e| e.ok())
            {
                if entry.file_type().is_file() {
                    maybe_hash_file(entry.path())?
                }
            }
        }
    }

    // Sort the hashed files to ensure that the order of files is always stable
    hashed_files.sort();

    let mut hasher = Sha256::new();
    for file_hash in hashed_files.into_iter() {
        hasher.update(file_hash.as_bytes());
    }

    Ok(PackageDigest::from(format!("{:X}", hasher.finalize())))

    public fun publish_package(owner: &signer, pack: PackageMetadata, code: vector<vector<u8>>) acquires PackageRegistry {
        // Disallow incompatible upgrade mode. Governance can decide later if this should be reconsidered.
        assert!(
            pack.upgrade_policy.policy > upgrade_policy_arbitrary().policy,
            error::invalid_argument(EINCOMPATIBLE_POLICY_DISABLED),
        );

        let addr = signer::address_of(owner);
        if (!exists<PackageRegistry>(addr)) {
            move_to(owner, PackageRegistry { packages: vector::empty() })
        };

        // Checks for valid dependencies to other packages
        let allowed_deps = check_dependencies(addr, &pack);

        // Check package against conflicts
        // To avoid prover compiler error on spec
        // the package need to be an immutable variable
        let module_names = get_module_names(&pack);

        // Record, per module in this package, the object's transitive root owner at (re)publish, so
        // lazy self-init can detect a later transfer of the object or an ancestor since that module
        // was published (see `init::internal_maybe_initialize`). Objects only; feature-gated.
        if (features::is_lazy_module_initialization_enabled() && object::is_object(addr)) {
            let owner = object::address_to_object<object::ObjectCore>(addr).root_owner();
            module_names.for_each_ref(|name| {
                init::record_deploy_owner(addr, *name.bytes(), owner);
            });
        };
        let package_immutable = &borrow_global<PackageRegistry>(addr).packages;
        let len = package_immutable.length();
        let index = len;
        let upgrade_number = 0;
        package_immutable.enumerate_ref(|i, old| {
            let old: &PackageMetadata = old;
            if (old.name == pack.name) {
                upgrade_number = old.upgrade_number + 1;
                check_upgradability(old, &pack, &module_names);
                index = i;
            } else {
                check_coexistence(old, &module_names)
            };
        });

        // Assign the upgrade counter.
        pack.upgrade_number = upgrade_number;

        let packages = &mut borrow_global_mut<PackageRegistry>(addr).packages;
        // Update registry
        let policy = pack.upgrade_policy;
        if (index < len) {
            pack.modules.for_each_ref(|m| {
                let m: &ModuleMetadata = m;
                init::reset_initialized(addr, *m.name.bytes());
            });
            *packages.borrow_mut(index) = pack
        } else {
            packages.push_back(pack)
        };

        event::emit(PublishPackage {
            code_address: addr,
            is_upgrade: upgrade_number > 0
        });

        // Request publish
        if (features::code_dependency_check_enabled())
            request_publish_with_allowed_deps(addr, module_names, allowed_deps, code, policy.policy)
        else
        // The new `request_publish_with_allowed_deps` has not yet rolled out, so call downwards
        // compatible code.
            request_publish(addr, module_names, code, policy.policy)
    }

    /// Checks whether the given package is upgradable, and returns true if a compatibility check is needed.
    fun check_upgradability(
        old_pack: &PackageMetadata, new_pack: &PackageMetadata, new_modules: &vector<String>) {
        assert!(old_pack.upgrade_policy.policy < upgrade_policy_immutable().policy,
            error::invalid_argument(EUPGRADE_IMMUTABLE));
        assert!(can_change_upgrade_policy_to(old_pack.upgrade_policy, new_pack.upgrade_policy),
            error::invalid_argument(EUPGRADE_WEAKER_POLICY));
        let old_modules = get_module_names(old_pack);

        old_modules.for_each_ref(|old_module| {
            assert!(
                vector::contains(new_modules, old_module),
                EMODULE_MISSING
            );
        });
    }

    /// Checks whether a new package with given names can co-exist with old package.
    fun check_coexistence(old_pack: &PackageMetadata, new_modules: &vector<String>) {
        // The modules introduced by each package must not overlap with `names`.
        old_pack.modules.for_each_ref(|old_mod| {
            let old_mod: &ModuleMetadata = old_mod;
            let j = 0;
            while (j < vector::length(new_modules)) {
                let name = vector::borrow(new_modules, j);
                assert!(&old_mod.name != name, error::already_exists(EMODULE_NAME_CLASH));
                j += 1;
            };
        });
    }

    /// Check that the upgrade policies of all packages are equal or higher quality than this package. Also
    /// compute the list of module dependencies which are allowed by the package metadata. The later
    /// is passed on to the native layer to verify that bytecode dependencies are actually what is pretended here.
    fun check_dependencies(publish_address: address, pack: &PackageMetadata): vector<AllowedDep>
    acquires PackageRegistry {
        let allowed_module_deps = vector::empty();
        let deps = &pack.deps;
        deps.for_each_ref(|dep| {
            let dep: &PackageDep = dep;
            assert!(exists<PackageRegistry>(dep.account), error::not_found(EPACKAGE_DEP_MISSING));
            if (is_policy_exempted_address(dep.account)) {
                // Allow all modules from this address, by using "" as a wildcard in the AllowedDep
                let account: address = dep.account;
                let module_name = string::utf8(b"");
                vector::push_back(&mut allowed_module_deps, AllowedDep { account, module_name });
            } else {
                let registry = borrow_global<PackageRegistry>(dep.account);
                let found = vector::any(&registry.packages, |dep_pack| {
                    let dep_pack: &PackageMetadata = dep_pack;
                    if (dep_pack.name == dep.package_name) {
                        // Check policy
                        assert!(
                            dep_pack.upgrade_policy.policy >= pack.upgrade_policy.policy,
                            error::invalid_argument(EDEP_WEAKER_POLICY)
                        );
                        if (dep_pack.upgrade_policy == upgrade_policy_arbitrary()) {
                            assert!(
                                dep.account == publish_address,
                                error::invalid_argument(EDEP_ARBITRARY_NOT_SAME_ADDRESS)
                            )
                        };
                        // Add allowed deps
                        let account = dep.account;
                        let k = 0;
                        let r = vector::length(&dep_pack.modules);
                        while (k < r) {
                            let module_name = vector::borrow(&dep_pack.modules, k).name;
                            vector::push_back(&mut allowed_module_deps, AllowedDep { account, module_name });
                            k += 1;
                        };
                        true
                    } else {
                        false
                    }
                });
                assert!(found, error::not_found(EPACKAGE_DEP_MISSING));
            };
        });
        allowed_module_deps
    }

fn native_request_publish(
    context: &mut SafeNativeContext,
    _ty_args: &[Type],
    mut args: VecDeque<Value>,
) -> SafeNativeResult<SmallVec<[Value; 1]>> {
    debug_assert!(matches!(args.len(), 4 | 5));
    let with_allowed_deps = args.len() == 5;

    context.charge(CODE_REQUEST_PUBLISH_BASE)?;

    let policy = safely_pop_arg!(args, u8);
    let mut code = vec![];
    for module in safely_pop_arg!(args, Vec<Value>) {
        let module_code = module.value_as::<Vec<u8>>()?;

        context.charge(CODE_REQUEST_PUBLISH_PER_BYTE * NumBytes::new(module_code.len() as u64))?;
        code.push(module_code);
    }

    let allowed_deps = if with_allowed_deps {
        let mut allowed_deps: BTreeMap<AccountAddress, BTreeSet<String>> = BTreeMap::new();

        for dep in safely_pop_arg!(args, Vec<Value>) {
            let (account, module_name) = unpack_allowed_dep(dep)?;

            let entry = allowed_deps.entry(account);

            if let Entry::Vacant(_) = &entry {
                // TODO: Is the 32 here supposed to indicate the length of an account address in bytes?
                context.charge(CODE_REQUEST_PUBLISH_PER_BYTE * NumBytes::new(32))?;
            }

            context
                .charge(CODE_REQUEST_PUBLISH_PER_BYTE * NumBytes::new(module_name.len() as u64))?;
            entry.or_default().insert(module_name);
        }

        Some(allowed_deps)
    } else {
        None
    };

    let mut expected_modules = BTreeSet::new();
    for name in safely_pop_arg!(args, Vec<Value>) {
        let str = get_move_string(name)?;

        // TODO(Gas): fine tune the gas formula
        context.charge(CODE_REQUEST_PUBLISH_PER_BYTE * NumBytes::new(str.len() as u64))?;
        expected_modules.insert(str);
    }

    let destination = safely_pop_arg!(args, AccountAddress);

    // Add own modules to allowed deps
    let allowed_deps = allowed_deps.map(|mut allowed| {
        allowed
            .entry(destination)
            .or_default()
            .extend(expected_modules.clone());
        allowed
    });

    let code_context = context.extensions_mut().get_mut::<NativeCodeContext>();
    if code_context.requested_module_bundle.is_some() || !code_context.enabled {
        // Can't request second time or if publish requests are not allowed.
        return Err(SafeNativeError::abort(EALREADY_REQUESTED));
    }
    code_context.requested_module_bundle = Some(PublishRequest {
        destination,
        bundle: ModuleBundle::new(code),
        expected_modules,
        allowed_deps,
        check_compat: policy != ARBITRARY_POLICY,
    });

    Ok(smallvec![])
}
