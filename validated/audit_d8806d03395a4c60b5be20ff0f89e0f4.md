### Title
Unchecked type assertion on attacker-controlled CW contract JSON response causes unrecovered panic in the `pointer` precompile - (File: precompiles/pointer/pointer.go)

### Summary
The `pointer` precompile's `AddCW20`, `AddCW721`, and `AddCW1155` executors parse a JSON reply from an arbitrary CosmWasm contract query and immediately perform unchecked Go type assertions (`.( string)`) on the decoded map values, with no recovery in the precompile dispatch path that invokes them.

### Finding Description
`AddCW20`, `AddCW721`, and `AddCW1155` in `precompiles/pointer/pointer.go` call `p.wasmdKeeper.QuerySmartSafe` against a caller-supplied CW address, `json.Unmarshal` the raw response bytes into `map[string]interface{}{}`, and then do:
```go
name := formattedRes["name"].(string)
symbol := formattedRes["symbol"].(string)
``` [1](#0-0) [2](#0-1) [3](#0-2) 

These type assertions are unchecked (single-value form), so if the queried CW contract's `token_info`/`contract_info` response omits `name`/`symbol`, or returns them as a non-string JSON type (number, bool, object, `null`), the assertion panics with a bare "interface conversion" error — analogous in bug class to the TagLib CVE's unchecked pointer cast on attacker-supplied file data.

The precompile is dispatched through `DynamicGasPrecompile.RunAndCalculateGas`, which invokes `d.executor.Execute(...)` (which resolves to `PrecompileExecutor.Execute` → `AddCW20`/`AddCW721`/`AddCW1155`) with no `recover()` around that call. The only `recover()` in this file is scoped narrowly to `chargeDecodeGas`, and it explicitly re-panics anything other than a gas-meter error: [4](#0-3) [5](#0-4) 

A CW contract is fully attacker-controlled (any wasm user can deploy one) and its `token_info`/`contract_info` query handler can be written to return any JSON shape, so any EVM caller can trigger this by invoking `addCW20Pointer`/`addCW721Pointer`/`addCW1155Pointer` (0x…100b) against a malicious contract they deploy.

### Impact Explanation
An unrecovered panic here is a denial-of-service condition reachable from a single, unprivileged transaction (deploy a CW contract with a crafted `token_info` query response, then call the pointer precompile against it). Whether this manifests as a full node crash depends on whether the calling context (e.g., a direct `eth_call`/`eth_estimateGas` RPC evaluation path, versus a full `DeliverTx`) has an outer panic-recovery boundary; I could not fully verify from the indexed code whether the JSON-RPC read-only EVM-call path wraps precompile execution in a recover the way transaction delivery normally does in the Cosmos SDK. If invoked without an enclosing recover (e.g., directly from `eth_call`), this crashes the RPC node process, matching the "crash of default-configuration RPC nodes" impact bucket. If it is always caught by an outer recover (e.g., standard `baseapp` `runTx` panic handling), the practical effect is degraded to a failed/reverted transaction rather than a node crash — I was not able to confirm which applies in the time available and this should be validated further.

### Likelihood Explanation
High: no privileged access is required — any address can instantiate a CW20/CW721/CW1155-mimicking contract that returns malformed JSON from its info query, then call `addCW20Pointer`/`addCW721Pointer`/`addCW1155Pointer` with that contract's address. This is a one-transaction, deterministic trigger.

### Recommendation
Replace the unchecked type assertions with the checked two-value form (`v, ok := formattedRes["name"].(string)`) and return a descriptive error when `ok` is false or the key is absent, mirroring the defensive error-returns already used elsewhere in the same functions (e.g., for `sdk.AccAddressFromBech32` and `json.Unmarshal` failures). Additionally, wrap `d.executor.Execute` in `DynamicGasPrecompile.RunAndCalculateGas` (and the static `Precompile.Run`) with a `recover()` that converts any panic into an `error`, consistent with the pattern already used for gas-meter panics, so that malformed downstream (wasm) responses can never propagate as raw Go panics through the precompile boundary.

### Proof of Concept
1. Deploy a CosmWasm contract whose `{"token_info":{}}` (or `{"contract_info":{}}`) query handler returns JSON such as `{"name": 12345, "symbol": null}` instead of strings.
2. From any EVM account, call the pointer precompile (`0x000000000000000000000000000000000000100b`) method `addCW20Pointer(contractAddr)` (or `addCW721Pointer`/`addCW1155Pointer`) targeting that contract.
3. Execution reaches `formattedRes["name"].(string)` in `precompiles/pointer/pointer.go`, which panics on the non-string value; no recover exists in `DynamicGasPrecompile.RunAndCalculateGas` for this panic, so it propagates out of the precompile dispatch layer.

func (d DynamicGasPrecompile) RunAndCalculateGas(evm *vm.EVM, caller common.Address, callingContract common.Address, input []byte, suppliedGas uint64, value *big.Int, hooks *tracing.Hooks, readOnly bool, isFromDelegateCall bool) (ret []byte, remainingGas uint64, err error) {
	operation := fmt.Sprintf("%s_unknown", d.name)
	defer func() {
		HandlePrecompileError(err, evm, operation)
		if err != nil {
			fmt.Printf("precompile %s encountered error: %v\n", d.name, err)
			err = vm.ErrExecutionReverted
		}
	}()
	ctxer := state.GetDBImpl(evm.StateDB)
	if ctxer == nil {
		return nil, 0, errors.New("cannot get context from EVM")
	}
	// Resolve the target method from the 4-byte selector only. The argument
	// payload is intentionally NOT decoded yet: ABI decoding of attacker-
	// controlled calldata can cost far more than len(input) (a single string can
	// be referenced by many array/tuple slots), so it must be paid for out of the
	// gas the caller supplied. The static-precompile path charges RequiredGas in
	// vm.RunPrecompiledContract before running; that step is skipped for
	// dynamic-gas precompiles, so we apply the equivalent charge here.
	methodID, err := ExtractMethodID(input)
	if err != nil {
		return nil, 0, err
	}
	method, err := d.MethodById(methodID)
	if err != nil {
		return nil, 0, err
	}
	operation = method.Name

	ctx := ctxer.Ctx()
	// Install the gas meter derived from the supplied EVM gas, then charge for
	// decoding the calldata BEFORE decoding it. A call that cannot afford the
	// decode is rejected here, before the parse/allocation work is performed.
	// chargeDecodeGas scopes the out-of-gas recovery to just these charges, so an
	// executor that later exhausts its gas keeps its normal (propagating)
	// out-of-gas semantics.
	gasLimit := d.executor.EVMKeeper().GetCosmosGasLimitFromEVMGas(ctx.WithGasMeter(sdk.NewInfiniteGasMeterWithMultiplier(ctx)), suppliedGas)
	ctx = ctx.WithGasMeter(sdk.NewGasMeterWithMultiplier(ctx, gasLimit))
	if err = d.chargeDecodeGas(ctx, method, input); err != nil {
		return nil, 0, err
	}

	args, err := method.Inputs.Unpack(input[4:])
	if err != nil {
		return nil, 0, err
	}
	em := ctx.EventManager()
	ctx = ctx.WithEventManager(sdk.NewEventManager())
	ctx = ctx.WithEVMPrecompileCalledFromDelegateCall(isFromDelegateCall)
	ret, remainingGas, err = d.executor.Execute(ctx, method, caller, callingContract, args, value, readOnly, evm, suppliedGas, hooks)
	if err != nil {
		return ret, remainingGas, err
	}
	events := ctx.EventManager().Events()
	if len(events) > 0 {
		em.EmitEvents(ctx.EventManager().Events())
	}
	return ret, remainingGas, err
}
