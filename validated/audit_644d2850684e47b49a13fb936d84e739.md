### Title
GaslessSwapRouter.claimCommission() drains entire contract balance, not tracked commission, allowing owner to rug undistributed gasless-swap proceeds - (File: contracts/bindings/kip247/GaslessSwapRouter.go, decompiled from `GaslessSwapRouterBinRuntime`)

### Summary
The `GaslessSwapRouter` contract (registered via KIP-149 `Registry` and used by Kaia's gasless transaction module) exposes an owner-only `claimCommission()` function whose decompiled bytecode sweeps `address(this).balance` in full and forwards it to the owner, rather than withdrawing a separately tracked/accrued commission amount.

### Finding Description
`GaslessSwapRouter` is the on-chain swap router used by Kaia's gasless flow: users approve tokens, and `swapForGas(token, amountIn, minAmountOut, amountRepay, deadline)` swaps the user's ERC20 for native KAIA, repays the fee-delegating proposer, forwards the remainder to the user, and retains a commission cut (as emitted in `SwappedForGas(proposer, amountRepaid, user, finalUserAmount, commission)`) <cite repo="blackvul/kaia--022" path="contracts/bindings/kip247/GaslessSwapRouter.go" start="1127="1135" /> [1](#0-0) . This router is wired into the node's gasless module: `kaiax/gasless/impl/getter.go` decodes `swapForGas` calls against the router address published via the on-chain Registry/MultiCall, and the node treats such transactions specially (bundling an approve+swap with a proposer-funded lend transaction) [2](#0-1) [3](#0-2) .

The owner-only `claimCommission()` (selector `0xfad99f98`) is implemented in the decompiled bytecode as: read `SELFBALANCE` (`47`), check non-zero, and forward the entire balance via a raw `call` to the stored owner slot, emitting `CommissionClaimed(amount)` on success [4](#0-3) [5](#0-4) . Because it uses the contract's raw native balance rather than a dedicated accrued-commission counter, any KAIA that is momentarily or unintentionally present in the router — e.g. via its `receive()` payable fallback, unswept unwrapped WKAIA dust from `swapForGas` executions, or funds sent directly to the router — is swept together with legitimate commission and sent to the owner [6](#0-5) . The full source `.sol` for `GaslessSwapRouter` is not present in this repository (only ABI/bytecode bindings exist), so this analysis relies on the decompiled runtime bytecode; the `Owner`/`RenounceOwnership`/`TransferOwnership` functions in the ABI confirm this is an `Ownable`-style singly-privileged admin contract [7](#0-6) [8](#0-7) .

### Impact Explanation
Since the router is the designated settlement contract for every gasless swap on the chain (its address is discovered on-chain via `MultiCallGaslessInfo` and trusted by the node's gasless tx-pool/bundling logic), any KAIA balance sitting in it — whether legitimate accrued commission from many unrelated users' swaps, or residual/leftover funds from slippage/rounding in `swapForGas` — can be withdrawn in one shot by a single privileged account. This centralizes custody of funds that are effectively "in flight" or owed across many gasless users into a single admin key, which is a rug-pull vector consistent with the referenced Sherlock finding's "Centralisation Risk" class (admin can withdraw all funds in the contract, not just its own share).

### Likelihood Explanation
The `claimCommission` path is only reachable by the contract owner, so it does not by itself constitute a vulnerability an unprivileged gasless user, bidder, or RPC caller can trigger. However, because the router is a core piece of the in-scope gasless settlement pipeline (reachable indirectly by any user submitting a `swapForGas` transaction whose commission/residual balance accumulates in this single contract), the concentration of unrelated users' funds under one non-tracked, fully-sweepable balance is the direct root cause matched to the reported bug class. Exploitation likelihood depends entirely on the trustworthiness of the current owner key; no on-chain mechanism (timelock, multisig enforcement, or accrued-commission accounting) mitigates it based on what's visible in this repository.

### Recommendation
Track commission accrual in a dedicated state variable incremented per-swap (matching the `commission` value emitted in `SwappedForGas`) and have `claimCommission()` transfer only that tracked amount (resetting it to zero), instead of sweeping `address(this).balance`. Additionally, ensure `swapForGas` never leaves user-owed principal in the contract (fully forward `finalUserAmount` before returning) so that no non-commission KAIA can ever be co-mingled with the withdrawable admin balance.

### Proof of Concept
1. Multiple users execute `approve` + `swapForGas` gasless transactions through the registered `GaslessSwapRouter`; each swap accrues a `commission` cut into the contract's native balance as emitted by `SwappedForGas` [9](#0-8) .
2. If any leftover/undelivered KAIA also lands in the contract (via `receive()` or rounding in the swap-and-repay logic) [6](#0-5) , it is indistinguishable from commission because `claimCommission()` reads `SELFBALANCE` directly rather than a segregated counter [4](#0-3) .
3. The owner calls `claimCommission()` (`0xfad99f98`), which forwards the router's entire native balance to itself in one transaction [5](#0-4) , draining any commingled user-owed value along with legitimate commission.

Note: Because the `.sol` source for `GaslessSwapRouter` is not indexed in this repository (only the compiled ABI/bytecode bindings under `contracts/bindings/kip247/GaslessSwapRouter.go`), exact variable names and whether a separate commission accounting variable exists elsewhere could not be fully confirmed from decompiled bytecode alone. Starting a full Devin session with filesystem access would allow decompiling/verifying the exact bytecode logic or locating the original Solidity source if it exists outside the indexed portions of the repo.

func getGaslessInfo(bc backends.BlockChainForCaller, header *types.Header) (common.Address, []common.Address, error) {
	statedb, err := bc.StateAt(header.Root)
	if err != nil {
		return common.Address{}, nil, err
	}

	// If Registry is not installed, do not query GaslessSwapRouter contract.
	if statedb.GetCode(system.RegistryAddr) == nil || bc.Config().IsRandaoForkBlockParent(header.Number) {
		return common.Address{}, nil, nil
	}

	caller, err := system.NewMultiCallContractCaller(statedb, bc, header)
	if err != nil {
		return common.Address{}, nil, err
	}

	opts := &bind.CallOpts{BlockNumber: header.Number}
	info, err := caller.MultiCallGaslessInfo(opts)

	return info.Gsr, info.Tokens, err
}
