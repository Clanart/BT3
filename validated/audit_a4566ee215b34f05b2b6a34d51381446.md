Based on my investigation, I found a genuine, reachable race-condition analog to the CVE's bug class — an unlocked, security-relevant field read that races against a concurrent locked write, in the exact style of the CVE's "check performed without holding the relevant mutex, permitting state to change between check and use."

### Title
Unsynchronized read of `auctionEntryPointVersion` in `BidPool.getBidTxGasLimit` races with `updateAuctionInfo`, producing non-deterministic bid-tx calldata/gas encoding - ([File: kaiax/auction/impl/bid_pool.go])

### Summary
`BidPool.getBidTxGasLimit` reads `bp.bidTxGasBuffer` under `auctionInfoMu.RLock()`, but then reads `bp.auctionEntryPointVersion` completely outside the lock to build the auction call data. `updateAuctionInfo`, invoked from `PostInsertBlock` on every block that changes the on-chain `AuctionEntryPoint`/version/auctioneer, writes all of these fields together under `auctionInfoMu.Lock()`. Any bidder-triggered `AddBid` call that races with a block-boundary `updateAuctionInfo` call can read a version string that is inconsistent with the atomically-read gas buffer, or — because Go string reads/writes are not atomic — can observe a torn value of `auctionEntryPointVersion` while it is being reassigned.

### Finding Description
`getBidTxGasLimit` is reachable from any unprivileged auction bidder/searcher submitting a bid (`auction_submitBid` RPC or p2p `HandleBid` → `AddBid`): [1](#0-0) 

Meanwhile `updateAuctionInfo` mutates the same fields (including `auctionEntryPointVersion`) under the write lock, triggered by every new block once the Randao fork is active: [2](#0-1) [3](#0-2) 

This is structurally identical to the CVE's bug class: a permission/consistency check is protected by a lock for part of its data (`bidTxGasBuffer`), but a security-relevant companion value (`auctionEntryPointVersion`, which selects the ABI/typehash used to encode the auction call — see `system.EncodeAuctionCallData`) is read without holding that same lock, so the "checked" state and the state actually used to build the transaction can diverge if a concurrent writer runs in between — exactly the same "check under one context, act under another, changed context" race pattern as `perf_event_open()`'s unlocked `ptrace_may_access()` versus the later privileged attach.

### Impact Explanation
Because `bp.auctionEntryPointVersion` is read unsynchronized while it can be concurrently written by the block-processing goroutine, two things can happen: (1) the generated `BidTx` calldata can be encoded against a different `AuctionEntryPoint` ABI/typehash version than the one actually active on-chain at settlement time, causing the bid to be miscomputed or rejected inconsistently, and (2) because Go does not guarantee atomicity of unsynchronized string reads, a torn/inconsistent value could be observed, producing non-deterministic behavior in the resulting `BidTx` between two honest nodes racing this same code path around the same block boundary, contributing to state divergence in gasless/auction settlement.

### Likelihood Explanation
Every accepted bid on any block that also happens to change the `AuctionEntryPoint` registry entry, its version, the auctioneer, or `bidTxGasBuffer` triggers this race window. Any external bidder can trigger `AddBid` at will (via RPC/P2P), and `updateAuctionInfo` fires on every `PostInsertBlock` post-Randao, so the race window recurs on essentially every block once auctions are active, making it easy to hit in practice (this is also the exact style of race the codebase's own `race_test.go` acknowledges elsewhere for transaction fields).

### Recommendation
Read `bp.auctionEntryPointVersion` (and any other fields needed for consistent calldata encoding) under the same `auctionInfoMu.RLock()` critical section as `bp.bidTxGasBuffer` in `getBidTxGasLimit`, mirroring the pattern already used in `validateBidSigs`.

### Proof of Concept
1. Node has an active auction (`AuctionEntryPoint`/version/auctioneer set).
2. Governance/registry updates `AuctionEntryPoint` version in the block N→N+1 transition; `PostInsertBlock` calls `updateAuctionInfo`, acquiring `auctionInfoMu.Lock()` and reassigning `auctioneer`, `auctionEntryPoint`, `auctionEntryPointVersion`, `bidTxGasBuffer`.
3. Concurrently, an external searcher submits a bid via `auction_submitBid`/`HandleBid`, hitting `AddBid` → `getBidTxGasLimit`, which reads `bidTxGasBuffer` under lock but then reads `bp.auctionEntryPointVersion` without any lock.
4. If this read interleaves with step 2's write, `EncodeAuctionCallData` is invoked with a version value inconsistent with the buffer just read (or a torn string), producing calldata/gas-limit combinations that differ from what a node executing the race slightly earlier or later would produce for logically the same bid. func (bp *BidPool) updateAuctionInfo(auctioneer common.Address, auctionEntryPoint common.Address, auctionEntryPointVersion string, bidTxGasBuffer uint64) {
	bp.auctionInfoMu.Lock()
	defer bp.auctionInfoMu.Unlock()

	if bp.auctioneer == auctioneer && bp.auctionEntryPoint == auctionEntryPoint && bp.auctionEntryPointVersion == auctionEntryPointVersion && bp.bidTxGasBuffer == bidTxGasBuffer {
		return
	}

	// Clear the existing auction pool since the auctioneer or auction entry point address is changed.
	bp.clearBidPool()

	bp.auctioneer = auctioneer
	bp.auctionEntryPoint = auctionEntryPoint
	bp.auctionEntryPointVersion = auctionEntryPointVersion
	bp.bidTxGasBuffer = bidTxGasBuffer

	logger.Info("Update auction info", "auctioneer", auctioneer, "auctionEntryPoint", auctionEntryPoint, "auctionEntryPointVersion", auctionEntryPointVersion, "bidTxGasBuffer", bidTxGasBuffer)
}

func (bp *BidPool) getBidTxGasLimit(bid *auction.Bid) (uint64, error) {
	bp.auctionInfoMu.RLock()
	buffer := bp.bidTxGasBuffer
	bp.auctionInfoMu.RUnlock()

	data, err := system.EncodeAuctionCallData(bid, bp.auctionEntryPointVersion)
	if err != nil {
		return 0, err
	}

	rules := bp.ChainConfig.Rules(big.NewInt(int64(bid.BlockNumber)))
	intrinsicGas, err := types.IntrinsicGas(data, nil, nil, false, rules)
	if err != nil {
		return 0, err
	}
	floorDataGas := uint64(0)
	if rules.IsPrague {
		floorDataGas, err = blockchain.FloorDataGas(types.TxTypeEthereumDynamicFee, data, 0)
		if err != nil {
			return 0, err
		}
	}

	return max(intrinsicGas+bid.CallGasLimit+buffer, floorDataGas), nil
}

func (a *AuctionModule) PostInsertBlock(block *types.Block) error {
	if a.Downloader.Synchronising() || !a.ChainConfig.IsRandaoForkEnabled(block.Number()) {
		atomic.CompareAndSwapUint32(&a.bidPool.running, 1, 0)
		return nil
	}

	if !a.updateAuctionInfo(block.Number()) {
		logger.Debug("stop auction since auctioneer or auction entry point is not set")
		atomic.CompareAndSwapUint32(&a.bidPool.running, 1, 0)
		return nil
	}

	atomic.CompareAndSwapUint32(&a.bidPool.running, 0, 1)

	txHashMap := make(map[common.Hash]struct{})
	for _, tx := range block.Transactions() {
		txHashMap[tx.Hash()] = struct{}{}
	}
	a.bidPool.removeOldBids(block.Number().Uint64(), txHashMap)

	return nil
}
