Confirmed: `source_digest` never appears in the native `code.rs` publish request validation nor in `aptos_vm.rs::validate_publish_request` — it is only used as an opaque metadata field compared in the CLI's `verify()` function, never checked against actual bytecode by the chain itself.### Title
`aptos move verify-package` never checks actual on-chain bytecode against `PackageMetadata`, letting published modules diverge from advertised source with no on-chain root of trust to catch it - (File: `aptos-move/cli/src/stored_package.rs`)

### Summary
Aptos's on-chain publish path (`aptos_framework::code::publish_package`) stores a `PackageMetadata` struct — including a `source_digest` and per-module `source`/`source_map` fields — that is supplied entirely by the publisher and is never cryptographically bound to the actual bytecode being published. The only tool meant to give third parties assurance that on-chain bytecode matches claimed source, `aptos move verify-package`, does not download or hash the real on-chain bytecode at all; it only compares two `PackageMetadata` structs (one rebuilt locally, one read from chain).

### Finding Description
The publish flow in Move (`aptos-move/framework/aptos-framework/sources/code.move`) takes a publisher-provided `pack: PackageMetadata` (containing `source_digest: String` and `modules: vector<ModuleMetadata>` with `source`/`source_map`) together with `code: vector<vector<u8>>` (the actual bytecode) and stores `pack` verbatim in `PackageRegistry`: [1](#0-0) 

Neither the Move `publish_package` function nor the native functions it calls (`request_publish` / `request_publish_with_allowed_deps`) ever hash `code` and compare it to `pack.source_digest` or the modules' declared `source`: [2](#0-1) 

On the Rust side, `native_request_publish` in `aptos-move/framework/natives/src/code.rs` only pops `policy`, `code`, `allowed_deps`, `expected_modules`, and `destination` and builds a `PublishRequest` — it never touches `source_digest` or module `source` fields: [3](#0-2) 

`AptosVM::validate_publish_request` (`aptos-move/aptos-vm/src/aptos_vm.rs:1804-1863`) validates module-name registration, allowed dependencies, resource groups, and events — again with no reference to `source_digest` or source text: [4](#0-3) 

The intended external safety net is `aptos move verify-package` (`aptos-move/cli/src/commands.rs`), which is documented as verifying "that on-chain bytecode matches a local compilation of the Move code" (`third_party/move/documentation/book/src/cli-deploy.md:12`). Its implementation calls `CachedPackageRegistry::create(client, self.account, false)` with `with_bytecode = false`: [5](#0-4) 

`CachedPackageRegistry::create` only populates `bytecode` when `with_bytecode` is `true`; with `false` it fetches nothing beyond the `PackageMetadata` resource: [6](#0-5) 

Then `verify()` compares only metadata fields — `name`, `deps`, `modules` (which is the `ModuleMetadata` struct containing gzipped `source`/`source_map`, not the real bytecode), `manifest`, `upgrade_policy`, `extension`, `source_digest` — never the actual on-chain module bytecode: [7](#0-6) 

Because `source_digest` and per-module `source` are self-reported by the publisher and never checked by any on-chain or off-chain code path against the real bytecode, a publisher can submit `code` bytes that differ from the source/metadata they publish alongside it. `verify-package`'s own metadata-vs-metadata comparison will happily report "Successfully verified source of package" even though it never inspected a single byte of the real bytecode.

### Impact Explanation
This breaks the "verified bytes / package metadata / committed module bytes" invariant explicitly called out in the audit gate. Downstream integrators, wallets, or auditors who rely on `verify-package` (or on `CachedPackageRegistry`/`stored_package::verify` as a building block) to confirm that a deployed package matches audited source obtain a false positive: the tool asserts equivalence purely from metadata self-attestation, with no cryptographic tie to the deployed bytecode. This is the direct Aptos analog of the external report's "not IERC4626 compliant" bug class — a claimed conformance/verification mechanism that does not actually enforce what it advertises, and here the consequence is more severe because it undermines code-safety trust for any mainnet package (compatible or immutable upgrade policy included), enabling silent code substitution to go "verified."

### Likelihood Explanation
High for occurrence, since it requires no special privilege — any publisher can submit metadata whose `source`/`source_digest` do not correspond to the `code` bytes they submit; the chain performs no check to prevent this at publish time. The likelihood of exploitation depends on downstream parties trusting `verify-package` output; given it's a documented, first-class CLI feature (`cli-deploy.md`) intended specifically for "code review and reproducibility," reliance is plausible and the deception is silent (no error, differing hash requirements, or anomalies surfaced to the caller).

### Recommendation
1. Change `VerifyPackage::execute` to always call `CachedPackageRegistry::create(client, self.account, true)` and add a bytecode-equality check (e.g., `registry.get_bytecode(module_name)` compared byte-for-byte against the locally compiled module) to `verify()`, not just metadata equality.
2. Consider enforcing on-chain, in `code::publish_package`/native `request_publish`, that `source_digest` is computed from the actual submitted `code` bytes (or drop the field's advertised "sha256 of sources" semantics if it cannot be tied to bytecode) so metadata cannot silently diverge from what is executed.
3. Update `stored_package::verify` to explicitly document/limit its guarantee ("this only compares metadata, not bytecode") if the fetch-bytecode fix is not adopted, to avoid downstream over-trust.

### Proof of Concept
1. Build package A with benign source `S_good`; compute its true `PackageMetadata` (`modules[i].source`, `source_digest`) from `S_good`.
2. Compile a different, malicious module set `code_evil` (arbitrary bytecode, same module names/signatures needed to satisfy `expected_modules`/compatibility checks).
3. Publish `code_evil` via `code::publish_package(owner, metadata_from_S_good, code_evil)` — this succeeds because neither the Move framework (`code.move`) nor the native (`code.rs`) nor `AptosVM::validate_publish_request` cross-checks `code_evil` bytes against `metadata_from_S_good.source_digest`/`modules[i].source`.
4. A third party runs `aptos move verify-package --account <addr>` against locally-built `S_good`. `CachedPackageRegistry::create(..., false)` fetches only the on-chain `PackageMetadata` (matching `metadata_from_S_good`), and `verify()` compares it field-by-field to the locally rebuilt metadata from `S_good` — all fields match since the metadata was never altered, only the bytecode was swapped. The command reports `"Successfully verified source of package"` even though the deployed bytecode is `code_evil`, not derived from `S_good`.

fn native_request_publish(
    context: &mut SafeNativeContext,
    _ty_args: &[Type],
    mut args: VecDeque<Value>,
) -> SafeNativeResult<SmallVec<[Value; 1]>> {
    debug_assert!(matches!(args.len(), 4 | 5));
    let with_allowed_deps = args.len() == 5;

    context.charge(CODE_REQUEST_PUBLISH_BASE)?;

    let policy = safely_pop_arg!(args, u8);
    let mut code = vec![];
    for module in safely_pop_arg!(args, Vec<Value>) {
        let module_code = module.value_as::<Vec<u8>>()?;

        context.charge(CODE_REQUEST_PUBLISH_PER_BYTE * NumBytes::new(module_code.len() as u64))?;
        code.push(module_code);
    }

    let allowed_deps = if with_allowed_deps {
        let mut allowed_deps: BTreeMap<AccountAddress, BTreeSet<String>> = BTreeMap::new();

        for dep in safely_pop_arg!(args, Vec<Value>) {
            let (account, module_name) = unpack_allowed_dep(dep)?;

            let entry = allowed_deps.entry(account);

            if let Entry::Vacant(_) = &entry {
                // TODO: Is the 32 here supposed to indicate the length of an account address in bytes?
                context.charge(CODE_REQUEST_PUBLISH_PER_BYTE * NumBytes::new(32))?;
            }

            context
                .charge(CODE_REQUEST_PUBLISH_PER_BYTE * NumBytes::new(module_name.len() as u64))?;
            entry.or_default().insert(module_name);
        }

        Some(allowed_deps)
    } else {
        None
    };

    let mut expected_modules = BTreeSet::new();
    for name in safely_pop_arg!(args, Vec<Value>) {
        let str = get_move_string(name)?;

        // TODO(Gas): fine tune the gas formula
        context.charge(CODE_REQUEST_PUBLISH_PER_BYTE * NumBytes::new(str.len() as u64))?;
        expected_modules.insert(str);
    }

    let destination = safely_pop_arg!(args, AccountAddress);

    // Add own modules to allowed deps
    let allowed_deps = allowed_deps.map(|mut allowed| {
        allowed
            .entry(destination)
            .or_default()
            .extend(expected_modules.clone());
        allowed
    });

    let code_context = context.extensions_mut().get_mut::<NativeCodeContext>();
    if code_context.requested_module_bundle.is_some() || !code_context.enabled {
        // Can't request second time or if publish requests are not allowed.
        return Err(SafeNativeError::abort(EALREADY_REQUESTED));
    }
    code_context.requested_module_bundle = Some(PublishRequest {
        destination,
        bundle: ModuleBundle::new(code),
        expected_modules,
        allowed_deps,
        check_compat: policy != ARBITRARY_POLICY,
    });

    Ok(smallvec![])
}

    /// Validate a publish request.
    fn validate_publish_request(
        &self,
        module_storage: &impl AptosModuleStorage,
        traversal_context: &mut TraversalContext,
        gas_meter: &mut impl GasMeter,
        modules: &[CompiledModule],
        mut expected_modules: BTreeSet<String>,
        allowed_deps: Option<BTreeMap<AccountAddress, BTreeSet<String>>>,
    ) -> VMResult<()> {
        self.reject_unstable_bytecode(modules)?;
        native_validation::validate_module_natives(modules)?;

        for m in modules {
            if !expected_modules.remove(m.self_id().name().as_str()) {
                return Err(Self::metadata_validation_error(&format!(
                    "unregistered module: '{}'",
                    m.self_id().name()
                )));
            }
            if let Some(allowed) = &allowed_deps {
                for dep in m.immediate_dependencies() {
                    if !allowed
                        .get(dep.address())
                        .map(|modules| {
                            modules.contains("") || modules.contains(dep.name().as_str())
                        })
                        .unwrap_or(false)
                    {
                        return Err(Self::metadata_validation_error(&format!(
                            "unregistered dependency: '{}'",
                            dep
                        )));
                    }
                }
            }
            verify_module_metadata_for_module_publishing(m, self.features())
                .map_err(|err| Self::metadata_validation_error(&err.to_string()))?;
        }

        resource_groups::validate_resource_groups(
            self.features(),
            module_storage,
            traversal_context,
            gas_meter,
            modules,
        )?;
        event_validation::validate_module_events(
            self.features(),
            module_storage,
            traversal_context,
            modules,
        )?;

        if !expected_modules.is_empty() {
            return Err(Self::metadata_validation_error(
                "not all registered modules published",
            ));
        }
        Ok(())
    }

impl CachedPackageRegistry {
    /// Creates a new registry.
    pub async fn create(
        client: Client,
        addr: AccountAddress,
        with_bytecode: bool,
    ) -> anyhow::Result<Self> {
        // Need to use a different type to deserialize JSON
        let inner = client
            .get_account_resource_bcs::<PackageRegistry>(addr, "0x1::code::PackageRegistry")
            .await?
            .into_inner();
        let mut bytecode = BTreeMap::new();
        if with_bytecode {
            for pack in &inner.packages {
                for module in &pack.modules {
                    let bytes = client
                        .get_account_module(addr, &module.name)
                        .await?
                        .into_inner()
                        .bytecode
                        .0;
                    bytecode.insert(module.name.clone(), bytes);
                }
            }
        }
        Ok(Self { inner, bytecode })
    }

    pub fn verify(&self, package_metadata: &PackageMetadata) -> anyhow::Result<()> {
        let self_metadata = self.metadata;

        if self_metadata.name != package_metadata.name {
            bail!(
                "Package name doesn't match {} : {}",
                package_metadata.name,
                self_metadata.name
            )
        } else if self_metadata.deps != package_metadata.deps {
            bail!(
                "Dependencies don't match {:?} : {:?}",
                package_metadata.deps,
                self_metadata.deps
            )
        } else if self_metadata.modules != package_metadata.modules {
            bail!(
                "Modules don't match {:?} : {:?}",
                package_metadata.modules,
                self_metadata.modules
            )
        } else if self_metadata.manifest != package_metadata.manifest {
            bail!(
                "Manifest doesn't match {:?} : {:?}",
                package_metadata.manifest,
                self_metadata.manifest
            )
        } else if self_metadata.upgrade_policy != package_metadata.upgrade_policy {
            bail!(
                "Upgrade policy doesn't match {:?} : {:?}",
                package_metadata.upgrade_policy,
                self_metadata.upgrade_policy
            )
        } else if self_metadata.extension != package_metadata.extension {
            bail!(
                "Extensions doesn't match {:?} : {:?}",
                package_metadata.extension,
                self_metadata.extension
            )
        } else if self_metadata.source_digest != package_metadata.source_digest {
            bail!(
                "Source digests doesn't match {:?} : {:?}",
                package_metadata.source_digest,
                self_metadata.source_digest
            )
        }

        Ok(())
    }
