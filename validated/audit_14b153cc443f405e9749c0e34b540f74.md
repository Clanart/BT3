### Title
Missing capacity check in `ReceivedCacheEntry::record`'s "timely" branch allows unbounded per-origin node map growth — ([File: gossip/src/received_cache.rs])

### Summary
The report's broken invariant is: *a fixed-capacity slot list combined with an admission/eviction check that is not actually enforced on every insertion path, letting an attacker fill (or in this case, unboundedly grow) the structure at near-zero cost.* The Agave analog is `ReceivedCacheEntry::record` in `gossip/src/received_cache.rs`, where the per-origin `nodes: HashMap<Pubkey, usize>` is supposed to be bounded by `CAPACITY = 50`, but the bound is only enforced on one of the two insertion branches. [1](#0-0) 

### Finding Description
`ReceivedCache` tracks, per gossip-message *origin*, which relaying nodes forwarded that origin's CRDS values and how "timely" they were, in order to later compute a prune set for redundant gossip push paths. The comment on `ReceivedCacheEntry::CAPACITY` explicitly states the intent:

> "Limit how big the cache can get if it is spammed with old messages with random pubkeys." [2](#0-1) 

But `record()` only applies that limit in the `else` branch (late/duplicate deliveries, `num_dups >= NUM_DUPS_THRESHOLD`):

```rust
fn record(&mut self, node: Pubkey, num_dups: usize) {
    if num_dups == 0 {
        self.num_upserts = self.num_upserts.saturating_add(1);
    }
    // If the message has been timely enough increment node's score.
    if num_dups < Self::NUM_DUPS_THRESHOLD {
        let score = self.nodes.entry(node).or_default();
        *score = score.saturating_add(1);
    } else if self.nodes.len() < Self::CAPACITY {
        let _ = self.nodes.entry(node).or_default();
    }
}
``` [3](#0-2) 

In the "timely" branch (`num_dups < NUM_DUPS_THRESHOLD`, i.e. this is the first or second time this specific value/origin pair has been seen), `self.nodes.entry(node).or_default()` unconditionally inserts a new key into the `HashMap` with no capacity check whatsoever. `num_dups` is per-value (it resets to 0 for every newly-seen, distinct CRDS value from a given origin), and `node` is the "from" field carried in the outer push-message envelope, which is not otherwise bound to any stake, key ownership check, or connection identity beyond being an arbitrary pubkey declared by the sender. An attacker can therefore:

1. Pick or reuse any legitimately signed CRDS value(s) for an origin (or generate many distinct values under disposable keypairs — signing cost is free).
2. Wrap each as a push message, each time declaring a different, arbitrary "from" pubkey (attacker does not need to own or stake that pubkey).
3. Every such delivery is "the first copy" of a distinct value, so `num_dups == 0 < NUM_DUPS_THRESHOLD`, hitting the unbounded branch.

Each such delivery adds a new entry to the per-origin `nodes` HashMap with no upper bound — unlike the crds table (`gossip/src/crds.rs`, `trim`/`drop`) or the duplicate-shred buffer (`gossip/src/duplicate_shred_handler.rs`, `maybe_prune_buffer`), both of which enforce a hard capacity and evict by stake regardless of path. Here the guard exists in name (`CAPACITY = 50`) but is bypassed by design for the "good" code path, exactly mirroring the Audius bug where a capacity guard (`maxDelegators`) was real, but an orthogonal check (aggregate `minDelegationAmount`) failed to prevent cheap dust admission through the intended gate.

### Impact Explanation
This is unprivileged, remotely triggerable memory growth in a core gossip-service data structure (no malicious-peer/validator/trusted-plugin assumption required — any UDP sender reachable by gossip can trigger it). Sustained abuse across many distinct origins/values causes unbounded heap growth in `ReceivedCache`, which is held by the gossip service for pruning decisions; this can degrade or crash a validator's gossip subsystem (non-RPC remote exhaustion), which falls within the accepted impact categories (non-RPC remote exhaustion/crash).

### Likelihood Explanation
The attack primitive requires no stake, no privileged key, and no interaction with peers/validators beyond sending gossip packets — an inherent property of the exploited branch is that legitimate/first-copy deliveries are never capacity-checked. Cost to the attacker is bounded only by their own bandwidth/CPU to mint distinct CRDS values and vary the "from" field, which is comparable to the ~17.5k-AUD-equivalent low-cost attack in the original report (here effectively free, since no funds/stake are required at all).

### Recommendation
Enforce `CAPACITY` uniformly across both branches of `ReceivedCacheEntry::record`, e.g. check `self.nodes.len() < Self::CAPACITY` (or perform stake-aware eviction, mirroring `crds.rs::drop`) before inserting in the "timely" branch as well, so the invariant "at most `CAPACITY` nodes tracked per origin" cannot be bypassed by any insertion path.

### Proof of Concept
Conceptual/local-evidence PoC (unit-test style, no live network needed):
1. Construct a `ReceivedCache` and, for a single `origin`, call `record(origin, node_i, 0)` for `i` in `0..N` with `N >> ReceivedCacheEntry::CAPACITY (50)`, using distinct fresh `Pubkey::new_unique()` values for `node_i` — no keypair signing or stake required to construct this call.
2. Observe that `cache.0.get(&origin).unwrap().nodes.len() == N`, i.e., unbounded, in contrast to feeding `num_dups = Self::NUM_DUPS_THRESHOLD` (or higher) which is correctly capped at 50 (as validated by the branch at [4](#0-3) ).
3. In the live gossip path, `record` is invoked from `crds_gossip_push.rs` per received push-message value with the caller-supplied duplicate count; since `num_dups` is computed per distinct CRDS value (not per sender), an attacker replaying distinct signed values while varying the declared "from" pubkey in the push envelope reproduces step 1 remotely. [5](#0-4)

```rust
use {
    itertools::Itertools,
    lazy_lru::LruCache,
    solana_pubkey::Pubkey,
    std::{cmp::Reverse, collections::HashMap},
};

// For each origin, tracks which nodes have sent messages from that origin and
// their respective score in terms of timeliness of delivered messages.
pub(crate) struct ReceivedCache(LruCache</*origin/owner:*/ Pubkey, ReceivedCacheEntry>);

#[derive(Clone, Default)]
struct ReceivedCacheEntry {
    nodes: HashMap<Pubkey, /*score:*/ usize>,
    num_upserts: usize,
}

impl ReceivedCache {
    // Minimum number of upserts before a cache entry can be pruned.
    const MIN_NUM_UPSERTS: usize = 20;

    pub(crate) fn new(capacity: usize) -> Self {
        Self(LruCache::new(capacity))
    }

    pub(crate) fn record(&mut self, origin: Pubkey, node: Pubkey, num_dups: usize) {
        match self.0.get_mut(&origin) {
            Some(entry) => entry.record(node, num_dups),
            None => {
                let mut entry = ReceivedCacheEntry::default();
                entry.record(node, num_dups);
                self.0.put(origin, entry);
            }
        }
    }

    pub(crate) fn prune(
        &mut self,
        pubkey: &Pubkey, // This node.
        origin: Pubkey,  // CRDS value owner.
        stake_threshold: f64,
        min_ingress_nodes: usize,
        stakes: &HashMap<Pubkey, u64>,
    ) -> impl Iterator<Item = Pubkey> + use<> {
        match self.0.get_mut(&origin) {
            None => None,
            Some(entry) if entry.num_upserts < Self::MIN_NUM_UPSERTS => None,
            Some(entry) => Some(
                std::mem::take(entry)
                    .prune(pubkey, &origin, stake_threshold, min_ingress_nodes, stakes)
                    .filter(move |node| node != &origin),
            ),
        }
        .into_iter()
        .flatten()
    }

    #[cfg(test)]
    fn mock_clone(&mut self) -> Self {
        Self(self.0.clone())
    }
}

impl ReceivedCacheEntry {
    // Limit how big the cache can get if it is spammed
    // with old messages with random pubkeys.
    const CAPACITY: usize = 50;
    // Threshold for the number of duplicates before which a message
    // is counted as timely towards node's score.
    const NUM_DUPS_THRESHOLD: usize = 2;

    fn record(&mut self, node: Pubkey, num_dups: usize) {
        if num_dups == 0 {
            self.num_upserts = self.num_upserts.saturating_add(1);
        }
        // If the message has been timely enough increment node's score.
        if num_dups < Self::NUM_DUPS_THRESHOLD {
            let score = self.nodes.entry(node).or_default();
            *score = score.saturating_add(1);
        } else if self.nodes.len() < Self::CAPACITY {
            // Ensure that node is inserted into the cache for later pruning.
            // This intentionally does not negatively impact node's score, in
            // order to prevent replayed messages with spoofed addresses force
            // pruning a good node.
            let _ = self.nodes.entry(node).or_default();
        }
    }

    fn prune(
        self,
        pubkey: &Pubkey, // This node.
        origin: &Pubkey, // CRDS value owner.
        stake_threshold: f64,
        min_ingress_nodes: usize,
        stakes: &HashMap<Pubkey, u64>,
    ) -> impl Iterator<Item = Pubkey> + use<> {
        debug_assert!((0.0..=1.0).contains(&stake_threshold));
        debug_assert!(self.num_upserts >= ReceivedCache::MIN_NUM_UPSERTS);
        // Enforce a minimum aggregate ingress stake; see:
        // https://github.com/solana-labs/solana/issues/3214
        let min_ingress_stake = {
            let stake = stakes.get(pubkey).min(stakes.get(origin));
            (stake.copied().unwrap_or_default() as f64 * stake_threshold) as u64
        };
        self.nodes
            .into_iter()
            .map(|(node, score)| {
                let stake = stakes.get(&node).copied().unwrap_or_default();
                (node, score, stake)
            })
            .sorted_unstable_by_key(|&(_, score, stake)| Reverse((score, stake)))
            .scan(0u64, |acc, (node, _score, stake)| {
                let old = *acc;
                *acc = acc.saturating_add(stake);
                Some((node, old))
            })
            .skip(min_ingress_nodes)
            .skip_while(move |&(_, stake)| stake < min_ingress_stake)
            .map(|(node, _stake)| node)
    }
}
```
