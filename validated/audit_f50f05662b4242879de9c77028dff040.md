### Title
Missing local response-receipt check in `HandlerV2.handleGetRequestTimeouts` allows duplicate GET request settlement via stale-height non-membership proof - (File: `evm/src/core/HandlerV2.sol`)

### Summary
`HandlerV2.handleGetRequestTimeouts` verifies that a GET request has timed out solely by proving non-membership of a response receipt against a state root the caller picks (`message.height`) on the destination chain, with no check of the EVM host's own `responseReceipts` mapping. This differs from the equivalent Substrate implementation, which explicitly rejects a timeout once a response has actually been received locally.

### Finding Description
In `HandlerV2.handleGetRequestTimeouts`: [1](#0-0) 

the function:
1. Fetches an arbitrary, caller-chosen `message.height`'s `StateCommitment` from `host.stateMachineCommitment(message.height)`.
2. Checks `request.timeout() > state.timestamp` using that height's timestamp (not the current/latest state).
3. Checks `host.requestCommitments(commitment).sender != address(0)` — this is `_requestCommitments`, which is only deleted by `dispatchTimeOut`, **not** by `dispatchIncoming(GetResponse)`: [2](#0-1) 
So after a legitimate `GetResponse` is delivered via `handleGetResponses`/`dispatchIncoming`, `_requestCommitments[commitment]` is still populated, and this check still passes.
4. Verifies a non-membership proof of `RESPONSE_RECEIPTS_STORAGE_PREFIX + commitment` against the state root of the **caller-selected** `message.height` — i.e., a proof of the destination chain's own receipt store at a point in time chosen by the attacker.
5. Calls `host.dispatchTimeOut(GetRequestTimeout(...))`, which only performs "replay protection" by deleting `_requestCommitments[commitment]`: [3](#0-2) 

Nowhere in this path is `host.responseReceipts(commitment)` (the EVM host's own record of whether the GET response was already delivered to this chain) checked. Compare this to the Substrate pallet-ismp implementation of the same message type, which explicitly guards against this: [4](#0-3) 

That Substrate code rejects the timeout with `GetResponseAlreadyReceived` if a response was already received — checked against the *local, current* host state, not a proof rooted at an arbitrary past height. `HandlerV2.sol` has no equivalent guard.

Since `state.stateRoot`/`state.timestamp` are looked up by an arbitrary `message.height` that the caller supplies (as long as a commitment exists there and the challenge period for that height has elapsed), and old `StateCommitment` entries are not proactively invalidated once superseded, an attacker can select a height whose timestamp already exceeds the request's timeout but which predates the destination chain's actual response-receipt write. The non-membership proof against that stale root is cryptographically valid (true for that historical root) even though a response has since been generated and already delivered on the source chain via a later height/proof.

### Impact Explanation
This allows both `onGetResponse()` and `onGetTimeout()` to be invoked for the same GET request against a downstream application (`host.dispatchIncoming` and `host.dispatchTimeOut` are independent, permissionless call paths gated by different, non-overlapping checks). Applications built on the assumption that exactly one of these callbacks fires per request (as implied by the protocol's ISMP semantics and enforced on the Substrate side) can have state corrupted, be double-refunded, double-triggered, or driven into inconsistent bookkeeping — a duplicate/erroneous execution outcome, matching the "replay/double-claim/double-settlement" and "false proof/state acceptance" impact categories.

### Likelihood Explanation
The call is fully permissionless: any address can call `handleGetRequestTimeouts` supplying any previously-recorded height for the destination chain (as long as the challenge period has passed) together with a matching non-membership proof. No relayer collusion or privileged access is needed — the attacker just needs to obtain the correct storage proof for an older, already-superseded state root and the request/response data, both of which are public.

### Recommendation
Add an explicit local check in `handleGetRequestTimeouts` (mirroring `modules/ismp/core/src/handlers/timeout.rs`) that rejects the timeout if `host.responseReceipts(commitment).relayer != address(0)`, i.e., if the GET response has already been recorded as delivered on this host — regardless of which height's proof is used. Additionally, consider requiring `message.height` to be at or after the latest known committed height for that state machine (or otherwise binding the non-membership check to the most recent trusted state) so a stale/superseded root cannot be used to "prove" a fact that is no longer true.

### Proof of Concept
1. Dispatch a `GetRequest` from the EVM host with a timeout `T`.
2. Wait until the destination chain processes the query and produces the response; the response is committed at destination height `H2` (`H2`'s timestamp/response-receipt reflects it exists).
3. Relayer delivers the response via `handleGetResponses`, which calls `host.dispatchIncoming(response, relayer)`, setting `_responseReceipts[commitment]` — but leaving `_requestCommitments[commitment]` intact.
4. Attacker fetches an earlier already-stored `StateCommitment` at height `H1 < H2` where `H1.timestamp > T` (timeout already elapsed at H1) but where the response receipt for the request did not yet exist in destination state at `H1`.
5. Attacker builds a non-membership `PolkadotTrie` proof for `RESPONSE_RECEIPTS_STORAGE_PREFIX + commitment` rooted at `H1.stateRoot` and calls `handleGetRequestTimeouts(host, GetTimeoutMessage{timeouts: [request], height: H1, proof})`.
6. The check `request.timeout() > state.timestamp` passes (timeout already elapsed at `H1`); `host.requestCommitments(commitment).sender != 0` still passes (not deleted by the earlier response delivery); the non-membership proof against `H1.stateRoot` verifies successfully.
7. `host.dispatchTimeOut(GetRequestTimeout(...))` executes, invoking `onGetTimeout()` on the application even though `onGetResponse()` was already invoked for the same request — demonstrating duplicate settlement.

    function handleGetRequestTimeouts(IHost host, GetTimeoutMessage calldata message) external notFrozen(host) {
        uint256 delay = block.timestamp - host.stateMachineCommitmentUpdateTime(message.height);
        uint256 challengePeriod = host.challengePeriod();
        if (challengePeriod != 0 && challengePeriod > delay) revert ChallengePeriodNotElapsed();

        // fetch the state commitment
        StateCommitment memory state = host.stateMachineCommitment(message.height);
        if (state.stateRoot == bytes32(0)) revert StateCommitmentNotFound();
        uint256 timeoutsLength = message.timeouts.length;

        for (uint256 i = 0; i < timeoutsLength; ++i) {
            GetRequest memory request = message.timeouts[i];
            // timed-out?
            if (request.timeout() > state.timestamp) revert MessageNotTimedOut();

            bytes32 commitment = request.hash();
            FeeMetadata memory meta = host.requestCommitments(commitment);
            if (meta.sender == address(0)) revert UnknownMessage();

            bytes[] memory keys = new bytes[](1);
            keys[0] = bytes.concat(RESPONSE_RECEIPTS_STORAGE_PREFIX, commitment);

            // verify state trie non-membership proofs
            PolkadotTrie.StorageValue memory entry = PolkadotTrie.VerifyProof(state.stateRoot, message.proof, keys)[0];
            if (entry.value.length != 0) revert InvalidProof();

            host.dispatchTimeOut(GetRequestTimeout(request, _msgSender()), meta, commitment);
        }
    }

    function dispatchIncoming(GetResponse memory response, address relayer) external restrict(_hostParams.handler) {
        // replay protection
        bytes32 commitment = response.request.hash();
        _responseReceipts[commitment] = ResponseReceipt({
            relayer: relayer,
            responseCommitment: response.hash()
        });

        (bool success,) = _bytesToAddress(response.request.from)
            .call(abi.encodeWithSelector(IApp.onGetResponse.selector, IncomingGetResponse(response, relayer)));

        if (!success) {
            // so that it can be retried
            delete _responseReceipts[commitment];
            return;
        }

        // reward the relayer fee
        uint256 fee = _requestCommitments[commitment].fee;
        if (fee != 0) {
            IERC20(feeToken()).safeTransfer(relayer, fee);
        }
        emit GetRequestHandled({commitment: commitment, relayer: relayer});
    }

    function dispatchTimeOut(
        GetRequestTimeout memory timeout,
        FeeMetadata memory meta,
        bytes32 commitment
    ) external restrict(_hostParams.handler) {
        // replay protection
        delete _requestCommitments[commitment];
        (bool success,) = _bytesToAddress(timeout.request.from)
            .call(abi.encodeWithSelector(IApp.onGetTimeout.selector, timeout));

        if (!success) {
            // so that it can be retried
            _requestCommitments[commitment] = meta;
            return;
        }

        if (meta.fee != 0) {
            // refund relayer fee
            IERC20(feeToken()).safeTransfer(meta.sender, meta.fee);
        }
        emit GetRequestTimeoutHandled({commitment: commitment, dest: string(timeout.request.dest)});
    }
