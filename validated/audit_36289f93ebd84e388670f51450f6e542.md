### Title
Unauthenticated exposure of privileged `governance_vote` RPC method allows any public-RPC caller to trigger unauthorized governance parameter changes - (File: kaiax/gov/headergov/impl/api.go)

### Summary
The GLPI advisory describes an incorrect rights check on a privileged, dashboard-modifying endpoint that is reachable by unauthenticated/under-privileged callers. The analogous condition in Kaia is that the `governance_vote` JSON-RPC method — which causes a node to cast a header-governance vote that can alter protocol-critical parameters (unit price/fees, minting amount, KIP-71 base-fee bounds, committee size, etc.) — is registered with `Public: true` and no caller-identity/authorization check, and the RPC endpoint registration logic exposes all `Public: true` namespaces by default whenever no explicit `--http.api`/`--ws.api` module whitelist is configured.

### Finding Description
`headerGovModule.APIs()` registers the `governance` namespace API with `Public: true`: [1](#0-0) 

The `Vote` handler only checks whether the *node's own* identity (`api.h.nodeAddress`) is the governing node in single-mode; it performs no check on who is invoking the RPC call itself: [2](#0-1) 

Because there is no distinction between "trusted local admin caller" and "arbitrary remote RPC caller," any client able to reach the HTTP/WS JSON-RPC endpoint of a node that happens to be the configured `governance.governingnode` can invoke `governance_vote` and have that node queue an on-chain vote using the node's own key/authority — without the caller possessing any credentials of their own.

This is compounded by the RPC module registration logic: if an operator does not explicitly restrict `--http.api`/`--ws.api` modules, every API with `Public: true` (including `governance`) is exposed by default: [3](#0-2) [4](#0-3) 

The vote is later ratified through `checkConsistency`/`VerifyVote`, which validates format and voter identity against the council but does not — and cannot — distinguish "the node's operator intentionally voted" from "an anonymous RPC caller tricked the node into voting": [5](#0-4) [6](#0-5) 

### Impact Explanation
If the governing node's operator exposes a public RPC endpoint (a common and legitimate operational need for e.g. block explorers, monitoring dashboards) without narrowing the module whitelist, an unauthenticated remote caller can direct that node to submit governance votes on its behalf. Because the governing node is the sole vote-arbiter in `single` governance mode, this can let an outside attacker unilaterally change security- and economy-critical parameters — e.g. `governance.unitprice` (fee levels), `reward.mintingamount` / `reward.ratio` (supply/reward distribution), `kip71.*` (base-fee bounds), or committee sizing — once ratified at the next epoch boundary. This maps directly to the required impact classes: fee abuse and reward redirection at the protocol level, achieved purely via a public RPC call with no signature or authorization from the caller.

### Likelihood Explanation
Exploitation requires the target node to (a) be the configured governing node, and (b) expose its `governance` RPC namespace publicly (either via `--http.api governance`/`--ws.api governance`, or by leaving the module whitelist empty, which causes all `Public` APIs to be exposed by default per `StartHTTPEndpoint`/`StartWSEndpoint`). This is a plausible but non-default operational configuration — I could not fully confirm within available tool budget what the *actual* default `--http.api` flag value is set to in `cmd/utils/flags.go`/`node/config.go` (searches for `RPCApiFlag`'s default value and `node/config.go`'s default HTTP modules did not resolve before the iteration budget ran out), so likelihood depends on whether governance is excluded from the out-of-the-box default module list. If it is excluded by default, likelihood is reduced to "operator misconfiguration" rather than "default-vulnerable."

### Recommendation
- Restrict `governance_vote` (and any other state-mutating governance/administrative APIs) to `IPCOnly: true` by default, or require it to be explicitly opted into rather than exposed whenever the module whitelist is empty.
- Add caller-side authentication/authorization for privileged write RPC methods (e.g., require a local-only transport, an auth token, or restrict via `Public: false` so it is never exposed by default fallback logic).
- Audit all `Public: true` namespace registrations (`governance`, and others) to ensure only genuinely read-only/query APIs default to public exposure; state-mutating APIs should never rely on `len(whitelist) == 0` fallback exposure.

### Proof of Concept
1. Operate (or compromise network access to) a Kaia consensus node configured as `governance.governingnode` in `single` governance mode, with its HTTP/WS RPC exposed and no explicit `--http.api`/`--ws.api` module restriction (or with `governance` explicitly whitelisted).
2. From any unauthenticated remote client, issue:
   ```
   curl "http://<target-node>:8551" -X POST -H 'Content-Type: application/json' --data '
     {"jsonrpc":"2.0","id":1,"method":"governance_vote","params":[
       "reward.mintingamount",
       "999999999999999999999999999"
     ]}'
   ```
3. The node accepts the call per `headerGovAPI.Vote` (only checking that the node's own address equals the governing node, not who made the RPC call), queues the vote via `PushMyVotes`, and — with no further caller-side authorization — writes it into the block header on the node's next proposal turn, subject to `VerifyVote`/`checkConsistency` passing (which they will, since format and node identity are valid).
4. Once ratified at the next epoch boundary, the malicious parameter value becomes chain-wide effective policy, achieved entirely through an unauthenticated RPC call.

func (api *headerGovAPI) Vote(name string, value any) (string, error) {
	var (
		voter     = api.h.nodeAddress
		nextBlock = api.h.Chain.CurrentBlock().NumberU64() + 1
		gp        = api.h.GetParamSet(nextBlock)
		gMode     = gp.GovernanceMode
	)

	if gMode == "single" && voter != gp.GoverningNode {
		return "", ErrVotePermissionDenied
	}

	vote := headergov.NewVoteData(voter, name, value)
	if vote == nil {
		return "", ErrInvalidKeyValue
	}

			module = "kaia"
		}
		whitelist[module] = true
	}
	// Register all the APIs exposed by the services
	handler := NewServer()
	for _, api := range apis {
		if api.Namespace == "klay" {
			api.Namespace = "kaia"
		}

		if !api.IPCOnly && (whitelist[api.Namespace] || (len(whitelist) == 0 && api.Public)) {
			if err := handler.RegisterName(api.Namespace, api.Service); err != nil {
				return nil, nil, err
			}
			logger.Debug("HTTP registered", "namespace", api.Namespace)
		}
	}

// (2) integrity of the voter (the voter must be the block proposer),
// (3) the vote value must be consistent compared to the latest ParamSet.
func (h *headerGovModule) VerifyVote(header *types.Header) error {
	if len(header.Vote) == 0 {
		return nil
	}

	var (
		vb       headergov.VoteBytes = header.Vote
		blockNum                     = header.Number.Uint64()
	)

	vote, err := vb.ToVoteData()
	if err != nil {
		logger.Error("ToVoteData error", "num", blockNum, "vote", vb, "err", err)
		return err
	}

	if gov.DeprecatedAt(vote.Name(), h.ChainConfig.Rules(header.Number)) {
		logger.Error("Vote is deprecated", "num", blockNum, "name", vote.Name())
		return ErrDeprecatedVote
	}

	council, err := h.ValSet.GetCouncil(blockNum)
	if err != nil {
		return err
	}

	// check if the voter is in council
	if !slices.Contains(council, vote.Voter()) {
		return ErrInvalidKeyValue
	}

	// check if Voter is the block proposer.
	author, err := h.Chain.Sealer().Author(header)
	if err != nil {
		return err
	}
	if author != vote.Voter() {
		return ErrInvalidVoter
	}

	// In single mode, only the governing node can write header.Vote after Permissionless.
	params := h.GetParamSet(blockNum)
	if h.ChainConfig.IsPermissionlessForkEnabled(new(big.Int).SetUint64(blockNum)) &&
		params.GovernanceMode == "single" &&
		vote.Voter() != params.GoverningNode {
		return ErrVotePermissionDenied
	}

	return h.checkConsistency(blockNum, vote)

// checkConsistency checks if vote values are consistent with chain states such as other parameters and validator set.
func (h *headerGovModule) checkConsistency(blockNum uint64, vote headergov.VoteData) error {
	switch vote.Name() {
	case gov.GovernanceGoverningNode:
		params := h.GetParamSet(blockNum)

		// compare with governing node only in single mode.
		if params.GovernanceMode != "single" {
			return nil
		}

		council, err := h.ValSet.GetCouncil(blockNum)
		if err != nil {
			return err
		}

		if !slices.Contains(council, params.GoverningNode) {
			return ErrGovNodeNotInValSetList
		}
		if !h.ChainConfig.IsPermissionlessForkEnabled(new(big.Int).SetUint64(blockNum)) {
			return nil
		}

		// After Permissionless only the governing node may vote, so a successor outside the council could never vote again.
		newNode, ok := vote.Value().(common.Address)
		if !ok || common.EmptyAddress(newNode) {
			return ErrInvalidKeyValue
		}
		if !slices.Contains(council, newNode) {
			return ErrGovNodeNotInValSetList
		}
		return nil
	case gov.Kip71LowerBoundBaseFee:
		params := h.GetParamSet(blockNum)
		if vote.Value().(uint64) > params.UpperBoundBaseFee {
			return ErrLowerBoundBaseFee
		} else {
			return nil
		}
	case gov.Kip71UpperBoundBaseFee:
		params := h.GetParamSet(blockNum)
		if vote.Value().(uint64) < params.LowerBoundBaseFee {
			return ErrUpperBoundBaseFee
		} else {
			return nil
		}
	case gov.AddValidator, gov.RemoveValidator:
		params := h.GetParamSet(blockNum)

		// compare with governing node only in single mode.
		if params.GovernanceMode != "single" {
			return nil
		}
		if slices.Contains(vote.Value().([]common.Address), params.GoverningNode) {
			return ErrGovNodeInValSetVoteValue
		}
		return nil
		// These votes are valid as long as it passes the format checks in NewVoteData(). No more checks here.
	case gov.GovernanceDeriveShaImpl, gov.GovernanceGovParamContract, gov.GovernanceGovernanceMode, gov.GovernanceUnitPrice,
		gov.IstanbulCommitteeSize, gov.IstanbulEpoch, gov.IstanbulPolicy,
		gov.Kip71BaseFeeDenominator, gov.Kip71GasTarget, gov.Kip71MaxBlockGasUsedForBaseFee,
		gov.RewardDeferredTxFee, gov.RewardKip82Ratio, gov.RewardMintingAmount, gov.RewardMinimumStake,
		gov.RewardProposerUpdateInterval, gov.RewardRatio, gov.RewardStakingRewardThreshold,
		gov.RewardStakingUpdateInterval, gov.RewardUseFlexReward, gov.RewardUseGiniCoeff:
		return nil
	default:
		return ErrInvalidKeyValue
	}
