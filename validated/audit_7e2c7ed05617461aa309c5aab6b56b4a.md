### Title
Contract governance (KIP-81) can set inconsistent KIP-71 base-fee bounds because `checkConsistency` is only enforced by header governance, not by `contractgov` - (File: `kaiax/gov/contractgov/impl/getter.go`)

### Summary
The reported bug is that `IchiVaultOracle` trusts an externally, owner-controlled parameter (`twapPeriod`) and only range-checks it at the point of consumption, so the vault owner can flip the parameter to make the oracle selectively revert and disrupt dependent protocol actions. The Kaia analog is the KIP-71 base-fee bound parameters (`kip71.lowerboundbasefee` / `kip71.upperboundbasefee`), which are similarly range-checked against each other, but that cross-parameter consistency check is implemented in only one of the two governance value-setting paths.

### Finding Description
Kaia's `gov` module aggregates governance parameters from two sources: header governance (votes recorded in block headers) and, post-Kore, contract governance via the `GovParam` contract (KIP-81) [1](#0-0) .

For header governance, `headerGovModule.checkConsistency` explicitly enforces that `kip71.lowerboundbasefee` cannot exceed `kip71.upperboundbasefee` and vice versa, returning `ErrLowerBoundBaseFee` / `ErrUpperBoundBaseFee` otherwise: [2](#0-1) 

However, the contract-governance path, `contractGovModule.GetParamSet`, builds the parameter set purely from per-parameter `FormatChecker`s (which are `noopFormatChecker` for both KIP-71 bound parameters) and never cross-validates `LowerBoundBaseFee` against `UpperBoundBaseFee`: [3](#0-2) [4](#0-3) 

The `GovParam` contract's parameters are set via public transactions (`setParam`/`setParamIn`) reachable by any GC member holding voting rights on that contract, and the resulting values are read live at block-processing time via `getAllParamsAt`: [5](#0-4) [6](#0-5) 

Because no consistency check exists on this path, it is possible to have `LowerBoundBaseFee > UpperBoundBaseFee` effective in the `ParamSet` used by consensus, something header governance is specifically designed to prevent. This parameter set feeds `KIP71Config.NextMagmaBlockBaseFee`, which assumes `lowerBoundBaseFee <= upperBoundBaseFee` when clamping the parent/next base fee: [7](#0-6) 

### Impact Explanation
`NextMagmaBlockBaseFee` is deterministic given the same inputs, so this does not directly cause honest-node state divergence by itself; all nodes computing from the same (inconsistent) `ParamSet` will agree on the same base fee. However, it breaks the invariant the protocol relies on elsewhere (the `TestEvenBaseFee` test explicitly asserts the computed fee stays within `[lowerBound, upperBound]`) [8](#0-7) , and other consumers of `gov.ParamSet` (fee estimation in `node/cn/gasprice`, `blockchain/tx_pool.go`, `blockchain/block_validator.go`) assume a well-formed bound relationship. An inconsistent bound pair can silently push the effective base fee to unintended extremes (e.g., collapsing toward an unintended floor/ceiling), undermining KIP-71 fee/burn accounting guarantees and gas price predictability network-wide, without ever being rejected the way an equivalent header-governance vote would be.

### Likelihood Explanation
Exploitation requires the ability to submit a transaction to the `GovParam` contract (KIP-81) that ends up setting `kip71.lowerboundbasefee`/`kip71.upperboundbasefee` inconsistently — this is gated by the `GovParam` contract's own on-chain access control (typically limited to the governance council), so it is not attacker-arbitrary, but it is a governance-parameter class explicitly in scope per this task's rules, and the missing check is a genuine gap between the two supposedly-equivalent governance pathways (header governance blocks it, contract governance does not).

### Recommendation
Apply the same cross-parameter consistency validation used in `headerGovModule.checkConsistency` (`kaiax/gov/headergov/impl/header.go`) to the contract-governance value path — either inside `contractGovModule.GetParamSet` in `kaiax/gov/contractgov/impl/getter.go`, or centrally when merging parameter sets in `kaiax/gov/param.go`/`paramset.go` — so that an inconsistent `LowerBoundBaseFee > UpperBoundBaseFee` (or vice versa) coming from the `GovParam` contract is rejected/ignored just as it is for header-governance votes.

### Proof of Concept
1. Deploy/utilize the `GovParam` contract registered as the chain's `governance.govparamcontract` (as in `tests/gov_contract_test.go`'s `deployGovParamTx_constructor`) after the Kore hardfork so `contractgov` is active [9](#0-8) .
2. As a GovParam-authorized account, submit `setParamIn("kip71.upperboundbasefee", true, <value lower than current lowerboundbasefee>, activation)` (or set `lowerboundbasefee` above the current `upperboundbasefee`) via a public transaction, as shown by `deployGovParamTx_setParamIn` [6](#0-5) .
3. Observe that `contractGovModule.GetParamSet` returns this inconsistent pair without error (no equivalent of `ErrLowerBoundBaseFee`/`ErrUpperBoundBaseFee` is raised) [10](#0-9) , whereas attempting the equivalent via `governance_vote`/header governance would be rejected by `checkConsistency` [2](#0-1) .
4. From the activation block onward, `KIP71Config.NextMagmaBlockBaseFee` computes base fees using the inconsistent bounds, violating the documented invariant that the resulting base fee stays within `[lowerBound, upperBound]`.

// GetParamSet returns default parameter set in case of the following errors:
// (1) contractgov is disabled (i.e., pre-Kore or GovParam address is zero)
// (2) GovParam address is not set
// (3) Contract call to GovParam failed
// Invalid parameters in the contract (i.e., invalid parameter name or non-canonical value) are ignored.
func (c *contractGovModule) GetParamSet(blockNum uint64) gov.ParamSet {
	m, err := c.contractGetAllParamsAt(blockNum)
	if err != nil {
		return *gov.GetDefaultGovernanceParamSet()
	}

	ret := *gov.GetDefaultGovernanceParamSet()
	for k, v := range m {
		err = ret.Set(k, v)
		if err != nil {
			return *gov.GetDefaultGovernanceParamSet()
		}
	}

	return ret
}

func (c *contractGovModule) contractGetAllParamsAtFromAddr(blockNum uint64, addr common.Address) (gov.PartialParamSet, error) {
	chain := c.Chain
	if chain == nil {
		return nil, ErrNotReady
	}

	config := c.ChainConfig
	if !config.IsKoreForkEnabled(new(big.Int).SetUint64(blockNum)) {
		return nil, ErrNotReady
	}

	caller := backends.NewBlockchainContractBackend(chain, nil, nil)
	contract, err := govcontract.NewGovParamCaller(addr, caller)
	if err != nil {
		return nil, err
	}

	names, values, err := contract.GetAllParamsAt(nil, new(big.Int).SetUint64(blockNum))
	if err != nil {
		logger.Warn("ContractEngine disabled: getAllParams call failed", "err", err)
		return nil, nil
	}

	if len(names) != len(values) {
		logger.Warn("ContractEngine disabled: getAllParams result invalid", "len(names)", len(names), "len(values)", len(values))
		return nil, nil
	}

	ret := ParseContractCall(names, values)

	rules := config.Rules(new(big.Int).SetUint64(blockNum))
	for name := range ret {
		if gov.DeprecatedAt(name, rules) {
			logger.Warn("Ignoring deprecated parameter from contract governance", "name", name, "blockNum", blockNum)
			delete(ret, name)
		}
	}

	return ret, nil
}

func (kc *KIP71Config) NextMagmaBlockBaseFee(parentHeaderNumber *big.Int, parentHeaderBaseFee *big.Int, parentHeaderGasUsed uint64) *big.Int {
	// governance parameters
	lowerBoundBaseFee := new(big.Int).SetUint64(kc.LowerBoundBaseFee)
	upperBoundBaseFee := new(big.Int).SetUint64(kc.UpperBoundBaseFee)
	makeEvenByCeil(lowerBoundBaseFee)
	makeEvenByFloor(upperBoundBaseFee)

	// If the parent is the magma disabled block or genesis, then return the lowerBoundBaseFee (default 25ston)
	if parentHeaderNumber.Cmp(new(big.Int).SetUint64(0)) == 0 || parentHeaderBaseFee == nil {
		return makeEvenByFloor(lowerBoundBaseFee)
	}

	var baseFeeDenominator *big.Int
	if kc.BaseFeeDenominator == 0 {
		// To avoid panic, set the fluctuation range small
		baseFeeDenominator = new(big.Int).SetUint64(64)
	} else {
		baseFeeDenominator = new(big.Int).SetUint64(kc.BaseFeeDenominator)
	}
	gasTarget := kc.GasTarget
	upperGasLimit := kc.MaxBlockGasUsedForBaseFee

	// check the case of upper/lowerBoundBaseFee is updated by governance mechanism
	parentBaseFee := parentHeaderBaseFee
	if parentBaseFee.Cmp(upperBoundBaseFee) >= 0 {
		parentBaseFee = upperBoundBaseFee
	} else if parentBaseFee.Cmp(lowerBoundBaseFee) <= 0 {
		parentBaseFee = lowerBoundBaseFee
	}

	// upper gas limit cut off the impulse of used gas to upper bound
	parentGasUsed := min(parentHeaderGasUsed, upperGasLimit)
	if parentGasUsed == gasTarget {
		return makeEvenByFloor(parentBaseFee)
	} else if parentGasUsed > gasTarget {
		// shortcut. If parentBaseFee is already reached upperbound, do not calculate.
		if parentBaseFee.Cmp(upperBoundBaseFee) == 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		// If the parent block used more gas than its target,
		// the baseFee of the next block should increase.
		// baseFeeDelta = max(1, parentBaseFee * (parentGasUsed - gasTarget) / gasTarget / baseFeeDenominator)
		gasUsedDelta := new(big.Int).SetUint64(parentGasUsed - gasTarget)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := math.BigMax(x.Div(y, baseFeeDenominator), common.Big1)

		nextBaseFee := x.Add(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(upperBoundBaseFee) > 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	} else {
		// shortcut. If parentBaseFee is already reached lower bound, do not calculate.
		if parentBaseFee.Cmp(lowerBoundBaseFee) == 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		// Otherwise if the parent block used less gas than its target,
		// the baseFee of the next block should decrease.
		// baseFeeDelta = parentBaseFee * (gasTarget - parentGasUsed) / gasTarget / baseFeeDenominator
		gasUsedDelta := new(big.Int).SetUint64(gasTarget - parentGasUsed)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := x.Div(y, baseFeeDenominator)

		nextBaseFee := x.Sub(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(lowerBoundBaseFee) < 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	}
}
