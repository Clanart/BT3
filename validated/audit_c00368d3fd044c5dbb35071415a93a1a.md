### Title
Unrecovered panic from unchecked type assertions in Pointer precompile `AddCW20`/`AddCW721`/`AddCW1155` - (File: precompiles/pointer/pointer.go)

### Summary
The Pointer precompile's `AddCW20`, `AddCW721`, and `AddCW1155` handlers query an arbitrary CW contract's `token_info`/`contract_info` and blindly type-assert the JSON response fields as `string` without validating their presence or type, and unlike sibling precompiles this executor installs no `recover()` around `Execute`.

### Finding Description
`AddCW20` does `sdk.AccAddressFromBech32(cwAddr)` then `p.wasmdKeeper.QuerySmartSafe(ctx, cwAddress, []byte("{\"token_info\":{}}"))`, unmarshal into `map[string]interface{}{}`, then:
```go
name := formattedRes["name"].(string)
symbol := formattedRes["symbol"].(string)
``` [1](#0-0) 
The same unchecked pattern (`formattedRes["name"].(string)`, `formattedRes["symbol"].(string)`) is repeated in `AddCW721` (querying `contract_info`) and `AddCW1155`. [2](#0-1) 

Any valid, bech32-formatted, deployed CosmWasm contract that responds successfully to `{"token_info":{}}` (for `AddCW20`) or `{"contract_info":{}}` (for `AddCW721`/`AddCW1155`) — but whose JSON response omits `name`/`symbol` keys, or returns them as non-string values (e.g. `null`, a number, an object) — will cause `formattedRes["name"].(string)` to panic with "interface conversion: interface {} is nil, not string" (a single-value type assertion panics on failure instead of returning `ok=false`).

Unlike `precompiles/addr/addr.go`, `precompiles/oracle/oracle.go`, and `precompiles/solo/solo.go`, all of which wrap their `Execute` bodies with `defer func() { if r := recover(); r != nil { err = ... } }()` specifically to "catch gas meter panics" (and incidentally any other panic), [3](#0-2)  `precompiles/pointer/pointer.go`'s `Execute` has no such guard: [4](#0-3) 

The outer dispatcher, `DynamicGasPrecompile.RunAndCalculateGas`, also does not `recover()` a general panic — its `defer` only calls `HandlePrecompileError` and rewrites `err`; the only `recover()` in that file is scoped narrowly inside `chargeDecodeGas` for gas-meter panics during calldata decoding, and it re-panics (`panic(r)`) for anything else. [5](#0-4) 

### Impact Explanation
A panic that propagates out of the EVM precompile call during `EndBlock`/transaction processing without being recovered by the ante/msg-server handler would crash the node evaluating that block. Because the Pointer precompile is reachable by any EVM transaction sender calling `addCW20Pointer`/`addCW721Pointer`/`addCW1155Pointer` with an attacker-controlled or attacker-deployed CosmWasm contract address whose query response deliberately omits or mistypes `name`/`symbol`, this is remotely triggerable by any unprivileged EVM caller. If the panic is not caught by a higher-level Cosmos SDK/ABCI recover wrapper, this can crash every full node/validator executing the same deterministic block, producing a chain-wide halt — a Critical/High severity outcome under the given ruleset ("crash of default-configuration RPC nodes" / "validator halt").

### Likelihood Explanation
Likelihood is high for triggering the panic path itself: any account can deploy or reference an existing CW contract that responds to `contract_info`/`token_info` queries with a JSON body lacking string `name`/`symbol` fields (e.g., a bare CW contract that only implements a minimal query handler returning `{}` or `{"name": null}`), and then call the Pointer precompile against it via a normal EVM transaction — no special privileges are required. What is uncertain from static review alone is whether an outer layer of the sei-chain EVM/ABCI transaction execution pipeline (outside the files inspected) installs a broader `recover()` that would downgrade this to a per-transaction revert rather than a node crash; I could not locate such a wrapper within `precompiles/common/precompiles.go` or `precompiles/pointer/pointer.go`, but the full EVM `ApplyMessage`/ante-handler call chain was not exhaustively traced.

### Recommendation
In `precompiles/pointer/pointer.go`, add a `recover()`-based defer to `Execute` consistent with the pattern used in `addr.go`/`oracle.go`/`solo.go`, and replace the unchecked type assertions in `AddCW20`, `AddCW721`, and `AddCW1155` with the two-value form (`name, ok := formattedRes["name"].(string)`) that returns a proper error (e.g., "CW contract response missing name/symbol") instead of relying on a panic/recover safety net.

### Proof of Concept
1. Deploy (or identify) a CosmWasm contract at address `cw1...` whose `{"contract_info":{}}` (or `{"token_info":{}}`) query handler returns valid JSON but without `name`/`symbol` keys, e.g. `{}`.
2. From any EVM account, call `IPointer(POINTER_PRECOMPILE_ADDRESS).addCW721Pointer("cw1...")` [6](#0-5) .
3. Execution reaches `p.wasmdKeeper.QuerySmartSafe` successfully, `json.Unmarshal` succeeds, and `formattedRes["name"].(string)` panics because the key is absent (`nil`, not `string`) [7](#0-6) .
4. Because `Execute` has no `recover()` [4](#0-3)  and the dispatcher's `defer` does not recover either [8](#0-7) , the panic propagates beyond the precompile boundary.

func (d DynamicGasPrecompile) RunAndCalculateGas(evm *vm.EVM, caller common.Address, callingContract common.Address, input []byte, suppliedGas uint64, value *big.Int, hooks *tracing.Hooks, readOnly bool, isFromDelegateCall bool) (ret []byte, remainingGas uint64, err error) {
	operation := fmt.Sprintf("%s_unknown", d.name)
	defer func() {
		HandlePrecompileError(err, evm, operation)
		if err != nil {
			fmt.Printf("precompile %s encountered error: %v\n", d.name, err)
			err = vm.ErrExecutionReverted
		}
	}()
	ctxer := state.GetDBImpl(evm.StateDB)
	if ctxer == nil {
		return nil, 0, errors.New("cannot get context from EVM")
	}
	// Resolve the target method from the 4-byte selector only. The argument
	// payload is intentionally NOT decoded yet: ABI decoding of attacker-
	// controlled calldata can cost far more than len(input) (a single string can
	// be referenced by many array/tuple slots), so it must be paid for out of the
	// gas the caller supplied. The static-precompile path charges RequiredGas in
	// vm.RunPrecompiledContract before running; that step is skipped for
	// dynamic-gas precompiles, so we apply the equivalent charge here.
	methodID, err := ExtractMethodID(input)
	if err != nil {
		return nil, 0, err
	}
	method, err := d.MethodById(methodID)
	if err != nil {
		return nil, 0, err
	}
	operation = method.Name

	ctx := ctxer.Ctx()
	// Install the gas meter derived from the supplied EVM gas, then charge for
	// decoding the calldata BEFORE decoding it. A call that cannot afford the
	// decode is rejected here, before the parse/allocation work is performed.
	// chargeDecodeGas scopes the out-of-gas recovery to just these charges, so an
	// executor that later exhausts its gas keeps its normal (propagating)
	// out-of-gas semantics.
	gasLimit := d.executor.EVMKeeper().GetCosmosGasLimitFromEVMGas(ctx.WithGasMeter(sdk.NewInfiniteGasMeterWithMultiplier(ctx)), suppliedGas)
	ctx = ctx.WithGasMeter(sdk.NewGasMeterWithMultiplier(ctx, gasLimit))
	if err = d.chargeDecodeGas(ctx, method, input); err != nil {
		return nil, 0, err
	}

	args, err := method.Inputs.Unpack(input[4:])
	if err != nil {
		return nil, 0, err
	}
	em := ctx.EventManager()
	ctx = ctx.WithEventManager(sdk.NewEventManager())
	ctx = ctx.WithEVMPrecompileCalledFromDelegateCall(isFromDelegateCall)
	ret, remainingGas, err = d.executor.Execute(ctx, method, caller, callingContract, args, value, readOnly, evm, suppliedGas, hooks)
	if err != nil {
		return ret, remainingGas, err
	}
	events := ctx.EventManager().Events()
	if len(events) > 0 {
		em.EmitEvents(ctx.EventManager().Events())
	}
	return ret, remainingGas, err
}

// chargeDecodeGas charges the (already-installed) gas meter for decoding the
// calldata, before it is decoded: a length-proportional scan cost that also
// bounds the DecodeGasCost scan, then the string-copy surcharge from
// DecodeGasCost. Its out-of-gas / overflow recovery is deliberately scoped to
// just these charges — a call that cannot afford the decode reverts here, while
// an executor that later exhausts its gas keeps its normal propagating
// out-of-gas semantics. Anything other than a gas-meter panic is re-raised.
func (d DynamicGasPrecompile) chargeDecodeGas(ctx sdk.Context, method *abi.Method, input []byte) (err error) {
	defer func() {
		if r := recover(); r != nil {
			switch r.(type) {
			case sdk.ErrorOutOfGas, sdk.ErrorGasOverflow:
				err = fmt.Errorf("%v", r)
			default:
				panic(r)
			}
		}
	}()
	scanCost := DefaultGasCost(input, false)
	ctx.GasMeter().ConsumeGas(scanCost, fmt.Sprintf("%s precompile calldata scan", d.name))
	decodeCost, ok := DecodeGasCost(method.Inputs, input)
	if !ok {
		// Calldata is structurally invalid (Unpack would reject it too); reject
		// now, without attempting the decode.
		return fmt.Errorf("invalid calldata encoding for %s", d.name)
	}
	// DecodeGasCost already includes scanCost; charge only the remaining
	// (string-copy) portion so the decode is priced exactly once.
	ctx.GasMeter().ConsumeGas(decodeCost-scanCost, fmt.Sprintf("%s precompile calldata decode", d.name))
	return nil
}
