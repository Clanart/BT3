### Title
`get_outputs` clobbers every earlier deposit's `data`/`presumed_origin` on each subsequent transaction in the same block, letting an attacker redirect a victim's deposit to their own InInstruction - ([File: processor/src/networks/bitcoin.rs])

### Summary
The bug class from the report — user funds deposited then effectively frozen/lost due to a later state change — maps onto `Bitcoin::get_outputs`: `outputs` is accumulated across the whole block but the per-transaction populate pass iterates over all accumulated outputs, not just the ones from the current `tx`. Any unprivileged user whose transaction lands in the same block after a deposit rewrites that deposit's `data` and `presumed_origin`. [1](#0-0) 

### Finding Description
In `get_outputs`, `let mut outputs = vec![]` is declared *outside* the `for tx in &block.txdata[1 ..]` loop [2](#0-1) . After scanning each transaction, `if outputs.is_empty() { continue }` only skips the populate pass when *no* outputs have ever been collected — once a single deposit is found, every later transaction in the block triggers the populate branch [3](#0-2) . That branch computes `presumed_origin` from the *current* tx's `tx.input[0]` and `data` from the *current* tx's embedded instruction via `Self::extract_serai_data(tx)`, then writes them into every output in `outputs`, including outputs belonging to earlier transactions [4](#0-3) .

Net effect: in a block where `txA` deposits to the Serai key and `txB` is any later transaction (it does not need to pay Serai at all), all outputs from `txA` end up with `txB`'s `extract_serai_data` result and `txB`'s `presumed_origin`. For `OutputType::External`, `output.data` — the user's `InInstruction` — is overwritten entirely [5](#0-4) .

### Impact Explanation
The `data` field carries the depositor's `InInstruction` (e.g., which chain/address to mint/burn to). An attacker who gets *any* transaction included in the same block after a victim's deposit — trivially achieved by broadcasting a self-payment — causes the victim's deposit to be reported with the attacker's embedded instruction (or empty/garbage data if the attacker embeds a specially crafted one). The deposit is still counted and its balance credited, but the instruction it executes is no longer the depositor's: funds can be minted/forwarded to the attacker's chosen destination, or the `presumed_origin` (used for refunds/origin attribution) points to the attacker's input [6](#0-5) . This is the Serai analog of "user can't withdraw / loses deposited funds": deposited value is processed under the wrong metadata, permanently misallocating it.

### Likelihood Explanation
Fully reachable by an unprivileged party: they only need a transaction confirmed in the same block *after* a victim's deposit — achievable by watching the mempool and broadcasting a fee-competitive tx, or even unintentionally whenever two deposits share a block (in which case the first depositor's data is corrupted even without adversary). Every deposit's metadata is determined by the last transaction in the block that reaches the populate branch.

### Recommendation
Scope the populate pass to only the outputs scanned from the current transaction — e.g., collect per-tx outputs into a temporary `Vec`, populate it, then `outputs.extend(it)`; or track `let start = outputs.len()` and iterate `&mut outputs[start ..]`. The `outputs.is_empty()` check should likewise test whether the *current* tx produced outputs.

### Proof of Concept

// Block with two txs: victim's deposit tx_v, then attacker's unrelated tx_a.
// After the loop, the victim's Output has tx_a's origin and tx_a's serai data.

// processor/src/networks/bitcoin.rs
for tx in &block.txdata[1 ..] {
  for output in scanner.scan_transaction(tx) {   // tx_v -> [V]; tx_a -> []
    ...
    outputs.push(output);
  }
  if outputs.is_empty() { continue; }            // tx_a: non-empty -> falls through!
  let presumed_origin = /* derived from tx_a.input[0] */;
  let data = Self::extract_serai_data(tx);       // tx_a's data
  for output in &mut outputs {                   // rewrites V too
    if output.kind == OutputType::External {
      output.data.clone_from(&data);             // victim's InInstruction lost
    }
    output.presumed_origin.clone_from(&presumed_origin);
  }
}
// outputs[0] (from tx_v) now carries tx_a's data/origin.

  async fn get_outputs(&self, block: &Self::Block, key: ProjectivePoint) -> Vec<Output> {
    let (scanner, _, kinds) = scanner(key);

    let mut outputs = vec![];
    // Skip the coinbase transaction which is burdened by maturity
    for tx in &block.txdata[1 ..] {
      for output in scanner.scan_transaction(tx) {
        let offset_repr = output.offset().to_repr();
        let offset_repr_ref: &[u8] = offset_repr.as_ref();
        let kind = kinds[offset_repr_ref];

        let output = Output { kind, presumed_origin: None, output, data: vec![] };
        assert_eq!(output.tx_id(), tx.id());
        outputs.push(output);
      }

      if outputs.is_empty() {
        continue;
      }

      // populate the outputs with the origin and data
      let presumed_origin = {
        // This may identify the P2WSH output *embedding the InInstruction* as the origin, which
        // would be a bit trickier to spend that a traditional output...
        // There's no risk of the InInstruction going missing as it'd already be on-chain though
        // We *could* parse out the script *without the InInstruction prefix* and declare that the
        // origin
        // TODO
        let spent_output = {
          let input = &tx.input[0];
          let mut spent_tx = input.previous_output.txid.as_raw_hash().to_byte_array();
          spent_tx.reverse();
          let mut tx;
          while {
            tx = self.rpc.get_transaction(&spent_tx).await;
            tx.is_err()
          } {
            log::error!("couldn't get transaction from bitcoin node: {tx:?}");
            sleep(Duration::from_secs(5)).await;
          }
          tx.unwrap().output.swap_remove(usize::try_from(input.previous_output.vout).unwrap())
        };
        Address::new(spent_output.script_pubkey)
      };
      let data = Self::extract_serai_data(tx);
      for output in &mut outputs {
        if output.kind == OutputType::External {
          output.data.clone_from(&data);
        }
        output.presumed_origin.clone_from(&presumed_origin);
      }
    }

    outputs
  }
