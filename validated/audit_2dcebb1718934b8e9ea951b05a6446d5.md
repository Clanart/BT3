### Title
Reward-per-share denominator inflation via direct staking-token donation permanently dilutes MGP yield - ([File: rewards/MasterMagpie.sol])

### Summary
`_calLpSupply()` uses `IERC20(_stakingToken).balanceOf(address(this))` as the reward-share denominator for every pool except vlMGP/mWomSV, instead of an internally tracked total-staked accounting variable. Any unprivileged address can transfer the staking token directly to `MasterMagpie` (no `deposit()` needed) to inflate that balance without ever crediting a `UserInfo.amount`, and any subsequent call to `updatePool` (via `deposit`, `withdraw`, or `massUpdatePools`) permanently bakes the diluted `accMGPPerShare` into pool state.

### Finding Description
`updatePool()` computes `mgpReward = multiplier * mgpPerSec * pool.allocPoint / totalAllocPoint` and then does `accMGPPerShare += mgpReward * 1e12 / lpSupply`, where `lpSupply = _calLpSupply(_stakingToken)`: [1](#0-0) 

For any staking token that is not `vlmgp` or `mWomSV`, `_calLpSupply` simply returns the raw ERC20 balance of the contract rather than a sum of legitimately-staked `UserInfo.amount`: [2](#0-1) 

Because `deposit()`/`_deposit()` transfers tokens in via `safeTransferFrom` and separately increments `user.amount`/`user.available`, and `withdraw()`/`_withdraw()`/`_harvestAndUnstake()` only decrements `user.amount` for the caller's own tracked balance, none of these functions reconcile `balanceOf(address(this))` against the sum of all `UserInfo.amount`: [3](#0-2) 

An attacker (or anyone) can call `stakingToken.transfer(masterMagpieAddress, X)` directly on the token contract — bypassing `deposit()` entirely — which raises `balanceOf(address(this))` with no corresponding `UserInfo.amount` credited to anyone. The next time `updatePool` runs (triggered by any user's `deposit`, `withdraw`, or `massUpdatePools`, including the attacker's own `withdraw` call), the inflated `lpSupply` permanently shrinks the `accMGPPerShare` increment for that interval. Since `pool.lastRewardTimestamp` advances at the same time, the under-accrued MGP for that interval can never be recovered — the emitted MGP (based on `mgpPerSec`) is not fully reflected in `accMGPPerShare`, and the donated tokens are not withdrawable by anyone because no `UserInfo.available`/`amount` corresponds to them.

### Impact Explanation
This breaks the intended invariant that MGP emitted per interval (`mgpPerSec * allocPoint / totalAllocPoint * multiplier`) must be fully distributable across `sum(UserInfo.amount)`. Once diluted, the shortfall in `accMGPPerShare` is permanent because `lastRewardTimestamp` is advanced and the interval cannot be recomputed. Legitimate stakers' pending/future MGP yield is permanently reduced relative to what `mgpPerSec` was configured to distribute, matching "Permanent freezing of unclaimed yield." No sweep/rescue function exists in the reviewed code to reclaim or reconcile the donated balance and correct `accMGPPerShare`.

### Likelihood Explanation
The attack requires only owning a small amount of the target pool's staking token (or receipt token) and no privileged role — a plain `ERC20.transfer` to `MasterMagpie` plus triggering `updatePool` (e.g., via the attacker's own `withdraw`/`deposit`, or simply waiting for any other user's interaction, or calling `massUpdatePools` directly which is unrestricted aside from `whenNotPaused`). It is trivially repeatable on every pool where `_calLpSupply` falls into the `balanceOf` branch, and capital required equals only the donated token amount (which is not necessarily lost forever to the attacker in a censorship sense, but it does not go to the attacker either — it dilutes all other stakers, which is the freezing impact).

### Recommendation
Track total staked amount internally (e.g., a `pool.totalStaked` field incremented/decremented in `_deposit`/`_withdraw`) and use that value in `_calLpSupply` instead of `IERC20(_stakingToken).balanceOf(address(this))`, mirroring the safe pattern already used for `vlmgp`/`mWomSV` (`totalSupply()` of an internally-controlled token). This removes the ability of externally-donated balances to affect the reward-share denominator.

### Proof of Concept
Hardhat test plan:
1. Deploy `MasterMagpie`, `Mgp`, a mock ERC20 staking token, and register a pool for that token with `add()`.
2. User A calls `deposit(stakingToken, 100e18)`.
3. Advance time, call `withdraw`/`updatePool` to record `accMGPPerShareBefore`.
4. Attacker directly calls `stakingToken.transfer(masterMagpieAddress, 10_000e18)` (no `deposit()`), then calls any function that triggers `updatePool` (e.g. `massUpdatePools()` or `deposit(stakingToken, 0)` is blocked by zero-amount checks—use `withdraw` with 0 if allowed, or wait for user A's next `withdraw`).
5. Advance time again, trigger `updatePool` again, record `accMGPPerShareAfter`.
6. Assert `accMGPPerShareAfter - accMGPPerShareBefore` for the same elapsed time and `mgpPerSec` is now much smaller than it would be absent the donation (i.e., `lpSupply` used in the calc = `100e18 + 10_000e18` instead of `100e18`), and that the diluted amount can never be recovered by User A even after withdrawing all deposited principal.
7. Assert `IERC20(mgp).balanceOf(masterMagpie)` accrual no longer matches `mgpPerSec * elapsed` fully attributable to `sum(UserInfo.amount)`, confirming permanent yield dilution/freezing.

    function updatePool(address _stakingToken) public whenNotPaused {
        PoolInfo storage pool = tokenToPoolInfo[_stakingToken];
        if (block.timestamp <= pool.lastRewardTimestamp || totalAllocPoint == 0) {
            return;
        }
        uint256 lpSupply = _calLpSupply(_stakingToken);
        if (lpSupply == 0) {
            pool.lastRewardTimestamp = block.timestamp;
            return;
        }        
        uint256 multiplier = block.timestamp - pool.lastRewardTimestamp;
        uint256 mgpReward = (multiplier * mgpPerSec * pool.allocPoint) / totalAllocPoint;
        
        pool.accMGPPerShare = pool.accMGPPerShare + ((mgpReward * 1e12) / lpSupply);
        pool.lastRewardTimestamp = block.timestamp;

        emit UpdatePool(
            _stakingToken,
            pool.lastRewardTimestamp,
            lpSupply,
            pool.accMGPPerShare
        );
    }

    function _deposit(address _stakingToken, address _account, uint256 _amount, bool _isVlmgp) internal {
        updatePool(_stakingToken);

        PoolInfo storage pool = tokenToPoolInfo[_stakingToken];
        UserInfo storage user = userInfo[_stakingToken][_account];

        if (user.amount > 0) {
            _harvestMGP(_stakingToken, _account);
        }
        _harvestBaseRewarder(_stakingToken, _account);

        user.amount = user.amount + _amount;
        if (!_isVlmgp) {
            user.available = user.available + _amount;
            IERC20(pool.stakingToken).safeTransferFrom(address(msg.sender), address(this), _amount);
        }
        user.rewardDebt = (user.amount * pool.accMGPPerShare) / 1e12;

        if (_amount > 0)
            if (!_isVlmgp)
                emit Deposit(_account, _stakingToken, _amount);
            else
                emit DepositNotAvailable(_account, _stakingToken, _amount);
    }

    /// @notice internal function to deal with withdraw staking token
    function _withdraw(address _stakingToken, address _account, uint256 _amount, bool _isVlMgp) internal {
        _harvestAndUnstake(_stakingToken, _account, _amount, _isVlMgp);

        if (!_isVlMgp)
            IERC20(tokenToPoolInfo[_stakingToken].stakingToken).safeTransfer(address(msg.sender), _amount);
        emit Withdraw(_account, _stakingToken, _amount);
    }

    function _harvestAndUnstake(address _stakingToken, address _account, uint256 _amount, bool _isVlMgp) internal {
        updatePool(_stakingToken);

        UserInfo storage user = userInfo[_stakingToken][_account];

        if (!_isVlMgp && user.available < _amount)
            revert WithdrawAmountExceedsStaked();
        else if(user.amount < _amount && _isVlMgp)
            revert UnlockAmountExceedsLocked();
        
        _harvestMGP(_stakingToken, _account);
        _harvestBaseRewarder(_stakingToken, _account);

        user.amount = user.amount - _amount;
        
        if(!_isVlMgp)
            user.available = user.available - _amount;
        user.rewardDebt = (user.amount * tokenToPoolInfo[_stakingToken].accMGPPerShare) / 1e12;
    }

    function _calLpSupply(address _stakingToken) internal view returns (uint256) {
        if (_stakingToken == address(vlmgp)) {
            return IERC20(address(vlmgp)).totalSupply();
        }
        if (_stakingToken == address(mWomSV)) {
            return IERC20(address(mWomSV)).totalSupply();
        }
        return IERC20(_stakingToken).balanceOf(address(this));
    }
