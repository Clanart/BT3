### Title
Permissionless `associatePubKey` allows fund/identity hijack without private-key proof, unlike signature-verified `associate` - ([File: precompiles/addr/addr.go])

### Summary
The `addr` precompile exposes two ways to bind a Sei address to an EVM address: `associate` (requires an ECDSA signature `v,r,s` over a message, cryptographically proving control of the private key) and `associatePubKey` (accepts a raw, unauthenticated public key and derives both addresses from it, with **no signature or proof-of-possession check**). [1](#0-0)  Any caller can invoke `associatePubKey` with someone else's known public key (public keys are frequently exposed on-chain — e.g., a Cosmos SDK account that has broadcast even one signed transaction reveals its pubkey) to force-create the canonical Sei↔EVM association for that victim.

### Finding Description
`associatePublicKey` parses an attacker-supplied compressed pubkey and derives `evmAddr`/`seiAddr` purely from that key material, then calls `associateAddresses`: [2](#0-1) 

```go
func (p PrecompileExecutor) associatePublicKey(...) {
    pubKeyBytes, _ := hex.DecodeString(pubKeyHex)
    pubKey, _ := btcec.ParsePubKey(pubKeyBytes)
    ...
    evmAddr, seiAddr, pubkey, err := helpers.GetAddressesFromPubkeyBytes(uncompressedPubKey)
    return p.associateAddresses(ctx, method, evmAddr, seiAddr, pubkey)
}
```

Compare this to `associate`, which requires the caller to supply a valid ECDSA signature over `customMessage`, from which the pubkey is *recovered* — proving the caller controls the corresponding private key: [3](#0-2) 

`associateAddresses` only checks that the target Sei address isn't *already* associated — it performs no check that the transaction sender is the owner of the pubkey being associated: [4](#0-3) 

Once associated, `AssociateAddresses` migrates the entire spendable/locked/wei balance sitting at the direct-cast address (`sdk.AccAddress(evmAddr[:])`) into the target Sei address, and sets the account's pubkey if none is set: [5](#0-4) 

This is the same bug class as the Gokapi advisory: a low-privilege actor (any transaction sender) can trigger a privileged/identity-binding operation (`associatePubKey`) that should require proof of ownership, but the check that exists on the sibling code path (`associate`'s signature verification) is missing here.

### Impact Explanation
An attacker who observes any victim's Cosmos-format public key (trivially obtainable from any prior signed Cosmos tx by that account, or a validator's consensus pubkey if it reuses account keys) can:
- Pre-emptively call `associatePubKey` to bind the victim's Sei identity to the deterministically-derived EVM address before the victim ever associates themselves, and simultaneously trigger `MigrateBalance`, sweeping any funds sitting at the direct-cast EVM address of that pubkey into the (now attacker-triggered) association.
- Because the mapping is one-way-locked (`associateAddresses` rejects re-association once `GetEVMAddress` is found), the attacker can grief a victim by locking their identity/association state, or by racing to be the entity that establishes the canonical binding and captures the balance-migration side effect first.

This matches the Impact category "unauthorized transfer" / fund loss via the forced balance migration, and "permanent freezing" in the griefing case where the victim can never self-associate afterward because the mapping already exists.

### Likelihood Explanation
Likelihood is high for the griefing/DoS variant: pubkeys are public once an account has broadcast a signed transaction, and calling the precompile costs only gas — no special privilege is required. The fund-migration variant depends on funds existing at the direct-cast `sdk.AccAddress(evmAddr[:])` address for that pubkey at the time of the call, which is a normal, common state for an account that has received a bank transfer but not yet interacted via EVM.

### Recommendation
Require the same proof-of-possession for `associatePubKey` as for `associate`: either require a signature over a domain-separated message recoverable to the supplied pubkey, or restrict `associatePubKey` to be callable only by the address that matches the derived `evmAddr`/`seiAddr` (i.e., verify `msg.Sender` corresponds to the pubkey before proceeding). At minimum, gate the balance-migration side effect behind the same ownership check.

### Proof of Concept
1. Observe any Cosmos account `V` that has broadcast at least one signed transaction (its pubkey `pkV` is now public in tx data / `/cosmos/auth` query).
2. As attacker `A` (any registered/funded EVM account), call `addr.associatePubKey(pkV)` via the precompile at `0x0000000000000000000000000000000000001004`.
3. The call succeeds without any signature: `evmAddr`/`seiAddr` are derived from `pkV`, `GetEVMAddress(ctx, seiAddr)` returns not-found (assuming `V` never self-associated), so `associateAddresses` proceeds, binds the mapping, sets `V`'s account pubkey if unset, and migrates any funds at `sdk.AccAddress(evmAddr[:])` into `seiAddr`. [4](#0-3) [5](#0-4) 
4. Victim `V` can no longer call `associate`/`associatePubKey` themselves for their own address since the mapping now exists, and any funds previously sitting at the direct-cast address have been moved under attacker-triggered execution.

Note: I could not find any additional signature/ownership check applied to `associatePubKey` in any legacy precompile version (`v600`–`v640`) — all variants show the identical pattern, confirming this is a long-standing, unmitigated gap rather than a one-off regression. [6](#0-5)

func (p PrecompileExecutor) associate(ctx sdk.Context, method *abi.Method, args []interface{}, value *big.Int) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}

	if err := pcommon.ValidateArgsLength(args, 4); err != nil {
		return nil, 0, err
	}

	// v, r and s are components of a signature over the customMessage sent.
	// We use the signature to construct the user's pubkey to obtain their addresses.
	v := args[0].(string)
	r := args[1].(string)
	s := args[2].(string)
	customMessage := args[3].(string)

	rBytes, err := decodeHexString(r)
	if err != nil {
		return nil, 0, err
	}
	sBytes, err := decodeHexString(s)
	if err != nil {
		return nil, 0, err
	}
	vBytes, err := decodeHexString(v)
	if err != nil {
		return nil, 0, err
	}

	vBig := new(big.Int).SetBytes(vBytes)
	rBig := new(big.Int).SetBytes(rBytes)
	sBig := new(big.Int).SetBytes(sBytes)

	// Derive addresses
	vBig = new(big.Int).Add(vBig, utils.Big27)

	customMessageHash := crypto.Keccak256Hash([]byte(customMessage))
	evmAddr, seiAddr, pubkey, err := helpers.GetAddresses(vBig, rBig, sBig, customMessageHash)
	if err != nil {
		return nil, 0, err
	}

	return p.associateAddresses(ctx, method, evmAddr, seiAddr, pubkey)
}

func (p PrecompileExecutor) associatePublicKey(ctx sdk.Context, method *abi.Method, args []interface{}, value *big.Int) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}

	if err := pcommon.ValidateArgsLength(args, 1); err != nil {
		return nil, 0, err
	}

	// Takes a single argument, a compressed pubkey in hex format, excluding the '0x'
	pubKeyHex := args[0].(string)

	pubKeyBytes, err := hex.DecodeString(pubKeyHex)
	if err != nil {
		return nil, 0, err
	}

	// Parse the compressed public key
	pubKey, err := btcec.ParsePubKey(pubKeyBytes)
	if err != nil {
		return nil, 0, err
	}

	// Convert to uncompressed public key
	uncompressedPubKey := pubKey.SerializeUncompressed()

	evmAddr, seiAddr, pubkey, err := helpers.GetAddressesFromPubkeyBytes(uncompressedPubKey)
	if err != nil {
		return nil, 0, err
	}

	return p.associateAddresses(ctx, method, evmAddr, seiAddr, pubkey)
}

func (p PrecompileExecutor) associateAddresses(ctx sdk.Context, method *abi.Method, evmAddr common.Address, seiAddr sdk.AccAddress, pubkey cryptotypes.PubKey) (ret []byte, remainingGas uint64, err error) {
	// Check that address is not already associated
	_, found := p.evmKeeper.GetEVMAddress(ctx, seiAddr)
	if found {
		return nil, 0, fmt.Errorf("address %s is already associated with evm address %s", seiAddr, evmAddr)
	}

	// Associate Addresses:
	associationHelper := helpers.NewAssociationHelper(p.evmKeeper, p.bankKeeper, p.accountKeeper)
	err = associationHelper.AssociateAddresses(ctx, seiAddr, evmAddr, pubkey, false)
	if err != nil {
		return nil, 0, err
	}

	ret, err = method.Outputs.Pack(seiAddr.String(), evmAddr)
	return ret, pcommon.GetRemainingGas(ctx, p.evmKeeper), err
}

func (p AssociationHelper) AssociateAddresses(ctx sdk.Context, seiAddr sdk.AccAddress, evmAddr common.Address, pubkey cryptotypes.PubKey, migrateUseiOnly bool) error {
	castAddr := sdk.AccAddress(evmAddr[:])
	if !castAddr.Equals(seiAddr) && p.accountKeeper.GetAccount(ctx, seiAddr) == nil {
		castAcc := p.accountKeeper.GetAccount(ctx, castAddr)
		castBaseAcc, ok := castAcc.(*authtypes.BaseAccount)
		if ok && castBaseAcc.GetPubKey() == nil && p.bankKeeper.LockedCoins(ctx, castAddr).IsZero() {
			p.accountKeeper.SetAccount(ctx, authtypes.NewBaseAccount(seiAddr, pubkey, castBaseAcc.GetAccountNumber(), castBaseAcc.GetSequence()))
		}
	}
	p.evmKeeper.SetAddressMapping(ctx, seiAddr, evmAddr)
	acc := p.accountKeeper.GetAccount(ctx, seiAddr)
	if acc == nil {
		acc = p.accountKeeper.NewAccountWithAddress(ctx, seiAddr)
	}
	if acc.GetPubKey() == nil {
		if err := acc.SetPubKey(pubkey); err != nil {
			return err
		}
		p.accountKeeper.SetAccount(ctx, acc)
	}
	return p.MigrateBalance(ctx, evmAddr, seiAddr, migrateUseiOnly)
}

func (p AssociationHelper) MigrateBalance(ctx sdk.Context, evmAddr common.Address, seiAddr sdk.AccAddress, migrateUseiOnly bool) error {
	castAddr := sdk.AccAddress(evmAddr[:])
	if castAddr.Equals(seiAddr) {
		return nil
	}
	var castAddrBalances sdk.Coins
	if migrateUseiOnly {
		castAddrBalances = sdk.Coins{p.bankKeeper.GetBalance(ctx, castAddr, "usei")}
	} else {
		castAddrBalances = p.bankKeeper.SpendableCoins(ctx, castAddr)
	}
	if !castAddrBalances.IsZero() {
		if err := p.bankKeeper.SendCoins(ctx, castAddr, seiAddr, castAddrBalances); err != nil {
			return err
		}
	}
	castAddrWei := p.bankKeeper.GetWeiBalance(ctx, castAddr)
	if !castAddrWei.IsZero() {
		if err := p.bankKeeper.SendCoinsAndWei(ctx, castAddr, seiAddr, sdk.ZeroInt(), castAddrWei); err != nil {
			return err
		}
	}
	if p.bankKeeper.LockedCoins(ctx, castAddr).IsZero() {
		p.accountKeeper.RemoveAccount(ctx, authtypes.NewBaseAccountWithAddress(castAddr))
	}
	return nil
}
