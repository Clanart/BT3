### Title
`Scanner::scan_block` reports immature coinbase outputs as spendable `ReceivedOutput`s — ([File: networks/bitcoin/src/wallet/mod.rs](networks/bitcoin/src/wallet/mod.rs))

### Summary
The ClearingHouse bug class is an unauthenticated external trigger: any third party can fabricate an event (a spoofed Seaport settlement) that the protocol accepts as genuine, corrupting internal state. The analog in Serai's Bitcoin scanner is `Scanner::scan_block`, which scans every transaction in a block — including the coinbase — purely by `script_pubkey` match, emitting `ReceivedOutput`s that are treated as spendable inputs even though coinbase outputs cannot be spent for 100 blocks (Bitcoin consensus maturity rule). Any miner can therefore cause the wallet to report funds as received that are not actually spendable.

### Finding Description
`Scanner::scan_block` iterates `block.txdata` starting at index 0, so it includes the coinbase transaction, and `scan_transaction` only checks `self.scripts.get(&output.script_pubkey)` before pushing a `ReceivedOutput` [1](#0-0) .

A `ReceivedOutput` is defined as "A spendable output" and is consumed by `SignableTransaction::new`, which unconditionally turns each one into a `TxIn` and prevout [2](#0-1) . `multisig` only verifies the offset/script correspondence — it has no notion of maturity [3](#0-2) . Nothing in the `Scanner`/`ReceivedOutput`/`SignableTransaction` pipeline records that an output came from a coinbase or checks confirmation depth.

The code itself acknowledges the gap only in a doc comment: "This will also scan the coinbase transaction which is bound by maturity. If received outputs must be immediately spendable, a post-processing pass is needed" — no such pass exists in the in-scope crate [4](#0-3) .

### Impact Explanation
An attacker who mines a block (or on any chain where coinbase rewards can be directed arbitrarily) pays the coinbase reward to a Scanner-registered script. `scan_block` reports it as a normal spendable `ReceivedOutput`. If the wallet then builds a `SignableTransaction` spending it, the fully-signed transaction is consensus-invalid (`bad-txns-premature-spend-of-coinbase`) and rejected by the network — the threshold signing round is wasted, the wallet's view of its spendable balance is inflated by the entire block reward, and any accounting built on `ReceivedOutput::value()` counts unmatured funds. This is the same shape as the ClearingHouse flaw: a party-controlled on-chain artifact is accepted as a genuine "settlement" without validating its provenance/maturity, poisoning downstream state.

### Likelihood Explanation
Requires the attacker to win a block whose coinbase pays the victim's script — permissionless but hashpower-bound on mainnet. Incentive exists because miners can already direct rewards anywhere; an attacker with any mining capability (including rented hashpower or an honest-but-coopting pool) can trigger it deterministically since the scanner applies no coinbase exclusion. Exploitation of the downstream effect additionally needs the wallet to attempt spending within 100 blocks, which is the default assumption of the `ReceivedOutput` API.

### Recommendation
In `Scanner::scan_block`, skip `block.txdata[0]` (or explicitly check `tx.is_coinbase()` and skip it), matching the existing suggestion to scan `block.txdata[1 ..]`. Alternatively, carry a `coinbase: bool` flag on `ReceivedOutput` so consumers can enforce the 100-block maturity window before passing outputs to `SignableTransaction::new`. At minimum, `Coinbase` outputs should never be represented as immediately-spendable `ReceivedOutput`s.

### Proof of Concept
1. Construct `Scanner::new(key)` for an even Taproot key; note the registered `Scalar::ZERO` script from `p2tr_script_buf(key)` [5](#0-4) .
2. Mine a block whose coinbase (`block.txdata[0]`, `input[0].previous_output.is_null()`) has an output paying that script.
3. Call `scanner.scan_block(&block)` at depth 0 — it returns a `ReceivedOutput` for the coinbase output, identical in form to a mature one (this exact flow is exercised by `send_and_get_output`, which deliberately mines coinbases to the scanner address and then mines 100 extra blocks only as a test workaround) [6](#0-5) .
4. Feed that `ReceivedOutput` to `SignableTransaction::new` and `TransactionMachine`; the resulting signed transaction is rejected by Bitcoin Core with `bad-txns-premature-spend-of-coinbase`, while the scanner reported the funds as spendable.

  pub fn scan_transaction(&self, tx: &Transaction) -> Vec<ReceivedOutput> {
    let mut res = Vec::new();
    for (vout, output) in tx.output.iter().enumerate() {
      // If the vout index exceeds 2**32, stop scanning outputs
      let Ok(vout) = u32::try_from(vout) else { break };

      if let Some(offset) = self.scripts.get(&output.script_pubkey) {
        res.push(ReceivedOutput {
          offset: *offset,
          output: output.clone(),
          outpoint: OutPoint::new(tx.compute_txid(), vout),
        });
      }
    }
    res
  }

  /// Scan a block.
  ///
  /// This will also scan the coinbase transaction which is bound by maturity. If received outputs
  /// must be immediately spendable, a post-processing pass is needed to remove those outputs.
  /// Alternatively, scan_transaction can be called on `block.txdata[1 ..]`.
  pub fn scan_block(&self, block: &Block) -> Vec<ReceivedOutput> {
    let mut res = Vec::new();
    for tx in &block.txdata {
      res.extend(self.scan_transaction(tx));
    }
    res
  }

async fn send_and_get_output(rpc: &Rpc, scanner: &Scanner, key: ProjectivePoint) -> ReceivedOutput {
  let block_number = rpc.get_latest_block_number().await.unwrap() + 1;

  rpc
    .rpc_call::<Vec<String>>(
      "generatetoaddress",
      serde_json::json!([
        1,
        Address::from_script(&p2tr_script_buf(key).unwrap(), Network::Regtest).unwrap()
      ]),
    )
    .await
    .unwrap();

  // Mine until maturity
  rpc
    .rpc_call::<Vec<String>>(
      "generatetoaddress",
      serde_json::json!([100, Address::p2sh(Script::new(), Network::Regtest).unwrap()]),
    )
    .await
    .unwrap();

  let block = rpc.get_block(&rpc.get_block_hash(block_number).await.unwrap()).await.unwrap();

  let mut outputs = scanner.scan_block(&block);
  assert_eq!(outputs, scanner.scan_transaction(&block.txdata[0]));

  assert_eq!(outputs.len(), 1);
  assert_eq!(outputs[0].outpoint(), &OutPoint::new(block.txdata[0].compute_txid(), 0));
  assert_eq!(outputs[0].value(), block.txdata[0].output[0].value.to_sat());

  assert_eq!(
    ReceivedOutput::read::<&[u8]>(&mut outputs[0].serialize().as_ref()).unwrap(),
    outputs[0]
  );

  outputs.swap_remove(0)
