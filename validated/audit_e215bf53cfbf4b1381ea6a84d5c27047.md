### Title
Unrestricted `harvestAll()` allows attackers to snipe delegatedPool bribe distributions via vote-then-harvest-then-unvote, stealing yield from long-term voters - (File: rewards/DelegateVoteRewardPool.sol)

### Summary
`DelegateVoteRewardPool.harvestAll()` has no access-control modifier and can be called by anyone at any time. [1](#0-0)  Because reward accounting is a simple `rewardPerTokenStored += amount / totalSupply` model with no time-weighting or vesting, an attacker can vote a large vlMGP delta into the `delegatedPool` immediately before calling `harvestAll()`, capture a pro-rata share of bribes that accrued before their stake existed, and then `unvote` in the same block to withdraw with zero time-weighted exposure.

### Finding Description
`WombatBribeManager.vote()` lets any account holding vlMGP votable power stake into the `delegatedPool`'s rewarder (`DelegateVoteRewardPool`) via `IBribeRewardPool(pool.rewarder).stakeFor(msg.sender, uint256(delta))`, which increases `totalSupply` and the caller's `_balances` immediately, and sets `userRewardPerTokenPaid` to the *current* `rewardPerTokenStored` through the `updateRewards` modifier. [2](#0-1) [3](#0-2) 

Normally, `harvestAll()` is meant to only be triggered as a side effect of `castVotes()`: `if (delegatedPool != address(0)) IDelegateVoteRewardPool(delegatedPool).harvestAll();`. [4](#0-3)  However, `harvestAll()` itself is `external` with no `onlyOperator`/access-control check: [1](#0-0) 

```
function harvestAll() external {
    (address[] memory rewardTokensList, uint256[] memory earnedRewards) =
        IWombatBribeManager(operator).claimAllBribes(address(this));
    _manageRewards(rewardTokensList, earnedRewards);
}
```

`_manageRewards` -> `_queueNewRewardsWithoutTransfer` distributes the freshly harvested bribes by dividing by the *current* `totalSupply`: [5](#0-4) 

```
rewardInfo.rewardPerTokenStored = rewardInfo.rewardPerTokenStored +
    (_amountReward * 10 ** this.stakingDecimals()) / totalSupply;
```

Exploit flow:
1. Attacker holds real vlMGP votable power (a precondition, but not flash-loanable since vlMGP is a locked/vote-escrow balance).
2. Attacker calls `WombatBribeManager.vote([delegatedPoolLp], [largeDelta])`, which calls `stakeFor` on the `DelegateVoteRewardPool`, inflating `totalSupply` and setting attacker's `userRewardPerTokenPaid` to the pre-harvest `rewardPerTokenStored`.
3. Attacker (or anyone) calls `DelegateVoteRewardPool.harvestAll()` directly - no modifier stops this - harvesting all bribes accrued since the last harvest (potentially days of accrual from long-term voters) and distributing them pro-rata over the now-inflated `totalSupply`.
4. Attacker calls `WombatBribeManager.unvote(delegatedPoolLp)` to withdraw, which calls `withdrawFor(..., true)` and immediately claims the earned reward via `_getReward`, computed as `balance * (rewardPerTokenStored - userRewardPerTokenPaid) / 1e18` - a pro-rata share of bribes the attacker never contributed time-weighted vote power toward. [6](#0-5) 

Existing checks that fail to stop this: there is no `onlyOperator` guard on `harvestAll()` (unlike `stakeFor`/`withdrawFor`, which do have `onlyOperator`), and there is no minimum holding period or time-weighting in the reward-per-token math.

### Impact Explanation
This is theft of unclaimed yield: bribes that accrued to long-term `delegatedPool` voters over the period since the last harvest get diluted and redirected to an attacker who deposits stake for a single block. This matches the Immunefi impact class "theft of unclaimed yield" / "direct theft of user funds." The magnitude scales with the size of the attacker's vlMGP votable power relative to the existing `totalSupply` of the delegatedPool, and with the amount of bribes accrued since the last harvest.

### Likelihood Explanation
Feasibility is moderate: the attacker needs pre-existing vlMGP votable power (which requires previously locking MGP - a real but sunk cost, not flash-loanable, and reusable indefinitely since vote/unvote have no cooldown). The attack is fully permissionless (`harvestAll()` has no access control), requires no privileged role, and is repeatable every time meaningful bribes accrue for the delegatedPool's voted pools. The larger the attacker's vlMGP stake relative to `totalSupply` and the longer bribes have accrued since the last harvest, the larger the theft.

### Recommendation
Restrict `harvestAll()` to be callable only by the `operator` (`WombatBribeManager`) as part of `castVotes()`, mirroring the `onlyOperator` modifier already used on `stakeFor`/`withdrawFor`. Additionally, consider adding a minimum holding/lock period before newly staked vlMGP votes become eligible for freshly harvested rewards, or checkpoint pending bribes prior to any stake change so that new depositors cannot capture rewards accrued before their deposit.

### Proof of Concept
Foundry test plan:
1. Deploy `WombatBribeManager`, `DelegateVoteRewardPool` (as delegatedPool rewarder), and mock bribe/voter contracts that accrue bribes over time.
2. Have a long-term voter (Alice) vote a stable vlMGP amount into `delegatedPool` and let bribes accrue (e.g., via mock bribe manager) over several blocks/days without harvesting.
3. Attacker (Bob), holding a large pre-existing vlMGP votable balance, calls `WombatBribeManager.vote([delegatedPoolLp], [largeDelta])` in the current block.
4. Bob calls `DelegateVoteRewardPool.harvestAll()` directly (not through `castVotes`), triggering `claimAllBribes` and `_manageRewards`, updating `rewardPerTokenStored` over the now-inflated `totalSupply`.
5. Bob immediately calls `WombatBribeManager.unvote(delegatedPoolLp)`, which internally claims his reward share via `_getReward`.
6. Assert: Bob's claimed reward (`rewardPaid` event amount) is greater than `(bribeAccrued * timeInPool / totalTimeWeightedContribution)` i.e., disproportionate to his zero-length holding period, while Alice's subsequently claimable reward via `getReward` is measurably reduced compared to a baseline scenario where Bob never voted/unvoted.

    function _queueNewRewardsWithoutTransfer(
        uint256 _amountReward,
        address _rewardToken
    ) internal {
        if (!isRewardToken[_rewardToken]) {
            rewardTokens.push(_rewardToken);
            isRewardToken[_rewardToken] = true;
        }
        Reward storage rewardInfo = rewards[_rewardToken];
        rewardInfo.historicalRewards =
            rewardInfo.historicalRewards +
            _amountReward;
        if (totalSupply == 0) {
            rewardInfo.queuedRewards += _amountReward;
        } else {
            if (rewardInfo.queuedRewards > 0) {
                _amountReward += rewardInfo.queuedRewards;
                rewardInfo.queuedRewards = 0;
            }
            rewardInfo.rewardPerTokenStored =
                rewardInfo.rewardPerTokenStored +
                (_amountReward * 10 ** this.stakingDecimals()) /
                totalSupply;
        }
        emit RewardAdded(_amountReward, _rewardToken);
    }
