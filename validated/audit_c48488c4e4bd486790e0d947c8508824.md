## Analysis Result

While investigating the reported bug class (missing address checks enabling asset loss during a transfer), I found that sei-chain's Astaria-analog code (the pointer contracts that wrap CosmWasm NFTs as ERC-721 tokens) already implements the recipient zero-address check that the original report flags as missing. However, in the same function I found a stronger, exploitable variant of the underlying bug class ("transfers NFT without any [caller] check") in the `CW721ERC721Pointer` contract.

### Title
Missing caller-authorization check in `CW721ERC721Pointer.transferFrom` allows any address to steal pointer-wrapped NFTs - (File: contracts/src/CW721ERC721Pointer.sol)

### Summary
`CW721ERC721Pointer.transferFrom` overrides OpenZeppelin's `ERC721.transferFrom` but drops the caller-authorization check (`_isApprovedOrOwner`). It only validates that the recipient is not the zero address and that `from` really owns the token — it never checks that `msg.sender` is the owner, an approved address, or an approved operator for the token. [1](#0-0) 

### Finding Description
The pointer contract's `transferFrom` is:
```solidity
function transferFrom(address from, address to, uint256 tokenId) public override {
    if (to == address(0)) {
        revert ERC721InvalidReceiver(address(0));
    }
    require(from == ownerOf(tokenId), "`from` must be the owner");
    string memory recipient = _formatPayload("recipient", _doubleQuotes(AddrPrecompile.getSeiAddr(to)));
    string memory tId = _formatPayload("token_id", _doubleQuotes(Strings.toString(tokenId)));
    string memory req = _curlyBrace(_formatPayload("transfer_nft", _curlyBrace(_join(recipient, tId, ","))));
    _execute(bytes(req));
}
``` [2](#0-1) 

Unlike the standard OpenZeppelin `ERC721.transferFrom` (and unlike the contrasting `CW1155ERC1155Pointer.safeTransferFrom`, which explicitly requires `msg.sender == from || isApprovedForAll(from, msg.sender)`), this override never checks `msg.sender` against ownership or approval: [3](#0-2) 

The only guard is `require(from == ownerOf(tokenId), ...)`, which is trivially satisfiable by any attacker simply passing the real owner's address as `from` — this does not prove the caller has any right to move the token. The function then executes a `transfer_nft` CosmWasm message via the wasmd precompile, moving the underlying CW721 token from the real owner to any `to` address the attacker chooses.

### Impact Explanation
Any unprivileged EVM account can call `CW721ERC721Pointer.transferFrom(victimOwner, attackerAddress, tokenId)` for any NFT tracked by the pointer, transferring it out of the true owner's control without their consent, approval, or signature. This is a direct, permanent unauthorized transfer of an NFT (concrete fund/asset loss) reachable by a single public transaction — matching the "unauthorized transfer via precompile or pointer" acceptance criterion.

### Likelihood Explanation
Trivial to trigger: it requires only a single EVM transaction calling the public `transferFrom` function on any deployed `CW721ERC721Pointer` instance with the real owner's address as `from` and the attacker's address as `to`. No special privileges, front-running, or race conditions are needed.

### Recommendation
Restore the standard ERC-721 authorization check before executing the transfer, e.g.:
```solidity
require(_isApprovedOrOwner(msg.sender, tokenId), "not authorized to transfer");
```
or equivalently check `msg.sender == from || getApproved(tokenId) == msg.sender || isApprovedForAll(from, msg.sender)` prior to invoking the CosmWasm `transfer_nft` execution.

### Proof of Concept
1. Owner `O` owns CW721 token `id=1`, exposed as ERC-721 via `CW721ERC721Pointer` at address `P`.
2. Attacker `A` (unrelated EVM account with no approval) calls `P.transferFrom(O, A, 1)`.
3. `transferFrom` checks `to != address(0)` (passes) and `from == ownerOf(1)` (passes, since `O` is indeed the owner) — no check that `msg.sender == A` has any rights over token `1`.
4. The contract executes `{"transfer_nft":{"recipient": <A's sei addr>, "token_id":"1"}}` against the underlying CW721 contract via the wasmd precompile, transferring the NFT from `O` to `A` with no consent from `O`.
