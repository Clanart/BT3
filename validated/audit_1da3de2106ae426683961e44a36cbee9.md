Chia's architecture has no analog to the Curve LP oracle / read-only reentrancy bug class. That vulnerability depends on: (1) an on-chain price oracle contract calling into a stateful AMM pool's `get_virtual_price()` view function, and (2) the EVM's ability to reenter that pool mid-transaction via `raw_call`/external transfer callbacks while pool state (balances) has been updated but LP token supply hasn't been burned yet, producing a transiently-incorrect price that a separate lending/liquidation contract reads and acts upon.

Chia has no equivalent mechanism reachable by an unprivileged spend-bundle submitter:
- There is no on-chain lending/liquidation protocol, collateral oracle, or AMM "virtual price" computation in this codebase. The only "pool" concept is the plot-NFT/pooling singleton adapter in `chia/pools/`, which tracks farming reward distribution state via singleton lineage, not asset pricing [1](#0-0) .
- CLVM spend bundle validation is atomic per-transaction; there is no mid-transaction "external call" primitive analogous to `raw_call` that lets one coin's spend query another coin's not-yet-finalized state through a callback, so there is no "read-only reentrancy" window to exploit for a stale/deflated price read.
- CAT/offer settlement logic (`chia/wallet/trading/offer.py`) resolves value via fixed notarized payment amounts and `arbitrage()` checks on exact offered/requested coin amounts, not via any dynamically computed pool "virtual price" that could be manipulated by sequencing puzzle callbacks within a spend [2](#0-1) .

Since there is no oracle, AMM, or liquidation mechanism computing an LP-token-style virtual price from a coin's state in this codebase, the reported bug class has no reachable analog under the stated scope rules.

    def arbitrage(self) -> dict[bytes32 | None, int]:
        """
        Returns a dictionary of the type of each asset and amount that is involved in the trade
        With the amount being how much their offered amount within the offer
        exceeds/falls short of their requested amount.
        """
        offered_amounts: dict[bytes32 | None, int] = self.get_offered_amounts()
        requested_amounts: dict[bytes32 | None, int] = self.get_requested_amounts()

        arbitrage_dict: dict[bytes32 | None, int] = {}
        for asset_id in [*requested_amounts.keys(), *offered_amounts.keys()]:
            arbitrage_dict[asset_id] = offered_amounts.get(asset_id, 0) - requested_amounts.get(asset_id, 0)
