# Missing re-validation of peer stake for already-established QUIC connections allows retaining staked-tier QoS after stake is lost - (File: `streamer/src/nonblocking/swqos.rs`, `streamer/src/nonblocking/simple_qos.rs`)

## Summary
The SecondSwap bug is a classic "check-then-use" (TOCTOU) flaw: a privilege flag (`sellable`) is checked once at listing time but never re-verified at the later point where the privilege is actually consumed (`completePurchase`). The Agave analog is in the QUIC connection admission path (`SwQos`/`SimpleQos`): a connecting peer's stake is looked up **once**, at connection-accept time, cached into the connection's context/table entry, and then used for the entire lifetime of that (potentially long-lived) QUIC connection to grant elevated connection-count limits, eviction immunity, and stream-throughput quotas — with no re-check against the periodically refreshed stake set.

## Finding Description
`get_connection_stake` is invoked once when a connection is built via `build_connection_context`, which classifies the peer as `ConnectionPeerType::Staked(stake)` or `Unstaked` and stores `total_stake`/`peer_type` into the `SwQosConnectionContext` / `SimpleQosConnectionContext`. [1](#0-0) 

This cached `peer_type`/`stake` is then used to admit the connection into the `staked_connection_table` with a higher `max_connections_per_staked_peer`, to compute `max_uni_streams`/throttling budget, and to decide whether the connection can survive eviction (`prune_random` compares against each `ConnectionEntry::stake()`, which simply returns the `peer_type` captured at connection-creation time, not a fresh lookup). [2](#0-1) [3](#0-2) 

Meanwhile, the authoritative stake map (`StakedNodes`) is refreshed independently every 5 seconds from the root bank's epoch stakes by `StakedNodesUpdaterService`: [4](#0-3) 

Nothing in `swqos.rs`/`simple_qos.rs` re-queries `staked_nodes` for connections that are already open — `try_add_connection` and `cache_new_connection` only run at connection-establishment, and `on_stream_accepted`/stream throttling (`max_streams_per_throttling_interval`) reuse the stale `conn_context.peer_type`/`total_stake` captured at accept time for the whole connection lifetime. [5](#0-4) [6](#0-5) 

This is exactly the SecondSwap pattern: `listVesting` (connection accept) checks `sellable`/stake, but `completePurchase` (ongoing stream throughput/eviction decisions over the connection's life) never re-checks the up-to-date state.

## Impact Explanation
An unprivileged peer that briefly holds significant stake (e.g., a delegator who stakes, opens QUIC connections while staked, then undelegates/moves stake away, which is entirely normal non-malicious behavior) keeps its elevated `staked_connection_table` slot, its higher `max_connections_per_staked_peer` allotment, its immunity to `prune_random` (since eviction compares stale cached stake against new staked peers' stake), and its stream-throughput share computed from stale `total_stake`, until the connection is closed for unrelated reasons (idle timeout, client disconnect). This lets a now-unstaked/zero-stake remote party continue consuming TPU/QUIC resources at staked-tier priority, degrading service and stream budget available to genuinely current stake-weighted peers — a non-RPC remote resource-exhaustion condition against a core ingestion path (TPU/QUIC), without requiring any malicious/trusted-peer assumption beyond normal stake churn.

## Likelihood Explanation
Stake changes (undelegate, redelegate, deactivation, moving stake between validators) happen routinely every epoch, and `StakedNodesUpdaterService` only refreshes the shared map on a 5-second cadence while independently doing nothing to existing connections. QUIC connections used for TPU submission can remain open well beyond a single stake-refresh cycle or even across epoch boundaries, so the staleness window is not a narrow race — it can persist for the connection's full lifetime. No special privilege beyond obtaining stake once is required to exploit the gap.

## Recommendation
Periodically re-evaluate `peer_type`/stake for already-admitted connections (e.g., during the existing stake-refresh cycle or on each stream admission) instead of trusting the value captured once in `SwQosConnectionContext`/`SimpleQosConnectionContext`/`ConnectionEntry`, and demote/evict connections whose current stake no longer justifies staked-tier treatment.

## Proof of Concept
1. A peer stakes enough to be classified `ConnectionPeerType::Staked(stake)` and opens QUIC connections to a validator's TPU, filling `staked_connection_table` up to `max_connections_per_staked_peer` and locking in a high `max_streams_per_second` budget via `cache_new_connection`. [7](#0-6) 
2. The peer immediately undelegates/removes its stake. Within one `StAKE_REFRESH_CYCLE` (5s), the shared `staked_nodes` map reflects the peer as unstaked/zero-stake. [8](#0-7) 
3. The peer keeps its existing QUIC connections open. No code path re-derives `peer_type`/`total_stake` for those connections; `ConnectionEntry::stake()` and the throttling EMA continue to use the value cached at accept time, so the connection keeps its staked-tier connection slot, eviction immunity, and stream quota indefinitely. [2](#0-1)

impl QosController<SwQosConnectionContext> for SwQos {
    fn build_connection_context(&self, connection: &Connection) -> SwQosConnectionContext {
        let remote_address = connection.remote_address();
        get_connection_stake(connection, &self.staked_nodes).map_or(
            SwQosConnectionContext {
                peer_type: ConnectionPeerType::Unstaked,
                total_stake: 0,
                remote_pubkey: None,
                in_staked_table: false,
                remote_address,
                stream_counter: None,
                last_update: Arc::new(AtomicU64::new(timing::timestamp())),
            },
            |(pubkey, stake, total_stake)| {
                // The heuristic is that the stake should be large enough to have 1 stream pass through within one throttle
                // interval during which we allow max (MAX_STREAMS_PER_MS * STREAM_THROTTLING_INTERVAL_MS) streams.

                let peer_type = {
                    let max_streams_per_ms = self.staked_stream_load_ema.max_streams_per_ms();
                    let min_stake_ratio =
                        1_f64 / (max_streams_per_ms * STREAM_THROTTLING_INTERVAL_MS) as f64;
                    let stake_ratio = stake as f64 / total_stake as f64;
                    if stake_ratio < min_stake_ratio {
                        // If it is a staked connection with ultra low stake ratio, treat it as unstaked.
                        ConnectionPeerType::Unstaked
                    } else {
                        ConnectionPeerType::Staked(stake)
                    }
                };

                SwQosConnectionContext {
                    peer_type,
                    total_stake,
                    remote_pubkey: Some(pubkey),
                    in_staked_table: false,
                    remote_address,
                    last_update: Arc::new(AtomicU64::new(timing::timestamp())),
                    stream_counter: None,
                }
            },
        )
    }

    pub(crate) fn prune_random(&mut self, sample_size: usize, threshold_stake: u64) -> usize {
        let num_pruned = std::iter::once(self.table.len())
            .filter(|&size| size > 0)
            .flat_map(|size| {
                let mut rng = rng();
                repeat_with(move || rng.random_range(0..size))
            })
            .map(|index| {
                let connection = self.table[index].first();
                let stake = connection.map(|connection: &ConnectionEntry<S>| connection.stake());
                (index, stake)
            })
            .take(sample_size)
            .min_by_key(|&(_, stake)| stake)
            .filter(|&(_, stake)| stake < Some(threshold_stake))
            .and_then(|(index, _)| self.table.swap_remove_index(index))
            .map(|(_, connections)| connections.len())
            .unwrap_or_default();
        self.total_size = self.total_size.saturating_sub(num_pruned);
        num_pruned
    }

const STAKE_REFRESH_CYCLE: Duration = Duration::from_secs(5);

pub struct StakedNodesUpdaterService {
    thread_hdl: JoinHandle<()>,
}

impl StakedNodesUpdaterService {
    pub fn new(
        exit: Arc<AtomicBool>,
        bank_forks: Arc<RwLock<BankForks>>,
        staked_nodes: Arc<RwLock<StakedNodes>>,
        staked_nodes_overrides: Arc<RwLock<HashMap<Pubkey, u64>>>,
    ) -> Self {
        let thread_hdl = Builder::new()
            .name("solStakedNodeUd".to_string())
            .spawn(move || {
                while !exit.load(Ordering::Relaxed) {
                    let stakes = {
                        let root_bank = bank_forks.read().unwrap().root_bank();
                        root_bank.current_epoch_staked_nodes()
                    };
                    let overrides = staked_nodes_overrides.read().unwrap().clone();
                    *staked_nodes.write().unwrap() = StakedNodes::new(stakes, overrides);
                    std::thread::sleep(STAKE_REFRESH_CYCLE);
                }
            })
            .unwrap();

        Self { thread_hdl }
    }
