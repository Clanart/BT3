This confirms the mechanism: `capture_git_baseline` (via `git stash create`) snapshots HEAD + uncommitted changes into a new baseline SHA that already bakes in any edits made since the *previous* baseline — so if UPS re-captures a baseline after a dangerous edit has already been made, that edit becomes indistinguishable from "pre-existing" content for future diffs.

### Title
`restore_unreviewed_stop_state` fails to re-arm the correct baseline after a UserPromptSubmit race, permanently dropping the dangerous edit from review - (File: `plugins/security-guidance/hooks/diffstate.py`)

### Summary
`restore_unreviewed_stop_state` only restores `baseline_sha` when the on-disk state currently has none set (`if baseline_sha and not state.get("baseline_sha")`), but `consume_stop_state` already cleared `touched_paths` before the Stop hook's slow LLM/network work completes. During that window the next turn's `UserPromptSubmit` handler can race in, see an empty `touched_paths`, and legitimately overwrite `baseline_sha` with a fresh `git stash create` snapshot that already contains the unreviewed dangerous edit. When the original Stop hook later calls `restore_unreviewed_stop_state` on transient failure, the guard blocks restoring the true (older) baseline, so the dangerous edit is baked into the new baseline and silently excluded from all future diffs.

### Finding Description
The Stop-hook flow in `handle_stop_hook` (`plugins/security-guidance/hooks/security_reminder_hook.py`) is asynchronous ("asyncRewake") and can still be executing (network calls to `api.anthropic.com`, LLM review) after the user has already submitted the next prompt, per the code's own comments [1](#0-0) . It begins by calling `consume_stop_state`, which atomically snapshots `touched_paths`/`baseline_sha` and clears `touched_paths` on disk [2](#0-1) .

Between that clear and the eventual `restore_unreviewed_stop_state` call (reachable on `ensure_anthropic_reachable()` failure or an LLM HTTP error, i.e. "retry after partial stop-hook failure") [3](#0-2) [4](#0-3) , the next turn's `handle_user_prompt_submit` can run concurrently. Its preservation guard checks `if state.get("touched_paths") and state.get("baseline_sha"))` to decide whether to keep the old baseline [5](#0-4) . Because `touched_paths` was already cleared by `consume_stop_state`, this check evaluates false, so UPS overwrites `baseline_sha` with a brand-new `capture_git_baseline` SHA — which via `git stash create` bakes in HEAD *plus all current uncommitted changes*, including the still-unreviewed dangerous edit [6](#0-5) .

When the stalled Stop hook finally calls `restore_unreviewed_stop_state(session_id, touched_paths, snap_baseline)`, the touched_paths list is correctly merged back in, but the baseline restore is gated by `if baseline_sha and not state.get("baseline_sha")` [7](#0-6) . Since UPS already wrote a (new) baseline_sha, this condition is false, and the original correct baseline (`snap_baseline`) is discarded.

Critically, `compute_v2_review_set` never consults `touched_paths` at all — it computes `review_set = dirty_now ∩ changed_since(baseline_sha)` purely from git state [8](#0-7) . Since the dangerous file's content now matches the new baseline snapshot exactly, `changed_since` excludes it, so it silently drops out of the review set on the next Stop fire — even though `touched_paths` (which is not actually used for scoping) still nominally "contains" it. This breaks the stated invariant that the review set stay bound to the correct baseline for edits made during the session.

### Impact Explanation
This is a logic-level bypass of the security-guidance Stop-hook review gate: an edit that introduces a dangerous pattern is durably excluded from LLM security review because the baseline used for diffing silently advances past it. This matches "Logic-level service disruption caused by bypassing a required guard or misbinding security state" — the review pipeline's baseline gets misbound to a state that already contains the unreviewed change, defeating the guard whose entire purpose is to force review of turn-scoped edits.

### Likelihood Explanation
No privileged access is required — an ordinary user/agent operating in a cloned repo can trigger this purely through normal timing: edit a file, let the Stop hook begin its (network-dependent) review, and submit the next prompt before that Stop hook completes. Transient `api.anthropic.com` unreachability or an LLM HTTP error (both explicitly handled, non-exotic conditions) is sufficient to hit the `restore_unreviewed_stop_state` path, and the race window between `consume_stop_state`'s clear and that restore call spans the full LLM round-trip, making the race easily repeatable in practice, especially on slow networks or with rapid follow-up prompts.

### Recommendation
Track the *intended* baseline explicitly across the consume→restore window (e.g., have `consume_stop_state` mark the state as "Stop in flight" with the snapshotted baseline, and have UPS's preservation check consult that marker instead of/in addition to `touched_paths`), or make `restore_unreviewed_stop_state` unconditionally restore `snap_baseline` when it is older than (an ancestor of) the current `baseline_sha`, rather than only when none is set.

def capture_git_baseline(cwd):
    """
    Capture a git ref representing the current working tree state.
    Uses `git stash create` which creates a commit object for the current state
    (HEAD + uncommitted changes) without modifying the stash list or working tree.
    Falls back to HEAD if the working tree is clean.
    Returns the SHA string, or None if not in a git repo or if the repo has no commits.

    NOTE: `git stash create` does NOT capture untracked files. UPS pairs this
    SHA with a `_list_untracked()` snapshot stored as `untracked_at_baseline`,
    and `compute_v2_review_set` subtracts that set so pre-existing untracked
    files are not reviewed as Claude-authored.
    """
    try:
        # Check if HEAD exists (i.e., repo has at least one commit)
        head_check = subprocess.run(
            [*GIT_CMD, "rev-parse", "HEAD"],
            cwd=cwd, capture_output=True, text=True, timeout=5
        )
        if head_check.returncode != 0:
            # No commits yet — skip review rather than creating commits in the user's repo
            debug_log("No commits in repo, skipping baseline capture")
            return None

        result = subprocess.run(
            [*GIT_CMD, "stash", "create"],
            cwd=cwd, capture_output=True, text=True, timeout=15
        )
        sha = result.stdout.strip()
        if sha:
            return sha
```

def compute_v2_review_set(cwd, baseline_sha, head_at_capture, untracked_at_baseline=None):
    """v2 diff strategy: derive the review set from git state alone.

    review_set = (files dirty vs current HEAD, plus files committed this turn
    when HEAD advanced linearly) ∩ (files whose content differs from the
    pre-turn stash baseline). The first term is immune to checkout/pull
    ballooning; the second filters out the user's untouched pre-turn WIP.
    Falls back to dirty_now alone when no baseline is available.

    untracked_at_baseline: {repo-root-relative path: mtime_ns} captured at
    UPS. `git stash create` doesn't include untracked files, so without this
    snapshot a pre-existing untracked file looks "new since baseline" forever.
    A file is excluded only if it was untracked at baseline AND its mtime is
    unchanged — an in-place edit during the turn is still reviewed.

    Known limitation: a Bash-only turn that's interrupted before Stop fires
    leaves touched_paths empty, so the next UPS re-baselines past those edits.
    v1 never reviews Bash-only turns at all, so v2 is no worse there.

    Returns (absolute paths sorted, diff_base, repo_root, metrics).
    diff_base is "HEAD" unless HEAD advanced linearly this turn (commits),
    in which case it's head_at_capture so committed files produce a diff.
    repo_root is the git toplevel — `git diff --name-only` outputs paths
    relative to it (not to cwd), so the caller's get_git_diff must run
    from there too or pathspecs won't match.

    Also returns the untracked subset of review_set so get_git_diff can do
    a targeted `add -N -- <files>` instead of a whole-tree scan.
    """
    repo = _git_toplevel(cwd) or cwd
    if not isinstance(untracked_at_baseline, dict):
        untracked_at_baseline = {}

    tracked_dirty, untracked = _git_status_porcelain(repo)
    if tracked_dirty is None:
        return [], "HEAD", repo, [], {"dirty_now_count": -1, "changed_since_count": -1, "review_set_count": 0}

    def _unchanged_since_baseline(p):
        base_mtime = untracked_at_baseline.get(p)
        if base_mtime is None:
            return False
        try:
            return os.stat(os.path.join(repo, p)).st_mtime_ns == base_mtime
        except OSError:
            return False

    preexisting_unchanged = {p for p in untracked if _unchanged_since_baseline(p)}
    new_untracked = untracked - preexisting_unchanged
    dirty_now = tracked_dirty | new_untracked

    diff_base = "HEAD"
    current_head = _git_rev_parse_head(repo)
    if (head_at_capture and current_head and head_at_capture != current_head
            and _is_ancestor(repo, head_at_capture, current_head)):
        dirty_now |= _git_name_only(repo, f"{head_at_capture}..HEAD") or set()
        diff_base = head_at_capture

    # changed_since: tracked files vs the stash baseline (no temp index — the
    # stash never contained untracked files anyway), then union with
    # currently-untracked. The previous `include_untracked=True` arm cost a
    # full `git add -N .` (slow in large repos) per call to surface
    # untracked files in the diff output — but `git diff <stash>` already
    # lists them as "only in worktree" without that, and we have the explicit
    # set from status regardless.
    if baseline_sha:
        changed_since = _git_name_only(repo, baseline_sha)
        if changed_since is not None:
            changed_since |= new_untracked
    else:
        changed_since = None
    # changed_since is None on missing baseline OR on git error (e.g. the
    # dangling stash SHA was pruned). Either way, don't intersect with ∅ —
    # that would silently zero the review set. Fall back to dirty_now.
    review_set = (dirty_now & changed_since) if changed_since is not None else dirty_now
```
