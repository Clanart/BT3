### Title
Unprivileged call to `claimAllBribes(delegatedPool)` bypasses `_manageRewards`/`_queueNewRewardsWithoutTransfer`, permanently freezing bribe rewards in `DelegateVoteRewardPool` - (File: wombat/WombatBribeManager.sol)

### Summary
`WombatBribeManager.claimAllBribes(address _for)` is a `public` function with no access control and no check that `_for == msg.sender` or that the caller is `delegatedPool` itself. Any unprivileged account can call `claimAllBribes(delegatedPool)` directly, pulling bribe reward tokens from every pool the `DelegateVoteRewardPool` has voted in straight into the `DelegateVoteRewardPool` contract's raw token balance, completely skipping the `harvestAll()` → `_manageRewards()` → `_queueNewRewardsWithoutTransfer()` accounting path that is the only mechanism that updates `rewardPerTokenStored`.

### Finding Description
`claimAllBribes` is declared as `override public` with no restriction on the caller or on the `_for` argument: [1](#0-0) 

For each pool the vote-manager tracks, it checks `userVotedForPoolInVlmgp[_for][lp] > 0` and, if true, calls `IBribeRewardPool(pool.rewarder).getReward(_for, _for)` directly, which internally transfers the earned reward token straight to `_for` via `_getReward`: [2](#0-1) [3](#0-2) 

`userVotedForPoolInVlmgp[delegatedPool][lp]` is populated naturally as part of normal protocol operation: when a user stakes into `DelegateVoteRewardPool`, it calls `_updateVote()`, which calls `IWombatBribeManager(operator).vote(votePools, deltas)`. Since this call originates from the `DelegateVoteRewardPool` contract, `msg.sender == delegatedPool` inside `vote()`, so `userVotedForPoolInVlmgp[delegatedPool][pool.poolAddress]` is incremented for every pool that has voting weight: [4](#0-3) [5](#0-4) [6](#0-5) 

The intended path is `DelegateVoteRewardPool.harvestAll()`, which calls `claimAllBribes(address(this))` and then routes the resulting `rewardTokensList`/`earnedRewards` through `_manageRewards`, which deducts protocol fees and calls `_queueNewRewardsWithoutTransfer` to update `rewards[token].rewardPerTokenStored` (or `queuedRewards` if `totalSupply == 0`): [7](#0-6) [8](#0-7) 

Because `claimAllBribes` is externally callable by anyone with any `_for` value (including `delegatedPool`), an attacker can invoke `WombatBribeManager.claimAllBribes(delegatedPool)` directly. This causes `pool.rewarder.getReward(delegatedPool, delegatedPool)` to fire for every pool where `delegatedPool` has voting power, transferring the raw bribe tokens into `DelegateVoteRewardPool`'s token balance — but `_manageRewards`/`_queueNewRewardsWithoutTransfer` is never invoked, since the attacker's transaction never goes through `DelegateVoteRewardPool.harvestAll()`. The tokens land in the contract but are never reflected in `rewardPerTokenStored`. Because the pool-level `earned(delegatedPool, token)` is zeroed out after this claim (`userRewards[rewardToken][delegatedPool] = 0` in the pool-level rewarder), a subsequent legitimate `harvestAll()` call will see `earnedRewards = 0` for these tokens, so the tokens already sitting in the `DelegateVoteRewardPool` balance are never queued — they are permanently stranded and unclaimable by any staker.

No modifier, `nonReentrant` guard, or `onlyOperator`/caller check exists in `claimAllBribes` to stop `_for` from being an arbitrary address such as `delegatedPool`; the only condition is the pre-existing vote allocation, which is a normal state of the system.

### Impact Explanation
This results in permanent freezing of unclaimed yield: bribe reward tokens are transferred into `DelegateVoteRewardPool` but never accounted for in `rewardPerTokenStored`/`historicalRewards`, so no `DelegateVoteRewardPool` staker can ever claim them via `getReward`/`_getDelegateReward`. This matches the "theft or permanent freezing of unclaimed yield" impact class, and violates the Backing invariant (token balance not fully represented in claimable accounting) permanently (well beyond 24 hours, effectively forever since there is no recovery mechanism in the contract).

### Likelihood Explanation
- No capital is required: the attacker only needs to call a `public` function with an address argument.
- The only precondition (`userVotedForPoolInVlmgp[delegatedPool][lp] > 0`) is satisfied under normal, expected protocol operation whenever any user has staked into `DelegateVoteRewardPool` and votes have been allocated to at least one pool.
- The attack is trivially repeatable every time new bribe rewards accrue for pools the delegated pool has voted in, and it can be front-run against every future intended `harvestAll()` call, permanently siphoning newly accrued rewards into unaccounted, stuck balances.

### Recommendation
Restrict `claimAllBribes` so that when `_for == delegatedPool`, it can only be invoked through `DelegateVoteRewardPool.harvestAll()` (e.g., require `msg.sender == delegatedPool` when `_for == delegatedPool`, or have `harvestAll()` itself pass a flag/only allow the operator to trigger the delegated-pool branch). Alternatively, make `_manageRewards`-style accounting update part of `claimAllBribes` itself (i.e., always queue rewards for `delegatedPool` inside the bribe manager) rather than relying on a separate, un-gated external call chain.

### Proof of Concept
Foundry test plan:
1. Deploy `WombatBribeManager`, `DelegateVoteRewardPool`, and mock `IBribeRewardPool`/pool rewarders with a mock bribe reward token.
2. Set up `delegatedPool` in `WombatBribeManager` via `setDelegatedPool`, add at least one active pool via `addPool`.
3. Simulate a user staking into `DelegateVoteRewardPool` (via `stakeFor`) so that `_updateVote()` casts votes, populating `userVotedForPoolInVlmgp[delegatedPool][lp] > 0`.
4. Have the pool's `rewarder` accrue reward tokens for `delegatedPool` (mock `earned(delegatedPool, token) > 0`, fund the rewarder with tokens).
5. From an arbitrary EOA (attacker), call `WombatBribeManager.claimAllBribes(delegatedPool)` directly (not through `DelegateVoteRewardPool.harvestAll()`).
6. Assert: `IERC20(rewardToken).balanceOf(delegatedPool)` increased by the claimed amount, but `DelegateVoteRewardPool.rewards(rewardToken).rewardPerTokenStored` and `historicalRewards` remain unchanged (still zero or unchanged from before the call).
7. Assert: summing all stakers' `earned()` in `DelegateVoteRewardPool` for that token is less than the actual token balance held by the contract, proving the tokens are permanently stuck and unclaimable.

    function _manageRewards(
        address[] memory rewardTokensList,
        uint256[] memory earnedRewards
    ) internal {
        uint256 length = rewardTokensList.length;
        for (uint256 index = 0; index < length; ++index) {
            uint256 fees = (protocolFee * earnedRewards[index]) / DENOMINATOR;
            if (fees > 0 && feeCollector != address(0)) {
                earnedRewards[index] = earnedRewards[index] - fees;
                IERC20(rewardTokensList[index]).safeTransfer(
                    feeCollector,
                    fees
                );
            }
            if (earnedRewards[index] > 0) {
                _queueNewRewardsWithoutTransfer(
                    earnedRewards[index],
                    rewardTokensList[index]
                );
            }
        }
    }

    /// @notice Sends new rewards to be distributed to the users staking.
    /// @param _amountReward Amount of reward token to be distributed
    /// @param _rewardToken Address reward token
    function _queueNewRewardsWithoutTransfer(
        uint256 _amountReward,
        address _rewardToken
    ) internal {
        if (!isRewardToken[_rewardToken]) {
            rewardTokens.push(_rewardToken);
            isRewardToken[_rewardToken] = true;
        }
        Reward storage rewardInfo = rewards[_rewardToken];
        rewardInfo.historicalRewards =
            rewardInfo.historicalRewards +
            _amountReward;
        if (totalSupply == 0) {
            rewardInfo.queuedRewards += _amountReward;
        } else {
            if (rewardInfo.queuedRewards > 0) {
                _amountReward += rewardInfo.queuedRewards;
                rewardInfo.queuedRewards = 0;
            }
            rewardInfo.rewardPerTokenStored =
                rewardInfo.rewardPerTokenStored +
                (_amountReward * 10 ** this.stakingDecimals()) /
                totalSupply;
        }
        emit RewardAdded(_amountReward, _rewardToken);
    }
