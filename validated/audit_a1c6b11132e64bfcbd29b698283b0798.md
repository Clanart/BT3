### Title
Payout tx OP_RETURN operator-identity binding is not covered by `in_signature`, allowing a third party to rewrite the operator-attribution output and make a funding operator's reimbursement permanently unclaimable - (File: core/src/builder/transaction/operator_reimburse.rs)

### Summary
`create_payout_txhandler` builds the payout transaction's OP_RETURN (which records the fronting operator's xonly pubkey used later by `update_finalized_payouts`/`get_first_unhandled_payout_by_operator_xonly_pk`/`is_kickoff_malicious`) and signs the single input with the withdrawing user's own `taproot::Signature`, without the withdraw path enforcing that this signature covers all outputs (i.e., without requiring `TapSighashType::Default`/`ALL`). Because `update_finalized_payouts` accepts *any* syntactically valid 32-byte value in the OP_RETURN as an "operator xonly pk" (no registration check), and `get_first_unhandled_payout_by_operator_xonly_pk` matches this value by strict equality per configured operator, a witness that does not commit to the OP_RETURN byte-for-byte lets a third party rebroadcast a transaction with the same input/witness/output0 but a different, unregistered OP_RETURN payload - permanently orphaning the withdrawal for the real funding operator and causing that operator's later kickoff to be flagged malicious.

### Finding Description
Binding claimed and verified in code: `withdrawals.payout_payer_operator_xonly_pk` (populated by `update_finalized_payouts`) must equal the xonly pubkey of the operator `O` who actually fronted withdrawal `i`'s payout.

Code path:
1. `Operator::withdraw` builds `payout_txhandler` via `create_payout_txhandler(input_utxo, output_txout, self.signer.xonly_public_key, in_signature, ...)` [1](#0-0) , where `in_signature` is the withdrawing L2 user's own taproot signature, forwarded from the RPC layer without any check that its `sighash_type` is `Default`/`ALL`.
2. `create_payout_txhandler` places `operator_xonly_pk.serialize()` in a fresh OP_RETURN output (`op_return_txout`) and finalizes the witness for input 0 using exactly `user_sig` via `set_p2tr_key_spend_witness(&user_sig, 0)` [2](#0-1) . Nothing in this function or its caller inspects/pins the sighash flag embedded in `user_sig`.
3. On-chain, once mined, `Verifier::update_finalized_payouts` reads whichever OP_RETURN is present in the confirmed payout tx and parses it purely by length/curve validity: `XOnlyPublicKey::from_slice(bytes).ok()` [3](#0-2) . There is no check that the recovered key belongs to any provisioned operator - it is stored as-is via `update_payout_txs_and_payer_operator_xonly_pk` [4](#0-3) .
4. `PayoutCheckerTask::run_once` (each operator's own poller) only looks for its own key via `get_first_unhandled_payout_by_operator_xonly_pk(self.operator.signer.xonly_public_key)`, an exact-equality SQL match [5](#0-4) [6](#0-5) . A garbage/unregistered key is never polled by any real operator.
5. If `O` still attempts a kickoff for that withdrawal (having genuinely fronted the money), `Verifier::is_kickoff_malicious` compares the DB's stored (garbage) `operator_xonly_pk` against `kickoff_data.operator_xonly_pk` and returns `true` on mismatch [7](#0-6) , causing verifiers to treat `O`'s kickoff as malicious and potentially send a `Challenge`, risking `O`'s collateral [8](#0-7) .

Root cause: the OP_RETURN operator-attribution byte string is only cryptographically bound to the rest of the payout transaction by the *signer's chosen* sighash flag, and clementine never fixes or validates that flag before constructing/accepting the transaction. If the user-provided `in_signature` does not use a sighash type that commits to output 2 (the OP_RETURN) - e.g. `SIGHASH_SINGLE`, which under BIP341 commits only to the output at the same index as the spent input (index 0, the user payout output) - the witness stays valid on a mutated transaction that keeps input 0 and output 0 identical but swaps output 2 for an unrelated (but still 32-byte, curve-valid) value. pub fn create_payout_txhandler(
    input_utxo: UTXO,
    output_txout: TxOut,
    operator_xonly_pk: XOnlyPublicKey,
    user_sig: taproot::Signature,
    _network: bitcoin::Network,
) -> Result<TxHandler<Signed>, BridgeError> {
    let txin = SpendableTxIn::new_partial(input_utxo.outpoint, input_utxo.txout);

    let output_txout = UnspentTxOut::from_partial(output_txout.clone());

    let op_return_txout = op_return_txout(PushBytesBuf::from(operator_xonly_pk.serialize()));

    let mut txhandler = TxHandlerBuilder::new(TransactionType::Payout)
        .with_version(NON_STANDARD_V3)
        .add_input(
            NormalSignatureKind::NotStored,
            txin,
            SpendPath::KeySpend,
            DEFAULT_SEQUENCE,
        )
        .add_output(output_txout)
        .add_output(UnspentTxOut::from_partial(anchor_output(
            NON_EPHEMERAL_ANCHOR_AMOUNT,
        )))
        .add_output(UnspentTxOut::from_partial(op_return_txout))
        .finalize();
    txhandler.set_p2tr_key_spend_witness(&user_sig, 0)?;
    txhandler.promote()
}

    pub async fn update_payout_txs_and_payer_operator_xonly_pk(
        &self,
        tx: Option<DatabaseTransaction<'_>>,
        payout_txs_and_payer_operator_xonly_pk: Vec<(
            u32,
            Txid,
            Option<XOnlyPublicKey>,
            bitcoin::BlockHash,
        )>,
    ) -> Result<(), BridgeError> {
        if payout_txs_and_payer_operator_xonly_pk.is_empty() {
            return Ok(());
        }
        // Convert all values first, propagating any errors
        let converted_values: Result<Vec<_>, BridgeError> = payout_txs_and_payer_operator_xonly_pk
            .iter()
            .map(|(idx, txid, operator_xonly_pk, block_hash)| {
                Ok((
                    i32::try_from(*idx).wrap_err("Failed to convert payout index to i32")?,
                    TxidDB(*txid),
                    operator_xonly_pk.map(XOnlyPublicKeyDB),
                    BlockHashDB(*block_hash),
                ))
            })
            .collect();
        let converted_values = converted_values?;

        let mut query_builder = QueryBuilder::new(
            "UPDATE withdrawals AS w SET
                payout_txid = c.payout_txid,
                payout_payer_operator_xonly_pk = c.payout_payer_operator_xonly_pk,
                payout_tx_blockhash = c.payout_tx_blockhash
                FROM (",
        );

        query_builder.push_values(
            converted_values.into_iter(),
            |mut b, (idx, txid, operator_xonly_pk, block_hash)| {
                b.push_bind(idx)
                    .push_bind(txid)
                    .push_bind(operator_xonly_pk)
                    .push_bind(block_hash);
            },
        );

        query_builder
            .push(") AS c(idx, payout_txid, payout_payer_operator_xonly_pk, payout_tx_blockhash) WHERE w.idx = c.idx");

        let query = query_builder.build();
        execute_query_with_tx!(self.connection, tx, query, execute)?;

        Ok(())
    }

    pub async fn get_first_unhandled_payout_by_operator_xonly_pk(
        &self,
        tx: Option<DatabaseTransaction<'_>>,
        operator_xonly_pk: XOnlyPublicKey,
    ) -> Result<Option<(u32, Txid, BlockHash)>, BridgeError> {
        let query = sqlx::query_as::<_, (i32, Option<TxidDB>, Option<BlockHashDB>)>(
            "SELECT w.idx, w.move_to_vault_txid, w.payout_tx_blockhash
             FROM withdrawals w
             WHERE w.payout_txid IS NOT NULL
                AND w.is_payout_handled = FALSE
                AND w.payout_payer_operator_xonly_pk = $1
                ORDER BY w.idx ASC
             LIMIT 1",
        )
        .bind(XOnlyPublicKeyDB(operator_xonly_pk));

        let results = execute_query_with_tx!(self.connection, tx, query, fetch_optional)?;

        results
            .map(|(citrea_idx, move_to_vault_txid, payout_tx_blockhash)| {
                Ok((
                    u32::try_from(citrea_idx).wrap_err("Failed to convert citrea index to u32")?,
                    move_to_vault_txid
                        .expect("move_to_vault_txid Must be Some")
                        .0,
                    payout_tx_blockhash
                        .expect("payout_tx_blockhash Must be Some")
                        .0,
                ))
            })
            .transpose()
    }
