### Title
Missing deadline re-validation in Gasless Swap bundle execution path allows inclusion of expired GaslessSwapTx - (File: kaiax/gasless/impl/getter.go)

### Summary
`GaslessModule.VerifyExecutable` (and the `IsExecutable` wrapper it backs) — the function that gates whether a `GaslessApproveTx`/`GaslessSwapTx` pair is treated as bundleable and gets promoted/executed in a block — never checks `SwapArgs.Deadline` against the current chain time. The only place the deadline is checked is `checkBalanceForSwap` in `kaiax/gasless/impl/tx_pool.go`, which runs once at tx-pool admission (`GetCheckBalance`). Because the pool-admission check and the block-building/execution-decision check are two separate, non-re-synchronized checkpoints, an already-admitted `GaslessSwapTx` whose `deadline` has since elapsed can still be judged "executable" and bundled/executed by `ExtractTxBundles`.

### Finding Description
The KIP-247 gasless flow validates a swap transaction's staleness cutoff (`deadline`) only inside `checkBalanceForSwap`: [1](#0-0) 

This function is invoked through `GetCheckBalance()`, which is a `TxPoolModule` hook exercised when the transaction is admitted to the pool: [2](#0-1) 

However, the code path that actually decides whether a `GaslessSwapTx` is executable and should be bundled into a block — `VerifyExecutable`/`IsExecutable`, called from `ExtractTxBundles` at block-construction time — never touches `Deadline` at all. It only checks decode validity, sender/token/amount consistency, and nonce sequencing (Sx, Ax, AP1, SP1–SP4): [3](#0-2) 

`ExtractTxBundles` (the `TxBundlingModule` entrypoint used by the block builder/worker) relies solely on `IsExecutable` to decide inclusion — it performs no additional deadline check: [4](#0-3) 

A `GaslessSwapTx` can sit in the pool for an extended period before being promoted to `pending`/bundled — e.g. while it is nonce-gapped behind its paired `ApproveTx`, or while pool/block-building capacity is constrained (`GetMaxBundleTxsInPending`, `IsReady` flow control). The admission-time deadline check therefore does not guarantee the deadline is still valid by the time the transaction is actually selected, bundled, and executed by `ApplyTransactions`/`commitBundleTransaction` in the worker.

### Impact Explanation
The `deadline` field exists specifically to bound the staleness window in which the declared `MinAmountOut`/`AmountRepay` economics remain valid (classic AMM slippage/staleness protection, analogous to Uniswap-style deadlines). Because the block-building decision path (`IsExecutable`/`VerifyExecutable`) omits this re-check:
- A `GaslessSwapTx` that has technically expired can still be selected, wrapped with a proposer-funded `LendTxGenerator`, and executed on-chain.
- The block proposer fronts gas for a stale swap whose price/slippage guarantees were computed against a swap-router state that may have materially diverged by execution time, exposing the gasless settlement (and the fee-delegating proposer) to unfavorable execution or arbitrage extraction that the `deadline` mechanism was designed to prevent.
- Different nodes building blocks at different wall-clock/height offsets can reach different bundling decisions for the same pooled transaction (one includes it as "still executable", another rejects), which is a state-divergence risk between honest block producers for the same pending transaction set.

This mirrors the CVE-2021-35473 bug class: a validity/expiration check enforced only at one checkpoint (initial admission/first validation) is not re-verified at the point where the privileged action (final resource use / here, block inclusion and value settlement) actually occurs.

### Likelihood Explanation
Any unprivileged gasless user (or an attacker crafting/replaying a `GaslessApproveTx`+`GaslessSwapTx` pair) can trigger this by submitting a valid pair near the pool's promotion boundary (e.g., relying on nonce-gap queuing or waiting for a `MaxBundleTxsInPending` window) and letting the deadline lapse before the pair is actually picked up by `ExtractTxBundles`. No special privileges, node compromise, or off-chain component access is required — only normal transaction submission via public RPC.

### Recommendation
Re-validate `SwapArgs.Deadline` against `g.Chain.CurrentBlock().Time()` (or the block being built) inside `VerifyExecutable`/`IsExecutable` (`kaiax/gasless/impl/getter.go`), not only inside `checkBalanceForSwap` (`kaiax/gasless/impl/tx_pool.go`). This ensures the deadline invariant is enforced at the actual point of block inclusion/execution, not merely at initial pool admission.

### Proof of Concept
1. Submit `GaslessApproveTx` (nonce N) and `GaslessSwapTx` (nonce N+1, `Deadline = now + Δ`) to the pool; `checkBalanceForSwap` accepts them because `deadline >= CurrentBlock().Time()` at that moment. [1](#0-0) 
2. Delay promotion (e.g., via pool congestion, `MaxBundleTxsInPending` throttling, or simply waiting several blocks) until `Deadline < CurrentBlock().Time()`.
3. When the builder later calls `ExtractTxBundles` → `IsExecutable(approveTx, swapTx)` → `VerifyExecutable`, none of the checks reference `Deadline`, so the pair is still reported executable and gets bundled: [5](#0-4) 
4. The bundle (`LendTxGenerator`, `ApproveTx`, `SwapTx`) is included and executed by the worker, settling an expired gasless swap despite the deadline having elapsed.

func (g *GaslessModule) GetCheckBalance() func(tx *types.Transaction) error {
	return func(tx *types.Transaction) error {
		if approveArgs, ok := decodeApproveTx(tx, g.signer); ok {
			return g.checkBalanceForApprove(approveArgs)
		}
		if swapArgs, ok := decodeSwapTx(tx, g.signer); ok {
			return g.checkBalanceForSwap(swapArgs, tx.Nonce())
		}
		return errors.New("not a gasless transaction") // should not happen because IsModuleTx is called before GetCheckBalance
	}
}

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
}
