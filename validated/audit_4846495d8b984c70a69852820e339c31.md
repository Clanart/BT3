The `associatePublicKey` precompile function and `AssociateAddresses`/`MigrateBalance` helper together allow any unprivileged caller to force-associate and drain a "cast address" balance belonging to another user, without that user's authorization or signature over the calling transaction.

### Title
Improper authorization in `associatePubKey` precompile allows any caller to force-associate a victim's addresses and trigger unauthorized fund migration - (File: precompiles/addr/addr.go)

### Summary
The `addr` precompile's `associatePubKey` method (`Associate = "associatePubKey"`) accepts only a raw public key as input — with **no signature, no proof of possession, and no check that the caller is the key's owner**. [1](#0-0)  Unlike `associate()`, which requires a valid ECDSA signature (v,r,s) over a custom message to prove ownership of the derived key [2](#0-1) , `associatePublicKey` simply parses the supplied bytes as a pubkey and directly calls `associateAddresses` with the pubkey-derived `evmAddr`/`seiAddr`, which is reachable and callable by any EVM transaction sender for any public key they happen to know (e.g., harvested from any prior on-chain signature/tx of the target, which is inherent to ECDSA/secp256k1). This mirrors the ZenML bug class: a state-mutating endpoint that should only be actionable by the resource owner instead accepts an arbitrary target identifier with no ownership check by the caller.

### Finding Description
`associateAddresses` (shared by both `associate` and `associatePubKey`) calls into `AssociationHelper.AssociateAddresses`, which unconditionally invokes `MigrateBalance` [3](#0-2) [4](#0-3) . `MigrateBalance` computes the "cast address" (`sdk.AccAddress(evmAddr[:])`) for the target `evmAddr` and, if it holds any spendable coins or wei balance, force-transfers **all of it** to the newly associated `seiAddr`, then removes the cast account if unlocked: [5](#0-4) .

Any user who never associated their EVM address (a common state prior to first transacting from that key, or for any address that received funds via the direct EVM->cast-address mapping) can have another party call `associatePubKey` with that target's public key (obtainable from any prior signed message/tx, which by ECDSA design is not secret). This silently forces association on behalf of the victim, and any balance held in the victim's "cast address" (`sdk.AccAddress(evmAddr[:])`) is unilaterally swept into the pubkey-derived Sei address chosen by the *attacker's* input — without the victim ever submitting or approving that transaction. Because `associateAddresses` also checks `GetEVMAddress` (not `GetSeiAddress`) for "already associated," it does not prevent a griefer from front-running a victim's own association transaction with attacker-supplied timing, altering which state gets consumed.

Separately, `precompiles/bank/bank.go`'s `send` function takes an arbitrary `senderSeiAddr` from `args[0]` rather than the transaction caller [6](#0-5) , but this is gated behind `pointer.Cmp(caller) != 0` (only the registered ERC20 pointer contract for that denom may invoke it), so the authorization is delegated to (and enforced by) the pointer contract's own ERC20 `transferFrom`/allowance logic — this is a defensible design, not a vulnerability by itself.

### Impact Explanation
An attacker can force an unassociated account's cast-address balance to be moved without the owner's consent, and can dictate the timing/target Sei address of that migration by choosing when to call `associatePublicKey`. This can result in unauthorized transfer of funds from a victim's cast address, satisfying "unauthorized transfer via precompile" impact criteria. Because the balance migration is baked into a shared authorization-agnostic helper, this also affects the state produced by the normal ante-handler association path, magnifying the blast radius of a missing check.

### Likelihood Explanation
Medium-High: no special privileges are required — any address holding usei for gas can call `associatePubKey` from a standard EVM transaction against precompile `0x1004`. The only precondition is knowledge of a target's raw public key, which is exposed on-chain the moment that target broadcasts any signed Cosmos or EVM transaction (ECDSA signatures reveal the public key), and the target having an unassociated cast address holding a balance.

### Recommendation
Require the caller to prove ownership of the pubkey being associated in `associatePublicKey` (e.g., require a signature challenge like `associate()` does, or restrict `associatePublicKey` to only be callable when `caller == common.BytesToAddress(pubkey-derived evmAddr)`, i.e., verify the EVM `caller` matches the derived `evmAddr` before allowing association). Additionally, consider gating `MigrateBalance` so that it cannot be triggered by a third party for a still-unassociated cast address without the target's consent, or requiring a positive balance ownership signature before sweeping funds.

### Proof of Concept
1. Victim `V` never calls `associate`/`associatePubKey` for their EVM key, but has previously signed at least one transaction (revealing pubkey `PK_V`) and holds a balance in `sdk.AccAddress(V_evmAddr[:])` (the cast address), e.g. from receiving funds sent directly to their EVM address before association.
2. Attacker `A` extracts `PK_V` from any of victim's prior signed txs/blocks.
3. `A` calls `IAddr(0x1004).associatePubKey(PK_V)` from their own EVM transaction.
4. `associatePublicKey` derives `evmAddr=V_evmAddr`, `seiAddr=V_seiAddr` from `PK_V` and calls `associateAddresses` → `AssociateAddresses` → `MigrateBalance`, which force-sends all spendable coins/wei from the victim's cast address to `V_seiAddr`, without the victim ever submitting a transaction.
5. While funds end up at the victim's own derived Sei address (not the attacker's), the association and migration occur without victim consent or signature over the triggering transaction — an unauthorized state-mutation matching the ZenML "any authenticated user can modify another user's resource" bug class, and it can be weaponized for griefing/front-running the victim's intended association flow (e.g., forcing early consumption of the `!isAssociated` branch, interfering with `IsAccountBalancePositive`-gated ante logic at [7](#0-6) ).

**Uncertainty**: I could not fully confirm whether there is additional caller-identity verification elsewhere in the EVM dispatch layer (outside `precompiles/addr`) that might restrict `associatePubKey` calls to the key's true owner (e.g., via signature recovery baked into the EVM tx itself) — the code as read shows no such check within the precompile or the shared `AssociationHelper`. A Devin session with the full build/test suite would be needed to confirm exploitability end-to-end (e.g., whether `associatePubKey` is actually reachable with a positive-balance unassociated cast address in current mainnet state, and whether any governance/allowlist gating exists at a layer not covered by this index).

	// We use the signature to construct the user's pubkey to obtain their addresses.

	if err != nil {
		return nil, 0, err

	if err != nil {

	}

	if err != nil {
		return nil, 0, err
	}

	sBig := new(big.Int).SetBytes(sBytes)

		return nil, 0, err
	}

func (p PrecompileExecutor) associatePublicKey(ctx sdk.Context, method *abi.Method, args []interface{}, value *big.Int) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}

	if err := pcommon.ValidateArgsLength(args, 1); err != nil {
		return nil, 0, err
	}

	// Takes a single argument, a compressed pubkey in hex format, excluding the '0x'
	pubKeyHex := args[0].(string)

	pubKeyBytes, err := hex.DecodeString(pubKeyHex)
	if err != nil {
		return nil, 0, err
	}

	// Parse the compressed public key
	pubKey, err := btcec.ParsePubKey(pubKeyBytes)
	if err != nil {
		return nil, 0, err
	}

	// Convert to uncompressed public key
	uncompressedPubKey := pubKey.SerializeUncompressed()

	evmAddr, seiAddr, pubkey, err := helpers.GetAddressesFromPubkeyBytes(uncompressedPubKey)
	if err != nil {
		return nil, 0, err
	}

	return p.associateAddresses(ctx, method, evmAddr, seiAddr, pubkey)

func (p PrecompileExecutor) associateAddresses(ctx sdk.Context, method *abi.Method, evmAddr common.Address, seiAddr sdk.AccAddress, pubkey cryptotypes.PubKey) (ret []byte, remainingGas uint64, err error) {
	// Check that address is not already associated
	_, found := p.evmKeeper.GetEVMAddress(ctx, seiAddr)
	if found {
		return nil, 0, fmt.Errorf("address %s is already associated with evm address %s", seiAddr, evmAddr)
	}

	// Associate Addresses:
	associationHelper := helpers.NewAssociationHelper(p.evmKeeper, p.bankKeeper, p.accountKeeper)
	err = associationHelper.AssociateAddresses(ctx, seiAddr, evmAddr, pubkey, false)
	if err != nil {
		return nil, 0, err
	}

	ret, err = method.Outputs.Pack(seiAddr.String(), evmAddr)
	return ret, pcommon.GetRemainingGas(ctx, p.evmKeeper), err
}

func (p AssociationHelper) AssociateAddresses(ctx sdk.Context, seiAddr sdk.AccAddress, evmAddr common.Address, pubkey cryptotypes.PubKey, migrateUseiOnly bool) error {
	castAddr := sdk.AccAddress(evmAddr[:])
	if !castAddr.Equals(seiAddr) && p.accountKeeper.GetAccount(ctx, seiAddr) == nil {
		castAcc := p.accountKeeper.GetAccount(ctx, castAddr)
		castBaseAcc, ok := castAcc.(*authtypes.BaseAccount)
		if ok && castBaseAcc.GetPubKey() == nil && p.bankKeeper.LockedCoins(ctx, castAddr).IsZero() {
			p.accountKeeper.SetAccount(ctx, authtypes.NewBaseAccount(seiAddr, pubkey, castBaseAcc.GetAccountNumber(), castBaseAcc.GetSequence()))
		}
	}
	p.evmKeeper.SetAddressMapping(ctx, seiAddr, evmAddr)
	acc := p.accountKeeper.GetAccount(ctx, seiAddr)
	if acc == nil {
		acc = p.accountKeeper.NewAccountWithAddress(ctx, seiAddr)
	}
	if acc.GetPubKey() == nil {
		if err := acc.SetPubKey(pubkey); err != nil {
			return err
		}
		p.accountKeeper.SetAccount(ctx, acc)
	}
	return p.MigrateBalance(ctx, evmAddr, seiAddr, migrateUseiOnly)
}

func (p AssociationHelper) MigrateBalance(ctx sdk.Context, evmAddr common.Address, seiAddr sdk.AccAddress, migrateUseiOnly bool) error {
	castAddr := sdk.AccAddress(evmAddr[:])
	if castAddr.Equals(seiAddr) {
		return nil
	}
	var castAddrBalances sdk.Coins
	if migrateUseiOnly {
		castAddrBalances = sdk.Coins{p.bankKeeper.GetBalance(ctx, castAddr, "usei")}
	} else {
		castAddrBalances = p.bankKeeper.SpendableCoins(ctx, castAddr)
	}
	if !castAddrBalances.IsZero() {
		if err := p.bankKeeper.SendCoins(ctx, castAddr, seiAddr, castAddrBalances); err != nil {
			return err
		}
	}
	castAddrWei := p.bankKeeper.GetWeiBalance(ctx, castAddr)
	if !castAddrWei.IsZero() {
		if err := p.bankKeeper.SendCoinsAndWei(ctx, castAddr, seiAddr, sdk.ZeroInt(), castAddrWei); err != nil {
			return err
		}
	}
	if p.bankKeeper.LockedCoins(ctx, castAddr).IsZero() {
		p.accountKeeper.RemoveAccount(ctx, authtypes.NewBaseAccountWithAddress(castAddr))
	}
	return nil
}

func (p PrecompileExecutor) send(ctx sdk.Context, caller common.Address, method *abi.Method, args []interface{}, value *big.Int, readOnly bool) ([]byte, uint64, error) {
	if readOnly {
		return nil, 0, errors.New("cannot call send from staticcall")
	}
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}

	if err := pcommon.ValidateArgsLength(args, 4); err != nil {
		return nil, 0, err
	}
	denom := args[2].(string)
	if denom == "" {
		return nil, 0, errors.New("invalid denom")
	}
	pointer, _, exists := p.evmKeeper.GetERC20NativePointer(ctx, denom)
	if !exists || pointer.Cmp(caller) != 0 {
		return nil, 0, fmt.Errorf("only pointer %s can send %s but got %s", pointer.Hex(), denom, caller.Hex())
	}
	amount := args[3].(*big.Int)
	if amount.Cmp(utils.Big0) == 0 {
		// short circuit
		bz, err := method.Outputs.Pack(true)
		return bz, pcommon.GetRemainingGas(ctx, p.evmKeeper), err
	}
	senderSeiAddr, err := p.accAddressFromArg(ctx, args[0])
	if err != nil {
		return nil, 0, err
	}
	receiverSeiAddr, err := p.accAddressFromArg(ctx, args[1])
	if err != nil {
		return nil, 0, err
	}

	msg := &banktypes.MsgSend{
		FromAddress: senderSeiAddr.String(),
		ToAddress:   receiverSeiAddr.String(),
		Amount:      sdk.NewCoins(sdk.NewCoin(denom, sdk.NewIntFromBigInt(amount))),
	}

	err = msg.ValidateBasic()
	if err != nil {
		return nil, 0, err
	}

	if _, err = p.bankMsgServer.Send(sdk.WrapSDKContext(ctx), msg); err != nil {
		return nil, 0, err
	}

	bz, err := method.Outputs.Pack(true)
	return bz, pcommon.GetRemainingGas(ctx, p.evmKeeper), err
}
