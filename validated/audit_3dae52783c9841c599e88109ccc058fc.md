### Title
Stale cached GaslessSwapRouter address lets bundled Gasless swaps be admitted and revert, causing proposer fee-lending loss - (File: kaiax/gasless/impl/getter.go, kaiax/gasless/impl/execution.go)

### Summary
The external report's bug class ("transactions routed through a contract that can be paused/changed mid-flight fail and someone loses fees") maps onto `kaiax/gasless`'s router address caching. `GaslessModule` validates `IsApproveTx`/`IsSwapTx`/`VerifyExecutable` against a swap-router address cache that is refreshed only once per finalized block (`PostInsertBlock` → `updateAddresses`), while the actual bundle (`[LendTxGenerator, ApproveTx, SwapTx]`) is built and executed within the *next* block, using live, current EVM/registry state.

### Finding Description
`isApproveTx`/`isSwapTx` compare the transaction's target address against `g.swapRouter`, a value cached from the parent block's `MultiCallGaslessInfo` read [4](#0-3) [5](#0-4) . `ExtractTxBundles` uses these stale checks to decide which pending swap transactions are gasless-eligible and wraps them with a proposer-funded `LendTxGenerator` that unconditionally transfers KAIA to the sender before the approve/swap sequence executes [6](#0-5) [7](#0-6) . If the `GaslessSwapRouter` registration is changed (deactivated/replaced) via any transaction executing earlier in the same block-in-construction — a state change the cache has not yet observed since it only updates in `PostInsertBlock` of the *previous* block — the bundle can still be admitted with the stale router address. When the block is actually executed, the `SwapTx` call to the now-stale router address can revert (e.g., router no longer authorized to pull repay tokens, or contract behavior changed), so the swap's on-chain repayment to the proposer never completes, even though the `LendTx` already unconditionally paid out the lent gas amount to the user.

### Impact Explanation
This is fee-delegation abuse in the gasless flow: the proposer, acting as the delegated fee-payer, transfers value via `LendTx` before verifying that the actual, current router state (not last block's cached copy) will successfully execute the swap and trigger repayment. A user (or malicious actor timing a router change) can cause the proposer to lend funds that are never recovered, since `LendTx` execution is unconditional and precedes the swap/repay step in the bundle. This is a concrete value-movement/fee-loss condition matching the report's bug class, but the loss falls on the block proposer (the fee-delegation counterparty) rather than the end user.

### Likelihood Explanation
Requires the `GaslessSwapRouter` registry entry to be changed within the same block where a previously-cached-valid gasless bundle is included — a narrow timing window, and system-contract registry changes are typically governance-gated, not something an ordinary unprivileged sender can trigger directly. Reachable only indirectly (a sender cannot force a registry update to co-occur with their bundle), so likelihood is low-to-moderate and depends on operational timing of legitimate router migrations.

### Recommendation
Re-validate `isApproveTx`/`isSwapTx` conditions against the state of the block actually being built (not the cached, previous-block value) immediately before executing `LendTx`, or make `LendTx` conditional/atomic with successful `SwapTx` repayment (e.g., bundle-level all-or-nothing execution) so a stale router address cannot result in unconditional value transfer without repayment.

### Proof of Concept
1. Block N-1 finalizes with `GaslessSwapRouter = R1`; `updateAddresses` caches `g.swapRouter = R1` [1](#0-0) .
2. User signs `ApproveTx`(to `R1`) and `SwapTx`(to `R1`) while `R1` is the registered router.
3. Before these txs are bundled into block N, a governance/registry transaction ordered earlier in block N deactivates `R1` (e.g., replaces it with `R2`, and `R1`'s authorization to pull repay funds is revoked).
4. `ExtractTxBundles`, still using the stale `g.swapRouter = R1` cache, admits the bundle: `[LendTxGenerator, ApproveTx, SwapTx]` [8](#0-7) .
5. Block N executes: `LendTx` unconditionally sends `lendAmount` KAIA to the user [9](#0-8) ; `ApproveTx` succeeds trivially; `SwapTx` calls the now-deauthorized `R1` and reverts, so the repay to the proposer never happens.
6. Net effect: proposer's lent KAIA is not recovered.

Note: I could not fully verify within the available exploration whether an additional safeguard exists elsewhere (e.g., in tx-pool promotion/`IsExecutable` re-checks at inclusion time, or bundle atomicity enforced by the block builder) that would prevent `LendTx` from executing without a guaranteed successful `SwapTx`; `kaiax/gasless/impl/tx_pool.go` and `work/builder` bundle-execution semantics were not read in full detail due to iteration limits, so this should be double-checked against those files.

func (g *GaslessModule) isApproveTx(args *ApproveArgs) bool {
	g.gaslessInfoMu.RLock()
	defer g.gaslessInfoMu.RUnlock()

	return g.allowedTokens[args.Token] && // A1
		g.swapRouter == args.Spender && // A3
		args.Amount.Cmp(abi.MaxUint256) == 0 // A4
}

// IsSwapTx checks following conditions:
// S1. tx.to is a whitelisted SwapRouter contract.
// S2. tx.data is `swapForGas(token, amountIn, minAmountOut, amountRepay)`.
// S3. token is a whitelisted ERC20 token.
func (g *GaslessModule) IsSwapTx(tx *types.Transaction) bool {
	args, ok := decodeSwapTx(tx, g.signer)
	return ok && g.isSwapTx(args)
}

func (g *GaslessModule) isSwapTx(args *SwapArgs) bool {
	g.gaslessInfoMu.RLock()
	defer g.gaslessInfoMu.RUnlock()

	return g.swapRouter == args.Router && // S1
		g.allowedTokens[args.Token] // S3
}

// L1. LendTx.type = 0x7802 (TxTypeEthereumDynamicFee)
// L2. LendTx.from = proposer
// L3. LendTx.to = SwapTx.from
// L4. LendTx.value = LendAmount(approveTxOrNil, swapTx)
func (g *GaslessModule) GetLendTxGenerator(approveTxOrNil, swapTx *types.Transaction) *builder.TxOrGen {
	var src []byte
	if approveTxOrNil != nil {
		src = append(src, approveTxOrNil.Hash().Bytes()...)
	}
	src = append(src, swapTx.Hash().Bytes()...)
	bundleHash := crypto.Keccak256Hash(src)

	gen := func(nonce uint64) (*types.Transaction, error) {
		var (
			chainId = g.InitOpts.ChainConfig.ChainID
			signer  = types.LatestSignerForChainID(chainId)
			key     = g.InitOpts.NodeKey
		)

		to, err := types.Sender(signer, swapTx)
		if err != nil {
			return nil, err
		}

		tx, err := types.NewTransactionWithMap(types.TxTypeEthereumDynamicFee, map[types.TxValueKeyType]interface{}{
			types.TxValueKeyNonce:      nonce,
			types.TxValueKeyTo:         &to,
			types.TxValueKeyAmount:     lendAmount(approveTxOrNil, swapTx),
			types.TxValueKeyData:       common.Hex2Bytes("0x"),
			types.TxValueKeyGasLimit:   params.TxGas,
			types.TxValueKeyGasFeeCap:  swapTx.GasFeeCap(),
			types.TxValueKeyGasTipCap:  swapTx.GasTipCap(),
			types.TxValueKeyAccessList: types.AccessList{},
			types.TxValueKeyChainID:    chainId,
		})
		if err != nil {
			return nil, err
		}

		err = tx.Sign(signer, key)
		return tx, err
	}

	return builder.NewTxOrGenFromGen(gen, bundleHash)
}

func (g *GaslessModule) updateAddresses(header *types.Header) error {
	g.gaslessInfoMu.Lock()
	defer g.gaslessInfoMu.Unlock()

	swapRouter, tokens, err := getGaslessInfo(g.Chain, header)
	// proceed even if there is something wrong with multicall contract
	if err != nil {
		g.swapRouter = common.Address{}
		g.allowedTokens = map[common.Address]bool{}
		logger.Warn("there is something wrong with multicall contract", "err", err.Error())
		return nil
	}

	g.swapRouter = swapRouter

	g.allowedTokens = map[common.Address]bool{}
	for _, addr := range tokens {
		// all tokens are allowed if nil
		if g.GaslessConfig.AllowedTokens == nil {
			g.allowedTokens[addr] = true
		}
		for _, allowed := range g.GaslessConfig.AllowedTokens {
			if addr == allowed {
				g.allowedTokens[addr] = true
			}
		}
	}

	return nil
}

func getGaslessInfo(bc backends.BlockChainForCaller, header *types.Header) (common.Address, []common.Address, error) {
	statedb, err := bc.StateAt(header.Root)
	if err != nil {
		return common.Address{}, nil, err
	}

	// If Registry is not installed, do not query GaslessSwapRouter contract.
	if statedb.GetCode(system.RegistryAddr) == nil || bc.Config().IsRandaoForkBlockParent(header.Number) {
		return common.Address{}, nil, nil
	}

	caller, err := system.NewMultiCallContractCaller(statedb, bc, header)
	if err != nil {
		return common.Address{}, nil, err
	}

	opts := &bind.CallOpts{BlockNumber: header.Number}
	info, err := caller.MultiCallGaslessInfo(opts)

	return info.Gsr, info.Tokens, err
}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
}
