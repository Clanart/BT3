Confirmed: `RunAndCalculateGas` in `precompiles/common/precompiles.go` (the entry point for the `pointer` precompile, since it uses `DynamicGasPrecompile`) has no `recover()` around the call to `d.executor.Execute(...)` — only `chargeDecodeGas` has a narrowly-scoped recover for gas-meter panics, and it explicitly re-panics anything that isn't `ErrorOutOfGas`/`ErrorGasOverflow`. A panic inside `Execute` (or any function it calls) is therefore not caught anywhere in this call path.

### Title
Unchecked type assertion on attacker-controlled CW20/CW721/CW1155 query response causes node panic in pointer precompile - (File: precompiles/pointer/pointer.go)

### Summary
The `pointer` precompile's `AddCW20`, `AddCW721`, and `AddCW1155` executors unmarshal a JSON response from a smart-contract query and immediately type-assert two fields to `string` without the comma-ok form, mirroring the CVE's root cause of "using a fallible accessor result without checking its error/validity."

### Finding Description
`AddCW20`, `AddCW721`, and `AddCW1155` in `precompiles/pointer/pointer.go` query an arbitrary, caller-supplied CosmWasm contract address via `p.wasmdKeeper.QuerySmartSafe` and unmarshal the raw JSON reply into `map[string]interface{}`: [1](#0-0) [2](#0-1) [3](#0-2) 

The `name`/`symbol` fields are then extracted with a bare, unchecked type assertion:
```go
name := formattedRes["name"].(string)
symbol := formattedRes["symbol"].(string)
```
`cwAddr` is fully attacker-controlled (`args[0].(string)` from the ABI call), so any user can deploy (or already have deployed) a CW20/CW721/CW1155-labeled contract whose `token_info`/`contract_info` query returns `name` or `symbol` as a non-string JSON value (a number, bool, object, array) or omits the key entirely (making the map lookup return `nil`). In all these cases `.(string)` panics with a runtime type-assertion failure.

Unlike sibling precompiles (`addr`, `gov`, `mint`, `params`, `solo`), whose `Execute` methods wrap the body in `defer func() { if r := recover(); r != nil { err = ... } }()` specifically to convert such panics into an EVM revert, `pointer.PrecompileExecutor.Execute` has no such recover: [4](#0-3) 

The call chain from the EVM to this code is `DynamicGasPrecompile.RunAndCalculateGas` → `d.executor.Execute` → `AddCW20/AddCW721/AddCW1155`. `RunAndCalculateGas` itself has no top-level recover around `d.executor.Execute`; the only recover present (`chargeDecodeGas`) is scoped to an earlier gas-charging step and explicitly re-panics any non-gas-related recovered value: [5](#0-4) [6](#0-5) 

Consequently, a panic raised inside `AddCW20`/`AddCW721`/`AddCW1155` is unhandled all the way up through the precompile dispatch and into the EVM's `Call`/precompile-execution path.

### Impact Explanation
If the panic is not recovered somewhere higher up the EVM interpreter/ABCI stack (which appears not to be the case for this specific unrecovered-panic path, since the sibling precompiles deliberately add their own recover to avoid relying on any outer safety net), any transaction or `eth_call` invoking `addCW20Pointer`, `addCW721Pointer`, or `addCW1155Pointer` against a maliciously crafted CW contract will crash transaction processing on every full node executing that block/tx — a consensus-critical DoS: full nodes processing the same transaction deterministically panic, which can halt block production or crash default-configuration nodes serving `eth_call`. This matches the "crash of default-configuration RPC nodes" / "validator halt" impact bar.

### Likelihood Explanation
High. Deploying a CosmWasm contract that returns a non-string `name`/`symbol` field (or omits it) from a `token_info`/`contract_info` query is trivial and entirely within the control of any unprivileged wasm contract deployer. Calling `pointer.addCW20Pointer(cwAddr)` (or the CW721/1155 equivalents) against that contract from any EOA or contract is a single, ordinary EVM transaction — no privileged access required.

### Recommendation
Use the comma-ok form for both type assertions in `AddCW20`, `AddCW721`, and `AddCW1155`, returning a normal error (not a panic) when `name`/`symbol` are missing or not strings, e.g.:
```go
name, ok := formattedRes["name"].(string)
if !ok {
    return nil, 0, errors.New("cw contract token_info/contract_info did not return a string name")
}
symbol, ok := formattedRes["symbol"].(string)
if !ok {
    return nil, 0, errors.New("cw contract token_info/contract_info did not return a string symbol")
}
```
Additionally, add a `defer recover()` in `pointer.PrecompileExecutor.Execute` (matching `addr`, `gov`, `mint`, etc.) as defense-in-depth against any other unforeseen panic paths in this executor.

### Proof of Concept
1. Deploy a CosmWasm contract whose `QuerySmart` handler responds to `{"token_info":{}}` with JSON such as `{"name": 12345, "symbol": "T"}` (a numeric `name` instead of a string), or omits `name` entirely.
2. From any EVM account, call the `pointer` precompile (`0x000000000000000000000000000000000000100b`) method `addCW20Pointer(cwAddr)` with `cwAddr` set to the malicious contract's bech32 address.
3. Execution reaches `precompiles/pointer/pointer.go:154` (`name := formattedRes["name"].(string)`), where the interface holds a `float64`/`nil` instead of `string`, triggering a Go runtime panic (`interface conversion: interface {} is float64, not string`).
4. Because neither `AddCW20` nor `Execute` nor `RunAndCalculateGas` recovers this panic, it propagates out of precompile execution into the EVM/ABCI transaction-processing path on every node that processes this transaction, which is unrecoverable code compared to the recover-guarded sibling precompiles.

func (d DynamicGasPrecompile) RunAndCalculateGas(evm *vm.EVM, caller common.Address, callingContract common.Address, input []byte, suppliedGas uint64, value *big.Int, hooks *tracing.Hooks, readOnly bool, isFromDelegateCall bool) (ret []byte, remainingGas uint64, err error) {
	operation := fmt.Sprintf("%s_unknown", d.name)
	defer func() {
		HandlePrecompileError(err, evm, operation)
		if err != nil {
			fmt.Printf("precompile %s encountered error: %v\n", d.name, err)
			err = vm.ErrExecutionReverted
		}
	}()
	ctxer := state.GetDBImpl(evm.StateDB)
	if ctxer == nil {
		return nil, 0, errors.New("cannot get context from EVM")
	}
	// Resolve the target method from the 4-byte selector only. The argument
	// payload is intentionally NOT decoded yet: ABI decoding of attacker-
	// controlled calldata can cost far more than len(input) (a single string can
	// be referenced by many array/tuple slots), so it must be paid for out of the
	// gas the caller supplied. The static-precompile path charges RequiredGas in
	// vm.RunPrecompiledContract before running; that step is skipped for
	// dynamic-gas precompiles, so we apply the equivalent charge here.
	methodID, err := ExtractMethodID(input)
	if err != nil {
		return nil, 0, err
	}
	method, err := d.MethodById(methodID)
	if err != nil {
		return nil, 0, err
	}
	operation = method.Name

	ctx := ctxer.Ctx()
	// Install the gas meter derived from the supplied EVM gas, then charge for
	// decoding the calldata BEFORE decoding it. A call that cannot afford the
	// decode is rejected here, before the parse/allocation work is performed.
	// chargeDecodeGas scopes the out-of-gas recovery to just these charges, so an
	// executor that later exhausts its gas keeps its normal (propagating)
	// out-of-gas semantics.
	gasLimit := d.executor.EVMKeeper().GetCosmosGasLimitFromEVMGas(ctx.WithGasMeter(sdk.NewInfiniteGasMeterWithMultiplier(ctx)), suppliedGas)
	ctx = ctx.WithGasMeter(sdk.NewGasMeterWithMultiplier(ctx, gasLimit))
	if err = d.chargeDecodeGas(ctx, method, input); err != nil {
		return nil, 0, err
	}

	args, err := method.Inputs.Unpack(input[4:])
	if err != nil {
		return nil, 0, err
	}
	em := ctx.EventManager()
	ctx = ctx.WithEventManager(sdk.NewEventManager())
	ctx = ctx.WithEVMPrecompileCalledFromDelegateCall(isFromDelegateCall)
	ret, remainingGas, err = d.executor.Execute(ctx, method, caller, callingContract, args, value, readOnly, evm, suppliedGas, hooks)
	if err != nil {
		return ret, remainingGas, err
	}
	events := ctx.EventManager().Events()
	if len(events) > 0 {
		em.EmitEvents(ctx.EventManager().Events())
	}
	return ret, remainingGas, err
}

func (d DynamicGasPrecompile) chargeDecodeGas(ctx sdk.Context, method *abi.Method, input []byte) (err error) {
	defer func() {
		if r := recover(); r != nil {
			switch r.(type) {
			case sdk.ErrorOutOfGas, sdk.ErrorGasOverflow:
				err = fmt.Errorf("%v", r)
			default:
				panic(r)
			}
		}
	}()
	scanCost := DefaultGasCost(input, false)
	ctx.GasMeter().ConsumeGas(scanCost, fmt.Sprintf("%s precompile calldata scan", d.name))
	decodeCost, ok := DecodeGasCost(method.Inputs, input)
	if !ok {
		// Calldata is structurally invalid (Unpack would reject it too); reject
		// now, without attempting the decode.
		return fmt.Errorf("invalid calldata encoding for %s", d.name)
	}
	// DecodeGasCost already includes scanCost; charge only the remaining
	// (string-copy) portion so the decode is priced exactly once.
	ctx.GasMeter().ConsumeGas(decodeCost-scanCost, fmt.Sprintf("%s precompile calldata decode", d.name))
	return nil
}
