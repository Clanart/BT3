This is the exact same bug class as the Astro `x-astro-path` issue: a client-controlled field that bypasses a cryptographic authorization check because a sibling/adjacent field is properly protected while this one is not — creating an inconsistency that an unprivileged caller of a public API can exploit.

### Title
Unauthenticated `maxGasPrice` override in `auction_submitBid` bypasses EIP-712 searcher signature (V2.1 bids on V3.0 entry point) - (File: `kaiax/auction/eip712.go`, `kaiax/auction/impl/api.go`)

### Summary
The `AuctionAPI.SubmitBid` RPC handler (`kaiax/auction/impl/api.go`) builds a `Bid` directly from caller-supplied JSON (`BidInput`), including `MaxGasPrice`, and only rejects it if the two signatures fail to validate. The searcher's EIP-712 signature is verified via `bid.ValidateSearcherSig`, which calls `GetHashTypedData` (`kaiax/auction/eip712.go`). That function selects the struct hash based on a caller/contract-reported `version` string: when `version == AuctionVersionV3` ("0.0.2") it hashes `MaxGasPrice` as part of the signed struct (`bidV3.EncodeData`, line 102-118); for any other version — including the default V2.1 path (line 142-147) — `MaxGasPrice` is **not included in the signed digest at all** (`Bid.EncodeData`, lines 75-86).

### Finding Description
`kaiax/auction/impl/api.go` `SubmitBid` (lines 118-142) takes the untrusted `BidInput` from the RPC caller, converts it to a `Bid` via `ToBid` (copying `MaxGasPrice` verbatim, line 101-103), and calls `bp.AddBid(bid)`. This eventually calls `bp.validateBidSigs` → `bid.ValidateSearcherSig(chainId, verifyingContract, version)` where `version` is looked up from the live entry-point contract's `AUCTION_VERSION()` (see `blockchain/system/auction.go` `ReadAuctionVersion`).

When the deployed entry point reports version `"0.0.1"` (V2.1) — or any unrecognized string — `GetHashTypedData` falls back to the V2.1 typehash `Bid.EncodeType`/`EncodeData` (`kaiax/auction/eip712.go` lines 71-86), whose EIP-712 struct explicitly omits `maxGasPrice`:
```
auctionType = "AuctionTx(bytes32 targetTxHash,uint256 blockNumber,address sender,address to,uint256 nonce,uint256 bid,uint256 callGasLimit,bytes data)"
``` [1](#0-0) 

Meanwhile `ValidateSearcherSig` (`kaiax/auction/bid.go` lines 94-115) only checks that the recovered signer of that (V2.1) digest equals `b.Sender`; it never checks whether `MaxGasPrice` was zero/empty or otherwise constrained. Similarly, `ValidateAuctioneerSig` only signs over the raw bytes of `SearcherSig` itself (`GetEthSignedMessageHash`, lines 52-55), so the auctioneer's attestation covers "this exact searcher signature blob was approved" but says nothing about which un-hashed fields (like `MaxGasPrice` under V2.1) accompany it in the submitted `BidData`.

This means:
1. A searcher signs a V2.1-style bid (no `maxGasPrice` in the digest, e.g. leaving it as `nil`/`0` intentionally).
2. An unprivileged caller (any public RPC caller, per the "auction bidder" reachable role) who obtains that valid `(searcherSig, auctioneerSig)` pair — e.g. by observing it broadcast, or by being the searcher/auctioneer themselves relaying it — can resubmit the same `BidInput` JSON with an arbitrary non-zero `MaxGasPrice` value. Both signatures still validate because neither one binds to `MaxGasPrice` on this code path.
3. `bp.insertBid`/`bp.AddBid` accepts the bid with the attacker-chosen `MaxGasPrice`, and `bp.getBidTxGasLimit`/downstream bid-tx-generation logic (block-building path, `blockchain/system/auction.go` `EncodeAuctionCallData`) will encode and execute the bid transaction on-chain using this tampered `MaxGasPrice`, exactly as if the searcher had agreed to it.

This is structurally identical to the Astro bug: `x-astro-locals` (the auctioneer/searcher signature) is properly authenticated, but the sibling field `maxGasPrice` (like `x-astro-path`) rides along unauthenticated in the exact same message, silently bypassing the very signature check that is supposed to gate the whole request.

### Impact Explanation
`MaxGasPrice` is a fee/economic-safety parameter meant to bound how much gas price the searcher authorizes the bid transaction to pay. Because it can be forged/raised or altered without invalidating either signature under the V2.1 fallback path, an attacker can cause a searcher's bid to be executed with a gas price the searcher never agreed to — extracting value from the searcher (fee abuse) or manipulating bid economics/fairness of the KIP-249 auction (Medium/High severity fee-abuse and settlement-integrity impact), reachable purely through the public `auction_submitBid` RPC by any bidder-class caller with access to a previously-issued signature pair.

### Likelihood Explanation
Requires the entry-point contract to be running (or reporting) the V2.1 `AUCTION_VERSION` (or any unrecognized version string — the code defaults to V2.1 for unknown versions too), and requires the attacker to possess or intercept a valid `(SearcherSig, AuctioneerSig)` bid pair with `MaxGasPrice` unset — a realistic scenario since bids are submitted over the public `auction_submitBid` API and the V2.1 path is the explicit default/fallback in `GetHashTypedData`.

### Recommendation
Bind `MaxGasPrice` into the signed struct hash unconditionally regardless of `version` (or reject any bid whose `MaxGasPrice` is non-zero when the resolved version does not support it), so that no field of `BidData` can be altered post-signature without invalidating `ValidateSearcherSig`.

### Proof of Concept
1. Deploy/point the client at an `AuctionEntryPoint` reporting `AUCTION_VERSION() == "0.0.1"`.
2. Searcher signs a bid `B0` with `MaxGasPrice = nil` using `GetHashTypedData(chainId, entryPoint, "0.0.1")`; obtain a valid `AuctioneerSig` over `B0.SearcherSig`.
3. Attacker submits `auction_submitBid` with the same `TargetTxRaw/TargetTxHash/Sender/To/Nonce/Bid/CallGasLimit/Data/SearcherSig/AuctioneerSig` as `B0`, but with `MaxGasPrice` set to an arbitrary large value.
4. `ValidateSearcherSig` recomputes the V2.1 digest (which never includes `MaxGasPrice`), recovers the same `Sender`, and passes. `ValidateAuctioneerSig` recomputes the digest over `SearcherSig` bytes only, and passes.
5. `bp.AddBid` accepts the tampered bid; the bid transaction is later built/executed carrying the attacker-chosen `MaxGasPrice`. [2](#0-1) [3](#0-2) [4](#0-3) [5](#0-4)

// EncodeEIP712 encodes any EIP712Encoder according to EIP-712 specification
func EncodeEIP712(encoder EIP712Encoder) []byte {
	encoded := make([]byte, 0)
	encoded = append(encoded, encoder.EncodeType()...)
	encoded = append(encoded, encoder.EncodeData()...)
	return crypto.Keccak256Hash(encoded).Bytes()
}

// GetHashTypedData returns the EIP-712 digest for the bid.
// version must match the on-chain AUCTION_VERSION of the entry-point contract
// the bid targets; "0.0.2" selects the v3.0 struct typehash (with maxGasPrice),
// any other value falls back to the v2.1 typehash.
func (b *Bid) GetHashTypedData(chainId *big.Int, verifyingContract common.Address, version string) []byte {
	if chainId == nil {
		return nil
	}

	domain := EIP712Domain{
		EIP712DomainTypeHash: eip712TypeHash,
		NameHash:             auctionNameHash,
		VersionHash:          crypto.Keccak256Hash([]byte(version)),
		ChainId:              chainId,
		VerifyingContract:    verifyingContract,
	}

	domainSeparator := EncodeEIP712(domain)

	var structHash []byte
	if version == AuctionVersionV3 {
		structHash = EncodeEIP712(bidV3{b})
	} else if version == AuctionVersionV2 {
		structHash = EncodeEIP712(b)
	} else {
		// Unknown version: default to v2.1 typehash.
		structHash = EncodeEIP712(b)
	}

func (api *AuctionAPI) SubmitBid(ctx context.Context, bidInput BidInput) RPCOutput {
	numBidRequestCounter.Inc(1)
	if api.a.IsDisabled() {
		return makeRPCOutput(EMPTY_HASH, auction.ErrAuctionDisabled)
	}

	//  1. directly send target transaction
	targetTx, errTxDecode := toTx(bidInput.TargetTxRaw)
	if errTxDecode != nil {
		return makeRPCOutput(EMPTY_HASH, errTxDecode)
	}
	if targetTx.Hash() != bidInput.TargetTxHash {
		return makeRPCOutput(EMPTY_HASH, auction.ErrInvalidTargetTxHash)
	}
	errTargetTxSend := api.a.Backend.SendTx(ctx, targetTx)
	// ignore known transaction related errors against target tx validation
	if errTargetTxSend != nil && !(strings.HasPrefix(errTargetTxSend.Error(), "known transaction:") || errors.Is(errTargetTxSend, gasless_impl.ErrUnableToAddKnownBundleTx)) {
		return makeRPCOutput(EMPTY_HASH, errTargetTxSend)
	}

	// 2. add bid
	bid := ToBid(bidInput)
	bidHash, errValidateBid := api.a.bidPool.AddBid(bid)
	return makeRPCOutput(bidHash, errValidateBid)
}

func (b *Bid) ValidateSearcherSig(chainId *big.Int, verifyingContract common.Address, version string) error {
	if chainId == nil {
		return ErrNilChainId
	}

	if common.EmptyAddress(verifyingContract) {
		return ErrNilVerifyingContract
	}

	digest := b.GetHashTypedData(chainId, verifyingContract, version)

	recoveredSender, err := getSigner(b.SearcherSig, digest)
	if err != nil {
		return fmt.Errorf("failed to recover searcher sig: %v", err)
	}

	if recoveredSender != b.Sender {
		return fmt.Errorf("invalid searcher sig: expected %v, calculated %v", b.Sender.String(), recoveredSender.String())
	}

	return nil
}

// EncodeAuctionCallData encodes the bid as calldata for the active auction
// entry-point contract. version must match the on-chain AUCTION_VERSION of the
// active contract; "0.0.2" selects the v3.0 ABI (with maxGasPrice), any other
// value falls back to the v2.1 ABI.
func EncodeAuctionCallData(bid *auction.Bid, version string) ([]byte, error) {
	if version == auction.AuctionVersionV3 {
		maxGasPrice := bid.MaxGasPrice
		if maxGasPrice == nil {
			maxGasPrice = new(big.Int)
		}
		input := contractsv3.IAuctionEntryPointAuctionTx{
			TargetTxHash:  bid.TargetTxHash,
			BlockNumber:   new(big.Int).SetUint64(bid.BlockNumber),
			Sender:        bid.Sender,
			To:            bid.To,
			Nonce:         new(big.Int).SetUint64(bid.Nonce),
			Bid:           bid.Bid,
			MaxGasPrice:   maxGasPrice,
			CallGasLimit:  new(big.Int).SetUint64(bid.CallGasLimit),
			Data:          bid.Data,
			SearcherSig:   bid.SearcherSig,
			AuctioneerSig: bid.AuctioneerSig,
		}
		return abiV3.Pack("call", input)
	}

	// auction.AuctionVersionV2 or unknown version: default to v2.1 ABI.
	input := contracts.IAuctionEntryPointAuctionTx{
		TargetTxHash:  bid.TargetTxHash,
		BlockNumber:   new(big.Int).SetUint64(bid.BlockNumber),
		Sender:        bid.Sender,
		To:            bid.To,
		Nonce:         new(big.Int).SetUint64(bid.Nonce),
		Bid:           bid.Bid,
		CallGasLimit:  new(big.Int).SetUint64(bid.CallGasLimit),
		Data:          bid.Data,
		SearcherSig:   bid.SearcherSig,
		AuctioneerSig: bid.AuctioneerSig,
	}
	return abi.Pack("call", input)
}
