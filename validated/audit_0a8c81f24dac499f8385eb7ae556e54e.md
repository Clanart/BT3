### Title
Coinbase outputs are reported as spendable vault deposits before maturity - (`networks/bitcoin/src/wallet/mod.rs`)

### Summary
`Scanner::scan_block` scans every transaction in a block, including `block.txdata[0]`, and converts matching coinbase outputs into `ReceivedOutput` values described as spendable. Because `ReceivedOutput` carries only the offset, `TxOut`, and `OutPoint`, the resulting value contains no maturity information. `SignableTransaction::new` then accepts that coinbase outpoint as an ordinary input without checking whether it came from a coinbase or whether it is mature.

### Finding Description
`Scanner::scan_block` calls `scan_transaction` for all entries in `block.txdata`, rather than skipping the coinbase transaction at index zero. [1](#0-0)  `scan_transaction` identifies ownership solely by matching `output.script_pubkey` and returns a `ReceivedOutput` for the matching transaction output. [2](#0-1)  The `ReceivedOutput` type is documented as “A spendable output,” but contains no coinbase flag or maturity height. [3](#0-2) 

The transaction builder consumes each returned `outpoint` directly as a transaction input. [4](#0-3)  During multisig setup, the only ownership check verifies that the stored prevout script equals the Taproot script for the threshold key plus the recorded offset; it does not check coinbase maturity. [5](#0-4)  The signer then commits to all supplied prevouts and produces a Taproot key-spend signature for the immature input. [6](#0-5) 

### Impact Explanation
A miner can create a valid block whose coinbase pays the Serai vault’s Taproot script. A consumer using the public `scan_block` API receives that output as an apparently spendable `ReceivedOutput`, even though Bitcoin consensus forbids spending coinbase outputs for 100 blocks.

Any accounting or deposit crediting based on this API therefore reports funds as available while they cannot actually back a withdrawal. The resulting spend can be fully signed yet will be rejected by the network, causing failed withdrawals and temporarily overstating immediately spendable vault funds.

### Likelihood Explanation
This requires a miner to produce a block paying the vault script, so it is not available on demand to an ordinary transaction sender. It still uses only public Bitcoin inputs and requires no validator compromise, malformed encoding, leaked key, or malicious RPC response. The code documents the maturity caveat, but the API still returns an object represented as spendable and downstream transaction construction performs no independent maturity check.

### Recommendation
Make `Scanner::scan_block` skip `block.txdata[0]` by default, or return coinbase matches through a distinct API/type that cannot be passed to `SignableTransaction::new` as an ordinary spendable input. If delayed availability must be supported, record the producing block height and maturity height in `ReceivedOutput`, expose an `is_mature`/`matures_at` check, and enforce maturity before scheduling or signing a spend.

// Vault scanner.
let scanner = Scanner::new(vault_key).unwrap();

// A public miner mines a valid block whose coinbase contains:
// block.txdata[0].output[0].script_pubkey == p2tr_script_buf(vault_key)
let block = bitcoin_rpc.get_block(&block_hash).await.unwrap();

// The coinbase output is returned as a normal ReceivedOutput.
let outputs = scanner.scan_block(&block);
assert_eq!(outputs.len(), 1);
assert_eq!(
  outputs[0].outpoint(),
  &OutPoint::new(block.txdata[0].compute_txid(), 0),
);

// The output is accepted as spendable input.
let spend = SignableTransaction::new(
  outputs,
  &[(p2tr_script_buf(vault_key).unwrap(), payment_amount)],
  None,
  None,
  fee_per_vbyte,
).unwrap();

// vault's Taproot script. The produced transaction can receive a valid
// threshold signature, yet Bitcoin consensus rejects it before maturity as a
// premature coinbase spend.

  pub fn scan_transaction(&self, tx: &Transaction) -> Vec<ReceivedOutput> {
    let mut res = Vec::new();
    for (vout, output) in tx.output.iter().enumerate() {
      // If the vout index exceeds 2**32, stop scanning outputs
      let Ok(vout) = u32::try_from(vout) else { break };

      if let Some(offset) = self.scripts.get(&output.script_pubkey) {
        res.push(ReceivedOutput {
          offset: *offset,
          output: output.clone(),
          outpoint: OutPoint::new(tx.compute_txid(), vout),
        });
      }
    }
