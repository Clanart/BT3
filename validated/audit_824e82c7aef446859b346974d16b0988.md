### Title
Unbounded Attacker-Controlled Lend Amount Drains Proposer Funds in Gasless Module - (File: kaiax/gasless/impl/getter.go)

### Summary
The `kaiax/gasless` module implements KIP-247 gasless transactions: the block proposer "lends" gas fee KAIA to a user via a `LendTx` generated by `GetLendTxGenerator`, and the user is expected to repay via the `SwapForGas` call in the same bundle. The amount lent (`lendAmount`) is computed purely from user-supplied, attacker-controlled transaction fields (`GasLimit * GasPrice` of the user's own `ApproveTx`/`SwapTx`), with no cap enforced anywhere in the mempool admission (`checkBalanceForApprove`/`checkBalanceForSwap`), executability verification (`VerifyExecutable`), or lend-tx generation (`GetLendTxGenerator`) logic.

### Finding Description
`lendAmount()` sums `ApproveTx.Fee()` and `SwapTx.Fee()` [1](#0-0) , where `Fee() = GasLimit * GasPrice`, both of which are chosen by the transaction sender (an unprivileged, unrestricted user submitting a public transaction). This `lendAmount` becomes the `Value` of the `LendTx` that the block proposer signs and funds from its own `NodeKey` account: `types.TxValueKeyAmount: lendAmount(approveTxOrNil, swapTx)` [2](#0-1) .

`VerifyExecutable` only checks that `AmountRepay` exactly equals `repayAmount(approveTxOrNil, swapTx)` (which is itself derived from the same attacker-controlled gas parameters) — it never bounds the absolute size of `lendAmount`/`repayAmount` against any sane maximum [3](#0-2) . Likewise `checkBalanceForApprove` and `checkBalanceForSwap`, which gate mempool admission for gasless module transactions, only validate token balance/allowance/deadline/minAmountOut/amountIn relationships — none of them cap `GasLimit`, `GasPrice`, or the resulting `Fee()`/`lendAmount` [4](#0-3) . The module's own documentation confirms sender balance checks are explicitly skipped for gasless senders ("Sender balance check is omitted for gasless transactions") [5](#0-4) .

Since the `LendTx` is generated and funded entirely by the proposer (`key := g.InitOpts.NodeKey`) before the swap's actual on-chain repayment succeeds or fails, and the sender fully controls `GasLimit`/`GasPrice` of both the approve and swap legs, a malicious sender can set arbitrarily large gas limits/prices to inflate `lendAmount` far beyond any legitimate gas-fee reimbursement need, forcing the proposer to transfer a correspondingly large amount of native KAIA to the attacker's address in the `LendTx` for every gasless bundle it builds — this is unrestricted value movement out of the proposer's account analogous to the unbounded `amoMinterBorrow` pattern in the reference report, except here the "lender" is the block proposer itself and the "borrower" is any public tx sender.

### Impact Explanation
If exploitable end-to-end (see Likelihood/uncertainty below), each gasless bundle processed by a proposer would let an attacker extract KAIA from the proposer's balance without an enforced ceiling, directly causing unauthorized value movement/loss of proposer funds — a concrete, in-scope impact category (unauthorized value movement) reachable purely from a submitted transaction pair by an unprivileged sender.

### Likelihood Explanation
Likelihood is **uncertain** and could not be fully confirmed from the indexed code. The repayment enforcement partially resides in the on-chain `GaslessSwapRouter` contract's `swapForGas` function (bytecode only available in `contracts/bindings/kip247/GaslessSwapRouter.go`, source Solidity not found in the index), which is responsible for pulling the declared `amountRepay` back from the swap output and reimbursing the proposer within the same bundle. If that contract strictly enforces that the actual DEX-swap proceeds must cover the declared, attacker-chosen `amountRepay` (and reverts the whole atomic bundle otherwise, clawing back the lend before block finalization), the practical drain may be bounded by the token's real liquidity/slippage rather than being fully unbounded. However, nothing in the `kaiax/gasless` Go module itself imposes a maximum `GasLimit`/`GasPrice`/`lendAmount`, so the attack surface (proposer being forced to advance an attacker-dictated, arbitrarily large KAIA amount before repayment is confirmed) is real at the module level even if the router contract provides some downstream mitigation.

### Recommendation
- Enforce an explicit upper bound on `ApproveTx`/`SwapTx` `GasLimit` and/or `GasPrice` accepted by the gasless module (e.g., cap `lendAmount` to a small multiple of `params.TxGas * currentBaseFee` or a configurable `MaxLendAmount`), rejecting outsized values in `checkBalanceForApprove`/`checkBalanceForSwap` and `VerifyExecutable`.
- Confirm and, if necessary, harden the on-chain `GaslessSwapRouter.swapForGas` (Solidity source not present in this index — recommend a Devin session with full repo access to review it) to guarantee atomic, all-or-nothing settlement: the `LendTx` value transferred to the user must never exceed what can be verifiably recovered from the same swap in the same bundle, with no partial-success path that leaves the proposer under-repaid.
- Add a per-block or per-proposer aggregate cap on total lent KAIA via gasless bundles, mirroring the "overall limits" recommendation from the analogous `amoMinterBorrow` report, to bound worst-case exposure even if a single bundle's cap is miscalculated.

### Proof of Concept
1. Attacker crafts `ApproveTx` (or omits it) and `SwapTx` calling `swapForGas` on the whitelisted `GaslessSwapRouter`, satisfying `IsApproveTx`/`IsSwapTx` structural checks [6](#0-5) .
2. Attacker sets an inflated `GasLimit` and/or `GasPrice` on the `SwapTx` (and optional `ApproveTx`), inflating `swapTx.Fee()`/`approveTx.Fee()`.
3. Attacker sets `amountRepay` in the `swapForGas` calldata to exactly `repayAmount(approveTxOrNil, swapTx)` so `VerifyExecutable`'s equality check passes [7](#0-6) .
4. Because sender balance checks are skipped for gasless txs [5](#0-4) , and `checkBalanceForApprove`/`checkBalanceForSwap` never bound `Fee()`, the tx pair is admitted and later becomes "ready" via `isSwapTxReady`/`isApproveTxReady` [8](#0-7) .
5. The proposer's block builder calls `ExtractTxBundles`, which unconditionally prepends `g.GetLendTxGenerator(approveTxs[addr], tx)` for every executable gasless pair, generating a `LendTx` funded from the proposer's `NodeKey` for the inflated `lendAmount` [9](#0-8) .
6. If the downstream `GaslessSwapRouter` contract does not perfectly reconcile the inflated repay claim against real swap proceeds within the same atomic bundle, the proposer's KAIA balance is drained to the attacker without an enforced ceiling — this final on-chain reconciliation step is the part not fully verifiable within the indexed source and should be validated directly.

func (g *GaslessModule) IsApproveTx(tx *types.Transaction) bool {
	args, ok := decodeApproveTx(tx, g.signer)
	return ok && g.isApproveTx(args)
}

func (g *GaslessModule) isApproveTx(args *ApproveArgs) bool {
	g.gaslessInfoMu.RLock()
	defer g.gaslessInfoMu.RUnlock()

	return g.allowedTokens[args.Token] && // A1
		g.swapRouter == args.Spender && // A3
		args.Amount.Cmp(abi.MaxUint256) == 0 // A4
}

// IsSwapTx checks following conditions:

	args, ok := decodeSwapTx(tx, g.signer)
	return ok && g.isSwapTx(args)
}

func (g *GaslessModule) isSwapTx(args *SwapArgs) bool {
	g.gaslessInfoMu.RLock()
	defer g.gaslessInfoMu.RUnlock()

	return g.swapRouter == args.Router && // S1
		g.allowedTokens[args.Token] // S3
}

func lendAmount(approveTxOrNil, swapTx *types.Transaction) *big.Int {
	r := new(big.Int)

	// R2 = ApproveTx.Fee() if exists
	if approveTxOrNil != nil {
		r.Add(r, approveTxOrNil.Fee())
	}

	// R3 = SwapTx.Fee()
	r.Add(r, swapTx.Fee())

	// LendAmount = R2 + R3
	return r
}

func (g *GaslessModule) checkBalanceForApprove(approveArgs *ApproveArgs) error {
	token := approveArgs.Token
	bc := backends.NewBlockchainContractBackend(g.Chain, nil, nil)

	if g.GaslessConfig.ShouldCheckSenderCode() {
		if g.getCurrentHasCode(approveArgs.Sender) {
			return errors.New("sender with code is not allowed")
		}
	}

	if g.GaslessConfig.ShouldCheckToken() {
		tokenContract, err := sc_erc20.NewERC20(token, bc)
		if err != nil {
			return err
		}

		// tx.token.balanceOf(sender) > 0
		tokenBalance, err := tokenContract.BalanceOf(nil, approveArgs.Sender)
		if err != nil {
			return err
		}
		if tokenBalance.Sign() <= 0 {
			return fmt.Errorf("insufficient sender token balance: token=%s, have=%s, want=nonzero", token.Hex(), tokenBalance.String())
		}
	}
	return nil
}

// tx.amountIn >= gsr.getAmountIn(minAmountOut)

// tx.token.balanceOf(sender) >= tx.amountIn

func (g *GaslessModule) checkBalanceForSwap(swapArgs *SwapArgs, swapNonce uint64) error {
	token := swapArgs.Token
	bc := backends.NewBlockchainContractBackend(g.Chain, nil, nil)

	g.gaslessInfoMu.RLock()
	swapRouter := g.swapRouter
	g.gaslessInfoMu.RUnlock()

	// tx.minAmountOut >= tx.amountRepay
	minAmountOut := swapArgs.MinAmountOut
	amountRepay := swapArgs.AmountRepay
	if minAmountOut.Cmp(amountRepay) < 0 {
		return fmt.Errorf("insufficient minAmountOut: minAmountOut=%s, amountRepay=%s", minAmountOut.String(), amountRepay.String())
	}

	if g.GaslessConfig.ShouldCheckSenderCode() {
		if g.getCurrentHasCode(swapArgs.Sender) {
			return errors.New("sender with code is not allowed")
		}
	}

	if g.GaslessConfig.ShouldCheckSwapAmount() {
		// tx.amountIn >= gsr.getAmountIn(minAmountOut)
		routerContract, err := kip247.NewGaslessSwapRouterCaller(swapRouter, bc)
		if err != nil {
			return err
		}
		// Required token amountIn, given the current exchange rate and the declared minAmountOut.
		requiredAmountIn, err := routerContract.GetAmountIn(nil, token, minAmountOut)
		if err != nil {
			return err
		}
		if swapArgs.AmountIn.Cmp(requiredAmountIn) < 0 {
			return fmt.Errorf("insufficient amountIn: have=%s, want=%s", swapArgs.AmountIn.String(), requiredAmountIn.String())
		}
	}

	if g.GaslessConfig.ShouldCheckToken() {

		tokenContract, err := sc_erc20.NewERC20(token, bc)
		if err != nil {
			return err
		}

		// If SwapTx.nonce is the sender's next nonce, then there is no room for ApproveTx proceeding SwapTx.
		senderNonce := g.getCurrentStateNonce(swapArgs.Sender)
		noApproveTxPreceeds := swapNonce == senderNonce
		if noApproveTxPreceeds {
			// tx.token.allowance(sender, router) >= tx.amountIn
			approval, err := tokenContract.Allowance(nil, swapArgs.Sender, swapRouter)
			if err != nil {
				return err
			}
			if approval.Cmp(swapArgs.AmountIn) < 0 {
				return fmt.Errorf("insufficient approval: approval=%s, want=%s", approval.String(), swapArgs.AmountIn.String())
			}
		}

		// tx.token.balanceOf(sender) >= tx.amountIn
		balance, err := tokenContract.BalanceOf(nil, swapArgs.Sender)
		if err != nil {
			return err
		}
		if balance.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("insufficient balance: balance=%s, want=%s", balance.String(), swapArgs.AmountIn.String())
		}
	}

	// tx.deadline >= currentTimestamp
	deadline := swapArgs.Deadline
	if deadline.Cmp(g.Chain.CurrentBlock().Time()) < 0 {
		return fmt.Errorf("insufficient deadline: deadline=%s, want=%s", deadline.String(), g.Chain.CurrentBlock().Time().String())
	}

	return nil
}

// isApproveTxReady assumes that the caller checked `g.IsApproveTx(approveTx)`
func (g *GaslessModule) isApproveTxReady(approveTx, nextTx *types.Transaction) bool {
	addr, err := types.Sender(g.signer, approveTx)
	if err != nil {
		return false
	}
	nonce := g.getCurrentStateNonce(addr)

	if approveTx.Nonce() != nonce {
		return false
	}
	if nextTx == nil || !g.IsSwapTx(nextTx) {
		return false
	}

	return g.IsExecutable(approveTx, nextTx)
}

// isSwapTxReady assumes that the caller checked `g.IsSwapTx(swapTx)`
func (g *GaslessModule) isSwapTxReady(swapTx, prevTx *types.Transaction) bool {
	addr, err := types.Sender(g.signer, swapTx)
	if err != nil {
		return false
	}
	nonce := g.getCurrentStateNonce(addr)

	var approveTx *types.Transaction
	if swapTx.Nonce() == nonce {
		approveTx = nil
	} else if swapTx.Nonce() == nonce+1 {
		if prevTx == nil || !g.IsApproveTx(prevTx) {
			return false
		}
		approveTx = prevTx
	} else {
		return false
	}

	return g.IsExecutable(approveTx, swapTx)
}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
}
