The reported bug is specific to Atlas's ERC-4337-style account abstraction, where `_verifyUser()` can delegate signature checking to a smart-contract wallet's `validateUserOp()` and return early before `_handleNonces()` runs. Stacks does not have an analogous "smart contract wallet" auth path: every `StacksTransaction` uses one of exactly three `TransactionSpendingCondition` variants (`Singlesig`, `Multisig`, `OrderIndependentMultisig`), all of which are cryptographic signature conditions verified uniformly through `TransactionSpendingCondition::verify()` [1](#0-0)  and `TransactionAuth::verify()`/`verify_origin()` [2](#0-1) , with no branch that substitutes an external contract call for signature checking.

Nonce checking is likewise performed unconditionally and independently of the auth condition type in `StacksChainState::check_transaction_nonces()`, which always validates both the origin nonce and (if present) the sponsor/payer nonce against on-chain account state before a transaction can execute [3](#0-2) . There is no code path in `transactions.rs`, `transaction.rs`, or `accounts.rs` where nonce validation is skipped based on the type of spending condition or "smart contract" origin — Stacks has no concept of a contract-controlled transaction sender with delegated signature validation. Because the root architectural precondition of the reported bug (a contract-callback-based signature check bypassing nonce enforcement) does not exist in this codebase, there is no valid analog here.

    pub fn check_transaction_nonces<T: ClarityConnection>(
        clarity_tx: &mut T,
        tx: &StacksTransaction,
        quiet: bool,
    ) -> Result<
        (StacksAccount, StacksAccount),
        (TransactionNonceMismatch, (StacksAccount, StacksAccount)),
    > {
        // who's sending it?
        let origin = tx.get_origin();
        let origin_account = StacksChainState::get_account(clarity_tx, &tx.origin_address().into());

        // who's paying the fee?
        let payer_account = if let Some(sponsor_address) = tx.sponsor_address() {
            let payer = tx.get_payer();
            let payer_account = StacksChainState::get_account(clarity_tx, &sponsor_address.into());

            if payer.nonce() != payer_account.nonce {
                let e = TransactionNonceMismatch {
                    expected: payer_account.nonce,
                    actual: payer.nonce(),
                    txid: tx.txid(),
                    principal: payer_account.principal.clone(),
                    is_origin: false,
                    quiet,
                };
                if !quiet {
                    warn!("{e}");
                }
                return Err((e, (origin_account, payer_account)));
            }

            payer_account
        } else {
            origin_account.clone()
        };

        // check nonces
        if origin.nonce() != origin_account.nonce {
            let e = TransactionNonceMismatch {
                expected: origin_account.nonce,
                actual: origin.nonce(),
                txid: tx.txid(),
                principal: origin_account.principal.clone(),
                is_origin: true,
                quiet,
            };
            if !quiet {
                warn!("{e}");
            }
            return Err((e, (origin_account, payer_account)));
        }

        Ok((origin_account, payer_account))
    }
