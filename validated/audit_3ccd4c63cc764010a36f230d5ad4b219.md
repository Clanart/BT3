### Title
Gasless swap bundle executability check ignores `Deadline`, allowing block builders to lend KAIA against expired/stale `SwapTx` in a non-atomic bundle - ([File: kaiax/gasless/impl/getter.go])

### Summary
The Kaia gasless-transaction module lets a sender submit an `ApproveTx`+`SwapTx` pair that pays for gas by borrowing KAIA from the block proposer and repaying it from the swap output. The pool-admission check (`checkBalanceForSwap`) validates `swapArgs.Deadline` against the current block time, but the function that actually decides whether the block builder is allowed to *bundle and execute* the pair at block-construction time — `VerifyExecutable`/`IsExecutable` — never re-checks the deadline. Combined with the fact that gasless bundles are explicitly built as **non-atomic**, this allows a `LendTx` (unconditional KAIA transfer to the sender) to be executed even though the paired `SwapTx` is stale/expired, creating a fund-loss/stale-execution path.

### Finding Description
`GetCheckBalance` re-validates a swap transaction when it enters the tx pool, including an explicit deadline check: [1](#0-0) 

However, the function that is actually consulted by the block builder to decide whether a `SwapTx` (with or without a preceding `ApproveTx`) is executable and should be bundled, `VerifyExecutable`, performs a series of consistency checks (Ax, Sx, AP1, SP1–SP4) but **never checks `swapArgs.Deadline`**: [2](#0-1) 

This `VerifyExecutable`/`IsExecutable` result is the sole gate used by `ExtractTxBundles` when the block builder decides to bundle `[LendTx, ApproveTx?, SwapTx]`: [3](#0-2) 

Critically, the bundle produced here is created with the atomicity flag set to `false`: [4](#0-3) 

This differs from the auction module's bundles, which are explicitly atomic (`true`): [5](#0-4) 

Because a `SwapTx` can remain queued/pending for a non-trivial window (up to `QueueTimeout`/`PendingTimeout` of 10s, or `KnownTxTimeout` of 30s) before the builder actually assembles it into a block, and `PreReset` only evicts transactions based on elapsed pool time — not on the transaction's own declared `Deadline` — a `SwapTx` whose deadline has already passed by inclusion time can still pass `VerifyExecutable` and be bundled: [6](#0-5) 

The `GetLendTxGenerator` unconditionally creates and signs a `LendTx` that transfers KAIA (`R2+R3`) from the block proposer's key to the sender, based purely on the fee math, with no deadline dependency: [7](#0-6) 

Since the bundle is non-atomic, if the on-chain `GaslessSwapRouter.swapForGas` (whose ABI declares a `deadline` parameter) reverts the swap because the deadline has elapsed, the `LendTx` — already included and executed in the block — still unconditionally transfers KAIA to the sender, with no corresponding repayment from the swap, since the repayment logic depends on the swap successfully executing.

### Impact Explanation
This is the direct analog of the reported Uniswap-style "missing deadline enforcement" bug class: the crucial time-sensitive validation exists at one point in the pipeline (mempool admission) but is dropped at the point where the transaction actually gets executed/settled (block-building bundling). Here the consequence is worse than a sandwich attack on a DEX trade — it is an unconditional value transfer (`LendTx`) from the block proposer that is not contingent on the paired `SwapTx` succeeding, due to (a) the missing deadline re-check in `VerifyExecutable`, and (b) the bundle being built non-atomically. This can result in the proposer losing lent KAIA when the swap subsequently reverts due to the expired deadline, i.e., unauthorized value movement / fee-delegation (gasless) settlement theft.

### Likelihood Explanation
Any unprivileged sender can submit a valid gasless `SwapTx` with a deadline close to submission time and let it sit in the pool (intentionally delaying broadcast, exploiting network conditions, or via congestion) until the deadline lapses just before the builder includes it. Because pool eviction timers (10s/30s) are unrelated to the transaction's own `Deadline` field, and `VerifyExecutable` performs no deadline check, this window is fully reachable by a normal transaction sender without needing any privileged/validator/network-level position — satisfying the "single submitted transaction" requirement.

### Recommendation
Add an explicit deadline check in `VerifyExecutable` (kaiax/gasless/impl/getter.go), mirroring the one already present in `checkBalanceForSwap`, so that block-building executability re-validates `swapArgs.Deadline` against the current block time immediately before bundling. Additionally, consider making the gasless `[LendTx, ApproveTx?, SwapTx]` bundle atomic (as done for auction bundles) so that a failing/reverting `SwapTx` also reverts the `LendTx`, eliminating the possibility of an unconditional, unrepaid value transfer.

### Proof of Concept
1. Attacker (sender) constructs a valid `ApproveTx`/`SwapTx` pair with `deadline = now + 1s` and submits it directly to a Kaia CN's tx pool; `checkBalanceForSwap` passes because deadline ≥ current block time at admission. [1](#0-0) 
2. Attacker delays broadcast/finalization (e.g., submits right before a burst of other pending transactions, or the CN is momentarily busy), so the transaction remains in the pool queue for several seconds without being evicted, since eviction is governed by `QueueTimeout`/`PendingTimeout`/`KnownTxTimeout`, not by the tx's own `Deadline`. [6](#0-5) 
3. When the block builder later calls `ExtractTxBundles`, it calls `g.IsExecutable(approveTxs[addr], tx)` → `VerifyExecutable`, which does not check `swapArgs.Deadline`, and the pair is accepted for bundling. [8](#0-7) 
4. The bundle `[LendTx, ApproveTx, SwapTx]` is built non-atomically (`false`), and the `LendTx` transfers `lendAmount` KAIA to the attacker's address unconditionally. [7](#0-6) 
5. On-chain execution of `swapForGas` with an expired `deadline` reverts (assuming the router enforces its declared `deadline` parameter), so no repayment reaches the proposer, while the `LendTx` transfer to the attacker already succeeded — resulting in loss of the lent KAIA.

Note: the exact on-chain Solidity source for `GaslessSwapRouter.swapForGas`'s deadline enforcement was not available in the indexed codebase (only Go bindings were found), so step 5's on-chain revert behavior could not be independently confirmed from source; a Devin session with full repository access would be needed to inspect `contracts/**/GaslessSwapRouter.sol` and confirm this precisely.

// PreReset removes timed out tx from the tx pool and knownTxs.
func (g *GaslessModule) PreReset(oldHead, newHead *types.Header) []common.Hash {
	g.knownTxsMu.Lock()
	defer g.knownTxsMu.Unlock()

	drops := make([]common.Hash, 0)

	for hash, knownTx := range *g.knownTxs {
		// remove pending timed out tx from tx pool
		if knownTx.status == TxStatusPending && knownTx.elapsedPromotedTime() >= PendingTimeout {
			drops = append(drops, hash)
		}
		// remove queue timed out tx from tx pool
		if knownTx.status == TxStatusQueue && knownTx.elapsedAddedTime() >= QueueTimeout {
			drops = append(drops, hash)
		}
		// remove known timed out tx from knownTxs
		if knownTx.elapsedPromotedOrAddedTime() >= KnownTxTimeout {
			g.knownTxs.delete(hash)
		}
	}

	return drops
}

func (g *GaslessModule) IsExecutable(approveTxOrNil, swapTx *types.Transaction) bool {
	err := g.VerifyExecutable(approveTxOrNil, swapTx)
	if err != nil {
		return false
	}
	return true
}

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

// MakeLendTx creates a transaction with following properties:
// L1. LendTx.type = 0x7802 (TxTypeEthereumDynamicFee)
// L2. LendTx.from = proposer
// L3. LendTx.to = SwapTx.from
// L4. LendTx.value = LendAmount(approveTxOrNil, swapTx)
func (g *GaslessModule) GetLendTxGenerator(approveTxOrNil, swapTx *types.Transaction) *builder.TxOrGen {
	var src []byte
	if approveTxOrNil != nil {
		src = append(src, approveTxOrNil.Hash().Bytes()...)
	}
	src = append(src, swapTx.Hash().Bytes()...)
	bundleHash := crypto.Keccak256Hash(src)

	gen := func(nonce uint64) (*types.Transaction, error) {
		var (
			chainId = g.InitOpts.ChainConfig.ChainID
			signer  = types.LatestSignerForChainID(chainId)
			key     = g.InitOpts.NodeKey
		)

		to, err := types.Sender(signer, swapTx)
		if err != nil {
			return nil, err
		}

		tx, err := types.NewTransactionWithMap(types.TxTypeEthereumDynamicFee, map[types.TxValueKeyType]interface{}{
			types.TxValueKeyNonce:      nonce,
			types.TxValueKeyTo:         &to,
			types.TxValueKeyAmount:     lendAmount(approveTxOrNil, swapTx),
			types.TxValueKeyData:       common.Hex2Bytes("0x"),
			types.TxValueKeyGasLimit:   params.TxGas,
			types.TxValueKeyGasFeeCap:  swapTx.GasFeeCap(),
			types.TxValueKeyGasTipCap:  swapTx.GasTipCap(),
			types.TxValueKeyAccessList: types.AccessList{},
			types.TxValueKeyChainID:    chainId,
		})
		if err != nil {
			return nil, err
		}

		err = tx.Sign(signer, key)
		return tx, err
	}

	return builder.NewTxOrGenFromGen(gen, bundleHash)
}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
}
