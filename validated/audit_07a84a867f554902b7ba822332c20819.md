### Title
`ThresholdKeys::read` permits quadratic Lagrange interpolation work from crafted `t`/`n` - (File: `crypto/dkg/src/lib.rs`)

### Summary
`ThresholdKeys::read` accepts attacker-controlled `t`, `n`, participant index, interpolation type, secret share, and `n` verification shares before constructing `ThresholdKeys`. [1](#0-0)  For `Interpolation::Lagrange`, `ThresholdKeys::new` computes a Lagrange factor for each of the first `t` participants, and each factor iterates over the other `t - 1` participants. [2](#0-1) [3](#0-2)  A well-formed blob declaring `t = n = 65,535` therefore causes approximately 4.29 billion scalar operations during deserialization.

### Finding Description
`Participant` and `ThresholdParams` only enforce nonzero indexes, `t <= n`, and `i <= n`, so the encoded maximum `t = n = 65,535` is accepted. [4](#0-3)  The serializer then reads `n` points and calls `ThresholdKeys::new`, which checks the share count and participant bounds but does not limit the threshold to an operational maximum. [5](#0-4)  Its group-key calculation calls `interpolation_factor` independently for every participant in `1..=t`, while `Interpolation::Lagrange` performs a linear scan for every factor. [6](#0-5) [7](#0-6) 

### Impact Explanation
An input of roughly 2 MiB for a 32-byte-point curve can force billions of field multiplications/subtractions and 65,535 field inversions inside `ThresholdKeys::read`. [8](#0-7) [2](#0-1)  In an application that accepts serialized `ThresholdKeys` from an unprivileged party, this is an algorithmic-complexity denial of service analogous to the reported parser ReDoS. [9](#0-8) 

### Likelihood Explanation
Exploitation requires the application to deserialize attacker-supplied `ThresholdKeys`; the attacker must provide `n` canonical point encodings, because an early invalid or truncated encoding terminates parsing. [10](#0-9)  Repeated valid generator encodings satisfy the parser because the `HashMap` is keyed by participant index, not point uniqueness. [10](#0-9)  The issue is accordingly most relevant to recovery/import APIs or other services treating `ThresholdKeys::read` input as untrusted. [9](#0-8) 

### Recommendation
Enforce a protocol-appropriate maximum `n`/`t` before allocating or interpolating, and reject encoded sizes inconsistent with the remaining input. [11](#0-10)  For legitimate large thresholds, replace the per-participant Lagrange loop with an `O(t)` prefix/suffix or factorial formulation for contiguous participant indexes. [3](#0-2) 

### Proof of Concept

```rust
use ciphersuite::{
  group::{ff::{Field, PrimeField}, GroupEncoding},
  Ciphersuite,

use dkg::ThresholdKeys;
use std::io;

fn quadratic_threshold_keys_read<C: Ciphersuite>() -> io::Result<()> {
  let n = u16::MAX;

  let mut encoded = Vec::new();
  encoded.extend(u32::try_from(C::ID.len()).unwrap().to_le_bytes());
  encoded.extend(C::ID);

  encoded.extend(n.to_le_bytes()); // t
  encoded.extend(n.to_le_bytes()); // n
  encoded.extend(1u16.to_le_bytes()); // i
  encoded.push(1); // Interpolation::Lagrange

  encoded.extend(C::F::ONE.to_repr().as_ref());

  let generator = C::generator().to_bytes();
  for _ in 1 ..= n {
    encoded.extend(generator.as_ref());
  }

  let mut reader = encoded.as_slice();
  let _ = ThresholdKeys::<C>::read(&mut reader)?;
  Ok(())
}
```

```rust
impl<F: Zeroize + PrimeField> Interpolation<F> {
  /// The interpolation factor for this participant, within this signing set.
  fn interpolation_factor(&self, i: Participant, included: &[Participant]) -> F {
    match self {
      Interpolation::Constant(c) => c[usize::from(u16::from(i) - 1)],
      Interpolation::Lagrange => {
        let i_f = F::from(u64::from(u16::from(i)));

        let mut num = F::ONE;
        let mut denom = F::ONE;
        for l in included {
          if i == *l {
            continue;
          }

          let share = F::from(u64::from(u16::from(*l)));
          num *= share;
          denom *= share - i_f;
        }

        // Safe as this will only be 0 if we're part of the above loop
        // (which we have an if case to avoid)
        num * denom.invert().unwrap()
      }
```
