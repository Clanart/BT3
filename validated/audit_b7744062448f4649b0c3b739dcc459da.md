## Analysis Result

The Kaia codebase contains a structurally identical bug-class instance: an unconditional state wipe triggered by an unrelated parameter change, causing accidental loss of already-validated, in-flight state — analogous to Tokemak's `clearExtraRewards()` issue.

### Title
Unconditional bid-pool wipe on gas-buffer parameter change causes accidental loss of valid, signature-verified auction bids - ([File: kaiax/auction/impl/bid_pool.go])

### Summary
`BidPool.updateAuctionInfo` clears the *entire* bid pool (`bidMap`, `bidTargetMap`, `bidWinnerMap`) — including bids for future blocks that are unaffected by the change — whenever `bidTxGasBuffer` (the on-chain `gasBufferEstimate`) differs from the previously cached value, even though that parameter has no bearing on the validity of already-verified bid signatures.

### Finding Description
Every block, `AuctionModule.PostInsertBlock` re-reads auction configuration from the `AuctionEntryPoint` system contract and forwards it to `BidPool.updateAuctionInfo`: [1](#0-0) 

`updateAuctionInfo` compares four values (`auctioneer`, `auctionEntryPoint`, `auctionEntryPointVersion`, `bidTxGasBuffer`) against the cached ones, and if *any* differ, it calls `clearBidPool()`, wiping the whole pool unconditionally, regardless of which of the four values actually changed: [2](#0-1) 

```go
func (bp *BidPool) clearBidPool() {
	bp.bidMu.Lock()
	defer bp.bidMu.Unlock()

	bp.bidMap = make(map[common.Hash]*auction.Bid)
	bp.bidTargetMap = make(map[uint64]map[common.Hash]*auction.Bid)
	bp.bidWinnerMap = make(map[uint64]map[common.Address]common.Hash)
}
``` [3](#0-2) 

While clearing is justifiable when the `auctioneer` or `auctionEntryPoint` address changes (since bid signatures are verified against those exact values via `validateBidSigs`), it is **not** justified when only `bidTxGasBuffer` changes. `bidTxGasBuffer` is used solely to compute the gas limit for constructing the bid transaction (`getBidTxGasLimit`) — it plays no role in `SearcherSig`/`AuctioneerSig` verification: [4](#0-3) [5](#0-4) 

`gasBufferEstimate` is a routine, frequently-tunable operational parameter on the `AuctionEntryPoint` contract (exposed via `setGasBufferEstimate`/`ChangeGasParameters`), unrelated to bid validity: [6](#0-5) 

The project's own test explicitly documents this behavior — updating only the gas buffer estimate empties `bidTargetMap`, `bidWinnerMap`, and `bidMap`: [7](#0-6) 

This check happens on **every block** (`PostInsertBlock` runs per block), so any legitimate, benign adjustment of the gas buffer estimate destroys all pending/winning bids network-wide, including bids already locked in for the very next block via `bidWinnerMap`/`bidTargetMap`, and bids for up to `allowFutureBlock` (2) blocks ahead that have nothing to do with the changed parameter.

### Impact Explanation
A searcher (auction bidder) who has already:
1. Submitted a fully validated bid (passed signature checks by both `Auctioneer` and searcher),
2. Been recorded as the current block's or an upcoming block's winning bid (`bidWinnerMap`),

can have that bid unconditionally erased the moment the `AuctionEntryPoint` owner performs a routine, harmless gas-parameter update. This denies the winning searcher their paid-for block inclusion slot (per KIP-249, bid payment/commitment is understood to occur off-chain/via the auctioneer flow), and no other bid can be resubmitted for that already-passed validation window before the block is built, causing an accidental loss of the auction's guaranteed execution — a concrete instance of unauthorized value/opportunity loss for a legitimate protocol participant (the bidder/searcher), mirroring exactly the "ExtraRewards can accidentally loss" bug class (unconditional deletion of valid state without checking the reason/necessity of the deletion).

### Likelihood Explanation
This requires only a normal `AuctionEntryPoint` operational tuning event (adjusting `gasBufferEstimate`, e.g., in response to changing gas-price conditions) which is an expected, routine, non-malicious admin action independent of any single bidder. It happens automatically on every block via `PostInsertBlock`/`updateAuctionInfo`, so any bidder whose bid happens to be pending at the moment such a routine update lands will unavoidably lose it. No attacker action is required — this is an "accidental" loss triggered by ordinary protocol operation, exactly as described in the reference report.

### Recommendation
In `BidPool.updateAuctionInfo`, only call `clearBidPool()` when `auctioneer`, `auctionEntryPoint`, or `auctionEntryPointVersion` change (values that affect signature/validity semantics). When only `bidTxGasBuffer` changes, update `bp.bidTxGasBuffer` in place without clearing `bidMap`/`bidTargetMap`/`bidWinnerMap`, since existing bids remain valid and their gas limits can be recomputed lazily or left as originally computed.

### Proof of Concept
1. Auctioneer submits a valid bid for block `N+1`; it passes `validateBid`/`validateBidSigs` and is stored in `bidMap`, `bidTargetMap[N+1]`, and `bidWinnerMap[N+1][sender]` via `insertBid`. [8](#0-7) 
2. Before block `N+1` is built, the `AuctionEntryPoint` contract owner calls `setGasBufferEstimate`/emits `ChangeGasParameters` to adjust the buffer (a routine, non-malicious operational action) — `auctioneer` and `auctionEntryPoint` address remain unchanged. [9](#0-8) 
3. On `PostInsertBlock` for block `N`, `updateAuctionInfo` detects `bidTxGasBuffer` differs from cached value and calls `clearBidPool()`, wiping the previously valid winning bid for block `N+1`. [10](#0-9) 
4. Test `TestBidPool_UpdateAuctionInfo_DifferentGasBufferEstimate` confirms this exact outcome (pool emptied after only the gas buffer changes). [11](#0-10) 
5. The searcher's already-won bid for block `N+1` is lost with no error surfaced to them, and their transaction fails to be prioritized as promised by the auction mechanism.

// updateAuctionInfo updates the auction info if the auctioneer or auction entry point address is changed.
func (bp *BidPool) updateAuctionInfo(auctioneer common.Address, auctionEntryPoint common.Address, auctionEntryPointVersion string, bidTxGasBuffer uint64) {
	bp.auctionInfoMu.Lock()
	defer bp.auctionInfoMu.Unlock()

	if bp.auctioneer == auctioneer && bp.auctionEntryPoint == auctionEntryPoint && bp.auctionEntryPointVersion == auctionEntryPointVersion && bp.bidTxGasBuffer == bidTxGasBuffer {
		return
	}

	// Clear the existing auction pool since the auctioneer or auction entry point address is changed.
	bp.clearBidPool()

	bp.auctioneer = auctioneer
	bp.auctionEntryPoint = auctionEntryPoint
	bp.auctionEntryPointVersion = auctionEntryPointVersion
	bp.bidTxGasBuffer = bidTxGasBuffer

	logger.Info("Update auction info", "auctioneer", auctioneer, "auctionEntryPoint", auctionEntryPoint, "auctionEntryPointVersion", auctionEntryPointVersion, "bidTxGasBuffer", bidTxGasBuffer)
}

func (bp *BidPool) insertBid(bid *auction.Bid) error {
	bp.bidMu.Lock()
	defer bp.bidMu.Unlock()

	var (
		blockNumber  = bid.BlockNumber
		targetTxHash = bid.TargetTxHash
		sender       = bid.Sender
	)

	// Re-check bidWinnerMap here — two concurrent bids can pass validateBid together.
	if _, ok := bp.bidMap[bid.Hash()]; ok {
		return auction.ErrBidAlreadyExists
	}
	if bp.senderHasDifferentWinner(bid) {
		return auction.ErrBidSenderExists
	}

	// If same block number, same target tx hash exists, replace it if it's better
	if existingBid, ok := bp.bidTargetMap[blockNumber][targetTxHash]; ok {
		// FCFS if the bid is the same.
		if existingBid.Bid.Cmp(bid.Bid) >= 0 {
			return auction.ErrLowBid
		}

		logger.Trace("Replace bid", "old", existingBid.Hash(), "new", bid.Hash())
		delete(bp.bidMap, existingBid.Hash())
		delete(bp.bidWinnerMap[blockNumber], existingBid.Sender)
	} else {
		if int64(len(bp.bidMap)) >= bp.maxBidPoolSize {
			logger.Info("Bid pool is full", "maxBidPoolSize", bp.maxBidPoolSize, "bid", bid.Hash())
			return auction.ErrBidPoolFull
		}
	}

	hash := bid.Hash()

	bp.initializeBidMap(blockNumber)

	bp.bidMap[hash] = bid
	bp.bidTargetMap[blockNumber][targetTxHash] = bid
	bp.bidWinnerMap[blockNumber][sender] = hash

	numBidsGauge.Update(int64(len(bp.bidMap)))

	logger.Trace("Add bid", "bid", hash)

	return nil
}

func (bp *BidPool) validateBidSigs(bid *auction.Bid) error {
	bp.auctionInfoMu.RLock()
	defer bp.auctionInfoMu.RUnlock()

	if bid.SearcherSig == nil || len(bid.SearcherSig) != crypto.SignatureLength {
		return auction.ErrInvalidSearcherSig
	}
	if bid.AuctioneerSig == nil || len(bid.AuctioneerSig) != crypto.SignatureLength {
		return auction.ErrInvalidAuctioneerSig
	}

	// Verify the EIP712 signature.
	if err := bid.ValidateSearcherSig(bp.ChainConfig.ChainID, bp.auctionEntryPoint, bp.auctionEntryPointVersion); err != nil {
		return err
	}

	// Verify the auctioneer signature.
	if err := bid.ValidateAuctioneerSig(bp.auctioneer); err != nil {
		return err
	}

	return nil
}

func (bp *BidPool) getBidTxGasLimit(bid *auction.Bid) (uint64, error) {
	bp.auctionInfoMu.RLock()
	buffer := bp.bidTxGasBuffer
	bp.auctionInfoMu.RUnlock()

	data, err := system.EncodeAuctionCallData(bid, bp.auctionEntryPointVersion)
	if err != nil {
		return 0, err
	}

	rules := bp.ChainConfig.Rules(big.NewInt(int64(bid.BlockNumber)))
	intrinsicGas, err := types.IntrinsicGas(data, nil, nil, false, rules)
	if err != nil {
		return 0, err
	}
	floorDataGas := uint64(0)
	if rules.IsPrague {
		floorDataGas, err = blockchain.FloorDataGas(types.TxTypeEthereumDynamicFee, data, 0)
		if err != nil {
			return 0, err
		}
	}

	return max(intrinsicGas+bid.CallGasLimit+buffer, floorDataGas), nil
}

func TestBidPool_UpdateAuctionInfo_DifferentGasBufferEstimate(t *testing.T) {
	var (
		mockCtrl = gomock.NewController(t)
		chain    = chain_mock.NewMockBlockChain(mockCtrl)
	)
	defer mockCtrl.Finish()

	block := types.NewBlockWithHeader(&types.Header{Number: big.NewInt(1)})
	chain.EXPECT().CurrentBlock().Return(block).AnyTimes()

	pool := NewBidPool(testChainConfig, chain, &auction.AuctionConfig{MaxBidPoolSize: 1024})
	require.NotNil(t, pool)

	// Start the auction
	pool.start()
	atomic.StoreUint32(&pool.running, 1)
	defer pool.stop()
	pool.auctioneer = testAuctioneer
	pool.auctionEntryPoint = testAuctionEntryPoint
	pool.auctionEntryPointVersion = auction.AuctionVersionV2
	pool.bidTxGasBuffer = 180_000

	// Add some bids
	for _, bid := range testBids[:3] {
		hash, err := pool.AddBid(bid)
		require.NoError(t, err)
		assert.Equal(t, bid.Hash(), hash)

		// Verify bid was added correctly
		assert.Equal(t, bid, pool.bidMap[hash])
		assert.Equal(t, bid, pool.bidTargetMap[bid.BlockNumber][bid.TargetTxHash])
		assert.Contains(t, pool.bidWinnerMap[bid.BlockNumber], bid.Sender)
	}

	// Update auction info with same addresses
	pool.updateAuctionInfo(testAuctioneer, testAuctionEntryPoint, auction.AuctionVersionV2, 180_000)
	assert.NotEmpty(t, pool.bidTargetMap)
	assert.NotEmpty(t, pool.bidWinnerMap)
	assert.NotEmpty(t, pool.bidMap)

	// Update auction info with different gas buffer estimate
	pool.updateAuctionInfo(testAuctioneer, testAuctionEntryPoint, auction.AuctionVersionV2, 160_000)

	// Verify pool was cleared and addresses were updated
	assert.Empty(t, pool.bidTargetMap)
	assert.Empty(t, pool.bidWinnerMap)
	assert.Empty(t, pool.bidMap)
	assert.Equal(t, uint64(160_000), pool.bidTxGasBuffer)
}
