### Title
Governance-controlled `RegisterPointerDisabled` param is bypassed via the `pointer` EVM precompile - (File: precompiles/pointer/pointer.go)

### Summary
The `RegisterPointerDisabled` params flag is meant to allow governance to shut off creation of new CW→ERC (and native→ERC) pointer contracts. The check exists only in the Cosmos message path `MsgRegisterPointer` (`x/evm/keeper/msg_server.go`), but the active EVM precompile at address `0x100b` (`precompiles/pointer/pointer.go`), which any EVM caller can invoke directly, performs no such check in `AddNative`, `AddCW20`, `AddCW721`, or `AddCW1155`. This mirrors the reported StHEU `vest()` bug class: a mode/flag that gates one code path is silently missing on a parallel, unprivileged-reachable path.

### Finding Description
`msgServer.RegisterPointer` explicitly gates pointer creation/upgrade on the disabled flag: [1](#0-0) 

The flag is read via `GetRegisterPointerDisabled`, which is a governance-settable EVM param: [2](#0-1) 

However, `precompiles/pointer/pointer.go` — the currently active pointer precompile reachable by any EVM transaction sender at `0x000000000000000000000000000000000000100b` — implements the same functional operations (`AddNative`, `AddCW20`, `AddCW721`, `AddCW1155`) but never calls `GetRegisterPointerDisabled` before calling into `UpsertERCNativePointer` / `UpsertERCCW20Pointer` / `UpsertERCCW721Pointer` / `UpsertERCCW1155Pointer`: [3](#0-2) [4](#0-3) 

The legacy precompile versions (`v555`, `v562`) also contain the same `AddNative`/`AddCW20`/`AddCW721` logic with no disabled-flag check, confirming this is a structural gap, not a one-off: [5](#0-4) [6](#0-5) 

This is directly analogous to the external report's bug class: a state/mode flag (`migrationMode` / here `RegisterPointerDisabled`) that is correctly checked on one entry point but omitted on another semantically equivalent entry point, allowing the guarded action to still be performed.

### Impact Explanation
When governance disables pointer registration (e.g. during an incident, a pointer-code migration, or to freeze the pointer registry ahead of an upgrade), any unprivileged EVM account can still call the `pointer` precompile directly to create or upsert native/CW20/CW721/CW1155 pointer contracts. This defeats the intended safety control and can:
- Create pointer contracts pointing at addresses that governance specifically wanted blocked (e.g. contracts scheduled for migration, or malicious/incorrectly-metadata'd CW20/CW721/CW1155 contracts) while the flag is meant to prevent exactly this.
- Cause inconsistent state between the two entry points' invariants, since operators/monitoring may assume "disabled" fully halts pointer creation chain-wide.
- Interfere with a coordinated pointer-contract rollout/migration that depends on `RegisterPointerDisabled` being authoritative, potentially leading to duplicate/incorrect pointers being wired up mid-migration.

### Likelihood Explanation
High likelihood of triggering: the precompile is a standard, permissionless EVM entry point at a fixed, well-known address (`0x100b`) that any address can call with a plain EVM transaction; there is no privilege check besides basic call-context validation (`readOnly`/delegatecall guards). No special conditions are required beyond governance having set `RegisterPointerDisabled = true`.

### Recommendation
Add the same governance disabled-flag check used in `msgServer.RegisterPointer` to each of the pointer-creation entry points in `precompiles/pointer/pointer.go` (`AddNative`, `AddCW20`, `AddCW721`, `AddCW1155`), e.g.:
```go
if p.evmKeeper.GetRegisterPointerDisabled(ctx) {
    return nil, 0, errors.New("registering CW->ERC pointers has been disabled")
}
```
Apply the same fix to the legacy precompile variants (`v555`, `v562`) if they remain reachable/registered for older chain versions, to ensure the invariant holds across all code paths that can create or upgrade a pointer.

### Proof of Concept
1. Governance submits and passes a param-change proposal setting `x/evm` param `RegisterPointerDisabled = true`.
2. Attempt `MsgRegisterPointer` via the Cosmos tx path → correctly rejected with `"registering CW->ERC pointers has been disabled"` per `x/evm/keeper/msg_server.go` line 249-251.
3. From any unprivileged EOA, send an EVM transaction to `0x000000000000000000000000000000000000100b` calling `addNativePointer(token)` (or `addCW20Pointer`, `addCW721Pointer`, `addCW1155Pointer`) with a valid target denom/contract address.
4. The call succeeds: `AddNative`/`AddCW20`/`AddCW721`/`AddCW1155` in `precompiles/pointer/pointer.go` proceed straight to `UpsertERC*Pointer` without consulting `GetRegisterPointerDisabled`, creating a new pointer contract despite governance having disabled pointer registration.

func (p PrecompileExecutor) AddNative(ctx sdk.Context, method *ethabi.Method, caller common.Address, args []interface{}, value *big.Int, evm *vm.EVM, hooks *tracing.Hooks) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}
	if err := pcommon.ValidateArgsLength(args, 1); err != nil {
		return nil, 0, err
	}
	token := args[0].(string)
	metadata, metadataExists := p.bankKeeper.GetDenomMetaData(ctx, token)
	if !metadataExists {
		return nil, 0, fmt.Errorf("denom %s does not have metadata stored and thus can only have its pointer set through gov proposal", token)
	}
	name := metadata.Name
	symbol := metadata.Symbol
	var decimals uint8
	for _, denomUnit := range metadata.DenomUnits {
		if denomUnit.Exponent > uint32(decimals) && denomUnit.Exponent <= math.MaxUint8 {
			decimals = uint8(denomUnit.Exponent)
			name = denomUnit.Denom
			symbol = denomUnit.Denom
			if len(denomUnit.Aliases) > 0 {
				name = denomUnit.Aliases[0]
			}
		}
	}
	contractAddr, err := p.evmKeeper.UpsertERCNativePointer(ctx, evm, token, utils.ERCMetadata{Name: name, Symbol: symbol, Decimals: decimals})
	if err != nil {
		return nil, 0, err
	}

	ret, err = method.Outputs.Pack(contractAddr)
	remainingGas = pcommon.GetRemainingGas(ctx, p.evmKeeper)
	return
}

func (p Precompile) AddCW20(ctx sdk.Context, method *ethabi.Method, caller common.Address, args []interface{}, value *big.Int, evm *vm.EVM, suppliedGas uint64, hooks *tracing.Hooks) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}
	if err := pcommon.ValidateArgsLength(args, 1); err != nil {
		return nil, 0, err
	}
	cwAddr := args[0].(string)
	existingAddr, existingVersion, exists := p.evmKeeper.GetERC20CW20Pointer(ctx, cwAddr)
	if exists && existingVersion >= 1 {
		return nil, 0, fmt.Errorf("pointer at %s with version %d exists when trying to set pointer for version %d", existingAddr.Hex(), existingVersion, cw20.CurrentVersion(ctx))
	}
	cwAddress, err := sdk.AccAddressFromBech32(cwAddr)
	if err != nil {
		return nil, 0, err
	}
	res, err := p.wasmdKeeper.QuerySmart(ctx, cwAddress, []byte("{\"token_info\":{}}"))
	if err != nil {
		return nil, 0, err
	}
	formattedRes := map[string]interface{}{}
	if err := json.Unmarshal(res, &formattedRes); err != nil {
		return nil, 0, err
	}
	name := formattedRes["name"].(string)
	symbol := formattedRes["symbol"].(string)
	constructorArguments := []interface{}{
		cwAddr, name, symbol,
	}

	packedArgs, err := cw20.GetParsedABI().Pack("", constructorArguments...)
	if err != nil {
		panic(err)
	}
	bin := append(cw20.GetBin(), packedArgs...)
	if value == nil {
		value = utils.Big0
	}
	ret, contractAddr, remainingGas, err := evm.Create(caller, bin, suppliedGas, uint256.MustFromBig(value))
	if err != nil {
		return
	}
	err = p.evmKeeper.SetERC20CW20Pointer(ctx, cwAddr, contractAddr)
	if err != nil {
		return
	}

	ctx.EventManager().EmitEvent(sdk.NewEvent(
		types.EventTypePointerRegistered, sdk.NewAttribute(types.AttributeKeyPointerType, "cw20"),
		sdk.NewAttribute(types.AttributeKeyPointerAddress, contractAddr.Hex()), sdk.NewAttribute(types.AttributeKeyPointee, cwAddr),
		sdk.NewAttribute(types.AttributeKeyPointerVersion, fmt.Sprintf("%d", cw20.CurrentVersion(ctx)))))
	ret, err = method.Outputs.Pack(contractAddr)
	return
}
