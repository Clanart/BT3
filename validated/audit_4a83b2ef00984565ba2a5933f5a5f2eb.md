Confirmed: `RunAndCalculateGas` in `precompiles/common/precompiles.go` has **no `recover()`** around `d.executor.Execute(...)` (only `chargeDecodeGas` recovers gas-meter panics). This means any unrecovered Go panic raised inside a `DynamicGasPrecompileExecutor.Execute` (like the pointer precompile) propagates out of the precompiled-contract call and up through go-ethereum's EVM interpreter, which — unlike the other precompiles (`addr`, `oracle`, `slashing`, `solo`) that explicitly wrap their `Execute` with `defer recover()` "to catch gas meter panics" — the `pointer` precompile's `Execute`/`AddCW20`/`AddCW721`/`AddCW1155` do **not** have this guard.

### Title
Unrecovered type-assertion panic in Pointer precompile CW20/CW721/CW1155 registration crashes EVM/RPC node on malicious contract response - (File: precompiles/pointer/pointer.go)

### Summary
The Pointer precompile's `AddCW20`, `AddCW721`, and `AddCW1155` handlers unmarshal the target CosmWasm contract's JSON query response into `map[string]interface{}` and then perform unchecked type assertions (`formattedRes["name"].(string)`, `formattedRes["symbol"].(string)`) without verifying the keys exist or hold string values. Unlike sibling precompiles (`addr`, `oracle`, `slashing`, `solo`), the pointer precompile's `Execute` has no `defer recover()` guard, and the dynamic-gas dispatcher `DynamicGasPrecompile.RunAndCalculateGas` in `precompiles/common/precompiles.go` also does not recover panics from the executor call. A crafted CW20/CW721/CW1155 contract that returns a `token_info`/`contract_info` response missing `name`/`symbol` or with non-string values causes an unrecovered Go panic during transaction/precompile execution — the same bug class as GHSL-2024-250 (dereferencing/using a value without validating its presence/type before use).

### Finding Description
`precompiles/pointer/pointer.go`:
```go
res, err := p.wasmdKeeper.QuerySmartSafe(ctx, cwAddress, []byte("{\"token_info\":{}}"))
...
formattedRes := map[string]interface{}{}
if err := json.Unmarshal(res, &formattedRes); err != nil {
    return nil, 0, err
}
name := formattedRes["name"].(string)
symbol := formattedRes["symbol"].(string)
``` [1](#0-0) 

The same unguarded pattern exists in `AddCW721` and `AddCW1155`: [2](#0-1)  and [3](#0-2) .

`cwAddress` is any bech32 CosmWasm contract that an attacker fully controls (they deploy it themselves), so the JSON response to `token_info`/`contract_info` queries is entirely attacker-controlled. If `formattedRes["name"]` is absent (nil interface) or is a non-string JSON type (number, object, array, bool), the type assertion `.(string)` panics with `interface conversion: interface {} is nil, not string` (or similar).

The pointer precompile's `Execute` dispatcher does not wrap execution in `recover()`: [4](#0-3)  — contrast with `addr.go`'s explicit `defer recover()` "Needed to catch gas meter panics": [5](#0-4) .

The call path is `DynamicGasPrecompile.RunAndCalculateGas` → `d.executor.Execute(...)`, and this function only recovers panics inside `chargeDecodeGas` (scoped strictly to gas-meter panics), not around the `Execute` call itself: [6](#0-5) [7](#0-6) .

### Impact Explanation
An unrecovered Go panic occurring mid-transaction inside the EVM execution path is not merely an "execution reverted" — Go panics that aren't caught anywhere up the call stack crash the entire process. Since every full node (validator or public RPC node) executing this transaction (during block execution, `eth_call`/`eth_estimateGas` simulation, or mempool-adjacent transaction checks) evaluates the same EVM state, all nodes processing this transaction crash identically and deterministically, producing a validator/RPC node halt. Because it's fully deterministic and reachable by any address that can call `addCW20Pointer`/`addCW721Pointer`/`addCW1155Pointer` on the Pointer precompile (address `0x100b`) — even against `eth_call`/`estimateGas` style RPC queries prior to inclusion — this is a straightforward chain-halt / node-crash vector via a public entry point.

### Likelihood Explanation
High likelihood: no privileged access is required. Any user can (1) deploy a minimal CosmWasm contract whose `token_info` or `contract_info` query handler returns JSON lacking a `name`/`symbol` field or with a non-string type for those fields, and (2) call `pointer.addCW20Pointer(contractAddr)` (or CW721/CW1155 equivalent) via a normal EVM transaction or even a read-only `eth_call`. This requires no special privileges, no race conditions, and works deterministically every time.

### Recommendation
Use safe two-value type assertions (or a proper struct-based JSON decode) when extracting `name`/`symbol` from `formattedRes`, e.g.:
```go
name, ok := formattedRes["name"].(string)
if !ok {
    return nil, 0, fmt.Errorf("cw20 contract token_info response missing/invalid name field")
}
symbol, ok := formattedRes["symbol"].(string)
if !ok {
    return nil, 0, fmt.Errorf("cw20 contract token_info response missing/invalid symbol field")
}
```
Apply the same fix to `AddCW721` and `AddCW1155`. Additionally, add a `defer recover()` guard in `PrecompileExecutor.Execute` of `precompiles/pointer/pointer.go` (matching `addr.go`/`oracle.go`/`solo.go`/`slashing.go`), and consider adding a top-level `recover()` in `DynamicGasPrecompile.RunAndCalculateGas` around the `d.executor.Execute` call as defense-in-depth against any future unchecked type assertions or nil dereferences in precompile executors, converting such panics into a reverted transaction instead of a process crash.

### Proof of Concept
1. Deploy a CosmWasm contract `Malicious` whose `QueryMsg::TokenInfo {}` (for CW20) or `QueryMsg::ContractInfo {}` (for CW721/CW1155) handler returns raw JSON such as `{}` (empty object) or `{"name": 123, "symbol": null}`.
2. From any EOA, send an EVM transaction (or `eth_call`) to the Pointer precompile at `0x000000000000000000000000000000000000100b` calling `addCW20Pointer(<Malicious contract's bech32/derived address>)`.
3. Execution reaches `precompiles/pointer/pointer.go` `AddCW20`, unmarshals the attacker JSON into `formattedRes`, and executes `formattedRes["name"].(string)`, which panics because the value is missing or not a string.
4. Because neither `pointer.go`'s `Execute` nor `DynamicGasPrecompile.RunAndCalculateGas` recover this panic, the panic propagates out of the EVM precompile call into the node process, crashing block execution (validators) or the RPC node handling the `eth_call`.

func (d DynamicGasPrecompile) RunAndCalculateGas(evm *vm.EVM, caller common.Address, callingContract common.Address, input []byte, suppliedGas uint64, value *big.Int, hooks *tracing.Hooks, readOnly bool, isFromDelegateCall bool) (ret []byte, remainingGas uint64, err error) {
	operation := fmt.Sprintf("%s_unknown", d.name)
	defer func() {
		HandlePrecompileError(err, evm, operation)
		if err != nil {
			fmt.Printf("precompile %s encountered error: %v\n", d.name, err)
			err = vm.ErrExecutionReverted
		}
	}()
	ctxer := state.GetDBImpl(evm.StateDB)
	if ctxer == nil {
		return nil, 0, errors.New("cannot get context from EVM")
	}
	// Resolve the target method from the 4-byte selector only. The argument
	// payload is intentionally NOT decoded yet: ABI decoding of attacker-
	// controlled calldata can cost far more than len(input) (a single string can
	// be referenced by many array/tuple slots), so it must be paid for out of the
	// gas the caller supplied. The static-precompile path charges RequiredGas in
	// vm.RunPrecompiledContract before running; that step is skipped for
	// dynamic-gas precompiles, so we apply the equivalent charge here.
	methodID, err := ExtractMethodID(input)
	if err != nil {
		return nil, 0, err
	}
	method, err := d.MethodById(methodID)
	if err != nil {
		return nil, 0, err
	}
	operation = method.Name

	ctx := ctxer.Ctx()
	// Install the gas meter derived from the supplied EVM gas, then charge for
	// decoding the calldata BEFORE decoding it. A call that cannot afford the
	// decode is rejected here, before the parse/allocation work is performed.
	// chargeDecodeGas scopes the out-of-gas recovery to just these charges, so an
	// executor that later exhausts its gas keeps its normal (propagating)
	// out-of-gas semantics.
	gasLimit := d.executor.EVMKeeper().GetCosmosGasLimitFromEVMGas(ctx.WithGasMeter(sdk.NewInfiniteGasMeterWithMultiplier(ctx)), suppliedGas)
	ctx = ctx.WithGasMeter(sdk.NewGasMeterWithMultiplier(ctx, gasLimit))
	if err = d.chargeDecodeGas(ctx, method, input); err != nil {
		return nil, 0, err
	}

	args, err := method.Inputs.Unpack(input[4:])
	if err != nil {
		return nil, 0, err
	}
	em := ctx.EventManager()
	ctx = ctx.WithEventManager(sdk.NewEventManager())
	ctx = ctx.WithEVMPrecompileCalledFromDelegateCall(isFromDelegateCall)
	ret, remainingGas, err = d.executor.Execute(ctx, method, caller, callingContract, args, value, readOnly, evm, suppliedGas, hooks)
	if err != nil {
		return ret, remainingGas, err
	}
	events := ctx.EventManager().Events()
	if len(events) > 0 {
		em.EmitEvents(ctx.EventManager().Events())
	}
	return ret, remainingGas, err
}

func (d DynamicGasPrecompile) chargeDecodeGas(ctx sdk.Context, method *abi.Method, input []byte) (err error) {
	defer func() {
		if r := recover(); r != nil {
			switch r.(type) {
			case sdk.ErrorOutOfGas, sdk.ErrorGasOverflow:
				err = fmt.Errorf("%v", r)
			default:
				panic(r)
			}
		}
	}()
	scanCost := DefaultGasCost(input, false)
	ctx.GasMeter().ConsumeGas(scanCost, fmt.Sprintf("%s precompile calldata scan", d.name))
	decodeCost, ok := DecodeGasCost(method.Inputs, input)
	if !ok {
		// Calldata is structurally invalid (Unpack would reject it too); reject
		// now, without attempting the decode.
		return fmt.Errorf("invalid calldata encoding for %s", d.name)
	}
	// DecodeGasCost already includes scanCost; charge only the remaining
	// (string-copy) portion so the decode is priced exactly once.
	ctx.GasMeter().ConsumeGas(decodeCost-scanCost, fmt.Sprintf("%s precompile calldata decode", d.name))
	return nil
}
