### Title
Unrecovered type-assertion panic in Pointer precompile's `AddCW20`/`AddCW721`/`AddCW1155` on malformed CW20/CW721 query responses - (File: `precompiles/pointer/pointer.go`, `precompiles/common/precompiles.go`)

### Summary
The EVM Pointer precompile (`0x...100b`), reachable by any EVM caller via `addCW20Pointer`/`addCW721Pointer`, queries an attacker-controlled CosmWasm contract's `token_info`/`contract_info` and blindly type-asserts the JSON fields `name` and `symbol` as Go `string` without checking existence or type, e.g. `name := formattedRes["name"].(string)` in `precompiles/pointer/pointer.go:154` (and identically across every legacy version `v552` through `v66`, and in the CW721/CW1155 variants). If the target CW20/CW721/CW1155 contract's query response omits these fields or returns a non-string JSON type (number, bool, array, object), the type assertion panics with "interface conversion: interface {} is nil, not string" (or "... is float64, not string").

### Finding Description
Any EVM transaction sender can:
1. Instantiate an arbitrary CosmWasm contract (a CW20/CW721/CW1155-labeled contract is not actually validated to conform to the real cw20/cw721 spec) whose `token_info`/`contract_info` query handler returns JSON where `"name"` or `"symbol"` is missing or is a non-string value.
2. Call the Pointer precompile's `addCW20Pointer(cwAddr)` (or `addCW721Pointer`/`addCW1155Pointer`) with that contract's address.

The precompile calls `p.wasmdKeeper.QuerySmart(ctx, cwAddress, []byte("{\"token_info\":{}}"))`, unmarshals the raw JSON into a generic `map[string]interface{}`, and immediately does `formattedRes["name"].(string)` / `formattedRes["symbol"].(string)` with no `ok` check anywhere in `precompiles/pointer/pointer.go` or any of its legacy versions (`v552`, `v555`, `v562`, `v575`, `v580`, `v600`, `v605`, `v606`, `v610`, `v614`, `v620`, `v630`, `v640`, `v65`, `v66`). A missing key returns `nil`, and `nil.(string)` panics — a Go analogue of the CVE's null-pointer-dereference-on-malformed-input bug class: unsanitized external input is dereferenced/type-asserted without a nil/type check, causing a runtime fault instead of a graceful error.

Critically, the precompile call boundary in `DynamicGasPrecompile.RunAndCalculateGas` (`precompiles/common/precompiles.go:156-215`) does not wrap `d.executor.Execute(...)` in any `recover()` — only the narrow `chargeDecodeGas` helper (lines 224-247) scopes a recover, and that only re-panics for anything other than gas-meter errors. This means the panic is not converted into a Solidity-style revert at the precompile layer the way other precompiles do it (e.g. `precompiles/addr` and `precompiles/solo` explicitly wrap their `Execute` with a `recover()` "to catch gas meter panics" and turn any panic into `err = fmt.Errorf("execution reverted: %v", r)` — the pointer precompile has no such guard).

### Impact Explanation
The panic is caught somewhere further up the stack (e.g. `x/evm/keeper/msg_server.go` logs and re-panics, `app/app.go`'s `ProcessBlock`/`makeGigaDeliverTx` have top-level `recover()` that convert unhandled panics into a failed-tx ABCI response), so in the DeliverTx/block-processing path this is very likely reduced to "the transaction fails" rather than a validator crash, since all validators execute the same deterministic input and reach the identical panic/recover outcome (no chain split). However, this still represents a missing-input-validation defect: unlike every sibling precompile (`addr`, `solo`) that explicitly guards `Execute` against panics and downgrades them to clean EVM reverts, the pointer precompile relies entirely on callers further up the stack to catch its panics, and that reliance is undocumented and inconsistent across the 15+ legacy pointer implementations. If any RPC-facing simulation path (`eth_call`/`eth_estimateGas`, `debug_traceCall`) reaches this code without an enclosing `recover()`, it could crash or 500 that RPC worker goroutine per request; I was unable to fully confirm whether every such path is protected, only that `evmrpc/simulate.go`'s `SimulationAPI.Call` does wrap the top-level call in two `recover()`s.

### Likelihood Explanation
High likelihood of triggering: any account can create a CosmWasm contract that returns a `token_info`/`contract_info` reply with a non-string or absent `name`/`symbol` field (e.g. `{"name": null}` or omitting the field entirely, which is trivial for a contract author), then call `addCW20Pointer`/`addCW721Pointer`/`addCW1155Pointer` on it — no special privileges, funds, or race conditions required.

### Recommendation
In `precompiles/pointer/pointer.go` (and all legacy variants), replace the bare type assertions with the two-value form and return a proper error on failure, e.g.:
```go
name, ok := formattedRes["name"].(string)
if !ok {
    return nil, 0, fmt.Errorf("token_info response missing or invalid 'name' field")
}
symbol, ok := formattedRes["symbol"].(string)
if !ok {
    return nil, 0, fmt.Errorf("token_info response missing or invalid 'symbol' field")
}
```
Additionally, wrap `DynamicGasPrecompile.RunAndCalculateGas`'s call to `d.executor.Execute` in a `recover()` that downgrades any panic to `vm.ErrExecutionReverted` (mirroring the pattern already used in `precompiles/addr` and `precompiles/solo`), so a defect in any one precompile's field-parsing logic cannot depend on outer layers to avoid an unhandled panic.

2. From any EOA, send an EVM transaction calling the Pointer precompile at `0x000000000000000000000000000000000000100b`, method `addCW20Pointer(string cwAddr)` with `cwAddr` = `C`'s bech32 address.
3. 	operation := fmt.Sprintf("%s_unknown", d.name)
	defer func() {
		HandlePrecompileError(err, evm, operation)
		if err != nil {
			fmt.Printf("precompile %s encountered error: %v\n", d.name, err)
			err = vm.ErrExecutionReverted
		}
	}()
	ctxer := state.GetDBImpl(evm.StateDB)
	if ctxer == nil {
		return nil, 0, errors.New("cannot get context from EVM")
	}
	// Resolve the target method from the 4-byte selector only. The argument
	// payload is intentionally NOT decoded yet: ABI decoding of attacker-
	// controlled calldata can cost far more than len(input) (a single string can
	// be referenced by many array/tuple slots), so it must be paid for out of the
	// gas the caller supplied. The static-precompile path charges RequiredGas in
	// vm.RunPrecompiledContract before running; that step is skipped for
	// dynamic-gas precompiles, so we apply the equivalent charge here.
	methodID, err := ExtractMethodID(input)
	if err != nil {
		return nil, 0, err
	}
	method, err := d.MethodById(methodID)
	if err != nil {
		return nil, 0, err
	}
	operation = method.Name

	ctx := ctxer.Ctx()
	// Install the gas meter derived from the supplied EVM gas, then charge for
	// decoding the calldata BEFORE decoding it. A call that cannot afford the
	// decode is rejected here, before the parse/allocation work is performed.
	// chargeDecodeGas scopes the out-of-gas recovery to just these charges, so an
	// executor that later exhausts its gas keeps its normal (propagating)
	// out-of-gas semantics.
	gasLimit := d.executor.EVMKeeper().GetCosmosGasLimitFromEVMGas(ctx.WithGasMeter(sdk.NewInfiniteGasMeterWithMultiplier(ctx)), suppliedGas)
	ctx = ctx.WithGasMeter(sdk.NewGasMeterWithMultiplier(ctx, gasLimit))
	if err = d.chargeDecodeGas(ctx, method, input); err != nil {
		return nil, 0, err
	}

	args, err := method.Inputs.Unpack(input[4:])
	if err != nil {
		return nil, 0, err
	}
	em := ctx.EventManager()
	ctx = ctx.WithEventManager(sdk.NewEventManager())
	ctx = ctx.WithEVMPrecompileCalledFromDelegateCall(isFromDelegateCall)
	ret, remainingGas, err = d.executor.Execute(ctx, method, caller, callingContract, args, value, readOnly, evm, suppliedGas, hooks)
	if err != nil {
		return ret, remainingGas, err
	}
	events := ctx.EventManager().Events()
	if len(events) > 0 {
		em.EmitEvents(ctx.EventManager().Events())
	}
	return ret, remainingGas, err
}

func (d DynamicGasPrecompile) chargeDecodeGas(ctx sdk.Context, method *abi.Method, input []byte) (err error) {
	defer func() {
		if r := recover(); r != nil {
			switch r.(type) {
			case sdk.ErrorOutOfGas, sdk.ErrorGasOverflow:
				err = fmt.Errorf("%v", r)
			default:
				panic(r)
			}
		}
	}()
	scanCost := DefaultGasCost(input, false)
	ctx.GasMeter().ConsumeGas(scanCost, fmt.Sprintf("%s precompile calldata scan", d.name))
	decodeCost, ok := DecodeGasCost(method.Inputs, input)
	if !ok {
		// Calldata is structurally invalid (Unpack would reject it too); reject
		// now, without attempting the decode.
		return fmt.Errorf("invalid calldata encoding for %s", d.name)
	}
	// DecodeGasCost already includes scanCost; charge only the remaining
	// (string-copy) portion so the decode is priced exactly once.
	ctx.GasMeter().ConsumeGas(decodeCost-scanCost, fmt.Sprintf("%s precompile calldata decode", d.name))
	return nil
}
