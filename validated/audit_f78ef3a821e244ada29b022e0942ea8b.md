### Title
Governance-controlled `RegisterPointerDisabled` switch is bypassed by the `pointer` EVM precompile - ([File: precompiles/pointer/pointer.go])

### Summary
The chain exposes two independent code paths for creating CW↔EVM pointer contracts: the Cosmos `MsgRegisterPointer` handler and the `pointer` precompile at `0x000000000000000000000000000000000000100b`. Governance can disable pointer creation entirely via the `RegisterPointerDisabled` param, and `x/evm/keeper/msg_server.go`'s `RegisterPointer` correctly enforces it, but the EVM precompile path does not check this flag at all, letting any EVM caller create pointers even while the switch is set.

### Finding Description
`RegisterPointer` in the Cosmos msg server checks the disable flag before doing anything else: [1](#0-0) 

The corresponding value is read from chain params via `GetRegisterPointerDisabled`: [2](#0-1) 

A dedicated migration exists whose sole purpose is to flip this switch on-chain (`params.RegisterPointerDisabled = true`), confirming it is treated as a real, load-bearing admin control rather than a cosmetic default: [3](#0-2) 

However, the `pointer` precompile's `AddNative`, `AddCW20`, and `AddCW721` handlers — reachable directly by any EVM transaction sender calling `0x100b` — never call `GetRegisterPointerDisabled` or any equivalent guard before creating and registering a pointer: [4](#0-3) [5](#0-4) 

This is structurally identical to the reported bug class: an authorization/enablement flag exists and is enforced on one entry point (`request_self_service_share_transfer`/`create_pending_transaction` analog = `RegisterPointer`), but a second, functionally equivalent entry point (`AddNative`/`AddCW20`/`AddCW721` in the precompile) omits the check entirely, allowing an unprivileged caller to perform the exact action governance intended to block.

### Impact Explanation
When `RegisterPointerDisabled` is set (as the dedicated migration does), the chain operators have determined that CW↔EVM pointer creation must not proceed — for example during incident response to a pointer-related vulnerability, or to freeze the pointer surface during a migration. Because the EVM precompile ignores this flag, any address can still call `addNativePointer`, `addCW20Pointer`, or `addCW721Pointer` and register new ERC20/ERC721 pointer contracts for arbitrary native denoms or CW20/CW721 contracts. Since pointers are the bridge that lets EVM contracts transfer/mint/burn against native or CW20/CW721 assets, bypassing an intentional pointer-creation freeze can enable unauthorized asset bridging/transfer paths that governance believed were closed, undermining the safety guarantee the disable switch is meant to provide.

### Likelihood Explanation
The precompile is public and requires no special privilege — any EVM transaction sender can call it directly, exactly as in the original report where any shareholder could call `request_self_service_share_transfer`. No race condition, validator collusion, or special setup is required beyond the operator having toggled `RegisterPointerDisabled` to true, which is the very condition meant to prevent this exact behavior.

### Recommendation
Add a check for `p.evmKeeper.GetRegisterPointerDisabled(ctx)` at the top of `PrecompileExecutor.Execute` (or in each of `AddNative`, `AddCW20`, `AddCW721`) in `precompiles/pointer/pointer.go`, returning an error such as "registering CW->ERC pointers has been disabled" when the flag is set, mirroring the check already present in `x/evm/keeper/msg_server.go`'s `RegisterPointer`. Additionally, audit other legacy versions of this precompile (`precompiles/pointer/legacy/v552`, `v555`, `v562`, `v610`, `v640`, etc.) for the same omission, since they share the same handler logic without the flag check.

### Proof of Concept
1. Governance (or an emergency upgrade) sets `RegisterPointerDisabled = true` via `x/evm` params, as done by `MigrateDisableRegisterPointer`.
2. Verify via Cosmos RPC that `MsgRegisterPointer` now fails with "registering CW->ERC pointers has been disabled" (see `TestRegisterPointerDisabled` at `x/evm/keeper/msg_server_test.go:836-887`).
3. From any EVM account, send a transaction calling `addNativePointer(token)` / `addCW20Pointer(cwAddr)` / `addCW721Pointer(cwAddr)` on precompile address `0x000000000000000000000000000000000000100b`.
4. Observe the call succeeds and a new pointer contract is deployed and registered via `UpsertERCNativePointer`/`UpsertERCCW20Pointer`/`UpsertERCCW721Pointer`, despite `RegisterPointerDisabled` being true — demonstrating the bypass of the intended governance control.

func (k *Keeper) GetRegisterPointerDisabled(ctx sdk.Context) bool {
	if !ctx.IsTracing() {
		return k.GetParams(ctx).RegisterPointerDisabled
	}
	switch {
	case semver.Compare(ctx.ClosestUpgradeName(), "v6.0.6") < 0:
		// Not present in pre-5.8.0 params; use default
		return types.DefaultRegisterPointerDisabled
	default:
		return k.GetParams(ctx).RegisterPointerDisabled
	}
}

	}
	return

func (p PrecompileExecutor) AddNative(ctx sdk.Context, method *ethabi.Method, caller common.Address, args []interface{}, value *big.Int, evm *vm.EVM, hooks *tracing.Hooks) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}
	if err := pcommon.ValidateArgsLength(args, 1); err != nil {
		return nil, 0, err
	}
	token := args[0].(string)
	metadata, metadataExists := p.bankKeeper.GetDenomMetaData(ctx, token)
	if !metadataExists {
		return nil, 0, fmt.Errorf("denom %s does not have metadata stored and thus can only have its pointer set through gov proposal", token)
	}
	name := metadata.Name
	symbol := metadata.Symbol
	var decimals uint8
	for _, denomUnit := range metadata.DenomUnits {
		if denomUnit.Exponent > uint32(decimals) && denomUnit.Exponent <= math.MaxUint8 {
			decimals = uint8(denomUnit.Exponent)
			name = denomUnit.Denom
			symbol = denomUnit.Denom
			if len(denomUnit.Aliases) > 0 {
				name = denomUnit.Aliases[0]
			}
		}
	}
	contractAddr, err := p.evmKeeper.UpsertERCNativePointer(ctx, evm, token, utils.ERCMetadata{Name: name, Symbol: symbol, Decimals: decimals})
	if err != nil {
		return nil, 0, err
	}

	ret, err = method.Outputs.Pack(contractAddr)
	remainingGas = pcommon.GetRemainingGas(ctx, p.evmKeeper)
	return
}
