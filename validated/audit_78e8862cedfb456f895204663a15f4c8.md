## Finding

### Title
Stale historical state-commitment proofs let a GET request timeout be re-processed and its relayer fee double-refunded after the response was already delivered and paid — (File: `evm/src/core/EvmHost.sol`)

### Summary
`EvmHost.dispatchIncoming(GetResponse, ...)` pays the relayer fee from `_requestCommitments[commitment]` when a GET response is successfully delivered, but — unlike every other terminal path in the same contract — it never deletes `_requestCommitments[commitment]` afterward. The same commitment therefore remains "known" (`meta.sender != 0`) indefinitely, and `HandlerV2.handleGetRequestTimeouts` accepts a non-membership proof from *any* historical, still-stored state commitment height, not necessarily the latest one. This lets anyone submit a stale timeout proof (dated before the response was delivered) after the response has already been delivered and the relayer already paid, causing `dispatchTimeOut` to run again and refund the same fee a second time.

### Finding Description
`_requestCommitments` is the single source of truth for "is this outbound request still pending, and how much fee is owed." Every terminal-state function that consumes it explicitly deletes the entry as "replay protection": [1](#0-0) 

Compare this to the GET-response success path, which pays the fee but leaves the commitment in storage: [2](#0-1) 

`fundRequest`'s own docstring confirms the team is aware `_requestCommitments` can still exist post-delivery ("If called on an already delivered request, these funds will be seen as a donation") — showing this state is reachable and unaddressed: [3](#0-2) 

The state-commitment store itself is keyed by `(stateMachineId, height)` and old heights are never pruned: [4](#0-3) 

`HandlerV2.handleGetRequestTimeouts` only checks that the request's own `timeout()` has elapsed relative to the **chosen proof height's** timestamp — it does not require that height to be the latest, nor does it check whether a response was delivered at a *later* height: [5](#0-4) 

Attack sequence:
1. A `GetRequest` is dispatched with a fee escrowed in `_requestCommitments[commitment]`.
2. The request actually times out per its own `timeoutTimestamp`, but is later legitimately answered: a relayer submits a valid `GetResponse`. `dispatchIncoming` succeeds, `onGetResponse` runs, and the fee is paid to the relayer — but `_requestCommitments[commitment]` is **not deleted**.
3. An attacker (any permissionless caller) picks an **older, already-finalized** state-machine height whose state root predates the response delivery (still fully available in `_stateCommitments`), and where at that height the non-membership proof for `RESPONSE_RECEIPTS_STORAGE_PREFIX + commitment` genuinely holds (because the response hadn't been recorded yet at that height).
4. `handleGetRequestTimeouts` validates: challenge period elapsed for that height, `request.timeout() > state.timestamp` is false (request already expired by that historical timestamp), `meta.sender != 0` (still true, never cleared), and the stale non-membership proof verifies against that historical root.
5. `dispatchTimeOut` is invoked: it calls `onGetTimeout` on the app a second time (the app already processed `onGetResponse` for this same commitment) and refunds `meta.fee` to `meta.sender` — a duplicate refund of a fee that was already paid out to the relayer in step 2.

The existing guards (`DuplicateMessage` check in `handleGetResponses`, using `_responseReceipts`) only prevent replaying the *response* path twice; they do nothing to stop the *timeout* path from being triggered after-the-fact with a historically-valid-but-stale proof, because `_requestCommitments` was never invalidated on the success branch of `dispatchIncoming(GetResponse,...)`.

### Impact Explanation
This is a false/stale-proof acceptance leading to double-settlement of protocol funds: the host's fee-token balance pays out the same GET request's fee twice — once to the relayer that delivered the response, and again to the original payer via the bogus timeout. It also forces the destination application's `onGetTimeout` callback to execute for a request it already resolved via `onGetResponse`, which can corrupt application-level accounting/state that assumed at-most-once callback semantics. Any unprivileged caller can trigger this once the preconditions (late-but-valid response delivery, retained historical state commitment) occur naturally through normal relayer operation — no malicious relayer, admin, or governance actor is required.

### Likelihood Explanation
The precondition — a GET response delivered after its nominal timeout has elapsed, while an earlier finalized state commitment (predating the response) is still available on-chain — is a realistic and even common operational scenario for cross-chain messaging under congestion or delayed relaying. The host never prunes old `_stateCommitments` entries, so the stale proof material required to exploit this remains available for as long as the chain's history is queryable/provable. No signature forgery or trust assumption is needed; the exploit only reuses genuinely valid but outdated proof data against a commitment entry that should have been cleared.

### Recommendation
Delete `_requestCommitments[commitment]` in the success branch of `dispatchIncoming(GetResponse, ...)` immediately after (or instead of) paying the relayer fee, mirroring the "replay protection" pattern already used in both `dispatchTimeOut` overloads. Additionally, `handleGetRequestTimeouts` (and its POST counterpart) should reject non-membership proofs from a state height earlier than the height at which the corresponding response/receipt was actually recorded, or require the proof height be the current latest finalized height for that state machine, to prevent stale-height replay.

### Proof of Concept
1. Dispatch a `GetRequest` via `EvmHost.dispatch(DispatchGet)` with fee `F`, `timeoutTimestamp = T`.
2. Let time pass such that the destination state machine's timestamp advances past `T` at height `H1`, but no response has been recorded yet at `H1` (state commitment for `H1` is stored via `storeConsensusState`/state machine update flow).
3. A relayer later (legitimately) delivers the `GetResponse` at a later height `H2 > H1`; `EvmHost.dispatchIncoming(GetResponse,...)` succeeds, `onGetResponse` fires, and fee `F` is transferred to the relayer. `_requestCommitments[commitment]` still holds `{sender, fee: F}` (unchanged).
4. Attacker builds a `GetTimeoutMessage` referencing height `H1` (still stored in `_stateCommitments`), with a valid Merkle/trie non-membership proof for `RESPONSE_RECEIPTS_STORAGE_PREFIX || commitment` against `H1`'s root (true, since the response wasn't recorded until `H2`).
5. Attacker calls `HandlerV2.handleGetRequestTimeouts(host, message)`. All checks pass (`challengePeriod` elapsed for `H1`, `request.timeout() <= state(H1).timestamp`, `meta.sender != 0`, proof valid) → `host.dispatchTimeOut(GetRequestTimeout(...), meta, commitment)` executes, calling `onGetTimeout` again and refunding fee `F` a second time to `meta.sender`, resulting in `2F` paid out of the host's fee-token reserves for a single dispatched request.

    /**
     * @dev Dispatch an incoming GET response to source module
     * @param response - get response
     */
    function dispatchIncoming(GetResponse memory response, address relayer) external restrict(_hostParams.handler) {
        // replay protection
        bytes32 commitment = response.request.hash();
        _responseReceipts[commitment] = ResponseReceipt({
            relayer: relayer,
            responseCommitment: response.hash()
        });

        (bool success,) = _bytesToAddress(response.request.from)
            .call(abi.encodeWithSelector(IApp.onGetResponse.selector, IncomingGetResponse(response, relayer)));

        if (!success) {
            // so that it can be retried
            delete _responseReceipts[commitment];
            return;
        }

        // reward the relayer fee
        uint256 fee = _requestCommitments[commitment].fee;
        if (fee != 0) {
            IERC20(feeToken()).safeTransfer(relayer, fee);
        }
        emit GetRequestHandled({commitment: commitment, relayer: relayer});
    }

    function dispatchTimeOut(
        GetRequestTimeout memory timeout,
        FeeMetadata memory meta,
        bytes32 commitment
    ) external restrict(_hostParams.handler) {
        // replay protection
        delete _requestCommitments[commitment];
        (bool success,) = _bytesToAddress(timeout.request.from)
            .call(abi.encodeWithSelector(IApp.onGetTimeout.selector, timeout));

        if (!success) {
            // so that it can be retried
            _requestCommitments[commitment] = meta;
            return;
        }

        if (meta.fee != 0) {
            // refund relayer fee
            IERC20(feeToken()).safeTransfer(meta.sender, meta.fee);
        }
        emit GetRequestTimeoutHandled({commitment: commitment, dest: string(timeout.request.dest)});
    }

    /**
     * @dev Increase the relayer fee for a previously dispatched request.
     * This is provided for use only on pending requests, such that when they timeout,
     * the user can recover the entire relayer fee.
     *
     * @notice Payment can be made with either the native token or the feeToken.
     * If native tokens are supplied, it will perform a swap under the hood using the local uniswap router.
     * Will revert if enough native tokens are not provided.
     *
     * If no native tokens are provided then it will try to collect payment from the calling contract in
     * the feeToken.
     *
     * If called on an already delivered request, these funds will be seen as a donation to the hyperbridge protocol.
     * @param commitment - The request commitment
     * @param amount - The amount provided in `feeToken()`
     */
    function fundRequest(bytes32 commitment, uint256 amount) external payable notFrozen {
        if (msg.value > 0) {
            address[] memory path = new address[](2);
            address uniswapV2 = _hostParams.uniswapV2;
            path[0] = IUniswapV2Router02(uniswapV2).WETH();
            path[1] = feeToken();
            IUniswapV2Router02(uniswapV2).swapETHForExactTokens{value: msg.value}(
                amount, path, address(this), block.timestamp
            );
        } else {
            IERC20(feeToken()).safeTransferFrom(_msgSender(), address(this), amount);
        }

        FeeMetadata memory metadata = _requestCommitments[commitment];
        if (metadata.sender == address(0)) revert UnknownRequest();

        metadata.fee += amount;
        _requestCommitments[commitment] = metadata;

        emit RequestFunded({commitment: commitment, newFee: metadata.fee});
    }

    /**
     * @dev Check the provided Get request timeouts, then dispatch to modules
     * @param host - Ismp host
     * @param message - batch get request timeouts
     */
    function handleGetRequestTimeouts(IHost host, GetTimeoutMessage calldata message) external notFrozen(host) {
        uint256 delay = block.timestamp - host.stateMachineCommitmentUpdateTime(message.height);
        uint256 challengePeriod = host.challengePeriod();
        if (challengePeriod != 0 && challengePeriod > delay) revert ChallengePeriodNotElapsed();

        // fetch the state commitment
        StateCommitment memory state = host.stateMachineCommitment(message.height);
        if (state.stateRoot == bytes32(0)) revert StateCommitmentNotFound();
        uint256 timeoutsLength = message.timeouts.length;

        for (uint256 i = 0; i < timeoutsLength; ++i) {
            GetRequest memory request = message.timeouts[i];
            // timed-out?
            if (request.timeout() > state.timestamp) revert MessageNotTimedOut();

            bytes32 commitment = request.hash();
            FeeMetadata memory meta = host.requestCommitments(commitment);
            if (meta.sender == address(0)) revert UnknownMessage();

            bytes[] memory keys = new bytes[](1);
            keys[0] = bytes.concat(RESPONSE_RECEIPTS_STORAGE_PREFIX, commitment);

            // verify state trie non-membership proofs
            PolkadotTrie.StorageValue memory entry = PolkadotTrie.VerifyProof(state.stateRoot, message.proof, keys)[0];
            if (entry.value.length != 0) revert InvalidProof();

            host.dispatchTimeOut(GetRequestTimeout(request, _msgSender()), meta, commitment);
        }
    }
