### Title

Identity encryption keys make PedPoP secret shares publicly decryptable - (File: crypto/dkg/pedpop/src/encryption.rs)

### Summary

PedPoP accepts the identity point as a participant’s long-term encryption key, allowing a participant to publish `enc_key = identity` and cause every share addressed to them to use the publicly computable ECDH point `identity`. [1](#0-0) [2](#0-1) 

### Finding Description

`EncryptionKeyMessage::read` reads `enc_key` through `Ciphersuite::read_G`, which validates only canonical group encodings and does not reject identity. [1](#0-0) [3](#0-2)  The resulting identity key is stored without a proof of possession, recipient confirmation, or identity check when commitment messages are registered. [4](#0-3) 

`encrypt` then derives the shared point as `msg_key * enc_key`, so `msg_key * identity = identity`, and `cipher` derives the ChaCha20 key from the protocol context plus that known shared point. [5](#0-4) [6](#0-5)  The per-message PoP authenticates knowledge of the ephemeral message key, but it does not authenticate or validate the previously registered encryption key. [7](#0-6) [8](#0-7) 

### Impact Explanation

Anyone who observes the encrypted-share bytes and knows the DKG context can reconstruct the same ChaCha20 stream and recover every scalar share addressed to the participant which registered the identity key. [9](#0-8) [10](#0-9)  For `t = 1`, `ThresholdParams::new` accepts threshold one, so the recovered participant share is sufficient to reconstruct the threshold secret represented by that key share. [11](#0-10)  For larger thresholds, this still leaks a valid threshold key share to parties who did not participate in the DKG. [12](#0-11) 

### Likelihood Explanation

A DKG participant can independently place the canonical identity encoding in its own `EncryptionKeyMessage`; the parser accepts it, registration stores it, and all senders then encrypt shares to that key. [1](#0-0) [13](#0-12)  No invalid encoding, malformed point, malicious validator set, broken consensus, or leaked private key is required. [3](#0-2) 

### Recommendation

Reject identity points for both `EncryptionKeyMessage::enc_key` and `EncryptedMessage::key` before storing or using either value, preferably through a non-identity point reader equivalent to `Curve::read_G`. [14](#0-13)  Additionally bind possession of the registered encryption key to the participant and DKG context before any participant encrypts a share to it. [15](#0-14) 

### Proof of Concept

1. Malicious participant `i` constructs an `EncryptionKeyMessage` whose `enc_key` bytes canonically encode the group identity. [16](#0-15) 
2. Honest participants parse and register that message successfully because `read_G` accepts any canonical valid point, including identity. [17](#0-16) [3](#0-2) 
3. Each sender calculates `ecdh = msg_key * identity = identity` and encrypts the share with `ChaCha20` keyed by `Transcript("DKG Encryption v0.2", context, "shared_key" = identity_encoding)`. [5](#0-4) [6](#0-5) 
4. Any observer reconstructs the same public key and IV, XORs the ciphertext’s scalar-width payload with the keystream, and recovers the `SecretShare` bytes sent to participant `i`. [18](#0-17) [19](#0-18)

fn cipher<C: Ciphersuite>(context: [u8; 32], ecdh: &Zeroizing<C::G>) -> ChaCha20 {

  // TODO: https://github.com/serai-dex/serai/issues/151
  let mut transcript = RecommendedTranscript::new(b"DKG Encryption v0.2");
  transcript.append_message(b"context", context);

  transcript.domain_separate(b"encryption_key");

  let mut ecdh = ecdh.to_bytes();
  transcript.append_message(b"shared_key", ecdh.as_ref());
  ecdh.as_mut().zeroize();

  let zeroize = |buf: &mut [u8]| buf.zeroize();

  let mut key = Cc20Key::default();
  let mut challenge = transcript.challenge(b"key");

  // ChaCha20 has the same commentary as the transcript regarding ZAlloc
  // TODO: https://github.com/serai-dex/serai/issues/151

  context: [u8; 32],
  nonce: C::G,
  key: C::G,
  sender: Participant,
  msg: &[u8],

  transcript.domain_separate(b"proof_of_possession");

  transcript.append_message(b"nonce", nonce.to_bytes());
  transcript.append_message(b"key", key.to_bytes());
  // This is sufficient to prevent the attack this is meant to stop

  // This, as written above, doesn't hurt

  // an unknown to anyone discrete log, breaking the system
  C::hash_to_F(b"DKG-encryption-proof_of_possession", &transcript.challenge(b"schnorr"))
}

  fn read_G<R: Read>(reader: &mut R) -> io::Result<Self::G> {
    let mut encoding = <Self::G as GroupEncoding>::Repr::default();
    reader.read_exact(encoding.as_mut())?;

    let point = Option::<Self::G>::from(Self::G::from_bytes(&encoding))
      .ok_or_else(|| io::Error::other("invalid point"))?;
    if point.to_bytes().as_ref() != encoding.as_ref() {
      Err(io::Error::other("non-canonical point"))?;
    }
    Ok(point)
