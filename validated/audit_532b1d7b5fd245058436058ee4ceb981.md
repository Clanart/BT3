## Title
Missing contract-existence check on `dispatchIncoming(GetResponse)` and `dispatchTimeOut(...)` low-level calls permanently silences undeliverable callbacks - (File: `evm/src/core/EvmHost.sol`)

### Summary
`EvmHost.sol` implements four "dispatch to destination module" functions that each perform an untrusted low-level `.call()` to an address decoded from request/response data: `dispatchIncoming(PostRequest, ...)`, `dispatchIncoming(GetResponse, ...)`, `dispatchTimeOut(GetRequestTimeout, ...)`, and `dispatchTimeOut(PostRequestTimeout, ...)`. Only the first of these four guards the call with an `extcodesize` check before treating the destination as callable. The other three omit it, so a `.call()` to an address with no deployed code returns `(true, "")` per EVM semantics, is indistinguishable from a real successful callback, and is treated as final, non-retryable delivery.

### Finding Description
`dispatchIncoming(PostRequest memory request, address relayer)` explicitly checks for contract existence before doing anything else: [1](#0-0) 

If `destination` has no code, the function returns early *before* writing `_requestReceipts[commitment]`, leaving the request retryable/timeoutable exactly as if delivery never occurred.

The sibling functions that dispatch GET responses and both timeout types do not have this guard: [2](#0-1) 

In each of these three functions:
- `dispatchIncoming(GetResponse, ...)` writes `_responseReceipts[commitment]` *before* calling `_bytesToAddress(response.request.from).call(...)`.
- `dispatchTimeOut(GetRequestTimeout, ...)` and `dispatchTimeOut(PostRequestTimeout, ...)` delete `_requestCommitments[commitment]` *before* calling `_bytesToAddress(timeout.request.from).call(...)`.

Per the Solidity/EVM low-level call semantics cited in the external report, a `.call()` targeting an address with no code always returns `success == true`. Because these three functions branch on `success` to decide whether to roll back the state change (`delete _responseReceipts[commitment]` / restore `_requestCommitments[commitment]`) and allow a retry, a codeless `from`/destination address makes the `if (!success)` retry path unreachable — the function instead falls through to the "happy path": it emits the completion event, and for the two functions carrying a fee, pays out `IERC20(feeToken()).safeTransfer(...)`, all while the destination app's `onGetResponse`/`onGetTimeout`/`onPostRequestTimeout` callback never actually executed.

This is the exact bug class from the external report ("the low-level call will still return success... Account existence must be checked prior to calling if needed") reproduced locally, with the codebase's own `dispatchIncoming(PostRequest)` implementation showing the intended fix pattern that was not applied consistently to the other three call sites.

### Impact Explanation
When the destination app address has no code at call time (e.g. the app contract self-destructs, or a proxy/implementation is removed/uninitialized between request dispatch and response/timeout delivery), the protocol permanently marks the response/timeout as handled and pays out the associated fee, even though the module callback that was supposed to run application-level logic (e.g., releasing escrow, unlocking bandwidth, updating accounting) never executed. Because the receipt/commitment state is deleted/finalized on the false "success", there is no path left to retry delivery once code is later present again — the message is silently and permanently lost, which can cause funds tied to that request/response (relayer fee, or any app-side settlement gated behind the callback) to be paid out or dropped without the corresponding execution occurring.

### Likelihood Explanation
This requires the destination address to be codeless at the moment of delivery — realistically achievable for any application that can `SELFDESTRUCT` (still valid pre-Cancun deployments, or via `CREATE2`/proxy patterns where an implementation can be torn down) or for badly configured `from`/`to` fields. It does not require a malicious relayer, prover, or admin: the relayer/handler call is permissionless by design, and the corrupted value (`success` from a no-code `.call()`) is a deterministic EVM property, not something a peer needs to forge.

### Recommendation
Add the same `extcodesize` guard used in `dispatchIncoming(PostRequest)` to `dispatchIncoming(GetResponse)`, `dispatchTimeOut(GetRequestTimeout)`, and `dispatchTimeOut(PostRequestTimeout)` before performing the low-level `.call()`, returning early (without writing/deleting receipts or paying fees) when the target has no code, so the message remains retryable instead of being falsely finalized.

### Proof of Concept
1. App contract `A` on the destination chain dispatches a GET request via `IDispatcher.dispatch(...)`; `request.from = address(A)`.
2. Before the response/timeout proof is delivered, `A` executes `SELFDESTRUCT` (or a proxy backing `A` is emptied), so `address(A)` now has `extcodesize == 0`.
3. A relayer (any permissionless caller) submits a valid membership proof via `handleGetResponses`, which eventually invokes `EvmHost.dispatchIncoming(GetResponse, relayer)`.
4. `_responseReceipts[commitment]` is written, then `address(A).call(...)` returns `(true, "")` trivially since `A` has no code.
5. Because `success == true`, the function skips the rollback branch, transfers `fee` to `relayer`, and emits `GetRequestHandled` — even though `A.onGetResponse` never ran. The commitment can never be redelivered even if `A` is later redeployed at the same address with genuine logic, since the receipt already reflects a completed delivery. [3](#0-2)

    function dispatchIncoming(PostRequest memory request, address relayer) external restrict(_hostParams.handler) {
        address destination = _bytesToAddress(request.to);
        uint256 size;
        assembly {
            size := extcodesize(destination)
        }
        if (size == 0) {
            // instead of reverting the entire batch, early return here.
            return;
        }

        // replay protection
        bytes32 commitment = request.hash();
        _requestReceipts[commitment] = relayer;

        (bool success,) = address(destination)
            .call(abi.encodeWithSelector(IApp.onAccept.selector, IncomingPostRequest(request, relayer)));

        if (!success) {
            // so that it can be retried
            delete _requestReceipts[commitment];
            return;
        }
        emit PostRequestHandled({commitment: commitment, relayer: relayer});

    /**
     * @dev Dispatch an incoming GET response to source module
     * @param response - get response
     */
    function dispatchIncoming(GetResponse memory response, address relayer) external restrict(_hostParams.handler) {
        // replay protection
        bytes32 commitment = response.request.hash();
        _responseReceipts[commitment] = ResponseReceipt({
            relayer: relayer,
            responseCommitment: response.hash()
        });

        (bool success,) = _bytesToAddress(response.request.from)
            .call(abi.encodeWithSelector(IApp.onGetResponse.selector, IncomingGetResponse(response, relayer)));

        if (!success) {
            // so that it can be retried
            delete _responseReceipts[commitment];
            return;
        }

        // reward the relayer fee
        uint256 fee = _requestCommitments[commitment].fee;
        if (fee != 0) {
            IERC20(feeToken()).safeTransfer(relayer, fee);
        }
        emit GetRequestHandled({commitment: commitment, relayer: relayer});
    }

    /**
     * @dev Dispatch an incoming GET timeout to the source module.
     * @notice Does not refund any protocol fees.
     * @param timeout - timed-out get request bundled with the relayer that submitted the timeout proof
     * @param meta - fee metadata for the original request
     * @param commitment - request commitment
     */
    function dispatchTimeOut(
        GetRequestTimeout memory timeout,
        FeeMetadata memory meta,
        bytes32 commitment
    ) external restrict(_hostParams.handler) {
        // replay protection
        delete _requestCommitments[commitment];
        (bool success,) = _bytesToAddress(timeout.request.from)
            .call(abi.encodeWithSelector(IApp.onGetTimeout.selector, timeout));

        if (!success) {
            // so that it can be retried
            _requestCommitments[commitment] = meta;
            return;
        }

        if (meta.fee != 0) {
            // refund relayer fee
            IERC20(feeToken()).safeTransfer(meta.sender, meta.fee);
        }
        emit GetRequestTimeoutHandled({commitment: commitment, dest: string(timeout.request.dest)});
    }
