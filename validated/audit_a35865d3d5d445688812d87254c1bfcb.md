### Title
Gasless module lends KAIA against a stale, once-per-block cached `allowedTokens`/`swapRouter` set, allowing an unrepaid gas loan if the on-chain GaslessSwapRouter allow-list changes before the bundle executes - (File: kaiax/gasless/impl/getter.go)

### Summary
The `kaiax/gasless` module decides whether to treat an `ApproveTx`/`SwapTx` pair as a gasless bundle - and therefore whether to prepend an unconditional `LendTxGenerator` transaction that pays out KAIA to the sender - based on an in-memory `allowedTokens` map and `swapRouter` address that are refreshed only once per block header via `updateAddresses`. This is the same bug class as the reported `AvailBridge` issue: a privileged/administrative update to an allow-list can occur after a value-moving step has already been taken but before the corresponding compensating/verifying step executes, because the two steps consult the allow-list at different points in time.

### Finding Description
`GaslessModule.updateAddresses` re-reads the `GaslessSwapRouter` contract once per block and repopulates `g.allowedTokens` and `g.swapRouter`: [1](#0-0) 

All admission and execution-eligibility checks (`isApproveTx`, `isSwapTx`, `VerifyExecutable`) read this cached map under a lock, not the authoritative on-chain state at the moment of actual inclusion: [2](#0-1) 

When a bundle is judged executable, `GetLendTxGenerator` unconditionally builds and signs a value-transfer transaction from the block proposer's node key to the swap sender, prior to (and independent of) the `ApproveTx`/`SwapTx` themselves: [3](#0-2) 

Because `LendTx`, `ApproveTx`, and `SwapTx` are three distinct on-chain transactions rather than a single atomic call, the correctness of the whole flow depends on `SwapTx` still being valid at inclusion time against the *authoritative* GaslessSwapRouter contract state. If the router's registered/allowed token set (or the router address itself, via KIP-149 Registry) changes between the header used to populate the cache and the block in which the bundle is actually included - or even via an earlier transaction in the very same block that removes the token/router - the module's admission-time checks (`isApproveTxReady`/`isSwapTxReady`, `checkBalanceForSwap`) can pass on stale data while the real `SwapTx` execution against the updated GaslessSwapRouter can fail or behave differently. In that case, the `LendTx` funds have already been unconditionally transferred to the sender, but the compensating swap that is supposed to produce `AmountRepay` back to the lender may not execute as expected, since `VerifyExecutable`'s `SP4` check on `AmountRepay` is only a mempool-time correctness check, not an on-chain enforced guarantee tied to the lend: [4](#0-3) 

This mirrors the report's root cause exactly: two logically-coupled operations (lock/lend vs. release/repay) each independently consult a mutable allow-list, and the list can be updated in the gap between them, breaking the assumed consistency.

### Impact Explanation
If the swap fails to properly repay the lender due to the router/allowed-token set changing between validation and execution, the block proposer's lent KAIA is not repaid, resulting in fee-delegation/gasless settlement value loss for the lender (the node operating the gasless mechanism). This falls under the accepted "gasless or auction settlement theft" impact category. The exact mechanics of on-chain enforcement inside the `GaslessSwapRouter` contract could not be verified because its Solidity source was not found in the indexed codebase (only generated bindings for a similarly-named module were located), so the precise conditions under which the swap would revert vs. silently under-repay could not be confirmed from available code.

### Likelihood Explanation
The staleness window is structural, not incidental: `updateAddresses` is invoked once per processed block header, meaning the cached allow-list is always up to one block old relative to the chain tip, and can be additionally stale within the same block if the swap-router state is modified by an earlier transaction in that block. Any account with permission to modify the GaslessSwapRouter's token list (the entity managing the KIP-149-registered router) can trigger this window; no attacker collusion with a validator is required. However, exploiting it profitably requires the sender to time a swap so the token is de-listed exactly between admission and inclusion, which is a narrower, timing-dependent condition, and I could not confirm from the indexed contract code whether `swapForGas` would revert cleanly (safe) or complete partially (unsafe) in that scenario.

### Recommendation
Re-validate `IsApproveTx`/`IsSwapTx`/`VerifyExecutable` against the authoritative on-chain state of the target block being built (not the cached, once-per-block-refreshed `allowedTokens`/`swapRouter`) immediately before generating and including the `LendTx`, or make the lend transaction itself conditional/atomic with the swap's repayment (e.g., via a single wrapping contract call) so that a failed/invalidated swap cannot leave an unrepaid loan on-chain.

### Proof of Concept
Could not be fully constructed without access to `GaslessSwapRouter.sol`'s on-chain enforcement logic, which was not present in the indexed codebase. Conceptually:
1. A token `T` is registered in `GaslessSwapRouter` and reflected in `g.allowedTokens` via `updateAddresses` at block `N`.
2. A user submits `ApproveTx(T)` + `SwapTx(T, ...)` at block `N+1`; the module's cached `allowedTokens` (still from block `N`) marks the bundle executable, and `GetLendTxGenerator` produces a `LendTx` sending KAIA to the user, prepended in the block being built: [5](#0-4) 
3. Before/within block `N+1`, the router's admin removes token `T` from the allow-list.
4. `LendTx` executes and pays out KAIA unconditionally; `SwapTx` executes against the updated router state and does not perform the expected repayment, leaving the lender under-collateralized - unverifiable to conclusively reproduce end-to-end without the router contract source.

func (g *GaslessModule) isApproveTx(args *ApproveArgs) bool {
	g.gaslessInfoMu.RLock()
	defer g.gaslessInfoMu.RUnlock()

	return g.allowedTokens[args.Token] && // A1
		g.swapRouter == args.Spender && // A3
		args.Amount.Cmp(abi.MaxUint256) == 0 // A4
}

// IsSwapTx checks following conditions:
// S1. tx.to is a whitelisted SwapRouter contract.
// S2. tx.data is `swapForGas(token, amountIn, minAmountOut, amountRepay)`.
// S3. token is a whitelisted ERC20 token.
func (g *GaslessModule) IsSwapTx(tx *types.Transaction) bool {
	args, ok := decodeSwapTx(tx, g.signer)
	return ok && g.isSwapTx(args)
}

func (g *GaslessModule) isSwapTx(args *SwapArgs) bool {
	g.gaslessInfoMu.RLock()
	defer g.gaslessInfoMu.RUnlock()

	return g.swapRouter == args.Router && // S1
		g.allowedTokens[args.Token] // S3
}

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

// MakeLendTx creates a transaction with following properties:
// L1. LendTx.type = 0x7802 (TxTypeEthereumDynamicFee)
// L2. LendTx.from = proposer
// L3. LendTx.to = SwapTx.from
// L4. LendTx.value = LendAmount(approveTxOrNil, swapTx)
func (g *GaslessModule) GetLendTxGenerator(approveTxOrNil, swapTx *types.Transaction) *builder.TxOrGen {
	var src []byte
	if approveTxOrNil != nil {
		src = append(src, approveTxOrNil.Hash().Bytes()...)
	}
	src = append(src, swapTx.Hash().Bytes()...)
	bundleHash := crypto.Keccak256Hash(src)

	gen := func(nonce uint64) (*types.Transaction, error) {
		var (
			chainId = g.InitOpts.ChainConfig.ChainID
			signer  = types.LatestSignerForChainID(chainId)
			key     = g.InitOpts.NodeKey
		)

		to, err := types.Sender(signer, swapTx)
		if err != nil {
			return nil, err
		}

		tx, err := types.NewTransactionWithMap(types.TxTypeEthereumDynamicFee, map[types.TxValueKeyType]interface{}{
			types.TxValueKeyNonce:      nonce,
			types.TxValueKeyTo:         &to,
			types.TxValueKeyAmount:     lendAmount(approveTxOrNil, swapTx),
			types.TxValueKeyData:       common.Hex2Bytes("0x"),
			types.TxValueKeyGasLimit:   params.TxGas,
			types.TxValueKeyGasFeeCap:  swapTx.GasFeeCap(),
			types.TxValueKeyGasTipCap:  swapTx.GasTipCap(),
			types.TxValueKeyAccessList: types.AccessList{},
			types.TxValueKeyChainID:    chainId,
		})
		if err != nil {
			return nil, err
		}

		err = tx.Sign(signer, key)
		return tx, err
	}

	return builder.NewTxOrGenFromGen(gen, bundleHash)
}

func (g *GaslessModule) updateAddresses(header *types.Header) error {
	g.gaslessInfoMu.Lock()
	defer g.gaslessInfoMu.Unlock()

	swapRouter, tokens, err := getGaslessInfo(g.Chain, header)
	// proceed even if there is something wrong with multicall contract
	if err != nil {
		g.swapRouter = common.Address{}
		g.allowedTokens = map[common.Address]bool{}
		logger.Warn("there is something wrong with multicall contract", "err", err.Error())
		return nil
	}

	g.swapRouter = swapRouter

	g.allowedTokens = map[common.Address]bool{}
	for _, addr := range tokens {
		// all tokens are allowed if nil
		if g.GaslessConfig.AllowedTokens == nil {
			g.allowedTokens[addr] = true
		}
		for _, allowed := range g.GaslessConfig.AllowedTokens {
			if addr == allowed {
				g.allowedTokens[addr] = true
			}
		}
	}
