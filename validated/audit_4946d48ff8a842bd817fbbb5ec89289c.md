`SerializeG1Point` and `deserializeG1Point` in `serialization.go` are thin wrappers that delegate directly to gnark-crypto's `bls12381.G1Affine.Bytes()` and `bls12381.G1Affine.SetBytes()` — go-eth-kzg implements no custom masking, flag, or canonicalization logic of its own on top of it. [1](#0-0) 

The BLS12-381 compressed point format used by gnark-crypto (ZCash-style compression flags encoded in the top bits of the first byte) is a canonical serialization: for every valid subgroup point there is exactly one accepted compressed encoding, and `SetBytes` rejects any non-canonical variant (e.g., wrong flag bits, x ≥ field modulus, infinity-flag/x mismatch) before subgroup-checking the result. Since `SerializeG1Point`/`deserializeG1Point` add no extra logic, any divergence between "deserialization success" and "bytes are the unique canonical encoding" would have to originate inside gnark-crypto's `SetBytes`/`Bytes` implementation itself, not in this repository's code.

Per the audit scope rules, "defects inside gnark-crypto with no path through this repo" are explicitly out of scope, and this repo introduces no additional path, flag-handling, or divergence logic around G1 point (de)serialization — `ComputeBlobKZGProof` calls `DeserializeKZGCommitment` (which is `deserializeG1Point`) only to validate the commitment's subgroup membership and never re-serializes the deserialized commitment for use in the transcript (the raw `blobCommitment` bytes are what feed `computeChallenge`, not a re-serialized value). [2](#0-1) 

Because the commitment bytes used in the Fiat-Shamir challenge are the attacker-supplied bytes directly (not `SerializeG1Point(deserializeG1Point(b))`), there is no roundtrip-mismatch surface reachable through `ComputeBlobKZGProof` even if such a gap existed in the underlying curve library.

```go
// SerializeG1Point converts a [bls12381.G1Affine] to [G1Point].
func SerializeG1Point(affine bls12381.G1Affine) G1Point {
	return affine.Bytes()
}

// deserializeG1Point converts a [G1Point] to the internal [bls12381.G1Affine] type. It will return an error if the
// point is not on the group or if the point is not in the correct subgroup.
//
// It implements [validate_kzg_g1].
//
// [validate_kzg_g1]: https://github.com/ethereum/consensus-specs/blob/017a8495f7671f5fff2075a9bfc9238c1a0982f8/specs/deneb/polynomial-commitments.md#validate_kzg_g1
func deserializeG1Point(serPoint G1Point) (bls12381.G1Affine, error) {
	var point bls12381.G1Affine
	_, err := point.SetBytes(serPoint[:])
	if err != nil {
		return bls12381.G1Affine{}, err
	}
	return point, nil
}
```
