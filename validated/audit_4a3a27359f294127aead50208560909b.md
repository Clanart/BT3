### Title
`ReceivedOutput::read` accepts an arbitrary scalar offset without binding it to the output's `script_pubkey`, allowing attacker-controlled bytes to fabricate unspendable received funds - (File: `networks/bitcoin/src/wallet/mod.rs`)

### Summary
The sg/KERNEL_DS bug class is "a write/load operation that is not restricted to the domain it claims to operate on" — bytes from one security domain are applied to a privileged context without validation. In `bitcoin-serai`, `ReceivedOutput` couples a spendability-critical secret (the scalar `offset` needed to re-key the threshold keys) to a Bitcoin `TxOut`, and `ReceivedOutput::read` deserializes both fields straight from the byte stream with no cryptographic consistency check. A `ReceivedOutput` constructed from hostile bytes claims funds are received while carrying an offset that does not re-key the wallet's group key to the output's `script_pubkey`.

### Finding Description
`Scanner::scan_transaction` is the only legitimate constructor of `ReceivedOutput` and it always inserts the correct registered offset for the matched `script_pubkey` [1](#0-0) . However, `ReceivedOutput::read` — the path used to reload persisted outputs — reads `offset` via `Secp256k1::read_F`, then decodes `TxOut` and `OutPoint`, and returns the pair unconditionally [2](#0-1) . It never verifies that `p2tr_script_buf(scanner_key + GENERATOR * offset) == output.script_pubkey`. The analogous verification `group_key()` in `ThresholdKeys` derives the tweaked key as `(core.group_key * scalar) + (G * offset)` [3](#0-2) , and FROST signing adds `offset` to `included[0]`'s share [4](#0-3) , so signing proceeds under whatever offset the bytes claim. Additionally, `read_F` only enforces canonicity, not semantic correctness [5](#0-4) .

### Impact Explanation
An attacker who can feed bytes to `ReceivedOutput::read` (e.g., a tampered output cache, a malicious/coerced data source upstream of the wallet's persistence layer, or injected records in any pipeline that round-trips `ReceivedOutput::serialize`/`read`) can cause the wallet to report an output as received while the recorded offset does not correspond to the output's `script_pubkey`. When the wallet later signs for it — calling `keys.offset(received.offset())` and running the FROST signing protocol — the produced signature validates under `group_key = core * 1 + G * offset`, which is not the key committed in the output's `script_pubkey`. The funds are reported received but are not spendable; in the worst case a substituted `TxOut`/`OutPoint` makes the wallet attempt to spend a nonexistent or attacker-chosen outpoint. This satisfies the "funds reported received that are not spendable" acceptance criterion.

### Likelihood Explanation
Reachability is via the explicitly in-scope `ReceivedOutput::read` untrusted-bytes surface. Exploitation requires only supplying crafted serialized bytes — a canonical scalar plus validly consensus-encoded `TxOut`/`OutPoint` — no valid proofs or keys needed since no binding check exists. Severity is bounded because an attacker must be positioned to influence the wallet's persisted/received-output store rather than merely send on-chain transactions (on-chain sends go through `scan_transaction`, which is safe). Rated Medium: integrity loss of reported/spendable funds under an untrusted-deserialization assumption.

### Recommendation
Bind the offset to the output on deserialization: change `ReceivedOutput::read` (or add a `verify`/`new_checked` constructor) to take the scanner's base `key` and assert `p2tr_script_buf(key + ProjectivePoint::GENERATOR * offset) == Some(output.script_pubkey)`, rejecting otherwise — mirroring the check `register_offset` performs at registration time [6](#0-5) . Alternatively, store a keyed MAC over the serialized `ReceivedOutput` so locally persisted outputs cannot be substituted by an unprivileged writer.

### Proof of Concept

```rust
// networks/bitcoin: attacker-controlled bytes -> ReceivedOutput::read
let scanner = Scanner::new(wallet_key).unwrap();           // even wallet key
let real = scanner.scan_transaction(&attacker_tx)[0].clone(); // honest path

// Craft bytes: keep a TxOut paying to an unrelated script_pubkey,
// but claim offset = 0 (or any scalar the attacker prefers).
let mut crafted = Vec::new();
crafted.extend(Scalar::ZERO.to_bytes());                    // bogus offset
crafted.extend(serialize(&victim_controlled_txout));        // mismatched script_pubkey
crafted.extend(serialize(&OutPoint::new(txid, 0)));

let received = ReceivedOutput::read(&mut crafted.as_slice()).unwrap(); // accepted
// Wallet reports `received.value()` as spendable funds, but
// keys.offset(received.offset()) re-keys to a group key != script_pubkey's key,
// so the FROST signature produced for this outpoint cannot spend it.
assert_ne!(
  p2tr_script_buf(wallet_key + ProjectivePoint::GENERATOR * received.offset()),
  Some(received.output().script_pubkey.clone()),
); // no such check is ever performed inside read
```

```rust
  pub fn read<R: Read>(r: &mut R) -> io::Result<ReceivedOutput> {
    let offset = Secp256k1::read_F(r)?;
    let output;
    let outpoint;
    {
      let mut buf_r = BufReader::with_capacity(0, r);
      output =
        TxOut::consensus_decode(&mut buf_r).map_err(|_| io::Error::other("invalid TxOut"))?;
      outpoint =
        OutPoint::consensus_decode(&mut buf_r).map_err(|_| io::Error::other("invalid OutPoint"))?;
    }
    Ok(ReceivedOutput { offset, output, outpoint })
  }
```

```rust
  pub fn register_offset(&mut self, mut offset: Scalar) -> Option<Scalar> {
    // This loop will terminate as soon as an even point is found, with any point having a ~50%
    // chance of being even
    // That means this should terminate within a very small amount of iterations
    loop {
      match p2tr_script_buf(self.key + (ProjectivePoint::GENERATOR * offset)) {
        Some(script) => {
          if self.scripts.contains_key(&script) {
            None?;
          }
          self.scripts.insert(script, offset);
          return Some(offset);
        }
        None => offset += Scalar::ONE,
      }
    }
  }
```

```rust
  pub fn scan_transaction(&self, tx: &Transaction) -> Vec<ReceivedOutput> {
    let mut res = Vec::new();
    for (vout, output) in tx.output.iter().enumerate() {
      // If the vout index exceeds 2**32, stop scanning outputs
      let Ok(vout) = u32::try_from(vout) else { break };

      if let Some(offset) = self.scripts.get(&output.script_pubkey) {
        res.push(ReceivedOutput {
          offset: *offset,
          output: output.clone(),
          outpoint: OutPoint::new(tx.compute_txid(), vout),
        });
      }
    }
    res
  }
```
