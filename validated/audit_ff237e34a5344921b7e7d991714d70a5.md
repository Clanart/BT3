## Title
DataLayer subscription/mirror sync performs unrestricted outbound HTTP fetches to attacker-controlled URLs (SSRF) - (File: `chia/data_layer/download_data.py`, `chia/data_layer/data_layer.py`)

### Summary
The Pterodactyl advisory describes an SSRF bypass in a remote-file-pull feature: a user-supplied URL is fetched by the trusted server process without adequate restriction on internal/loopback destinations. Chia's DataLayer module has an analogous "remote file pull" feature: a Data Layer client can `subscribe()` a store to arbitrary URLs, and the DataLayer service periodically fetches `.dat` delta/full-tree files from those URLs via `http_download()`, with no validation that the target host is not internal/loopback/link-local.

### Finding Description
`DataStore.subscribe()`/the `subscribe` RPC lets a local Data Layer client register a `ServerInfo(url=...)` for any store id with an arbitrary URL string [1](#0-0) . Mirror URLs (added on-chain via `add_mirror`) are similarly propagated into the sync loop as untrusted external inputs, as documented explicitly: "Plugin and mirror URLs are external trust inputs" [2](#0-1) .

During periodic sync, `DataLayer.fetch_and_validate()` iterates over `get_available_servers_for_store()` results and calls `insert_from_delta_file()` with `server_info=server_info` and no downloader, causing `download_file()` to fall back to the plain `http_download()` path [3](#0-2) [4](#0-3) .

`http_download()` issues an outbound `aiohttp` GET directly to `server_info.url + "/" + filename` with no scheme allowlist and no check against loopback/private/link-local/metadata addresses (e.g. `169.254.169.254`, `127.0.0.1`, RFC1918 ranges): [5](#0-4) 

By contrast, the S3 plugin path *does* perform scheme/membership validation before acting on a URL (`parse_result.scheme == "s3"` and `url in store.urls`) [6](#0-5) , but this validation is specific to the S3 plugin service and is not applied to the default plain-HTTP `http_download()` path used whenever no downloader plugin handles the URL. No equivalent validation exists in `chia/data_layer/download_data.py` or `chia/data_layer/data_layer.py`.

This mirrors the GHSA-qq22-jj8x-4wwv bug class: a "pull"/download feature that is supposed to fetch external replica data instead allows the operator's own node process to be coerced into making arbitrary outbound requests to internal-network or loopback endpoints under attacker (subscriber/mirror) control.

### Impact Explanation
An unprivileged Data Layer client (or a store owner adding a malicious mirror URL, since mirror URLs are also untrusted per the module's own trust model) can cause the node's DataLayer service to issue authenticated-context or blind outbound HTTP GET requests to arbitrary hosts reachable from the node's network context — including localhost services, cloud metadata endpoints, or other internal-network services not otherwise exposed. This is classic SSRF: information disclosure or unauthorized action against internal services reachable only from the node's own network position. This does not directly produce coin-level state corruption, but it satisfies CWE-918/441/284's class of "server performing unauthorized action on behalf of attacker via forged request," analogous to the referenced advisory.

### Likelihood Explanation
`subscribe()` is a routine, low-privilege Data Layer RPC operation intended for legitimate use (subscribing to replicate another store's data), and mirror URLs are explicitly documented as untrusted external input that the sync loop still fetches from. Any client with access to the local Data Layer RPC, or any party able to get a URL registered as a mirror for a subscribed store, can trigger the fetch merely by waiting for the periodic `periodically_manage_data()` / `update_subscription()` cycle to run.

### Recommendation
Add URL validation before `http_download()` (and before handing URLs to any downloader plugin) that rejects loopback, link-local, private/RFC1918, and cloud-metadata address ranges (resolving DNS first to avoid TOCTOU/DNS-rebinding), and restricts allowed schemes to `http`/`https`. Apply the same allowlist logic uniformly across `chia/data_layer/download_data.py`, `data_layer.py`'s `get_downloader()`, and any mirror-URL ingestion path, not only within the optional S3 plugin.

### Proof of Concept
1. Start a `data_layer` node with a DataLayer store enabled and RPC access available to a local, unprivileged client.
2. Call `subscribe` with `store_id=<target>` and `urls=["http://169.254.169.254"]` (or `http://127.0.0.1:<internal-port>`), as exposed via `DataLayerRpcClient.subscribe()` [1](#0-0) .
3. Wait for the periodic sync loop (`manage_data_interval`) to invoke `fetch_and_validate()` for that store, which selects the subscribed `ServerInfo` and calls `insert_from_delta_file()`/`download_file()`/`http_download()` [7](#0-6) .
4. Observe the node performing an outbound GET to `http://169.254.169.254/<generated-filename>` (or the internal target) with no restriction, confirming SSRF against the node's internal network context [8](#0-7) .

```python
async def download_file(
    data_store: DataStore,
    target_filename_path: Path,
    store_id: bytes32,
    root_hash: bytes32,
    generation: int,
    server_info: ServerInfo,
    proxy_url: str | None,
    downloader: PluginRemote | None,
    timeout: aiohttp.ClientTimeout,
    client_foldername: Path,
    timestamp: int,
    log: logging.Logger,
    grouped_by_store: bool,
    group_downloaded_files_by_store: bool,
    max_delta_file_size: int,
) -> bool:
    if target_filename_path.exists():
        return True
    filename = get_delta_filename(store_id, root_hash, generation, grouped_by_store)

    if downloader is None:
        # use http downloader - this raises on any error
        try:
            await http_download(
                target_filename_path, filename, proxy_url, server_info, timeout, log, max_delta_file_size
            )
        except (asyncio.TimeoutError, aiohttp.ClientError, MaxDeltaFileSizeExceededError):
            new_server_info = await data_store.server_misses_file(store_id, server_info, timestamp)
            log.info(
                f"Failed to download {filename} from {new_server_info.url}."
                f"Miss {new_server_info.num_consecutive_failures}."
            )
            log.info(f"Next attempt from {new_server_info.url} in {new_server_info.ignore_till - timestamp}s.")
            return False
        return True
```

```python
async def http_download(
    target_filename_path: Path,
    filename: str,
    proxy_url: str | None,
    server_info: ServerInfo,
    timeout: aiohttp.ClientTimeout,
    log: logging.Logger,
    max_delta_file_size: int,
) -> None:
    """
    Download a file from a server using aiohttp.
    Raises exceptions on errors
    """
    async with aiohttp.ClientSession() as session:
        headers = {"accept-encoding": "gzip"}
        async with session.get(
            server_info.url + "/" + filename,
            headers=headers,
            timeout=timeout,
            proxy=proxy_url,
        ) as resp:
            resp.raise_for_status()
```

```python
    async def download(self, request: web.Request) -> web.Response:
        try:
            data = await request.json()
            url = data["url"]
            filename = data["filename"]
            group_files_by_store = data.get("group_files_by_store", False)
            max_delta_file_size = data.get("max_delta_file_size")
            if not isinstance(max_delta_file_size, int) or max_delta_file_size <= 0:
                max_delta_file_size = 250

            # filename must follow the DataLayer naming convention
            if not is_filename_valid(filename, group_files_by_store):
                return web.json_response({"downloaded": False})

            # Pull the store_id from the filename to make sure we only download for configured stores
            filename_store_id = bytes32.fromhex(filename[:64])
            parse_result = urlparse(url)
            should_download = False
            for store in self.stores:
                if store.id == filename_store_id and parse_result.scheme == "s3" and url in store.urls:
                    should_download = True
                    break

            if not should_download:
                return web.json_response({"downloaded": False})
```
