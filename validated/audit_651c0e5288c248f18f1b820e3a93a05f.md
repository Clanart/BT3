### Title
Lack of Interface Validation when Registering CW→ERC Pointers Allows Deployment of Broken/Malicious Pointer Contracts for Arbitrary Addresses - (File: x/evm/keeper/msg_server.go)

### Summary
`MsgRegisterPointer` lets any unprivileged transaction sender request a CW pointer be instantiated for an arbitrary `msg.ErcAddress` string, with `PointerType` chosen as `ERC20`, `ERC721`, or `ERC1155` [1](#0-0) . Unlike the CW20/CW721/CW1155 "Add" precompile flows, which query the target CosmWasm contract (`token_info`/`contract_info`) before deploying a pointer [2](#0-1) , `RegisterPointer` performs no analogous validation that `msg.ErcAddress` is even a contract, let alone one that implements the ERC20/ERC721/ERC1155 interface the pointer type presumes.

### Finding Description
`RegisterPointer` converts `msg.ErcAddress` to `common.HexToAddress(msg.ErcAddress)` for lookups and stores it directly via `SetCW20ERC20Pointer` / `SetCW721ERC721Pointer` / `SetCW1155ERC1155Pointer` without checking:
- whether the address has any deployed code (EOA vs contract),
- whether the contract implements the expected `name()/symbol()/decimals()/balanceOf()/transfer()` (ERC20), `ownerOf()/safeTransferFrom()` (ERC721), or `balanceOf()/safeTransferFrom()` (ERC1155) selectors. [3](#0-2) 

The instantiated CW pointer contract (via `wasmKeeper.Instantiate`/`Migrate` with `codeID := server.GetStoredPointerCodeID(...)`) is a generic wasm wrapper that assumes the target implements the corresponding ERC interface's ABI when it later forwards CW `execute`/`query` calls as EVM calls to `msg.ErcAddress`. If `msg.ErcAddress` is an EOA, an empty contract, a contract that reverts on any of these selectors, or a contract with a different function signature that happens to match a 4-byte selector collision, the pointer's cross-chain calls will behave unpredictably — reverting unexpectedly, returning garbage decoded as balances/ownership, or silently no-op'ing (calls to non-existent code return success with empty data in the EVM, which many naive decoders interpret as zero-valued success). This mirrors exactly the AvailBridge finding: an `initialize`/`register` function accepts an address that is supposed to conform to an interface but never checks that it does, letting the deployer (any tx sender, since `RegisterPointer` is a permissionless `Msg`, not privileged) point CosmWasm consumers of the pointer at a non-conforming or malicious contract.

### Impact Explanation
A pointer that silently misreports balances/ownership/decimals for a token that does not actually implement the assumed interface can mislead any CosmWasm contract or user that queries the pointer's `balance`, `token_info`, `owner_of`, etc., producing incorrect accounting. Because CW consumers (e.g., money markets, DEXes) treat CW20/CW721 pointer query results as ground truth balances, this can enable unauthorized transfer/inflation-adjacent behavior or fund-loss scenarios for any protocol built on top of a pointer for an address that isn't a genuine ERC20/721/1155 contract — satisfying the "unauthorized transfer via pointer" / "fund loss" criteria. This is Medium severity because it requires downstream integrations to trust an unvalidated pointer, but the pointer registration itself is fully permissionless and reachable by any unprivileged sender.

### Likelihood Explanation
High reachability: `RegisterPointer` is a standard `Msg` handler invocable by any account via a normal transaction (`x/evm/client/cli/native_tx.go` `RegisterCwPointerCmd`) [4](#0-3) , requiring no special role beyond paying gas, and the only gating check is whether `server.GetRegisterPointerDisabled(ctx)` is false and whether a higher-version pointer already exists [5](#0-4) . No call is made to validate the target contract's bytecode or interface before deployment.

### Recommendation
Before instantiating or migrating the pointer contract in `RegisterPointer`, verify that `msg.ErcAddress` has non-empty code and that it responds correctly to the interface-defining calls for the requested `PointerType` (e.g., static-call `supportsInterface`/`name()`/`symbol()`/`decimals()` for ERC20, `ownerOf`/`balanceOf` selectors for ERC721/1155), returning an error if the target does not conform, analogous to the `token_info`/`contract_info` pre-check already used in the CW→ERC direction (`precompiles/pointer/*/pointer.go` `AddCW20`/`AddCW721`).

### Proof of Concept
1. Deploy (or use) an EOA or a contract with no ERC20/721/1155 functions at address `X`.
2. Submit `MsgRegisterPointer{Sender: attacker, PointerType: ERC20, ErcAddress: X}` via `seid tx evm register-cw-pointer ERC20 X`.
3. `RegisterPointer` in `x/evm/keeper/msg_server.go` instantiates a CW20 pointer wasm contract bound to `X` without validating `X` implements ERC20, and calls `SetCW20ERC20Pointer(ctx, X, pointerAddr)`.
4. Any CosmWasm contract that queries the resulting pointer (`balance`, `token_info`) will receive attacker-influenced or garbage results (e.g., always-zero or reverting) because `X` does not implement the assumed ABI, corrupting any downstream logic relying on the pointer. [3](#0-2)

func (server msgServer) RegisterPointer(goCtx context.Context, msg *types.MsgRegisterPointer) (*types.MsgRegisterPointerResponse, error) {
	ctx := sdk.UnwrapSDKContext(goCtx)
	if server.GetRegisterPointerDisabled(ctx) {
		return nil, fmt.Errorf("registering CW->ERC pointers has been disabled")
	}
	var existingPointer sdk.AccAddress
	var existingVersion uint16
	var currentVersion uint16
	var exists bool
	switch msg.PointerType {
	case types.PointerType_ERC20:
		currentVersion = erc20.CurrentVersion
		existingPointer, existingVersion, exists = server.GetCW20ERC20Pointer(ctx, common.HexToAddress(msg.ErcAddress))
	case types.PointerType_ERC721:
		currentVersion = erc721.CurrentVersion
		existingPointer, existingVersion, exists = server.GetCW721ERC721Pointer(ctx, common.HexToAddress(msg.ErcAddress))
	case types.PointerType_ERC1155:
		currentVersion = erc1155.CurrentVersion
		existingPointer, existingVersion, exists = server.GetCW1155ERC1155Pointer(ctx, common.HexToAddress(msg.ErcAddress))
	default:
		panic("unknown pointer type")
	}
	if exists && existingVersion >= currentVersion {
		return nil, fmt.Errorf("pointer %s already registered at version %d", existingPointer.String(), existingVersion)
	}
	payload := map[string]interface{}{}
	switch msg.PointerType {
	case types.PointerType_ERC20:
		payload["erc20_address"] = msg.ErcAddress
	case types.PointerType_ERC721:
		payload["erc721_address"] = msg.ErcAddress
	case types.PointerType_ERC1155:
		payload["erc1155_address"] = msg.ErcAddress
	default:
		panic("unknown pointer type")
	}
	codeID := server.GetStoredPointerCodeID(ctx, msg.PointerType)
	moduleAcct := server.accountKeeper.GetModuleAddress(types.ModuleName)
	var err error
	var pointerAddr sdk.AccAddress
	if exists {
		bz, _ := json.Marshal(map[string]interface{}{})
		pointerAddr = existingPointer
		_, err = server.wasmKeeper.Migrate(ctx, existingPointer, moduleAcct, codeID, bz)
	} else {
		bz, jerr := json.Marshal(payload)
		if jerr != nil {
			return nil, jerr
		}
		pointerAddr, _, err = server.wasmKeeper.Instantiate(ctx, codeID, moduleAcct, moduleAcct, bz, fmt.Sprintf("Pointer of %s", msg.ErcAddress), sdk.NewCoins())
	}
	if err != nil {
		return nil, err
	}
	switch msg.PointerType {
	case types.PointerType_ERC20:
		err = server.SetCW20ERC20Pointer(ctx, common.HexToAddress(msg.ErcAddress), pointerAddr.String())
		ctx.EventManager().EmitEvent(sdk.NewEvent(
			types.EventTypePointerRegistered, sdk.NewAttribute(types.AttributeKeyPointerType, "erc20"),
			sdk.NewAttribute(types.AttributeKeyPointerAddress, pointerAddr.String()), sdk.NewAttribute(types.AttributeKeyPointee, msg.ErcAddress),
			sdk.NewAttribute(types.AttributeKeyPointerVersion, fmt.Sprintf("%d", erc20.CurrentVersion))))
	case types.PointerType_ERC721:
		err = server.SetCW721ERC721Pointer(ctx, common.HexToAddress(msg.ErcAddress), pointerAddr.String())
		ctx.EventManager().EmitEvent(sdk.NewEvent(
			types.EventTypePointerRegistered, sdk.NewAttribute(types.AttributeKeyPointerType, "erc721"),
			sdk.NewAttribute(types.AttributeKeyPointerAddress, pointerAddr.String()), sdk.NewAttribute(types.AttributeKeyPointee, msg.ErcAddress),
			sdk.NewAttribute(types.AttributeKeyPointerVersion, fmt.Sprintf("%d", erc721.CurrentVersion))))
	case types.PointerType_ERC1155:
		err = server.SetCW1155ERC1155Pointer(ctx, common.HexToAddress(msg.ErcAddress), pointerAddr.String())
		ctx.EventManager().EmitEvent(sdk.NewEvent(
			types.EventTypePointerRegistered, sdk.NewAttribute(types.AttributeKeyPointerType, "erc1155"),
			sdk.NewAttribute(types.AttributeKeyPointerAddress, pointerAddr.String()), sdk.NewAttribute(types.AttributeKeyPointee, msg.ErcAddress),
			sdk.NewAttribute(types.AttributeKeyPointerVersion, fmt.Sprintf("%d", erc1155.CurrentVersion))))
	default:
		panic("unknown pointer type")
	}
	return &types.MsgRegisterPointerResponse{PointerAddress: pointerAddr.String()}, err
}

func RegisterCwPointerCmd() *cobra.Command {
	cmd := &cobra.Command{
		Use:   "register-cw-pointer [pointer type] [erc address]",
		Short: `Register a CosmWasm pointer for an ERC20/721/1155 contract. Pointer type is either ERC20, ERC721, or ERC1155.`,
		Args:  cobra.ExactArgs(2),
		RunE: func(cmd *cobra.Command, args []string) error {
			clientCtx, err := client.GetClientTxContext(cmd)
			if err != nil {
				return err
			}

			msg := &types.MsgRegisterPointer{
				Sender:      clientCtx.GetFromAddress().String(),
				PointerType: types.PointerType(types.PointerType_value[args[0]]),
				ErcAddress:  args[1],
			}
			if err := msg.ValidateBasic(); err != nil {
				return err
			}

			return tx.GenerateOrBroadcastTxCLI(cmd.Context(), clientCtx, cmd.Flags(), msg)
		},
	}

	flags.AddTxFlagsToCmd(cmd)

	return cmd
}
