### Title
Auction bid gas-limit caching does not track all AuctionEntryPoint gas parameters, causing stale bid execution risk after `changeGasParameters` - ([File: kaiax/auction/impl/bid_pool.go])

### Summary
The `kaiax/auction` module caches a bid's gas limit once, at bid-submission time, using only the `gasBufferEstimate` parameter read from the on-chain `AuctionEntryPoint`. The staleness-detection logic that clears the bid pool on parameter change only compares `auctioneer`, `auctionEntryPoint` address, `auctionEntryPointVersion`, and `bidTxGasBuffer` — it does not account for the other gas-related parameters (`gasPerByteIntrinsic`, `gasPerByteEip7623`, `gasContractExecution`, `gasBufferUnmeasured`) exposed by the contract's `changeGasParameters` function.

### Finding Description
When a bid is accepted, `BidPool.AddBid` computes and permanently caches the bid's gas limit via `getBidTxGasLimit`, which is a purely client-side estimate: `max(intrinsicGas + bid.CallGasLimit + buffer, floorDataGas)`, where `buffer` is `bp.bidTxGasBuffer` (== `gasBufferEstimate`) captured under lock at that instant: [1](#0-0) 

This gas limit is only recomputed at block-building time if it wasn't already set (`bid.GetGasLimit() == 0`), meaning the value used to build the actual on-chain transaction is normally the stale value from bid submission time, not the value in effect when the transaction is later included in a block: [2](#0-1) 

The module does read fresh auction info once per block (in `PostInsertBlock`/`updateAuctionInfo`) and clears the entire bid pool if `auctioneer`, `auctionEntryPoint`, `auctionEntryPointVersion`, or `bidTxGasBuffer` changed: [3](#0-2) [4](#0-3) 

However, the `IAuctionEntryPoint` contract exposes a governance/admin function `changeGasParameters(gasPerByteIntrinsic, gasPerByteEip7623, gasContractExecution, gasBufferEstimate, gasBufferUnmeasured)` that can change four other gas-accounting parameters besides `gasBufferEstimate`: [5](#0-4) 

None of these four other parameters are read or tracked by `updateAuctionInfo`, which only calls `system.ReadGasBufferEstimate`: [6](#0-5) 

This is directly analogous to the GMX report's bug class: a config value ("order" analog: the searcher's already-signed bid) is fixed/agreed-upon at submission time, but downstream execution parameters can change before actual on-chain inclusion, and the system's invalidation/staleness check does not cover all the parameters that affect correctness of the already-accepted item.

### Impact Explanation
Because I could not locate the actual production `AuctionEntryPoint.sol` implementation in the indexed codebase (only the stripped-down `AuctionEntryPointMock.sol`, whose `call()` function has the real gas-accounting/bid-taking/refund logic commented out), I cannot confirm with certainty how `gasPerByteIntrinsic`, `gasPerByteEip7623`, `gasContractExecution`, and `gasBufferUnmeasured` are actually consumed on-chain (e.g., whether they gate a `require`/revert condition, affect refund amounts paid by/to the searcher, or affect deposit accounting). If, as their naming strongly suggests, these values are used by the contract to validate that enough gas was supplied for intrinsic/contract-execution/unmeasured overhead, then an increase to any of them via `changeGasParameters` after bids are queued (but before block inclusion) could cause the winning bid's on-chain `call()` to revert or under/over-refund gas, while the kaiax client-side pool has no mechanism to detect this and re-validate or re-quote the already-cached bid. This would only be a Medium-severity, index-limited hypothesis rather than a confirmed critical fund-loss bug.

### Likelihood Explanation
`changeGasParameters` and `changeAuctioneer`/entry-point migrations are presumably restricted to a privileged governance/operator role on `AuctionEntryPoint`, so triggering this requires a legitimate parameter update coinciding with in-flight bids — this is a normal operational event (analogous to GMX's config-keeper updates), not an attacker-controlled action, making it a plausible but low-frequency real-world scenario rather than an actively exploitable attack path by an unprivileged actor.

### Recommendation
Extend `BidPool.updateAuctionInfo`'s change-detection to also track `gasPerByteIntrinsic`, `gasPerByteEip7623`, `gasContractExecution`, and `gasBufferUnmeasured` (reading them via `system.Read...` helpers analogous to `ReadGasBufferEstimate`), and clear/invalidate the bid pool (or recompute cached `GasLimit` values) whenever any of these parameters change, consistent with the existing handling of `bidTxGasBuffer`.

### Proof of Concept
Not able to produce a concrete PoC transaction/bid sequence proving fund loss, because the actual `AuctionEntryPoint` production contract logic (the code that consumes `gasPerByteIntrinsic`/`gasPerByteEip7623`/`gasContractExecution`/`gasBufferUnmeasured`) is not present in the indexed codebase — only the mock with this logic commented out is available: [7](#0-6) . A Devin session with full repository/filesystem access would be needed to locate and inspect the real `AuctionEntryPoint` contract to confirm exploitability and severity.

// updateAuctionInfo updates the auction info if the auctioneer or auction entry point address is changed.
func (bp *BidPool) updateAuctionInfo(auctioneer common.Address, auctionEntryPoint common.Address, auctionEntryPointVersion string, bidTxGasBuffer uint64) {
	bp.auctionInfoMu.Lock()
	defer bp.auctionInfoMu.Unlock()

	if bp.auctioneer == auctioneer && bp.auctionEntryPoint == auctionEntryPoint && bp.auctionEntryPointVersion == auctionEntryPointVersion && bp.bidTxGasBuffer == bidTxGasBuffer {
		return
	}

	// Clear the existing auction pool since the auctioneer or auction entry point address is changed.
	bp.clearBidPool()

	bp.auctioneer = auctioneer
	bp.auctionEntryPoint = auctionEntryPoint
	bp.auctionEntryPointVersion = auctionEntryPointVersion
	bp.bidTxGasBuffer = bidTxGasBuffer

	logger.Info("Update auction info", "auctioneer", auctioneer, "auctionEntryPoint", auctionEntryPoint, "auctionEntryPointVersion", auctionEntryPointVersion, "bidTxGasBuffer", bidTxGasBuffer)
}

func (bp *BidPool) getBidTxGasLimit(bid *auction.Bid) (uint64, error) {
	bp.auctionInfoMu.RLock()
	buffer := bp.bidTxGasBuffer
	bp.auctionInfoMu.RUnlock()

	data, err := system.EncodeAuctionCallData(bid, bp.auctionEntryPointVersion)
	if err != nil {
		return 0, err
	}

	rules := bp.ChainConfig.Rules(big.NewInt(int64(bid.BlockNumber)))
	intrinsicGas, err := types.IntrinsicGas(data, nil, nil, false, rules)
	if err != nil {
		return 0, err
	}
	floorDataGas := uint64(0)
	if rules.IsPrague {
		floorDataGas, err = blockchain.FloorDataGas(types.TxTypeEthereumDynamicFee, data, 0)
		if err != nil {
			return 0, err
		}
	}

	return max(intrinsicGas+bid.CallGasLimit+buffer, floorDataGas), nil

// updateAuctionInfo updates the auctioneer address and auction entry point address for the given block number.
// It expects the `num` is after Randao fork.
// It returns true if the non-zero auctioneer address and auction entry point address are set, otherwise false.
func (a *AuctionModule) updateAuctionInfo(num *big.Int) bool {
	auctioneer := common.Address{}
	auctionEntryPointAddr := common.Address{}
	auctionEntryPointVersion := ""
	bidTxGasBuffer := uint64(0)

	defer func() {
		a.bidPool.updateAuctionInfo(auctioneer, auctionEntryPointAddr, auctionEntryPointVersion, bidTxGasBuffer)
	}()

	header := a.Chain.GetHeaderByNumber(num.Uint64())
	if header == nil {
		return false
	}
	_, err := a.Chain.StateAt(header.Root)
	if err != nil {
		return false
	}

	backend := backends.NewBlockchainContractBackend(a.Chain, nil, nil)

	// 1. Read auction entry point address
	auctionEntryPointAddr, err = system.ReadActiveAddressFromRegistry(backend, system.AuctionEntryPointName, num)
	if err != nil {
		return false
	}

	if auctionEntryPointAddr == (common.Address{}) {
		return false
	}

	// 2. Read auctioneer address
	auctioneer, err = system.ReadAuctioneer(backend, auctionEntryPointAddr, num)
	if err != nil {
		return false
	}

	if auctioneer == (common.Address{}) {
		return false
	}

	// 3. Read gas buffer estimate
	bidTxGasBuffer, err = system.ReadGasBufferEstimate(backend, auctionEntryPointAddr, num)
	if err != nil {
		return false
	}

	// 4. Read AUCTION_VERSION to pick the right EIP-712 typehash and ABI for bids targeting this entry point.
	auctionEntryPointVersion, err = system.ReadAuctionVersion(backend, auctionEntryPointAddr, num)
	if err != nil {
		return false
	}

	return true
}
