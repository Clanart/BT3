### Title
Blind SSRF via unrestricted DataLayer mirror/subscription URLs enables internal network port scanning - ([File: chia/data_layer/data_layer.py])

### Summary
Chia's DataLayer service accepts arbitrary user-supplied URLs through the `subscribe` RPC (`data_layer.subscribe`) and stores them as mirror server URLs with no validation of scheme, host, or address space. During the periodic sync loop, `fetch_and_validate()` iterates these URLs and issues outbound HTTP GET requests via `http_download()`, exactly mirroring the blind-SSRF bug class described in the Open WebUI advisory (unrestricted `requests.get` on a user-supplied URL).

### Finding Description
A local RPC caller (any client with access to the DataLayer RPC, e.g. wallet/DL CLI tooling) can call `subscribe(store_id, urls)`: [1](#0-0) 

The `urls` list is only stripped of trailing slashes and wrapped into `ServerInfo` objects — there is no restriction on scheme (e.g. `http://127.0.0.1/...`, `http://169.254.169.254/...`, internal RFC1918 addresses) and no allow/deny list is applied.

Later, the periodic sync loop (`fetch_and_validate`) picks a server from this list and downloads a "delta file" from it: [2](#0-1) 

This calls `insert_from_delta_file()` → `download_file()` → `http_download()`, which performs a plain `aiohttp` GET to the attacker-controlled URL with a predictable, attacker-known filename appended: [3](#0-2) 

The response is not exposed to the caller directly, but success/failure is observable indirectly: on success the file is parsed and inserted (visible via subsequent state/logs), on failure the server is marked with a "miss" and backed off (`server_misses_file`), and on connection errors a distinct log message ("Server {url} unavailable") is emitted: [4](#0-3) 

This differential (connection failure vs. HTTP error vs. successful/parse-failure path) is the same oracle used in the reported Open WebUI SSRF to fingerprint open ports on the internal network. `get_downloader()` similarly POSTs to arbitrary plugin URLs derived from configured downloaders, though those originate from local config rather than a single RPC call.

### Impact Explanation
This is a blind SSRF that lets any actor with DataLayer RPC access cause the node to make outbound HTTP requests to attacker-chosen destinations, including loopback and private/internal addresses, on a recurring background schedule (`periodically_manage_data()`). Response-timing/error differentials allow port scanning of the node's local network (localhost services, internal infra) — the same medium-severity impact class as the referenced advisory (CWE-918, confirm-only impact with no direct data exfiltration since the SSRF is blind). Because this reaches only the DataLayer plugin/downloader trust boundary and not settlement, mempool, or coin-state logic, it does not itself cause unauthorized coin movement or supply inflation, but it is a legitimate reachable SSRF analog exposed to a local RPC caller.

### Likelihood Explanation
Medium. Exploitation requires access to the DataLayer RPC (`subscribe`), which is gated by standard local RPC authentication (mTLS/cert-based, matching the "local RPC caller" scope named in this analysis). Any authenticated DataLayer client (a normal, unprivileged use case — subscribing to a peer's store) can supply an arbitrary URL, so no additional privilege beyond ordinary DataLayer usage is needed. The sync loop runs automatically and repeatedly, requiring no further interaction after subscription.

### Recommendation
Validate and restrict subscription/mirror/downloader/uploader URLs in `DataLayer.subscribe()`, `get_downloader()`, and `get_uploaders()`/`add_missing_files()`: enforce `https`/`http` public-scheme only, resolve and reject loopback, link-local, and private (RFC1918/RFC4193) address ranges, and consider disallowing redirects to such ranges in `http_download()`. Apply this validation both at subscription time and at fetch time (in case DNS rebinding is used to bypass a subscribe-time check).

### Proof of Concept
1. As an authenticated DataLayer RPC client, call:
```
subscribe(store_id=<bytes32>, urls=["http://127.0.0.1:6379", "http://169.254.169.254"])
```
via `chia/data_layer/data_layer_rpc_api.py` (subscribe endpoint) → `DataLayer.subscribe()` [1](#0-0) .
2. Wait for the background sync loop to invoke `fetch_and_validate(store_id)` [2](#0-1) , which triggers `http_download()` against the supplied URL/port [3](#0-2) .
3. Observe divergent behavior/logs ("Server {url} unavailable" vs. miss-backoff vs. successful download attempt) to determine whether the target host/port is open, effectively port-scanning the local network from the node's vantage point.

    async def subscribe(self, store_id: bytes32, urls: list[str]) -> Subscription:
        parsed_urls = [url.rstrip("/") for url in urls]
        subscription = Subscription(store_id, [ServerInfo(url, 0, 0) for url in parsed_urls])
        await self.wallet_rpc.dl_track_new(DLTrackNew(launcher_id=subscription.store_id))
        async with self.subscription_lock:
            await self.data_store.subscribe(subscription)
        self.log.info(f"Done adding subscription: {subscription.store_id}")
        return subscription

async def http_download(
    target_filename_path: Path,
    filename: str,
    proxy_url: str | None,
    server_info: ServerInfo,
    timeout: aiohttp.ClientTimeout,
    log: logging.Logger,
    max_delta_file_size: int,
) -> None:
    """
    Download a file from a server using aiohttp.
    Raises exceptions on errors
    """
    async with aiohttp.ClientSession() as session:
        headers = {"accept-encoding": "gzip"}
        async with session.get(
            server_info.url + "/" + filename,
            headers=headers,
            timeout=timeout,
            proxy=proxy_url,
        ) as resp:
            resp.raise_for_status()
            size = int(resp.headers.get("content-length", 0))
            max_delta_file_size_bytes = max_delta_file_size * 1024 * 1024
            if size > max_delta_file_size_bytes:
                raise MaxDeltaFileSizeExceededError(f"Maximum delta file size exceeded: {max_delta_file_size} MiB.")
            log.debug(f"Downloading delta file {filename}. Size {size} bytes.")
