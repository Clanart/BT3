### Title
Gasless swap deadline is validated only at tx-pool admission but not re-checked at bundle/block-building time - ([File: kaiax/gasless/impl/tx_pool.go], [File: kaiax/gasless/impl/getter.go], [File: kaiax/gasless/impl/builder.go])

### Summary
The `kaiax/gasless` module implements KIP-247 gasless swaps: a proposer lends gas fee via a `LendTx` and expects repayment from the user's `GaslessSwapTx`. The `SwapArgs.Deadline` field carried in the swap transaction is validated for staleness (`tx.deadline >= currentTimestamp`) only inside `checkBalanceForSwap`, which is invoked from `GetCheckBalance()` at transaction-pool admission time. [1](#0-0) 
However, the authoritative "is this swap executable / should we bundle it" logic - `VerifyExecutable` (used by `IsExecutable`, which itself backs `IsReady`/`isSwapTxReady` for pool promotion and `ExtractTxBundles` for block building) - never checks the deadline at all. [2](#0-1) [3](#0-2) [4](#0-3) 

### Finding Description
This mirrors the report's bug class: a time-bounded authorization (`priceSig`/here, `Deadline`) is checked once, at an early gate, but the code path that actually consumes/executes the authorized action does not re-verify it is still within validity window before use.

In this codebase:
- `checkBalanceForSwap` (deadline check) runs once, when the swap tx is first admitted into the pool (`GetCheckBalance`).
- Afterward, the swap tx can sit in the pool (e.g., waiting on nonce ordering for an approve tx, being requeued after `PreReset`/`PostReset`, or waiting several blocks until promoted), and eventually becomes "ready" via `isSwapTxReady` → `IsExecutable` → `VerifyExecutable`, or is selected for bundling via `ExtractTxBundles` → `IsExecutable`. None of these paths re-check `swapArgs.Deadline` against the current block time. [5](#0-4) 
- Once bundled, `GetLendTxGenerator` unconditionally creates and prepends a `LendTx` that transfers KAIA value to the sender (`lendAmount`) before the `SwapTx` executes. [6](#0-5) [7](#0-6) 

If the swap's on-chain deadline has expired by the time the bundle is actually included in a block, the `GaslessSwapRouter.swapForGas` call inside the `SwapTx` would revert (assuming the router contract enforces its own deadline check on-chain, which is standard for such router functions), but per-tx failure within a bundle does not necessarily unwind the already-executed `LendTx` that funded the sender - the `LendTx` is a separate, already-signed and already-mined transaction in the same block, not an atomic call. The `IsExecutable`/`VerifyExecutable` gate exists specifically to prevent building bundles that will fail, but omitting the deadline check leaves exactly the temporal-validity gap the original report calls out ("does not check if the signature/authorization is out of date" at the point of actual use).

### Impact Explanation
If the module bundles and includes a swap tx whose deadline has already passed by the time of block building, the proposer's `LendTx` still transfers value to the sender, while the swap (which was supposed to repay that lent amount) fails on-chain. This is a concrete value-movement/fee-delegation abuse: the proposer loses the lent KAIA with no repayment because the staleness check was bypassed via the timing gap between pool admission and later block inclusion.

### Likelihood Explanation
Reachable by any unprivileged sender who can submit a `GaslessApproveTx`/`GaslessSwapTx` pair with a deadline set to expire shortly after submission (well within the `PendingTimeout`/`QueueTimeout`/`KnownTxTimeout` windows of 10-30 seconds defined in the module, or across a chain reorg/`PreReset`/`PostReset` cycle that re-queues the tx). No special privileges, validator collusion, or node compromise are required - it's purely a matter of transaction timing relative to block inclusion, which is normal, expected behavior for any gasless-tx submitter. [8](#0-7) 

### Recommendation
Add an explicit deadline check inside `VerifyExecutable` (or immediately before `IsExecutable` is used for `isSwapTxReady`/`ExtractTxBundles`), comparing `swapArgs.Deadline` against the current block time (e.g., `g.Chain.CurrentBlock().Time()` as already done in `checkBalanceForSwap`), so that any swap tx becomes non-executable and is excluded from bundling once its deadline has passed - regardless of how long it has been sitting in the pool since the initial admission check.

### Proof of Concept
1. Attacker generates `AccountA` with `AccountKeyLegacy` (or any) and constructs `GaslessApproveTx` (nonce N) and `GaslessSwapTx` (nonce N+1) with `SwapArgs.Deadline = currentBlockTime + 5` (5 seconds in the future), satisfying `checkBalanceForSwap`'s check at submission time.
2. Attacker submits both txs to the tx pool. Due to normal network/propagation/nonce-ordering delay (or by deliberately delaying the approve tx, or via a chain reorg triggering `PreReset`/`PostReset` re-evaluation), the pair is not promoted/bundled until more than 5 seconds later.
3. When the proposer's `worker`/`builder` calls `ExtractTxBundles` → `IsExecutable(approveTx, swapTx)` → `VerifyExecutable`, none of the checks (`Sx`, `Ax`, `AP1`, `SP1`-`SP4`) validate `swapArgs.Deadline`, so the bundle `[LendTxGenerator, ApproveTx, SwapTx]` is still produced and included. [9](#0-8) 
4. The `LendTx` executes first, transferring `lendAmount(approveTx, swapTx)` KAIA to the sender. `SwapTx` then calls `swapForGas` on the (out-of-scope) `GaslessSwapRouter` contract, which is expected to enforce its own deadline and revert - the sender keeps the lent KAIA without completing the repayment swap.

Note: full confirmation that `GaslessSwapRouter.swapForGas`'s on-chain deadline enforcement and post-revert fee/repayment handling would require reviewing the `kip247`/router contract source, which was not found in the indexed codebase (only its Go binding interface `kip247.NewGaslessSwapRouterCaller` was located). This should be verified in a live Devin session with full repository access to confirm the exact on-chain consequence of a reverted `swapForGas` call within the bundle.

// isSwapTxReady assumes that the caller checked `g.IsSwapTx(swapTx)`
func (g *GaslessModule) isSwapTxReady(swapTx, prevTx *types.Transaction) bool {
	addr, err := types.Sender(g.signer, swapTx)
	if err != nil {
		return false
	}
	nonce := g.getCurrentStateNonce(addr)

	var approveTx *types.Transaction
	if swapTx.Nonce() == nonce {
		approveTx = nil
	} else if swapTx.Nonce() == nonce+1 {
		if prevTx == nil || !g.IsApproveTx(prevTx) {
			return false
		}
		approveTx = prevTx
	} else {
		return false
	}

	return g.IsExecutable(approveTx, swapTx)
}

func (g *GaslessModule) IsExecutable(approveTxOrNil, swapTx *types.Transaction) bool {
	err := g.VerifyExecutable(approveTxOrNil, swapTx)
	if err != nil {
		return false
	}
	return true
}

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

// MakeLendTx creates a transaction with following properties:
// L1. LendTx.type = 0x7802 (TxTypeEthereumDynamicFee)
// L2. LendTx.from = proposer
// L3. LendTx.to = SwapTx.from
// L4. LendTx.value = LendAmount(approveTxOrNil, swapTx)
func (g *GaslessModule) GetLendTxGenerator(approveTxOrNil, swapTx *types.Transaction) *builder.TxOrGen {
	var src []byte
	if approveTxOrNil != nil {
		src = append(src, approveTxOrNil.Hash().Bytes()...)
	}
	src = append(src, swapTx.Hash().Bytes()...)
	bundleHash := crypto.Keccak256Hash(src)

	gen := func(nonce uint64) (*types.Transaction, error) {
		var (
			chainId = g.InitOpts.ChainConfig.ChainID
			signer  = types.LatestSignerForChainID(chainId)
			key     = g.InitOpts.NodeKey
		)

		to, err := types.Sender(signer, swapTx)
		if err != nil {
			return nil, err
		}

		tx, err := types.NewTransactionWithMap(types.TxTypeEthereumDynamicFee, map[types.TxValueKeyType]interface{}{
			types.TxValueKeyNonce:      nonce,
			types.TxValueKeyTo:         &to,
			types.TxValueKeyAmount:     lendAmount(approveTxOrNil, swapTx),
			types.TxValueKeyData:       common.Hex2Bytes("0x"),
			types.TxValueKeyGasLimit:   params.TxGas,
			types.TxValueKeyGasFeeCap:  swapTx.GasFeeCap(),
			types.TxValueKeyGasTipCap:  swapTx.GasTipCap(),
			types.TxValueKeyAccessList: types.AccessList{},
			types.TxValueKeyChainID:    chainId,
		})
		if err != nil {
			return nil, err
		}

		err = tx.Sign(signer, key)
		return tx, err
	}

	return builder.NewTxOrGenFromGen(gen, bundleHash)
}

func lendAmount(approveTxOrNil, swapTx *types.Transaction) *big.Int {
	r := new(big.Int)

	// R2 = ApproveTx.Fee() if exists
	if approveTxOrNil != nil {
		r.Add(r, approveTxOrNil.Fee())
	}

	// R3 = SwapTx.Fee()
	r.Add(r, swapTx.Fee())

	// LendAmount = R2 + R3
	return r
}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
}
