### Title
SSRF via unrestricted DataLayer mirror URLs fetched by `http_download` - (File: chia/data_layer/download_data.py)

### Summary
`get_mirror_info` in `chia/wallet/db_wallet/db_wallet_puzzles.py` extracts a `launcher_id` and a list of URL memos from any coin spent to the `create_mirror_puzzle()` puzzle hash, with no validation that the spender owns or controls that `launcher_id`/store. [1](#0-0)  These attacker-controlled URLs are later fed unchanged into `http_download`, which performs a raw `aiohttp` GET to `server_info.url + "/" + filename`. [2](#0-1) 

### Finding Description
Any user with a standard wallet can call `dl_new_mirror` and place an arbitrary `launcher_id` (someone else's DataLayer singleton) and arbitrary URLs into the mirror coin's memos: `create_new_mirror` spends the caller's own coins to a `create_mirror_puzzle()` output whose memos are `[launcher_id, *urls]`, with no on-chain or wallet-side ownership check tying the mirror to the referenced store. [3](#0-2)  The RPC/CLI path exposing this to any local wallet operator is `add_mirror` → `DLNewMirror`. [4](#0-3) [5](#0-4) 

Once confirmed on chain, any other DataLayer client tracking that store pulls the mirror list via `update_subscriptions_from_wallet`/`get_mirrors` and stores the URLs verbatim as `ServerInfo` without scheme or host validation (e.g. `http://127.0.0.1/...` is accepted, as shown in the test fixtures). [6](#0-5) [7](#0-6) 

During normal sync, `fetch_and_validate` iterates `servers_info` and calls `insert_from_delta_file` → `download_file` → `http_download`, which performs an unauthenticated, unrestricted HTTP GET against the attacker-supplied URL from the DataLayer server process. [8](#0-7) [9](#0-8) [2](#0-1)  There is no allow-list, no restriction against loopback/link-local/private ranges, and no scheme restriction beyond what `aiohttp` itself enforces (http/https), meaning cloud metadata endpoints (`169.254.169.254`), internal admin panels, or other RPC ports on the host/network reachable by the DataLayer node can be probed or triggered.

### Impact Explanation
This is a Server-Side Request Forgery: the attacker (any wallet holder able to fund a small mirror-coin transaction) can force any DataLayer node tracking that store to make outbound HTTP requests to arbitrary internal or external hosts/ports, potentially exfiltrating response data (which is streamed to disk during `insert_into_data_store_from_file` and processed as a delta file) or interacting with internal-only services. It does not directly move funds, but it satisfies the "concrete, spend-triggered" bug class analogous to the reported CVE: a single (cheap) on-chain spend controls a downstream node's outbound network fetch target.

### Likelihood Explanation
Likely to be reachable in production: creating a mirror coin costs only a small fee/amount and requires no special privilege — any user of a standard wallet with `dl_new_mirror`/`add_mirror` access can do it for any `launcher_id`, including stores they do not own. [3](#0-2)  Any operator running a DataLayer client that subscribes/syncs to that store will automatically fetch from the malicious mirror the next time `fetch_and_validate` runs, without any manual approval step for individual mirror URLs.

### Recommendation
Validate and restrict mirror/server URLs before they are persisted or used for outbound fetches in `chia/data_layer/dl_wallet_store.py`, `chia/data_layer/data_layer.py` (`update_subscriptions_from_wallet`), and `chia/data_layer/download_data.py` (`http_download`): enforce an allow-list of schemes (https only recommended), block loopback/link-local/private/multicast IP ranges and DNS names resolving to them (with re-resolution checks to avoid DNS-rebinding), and consider requiring per-store user confirmation before adding a discovered mirror URL to the active server list.

### Proof of Concept
1. Attacker wallet calls `add_mirror`/`dl_new_mirror` with `launcher_id` = victim's known public DataLayer store id and `urls = ["http://169.254.169.254/latest/meta-data/"]`, paying only the mirror amount + fee. [4](#0-3) 
2. Transaction confirms on chain; the mirror coin (`create_mirror_puzzle()`) is spendable/readable by anyone. [1](#0-0) 
3. A victim's DataLayer node tracking the same store calls `update_subscriptions_from_wallet`, ingesting the attacker's URL into its `ServerInfo` list. [6](#0-5) 
4. On the next sync cycle, `fetch_and_validate` → `insert_from_delta_file` → `download_file` → `http_download` issues a GET to the attacker's chosen URL from the victim's node. [8](#0-7) [2](#0-1)

    return P2_PARENT.curry(Program.to(1))

def get_mirror_info(
    parent_puzzle: Program | SerializedProgram, parent_solution: Program | SerializedProgram
) -> tuple[bytes32, list[bytes]]:
    assert type(parent_puzzle) is type(parent_solution)
    _, conditions = run_with_cost(parent_puzzle, INFINITE_COST, parent_solution)
    for condition in conditions.as_iter():
        if (
            condition.first().as_python() == ConditionOpcode.CREATE_COIN
            and condition.at("rf").as_python() == create_mirror_puzzle().get_tree_hash()
        ):
            memos: list[bytes] = condition.at("rrrf").as_python()
            launcher_id = bytes32(memos[0])
            return launcher_id, [url for url in memos[1:]]
    raise ValueError("The provided puzzle and solution do not create a mirror coin")

async def download_file(
    data_store: DataStore,
    target_filename_path: Path,
    store_id: bytes32,
    root_hash: bytes32,
    generation: int,
    server_info: ServerInfo,
    proxy_url: str | None,
    downloader: PluginRemote | None,
    timeout: aiohttp.ClientTimeout,
    client_foldername: Path,
    timestamp: int,
    log: logging.Logger,
    grouped_by_store: bool,
    group_downloaded_files_by_store: bool,
    max_delta_file_size: int,
) -> bool:
    if target_filename_path.exists():
        return True
    filename = get_delta_filename(store_id, root_hash, generation, grouped_by_store)

    if downloader is None:
        # use http downloader - this raises on any error
        try:
            await http_download(
                target_filename_path, filename, proxy_url, server_info, timeout, log, max_delta_file_size
            )
        except (asyncio.TimeoutError, aiohttp.ClientError, MaxDeltaFileSizeExceededError):

                f"Miss {new_server_info.num_consecutive_failures}."
            )
            log.info(f"Next attempt from {new_server_info.url} in {new_server_info.ignore_till - timestamp}s.")
            return False
        return True

async def http_download(
    target_filename_path: Path,
    filename: str,
    proxy_url: str | None,
    server_info: ServerInfo,
    timeout: aiohttp.ClientTimeout,
    log: logging.Logger,
    max_delta_file_size: int,
) -> None:
    """
    Download a file from a server using aiohttp.
    Raises exceptions on errors
    """
    async with aiohttp.ClientSession() as session:
        headers = {"accept-encoding": "gzip"}
        async with session.get(
            server_info.url + "/" + filename,
            headers=headers,
            timeout=timeout,
            proxy=proxy_url,
        ) as resp:
            resp.raise_for_status()
