## Confirmed local analog

`CallDispatcher` is a completely permissionless, callback-free executor: `dispatch()` blindly executes any `Call[]` array against `call.to`/`call.data`, with no access control and no way to recover funds itself. [1](#0-0) 

`IntentsBase._execute()` routes an order's post-fill calldata through this dispatcher, then sweeps back **only the tokens listed in `order.output.assets`** (bounded by `outputsLen`) as "dust": [2](#0-1) 

### Title
Post-fill calldata can strand non-output-asset tokens permanently in the shared `CallDispatcher`, with no recovery path — (File: evm/src/apps/intentsv2/IntentsBase.sol)

### Summary
`_execute()` is the exact structural analog of the `SpigotedLoan._claimAndTrade()` bug: it performs an action that can leave behind tokens the contract obtained but did not account for, and provides no path to reclaim exactly those leftover assets. In the SpigotedLoan case, claimed revenue tokens not fully traded were locked in `unusedTokens` until debt was paid another way. Here, tokens obtained during postdispatch calldata execution that are **not** among `order.output.assets` are never swept and never tracked as dust anywhere — they are simply orphaned in `CallDispatcher`, a single contract shared across every order and every gateway on that chain.

### Finding Description
`_execute()` is called once per fill for orders that carry `order.output.call`:
1. The `CallDispatcher` executes the order's arbitrary `Call[]` (e.g., routing output tokens through a DEX, lending protocol, etc.) — [3](#0-2) 
2. The sweep loop only iterates `i < outputsLen`, checking balances of `order.output.assets[i].token` — [4](#0-3) 
3. Anything the calldata call produced or left in the dispatcher that is **not** one of the order's declared output tokens (e.g., a token minted/received from the routed call, a leftover intermediate swap token, or residual native ETH when the outputs are ERC-20-only) is invisible to this sweep and stays in `CallDispatcher` indefinitely.

Because `CallDispatcher` is a single shared, stateless-router contract used by every order (not scoped per-order), there is no `_sweepDust`-equivalent, no governance sweep, and no per-order accounting for it — `_sweepDust` in `IntentsBase.sol` only operates on the **gateway's own balance**, not the dispatcher's: [5](#0-4) . The dispatcher itself has no owner, no withdraw function, and accepts arbitrary calls only through its stateless `dispatch()` entrypoint [6](#0-5) , so any token it ends up holding outside the current order's declared output set can never be recovered by anyone — not the user, not the solver, not governance.

This mirrors the report's broken invariant precisely: an action (claim-and-trade / calldata-execute) produces tokens that are not fully accounted for by the post-action bookkeeping (`unusedTokens` / dust-sweep-by-output-list), and the surplus becomes permanently stranded because the only recovery mechanism (`sweep()` / `_sweepDust`) is scoped to a different set of tracked balances than the ones actually held.

### Impact Explanation
Any solver that supplies calldata routing through a DEX/vault/lending call whose actual proceeds land in a token outside `order.output.assets` (intentionally or due to a misconfigured/atypical route, oracle mismatch, or multi-hop swap producing an intermediate token) permanently locks that value in `CallDispatcher`. Because the dispatcher is shared across all orders/gateways on the chain, the loss compounds over time and is unrecoverable by design — no privileged sweep exists for it. This is a direct, unauthorized-style loss of funds with no beneficiary ever receiving them, matching the bounty's "stealing or loss of funds" / "logic attack" categories.

### Likelihood Explanation
No privileged actor, malicious relayer, or governance compromise is required — any solver constructing `order.output.call` (a normal, permissionless feature of order fulfillment) can trigger this simply by having their routed call produce or leave a token other than the ones enumerated in the order's `output.assets`. This can happen accidentally (multi-hop swaps, reward tokens from a lending call, rounding remnants of an unrelated token) as easily as it can happen deliberately.

### Recommendation
Either (a) scope calldata execution to a fresh, per-fill dispatcher/proxy that is destroyed or fully swept of *all* balances (not just declared output tokens) after each `_execute()` call, or (b) add a governance-gated `sweep(address token, address to, uint256 amount)` on `CallDispatcher` itself (mirroring `_sweepDust`) so tokens accidentally stranded there can still be recovered, analogous to how the Debt DAO fix let `claimAndRepay()` trade previously-unswept `unusedTokens`.

### Proof of Concept
1. User places a cross-chain or same-chain order whose `output.call` routes solver-supplied output tokens through a mock DEX/lending call that, instead of returning the exact `order.output.assets` token, sends back a different ERC-20 (e.g., a reward token, or unwraps into a token pair) to the `CallDispatcher`.
2. Solver fills the order; `_execute()` runs `ICallDispatcher.dispatch(order.output.call)`.
3. The sweep loop in `_execute()` only checks `IERC20(order.output.assets[i].token).balanceOf(dispatcher)` for `i < outputsLen`; the unrelated token balance is skipped entirely.
4. Assert: `CallDispatcher` retains a non-zero balance of the unrelated token after the fill completes, `OrderFilled` is emitted as normal, and no `DustCollected`/`DustSwept` event ever references that token — confirming it is permanently stranded with no recovery function reachable by the user, solver, or governance.

    function dispatch(bytes memory encoded) external {
        Call[] memory calls = abi.decode(encoded, (Call[]));
        uint256 callsLen = calls.length;
        for (uint256 i = 0; i < callsLen; ++i) {
            Call memory call = calls[i];
            uint32 size;
            address to = call.to;
            assembly {
                size := extcodesize(to)
            }

            if (size == 0) {
                revert NotContract(to);
            }

            (bool success, bytes memory result) = to.call{value: call.value}(call.data);
            if (!success) revert CallFailed(to, result);
        }
    }

    function _execute(Order calldata order, uint256 outputsLen) internal {
        if (order.output.call.length == 0) return;

        address dispatcher = _params.dispatcher;
        ICallDispatcher(dispatcher).dispatch(order.output.call);

        Call[] memory sweepCalls = new Call[](outputsLen);
        uint256 sweepCount = 0;

        for (uint256 i; i < outputsLen;) {
            address token = address(uint160(uint256(order.output.assets[i].token)));

            if (token == address(0)) {
                uint256 balance = dispatcher.balance;
                if (balance > 0) {
                    sweepCalls[sweepCount] = Call({to: address(this), value: balance, data: ""});
                    sweepCount++;
                    emit DustCollected(token, balance);
                }
            } else {
                uint256 balance = IERC20(token).balanceOf(dispatcher);
                if (balance > 0) {
                    sweepCalls[sweepCount] = Call({
                        to: token,
                        value: 0,
                        data: abi.encodeWithSelector(IERC20.transfer.selector, address(this), balance)
                    });
                    sweepCount++;
                    emit DustCollected(token, balance);
                }
            }

            unchecked {
                ++i;
            }
        }

        if (sweepCount > 0) {
            Call[] memory finalCalls = new Call[](sweepCount);
            for (uint256 i; i < sweepCount;) {
                finalCalls[i] = sweepCalls[i];
                unchecked {
                    ++i;
                }
            }
            ICallDispatcher(dispatcher).dispatch(abi.encode(finalCalls));
        }
    }

    function _sweepDust(SweepDust memory req) internal {
        uint256 outputsLen = req.outputs.length;
        for (uint256 i; i < outputsLen;) {
            TokenInfo memory info = req.outputs[i];
            address token = address(uint160(uint256(info.token)));
            uint256 amount = info.amount;

            if (token == address(0)) {
                (bool sent,) = req.beneficiary.call{value: amount}("");
                if (!sent) revert InsufficientNativeToken();
            } else {
                IERC20(token).safeTransfer(req.beneficiary, amount);
            }
            unchecked {
                ++i;
            }
            emit DustSwept(token, amount, req.beneficiary);
        }
    }
