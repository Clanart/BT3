### Title
Forked FROST signing processes reuse identical secret preprocess nonces, enabling private share recovery - ([File: crypto/frost/src/sign.rs](crypto/frost/src/sign.rs))

### Summary
`AlgorithmSignMachine` derives and stores secret FROST nonces during preprocessing, and a `fork()` after preprocessing gives every child the same nonce state. Each child can subsequently consume its copied state in `sign`, producing signature shares for attacker-controlled messages. Three shares using the same underlying nonce pair but distinct binding factors/challenges are sufficient to solve for the signer's secret share.

### Finding Description
`AlgorithmMachine::preprocess` generates a random seed, expands it with `ChaCha20Rng`, derives the FROST nonce pair, and stores both the seed and resulting `nonces` inside `AlgorithmSignMachine`. [1](#0-0)  The nonce generation itself is deterministic from the supplied RNG bytes and secret share. [2](#0-1) 

If a process forks after `preprocess`, each child inherits byte-identical `nonces`, `seed`, and `preprocess` state because no process-identity check or post-fork reseeding exists in `AlgorithmSignMachine`. [3](#0-2)  Each child then calls `sign`, which drains the child-local copy of the same nonce vector and computes the effective nonce as `d + rho * e`. [4](#0-3)  The resulting signature share is `effective_nonce + c * secret_share`. [5](#0-4) 

The ordinary Rust consuming `self` API prevents reuse within one process, but it cannot distinguish or invalidate duplicated memory created by `fork()`. [6](#0-5) 

### Impact Explanation
An unprivileged participant can supply or cause the children to sign different messages while keeping the same public preprocess set. Because the raw nonce pair is identical while `rho` and the Schnorr challenge vary by message, each observed share provides an equation:

```text
s_i = d + rho_i * e + c_i * x
```

Here `d` and `e` are the secret FROST nonce components and `x` is the Lagrange-adjusted private signing share. [7](#0-6)  Three such shares create three linear equations in three unknown scalars, allowing direct recovery of `x` and therefore compromise of the participant's threshold share. [5](#0-4) 

### Likelihood Explanation
This requires a deployment pattern equivalent to a preforking service creating or loading a FROST signing machine before worker processes sign requests. In such a deployment, requests carrying distinct public message bytes reach different children while all children inherit the same unpublished nonce pair. [1](#0-0)  No malicious validator, broken consensus, leaked key, or invalid encoding is required; the attacker only needs to influence which public messages each inherited machine signs. [6](#0-5) 

### Recommendation
Bind nonce state to the process after fork and detect reuse across process IDs, preferably by storing the PID or a kernel-provided fork identifier in `AlgorithmSignMachine` and refusing `sign` when it changes. [3](#0-2)  More robustly, defer secret nonce generation until `sign` or mix fresh operating-system entropy and the signing transcript into the effective nonce derivation, so inherited machines cannot produce correlated shares. [8](#0-7)  If deterministic caching remains necessary, `from_cache` should incorporate fresh entropy rather than reconstructing the same nonce pair solely from the cached seed. [9](#0-8) 

### Proof of Concept
1. In a preforked signing service, construct `AlgorithmSignMachine` through `AlgorithmMachine::preprocess`, which stores the secret nonce vector in the machine. [1](#0-0) 
2. Call `fork()` three times so all children inherit identical `d` and `e`.
3. Give each child the same remote preprocess map but a different public message `m_i`; each child independently calls `sign` and publishes `s_i`. [6](#0-5) 
4. For each child, compute its public `rho_i` through the normal binding-factor transcript and its public challenge `c_i` through `Hram`. [10](#0-9) [5](#0-4) 
5. Solve the public linear system:

```text
[s_1]   [1 rho_1 c_1] [d]
[s_2] = [1 rho_2 c_2] [e]
[s_3]   [1 rho_3 c_3] [x]
```

The recovered `x` is the Lagrange-adjusted private share used by `SchnorrSignature::sign`. [11](#0-10)

    mut self,
    mut preprocesses: HashMap<Participant, Preprocess<C, A::Addendum>>,
    msg: &[u8],
  ) -> Result<(Self::SignatureMachine, SignatureShare<C>), FrostError> {
    let multisig_params = self.params.multisig_params();

    let mut included = Vec::with_capacity(preprocesses.len() + 1);
    included.push(multisig_params.i());
    for l in preprocesses.keys() {
      included.push(*l);
    }
    included.sort_unstable();

    // Included < threshold
    if included.len() < usize::from(multisig_params.t()) {
      Err(FrostError::InvalidSigningSet("not enough signers"))?;
    }
    // OOB index
    if u16::from(included[included.len() - 1]) > multisig_params.n() {
      Err(FrostError::InvalidParticipant(multisig_params.n(), included[included.len() - 1]))?;
    }
    // Same signer included multiple times
    for i in 0 .. (included.len() - 1) {
      if included[i] == included[i + 1] {
        Err(FrostError::DuplicatedParticipant(included[i]))?;
      }
    }

    let view = self.params.keys.view(included.clone()).unwrap();
    validate_map(&preprocesses, &included, multisig_params.i())?;

    {
      // Domain separate FROST
      self.params.algorithm.transcript().domain_separate(b"FROST");
    }

    let nonces = self.params.algorithm.nonces();
    #[allow(non_snake_case)]
    let mut B = BindingFactor(HashMap::<Participant, _>::with_capacity(included.len()));
    {
      // Parse the preprocesses
      for l in &included {
        {
          self
            .params
            .algorithm
            .transcript()
            .append_message(b"participant", C::F::from(u64::from(u16::from(*l))).to_repr());
        }

        if *l == self.params.keys.params().i() {
          let commitments = self.preprocess.commitments.clone();
          commitments.transcript(self.params.algorithm.transcript());

          let addendum = self.preprocess.addendum.clone();
          {
            let mut buf = vec![];
            addendum.write(&mut buf).unwrap();
            self.params.algorithm.transcript().append_message(b"addendum", buf);
          }

          B.insert(*l, commitments);
          self.params.algorithm.process_addendum(&view, *l, addendum)?;
        } else {
          let preprocess = preprocesses.remove(l).unwrap();
          preprocess.commitments.transcript(self.params.algorithm.transcript());
          {
            let mut buf = vec![];
            preprocess.addendum.write(&mut buf).unwrap();
            self.params.algorithm.transcript().append_message(b"addendum", buf);
          }

          B.insert(*l, preprocess.commitments);
          self.params.algorithm.process_addendum(&view, *l, preprocess.addendum)?;
        }
      }

      // Re-format into the FROST-expected rho transcript
      let mut rho_transcript = A::Transcript::new(b"FROST_rho");
      rho_transcript.append_message(b"group_key", self.params.keys.group_key().to_bytes());
      rho_transcript.append_message(b"message", C::hash_msg(msg));
      rho_transcript.append_message(
        b"preprocesses",
        C::hash_commitments(self.params.algorithm.transcript().challenge(b"preprocesses").as_ref()),
      );

      B.calculate_binding_factors(&rho_transcript);

      // Merge the rho transcript back into the global one to ensure its advanced, while
      // simultaneously committing to everything
      self

        .algorithm
        .transcript()
        .append_message(b"rho_transcript", rho_transcript.challenge(b"merge"));

  fn random_nonce<R: RngCore + CryptoRng>(
    secret: &Zeroizing<Self::F>,
    rng: &mut R,
  ) -> Zeroizing<Self::F> {
    let mut seed = Zeroizing::new(vec![0; 32]);
    rng.fill_bytes(seed.as_mut());

    let mut repr = secret.to_repr();

    // Perform rejection sampling until we reach a non-zero nonce
    // While the IETF spec doesn't explicitly require this, generating a zero nonce will produce
    // commitments which will be rejected for being zero (and if they were used, leak the secret
    // share)
    // Rejection sampling here will prevent an honest participant from ever generating 'malicious'
    // values and ensure safety
    let mut res;
    while {
      seed.extend(repr.as_ref());
      res = Zeroizing::new(<Self as Curve>::hash_to_F(b"nonce", seed.deref()));
      res.ct_eq(&Self::F::ZERO).into()
    } {
      seed = Zeroizing::new(vec![0; 32]);
      rng.fill_bytes(&mut seed);
    }
    repr.as_mut().zeroize();

    private_key: &Zeroizing<C::F>,
    nonce: Zeroizing<C::F>,
    challenge: C::F,

      // Uses deref instead of * as * returns C::F yet deref returns &C::F, preventing a copy
