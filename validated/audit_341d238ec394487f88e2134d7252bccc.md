### Title
Gasless bundle-tx queue can be griefed by unauthenticated, balance-free spam transactions, blocking legitimate gasless swaps - ([File: kaiax/gasless/impl/tx_pool.go])

### Summary
The `kaiax/gasless` module (Kaia's gasless-transaction facility per KIP-247) admits any transaction shaped like a `GaslessApproveTx`/`GaslessSwapTx` into a bounded `knownTxs` queue *before* any token-balance, allowance, or economic-cost validation is performed. Because gas/KAIA-balance checks are explicitly skipped for gasless-shaped transactions, and by default *any* ERC20 token is accepted (`AllowedTokens: nil` = "all tokens allowed"), an attacker can flood the fixed-size bundle-tx queue with cheap, self-crafted approve/swap-shaped transactions from throwaway zero-balance addresses, exhausting `MaxBundleTxsInQueue` and causing all subsequent legitimate gasless transactions to be rejected with `ErrBundleTxQueueFull`. This is the same bug class as the referenced report: an unprivileged, permissionless call is used to pre-commit/occupy a shared resource slot that legitimate participants need, blocking them entirely.

### Finding Description
`PreAddTx` is the tx-pool hook that decides whether an incoming transaction is placed into the gasless bundle queue. It only checks `IsBundleTx(tx)` — i.e., whether the transaction is shaped like `IsApproveTx`/`IsSwapTx` — and whether the queue has capacity; it performs no balance, allowance, or executability validation: [1](#0-0) 

`IsApproveTx`/`IsSwapTx` only require that `token` be in `allowedTokens` and that the calldata pattern matches (`approve(spender, MaxUint)` to the whitelisted `swapRouter`, or `swapForGas(...)`): [2](#0-1) 

By default, `AllowedTokens` is `nil`, and per the documented semantics "all tokens are allowed if AllowedTokens is nil", meaning any existing ERC20 contract (real or attacker-deployed) qualifies as a valid gasless token for the purpose of shaping a matching transaction: [3](#0-2) 

Crucially, the README documents that normal sender KAIA-balance checks (`value + gas*gasPrice <= balance`), which every other transaction type must satisfy to even enter the pool, are explicitly *omitted* for gasless-shaped transactions, replaced instead by `GetCheckBalance()` which validates ERC20 token balance/allowance — but that validation only runs at promotion time (`isReady`/`isApproveTxReady`), not at `PreAddTx` queue-admission time: [4](#0-3) [5](#0-4) 

Because `PreAddTx` only gates on the queue counter `numQueue() >= MaxBundleTxsInQueue` (default 200) and does not require the sender to actually hold KAIA or the referenced token, an attacker can generate an arbitrary number of syntactically-valid but economically-empty approve/swap-shaped transactions (using any existing ERC20 address as `token`, since `AllowedTokens` is `nil` by default) from any number of zero-balance throwaway EOAs, and submit them to saturate the queue: [6](#0-5) 

Once `numQueue()` reaches `MaxBundleTxsInQueue`, every subsequent legitimate `GaslessApproveTx`/`GaslessSwapTx` — including from real users trying to use the gasless service — is rejected outright with `ErrBundleTxQueueFull`, before any economic or balance validation can even distinguish honest transactions from spam.

### Impact Explanation
This blocks the entire gasless-transaction service for all users on the affected node/network — analogous to the referenced report where a griefer's unauthorized-but-superficially-valid state commitment (forged token passing `balanceOf()` checks) blocked all legitimate `lenderAcceptBids()` calls. Here, spam transactions that pass only the superficial shape check (no real balance/allowance) occupy the shared, capacity-limited gasless queue and deny service to legitimate senders, a denial-of-service on a core public-facing feature of the protocol (KIP-247 gasless transactions) that block proposers rely on for accepting user swaps.

### Likelihood Explanation
This is trivially reachable by any unprivileged transaction sender: no special privileges, staking, or governance access is required. Because normal KAIA-balance checks are bypassed for gasless-shaped transactions and `AllowedTokens` defaults to "all tokens allowed", the attacker does not even need to deploy a custom malicious token or fund any account — any existing ERC20 address can be referenced to satisfy the shape check, and zero-balance EOAs can be freely generated to bypass sender-based rate limiting. The only cost is generating distinct signed transactions, which is cheap.

### Recommendation
- Do not admit a transaction into the bundle queue (`PreAddTx`) purely based on `IsBundleTx` shape matching; perform at least a lightweight balance/allowance existence check for the referenced token, or require the sender to hold a minimum real balance/nonce state before occupying a queue slot.
- Track queue occupancy per-sender (not just a global counter) to prevent a single attacker (or set of throwaway addresses) from exhausting the whole queue.
- Consider restoring `AllowedTokens` to a curated non-nil whitelist by default rather than defaulting to "all tokens allowed", reducing the attack surface for cheaply-constructed spam transactions.

### Proof of Concept
1. Deploy or pick any existing ERC20 contract `T` (since `AllowedTokens` is `nil` by default, any token qualifies) and note the whitelisted `GaslessSwapRouter` address (`swapRouter`).
2. From N distinct freshly-generated EOAs with zero KAIA balance, craft legacy transactions calling `T.approve(swapRouter, MaxUint256)` — this matches `IsApproveTx` conditions A1–A4 in [7](#0-6) .
3. Submit these N transactions to the tx pool. Each passes `IsModuleTx` and is queued via `PreAddTx` in [1](#0-0)  without any balance validation (per the README’s balance-check omission) since the balance/allowance check only happens later at promotion (`isReady`).
4. Once N reaches `MaxBundleTxsInQueue` (200 by default), subsequent legitimate `GaslessApproveTx`/`GaslessSwapTx` from real users are rejected with `ErrBundleTxQueueFull`, denying gasless service to all users until the queue drains (10s timeout per entry, but attacker can continuously resubmit new spam from new addresses to keep the queue full indefinitely).

func (g *GaslessModule) PreAddTx(tx *types.Transaction, local bool) error {
	g.knownTxsMu.RLock()
	defer g.knownTxsMu.RUnlock()

	if knownTx, ok := g.knownTxs.get(tx.Hash()); ok && knownTx.elapsedPromotedOrAddedTime() < KnownTxTimeout {
		return ErrUnableToAddKnownBundleTx
	}

	if g.IsBundleTx(tx) {
		if uint(g.knownTxs.numQueue()) >= g.GetMaxBundleTxsInQueue() {
			return ErrBundleTxQueueFull
		}
		g.knownTxs.add(tx, TxStatusQueue)
	}
	return nil
}

func (g *GaslessModule) isReady(txs map[uint64]*types.Transaction, i uint64, ready types.Transactions) bool {
	tx := txs[i]

	if g.IsApproveTx(tx) && i < uint64(math.MaxUint64) {
		return g.isApproveTxReady(tx, txs[i+1])
	}

	if g.IsSwapTx(tx) {
		var prevTx *types.Transaction
		if len(ready) > 0 {
			prevTx = ready[len(ready)-1]
		}
		return g.isSwapTxReady(tx, prevTx)
	}

	return false
}

// isApproveTxReady assumes that the caller checked `g.IsApproveTx(approveTx)`
func (g *GaslessModule) isApproveTxReady(approveTx, nextTx *types.Transaction) bool {
	addr, err := types.Sender(g.signer, approveTx)
	if err != nil {
		return false
	}
	nonce := g.getCurrentStateNonce(addr)

	if approveTx.Nonce() != nonce {
		return false
	}
	if nextTx == nil || !g.IsSwapTx(nextTx) {
		return false
	}

	return g.IsExecutable(approveTx, nextTx)
}

// IsApproveTx checks following conditions:
// A1. tx.to is a whitelisted ERC20 token.
// A2. tx.data is `approve(spender, amount)`.
// A3. spender is a whitelisted SwapRouter contract.
// A4. amount is MaxUint.
func (g *GaslessModule) IsApproveTx(tx *types.Transaction) bool {
	args, ok := decodeApproveTx(tx, g.signer)
	return ok && g.isApproveTx(args)
}

func (g *GaslessModule) isApproveTx(args *ApproveArgs) bool {
	g.gaslessInfoMu.RLock()
	defer g.gaslessInfoMu.RUnlock()

	return g.allowedTokens[args.Token] && // A1
		g.swapRouter == args.Spender && // A3
		args.Amount.Cmp(abi.MaxUint256) == 0 // A4
}

// IsSwapTx checks following conditions:
// S1. tx.to is a whitelisted SwapRouter contract.
// S2. tx.data is `swapForGas(token, amountIn, minAmountOut, amountRepay)`.
// S3. token is a whitelisted ERC20 token.
func (g *GaslessModule) IsSwapTx(tx *types.Transaction) bool {
	args, ok := decodeSwapTx(tx, g.signer)
	return ok && g.isSwapTx(args)
}
