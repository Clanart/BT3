### Title
Missing Contract/Format Validation on `governance.govparamcontract` Target Allows Governance Parameter Hijacking - (File: kaiax/gov/param.go, kaiax/gov/contractgov/impl/getter.go)

### Summary
The `governance.govparamcontract` parameter, which designates the on-chain `GovParam` contract that contractgov trusts as the source of truth for governance parameters, is validated only for being an `common.Address`-typed value — with no check that the address actually contains valid `GovParam` contract code, honors KIP-81 semantics, or is otherwise "safe." This mirrors the GovernorBravo "arbitrary target" bug class: a governance-level configuration accepts any address as the authoritative "target" without whitelisting or validation of what that target actually is.

### Finding Description
The `GovernanceGovParamContract` parameter definition only checks the vote value's Go type: [1](#0-0) 
Its `FormatChecker` is `func(cv any) bool { _, ok := cv.(common.Address); return ok }` — any 20-byte address, including an EOA or an attacker-deployed lookalike contract, passes.

At the header-governance vote-consistency layer, `checkConsistency` explicitly performs no state validation for this parameter — the test suite documents this directly: "`govparamcontract` is not state-checked here; a non-contract address is accepted (verified via committed seals)": [2](#0-1) 
And the switch in `checkConsistency` falls through `GovernanceGovParamContract` to the no-op branch that just returns `nil`: [3](#0-2) 

Once ratified, this address becomes the sole trust anchor for contractgov, which unconditionally calls `getAllParamsAt` on it and imports every returned `(name, value)` pair into the live parameter set: [4](#0-3) 

The only validation applied to values retrieved from this attacker-chosen address is per-field `Canonicalizer`/`FormatChecker` in `PartialParamSet.Add`: [5](#0-4) 
There is no cross-field consistency validation (e.g., the `LowerBoundBaseFee < UpperBoundBaseFee` check that headergov's `checkConsistency` enforces for header votes) applied to contract-sourced parameters at all — contractgov bypasses that entirely.

### Impact Explanation
If the `governance.govparamcontract` target is misconfigured or maliciously redirected to an attacker-controlled contract (e.g., via a compromised or malicious governing-node vote, or an operational mistake pointing it at a non-canonical/lookalike contract that mimics the `getAllParamsAt(uint256)` ABI), that contract fully controls: `governance.unitprice`, `reward.mintingamount`, `reward.ratio`, `reward.kip82ratio`, `reward.stakingrewardthreshold`, and all KIP-71 base fee bounds (`kip71.lowerboundbasefee`/`upperboundbasefee`/`gastarget`/etc.), without going through KIP-81's intended checkpoint-based on-chain voting process among GC members, and without the cross-field sanity checks that legitimate header-governance votes receive. This can be used to inflate `RewardMintingAmount` (supply inflation), manipulate `UnitPrice`/KIP-71 bounds (fee abuse), or redistribute `RewardRatio`/`StakingRewardThreshold` (reward redirection) — all reachable through the standard governance-vote transaction path with no additional safeguards on the target contract's legitimacy.

### Likelihood Explanation
Setting this parameter is gated by the same voting authorization already required for any other governance parameter (governing node in `single` mode, or GC member consensus in `none` mode), so the likelihood is tied to the same trust assumptions Kaia already places on governance voters for every other parameter. However, unlike every numeric/enum parameter which is format- and (for several) range-checked, `govparamcontract` has no equivalent target-legitimacy check, making it the weakest link: a single malformed or malicious vote for this one parameter can subsequently override many other parameters simultaneously and silently, bypassing checks that would otherwise apply to each of those parameters individually via header voting.

### Recommendation
- Add a format/state check to `GovernanceGovParamContract`'s validation (in `kaiax/gov/param.go` and/or `checkConsistency` in `kaiax/gov/headergov/impl/header.go`) that verifies the target address contains contract code, and ideally validate a known interface identifier / bytecode signature to confirm it is a genuine `GovParam` deployment.
- Apply the same cross-field consistency checks (e.g., `LowerBoundBaseFee < UpperBoundBaseFee`) to parameters retrieved from contract governance in `contractGetAllParamsAtFromAddr`, not only to header-vote-sourced values.
- Consider restricting changes to `governance.govparamcontract` to require a stronger/multi-party governance action (e.g., requiring council supermajority regardless of governance mode) rather than a single governing-node vote.

### Proof of Concept
1. Governing node (or majority in `none` mode) casts `governance_vote("governance.govparamcontract", <attackerContractAddress>)`.
2. `NewVoteData`/`FormatChecker` accepts it because it is merely type-checked as an address [1](#0-0) ; `VerifyVote`→`checkConsistency` performs no additional check for this parameter name [3](#0-2) .
3. Vote is ratified at the next epoch boundary and stored in `header.Governance`.
4. From the next epoch onward, `contractGetAllParamsAtFromAddr` calls `getAllParamsAt` on the attacker's contract and blindly imports every `(name,value)` it returns into the live `ParamSet` [6](#0-5) , letting the attacker's contract dictate `reward.mintingamount`, `governance.unitprice`, KIP-71 bounds, etc., without further validation beyond per-field canonicalization.

func (c *contractGovModule) contractGetAllParamsAt(blockNum uint64) (gov.PartialParamSet, error) {
	addr, err := c.contractAddrAt(blockNum)
	if err != nil {
		return nil, err
	}
	if common.EmptyAddress(addr) {
		logger.Trace("ContractEngine disabled: GovParamContract address not set")
		return nil, nil
	}

	return c.contractGetAllParamsAtFromAddr(blockNum, addr)
}

func (c *contractGovModule) contractGetAllParamsAtFromAddr(blockNum uint64, addr common.Address) (gov.PartialParamSet, error) {
	chain := c.Chain
	if chain == nil {
		return nil, ErrNotReady
	}

	config := c.ChainConfig
	if !config.IsKoreForkEnabled(new(big.Int).SetUint64(blockNum)) {
		return nil, ErrNotReady
	}

	caller := backends.NewBlockchainContractBackend(chain, nil, nil)
	contract, err := govcontract.NewGovParamCaller(addr, caller)
	if err != nil {
		return nil, err
	}

	names, values, err := contract.GetAllParamsAt(nil, new(big.Int).SetUint64(blockNum))
	if err != nil {
		logger.Warn("ContractEngine disabled: getAllParams call failed", "err", err)
		return nil, nil
	}

	if len(names) != len(values) {
		logger.Warn("ContractEngine disabled: getAllParams result invalid", "len(names)", len(names), "len(values)", len(values))
		return nil, nil
	}

	ret := ParseContractCall(names, values)

	rules := config.Rules(new(big.Int).SetUint64(blockNum))
	for name := range ret {
		if gov.DeprecatedAt(name, rules) {
			logger.Warn("Ignoring deprecated parameter from contract governance", "name", name, "blockNum", blockNum)
			delete(ret, name)
		}
	}

	return ret, nil
}

func (p PartialParamSet) Add(name string, value any) error {
	param, ok := Params[ParamName(name)]
	if !ok {
		return ErrInvalidParamName
	}

	cv, err := param.Canonicalizer(value)
	if err != nil {
		return err
	}

	if !param.FormatChecker(cv) {
		return ErrInvalidParamValue
	}

	p[ParamName(name)] = cv
	return nil
}
