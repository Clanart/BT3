## Finding: GET-response and GET-timeout paths can both pay out on the same commitment (double fee settlement)

### Summary
`HyperApp.sol`'s `onGetResponse`/`onGetTimeout` default callbacks are indeed unguarded and independent [1](#0-0) , but the real one-time-settlement guarantee for GET requests is supposed to live in `EvmHost.sol`/`HandlerV2.sol`, and it is broken there — not just missing at the app layer.

### Finding Description
`EvmHost.dispatchIncoming(GetResponse,...)` records a `_responseReceipts[commitment]` and pays the relayer fee, but it **never deletes `_requestCommitments[commitment]`**: [2](#0-1) 

`EvmHost.dispatchTimeOut(GetRequestTimeout,...)` only checks/clears `_requestCommitments[commitment]` and, on success, **refunds `meta.fee` to `meta.sender`** — despite the function's own comment claiming "Does not refund any protocol fees": [3](#0-2) 

Because the response path never clears `_requestCommitments`, the guard in `HandlerV2.handleGetRequestTimeouts` — `if (meta.sender == address(0)) revert UnknownMessage();` — still passes after a response has already been delivered: [4](#0-3) 

The only remaining defense is a non-membership proof of `RESPONSE_RECEIPTS_STORAGE_PREFIX || commitment` against a Hyperbridge-relayed state commitment at an attacker-chosen `message.height`: [5](#0-4) 

This check has two weaknesses:
1. It never checks the **local** `_responseReceipts` mapping on this same `EvmHost` — even though `dispatchIncoming(GetResponse)` may already have executed and paid the relayer on this exact chain.
2. It accepts **any previously stored, still-available height's** state commitment (`_stateCommitments[stateMachineId][height]` is height-indexed and not required to be the latest), so a permissionless caller can supply a proof anchored to an older finalized height — from before the response receipt was included in Hyperbridge's state — even after the response has already been delivered and paid out locally and later included on Hyperbridge at a newer height.

Consequently the invariant "exactly one of {response, timeout} settles a GET commitment" is not enforced by the Host: a caller can (a) let the response be delivered via `handleGetResponses` → `dispatchIncoming` (relayer paid, `_responseReceipts` set, `_requestCommitments` left intact), then (b) submit `handleGetRequestTimeouts` with a stale-height non-membership proof, causing `dispatchTimeOut` to run `onGetTimeout` and refund `meta.fee` a second time to `meta.sender`.

### Impact Explanation
This is a duplicate-settlement / double-payout of the request's fee (`meta.fee`) — once to the relayer (via response) and once as a "refund" to the original sender (via timeout) — draining the fee-token balance held by the Host. Any derived app relying on `HyperApp`'s bare callbacks for its own escrow/refund bookkeeping inherits the same lack of a one-time-settlement guard, compounding the impact for apps that move additional funds in `onGetTimeout`.

### Likelihood Explanation
Requires a normal, permissionless GET request with non-zero fee, a response delivered while an older stored state-machine height (pre-dating the response's inclusion in Hyperbridge's state) is still available on the source `EvmHost`, and a permissionless timeout-proof submission using that older height. This is a plausible race for GET requests with a configured `timeout` and non-zero `fee`, given `handleGetRequestTimeouts` is fully permissionless and does not pin to the latest height or check local response receipts.

### Recommendation
- In `EvmHost.dispatchIncoming(GetResponse,...)`, delete `_requestCommitments[commitment]` after the relayer fee payout succeeds, so a subsequent timeout fails the `meta.sender == address(0)` check.
- In `HandlerV2.handleGetRequestTimeouts` (and/or `EvmHost.dispatchTimeOut`), additionally require `host.responseReceipts(commitment).relayer == address(0)` before proceeding, independent of the non-membership proof height chosen.
- Consider forcing `message.height` in timeout messages to be at or above the latest known state-machine height (or otherwise reject proofs anchored to stale heights when a newer commitment already exists) to remove the stale-height replay window.

### Proof of Concept
1. Dispatch a `DispatchGet` with `fee > 0` and a non-zero `timeout`.
2. Relayer delivers the response via `HandlerV2.handleGetResponses` → `EvmHost.dispatchIncoming(GetResponse,...)`: `onGetResponse` executes, relayer is paid `fee`, `_responseReceipts[commitment]` is set, `_requestCommitments[commitment]` remains unchanged.
3. Before Hyperbridge's *newer* state commitment (which contains the response receipt) becomes the only one referenced, submit `HandlerV2.handleGetRequestTimeouts` with a proof anchored to an *older* still-stored `_stateCommitments[stateMachineId][height]` where the response receipt is genuinely absent.
4. `meta.sender != address(0)` check passes (never cleared), non-membership proof passes (older height), `dispatchTimeOut` executes `onGetTimeout` and refunds `meta.fee` to `meta.sender` — a second payout for the same commitment. [6](#0-5) [7](#0-6)

    function dispatchIncoming(GetResponse memory response, address relayer) external restrict(_hostParams.handler) {
        // replay protection
        bytes32 commitment = response.request.hash();
        _responseReceipts[commitment] = ResponseReceipt({
            relayer: relayer,
            responseCommitment: response.hash()
        });

        (bool success,) = _bytesToAddress(response.request.from)
            .call(abi.encodeWithSelector(IApp.onGetResponse.selector, IncomingGetResponse(response, relayer)));

        if (!success) {
            // so that it can be retried
            delete _responseReceipts[commitment];
            return;
        }

        // reward the relayer fee
        uint256 fee = _requestCommitments[commitment].fee;
        if (fee != 0) {
            IERC20(feeToken()).safeTransfer(relayer, fee);
        }
        emit GetRequestHandled({commitment: commitment, relayer: relayer});
    }

    /**
     * @dev Dispatch an incoming GET timeout to the source module.
     * @notice Does not refund any protocol fees.
     * @param timeout - timed-out get request bundled with the relayer that submitted the timeout proof
     * @param meta - fee metadata for the original request
     * @param commitment - request commitment
     */
    function dispatchTimeOut(
        GetRequestTimeout memory timeout,
        FeeMetadata memory meta,
        bytes32 commitment
    ) external restrict(_hostParams.handler) {
        // replay protection
        delete _requestCommitments[commitment];
        (bool success,) = _bytesToAddress(timeout.request.from)
            .call(abi.encodeWithSelector(IApp.onGetTimeout.selector, timeout));

        if (!success) {
            // so that it can be retried
            _requestCommitments[commitment] = meta;
            return;
        }

        if (meta.fee != 0) {
            // refund relayer fee
            IERC20(feeToken()).safeTransfer(meta.sender, meta.fee);
        }
        emit GetRequestTimeoutHandled({commitment: commitment, dest: string(timeout.request.dest)});
    }

    function handleGetRequestTimeouts(IHost host, GetTimeoutMessage calldata message) external notFrozen(host) {
        uint256 delay = block.timestamp - host.stateMachineCommitmentUpdateTime(message.height);
        uint256 challengePeriod = host.challengePeriod();
        if (challengePeriod != 0 && challengePeriod > delay) revert ChallengePeriodNotElapsed();

        // fetch the state commitment
        StateCommitment memory state = host.stateMachineCommitment(message.height);
        if (state.stateRoot == bytes32(0)) revert StateCommitmentNotFound();
        uint256 timeoutsLength = message.timeouts.length;

        for (uint256 i = 0; i < timeoutsLength; ++i) {
            GetRequest memory request = message.timeouts[i];
            // timed-out?
            if (request.timeout() > state.timestamp) revert MessageNotTimedOut();

            bytes32 commitment = request.hash();
            FeeMetadata memory meta = host.requestCommitments(commitment);
            if (meta.sender == address(0)) revert UnknownMessage();

            bytes[] memory keys = new bytes[](1);
            keys[0] = bytes.concat(RESPONSE_RECEIPTS_STORAGE_PREFIX, commitment);

            // verify state trie non-membership proofs
            PolkadotTrie.StorageValue memory entry = PolkadotTrie.VerifyProof(state.stateRoot, message.proof, keys)[0];
            if (entry.value.length != 0) revert InvalidProof();

            host.dispatchTimeOut(GetRequestTimeout(request, _msgSender()), meta, commitment);
        }
    }
