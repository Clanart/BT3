### Title
Missing native-value check in gasless tx-pool admission allows insolvent transactions to bypass balance validation - (File: `kaiax/gasless/impl/tx_pool.go`, `kaiax/gasless/impl/getter.go`)

### Summary
The gasless module's transaction classification (`IsApproveTx` / `IsSwapTx`) determines whether a transaction is a "gasless" `approve`/`swapForGas` call purely from `tx.To()` and `tx.Data()` (the 4-byte selector and decoded ABI args). It never inspects `tx.Value()`. When `TxPool.validateTx` finds a matching module transaction, it sets `shouldSkipBalanceCheck = true` and entirely replaces the standard `sender balance >= tx.Cost()` (`value + gas*price`) check with the module's own `GetCheckBalance()`, which itself never validates that the sender can actually cover the declared native `tx.Value()`.

### Finding Description
`decodeFunctionCall` in `kaiax/gasless/impl/getter.go` only checks tx type, `To`, calldata length, and method selector: [1](#0-0) 

`IsApproveTx`/`isApproveTx` and `IsSwapTx`/`isSwapTx` only check token/router whitelisting and ABI-decoded arguments — they never check `tx.Value()`: [2](#0-1) 

In the tx pool, once `IsModuleTx` matches (i.e. `IsApproveTx(tx) || IsSwapTx(tx)`), the pool skips its normal solvency check and defers entirely to the module's `GetCheckBalance()`: [3](#0-2) [4](#0-3) 

`checkBalanceForApprove` and `checkBalanceForSwap` verify only ERC20 token balance/allowance, router `getAmountIn`, and deadline — at no point do they check that the sender's native KAIA balance covers `tx.Value() + tx.Fee()`: [5](#0-4) 

This mirrors the reported bug class: a check intended to gate on "no calldata / native transfer" is satisfied by matching calldata patterns while ignoring the accompanying `msg.value`/`tx.Value()`, allowing the value-related invariant (sufficient balance to cover the transferred value) to be silently bypassed for any transaction whose calldata happens to match the gasless `approve`/`swapForGas` selector — even though these functions are declared `nonpayable` and no design in this module expects a nonzero `Value` to accompany them.

### Impact Explanation
Any unprivileged transaction sender can craft a Legacy transaction targeting a whitelisted ERC20 token or the whitelisted `GaslessSwapRouter` with a matching `approve`/`swapForGas` calldata and an arbitrary, unbacked `tx.Value()`. Because `IsModuleTx` classifies it as a gasless tx purely by calldata, the pool's standard `senderBalance >= tx.Cost()` check (`blockchain/tx_pool.go` lines 934-988) is entirely bypassed, and the substitute check in `checkBalanceForApprove`/`checkBalanceForSwap` never inspects `tx.Value()`. This is an acceptance-of-an-invalid-transaction defect: the pool admits (and can propagate/gossip and attempt to include) transactions that violate the fundamental "sender can pay for tx.Cost()" invariant enforced for every other transaction type in the pool. This undermines a security-relevant invariant of the gasless bundle admission logic and can be leveraged to flood the gasless bundle queue/pending slots (`GetMaxBundleTxsInQueue`/`GetMaxBundleTxsInPending`) with transactions that appear to be legitimate "approve"/"swap" pairs but declare unbacked value, since the pool no longer performs its own sanity check to reject them at admission time.

### Likelihood Explanation
High reachability: any address, without any special privilege (no need for AccountKey control, no consensus role), can submit a Legacy transaction with legitimate-looking `approve`/`swapForGas` calldata plus a non-zero `Value` directly via public RPC (`eth_sendRawTransaction`). No preconditions beyond an ERC20 token/router pair being whitelisted (which is normal, expected mainnet state via KIP-149 Registry / MultiCall) are required. The check that is supposed to gate `IsModuleTx` classification never considers `tx.Value()`, so the bypass is deterministic and always reachable.

### Recommendation
In `IsApproveTx`/`IsSwapTx` (or in `decodeFunctionCall`), explicitly reject any transaction with non-zero `tx.Value()`, since `approve` and `swapForGas` are `nonpayable` and the gasless design assumes the sender holds no usable KAIA. Additionally, in `checkBalanceForApprove` and `checkBalanceForSwap`, add an explicit assertion that `tx.Value().Sign() == 0` (or otherwise verify the sender can cover `tx.Value()`), so that `shouldSkipBalanceCheck` in `blockchain/tx_pool.go` cannot be used to admit a transaction whose native-value cost was never actually validated.

### Proof of Concept
1. Ensure a token `T` is in `GaslessModule.allowedTokens` and `SwapRouter` `R` is registered (normal mainnet state via `Registry`/`MultiCall`, as exercised in `tests/gasless_test.go`).
2. Attacker (with an account holding zero or near-zero KAIA, but non-zero balance of `T` if `ShouldCheckToken` is enabled) constructs a Legacy transaction:
   - `to = T`
   - `data = approve(R, MaxUint256)` selector + args
   - `value = <arbitrarily large, unbacked amount>`
   - signs and submits via `eth_sendRawTransaction`.
3. `TxPool.validateTx` calls `module.IsModuleTx(tx)` → `IsApproveTx` returns true (value never inspected) → `shouldSkipBalanceCheck = true` → `checkBalance(tx)` → `checkBalanceForApprove` only checks token balance (if enabled), never `tx.Value()`.
4. The standard `senderBalance.Cmp(tx.Cost())` check at `blockchain/tx_pool.go` lines 983-988 is skipped entirely, so the transaction with unbacked `Value` is admitted into the pool despite violating the pool's core solvency invariant that every other tx type must satisfy.

Note: I was unable to fully trace, within the remaining budget, the exact downstream behavior when such a transaction is later selected for block inclusion (whether `TransitionDb`/`vm.Call`'s `CanTransfer` check causes it to be silently dropped from block building or causes an on-chain revert), so the ultimate on-chain consequence (beyond pool-admission-invariant violation and gasless-queue resource abuse) is not fully confirmed and should be verified with a live Devin session.

func decodeFunctionCall(tx *types.Transaction, method abi.Method) (common.Address, map[string]interface{}, bool) {
	if tx.Type() != types.TxTypeLegacyTransaction || // not legacy tx: unable to statically determine the max gas fee.
		tx.To() == nil || // not a contract call.
		len(tx.Data()) < 4 || // too short to be a contract call.
		!bytes.Equal(tx.Data()[:4], method.ID) { // not the target function.
		return common.Address{}, nil, false
	}

	inputs := make(map[string]interface{})
	err := method.Inputs.UnpackIntoMap(inputs, tx.Data()[4:])
	return *tx.To(), inputs, err == nil
}

func (g *GaslessModule) IsModuleTx(tx *types.Transaction) bool {
	if tx == nil {
		return false
	}
	return g.IsApproveTx(tx) || g.IsSwapTx(tx)
}

func (g *GaslessModule) GetCheckBalance() func(tx *types.Transaction) error {
	return func(tx *types.Transaction) error {
		if approveArgs, ok := decodeApproveTx(tx, g.signer); ok {
			return g.checkBalanceForApprove(approveArgs)
		}
		if swapArgs, ok := decodeSwapTx(tx, g.signer); ok {
			return g.checkBalanceForSwap(swapArgs, tx.Nonce())
		}
		return errors.New("not a gasless transaction") // should not happen because IsModuleTx is called before GetCheckBalance
	}
}

func (g *GaslessModule) checkBalanceForApprove(approveArgs *ApproveArgs) error {
	token := approveArgs.Token
	bc := backends.NewBlockchainContractBackend(g.Chain, nil, nil)

	if g.GaslessConfig.ShouldCheckSenderCode() {
		if g.getCurrentHasCode(approveArgs.Sender) {
			return errors.New("sender with code is not allowed")
		}
	}

	if g.GaslessConfig.ShouldCheckToken() {
		tokenContract, err := sc_erc20.NewERC20(token, bc)
		if err != nil {
			return err
		}

		// tx.token.balanceOf(sender) > 0
		tokenBalance, err := tokenContract.BalanceOf(nil, approveArgs.Sender)
		if err != nil {
			return err
		}
		if tokenBalance.Sign() <= 0 {
			return fmt.Errorf("insufficient sender token balance: token=%s, have=%s, want=nonzero", token.Hex(), tokenBalance.String())
		}
	}
	return nil
}

// tx.amountIn >= gsr.getAmountIn(minAmountOut)
// tx.token.approval(sender, router) >= tx.amountIn
// tx.token.balanceOf(sender) >= tx.amountIn
// tx.deadline >= currentTimestamp
func (g *GaslessModule) checkBalanceForSwap(swapArgs *SwapArgs, swapNonce uint64) error {
	token := swapArgs.Token
	bc := backends.NewBlockchainContractBackend(g.Chain, nil, nil)

	g.gaslessInfoMu.RLock()
	swapRouter := g.swapRouter
	g.gaslessInfoMu.RUnlock()

	// tx.minAmountOut >= tx.amountRepay
	minAmountOut := swapArgs.MinAmountOut
	amountRepay := swapArgs.AmountRepay
	if minAmountOut.Cmp(amountRepay) < 0 {
		return fmt.Errorf("insufficient minAmountOut: minAmountOut=%s, amountRepay=%s", minAmountOut.String(), amountRepay.String())
	}

	if g.GaslessConfig.ShouldCheckSenderCode() {
		if g.getCurrentHasCode(swapArgs.Sender) {
			return errors.New("sender with code is not allowed")
		}
	}

	if g.GaslessConfig.ShouldCheckSwapAmount() {
		// tx.amountIn >= gsr.getAmountIn(minAmountOut)
		routerContract, err := kip247.NewGaslessSwapRouterCaller(swapRouter, bc)
		if err != nil {
			return err
		}
		// Required token amountIn, given the current exchange rate and the declared minAmountOut.
		requiredAmountIn, err := routerContract.GetAmountIn(nil, token, minAmountOut)
		if err != nil {
			return err
		}
		if swapArgs.AmountIn.Cmp(requiredAmountIn) < 0 {
			return fmt.Errorf("insufficient amountIn: have=%s, want=%s", swapArgs.AmountIn.String(), requiredAmountIn.String())
		}
	}

	if g.GaslessConfig.ShouldCheckToken() {

		tokenContract, err := sc_erc20.NewERC20(token, bc)
		if err != nil {
			return err
		}

		// If SwapTx.nonce is the sender's next nonce, then there is no room for ApproveTx proceeding SwapTx.
		senderNonce := g.getCurrentStateNonce(swapArgs.Sender)
		noApproveTxPreceeds := swapNonce == senderNonce
		if noApproveTxPreceeds {
			// tx.token.allowance(sender, router) >= tx.amountIn
			approval, err := tokenContract.Allowance(nil, swapArgs.Sender, swapRouter)
			if err != nil {
				return err
			}
			if approval.Cmp(swapArgs.AmountIn) < 0 {
				return fmt.Errorf("insufficient approval: approval=%s, want=%s", approval.String(), swapArgs.AmountIn.String())
			}
		}

		// tx.token.balanceOf(sender) >= tx.amountIn
		balance, err := tokenContract.BalanceOf(nil, swapArgs.Sender)
		if err != nil {
			return err
		}
		if balance.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("insufficient balance: balance=%s, want=%s", balance.String(), swapArgs.AmountIn.String())
		}
	}

	// tx.deadline >= currentTimestamp
	deadline := swapArgs.Deadline
	if deadline.Cmp(g.Chain.CurrentBlock().Time()) < 0 {
		return fmt.Errorf("insufficient deadline: deadline=%s, want=%s", deadline.String(), g.Chain.CurrentBlock().Time().String())
	}

	return nil
}
