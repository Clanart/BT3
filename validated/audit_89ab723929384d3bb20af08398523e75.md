### Title
Unbounded parameter sizes in public `debug_isGaslessTx` RPC endpoint enable Denial of Service - (File: `kaiax/gasless/impl/api.go`)

### Summary
The gasless module exposes a **public** JSON-RPC endpoint, `debug_isGaslessTx`, that accepts an arbitrary-length array of arbitrary-size raw transaction byte blobs and RLP-decodes each one before any transaction-pool-style size limits (`MaxTxDataSize`, slot accounting, etc.) are applied. This mirrors the Discourse CVE-2024-27100 pattern: an endpoint reachable by an unprivileged caller accepts unbounded-size parameters, which can be abused to force excessive resource consumption and render the node inoperable.

### Finding Description
`IsGaslessTx` is registered as a public RPC method: [1](#0-0) 

Its signature and implementation accept a caller-controlled slice of `hexutil.Bytes` with **no limit on the number of elements and no limit on the size of each element** before calling `rlp.DecodeBytes`: [2](#0-1) 

Contrast this with the normal transaction-admission path in the tx pool, which enforces `MaxTxDataSize` (128 KB) and slot-based accounting specifically "to prevent DOS attacks": [3](#0-2) [4](#0-3) 

The `debug_isGaslessTx` handler bypasses all of that: it is invoked directly from an RPC request, decodes every supplied byte blob unconditionally, and only after full RLP decoding does it check whether the transaction is a swap/approve transaction. There is no cap on `len(rawTxs)`, no cap on `len(rawTx)`, and no early rejection of oversized inputs analogous to `ErrOversizedData`/`MaxTxDataSize` used elsewhere in the codebase.

### Impact Explanation
A single unauthenticated RPC caller can submit a request containing many large hex-encoded byte strings (e.g., tens/hundreds of megabytes total, or a very large array of moderately sized entries). The node will allocate memory for each entry and pay full RLP-decoding CPU cost for each, with no admission control, unlike the tx pool path that rejects entries over `MaxTxDataSize` before doing expensive work. Because this API is marked `Public: true` under the `debug` namespace, it is reachable by any RPC client that can reach the node's RPC surface, and repeated/parallel requests can exhaust memory/CPU and disrupt node availability — the same "excessive resource consumption... render an instance inoperable" impact described in the reference advisory.

### Likelihood Explanation
Likelihood is high: the endpoint requires no authentication, no gas payment, and no prior state (unlike a transaction, it never needs to enter the pool or be mined), so it is trivially and repeatedly callable by any RPC client, including scripted/automated abuse.

### Recommendation
Enforce size limits on `debug_isGaslessTx` inputs before decoding:
- Reject requests where `len(rawTxs)` exceeds a small bound (e.g., 2, since the API only supports 1 or 2 transactions per its own documented semantics).
- Reject any individual `rawTx` whose length exceeds `blockchain.MaxTxDataSize` (or a similarly small constant) before calling `rlp.DecodeBytes`, mirroring the check already present in `TxPool.validateTx`.

### Proof of Concept
```
curl "http://localhost:8551" -X POST -H 'Content-Type: application/json' --data '
{
  "jsonrpc":"2.0",
  "id":1,
  "method":"debug_isGaslessTx",
  "params":[[
    "0x<huge_hex_blob_many_MB_1>",
    "0x<huge_hex_blob_many_MB_2>",
    ... repeated many times ...
  ]]
}'
```
Because `IsGaslessTx` (`kaiax/gasless/impl/api.go`) neither limits the number of array elements nor the size of each element before RLP-decoding, sending a request with a large number of oversized entries forces the node to allocate memory and spend CPU decoding all of them, unlike the transaction pool's `validateTx`, which rejects oversized payloads (`ErrOversizedData`) up front.

// IsGaslessTx checks if the given raw transactions form a valid gasless transaction
// It returns a detailed result explaining why a transaction is not a valid gasless transaction if it's not
func (s *GaslessAPI) IsGaslessTx(ctx context.Context, rawTxs []hexutil.Bytes) *GaslessTxResponse {
	if len(rawTxs) == 0 {
		return ToResponse(errors.New("no transactions provided"))
	}

	// Decode the raw transactions
	txs := make([]*types.Transaction, 0, len(rawTxs))
	for i, rawTx := range rawTxs {
		if len(rawTx) == 0 {
			return ToResponse(fmt.Errorf("empty transaction at index %d", i))
		}

		// Handle Ethereum transaction envelope
		if 0 < rawTx[0] && rawTx[0] < 0x7f {
			rawTx = append([]byte{byte(types.EthereumTxTypeEnvelope)}, rawTx...)
		}

		tx := new(types.Transaction)
		if err := rlp.DecodeBytes(rawTx, tx); err != nil {
			return ToResponse(fmt.Errorf("failed to decode transaction at index %d: %v", i, err))
		}

		txs = append(txs, tx)
	}
