### Title
SSRF via unauthenticated on-chain DataLayer mirror coins with attacker-controlled URLs - (File: `chia/data_layer/download_data.py`, `chia/data_layer/data_layer_wallet.py`, `chia/wallet/db_wallet/db_wallet_puzzles.py`)

### Summary
Any unprivileged spend-bundle submitter can create a coin under the fixed, well-known `MIRROR_PUZZLE_HASH` puzzle with an arbitrary `launcher_id` and arbitrary URL memos. Any node running DataLayer that tracks or subscribes to that `launcher_id` will pick up the mirror coin, store its URLs as legitimate sync targets, and later have its background sync loop issue outbound `aiohttp` requests (or plugin download POSTs) to those attacker-chosen URLs with no scheme, hostname, or IP-range validation — a direct SSRF analog to the FreeScout `fetch_test`/`send_test` bug class, but triggerable without any authentication, purely from a mempool-accepted spend.

### Finding Description
`create_mirror_puzzle()` returns a fixed, parameterless puzzle (`P2_PARENT.curry(Program.to(1))`), and its tree hash `MIRROR_PUZZLE_HASH` is public/derivable by anyone. [1](#0-0) 

Because the puzzle takes no per-owner parameter, **anyone** can spend any coin they own to create a new coin with `puzzle_hash == MIRROR_PUZZLE_HASH` and memos `[launcher_id, url1, url2, ...]`. There is no signature, ownership, or ACL check tying the `launcher_id` to the coin creator — `get_mirror_info()` simply parses whatever `CREATE_COIN` condition and memo bytes are present. [2](#0-1) 

When a node's wallet sees such a coin added and is tracking that `launcher_id`, it unconditionally records the mirror and its URLs: [3](#0-2) 

The DataLayer service later reads these wallet-tracked mirrors via `update_subscriptions_from_wallet()` with no filtering beyond stripping a trailing slash: [4](#0-3) 

During the periodic sync loop, `fetch_and_validate()` iterates these attacker-supplied server URLs and passes them into `insert_from_delta_file()` / `download_file()`: [5](#0-4) 

`http_download()` performs a raw `aiohttp` GET directly against `server_info.url + "/" + filename`, with no host/IP validation, no blocklist for private or link-local ranges (e.g., `169.254.169.254`), and no scheme restriction beyond what `aiohttp` itself accepts: [6](#0-5) 

If a plugin downloader is configured, the URL is instead POSTed as a `request_json["url"]` field to the plugin, which may perform its own fetch of the attacker-controlled `url` — a second SSRF surface: [7](#0-6) 

This mirrors the FreeScout root cause exactly: a user/attacker-controlled server URL is passed straight to an outbound network client with all IP/host validation absent — here, it's on-chain and permissionless rather than gated behind an authenticated admin panel, making it reachable by any unauthenticated spend-bundle submitter (per the "Data Layer client" allowed reachability class in scope).

### Impact Explanation
Any node running the DataLayer service that subscribes to (or owns and thus tracks mirrors for) a given store can be forced to make outbound HTTP requests to attacker-chosen internal hosts/ports, including cloud metadata endpoints (`169.254.169.254`) or internal service ports. Differentiated success/failure and HTTP response codes/log entries let an attacker perform internal network reconnaissance and potentially exfiltrate partial data from internal HTTP services or plugin backends, all without requiring the target operator to take any action beyond normal store-subscription/tracking behavior. This is a Medium-severity SSRF consistent with the referenced CVE class.

### Likelihood Explanation
Likelihood is fairly high for any node that is actively syncing/subscribing to DataLayer stores (a common, expected usage pattern), since the only requirement is submitting a standard, low-value coin spend to a public puzzle hash with attacker-chosen memos — no special privileges, no admin authentication, and no interaction with the victim beyond them already tracking the targeted `launcher_id`.

### Recommendation
- Validate mirror/subscription URLs before use: enforce an allowed scheme list (`http`/`https`), resolve hostnames and reject connections to private, loopback, link-local, and multicast IP ranges (equivalent to a `checkUrlIpAndHost()`-style guard), and re-validate on redirect.
- Apply the same validation to plugin `downloader.url` construction and to the `url` field embedded in `request_json` sent to plugins.
- Consider rate-limiting/backoff and provenance checks on mirror coins (e.g., require mirrors to be created by the store owner's tracked outputs, or clearly label/segregate untrusted third-party mirror URLs) before they are used as automatic fetch targets.

### Proof of Concept
1. Attacker crafts and submits a spend bundle creating a coin with `puzzle_hash = create_mirror_puzzle().get_tree_hash()` and memo list `[victim_tracked_launcher_id, "http://169.254.169.254/latest/meta-data/"]` (any amount, e.g. 1 mojo). [1](#0-0) 
2. Once the coin confirms, any node tracking `victim_tracked_launcher_id` records it as a mirror via `coin_added()`. [3](#0-2) 
3. On its next `periodically_manage_data()` cycle, that node's `update_subscription()` → `fetch_and_validate()` → `insert_from_delta_file()` → `http_download()` issues an outbound GET to the attacker-chosen URL. [8](#0-7) 
4. Success/failure of the fetch (visible via logs/backoff state in `get_available_servers_for_store`/`server_misses_file`) confirms port/service reachability, demonstrating the SSRF/port-scan primitive.

def get_mirror_info(
    parent_puzzle: Program | SerializedProgram, parent_solution: Program | SerializedProgram
) -> tuple[bytes32, list[bytes]]:
    assert type(parent_puzzle) is type(parent_solution)
    _, conditions = run_with_cost(parent_puzzle, INFINITE_COST, parent_solution)
    for condition in conditions.as_iter():
        if (
            condition.first().as_python() == ConditionOpcode.CREATE_COIN
            and condition.at("rf").as_python() == create_mirror_puzzle().get_tree_hash()
        ):
            memos: list[bytes] = condition.at("rrrf").as_python()
            launcher_id = bytes32(memos[0])
            return launcher_id, [url for url in memos[1:]]
    raise ValueError("The provided puzzle and solution do not create a mirror coin")
```

async def download_file(
    data_store: DataStore,
    target_filename_path: Path,
    store_id: bytes32,
    root_hash: bytes32,
    generation: int,
    server_info: ServerInfo,
    proxy_url: str | None,
    downloader: PluginRemote | None,
    timeout: aiohttp.ClientTimeout,
    client_foldername: Path,
    timestamp: int,
    log: logging.Logger,
    grouped_by_store: bool,
    group_downloaded_files_by_store: bool,
    max_delta_file_size: int,
) -> bool:
    if target_filename_path.exists():
        return True
    filename = get_delta_filename(store_id, root_hash, generation, grouped_by_store)

    if downloader is None:
        # use http downloader - this raises on any error
        try:
            await http_download(
                target_filename_path, filename, proxy_url, server_info, timeout, log, max_delta_file_size
            )
        except (asyncio.TimeoutError, aiohttp.ClientError, MaxDeltaFileSizeExceededError):
            new_server_info = await data_store.server_misses_file(store_id, server_info, timestamp)
            log.info(
                f"Failed to download {filename} from {new_server_info.url}."
                f"Miss {new_server_info.num_consecutive_failures}."
            )
            log.info(f"Next attempt from {new_server_info.url} in {new_server_info.ignore_till - timestamp}s.")
            return False
        return True
```

async def http_download(
    target_filename_path: Path,
    filename: str,
    proxy_url: str | None,
    server_info: ServerInfo,
    timeout: aiohttp.ClientTimeout,
    log: logging.Logger,
    max_delta_file_size: int,
) -> None:
    """
    Download a file from a server using aiohttp.
    Raises exceptions on errors
    """
    async with aiohttp.ClientSession() as session:
        headers = {"accept-encoding": "gzip"}
        async with session.get(
            server_info.url + "/" + filename,
            headers=headers,
            timeout=timeout,
            proxy=proxy_url,
        ) as resp:
            resp.raise_for_status()
            size = int(resp.headers.get("content-length", 0))
            max_delta_file_size_bytes = max_delta_file_size * 1024 * 1024
            if size > max_delta_file_size_bytes:
                raise MaxDeltaFileSizeExceededError(f"Maximum delta file size exceeded: {max_delta_file_size} MiB.")
            log.debug(f"Downloading delta file {filename}. Size {size} bytes.")
