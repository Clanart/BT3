### Title
Signed repair requests lack replay/nonce-uniqueness enforcement, allowing captured-packet replay flooding - ([File: core/src/repair/serve_repair.rs])

### Summary
The external report's bug class is: a signature that is meant to authorize exactly one action can instead be reused an unlimited number of times because there is no server-side tracking of "already used" signatures/nonces. The Agave analog is in the repair-request signature verification path: `ServeRepair::verify_signed_packet` and `decode_request` in `core/src/repair/serve_repair.rs` validate a `RepairRequestHeader`'s signature, recipient match, and a coarse time window, but never record or check the `nonce` against a set of previously-seen values for that sender/packet.

### Finding Description
Each repair request carries a `RepairRequestHeader { signature, sender, recipient, timestamp, nonce }` [1](#0-0) . The signature covers `sender`, `recipient`, `timestamp`, and `nonce`, and is produced once by the requester via `repair_proto_to_bytes` [2](#0-1) .

On the receiving side, `verify_signed_packet` only checks: (1) the ed25519 signature is valid, (2) `header.recipient == my_id`, and (3) `timestamp` is within `SIGNED_REPAIR_TIME_WINDOW` of the receiver's clock [3](#0-2) . There is no lookup against a cache/set of nonces or full signatures already processed for that `(sender, nonce)` pair. `decode_request`, which drives the whole processing pipeline, calls `verify_signed_packet` and then proceeds directly to compute the sender's stake and whitelist status and hand the request off for servicing — again with no replay/uniqueness check [4](#0-3) .

Because repair requests are sent over plaintext UDP, any network observer (an "unprivileged" party, not necessarily a validator/peer with a private key) can capture one valid signed repair packet from a legitimate low- or high-stake node and replay the exact same bytes to the target repeatedly, as many times as desired, as long as it is replayed within `SIGNED_REPAIR_TIME_WINDOW` of the original timestamp. Each replayed copy passes signature verification (the signature is unchanged and still matches `sender`), passes the recipient check, and passes the time-window check, so the target will re-execute the expensive work of servicing the repair request (blockstore lookup and shred/packet generation, e.g. via `run_window_request`/`run_highest_window_request`) once per replay [5](#0-4) . The `nonce` field is only used client-side to correlate responses in `OutstandingShredRepairs`/`verify_repair_nonce` on the requester's node [6](#0-5)  — it provides no anti-replay guarantee on the server that processes the request.

This mirrors the report's exact defect: a signature meant to authorize one specific action (one repair query, for one nonce/timestamp) can be reused/replayed arbitrarily many times because the verifying party never records which signatures/nonces have already been consumed.

### Impact Explanation
An attacker who merely observes network traffic (no stake, no validator identity, no private key) can capture a single legitimately signed repair request and flood-replay it to the target validator within the signed time window. Each replay forces the target to redo blockstore reads and shred/packet serialization and to send a UDP response, giving the attacker bandwidth/CPU amplification without needing to forge any signature or possess any keys. This is a non-RPC, unprivileged remote resource-exhaustion vector against the repair/serve-repair path (UDP/blockstore), fitting the "non-RPC remote exhaustion/crash" impact category.

### Likelihood Explanation
Likelihood is medium: it requires the attacker to be able to observe/capture at least one legitimate signed repair packet in transit (repair traffic is UDP and unencrypted, so this is passive network observation, not "malicious peer" collusion or key compromise). Once one packet is captured, replay is trivial and can be repeated at will within the time window, and a new packet can be captured again once the window expires, sustaining the attack indefinitely.

### Recommendation
Track consumed `(sender, nonce)` pairs (or full signatures) per signer within the `SIGNED_REPAIR_TIME_WINDOW` in a bounded cache on the receiving side, and reject requests whose nonce/signature has already been seen for that sender, analogous to the mitigation the original report recommends (a used-signature map or incrementing nonce enforcement) — but enforced by the verifier, not just used opportunistically by the client.

### Proof of Concept
1. Attacker passively captures one raw UDP repair-request packet (any `RepairProtocol::WindowIndex`/`HighestWindowIndex`/etc. variant) sent by a legitimate node to a target validator's repair socket.
2. Attacker resends the identical byte sequence to the target's repair-request port N times within `SIGNED_REPAIR_TIME_WINDOW`.
3. Each copy passes `ServeRepair::verify_signed_packet` (signature, recipient, timestamp checks all still hold) [7](#0-6) , so the target performs a fresh blockstore lookup/response for each replay, consuming CPU/disk/bandwidth proportional to N with no server-side replay rejection.

Note: I was unable to fully verify whether there is additional per-IP/per-pubkey rate limiting or nonce caching implemented elsewhere in the repair request-handling pipeline (e.g., in the socket/packet-batch layer before `decode_request` is called) due to running out of tool iterations before inspecting `core/src/repair/serve_repair.rs` lines ~900–1090 and the request dispatch loop. If such throttling exists and effectively bounds per-signature replay cost, it would mitigate (but likely not fully eliminate) this finding.

    fn decode_request(
        remote_request: BytesPacket,
        epoch_staked_nodes: &Option<Arc<HashMap<Pubkey, u64>>>,
        whitelist: &HashSet<Pubkey>,
        my_id: &Pubkey,
        socket_addr_space: &SocketAddrSpace,
    ) -> Result<RepairRequestWithMeta> {
        let Ok(request) = deserialize_request::<RepairProtocol>(&remote_request) else {
            return Err(Error::from(RepairVerifyError::Malformed));
        };
        let from_addr = remote_request.meta().socket_addr();
        if !ContactInfo::is_valid_address(&from_addr, socket_addr_space) {
            return Err(Error::from(RepairVerifyError::Malformed));
        }
        Self::verify_signed_packet(my_id, remote_request.buffer(), &request)?;
        if request.sender() == Some(my_id) {
            error!("self repair: from_addr={from_addr} my_id={my_id} request={request:?}");
            return Err(Error::from(RepairVerifyError::SelfRepair));
        }
        let stake = *epoch_staked_nodes
            .as_ref()
            .and_then(|stakes| stakes.get(request.sender()?))
            .unwrap_or(&0);

        let whitelisted = request
            .sender()
            .map(|pubkey| whitelist.contains(pubkey))
            .unwrap_or_default();

        Ok(RepairRequestWithMeta {
            request,
            from_addr,
            stake,
            whitelisted,
        })
    }

    fn verify_signed_packet(my_id: &Pubkey, bytes: &[u8], request: &RepairProtocol) -> Result<()> {
        match request {
            RepairProtocol::LegacyWindowIndex
            | RepairProtocol::LegacyHighestWindowIndex
            | RepairProtocol::LegacyOrphan
            | RepairProtocol::LegacyWindowIndexWithNonce
            | RepairProtocol::LegacyHighestWindowIndexWithNonce
            | RepairProtocol::LegacyOrphanWithNonce
            | RepairProtocol::LegacyAncestorHashes => {
                return Err(Error::from(RepairVerifyError::Unsigned));
            }
            RepairProtocol::Pong(pong) => {
                if !pong.verify() {
                    return Err(Error::from(RepairVerifyError::SigVerify));
                }
            }
            RepairProtocol::WindowIndex { header, .. }
            | RepairProtocol::HighestWindowIndex { header, .. }
            | RepairProtocol::Orphan { header, .. }
            | RepairProtocol::AncestorHashes { header, .. }
            | RepairProtocol::ParentAndFecSetCount { header, .. }
            | RepairProtocol::FecSetRoot { header, .. }
            | RepairProtocol::WindowIndexForBlockId { header, .. } => {
                if &header.recipient != my_id {
                    return Err(Error::from(RepairVerifyError::IdMismatch));
                }
                let time_diff_ms = timestamp().abs_diff(header.timestamp);
                if u128::from(time_diff_ms) > SIGNED_REPAIR_TIME_WINDOW.as_millis() {
                    return Err(Error::from(RepairVerifyError::TimeSkew));
                }
                let Some(leading_buf) = bytes.get(..4) else {
                    debug_assert!(
                        false,
                        "request should have failed deserialization: {request:?}",
                    );
                    return Err(Error::from(RepairVerifyError::Malformed));
                };
                let Some(trailing_buf) = bytes.get(4 + SIGNATURE_BYTES..) else {
                    debug_assert!(
                        false,
                        "request should have failed deserialization: {request:?}",
                    );
                    return Err(Error::from(RepairVerifyError::Malformed));
                };
                let Some(from_id) = request.sender() else {
                    return Err(Error::from(RepairVerifyError::SigVerify));
                };
                let signed_data = [leading_buf, trailing_buf].concat();
                if !header.signature.verify(from_id.as_ref(), &signed_data) {
                    return Err(Error::from(RepairVerifyError::SigVerify));
                }
            }
        }
        Ok(())
    }

    pub fn repair_proto_to_bytes(request: &RepairProtocol, keypair: &Keypair) -> Result<Vec<u8>> {
        debug_assert!(request.supports_signature());
        let mut payload = serialize(&request)?;
        let signable_data = [&payload[..4], &payload[4 + SIGNATURE_BYTES..]].concat();
        let signature = keypair.sign_message(&signable_data[..]);
        payload[4..4 + SIGNATURE_BYTES].copy_from_slice(signature.as_ref());
        Ok(payload)
    }

    /// test run_window_request responds with the right shred, and do not overrun
    pub fn run_highest_window_request(slot: Slot, num_slots: u64, nonce: Nonce) {
        let recycler = PacketBatchRecycler::default();
        agave_logger::setup();
        let ledger_path = get_tmp_ledger_path_auto_delete!();
        let blockstore = Arc::new(Blockstore::open(ledger_path.path()).unwrap());
        let handler = StandardRepairHandler::new(blockstore.clone());
        let rv = handler.run_highest_window_request(&recycler, &socketaddr_any!(), 0, 0, nonce);
        assert!(rv.is_none());

        let _ = fill_blockstore_slot_with_ticks(
            &blockstore,
            max_ticks_per_n_shreds(1, None) + 1,
            slot,
            slot - num_slots + 1,
            Hash::default(),
        );

        let index = 1;
        let mut rv = handler
            .run_highest_window_request(&recycler, &socketaddr_any!(), slot, index, nonce)
            .expect("packets");
        let request = ShredRepairType::HighestShred(slot, index);
        verify_responses(&request, rv.iter());

        let rv: Vec<Shred> = rv
            .iter_mut()
            .map(|mut packet| {
                packet.meta_mut().flags |= PacketFlags::REPAIR;
                let (shred, repair_nonce) =
                    shred::layout::get_shred_and_repair_nonce(packet.as_ref()).unwrap();
                assert_eq!(repair_nonce.unwrap(), nonce);
                Shred::new_from_serialized_shred(shred.to_vec()).unwrap()
            })
            .collect();
        assert!(!rv.is_empty());
        let index = blockstore.meta(slot).unwrap().unwrap().received - 1;
        assert_eq!(rv[0].index(), index as u32);
        assert_eq!(rv[0].slot(), slot);

        let rv = handler.run_highest_window_request(
            &recycler,
            &socketaddr_any!(),
            slot,
            index + 1,
            nonce,
        );
        assert!(rv.is_none());
    }

// Returns false if repair nonce is invalid and packet should be discarded.
#[must_use]
fn verify_repair_nonce(
    packet: PacketRef,
    now: u64, // solana_time_utils::timestamp()
    outstanding_repair_requests: &mut OutstandingShredRepairs,
) -> bool {
    debug_assert!(packet.meta().flags.contains(PacketFlags::REPAIR));
    let Some((shred, Some(nonce))) = shred::layout::get_shred_and_repair_nonce(packet) else {
        return false;
    };
    outstanding_repair_requests
        .register_response(nonce, shred, now, |_| ())
        .is_some()
}
