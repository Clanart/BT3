### Title
Gasless swap deadline is enforced only at mempool admission, not at readiness/promotion or bundling time, allowing stale swaps to be included after expiry - (File: kaiax/gasless/impl/tx_pool.go, kaiax/gasless/impl/getter.go)

### Summary
The gasless module's swap-transaction "deadline" check (analogous to `zcap`'s `expires` check) is implemented in only one of several validation code paths, mirroring the reported bug class of *incomplete expiration checks along different verification chains*. `checkBalanceForSwap` validates `tx.deadline >= currentTimestamp` [1](#0-0) , but this function is only reachable through `GetCheckBalance()`, used at initial transaction-pool admission [2](#0-1) . The core "is this gasless pair valid/executable" logic used everywhere else — `VerifyExecutable`/`IsExecutable` (used by `isSwapTxReady`/`isApproveTxReady` for promotion decisions, and by `ExtractTxBundles` for block-building bundling, and by the public `eth_isGaslessTx`-style RPC) — never re-checks the deadline at all [3](#0-2) .

### Finding Description
`IsExecutable`/`VerifyExecutable` enumerates conditions A1–A4, S1–S3, AP1, SP1–SP4 (token whitelisting, sender match, allowance, nonce sequencing, repay-amount correctness) but includes no deadline/expiry check [4](#0-3) . This function is what gates:
- Promotion readiness (`isSwapTxReady`/`isApproveTxReady`, which call `g.IsExecutable(...)`) [5](#0-4) 
- Block-building bundle extraction (`ExtractTxBundles`, which also calls `g.IsExecutable(...)`) [6](#0-5) 
- The public RPC `IsGaslessTx`, which calls `VerifyExecutable` directly [7](#0-6) 

The only place the deadline is actually validated against the current block time is `checkBalanceForSwap`, reachable exclusively via `GetCheckBalance()` [2](#0-1) , which (per the integration test) fires at initial transaction submission (`sendSwapTx` returns the "insufficient deadline" error synchronously on send, i.e., at pool admission, not on-chain execution) [8](#0-7) .

Because `PreReset` (which purges stale pooled gasless txs) only tracks pool-side timers (`PendingTimeout`, `QueueTimeout`, `KnownTxTimeout`) unrelated to the transaction's own declared `deadline` field [9](#0-8) , a swap transaction that passed the deadline check at admission time (when its nonce was not yet current, i.e., queued behind a pending approve/other tx) can later become "ready" and be promoted/bundled purely based on nonce sequencing and repay-amount arithmetic — with no re-verification that `deadline >= currentBlockTime` at the time of actual promotion/inclusion. This is structurally the same defect pattern as the zcap advisory: the expiration check exists in one validation path but is silently skipped in the "shorter"/alternate path that is actually used to grant execution.

I was not able to further confirm within the available iterations whether the underlying `GaslessSwapRouter.swapForGas` Solidity contract independently re-checks `deadline` on-chain (the contract bytecode is only available in compiled/minified form in the bindings file, not decompiled source) [10](#0-9) . Notably, the test's assertion of the "insufficient deadline" error message text exactly matches the Go-side `checkBalanceForSwap` error string (not a typical Solidity revert reason), which suggests the deadline enforcement observed in the test is the off-chain pool-side check, not an on-chain contract-level guarantee. If the contract does not independently enforce the deadline, the missing recheck in `IsExecutable`/promotion path becomes a direct path to on-chain execution of an expired gasless swap.

### Impact Explanation
If the on-chain `GaslessSwapRouter` contract does not itself enforce `deadline`, an expired gasless swap can still be promoted to `pending` and bundled with a proposer-funded lend transaction (`GetLendTxGenerator`), causing:
- Execution of a swap the user intended to expire, potentially at a stale/unfavorable state, and
- The block proposer's `LendTxGenerator`-funded gas advance being spent on a transaction that should have been rejected, creating settlement/fee-delegation risk for the gasless module's fee-lending mechanism.

Even if `minAmountOut` bounds slippage, allowing execution past the user-declared deadline violates the explicit intent/authorization boundary of the gasless authorization, which is the same class of harm the zcap advisory addresses (execution outside the intended validity window).

### Likelihood Explanation
Reachable by any ordinary gasless user/attacker: submit a swap tx (optionally preceded by an approve tx) with a nonce gap so it sits `queued` past its own deadline, then let it naturally become `ready` once the required nonce/approve conditions are met. No privileged access, node compromise, or consensus-level manipulation is needed — only normal transaction submission timing, which any unprivileged sender or gasless-swap user can control.

### Recommendation
Add an explicit deadline check inside `VerifyExecutable` (or immediately before it is used in `isSwapTxReady`, `isApproveTxReady`, and `ExtractTxBundles`) comparing `swapArgs.Deadline` against the current chain head's timestamp at promotion/bundling time, not only at initial pool admission via `checkBalanceForSwap`. Additionally, verify whether `GaslessSwapRouter.swapForGas` enforces `deadline` on-chain; if not, add that guard so expired swaps revert even if incorrectly bundled.

### Proof of Concept
1. Attacker crafts `ApproveTx` (nonce N) + `SwapTx` (nonce N+1) with `deadline = now + 5s`, satisfying `checkBalanceForSwap` at submission.
2. Attacker ensures `ApproveTx` is delayed (e.g., low gas price) so `SwapTx` remains `queued` (nonce N+1 not yet current) past the 5s deadline.
3. Once `ApproveTx` is finally included/promoted, `isSwapTxReady`/`isApproveTxReady` call `g.IsExecutable(approveTx, swapTx)` [5](#0-4)  — which never checks `swapArgs.Deadline` [3](#0-2)  — so `SwapTx` is promoted and bundled via `ExtractTxBundles` [11](#0-10)  despite its deadline having already elapsed.

func (g *GaslessModule) isApproveTxReady(approveTx, nextTx *types.Transaction) bool {
	addr, err := types.Sender(g.signer, approveTx)
	if err != nil {
		return false
	}
	nonce := g.getCurrentStateNonce(addr)

	if approveTx.Nonce() != nonce {
		return false
	}
	if nextTx == nil || !g.IsSwapTx(nextTx) {
		return false
	}

	return g.IsExecutable(approveTx, nextTx)
}

// isSwapTxReady assumes that the caller checked `g.IsSwapTx(swapTx)`
func (g *GaslessModule) isSwapTxReady(swapTx, prevTx *types.Transaction) bool {
	addr, err := types.Sender(g.signer, swapTx)
	if err != nil {
		return false
	}
	nonce := g.getCurrentStateNonce(addr)

	var approveTx *types.Transaction
	if swapTx.Nonce() == nonce {
		approveTx = nil
	} else if swapTx.Nonce() == nonce+1 {
		if prevTx == nil || !g.IsApproveTx(prevTx) {
			return false
		}
		approveTx = prevTx
	} else {
		return false
	}

	return g.IsExecutable(approveTx, swapTx)
}

// PreReset removes timed out tx from the tx pool and knownTxs.
func (g *GaslessModule) PreReset(oldHead, newHead *types.Header) []common.Hash {
	g.knownTxsMu.Lock()
	defer g.knownTxsMu.Unlock()

	drops := make([]common.Hash, 0)

	for hash, knownTx := range *g.knownTxs {
		// remove pending timed out tx from tx pool
		if knownTx.status == TxStatusPending && knownTx.elapsedPromotedTime() >= PendingTimeout {
			drops = append(drops, hash)
		}
		// remove queue timed out tx from tx pool
		if knownTx.status == TxStatusQueue && knownTx.elapsedAddedTime() >= QueueTimeout {
			drops = append(drops, hash)
		}
		// remove known timed out tx from knownTxs
		if knownTx.elapsedPromotedOrAddedTime() >= KnownTxTimeout {
			g.knownTxs.delete(hash)
		}
	}

	return drops
}

// IsGaslessPattern checks following conditions:
// Ax. IsApproveTx conditions (if ApproveTx != nil)
// Sx. IsSwapTx conditions
// AP1. ApproveTx.from == SwapTx.from

func (g *GaslessModule) IsExecutable(approveTxOrNil, swapTx *types.Transaction) bool {
	err := g.VerifyExecutable(approveTxOrNil, swapTx)
	if err != nil {
		return false
	}
	return true
}

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
}
