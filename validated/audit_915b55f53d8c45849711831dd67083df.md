### Title
Unbounded Gas Fee in Gasless Swap/Approve Transactions Allows Draining the Block Proposer's Balance - ([File: kaiax/gasless/impl/getter.go])

### Summary
The `kaiax/gasless` module lets an unprivileged transaction sender submit a `GaslessApproveTx`/`GaslessSwapTx` pair (or a standalone swap tx) whose gas fee is fronted by the block proposer via an auto-generated `LendTx`. The lend amount is computed directly from the user-supplied `GasPrice`/`GasLimit` of the swap/approve transactions with no upper bound check, analogous to the Starknet report's missing cap on `max_price_per_unit`/fee for a privileged, single-signer-authorized payment flow.

### Finding Description
`lendAmount()` computes the value the proposer must pay to the user as `approveTxOrNil.Fee() + swapTx.Fee()`, where `Fee() = GasPrice * GasLimit` of the user-crafted transactions: [1](#0-0) 

This value is directly used as the `Value` of the `LendTx`, which is signed and paid for by the block proposer's own node key/balance (`g.InitOpts.NodeKey`), not the user: [2](#0-1) 

Critically, gasless transactions bypass the normal sender-balance check that would otherwise limit how much fee a user can "afford," because the tx-pool module hook `GetCheckBalance()` replaces the standard balance check with only token-related checks (`checkBalanceForApprove`/`checkBalanceForSwap`): [3](#0-2) [4](#0-3) 

The classification checks (`IsApproveTx`/`IsSwapTx` and the `A1–A4`, `S1–S3` predicates) only validate token whitelisting, spender/router identity, and the max-approve amount — they impose **no constraint on `GasPrice` or `GasLimit`** of the approve/swap transaction: [5](#0-4) 

Likewise, `checkBalanceForApprove`/`checkBalanceForSwap` (the only balance-related gate applied to these module transactions) validate token balance/allowance/deadline, not gas price bounds: [6](#0-5) 

And `GaslessConfig` exposes only allowed-token lists, bundle-size limits, and a balance-check level — no maximum gas price or maximum lend amount setting exists to bound this exposure: [7](#0-6) 

This mirrors the External Report's bug class exactly: a value-transfer/fee-payment mechanism that is authorized/triggered by an unprivileged party (the escaping Guardian in Starknet; the gasless tx sender here) with no cap on the fee/price fields (`max_price_per_unit`/`tip` there; `GasPrice`/`GasLimit` here), enabling the payer (a "nice" sequencer there; the block proposer here) to be drained.

### Impact Explanation
An unprivileged, gasless-eligible user (any account holding a whitelisted token and minimal token balance) can submit a swap (optionally preceded by an approve) transaction with an artificially inflated `GasPrice` and/or `GasLimit`. When the proposer builds the block, it must generate and fund a `LendTx` transferring `GasPrice * GasLimit` (summed over approve+swap) worth of KAIA from the proposer's own account to the attacker, before the attacker's swap fully repays it in-kind. Since the attacker fully controls the `AmountRepay` field to match `repayAmount()` (which is itself derived from the same attacker-controlled `GasPrice`), the attacker can coordinate the repayment consistency check while extracting real KAIA value from the proposer if the resulting swap/repay economics are unfavorable to the proposer, or exhaust the proposer's balance for legitimate block production. This is a direct, reachable value-extraction/fee-abuse path from a "gasless user"/"public-RPC caller," matching the required in-scope actor set.

### Likelihood Explanation
Likelihood is High: no privileged role, node compromise, or consensus assumption is needed — only crafting a legacy transaction with a whitelisted token/router and an inflated `GasPrice`/`GasLimit`, which any address holding minimal token balance can submit through the standard RPC transaction submission and gasless tx-pool promotion path (`IsModuleTx` → `PreAddTx` → `ExtractTxBundles` → `GetLendTxGenerator`).

### Recommendation
Introduce an explicit upper bound on the gas price and/or total lend amount permitted for `GaslessApproveTx`/`GaslessSwapTx`, analogous to `MAX_ESCAPE_MAX_FEE`/`MAX_ESCAPE_TIP` in the referenced report — e.g., cap `GasPrice` to the current network base fee (KIP-71) plus a bounded tip, and/or cap the total `lendAmount()` the proposer will front per bundle, rejecting transactions (via `isApproveTx`/`isSwapTx` or `checkBalanceForApprove`/`checkBalanceForSwap`) that exceed these limits.

### Proof of Concept
1. Attacker acquires a small balance of a whitelisted gasless token and approves the `swapRouter` for `MaxUint256` via a normal `GaslessApproveTx` (satisfying A1–A4).
2. Attacker crafts a `GaslessSwapTx` calling `swapForGas(token, amountIn, minAmountOut, amountRepay, deadline)` with `amountRepay` computed to satisfy `repayAmount()`, but sets the transaction's `GasPrice` (and/or `GasLimit`) to an extreme value.
3. `checkBalanceForApprove`/`checkBalanceForSwap` (kaiax/gasless/impl/tx_pool.go) only check token balance/allowance/deadline — they never inspect `GasPrice`/`GasLimit`, so the transaction is accepted into the pool.
4. During block building, `GetLendTxGenerator` (kaiax/gasless/impl/getter.go:268-313) computes `lendAmount()` = `approveTx.Fee() + swapTx.Fee()` = attacker-chosen `GasPrice * GasLimit`, and creates/sign a `LendTx` funded by the proposer's node key, transferring that amount to the attacker's address before the swap executes.
5. Repeating this against a proposer with limited balance can exhaust its funds or force it to pay unbounded value to gasless senders, since no ceiling exists on the attacker-chosen fee parameters that drive the lend amount.

// A1. tx.to is a whitelisted ERC20 token.

func (g *GaslessModule) IsApproveTx(tx *types.Transaction) bool {
	args, ok := decodeApproveTx(tx, g.signer)
	return ok && g.isApproveTx(args)
}

func (g *GaslessModule) isApproveTx(args *ApproveArgs) bool {
	g.gaslessInfoMu.RLock()
	defer g.gaslessInfoMu.RUnlock()

	return g.allowedTokens[args.Token] && // A1
		g.swapRouter == args.Spender && // A3
		args.Amount.Cmp(abi.MaxUint256) == 0 // A4
}

// IsSwapTx checks following conditions:

}

func (g *GaslessModule) isSwapTx(args *SwapArgs) bool {
	g.gaslessInfoMu.RLock()
	defer g.gaslessInfoMu.RUnlock()

	return g.swapRouter == args.Router && // S1
		g.allowedTokens[args.Token] // S3
}

func lendAmount(approveTxOrNil, swapTx *types.Transaction) *big.Int {
	r := new(big.Int)

	// R2 = ApproveTx.Fee() if exists
	if approveTxOrNil != nil {
		r.Add(r, approveTxOrNil.Fee())
	}

	// R3 = SwapTx.Fee()
	r.Add(r, swapTx.Fee())

	// LendAmount = R2 + R3
	return r
}

func (g *GaslessModule) GetCheckBalance() func(tx *types.Transaction) error {
	return func(tx *types.Transaction) error {
		if approveArgs, ok := decodeApproveTx(tx, g.signer); ok {
			return g.checkBalanceForApprove(approveArgs)
		}
		if swapArgs, ok := decodeSwapTx(tx, g.signer); ok {
			return g.checkBalanceForSwap(swapArgs, tx.Nonce())
		}
		return errors.New("not a gasless transaction") // should not happen because IsModuleTx is called before GetCheckBalance
	}
}

func (g *GaslessModule) checkBalanceForApprove(approveArgs *ApproveArgs) error {
	token := approveArgs.Token
	bc := backends.NewBlockchainContractBackend(g.Chain, nil, nil)

	if g.GaslessConfig.ShouldCheckSenderCode() {
		if g.getCurrentHasCode(approveArgs.Sender) {
			return errors.New("sender with code is not allowed")
		}
	}

	if g.GaslessConfig.ShouldCheckToken() {
		tokenContract, err := sc_erc20.NewERC20(token, bc)
		if err != nil {
			return err
		}

		// tx.token.balanceOf(sender) > 0
		tokenBalance, err := tokenContract.BalanceOf(nil, approveArgs.Sender)
		if err != nil {
			return err
		}
		if tokenBalance.Sign() <= 0 {
			return fmt.Errorf("insufficient sender token balance: token=%s, have=%s, want=nonzero", token.Hex(), tokenBalance.String())
		}
	}
	return nil
}

// tx.minAmountOut >= tx.amountRepay
// tx.amountIn >= gsr.getAmountIn(minAmountOut)
// tx.token.approval(sender, router) >= tx.amountIn
// tx.token.balanceOf(sender) >= tx.amountIn
// tx.deadline >= currentTimestamp
func (g *GaslessModule) checkBalanceForSwap(swapArgs *SwapArgs, swapNonce uint64) error {
	token := swapArgs.Token
	bc := backends.NewBlockchainContractBackend(g.Chain, nil, nil)

	g.gaslessInfoMu.RLock()
	swapRouter := g.swapRouter
	g.gaslessInfoMu.RUnlock()

	// tx.minAmountOut >= tx.amountRepay
	minAmountOut := swapArgs.MinAmountOut
	amountRepay := swapArgs.AmountRepay
	if minAmountOut.Cmp(amountRepay) < 0 {
		return fmt.Errorf("insufficient minAmountOut: minAmountOut=%s, amountRepay=%s", minAmountOut.String(), amountRepay.String())
	}

	if g.GaslessConfig.ShouldCheckSenderCode() {
		if g.getCurrentHasCode(swapArgs.Sender) {
			return errors.New("sender with code is not allowed")
		}
	}

	if g.GaslessConfig.ShouldCheckSwapAmount() {
		// tx.amountIn >= gsr.getAmountIn(minAmountOut)
		routerContract, err := kip247.NewGaslessSwapRouterCaller(swapRouter, bc)
		if err != nil {
			return err
		}
		// Required token amountIn, given the current exchange rate and the declared minAmountOut.
		requiredAmountIn, err := routerContract.GetAmountIn(nil, token, minAmountOut)
		if err != nil {
			return err
		}
		if swapArgs.AmountIn.Cmp(requiredAmountIn) < 0 {
			return fmt.Errorf("insufficient amountIn: have=%s, want=%s", swapArgs.AmountIn.String(), requiredAmountIn.String())
		}
	}

	if g.GaslessConfig.ShouldCheckToken() {

		tokenContract, err := sc_erc20.NewERC20(token, bc)
		if err != nil {
			return err
		}

		// If SwapTx.nonce is the sender's next nonce, then there is no room for ApproveTx proceeding SwapTx.
		senderNonce := g.getCurrentStateNonce(swapArgs.Sender)
		noApproveTxPreceeds := swapNonce == senderNonce
		if noApproveTxPreceeds {
			// tx.token.allowance(sender, router) >= tx.amountIn
			approval, err := tokenContract.Allowance(nil, swapArgs.Sender, swapRouter)
			if err != nil {
				return err
			}
			if approval.Cmp(swapArgs.AmountIn) < 0 {
				return fmt.Errorf("insufficient approval: approval=%s, want=%s", approval.String(), swapArgs.AmountIn.String())
			}
		}

		// tx.token.balanceOf(sender) >= tx.amountIn
		balance, err := tokenContract.BalanceOf(nil, swapArgs.Sender)
		if err != nil {
			return err
		}
		if balance.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("insufficient balance: balance=%s, want=%s", balance.String(), swapArgs.AmountIn.String())
		}
	}

	// tx.deadline >= currentTimestamp
	deadline := swapArgs.Deadline
	if deadline.Cmp(g.Chain.CurrentBlock().Time()) < 0 {
		return fmt.Errorf("insufficient deadline: deadline=%s, want=%s", deadline.String(), g.Chain.CurrentBlock().Time().String())
	}

	return nil
}

	return &GaslessConfig{

		Disable:               false,
