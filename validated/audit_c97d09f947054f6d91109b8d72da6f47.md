### Title
Stale non-membership timeout proof allows double payment of GET-request fees on `EvmHost` - (File: `evm/src/core/EvmHost.sol` / `evm/src/core/HandlerV2.sol`)

### Summary
`EvmHost.dispatchIncoming(GetResponse,...)` pays out the request's escrowed fee to the delivering relayer but never clears `_requestCommitments[commitment]`. `HandlerV2.handleGetRequestTimeouts` independently authorizes a fee refund for the *same* commitment based solely on a non-membership proof anchored at an **arbitrary, attacker-chosen historical height** taken from `_stateCommitments`, without ever checking whether a response has since been delivered on this same host. Because old heights are retained forever in `_stateCommitments`, an attacker can submit a stale, pre-response non-membership proof after the response has already been paid, triggering a second payout of the same fee.

### Finding Description
Two independent, non-cross-checking payment paths exist for the same `_requestCommitments[commitment]` entry:

1. **Response delivery path** – `EvmHost.dispatchIncoming(GetResponse, relayer)`: [1](#0-0) 
On success it pays `_requestCommitments[commitment].fee` to the relayer, but it **never deletes `_requestCommitments[commitment]`**.

2. **Timeout path** – `EvmHost.dispatchTimeOut(GetRequestTimeout,...)`: [2](#0-1) 
This deletes `_requestCommitments[commitment]` and, on a successful `onGetTimeout` callback, refunds `meta.fee` to `meta.sender` (the original payer). It performs **no check** against `_responseReceipts` (which would prove a response was already delivered).

The gating logic in `HandlerV2.handleGetRequestTimeouts` only requires: [3](#0-2) 
- `request.timeout() <= state.timestamp` for the *chosen* height `message.height`
- a non-membership proof of the response receipt key against `host.stateMachineCommitment(message.height).stateRoot`

Crucially, `message.height` can be **any previously committed height**: `EvmHost._stateCommitments[stateMachineId][height]` is a plain mapping that is never pruned once written (only `_vetoes` can invalidate a specific height, which requires the fisherman flow), and `stateMachineCommitmentUpdateTime` only enforces a *minimum* delay (challenge period elapsed), not recency: [4](#0-3) 

Compare this with the response-delivery path, `handleGetResponses`, which verifies responses via an **overlay MMR root** at `message.proof.height` and separately guards against duplicates using the *live* `_responseReceipts` mapping: [5](#0-4) 

Because the timeout path never consults `_responseReceipts`, an attacker can:
1. Wait until a response for a GET request has been legitimately delivered via `handleGetResponses`/`dispatchIncoming(GetResponse,...)`, paying the fee to the relayer.
2. Find (or already have) a historical height `H_old` in `_stateCommitments` whose `state.timestamp` is already past `request.timeout()` (a normal, satisfiable condition near a request's expiry) but whose state predates the response being recorded — i.e., a window that legitimately existed before the response was delivered.
3. Fetch a genuine non-membership proof for the response-receipt key at `H_old` (this is a real proof of a real historical state; no forged proof needed) and submit it via `handleGetRequestTimeouts`.
4. `dispatchTimeOut` succeeds because `meta.sender != address(0)` (the commitment metadata was never removed by the response path) and the non-membership proof at `H_old` validates. The fee is paid a **second time**, to `meta.sender`.

This is a case of "false state acceptance" in the sense required by the bounty scope: a proof that was true *at a past height* is accepted as authoritative for the *current* protocol state, even though a subsequent, more recent commitment already falsifies it (the response now exists). The host has all the state needed (`_responseReceipts`) to detect this locally and refuses to check it.

### Impact Explanation
This directly causes double-settlement of protocol funds: the same `feeToken` fee is disbursed twice for one GET request — once to the relayer that delivered the response, and once to the original fee payer via the stale timeout. This drains the `EvmHost`'s fee-token balance, which was funded to cover exactly one payout per request, matching the bounty's "double-claim/double-settlement" and "false proof/state acceptance" categories. No relayer, prover, admin, or governance compromise is required — the exploit path requires only a routine, honestly-obtained non-membership proof for a height that a normal, unprivileged caller may already hold or query.

### Likelihood Explanation
`handleGetRequestTimeouts` is a permissionless, public entrypoint (`external`, gated only by `notFrozen`). The only preconditions are: (a) the GET request's timeout has elapsed relative to *some* historical Hyperbridge height that the `EvmHost` has ever committed, and (b) a genuine non-membership proof for that height (obtainable off-chain from any archive node/light client of Hyperbridge, since `_stateCommitments` for old heights is retained indefinitely). Given that responses frequently arrive close to or slightly after nominal timeouts (especially under load or relayer latency), the window where "not yet responded at H_old" but "responded by now" is realistic and not contrived. No collusion or privileged role is needed.

### Recommendation
- In `dispatchIncoming(GetResponse, relayer)`, delete `_requestCommitments[commitment]` after paying the fee (mirroring the delete-on-consumption pattern already used in `dispatchTimeOut`), so a later timeout dispatch sees `meta.sender == address(0)` and reverts with `UnknownMessage`.
- Additionally/defense-in-depth: in `dispatchTimeOut(GetRequestTimeout,...)`, explicitly check `_responseReceipts[commitment].relayer == address(0)` before processing the timeout, and revert if a response has already been recorded, regardless of which height's proof is presented.
- Consider bounding the acceptable heights for non-membership timeout proofs to the latest known height (or requiring the proof height to be at or after the current watermark) rather than any historically committed height.

### Proof of Concept
1. Alice dispatches a `GetRequest` `R` from `EvmHost` with fee `F` (escrowed in `_requestCommitments[commitment(R)]`), timeout `T`.
2. Hyperbridge processes `R`; shortly after `T`, the response for `R` becomes available and a relayer submits it via `HandlerV2.handleGetResponses`, which calls `EvmHost.dispatchIncoming(GetResponse, relayer)`. Fee `F` is paid to `relayer`; `_requestCommitments[commitment(R)]` is left intact (bug).
3. Mallory (anyone) queries Hyperbridge's own historical trie for a height `H_old` that Hyperbridge's own consensus committed to this `EvmHost` (`_stateCommitments[hyperbridgeId][H_old]`) at a time before the response for `R` existed in Hyperbridge's `RESPONSE_RECEIPTS_STORAGE_PREFIX` child-trie, but where `state.timestamp(H_old) >= T`.
4. Mallory builds a `GetTimeoutMessage` with `height = H_old` and a valid non-membership proof of the response-receipt key for `commitment(R)` at that height, and calls `HandlerV2.handleGetRequestTimeouts`.
5. Checks pass: `request.timeout() <= state.timestamp(H_old)`; `meta.sender != address(0)` (still set from step 1); non-membership proof verifies against `state.stateRoot(H_old)`.
6. `EvmHost.dispatchTimeOut` executes, deletes `_requestCommitments[commitment(R)]`, invokes `onGetTimeout` on Alice's module, and (assuming the callback succeeds) refunds fee `F` again to `meta.sender` (Alice) — a second payout of the same escrowed fee, draining `F` extra from the host's fee-token holdings beyond what was ever collected for `R`.

    function dispatchIncoming(GetResponse memory response, address relayer) external restrict(_hostParams.handler) {
        // replay protection
        bytes32 commitment = response.request.hash();
        _responseReceipts[commitment] = ResponseReceipt({
            relayer: relayer,
            responseCommitment: response.hash()
        });

        (bool success,) = _bytesToAddress(response.request.from)
            .call(abi.encodeWithSelector(IApp.onGetResponse.selector, IncomingGetResponse(response, relayer)));

        if (!success) {
            // so that it can be retried
            delete _responseReceipts[commitment];
            return;
        }

        // reward the relayer fee
        uint256 fee = _requestCommitments[commitment].fee;
        if (fee != 0) {
            IERC20(feeToken()).safeTransfer(relayer, fee);
        }
        emit GetRequestHandled({commitment: commitment, relayer: relayer});
    }

        delete _requestCommitments[commitment];

            .call(abi.encodeWithSelector(IApp.onGetTimeout.selector, timeout));

        if (!success) {
            // so that it can be retried
            _requestCommitments[commitment] = meta;
            return;
        }

        if (meta.fee != 0) {
            // refund relayer fee
            IERC20(feeToken()).safeTransfer(meta.sender, meta.fee);
        }
        emit GetRequestTimeoutHandled({commitment: commitment, dest: string(timeout.request.dest)});
    }

    function handleGetResponses(IHost host, GetResponseMessage calldata message) external notFrozen(host) {
        uint256 timestamp = block.timestamp;
        uint256 delay = timestamp - host.stateMachineCommitmentUpdateTime(message.proof.height);
        uint256 challengePeriod = host.challengePeriod();
        if (challengePeriod != 0 && challengePeriod > delay) revert ChallengePeriodNotElapsed();

        uint256 responsesLength = message.responses.length;
        MerkleMountainRange.Leaf[] memory leaves = new MerkleMountainRange.Leaf[](responsesLength);

        for (uint256 i = 0; i < responsesLength; ++i) {
            GetResponseLeaf memory leaf = message.responses[i];
            // don't check for timeouts because it's checked on Hyperbridge

            // known request? also serves as source check
            FeeMetadata memory meta = host.requestCommitments(leaf.response.request.hash());
            if (meta.sender == address(0)) revert UnknownMessage();
            leaves[i] = MerkleMountainRange.Leaf(leaf.index, leaf.response.hash());
        }

        bytes32 root = host.stateMachineCommitment(message.proof.height).overlayRoot;
        if (root == bytes32(0)) revert StateCommitmentNotFound();
        bool valid = MerkleMountainRange.VerifyProof(root, message.proof.multiproof, leaves, message.proof.leafCount);
        if (!valid) revert InvalidProof();

        for (uint256 i = 0; i < responsesLength; ++i) {
            GetResponseLeaf memory leaf = message.responses[i];
            // duplicate response?
            if (host.responseReceipts(leaf.response.request.hash()).relayer != address(0)) revert DuplicateMessage();
            host.dispatchIncoming(leaf.response, _msgSender());
        }
    }

    function handleGetRequestTimeouts(IHost host, GetTimeoutMessage calldata message) external notFrozen(host) {
        uint256 delay = block.timestamp - host.stateMachineCommitmentUpdateTime(message.height);
        uint256 challengePeriod = host.challengePeriod();
        if (challengePeriod != 0 && challengePeriod > delay) revert ChallengePeriodNotElapsed();

        // fetch the state commitment
        StateCommitment memory state = host.stateMachineCommitment(message.height);
        if (state.stateRoot == bytes32(0)) revert StateCommitmentNotFound();
        uint256 timeoutsLength = message.timeouts.length;

        for (uint256 i = 0; i < timeoutsLength; ++i) {
            GetRequest memory request = message.timeouts[i];
            // timed-out?
            if (request.timeout() > state.timestamp) revert MessageNotTimedOut();

            bytes32 commitment = request.hash();
            FeeMetadata memory meta = host.requestCommitments(commitment);
            if (meta.sender == address(0)) revert UnknownMessage();

            bytes[] memory keys = new bytes[](1);
            keys[0] = bytes.concat(RESPONSE_RECEIPTS_STORAGE_PREFIX, commitment);

            // verify state trie non-membership proofs
            PolkadotTrie.StorageValue memory entry = PolkadotTrie.VerifyProof(state.stateRoot, message.proof, keys)[0];
            if (entry.value.length != 0) revert InvalidProof();

            host.dispatchTimeOut(GetRequestTimeout(request, _msgSender()), meta, commitment);
        }
    }
