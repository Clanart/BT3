### Title
Permanent pointer-namespace squatting via `MsgRegisterPointer` for non-existent/non-conforming ERC contracts - ([File: x/evm/keeper/msg_server.go])

### Summary
`MsgRegisterPointer` lets any transaction sender register a CosmWasm pointer contract for an arbitrary `ErcAddress` (ERC20/ERC721/ERC1155) with no validation that the address actually contains a contract, let alone one implementing the claimed token standard. This mirrors the reported `ConcreteStorage.updateAccessControl` bug class: a critical, permanently-recorded external reference is accepted and persisted without any conformance check on the referenced contract.

### Finding Description
`msgServer.RegisterPointer` [1](#0-0)  only checks whether a pointer already exists for `msg.ErcAddress`/`PointerType`, then immediately builds an instantiate payload keyed purely off the caller-supplied `ErcAddress` string [2](#0-1) , and persists the mapping via `SetCW20ERC20Pointer` / `SetCW721ERC721Pointer` / `SetCW1155ERC1155Pointer` [3](#0-2) .

`MsgRegisterPointer.ValidateBasic()` only checks the sender is a valid bech32 address and that `ErcAddress` is a syntactically valid hex address — it never checks that code exists at that address or that it implements the expected ERC standard [4](#0-3) . Unlike the `AddCW20` pointer precompile path, which at least performs a `QuerySmart(... "token_info" ...)` round-trip against a CosmWasm contract to obtain `name`/`symbol` before creating the pointer [5](#0-4) , the `RegisterPointer` Cosmos message path (used to wrap an EVM ERC20/721/1155 contract with a CW pointer) performs no equivalent existence/interface check on `msg.ErcAddress` at all — it does not call `evm.StateDB.GetCode`, does not attempt an ERC165 `supportsInterface` probe, and does not verify the address is even a contract (it could be an EOA or an address with no deployed code yet).

Once a pointer for a given `(PointerType, ErcAddress)` pair is created, subsequent `RegisterPointer` calls for that same pair are rejected unless the caller wants to "upgrade" to a newer pointer code version (`existingVersion >= currentVersion` check) [6](#0-5) , and the pointer info is written to permanent chain state.

### Impact Explanation
Any unprivileged EVM/Cosmos transaction sender can permanently squat the CW pointer registry slot for any hex address — including addresses of tokens that do not yet exist, or that are not the type claimed (e.g. registering an EOA or a plain non-ERC contract as an "ERC721" pointee). Because the registry check is keyed solely on `(PointerType, ErcAddress)` and no interface conformance is verified, this permanently blocks the real token contract (once deployed to that address, e.g. via deterministic CREATE2 deployment plans) from ever obtaining a legitimate, functioning CW pointer, since the slot is already considered "registered" at the current version. This is a permanent freezing/denial-of-service of expected pointer functionality for the affected token, which downstream integrations (wallets, CW-side consumers) rely on to interact with the EVM-side asset via CosmWasm.

### Likelihood Explanation
The message is fully permissionless — reachable by any account able to submit a signed Cosmos transaction (`MsgRegisterPointer`), with the only gate being `GetRegisterPointerDisabled` param check [7](#0-6) , which is enabled by default in normal chain configuration. No special privilege, fee threshold, or interface check makes this hard to exploit; an attacker can pre-register pointer slots for many well-known or predictable addresses cheaply.

### Recommendation
Before instantiating and persisting a pointer for `msg.ErcAddress`, validate that the address actually contains contract code and that it exposes the interface behavior expected for the declared `PointerType` (e.g., an ERC165 `supportsInterface` check for ERC721/ERC1155, or a best-effort static call to a canonical ERC20 view function such as `decimals()`/`totalSupply()` for ERC20), analogous to the `require`-based conformance check the report's remediation applied to `ConcreteStorage.updateAccessControl`. Reject registration with a clear error if the address has no code or fails the interface probe.

### Proof of Concept
1. Pick a hex address `X` with no deployed code (or an address predicted to later host an ERC721 contract via deterministic deployment).
2. Submit `MsgRegisterPointer{Sender: attacker, PointerType: PointerType_ERC721, ErcAddress: X}`.
3. `RegisterPointer` finds no existing pointer, instantiates a CW721 pointer wrapping `X`, and calls `SetCW721ERC721Pointer(ctx, X, pointerAddr)` — succeeding with no validation that `X` is a contract or implements ERC721 [8](#0-7) .
4. Later, the legitimate ERC721 contract is deployed to `X`. Any subsequent `RegisterPointer` call for `(ERC721, X)` is rejected because `existingVersion >= currentVersion` [6](#0-5) , permanently denying the real token a functioning CW pointer at the version created by the legitimate deployer.

func (server msgServer) RegisterPointer(goCtx context.Context, msg *types.MsgRegisterPointer) (*types.MsgRegisterPointerResponse, error) {
	ctx := sdk.UnwrapSDKContext(goCtx)
	if server.GetRegisterPointerDisabled(ctx) {
		return nil, fmt.Errorf("registering CW->ERC pointers has been disabled")
	}
	var existingPointer sdk.AccAddress
	var existingVersion uint16
	var currentVersion uint16
	var exists bool
	switch msg.PointerType {
	case types.PointerType_ERC20:
		currentVersion = erc20.CurrentVersion
		existingPointer, existingVersion, exists = server.GetCW20ERC20Pointer(ctx, common.HexToAddress(msg.ErcAddress))
	case types.PointerType_ERC721:
		currentVersion = erc721.CurrentVersion
		existingPointer, existingVersion, exists = server.GetCW721ERC721Pointer(ctx, common.HexToAddress(msg.ErcAddress))
	case types.PointerType_ERC1155:
		currentVersion = erc1155.CurrentVersion
		existingPointer, existingVersion, exists = server.GetCW1155ERC1155Pointer(ctx, common.HexToAddress(msg.ErcAddress))
	default:
		panic("unknown pointer type")
	}
	if exists && existingVersion >= currentVersion {
		return nil, fmt.Errorf("pointer %s already registered at version %d", existingPointer.String(), existingVersion)
	}
	payload := map[string]interface{}{}
	switch msg.PointerType {
	case types.PointerType_ERC20:
		payload["erc20_address"] = msg.ErcAddress
	case types.PointerType_ERC721:
		payload["erc721_address"] = msg.ErcAddress
	case types.PointerType_ERC1155:
		payload["erc1155_address"] = msg.ErcAddress
	default:
		panic("unknown pointer type")
	}
	codeID := server.GetStoredPointerCodeID(ctx, msg.PointerType)
	moduleAcct := server.accountKeeper.GetModuleAddress(types.ModuleName)
	var err error
	var pointerAddr sdk.AccAddress
	if exists {
		bz, _ := json.Marshal(map[string]interface{}{})
		pointerAddr = existingPointer
		_, err = server.wasmKeeper.Migrate(ctx, existingPointer, moduleAcct, codeID, bz)
	} else {
		bz, jerr := json.Marshal(payload)
		if jerr != nil {
			return nil, jerr
		}
		pointerAddr, _, err = server.wasmKeeper.Instantiate(ctx, codeID, moduleAcct, moduleAcct, bz, fmt.Sprintf("Pointer of %s", msg.ErcAddress), sdk.NewCoins())
	}
	if err != nil {
		return nil, err
	}
	switch msg.PointerType {
	case types.PointerType_ERC20:
		err = server.SetCW20ERC20Pointer(ctx, common.HexToAddress(msg.ErcAddress), pointerAddr.String())
		ctx.EventManager().EmitEvent(sdk.NewEvent(
			types.EventTypePointerRegistered, sdk.NewAttribute(types.AttributeKeyPointerType, "erc20"),
			sdk.NewAttribute(types.AttributeKeyPointerAddress, pointerAddr.String()), sdk.NewAttribute(types.AttributeKeyPointee, msg.ErcAddress),
			sdk.NewAttribute(types.AttributeKeyPointerVersion, fmt.Sprintf("%d", erc20.CurrentVersion))))
	case types.PointerType_ERC721:
		err = server.SetCW721ERC721Pointer(ctx, common.HexToAddress(msg.ErcAddress), pointerAddr.String())
		ctx.EventManager().EmitEvent(sdk.NewEvent(
			types.EventTypePointerRegistered, sdk.NewAttribute(types.AttributeKeyPointerType, "erc721"),
			sdk.NewAttribute(types.AttributeKeyPointerAddress, pointerAddr.String()), sdk.NewAttribute(types.AttributeKeyPointee, msg.ErcAddress),
			sdk.NewAttribute(types.AttributeKeyPointerVersion, fmt.Sprintf("%d", erc721.CurrentVersion))))
	case types.PointerType_ERC1155:
		err = server.SetCW1155ERC1155Pointer(ctx, common.HexToAddress(msg.ErcAddress), pointerAddr.String())
		ctx.EventManager().EmitEvent(sdk.NewEvent(
			types.EventTypePointerRegistered, sdk.NewAttribute(types.AttributeKeyPointerType, "erc1155"),
			sdk.NewAttribute(types.AttributeKeyPointerAddress, pointerAddr.String()), sdk.NewAttribute(types.AttributeKeyPointee, msg.ErcAddress),
			sdk.NewAttribute(types.AttributeKeyPointerVersion, fmt.Sprintf("%d", erc1155.CurrentVersion))))
	default:
		panic("unknown pointer type")
	}
	return &types.MsgRegisterPointerResponse{PointerAddress: pointerAddr.String()}, err

func (msg *MsgRegisterPointer) ValidateBasic() error {
	_, err := sdk.AccAddressFromBech32(msg.Sender)
	if err != nil {
		return sdkerrors.Wrapf(sdkerrors.ErrInvalidAddress, "Invalid sender address (%s)", err)
	}

	if !common.IsHexAddress(msg.ErcAddress) {
		return sdkerrors.ErrInvalidAddress
	}

	return nil
}

func (p PrecompileExecutor) AddNative(ctx sdk.Context, method *ethabi.Method, caller common.Address, args []interface{}, value *big.Int, evm *vm.EVM, hooks *tracing.Hooks) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}
	if err := pcommon.ValidateArgsLength(args, 1); err != nil {
		return nil, 0, err
	}
	token := args[0].(string)
	metadata, metadataExists := p.bankKeeper.GetDenomMetaData(ctx, token)
	if !metadataExists {
		return nil, 0, fmt.Errorf("denom %s does not have metadata stored and thus can only have its pointer set through gov proposal", token)
	}
	name := metadata.Name
	symbol := metadata.Symbol
	var decimals uint8
	for _, denomUnit := range metadata.DenomUnits {
		if denomUnit.Exponent > uint32(decimals) && denomUnit.Exponent <= math.MaxUint8 {
			decimals = uint8(denomUnit.Exponent)
			name = denomUnit.Denom
			symbol = denomUnit.Denom
			if len(denomUnit.Aliases) > 0 {
				name = denomUnit.Aliases[0]
			}
		}
	}
	contractAddr, err := p.evmKeeper.UpsertERCNativePointer(ctx, evm, token, utils.ERCMetadata{Name: name, Symbol: symbol, Decimals: decimals})
	if err != nil {
		return nil, 0, err
	}

	ret, err = method.Outputs.Pack(contractAddr)
	remainingGas = pcommon.GetRemainingGas(ctx, p.evmKeeper)
	return
}
