### Title
Gasless LendTx sends KAIA to an unvalidated user-controlled recipient, letting a griefing user force the proposer to waste gas — ([File: kaiax/gasless/impl/getter.go])

### Summary
`GetLendTxGenerator` in the gasless (KIP-247) module builds a `LendTx` that transfers native KAIA directly from the block proposer's node key to `SwapTx.from` with no validation that this address can actually accept a plain value transfer, mirroring the reported pattern of transferring funds to an unvalidated/untrusted recipient that can be made to permanently reject the transfer.

### Finding Description
`GetLendTxGenerator` constructs the lend transaction with `to = types.Sender(signer, swapTx)` (the gasless swap sender) and `value = lendAmount(...)`, then signs it with the proposer's node key: [1](#0-0) 

There is no check anywhere in `VerifyExecutable`/`IsExecutable` that the recipient address is capable of receiving a bare value transfer (e.g., that it has no code, or that any installed code has a payable receive/fallback): [2](#0-1) 

The recipient (`SwapTx.from`) is attacker-controlled: it is the address of the user submitting the `GaslessApproveTx`/`GaslessSwapTx` pair. Kaia supports EIP-7702-style code delegation for EOA-controlled addresses (`validate7702` checks are present throughout the value-transfer tx types, e.g. `TxInternalDataFeeDelegatedValueTransfer.Validate`): [3](#0-2) 

A user can therefore delegate code to their own address that has no payable `receive()`/`fallback()` (or one that always reverts), then submit a valid `GaslessApproveTx` + `GaslessSwapTx` pair. When the proposer's builder detects the pair via `ExtractTxBundles`, it unconditionally prepends the `LendTxGenerator` to the bundle: [4](#0-3) 

Because the recipient's delegated code reverts on the plain-value `CALL`, the generated `LendTx` will fail whenever the proposer tries to include this bundle. Since `IsExecutable`/`VerifyExecutable` only check token/amount/nonce conditions and never simulate or validate that the recipient can accept the KAIA transfer, this failure is not filtered out before block-building, and the proposer repeatedly wastes computation/gas attempting to build and include the doomed bundle for as long as the two gasless transactions remain pending (analogous to the reported `SellOrderProcessor`/`BuyOrderIssuer` "recipient never validated" root cause).

### Impact Explanation
Every block-building attempt that detects this crafted Approve/Swap pair triggers construction, signing, and (attempted) execution of a `LendTx` funded and signed by the proposer's own key, which will revert. This forces the block proposer (the "operator" analog) to repeatedly waste computation and potentially gas/fee-relevant resources rebuilding bundles across multiple blocks while the pending gasless pair persists in the pool, degrading proposer efficiency and providing a low-cost griefing vector against any Kaia CN. This matches the Medium-severity impact class in the reference report (gas-wasting force via an unvalidated, attacker-poisoned recipient), though it does not directly enable fund theft.

### Likelihood Explanation
Reachable by a single unprivileged user: they only need to (1) install delegated code at their own address that rejects bare value transfers (feasible via a 7702-style authorization, supported by this codebase's `validate7702` checks), and (2) submit a syntactically valid `GaslessApproveTx` + `GaslessSwapTx` pair meeting `VerifyExecutable`'s existing checks. No special privileges, validator collusion, or race conditions are required — this is purely a crafted-transaction attack usable by any transaction sender.

### Recommendation
Before including the `LendTxGenerator` in a bundle (or before signing/broadcasting the `LendTx`), validate that the recipient (`SwapTx.from`) can accept a plain KAIA transfer — e.g., reject/skip the gasless pair if the recipient address has contract code installed (via `StateDB.GetCodeSize`) that is not a plain EOA, or simulate the `LendTx` execution and drop the bundle (without penalizing the proposer) if it would revert, similar to how the reference report recommends rejecting orders with unvalidated/blocklistable recipients up front.

### Proof of Concept
1. Attacker submits a 7702-style authorization/tx that installs contract code with no payable `receive`/`fallback` (always reverts on plain value transfer) at their own EOA address `A`.
2. Attacker signs and submits `GaslessApproveTx` and `GaslessSwapTx` from `A` satisfying `VerifyExecutable`'s checks (whitelisted token/router, correct nonce sequencing, correct `AmountRepay`), per: [2](#0-1) 
3. On each block-building attempt while these two txs remain pending, `ExtractTxBundles` calls `GetLendTxGenerator(approveTx, swapTx)`, producing and signing a `LendTx` to `A`: [5](#0-4) [1](#0-0) 
4. Execution of `LendTx` reverts because `A`'s delegated code rejects the value transfer, wasting the proposer's effort rebuilding/re-attempting the bundle across subsequent blocks, with no mechanism in the module to detect and permanently exclude the crafted, unpayable recipient.

**Uncertainty note:** I could not find in this repo a full runtime trace of what specifically happens to the enclosing block/bundle when the generated `LendTx` reverts during actual block sealing (e.g., whether the whole bundle is dropped cleanly after one wasted attempt, or retried every block) — that logic lives in the `work/builder` package, which I did not have visibility into in enough depth via the available search results to confirm the exact retry cadence. This affects the precise severity/likelihood of repeated waste but does not change the underlying root cause (missing recipient validation for a native-value transfer funded by the proposer).

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

func (g *GaslessModule) GetLendTxGenerator(approveTxOrNil, swapTx *types.Transaction) *builder.TxOrGen {
	var src []byte
	if approveTxOrNil != nil {
		src = append(src, approveTxOrNil.Hash().Bytes()...)
	}
	src = append(src, swapTx.Hash().Bytes()...)
	bundleHash := crypto.Keccak256Hash(src)

	gen := func(nonce uint64) (*types.Transaction, error) {
		var (
			chainId = g.InitOpts.ChainConfig.ChainID
			signer  = types.LatestSignerForChainID(chainId)
			key     = g.InitOpts.NodeKey
		)

		to, err := types.Sender(signer, swapTx)
		if err != nil {
			return nil, err
		}

		tx, err := types.NewTransactionWithMap(types.TxTypeEthereumDynamicFee, map[types.TxValueKeyType]interface{}{
			types.TxValueKeyNonce:      nonce,
			types.TxValueKeyTo:         &to,
			types.TxValueKeyAmount:     lendAmount(approveTxOrNil, swapTx),
			types.TxValueKeyData:       common.Hex2Bytes("0x"),
			types.TxValueKeyGasLimit:   params.TxGas,
			types.TxValueKeyGasFeeCap:  swapTx.GasFeeCap(),
			types.TxValueKeyGasTipCap:  swapTx.GasTipCap(),
			types.TxValueKeyAccessList: types.AccessList{},
			types.TxValueKeyChainID:    chainId,
		})
		if err != nil {
			return nil, err
		}

		err = tx.Sign(signer, key)
		return tx, err
	}

	return builder.NewTxOrGenFromGen(gen, bundleHash)
}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
}
