## Title
Stale Off-Chain Balance/Allowance Checks in Gasless Module Allow Unbacked LendTx Payout - ([File: kaiax/gasless/impl/tx_pool.go])

### Summary
The Kaia gasless-transaction module lends real KAIA gas fees to a sender (via a proposer-signed `LendTx`) based on an ERC-20 token balance/allowance check performed once against the tx-pool's snapshot state, without re-validating that balance/allowance at the moment the `LendTx`+`SwapTx` bundle is actually assembled and committed into a block. This mirrors the reported `BoostController` bug class: a value/authorization check performed once, with no re-check before the party actually benefits.

### Finding Description
`GaslessModule.checkBalanceForSwap` and `checkBalanceForApprove` verify the sender's token balance and router allowance against `g.Chain`'s *current* state at admission/filter time: [1](#0-0) 

These functions are invoked only through `GetCheckBalance()`, which is wired into `TxPool.validateTx` (on `AddRemote`/`AddLocal`) and `txList.Filter` (during periodic re-filtering): [2](#0-1) [3](#0-2) 

Separately, `GaslessModule.ExtractTxBundles` builds the actual `[LendTx, ApproveTx?, SwapTx]` bundle that a proposer commits to a block, calling `GetLendTxGenerator` to synthesize a real-value `LendTx` (proposer → sender) purely from the fee arithmetic of the approve/swap transactions, with **no on-chain balance/allowance re-check at bundle-construction time**: [4](#0-3) [5](#0-4) 

`VerifyExecutable`/`IsExecutable` (used both by `IsReady` for promotion and by `ExtractTxBundles`) re-validate nonce sequencing and the `RepayAmount` arithmetic, but never re-check the sender's live ERC-20 `balanceOf`/`allowance` — that check exists only in `checkBalanceForSwap`, which is gated behind `ShouldCheckToken()` and is only invoked from the tx-pool path, not from `VerifyExecutable`/bundle extraction: [6](#0-5) 

Between the moment `checkBalanceForSwap` passes (against pool head state) and the moment the block containing the `LendTx`+`SwapTx` bundle is actually built/committed, the sender's token balance or router allowance can change (e.g., the sender transfers away the token or revokes/reduces the approval in an intervening transaction, or simply because the tx pool's `currentState` lags behind the block being assembled). If the actual `swapForGas` call on-chain then fails to pull enough tokens to cover `amountRepay`, the `LendTx` — a real, unconditional KAIA transfer to the sender — has already been included by `builder.NewBundle`, and `Bundle.IsConflict`/`TargetRequired` semantics govern only mempool-bundle conflict resolution, not on-chain atomicity between the `LendTx` and the `SwapTx`'s success. This is the same class of defect as `BoostController.delegateBoost`: a point-in-time authorization/collateral check that is not continuously enforced up to the point of value transfer.

### Impact Explanation
If the on-chain `GaslessSwapRouter.swapForGas` contract does not itself robustly enforce that the swap can fully repay the lent amount (this repo does not contain that contract's Solidity source, so its independent enforcement cannot be verified here), a malicious gasless-tx sender could receive proposer-funded KAIA via `LendTx` without providing sufficient token collateral, resulting in the proposer being repaid less than lent — i.e., unauthorized value extraction from the block proposer's fee-lending flow. This is a Medium/High-severity fee/gasless-settlement abuse, matching the "gasless and auction settlement theft" category explicitly in scope.

### Likelihood Explanation
Exploitability depends on an attacker's ability to race a balance/allowance-reducing transaction between the mempool admission check and the final block-committing check, or exploiting propagation lag between tx-pool `currentState` and the actual state at inclusion (particularly across reorgs/`PostReset`, or when `BalanceCheckLevel` is configured below `BalanceCheckLevelTokenBalanceAndAllowance`, in which case `ShouldCheckToken()` skips the check entirely). Whether this is actually exploitable end-to-end hinges on whether the deployed `GaslessSwapRouter` contract independently re-validates and reverts atomically with the `LendTx` — code this index does not contain, so I cannot confirm or rule out an on-chain safety net.

### Recommendation
1. Re-validate the sender's token balance/allowance against the state that will actually be used at block-commit time (immediately before `GetLendTxGenerator` produces the `LendTx`), not only at tx-pool admission.
2. Ensure `BalanceCheckLevel` cannot be configured to skip the token check when gasless lending is enabled, or make the check mandatory regardless of `BalanceCheckLevelFlag`.
3. Ensure the on-chain `swapForGas` execution and the `LendTx` value transfer are atomic within the bundle (i.e., the `LendTx` should be conditioned on—or reversible with—`SwapTx` success), rather than relying solely on off-chain pre-checks.

### Proof of Concept
Conceptual sequence (cannot be fully substantiated without the `GaslessSwapRouter` Solidity source, which is outside this index):
1. Sender submits `ApproveTx` (max allowance) + `SwapTx` referencing token `T`; `checkBalanceForApprove`/`checkBalanceForSwap` pass because sender currently holds sufficient `T` and allowance, per `kaiax/gasless/impl/tx_pool.go:144-172`.
2. Sender (or a colluding party) submits a third-party transaction transferring away `T` or calling `approve(router, 0)`, landing in an earlier position within the same block or a block built from more recent state than the pool's cached check.
3. Proposer's `ExtractTxBundles` (`kaiax/gasless/impl/builder.go:28-72`) still bundles `[LendTx, ApproveTx, SwapTx]` because `IsExecutable`/`VerifyExecutable` (`kaiax/gasless/impl/getter.go:211-266`) never re-checks live token balance/allowance — only nonce ordering and repay-amount arithmetic.
4. `LendTx` unconditionally transfers real KAIA to the sender; `SwapTx` fails or repays less than `amountRepay` on-chain if the router doesn't independently enforce sufficiency, leaving the proposer under-repaid.

func (g *GaslessModule) GetCheckBalance() func(tx *types.Transaction) error {
	return func(tx *types.Transaction) error {
		if approveArgs, ok := decodeApproveTx(tx, g.signer); ok {
			return g.checkBalanceForApprove(approveArgs)
		}
		if swapArgs, ok := decodeSwapTx(tx, g.signer); ok {
			return g.checkBalanceForSwap(swapArgs, tx.Nonce())
		}
		return errors.New("not a gasless transaction") // should not happen because IsModuleTx is called before GetCheckBalance
	}
}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
}

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

// MakeLendTx creates a transaction with following properties:
// L1. LendTx.type = 0x7802 (TxTypeEthereumDynamicFee)
// L2. LendTx.from = proposer
// L3. LendTx.to = SwapTx.from
// L4. LendTx.value = LendAmount(approveTxOrNil, swapTx)
func (g *GaslessModule) GetLendTxGenerator(approveTxOrNil, swapTx *types.Transaction) *builder.TxOrGen {
	var src []byte
	if approveTxOrNil != nil {
		src = append(src, approveTxOrNil.Hash().Bytes()...)
	}
	src = append(src, swapTx.Hash().Bytes()...)
	bundleHash := crypto.Keccak256Hash(src)

	gen := func(nonce uint64) (*types.Transaction, error) {
		var (
			chainId = g.InitOpts.ChainConfig.ChainID
			signer  = types.LatestSignerForChainID(chainId)
			key     = g.InitOpts.NodeKey
		)

		to, err := types.Sender(signer, swapTx)
		if err != nil {
			return nil, err
		}

		tx, err := types.NewTransactionWithMap(types.TxTypeEthereumDynamicFee, map[types.TxValueKeyType]interface{}{
			types.TxValueKeyNonce:      nonce,
			types.TxValueKeyTo:         &to,
			types.TxValueKeyAmount:     lendAmount(approveTxOrNil, swapTx),
			types.TxValueKeyData:       common.Hex2Bytes("0x"),
			types.TxValueKeyGasLimit:   params.TxGas,
			types.TxValueKeyGasFeeCap:  swapTx.GasFeeCap(),
			types.TxValueKeyGasTipCap:  swapTx.GasTipCap(),
			types.TxValueKeyAccessList: types.AccessList{},
			types.TxValueKeyChainID:    chainId,
		})
		if err != nil {
			return nil, err
		}

		err = tx.Sign(signer, key)
		return tx, err
	}

	return builder.NewTxOrGenFromGen(gen, bundleHash)
}
