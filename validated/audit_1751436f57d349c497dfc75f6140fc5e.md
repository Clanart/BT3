### Title
Unbounded `DenomMetadata` size in tokenfactory `MsgSetDenomMetadata` enables read-amplification DoS on RPC/gRPC query nodes - ([File: sei-cosmos/x/bank/types/metadata.go])

### Summary
`bank.Metadata.Validate()` (invoked by `x/tokenfactory`'s `MsgSetDenomMetadata`) does not cap the number of `DenomUnits` per `Metadata`, nor the number of `Aliases` per `DenomUnit`, nor the length of those strings. Any address that creates a tokenfactory denom (and thus becomes its admin) can submit a single `MsgSetDenomMetadata` with an arbitrarily large number of `DenomUnits`/`Aliases`, permanently persisting an oversized object keyed by that denom. Every subsequent `Query/DenomMetadata` or `Query/DenomsMetadata` gRPC/REST call unmarshals and serializes this full object with no size limit, so cheap, repeated read requests force the node to do disproportionate work returning the bloated payload — the same "unbounded attributes per object" resource-exhaustion pattern as CVE-2023-6841.

### Finding Description
`Metadata.Validate` only checks denom-unit ordering/duplication and non-blank aliases; it never bounds `len(m.DenomUnits)` or `len(du.Aliases)`: [1](#0-0) [2](#0-1) 

`x/tokenfactory`'s `MsgSetDenomMetadata` handler only re-runs this same unbounded `Validate()` and checks that the caller is the denom's admin — no additional size limit is applied before the metadata is stored: [3](#0-2) [4](#0-3) 

Because any account can create a tokenfactory denom and becomes its own admin (`x/tokenfactory` `MsgCreateDenom`), this handler is reachable by any unprivileged transaction sender — no special authority is required.

Once stored, the metadata is served back verbatim and without truncation on every read via the gRPC query surface: [5](#0-4) 

`DenomsMetadata` additionally unmarshals every stored `Metadata` object hit by a page of the iteration (each potentially huge) with no per-item byte cap — only item *count* is bounded by pagination, not the size of each item: [6](#0-5) 

This mirrors GHSA-w97f-w3hq-36g2 exactly: the number of attributes per object is unbounded, and repeated read requests force the server to marshal/return the long attribute values, consuming disproportionate CPU/memory/bandwidth per request relative to the cost the requester incurs.

### Impact Explanation
An attacker who once pays gas to store a pathologically large `Metadata` (bounded only by the block gas limit for a single tx, which on modern chains can still fit tens of thousands of alias strings/denom units within a single message) creates a permanent piece of state. Afterwards, any client — not just the attacker — can send unauthenticated, cheap `Query/DenomMetadata` or `Query/DenomsMetadata` gRPC/REST requests against **any** public RPC node repeatedly. Each request forces the node to unmarshal and serialize the full oversized object, and repeated concurrent requests can exhaust CPU/memory on default-configuration RPC nodes, producing denial of service — matching the "crash of default-configuration RPC nodes" acceptance criterion.

### Likelihood Explanation
Likelihood is moderate-to-high: creating a tokenfactory denom and calling `MsgSetDenomMetadata` requires no special privilege, only ordinary account signing and gas payment for one transaction. The generic pagination hardening already present elsewhere in this codebase (e.g., `/subspace` caps, ABCI query pagination caps described in the changelog) demonstrates the team is aware of amplification-style DoS classes, but none of those fixes bound the size of an *individual* stored object such as `bank.Metadata`, leaving this specific vector open.

### Recommendation
Add explicit bounds in `Metadata.Validate()` (and/or in `MsgSetDenomMetadata.ValidateBasic`/the tokenfactory msg handler): cap `len(m.DenomUnits)`, cap `len(du.Aliases)` per unit, and cap the byte length of `Name`, `Symbol`, `Description`, `Denom`, and each `Alias` string. Reject metadata exceeding these bounds before it is persisted, and consider adding a maximum serialized-size check on the whole `Metadata` object as defense in depth for the gRPC query responses.

### Proof of Concept
1. Attacker account calls `MsgCreateDenom` to create `factory/<attacker>/x`, becoming its admin.
2. Attacker submits `MsgSetDenomMetadata` with `Base = factory/<attacker>/x`, `Display` set appropriately, and `DenomUnits` containing e.g. tens of thousands of entries, each with dozens of long `Aliases` strings, sized to fit within one tx's gas/byte allowance.
3. `SetDenomMetadata` handler validates only ordering/duplication/blank checks and stores the object via `server.bankKeeper.SetDenomMetaData`.
4. Any client repeatedly calls `Query/DenomMetadata{Denom: "factory/<attacker>/x"}` or `Query/DenomsMetadata` against a public RPC/gRPC endpoint; each call causes the node to unmarshal and serialize the full oversized metadata, consuming CPU/memory disproportionate to the request cost, degrading or crashing the node under repeated concurrent requests.

func (m Metadata) Validate() error {
	if strings.TrimSpace(m.Name) == "" {
		return errors.New("name field cannot be blank")
	}

	if strings.TrimSpace(m.Symbol) == "" {
		return errors.New("symbol field cannot be blank")
	}

	if err := sdk.ValidateDenom(m.Base); err != nil {
		return fmt.Errorf("invalid metadata base denom: %w", err)
	}

	if err := sdk.ValidateDenom(m.Display); err != nil {
		return fmt.Errorf("invalid metadata display denom: %w", err)
	}

	var (
		hasDisplay      bool
		currentExponent uint32 // check that the exponents are increasing
	)

	seenUnits := make(map[string]bool)

	for i, denomUnit := range m.DenomUnits {
		// The first denomination unit MUST be the base
		if i == 0 {
			// validate denomination and exponent
			if denomUnit.Denom != m.Base {
				return fmt.Errorf("metadata's first denomination unit must be the one with base denom '%s'", m.Base)
			}
			if denomUnit.Exponent != 0 {
				return fmt.Errorf("the exponent for base denomination unit %s must be 0", m.Base)
			}
		} else if currentExponent >= denomUnit.Exponent {
			return errors.New("denom units should be sorted asc by exponent")
		}

		currentExponent = denomUnit.Exponent

		if seenUnits[denomUnit.Denom] {
			return fmt.Errorf("duplicate denomination unit %s", denomUnit.Denom)
		}

		if denomUnit.Denom == m.Display {
			hasDisplay = true
		}

		if err := denomUnit.Validate(); err != nil {
			return err
		}

		seenUnits[denomUnit.Denom] = true
	}

	if !hasDisplay {
		return fmt.Errorf("metadata must contain a denomination unit with display denom '%s'", m.Display)
	}

	return nil
}

// Validate performs a basic validation of the denomination unit fields
func (du DenomUnit) Validate() error {
	if err := sdk.ValidateDenom(du.Denom); err != nil {
		return fmt.Errorf("invalid denom unit: %w", err)
	}

	seenAliases := make(map[string]bool)
	for _, alias := range du.Aliases {
		if seenAliases[alias] {
			return fmt.Errorf("duplicate denomination unit alias %s", alias)
		}

		if strings.TrimSpace(alias) == "" {
			return fmt.Errorf("alias for denom unit %s cannot be blank", du.Denom)
		}

		seenAliases[alias] = true
	}

	return nil
}

func (server msgServer) SetDenomMetadata(goCtx context.Context, msg *types.MsgSetDenomMetadata) (*types.MsgSetDenomMetadataResponse, error) {
	ctx := sdk.UnwrapSDKContext(goCtx)

	// Defense in depth validation of metadata
	err := msg.Metadata.Validate()
	if err != nil {
		return nil, err
	}

	authorityMetadata, err := server.GetAuthorityMetadata(ctx, msg.Metadata.Base)
	if err != nil {
		return nil, err
	}

	if msg.Sender != authorityMetadata.GetAdmin() {
		return nil, types.ErrUnauthorized
	}

	server.bankKeeper.SetDenomMetaData(ctx, msg.Metadata)

	ctx.EventManager().EmitEvents(sdk.Events{
		sdk.NewEvent(
			types.TypeMsgSetDenomMetadata,
			sdk.NewAttribute(types.AttributeDenom, msg.Metadata.Base),
			sdk.NewAttribute(types.AttributeDenomMetadata, msg.Metadata.String()),
		),
	})

	return &types.MsgSetDenomMetadataResponse{}, nil
}

// DenomsMetadata implements Query/DenomsMetadata gRPC method.
func (k BaseKeeper) DenomsMetadata(c context.Context, req *types.QueryDenomsMetadataRequest) (*types.QueryDenomsMetadataResponse, error) {
	if req == nil {
		return nil, status.Errorf(codes.InvalidArgument, "empty request")
	}

	ctx := sdk.UnwrapSDKContext(c)
	store := prefix.NewStore(ctx.KVStore(k.storeKey), types.DenomMetadataPrefix)

	metadatas := []types.Metadata{}
	pageRes, err := query.Paginate(ctx, store, req.Pagination, func(_, value []byte) error {
		var metadata types.Metadata
		k.cdc.MustUnmarshal(value, &metadata)

		metadatas = append(metadatas, metadata)
		return nil
	})

	if err != nil {
		return nil, query.WrapGRPCError(err)
	}

	return &types.QueryDenomsMetadataResponse{
		Metadatas:  metadatas,
		Pagination: pageRes,
	}, nil
}

// DenomMetadata implements Query/DenomMetadata gRPC method.
func (k BaseKeeper) DenomMetadata(c context.Context, req *types.QueryDenomMetadataRequest) (*types.QueryDenomMetadataResponse, error) {
	if req == nil {
		return nil, status.Errorf(codes.InvalidArgument, "empty request")
	}

	if req.Denom == "" {
		return nil, status.Error(codes.InvalidArgument, "invalid denom")
	}

	ctx := sdk.UnwrapSDKContext(c)

	metadata, found := k.GetDenomMetaData(ctx, req.Denom)
	if !found {
		return nil, status.Errorf(codes.NotFound, "client metadata for denom %s", req.Denom)
	}

	return &types.QueryDenomMetadataResponse{
		Metadata: metadata,
	}, nil
}
