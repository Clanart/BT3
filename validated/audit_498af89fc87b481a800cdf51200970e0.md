### Title
Identity public keys enable universal Schnorr signature forgery - (File: crypto/schnorr/src/lib.rs)

### Summary
`SchnorrSignature::verify` accepts an identity public key, while `SchnorrSignature::read` accepts an identity nonce and zero scalar; together, these allow the fixed signature `(R = identity, s = 0)` to verify for every message and challenge under the identity key. [1](#0-0) [2](#0-1) 

### Finding Description
`C::read_G` rejects invalid and non-canonical encodings but does not reject the group identity, and `C::read_F` accepts the canonical zero scalar. [3](#0-2) [4](#0-3)  `SchnorrSignature::read` directly uses those permissive readers for `R` and `s`. [5](#0-4)  Verification evaluates `R + cA - sG == identity`, so `A = identity`, `R = identity`, and `s = 0` satisfy the equation for arbitrary `c`. [1](#0-0) 

### Impact Explanation
An attacker who can supply an identity-encoded public key can authenticate arbitrary messages without knowing a discrete logarithm: the challenge-bound public-key term vanishes, the nonce term is identity, and the solution term is zero. [1](#0-0) 

### Likelihood Explanation
This is reachable wherever untrusted public-key bytes are decoded with `C::read_G` and passed to `verify`, or untrusted signature bytes are passed to `SchnorrSignature::read`. [4](#0-3) [5](#0-4)  The FROST-specific `Curve::read_G` explicitly rejects identity points, but that protection is absent from the generic Schnorr verification path. [6](#0-5) 

### Recommendation
Reject identity public keys in `SchnorrSignature::verify` and `batch_verify`, and reject identity `R` values when decoding signatures; alternatively, expose a validated non-identity public-key type so callers cannot accidentally pass the identity element. [5](#0-4) [7](#0-6) 

### Proof of Concept
For an Ed25519-compatible ciphersuite, a canonical identity public key plus the serialized signature `identity || 0` passes verification:

```rust
use ciphersuite::{Ciphersuite, group::ff::PrimeField};
use dalek_ff_group::Ed25519;
use schnorr::SchnorrSignature;

let mut identity = [0u8; 32];
identity[0] = 1; // canonical compressed Ed25519 identity

let public_key =
  <Ed25519 as Ciphersuite>::read_G(&mut identity.as_slice()).unwrap();

let mut signature_bytes = Vec::new();
signature_bytes.extend(identity);
signature_bytes.extend([0u8; 32]); // s = 0

let signature =
  SchnorrSignature::<Ed25519>::read(&mut signature_bytes.as_slice()).unwrap();

let challenge =
  <Ed25519 as Ciphersuite>::F::from_u128(0x42);

assert!(signature.verify(public_key, challenge));
```

This succeeds because the verification expression reduces to `identity + c·identity - 0·G = identity`. [1](#0-0)

  pub fn batch_statements(&self, public_key: C::G, challenge: C::F) -> [(C::F, C::G); 3] {
    // s = r + ca
    // sG == R + cA
    // R + cA - sG == 0
    [
      // R
      (C::F::ONE, self.R),
      // cA
      (challenge, public_key),
      // -sG
      (-self.s, C::generator()),
    ]
  }

  ///
  /// This challenge must be properly crafted, which means being binding to the public key, nonce,
  /// and any message. Failure to do so will let a malicious adversary to forge signatures for
  /// different keys/messages.
  #[must_use]
  pub fn verify(&self, public_key: C::G, challenge: C::F) -> bool {
    multiexp_vartime(&self.batch_statements(public_key, challenge)).is_identity().into()

  fn read_F<R: Read>(reader: &mut R) -> io::Result<Self::F> {
    let mut encoding = <Self::F as PrimeField>::Repr::default();
    reader.read_exact(encoding.as_mut())?;

    // ff mandates this is canonical
    let res = Option::<Self::F>::from(Self::F::from_repr(encoding))
      .ok_or_else(|| io::Error::other("non-canonical scalar"));
    encoding.as_mut().zeroize();
    res
  }

  /// Read a canonical point from something implementing std::io::Read.
  ///
  /// The provided implementation is safe so long as `GroupEncoding::to_bytes` always returns a
  /// canonical serialization.
  #[cfg(any(feature = "alloc", feature = "std"))]
  #[allow(non_snake_case)]
  fn read_G<R: Read>(reader: &mut R) -> io::Result<Self::G> {
    let mut encoding = <Self::G as GroupEncoding>::Repr::default();
    reader.read_exact(encoding.as_mut())?;

    let point = Option::<Self::G>::from(Self::G::from_bytes(&encoding))
      .ok_or_else(|| io::Error::other("invalid point"))?;
    if point.to_bytes().as_ref() != encoding.as_ref() {
      Err(io::Error::other("non-canonical point"))?;
    }
    Ok(point)
