### Title
Nil dereference panic on attacker-supplied `TxData` with missing gas-fee fields — Cmp() called on nil `*big.Int` in the EVM fee/priority pipeline - ([File: x/evm/ante/fee.go], [File: app/prioritizer.go], [File: x/evm/types/ethtx/dynamic_fee_tx.go])

### Summary
`MsgEVMTransaction.Data` is an arbitrary protobuf `Any` that any unprivileged transaction sender can populate directly (it is not required to originate from RLP-decoded, signature-checked Ethereum bytes). `evmtypes.UnpackTxData` accepts this `Any` and `proto.Unmarshal`s it into `ethtx.DynamicFeeTx` (or other tx-data types) without any required-field validation. Fields such as `GasFeeCap`/`GasTipCap` are optional custom-type pointers that remain `nil` if simply omitted from the crafted bytes. Downstream ante-handler and mempool-priority code calls `.Cmp(...)` directly on the return value of `GetGasFeeCap()`/`GetGasTipCap()` without checking for `nil`, causing a nil-pointer-dereference panic — the exact bug class described in the external report (`gencodec`-style "required" annotations are not enforced by (de)serialization, and `big.Int.Cmp(nil)` panics).

### Finding Description
`evmtypes.UnpackTxData` (`x/evm/types/codec.go:93-134`) unmarshals the raw bytes of `MsgEVMTransaction.Data` into one of several `ethtx.TxData` proto messages (`LegacyTx`, `AccessListTx`, `DynamicFeeTx`, `BlobTx`, `AssociateTx`, `SetCodeTx`) purely based on whichever `proto.Unmarshal` call succeeds. Protobuf3 unmarshalling does not enforce "required" semantics, so a message that simply omits the `GasFeeCap`/`GasTipCap` fields unmarshal successfully with those fields left as `nil`: [1](#0-0) 

`ethtx.DynamicFeeTx`'s accessors explicitly return `nil` (not a zero `big.Int`) when the underlying field is unset: [2](#0-1) 

The EVM fee-check ante decorator, which runs on every EVM transaction as part of the ante pipeline reachable by any transaction sender, immediately calls `.Cmp()` on this potentially-nil value without a nil check: [3](#0-2) 

The same unchecked pattern is duplicated in the mempool transaction-priority calculation path used to rank incoming transactions: [4](#0-3) 

`PreprocessUnpacked` (`x/evm/ante/preprocess.go:164-246`), which runs earlier in the pipeline, does not prevent this: it builds a temporary `ethtypes.Transaction` via `AsEthereumData()`/`ethtypes.NewTx()` purely to derive the sender address; go-ethereum's internal `copy()` tolerates a nil `GasFeeCap` there, so preprocessing succeeds and sets `msg.Derived`, allowing the transaction to reach `EVMFeeCheckDecorator.AnteHandle`, where the original (still-nil) `ethtx.DynamicFeeTx` object is re-unpacked fresh from `msg.Data` and used directly: [5](#0-4) 

### Impact Explanation
Any account capable of submitting a Cosmos SDK transaction can construct one containing a `MsgEVMTransaction` whose `Data` field packs a hand-crafted `ethtx.DynamicFeeTx` (or `SetCodeTx`) protobuf payload with `GasFeeCap`/`GasTipCap` omitted. When this transaction is processed by `EVMFeeCheckDecorator.AnteHandle` (and/or by `SeiTxPrioritizer.getEvmTxPriority` during mempool insertion), `txData.GetGasFeeCap().Cmp(...)` dereferences a nil pointer and panics. This is the same nil-dereference-via-`Cmp` bug class as the reported restoration-server issue, reachable here from the EVM transaction ante pipeline that every public node processes for every submitted transaction. Depending on whether the panic occurs inside code paths protected by baseapp's `runTx` recovery versus mempool/priority code invoked outside that scope, this can manifest as a crash of node processes handling `CheckTx`/mempool re-ordering, denying transaction processing.

### Likelihood Explanation
The attack requires only the ability to submit an arbitrary Cosmos SDK transaction embedding a `MsgEVMTransaction` with a crafted `Data` `Any` — this is available to any public, unprivileged RPC client/transaction sender; no special permissions, validator status, or precompile access are needed. `MsgEVMTransaction` is a fully public/registered `sdk.Msg` type (`x/evm/types/codec.go:56-64`), and no ValidateBasic-style check on `TxData` completeness exists before the fee decorator runs.

### Recommendation
Add explicit nil checks for all optional big-int fields (`GasFeeCap`, `GasTipCap`, `GasPrice`, `BlobFeeCap`, `Amount`, etc.) returned from `ethtx.TxData` accessors before any `.Cmp()`/`.Sign()` call in `x/evm/ante/fee.go`, `app/prioritizer.go`, and any other ante/mempool code operating on unpacked `TxData`. Alternatively/additionally, enforce required-field validation immediately in `UnpackTxData` (or in a `TxData.Validate()` call invoked right after unpacking, before any ante-handler logic executes), rejecting any `MsgEVMTransaction` whose `TxData` is missing mandatory fee fields for its tx type, mirroring the `ethtx.DynamicFeeTx.Validate()` checks (`x/evm/types/ethtx/dynamic_fee_tx.go`) but ensuring they run unconditionally before fee/priority computations.

### Proof of Concept
1. Craft a protobuf-encoded `ethtx.DynamicFeeTx` message that sets `ChainID`, `Nonce`, `GasLimit`, `To`, `Data`, `Accesses`, and signature fields, but deliberately omits the `GasFeeCap` and `GasTipCap` fields (simply do not serialize those field numbers).
2. Wrap these bytes in a `codectypes.Any` with `TypeUrl` set to the `ethtx.DynamicFeeTx` type URL, and place it in `MsgEVMTransaction.Data`.
3. Broadcast a standard Cosmos SDK transaction containing this `MsgEVMTransaction` via `broadcast_tx_sync`/`broadcast_tx_async` to a public node.
4. `evmtypes.UnpackTxData` (`x/evm/types/codec.go:93-134`) successfully unmarshals this into an `ethtx.DynamicFeeTx` with `GasFeeCap == nil`.
5. `EVMPreprocessDecorator`/`PreprocessUnpacked` succeeds (nil-tolerant) and sets `msg.Derived`.
6. `EVMFeeCheckDecorator.AnteHandle` re-unpacks the same `Data`, and at `txData.GetGasFeeCap().Cmp(fc.getBaseFee(ctx))` (`x/evm/ante/fee.go:48`) dereferences the nil `*big.Int` returned by `DynamicFeeTx.GetGasFeeCap()`, panicking with `invalid memory address or nil pointer dereference`, mirroring the `TestCmpWithNil` panic shown in the external report.

func UnpackTxData(any *codectypes.Any) (ethtx.TxData, error) {
	if any == nil {
		return nil, errors.New("protobuf Any message cannot be nil")
	}

	txData, ok := any.GetCachedValue().(ethtx.TxData)
	if !ok {
		ltx := ethtx.LegacyTx{}
		if proto.Unmarshal(any.Value, &ltx) == nil {
			// value is a legacy tx
			return &ltx, nil
		}
		atx := ethtx.AccessListTx{}
		if proto.Unmarshal(any.Value, &atx) == nil {
			// value is a accesslist tx
			return &atx, nil
		}
		dtx := ethtx.DynamicFeeTx{}
		if proto.Unmarshal(any.Value, &dtx) == nil {
			// value is a dynamic fee tx
			return &dtx, nil
		}
		btx := ethtx.BlobTx{}
		if proto.Unmarshal(any.Value, &btx) == nil {
			// value is a blob tx
			return &btx, nil
		}
		astx := ethtx.AssociateTx{}
		if proto.Unmarshal(any.Value, &astx) == nil {
			// value is an associate tx
			return &astx, nil
		}
		stx := ethtx.SetCodeTx{}
		if proto.Unmarshal(any.Value, &stx) == nil {
			// value is a set code tx
			return &stx, nil
		}
		return nil, fmt.Errorf("cannot unpack Any into TxData %T", any)
	}

	return txData, nil
}

// PreprocessUnpacked does the same thing as Preprocess but accepts already unpacked txData to save computation
// if txData is nil, it will unpack from msgEVMTransaction.Data.
func PreprocessUnpacked(ctx sdk.Context, msgEVMTransaction *evmtypes.MsgEVMTransaction, chainID *big.Int, isBlockTest bool, txData ethtx.TxData) error {
	if msgEVMTransaction.Derived != nil {
		if msgEVMTransaction.Derived.PubKey == nil {
			// this means the message has `Derived` set from the outside, in which case we should reject
			return sdkerrors.ErrInvalidPubKey
		}
		// already preprocessed
		return nil
	}

	if txData == nil {
		// TxData not passed in, unpack it.
		var err error
		txData, err = evmtypes.UnpackTxData(msgEVMTransaction.Data)
		if err != nil {
			return err
		}
	}

	if atx, ok := txData.(*ethtx.AssociateTx); ok {
		V, R, S := atx.GetRawSignatureValues()
		V = new(big.Int).Add(V, utils.Big27)
		// Hash custom message passed in
		customMessageHash := crypto.Keccak256Hash([]byte(atx.CustomMessage))
		evmAddr, seiAddr, pubkey, err := helpers.GetAddresses(V, R, S, customMessageHash)
		if err != nil {
			return err
		}
		msgEVMTransaction.Derived = &derived.Derived{
			SenderEVMAddr: evmAddr,
			SenderSeiAddr: seiAddr,
			PubKey:        &secp256k1.PubKey{Key: pubkey.Bytes()},
			Version:       derived.Cancun,
			IsAssociate:   true,
		}
		return nil
	}

	ethTx := ethtypes.NewTx(txData.AsEthereumData())
	if ethTx.Type() != ethtypes.LegacyTxType {
		chainID = ethTx.ChainId()
	}
	chainCfg := evmtypes.DefaultChainConfig()
	ethCfg := chainCfg.EthereumConfig(chainID)
	version := GetVersion(ctx, ethCfg)
	signer := SignerMap[version](chainID)
	if !IsTxTypeAllowed(version, ethTx.Type()) {
		return ethtypes.ErrInvalidChainId
	}

	var txHash common.Hash
	V, R, S := ethTx.RawSignatureValues()
	if ethTx.Protected() {
		V = helpers.AdjustV(V, ethTx.Type(), ethCfg.ChainID)
		txHash = signer.Hash(ethTx)
	} else {
		if isBlockTest {
			// need to allow unprotected legacy txs in blocktest
			// to not lose coverage for other parts of the code
			txHash = ethtypes.FrontierSigner{}.Hash(ethTx)
		} else {
			return errors.New("unsupported tx type: unsafe legacy tx")
		}
	}
	evmAddr, seiAddr, seiPubkey, err := helpers.GetAddresses(V, R, S, txHash)
	if err != nil {
		return sdkerrors.ErrInvalidChainID
	}
	msgEVMTransaction.Derived = &derived.Derived{
		SenderEVMAddr: evmAddr,
		SenderSeiAddr: seiAddr,
		PubKey:        &secp256k1.PubKey{Key: seiPubkey.Bytes()},
		Version:       version,
		IsAssociate:   false,
	}
	return nil
}
