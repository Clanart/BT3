Based on my investigation, the strongest analog to CVE-2018-7551 is the **oneof-switch use-after-free** class of bug in Protobuf's Python C-extension binding, and the codebase evidence shows this exact issue was already identified and patched, with a regression test present. I have enough to write the final analog analysis.

### Title
Invalid-free-class Use-After-Free on oneof switch during `MergeFromString` from untrusted bytes - ([File: python/google/protobuf/pyext/message.cc])

### Summary
CVE-2018-7551 is an invalid free in `MiniPS::delete0` (sam2p): a crafted input drives an object-lifetime path where the C++ heap object backing an interpreter-visible object is freed while a live reference to it still exists, and later touching that reference corrupts memory. The Protobuf-analog is the C++/Python binding layer, where a submessage inside a `oneof` is represented both as a native message pointer and as a Python wrapper object (`CMessage`) held by the application. When a bounded, attacker-controlled binary payload is merged into an existing message via the public `MergeFromString`/`MergeFrom` API and the payload sets a different member of the same `oneof`, the native merge logic (`Reflection::ClearOneof`, `TcParser::ChangeOneof` in `src/google/protobuf/generated_message_tctable_lite.cc:1989-2054` and `src/google/protobuf/generated_message_reflection.cc:3403-3448`) `delete`s the previously-active oneof submessage object. If the Python wrapper for that submessage is still alive and not detached/released beforehand, the wrapper now points at freed memory — an invalid-free/UAF pattern structurally analogous to the sam2p bug, reachable purely through the public parse/merge API on attacker-controlled bytes.

### Finding Description
- Attacker-controlled value: the wire bytes passed to `Message.MergeFromString(data)` / `ParseFromString(data)`, a supported public API.
- Failed invariant in the general case: a live language-level wrapper object referencing a native submessage must not outlive that native object's `delete`.
- Missing check (absent the guard): merging bytes that set a different `oneof` case than the one currently held by the destination message causes the C++ layer to `delete` the old submessage (`generated_message_reflection.cc:3438-3440`, `TcParser::ChangeOneof` at `generated_message_tctable_lite.cc:2038-2047`) without protobuf's Python layer knowing to invalidate any Python-level reference to that now-dangling C++ object.
- This repository shows the fix already implemented: `MergeFromStringImpl` (`python/google/protobuf/pyext/message.cc:2074-2169`) explicitly parses into a temporary message first and calls `MaybeReleaseOneofBeforeMerge` (`python/google/protobuf/pyext/message.cc:757-807`) to detect a pending oneof switch and detach/release the Python wrapper for the old submessage *before* the native `MergeFrom`/`delete` runs, specifically to "prevent use-after-free bugs" (comment at `python/google/protobuf/pyext/message.cc:2087-2092`). The same guard is applied on the `MergeFrom(Message)` path via `MaybeReleaseOneofBeforeMerge` before `message->MergeFrom(*other_message->message)` at `python/google/protobuf/pyext/message.cc:2004-2008`.
- A dedicated regression test, `testOneofSwitchMergeUAF` in `python/google/protobuf/internal/message_test.py:2184-2202`, directly encodes this scenario: it keeps a Python reference (`sub_ref`) to a oneof submessage, merges in bytes that switch the oneof to a different field, and asserts the old reference remains valid rather than corrupted — confirming the fix's intent and the exact bug class being defended against.

### Impact Explanation
Were this guard absent or bypassable, an attacker able to supply bytes to a trusted application's `MergeFromString`/`MergeFrom` call could trigger deletion of a C++ object that a held Python object still points to, leading to use-after-free on subsequent access — potentially memory corruption, denial of service, or (depending on heap layout/reuse) further exploitation, matching the severity class of the sam2p CVE (crash up to unspecified further impact). However, in this checkout the mitigation is present and exercised by the cited path and test, so **no currently-reachable analog vulnerability exists**; this is a documented, fixed bug class rather than an open one.

### Likelihood Explanation
Low/None in the current codebase: the vulnerable window (`delete` of the old oneof member before Python releases its wrapper) is closed by parsing into a temporary message and calling `MaybeReleaseOneofBeforeMerge`/`FixupMessageAfterMerge` around every public merge entry point (`MergeFrom`, `MergeFromString`, and transitively `ParseFromString` via `is_cleared`). No other reachable public parse path (pure C++ `ParseFrom`/`TcParser::ChangeOneof`, upb-based PHP/Ruby bindings which use tagged unions rather than persistent native-object wrappers) was found to have the same wrapper-persistence hazard, since those either have no long-lived native-pointer wrapper (upb) or operate purely within `MessageLite`/`Arena` ownership without an external language-level alias.

### Recommendation
No action required for this specific path — the mitigation and its regression test are already present at `python/google/protobuf/pyext/message.cc:757-807`, `python/google/protobuf/pyext/message.cc:2074-2169`, and `python/google/protobuf/internal/message_test.py:2184-2202`. As a defensive follow-up, ensure any *new* public merge/copy entry points added to `python/google/protobuf/pyext/message.cc` (e.g. `CopyFrom`, extension-set merges) that can switch a oneof case are audited to route through `MaybeReleaseOneofBeforeMerge`/`FixupMessageAfterMerge` before invoking native `MergeFrom`/`CopyFrom`, and that `testOneofSwitchMergeUAF`-style regression coverage is extended to `CopyFrom` and nested-message oneof scenarios.

### Proof of Concept
Not applicable as an exploitable PoC against this checkout — the existing regression test in `python/google/protobuf/internal/message_test.py:2184-2202` already reproduces the scenario (hold `sub_ref = m2.oneof_nested_message`, then `m2.MergeFromString(data2)` where `data2` sets a different oneof member) and asserts the previously-fixed correct behavior (`sub_ref.bb == 42` still valid) rather than a crash, confirming the guard is active in this codebase. int MaybeReleaseOneofBeforeMerge(CMessage* self, const Message& other) {
```text
  CMessage::CompositeFieldsMap* composite_fields =
      self->composite_fields.TryGet();
  if (!composite_fields) {
    return 0;
  }

  Message* message = AssureWritable(self);
  if (message == nullptr) return -1;
  const Reflection* reflection = message->GetReflection();
  PyMessageFactory* factory = GetFactoryForMessage(self);
  std::vector<const FieldDescriptor*> fields_to_release;
  std::vector<std::pair<const FieldDescriptor*, ScopedPyObjectPtr>>
      nested_message_fields;
  composite_fields->ForEach([&](const void* key, PyObject* value) {
    const FieldDescriptor* descriptor =
        reinterpret_cast<const FieldDescriptor*>(key);
    if (descriptor->cpp_type() == FieldDescriptor::CPPTYPE_MESSAGE &&
        // For normal repeated message, MergeFrom will append the messages.
        // For message map with same keys, it is overwrite
        !descriptor->is_repeated() &&
        reflection->HasField(*message, descriptor)) {
      if (reflection->HasField(other, descriptor)) {
        Py_INCREF(value);
        nested_message_fields.emplace_back(descriptor, value);
      } else {
        // Release oneof message if the other message has set a different oneof
        const OneofDescriptor* oneof = descriptor->containing_oneof();
        if (oneof && reflection->HasOneof(other, oneof)) {
          fields_to_release.push_back(descriptor);
        }
      }
    }
  });

  for (const auto& [field, value] : nested_message_fields) {
    if (MaybeReleaseOneofBeforeMerge(
            reinterpret_cast<CMessage*>(value.get()),
            reflection->GetMessage(other, field, factory->message_factory)) <
        0) {
      return -1;
    }
  }

  for (const FieldDescriptor* field : fields_to_release) {
    if (InternalReleaseFieldByDescriptor(self, field) < 0) {
      return -1;
    }
  }
  return 0;
}
```

```text
static PyObject* MergeFromStringImpl(CMessage* self, PyObject* arg,
                                     bool is_cleared) {
  Py_buffer data;
  if (PyObject_GetBuffer(arg, &data, PyBUF_SIMPLE) < 0) {
    return nullptr;
  }
  auto cleanup_data = absl::MakeCleanup([&data] { PyBuffer_Release(&data); });

  Message* message = AssureWritable(self);
  if (message == nullptr) {
    return nullptr;
  }

  // We parse into a temporary message first to detect oneof switches before
  // modifying the target message. This allows us to release the wrappers
  // for switching oneof fields in the target message before they are deleted
  // by C++ during the merge, preventing use-after-free bugs.
  // We use heap allocation (nullptr arena) for the temporary message so that
  // it is collected immediately after the merge, avoiding wasting arena memory.
  std::unique_ptr<Message> temp_message;
  Message* merge_dst;

  if (is_cleared) {
    // Check that it is really empty.
    ABSL_DCHECK_EQ(message->ByteSizeLong(), 0);
    merge_dst = message;
  } else {
    temp_message.reset(message->New(nullptr));
    merge_dst = temp_message.get();
  }

  PyMessageFactory* factory = GetFactoryForMessage(self);
  int depth = allow_oversize_protos
                  ? INT_MAX
                  : io::CodedInputStream::GetDefaultRecursionLimit();
  const char* ptr;
  internal::ParseContext ctx(
      depth, false, &ptr,
      absl::string_view(static_cast<const char*>(data.buf), data.len));

  ctx.data().pool = factory->pool->pool->get();
  ctx.data().factory = factory->message_factory;

  ptr = merge_dst->_InternalParse(ptr, &ctx);

  if (is_cleared) {
    // If we merged into the final destination, fix up now before we might have
    // an early exit.
    FixupMessageAfterMerge(self);
  }
```

```text
void Reflection::ClearOneof(Message* message,
                            const OneofDescriptor* oneof_descriptor) const {
  if (oneof_descriptor->is_synthetic()) {
    ClearField(message, oneof_descriptor->field(0));
    return;
  }
  // TODO: Consider to cache the unused object instead of deleting
  // it. It will be much faster if an application switches a lot from
  // a few oneof fields.  Time/space tradeoff
  uint32_t oneof_case = GetOneofCase(*message, oneof_descriptor);
  if (oneof_case > 0) {
    const FieldDescriptor* field = descriptor_->FindFieldByNumber(oneof_case);
    if (message->GetArena() == nullptr) {
      switch (field->cpp_type()) {
        case FieldDescriptor::CPPTYPE_STRING: {
          switch (field->cpp_string_type()) {
            case FieldDescriptor::CppStringType::kCord:
              delete *MutableRaw<absl::Cord*>(message, field);
              break;
            case FieldDescriptor::CppStringType::kView:
            case FieldDescriptor::CppStringType::kString:
              if (IsMicroString(field)) {
                MutableField<MicroString>(message, field)->Destroy();
              } else {
                // Oneof string fields are never set as a default instance.
                // We just need to pass some arbitrary default string to make it
                // work. This allows us to not have the real default accessible
                // from reflection.
                MutableField<ArenaStringPtr>(message, field)->Destroy();
              }
              break;
          }
          break;
        }

        case FieldDescriptor::CPPTYPE_MESSAGE:
          delete *MutableRaw<Message*>(message, field);
          break;
        default:
          break;
      }
    }

    *MutableOneofCase(message, oneof_descriptor) = 0;
  }
}
```

```text
void TcParser::ChangeOneof(const TcParseTableBase* table,
                           const ClassData* class_data,
                           const TcParseTableBase::FieldEntry& entry,
                           uint32_t field_num, ParseContext* ctx,
                           MessageLite* msg) {
  // The _oneof_case_ value offset is stored in the has-bit index.
  uint32_t* oneof_case = &TcParser::RefAt<uint32_t>(msg, entry.has_idx);
  uint32_t current_case = *oneof_case;
  *oneof_case = field_num;

  // If the member is already active, then it should be merged. We're done.
  if (current_case == field_num) return;

  if (current_case == 0) {
    // If the member is empty, we don't have anything to clear.
    // We must create a new member object.
    InitOneof(table, class_data, entry, msg);
    return;
  }

  // Look up the value that is already stored, and dispose of it if necessary.
  const FieldEntry* current_entry = FindFieldEntry(table, current_case);
  uint16_t current_kind = current_entry->type_card & field_layout::kFkMask;
  uint16_t current_rep = current_entry->type_card & field_layout::kRepMask;
  if (current_kind == field_layout::kFkString) {
    switch (current_rep) {
      case field_layout::kRepAString: {
        auto& field = RefAt<ArenaStringPtr>(msg, current_entry->offset);
        field.Destroy();
        break;
      }
      case field_layout::kRepMString: {
        if (msg->GetArena() == nullptr) {
          RefAt<MicroString>(msg, current_entry->offset).Destroy();
        }
        break;
      }
      case field_layout::kRepCord: {
        if (msg->GetArena() == nullptr) {
          delete RefAt<absl::Cord*>(msg, current_entry->offset);
        }
        break;
      }
      case field_layout::kRepSString:
      case field_layout::kRepIString:
      default:
        internal::Unreachable();
        return;
    }
  } else if (current_kind == field_layout::kFkMessage) {
    switch (current_rep) {
      case field_layout::kRepMessage:
      case field_layout::kRepGroup: {
        auto& field = RefAt<MessageLite*>(msg, current_entry->offset);
        if (!msg->GetArena()) {
          delete field;
        }
        break;
      }
      default:
        internal::Unreachable();
        return;
    }
  }
  InitOneof(table, class_data, entry, msg);
}
```
