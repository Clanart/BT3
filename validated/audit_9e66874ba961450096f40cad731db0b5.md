### Title
Missing validation of `ErcAddress` in `MsgRegisterPointer` allows creating a permanent CW pointer to a non-contract or non-ERC20/721/1155 address - (File: x/evm/keeper/msg_server.go)

### Summary
`RegisterPointer` (triggered by any unprivileged, signed `MsgRegisterPointer` transaction) creates a permanent CosmWasm "pointer" contract that wraps an arbitrary EVM address supplied by the caller, without ever verifying that the address is a deployed contract, let alone that it implements the ERC20/ERC721/ERC1155 interface it is bound to represent.

### Finding Description
`MsgRegisterPointer.ValidateBasic` only checks that `Sender` is a valid bech32 address and that `ErcAddress` is a syntactically valid hex address: [1](#0-0) 

The handler `RegisterPointer` then takes `msg.ErcAddress` as-is and, if no pointer already exists at a sufficient version, instantiates a CW20/CW721/CW1155 pointer wasm contract configured with that raw address and permanently records the mapping via `SetCW20ERC20Pointer` / `SetCW721ERC721Pointer` / `SetCW1155ERC1155Pointer`: [2](#0-1) 

Unlike the reverse direction (`AddCW20`/`AddCW721` in the pointer precompile), which actively queries the CosmWasm contract (`token_info`/`contract_info`) to confirm it is a real CW20/CW721 before creating a pointer: [3](#0-2) 

there is no equivalent check on the CW→ERC path that the target EVM address has code, or that it actually exposes `decimals()/symbol()/balanceOf()` (ERC20), `ownerOf()` (ERC721), or `balanceOf(address,id)` (ERC1155) semantics. This is confirmed by existing test code, which successfully registers pointers against addresses that were never deployed as contracts (a `MockAddressPair()` value, and literally the zero address `0x0000...0000`): [4](#0-3) [5](#0-4) 

This mirrors the reported `setPoolAddress` bug class exactly: an address that is assumed to conform to a specific external contract interface is accepted and permanently bound with zero interface/existence validation, and every subsequent consumer of that binding (the pointer contract's queries/executes) implicitly trusts that assumption.

### Impact Explanation
Once a pointer is registered for a bogus/non-conforming `ErcAddress`, it is stored under `PointerCW20ERC20Key`/`PointerCW721ERC721Key`/`PointerCW1155ERC1155Key` and is only replaceable by a future version bump (`existingVersion >= currentVersion` gate) via `Migrate`, meaning the binding is effectively permanent for the current pointer-code version: [6](#0-5) 

Any user or contract that subsequently sends funds/NFTs to, or attempts to interact with, that pointer contract expecting it to bridge to a real ERC20/721/1155 token will have those interactions permanently break (revert or behave incorrectly), because the underlying `ErcAddress` has no code or does not implement the expected interface. Because the pointer address for a given `ErcAddress` is deterministic and can be squatted by any unprivileged sender before the real contract is even known/deployed at that slot, this also allows front-running/griefing of legitimate CW-EVM asset bridging, freezing user funds or breaking bridge functionality that depends on the pointer resolving correctly.

### Likelihood Explanation
The entry point is `MsgRegisterPointer`, reachable by any account via a normal signed Cosmos transaction or the `register-cw-pointer` CLI command, requiring no special privilege: [7](#0-6) 
The only gate is the `RegisterPointerDisabled` module parameter; when enabled (not disabled), any transaction sender can trigger this path with zero additional cost beyond gas, and the test suite demonstrates the missing validation is not merely theoretical — it is exercised and passes in the existing test code.

### Recommendation
Before instantiating/migrating a CW pointer for `msg.ErcAddress`, verify:
1. The address has non-empty contract code (`evm.StateDB.GetCodeSize(addr) > 0` or equivalent).
2. The address responds correctly to a staticcall for the interface being pointed to (e.g., `decimals()`/`symbol()`/`totalSupply()` for ERC20, `ownerOf()`/`balanceOf()` for ERC721, `balanceOf(address,uint256)` for ERC1155), analogous to the `token_info`/`contract_info` checks already performed in `AddCW20`/`AddCW721`.
3. Reject the registration with a clear error if these checks fail, rather than silently creating a permanently-bound pointer.

### Proof of Concept
1. Call `MsgRegisterPointer{PointerType: ERC20, ErcAddress: "0x0000000000000000000000000000000000000000"}` (or any address with no deployed bytecode) from any funded account.
2. `RegisterPointer` succeeds and instantiates a CW20 pointer contract bound to that address, as shown by the passing test `TestMigrateCWERC721Pointers` using the zero address as `ErcAddress`: [8](#0-7) 
3. Any subsequent query/execute against the resulting pointer contract that attempts to call into the bogus `ErcAddress` (e.g., `balanceOf`, `transfer`) will fail against a non-existent/non-conforming contract, and the binding cannot be corrected except via a pointer-code version upgrade, permanently breaking that pointer slot.

func (msg *MsgRegisterPointer) ValidateBasic() error {
	_, err := sdk.AccAddressFromBech32(msg.Sender)
	if err != nil {
		return sdkerrors.Wrapf(sdkerrors.ErrInvalidAddress, "Invalid sender address (%s)", err)
	}

	if !common.IsHexAddress(msg.ErcAddress) {
		return sdkerrors.ErrInvalidAddress
	}

	return nil
}

func (server msgServer) RegisterPointer(goCtx context.Context, msg *types.MsgRegisterPointer) (*types.MsgRegisterPointerResponse, error) {
	ctx := sdk.UnwrapSDKContext(goCtx)
	if server.GetRegisterPointerDisabled(ctx) {
		return nil, fmt.Errorf("registering CW->ERC pointers has been disabled")
	}
	var existingPointer sdk.AccAddress
	var existingVersion uint16
	var currentVersion uint16
	var exists bool
	switch msg.PointerType {
	case types.PointerType_ERC20:
		currentVersion = erc20.CurrentVersion
		existingPointer, existingVersion, exists = server.GetCW20ERC20Pointer(ctx, common.HexToAddress(msg.ErcAddress))
	case types.PointerType_ERC721:
		currentVersion = erc721.CurrentVersion
		existingPointer, existingVersion, exists = server.GetCW721ERC721Pointer(ctx, common.HexToAddress(msg.ErcAddress))
	case types.PointerType_ERC1155:
		currentVersion = erc1155.CurrentVersion
		existingPointer, existingVersion, exists = server.GetCW1155ERC1155Pointer(ctx, common.HexToAddress(msg.ErcAddress))
	default:
		panic("unknown pointer type")
	}
	if exists && existingVersion >= currentVersion {
		return nil, fmt.Errorf("pointer %s already registered at version %d", existingPointer.String(), existingVersion)
	}
	payload := map[string]interface{}{}
	switch msg.PointerType {
	case types.PointerType_ERC20:
		payload["erc20_address"] = msg.ErcAddress
	case types.PointerType_ERC721:
		payload["erc721_address"] = msg.ErcAddress
	case types.PointerType_ERC1155:
		payload["erc1155_address"] = msg.ErcAddress
	default:
		panic("unknown pointer type")
	}
	codeID := server.GetStoredPointerCodeID(ctx, msg.PointerType)
	moduleAcct := server.accountKeeper.GetModuleAddress(types.ModuleName)
	var err error
	var pointerAddr sdk.AccAddress
	if exists {
		bz, _ := json.Marshal(map[string]interface{}{})
		pointerAddr = existingPointer
		_, err = server.wasmKeeper.Migrate(ctx, existingPointer, moduleAcct, codeID, bz)
	} else {
		bz, jerr := json.Marshal(payload)
		if jerr != nil {
			return nil, jerr
		}
		pointerAddr, _, err = server.wasmKeeper.Instantiate(ctx, codeID, moduleAcct, moduleAcct, bz, fmt.Sprintf("Pointer of %s", msg.ErcAddress), sdk.NewCoins())
	}
	if err != nil {
		return nil, err
	}
	switch msg.PointerType {
	case types.PointerType_ERC20:
		err = server.SetCW20ERC20Pointer(ctx, common.HexToAddress(msg.ErcAddress), pointerAddr.String())
		ctx.EventManager().EmitEvent(sdk.NewEvent(
			types.EventTypePointerRegistered, sdk.NewAttribute(types.AttributeKeyPointerType, "erc20"),
			sdk.NewAttribute(types.AttributeKeyPointerAddress, pointerAddr.String()), sdk.NewAttribute(types.AttributeKeyPointee, msg.ErcAddress),
			sdk.NewAttribute(types.AttributeKeyPointerVersion, fmt.Sprintf("%d", erc20.CurrentVersion))))
	case types.PointerType_ERC721:
		err = server.SetCW721ERC721Pointer(ctx, common.HexToAddress(msg.ErcAddress), pointerAddr.String())
		ctx.EventManager().EmitEvent(sdk.NewEvent(
			types.EventTypePointerRegistered, sdk.NewAttribute(types.AttributeKeyPointerType, "erc721"),
			sdk.NewAttribute(types.AttributeKeyPointerAddress, pointerAddr.String()), sdk.NewAttribute(types.AttributeKeyPointee, msg.ErcAddress),
			sdk.NewAttribute(types.AttributeKeyPointerVersion, fmt.Sprintf("%d", erc721.CurrentVersion))))
	case types.PointerType_ERC1155:
		err = server.SetCW1155ERC1155Pointer(ctx, common.HexToAddress(msg.ErcAddress), pointerAddr.String())
		ctx.EventManager().EmitEvent(sdk.NewEvent(
			types.EventTypePointerRegistered, sdk.NewAttribute(types.AttributeKeyPointerType, "erc1155"),
			sdk.NewAttribute(types.AttributeKeyPointerAddress, pointerAddr.String()), sdk.NewAttribute(types.AttributeKeyPointee, msg.ErcAddress),
			sdk.NewAttribute(types.AttributeKeyPointerVersion, fmt.Sprintf("%d", erc1155.CurrentVersion))))
	default:
		panic("unknown pointer type")
	}
	return &types.MsgRegisterPointerResponse{PointerAddress: pointerAddr.String()}, err
}

func TestMigrateCWERC721Pointers(t *testing.T) {
	k := testkeeper.EVMTestApp.EvmKeeper
	ctx := testkeeper.EVMTestApp.GetContextForDeliverTx([]byte{}).WithBlockTime(time.Now())
	params := k.GetParams(ctx)
	params.RegisterPointerDisabled = false
	k.SetParams(ctx, params)
	require.Nil(t, migrations.StoreCWPointerCode(ctx, &k, false, true, false))
	msgServer := keeper.NewMsgServerImpl(&k)
	res, err := msgServer.RegisterPointer(sdk.WrapSDKContext(ctx), &types.MsgRegisterPointer{
		PointerType: types.PointerType_ERC721,
		ErcAddress:  "0x0000000000000000000000000000000000000000",
	})
	require.Nil(t, err)
	require.Nil(t, migrations.MigrateCWERC721Pointers(ctx, &k))
	// address should stay the same
	addr, _, _ := k.GetCW721ERC721Pointer(ctx, common.HexToAddress("0x0000000000000000000000000000000000000000"))
	require.Equal(t, res.PointerAddress, addr.String())
}

func RegisterCwPointerCmd() *cobra.Command {
	cmd := &cobra.Command{
		Use:   "register-cw-pointer [pointer type] [erc address]",
		Short: `Register a CosmWasm pointer for an ERC20/721/1155 contract. Pointer type is either ERC20, ERC721, or ERC1155.`,
		Args:  cobra.ExactArgs(2),
		RunE: func(cmd *cobra.Command, args []string) error {
			clientCtx, err := client.GetClientTxContext(cmd)
			if err != nil {
				return err
			}

			msg := &types.MsgRegisterPointer{
				Sender:      clientCtx.GetFromAddress().String(),
				PointerType: types.PointerType(types.PointerType_value[args[0]]),
				ErcAddress:  args[1],
			}
			if err := msg.ValidateBasic(); err != nil {
				return err
			}

			return tx.GenerateOrBroadcastTxCLI(cmd.Context(), clientCtx, cmd.Flags(), msg)
		},
	}

	flags.AddTxFlagsToCmd(cmd)

	return cmd
}
