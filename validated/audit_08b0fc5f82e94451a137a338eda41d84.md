### Title
`RegisterPointerDisabled` governance kill-switch only gates the Cosmos `MsgRegisterPointer` path, not the equivalent EVM precompile pointer-creation methods - ([File: precompiles/pointer/pointer.go])

### Summary
The `x/evm` module exposes a governance-controlled param, `RegisterPointerDisabled`, intended to globally disable creation of new CW/native↔ERC pointer contracts. The only place this flag is checked is the Cosmos `MsgRegisterPointer` handler. The EVM precompile at address `0x000000000000000000000000000000000000100b` (`precompiles/pointer/pointer.go`, plus every legacy version under `precompiles/pointer/legacy/*`) exposes `addNativePointer`, `addCW20Pointer`, `addCW721Pointer`, and `addCW1155Pointer` methods that perform pointer creation as well, but never consult `RegisterPointerDisabled`. Once an operator disables pointer registration via governance (as the migration `MigrateDisableRegisterPointer` does by setting `params.RegisterPointerDisabled = true`), an ordinary EVM transaction can still call the precompile and create new pointer contracts, defeating the intended kill-switch — directly analogous to the n8n bug where disabling the OIDC provider left `generateLoginUrl`/callback still functional because only one of two code paths enforced `assertOidcLoginEnabled`.

### Finding Description
`x/evm/keeper/msg_server.go`'s `RegisterPointer` checks the flag first: [1](#0-0) 

The getter is defined here: [2](#0-1) 

and is set to `true` by an on-chain upgrade migration, showing this is an actively used, real-world governance/ops control: [3](#0-2) 

However, the EVM precompile that performs the same class of operation (`AddNative`, `AddCW20`, `AddCW721`, `AddCW1155` — creating a new pointer contract for a native denom or CW20/CW721/CW1155 contract) has no such check anywhere in its `Execute` dispatcher or in any of the four handler functions: [4](#0-3) [5](#0-4) [6](#0-5) 

The same omission exists in every legacy pointer precompile version examined (`precompiles/pointer/legacy/v562/pointer.go`, `v614/pointer.go`, etc.), confirming this has been the case across upgrades, not a one-off regression: [7](#0-6) [8](#0-7) 

A repository-wide search confirms `RegisterPointerDisabled`/`GetRegisterPointerDisabled` is referenced only in the params type/keeper files, migrations, and `msg_server.go`/`msg_server_test.go` — never inside `precompiles/pointer/`.

### Impact Explanation
`RegisterPointerDisabled` is a governance/operator safety control meant to freeze all new pointer creation (e.g., in response to a discovered exploit in pointer contract templates, a compromised CW20/CW721/CW1155 code template, or to pause onboarding of new bridged assets). Because the EVM precompile route bypasses this check entirely, any unprivileged EVM transaction sender can still call `0x100b`'s `addNativePointer`/`addCW20Pointer`/`addCW721Pointer`/`addCW1155Pointer` to deploy new pointer contracts after the chain operator believed the feature was disabled. This can be used to keep creating pointer contracts for malicious or unvetted CW20/CW721/CW1155 tokens during a period when governance explicitly intended to halt that activity (e.g. while a vulnerability in the pointer contract bytecode/template is being fixed), enabling continued exploitation via newly-created pointer contracts and undermining an operator-controlled security freeze.

### Likelihood Explanation
High reachability: the precompile is a standard, permissionless EVM precompile callable by any account via a plain EVM transaction — no special permission, contract deployment, or elevated access needed. The only precondition is that governance has set `RegisterPointerDisabled = true` (via proposal or upgrade migration, as already codified in `MigrateDisableRegisterPointer`), which is exactly the scenario the control exists to enforce. Given this is a straightforward missing-check bug spanning the entire precompile version history, it is easily triggered as soon as the disable flag is toggled.

### Recommendation
Add a `if p.evmKeeper.GetRegisterPointerDisabled(ctx) { return nil, 0, errors.New("registering pointers has been disabled") }` check at the top of `PrecompileExecutor.Execute` in `precompiles/pointer/pointer.go` (and mirror it in still-reachable legacy precompile versions, or route them through a shared helper), so the EVM path enforces the same governance kill-switch as `MsgRegisterPointer`.

### Proof of Concept
1. Governance/operator sets `RegisterPointerDisabled = true` (e.g. via `MsgUpdateParams` or the `MigrateDisableRegisterPointer` upgrade handler).
2. Confirm the Cosmos path is blocked: calling `MsgRegisterPointer` now returns `"registering CW->ERC pointers has been disabled"` per `x/evm/keeper/msg_server.go:249-251`.
3. From any EVM account, send a transaction calling `addCW20Pointer(cwAddress)` (or `addNativePointer`/`addCW721Pointer`/`addCW1155Pointer`) on the pointer precompile at `0x000000000000000000000000000000000000100b`.
4. Observe the call succeeds and a new ERC pointer contract is deployed via `p.evmKeeper.UpsertERCCW20Pointer` (`precompiles/pointer/pointer.go:156`), even though `RegisterPointerDisabled` is `true` — demonstrating the governance freeze is bypassed.

func (p PrecompileExecutor) AddNative(ctx sdk.Context, method *ethabi.Method, caller common.Address, args []interface{}, value *big.Int, evm *vm.EVM, hooks *tracing.Hooks) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}
	if err := pcommon.ValidateArgsLength(args, 1); err != nil {
		return nil, 0, err
	}
	token := args[0].(string)
	metadata, metadataExists := p.bankKeeper.GetDenomMetaData(ctx, token)
	if !metadataExists {
		return nil, 0, fmt.Errorf("denom %s does not have metadata stored and thus can only have its pointer set through gov proposal", token)
	}
	name := metadata.Name
	symbol := metadata.Symbol
	var decimals uint8
	for _, denomUnit := range metadata.DenomUnits {
		if denomUnit.Exponent > uint32(decimals) && denomUnit.Exponent <= math.MaxUint8 {
			decimals = uint8(denomUnit.Exponent)
			name = denomUnit.Denom
			symbol = denomUnit.Denom
			if len(denomUnit.Aliases) > 0 {
				name = denomUnit.Aliases[0]
			}
		}
	}
	contractAddr, err := p.evmKeeper.UpsertERCNativePointer(ctx, evm, token, utils.ERCMetadata{Name: name, Symbol: symbol, Decimals: decimals})
	if err != nil {
		return nil, 0, err
	}

	ret, err = method.Outputs.Pack(contractAddr)
	remainingGas = pcommon.GetRemainingGas(ctx, p.evmKeeper)
	return
}

func (p PrecompileExecutor) AddNative(ctx sdk.Context, method *ethabi.Method, caller common.Address, args []interface{}, value *big.Int, evm *vm.EVM, suppliedGas uint64, hooks *tracing.Hooks) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}
	if err := pcommon.ValidateArgsLength(args, 1); err != nil {
		return nil, 0, err
	}
	token := args[0].(string)
	existingAddr, existingVersion, exists := p.evmKeeper.GetERC20NativePointer(ctx, token)
	if exists && existingVersion >= 1 {
		return nil, 0, fmt.Errorf("pointer at %s with version %d exists when trying to set pointer for version %d", existingAddr.Hex(), existingVersion, native.CurrentVersion)
	}
	metadata, metadataExists := p.bankKeeper.GetDenomMetaData(ctx, token)
	if !metadataExists {
		return nil, 0, fmt.Errorf("denom %s does not have metadata stored and thus can only have its pointer set through gov proposal", token)
	}
	name := metadata.Name
	symbol := metadata.Symbol
	var decimals uint8
	for _, denomUnit := range metadata.DenomUnits {
		if denomUnit.Exponent > uint32(decimals) && denomUnit.Exponent <= math.MaxUint8 {
			decimals = uint8(denomUnit.Exponent)
			name = denomUnit.Denom
			symbol = denomUnit.Denom
			if len(denomUnit.Aliases) > 0 {
				name = denomUnit.Aliases[0]
			}
		}
	}
	constructorArguments := []interface{}{
		token, name, symbol, decimals,
	}

	packedArgs, err := native.GetParsedABI().Pack("", constructorArguments...)
	if err != nil {
		panic(err)
	}
	bin := append(native.GetBin(), packedArgs...)
	if value == nil {
		value = utils.Big0
	}
	ret, contractAddr, remainingGas, err := evm.Create(caller, bin, suppliedGas, uint256.MustFromBig(value))
	if err != nil {
		return
	}
	err = p.evmKeeper.SetERC20NativePointer(ctx, token, contractAddr)
	if err != nil {
		return
	}

	ctx.EventManager().EmitEvent(sdk.NewEvent(
		types.EventTypePointerRegistered, sdk.NewAttribute(types.AttributeKeyPointerType, "native"),
		sdk.NewAttribute(types.AttributeKeyPointerAddress, contractAddr.Hex()), sdk.NewAttribute(types.AttributeKeyPointee, token),
		sdk.NewAttribute(types.AttributeKeyPointerVersion, fmt.Sprintf("%d", native.CurrentVersion))))
	ret, err = method.Outputs.Pack(contractAddr)
	return
}
