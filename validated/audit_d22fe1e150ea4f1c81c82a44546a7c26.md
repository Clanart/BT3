### Title
SSRF via unauthenticated DataLayer mirror coins forcing arbitrary outbound HTTP requests - (File: `chia/data_layer/data_layer.py`, `chia/wallet/db_wallet/db_wallet_puzzles.py`)

### Summary
The GHSA-w6x9-28jw-hq7j report describes a server-side fetch to a fully attacker-controlled URL with no SSRF protection, triggered over an unauthenticated channel and no ownership check on the target being contacted. Chia's DataLayer has an analogous pattern: "mirror" coins that advertise arbitrary URLs for a store are spendable/creatable by *any* wallet holder for *any* `launcher_id`, with no proof of ownership of that DataLayer store, and any node tracking that store will automatically issue outbound HTTP requests to those attacker-supplied URLs.

### Finding Description
A DataLayer "mirror" is simply a coin sent to a fixed, ownerless puzzle (`create_mirror_puzzle()` = `P2_PARENT.curry(Program.to(1))`), with the associated `launcher_id` and URL list embedded purely in the `CREATE_COIN` memos: [1](#0-0) [2](#0-1) 

Any wallet can create such a coin for *any* `launcher_id`, including a store it does not own, via `DataLayerWallet.create_new_mirror()` (reachable through the `dl_new_mirror` wallet RPC): [3](#0-2) [4](#0-3) 

Nothing in `get_mirror_info()` or `DataLayerStore.add_mirror()` validates that the coin's creator has any relationship to (or control over) the `launcher_id` singleton it claims to mirror — the launcher id and URLs are taken verbatim from memos supplied by whoever spends into the mirror puzzle. [5](#0-4) 

Once such a coin confirms on-chain, any DataLayer node tracking/subscribing to that `launcher_id` pulls these URLs automatically:
- `DataLayer.update_subscriptions_from_wallet()` reads mirror URLs from wallet RPC and pushes them into the local subscription table without validation: [6](#0-5) 
- The periodic sync loop (`fetch_and_validate()`) then performs real outbound HTTP requests to those server URLs to download delta files: [7](#0-6) 

This mirrors the MagicMirror bug class (CWE-441/CWE-918): a low-privilege actor supplies a URL that a separate server-side component with no authentication/authorization check on the target then blindly fetches, forcing an outbound request from the victim's infrastructure. In this case the "unauthenticated channel" is the mempool/chain itself — spending XCH to a well-known, ownerless puzzle hash with attacker-chosen memos requires no relationship to the targeted store's owner, and the resulting HTTP fetch happens automatically as part of normal DataLayer subscription maintenance.

### Impact Explanation
An attacker who merely spends a small amount of XCH can force any DataLayer node that subscribes to (or owns and pseudo-subscribes to) the targeted store to issue outbound HTTP GET requests to attacker-chosen URLs — including internal-network or cloud-metadata addresses reachable from the DataLayer host, at the interval configured by `manage_data_interval`. This is a server-side request forgery against DataLayer service operators (e.g., mirror servers, offer counterparties running DataLayer nodes) with no user interaction beyond having already subscribed to the abused store id, and repeats on every sync cycle for as long as the malicious mirror coin remains unspent. Body content isn't returned to the attacker directly (the response must parse into the DataLayer delta-file format to affect local state), so this remains primarily a blind-SSRF / internal port-scanning and confused-deputy vector rather than direct data exfiltration, keeping severity at Medium.

### Likelihood Explanation
Creating a mirror coin only requires standard wallet functionality (`generate_signed_transaction` to a known puzzle hash) and is exposed through the public `dl_new_mirror` wallet RPC/CLI with no special permission beyond normal spend authority over one's own coins; it does not require controlling the targeted singleton. Any store id that a victim node subscribes to (a normal, expected DataLayer operation for consuming another party's public dataset) is a viable target. This is a straightforward, repeatable network-observable action requiring no timing races or privileged access.

### Recommendation
Before treating a mirror record's URLs as trusted for outbound fetches, verify that the mirror-creating party has some authorized relationship to the targeted `launcher_id` (e.g., require store-owner attestation or bind mirror creation to a coin/announcement controlled by the singleton owner) rather than trusting arbitrary `CREATE_COIN` memos. Additionally, apply SSRF hardening (private/link-local/metadata IP blocklisting, scheme allowlisting, redirect restrictions) to `http_download()`/`fetch_and_validate()` and `get_downloader()`/`get_uploaders()` HTTP calls in `chia/data_layer/data_layer.py` and `chia/data_layer/download_data.py`, mirroring the hardened `/cors`-style protections referenced in the upstream MagicMirror fix.

### Proof of Concept
1. Attacker wallet calls `dl_new_mirror` (or CLI `chia data add_mirror`) with `launcher_id` set to a victim's real DataLayer store id and `urls=["http://169.254.169.254/latest/meta-data/", "http://internal-host:9999/admin"]`, paying only the mirror `amount` + fee: [4](#0-3) 
2. The resulting coin confirms on-chain; any node syncing that `launcher_id` parses it as a legitimate mirror via `get_mirror_info()` and stores it, with no check that the attacker owns the store: [5](#0-4) 
3. A victim DataLayer node that owns or subscribes to that store id calls `update_subscriptions_from_wallet()`, pulling the attacker's URLs into its subscription table: [6](#0-5) 
4. On the next periodic sync, `fetch_and_validate()` issues an HTTP request to the attacker-controlled/internal URL as part of normal delta-file download logic, with no target validation: [8](#0-7)

```python
def get_mirror_info(
    parent_puzzle: Program | SerializedProgram, parent_solution: Program | SerializedProgram
) -> tuple[bytes32, list[bytes]]:
    assert type(parent_puzzle) is type(parent_solution)
    _, conditions = run_with_cost(parent_puzzle, INFINITE_COST, parent_solution)
    for condition in conditions.as_iter():
        if (
            condition.first().as_python() == ConditionOpcode.CREATE_COIN
            and condition.at("rf").as_python() == create_mirror_puzzle().get_tree_hash()
        ):
            memos: list[bytes] = condition.at("rrrf").as_python()
            launcher_id = bytes32(memos[0])
            return launcher_id, [url for url in memos[1:]]
    raise ValueError("The provided puzzle and solution do not create a mirror coin")
```

```python
    async def dl_new_mirror(
        self,
        request: DLNewMirror,
        action_scope: WalletActionScope,
        extra_conditions: tuple[Condition, ...] = tuple(),
    ) -> DLNewMirrorResponse:
        """Add a new on chain message for a specific singleton"""
        if self.service.wallet_state_manager is None:
            raise ValueError("The wallet service is not currently initialized")

        dl_wallet = await self.service.wallet_state_manager.get_dl_wallet()
        async with self.service.wallet_state_manager.lock:
            await dl_wallet.create_new_mirror(
                request.launcher_id,
                request.amount,
                Mirror.encode_urls(request.urls),
                action_scope,
                fee=request.fee,
                extra_conditions=extra_conditions,
            )

        # tx_endpoint will take care of default values here
        return DLNewMirrorResponse(unsigned_transactions=[], transactions=[])
```

```python
        """
        Add a mirror coin to the DB
        """

        async with self.db_wrapper.writer_maybe_transaction() as conn:
            await conn.execute_insert(
                "INSERT OR REPLACE INTO mirrors VALUES (?, ?, ?, ?, ?)",
                (
                    mirror.coin_id,
                    mirror.launcher_id,
                    mirror.amount.stream_to_bytes(),
                    b"".join(
                        [uint16(len(url)).stream_to_bytes() + url for url in Mirror.encode_urls(mirror.urls)]
                    ),  # prefix each item with a length
                    1 if mirror.ours else 0,
                ),
            )
```
