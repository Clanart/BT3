### Title
CW→ERC Pointer Registration Bypasses `RegisterPointerDisabled` Governance Kill-Switch via the Pointer Precompile - (File: precompiles/pointer/pointer.go)

### Summary
The `x/evm` module exposes a governance-controlled kill switch, `RegisterPointerDisabled`, intended to globally disable creation of new CW→ERC pointer contracts. It is correctly enforced in the `MsgRegisterPointer` Cosmos message handler, but the equivalent EVM-reachable path — the `pointer` precompile at address `0x100b` — never checks it, so any EVM caller can still register pointers after the flag is enabled, exactly mirroring the Zitadel bug where a "registration disabled" flag was enforced on one entry point (the UI button) but not on the other reachable entry point (the direct URL).

### Finding Description
`x/evm/keeper/msg_server.go`'s `RegisterPointer` handler explicitly gates pointer creation: [1](#0-0) 

This check reads the param via `GetRegisterPointerDisabled`, which is defined in the keeper and defaults to `false`, settable via governance/params update: [2](#0-1) [3](#0-2) 

However, the `pointer` precompile — reachable by any EVM transaction sender calling contract address `0x000000000000000000000000000000000000100b` — implements `addNativePointer`, `addCW20Pointer`, `addCW721Pointer`, and `addCW1155Pointer` without any call to `GetRegisterPointerDisabled`: [4](#0-3) [5](#0-4) [6](#0-5) 

These methods call straight into `UpsertERCNativePointer` / `UpsertERCCW20Pointer` / `UpsertERCCW721Pointer` / `UpsertERCCW1155Pointer` on the EVM keeper, which perform the pointer deployment/registration unconditionally: [7](#0-6) 

The disabled-flag test suite only covers `RegisterPointer` message-server behavior and never asserts that the precompile path is also blocked, confirming the gap was never exercised: [8](#0-7) 

### Impact Explanation
If an operator/governance disables pointer registration (e.g., to freeze creation of new CW20/CW721/CW1155↔ERC pointer contracts for compliance, security-incident containment, or migration-control reasons), any unprivileged EVM transaction sender can still register new pointers by calling the `pointer` precompile directly, completely bypassing the intended restriction — the same class of bypass as the Zitadel advisory (enforcement present on one entry point, absent on the functionally equivalent one). This can enable creation of unauthorized/duplicate token bridges between the CW and EVM worlds during a period when the chain operators specifically intended to prevent that, potentially undermining incident response or migration procedures that rely on the flag.

### Likelihood Explanation
High likelihood if the parameter is ever set to `true`: the precompile is public, permissionless, and requires only a standard EVM call — no special privilege, contract deployment rights, or CosmWasm access are needed. The bypass requires no race condition or edge case; it is a straightforward, deterministic call to `0x100b`.

### Recommendation
Add the same `GetRegisterPointerDisabled` check at the top of `PrecompileExecutor.Execute` (or in each of `AddNative`, `AddCW20`, `AddCW721`, `AddCW1155`) in `precompiles/pointer/pointer.go`, returning an error identical to the one used in `x/evm/keeper/msg_server.go`'s `RegisterPointer`, so both entry points enforce the flag consistently. Also add regression tests exercising the precompile with `RegisterPointerDisabled = true`.

### Proof of Concept
1. Governance/param-change sets `x/evm` params `RegisterPointerDisabled = true` (verified enforced against `MsgRegisterPointer` per `x/evm/keeper/msg_server_test.go:836-907`).
2. An unprivileged EVM account sends a transaction calling `addCW20Pointer(cwAddr)` (or `addNativePointer`/`addCW721Pointer`/`addCW1155Pointer`) on precompile address `0x000000000000000000000000000000000000100b`.
3. `PrecompileExecutor.AddCW20` in `precompiles/pointer/pointer.go` executes without checking the disabled flag, calls `UpsertERCCW20Pointer`, and successfully deploys/registers a new ERC20 pointer contract for the CW20 token — despite the chain-wide disable flag being set.

func (p PrecompileExecutor) AddNative(ctx sdk.Context, method *ethabi.Method, caller common.Address, args []interface{}, value *big.Int, evm *vm.EVM, hooks *tracing.Hooks) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}
	if err := pcommon.ValidateArgsLength(args, 1); err != nil {
		return nil, 0, err
	}
	token := args[0].(string)
	metadata, metadataExists := p.bankKeeper.GetDenomMetaData(ctx, token)
	if !metadataExists {
		return nil, 0, fmt.Errorf("denom %s does not have metadata stored and thus can only have its pointer set through gov proposal", token)
	}
	name := metadata.Name
	symbol := metadata.Symbol
	var decimals uint8
	for _, denomUnit := range metadata.DenomUnits {
		if denomUnit.Exponent > uint32(decimals) && denomUnit.Exponent <= math.MaxUint8 {
			decimals = uint8(denomUnit.Exponent)
			name = denomUnit.Denom
			symbol = denomUnit.Denom
			if len(denomUnit.Aliases) > 0 {
				name = denomUnit.Aliases[0]
			}
		}
	}
	contractAddr, err := p.evmKeeper.UpsertERCNativePointer(ctx, evm, token, utils.ERCMetadata{Name: name, Symbol: symbol, Decimals: decimals})
	if err != nil {
		return nil, 0, err
	}

	ret, err = method.Outputs.Pack(contractAddr)
	remainingGas = pcommon.GetRemainingGas(ctx, p.evmKeeper)
	return
}

func (k *Keeper) UpsertERCPointer(
	ctx sdk.Context, evm *vm.EVM, typ string, args []interface{}, getter PointerGetter, setter PointerSetter,
) (contractAddr common.Address, err error) {
	pointee := args[0].(string)
	evmModuleAddress := k.GetEVMAddressOrDefault(ctx, k.AccountKeeper().GetModuleAddress(types.ModuleName))

	var bin []byte
	bin, err = artifacts.GetParsedABI(typ).Pack("", args...)
	if err != nil {
		panic(err)
	}
	bin = append(artifacts.GetBin(typ), bin...)
	// GetDeploymentCode / Create take EVM snapshots that Freeze() Multistore layers.
	// Exists-lookup and commits must use the live unfrozen top (sdb.Ctx): cachekv
	// forbids writing a frozen layer, and same-tx readers that skip frozen-empty
	// parents would miss those writes. The precompile Prepare `ctx` is that top at
	// Prepare time, but is frozen once this Upsert snapshots. Always attach the
	// caller's gas meter (finite precompile meter in deliver) — sdb.Ctx() alone
	// carries the infinite EVM meter.
	sdb := state.GetDBImpl(evm.StateDB)
	liveCtx := func() sdk.Context {
		if sdb == nil {
			return ctx
		}
		return sdb.Ctx().WithGasMeter(ctx.GasMeter())
	}
	existingAddr, _, exists := getter(liveCtx(), pointee)
	suppliedGas := k.getEvmGasLimitFromCtx(ctx)
	var remainingGas uint64
	if exists {
		var ret []byte
		contractAddr = existingAddr
		ret, remainingGas, err = evm.GetDeploymentCode(evmModuleAddress, bin, suppliedGas, utils.Big0, existingAddr)
		if err != nil {
			return
		}
		// Only write on success: a failed GetDeploymentCode can leave ret as nil or
		// revert data, which must not clobber live pointer bytecode (even transiently).
		writeCtx := liveCtx()
		k.SetCode(writeCtx, contractAddr, ret)
		if sdb != nil {
			sdb.RefreshCodeCache(contractAddr, ret)
		}
	} else {
		_, contractAddr, remainingGas, err = evm.Create(evmModuleAddress, bin, suppliedGas, uint256.NewInt(0))
	}
	if err != nil {
		return
	}
	ctx.GasMeter().ConsumeGas(k.GetCosmosGasLimitFromEVMGas(ctx, suppliedGas-remainingGas), "ERC pointer deployment")
	if err = setter(liveCtx(), pointee, contractAddr); err != nil {
		return
	}
	ctx.EventManager().EmitEvent(sdk.NewEvent(
		types.EventTypePointerRegistered, sdk.NewAttribute(types.AttributeKeyPointerType, typ),
		sdk.NewAttribute(types.AttributeKeyPointerAddress, contractAddr.Hex()), sdk.NewAttribute(types.AttributeKeyPointee, pointee)))
	return
}

func TestRegisterPointerDisabled(t *testing.T) {
	k, ctx := testkeeper.MockEVMKeeper(t)
	sender, _ := testkeeper.MockAddressPair()
	pointer, pointee := testkeeper.MockAddressPair()
	// set params to disable registering CW->ERC pointers
	params := k.GetParams(ctx)
	params.RegisterPointerDisabled = true
	k.SetParams(ctx, params)

	// Test register-pointer for ERC20 fails with useLatest = true
	_, err := keeper.NewMsgServerImpl(k).RegisterPointer(sdk.WrapSDKContext(ctx), &types.MsgRegisterPointer{
		Sender:      sender.String(),
		PointerType: types.PointerType_ERC20,
		ErcAddress:  pointee.Hex(),
	})
	require.NotNil(t, err)
	require.Contains(t, err.Error(), "registering CW->ERC pointers has been disabled")
	_, _, exists := k.GetCW20ERC20Pointer(ctx, pointee)
	require.False(t, exists)

	// Test register-pointer for ERC721 fails with useLatest = true
	_, err = keeper.NewMsgServerImpl(k).RegisterPointer(sdk.WrapSDKContext(ctx), &types.MsgRegisterPointer{
		Sender:      sender.String(),
		PointerType: types.PointerType_ERC721,
		ErcAddress:  pointee.Hex(),
	})
	require.NotNil(t, err)
	require.Contains(t, err.Error(), "registering CW->ERC pointers has been disabled")
	_, _, exists = k.GetCW721ERC721Pointer(ctx, pointee)
	require.False(t, exists)

	// Test register-pointer for ERC1155 fails with useLatest = true
	_, err = keeper.NewMsgServerImpl(k).RegisterPointer(sdk.WrapSDKContext(ctx), &types.MsgRegisterPointer{
		Sender:      sender.String(),
		PointerType: types.PointerType_ERC1155,
		ErcAddress:  pointee.Hex(),
	})
	require.NotNil(t, err)
	require.Contains(t, err.Error(), "registering CW->ERC pointers has been disabled")
	_, _, exists = k.GetCW1155ERC1155Pointer(ctx, pointee)
	require.False(t, exists)

	// Test that no events are emitted
	hasRegisteredEvent := false
	for _, e := range ctx.EventManager().Events() {
		if e.Type == types.EventTypePointerRegistered {
			hasRegisteredEvent = true
			break
		}
	}
	require.False(t, hasRegisteredEvent)

	// Test that existing pointers can still be queried
	// First manually set up a pointer
	err = k.SetCW20ERC20PointerWithVersion(ctx, pointee, pointer.String(), erc20.CurrentVersion)
	require.Nil(t, err)

	// Verify the pointer exists and can be queried
	gotPointer, version, exists := k.GetCW20ERC20Pointer(ctx, pointee)
	require.True(t, exists)
	require.Equal(t, erc20.CurrentVersion, version)
	require.Equal(t, pointer, gotPointer)

	// Test that attempting to register a pointer for an address that already has one still fails
	_, err = keeper.NewMsgServerImpl(k).RegisterPointer(sdk.WrapSDKContext(ctx), &types.MsgRegisterPointer{
		Sender:      sender.String(),
		PointerType: types.PointerType_ERC20,
		ErcAddress:  pointee.Hex(),
	})
	require.NotNil(t, err)
	require.Contains(t, err.Error(), "registering CW->ERC pointers has been disabled")
}
