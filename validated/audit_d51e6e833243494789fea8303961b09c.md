## Analysis: Applying the AMM-oracle-manipulation pattern to GitHub Desktop

The Uniswap report's broken invariant is: **a value that an unprivileged, adversarial counterparty can cheaply influence is trusted for a security decision, and the built-in bounds checks reduce but don't eliminate the exposure.**

The closest structural analog I could locate in this codebase is `getEndpointKind` in `app/src/lib/trampoline/trampoline-credential-helper.ts`, which classifies a git credential request as `'github.com' | 'ghe.com' | 'enterprise' | 'generic'` based on signals that are largely supplied by the remote/proxy the user is talking to (`WWW-Authenticate` header realm, and a `HEAD /meta` heuristic in `isGitHubHost`), rather than a static allow-list of trusted endpoints.

### Title
Credential-helper endpoint classification trusts attacker-controllable server signals, risking GitHub token disclosure to non-GitHub hosts - (File: app/src/lib/trampoline/trampoline-credential-helper.ts)

### Summary
`getEndpointKind` decides whether a git credential request is a "GitHub"-class host (`github.com`/`ghe.com`/`enterprise`) versus `'generic'`. For unknown hosts it falls back to inspecting the `WWW-Authenticate` realm string forwarded by git, and ultimately to `isGitHubHost()` in `app/src/lib/api.ts`, which performs a `HEAD` request to `<endpoint>/meta` and trusts the response if it merely contains an `x-github-request-id` header. [1](#0-0) [2](#0-1) 

### Finding Description
When git needs credentials for an HTTPS remote, Desktop's trampoline credential helper (`createCredentialHelperTrampolineHandler` → `getCredential`) first checks if the endpoint is a known GitHub account; if not, it calls `getEndpointKind`, which:
1. Checks `WWW-Authenticate` realm text captured from the *remote server's own HTTP response* (`realm="GitHub"` → `'enterprise'`). [3](#0-2) 
2. Falls back to `isGitHubHost(endpoint)`, which sends a HEAD request to `<endpoint>/meta` and classifies the host as GitHub-owned solely because the response carries an `x-github-request-id` header. [4](#0-3) 

Both signals originate from the remote server the user is cloning/fetching/pushing to — i.e., an attacker-controlled endpoint. There is no cryptographic pinning; the "proof" of being a GitHub-class host is just an HTTP header value that any server operator can emit, mirroring how `getPriceFromAMM` blindly trusted `getAmountsOut`'s output as ground truth. If `endpointKind !== 'generic'`, and Desktop has an existing account whose API endpoint happens to match `getAPIEndpoint(endpoint)` (`app/src/lib/trampoline/trampoline-credential-helper.ts:104-112`), the flow moves to `getGitHubCredential`, which retrieves the user's stored GitHub/GHE **token** and hands it to git for that endpoint via `credWithAccount`. [5](#0-4) [6](#0-5) 

The `getAPIEndpoint`/`isDotCom`/`isGHE`/`isGHES` helpers used for the match are hostname-based, and `getEnterpriseAPIURL` is a pure string derivation from the URL host with no verification against the account's actual registered endpoint value beyond string equality. [7](#0-6) 

### Impact Explanation
If an attacker can get Desktop to attempt HTTPS auth against a spoofed host that returns `realm="GitHub"` or crafted headers on `/meta` (e.g., via a malicious `insteadOf`/rewritten remote URL, a compromised proxy, DNS/hosts manipulation of a look-alike GHE hostname, or a subdomain the victim already has a GHE account configured for), Desktop's credential helper can classify that host as an `'enterprise'`/GitHub-class endpoint. Combined with an account whose `getAPIEndpoint()` derivation coincidentally or intentionally matches, this can lead the stored GitHub PAT/OAuth token to be sent to the attacker-controlled server — this is the "credential/token exfiltration" impact class explicitly called out as valid.

### Likelihood Explanation
This requires the attacker to control (or MITM/proxy) the target git remote and to know or guess the user's account endpoint well enough to satisfy the `apiEndpoint` match in `getCredential`. This is a non-trivial precondition, and I was not able to fully trace every branch of `getAPIEndpoint`/`findGitHubTrampolineAccount` matching logic or `find-account.ts` within the available context to confirm whether the endpoint match can be trivially satisfied by an attacker-chosen hostname (e.g., a GHE Cloud subdomain the victim is signed into, where any `*.ghe.com` host is treated as `isGHE` and thus `'ghe.com'`-classified without any additional per-org validation). [8](#0-7) 

### Recommendation
Do not derive trust classification from remote-supplied signals (`WWW-Authenticate` realm strings, `/meta` header presence). Restrict automatic GitHub credential attachment to hostnames that exactly match an already-registered, user-authenticated account endpoint (exact host/scheme comparison, not derived string construction), and require explicit user confirmation before sending a GitHub token to any host not previously associated with that account.

### Proof of Concept
I could not build a concrete, verified end-to-end PoC from the indexed code alone — confirming exploitability requires tracing `findGitHubTrampolineAccount`/`find-account.ts` matching semantics and the exact conditions under which `apiEndpoint` in `getCredential` coincides with a spoofed host, which were not fully available in the retrieved context.

```typescript
async function getCredential(cred: Credential, store: Store, token: string) {
  const ghCred = await getGitHubCredential(cred, store)

  if (ghCred) {
    return ghCred
  }

  const endpointKind = await getEndpointKind(cred, store)
  const accounts = await store.getAll()

  const endpoint = `${getCredentialUrl(cred)}`
  const apiEndpoint = getAPIEndpoint(endpoint)

  // If it appears as if the endpoint is a GitHub host and we don't have an
  // account for that endpoint then we should prompt the user to sign in.
  if (
    endpointKind !== 'generic' &&
    !accounts.some(a => a.endpoint === apiEndpoint)
  ) {
    if (getIsBackgroundTaskEnvironment(token)) {
      debug('background task environment, skipping prompt')
      return undefined
    }

    const account = await ui.promptForGitHubSignIn(endpoint)

    if (!account) {
      setHasRejectedCredentialsForEndpoint(token, endpoint)
    }

    return credWithAccount(cred, account)
  }

  // GitHub.com/GHE creds are only stored internally
  if (endpointKind !== 'generic') {
    return undefined
  }
```

```typescript
const getEndpointKind = async (cred: Credential, store: Store) => {
  const credentialUrl = getCredentialUrl(cred)
  const endpoint = `${credentialUrl}`

  if (isGist(endpoint)) {
    return 'generic'
  }

  if (isDotCom(endpoint)) {
    return 'github.com'
  }

  if (isGHE(endpoint)) {
    return 'ghe.com'
  }

  // When Git attempts to authenticate with a host it captures any
  // WWW-Authenticate headers and forwards them to the credential helper. We
  // use them as a happy-path to determine if the host is a GitHub host without
  // having to resort to making a request ourselves.
  for (const [k, v] of cred.entries()) {
    if (k.startsWith('wwwauth[')) {
      if (v.includes('realm="GitHub"')) {
        return 'enterprise'
      } else if (/realm="(GitLab|Gitea|Atlassian Bitbucket)"/.test(v)) {
        return 'generic'
      }
    }
  }

  const existingAccount = await findGitHubTrampolineAccount(store, endpoint)
  if (existingAccount) {
    return isDotCom(existingAccount.endpoint) ? 'github.com' : 'enterprise'
  }

  // All GitHub hosts use HTTPS, so if the protocol is not HTTPS we can
  // assume that this is not a GitHub host.
  if (credentialUrl.protocol !== 'https:') {
    return 'generic'
  }

  return (await isGitHubHost(endpoint)) ? 'enterprise' : 'generic'
```

```typescript
/**
 * Get the API URL for an HTML URL. For example:
 *
 * http://github.mycompany.com -> https://github.mycompany.com/api/v3
 */
export function getEnterpriseAPIURL(endpoint: string): string {
  const { host } = new window.URL(endpoint)

  return isGHE(endpoint) ? `https://api.${host}/` : `https://${host}/api/v3`
}

export const getAPIEndpoint = (endpoint: string) =>
  isDotCom(endpoint) ? getDotComAPIEndpoint() : getEnterpriseAPIURL(endpoint)
```

```typescript
export const isDotCom = (ep: string) => {
  if (ep === getDotComAPIEndpoint()) {
    return true
  }

  const { hostname } = new URL(ep)
  return hostname === 'api.github.com' || hostname === 'github.com'
}

export const isGist = (ep: string) => {
  const { hostname } = new URL(ep)
  return hostname === 'gist.github.com' || hostname === 'gist.ghe.io'
}

/** Whether or not the given endpoint URI is under the ghe.com domain */
export const isGHE = (ep: string) => new URL(ep).hostname.endsWith('.ghe.com')

/**
 * Whether or not the given endpoint URI appears to point to a GitHub Enterprise
 * Server instance
 */
export const isGHES = (ep: string) => !isDotCom(ep) && !isGHE(ep)
```
