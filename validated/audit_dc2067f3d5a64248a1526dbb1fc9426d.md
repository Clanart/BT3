### Title
Missing bounds check in CLVM atom length-prefix parsing during canonical-serialization check - (File: chia/full_node/mempool_manager.py)

### Summary
`is_atom_canonical()` in `chia/full_node/mempool_manager.py` reads a variable-length CLVM atom length prefix directly out of an untrusted `clvm_buffer` without ever checking that the buffer actually contains as many prefix bytes as the top nibble of the first byte claims. This mirrors the CVE-2019-15699 bug class: a length field embedded in attacker-controlled input is trusted to compute how many subsequent bytes to read, with no check against the real remaining buffer size.

### Finding Description
`is_atom_canonical(clvm_buffer, offset)` inspects the top bits of `clvm_buffer[offset]` to determine how many additional length-prefix bytes follow (`prefix_len` up to 5) and then loops reading `clvm_buffer[offset]` that many more times to assemble `atom_len`, with no check that `offset` stays within `len(clvm_buffer)`: [1](#0-0) 

Contrast this with the equivalent length-prefixed parsers in `chia/full_node/full_block_utils.py` (`skip_bytes`, `skip_list`, `generator_from_block`, `block_info_from_block`), which explicitly validate `len(buf) < 4` and `n > len(buf)` before consuming length-prefixed data and raise a `ValueError` instead of reading out of bounds: [2](#0-1) [3](#0-2) 

`is_atom_canonical` is invoked from `is_clvm_canonical`, which walks a CLVM-serialized buffer token by token: [4](#0-3) 

### Impact Explanation
Because Python `bytes`/`bytearray` indexing is itself bounds-checked at the interpreter level, an out-of-range index in `clvm_buffer[offset]` raises an `IndexError` rather than causing a native memory over-read as in the original Suricata C code. This is a materially weaker consequence than the CVE it's modeled after: there is no possibility of memory disclosure or corruption in Python. Whether this constitutes a valid "spend-triggered transaction-processing halt" per the scope rules depends entirely on whether `is_clvm_canonical`/`is_atom_canonical` runs on attacker-supplied spend-bundle CLVM bytes during mempool admission without the caller catching `IndexError`, and whether an uncaught exception there would abort/crash the relevant task rather than being handled as a normal rejection.

```python
def is_atom_canonical(clvm_buffer: bytes, offset: int) -> tuple[int, bool]:
    b = clvm_buffer[offset]
    if (b & 0b11000000) == 0b10000000:
        # 6 bits length prefix
        mask = 0b00111111
        prefix_len = 0
        min_value = 1
    elif (b & 0b11100000) == 0b11000000:
        # 5 + 8 bits length prefix
        mask = 0b00011111
        prefix_len = 1
        min_value = 1 << 6
    elif (b & 0b11110000) == 0b11100000:
        # 4 + 8 + 8 bits length prefix
        mask = 0b00001111
        prefix_len = 2
        min_value = 1 << (5 + 8)
    elif (b & 0b11111000) == 0b11110000:
        # 3 + 8 + 8 + 8 bits length prefix
        mask = 0b00000111
        prefix_len = 3
        min_value = 1 << (4 + 8 + 8)
    elif (b & 0b11111100) == 0b11111000:
        # 2 + 8 + 8 + 8 + 8 bits length prefix
        mask = 0b00000011
        prefix_len = 4
        min_value = 1 << (3 + 8 + 8 + 8)
    elif (b & 0b11111110) == 0b11111100:
        # 1 + 8 + 8 + 8 + 8 + 8 bits length prefix
        mask = 0b00000001
        prefix_len = 5
        min_value = 1 << (2 + 8 + 8 + 8 + 8)

    atom_len = b & mask
    for i in range(prefix_len):
        atom_len <<= 8
        offset += 1
        atom_len |= clvm_buffer[offset]

    return 1 + prefix_len + atom_len, atom_len >= min_value
```

```python
def is_clvm_canonical(clvm_buffer: bytes) -> bool:
    """
    checks whether the CLVM serialization is all canonical representation.
    atoms can be serialized in more than one way by using more bytes than
    necessary to encode the length prefix. This functions ensures that all atoms are
    encoded with the shortest representation. back-references are not allowed
    and will make this function return false
    """
    assert clvm_buffer != b""

    offset = 0
    tokens_left = 1
    while True:
        b = clvm_buffer[offset]

        # pair
        if b == 0xFF:
            tokens_left += 1
            offset += 1
            continue

        # back references cannot be considered canonical, since they may be
        # encoded in many different ways
        if b == 0xFE:
            return False

        # small atom or NIL
        if b <= 0x80:
            tokens_left -= 1
            offset += 1
        else:
            atom_len, canonical = is_atom_canonical(clvm_buffer, offset)
            if not canonical:
                return False
            tokens_left -= 1
            offset += atom_len

        if tokens_left == 0:
            break

    # if there's garbage at the end, it's not canonical
    return offset == len(clvm_buffer)
```

```python
def skip_bytes(buf: memoryview) -> memoryview:
    if len(buf) < 4:
        raise ValueError(f"byte length prefix requires 4 bytes, remaining buffer {len(buf)}")
    n = int.from_bytes(buf[:4], "big", signed=False)
    buf = buf[4:]
    if n > len(buf):
        raise ValueError(f"byte length {n} exceeds remaining buffer {len(buf)}")
    return buf[n:]
```
