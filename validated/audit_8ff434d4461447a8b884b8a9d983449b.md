### Title
Governance-controlled `RegisterPointerDisabled` param is not enforced on the EVM pointer precompile, allowing anyone to bypass the pointer-registration freeze - ([File: precompiles/pointer/pointer.go])

### Summary
The `shareKey` report describes a case where a supply/creation cap is enforced on one entrypoint (`purchase`) but a functionally equivalent side-effect entrypoint (`shareKey`) creates the same resource without going through the guarded path, letting anyone bypass the cap cheaply. Sei-chain has an analogous split-entrypoint gap: pointer (CW20/CW721/CW1155/native) creation can happen through two independent code paths — the Cosmos `MsgRegisterPointer` handler and the EVM `pointer` precompile (`0x100b`) — but the governance kill-switch `RegisterPointerDisabled` is enforced only on the first.

### Finding Description
`x/evm/keeper/msg_server.go`'s `RegisterPointer` handler explicitly checks the governance-settable param before creating/upgrading a pointer: [1](#0-0) 

This param can be flipped on by a migration (e.g. `MigrateDisableRegisterPointer`), and is read through `k.GetRegisterPointerDisabled`: [2](#0-1) [3](#0-2) 

However, the EVM-native `pointer` precompile at address `0x100b`, which exposes `addNativePointer`, `addCW20Pointer`, `addCW721Pointer`, and `addCW1155Pointer` and performs the exact same "upsert pointer" state mutation (`UpsertERCNativePointer` / `UpsertERCCW20Pointer` / `UpsertERCCW721Pointer` / `UpsertERCCW1155Pointer`), never calls `GetRegisterPointerDisabled` anywhere in its execution path: [4](#0-3) [5](#0-4) [6](#0-5) 

A grep across the codebase for `RegisterPointerDisabled` confirms the only production check sites are the params type/getter and the `msg_server.go` `RegisterPointer` handler — the precompile package and its `UpsertERCPointer`/`UpsertERC*Pointer` keeper functions in `x/evm/keeper/pointer_upgrade.go` never reference it. [7](#0-6) 

This mirrors the `shareKey` bug class exactly: the cap/guard ("no new pointers may be created") is only checked on one of two functionally equivalent creation paths, so any EVM transaction sender can trivially route around a chain-wide, governance-mandated freeze simply by calling the precompile instead of submitting a `MsgRegisterPointer`.

### Impact Explanation
`RegisterPointerDisabled` exists to let governance halt the creation/upgrade of CW↔ERC pointer contracts network-wide (e.g., in response to a discovered pointer-logic bug, an ongoing incident, or a planned pointer-migration window where new pointer creation must be frozen to keep the migration process consistent — see `x/evm/migrations/migrate_all_pointers_test.go`). Because the precompile path ignores the flag, any unprivileged EVM caller can continue creating and upgrading pointers to arbitrary CW20/CW721/CW1155/native tokens during the freeze window, defeating the safety control governance activated. Depending on why the freeze was enacted, this can let attackers stand up new/duplicate pointer contracts (each pointer deployment also triggers `evm.Create`, deploying new bytecode and consuming resources) during a period administrators believed was locked down, undermining the intended mitigation and potentially interacting badly with an in-progress pointer migration.

### Likelihood Explanation
High likelihood of exploitation once the flag is set: no special privileges are required, just an EVM transaction to `0x100b` calling `addNativePointer`/`addCW20Pointer`/`addCW721Pointer`/`addCW1155Pointer`. It requires governance to have enabled `RegisterPointerDisabled` at all (a deliberate, presumably rare admin action), but whenever that happens, bypass is trivial, permissionless, and repeatable for every token address.

### Recommendation
Add a `RegisterPointerDisabled` check at the top of `PrecompileExecutor.Execute` in `precompiles/pointer/pointer.go` (and in any legacy precompile versions still reachable on-chain), mirroring the check already present in `x/evm/keeper/msg_server.go`'s `RegisterPointer`, so both entrypoints are governed by the same on/off switch.

### Proof of Concept
1. Governance (or an internal migration) sets `RegisterPointerDisabled = true` via `SetParams`/`MigrateDisableRegisterPointer`.
2. Confirm `MsgRegisterPointer` now fails: `x/evm/keeper/msg_server.go` returns `"registering CW->ERC pointers has been disabled"`.
3. From any account, submit an EVM transaction calling the `pointer` precompile at `0x100b` with method `addCW20Pointer(cwAddr)` (or `addNativePointer`/`addCW721Pointer`/`addCW1155Pointer`).
4. Observe the call succeeds and a new pointer contract is deployed/upgraded via `UpsertERCCW20Pointer` (`x/evm/keeper/pointer_upgrade.go`), because `PrecompileExecutor.AddCW20`/`Execute` never consult `GetRegisterPointerDisabled`, unlike the disabled Cosmos-tx path.

func (k *Keeper) GetRegisterPointerDisabled(ctx sdk.Context) bool {
	if !ctx.IsTracing() {
		return k.GetParams(ctx).RegisterPointerDisabled
	}
	switch {
	case semver.Compare(ctx.ClosestUpgradeName(), "v6.0.6") < 0:
		// Not present in pre-5.8.0 params; use default
		return types.DefaultRegisterPointerDisabled
	default:
		return k.GetParams(ctx).RegisterPointerDisabled
	}
}

func (p PrecompileExecutor) AddNative(ctx sdk.Context, method *ethabi.Method, caller common.Address, args []interface{}, value *big.Int, evm *vm.EVM, hooks *tracing.Hooks) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}
	if err := pcommon.ValidateArgsLength(args, 1); err != nil {
		return nil, 0, err
	}
	token := args[0].(string)
	metadata, metadataExists := p.bankKeeper.GetDenomMetaData(ctx, token)
	if !metadataExists {
		return nil, 0, fmt.Errorf("denom %s does not have metadata stored and thus can only have its pointer set through gov proposal", token)
	}
	name := metadata.Name
	symbol := metadata.Symbol
	var decimals uint8
	for _, denomUnit := range metadata.DenomUnits {
		if denomUnit.Exponent > uint32(decimals) && denomUnit.Exponent <= math.MaxUint8 {
			decimals = uint8(denomUnit.Exponent)
			name = denomUnit.Denom
			symbol = denomUnit.Denom
			if len(denomUnit.Aliases) > 0 {
				name = denomUnit.Aliases[0]
			}
		}
	}
	contractAddr, err := p.evmKeeper.UpsertERCNativePointer(ctx, evm, token, utils.ERCMetadata{Name: name, Symbol: symbol, Decimals: decimals})
	if err != nil {
		return nil, 0, err
	}

	ret, err = method.Outputs.Pack(contractAddr)
	remainingGas = pcommon.GetRemainingGas(ctx, p.evmKeeper)
	return
}
