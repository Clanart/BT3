### Title
Historical Regression: Oneof Case-Switch During Wire Parsing Could Overwrite a Lazy Field Without Destroying It, Leaking Referenced State - ([File: src/google/protobuf/message_unittest.inc])

### Summary
The `GaugeFactory` report's core flaw is that a public, unauthenticated entry point (`deployGauge`) let an attacker overwrite an existing keyed record (`lpTokenToGauge[lpToken]`) with no check that the slot was already occupied, silently discarding/orphaning the previously associated state. The nearest genuine Protobuf analog is the `TcParser::ChangeOneof` oneof-case switch logic in the C++ tabledriven parser: when a wire stream (attacker-controlled bytes, bounded, via the public `ParseFrom*`/`MergeFrom` API) contains two occurrences of the same `oneof` with different field numbers, the second occurrence must destroy the object currently occupying that oneof slot before installing the new one. A regression test, `TestRegressionOverwrittenLazyOneofDoesNotLeak`, documents that this destruction path historically failed to properly tear down a `LazyField`-backed oneof member (a message field whose contents were kept unparsed inside a `Cord`), so the old value was overwritten/orphaned rather than destroyed — the parser's invariant "exactly one live member value per oneof, with proper release of the previous one" was violated [1](#0-0) .

### Finding Description
`TcParser::ChangeOneof` is the function responsible for the "one active member" invariant of a `oneof`: on seeing a new tag for a different member of the same oneof already holding a value, it must look up the currently active field's `FieldEntry`, destroy/release the object it holds, and only then switch the oneof case to the new field number [2](#0-1) . The teardown branch explicitly special-cases `kFkString` and `kFkMessage` representations (`kRepAString`, `kRepMString`, `kRepCord`, `kRepMessage`, `kRepGroup`), each with its own bespoke destroy/`delete` logic depending on arena ownership [3](#0-2) . Historically, an oneof member represented as a `LazyField` (unparsed bytes cached in a `Cord` to defer full submessage parsing) was not covered correctly by this teardown path: when an attacker crafts a serialized message with the lazy oneof member set first and a different oneof member set second (both wire-valid, both within the same `oneof`), `ChangeOneof` executes the "current member occupied → dispose of it → init new member" branch, but the disposal step failed to actually run the `LazyField`'s destructor, so the `Cord` payload referenced by the overwritten value was never released. The regression test constructs exactly this payload: it sets `oneof_lazy_nested_message`, inflates it past `Cord`'s small-string-optimization threshold via unknown fields so a real heap-backed `Cord` is used, serializes it, then appends a second encoding of the same message with a different oneof member (`oneof_uint32`) set, and parses the concatenation once [1](#0-0) . This is directly analogous to `GaugeFactory.deployGauge` being called twice for the same `lpToken` key: the second write silently overwrites/orphans the first value's state without the code path that should release/invalidate it running correctly.

### Impact Explanation
In the fixed/current state, the test only asserts successful parsing and (implicitly, via ASan/LeakSanitizer runs) absence of a leak, i.e., the invariant is now upheld — the previous `LazyField`/`Cord` payload is properly destroyed during the oneof switch [4](#0-3) . Where this class of bug is live (as documented by the regression comment: "This call had a bug where the LazyField was not destroyed in any way causing the Cord inside it to leak its contents"), the impact is a memory leak of arena/heap-owned data reachable purely from a bounded, attacker-supplied binary payload through the public parse API — no privileged access, hostile schema, or extra allocation beyond the message's own encoded bytes is required. This does not rise to memory corruption, use-after-free, or RCE; the failure mode is loss of freed-object bookkeeping (leak), not disclosure or overwrite of unrelated memory.

### Likelihood Explanation
Triggering the code path requires only two ordinary conditions reachable by any client sending bytes to `ParseFromString`/`MergeFrom`: (1) a message schema with a `oneof` containing at least one message-typed field eligible for lazy parsing, and (2) a wire stream containing two tags belonging to that oneof, first the lazy-eligible one (with enough bytes to avoid `Cord`'s SSO), then a different member. Both are ordinary, spec-compliant protobuf wire sequences (repeated/duplicate oneof tags are explicitly legal on the wire, with "last one wins" semantics enforced elsewhere), so the trigger condition is trivially attacker-reachable, but the specific defect is already covered by a regression test in this checkout, indicating it has been fixed upstream and this exact instance is not currently exploitable in this repository's shipped `ChangeOneof` logic [2](#0-1) .

### Recommendation
Because the specific `LazyField` teardown gap this analog is based on already has a passing regression test in this checkout, no code change is indicated here; the recommendation is to keep `TestRegressionOverwrittenLazyOneofDoesNotLeak` in the required/blocking test suite for `TcParser::ChangeOneof` and any future representation kinds added to `field_layout::kFkMessage`/`kFkString` (e.g., new lazy or cord variants), and to add an explicit `case`/`default: internal::Unreachable()` audit whenever a new `RepXxx` representation is introduced under `kFkMessage`/`kFkString`, since `ChangeOneof`'s teardown `switch` statements enumerate representations by hand and a newly added representation that isn't added to both `InitOneof` and `ChangeOneof` reproduces exactly this class of bug [5](#0-4) .

### Proof of Concept
The existing regression test is the concrete, already-executed reproduction: it builds a `TestAllTypes` message, sets `oneof_lazy_nested_message` and inflates it past `Cord`'s SSO limit with unknown fixed64 fields, serializes it, then appends a second serialization of the same message with `oneof_uint32` set instead, and parses the concatenated bytes into a fresh, arena-allocated message — the historical bug (silent overwrite without destroying the previous `LazyField`/`Cord`) manifested as a leak detectable under LeakSanitizer on this exact call [1](#0-0) .

void TcParser::InitOneof(const TcParseTableBase* table,
                         const ClassData* class_data,
                         const TcParseTableBase::FieldEntry& entry,
                         MessageLite* msg) {
  uint16_t kind = entry.type_card & field_layout::kFkMask;
  uint16_t rep = entry.type_card & field_layout::kRepMask;
  if (kind == field_layout::kFkString) {
    switch (rep) {
      case field_layout::kRepAString: {
        RefAt<ArenaStringPtr>(msg, entry.offset).InitDefault();
        break;
      }
      case field_layout::kRepMString: {
        RefAt<MicroString>(msg, entry.offset).InitDefault();
        break;
      }
      case field_layout::kRepCord: {
        absl::Cord* field = Arena::Create<absl::Cord>(msg->GetArena());
        RefAt<absl::Cord*>(msg, entry.offset) = field;
        break;
      }
      case field_layout::kRepSString:
      case field_layout::kRepIString:
      default:
        internal::Unreachable();
        return;
    }
  } else if (kind == field_layout::kFkMessage) {
    switch (rep) {
      case field_layout::kRepMessage:
      case field_layout::kRepGroup: {
        auto& field = RefAt<MessageLite*>(msg, entry.offset);
        field = NewMessage(class_data, msg->GetArena());
        break;
      }
      default:
        internal::Unreachable();
        return;
    }
  }
}

// Destroys any existing oneof union member (if necessary). Initializes the
// oneof field if the caller is responsible for initializing the object, or does
// not perform initialization if the field already has the desired case.
void TcParser::ChangeOneof(const TcParseTableBase* table,
                           const ClassData* class_data,
                           const TcParseTableBase::FieldEntry& entry,
                           uint32_t field_num, ParseContext* ctx,
                           MessageLite* msg) {
  // The _oneof_case_ value offset is stored in the has-bit index.
  uint32_t* oneof_case = &TcParser::RefAt<uint32_t>(msg, entry.has_idx);
  uint32_t current_case = *oneof_case;
  *oneof_case = field_num;

  // If the member is already active, then it should be merged. We're done.
  if (current_case == field_num) return;

  if (current_case == 0) {
    // If the member is empty, we don't have anything to clear.
    // We must create a new member object.
    InitOneof(table, class_data, entry, msg);
    return;
  }

  // Look up the value that is already stored, and dispose of it if necessary.
  const FieldEntry* current_entry = FindFieldEntry(table, current_case);
  uint16_t current_kind = current_entry->type_card & field_layout::kFkMask;
  uint16_t current_rep = current_entry->type_card & field_layout::kRepMask;
  if (current_kind == field_layout::kFkString) {
    switch (current_rep) {
      case field_layout::kRepAString: {
        auto& field = RefAt<ArenaStringPtr>(msg, current_entry->offset);
        field.Destroy();
        break;
      }
      case field_layout::kRepMString: {
        if (msg->GetArena() == nullptr) {
          RefAt<MicroString>(msg, current_entry->offset).Destroy();
        }
        break;
      }
      case field_layout::kRepCord: {
        if (msg->GetArena() == nullptr) {
          delete RefAt<absl::Cord*>(msg, current_entry->offset);
        }
        break;
      }
      case field_layout::kRepSString:
      case field_layout::kRepIString:
      default:
        internal::Unreachable();
        return;
    }
  } else if (current_kind == field_layout::kFkMessage) {
    switch (current_rep) {
      case field_layout::kRepMessage:
      case field_layout::kRepGroup: {
        auto& field = RefAt<MessageLite*>(msg, current_entry->offset);
        if (!msg->GetArena()) {
          delete field;
        }
        break;
      }
      default:
        internal::Unreachable();
        return;
    }
  }
  InitOneof(table, class_data, entry, msg);
}
