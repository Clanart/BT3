## Analysis Result

### Title
Gasless module's bundle-tx admission queue uses a single global counter shared across all senders, letting one attacker exhaust queue capacity and deny gasless service to unrelated users - (File: kaiax/gasless/impl/tx_pool.go)

### Summary
The OpenReception bug class is a shared limiting resource (the PIN throttle row) keyed by an identifier that is not scoped to the tenant/victim it is supposed to protect, so an unrelated attacker can exhaust or manipulate that shared resource and deny service to a victim who never interacted with the attacker's context. The closest reachable analog in `kaia` is the gasless transaction pool's admission gate for bundle transactions (`GaslessApproveTx`/`GaslessSwapTx`), which is gated by a single global counter (`knownTxs.numQueue()`) rather than a per-sender quota.

### Finding Description
`GaslessModule.PreAddTx` is the pool-admission hook invoked for every incoming transaction that is a gasless bundle tx. It checks a single shared map `g.knownTxs` (keyed only by transaction hash, with no sender/account partitioning) against a single global cap `g.GetMaxBundleTxsInQueue()`: [1](#0-0) 

The underlying `knownTxs` type is a flat `map[common.Hash]*knownTx` with aggregate counters `numQueue()`/`numPending()`/`numExecutable()` that sum across *all* senders, with no per-account bucketing anywhere in the type: [2](#0-1) 

Because the admission check `uint(g.knownTxs.numQueue()) >= g.GetMaxBundleTxsInQueue()` is keyed on this single global count rather than per-sender, any account (unprivileged, requires no special relationship with the node operator or other users) can submit a stream of syntactically valid `GaslessApproveTx`/`GaslessSwapTx` pairs from many different EOAs to saturate the shared queue slot. Once saturated, `PreAddTx` returns `ErrBundleTxQueueFull` for every subsequent gasless bundle tx from any sender, including completely unrelated legitimate users, exactly mirroring the cross-tenant lockout pattern from the report: a resource keyed by something that fails to distinguish between the attacker's activity and the victim's, causing the victim's legitimate requests to be denied due to unrelated attacker activity.

### Impact Explanation
Legitimate users attempting to use gasless swaps (an unprivileged, publicly reachable feature funded by the block proposer per KIP-247) can be denied admission to the tx pool by an attacker who has no relationship to those victims, simply by flooding the shared global bundle-queue counter from throwaway accounts. This is a availability/DoS impact against a specific reachable public feature (gasless transactions), matching the "Medium" severity class of the original report (state-transition/pool admission DoS via improperly scoped shared throttle/limit).

### Likelihood Explanation
The attack requires only the ability to submit transactions to the public RPC/tx pool — no special privilege, no validator/peer position, and no cryptographic secrets. Constructing decodable `GaslessApproveTx`/`GaslessSwapTx` pairs that pass `IsApproveTx`/`IsSwapTx` decoding (to be classified as bundle txs and consume the global counter) is feasible for any external caller, especially if the balance-check level is configured lower (`BalanceCheckLevelStatic`) as demonstrated in the module's own tests, lowering the cost of generating admissible filler bundle txs.

### Recommendation
Scope the bundle-tx admission quota per sender (or per some other tenant-equivalent boundary) in addition to, or instead of, the global cap, so that one account's queued bundle txs cannot crowd out other accounts' legitimate gasless bundle txs. Concretely, change `PreAddTx`/`GetMaxBundleTxsInQueue` in `kaiax/gasless/impl/tx_pool.go` to track counts keyed by sender address (similar to how `blockchain/tx_pool.go` enforces `NonExecSlotsAccount` per-account limits alongside `NonExecSlotsAll`) rather than relying solely on the aggregate `knownTxs.numQueue()`.

### Proof of Concept
1. Attacker generates N distinct EOAs (no funding needed if `ShouldCheckSenderCode`/`ShouldCheckToken`/balance checks are relaxed via configuration, or minimal funding otherwise).
2. For each EOA, attacker crafts a valid `GaslessApproveTx` + `GaslessSwapTx` pair that passes `decodeApproveTx`/`decodeSwapTx` and `isApproveTx`/`isSwapTx` classification, and submits them to the public tx-pool RPC.
3. Each submission increments `g.knownTxs` via `PreAddTx`'s `g.knownTxs.add(tx, TxStatusQueue)` call until `numQueue() >= GetMaxBundleTxsInQueue()`.
4. Once the shared global cap is reached, a legitimate, unrelated user's gasless swap submission hits the same check and receives `ErrBundleTxQueueFull`, denying them the gasless feature despite having no interaction with the attacker.

func (g *GaslessModule) PreAddTx(tx *types.Transaction, local bool) error {
	g.knownTxsMu.RLock()
	defer g.knownTxsMu.RUnlock()

	if knownTx, ok := g.knownTxs.get(tx.Hash()); ok && knownTx.elapsedPromotedOrAddedTime() < KnownTxTimeout {
		return ErrUnableToAddKnownBundleTx
	}

	if g.IsBundleTx(tx) {
		if uint(g.knownTxs.numQueue()) >= g.GetMaxBundleTxsInQueue() {
			return ErrBundleTxQueueFull
		}
		g.knownTxs.add(tx, TxStatusQueue)
	}
	return nil
}

type knownTxs map[common.Hash]*knownTx

func (k knownTxs) add(tx *types.Transaction, status int) {
	if tx == nil {
		return
	}

	if ktx, ok := k.get(tx.Hash()); ok {
		ktx.status = status
	} else {
		k[tx.Hash()] = &knownTx{
			tx:           tx,
			addedTime:    time.Time{},
			promotedTime: time.Time{},
			status:       status,
		}
	}

	if status == TxStatusQueue {
		k[tx.Hash()].startAddedTimeIfZero()
	} else if status == TxStatusPending {
		k[tx.Hash()].startPromotedTimeIfZero()
	}

	updateMetrics(&k)
}

func (k knownTxs) addKnownTx(knownTx *knownTx) {
	if ktx, ok := k.get(knownTx.tx.Hash()); ok {
		ktx.status = knownTx.status
	} else {
		k[knownTx.tx.Hash()] = knownTx
	}
	updateMetrics(&k)
}

func (k knownTxs) get(hash common.Hash) (*knownTx, bool) {
	tx, ok := k[hash]
	return tx, ok
}

func (k knownTxs) has(hash common.Hash) bool {
	_, ok := k[hash]
	return ok
}

func (k knownTxs) delete(hash common.Hash) {
	delete(k, hash)
	updateMetrics(&k)
}

func (k knownTxs) numPending() int {
	num := 0
	for _, knownTx := range k {
		if knownTx.status == TxStatusPending {
			num++
		}
	}
	return num
}

func (k knownTxs) numExecutable() int {
	num := 0
	for _, knownTx := range k {
		if knownTx.status == TxStatusPending && !knownTx.tx.IsMarkedUnexecutable() {
			num++
		}
	}
	return num
}

func (k knownTxs) numQueue() int {
	num := 0
	for _, knownTx := range k {
		if knownTx.status == TxStatusQueue {
			num++
		}
	}
	return num
}
