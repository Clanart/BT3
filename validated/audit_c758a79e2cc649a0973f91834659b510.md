Based on the codebase evidence, I found a concrete local analog. The "IntentGateway only accepts incoming assets from itself or known instances" comment reveals the exact same class of missing/incomplete sender authentication described in the Allora report — but here it manifests as an insecure fallback in the Tron `IntentGatewayV2` contract's `instance()` resolver.

### Title
Insecure self-fallback in `instance()` breaks `authenticate()`, allowing forged `RedeemEscrow`/`RefundEscrow` requests from any unregistered chain to drain escrow - (File: `evm/tron/contracts/apps/IntentGatewayV2.sol`)

### Summary
`IntentGatewayV2.onAccept` authenticates `RedeemEscrow`/`RefundEscrow` requests via `authenticate(request)`, which compares the incoming request's `from` address against `instance(request.source)`. [1](#0-0)  However, `instance()` does not revert for state machines with no registered gateway — it falls back to returning `address(this)`: [2](#0-1)  This means any chain that Hyperbridge/ISMP recognizes as a valid `StateMachine` but for which the protocol has never configured an `_instances` entry is implicitly treated as authenticating "from itself."

### Finding Description
`authenticate()` is meant to verify that an incoming POST request genuinely originates from a registered IntentGateway deployment on the claimed source chain (`_instances[keccak256(source)]`). The intended invariant, mirrored correctly in the newer EVM version's `_instance()` helper which reverts with `UnknownInstance` on an unregistered chain [3](#0-2) , is broken in the Tron contract: its `instance()` returns `address(this)` instead of reverting when no gateway is registered for `request.source`:

```solidity
function instance(bytes calldata stateMachineId) public view returns (address) {
    address gateway = _instances[keccak256(stateMachineId)];
    return gateway == address(0) ? address(this) : gateway;
}

function authenticate(PostRequest calldata request) internal view {
    if (request.from.length != 20) revert InvalidInput();
    address module = address(bytes20(request.from));
    if (instance(request.source) != module) revert Unauthorized();
}
``` [2](#0-1) 

Because the codebase explicitly documents that contracts are deployed deterministically via CREATE2 to preserve identical addresses across all chains ("preserving the deterministic CREATE2 deployment addresses" [4](#0-3) ), an attacker who deploys the same bytecode via the same CREATE2 factory + salt on ANY EVM-compatible state machine that ISMP will treat as a legitimate source — even one where the protocol never deployed/registered an official IntentGateway instance — obtains a contract at the exact same address as the real `IntentGatewayV2` (`address(this)`) on the destination chain. That attacker-controlled contract can then dispatch a forged `RedeemEscrow`/`RefundEscrow` message with `from = address(this)` (satisfied automatically, since the ISMP host sets `from` to the dispatching contract's own address, which now collides with the target's self-address), and `source` equal to that unregistered chain. `authenticate()` then computes `instance(source) == address(this)` (fallback) `== module`, and the check incorrectly passes.

### Impact Explanation
Once `authenticate()` is bypassed, `onAccept` calls `withdraw(body, kind == RequestKind.RefundEscrow)` with an attacker-chosen `WithdrawalRequest` (commitment, token list, beneficiary): [1](#0-0) . `withdraw()` transfers out the escrowed token amounts recorded under `_orders[commitment][token]` to an attacker-controlled beneficiary and decrements the escrow accounting: [5](#0-4) . An attacker can target the `commitment` of any real, publicly-observable escrowed order and redirect its escrowed funds to themselves, or replay refunds — this is a direct theft/unauthorized withdrawal of bridged/escrowed user funds.

### Likelihood Explanation
This requires no privileged actor, relayer, or admin — only an unprivileged attacker able to (a) deploy a contract via the standard deterministic CREATE2 factory that reproduces the `IntentGatewayV2` address on some chain ISMP accepts as a valid `StateMachine` source but which has no `_instances` entry configured, and (b) dispatch a crafted ISMP POST request through that contract targeting a real deployment with known escrowed orders. Given the pattern of deterministic, address-preserving deployments used throughout this codebase, obtaining a same-address deployment on an alternate/unregistered chain is a normal, expected, publicly-documented deployment technique rather than an exotic collision.

### Recommendation
Change `instance()` to revert (e.g., with `UnknownInstance`) when no gateway is registered for the given state machine, matching the fixed behavior already present in `evm/src/apps/intentsv2/IntentsBase.sol`'s `_instance()`, instead of silently falling back to `address(this)`.

### Proof of Concept
1. Note that a real order with `commitment = C` and escrowed `TokenInfo[] tokens` exists on the destination `IntentGatewayV2` (observable on-chain via `placeOrder`/`_orders`).
2. Attacker deploys arbitrary bytecode via the same CREATE2 factory/salt used to deploy the real `IntentGatewayV2`, but on any EVM `StateMachine` id `X` for which the protocol has never called `NewDeployment`/set `_instances[keccak256(X)]` — the resulting contract address equals `address(this)` of the real target.
3. From that contract, dispatch an ISMP POST request to the real `IntentGatewayV2` with `body = RequestKind.RedeemEscrow ++ abi.encode(WithdrawalRequest({commitment: C, tokens: tokens, beneficiary: attacker}))`.
4. On delivery, `onAccept` → `authenticate()` computes `instance(X) == address(0)-fallback == address(this) == module (attacker's contract address)` → passes.
5. `withdraw()` transfers the escrowed tokens for commitment `C` to the attacker's `beneficiary`, draining the real user's escrow. [6](#0-5)

    function onAccept(IncomingPostRequest calldata incoming) external override onlyHost {
        RequestKind kind = RequestKind(uint8(incoming.request.body[0]));
        if (kind == RequestKind.RedeemEscrow || kind == RequestKind.RefundEscrow) {
            authenticate(incoming.request);
            WithdrawalRequest memory body = abi.decode(incoming.request.body[1:], (WithdrawalRequest));
            return withdraw(body, kind == RequestKind.RefundEscrow);
        }

        // only hyperbridge is permitted to perfom these actions
        if (keccak256(incoming.request.source) != keccak256(IDispatcher(host()).hyperbridge())) revert Unauthorized();
        if (kind == RequestKind.NewDeployment) {
            NewDeployment memory body = abi.decode(incoming.request.body[1:], (NewDeployment));
            _instances[keccak256(body.stateMachineId)] = body.gateway;

            emit NewDeploymentAdded({stateMachineId: body.stateMachineId, gateway: body.gateway});
        } else if (kind == RequestKind.UpdateParams) {
            // Decode the body which includes optional destination-specific protocol fee updates

                    ++i;

    /**
     * @notice Withdraws the escrowed tokens for a request body.
     * @dev This function is marked as internal.
     * @param body The request body containing commitment, tokens, and beneficiary.
     * @param isRefund Whether this is a refund (true) or a successful fill (false).
     */
    function withdraw(WithdrawalRequest memory body, bool isRefund) internal {
        address beneficiary = address(uint160(uint256(body.beneficiary)));
        _filled[body.commitment] = beneficiary;

        // redeem escrowed tokens
        uint256 len = body.tokens.length;
        for (uint256 i; i < len;) {
            address token = address(uint160(uint256(body.tokens[i].token)));
            uint256 amount = body.tokens[i].amount;
            if (_orders[body.commitment][token] == 0) revert UnknownOrder();

            if (token == address(0)) {
                (bool sent,) = beneficiary.call{value: amount}("");
                if (!sent) revert InsufficientNativeToken();
            } else {
                (bool success,) = token.call(abi.encodeWithSelector(IERC20.transfer.selector, beneficiary, amount));
                if (!success) revert TransferFailed();
            }

            _orders[body.commitment][token] -= amount;
            unchecked {
                ++i;
            }
        }

        // redeem tx fees
        uint256 fees = _orders[body.commitment][TRANSACTION_FEES];
        if (fees > 0) {
            address feeToken = IDispatcher(host()).feeToken();
            (bool success,) = feeToken.call(abi.encodeWithSelector(IERC20.transfer.selector, beneficiary, fees));
            if (!success) revert TransferFailed();
            delete _orders[body.commitment][TRANSACTION_FEES];
        }

        if (isRefund) {
            emit EscrowRefunded({commitment: body.commitment});
        } else {
            emit EscrowReleased({commitment: body.commitment});
        }
    }
