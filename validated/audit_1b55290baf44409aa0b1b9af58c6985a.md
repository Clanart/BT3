### Title
Cached FROST preprocess seed is reused across `sign` invocations for the same context, enabling nonce reuse and secret-share recovery - (File: coordinator/src/tributary/signing_protocol.rs)

### Summary
`SigningProtocol::preprocess_internal` stores the FROST preprocess as a 32-byte ChaCha20 seed in `CachedPreprocesses`, keyed only by `context` (e.g., `(b"DkgConfirmer", attempt)`). Every call to `share_internal` reloads that same seed and regenerates the *identical* nonce pair `(d, e)` via `AlgorithmMachine::seeded_preprocess`. Because the cache is keyed on the attempt context rather than on the signing set and message, and is never invalidated after first use, any second `sign` within the same context that sees a different participant/preprocess set or a different `key_pair` message produces a second signature share under the same nonces but different binding factors `ρ`, Lagrange coefficients `λ`, and challenges `c` — the classic FROST nonce-reuse condition that leaks the secret key share.

### Finding Description
- `preprocess_internal` writes `CachedPreprocesses[context]` once and then, on every subsequent call for the same context, loads it back and calls `AlgorithmSignMachine::from_cache(algorithm, keys, CachedPreprocess(cached))`, which deterministically re-derives the nonces from the seed (`ChaCha20Rng::from_seed(*seed.0)` → `Commitments::new` → `C::random_nonce`). Nothing deletes or bumps the entry after `sign` runs. [1](#0-0) [2](#0-1) 
- `share_internal` calls `preprocess_internal` fresh on every invocation, so each call re-materializes a machine with the same `(d, e)`. Both `DkgConfirmer::share` and `DkgConfirmer::complete` route through `share_internal`, and `complete` accepts its own caller-supplied `preprocesses` map and `key_pair`, which need not equal the values used in the earlier `share` call. [3](#0-2) [4](#0-3) 
- The per-call variables that differentiate shares — `included` set, `ρ` (bound to `hash_commitments` of all preprocesses), `λ` (participant index within the set), and the message — are all computed inside `sign` from the caller-supplied maps and message, while the nonce scalars stay fixed. [5](#0-4) 
- The library itself documents that preprocess reuse enables third-party recovery of the private key share; the coordinator layer reuses it implicitly because the DB entry survives and is reloaded rather than consumed. [6](#0-5) 

### Impact Explanation
An unprivileged network participant who can deliver preprocess bytes (parsed via `read_preprocess`) or otherwise influence the `preprocesses`/`key_pair` maps across successive `share_internal`/`complete` calls for the same attempt causes the victim to sign twice with identical `(d, e)` under different `(ρ, λ, c)`. Each published share satisfies `s_j = d + e·ρ_j + λ_j·c_j·x`; collecting independent equations from repeat invocations lets the attacker solve the linear system for `x`, the victim's threshold secret share — full key-share recovery (Critical-class outcome per the scope rules). Analogous to the VDF report: a value whose security rests on the attacker not being able to obtain/precompute a reusable instance is instead deterministically regenerated and reused.

### Likelihood Explanation
- Reuse across `share()` → `complete()` is inherent in the code path (two `share_internal` calls per attempt); whether the attacker can vary the inputs between them depends on the tributary handler passing different preprocess sets or key pairs to each — plausible under equivocating peers, though I could not fully trace `handle.rs` call counts within the iteration limit.
- Even with identical inputs on both calls, the cache persisting for the entire attempt means any retry logic, crash recovery mid-attempt, or a second protocol message triggering `share` again produces the same nonces. The encryption of the cached seed does not mitigate this; the reuse itself is the vulnerability, not DB read access.
- The scan-time caveat: if the handler provably invokes `share` exactly once per context and `complete` never publishes its internally regenerated share, severity drops; that invariant is not enforced or asserted anywhere in the code shown.

### Recommendation
- Bind the cached preprocess to everything it will sign over: store/cache under `hash(context || msg || sorted participant/preprocess set)` or store the signed-share input alongside the seed and abort if a subsequent call presents different inputs.
- Consume-and-delete `CachedPreprocesses[context]` on the first `sign` (atomically in the same DB transaction that emits the share) so a second invocation cannot regenerate the nonces.
- Prefer deleting the deterministic `from_cache` replay path for `share`/`complete` recomputation — cache the produced `SignatureShare` instead of re-deriving it.

### Proof of Concept
Sketch (requires a coordinator node and a malicious peer able to feed preprocesses):

1. In attempt `k`, ensure `DkgConfirmer::share` runs with preprocess set `P1` → cache contains seed `s`; victim emits `share1 = d + e·ρ1 + λ1·c1·x`.
2. Cause a second `share_internal` execution for the same attempt with a different set `P2` (e.g., an equivocating validator sends an extra/altered preprocess, or `complete` is called with a differing `preprocesses` map / `key_pair`). `from_cache` regenerates the same `(d, e)`; `sign` recomputes `ρ2`, `λ2`, `c2` → victim emits `share2 = d + e·ρ2 + λ2·c2·x`.
3. Repeat once more with `P3` if needed. With `ρ_j`, `λ_j`, `c_j` all computable by the attacker from the public preprocesses and message, solve the linear system over the scalar field for `x` — the victim's MuSig/FROST secret share.

Untrusted inputs enter via `Commitments::read`/`read_preprocess` (in scope), and the output is a signature share broadcast to peers, satisfying the reachability rule for key-share recovery.

  fn share_internal(
    &mut self,
    participants: &[<Ristretto as Ciphersuite>::G],
    mut serialized_preprocesses: HashMap<Participant, Vec<u8>>,
    msg: &[u8],
  ) -> Result<(AlgorithmSignatureMachine<Ristretto, Schnorrkel>, [u8; 32]), Participant> {
    let machine = self.preprocess_internal(participants).0;

    let mut participants = serialized_preprocesses.keys().copied().collect::<Vec<_>>();
    participants.sort();
    let mut preprocesses = HashMap::new();
    for participant in participants {
      preprocesses.insert(
        participant,
        machine
          .read_preprocess(&mut serialized_preprocesses.remove(&participant).unwrap().as_slice())
          .map_err(|_| participant)?,
      );
    }

    let (machine, share) = machine.sign(preprocesses, msg).map_err(|e| match e {
      FrostError::InternalError(e) => unreachable!("FrostError::InternalError {e}"),
      FrostError::InvalidParticipant(_, _) |
      FrostError::InvalidSigningSet(_) |
      FrostError::InvalidParticipantQuantity(_, _) |
      FrostError::DuplicatedParticipant(_) |
      FrostError::MissingParticipant(_) => unreachable!("{e:?}"),
      FrostError::InvalidPreprocess(p) | FrostError::InvalidShare(p) => p,
    })?;

    Ok((machine, share.serialize().try_into().unwrap()))
  }

  fn seeded_preprocess(
    self,
    seed: CachedPreprocess,
  ) -> (AlgorithmSignMachine<C, A>, Preprocess<C, A::Addendum>) {
    let mut params = self.params;

    let mut rng = ChaCha20Rng::from_seed(*seed.0);
    let (nonces, commitments) = Commitments::new::<_>(
      &mut rng,
      params.keys.original_secret_share(),
      &params.algorithm.nonces(),
    );
    let addendum = params.algorithm.preprocess_addendum(&mut rng, &params.keys);

    let preprocess = Preprocess { commitments, addendum };

    // Also obtain entropy to randomly sort the included participants if we need to identify blame
    let mut blame_entropy = [0; 32];
    rng.fill_bytes(&mut blame_entropy);
    (
      AlgorithmSignMachine { params, seed, nonces, preprocess: preprocess.clone(), blame_entropy },
      preprocess,
    )
  }

  fn sign(
    mut self,
    mut preprocesses: HashMap<Participant, Preprocess<C, A::Addendum>>,
    msg: &[u8],
  ) -> Result<(Self::SignatureMachine, SignatureShare<C>), FrostError> {
    let multisig_params = self.params.multisig_params();

    let mut included = Vec::with_capacity(preprocesses.len() + 1);
    included.push(multisig_params.i());
    for l in preprocesses.keys() {
      included.push(*l);
    }
    included.sort_unstable();

    // Included < threshold
    if included.len() < usize::from(multisig_params.t()) {
      Err(FrostError::InvalidSigningSet("not enough signers"))?;
    }
    // OOB index
    if u16::from(included[included.len() - 1]) > multisig_params.n() {
      Err(FrostError::InvalidParticipant(multisig_params.n(), included[included.len() - 1]))?;
    }
    // Same signer included multiple times
    for i in 0 .. (included.len() - 1) {
      if included[i] == included[i + 1] {
        Err(FrostError::DuplicatedParticipant(included[i]))?;
      }
    }

    let view = self.params.keys.view(included.clone()).unwrap();
    validate_map(&preprocesses, &included, multisig_params.i())?;

    {
      // Domain separate FROST
      self.params.algorithm.transcript().domain_separate(b"FROST");
    }

    let nonces = self.params.algorithm.nonces();
    #[allow(non_snake_case)]
    let mut B = BindingFactor(HashMap::<Participant, _>::with_capacity(included.len()));
    {
      // Parse the preprocesses
      for l in &included {
        {
          self
            .params
            .algorithm
            .transcript()
            .append_message(b"participant", C::F::from(u64::from(u16::from(*l))).to_repr());
        }

        if *l == self.params.keys.params().i() {
          let commitments = self.preprocess.commitments.clone();
          commitments.transcript(self.params.algorithm.transcript());

          let addendum = self.preprocess.addendum.clone();
          {
            let mut buf = vec![];
            addendum.write(&mut buf).unwrap();
            self.params.algorithm.transcript().append_message(b"addendum", buf);
          }

          B.insert(*l, commitments);
          self.params.algorithm.process_addendum(&view, *l, addendum)?;
        } else {
          let preprocess = preprocesses.remove(l).unwrap();
          preprocess.commitments.transcript(self.params.algorithm.transcript());
          {
            let mut buf = vec![];
            preprocess.addendum.write(&mut buf).unwrap();
            self.params.algorithm.transcript().append_message(b"addendum", buf);
          }

          B.insert(*l, preprocess.commitments);
          self.params.algorithm.process_addendum(&view, *l, preprocess.addendum)?;
        }
      }

      // Re-format into the FROST-expected rho transcript
      let mut rho_transcript = A::Transcript::new(b"FROST_rho");
      rho_transcript.append_message(b"group_key", self.params.keys.group_key().to_bytes());
      rho_transcript.append_message(b"message", C::hash_msg(msg));
      rho_transcript.append_message(
        b"preprocesses",
        C::hash_commitments(self.params.algorithm.transcript().challenge(b"preprocesses").as_ref()),
      );

      // Generate the per-signer binding factors
      B.calculate_binding_factors(&rho_transcript);

      // Merge the rho transcript back into the global one to ensure its advanced, while
      // simultaneously committing to everything
      self
        .params
        .algorithm
        .transcript()
        .append_message(b"rho_transcript", rho_transcript.challenge(b"merge"));
    }

    #[allow(non_snake_case)]
    let Rs = B.nonces(&nonces);

    let our_binding_factors = B.binding_factors(multisig_params.i());
    let nonces = self
      .nonces
      .drain(..)
      .enumerate()
      .map(|(n, nonces)| {
        let [base, mut actual] = nonces.0;
        *actual *= our_binding_factors[n];
        *actual += base.deref();
        actual
      })
      .collect::<Vec<_>>();

    let share = self.params.algorithm.sign_share(&view, &Rs, nonces, msg);
