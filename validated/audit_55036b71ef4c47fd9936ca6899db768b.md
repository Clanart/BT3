### Title
GetStakingInfo() can revert and halt block processing because it makes an untrusted view call into permissionlessly-registered CLPool contracts via CLRegistry - ([File: kaiax/staking/impl/getter.go])

### Summary
`StakingModule.getFromState()` retrieves consensus-critical staking data by calling the `MultiCallContract`, which in turn calls into `CLRegistry.getAllCLs()` to enumerate `CLPool` addresses and their staking amounts [1](#0-0) . `CLPool`/CL registration is a permissionless mechanism (any GC/validator manager can register a Consensus Liquidity pool), analogous to the audit's "protocol" that can misbehave. If any single registered `CLPool` (or the `CLRegistry` aggregation itself) reverts during this view call, `MultiCallDPStakingInfo` fails and `GetStakingInfo()` returns an error for the whole block, exactly like `blacklistProtocol()` reverting because it must call into the compromised protocol it is trying to act on.

### Finding Description
`GetStakingInfo()` is the single source of truth for validator/staking data used in reward distribution and validator-set computation [2](#0-1) . When Prague/Permissionless forks are active, it calls `readCLInfo()`, which performs a raw EVM `Call` into `MultiCallContract.multiCallDPStakingInfo()` [3](#0-2) . This one aggregated call internally must enumerate every registered CL pool (as modeled by `CLRegistryMockThreeCL.getAllCLs()` returning `nodeIds`, `gcIds`, and `clPools`) [4](#0-3) , and the real `MultiCallContract` binding (`multiCallDPStakingInfo`) is defined to return `nodeIds`, `clPools`, `stakingAmounts` in one shot [5](#0-4) .

Any failure inside this call chain — whether from `CLRegistry` itself or from a malicious/buggy `CLPool` contract that a validator has registered — surfaces as a single hard error, wrapped as `ErrCLRegistryCall` [6](#0-5)  and propagated all the way up through `getFromState`, `getFromStateByNumber`, and `GetStakingInfo` with no isolation or fallback for the offending entry [7](#0-6) .

This mirrors the reported bug class precisely: a system operation (`blacklistProtocol`) that must succeed unconditionally is coupled to a call into an entity that is explicitly expected to potentially be malicious/compromised (a to-be-blacklisted protocol, or here, a permissionlessly registered CL pool), with no try/catch or per-entry isolation.

### Impact Explanation
`GetStakingInfo()` is consumed by consensus-critical paths: `RewardModule.FinalizeState()` (deferred reward distribution at the end of every block) and reward-address lookups [8](#0-7)  and [9](#0-8) , as well as validator/qualification logic. If a single malicious `CLPool` contract is crafted to revert on the specific read the multicall performs against it, every node that must execute `FinalizeState` for the affected block would fail to compute rewards, since `GetStakingInfo` errors out entirely rather than skipping the bad entry. Because this failure is deterministic and reproducible by any node processing that state (not an attacker-controlled network fault), it does not necessarily cause state divergence between honest nodes (all would fail identically) — but it can halt block finalization/consensus liveness network-wide, and it can permanently block a legitimate validator's reward distribution and/or the retrieval of staking info via RPC (`kaia_getReward`, `kaia_getRewardsAccumulated`) for the affected block, since the same code path is reused for both roles.

### Likelihood Explanation
This requires an attacker/validator to register a `CLPool` (via the permissionless CL registration flow) whose implementation is designed to revert on the specific getter the MultiCall/CLRegistry integration invokes on it. Since CL pool deployment/registration is expected to be permissionless (open to any GC operator wishing to enable Consensus Liquidity), this is reachable by an ordinary network participant without requiring validator/consensus privileges — matching the "any transaction sender/registrant" reachability bar. The exact internal call signature the real (non-mock) `MultiCallContract.multiCallDPStakingInfo()` makes into each `CLPool` was not available in the indexed sources (only bytecode/bindings and Solidity mocks were found), so it is not proven with full certainty which specific call could be induced to revert or whether the real contract wraps per-pool calls in try/catch; this is the key remaining uncertainty.

### Recommendation
Wrap external calls into individual `CLPool` entries (and any other permissionlessly supplied addresses) inside `MultiCallContract.multiCallDPStakingInfo()` with a low-level `staticcall`/try-catch pattern so a single misbehaving pool is skipped (e.g., contributing zero stake) rather than reverting the entire aggregation. Additionally, harden `kaiax/staking/impl/getter.go`'s `readCLInfo()` to treat per-entry read failures as a partial result instead of a hard error that voids the whole `GetStakingInfo()` call.

### Proof of Concept
Conceptual PoC (cannot be fully verified against the real, non-mock `MultiCallContract`/`CLRegistry` Solidity source, which was not present in the indexed repository):
1. Deploy a `CLPool`-conforming contract whose relevant view function (the one queried by `multiCallDPStakingInfo`) always reverts.
2. Register this `CLPool` for a valid node via the standard permissionless CL registration path so it appears in `CLRegistry.getAllCLs()`.
3. At the next block where `RewardModule.FinalizeState()` (or an RPC call to `kaia_getReward`) triggers `StakingModule.GetStakingInfo()`, the call to `contract.MultiCallDPStakingInfo(callOpts)` reverts, `readCLInfo()` returns `staking.ErrCLRegistryCall(err)` [10](#0-9) , and `GetStakingInfo()`/`FinalizeState()` fails for that block.

func (s *StakingModule) GetStakingInfo(num uint64) (*staking.StakingInfo, error) {
	isKaia := s.ChainConfig.IsKaiaForkEnabled(new(big.Int).SetUint64(num))
	sourceNum := sourceBlockNum(num, isKaia, s.stakingInterval)

	// Try cache first
	if si, ok := s.stakingInfoCache.Get(sourceNum); ok {
		return si.(*staking.StakingInfo), nil
	}

	// Only before Kaia, try the database
	if !isKaia {
		if si := ReadStakingInfo(s.ChainKv, sourceNum); si != nil {
			s.stakingInfoCache.Add(sourceNum, si)
			return si, nil
		}
	}

	// Read from the state
	si, err := s.getFromStateByNumber(sourceNum)
	if err != nil {
		return nil, err
	}

	// Only before Kaia, write to database
	if !isKaia {
		WriteStakingInfo(s.ChainKv, sourceNum, si)
	}

	// Cache it
	s.stakingInfoCache.Add(sourceNum, si)
	return si, nil
}

func (_MultiCallContract *MultiCallContractCaller) MultiCallDPStakingInfo(opts *bind.CallOpts) (struct {
	NodeIds        []common.Address
	ClPools        []common.Address
	StakingAmounts []*big.Int
}, error) {
	var out []interface{}
	err := _MultiCallContract.contract.Call(opts, &out, "multiCallDPStakingInfo")

	outstruct := new(struct {
		NodeIds        []common.Address
		ClPools        []common.Address
		StakingAmounts []*big.Int
	})
	if err != nil {
		return *outstruct, err
	}

	outstruct.NodeIds = *abi.ConvertType(out[0], new([]common.Address)).(*[]common.Address)
	outstruct.ClPools = *abi.ConvertType(out[1], new([]common.Address)).(*[]common.Address)
	outstruct.StakingAmounts = *abi.ConvertType(out[2], new([]*big.Int)).(*[]*big.Int)

	return *outstruct, err

}

// Distribute the deferred rewards at the end of block processing.
func (r *RewardModule) FinalizeState(header *types.Header, state *state.StateDB, txs []*types.Transaction, receipts []*types.Receipt) error {
	if r.GovModule.GetParamSet(header.Number.Uint64()).ProposerPolicy == uint64(istanbul.WeightedRandom) && common.EmptyHash(header.Root) {
		qualified, err := r.ValsetModule.GetQualifiedValidators(header.Number.Uint64())
		if err != nil {
			return err
		}
		useRewardAddress := valset.NewAddressSet(qualified).Contains(r.NodeAddress)

		if rewardAddr := r.GetRewardAddress(header.Number.Uint64(), r.NodeAddress); useRewardAddress && rewardAddr != (common.Address{}) {
			header.Rewardbase = rewardAddr
			logger.Trace("Use reward address for nodeValidator", "header.Number", header.Number.Uint64(), "nodeAddress", r.NodeAddress, "rewardbase", header.Rewardbase)
		} else {
			logger.Trace("No reward address for nodeValidator. Use node's rewardbase.", "header.Number", header.Number.Uint64(), "nodeAddress", r.NodeAddress, "rewardbase", header.Rewardbase)
		}
	}

	spec, err := r.GetDeferredReward(header, txs, receipts)
	if err != nil {
		return err
	}
	if err := spec.Validate(); err != nil {
		return err
	}
	for addr, amount := range spec.Rewards {
		state.AddBalance(addr, amount)
	}
	return nil
}

func (r *RewardModule) GetRewardAddress(num uint64, nodeId common.Address) common.Address {
	sInfo, err := r.StakingModule.GetStakingInfo(num)
	if err != nil {
		return common.Address{}
	}

	for idx, id := range sInfo.NodeIds {
		if id == nodeId {
			return sInfo.RewardAddrs[idx]
		}
	}
	return common.Address{}
}
