### Title
Diff-header injection via literal `diff --git ` substring in file content causes vulnerable code to be silently dropped from LLM security review - ([File: plugins/security-guidance/hooks/gitutil.py])

### Finding Description
`extract_file_paths_from_diff` and `parse_diff_into_files` both split the entire unified-diff text on the literal string `"diff --git "` and then treat the first line of *every* resulting chunk as a real `diff --git` header: [1](#0-0) [2](#0-1) 

The split is `str.split("diff --git ")` — a plain substring split with **no line anchoring**. Real `git diff` only emits this string at the start of a line, but the split has no way to distinguish a genuine header from the same literal text occurring *inside an added/modified line* of a file's own content (e.g. a comment, string literal, or test fixture that itself contains `diff --git a/x b/y`). Any attacker-controlled source line containing that substring is enough to fabricate a bogus chunk boundary.

Exploit flow:
1. Attacker adds/controls a file, e.g. `evil.py`, whose diff hunk contains a line such as `+# diff --git a/x.lock b/x.lock` followed by the actual dangerous payload (`+os.system(cmd)`).
2. `diff_output.split("diff --git ")` cuts the text at that embedded occurrence. The tail of `evil.py`'s legitimate hunk (containing the dangerous line) becomes the start of a *new* fabricated chunk whose first line is `a/x.lock b/x.lock` — attacker-chosen text.

    files = []
    file_diffs = diff_output.split("diff --git ")

    for file_diff in file_diffs:
        if not file_diff.strip():
            continue

        # Extract filename from first line: "a/path/to/file b/path/to/file"
        lines = file_diff.split('\n')
        header_match = re.match(r'^a/(.+?) b/(.+)$', lines[0])
        if not header_match:
            continue

        file_path = header_match.group(2) or header_match.group(1) or ''

        # Filter to source code files only
        if not _is_reviewable_source(file_path):
            continue

        # Extract the diff content (from first @@ onwards)
        diff_lines = []
        in_hunks = False
        for line in lines[1:]:
            if line.startswith('@@'):
                in_hunks = True
            if in_hunks:
                diff_lines.append(line)

        if diff_lines:
            files.append((file_path, '\n'.join(diff_lines)))

    return files
