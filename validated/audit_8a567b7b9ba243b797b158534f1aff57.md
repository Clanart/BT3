### Title
Gasless swap allowance is checked once at tx-pool admission but never re-verified before block inclusion, allowing sender-side allowance revocation to grief the fee-delegating proposer - (File: kaiax/gasless/impl/tx_pool.go, kaiax/gasless/impl/builder.go)

### Summary
The `kaiax/gasless` module implements KIP-247 gasless transactions where a block proposer prepays (lends) gas for a user via `LendTxGenerator`, and the user is expected to repay via a `GaslessSwapTx` that calls `SwapForGas` on the `GaslessSwapRouter`. Whether the router is authorized to pull the user's tokens (the actual value backing the repayment) is tracked entirely off-module, in the ERC20 token contract's own `allowance` mapping — mirroring the reported bug class of "allowances tracked in a different contract than the one enforcing the guarantee." The `gasless` module only reads that external allowance state once, at initial tx-pool admission, and never re-checks it when the bundle is later assembled into a block.

### Finding Description
When a `GaslessSwapTx` is first submitted to the pool, `checkBalanceForSwap` queries the token's live on-chain allowance and rejects the tx if insufficient: [1](#0-0) 

This check is explicitly skipped whenever a preceding `GaslessApproveTx` is expected (`noApproveTxPreceeds == false`), relying instead on the approve tx to establish the allowance later. But even in the branch where the check *is* performed (`noApproveTxPreceeds == true`, i.e., no approve tx accompanies this swap and an allowance is assumed to already exist), this is a point-in-time check executed only in `GetCheckBalance()`, invoked when the transaction is accepted into the pool.

Later, when the block builder actually assembles the gasless bundle `[LendTxGenerator, (ApproveTx), SwapTx]`, the only executability check performed is `IsExecutable` → `VerifyExecutable`, which validates purely calldata-decoded values (nonces, token match, `approveArgs.Amount >= swapArgs.AmountIn`, repay amount) — it never re-queries the token's actual on-chain `allowance`: [2](#0-1) [3](#0-2) 

Because a `GaslessSwapTx` submitted without an accompanying `ApproveTx` can sit in the pending pool for up to `PendingTimeout` (10s, and potentially longer across re-broadcast/backlog) before being bundled and mined: [4](#0-3) 

...the sender can, after the swap tx already passed admission, send an ordinary `approve(router, 0)` or `decreaseAllowance` call (or transfer away the tokens) to revoke the allowance the swap depended on. Nothing in the pool-promotion path (`isReady`/`isSwapTxReady`) or in bundle building re-validates the allowance against current chain state before the proposer commits to lending gas: [5](#0-4) 

### Impact Explanation
The `LendTxGenerator` transaction inside the bundle unconditionally transfers gas-fee value to the sender before `SwapForGas` executes in the same bundle. If the sender revokes/consumes the allowance after admission but before block inclusion, `SwapForGas`'s internal `transferFrom` will fail/revert (insufficient allowance), meaning the sender never repays the lent amount while the `LendTx` funds transfer already succeeded. This is a direct, unrecoverable value loss to the block proposer — the fee-delegation counterparty — triggerable by an ordinary unprivileged sender using only standard ERC20 calls plus the normal RPC submission path (`eth_sendRawTransaction`/`debug_isGaslessTx`), with no need for validator or peer compromise.

### Likelihood Explanation
The attack requires no special privileges: any account holding an allowed gasless token can submit a standalone `GaslessSwapTx` (or an approve+swap pair) and then, within the pending-pool window, submit a normal `approve`/`transfer` to invalidate the allowance the swap will rely on. Given `PendingTimeout` is 10 seconds and mempool/backlog conditions can extend this further, the window is realistic and repeatable per sender, per block.

### Recommendation
Re-verify the token's actual on-chain allowance (and balance) for the swap sender against the router immediately before/at the point the `LendTxGenerator` executes within the bundle — e.g., have the `GaslessSwapRouter` contract itself check allowance atomically as part of `SwapForGas`, and only release the lend transfer after that check succeeds within the same atomic bundle/transaction (or perform the allowance re-check in `ExtractTxBundles`/`IsExecutable` against fresh state right before bundle inclusion, not just at admission time). Document explicitly that allowance state is externally owned by the ERC20 token and is not centrally tracked by the gasless module, and ensure the repay step cannot be decoupled from a verified, current allowance.

### Proof of Concept
1. Attacker holds token `T`, `T` is in `AllowedTokens`, and `GaslessSwapRouter` is the module's configured router.
2. Attacker submits `GaslessSwapTx` (no accompanying approve, i.e., `swapNonce == senderNonce`) with a pre-existing valid allowance ≥ `amountIn`; it passes `checkBalanceForSwap`'s allowance check at admission (`kaiax/gasless/impl/tx_pool.go:151-163`) and enters the pending pool.
3. Before the tx is mined (within `PendingTimeout`), attacker sends a normal `approve(router, 0)` transaction for token `T` from the same account, executed and included first (e.g., with higher gas price/nonce ordering it earlier).
4. The block proposer's bundle builder (`ExtractTxBundles`/`IsExecutable`) does not re-check allowance, so it still includes `[LendTxGenerator, SwapTx]` in the block.
5. `LendTxGenerator` transfers gas value to the attacker; `SwapForGas` subsequently reverts due to zero allowance, so no repayment occurs — the proposer's lent gas is lost.

// isSwapTxReady assumes that the caller checked `g.IsSwapTx(swapTx)`
func (g *GaslessModule) isSwapTxReady(swapTx, prevTx *types.Transaction) bool {
	addr, err := types.Sender(g.signer, swapTx)
	if err != nil {
		return false
	}
	nonce := g.getCurrentStateNonce(addr)

	var approveTx *types.Transaction
	if swapTx.Nonce() == nonce {
		approveTx = nil
	} else if swapTx.Nonce() == nonce+1 {
		if prevTx == nil || !g.IsApproveTx(prevTx) {
			return false
		}
		approveTx = prevTx
	} else {
		return false
	}

	return g.IsExecutable(approveTx, swapTx)
}

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
}
