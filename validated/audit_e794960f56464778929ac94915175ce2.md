### Title
`MsgRegisterPointer` accepts an ERC address with no deployed code, letting a CW20/CW721/CW1155 pointer be created for a phantom ERC contract - (File: x/evm/types/message_register_pointer.go)

### Summary
The Sherlock report flags that `Factory.deploySurgePool` and `Pool.safeTransfer`/`safeTransferFrom` never verify that the `token` address parameter actually has code, so a low-level call to a non-contract address silently "succeeds" and the caller believes a transfer happened. The same class of bug (accepting an unverified counterpart address and relying on the low-level-call-to-empty-address-succeeds quirk) is reachable in sei-chain's CW↔EVM pointer bridge.

### Finding Description
`MsgRegisterPointer.ValidateBasic()` only checks that `ErcAddress` is a syntactically valid hex address via `common.IsHexAddress` — it never checks that the address has EVM code deployed: [1](#0-0) 

`msgServer.RegisterPointer` then instantiates (or migrates) a CosmWasm pointer contract keyed to that raw address without any code-existence check: [2](#0-1) 

This is confirmed by `TestMigrateCWERC20Pointers`, which successfully registers an ERC20 pointer for the literal zero address `0x0000000000000000000000000000000000000000` (an address that obviously has no code): [3](#0-2) 

The resulting CW20 pointer contract's `transfer`/`transfer_from` handlers wrap the target address in an `EvmMsg::DelegateCallEvm` and never validate a return value beyond whatever the EVM message-call framework reports: [4](#0-3) 

Underneath, calls to an address with no code go through `CallEVM`/`StaticCallEVM`, which build an `evmMsg` and execute it via `applyEVMMessage`; per standard EVM semantics, a `CALL`/`DELEGATECALL` to an address with empty code returns success with empty return data instead of failing: [5](#0-4) 

So a pointer registered against a non-contract (EOA, zero address, or an address that has not yet deployed code) will have every `transfer`/`transferFrom`/`approve` "succeed" from the EVM's perspective while moving zero tokens, exactly mirroring the Sherlock finding's core defect: the callee address is never checked to have code before being treated as a token/contract, and empty-code calls are indistinguishable from successful ones.

### Impact Explanation
Any unprivileged public-RPC/CLI user can submit `MsgRegisterPointer` for an arbitrary, non-contract EVM address (a random EOA or a not-yet-deployed CREATE2 address) and receive a live CW20/CW721/CW1155 pointer contract that is treated by other bridge code (the `execute` precompile's pointer-authorization check, indexers, integrators) as a genuine, functioning ERC20/721/1155 wrapper. Downstream systems (DEXs, wallets, integrators who trust "if `RegisterPointer` succeeded and the query interface responds, this is a real token") can be misled into believing balances/transfers occurred when nothing moved, which is the fund-loss/confusion vector the Sherlock report is warning about, adapted from Solidity `safeTransfer` misuse to sei-chain's pointer-registration bridge.

### Likelihood Explanation
Likelihood is high for triggering the state (any signer can send `MsgRegisterPointer` for any syntactically valid hex address, no special permission required, and the CLI command is directly exposed: `seid tx evm register-cw-pointer`), but the severity depends on whether a real integrator is fooled — this requires a social/integration precondition rather than an on-chain race, so it is a "High" rather than "Critical" analog.

### Recommendation
In `MsgRegisterPointer.ValidateBasic()` or in `msgServer.RegisterPointer`, before instantiating/migrating the pointer contract, verify that `ErcAddress` has non-empty EVM code (e.g., `k.GetCodeSize(ctx, common.HexToAddress(msg.ErcAddress)) > 0`) and reject the message otherwise, analogous to adding `require(address(_token).code.length != 0)` in the audited Solidity fix.

### Proof of Concept
1. Call `seid tx evm register-cw-pointer ERC20 0x0000000000000000000000000000000000000000` (or any EOA/未部署 address) from any funded account.
2. Observe the transaction succeeds and a CW20 pointer contract is created and registered via `SetCW20ERC20Pointer`, as reproduced by `TestMigrateCWERC20Pointers`.
3. Call `transfer`/`transferFrom` on the resulting pointer; the underlying `DelegateCallEvm`/`CallEVM` to the code-less address returns success with no state change, so the pointer's execution reports success without any tokens actually moving — indistinguishable on-chain from a legitimate transfer to consumers who only check for tx success.

func (msg *MsgRegisterPointer) ValidateBasic() error {
	_, err := sdk.AccAddressFromBech32(msg.Sender)
	if err != nil {
		return sdkerrors.Wrapf(sdkerrors.ErrInvalidAddress, "Invalid sender address (%s)", err)
	}

	if !common.IsHexAddress(msg.ErcAddress) {
		return sdkerrors.ErrInvalidAddress
	}

	return nil
}

func TestMigrateCWERC20Pointers(t *testing.T) {
	k := testkeeper.EVMTestApp.EvmKeeper
	ctx := testkeeper.EVMTestApp.GetContextForDeliverTx([]byte{}).WithBlockTime(time.Now())
	params := k.GetParams(ctx)
	params.RegisterPointerDisabled = false
	k.SetParams(ctx, params)
	require.Nil(t, migrations.StoreCWPointerCode(ctx, &k, true, false, false))
	msgServer := keeper.NewMsgServerImpl(&k)
	res, err := msgServer.RegisterPointer(sdk.WrapSDKContext(ctx), &types.MsgRegisterPointer{
		PointerType: types.PointerType_ERC20,
		ErcAddress:  "0x0000000000000000000000000000000000000000",
	})
	require.Nil(t, err)
	require.Nil(t, migrations.MigrateCWERC20Pointers(ctx, &k))
	// address should stay the same
	addr, _, _ := k.GetCW20ERC20Pointer(ctx, common.HexToAddress("0x0000000000000000000000000000000000000000"))
	require.Equal(t, res.PointerAddress, addr.String())
}

fn transfer(
    deps: DepsMut<EvmQueryWrapper>,
    _env: Env,
    info: MessageInfo,
    recipient: String,
    amount: Uint128,
) -> Result<Response<EvmMsg>, ContractError> {
    deps.api.addr_validate(&recipient)?;

    let erc_addr = ERC20_ADDRESS.load(deps.storage)?;

    let querier = EvmQuerier::new(&deps.querier);
    let payload = querier.erc20_transfer_payload(recipient.clone(), amount)?;
    let msg = EvmMsg::DelegateCallEvm { to: erc_addr, data: payload.encoded_payload };
    let res = Response::new()
        .add_attribute("from", info.sender)
        .add_attribute("to", recipient)
        .add_attribute("amount", amount)
        .add_message(msg);

    Ok(res)
}

func (k *Keeper) CallEVM(ctx sdk.Context, from common.Address, to *common.Address, val *sdk.Int, data []byte) (retdata []byte, reterr error) {
	if ctx.IsEVM() && !ctx.EVMEntryViaWasmdPrecompile() {
		return nil, errors.New("sei does not support EVM->CW->EVM call pattern")
	}
	if to == nil && len(data) > params.MaxInitCodeSize {
		return nil, fmt.Errorf("%w: code size %v, limit %v", core.ErrMaxInitCodeSizeExceeded, len(data), params.MaxInitCodeSize)
	}
	if to != nil && to.Cmp(common.HexToAddress(solo.SoloAddress)) == 0 {
		return nil, errors.New("cannot call Solo precompile via CosmWasm")
	}
	value := utils.Big0
	if val != nil {
		if val.IsNegative() {
			return nil, sdkerrors.ErrInvalidCoins
		}
		value = val.BigInt()
	}
	// This call was not part of an existing StateTransition, so it should trigger one
	executionCtx := ctx.WithGasMeter(sdk.NewInfiniteGasMeterWithMultiplier(ctx)).WithEVMEntryViaWasmdPrecompile(false)
	stateDB := state.NewDBImpl(executionCtx, k, false)
	gp := k.GetGasPool()
	evmMsg := &core.Message{
		Nonce:     stateDB.GetNonce(from), // replay attack is prevented by the AccountSequence number set on the CW transaction that triggered this call
		GasLimit:  k.getEvmGasLimitFromCtx(ctx),
		GasPrice:  utils.Big0, // fees are already paid on the CW transaction
		GasFeeCap: utils.Big0,
		GasTipCap: utils.Big0,
		To:        to,
		Value:     value,
		Data:      data,
		From:      from,
	}
	// should not increment nonce since this isn't a transaction
	res, err := k.applyEVMMessage(ctx, evmMsg, stateDB, gp, false)
	if err != nil {
		return nil, err
	}
	k.consumeEvmGas(ctx, res.UsedGas)
	if res.Err != nil {
		return nil, res.Err
	}
	surplus, err := stateDB.Finalize()
	if err != nil {
		return nil, err
	}
	vmErr := ""
	if res.Err != nil {
		vmErr = res.Err.Error()
	}
	existingReceipt, err := k.GetTransientReceipt(ctx, ctx.TxSum(), uint64(ctx.TxIndex())) //nolint:gosec
	if err == nil {
		for _, l := range existingReceipt.Logs {
			stateDB.AddLog(&ethtypes.Log{
				Address: common.HexToAddress(l.Address),
				Topics:  utils.Map(l.Topics, common.HexToHash),
				Data:    l.Data,
			})
		}
		if existingReceipt.VmError != "" {
			vmErr = fmt.Sprintf("%s\n%s\n", existingReceipt.VmError, vmErr)
		}
	}
	existingDeferredInfo, found := k.GetEVMTxDeferredInfo(ctx)
	if found {
		surplus = surplus.Add(existingDeferredInfo.Surplus)
	}
	receipt, err := k.WriteReceipt(ctx, stateDB, evmMsg, ethtypes.LegacyTxType, ctx.TxSum(), res.UsedGas, vmErr, false)
	if err != nil {
		return nil, err
	}
	bloom := ethtypes.Bloom{}
	bloom.SetBytes(receipt.LogsBloom)
	k.AppendToEvmTxDeferredInfo(ctx, bloom, ctx.TxSum(), surplus)
	return res.ReturnData, nil
}
