### Title
Blind SSRF via Attacker-Controlled DataLayer Mirror URLs - ([File: chia/data_layer/data_layer.py], [File: chia/data_layer/download_data.py], [File: chia/wallet/db_wallet/db_wallet_puzzles.py])

### Summary
Any wallet user can create an on-chain "mirror" coin naming an arbitrary DataLayer `launcher_id` (store id) that they do **not** own, and attach arbitrary attacker-controlled URLs to it via unauthenticated coin memos. Any peer running a DataLayer service that later tracks/subscribes to that store id will automatically pull these URLs into its mirror/server list and issue outbound HTTP GET/POST requests to them without validating the destination, producing the same "blind SSRF via unvalidated preflight network request" pattern described in the Incus advisory (GHSA-8gw4-p4wq-4hcv).

### Finding Description
`DataLayerWallet.create_new_mirror()` builds a spend that creates a coin with the fixed `create_mirror_puzzle()` puzzle hash and stores `launcher_id` plus a list of URLs directly in the coin's `memos`, with no check that the caller owns or is otherwise authorized for that `launcher_id`: [1](#0-0) 

The RPC path `WalletRpcApi.dl_new_mirror()` forwards the caller-supplied `launcher_id` and `urls` straight into `create_new_mirror()` with no ownership validation: [2](#0-1) 

When any wallet observes a spend creating a coin with this mirror puzzle hash, it decodes the memos to recover `launcher_id` and `urls` and, if that launcher is tracked, stores the mirror unconditionally — no validation of URL scheme/host, and no check that the mirror creator is related to the store owner: [3](#0-2) [4](#0-3) 

`DataLayer.update_subscriptions_from_wallet()` pulls these attacker-controlled mirror URLs from the wallet and stores them as candidate servers for the store: [5](#0-4) 

`DataLayer.fetch_and_validate()` then randomly selects one of these server URLs and immediately attempts a delta-file sync against it via `insert_from_delta_file()`, before any data or root validation occurs: [6](#0-5) 

`download_file()` performs the actual outbound network call: if no downloader plugin is configured it issues an HTTP GET directly at the attacker-supplied URL (`server_info.url + "/" + filename`) via `http_download()`; if a downloader plugin is configured, it instead issues an HTTP POST to a plugin endpoint carrying the attacker-supplied URL as JSON payload: [7](#0-6) [8](#0-7) 

Additionally, `DataLayer.get_downloader()` independently issues an HTTP POST containing the mirror URL to every configured downloader plugin's `/handle_download` endpoint, again with no scheme/host validation: [9](#0-8) 

No hostname/IP allow-listing, SSRF-protection, or scheme restriction exists anywhere in this flow — a grep across `chia/data_layer/*.py` for private-IP/localhost/metadata-endpoint filtering or URL validation logic found none relevant to outbound request destinations. The request is sent as soon as the store is a tracked subscription target, before any content is validated against the wallet-advertised Merkle root.

### Impact Explanation
This is a blind SSRF primitive reachable by any wallet holder with enough balance to pay the mirror-coin amount and fee — no ownership of the target DataLayer store is required. It allows an attacker to coerce any DataLayer-enabled node that subscribes to (or simply tracks) a targeted store into issuing outbound HTTP GET/POST requests to arbitrary attacker-chosen destinations (internal services, link-local metadata endpoints, unroutable address space) sourced from that node's host. This can be used to probe internal network topology, trigger interactions with internal APIs, or exfiltrate limited information via request timing/side channels — consistent with CWE-918 classification and the CVSS vector in the referenced advisory (network-reachable, low complexity, requires only low-privileged authentication).

### Likelihood Explanation
Likelihood is high: creating a mirror coin requires only a standard signed spend bundle (no special permissions), and the `launcher_id` and `urls` fields are fully attacker-controlled with zero server-side validation of the destination host. The only prerequisite is that some other party is tracking/subscribed to the targeted store id (a normal, common DataLayer usage pattern for consuming shared datasets), making exploitation practical against any actively-used public DataLayer store.

### Recommendation
- Restrict mirror creation so that the `launcher_id` referenced must be owned by (or otherwise authorized for) the spender, or otherwise treat mirrors from unrelated coins as unauthoritative and require explicit user opt-in before using them as sync servers.
- Validate mirror/downloader URLs before use: enforce an allow-list of schemes (e.g., `https`/`s3` only), reject loopback/link-local/private/metadata-service addresses, and resolve DNS defensively (re-check resolved IP before connecting, disallow redirects to blocked ranges).
- Require successful content/root validation evidence before treating a URL as a legitimate mirror for repeated automatic polling, and rate-limit/backoff unauthenticated mirror sources more aggressively.

### Proof of Concept
1. Attacker (any funded wallet, no relationship to the target store) runs:
   ```
   dl_new_mirror(launcher_id=<victim_store_id>, amount=1, urls=["http://169.254.169.254/latest/meta-data/"], fee=...)
   ```
   using `WalletRpcApi.dl_new_mirror` — this creates and pushes a valid, low-value spend bundle with no ownership check on `victim_store_id`. [2](#0-1) 
2. Any peer with a `DataLayer` service that tracks `victim_store_id` observes the mirror coin, decodes `launcher_id`/`urls` from memos, and stores it as an available server via `coin_added()`. [3](#0-2) 
3. On the next `periodically_manage_data()` cycle, that peer's `fetch_and_validate()` selects the attacker's URL and calls `download_file()` → `http_download()`, causing an outbound GET from the victim host to the attacker-chosen URL (in this example, the cloud metadata endpoint) before any data validation occurs. [6](#0-5) [8](#0-7)

```python
def create_mirror_puzzle() -> Program:
    return P2_PARENT.curry(Program.to(1))


MIRROR_PUZZLE_HASH = create_mirror_puzzle().get_tree_hash()


def get_mirror_info(
    parent_puzzle: Program | SerializedProgram, parent_solution: Program | SerializedProgram
) -> tuple[bytes32, list[bytes]]:
    assert type(parent_puzzle) is type(parent_solution)
    _, conditions = run_with_cost(parent_puzzle, INFINITE_COST, parent_solution)
    for condition in conditions.as_iter():
        if (
            condition.first().as_python() == ConditionOpcode.CREATE_COIN
            and condition.at("rf").as_python() == create_mirror_puzzle().get_tree_hash()
        ):
            memos: list[bytes] = condition.at("rrrf").as_python()
            launcher_id = bytes32(memos[0])
            return launcher_id, [url for url in memos[1:]]
    raise ValueError("The provided puzzle and solution do not create a mirror coin")
```

```python
    async def get_downloader(self, store_id: bytes32, url: str) -> PluginRemote | None:
        request_json = {"store_id": store_id.hex(), "url": url}
        for d in self.downloaders:
            async with aiohttp.ClientSession() as session:
                try:
                    async with session.post(
                        d.url + "/handle_download",
                        json=request_json,
                        headers=d.headers,
                        timeout=self.client_timeout,
                    ) as response:
                        res_json = await response.json()
                        if res_json["handle_download"]:
                            return d
                except Exception as e:
                    self.log.error(f"get_downloader could not get response: {type(e).__name__}: {e}")
        return None
```

```python
async def download_file(
    data_store: DataStore,
    target_filename_path: Path,
    store_id: bytes32,
    root_hash: bytes32,
    generation: int,
    server_info: ServerInfo,
    proxy_url: str | None,
    downloader: PluginRemote | None,
    timeout: aiohttp.ClientTimeout,
    client_foldername: Path,
    timestamp: int,
    log: logging.Logger,
    grouped_by_store: bool,
    group_downloaded_files_by_store: bool,
    max_delta_file_size: int,
) -> bool:
    if target_filename_path.exists():
        return True
    filename = get_delta_filename(store_id, root_hash, generation, grouped_by_store)

    if downloader is None:
        # use http downloader - this raises on any error
        try:
            await http_download(
                target_filename_path, filename, proxy_url, server_info, timeout, log, max_delta_file_size
            )
        except (asyncio.TimeoutError, aiohttp.ClientError, MaxDeltaFileSizeExceededError):
            new_server_info = await data_store.server_misses_file(store_id, server_info, timestamp)
            log.info(
                f"Failed to download {filename} from {new_server_info.url}."
                f"Miss {new_server_info.num_consecutive_failures}."
            )
            log.info(f"Next attempt from {new_server_info.url} in {new_server_info.ignore_till - timestamp}s.")
            return False
        return True

    log.info(f"Using downloader {downloader} for store {store_id.hex()}.")
    request_json = {
        "url": server_info.url,
        "client_folder": str(client_foldername),
        "filename": filename,
        "group_files_by_store": group_downloaded_files_by_store,
        "max_delta_file_size": max_delta_file_size,
    }
    try:
        async with aiohttp.ClientSession() as session:
            async with session.post(
                downloader.url + "/download",
                json=request_json,
                headers=downloader.headers,
                timeout=timeout,
            ) as response:
                res_json = await response.json()
                assert isinstance(res_json["downloaded"], bool)
                return res_json["downloaded"]
    except (asyncio.TimeoutError, aiohttp.ClientError) as e:
        log.error(f"download_file could not get response from plugin {downloader}: {type(e).__name__}: {e}")
        return False
```

```python
async def http_download(
    target_filename_path: Path,
    filename: str,
    proxy_url: str | None,
    server_info: ServerInfo,
    timeout: aiohttp.ClientTimeout,
    log: logging.Logger,
    max_delta_file_size: int,
) -> None:
    """
    Download a file from a server using aiohttp.
    Raises exceptions on errors
    """
    async with aiohttp.ClientSession() as session:
        headers = {"accept-encoding": "gzip"}
        async with session.get(
            server_info.url + "/" + filename,
            headers=headers,
            timeout=timeout,
            proxy=proxy_url,
        ) as resp:
            resp.raise_for_status()
            size = int(resp.headers.get("content-length", 0))
            max_delta_file_size_bytes = max_delta_file_size * 1024 * 1024
            if size > max_delta_file_size_bytes:
                raise MaxDeltaFileSizeExceededError(f"Maximum delta file size exceeded: {max_delta_file_size} MiB.")
            log.debug(f"Downloading delta file {filename}. Size {size} bytes.")
```
