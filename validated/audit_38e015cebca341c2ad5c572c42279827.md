### Title
Gasless swap `LendTx` value transfer is not guaranteed to be atomic with the repaying `SwapTx`, allowing a block proposer's lent KAIA to be lost - ([File: kaiax/gasless/impl/getter.go])

### Summary
The KIP-247 gasless-transaction mechanism lends native KAIA to a sender via a proposer-signed `LendTx` and expects the sender's `GaslessSwapTx` to repay that amount out of a token swap. The ERC20 balance/allowance checks that gate admission of the swap are only evaluated at tx-pool time against then-current state, not atomically re-validated with the value-transfer step, mirroring the root cause of the reported `LMPVaultRouterBase.deposit` bug: a step that assumes tokens/funds are already available performs an unconditional action first and a token-dependent pull/repay afterwards, with no guarantee the second step still succeeds.

### Finding Description
The gasless flow bundles `[LendTxGenerator, GaslessApproveTx(optional), GaslessSwapTx]` [1](#0-0)  where `GetLendTxGenerator` creates a transaction that unconditionally transfers `lendAmount(approveTxOrNil, swapTx)` KAIA from the block proposer's node key to the sender before the swap executes [2](#0-1) .

Admission of the swap into the pool only occurs after `checkBalanceForSwap`/`checkBalanceForApprove`, which check the ERC20 token balance/allowance of the sender against the router **at the time of the check**, not at actual block-inclusion time [3](#0-2) . This is explicitly documented as a substitute for the normal native-balance check that is skipped for these module transactions: "Sender balance check is omitted for gasless transactions (see `GetCheckBalance()`)" [4](#0-3) .

Because the `LendTx` sends real KAIA value to the sender regardless of whether the subsequent `GaslessApproveTx`/`GaslessSwapTx` end up succeeding on-chain (e.g., token balance/allowance changed, price moved past `minAmountOut`, or any other state change between the promotion-time check and actual EVM execution of `swapForGas`), the proposer's lent funds are not guaranteed to be repaid by a successful swap. This is structurally the same defect class as the reported issue: an unconditional value-moving action (`_processEthIn` minting WETH to the contract / here, `LendTx` sending KAIA to the sender) precedes a token-dependent pull/repay step (`pullToken` from the depositor / here, `swapForGas`'s `transferFrom`+swap-and-repay) whose success is not guaranteed at the time the first step executes.

### Impact Explanation
If the swap transaction fails to execute as expected (revert, or executes but the router does not actually forward the repay amount to the proposer due to state divergence from the check-time snapshot), the block proposer's lent KAIA is not recovered. Since block building constructs these transactions independently (each as its own top-level transaction within the block), a revert in the later `SwapTx` does not roll back the already-applied `LendTx` balance change unless the builder atomically re-verifies success of the whole bundle before finalizing the block — a guarantee not evidenced in the reviewed bundling code (`ExtractTxBundles`/`IncorporateBundleTx`), which addresses bundle *conflicts*, not partial execution failure. This is a concrete value-movement/fee-abuse risk against the block proposer.

### Likelihood Explanation
The gasless swap/approve path is directly reachable by any unprivileged transaction sender simply by submitting a `GaslessApproveTx`/`GaslessSwapTx` pair (or lone swap) that passes pool-level checks but is engineered (or happens, via normal market/token activity) to fail or under-repay at actual execution time — e.g., by moving/spending the approved token balance, or by exploiting price movement between the `checkBalanceForSwap`/`getAmountIn` snapshot and actual block inclusion. No special privileges are required; only crafting a standard KIP-247 gasless transaction pair.

### Recommendation
Ensure gasless bundles are executed and validated atomically at block-construction time: either (a) simulate the full bundle (`LendTx` + `ApproveTx` + `SwapTx`) and only commit `LendTx`'s value transfer if the trailing `SwapTx` is confirmed to fully repay the lent amount within the same simulation, or (b) make the repayment/lend mechanism itself atomic (e.g., have the router directly credit the proposer within the same transaction that consumes the token, rather than relying on a separately staged, unconditionally-executed `LendTx`). Re-validate all balance/allowance/price conditions against the exact pre-state the bundle will execute against, immediately before inclusion, not merely at pool-admission time.

### Proof of Concept
Conceptual sequence, reachable by any sender:
1. Sender submits `GaslessApproveTx` (nonce n) and `GaslessSwapTx` (nonce n+1) referencing a whitelisted token/router, satisfying `checkBalanceForApprove`/`checkBalanceForSwap` at admission time [5](#0-4) .
2. The builder generates and prepends a `LendTx` that unconditionally sends `lendAmount` KAIA from the proposer to the sender [6](#0-5) [7](#0-6) .
3. Before/at the moment of block inclusion, sender's token balance/allowance or the router's exchange rate changes (e.g., sender transfers away the approved token, or slippage exceeds `minAmountOut`), causing `GaslessSwapTx` to revert or fail to fully repay `repayAmount` to the proposer.
4. `LendTx`, already a separate, independently-valid transaction, keeps its effect (sender received the lent KAIA) while the proposer is not repaid — resulting in a net loss to the block proposer, an analog of the original report's "unconditional action followed by an unguaranteed token-dependent step" defect.

// MakeLendTx creates a transaction with following properties:
// L1. LendTx.type = 0x7802 (TxTypeEthereumDynamicFee)
// L2. LendTx.from = proposer
// L3. LendTx.to = SwapTx.from
// L4. LendTx.value = LendAmount(approveTxOrNil, swapTx)
func (g *GaslessModule) GetLendTxGenerator(approveTxOrNil, swapTx *types.Transaction) *builder.TxOrGen {
	var src []byte
	if approveTxOrNil != nil {
		src = append(src, approveTxOrNil.Hash().Bytes()...)
	}
	src = append(src, swapTx.Hash().Bytes()...)
	bundleHash := crypto.Keccak256Hash(src)

	gen := func(nonce uint64) (*types.Transaction, error) {
		var (
			chainId = g.InitOpts.ChainConfig.ChainID
			signer  = types.LatestSignerForChainID(chainId)
			key     = g.InitOpts.NodeKey
		)

		to, err := types.Sender(signer, swapTx)
		if err != nil {
			return nil, err
		}

		tx, err := types.NewTransactionWithMap(types.TxTypeEthereumDynamicFee, map[types.TxValueKeyType]interface{}{
			types.TxValueKeyNonce:      nonce,
			types.TxValueKeyTo:         &to,
			types.TxValueKeyAmount:     lendAmount(approveTxOrNil, swapTx),
			types.TxValueKeyData:       common.Hex2Bytes("0x"),
			types.TxValueKeyGasLimit:   params.TxGas,
			types.TxValueKeyGasFeeCap:  swapTx.GasFeeCap(),
			types.TxValueKeyGasTipCap:  swapTx.GasTipCap(),
			types.TxValueKeyAccessList: types.AccessList{},
			types.TxValueKeyChainID:    chainId,
		})
		if err != nil {
			return nil, err
		}

		err = tx.Sign(signer, key)
		return tx, err
	}

	return builder.NewTxOrGenFromGen(gen, bundleHash)
}

func lendAmount(approveTxOrNil, swapTx *types.Transaction) *big.Int {
	r := new(big.Int)

	// R2 = ApproveTx.Fee() if exists
	if approveTxOrNil != nil {
		r.Add(r, approveTxOrNil.Fee())
	}

	// R3 = SwapTx.Fee()
	r.Add(r, swapTx.Fee())

	// LendAmount = R2 + R3
	return r
}

func (g *GaslessModule) checkBalanceForApprove(approveArgs *ApproveArgs) error {
	token := approveArgs.Token
	bc := backends.NewBlockchainContractBackend(g.Chain, nil, nil)

	if g.GaslessConfig.ShouldCheckSenderCode() {
		if g.getCurrentHasCode(approveArgs.Sender) {
			return errors.New("sender with code is not allowed")
		}
	}

	if g.GaslessConfig.ShouldCheckToken() {
		tokenContract, err := sc_erc20.NewERC20(token, bc)
		if err != nil {
			return err
		}

		// tx.token.balanceOf(sender) > 0
		tokenBalance, err := tokenContract.BalanceOf(nil, approveArgs.Sender)
		if err != nil {
			return err
		}
		if tokenBalance.Sign() <= 0 {
			return fmt.Errorf("insufficient sender token balance: token=%s, have=%s, want=nonzero", token.Hex(), tokenBalance.String())
		}
	}
	return nil

// tx.amountIn >= gsr.getAmountIn(minAmountOut)

// tx.token.balanceOf(sender) >= tx.amountIn
// tx.deadline >= currentTimestamp
func (g *GaslessModule) checkBalanceForSwap(swapArgs *SwapArgs, swapNonce uint64) error {
	token := swapArgs.Token
	bc := backends.NewBlockchainContractBackend(g.Chain, nil, nil)

	g.gaslessInfoMu.RLock()
	swapRouter := g.swapRouter
	g.gaslessInfoMu.RUnlock()

	// tx.minAmountOut >= tx.amountRepay
	minAmountOut := swapArgs.MinAmountOut
	amountRepay := swapArgs.AmountRepay
	if minAmountOut.Cmp(amountRepay) < 0 {
		return fmt.Errorf("insufficient minAmountOut: minAmountOut=%s, amountRepay=%s", minAmountOut.String(), amountRepay.String())
	}

	if g.GaslessConfig.ShouldCheckSenderCode() {
		if g.getCurrentHasCode(swapArgs.Sender) {
			return errors.New("sender with code is not allowed")
		}
	}

	if g.GaslessConfig.ShouldCheckSwapAmount() {
		// tx.amountIn >= gsr.getAmountIn(minAmountOut)
		routerContract, err := kip247.NewGaslessSwapRouterCaller(swapRouter, bc)
		if err != nil {
			return err
		}
		// Required token amountIn, given the current exchange rate and the declared minAmountOut.
		requiredAmountIn, err := routerContract.GetAmountIn(nil, token, minAmountOut)
		if err != nil {
			return err
		}
		if swapArgs.AmountIn.Cmp(requiredAmountIn) < 0 {
			return fmt.Errorf("insufficient amountIn: have=%s, want=%s", swapArgs.AmountIn.String(), requiredAmountIn.String())
		}
	}

	if g.GaslessConfig.ShouldCheckToken() {

		tokenContract, err := sc_erc20.NewERC20(token, bc)
		if err != nil {
			return err
		}

		// If SwapTx.nonce is the sender's next nonce, then there is no room for ApproveTx proceeding SwapTx.
		senderNonce := g.getCurrentStateNonce(swapArgs.Sender)
		noApproveTxPreceeds := swapNonce == senderNonce
		if noApproveTxPreceeds {
			// tx.token.allowance(sender, router) >= tx.amountIn
			approval, err := tokenContract.Allowance(nil, swapArgs.Sender, swapRouter)
			if err != nil {
				return err
			}
			if approval.Cmp(swapArgs.AmountIn) < 0 {
				return fmt.Errorf("insufficient approval: approval=%s, want=%s", approval.String(), swapArgs.AmountIn.String())
			}
		}

		// tx.token.balanceOf(sender) >= tx.amountIn
		balance, err := tokenContract.BalanceOf(nil, swapArgs.Sender)
		if err != nil {
			return err
		}
		if balance.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("insufficient balance: balance=%s, want=%s", balance.String(), swapArgs.AmountIn.String())
		}
	}

	// tx.deadline >= currentTimestamp
	deadline := swapArgs.Deadline
	if deadline.Cmp(g.Chain.CurrentBlock().Time()) < 0 {
		return fmt.Errorf("insufficient deadline: deadline=%s, want=%s", deadline.String(), g.Chain.CurrentBlock().Time().String())
	}

	return nil
