## Finding

### Title
Server-Side Request Forgery via unvalidated DataLayer mirror URLs - (File: `chia/data_layer/download_data.py`)

### Summary
Any wallet user can publish an on-chain "mirror" coin for **any** DataLayer store, embedding arbitrary attacker-controlled URL strings in the coin's memos. A DataLayer node that subscribes to that store id fetches delta files directly from those URLs via `aiohttp` with no scheme/host validation, allowing an unprivileged party to force the victim node to issue outbound HTTP requests to internal or link-local destinations of the attacker's choosing — the same bug class as CVE-2026-46382 (unvalidated user-supplied URI fetched by a server).

### Finding Description
A mirror coin is created by `DataLayerWallet.create_new_mirror()`, which spends XCH to `create_mirror_puzzle()` and encodes an arbitrary `launcher_id` and list of URL strings as memos: [1](#0-0) 

This is fully permissionless — the `launcher_id` in the memo is not verified to belong to the spender, and the URL strings are opaque bytes chosen entirely by the transaction creator: [2](#0-1) 

When the coin confirms, any wallet tracking that `launcher_id` records the mirror and its URLs without validating their contents: [3](#0-2) 

The DataLayer service periodically pulls these mirror URLs from the wallet and hands them to the fetch pipeline: [4](#0-3) [5](#0-4) 

The actual network fetch, `http_download()`, concatenates the attacker-supplied `server_info.url` directly into an `aiohttp` GET request with no allow-list, scheme restriction, or check against private/link-local/loopback address ranges: [6](#0-5) 

The only protections present (`max_delta_file_size`, `timeout`) bound response size/time but do nothing to prevent the request from being sent to an internal-only or cloud-metadata address. `is_filename_valid()` only validates the requested filename, never the destination host: [7](#0-6) 

### Impact Explanation
An unprivileged wallet holder (a "Data Layer client" in terms of this participant class) can weaponize any other user's DataLayer store id to make arbitrary nodes running the DataLayer service issue outbound HTTP requests to attacker-chosen destinations — e.g., cloud instance metadata services (`169.254.169.254`), internal-only admin interfaces, or other loopback/LAN services reachable from the host, none of which require attacker code execution or node compromise. This is a classic confused-deputy SSRF: the victim DataLayer server becomes a network proxy for the attacker, which can be used for internal network reconnaissance/port-scanning or to interact with services that trust the source IP of the DataLayer host.

### Likelihood Explanation
Likelihood is high: creating a mirror coin only requires spending a small amount of XCH (`dl_new_mirror`/`add_mirror` RPC or CLI, `chia/cmds/data.py:add_mirror`) and does not require ownership of, or any permission over, the target store id. Any node whose DataLayer service tracks/subscribes to that `launcher_id` will automatically pick up and fetch from the malicious URL as part of its normal periodic sync (`fetch_and_validate`), with no operator interaction needed.

### Recommendation
Validate mirror/server URLs before they are used for outbound fetches: enforce an `http(s)` scheme allow-list, resolve and reject requests to private/loopback/link-local/multicast address ranges (RFC 1918, 127.0.0.0/8, 169.254.0.0/16, etc.) unless explicitly allowed by local configuration, and consider requiring operator opt-in per mirror/subscription before automatically dereferencing on-chain-advertised URLs in `http_download()` and `download_file()`.

### Proof of Concept
1. Attacker runs `chia data add_mirror --id <victim_store_id> --amount 1 --url http://169.254.169.254/latest/meta-data/` (or any internal target), using their own wallet funds; `launcher_id` need not belong to the attacker (`chia/cmds/data.py` `add_mirror` → `DataLayerWallet.create_new_mirror`).
2. Once confirmed on-chain, any node subscribed to `victim_store_id` picks the URL up via `update_subscriptions_from_wallet` → `data_store.get_available_servers_for_store`.
3. On the next `fetch_and_validate()` cycle, `insert_from_delta_file` → `download_file` → `http_download` issues `session.get("http://169.254.169.254/latest/meta-data/" + "/" + filename, ...)` from the victim node, with no destination validation. [6](#0-5)

```python
def get_mirror_info(
    parent_puzzle: Program | SerializedProgram, parent_solution: Program | SerializedProgram
) -> tuple[bytes32, list[bytes]]:
    assert type(parent_puzzle) is type(parent_solution)
    _, conditions = run_with_cost(parent_puzzle, INFINITE_COST, parent_solution)
    for condition in conditions.as_iter():
        if (
            condition.first().as_python() == ConditionOpcode.CREATE_COIN
            and condition.at("rf").as_python() == create_mirror_puzzle().get_tree_hash()
        ):
            memos: list[bytes] = condition.at("rrrf").as_python()
            launcher_id = bytes32(memos[0])
            return launcher_id, [url for url in memos[1:]]
    raise ValueError("The provided puzzle and solution do not create a mirror coin")
```

```python
def is_filename_valid(filename: str, group_by_store: bool = False) -> bool:
    if group_by_store:
        if filename.count("/") != 1:
            return False
        filename = filename.replace("/", "-")

    split = filename.split("-")

    try:
        raw_store_id, raw_node_hash, file_type, raw_generation, raw_version, *rest = split
        store_id = bytes32(bytes.fromhex(raw_store_id))
        node_hash = bytes32(bytes.fromhex(raw_node_hash))
        generation = int(raw_generation)
    except ValueError:
        return False

    if len(rest) > 0:
        return False

    # TODO: versions should probably be centrally defined
    if raw_version != "v1.0.dat":
        return False

    if file_type not in {"delta", "full"}:
        return False

    generate_file_func = get_delta_filename if file_type == "delta" else get_full_tree_filename
    reformatted = generate_file_func(
        store_id=store_id, node_hash=node_hash, generation=generation, group_by_store=False
    )

    return reformatted == filename
```

```python
async def http_download(
    target_filename_path: Path,
    filename: str,
    proxy_url: str | None,
    server_info: ServerInfo,
    timeout: aiohttp.ClientTimeout,
    log: logging.Logger,
    max_delta_file_size: int,
) -> None:
    """
    Download a file from a server using aiohttp.
    Raises exceptions on errors
    """
    async with aiohttp.ClientSession() as session:
        headers = {"accept-encoding": "gzip"}
        async with session.get(
            server_info.url + "/" + filename,
            headers=headers,
            timeout=timeout,
            proxy=proxy_url,
        ) as resp:
            resp.raise_for_status()
```
