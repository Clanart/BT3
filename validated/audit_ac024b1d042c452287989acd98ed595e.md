### Title
Command Injection via Malicious Repository/Directory Name in "Open in Shell" (Windows) - (File: `app/src/lib/shells/win32.ts`)

### Summary
GitHub Desktop derives the local clone directory name from an attacker-controlled remote URL using `sanitizeCloneName()` [1](#0-0) , which only guards against path traversal (`/`, `\`, `:`, `..`) but does not strip shell metacharacters. That directory name becomes part of `repository.path`, which is later interpolated **unescaped** into shell command strings executed with `shell: true` in the Windows "Open in Shell" launcher [2](#0-1) .

### Finding Description
When a user clones a repository from a generic (non-GitHub-API) URL via the "Clone repository" → "URL" tab, `parseRepositoryIdentifier()`/`parseRemote()` extracts an `owner`/`name` pair straight from the attacker-supplied URL string [3](#0-2) . Because this is a free-text URL (not a validated GitHub API repository object), the parsed `name` component is not restricted to GitHub's slug character set — it can contain arbitrary characters that are legal in a Windows filename (e.g. `&`, `%`, `^`, `!`, `(`, `)`), since only `< > : " / \ | ? *` are filesystem-invalid on Windows.

`sanitizeCloneName()` is only designed to prevent directory-traversal, not shell metacharacter injection: [4](#0-3) 

The sanitized (but not shell-escaped) name is joined into the destination path with `Path.join()` in the clone dialog logic [5](#0-4)  and [6](#0-5) , becoming the on-disk repository folder and thus `repository.path` for the rest of the app's lifetime.

Later, when the user performs the ordinary "Open in Shell" action (menu item / context menu, wired through `app.tsx` → `dispatcher.openShell` → `appStore._openShell` → `launchShell`) [7](#0-6) [8](#0-7) , the Windows `launch()` function embeds this untrusted `path` directly into shell command argument **strings** that are executed with `shell: true` (i.e., via `cmd.exe /d /s /c` on Windows), for multiple shells: [9](#0-8) 

For example, for Git Bash: `spawn(gitBashPath, [`--cd="${path}"`], { shell: true, cwd: path })`, and for Cygwin the interpolation mixes single- and double-quoted shell syntax: `` `/bin/sh -lc 'cd "$(cygpath "${path}")"; exec bash'` ``. None of these use the `cmdEscape`/`quoteCommand` escaping helpers that the codebase already defines for exactly this purpose [10](#0-9)  — those are only wired into the Git hooks trampoline (`app/src/lib/hooks/get-shell.ts`), not into `app/src/lib/shells/win32.ts`.

### Impact Explanation
If the crafted directory name breaks out of the surrounding quotes when the resulting string is parsed by `cmd.exe`, an attacker-controlled command can be appended to the argument list Node passes to `cmd.exe /c`, resulting in arbitrary command execution in the context of the victim's user account the next time they open that specific cloned repository "in shell" — a completely ordinary, expected workflow action for any newly cloned repo, requiring no unnatural steps, elevated privileges, or prior compromise. This satisfies the "attacker controls a... link... git remote... and the result is code execution" impact bar.

### Likelihood Explanation
Likelihood depends on precisely how `cmd.exe`'s command-line tokenizer handles the specific metacharacters (`&`, `|`, `%`, `^`) once embedded inside the outer quoting that Node.js's `shell: true` implementation constructs around the whole argv. This is the same well-known class of Windows shell-quoting pitfall (`cmd.exe` treats `&`/`|` as command separators even inside naive `"..."` wrapping in many contexts) that Node's own documentation warns about for `shell: true` on Windows. I was not able to fully verify the exact resulting cmd.exe command line for each of the affected shells (GitBash, Cygwin, Hyper, Alacritty, PowerShellCore, Warp) in this session because further file reads were unavailable in the final iteration — this should be validated with a concrete PoC clone/build before treating this as confirmed-exploitable rather than a plausible, code-supported analog.

### Recommendation
- Apply the existing `cmdEscape`/`quoteCommand` helpers from `app/src/lib/hooks/shell-escape.ts` to the `path` argument before interpolating it into any `shell: true` spawn command in `app/src/lib/shells/win32.ts`, or avoid `shell: true` entirely by passing arguments as a proper argv array without manual string concatenation.
- Additionally harden `sanitizeCloneName()` to strip/replace shell-significant characters (`&`, `|`, `%`, `^`, `!`, `(`, `)`, backtick, `$`) in addition to path-traversal characters, consistent with `safeDirectoryName()` already used in `app/src/ui/lib/repository-path.tsx`.

### Proof of Concept
1. Attacker hosts a git repository on a self-controlled git server (or supplies a crafted URL) reachable at a URL whose final path segment is a malicious folder-name payload, e.g. `https://evil.example.com/owner/name & calc.exe & rem.git`.
2. Victim pastes this URL into GitHub Desktop's "Clone repository → URL" tab; `parseRepositoryIdentifier`/`sanitizeCloneName` accept it as a valid single path component (only `/ \ :` and `..` are filtered) and it becomes the local clone folder name, e.g. `C:\Users\victim\Documents\GitHub\name & calc.exe & rem`.
3. Victim right-clicks the repository (or uses the menu) and selects "Open in Shell" with Git Bash/Cygwin/Hyper/Alacritty/PowerShell Core/Warp configured as the shell.
4. `launch()` in `app/src/lib/shells/win32.ts` builds a `spawn(..., { shell: true })` call embedding the unescaped folder name in the command string, which is then parsed by `cmd.exe`; if the metacharacters survive quoting, the injected command (`calc.exe`) executes.

/**
 * Extracts a safe single-component directory name from a URL-derived repo name.
 *
 * Mirrors the approach of git's `git_url_basename()` in `dir.c`: treat `/`,
 * `\`, and `:` as path separators, take the last non-empty component, strip a
 * trailing `.git` suffix, and reject traversal segments. This ensures the
 * result is always a single path component that cannot escape the parent
 * directory when passed to `Path.join()`.
 *
 * Examples:
 *  - `"Hello-World"` → `"Hello-World"` (unchanged)
 *  - `"desktop.git/../../otherdir"` → `"otherdir"` (last component, traversal segments skipped)
 *  - `".."` → `null` (traversal-only name rejected)
 *
 * See: https://github.com/git/git/blob/master/dir.c (`git_url_basename`)
 */
export function sanitizeCloneName(name: string): string | null {
  const components = name.split(/[/\\:]/)

  let lastComponent = ''
  for (let i = components.length - 1; i >= 0; i--) {
    if (components[i].length > 0) {
      lastComponent = components[i]
      break
    }
  }

  if (lastComponent.length === 0) {
    return null
  }

  if (lastComponent.endsWith('.git')) {
    lastComponent = lastComponent.slice(0, -4)
  }

  if (
    lastComponent === '..' ||
    lastComponent === '.' ||
    lastComponent.length === 0
  ) {
    return null
  }

  return lastComponent
}

export function launch(
  foundShell: FoundShell<Shell>,
  path: string
): ChildProcess {
  const shell = foundShell.shell

  switch (shell) {
    case Shell.PowerShell:
      return spawn('START', ['"PowerShell"', `"${foundShell.path}"`], {
        shell: true,
        cwd: path,
      })
    case Shell.PowerShellCore:
      return spawn(
        'START',
        [
          '"PowerShell Core"',
          `"${foundShell.path}"`,
          '-WorkingDirectory',
          `"${path}"`,
        ],
        {
          shell: true,
          cwd: path,
        }
      )
    case Shell.Hyper:
      const hyperPath = `"${foundShell.path}"`
      log.info(`launching ${shell} at path: ${hyperPath}`)
      return spawn(hyperPath, [`"${path}"`], {
        shell: true,
        cwd: path,
      })
    case Shell.Alacritty:
      const alacrittyPath = `"${foundShell.path}"`
      log.info(`launching ${shell} at path: ${alacrittyPath}`)
      return spawn(alacrittyPath, [`--working-directory "${path}"`], {
        shell: true,
        cwd: path,
      })
    case Shell.GitBash:
      const gitBashPath = `"${foundShell.path}"`
      log.info(`launching ${shell} at path: ${gitBashPath}`)
      return spawn(gitBashPath, [`--cd="${path}"`], {
        shell: true,
        cwd: path,
      })
    case Shell.Cygwin:
      const cygwinPath = `"${foundShell.path}"`
      log.info(`launching ${shell} at path: ${cygwinPath}`)
      return spawn(
        cygwinPath,
        [`/bin/sh -lc 'cd "$(cygpath "${path}")"; exec bash`],
        {
          shell: true,
          cwd: path,
        }
      )
    case Shell.Warp:
      const warpPath = `"${foundShell.path}"`
      log.info(`launching ${shell} at path: ${warpPath}`)
      return spawn(warpPath, [`warp://action/new_tab?path="${path}"`], {
        shell: true,
        cwd: path,
      })
    case Shell.WSL:
      return spawn('START', ['"WSL"', `"${foundShell.path}"`], {
        shell: true,
        cwd: path,
      })
    case Shell.Cmd:
      return spawn(
        'START',
        ['"Command Prompt"', `"${foundShell.path}"`, ...foundShell.extraArgs!],
        {
          shell: true,
          cwd: path,
        }
      )
    case Shell.WindowsTerminal:
      const windowsTerminalPath = `"${foundShell.path}"`
      log.info(`launching ${shell} at path: ${windowsTerminalPath}`)
      return spawn(windowsTerminalPath, ['-d .'], { shell: true, cwd: path })
    case Shell.FluentTerminal:
      const fluentTerminalPath = `"${foundShell.path}"`
      log.info(`launching ${shell} at path: ${fluentTerminalPath}`)
      return spawn(fluentTerminalPath, ['new'], { shell: true, cwd: path })
    default:
      return assertNever(shell, `Unknown shell: ${shell}`)
  }
}

// https://github.com/ericcornelissen/shescape/blob/89072ba7de233f81f5553b52098671c94eb9bd0c/src/internal/win/cmd.js#L35
const cmdEscape = (arg: string) =>
  arg
    .replace(/[\0\u0008\r\u001B\u009B]/gu, '')
    .replace(/\n/gu, ' ')
    .replace(/"/gu, '""')
    .replace(/([%&<>^|])/gu, '"^$1"')
    .replace(/(?<!\\)(\\*)(?="|$)/gu, '$1$1')

export const cmd: Shell = {
  args: ['/d', '/s', '/c'],
  quoteCommand: (cmd, ...args) =>
    `"${[cmd, ...args].map(a => `"${cmdEscape(a)}"`).join(' ')}"`,
}
