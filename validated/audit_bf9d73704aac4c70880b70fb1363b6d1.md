## Finding Confirmed: Missing deprecated-TokenGateway rejection in gargantua's `ProxyModule::on_accept`

### Title
Gargantua's `ProxyModule::on_accept` lacks nexus's deprecated-TokenGateway rejection, allowing stale/decommissioned TokenGateway contracts to still route into `pallet_hyper_fungible_token::on_accept` - (File: `parachain/runtimes/gargantua/src/ismp.rs`)

### Summary
Nexus explicitly maintains a hard-coded denylist, `DEPRECATED_TOKEN_GATEWAY_ADDRESSES`, and rejects any `PostRequest` whose `from` matches one of these addresses at the very top of `ProxyModule::on_accept`, before dispatching or routing to any pallet [1](#0-0) . This check runs unconditionally, both for forwarded (`dest != host`) requests and for locally-routed requests, and is applied symmetrically to `on_timeout` as well [2](#0-1) [3](#0-2) .

Gargantua's `ProxyModule::on_accept` has no equivalent check anywhere in its request-processing pipeline — it goes straight from the bandwidth gate to the dest-forwarding/local-routing logic and dispatches directly into `pallet_hyper_fungible_token::Pallet::<Runtime>::default().on_accept(request)` when `to` resolves to `pallet_hyper_fungible_token::PALLET_ID` [4](#0-3) .

### Finding Description
The `from` field of an incoming `PostRequest` is the module identifier used by `pallet_hyper_fungible_token` to resolve the correct asset via its `ContractToAsset` mapping and authorize minting for that specific source-chain contract. Nexus's denylist was added specifically to permanently sever this trust relationship for known-decommissioned TokenGateway deployments, so that even if a stale `ContractToAsset` entry still exists (or is later re-created), the deprecated contract's on-chain code can never again mint tokens through Hyperbridge — the request is rejected before it can reach the pallet at all.

Because a decommissioned contract's bytecode typically remains live on the source EVM chain, anyone (unprivileged) can still call it and cause it to emit the same request-triggering event. A relayer can then submit a legitimate consensus/state proof for that event, since it is a real, provable piece of source-chain state. On nexus this is blocked unconditionally by `is_deprecated_token_gateway`. On gargantua, the identical `PostRequest` with the same `from` sails through `on_accept` and reaches `pallet_hyper_fungible_token::Pallet::<Runtime>::default().on_accept(request)` with no equivalent guard [5](#0-4) .

### Impact Explanation
If gargantua's `ContractToAsset` table retains (or is later populated with) a mapping for one of these addresses, the missing filter allows minting to proceed using a contract identity that governance/protocol operators have explicitly and permanently revoked elsewhere in the same codebase, corrupting the intended trust boundary between deprecated and active TokenGateway deployments and enabling unauthorized asset minting.

### Likelihood Explanation
This requires the source-chain deprecated contract to still be callable (typical for on-chain contracts, since they cannot be "deleted") and a relayer to submit its proof — both are unprivileged, ordinary protocol operations, not privileged/compromised-infrastructure actions.

### Recommendation
Add the same `is_deprecated_token_gateway` (or an equivalent, network-appropriate) check and constant list to gargantua's `ProxyModule::on_accept` (and `on_timeout`), mirroring nexus's implementation at [2](#0-1) , so the rejection is enforced consistently across all runtimes that route into `pallet_hyper_fungible_token`.

### Proof of Concept
1. Register a `ContractToAsset` mapping in gargantua's `pallet_hyper_fungible_token` for one of the addresses in nexus's `DEPRECATED_TOKEN_GATEWAY_ADDRESSES` list (e.g. `0xFd413e3AFe560182C4471F4d143A96d3e259B6dE`) — this is the same address nexus permanently blocks.
2. Construct a `PostRequest` with `from = 0xFd413e3AFe560182C4471F4d143A96d3e259B6dE`, `to` resolving to `pallet_hyper_fungible_token::PALLET_ID`, and `dest = gargantua host`.
3. Submit it through gargantua's `Runtime` `ProxyModule::on_accept` (with a valid proof of the underlying event) — observe it is *not* rejected, and instead is dispatched into `pallet_hyper_fungible_token::Pallet::<Runtime>::default().on_accept(request)`.
4. Submit the identical request through nexus's `ProxyModule::on_accept` and observe it is rejected with `"rejecting request from deprecated TokenGateway address ..."` before any pallet dispatch [6](#0-5) .
5. The divergence in outcome for the identical `from` address across the two runtimes demonstrates the asymmetric, missing defense in gargantua.

/// Deprecated TokenGateway contract addresses whose incoming ISMP Post requests
/// must be rejected unconditionally by the nexus runtime.
/// Any [`PostRequest`] whose `from` field matches any of these 20-byte addresses
/// is rejected in [`ProxyModule::on_accept`] before any other processing — the
/// message is neither dispatched locally nor forwarded onwards.
pub const DEPRECATED_TOKEN_GATEWAY_ADDRESSES: &[[u8; 20]] = &[
	// Ethereum / Arbitrum / Optimism / Base / BSC / Gnosis TokenGateway
	hex_literal::hex!("Fd413e3AFe560182C4471F4d143A96d3e259B6dE"),
	// Polygon / Unichain TokenGateway
	hex_literal::hex!("8b536105b6Fae2aE9199f5146D3C57Dfe53b614E"),
	// Soneium TokenGateway
	hex_literal::hex!("Ce304770236f39F9911BfCC51afBdfF3b8635718"),
];

/// Returns `true` if `from` is exactly one of the deprecated TokenGateway
/// contract addresses in [`DEPRECATED_TOKEN_GATEWAY_ADDRESSES`].
fn is_deprecated_token_gateway(from: &[u8]) -> bool {
	DEPRECATED_TOKEN_GATEWAY_ADDRESSES.iter().any(|deprecated| deprecated == from)
}

impl IsmpModule for ProxyModule {
	fn on_accept(&self, request: PostRequest) -> Result<Weight, anyhow::Error> {
		// Bandwidth gate. Always-enforce unless the `no-bandwidth` flag
		// is set; skipped for purchase messages so the recharge flow
		// itself doesn't need bandwidth. With the flag on the gate is a
		// no-op and this block is compiled out entirely.
		#[cfg(not(feature = "no-bandwidth"))]
		if !pallet_bandwidth::Pallet::<Runtime>::is_purchase_message(&request) {
			let bytes = ismp::abi::encode_post_request(&request).len() as u32;
			<pallet_bandwidth::Pallet<Runtime> as pallet_bandwidth::BandwidthGate>::try_consume(
				&request.source,
				&request.from,
				bytes,
			)
			.map_err(|err| {
				anyhow!(
					"bandwidth gate: {err} (source={:?}, from={:x?})",
					request.source,
					request.from
				)
			})?;
		}

		if request.dest != HostStateMachine::get() {
			Ismp::dispatch_request(
				Request::Post(request),
				FeeMetadata::<Runtime> { payer: [0u8; 32].into(), fee: Default::default() },
			)?;
			return Ok(Weight::from_parts(0, 0));
		}

		let pallet_id =
			ModuleId::from_bytes(&request.to).map_err(|err| Error::Custom(err.to_string()))?;

		match pallet_id {
			pallet_ismp_demo::PALLET_ID =>
				pallet_ismp_demo::IsmpModuleCallback::<Runtime>::default().on_accept(request),

			#[cfg(not(feature = "no-bandwidth"))]
			id if id == ModuleId::Pallet(pallet_bandwidth::pallet::PALLET_BANDWIDTH) =>
				pallet_bandwidth::Pallet::<Runtime>::default().on_accept(request),

			pallet_hyper_fungible_token::PALLET_ID =>
				pallet_hyper_fungible_token::Pallet::<Runtime>::default().on_accept(request),

			_ => Err(anyhow!("Destination module not found")),
		}
	}
