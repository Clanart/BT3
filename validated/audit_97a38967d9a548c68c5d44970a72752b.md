### Title
Arbitrary File Write via Unvalidated `foldername` Parameter in DataLayer `add_missing_files` RPC - (File: chia/data_layer/data_layer_rpc_api.py)

### Summary
The DataLayer RPC endpoint `add_missing_files` accepts a client-supplied `foldername` string and converts it directly into a filesystem `Path` with no validation, sandboxing, or restriction to the configured `server_files_location`. This path is then used as the write destination for tree/delta files, mirroring the Directus `filename_disk` issue where a value that should be server-controlled is instead accepted from the caller and used to determine where data is written on disk.

### Finding Description
`DataLayerRpcApi.add_missing_files()` reads `request["foldername"]` and wraps it in `Path()` with no normalization, path-traversal checks, or restriction to a safe base directory: [1](#0-0) 

That value flows into `DataLayer.add_missing_files()`, which uses it as `server_files_location` (instead of the service's own configured directory) and passes it straight to `write_files_for_root()`: [2](#0-1) 

`write_files_for_root()` builds the full-tree/delta filenames under the caller-supplied folder and creates any missing parent directories, then opens the target file for writing. When the caller passes `overwrite=True`, the open mode becomes `"wb"` (truncate/overwrite) rather than the default exclusive-create `"xb"`: [3](#0-2) 

The final filename component (`get_full_tree_filename_path`/`get_delta_filename_path`) is deterministic — `{store_id}-{node_hash}-full-{generation}-v1.0.dat` — but the *directory* prefix is fully attacker-chosen and unrestricted (absolute paths, `..` segments, arbitrary locations on the host filesystem are all accepted): [4](#0-3) 

This is analogous to the Directus bug: a parameter that determines *where on disk data is written* is treated as attacker-controlled input instead of being derived/enforced server-side, allowing the write location to escape the intended storage root (`self.server_files_location`).

### Impact Explanation
An unprivileged local RPC caller who can reach the DataLayer service's RPC API (any Data Layer client, per the local-RPC-caller threat model) and who owns/subscribes to at least one store can:
- Force `mkdir(parents=True, exist_ok=True)` to create directories anywhere the DataLayer process has filesystem permissions.
- Write files (containing the caller's own tree data, but with a caller-influenced generation/hash-derived name and an entirely caller-chosen parent directory) to arbitrary paths outside the intended `server_files_location` sandbox.
- With `overwrite=True`, truncate/overwrite an existing file at that path if the constructed filename happens to collide with one, since `"wb"` mode is used instead of exclusive `"xb"`.

This breaks the confinement that `server_files_location` is supposed to provide for DataLayer file publication, similar to how Directus's `filename_disk` bypass let a user escape the intended storage boundary. Depending on what files/directories are reachable by the DataLayer service process, this can lead to file/directory creation or overwrite outside the sanctioned storage tree.

### Likelihood Explanation
Reaching this code path only requires calling the `add_missing_files` RPC endpoint with a `foldername` field and one or more store ids the caller can operate on (owned or subscribed stores) — no special privileges beyond normal DataLayer RPC access are needed, and no filename/path validation exists on the `foldername` value at any layer (RPC API, `DataLayer.add_missing_files`, or `write_files_for_root`).

### Recommendation
- Do not accept an arbitrary `foldername` from RPC requests for this operation, or if it must remain configurable, validate that the resolved path is confined to (or a subdirectory of) `server_files_location` before use (e.g., resolve and compare against the canonical base path, rejecting `..` traversal and absolute-path escapes).
- Keep exclusive-create (`"xb"`) semantics as the default and audit uses of `overwrite=True` to ensure writes only ever target the intended, validated directory.

### Proof of Concept
1. As a DataLayer RPC caller owning/subscribed to `store_id`, send:
```json
POST /add_missing_files
{
  "ids": ["<store_id_hex>"],
  "overwrite": true,
  "foldername": "/absolute/attacker/chosen/path"
}
```
2. `add_missing_files` in `chia/data_layer/data_layer_rpc_api.py` converts `foldername` directly to a `Path` and passes it through unvalidated.
3. `DataLayer.add_missing_files()` uses this path as `server_files_location`, and `write_files_for_root()` creates directories under it and writes `{store_id}-{node_hash}-full/delta-{generation}-v1.0.dat` there, outside the service's configured storage root, overwriting any existing file with a colliding name because `overwrite=True` forces `"wb"` mode.

**Uncertainty**: I could not confirm from the indexed code whether the DataLayer RPC endpoint enforces any additional authentication/authorization beyond standard local RPC TLS-cert access (i.e., whether "any local RPC caller" vs. only a fully trusted operator can invoke this endpoint) — this affects how strictly "unprivileged" the reachable actor is, but the code path itself imposes no path-confinement checks regardless of caller identity.

    async def add_missing_files(self, request: dict[str, Any]) -> EndpointResult:
        """
        complete the data server files.
        """
        if "ids" in request:
            store_ids = request["ids"]
            ids_bytes = [bytes32.from_hexstr(id) for id in store_ids]
        else:
            subscriptions: list[Subscription] = await self.service.get_subscriptions()
            ids_bytes = [subscription.store_id for subscription in subscriptions]
        overwrite = request.get("overwrite", False)
        foldername: Path | None = None
        if "foldername" in request:
            foldername = Path(request["foldername"])
        for store_id in ids_bytes:
            await self.service.add_missing_files(store_id, overwrite, foldername)
        return {}

    async def add_missing_files(self, store_id: bytes32, overwrite: bool, foldername: Path | None) -> None:
        root = await self.data_store.get_tree_root(store_id=store_id)
        latest_generation = root.generation
        full_tree_first_publish_generation = max(0, latest_generation - self.maximum_full_file_count + 1)
        singleton_record = (
            await self.wallet_rpc.dl_latest_singleton(DLLatestSingleton(launcher_id=store_id, only_confirmed=True))
        ).singleton
        if singleton_record is None:
            self.log.error(f"No singleton record found for: {store_id}")
            return
        max_generation = min(singleton_record.generation, root.generation)
        server_files_location = foldername if foldername is not None else self.server_files_location
        files = []
        for generation in range(1, max_generation + 1):
            root = await self.data_store.get_tree_root(store_id=store_id, generation=generation)
            res = await write_files_for_root(
                self.data_store,
                store_id,
                root,
                server_files_location,
                full_tree_first_publish_generation,
                overwrite,
                self.group_files_by_store,
            )
            files.append(res.diff_tree.name)

async def write_files_for_root(
    data_store: DataStore,
    store_id: bytes32,
    root: Root,
    foldername: Path,
    full_tree_first_publish_generation: int,
    overwrite: bool = False,
    group_by_store: bool = False,
) -> WriteFilesResult:
    if root.node_hash is not None:
        node_hash = root.node_hash
    else:
        node_hash = bytes32.zeros  # todo change

    filename_full_tree = get_full_tree_filename_path(foldername, store_id, node_hash, root.generation, group_by_store)
    filename_diff_tree = get_delta_filename_path(foldername, store_id, node_hash, root.generation, group_by_store)
    filename_full_tree.parent.mkdir(parents=True, exist_ok=True)

    written = False
    mode: Literal["wb", "xb"] = "wb" if overwrite else "xb"

    written_full_file = False
    if root.generation >= full_tree_first_publish_generation:
        try:
            with open(filename_full_tree, mode) as writer:
                await data_store.write_tree_to_file(root, node_hash, store_id, False, writer)
            written = True
            written_full_file = True
        except FileExistsError:
            pass

    try:
        with open(filename_diff_tree, mode) as writer:
            await data_store.write_tree_to_file(root, node_hash, store_id, True, writer)
        written = True
    except FileExistsError:
        pass

    return WriteFilesResult(written, filename_full_tree if written_full_file else None, filename_diff_tree)
