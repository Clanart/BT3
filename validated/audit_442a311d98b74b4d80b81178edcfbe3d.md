## Title
Unauthenticated Address Association via `associatePubKey` Allows Third-Party Identity Spoofing and Fund Redirection - (File: precompiles/addr/addr.go)

### Summary
The `addr` precompile's `associatePubKey` method links an arbitrary secp256k1 public key to a Sei address and EVM address **without requiring any proof that the caller controls the corresponding private key**, unlike its sibling method `associate`, which requires a valid ECDSA signature over a custom message. Any unprivileged EVM caller can submit someone else's publicly-known compressed public key (which is routinely exposed on-chain via Cosmos tx signatures) and force an address association that migrates balances and account state, mirroring the PubNet bug class of unauthenticated identity binding/spoofing via an arbitrary identity parameter.

### Finding Description
`associate` derives the EVM/Sei address pair from an ECDSA signature (`v,r,s`) over a caller-supplied message, cryptographically proving possession of the private key before calling `associateAddresses`: [1](#0-0) 

In contrast, `associatePubKey` only requires a raw compressed public key as input — parsed directly with no signature check at all — before calling the exact same `associateAddresses` state-mutating routine: [2](#0-1) 

`associateAddresses` performs no additional authentication; it merely checks that the derived Sei address isn't already associated, then calls the shared `AssociateAddresses` helper: [3](#0-2) 

That helper mutates chain state significantly: it sets the EVM↔Sei address mapping, sets the account pubkey, and **migrates all spendable balances and wei balances from the "cast" address** (the address derived by directly casting the EVM address bytes to a Sei address) to the newly associated Sei address, then removes the cast account if unlocked: [4](#0-3) 

Because public keys are not secret (they appear in every signed Cosmos/EVM transaction, in block explorers, and can be derived from any observed signature), an attacker can extract a victim's public key and call `associatePubKey` on their behalf — this precompile method is callable directly and takes no `caller`-derived authentication parameter in `Execute`: [5](#0-4) 

This is structurally identical to the PubNet vulnerability: an endpoint accepts an unauthenticated "identity" parameter (there: `author-id`; here: a public key) and performs privileged state changes (upload as that user / associate and migrate funds as that user) without verifying the caller is the legitimate owner of that identity.

### Impact Explanation
Forcing an association on behalf of another user has concrete consequences:
- **Fund redirection**: `MigrateBalance` moves all spendable coins and wei balances from the victim's "cast" address to the Sei address derived from the attacker-supplied pubkey — this happens automatically as part of the association, using real bank transfers.
- **Griefing/DoS of legitimate association**: Since `associateAddresses` rejects re-association ("address is already associated"), an attacker can pre-emptively associate a victim's pubkey via `associatePubKey` (front-running the victim's own future association, e.g., their first EVM tx or their own `associate`/ante-handler-triggered association), potentially locking in unwanted account/pubkey state before the victim transacts.
- This satisfies the report's "unauthorized transfer via precompile" and "fund loss" criteria, since the coin migration is a direct consequence of the unauthenticated call.

### Likelihood Explanation
Likelihood is high: the required input (a compressed public key) is not secret — it is embedded in every Cosmos SDK transaction signature and is trivially recoverable from any on-chain activity by the target account. No special privileges, precompile pairing, or contract deployment is required; a single unprivileged EVM call to the `addr` precompile (`0x0000000000000000000000000000000000001004`) at `AssociatePubKey` is sufficient.

### Recommendation
Require `associatePubKey` to prove possession of the private key equivalent to what `associate` demands (e.g., require a signature over a challenge/nonce using the supplied pubkey, or require the transaction's msg sender/tx signer to match the derived address before allowing association). At minimum, gate the migration behavior so that balance migration from the cast address only occurs when the association is self-initiated (signed) rather than pubkey-only.

### Proof of Concept
1. Observe any transaction signed by victim `V` (Cosmos or EVM) and extract `V`'s compressed secp256k1 public key `pubKeyHex` from the signature data.
2. From any unprivileged EVM account, call the `addr` precompile at `0x0000000000000000000000000000000000001004`, method `associatePubKey(pubKeyHex)` — see dispatch in `Execute`: [6](#0-5) .
3. `associatePublicKey` parses the pubkey and derives `evmAddr`/`seiAddr` purely from the pubkey bytes, with no signature verification: [2](#0-1) .
4. `associateAddresses` → `AssociateAddresses` executes, migrating any spendable/wei balance sitting at the cast address to the newly bound Sei address and persisting the pubkey/account mapping: [7](#0-6) .
5. The attacker (or any third party) has now forced the victim's identity association and redirected any balance held at the cast address, without the victim ever signing an association transaction.

func (p PrecompileExecutor) associate(ctx sdk.Context, method *abi.Method, args []interface{}, value *big.Int) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}

	if err := pcommon.ValidateArgsLength(args, 4); err != nil {
		return nil, 0, err
	}

	// v, r and s are components of a signature over the customMessage sent.
	// We use the signature to construct the user's pubkey to obtain their addresses.
	v := args[0].(string)
	r := args[1].(string)
	s := args[2].(string)
	customMessage := args[3].(string)

	rBytes, err := decodeHexString(r)
	if err != nil {
		return nil, 0, err
	}
	sBytes, err := decodeHexString(s)
	if err != nil {
		return nil, 0, err
	}
	vBytes, err := decodeHexString(v)
	if err != nil {
		return nil, 0, err
	}

	vBig := new(big.Int).SetBytes(vBytes)
	rBig := new(big.Int).SetBytes(rBytes)
	sBig := new(big.Int).SetBytes(sBytes)

	// Derive addresses
	vBig = new(big.Int).Add(vBig, utils.Big27)

	customMessageHash := crypto.Keccak256Hash([]byte(customMessage))
	evmAddr, seiAddr, pubkey, err := helpers.GetAddresses(vBig, rBig, sBig, customMessageHash)
	if err != nil {
		return nil, 0, err
	}

	return p.associateAddresses(ctx, method, evmAddr, seiAddr, pubkey)

func (p PrecompileExecutor) associatePublicKey(ctx sdk.Context, method *abi.Method, args []interface{}, value *big.Int) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}

	if err := pcommon.ValidateArgsLength(args, 1); err != nil {
		return nil, 0, err
	}

	// Takes a single argument, a compressed pubkey in hex format, excluding the '0x'
	pubKeyHex := args[0].(string)

	pubKeyBytes, err := hex.DecodeString(pubKeyHex)
	if err != nil {
		return nil, 0, err
	}

	// Parse the compressed public key
	pubKey, err := btcec.ParsePubKey(pubKeyBytes)
	if err != nil {
		return nil, 0, err
	}

	// Convert to uncompressed public key
	uncompressedPubKey := pubKey.SerializeUncompressed()

	evmAddr, seiAddr, pubkey, err := helpers.GetAddressesFromPubkeyBytes(uncompressedPubKey)
	if err != nil {
		return nil, 0, err
	}

	return p.associateAddresses(ctx, method, evmAddr, seiAddr, pubkey)
}

func (p PrecompileExecutor) associateAddresses(ctx sdk.Context, method *abi.Method, evmAddr common.Address, seiAddr sdk.AccAddress, pubkey cryptotypes.PubKey) (ret []byte, remainingGas uint64, err error) {
	// Check that address is not already associated
	_, found := p.evmKeeper.GetEVMAddress(ctx, seiAddr)
	if found {
		return nil, 0, fmt.Errorf("address %s is already associated with evm address %s", seiAddr, evmAddr)
	}

	// Associate Addresses:
	associationHelper := helpers.NewAssociationHelper(p.evmKeeper, p.bankKeeper, p.accountKeeper)
	err = associationHelper.AssociateAddresses(ctx, seiAddr, evmAddr, pubkey, false)
	if err != nil {
		return nil, 0, err
	}

	ret, err = method.Outputs.Pack(seiAddr.String(), evmAddr)
	return ret, pcommon.GetRemainingGas(ctx, p.evmKeeper), err
}

func (p AssociationHelper) AssociateAddresses(ctx sdk.Context, seiAddr sdk.AccAddress, evmAddr common.Address, pubkey cryptotypes.PubKey, migrateUseiOnly bool) error {
	castAddr := sdk.AccAddress(evmAddr[:])
	if !castAddr.Equals(seiAddr) && p.accountKeeper.GetAccount(ctx, seiAddr) == nil {
		castAcc := p.accountKeeper.GetAccount(ctx, castAddr)
		castBaseAcc, ok := castAcc.(*authtypes.BaseAccount)
		if ok && castBaseAcc.GetPubKey() == nil && p.bankKeeper.LockedCoins(ctx, castAddr).IsZero() {
			p.accountKeeper.SetAccount(ctx, authtypes.NewBaseAccount(seiAddr, pubkey, castBaseAcc.GetAccountNumber(), castBaseAcc.GetSequence()))
		}
	}
	p.evmKeeper.SetAddressMapping(ctx, seiAddr, evmAddr)
	acc := p.accountKeeper.GetAccount(ctx, seiAddr)
	if acc == nil {
		acc = p.accountKeeper.NewAccountWithAddress(ctx, seiAddr)
	}
	if acc.GetPubKey() == nil {
		if err := acc.SetPubKey(pubkey); err != nil {
			return err
		}
		p.accountKeeper.SetAccount(ctx, acc)
	}
	return p.MigrateBalance(ctx, evmAddr, seiAddr, migrateUseiOnly)
}

func (p AssociationHelper) MigrateBalance(ctx sdk.Context, evmAddr common.Address, seiAddr sdk.AccAddress, migrateUseiOnly bool) error {
	castAddr := sdk.AccAddress(evmAddr[:])
	if castAddr.Equals(seiAddr) {
		return nil
	}
	var castAddrBalances sdk.Coins
	if migrateUseiOnly {
		castAddrBalances = sdk.Coins{p.bankKeeper.GetBalance(ctx, castAddr, "usei")}
	} else {
		castAddrBalances = p.bankKeeper.SpendableCoins(ctx, castAddr)
	}
	if !castAddrBalances.IsZero() {
		if err := p.bankKeeper.SendCoins(ctx, castAddr, seiAddr, castAddrBalances); err != nil {
			return err
		}
	}
	castAddrWei := p.bankKeeper.GetWeiBalance(ctx, castAddr)
	if !castAddrWei.IsZero() {
		if err := p.bankKeeper.SendCoinsAndWei(ctx, castAddr, seiAddr, sdk.ZeroInt(), castAddrWei); err != nil {
			return err
		}
	}
	if p.bankKeeper.LockedCoins(ctx, castAddr).IsZero() {
		p.accountKeeper.RemoveAccount(ctx, authtypes.NewBaseAccountWithAddress(castAddr))
	}
	return nil
}
