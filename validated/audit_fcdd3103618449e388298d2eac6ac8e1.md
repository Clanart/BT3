### Title
Gasless transaction admission can rely on a configurable, reduced balance/allowance check level (`BalanceCheckLevelStatic`) that omits verification of actual token balance and approval, allowing a sender without real repayment capacity to get gas lent by the proposer - ([File: kaiax/gasless/config.go])

### Summary
The Symmetrical report describes a protocol that authorizes a costly action (opening a leveraged position) based on a value that isn't a true collateral guarantee (unrealized PnL) instead of verifying actually-backed funds, breaking the "must be collateralized" invariant. The closest reachable analog in this Kaia codebase is the `kaiax/gasless` module, where a `GaslessSwapTx` (and its preceding `GaslessApproveTx`) is admitted to the tx pool and used to justify the proposer lending gas fees to the user (`GetLendTxGenerator`), but the depth of the check that proves the user can actually repay is controlled by a configurable `BalanceCheckLevel`, and the lowest level (`BalanceCheckLevelStatic`) skips the token balance/allowance verification entirely.

### Finding Description
`GaslessModule.GetCheckBalance()` returns `checkBalanceForApprove`/`checkBalanceForSwap`, which are invoked from `TxPool.validateTx` and `txList.Filter` as the sole balance-admission gate for gasless-pattern transactions (in place of the normal KAIA balance check) [1](#0-0) . These checks only run conditionally per config flags:

```go
if g.GaslessConfig.ShouldCheckToken() { ... balanceOf/allowance checks ... }
if g.GaslessConfig.ShouldCheckSwapAmount() { ... }
if g.GaslessConfig.ShouldCheckSenderCode() { ... }
``` [2](#0-1) 

The gate functions (`ShouldCheckToken`, `ShouldCheckSwapAmount`, `ShouldCheckSenderCode`) are all driven by a single integer `BalanceCheckLevel`, with the lowest level, `BalanceCheckLevelStatic`, only validating amount relationships and deadline — it explicitly does **not** check `tx.token.balanceOf(sender)` or `tx.token.approval(sender, router)` [3](#0-2) . This is a documented, operator-configurable node flag: `gasless.balance-check-level` [4](#0-3) , and the module's own README explicitly states: "Sender balance check is omitted for gasless transactions (see `GetCheckBalance()`)" [5](#0-4) .

The consequence is structurally analogous to the reported bug: the protocol extends real value (gas paid up-front by the block proposer via `LendTxGenerator`/`GetLendTxGenerator`, funded from the proposer's own balance) on the assumption that the user's position will be "collateralized" (i.e., they truly hold the swap-input token and have approved the router so the swap can successfully repay the lent gas), but at `BalanceCheckLevelStatic` this assumption is never verified against actual on-chain token state (`ERC20.balanceOf` / `ERC20.allowance`) at admission time. `VerifyExecutable`/`IsExecutable`, which gate promotion into the pending queue and bundle building, likewise only check nonce ordering and repay-amount arithmetic (`SP1`–`SP4`), never token balance or allowance [6](#0-5) . If the swap actually fails on execution (e.g., insufficient real token balance/allowance), the proposer's lent gas is not necessarily recovered, mirroring the "position built on a value that can evaporate, leaving no real collateral behind" pattern from the report.

### Impact Explanation
If a node operator runs with `gasless.balance-check-level=0` (Static), or if the token-balance/allowance-based checks are otherwise bypassed, a sender can get their gasless swap admitted and cause the block proposer to prepend a `LendTxGenerator`-produced transaction that transfers real KAIA to the sender to cover gas, based purely on self-declared `AmountIn`/`MinAmountOut`/`AmountRepay` values without proof of actual token holdings or approval. If the subsequent swap reverts due to insufficient real balance/allowance, the proposer has paid out value (the lent gas) without receiving the expected repayment, which is a direct value-extraction/fee-delegation abuse analogous to "creating a position with just unrealized/unverified value and no real collateral."

### Likelihood Explanation
This requires the balance-check level to be configured below `BalanceCheckLevelAll` (the default is `BalanceCheckLevelAll`, so by default the token balance/allowance check IS performed) [7](#0-6) . Under default configuration this specific path is not exploitable, since `BalanceCheckLevelAll` implies `ShouldCheckToken()` is true. The risk is contingent on operator misconfiguration (running the node with a lowered `gasless.balance-check-level`), or on any block-building path where these module-level admission checks are skipped/stale relative to actual execution-time state. I could not fully verify (given available tool budget) whether the worker/execution path re-validates balance/allowance a second time immediately before the lend/swap bundle is included in a block, which would materially change the exploitability; this needs further investigation via a Devin session with fuller repository access to `kaiax/gasless/impl` block-building/bundle code and the `PreRunTx`/`PostRunTx` hooks referenced in the README's "Execution" section.

### Recommendation
- Do not allow the level of balance/allowance verification for gasless transactions to be reduced below a level that verifies actual token balance and allowance before the proposer commits to lending gas.
- Re-verify token balance, allowance, and swap-amount sufficiency immediately before block inclusion (at bundle assembly time), not only once at tx-pool admission time, to close the window between admission-time checks and execution-time state changes.
- Consider making `BalanceCheckLevelTokenBalanceAndAllowance` (or higher) the enforced minimum regardless of operator configuration, given it directly protects proposer funds from being lent against unverified collateral.

### Proof of Concept
Could not be fully constructed within the current investigation depth: exploitation depends on demonstrating (1) a running node configured with `gasless.balance-check-level` below `BalanceCheckLevelTokenBalanceAndAllowance`, and (2) that the worker/bundle-building path does not perform a second, execution-time-accurate balance/allowance check before appending the `LendTxGenerator` transaction ahead of the swap. The test `TestPromoteGaslessTxsWithSingleSender` demonstrates that with `BalanceCheckLevelStatic`, gasless txs are promoted to pending without any real KAIA/token-balance verification [8](#0-7) , but confirming actual fund loss to the proposer at block-building time would require deeper tracing of the worker/bundle code beyond what was retrievable in this session.

func (g *GaslessModule) GetCheckBalance() func(tx *types.Transaction) error {
	return func(tx *types.Transaction) error {
		if approveArgs, ok := decodeApproveTx(tx, g.signer); ok {
			return g.checkBalanceForApprove(approveArgs)
		}
		if swapArgs, ok := decodeSwapTx(tx, g.signer); ok {
			return g.checkBalanceForSwap(swapArgs, tx.Nonce())
		}
		return errors.New("not a gasless transaction") // should not happen because IsModuleTx is called before GetCheckBalance
	}
}

func (g *GaslessModule) checkBalanceForSwap(swapArgs *SwapArgs, swapNonce uint64) error {
	token := swapArgs.Token
	bc := backends.NewBlockchainContractBackend(g.Chain, nil, nil)

	g.gaslessInfoMu.RLock()
	swapRouter := g.swapRouter
	g.gaslessInfoMu.RUnlock()

	// tx.minAmountOut >= tx.amountRepay
	minAmountOut := swapArgs.MinAmountOut
	amountRepay := swapArgs.AmountRepay
	if minAmountOut.Cmp(amountRepay) < 0 {
		return fmt.Errorf("insufficient minAmountOut: minAmountOut=%s, amountRepay=%s", minAmountOut.String(), amountRepay.String())
	}

	if g.GaslessConfig.ShouldCheckSenderCode() {
		if g.getCurrentHasCode(swapArgs.Sender) {
			return errors.New("sender with code is not allowed")
		}
	}

	if g.GaslessConfig.ShouldCheckSwapAmount() {
		// tx.amountIn >= gsr.getAmountIn(minAmountOut)
		routerContract, err := kip247.NewGaslessSwapRouterCaller(swapRouter, bc)
		if err != nil {
			return err
		}
		// Required token amountIn, given the current exchange rate and the declared minAmountOut.
		requiredAmountIn, err := routerContract.GetAmountIn(nil, token, minAmountOut)
		if err != nil {
			return err
		}
		if swapArgs.AmountIn.Cmp(requiredAmountIn) < 0 {
			return fmt.Errorf("insufficient amountIn: have=%s, want=%s", swapArgs.AmountIn.String(), requiredAmountIn.String())
		}
	}

	if g.GaslessConfig.ShouldCheckToken() {

		tokenContract, err := sc_erc20.NewERC20(token, bc)
		if err != nil {
			return err
		}

		// If SwapTx.nonce is the sender's next nonce, then there is no room for ApproveTx proceeding SwapTx.
		senderNonce := g.getCurrentStateNonce(swapArgs.Sender)
		noApproveTxPreceeds := swapNonce == senderNonce
		if noApproveTxPreceeds {
			// tx.token.allowance(sender, router) >= tx.amountIn
			approval, err := tokenContract.Allowance(nil, swapArgs.Sender, swapRouter)
			if err != nil {
				return err
			}
			if approval.Cmp(swapArgs.AmountIn) < 0 {
				return fmt.Errorf("insufficient approval: approval=%s, want=%s", approval.String(), swapArgs.AmountIn.String())
			}
		}

		// tx.token.balanceOf(sender) >= tx.amountIn
		balance, err := tokenContract.BalanceOf(nil, swapArgs.Sender)
		if err != nil {
			return err
		}
		if balance.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("insufficient balance: balance=%s, want=%s", balance.String(), swapArgs.AmountIn.String())
		}
	}

	// tx.deadline >= currentTimestamp
	deadline := swapArgs.Deadline
	if deadline.Cmp(g.Chain.CurrentBlock().Time()) < 0 {
		return fmt.Errorf("insufficient deadline: deadline=%s, want=%s", deadline.String(), g.Chain.CurrentBlock().Time().String())
	}

	return nil
}

const (
	BalanceCheckLevelStatic                   = iota // relation between amounts and deadline
	BalanceCheckLevelTokenBalanceAndAllowance        // all above + token balance and allowance
	BalanceCheckLevelSwapAmount                      // all above +	amountIn calculated by dex
	BalanceCheckLevelAll                             // all above +	sender code check
)

type GaslessConfig struct {
	// all tokens are allowed if AllowedTokens is nil while all are disallowed if empty slice
	AllowedTokens         []common.Address `toml:",omitempty"`
	Disable               bool
	MaxBundleTxsInPending uint
	MaxBundleTxsInQueue   uint
	BalanceCheckLevel     int
}

func DefaultGaslessConfig() *GaslessConfig {
	return &GaslessConfig{
		AllowedTokens:         nil,
		Disable:               false,
		MaxBundleTxsInPending: 100,
		MaxBundleTxsInQueue:   200,
		BalanceCheckLevel:     BalanceCheckLevelAll,
	}
}

func (cfg *GaslessConfig) ShouldCheckToken() bool {
	return cfg.BalanceCheckLevel >= BalanceCheckLevelTokenBalanceAndAllowance
}

func (cfg *GaslessConfig) ShouldCheckSwapAmount() bool {
	return cfg.BalanceCheckLevel >= BalanceCheckLevelSwapAmount
}

func (cfg *GaslessConfig) ShouldCheckSenderCode() bool {
	return cfg.BalanceCheckLevel >= BalanceCheckLevelAll
}

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}
