### Title
Unauthenticated JSON-RPC `send_tx` with `fee_paying_type=RBF` and zero-input attacker-controlled transaction drains bridge wallet UTXOs — (`crates/clementine-tx-sender/src/jsonrpc/server.rs`, `crates/clementine-tx-sender/src/rbf.rs`)

---

### Summary

The tx-sender JSON-RPC server exposes a `send_tx` endpoint with **no authentication**. An attacker who can reach the endpoint (trivially possible when bound to `0.0.0.0`, which the code explicitly permits) can submit a zero-input transaction with attacker-controlled outputs and `fee_paying_type=RBF`. The txsender loop will call `send_rbf_tx` → `create_funded_psbt` → `wallet_create_funded_psbt` with `add_inputs: true`, causing Bitcoin Core's wallet to select and lock its own UTXOs, sign them, and broadcast a transaction that pays the attacker's outputs. Bridge-controlled wallet funds are drained.

---

### Finding Description

**Step 1 — Unauthenticated entry point.**

`start_jsonrpc_server` builds a plain `jsonrpsee` server with no auth middleware and registers `send_tx` unconditionally: [1](#0-0) 

There is zero authentication, token validation, or IP allowlist in the handler. The config explicitly permits `0.0.0.0` binding: [2](#0-1) 

**Step 2 — Arbitrary tx accepted into the queue.**

The `send_tx` handler deserializes the raw hex, calls `insert_try_to_send`, and commits. No validation is performed on the tx content, its inputs, or whether `fee_paying_type=RBF` is appropriate for the submitted tx: [3](#0-2) 

`insert_try_to_send` saves the tx and its `fee_paying_type` verbatim: [4](#0-3) 

**Step 3 — Txsender loop dispatches to `send_rbf_tx`.**

`try_to_send_unconfirmed_txs` fetches all sendable txs and routes `FeePayingType::RBF` directly to `send_rbf_tx`: [5](#0-4) 

**Step 4 — Zero-input tx bypasses all guards and reaches `create_funded_psbt`.**

In `send_rbf_tx`, the `rbf_signing_info` dummy-witness block is skipped when `rbf_signing_info` is `None`. The zero-input tx has no outputs to trigger the dummy-output guard either (if the attacker includes at least one output). The code falls straight through to: [6](#0-5) 

**Step 5 — Wallet funds the attacker's transaction.**

`create_funded_psbt` calls `wallet_create_funded_psbt` with `add_inputs: Some(true)`. Because the submitted tx has zero inputs, the wallet selects its own UTXOs to cover the attacker's outputs plus fees, and adds a change output: [7](#0-6) 

**Step 6 — Wallet signs and the tx is broadcast.**

`wallet_process_psbt` with `sign=true` signs the wallet's inputs. Since `rbf_signing_info` is `None`, the wallet-signed PSBT is used directly. `send_raw_transaction` broadcasts the final tx: [8](#0-7) [9](#0-8) 

The `verify_new_inputs` check at line 909 is a **warning only** — it does not abort the flow: [10](#0-9) 

---

### Impact Explanation

Bridge-controlled wallet UTXOs (used to fund RBF fee bumps for bridge transactions) are spent into attacker-controlled outputs. This directly drains the tx-sender's fee reserve, preventing legitimate bridge transactions from being fee-bumped and confirmed, and constitutes theft of bridge-controlled BTC held in the wallet.

---

### Likelihood Explanation

- When `TX_SENDER_JSONRPC_BIND=0.0.0.0` (explicitly supported by the code), any network-reachable host can exploit this with a single HTTP POST.
- Even with the default `127.0.0.1` binding, any co-located process (another container in the same pod, a compromised sidecar, etc.) can exploit this — still no authentication is required.
- The attack requires no keys, no credentials, and no prior bridge state knowledge.

---

### Recommendation

1. **Add authentication** to the JSON-RPC server (shared secret, mTLS, or token header) before any method dispatch.
2. **Validate `fee_paying_type` against tx structure** in `insert_try_to_send`: reject `RBF`/`RbfWtxidGrind` submissions that have zero inputs and no `rbf_signing_info`, or that carry outputs not belonging to known bridge script templates.
3. **Restrict `0.0.0.0` binding** or require explicit operator acknowledgment with a mandatory auth secret when binding to a non-loopback address.

---

    pub async fn create_funded_psbt(
        &self,
        tx: &Transaction,
        fee_rate: FeeRateKvb,
    ) -> Result<WalletCreateFundedPsbtResult> {
        // 1. Create a funded PSBT using the wallet
        let create_psbt_opts = bitcoincore_rpc::json::WalletCreateFundedPsbtOptions {
            add_inputs: Some(true), // Let the wallet add its inputs
            include_unsafe: Some(self.include_unsafe),
            change_address: None,
            change_position: Some(tx.output.len() as u16), // Add change output at last index (so that SinglePlusAnyoneCanPay signatures stay valid)
            change_type: None,
            include_watching: None,
            lock_unspent: None,
            // Bitcoincore expects BTC/kvbyte for fee_rate
            fee_rate: Some(
                fee_rate
                    .fee_vb(1000)
                    .ok_or_eyre("Failed to convert fee rate to BTC/kvbyte")?,
            ),
            subtract_fee_from_outputs: vec![],
            replaceable: Some(true), // Mark as RBF enabled
            conf_target: None,
            estimate_mode: None,
        };

        let mut omitted = 0usize;
        let filtered_outputs: Vec<WalletCreateFundedPsbtOutput> = tx
            .output
            .iter()
            .filter_map(|out| {
                if out.script_pubkey.is_op_return() {
                    if let Some(Ok(Instruction::PushBytes(data))) =
                        out.script_pubkey.instructions().last()
                    {
                        return Some(WalletCreateFundedPsbtOutput::OpReturn(
                            data.as_bytes().to_vec(),
                        ));
                    }
                }
                let address = Address::from_script(
                    &out.script_pubkey,
                    self.network,
                )
                .map_err(|e| eyre!(e));
                match address {
                    Ok(address) => Some(WalletCreateFundedPsbtOutput::Spendable(
                        address.to_string(),
                        out.value,
                    )),
                    Err(err) => {
                        tracing::error!(
                            "Failed to get address from script for output of tx with txid {} for script: {}",
                            tx.compute_txid(),
                            err
                        );
                        omitted += 1;
                        None
                    }
                }
            })
            .collect::<Vec<_>>();

        if omitted > 0 {
            return Err(eyre::eyre!("Failed to get address for outputs of tx with txid {} for {} outputs in create_funded_psbt", tx.compute_txid(), omitted).into());
        }

        let outputs = WalletCreateFundedPsbtOutputs(filtered_outputs);

        self.rpc
            .wallet_create_funded_psbt(
                &tx.input
                    .iter()
                    .map(|inp| CreateRawTransactionInput {
                        txid: inp.previous_output.txid,
                        vout: inp.previous_output.vout,
                        sequence: Some(inp.sequence.to_consensus_u32()),
                        // give a specific weight if witness is not empty
                        weight: if inp.witness.is_empty() {
                            None
                        } else {
                            Some(inp.segwit_weight().to_wu())
                        },
                    })
                    .collect::<Vec<_>>(),
                outputs,
                None,
                Some(create_psbt_opts),
                None,
            )
            .await
            .map_err(|e| eyre!(e).into())
    }
