### Title
TOCTOU Race Condition in Gasless Bundle-Tx Queue-Limit Check Allows Bypass of `MaxBundleTxsInQueue` - (File: `kaiax/gasless/impl/tx_pool.go`)

### Summary
`GaslessModule.PreAddTx` enforces the gasless-bundle admission limit (`MaxBundleTxsInQueue`) by checking `g.knownTxs.numQueue() >= g.GetMaxBundleTxsInQueue()` and then calling `g.knownTxs.add(tx, TxStatusQueue)` — but both the check and the mutating add happen while holding only a **read lock** (`g.knownTxsMu.RLock()`), not a write lock. [1](#0-0) 

### Finding Description
`sync.RWMutex.RLock()` permits unlimited concurrent readers. `PreAddTx` is invoked concurrently for every transaction admitted to the tx pool (called from the tx pool's per-tx admission hook for every `AddLocal`/`AddRemote` gasless approve/swap transaction). Because the check (`numQueue() >= limit`) and the state mutation (`knownTxs.add(...)`) are wrapped in the same `RLock`/`RUnlock` pair rather than a `Lock`/`Unlock` pair, many goroutines can simultaneously read the same "current count is below limit" snapshot and then all proceed to call `add`, exactly mirroring the check-then-act TOCTOU pattern described in the OTP report (check attempt count, then act on stale state before the counter is durably updated). This is compounded by the underlying `knownTxs` map (see `kaiax/gasless/impl/tx_counter.go`) not being safe for concurrent writers, since its own consistency depends entirely on the caller holding an exclusive lock — which `PreAddTx` never acquires for the mutating path. [1](#0-0) 

Contrast this with the auction module's `bid_pool.go`, which correctly re-validates state under an exclusive `Lock()` in `insertBid` after an initial `RLock`-based `validateBid`, specifically to close this exact race window ("Re-check bidWinnerMap here — two concurrent bids can pass validateBid together"). [2](#0-1) 

### Impact Explanation
An unauthenticated/unprivileged transaction sender can submit many gasless bundle transactions (`GaslessApproveTx`/`GaslessSwapTx` per KIP-247) concurrently via the public RPC (`eth_sendRawTransaction` or the batch gasless submission path). By racing the `PreAddTx` check, an attacker can flood `knownTxs` well beyond the configured `MaxBundleTxsInQueue`, defeating the queue-admission control that exists specifically to bound gasless-transaction-related resource consumption and the block-builder's bundling/relocation work (`ExtractTxBundles`), and to bound the block proposer's gas-lending exposure per block, since every unbounded queued bundle transaction is a candidate for `LendTxGenerator` prepending and fee-lending by the proposer. [3](#0-2) 

### Likelihood Explanation
High: the race is trivially triggerable by any transaction sender submitting a burst of concurrent RPC calls with gasless approve/swap transactions; no special privilege, precise timing beyond ordinary goroutine scheduling, or validator/consensus access is required.

### Recommendation
Acquire `g.knownTxsMu.Lock()` (exclusive) instead of `RLock()` around the entire check-then-add critical section in `PreAddTx`, matching the double-checked-locking pattern already used in `kaiax/auction/impl/bid_pool.go`'s `insertBid`.

### Proof of Concept
1. Configure `GaslessConfig.MaxBundleTxsInQueue = N`.
2. From a single external account (or many), craft `N*10` valid `GaslessSwapTx`/`GaslessApproveTx` pairs.
3. Submit all of them concurrently (e.g., `2*N` goroutines calling `pool.AddLocal`/RPC `eth_sendRawTransaction` simultaneously) so their `PreAddTx` calls overlap while each observes `numQueue() < N`.
4. Observe `g.knownTxs.numQueue()` exceeding `N` afterward, confirming the queue-admission limit was bypassed via the RLock-protected check-then-act race. [1](#0-0)

func (g *GaslessModule) PreAddTx(tx *types.Transaction, local bool) error {
	g.knownTxsMu.RLock()
	defer g.knownTxsMu.RUnlock()

	if knownTx, ok := g.knownTxs.get(tx.Hash()); ok && knownTx.elapsedPromotedOrAddedTime() < KnownTxTimeout {
		return ErrUnableToAddKnownBundleTx
	}

	if g.IsBundleTx(tx) {
		if uint(g.knownTxs.numQueue()) >= g.GetMaxBundleTxsInQueue() {
			return ErrBundleTxQueueFull
		}
		g.knownTxs.add(tx, TxStatusQueue)
	}
	return nil
}

func (bp *BidPool) insertBid(bid *auction.Bid) error {
	bp.bidMu.Lock()
	defer bp.bidMu.Unlock()

	var (
		blockNumber  = bid.BlockNumber
		targetTxHash = bid.TargetTxHash
		sender       = bid.Sender
	)

	// Re-check bidWinnerMap here — two concurrent bids can pass validateBid together.
	if _, ok := bp.bidMap[bid.Hash()]; ok {
		return auction.ErrBidAlreadyExists
	}
	if bp.senderHasDifferentWinner(bid) {
		return auction.ErrBidSenderExists
	}

	// If same block number, same target tx hash exists, replace it if it's better
	if existingBid, ok := bp.bidTargetMap[blockNumber][targetTxHash]; ok {
		// FCFS if the bid is the same.
		if existingBid.Bid.Cmp(bid.Bid) >= 0 {
			return auction.ErrLowBid
		}

		logger.Trace("Replace bid", "old", existingBid.Hash(), "new", bid.Hash())
		delete(bp.bidMap, existingBid.Hash())
		delete(bp.bidWinnerMap[blockNumber], existingBid.Sender)
	} else {
		if int64(len(bp.bidMap)) >= bp.maxBidPoolSize {
			logger.Info("Bid pool is full", "maxBidPoolSize", bp.maxBidPoolSize, "bid", bid.Hash())
			return auction.ErrBidPoolFull

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
}
