Audit Report

## Title
Staked-peer QUIC connection privilege (`ConnectionPeerType::Staked`) is snapshotted once at connect time and never re-validated against current stake, allowing a peer to retain elevated QoS after unstaking - (File: streamer/src/nonblocking/swqos.rs / streamer/src/nonblocking/quic.rs)

## Summary
`get_connection_stake` performs a single point-in-time lookup of a connecting peer's stake against the live `staked_nodes` map, and this result is cached for the entire lifetime of the QUIC connection in `SwQosConnectionContext`/`SimpleQosConnectionContext`. Because `StakedNodesUpdaterService` refreshes the underlying `staked_nodes` map independently every 5 seconds from the root bank's current epoch stake set, a peer's cached `peer_type`/`total_stake` can become stale relative to reality, but nothing re-checks or downgrades an already-open connection.

## Finding Description
`build_connection_context` is invoked exactly once per connection, at connection-accept time, calling `get_connection_stake` against `staked_nodes`: [1](#0-0)  This is only called from the connection-accept path in `spawn_server`'s accept loop: [2](#0-1)  The resulting classification is cached into `SwQosConnectionContext { peer_type, total_stake, .. }` inside `build_connection_context` [3](#0-2)  and used to compute stream quotas and connection-table placement for the life of the connection, e.g. in `max_streams_per_throttling_interval` and `try_add_connection`'s staked-table logic (including `prune_random`, which evicts based on the cached `stake` value, not a live lookup): [4](#0-3) [5](#0-4) 

Meanwhile, the live `staked_nodes` map used for *new* connections is refreshed independently by a background service every `STAKE_REFRESH_CYCLE` (5 seconds) from the root bank's current epoch stake set: [6](#0-5)  There is no code path in `swqos.rs`, `simple_qos.rs`, `qos.rs`, or `quic.rs` that re-derives an already-open connection's `SwQosConnectionContext`/`SimpleQosConnectionContext` against this refreshed map; `build_connection_context` is called only once per connection (confirmed via a single call site each in `quic.rs`, `swqos.rs`, `simple_qos.rs`). QUIC connections use a 30-second idle timeout with keep-alive intervals, so a connection can be kept open indefinitely by ordinary traffic/keep-alives without triggering a fresh stake check: [7](#0-6) 

## Impact Explanation
A connection that was classified `Staked` at connect time keeps its reserved slot in the bounded `staked_connection_table` (capacity `max_staked_connections`, default 2000) and its `total_stake`-derived stream throughput allowance even after the peer's real stake drops to zero. Because `prune_random` uses the stale cached `stake` value rather than a live lookup, such a stale-staked connection is also comparatively resistant to eviction relative to genuinely low-staked new connections. This constitutes a non-RPC remote resource-degradation issue against the TPU/QUIC ingestion path (an occupied, quota-bearing slot that a currently-staked validator would otherwise be entitled to), which is a permitted impact category for Agave (non-RPC remote exhaustion/degradation).

## Likelihood Explanation
The precondition — obtain some stake delegated to a vote account, open a QUIC connection while staked, then deactivate the stake while keeping the connection alive with ordinary traffic/keep-alives — is achievable by any unprivileged actor using standard, permissionless stake delegate/deactivate instructions; no malicious validator, trusted party, or privileged access is required. The scale of degradation from a single stale connection is limited (one slot/one connection's worth of throughput), and repeating this to acquire many such slots would require staking and unstaking capital repeatedly, which bounds practical severity even though the missing guard itself is real and confirmed in the code.

## Recommendation
Periodically re-validate each open connection's cached `peer_type`/`total_stake` in `SwQosConnectionContext`/`SimpleQosConnectionContext` against the current `staked_nodes` snapshot (e.g., tied to the existing `StakedNodesUpdaterService` refresh cycle or on each stream open), and downgrade/evict connections whose backing stake has dropped to zero or been removed from `staked_nodes`, rather than trusting the one-time snapshot captured in `build_connection_context` for the connection's entire lifetime.

## Proof of Concept
1. Delegate a small stake to a vote account under a test identity so `staked_nodes.get_node_stake(pubkey)` returns non-zero.
2. Open a QUIC connection to the target's TPU/QUIC listener as that identity; `build_connection_context` (`streamer/src/nonblocking/swqos.rs:301-342`) classifies it `ConnectionPeerType::Staked(stake)` and `try_add_connection` (`streamer/src/nonblocking/swqos.rs:354-382`) places it in `staked_connection_table`.
3. Deactivate the stake so that after the next epoch/refresh cycle, `staked_nodes.get_node_stake(pubkey)` returns `None`.
4. Keep the already-open QUIC connection alive via keep-alive/periodic traffic (well within the 30s idle timeout, `streamer/src/quic.rs:38`). Confirm via stats/logs that the connection remains in `staked_connection_table` with its original `total_stake`-derived stream allowance despite the peer's current stake being zero, and that no code path re-invokes `build_connection_context` or otherwise re-checks `staked_nodes` for this connection.

pub fn get_connection_stake(
    connection: &Connection,
    staked_nodes: &RwLock<StakedNodes>,

    Some((
        pubkey,
        staked_nodes.get_node_stake(&pubkey)?,
        staked_nodes.total_stake(),
    ))
}

impl QosController<SwQosConnectionContext> for SwQos {
    fn build_connection_context(&self, connection: &Connection) -> SwQosConnectionContext {
        let remote_address = connection.remote_address();
        get_connection_stake(connection, &self.staked_nodes).map_or(
            SwQosConnectionContext {
                peer_type: ConnectionPeerType::Unstaked,
                total_stake: 0,
                remote_pubkey: None,
                in_staked_table: false,
                remote_address,
                stream_counter: None,
                last_update: Arc::new(AtomicU64::new(timing::timestamp())),
            },
            |(pubkey, stake, total_stake)| {
                // The heuristic is that the stake should be large enough to have 1 stream pass through within one throttle
                // interval during which we allow max (MAX_STREAMS_PER_MS * STREAM_THROTTLING_INTERVAL_MS) streams.

                let peer_type = {
                    let max_streams_per_ms = self.staked_stream_load_ema.max_streams_per_ms();
                    let min_stake_ratio =
                        1_f64 / (max_streams_per_ms * STREAM_THROTTLING_INTERVAL_MS) as f64;
                    let stake_ratio = stake as f64 / total_stake as f64;
                    if stake_ratio < min_stake_ratio {
                        // If it is a staked connection with ultra low stake ratio, treat it as unstaked.
                        ConnectionPeerType::Unstaked
                    } else {
                        ConnectionPeerType::Staked(stake)
                    }
                };

                SwQosConnectionContext {
                    peer_type,
                    total_stake,
                    remote_pubkey: Some(pubkey),
                    in_staked_table: false,
                    remote_address,
                    last_update: Arc::new(AtomicU64::new(timing::timestamp())),
                    stream_counter: None,
                }
            },
        )
    }

const STAKE_REFRESH_CYCLE: Duration = Duration::from_secs(5);

pub struct StakedNodesUpdaterService {
    thread_hdl: JoinHandle<()>,
}

impl StakedNodesUpdaterService {
    pub fn new(
        exit: Arc<AtomicBool>,
        bank_forks: Arc<RwLock<BankForks>>,
        staked_nodes: Arc<RwLock<StakedNodes>>,
        staked_nodes_overrides: Arc<RwLock<HashMap<Pubkey, u64>>>,
    ) -> Self {
        let thread_hdl = Builder::new()
            .name("solStakedNodeUd".to_string())
            .spawn(move || {
                while !exit.load(Ordering::Relaxed) {
                    let stakes = {
                        let root_bank = bank_forks.read().unwrap().root_bank();
                        root_bank.current_epoch_staked_nodes()
                    };
                    let overrides = staked_nodes_overrides.read().unwrap().clone();
                    *staked_nodes.write().unwrap() = StakedNodes::new(stakes, overrides);
                    std::thread::sleep(STAKE_REFRESH_CYCLE);
                }
            })
            .unwrap();

        Self { thread_hdl }
    }
