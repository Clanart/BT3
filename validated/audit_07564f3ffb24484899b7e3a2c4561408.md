### Title
Stake-weighted QUIC/TPU QoS trusts unbounded-age `StakedNodes` snapshot with no staleness check, allowing resource exhaustion after the background refresher stalls - (File: core/src/staked_nodes_updater_service.rs)

### Summary
The Olympus RBS bug is a "trust without freshness check" pattern: a periodically-refreshed value (`beat()`/spread) is consumed by a critical control path (`swap()`) without verifying that the refresh is actually happening, so a stalled updater silently turns a safety mechanism into a loss vector. Agave's stake-weighted QUIC/TPU admission and throttling logic has the same structural flaw: `StakedNodesUpdaterService` refreshes the shared `Arc<RwLock<StakedNodes>>` on a bare 5-second sleep loop with no liveness check, and every downstream consumer (`SwQos`, `simple_qos`, `compute_max_allowed_uni_streams_with_rtt`, `available_load_capacity_in_throttling_duration`) reads that shared state and grants connection/stream priority based on it, with no check on when it was last updated.

### Finding Description
`StakedNodesUpdaterService::new` spawns a single background thread that loops forever, sleeping `STAKE_REFRESH_CYCLE` (5s) between refreshes of the shared stake map: [1](#0-0) 

If this thread panics, deadlocks (e.g., on `bank_forks.read().unwrap()` contention), or simply falls behind for an extended period, `staked_nodes` is never invalidated — it just keeps serving the last successfully-computed snapshot indefinitely. There is no `last_update` timestamp attached to `StakedNodes`, and no consumer checks one.

Downstream, `SwQos::build_connection_context` calls `get_connection_stake(connection, &self.staked_nodes)` to classify a peer as `Staked(stake)`/`Unstaked` and compute `total_stake`, which is then used unconditionally to compute connection privileges: [2](#0-1) 

That classification directly drives the number of concurrent uni-streams a peer is granted: [3](#0-2) 

and the per-peer share of the staked throughput budget during throttling: [4](#0-3) 

None of these call sites check "how old is this stake data" before trusting it — exactly the missing invariant in the RBS report (`onlyWhileActive` had no `lastBeat` staleness check before allowing `swap()` at the cached spread).

### Impact Explanation
If the staked-nodes refresh loop stalls (crash, panic, lock starvation, or any bug that halts the thread) the validator keeps making admission/throttling decisions based on an arbitrarily stale stake snapshot forever. A node whose stake has since dropped to zero (or been fully unstaked/transferred) keeps being treated as heavily staked, retaining outsized `max_uni_streams` and throttling budget shares (`available_load_capacity_in_throttling_duration`), starving genuinely staked/current validators of QUIC/TPU bandwidth. Because `total_stake` and per-peer `stake` used in these formulas are also frozen, the QoS math (`stake_ratio`, `delta` scaling in `compute_max_allowed_uni_streams_with_rtt`) becomes systematically wrong across the whole cluster, degrading transaction ingestion for legitimate current stakeholders — a non-RPC remote exhaustion/degradation condition, without requiring any malicious peer or validator assumption (the trigger is the refresher thread failing, not attacker action).

### Likelihood Explanation
The refresher runs on a plain `thread::spawn` loop with `.unwrap()` on `bank_forks.read()`; any panic inside that loop silently kills the thread with no supervisor, no health metric consulted by the QoS path, and no fallback to unstaked treatment. Given `bank_forks` is a widely shared `RwLock` touched by many subsystems, and there is no explicit test/guard ensuring the updater thread's liveness is checked before `staked_nodes` is trusted, a stall is plausible under legitimate operational conditions (lock contention, OOM, thread panic due to any transient bug), matching the "Oracle stops updating / beat() isn't called" scenario in the source report.

### Recommendation
Attach a last-updated timestamp (or health flag) to `StakedNodes`/the shared `Arc<RwLock<StakedNodes>>`, and have `SwQos`/`SimpleQos`/`get_connection_stake` treat the snapshot as stale (falling back to unstaked/conservative treatment) if `now - last_update` exceeds a bounded threshold (e.g., a small multiple of `STAKE_REFRESH_CYCLE`). Additionally, monitor/restart the `StakedNodesUpdaterService` thread and emit metrics/alerts on refresh-loop stalls, mirroring the recommended `SYNC_THRESHOLD * frequency()` staleness check from the source report.

### Proof of Concept
1. Validator starts; `StakedNodesUpdaterService` populates `staked_nodes` with the current epoch's stake distribution, including peer `P` with high stake. [5](#0-4) 
2. The updater thread stalls or panics (e.g., due to prolonged `bank_forks` write-lock contention elsewhere in the validator, or any unrelated bug causing a panic inside the loop) — no other component detects or reacts to this.
3. Peer `P`'s stake subsequently drops to zero on-chain (unstake), but `staked_nodes` still reflects the old high-stake snapshot forever.
4. `SwQos::build_connection_context` still classifies `P` as `ConnectionPeerType::Staked(<old_stake>)` and computes `total_stake` from the stale map, granting `P` disproportionate `max_uni_streams` via `compute_max_allowed_uni_streams_with_rtt` and a large slice of `available_load_capacity_in_throttling_duration`. [3](#0-2) 
5. `P` (or any new connections mapped to it) continues consuming a large, unearned share of QUIC/TPU capacity, degrading ingestion for currently-staked validators — with no code path ever re-checking the age of the stake data being relied upon.

const STAKE_REFRESH_CYCLE: Duration = Duration::from_secs(5);

pub struct StakedNodesUpdaterService {
    thread_hdl: JoinHandle<()>,
}

impl StakedNodesUpdaterService {
    pub fn new(
        exit: Arc<AtomicBool>,
        bank_forks: Arc<RwLock<BankForks>>,
        staked_nodes: Arc<RwLock<StakedNodes>>,
        staked_nodes_overrides: Arc<RwLock<HashMap<Pubkey, u64>>>,
    ) -> Self {
        let thread_hdl = Builder::new()
            .name("solStakedNodeUd".to_string())
            .spawn(move || {
                while !exit.load(Ordering::Relaxed) {
                    let stakes = {
                        let root_bank = bank_forks.read().unwrap().root_bank();
                        root_bank.current_epoch_staked_nodes()
                    };
                    let overrides = staked_nodes_overrides.read().unwrap().clone();
                    *staked_nodes.write().unwrap() = StakedNodes::new(stakes, overrides);
                    std::thread::sleep(STAKE_REFRESH_CYCLE);
                }
            })
            .unwrap();

        Self { thread_hdl }
    }

fn compute_max_allowed_uni_streams_with_rtt(
    rtt_millis: u32,
    peer_type: ConnectionPeerType,
    total_stake: u64,
) -> u32 {
    let streams = match peer_type {
        ConnectionPeerType::Staked(peer_stake) => {
            // No checked math for f64 type. So let's explicitly check for 0 here
            if total_stake == 0 || peer_stake > total_stake {
                warn!(
                    "Invalid stake values: peer_stake: {peer_stake:?}, total_stake: \
                     {total_stake:?}"
                );

                QUIC_MIN_STAKED_CONCURRENT_STREAMS
            } else {
                let delta = (QUIC_TOTAL_STAKED_CONCURRENT_STREAMS
                    - QUIC_MIN_STAKED_CONCURRENT_STREAMS) as f64;

                (((peer_stake as f64 / total_stake as f64) * delta) as u32
                    + QUIC_MIN_STAKED_CONCURRENT_STREAMS)
                    .clamp(
                        QUIC_MIN_STAKED_CONCURRENT_STREAMS,
                        QUIC_MAX_STAKED_CONCURRENT_STREAMS,
                    )
            }
        }
        ConnectionPeerType::Unstaked => QUIC_MAX_UNSTAKED_CONCURRENT_STREAMS,
    };
    // scale amount of streams based on RTT if RTT is larger than REFERENCE_RTT_MS
    // multiply first then divide to avoid rounding errors.
    (streams.saturating_mul(rtt_millis.clamp(REFERENCE_RTT_MS, MAX_RTT_MS))) / REFERENCE_RTT_MS
}

impl QosController<SwQosConnectionContext> for SwQos {
    fn build_connection_context(&self, connection: &Connection) -> SwQosConnectionContext {
        let remote_address = connection.remote_address();
        get_connection_stake(connection, &self.staked_nodes).map_or(
            SwQosConnectionContext {
                peer_type: ConnectionPeerType::Unstaked,
                total_stake: 0,
                remote_pubkey: None,
                in_staked_table: false,
                remote_address,
                stream_counter: None,
                last_update: Arc::new(AtomicU64::new(timing::timestamp())),
            },
            |(pubkey, stake, total_stake)| {
                // The heuristic is that the stake should be large enough to have 1 stream pass through within one throttle
                // interval during which we allow max (MAX_STREAMS_PER_MS * STREAM_THROTTLING_INTERVAL_MS) streams.

                let peer_type = {
                    let max_streams_per_ms = self.staked_stream_load_ema.max_streams_per_ms();
                    let min_stake_ratio =
                        1_f64 / (max_streams_per_ms * STREAM_THROTTLING_INTERVAL_MS) as f64;
                    let stake_ratio = stake as f64 / total_stake as f64;
                    if stake_ratio < min_stake_ratio {
                        // If it is a staked connection with ultra low stake ratio, treat it as unstaked.
                        ConnectionPeerType::Unstaked
                    } else {
                        ConnectionPeerType::Staked(stake)
                    }
                };

                SwQosConnectionContext {
                    peer_type,
                    total_stake,
                    remote_pubkey: Some(pubkey),
                    in_staked_table: false,
                    remote_address,
                    last_update: Arc::new(AtomicU64::new(timing::timestamp())),
                    stream_counter: None,
                }
            },
        )
    }

    pub(crate) fn available_load_capacity_in_throttling_duration(
        &self,
        peer_type: ConnectionPeerType,
        total_stake: u64,
    ) -> u64 {
        match peer_type {
            ConnectionPeerType::Unstaked => self.max_unstaked_load_in_throttling_window,
            ConnectionPeerType::Staked(stake) => {
                if self.staked_throttling_enabled.load(Ordering::Relaxed) {
                    // 1 is added to `max_unstaked_load_in_throttling_window` to guarantee that staked
                    // clients get at least 1 more number of streams than unstaked connections.
                    self.max_staked_load_in_throttling_window
                        .saturating_mul(stake)
                        .checked_div(total_stake)
                        .unwrap_or(self.max_unstaked_load_in_throttling_window + 1)
                        .max(self.max_unstaked_load_in_throttling_window + 1)
                } else {
                    self.max_staked_load_in_throttling_window
                }
            }
        }
    }
