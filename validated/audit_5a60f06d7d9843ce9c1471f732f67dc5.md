### Title
`CallDispatcher.dispatch()` has zero access control, allowing any unprivileged caller to sweep any residual solver/order token balances left on the shared dispatcher - ([File: evm/src/utils/CallDispatcher.sol])

### Summary
`CallDispatcher.dispatch()` is a fully public, unauthenticated function that executes arbitrary `Call[]` against arbitrary targets with arbitrary calldata and arbitrary value, exactly like the `arbitraryCall()` primitive in the referenced report. Where the C4 finding was missing a check that the target wasn't an "active incentive" address, here the analogous missing check is a missing *caller* restriction: `dispatch()` never checks `msg.sender` at all, so anyone — not just the `IntentGatewayV2`/`IntentsBase` contract that is supposed to own the flow — can invoke it directly against the shared, single `CallDispatcher` instance.

### Finding Description
`IntentsBase._execute()` uses a shared `CallDispatcher` singleton (`_params.dispatcher`) to run solver-supplied swap/composability calldata during order fills, then sweeps only the tokens declared in `order.output.assets` back to itself: [1](#0-0) 

The sweep is bounded by `outputsLen`, i.e. only the token addresses explicitly listed in the *current* order's outputs are collected back into `IntentsBase`. Any token balance that ends up sitting on the dispatcher outside that list (e.g. an intermediate swap-path token, dust from a multi-hop route, a token sent to the dispatcher by mistake, or a partially-completed sweep) is left behind in the `CallDispatcher` contract.

Critically, `CallDispatcher.dispatch()` itself has no access-control modifier of any kind: [2](#0-1) 

Compare this to every other privileged dispatch point in the codebase, all of which gate the caller: `HostManager.onAccept` is `restrict(_params.host)` [3](#0-2) , and `SimplexPaymaster.onAccept` is `onlyHost` and further checks `request.source` [4](#0-3) . `CallDispatcher` has neither an owner check, a "called only from IntentsBase" check, nor any state tracking of which balances are "in flight" for a specific order (the direct analog of Locke's missing `incentives[who] == 0` check).

Because the contract is meant to be used as a shared utility (it's referenced generically as `ICallDispatcher`/`Call` and wired into `IntentsBase._params.dispatcher`), any stray balance it holds between transactions is an open invitation: an attacker simply calls `CallDispatcher.dispatch(abi.encode(calls))` directly with a `Call` that transfers out whatever ERC-20/ETH balance currently sits on the contract to themselves. There is no way for the contract to distinguish "IntentsBase calling on behalf of order X" from "random EOA calling to steal order X's leftover funds."

### Impact Explanation
Any token or ETH balance that transiently or accidentally remains on the `CallDispatcher` (from incomplete sweeps, non-enumerated intermediate swap tokens, or third-party mistaken transfers) can be drained by an unprivileged third party with a single transaction. This is a direct "stealing of funds" primitive that fits the bounty's impact gate (unauthorized execution / fund loss) and requires no malicious relayer, prover, or governance actor — just a public call to a public function on a contract central to the Intents fill path.

### Likelihood Explanation
Likelihood is high in practice because:
- `dispatch()` is `external` and callable by anyone with no restriction, so exploitation is trivial (a single transaction) once any balance exists on the contract.
- The sweep logic in `_execute()` is scoped only to `order.output.assets`, so any solver route that produces or routes through additional intermediate tokens (common in multi-hop DEX composability, which the code's own comments call out as the intended use case) will leave dust that this function cannot recover, but that an attacker can.
- The contract is designed to be a shared singleton across many fills/orders/gateway deployments, increasing the exposure window and the amount that can accumulate before being noticed or governance-swept.

### Recommendation
Restrict `CallDispatcher.dispatch()` to a known, authorized caller (e.g., an immutable `owner`/`intentGateway` address set at construction, checked via a `restrict`/`onlyOwner` modifier), mirroring the pattern already used by `HostManager.onAccept` (`restrict(_params.host)`) and `SimplexPaymaster.onAccept` (`onlyHost`). If the dispatcher must remain callable by multiple authorized apps, maintain an explicit allowlist of caller contracts instead of leaving it fully public. Additionally, `_execute()`'s post-swap sweep should enumerate and recover *all* tokens actually touched by `order.output.call` (not just the declared `order.output.assets`), so no balance is ever left resident on the shared dispatcher between transactions.

### Proof of Concept
1. A solver fills an order whose `order.output.call` routes through an intermediate token `X` not listed in `order.output.assets` (e.g., a multi-hop swap `A -> X -> B` where only `B` is declared as the output token). After `_execute()` runs, `IntentsBase` sweeps only token `B`'s balance off `CallDispatcher`; leftover dust of `X` remains on the dispatcher contract.
2. An attacker (any EOA, unrelated to the order or to governance) observes the `CallDispatcher` address (it is a fixed, shared, publicly known contract referenced in `_params.dispatcher`) and calls:
```solidity
Call[] memory calls = new Call[](1);
calls[0] = Call({
    to: address(X),
    value: 0,
    data: abi.encodeWithSelector(IERC20.transfer.selector, attacker, IERC20(X).balanceOf(address(dispatcher)))
});
CallDispatcher(dispatcher).dispatch(abi.encode(calls));
```
3. Because `dispatch()` performs no `msg.sender` check [2](#0-1) , the call succeeds and the attacker receives the residual token `X`, which was economically part of the fill (protocol dust or unswept solver value), with no participation from `IntentsBase`, the solver, or governance.

    function _execute(Order calldata order, uint256 outputsLen) internal {
        if (order.output.call.length == 0) return;

        address dispatcher = _params.dispatcher;
        ICallDispatcher(dispatcher).dispatch(order.output.call);

        Call[] memory sweepCalls = new Call[](outputsLen);
        uint256 sweepCount = 0;

        for (uint256 i; i < outputsLen;) {
            address token = address(uint160(uint256(order.output.assets[i].token)));

            if (token == address(0)) {
                uint256 balance = dispatcher.balance;
                if (balance > 0) {
                    sweepCalls[sweepCount] = Call({to: address(this), value: balance, data: ""});
                    sweepCount++;
                    emit DustCollected(token, balance);
                }
            } else {
                uint256 balance = IERC20(token).balanceOf(dispatcher);
                if (balance > 0) {
                    sweepCalls[sweepCount] = Call({
                        to: token,
                        value: 0,
                        data: abi.encodeWithSelector(IERC20.transfer.selector, address(this), balance)
                    });
                    sweepCount++;
                    emit DustCollected(token, balance);
                }
            }

            unchecked {
                ++i;
            }
        }

        if (sweepCount > 0) {
            Call[] memory finalCalls = new Call[](sweepCount);
            for (uint256 i; i < sweepCount;) {
                finalCalls[i] = sweepCalls[i];
                unchecked {
                    ++i;
                }
            }
            ICallDispatcher(dispatcher).dispatch(abi.encode(finalCalls));
        }
    }

    function dispatch(bytes memory encoded) external {
        Call[] memory calls = abi.decode(encoded, (Call[]));
        uint256 callsLen = calls.length;
        for (uint256 i = 0; i < callsLen; ++i) {
            Call memory call = calls[i];
            uint32 size;
            address to = call.to;
            assembly {
                size := extcodesize(to)
            }

            if (size == 0) {
                revert NotContract(to);
            }

            (bool success, bytes memory result) = to.call{value: call.value}(call.data);
            if (!success) revert CallFailed(to, result);
        }
    }
