### Title
Auction bid's `MaxGasPrice` field is not covered by the searcher's EIP-712 signature, enabling mass-assignment tampering of an unsigned field via `auction_submitBid` - ([File: kaiax/auction/eip712.go])

### Summary
The `auction_submitBid` RPC endpoint accepts a full `BidInput` struct from any caller and converts it 1:1 into a `Bid`/`BidData` object via `ToBid()`. The bid pool's only authenticity guarantee is that the `SearcherSig` recovers to `bid.Sender` and that `AuctioneerSig` recovers to the configured auctioneer. However, the struct-hash used for the default/V2 EIP-712 typed-data digest does not include the `MaxGasPrice` field, so a bid can be resubmitted with an attacker-modified `MaxGasPrice` value while still passing signature verification — a mass-assignment-style acceptance of a field that was never authorized/signed by the searcher.

### Finding Description
`Bid.EncodeData()` (the V2/2.1 struct-hash encoder used whenever `version != AuctionVersionV3`) only encodes `TargetTxHash, BlockNumber, Sender, To, Nonce, Bid, CallGasLimit`, and the hash of `Data`: [1](#0-0) 

Only the V3 variant, `bidV3.EncodeData()`, includes `MaxGasPrice` in the signed payload: [2](#0-1) 

`ValidateSearcherSig` simply recovers the signer from whichever digest is produced by `GetHashTypedData` (V2 or V3 depending on `auctionEntryPointVersion`) and compares it to `bid.Sender`: [3](#0-2) 

The RPC input struct decodes and forwards `MaxGasPrice` verbatim into `BidData` regardless of signature coverage: [4](#0-3) 

`BidPool.validateBid`/`validateBidSigs` never independently checks that `MaxGasPrice` was part of the signed data; it only checks block-number range, positive bid, data size, call-gas-limit, and that both signatures verify: [5](#0-4) 

Consequently, whenever the deployed `AuctionEntryPoint` uses the V2/2.1 typehash (`auctionEntryPointVersion != AuctionVersionV3`), the `MaxGasPrice` field behaves like an unauthenticated/mass-assignable field: anyone who can observe a validly signed `(SearcherSig, AuctioneerSig)` pair (e.g., from the P2P bid-gossip channel `HandleBid`, or by replaying a bid seen via the RPC/gossip network) can resubmit the same bid with a different `MaxGasPrice` and it will pass `validateBidSigs` unchanged, because that field is outside the hashed struct for V2. This is functionally identical to the iTop bug class: a caller can set an object field ("value to object fields") that they are "not supposed to" set, because the authorization mechanism (digital signature acting as the form's ACL) does not cover it.

### Impact Explanation
`MaxGasPrice` is threaded through to `system.EncodeAuctionCallData`, which becomes the calldata for the proposer-signed `BidTxGenerator` transaction that calls the on-chain `AuctionEntryPoint.call(auctionTx)`: [6](#0-5) 

If the on-chain `AuctionEntryPoint` contract (deployed as a system contract, not shown fully in this repo's mock) uses `maxGasPrice` to bound how much gas price/fee the searcher is willing to pay or to compute proposer compensation (as its presence in the V3-only hash structure suggests it is meant to be a searcher-committed value), an attacker able to tamper with this unsigned field can manipulate the fee/settlement math of the auction execution without the searcher's authorization — i.e., unauthorized value movement/fee abuse in the auction settlement path, matching the "gasless or auction settlement theft" acceptance criterion.

### Likelihood Explanation
Exploitation requires access to a validly signed bid's raw fields (searcher and auctioneer signatures), which are transmitted in cleartext over the P2P bid-gossip channel (`HandleBid`) and are also visible to anyone submitting via `auction_submitBid`. Since signatures are static byte blobs independent of `MaxGasPrice` under V2, no cryptographic break is needed — only observation/replay of a legitimate bid with a substituted `MaxGasPrice` value, making this a low-effort, network-observable tampering primitive. The practical severity depends on the currently-deployed `AuctionEntryPoint` version (V2 vs. V3); if V3 is exclusively used in production, this specific field is protected, but the code path supporting V2 remains reachable and unguarded.

### Recommendation
Include `MaxGasPrice` in the canonical EIP-712 struct hash for all supported auction versions (not just V3), or reject bids whose `MaxGasPrice` is set but not covered by the active signature version, so that every field forwarded into `BidData`/`system.EncodeAuctionCallData` is provably authorized by the searcher's signature — analogous to iTop's fix of restricting settable fields to an explicit allow-list per form/tx type (compare with the field allow-list pattern already used in `api/tx_args.go`'s `isTxField`/`checkArgs`).

### Proof of Concept
1. Observe (via P2P gossip or a previous `auction_submitBid` call) a legitimate bid tuple `{TargetTxHash, BlockNumber, Sender, To, Nonce, Bid, CallGasLimit, Data, SearcherSig, AuctioneerSig}` signed under the V2/2.1 typehash (`auctionEntryPointVersion != "0.0.2"`).
2. Construct a new `BidInput` JSON payload with the same signed fields and signatures but a different `MaxGasPrice` value.
3. Submit via `auction_submitBid`; `bp.validateBidSigs` (`kaiax/auction/impl/bid_pool.go:397-419`) verifies `ValidateSearcherSig`/`ValidateAuctioneerSig` successfully because `MaxGasPrice` is not part of `EncodeData()` (`kaiax/auction/eip712.go:75-86`), so the tampered bid is accepted into the bid pool and later encoded into the on-chain `AuctionEntryPoint.call` calldata.

Note: full on-chain financial impact could not be independently confirmed from this repository because the only available `AuctionEntryPoint` implementation (`AuctionEntryPointMock.sol`) has its gas/fee accounting logic commented out; the actual production contract's use of `maxGasPrice` was not available in the indexed context, so the described gap is a proven data-integrity flaw whose full monetary consequence depends on unseen on-chain contract code.

func (b *Bid) ValidateSearcherSig(chainId *big.Int, verifyingContract common.Address, version string) error {
	if chainId == nil {
		return ErrNilChainId
	}

	if common.EmptyAddress(verifyingContract) {
		return ErrNilVerifyingContract
	}

	digest := b.GetHashTypedData(chainId, verifyingContract, version)

	recoveredSender, err := getSigner(b.SearcherSig, digest)
	if err != nil {
		return fmt.Errorf("failed to recover searcher sig: %v", err)
	}

	if recoveredSender != b.Sender {
		return fmt.Errorf("invalid searcher sig: expected %v, calculated %v", b.Sender.String(), recoveredSender.String())
	}

	return nil
}

func ToBid(bidInput BidInput) *auction.Bid {
	bidData := auction.BidData{
		TargetTxHash:  bidInput.TargetTxHash,
		BlockNumber:   bidInput.BlockNumber,
		Sender:        bidInput.Sender,
		To:            bidInput.To,
		Nonce:         bidInput.Nonce,
		Bid:           bidInput.Bid.ToInt(),
		CallGasLimit:  bidInput.CallGasLimit,
		Data:          bidInput.Data,
		SearcherSig:   bidInput.SearcherSig,
		AuctioneerSig: bidInput.AuctioneerSig,
	}
	if bidInput.MaxGasPrice != nil {
		bidData.MaxGasPrice = bidInput.MaxGasPrice.ToInt()
	}
	return &auction.Bid{BidData: bidData}
}

func (bp *BidPool) validateBid(bid *auction.Bid) error {
	blockNumber := bid.BlockNumber

	bp.bidMu.RLock()

	// Check if the auction tx is already in the pool.
	if _, ok := bp.bidMap[bid.Hash()]; ok {
		bp.bidMu.RUnlock()
		return auction.ErrBidAlreadyExists
	}

	// 1. The `bid.Sender` must not be in the winner list of the same block number if the new bid isn't equal to the previous bid.
	if bp.senderHasDifferentWinner(bid) {
		bp.bidMu.RUnlock()
		return auction.ErrBidSenderExists
	}
	bp.bidMu.RUnlock()

	curBlock := bp.Chain.CurrentBlock()
	if curBlock == nil {
		return auction.ErrBlockNotFound
	}

	// 2. The `bid.BlockNumber` must be in range of `[currentBlockNumber + 1, currentBlockNumber + allowFutureBlock]`.
	curNum := curBlock.NumberU64()
	if blockNumber <= curNum || blockNumber > curNum+allowFutureBlock {
		return auction.ErrInvalidBlockNumber
	}

	// 3. The `bid.Bid` must be greater than 0.
	if bid.Bid.Sign() <= 0 {
		return auction.ErrZeroBid
	}

	// 4. The data size must be less than the maximum limit.
	if uint64(len(bid.Data)) > BidTxMaxDataSize {
		return auction.ErrExceedMaxDataSize
	}

	// 5. The gas limit must be less than the maximum limit.
	if bid.CallGasLimit > BidTxMaxCallGasLimit {
		return auction.ErrExceedMaxCallGasLimit
	}

	// 6. The `bid.SearcherSig` and `bid.AuctioneerSig` must be valid.
	if err := bp.validateBidSigs(bid); err != nil {
		return err
	}

	return nil
}

func (bp *BidPool) validateBidSigs(bid *auction.Bid) error {
	bp.auctionInfoMu.RLock()
	defer bp.auctionInfoMu.RUnlock()

	if bid.SearcherSig == nil || len(bid.SearcherSig) != crypto.SignatureLength {
		return auction.ErrInvalidSearcherSig
	}
	if bid.AuctioneerSig == nil || len(bid.AuctioneerSig) != crypto.SignatureLength {
		return auction.ErrInvalidAuctioneerSig
	}

	// Verify the EIP712 signature.
	if err := bid.ValidateSearcherSig(bp.ChainConfig.ChainID, bp.auctionEntryPoint, bp.auctionEntryPointVersion); err != nil {
		return err
	}

	// Verify the auctioneer signature.
	if err := bid.ValidateAuctioneerSig(bp.auctioneer); err != nil {
		return err
	}

	return nil
}

func (a *AuctionModule) GetBidTxGenerator(tx *types.Transaction, bid *auction.Bid) *builder.TxOrGen {
	gen := func(nonce uint64) (*types.Transaction, error) {
		var (
			chainId           = a.InitOpts.ChainConfig.ChainID
			signer            = types.LatestSignerForChainID(chainId)
			auctionEntryPoint = a.bidPool.GetAuctionEntryPoint()
			key               = a.InitOpts.NodeKey
		)

		data, err := system.EncodeAuctionCallData(bid, a.bidPool.GetAuctionEntryPointVersion())
		if err != nil {
			return nil, err
		}

		if bid.GetGasLimit() == 0 {
			gasLimit, err := a.bidPool.getBidTxGasLimit(bid)
			if err != nil {
				return nil, err
			}
			bid.SetGasLimit(gasLimit)
		}

		tx, err := types.NewTransactionWithMap(types.TxTypeEthereumDynamicFee, map[types.TxValueKeyType]interface{}{
			types.TxValueKeyNonce:      nonce,
			types.TxValueKeyTo:         &auctionEntryPoint,
			types.TxValueKeyAmount:     common.Big0,
			types.TxValueKeyData:       data,
			types.TxValueKeyGasLimit:   bid.GetGasLimit(),
			types.TxValueKeyGasFeeCap:  tx.GasFeeCap(),
			types.TxValueKeyGasTipCap:  tx.GasTipCap(),
			types.TxValueKeyAccessList: types.AccessList{},
			types.TxValueKeyChainID:    chainId,
		})
		if err != nil {
			return nil, err
		}

		err = tx.Sign(signer, key)

		return tx, err
	}
