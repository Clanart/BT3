### Title
Gasless swap sender-balance and allowance pre-check trusts nominal `amountIn` instead of actual amount deducted, allowing fee-on-transfer/deflationary tokens to break repayment accounting - (File: kaiax/gasless/impl/tx_pool.go)

### Summary
The Kaia gasless module validates a `swapForGas` transaction by checking `tokenContract.BalanceOf(sender) >= amountIn` and `Allowance(sender, router) >= amountIn` before admitting the bundled approve/swap transaction pair into the pool and before the proposer executes it and gets repaid gas costs from the swap output. This mirrors the Allo `_fundPool()` bug class: the check is based on the *stated* `amountIn` value rather than the amount the router will *actually* receive after the ERC20 transfer, which for fee-on-transfer or rebasing tokens can be less than the nominal value.

### Finding Description
`checkBalanceForSwap` in `kaiax/gasless/impl/tx_pool.go` performs: [1](#0-0) 
checking `balance.Cmp(swapArgs.AmountIn) < 0` and, earlier, `approval.Cmp(swapArgs.AmountIn) < 0`, both against the raw token amounts extracted from calldata by `decodeSwapTx`: [2](#0-1) 

The module treats `AmountIn` as the exact economic value that will move from the sender into the swap router/pool. This same pattern of "declared value equals actual value transferred" is the exact root cause identified in the report for `Allo._fundPool()`: no reconciliation via before/after balance checks is performed to detect fee-deducting tokens. The downstream `SwapForGas`/`SwappedForGas` flow computes `FinalUserAmount`/`Commission`/`AmountRepaid` from the router's internal accounting of `amountIn`, `minAmountOut`, and `amountRepay`: [3](#0-2) 

Because the actual contract source for `GaslessSwapRouter.sol` is not present in this repository (only the generated Go bindings are indexed), I cannot fully confirm from source whether the router itself measures `balanceOf(this)` deltas after the `transferFrom` before swapping. Based on the available bindings and the `kaiax/gasless` off-chain admission logic, the pre-check against nominal `amountIn` is confirmed, but the router's internal transfer-accounting could not be verified with certainty due to missing Solidity source in the indexed codebase.

### Impact Explanation
If a fee-on-transfer/deflationary token were added to the gasless allow-list, an unprivileged sender could submit a `swapForGas` bundle where the declared `amountIn` passes the pre-check (balance/allowance sufficiency), but the actual tokens received by the swap router are less than `amountIn`. This can cause:
- The AMM swap to produce less output than the router/proposer expects, breaking the `minAmountOut >= amountRepay` invariant enforced only at admission time using nominal values, not actual settlement values.
- A discrepancy between the gas amount the block proposer expects to be repaid (`amountRepay`) and what is actually recoverable from the swap, potentially causing proposer under-repayment (proposer pays gas up front expecting `amountRepay`, per the gasless design) or a state where the bundled approve+swap pair passes admission but fails/underperforms on execution, undermining the gasless fee-delegation guarantee for the block proposer who fronts gas.

This qualifies as fee/fee-delegation abuse: the proposer is an unprivileged actor (gas-fronting counterparty) whose repayment guarantee is undermined by a value-accounting mismatch identical in class to the reported Allo issue.

### Likelihood Explanation
Likelihood depends on whether the gasless module's token allow-list (`ShouldCheckToken`, config-defined) permits arbitrary/fee-on-transfer ERC20 tokens. If token admission is restricted to a small vetted list of standard tokens (e.g., only `testTokenContract`/WKAIA style tokens as seen in tests), the practical likelihood is lower. However, the code path itself performs no defensive before/after balance measurement, so any future addition of a non-standard token to the gasless config would immediately reintroduce this exact bug class with no code changes needed to trigger it — this is a systemic gap rather than a one-off oversight.

### Recommendation
1. In `checkBalanceForSwap` (`kaiax/gasless/impl/tx_pool.go`), treat `balance`/`allowance` checks as necessary but not sufficient; the actual on-chain settlement should not assume transferred amount equals `amountIn`.
2. In the `GaslessSwapRouter` contract (source not available in this index — recommend obtaining/adding it to the repo for review), verify that `swapForGas` measures `IERC20(token).balanceOf(address(this))` before and after `transferFrom`, and uses the delta (not the nominal `amountIn`) as the actual swap input, consistent with the reporter's recommended pattern of before/after balance snapshotting.
3. Restrict the gasless token allow-list to tokens verified not to implement fee-on-transfer/rebasing semantics, and/or explicitly document/enforce this as a system contract admission invariant validated by `kaiax/gasless` config governance.

// tx.amountIn >= gsr.getAmountIn(minAmountOut)

// tx.deadline >= currentTimestamp
func (g *GaslessModule) checkBalanceForSwap(swapArgs *SwapArgs, swapNonce uint64) error {
	token := swapArgs.Token
	bc := backends.NewBlockchainContractBackend(g.Chain, nil, nil)

	g.gaslessInfoMu.RLock()
	swapRouter := g.swapRouter
	g.gaslessInfoMu.RUnlock()

	// tx.minAmountOut >= tx.amountRepay
	minAmountOut := swapArgs.MinAmountOut
	amountRepay := swapArgs.AmountRepay
	if minAmountOut.Cmp(amountRepay) < 0 {
		return fmt.Errorf("insufficient minAmountOut: minAmountOut=%s, amountRepay=%s", minAmountOut.String(), amountRepay.String())
	}

	if g.GaslessConfig.ShouldCheckSenderCode() {
		if g.getCurrentHasCode(swapArgs.Sender) {
			return errors.New("sender with code is not allowed")
		}
	}

	if g.GaslessConfig.ShouldCheckSwapAmount() {
		// tx.amountIn >= gsr.getAmountIn(minAmountOut)
		routerContract, err := kip247.NewGaslessSwapRouterCaller(swapRouter, bc)
		if err != nil {
			return err
		}
		// Required token amountIn, given the current exchange rate and the declared minAmountOut.
		requiredAmountIn, err := routerContract.GetAmountIn(nil, token, minAmountOut)
		if err != nil {
			return err
		}
		if swapArgs.AmountIn.Cmp(requiredAmountIn) < 0 {
			return fmt.Errorf("insufficient amountIn: have=%s, want=%s", swapArgs.AmountIn.String(), requiredAmountIn.String())
		}
	}

	if g.GaslessConfig.ShouldCheckToken() {

		tokenContract, err := sc_erc20.NewERC20(token, bc)
		if err != nil {
			return err
		}

		// If SwapTx.nonce is the sender's next nonce, then there is no room for ApproveTx proceeding SwapTx.
		senderNonce := g.getCurrentStateNonce(swapArgs.Sender)
		noApproveTxPreceeds := swapNonce == senderNonce
		if noApproveTxPreceeds {
			// tx.token.allowance(sender, router) >= tx.amountIn
			approval, err := tokenContract.Allowance(nil, swapArgs.Sender, swapRouter)
			if err != nil {
				return err
			}
			if approval.Cmp(swapArgs.AmountIn) < 0 {
				return fmt.Errorf("insufficient approval: approval=%s, want=%s", approval.String(), swapArgs.AmountIn.String())
			}
		}

		// tx.token.balanceOf(sender) >= tx.amountIn
		balance, err := tokenContract.BalanceOf(nil, swapArgs.Sender)
		if err != nil {
			return err
		}
		if balance.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("insufficient balance: balance=%s, want=%s", balance.String(), swapArgs.AmountIn.String())
		}
	}

	// tx.deadline >= currentTimestamp
	deadline := swapArgs.Deadline
	if deadline.Cmp(g.Chain.CurrentBlock().Time()) < 0 {
		return fmt.Errorf("insufficient deadline: deadline=%s, want=%s", deadline.String(), g.Chain.CurrentBlock().Time().String())
	}

	return nil
}

func decodeSwapTx(tx *types.Transaction, signer types.Signer) (args *SwapArgs, ok bool) {
	to, inputs, ok := decodeFunctionCall(tx, routerSwapFunc)
	if !ok {
		return nil, false
	}
	token, ok := inputs["token"].(common.Address)
	if !ok {
		return nil, false
	}
	amountIn, ok := inputs["amountIn"].(*big.Int)
	if !ok {
		return nil, false
	}
	minAmountOut, ok := inputs["minAmountOut"].(*big.Int)
	if !ok {
		return nil, false
	}
	amountRepay, ok := inputs["amountRepay"].(*big.Int)
	if !ok {
		return nil, false
	}
	deadline, ok := inputs["deadline"].(*big.Int)
	if !ok {
		return nil, false
	}
	from, err := types.Sender(signer, tx)
	if err != nil {
		return nil, false
	}
	return &SwapArgs{
		Sender:       from,
		Router:       to,
		Token:        token,
		AmountIn:     amountIn,
		MinAmountOut: minAmountOut,
		AmountRepay:  amountRepay,
		Deadline:     deadline,
	}, true
}
