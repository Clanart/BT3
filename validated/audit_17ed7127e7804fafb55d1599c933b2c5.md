### Title
Contract governance (KIP-81) can set `kip71.lowerboundbasefee` above `kip71.upperboundbasefee`, bricking the KIP-71 fee market - (File: kaiax/gov/contractgov/impl/getter.go, kaiax/gov/param.go, params/kip71_config.go)

### Summary
The header-governance path validates that a `Kip71LowerBoundBaseFee` vote cannot exceed the current `UpperBoundBaseFee` (and vice versa), but the on-chain contract-governance path (KIP-81 `GovParam` contract, consumed via `contractgov`) applies no such cross-field check. A GC member can therefore set `kip71.lowerboundbasefee > kip71.upperboundbasefee` through `GovParam.setParam`/`setParamIn`, producing an internally inconsistent `KIP71Config` that is fed directly into the base-fee calculation used by every node to validate blocks.

### Finding Description
Header governance enforces bound ordering in `checkConsistency`: [1](#0-0) 

This check only runs from `VerifyVote` on the header-vote path: [2](#0-1) 

However, the `contractgov` module—which reads the same two parameters from the `GovParam` contract (KIP-81 on-chain voting)—performs no equivalent check. It only runs the per-parameter `Canonicalizer`/`FormatChecker`, both of which are no-ops for these two params: [3](#0-2) [4](#0-3) 

`contractgov.GetParamSet`/`GetPartialParamSet` simply pulls all params from the contract and applies `ParamSet.Set` (type assertion only, no cross-field validation) for each, independently of the other: [5](#0-4) [6](#0-5) 

So a single `GovParam.setParamIn("kip71.lowerboundbasefee", ...)` (or the upper-bound equivalent) transaction can independently push `LowerBoundBaseFee` above the existing `UpperBoundBaseFee` with no revert, unlike the header-vote path which would reject it.

The resulting `ParamSet` is converted straight into `KIP71Config` and used for consensus-critical base-fee computation: [7](#0-6) [8](#0-7) 

In `NextMagmaBlockBaseFee`, when `LowerBoundBaseFee > UpperBoundBaseFee`, the clamp order (`>= upperBoundBaseFee` checked before `<= lowerBoundBaseFee`) causes `parentBaseFee` to be forced up to `lowerBoundBaseFee`, which is now above the "upper" bound, and every subsequent branch (`parentGasUsed == gasTarget`, and the low-usage decrease branch's floor-at-lowerBound shortcut) returns a value at or above `LowerBoundBaseFee`, permanently exceeding the intended upper limit: [9](#0-8) 

### Impact Explanation
Because `NextMagmaBlockBaseFee` is a deterministic pure function computed identically by every honest node from the same `ParamSet`, this does not cause consensus divergence, but it does corrupt the KIP-71 dynamic fee mechanism for the entire network: base fee gets pinned at (or above) the misconfigured "lower" bound, which now sits above the intended "upper" bound, and the decrease/floor logic never lets it go below that value again. This effectively locks in an excessively high (or otherwise unintended) base fee network-wide, pricing out transactions whose `maxFeePerGas` is below the stuck value and denying normal fee-market operation for all senders (unprivileged tx senders, gasless users, auction participants) until governance corrects both parameters together. This is a protocol-level fee/pricing integrity bug reachable purely through a governance parameter-setting transaction against the `GovParam` system contract, which is explicitly an in-scope topic (KIP-71 pricing / governance parameters).

### Likelihood Explanation
Requires only one on-chain `GovParam.setParam`/`setParamIn` transaction that changes either `kip71.lowerboundbasefee` or `kip71.upperboundbasefee` without the submitter (or the contract) validating the other's current value—an easy operator/GC mistake with no on-chain guard against it, compared to the header-vote path which does guard it. No malicious node, consensus-message manipulation, or private key compromise is required beyond whatever access is already required to call the GovParam contract (mirroring the exact "one path checked, mirrored path unchecked" root cause from the Hats Protocol report).

### Recommendation
Add cross-field validation analogous to `headerGovModule.checkConsistency` in the `contractgov` (or shared `gov`) parameter application path—e.g., in `ParamSet.Set`/`PartialParamSet.Add`, or in `contractgov.GetParamSet`, reject/ignore updates where the resulting `LowerBoundBaseFee > UpperBoundBaseFee` (using the current effective values from `GetParamSet(blockNum)` as the comparison baseline), so contract governance enforces the same invariant that header governance already enforces.

### Proof of Concept
1. Deploy/observe an already-deployed `GovParam` contract acting as `governance.govparamcontract` post-Kore fork (contract governance enabled, as validated in `contractGetAllParamsAtFromAddr`).
2. As the (governance-authorized) caller of `GovParam`, call `setParamIn("kip71.lowerboundbasefee", true, <bytes for a value greater than the current kip71.upperboundbasefee>, relativeActivation)` — see `deployGovParamTx_setParamIn` pattern used in tests: [10](#0-9) 
3. Once the change activates, `contractgov.GetParamSet` merges `LowerBoundBaseFee` (now > `UpperBoundBaseFee`) into the effective `gov.ParamSet` with no rejection (no equivalent of `checkConsistency` is invoked in this path).
4. `ParamSet.ToKip71Config()` propagates the inconsistent pair into block processing; `NextMagmaBlockBaseFee` subsequently pins/produces a base fee at or above the misconfigured lower bound in the affected branches described above, deviating from the intended `[lowerBound, upperBound]` fee range network-wide.

func (h *headerGovModule) VerifyVote(header *types.Header) error {
	if len(header.Vote) == 0 {
		return nil
	}

	var (
		vb       headergov.VoteBytes = header.Vote
		blockNum                     = header.Number.Uint64()
	)

	vote, err := vb.ToVoteData()
	if err != nil {
		logger.Error("ToVoteData error", "num", blockNum, "vote", vb, "err", err)
		return err
	}

	if gov.DeprecatedAt(vote.Name(), h.ChainConfig.Rules(header.Number)) {
		logger.Error("Vote is deprecated", "num", blockNum, "name", vote.Name())
		return ErrDeprecatedVote
	}

	council, err := h.ValSet.GetCouncil(blockNum)
	if err != nil {
		return err
	}

	// check if the voter is in council
	if !slices.Contains(council, vote.Voter()) {
		return ErrInvalidKeyValue
	}

	// check if Voter is the block proposer.
	author, err := h.Chain.Sealer().Author(header)
	if err != nil {
		return err
	}
	if author != vote.Voter() {
		return ErrInvalidVoter
	}

	// In single mode, only the governing node can write header.Vote after Permissionless.
	params := h.GetParamSet(blockNum)
	if h.ChainConfig.IsPermissionlessForkEnabled(new(big.Int).SetUint64(blockNum)) &&
		params.GovernanceMode == "single" &&
		vote.Voter() != params.GoverningNode {
		return ErrVotePermissionDenied
	}

	return h.checkConsistency(blockNum, vote)

func (c *contractGovModule) GetParamSet(blockNum uint64) gov.ParamSet {
	m, err := c.contractGetAllParamsAt(blockNum)
	if err != nil {
		return *gov.GetDefaultGovernanceParamSet()
	}

	ret := *gov.GetDefaultGovernanceParamSet()
	for k, v := range m {
		err = ret.Set(k, v)
		if err != nil {
			return *gov.GetDefaultGovernanceParamSet()
		}
	}

	return ret
}

func (c *contractGovModule) contractGetAllParamsAt(blockNum uint64) (gov.PartialParamSet, error) {

	if err != nil {
		return nil, err
	}

		return nil, nil
	}

	return c.contractGetAllParamsAtFromAddr(blockNum, addr)

func (c *contractGovModule) contractGetAllParamsAtFromAddr(blockNum uint64, addr common.Address) (gov.PartialParamSet, error) {
	chain := c.Chain
	if chain == nil {
		return nil, ErrNotReady
	}

	config := c.ChainConfig
	if !config.IsKoreForkEnabled(new(big.Int).SetUint64(blockNum)) {
		return nil, ErrNotReady
	}

	caller := backends.NewBlockchainContractBackend(chain, nil, nil)
	contract, err := govcontract.NewGovParamCaller(addr, caller)
	if err != nil {
		return nil, err
	}

	names, values, err := contract.GetAllParamsAt(nil, new(big.Int).SetUint64(blockNum))
	if err != nil {
		logger.Warn("ContractEngine disabled: getAllParams call failed", "err", err)
		return nil, nil
	}

	if len(names) != len(values) {
		logger.Warn("ContractEngine disabled: getAllParams result invalid", "len(names)", len(names), "len(values)", len(values))
		return nil, nil
	}

	ret := ParseContractCall(names, values)

	rules := config.Rules(new(big.Int).SetUint64(blockNum))
	for name := range ret {
		if gov.DeprecatedAt(name, rules) {
			logger.Warn("Ignoring deprecated parameter from contract governance", "name", name, "blockNum", blockNum)
			delete(ret, name)
		}
	}

	return ret, nil
}

func (kc *KIP71Config) NextMagmaBlockBaseFee(parentHeaderNumber *big.Int, parentHeaderBaseFee *big.Int, parentHeaderGasUsed uint64) *big.Int {
	// governance parameters
	lowerBoundBaseFee := new(big.Int).SetUint64(kc.LowerBoundBaseFee)
	upperBoundBaseFee := new(big.Int).SetUint64(kc.UpperBoundBaseFee)
	makeEvenByCeil(lowerBoundBaseFee)
	makeEvenByFloor(upperBoundBaseFee)

	// If the parent is the magma disabled block or genesis, then return the lowerBoundBaseFee (default 25ston)
	if parentHeaderNumber.Cmp(new(big.Int).SetUint64(0)) == 0 || parentHeaderBaseFee == nil {
		return makeEvenByFloor(lowerBoundBaseFee)
	}

	var baseFeeDenominator *big.Int
	if kc.BaseFeeDenominator == 0 {
		// To avoid panic, set the fluctuation range small
		baseFeeDenominator = new(big.Int).SetUint64(64)
	} else {
		baseFeeDenominator = new(big.Int).SetUint64(kc.BaseFeeDenominator)
	}
	gasTarget := kc.GasTarget
	upperGasLimit := kc.MaxBlockGasUsedForBaseFee

	// check the case of upper/lowerBoundBaseFee is updated by governance mechanism
	parentBaseFee := parentHeaderBaseFee
	if parentBaseFee.Cmp(upperBoundBaseFee) >= 0 {
		parentBaseFee = upperBoundBaseFee
	} else if parentBaseFee.Cmp(lowerBoundBaseFee) <= 0 {
		parentBaseFee = lowerBoundBaseFee
	}

	// upper gas limit cut off the impulse of used gas to upper bound
	parentGasUsed := min(parentHeaderGasUsed, upperGasLimit)
	if parentGasUsed == gasTarget {
		return makeEvenByFloor(parentBaseFee)
	} else if parentGasUsed > gasTarget {
		// shortcut. If parentBaseFee is already reached upperbound, do not calculate.
		if parentBaseFee.Cmp(upperBoundBaseFee) == 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		// If the parent block used more gas than its target,
		// the baseFee of the next block should increase.
		// baseFeeDelta = max(1, parentBaseFee * (parentGasUsed - gasTarget) / gasTarget / baseFeeDenominator)
		gasUsedDelta := new(big.Int).SetUint64(parentGasUsed - gasTarget)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := math.BigMax(x.Div(y, baseFeeDenominator), common.Big1)

		nextBaseFee := x.Add(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(upperBoundBaseFee) > 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	} else {
		// shortcut. If parentBaseFee is already reached lower bound, do not calculate.
		if parentBaseFee.Cmp(lowerBoundBaseFee) == 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		// Otherwise if the parent block used less gas than its target,
		// the baseFee of the next block should decrease.
		// baseFeeDelta = parentBaseFee * (gasTarget - parentGasUsed) / gasTarget / baseFeeDenominator
		gasUsedDelta := new(big.Int).SetUint64(gasTarget - parentGasUsed)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := x.Div(y, baseFeeDenominator)

		nextBaseFee := x.Sub(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(lowerBoundBaseFee) < 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	}
}
