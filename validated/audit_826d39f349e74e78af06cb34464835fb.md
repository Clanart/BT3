### Title
Uncharged PDA derivation cost in `translate_signers` allows underpriced SHA256 work during CPI - (`program-runtime/src/cpi.rs`)

### Summary
`translate_signers` calls `Pubkey::create_program_address` directly for every signer-seed set supplied to a CPI, without charging the `create_program_address_units` compute cost that the dedicated `sol_create_program_address`/`sol_try_find_program_address` syscalls charge for the same operation. An attacker can supply up to `MAX_SIGNERS` signer-seed sets, each with up to `MAX_SEEDS` seeds of `MAX_SEED_LEN` bytes (deliberately invalid so no early success/failure shortcuts apply), forcing many uncharged SHA256 hashing operations per CPI call, while only the flat `invoke_units` cost is charged.

### Finding Description
The call chain for a CPI with signers is `cpi_common` → `translate_signers` → `Pubkey::create_program_address`: [1](#0-0) 

`cpi_common` charges only `invoke_units` once per CPI invocation before calling `translate_signers`: [2](#0-1) 

`translate_signers` then iterates over up to `MAX_SIGNERS` signer-seed sets (bounded check at line 646) and, for each, up to `MAX_SEEDS` seeds (bounded check at line 658), and calls `Pubkey::create_program_address` directly with no additional compute charge: [3](#0-2) 

Compare this with the syscall path for the exact same primitive (`sol_create_program_address` / `sol_try_find_program_address`), where the `create_program_address_units` cost is explicitly consumed via `compute_meter.consume_checked(cost)` immediately before invoking `Pubkey::create_program_address`: [4](#0-3) [5](#0-4) 

The default cost model defines `create_program_address_units: 1500` per derivation, plus `sha256_base_cost`/`sha256_byte_cost` for the underlying hashing: [6](#0-5) 

Since `translate_signers` bypasses this per-derivation charge, an attacker invoking CPI with the maximum number of signer-seed sets, each carrying the maximum number of maximum-length seeds — all crafted to be invalid PDAs (so no early termination and full hashing work is performed each time) — causes `MAX_SIGNERS * MAX_SEEDS` SHA256 hash computations over up to `MAX_SEED_LEN` bytes each, all under the identical flat `invoke_units` charge that a CPI with zero signers would incur. The compute cost does not scale with the amount of hashing work actually performed, unlike the syscall equivalent.

### Impact Explanation
This is a case of materially underpriced compute: the actual SHA256 hashing cost incurred by the CPI signer-seed verification path is not reflected in the compute units charged. An attacker can amplify actual CPU/hashing work per charged compute unit by repeating CPI calls with maximally-sized, deliberately-invalid signer-seed arrays across a single transaction (bounded by `max_instruction_trace_length` and the transaction's compute unit limit), causing disproportionate validator processing time relative to the fee/CU paid. This falls under the "materially underpriced compute" bounty category since it does not require any privileged access — only deploying and invoking an arbitrary sBPF program that performs CPI with crafted signer seeds.

### Likelihood Explanation
Fully reachable by an unprivileged attacker: deploy an arbitrary sBPF program, invoke a CPI (`invoke_signed` / `sol_invoke_signed_c`/`_rust`) with `signers_seeds_len` set to `MAX_SIGNERS`, each signer's seed list at `MAX_SEEDS` entries of `MAX_SEED_LEN` bytes, chosen so `Pubkey::create_program_address` fails validation (returning `BadSeeds`) after performing the full hash computation. This can be repeated across multiple CPI calls within one transaction/instruction trace, and across as many transactions as the attacker can afford, since the per-call cost is capped at the flat `invoke_units` value regardless of the seed-length/seed-count combination used.

### Recommendation
Charge `create_program_address_units` (or an equivalent cost scaled by the number of signer-seed sets and their total byte length, mirroring `sha256_base_cost`/`sha256_byte_cost`) inside `translate_signers` for every `Pubkey::create_program_address` invocation, consistent with the explicit charge already performed in `SyscallCreateProgramAddress`/`SyscallTryFindProgramAddress`. This ensures the compute meter reflects the true SHA256 hashing work regardless of whether the PDA derivation succeeds or fails.

```rust
#[test]
fn test_translate_signers_uncharged_hashing_cost() {
    let transaction_accounts =
        transaction_with_one_writable_instruction_account(b"foo".to_vec());
    mock_invoke_context!(
        invoke_context,
        transaction_context,
        b"instruction data",
        transaction_accounts,
        0,
        &[1]
    );

    let program_id = Pubkey::new_unique();

    // Build MAX_SIGNERS signer-seed sets, each MAX_SEEDS seeds of MAX_SEED_LEN bytes,
    // all guaranteed to fail PDA derivation (invalid seeds).
    let seed_bytes = [0xAAu8; MAX_SEED_LEN];
    let seeds_per_signer: Vec<&[u8]> = std::iter::repeat(seed_bytes.as_slice())
        .take(MAX_SEEDS)
        .collect();
    let all_signers: Vec<Vec<&[u8]>> = std::iter::repeat(seeds_per_signer.clone())
        .take(MAX_SIGNERS)
        .collect();

    let vm_addr = MM_INPUT_START;
    let (_mem, region) = mock_signers_multi(&all_signers, vm_addr); // helper building nested VmSlice layout

    let config = Config { aligned_memory_mapping: false, ..Config::default() };
    let mapping = unsafe { MemoryMapping::new(vec![region], &config, SBPFVersion::V3).unwrap() };
    invoke_context
        .memory_contexts
        .set_memory_context_abi_v1(MemoryContext::new(BpfAllocator::new(0), Vec::new(), mapping))
        .unwrap();

    // Record compute units before and after.
    let remaining_before = invoke_context.compute_meter.get_remaining();
    let result = translate_signers(
        &program_id,
        vm_addr,
        all_signers.len() as u64,
        &invoke_context,
    );
    // All derivations should fail (BadSeeds) since seeds are invalid, but the
    // function still performed MAX_SIGNERS * MAX_SEEDS SHA256 hashes internally.
    assert!(result.is_err());
    let remaining_after = invoke_context.compute_meter.get_remaining();

    // Assert: no create_program_address_units-equivalent cost was charged for
    // the hashing work performed (only whatever cpi_common's invoke_units
    // charged beforehand, which translate_signers itself does not add to).
    assert_eq!(
        remaining_before, remaining_after,
        "translate_signers consumed 0 additional compute units despite performing \
         MAX_SIGNERS * MAX_SEEDS SHA256 hashes over MAX_SEED_LEN-byte seeds"
    );
}
```

```rust
pub fn translate_signers(
    program_id: &Pubkey,
    signers_seeds_addr: u64,
    signers_seeds_len: u64,
    invoke_context: &InvokeContext,
) -> Result<Vec<Pubkey>, Error> {
    let check_aligned = invoke_context.get_check_aligned();
    let memory_mapping = invoke_context.memory_contexts.memory_mapping()?;
    if signers_seeds_len > 0 {
        let signers_seeds = translate_slice::<VmSlice<VmSlice<u8>>>(
            memory_mapping,
            signers_seeds_addr,
            signers_seeds_len,
            check_aligned,
        )?;
        if signers_seeds.len() > MAX_SIGNERS {
            return Err(Box::new(CpiError::TooManySigners));
        }
        Ok(signers_seeds
            .iter()
            .map(|signer_seeds| {
                let untranslated_seeds = translate_slice::<VmSlice<u8>>(
                    memory_mapping,
                    signer_seeds.ptr(),
                    signer_seeds.len(),
                    check_aligned,
                )?;
                if untranslated_seeds.len() > MAX_SEEDS {
                    return Err(Box::new(InstructionError::MaxSeedLengthExceeded) as Error);
                }
                let seeds_bytes = untranslated_seeds
                    .iter()
                    .map(|untranslated_seed| {
                        translate_vm_slice(untranslated_seed, memory_mapping, check_aligned)
                    })
                    .collect::<Result<Vec<_>, Error>>()?;
                Pubkey::create_program_address(&seeds_bytes, program_id)
                    .map_err(|err| Box::new(CpiError::BadSeeds(err)) as Error)
            })
            .collect::<Result<Vec<_>, Error>>()?)
    } else {
        Ok(vec![])
    }
}
```

```rust
    /// Create a program address
    SyscallTryFindProgramAddress,
    fn rust(
        invoke_context: &mut InvokeContext<'_, '_>,
        seeds_addr: u64,
        seeds_len: u64,
        program_id_addr: u64,

        bump_seed_addr: u64,

        let cost = invoke_context
            .get_execution_cost()
            .create_program_address_units;
        invoke_context.compute_meter.consume_checked(cost)?;

        let check_aligned = invoke_context.get_check_aligned();
        let memory_mapping = invoke_context.memory_contexts.memory_mapping_mut()?;
        let (seeds, program_id) = translate_and_check_program_address_inputs(
            seeds_addr,
            seeds_len,
            program_id_addr,
            memory_mapping,
            check_aligned,
        )?;

        let mut bump_seed = [u8::MAX];
        for _ in 0..u8::MAX {
            {
                let mut seeds_with_bump = seeds.to_vec();
                seeds_with_bump.push(&bump_seed);

                if let Ok(new_address) =
                    Pubkey::create_program_address(&seeds_with_bump, program_id)
                {
                    translate_mut!(
                        memory_mapping,
                        check_aligned,
                        let bump_seed_ref: (&mut MaybeUninit<u8>) = map(bump_seed_addr)?;
                        let address: (&mut [MaybeUninit<u8>]) = map(address_addr, std::mem::size_of::<Pubkey>() as u64)?;
                    );
                    bump_seed_ref.write(bump_seed[0]);
                    address.write_copy_of_slice(new_address.as_ref());
                    return Ok(0);
                }
            }
            bump_seed[0] = bump_seed[0].saturating_sub(1);
            invoke_context.compute_meter.consume_checked(cost)?;
        }
```
