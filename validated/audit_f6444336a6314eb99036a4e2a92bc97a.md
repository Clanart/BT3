## Finding

### Title
Operator reimbursed for a payout it never funded — payout tx's operator-attribution OP_RETURN is unsigned and forgeable - (File: `core/src/builder/transaction/operator_reimburse.rs`)

### Summary
The payout transaction that "fronts" a Citrea withdrawal only cryptographically binds the user to the withdrawal output (script/amount) via a `SinglePlusAnyoneCanPay` signature. The OP_RETURN output that records *which operator fronted the payout* — the field later used to trigger automatic reimbursement — sits outside that signature's coverage and can be freely set by whoever assembles and broadcasts the final transaction. This breaks the invariant "operator credited for reimbursement == operator that actually paid the withdrawal."

### Finding Description
`create_payout_txhandler` builds a 3-output transaction: output 0 = user's payout, output 1 = anchor, output 2 = OP_RETURN with `operator_xonly_pk.serialize()`: [1](#0-0) 

The user's signature is explicitly documented as `SinglePlusAnyoneCanPay`, and it is only guaranteed to cover the withdrawal output's script/amount, i.e. output index 0 — not the OP_RETURN at index 2: [2](#0-1) 

`operator.rs::withdraw` verifies the signature only against `sighash_txin(0, ...)` and then completes the transaction by adding whatever extra funding inputs are needed via `fund_raw_transaction`: [3](#0-2) [4](#0-3) 

Because SIGHASH_SINGLE|ANYONECANPAY only commits input 0 + output 0, an attacker who has learned the user's `input_signature`, `input_outpoint`, `output_script_pubkey`, and `output_amount` — which are exactly the fields submitted publicly to Citrea's withdrawal contract, as shown in test helpers building the `safeWithdraw`/`withdraw` calls — can independently reconstruct a valid payout transaction: input 0 and output 0 identical to the legitimate one (satisfying the user's signature), add their own funding input(s) to cover the payout amount, and write **any** operator's `xonly_pk` into the OP_RETURN output, then broadcast it directly to Bitcoin without ever calling any Clementine RPC.

Once mined, `update_finalized_payouts` reads the OP_RETURN and attributes the payout to whichever `operator_xonly_pk` was embedded, with no check that this operator is the one who actually funded the transaction: [5](#0-4) 

This attribution is stored via `update_payout_txs_and_payer_operator_xonly_pk` and later read by `get_first_unhandled_payout_by_operator_xonly_pk`, filtered strictly on `operator_xonly_pk`: [6](#0-5) 

`PayoutCheckerTask` automatically picks up any payout attributed to the local operator's own key and drives it through `handle_finalized_payout`/kickoff/round flow to completion: [7](#0-6) 

The only sanity check performed later, `is_kickoff_malicious`, verifies that the kickoff's `operator_xonly_pk` matches the OP_RETURN's `operator_xonly_pk` and that a committed blockhash matches — it does **not** verify that the named operator actually supplied the BTC that funded the payout output: [8](#0-7) 

The named operator then collects `reimburse_tx`, funded from their own round/collateral UTXO, for a payout they never funded: [9](#0-8) 

### Impact Explanation
This directly matches the Critical bucket "an operator reimbursed for a payout it never funded." An attacker (any party who can observe a pending withdrawal's public Citrea submission and has enough BTC to fund the difference) can force the protocol to credit reimbursement to an arbitrary operator xonly_pk that never spent its own funds to pay the withdrawing user. This can be used to: (a) grant a colluding operator "free" reimbursements funded entirely by third-party BTC, breaking the economic model of the bridge, or (b) grief an honest, uninvolved operator by forcing its automation to consume a kickoff connector / round slot for a payout it didn't make (denial-of-availability side-effect, though the core issue is the misattributed credit).

### Likelihood Explanation
Reachable by any unprivileged party. The withdrawal's `input_signature`, `input_outpoint`, `output_script_pubkey`, `output_amount` are the exact fields submitted to Citrea's public withdrawal/`safeWithdraw` contract calls, so they are observable on a public chain once a user initiates a withdrawal. No verifier, operator, watchtower, aggregator, or security-council role, and no key compromise, is required — only ordinary BTC to cover the payout amount plus fees and knowledge of Bitcoin transaction construction.

### Recommendation
Bind the operator-attribution output to the same signature domain as the withdrawal output, e.g., by requiring the OP_RETURN (or an equivalent operator commitment) to be covered by a signature (from the operator itself, or with `SIGHASH_ALL`) rather than left outside the `SinglePlusAnyoneCanPay` coverage. Alternatively, require the funding/change output of the payout transaction to come from a UTXO provably controlled by the operator named in the OP_RETURN, and reject attribution during `update_finalized_payouts`/`is_kickoff_malicious` unless that provenance can be verified.

### Proof of Concept
1. User submits withdrawal to Citrea's bridge contract with `(withdrawal_id, input_signature, input_outpoint, output_script_pubkey, output_amount)` — these become public on Citrea.
2. Attacker copies these exact values and constructs `create_payout_txhandler`-equivalent transaction, but substitutes `operator_xonly_pk` = victim/colluding operator's public key (any registered operator's key, which is public), and adds their own wallet UTXO(s) as extra funding inputs (permitted by `ANYONECANPAY`) to cover `output_amount` + fees.
3. Attacker signs their own added inputs and broadcasts directly to Bitcoin, bypassing any Clementine RPC entirely.
4. Once confirmed, `update_finalized_payouts` (`core/src/verifier.rs:2312-2342`) records `payout_payer_operator_xonly_pk` = the attacker-chosen operator.
5. That operator's `PayoutCheckerTask` (`core/src/task/payout_checker.rs`) automatically drives kickoff/round/reimburse flow and collects `reimburse_tx` (`core/src/builder/transaction/operator_reimburse.rs:341-384`) for BTC it never spent.

pub fn create_reimburse_txhandler(
    move_txhandler: &TxHandler,
    round_txhandler: &TxHandler,
    kickoff_txhandler: &TxHandler,
    kickoff_idx: usize,
    paramset: &'static ProtocolParamset,
    operator_reimbursement_address: &bitcoin::Address,
) -> Result<TxHandler, BridgeError> {
    let builder = TxHandlerBuilder::new(TransactionType::Reimburse)
        .with_version(NON_STANDARD_V3)
        .add_input(
            NormalSignatureKind::Reimburse1,
            move_txhandler.get_spendable_output(UtxoVout::DepositInMove)?,
            builder::script::SpendPath::ScriptSpend(0),
            DEFAULT_SEQUENCE,
        )
        .add_input(
            NormalSignatureKind::Reimburse2,
            kickoff_txhandler.get_spendable_output(UtxoVout::ReimburseInKickoff)?,
            builder::script::SpendPath::ScriptSpend(0),
            DEFAULT_SEQUENCE,
        )
        .add_input(
            NormalSignatureKind::OperatorSighashDefault,
            round_txhandler.get_spendable_output(UtxoVout::ReimburseInRound(
                kickoff_idx,
                paramset.num_kickoffs_per_round,
            ))?,
            builder::script::SpendPath::KeySpend,
            DEFAULT_SEQUENCE,
        );

    Ok(builder
        .add_output(UnspentTxOut::from_partial(TxOut {
            value: move_txhandler
                .get_spendable_output(UtxoVout::DepositInMove)?
                .get_prevout()
                .value,
            script_pubkey: operator_reimbursement_address.script_pubkey(),
        }))
        .add_output(UnspentTxOut::from_partial(
            builder::transaction::anchor_output(paramset.anchor_amount()),
        ))
        .finalize())

pub fn create_payout_txhandler(
    input_utxo: UTXO,
    output_txout: TxOut,
    operator_xonly_pk: XOnlyPublicKey,
    user_sig: taproot::Signature,
    _network: bitcoin::Network,
) -> Result<TxHandler<Signed>, BridgeError> {
    let txin = SpendableTxIn::new_partial(input_utxo.outpoint, input_utxo.txout);

    let output_txout = UnspentTxOut::from_partial(output_txout.clone());

    let op_return_txout = op_return_txout(PushBytesBuf::from(operator_xonly_pk.serialize()));

    let mut txhandler = TxHandlerBuilder::new(TransactionType::Payout)
        .with_version(NON_STANDARD_V3)
        .add_input(
            NormalSignatureKind::NotStored,
            txin,
            SpendPath::KeySpend,
            DEFAULT_SEQUENCE,
        )
        .add_output(output_txout)
        .add_output(UnspentTxOut::from_partial(anchor_output(
            NON_EPHEMERAL_ANCHOR_AMOUNT,
        )))
        .add_output(UnspentTxOut::from_partial(op_return_txout))
        .finalize();
    txhandler.set_p2tr_key_spend_witness(&user_sig, 0)?;
    txhandler.promote()
}

    pub async fn get_first_unhandled_payout_by_operator_xonly_pk(
        &self,
        tx: Option<DatabaseTransaction<'_>>,
        operator_xonly_pk: XOnlyPublicKey,
    ) -> Result<Option<(u32, Txid, BlockHash)>, BridgeError> {
        let query = sqlx::query_as::<_, (i32, Option<TxidDB>, Option<BlockHashDB>)>(
            "SELECT w.idx, w.move_to_vault_txid, w.payout_tx_blockhash
             FROM withdrawals w
             WHERE w.payout_txid IS NOT NULL
                AND w.is_payout_handled = FALSE
                AND w.payout_payer_operator_xonly_pk = $1
                ORDER BY w.idx ASC
             LIMIT 1",
        )
        .bind(XOnlyPublicKeyDB(operator_xonly_pk));

        let results = execute_query_with_tx!(self.connection, tx, query, fetch_optional)?;

        results
            .map(|(citrea_idx, move_to_vault_txid, payout_tx_blockhash)| {
                Ok((
                    u32::try_from(citrea_idx).wrap_err("Failed to convert citrea index to u32")?,
                    move_to_vault_txid
                        .expect("move_to_vault_txid Must be Some")
                        .0,
                    payout_tx_blockhash
                        .expect("payout_tx_blockhash Must be Some")
                        .0,
                ))
            })
            .transpose()
    }

    async fn run_once(&mut self) -> Result<Self::Output, BridgeError> {
        let mut dbtx = self.db.begin_transaction().await?;
        let unhandled_payout = self
            .db
            .get_first_unhandled_payout_by_operator_xonly_pk(
                Some(&mut dbtx),
                self.operator.signer.xonly_public_key,
            )
            .await?;

        if unhandled_payout.is_none() {
            return Ok(false);
        }

        let (citrea_idx, move_to_vault_txid, payout_tx_blockhash) =
            unhandled_payout.expect("Must be Some");

        tracing::info!(
            "Unhandled payout found for withdrawal {}, move_txid: {}",
            citrea_idx,
            move_to_vault_txid
        );

        let deposit_data = self
            .db
            .get_deposit_data_with_move_tx(Some(&mut dbtx), move_to_vault_txid)
            .await?;
        if deposit_data.is_none() {
            return Err(eyre::eyre!("Fronted withdrawal for move tx {move_to_vault_txid} found, but the signatures for the deposit are not found in the db.").into());
        }

        let deposit_data = deposit_data.expect("Must be Some");

        let kickoff_txid = self
            .operator
            .handle_finalized_payout(
                &mut dbtx,
                deposit_data.get_deposit_outpoint(),
                payout_tx_blockhash,
            )
            .await?;

        // fetch and save the LCP for if we get challenged and need to provide proof of payout later
        let (_, payout_block_height) = self
            .operator
            .db
            .get_block_info_from_hash(Some(&mut dbtx), payout_tx_blockhash)
            .await?
            .ok_or_eyre("Couldn't find payout blockhash in bitcoin sync")?;

        let _ = self
            .operator
            .citrea_client
            .fetch_validate_and_store_lcp(
                payout_block_height as u64,
                citrea_idx,
                &self.operator.db,
                Some(&mut dbtx),
                self.operator.config.protocol_paramset(),
            )
            .await?;

        #[cfg(feature = "automation")]
        self.operator.end_round(&mut dbtx).await?;

        self.db
            .mark_payout_handled(Some(&mut dbtx), citrea_idx, kickoff_txid)
            .await?;
