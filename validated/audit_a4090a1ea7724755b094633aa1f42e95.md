### Title
ReDoS via unbounded regex in CometBFT/Tendermint event-subscription `MATCHES`/`CONTAINS` query operator - ([File: sei-tendermint/internal/pubsub/query/query.go])

### Summary
The Tendermint/CometBFT pubsub query compiler used by sei-chain's consensus-layer RPC event subscription system compiles the `MATCHES` operator directly into a call to Go's backtracking `regexp.MatchString` using an attacker-supplied pattern string, with no complexity bound, sandboxing, or timeout, mirroring the Parse Server `$regex` LiveQuery ReDoS bug class described in the external report.

### Finding Description
`compileCondition` in `sei-tendermint/internal/pubsub/query/query.go` builds a match closure for the `TMatches` operator: [1](#0-0) 

The pattern (`v.(string)`) comes verbatim from the client-supplied subscription query string parsed by `syntax.Parse`, and `s` is an event-attribute value taken from ABCI events emitted during transaction/block processing (e.g. `tx.hash`, message attributes, memo-derived fields, etc.), so both the regex and the subject string are influenced by network-visible data.

This compiled `condition.match` function is invoked once per subscriber per published event inside the single, serialized event-dispatch goroutine of the pubsub server: [2](#0-1) [3](#0-2) 

`Server.send` iterates every registered subscription (`s.subs.index.all`) and calls `si.query.Matches(events)` synchronously while holding `s.subs.RLock()` — a single serialized loop shared by all clients on the node. `EventBus.PublishEventTx`, `PublishEventNewBlock`, etc. feed this same queue for every transaction/block processed by the node: [4](#0-3) 

A single unprivileged RPC client can open a websocket subscription (`/subscribe`) with a crafted query containing a catastrophically-backtracking `MATCHES` pattern (e.g. `(a+)+$` style) targeting a commonly-populated event attribute tag. As soon as any transaction produces an event whose attribute value triggers exponential backtracking against that pattern, the single sender goroutine that serially dispatches events to *all* subscribers on the node stalls, exactly analogous to how Parse Server's LiveQuery blocked its single Node.js event loop.

### Impact Explanation
Because event dispatch is fully serialized in one goroutine (`s.send`) guarded by an RLock shared across the whole subscription index, a stalled regex evaluation blocks delivery of every other subscriber's events on that node (all RPC/websocket subscriptions, including those used by wallets, explorers, and relayers). If the dispatch queue backs up while the goroutine is stuck, subsequent `Publish*` calls made from block-execution code paths can eventually block on the bounded queue channel, extending the denial of service into transaction/block-event publication paths on the affected node. This is a reachable DoS against a public RPC node's event-subscription surface using only a public, unauthenticated RPC/websocket connection and standard user-triggerable event content — no validator, peer, or governance privilege required.

### Likelihood Explanation
Likelihood is high for any node exposing the default CometBFT/Tendermint RPC/websocket `/subscribe` endpoint (the default sei-chain RPC configuration), which is a normal, publicly reachable interface, not p2p or validator-only. An attacker only needs network access to the RPC endpoint and a single crafted subscription query plus a way to trigger matching events (e.g., their own transactions), both trivially available to any unprivileged sender.

### Recommendation
Apply the same mitigation pattern as the upstream Parse Server fix: evaluate subscriber-supplied regex patterns with a bounded timeout (or in an isolated execution context), reject/limit regex complexity at query-compile time in `compileCondition`/`syntax.Parse`, and/or make event dispatch to slow-matching subscribers non-blocking with per-subscription timeouts so one pathological `MATCHES` query cannot stall delivery to the rest of the node's subscribers.

### Proof of Concept
1. Connect to the node's public RPC websocket endpoint (`/websocket`, default port).
2. Send a `subscribe` JSON-RPC request with a query such as: `tm.event='Tx' AND some.attr MATCHES '^(a+)+$'` (or another catastrophic-backtracking pattern) targeting an attribute tag that will receive attacker-controllable long strings (e.g., a memo or message field echoed into events).
3. Submit ordinary transactions whose event attribute values are long strings crafted to trigger exponential backtracking against the pattern (e.g., many repeated `a` characters followed by a non-matching character).
4. Observe that the node's `Server.send` goroutine (single event-dispatch loop) stalls on `regexp.MatchString`, delaying or halting delivery of events to all other RPC subscribers on the node.

Note: I was unable to directly inspect the exact buffered-channel capacity of `pubsub.Server`'s internal `queue` or definitively trace whether/when a fully-stalled sender goroutine would propagate backpressure into consensus-critical `Publish*` calls invoked from block execution; this would need to be confirmed with a live reproduction to establish whether impact extends beyond RPC-subscriber-only denial of service to actual block-processing delay.

func (s *Server) run(ctx context.Context) {
	// The server runs until ctx is canceled.
	s.done = ctx.Done()
	queue := s.queue

	// Shutdown monitor: When the context ends, wait for any active publish
	// calls to exit, then close the queue to signal the sender to exit.
	go func() {
		<-ctx.Done()
		s.pubs.Lock()
		defer s.pubs.Unlock()
		close(s.queue)
		s.queue = nil
	}()

	s.exited = make(chan struct{})
	go func() {
		defer close(s.exited)

		// Sender: Service the queue and forward messages to subscribers.
		for it := range queue {
			if err := s.send(it.Data, it.Events); err != nil {
				logger.Error("error sending event", "err", err)
			}
		}
		// Terminate all subscribers before exit.
		s.subs.Lock()
		defer s.subs.Unlock()
		for si := range s.subs.index.all {
			si.sub.stop(ErrTerminated)
		}
		s.subs.index = nil
	}()
}

// send delivers the given message to all matching subscribers.  An error in
// query matching stops transmission and is returned.
func (s *Server) send(data types.EventData, events []abci.Event) error {
	// At exit, evict any subscriptions that were too slow.
	evict := make(subInfoSet)
	defer func() {
		if len(evict) != 0 {
			s.subs.Lock()
			defer s.subs.Unlock()
			s.removeSubs(evict, ErrTerminated)
		}
	}()

	// N.B. Order is important here. We must acquire and defer the lock release
	// AFTER deferring the eviction cleanup: The cleanup must happen after the
	// reader lock has released, or it will deadlock.
	s.subs.RLock()
	defer s.subs.RUnlock()

	// If an observer is defined, give it control of the message before
	// attempting to deliver it to any matching subscribers. If the observer
	// fails, the message will not be forwarded.
	if s.subs.observe != nil {
		err := s.subs.observe(Message{
			data:   data,
			events: events,
		})
		if err != nil {
			return fmt.Errorf("observer failed on message: %w", err)
		}
	}

	for si := range s.subs.index.all {
		if !si.query.Matches(events) {
			continue
		}

		// Publish the events to the subscriber's queue. If this fails, e.g.,
		// because the queue is over capacity or out of quota, evict the
		// subscription from the index.
		if err := si.sub.publish(Message{
			subID:  si.sub.id,
			data:   data,
			events: events,
		}); err != nil {
			evict.add(si)
		}
	}

	return nil
}

// PublishEventTx publishes tx event with events from Result. Note it will add
// predefined keys (EventTypeKey, TxHashKey). Existing events with the same keys
// will be overwritten.
func (b *EventBus) PublishEventTx(data types.EventDataTx) error {
	events := data.Result.Events

	// add Tendermint-reserved events
	events = append(events, types.EventTx)

	tokens := strings.Split(types.TxHashKey, ".")
	events = append(events, abci.Event{
		Type: tokens[0],
		Attributes: []abci.EventAttribute{
			{
				Key:   []byte(tokens[1]),
				Value: []byte(fmt.Sprintf("%X", types.Tx(data.Tx).Hash())),
			},
		},
	})

	tokens = strings.Split(types.TxHeightKey, ".")
	events = append(events, abci.Event{
		Type: tokens[0],
		Attributes: []abci.EventAttribute{
			{
				Key:   []byte(tokens[1]),
				Value: []byte(fmt.Sprintf("%d", data.Height)),
			},
		},
	})

	return b.pubsub.PublishWithEvents(data, events)
}
