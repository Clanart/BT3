This confirms `send_citrea_tx` (which populates the `tx_sender_citrea_raw_tx_queue` table read by `get_citrea_txs_with_null_commit_outpoint`) is called only with `CitreaTxRequest::BatchProof`, `BatchProofMethodId`, or `SequencerCommitment` payloads. There is no code path in `crates/clementine-tx-sender/src/db/citrea.rs` or its callers where an attacker's Bitcoin transaction body, deposit, or withdrawal request bytes are written into this queue.
