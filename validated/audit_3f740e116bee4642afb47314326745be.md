Audit Report

## Title
Unstaked/unverified QUIC connection attempts can exhaust the global TPU connection-rate token bucket before stake is known, starving staked validators of new connections - (File: `streamer/src/nonblocking/quic.rs`)

## Summary
`run_server()` and `setup_connection()` in the TPU QUIC server gate every incoming connection with a single, node-wide `overall_connection_rate_limiter` token bucket (`TOTAL_CONNECTIONS_PER_SECOND`, burst `MAX_CONNECTION_BURST`) shared by staked and unstaked peers alike. This bucket is checked/consumed immediately after a handshake, before `qos.build_connection_context()` resolves the peer's stake via `get_connection_stake()`, so an unprivileged, stakeless peer can deplete the shared budget and cause staked validators' legitimate connections to be dropped via `incoming.ignore()`/connection close before stake is ever evaluated.

## Finding Description
In `run_server()`, incoming connections are checked against the global bucket (`overall_connection_rate_limiter.current_tokens() == 0`) and a per-IP bucket (`rate_limiter.is_allowed`) prior to the handshake completing. [1](#0-0) 

After the handshake, `setup_connection()` re-registers the per-IP limiter and consumes the global bucket (`overall_connection_rate_limiter.consume_tokens(1)`), still before stake resolution. [2](#0-1) 

Only afterward is `qos.build_connection_context(&new_connection)` invoked, which calls `get_connection_stake()` to look up the peer's stake and classify it as `Staked`/`Unstaked`. [3](#0-2) [4](#0-3) 

The `overall_connection_rate_limiter` is instantiated once per server as a single shared `TokenBucket`, with no per-stake partitioning. [5](#0-4) 

The underlying `TokenBucket::consume_tokens` is a simple atomic counter decrement/refill with no notion of caller identity or stake — any successful QUIC handshake decrements the same global counter. [6](#0-5) 

The per-IP `ConnectionRateLimiter` guard is a separate, independent gate keyed by source IP and does not protect the shared global bucket at all — an attacker distributing handshake attempts across many source IPs stays under per-IP limits while still exhausting the single global bucket, since the two limiters are checked/consumed independently and non-atomically (per-IP first-pass, then global, then per-IP again, then global again) with no coordination between them.

## Impact Explanation
When the shared bucket is exhausted, `run_server()` calls `incoming.ignore()` and `setup_connection()` closes the connection with `CONNECTION_CLOSE_CODE_DISALLOWED`, with no distinction between staked and unstaked callers at that gate — this is a genuine non-RPC remote-exhaustion condition in the QUIC/TPU path, matching the "non-RPC remote exhaustion/crash" category. The corrupted/exhausted value is the shared `TokenBucket`'s `tokens` counter (the `overall_connection_rate_limiter`), consumed by unprivileged, stakeless handshake completions before `get_connection_stake()` ever runs, which can starve staked validators of new TPU QUIC connections needed for transaction/vote submission. [7](#0-6) 

## Likelihood Explanation
The attack requires no stake, no validator identity, and no privileged access — only the ability to complete QUIC handshakes against the public TPU endpoint from enough distinct source IPs to stay under per-IP limits while collectively exceeding `TOTAL_CONNECTIONS_PER_SECOND` plus `MAX_CONNECTION_BURST`. This is achievable by any unprivileged network participant with modest distributed infrastructure and sustained throughput; it is not a single low-rate request but is fully reachable via public inputs with no malicious-node/validator assumption, satisfying the "unprivileged, public inputs" requirement.

## Recommendation
Split the global connection-rate budget into separate staked and unstaked token buckets (or reserve a portion of the budget exclusively for staked/known-identity peers), analogous to the existing `max_staked_connections`/`max_unstaked_connections` partitioning in `SwQosConfig`. Alternatively, move stake resolution earlier (e.g., via the TLS peer certificate during the handshake) so that global rate-limiter consumption can be attributed and budgeted per stake class rather than a single shared counter consumed indiscriminately in `setup_connection()`.

## Proof of Concept
1. Deploy multiple attacker-controlled hosts across distinct source IPs, each staying below `quic_server_params.max_connections_per_ipaddr_per_min` (and its 10x burst) as enforced by `ConnectionRateLimiter` in `run_server()`. [8](#0-7) 
2. Collectively drive QUIC handshake attempts against the validator's TPU port at a sustained rate above `TOTAL_CONNECTIONS_PER_SECOND` plus `MAX_CONNECTION_BURST`, all as unstaked/no-identity clients.
3. Observe `overall_connection_rate_limiter.consume_tokens(1)` in `setup_connection()` failing for legitimate staked-validator connection attempts, incrementing `stats.connection_rate_limited_across_all`, while the attacker's own connections never hit their per-IP caps. [7](#0-6) 
4. Confirm staked validators attempting fresh TPU connections during this window are dropped by the same shared-bucket check in `run_server()` (`overall_connection_rate_limiter.current_tokens() == 0`) before their stake is ever evaluated by `get_connection_stake()`. [9](#0-8)

impl QosController<SwQosConnectionContext> for SwQos {
    fn build_connection_context(&self, connection: &Connection) -> SwQosConnectionContext {
        let remote_address = connection.remote_address();
        get_connection_stake(connection, &self.staked_nodes).map_or(
            SwQosConnectionContext {
                peer_type: ConnectionPeerType::Unstaked,
                total_stake: 0,
                remote_pubkey: None,
                in_staked_table: false,
                remote_address,
                stream_counter: None,
                last_update: Arc::new(AtomicU64::new(timing::timestamp())),
            },
            |(pubkey, stake, total_stake)| {
                // The heuristic is that the stake should be large enough to have 1 stream pass through within one throttle
                // interval during which we allow max (MAX_STREAMS_PER_MS * STREAM_THROTTLING_INTERVAL_MS) streams.

                let peer_type = {
                    let max_streams_per_ms = self.staked_stream_load_ema.max_streams_per_ms();
                    let min_stake_ratio =
                        1_f64 / (max_streams_per_ms * STREAM_THROTTLING_INTERVAL_MS) as f64;
                    let stake_ratio = stake as f64 / total_stake as f64;
                    if stake_ratio < min_stake_ratio {
                        // If it is a staked connection with ultra low stake ratio, treat it as unstaked.
                        ConnectionPeerType::Unstaked
                    } else {
                        ConnectionPeerType::Staked(stake)
                    }
                };

                SwQosConnectionContext {
                    peer_type,
                    total_stake,
                    remote_pubkey: Some(pubkey),
                    in_staked_table: false,
                    remote_address,
                    last_update: Arc::new(AtomicU64::new(timing::timestamp())),
                    stream_counter: None,
                }
            },
        )
    }

    pub fn consume_tokens(&self, request_size: u64) -> Result<u64, u64> {
        let now = self.time_us();
        self.update_state(now);
        match self.tokens.fetch_update(
            Ordering::AcqRel,  // winner publishes new amount
            Ordering::Acquire, // everyone observed correct number
            |tokens| {
                if tokens >= request_size {
                    Some(tokens.saturating_sub(request_size))
                } else {
                    None
                }
            },
        ) {
            Ok(prev) => Ok(prev.saturating_sub(request_size)),
            Err(prev) => Err(request_size.saturating_sub(prev)),
        }
    }
