## Analog Identified: Retroactive Reward Re-pricing in `pallet-consensus-incentives`

### Title
Changing `cost_per_block` retroactively re-prices the entire unpaid block backlog, letting a relayer drain excess treasury funds - (File: `modules/pallets/consensus-incentives/src/impls.rs`)

### Summary
`pallet-consensus-incentives` pays relayers for advancing a state machine's consensus, computing `reward = (latest_height - baseline) * cost_per_block` where `baseline` is the last-rewarded height watermark [1](#0-0) . `cost_per_block` is a single governance-mutable value read fresh at reward-calculation time, with no accrual/settlement step before it changes [2](#0-1) . This is structurally identical to the Quill bug: a per-unit rate is changed without first accruing pending value at the old rate, so a stale span gets priced at the new rate.

### Finding Description
`update_cost_per_block` overwrites `StateMachinesCostPerBlock` for a state machine unconditionally: [2](#0-1) 

It never checks or settles the outstanding unpaid block span (`latest_commitment_height - LastRewardedHeight`) at the *old* rate before applying the new one.

`process_message`/`calculate_reward` computes the reward for the entire unpaid span using whatever `cost_per_block` is stored *at the moment the message executes*, not the rate(s) that were actually in effect while each of those blocks were produced: [3](#0-2) 

`LastRewardedHeight` only advances when a consensus message is actually processed through `FeeHandler::on_executed`, which is triggered automatically whenever any relayer submits a valid signed consensus proof — a fully permissionless action [4](#0-3) . There is no per-height rate ledger; the whole backlog is billed at one snapshot of `cost_per_block`.

### Impact Explanation
A relayer can withhold submitting consensus updates for a state machine (or simply exploit a naturally-existing backlog) while governance raises `cost_per_block` for that state machine, then submit the pending consensus proof immediately after the rate increases. The full accumulated block span — produced while the *old*, lower rate was in force — is paid out of `T::TreasuryAccount` at the *new*, higher rate, draining more treasury funds than governance ever intended for those already-elapsed blocks [5](#0-4) . This is a direct loss-of-funds / fund-manipulation vector on treasury-held relayer incentive funds, exploitable by any unprivileged relayer with no need for governance or operator compromise — only correct timing relative to a public parameter-change extrinsic.

### Likelihood Explanation
Likely whenever a `cost_per_block` increase is scheduled/announced (common operational tuning) and a state machine has any unpaid backlog — which can be encouraged simply by a relayer choosing not to relay consensus updates for that chain until after the rate bump. No special access is required; the relayer only needs to control (or wait for) the timing of a permissionless `process_message` execution relative to a public governance call.

### Recommendation
Before applying a new `cost_per_block`, settle/accrue the pending reward for the outstanding span at the *current* rate (e.g., force-reward or checkpoint `LastRewardedHeight` to the state machine's `latest_commitment_height` using the old rate) inside `update_cost_per_block`, mirroring the "accrue before changing" fix applied upstream in Quill's `mintAggInterest`-before-`stabilityPoolYieldSplit` pattern. Alternatively, store a rate-effective-height table and compute the reward as a sum over per-rate sub-spans rather than a single multiplication over the full backlog.

### Proof of Concept
1. Governance sets `cost_per_block = X` for `state_machine_id`.
2. State machine advances from height `H0` to `H0+N` over time, but no relayer submits the consensus message yet (or a relayer intentionally withholds it), so `LastRewardedHeight` stays at `H0`.
3. Governance calls `update_cost_per_block(state_machine_id, Y)` with `Y > X` — this simply overwrites storage, per [2](#0-1) .
4. A relayer now submits the consensus proof advancing the state machine to `H0+N`. `on_executed` → `process_message` → `calculate_reward` computes `blocks = N`, `block_cost = Y` (the new rate), reward `= N * Y`, transferred from the treasury [6](#0-5) .
5. The relayer collects `N * Y` instead of the `N * X` that governance intended to pay for that pre-existing backlog — an unauthorized excess withdrawal from the treasury attributable solely to rate-change timing, not to any additional relaying work.

	fn process_message(
		state_machine_height: StateMachineHeight,
		state_machine_id: StateMachineId,
		relayer_account: T::AccountId,
	) -> Result<(), Error<T>> {
		if let Some(block_cost) = StateMachinesCostPerBlock::<T>::get(state_machine_id) {
			let reward = Self::calculate_reward(&state_machine_id, block_cost)?;

			if reward.is_zero() {
				return Ok(());
			}

			T::Currency::transfer(
				&T::TreasuryAccount::get().into_account_truncating(),
				&relayer_account,
				reward,
				Preservation::Expendable,
			)
			.map_err(|_| Error::<T>::RewardTransferFailed)?;

			Self::deposit_event(Event::<T>::RelayerRewarded {
				relayer: relayer_account.clone(),
				amount: reward,
				state_machine_height,
			});

			T::ReputationAsset::mint_into(&relayer_account, reward.saturated_into())
				.map_err(|_| Error::<T>::ReputationMintFailed)?;

			LastRewardedHeight::<T>::mutate(state_machine_id, |watermark| {
				*watermark = Some(watermark.unwrap_or_default().max(state_machine_height.height));
			});
		}
		Ok(())
	}

	/// Calculate the reward for a message based on the state machine id
	fn calculate_reward(
		state_machine_id: &StateMachineId,
		block_cost: <T as pallet_ismp::Config>::Balance,
	) -> Result<<T as pallet_ismp::Config>::Balance, Error<T>> {
		let host = <T::IsmpHost>::default();
		let latest_height = host
			.latest_commitment_height(state_machine_id.clone())
			.map_err(|_| Error::<T>::CouldNotGetStateMachineHeight)?;
		let previous_height =
			host.previous_commitment_height(state_machine_id.clone()).unwrap_or_default();

		// Use the rewarded watermark as the baseline and fall back to the previous height until
		// the first reward is recorded for this chain. The watermark only moves forward, so a
		// height that is rolled back and later resubmitted is not paid for a second time.
		let baseline = LastRewardedHeight::<T>::get(state_machine_id).unwrap_or(previous_height);

		let blocks = latest_height.saturating_sub(baseline);

		let blocks_as_balance: <T as pallet_ismp::Config>::Balance = blocks.saturated_into();
		let reward = blocks_as_balance.saturating_mul(block_cost);

		Ok(reward)

/// Implementation of the FeeHandler trait for the RelayerIncentives pallet
impl<T: Config> FeeHandler for Pallet<T>
where
	<T as frame_system::Config>::AccountId: From<[u8; 32]>,
{
	fn on_executed(
		messages: Vec<MessageWithWeight>,
		events: Vec<IsmpEvent>,
	) -> DispatchResultWithPostInfo {
		let maybe_relayer_account = messages.get(0).and_then(|first_message| {
			if let Message::Consensus(consensus_msg) = &first_message.message {
				let data = sp_io::hashing::keccak_256(&consensus_msg.consensus_proof);
				Signature::decode(&mut &consensus_msg.signer[..])
					.ok()
					.and_then(|sig| sig.verify_and_get_sr25519_pubkey(&data, None).ok())
					.map(|pub_key| pub_key.into())
			} else {
				None::<[u8; 32]>
			}
		});

		if let Some(relayer_account) = maybe_relayer_account {
			// When a batch contains multiple `StateMachineUpdated` events for the
			// same `state_machine_id` (sequential consensus updates for the same
			// chain), `calculate_reward` reads the same persisted
			// `(latest_commitment_height, previous_commitment_height)` pair on
			// every iteration and pays the same block-span reward N times.
			// Collapse the per-state-machine event stream to the single highest
			// `latest_height` so each state machine receives one reward per
			// batch, sized by the actual span of its commitment advance.
			let mut highest_per_state_machine: BTreeMap<StateMachineId, u64> = BTreeMap::new();
			for event in events {
				if let IsmpEvent::StateMachineUpdated(update) = event {
					highest_per_state_machine
						.entry(update.state_machine_id)
						.and_modify(|h| {
							if update.latest_height > *h {
								*h = update.latest_height;
							}
						})
						.or_insert(update.latest_height);
				}
			}

			for (state_machine_id, latest_height) in highest_per_state_machine {
				let state_machine_height =
					StateMachineHeight { id: state_machine_id.clone(), height: latest_height };

				let _ = Self::process_message(
					state_machine_height,
					state_machine_id,
					relayer_account.clone().into(),
				);
			}
		}

		/// Update cost per block for a state machine
		#[pallet::call_index(0)]
		#[pallet::weight(T::WeightInfo::update_cost_per_block())]
		pub fn update_cost_per_block(
			origin: OriginFor<T>,
			state_machine_id: StateMachineId,
			cost_per_block: <T as pallet_ismp::Config>::Balance,
		) -> DispatchResult {
			T::IncentivesOrigin::ensure_origin(origin)?;

			StateMachinesCostPerBlock::<T>::mutate(state_machine_id.clone(), |maybe_cost| {
				*maybe_cost = Some(cost_per_block);
			});

			Self::deposit_event(Event::<T>::StateMachineCostPerBlockUpdated {
				state_machine_id,
				cost_per_block,
			});

			Ok(())
		}
