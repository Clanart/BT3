## Finding: Relayer fees (and any escrowed funds routed through `dispatch_request`) can be permanently locked when dispatched to an unrecognized destination `StateMachine` — ([File: modules/pallets/ismp/src/dispatcher.rs])

### Summary
`pallet_ismp`'s `IsmpDispatcher::dispatch_request` collects the relayer fee and commits an outgoing request for *any* `StateMachine` destination without ever checking that a consensus client/state machine client is actually configured for that destination. Unlike `PolygonZkEVMBridge.bridgeAsset()`/`bridgeMessage()`, which at least check `destinationNetwork != networkID`, Hyperbridge's dispatcher performs no destination-existence check at all before escrowing funds. Because the later timeout path (`modules/ismp/core/src/handlers/timeout.rs`) requires `validate_state_machine` to succeed against that same unrecognized destination, a request sent to a bogus/unconfigured `StateMachine` can neither be delivered nor timed out — the escrowed fee is stuck forever.

### Finding Description
`Pallet::<T>::dispatch_request` (called from the `IsmpDispatcher` impl) only performs a duplicate-commitment check: [1](#0-0) 

The `IsmpDispatcher` wrapper collects the fee unconditionally and constructs the `PostRequest`/`GetRequest` using whatever `dest` was supplied, with no check that `dest` corresponds to a registered consensus client: [2](#0-1) 

Contrast this with the *incoming* request handler, which does validate the source/destination state machine before accepting anything: [3](#0-2) 

The only place a "does this state machine exist" check happens is `validate_state_machine`, which is invoked when *handling* incoming requests/responses/timeouts, and it fails for any `state_id` with no registered consensus client: [4](#0-3) 

Critically, this same check gates the **timeout** path used to refund the escrowed fee: [5](#0-4) 

So if a caller (a demo/example pallet, `host-executive`, `token-governor`, or any pallet built against `IsmpDispatcher`) dispatches a `DispatchPost`/`DispatchGet` with a `dest` that is not — or is no longer — a configured consensus client's state machine (e.g., a typo'd para ID, a decommissioned chain, or simply a `StateMachine::Evm(x)` for a chain hyperbridge never connected), the pallet:
1. Withdraws the relayer fee into `RELAYER_FEE_ACCOUNT` and commits the request (`RequestCommitments`), exactly like the vulnerable `bridgeAsset()`/`bridgeMessage()`.
2. No relayer can ever deliver it (there is no real chain/consensus client to produce a state proof against).
3. No one can ever submit a valid `TimeoutMessage` for it either, because `validate_state_machine(host, timeout_proof.height)` fails with `ConsensusStateIdNotRecognized` for that `state_id` — there is no consensus client to resolve.

The refund logic exists (`on_request_timeout` transfers the escrowed fee back to the payer) but is unreachable for this class of request: [6](#0-5) 

### Impact Explanation
This is a direct fund-loss/lock bug analogous to the PolygonZkEVMBridge report: value (relayer fees, and any downstream pallet's escrowed funds that call `dispatch_request` with a caller/governance-supplied `dest`, e.g. `host-executive::withdraw`/`update_host_params` or user-facing demo transfer pallets) becomes permanently inaccessible because the destination was never validated as an actually-connected state machine. Since neither delivery nor timeout-refund is achievable, the funds are lost for good — not merely delayed until a future network deployment as in the original report, but truly unrecoverable given the current architecture (there's no admin call to force-refund a specific stuck commitment).

### Likelihood Explanation
Any unprivileged pallet built against `IsmpDispatcher` (or a misconfigured privileged one) can trigger this simply by supplying a `dest` `StateMachine` value for which hyperbridge currently has, or ever had, no consensus client registered — no relayer, prover, or governance collusion is required. Typos in `para_id`/EVM chain id, dispatching to a chain before its light client is deployed, or dispatching to a chain whose light client is later removed, are all realistic operator/user errors that this code path does nothing to prevent.

### Recommendation
Before withdrawing the fee and committing the request in `IsmpDispatcher::dispatch_request` (`modules/pallets/ismp/src/dispatcher.rs`), validate that `dispatch_post.dest`/`dispatch_get.dest` is a state machine known to the host's `consensus_clients()` (the same `check_state_machine_client` closure already used in `modules/ismp/core/src/handlers/request.rs` and `handlers/timeout.rs`), and reject the dispatch otherwise. This mirrors the Polygon fix of validating `networkID` is a valid destination before allowing bridging.

### Proof of Concept
1. Deploy/run hyperbridge with consensus clients only for `StateMachine::Evm(1)` and `StateMachine::Polkadot(1000)`.
2. Call any pallet that wraps `IsmpDispatcher::dispatch_request` (e.g. the demo pallet's `dispatch_to_evm`, or `host-executive::withdraw`) with `dest = StateMachine::Evm(999999)` (no registered consensus client) and a non-zero `fee`.
3. Observe: the fee is transferred to `RELAYER_FEE_ACCOUNT`, the commitment is stored in `RequestCommitments`, and a `PostRequest`/`GetRequest` event is emitted — exactly as with a valid destination (`modules/pallets/ismp/src/dispatcher.rs:96-151`, `modules/pallets/ismp/src/impls.rs:89-121`).
4. Attempt to submit a `TimeoutMessage::Post`/`Get` for this commitment once its timeout elapses: `handle` calls `validate_state_machine(host, timeout_proof.height)` for `state_id = StateMachine::Evm(999999)`, which returns `Error::ConsensusStateIdNotRecognized` because no consensus client resolves it (`modules/ismp/core/src/handlers.rs:121-148`, `modules/ismp/core/src/handlers/timeout.rs:48-52`).
5. Result: the request can never be delivered (no real chain exists) and can never be timed out/refunded — the escrowed fee is permanently locked.

	pub fn dispatch_request(request: Request, meta: FeeMetadata<T>) -> Result<H256, ismp::Error> {
		let commitment = hash_request::<Pallet<T>>(&request);

		if RequestCommitments::<T>::contains_key(commitment) {
			Err(ismp::Error::Custom("Duplicate request".to_string()))?
		}

		let (dest_chain, source_chain, nonce) =
			(request.dest_chain(), request.source_chain(), request.nonce());
		let leaf_index_and_pos = T::OffchainDB::push(Leaf::Request(request));
		// Deposit Event
		Pallet::<T>::deposit_event(Event::Request {
			request_nonce: nonce,
			source_chain,
			dest_chain,
			commitment,
		});

		RequestCommitments::<T>::insert(
			commitment,
			RequestMetadata {
				offchain: LeafIndexAndPos {
					leaf_index: leaf_index_and_pos.index,
					pos: leaf_index_and_pos.position,
				},
				fee: meta,
				claimed: false,
			},
		);

		Ok(commitment)
	}

	fn dispatch_request(
		&self,
		request: DispatchRequest,
		fee: FeeMetadata<T>,
	) -> Result<H256, anyhow::Error> {
		// collect payment for the request
		if fee.fee != Zero::zero() {
			T::Currency::transfer(
				&fee.payer,
				&RELAYER_FEE_ACCOUNT.into_account_truncating(),
				fee.fee,
				Preservation::Expendable,
			)
			.map_err(|err| IsmpError::Custom(format!("Error withdrawing request fees: {err:?}")))?;
		}

		let request = match request {
			DispatchRequest::Get(dispatch_get) => {
				let get = GetRequest {
					source: self.host_state_machine(),
					dest: dispatch_get.dest,
					nonce: self.next_nonce(),
					from: dispatch_get.from,
					keys: dispatch_get.keys,
					height: dispatch_get.height,
					context: dispatch_get.context,
					timeout_timestamp: if dispatch_get.timeout == 0 {
						0
					} else {
						<T::TimestampProvider as UnixTime>::now()
							.as_secs()
							.saturating_add(dispatch_get.timeout)
					},
				};
				Request::Get(get)
			},
			DispatchRequest::Post(dispatch_post) => {
				let post = PostRequest {
					source: self.host_state_machine(),
					dest: dispatch_post.dest,
					nonce: self.next_nonce(),
					from: dispatch_post.from,
					to: dispatch_post.to,
					timeout_timestamp: if dispatch_post.timeout == 0 {
						0
					} else {
						<T::TimestampProvider as UnixTime>::now()
							.as_secs()
							.saturating_add(dispatch_post.timeout)
					},
					body: dispatch_post.body,
				};
				Request::Post(post)
			},
		};

		let commitment = Pallet::<T>::dispatch_request(request, fee)?;

		Ok(commitment)
	}

pub fn validate_state_machine<H>(
	host: &H,
	proof_height: StateMachineHeight,
) -> Result<Box<dyn StateMachineClient>, Error>
where
	H: IsmpHost,
{
	// Ensure consensus client is not frozen
	let consensus_client_id = host.consensus_client_id(proof_height.id.consensus_state_id).ok_or(
		Error::ConsensusStateIdNotRecognized {
			consensus_state_id: proof_height.id.consensus_state_id,
		},
	)?;
	let consensus_client = host.consensus_client(consensus_client_id)?;
	// Ensure client is not frozen
	host.is_consensus_client_frozen(proof_height.id.consensus_state_id)?;

	// Ensure delay period has elapsed
	if !verify_delay_passed(host, &proof_height)? {
		return Err(Error::ChallengePeriodNotElapsed {
			state_machine_id: proof_height.id,
			current_time: host.timestamp(),
			update_time: host.state_machine_update_time(proof_height)?,
		});
	}

	consensus_client.state_machine(proof_height.id.state_id)
}
