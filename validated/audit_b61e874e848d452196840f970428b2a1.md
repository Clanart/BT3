### Title
Unchecked type assertion on untrusted CW20/CW721/CW1155 query response causes an unrecovered panic in the pointer precompile - (File: precompiles/pointer/pointer.go)

### Summary
The pointer precompile's `AddCW20`, `AddCW721`, and `AddCW1155` handlers assume that a CosmWasm contract's `token_info`/`contract_info` query response JSON always contains `name` and `symbol` fields typed as strings, and perform unchecked Go type assertions (`.(string)`) on the unmarshaled `map[string]interface{}`. This is the same root-cause pattern as the reported `safeSymbol()` bug (assuming an external contract's metadata return type without validating it), except in sei-chain it manifests as a Go runtime panic rather than a Solidity revert, and that panic is not recovered anywhere in the precompile call path before it reaches the EVM message-handling layer.

### Finding Description
`AddCW20` (and the near-identical `AddCW721`/`AddCW1155`) in [1](#0-0)  queries an attacker-controllable CosmWasm contract and blindly asserts the returned JSON fields as strings: [2](#0-1) 

Any user can deploy a CW20/CW721/CW1155 contract whose `token_info`/`contract_info` query handler returns a `name` or `symbol` field that is missing, `null`, a number, or an object instead of a JSON string. `json.Unmarshal` will happily decode this into the map, but `formattedRes["name"].(string)` will then panic with an "interface conversion" error (or "not string" for wrong types).

Unlike other precompiles in this codebase (e.g. `addr`, `slashing`, `solo`), which explicitly wrap their `Execute` method bodies in `defer recover()` to convert any panic into a revert, the pointer precompile's `Execute` has no such guard: [3](#0-2) 

The pointer precompile is registered as a `DynamicGasPrecompile`, whose `RunAndCalculateGas` only recovers `sdk.ErrorOutOfGas`/`sdk.ErrorGasOverflow` panics raised during its own calldata-decode gas charge, and explicitly re-panics anything else: [4](#0-3) [5](#0-4) 

This is corroborated by the test explicitly documenting this behavior: a non-gas panic from the executor must propagate rather than be masked. [6](#0-5) 

The panic then propagates to `EVMTransaction` in the msg server, whose top-level recover logs the panic and **re-panics** rather than converting it to a normal transaction failure: [7](#0-6) 

### Impact Explanation
If this panic is not caught by an outer Cosmos SDK `baseapp.runTx` recover (standard SDK behavior converts panics to failed-tx results, protecting node liveness), the impact is limited to a single reverted transaction — low severity. However, if any code path invoking `AddCW20Pointer`/`AddCW721Pointer`/`AddCW1155Pointer` executes outside of the standard per-transaction panic-recovery envelope (e.g., during deferred/synthetic EVM execution triggered from a CosmWasm contract call via the wasmd-to-EVM bridge, or from deferred EndBlock pointer-registration/receipt-writing work), an uncaught panic reaching that context could crash the node process for every validator that processes the same block deterministically, which would constitute a validator/chain halt. This escalation path could not be fully confirmed from the available code and needs verification against `sei-cosmos/baseapp/baseapp.go`'s `runTx` recovery and any deferred/synthetic-receipt EVM call paths.

### Likelihood Explanation
Trivial to trigger: any unprivileged account can instantiate a CW20/CW721/CW1155 contract with a `token_info`/`contract_info` query that omits or mistypes the `name`/`symbol` field, then call `addCW20Pointer`/`addCW721Pointer`/`addCW1155Pointer` (address `0x000000000000000000000000000000000000100b`) with that contract's address, in a single transaction — no special privileges or timing required.

### Recommendation
Replace the unchecked type assertions with the two-value form and return a proper error instead of panicking, e.g.:
```go
name, ok := formattedRes["name"].(string)
if !ok {
    return nil, 0, fmt.Errorf("cw20 token_info returned non-string name")
}
symbol, ok := formattedRes["symbol"].(string)
if !ok {
    return nil, 0, fmt.Errorf("cw20 token_info returned non-string symbol")
}
```
Apply the same fix to `AddCW721` and `AddCW1155`. Additionally, consider adding a `defer recover()` guard in `PrecompileExecutor.Execute` for the pointer precompile (consistent with `addr`, `slashing`, and `solo` precompiles) so that any future unchecked assertion or similar panic is converted into a revert rather than propagating past the precompile boundary, and verify/harden the msg-server and EndBlock/deferred receipt paths so a stray panic from precompile execution can never escape per-tx isolation.

### Proof of Concept
1. As any account, instantiate a CW20 contract whose `token_info` query handler returns `{"name": 12345, "symbol": "TEST", "decimals": 6, "total_supply": "0"}` (name as a number instead of a string), or simply omits the `name` key.
2. Call the pointer precompile at `0x000000000000000000000000000000000000100b` with method `addCW20Pointer(cw20Address)`.
3. `p.wasmdKeeper.QuerySmartSafe` succeeds and returns the JSON; `json.Unmarshal` succeeds; `formattedRes["name"].(string)` panics with `interface conversion: interface {} is float64, not string` (or nil-interface panic if the key is absent).
4. The panic is not recovered by `PrecompileExecutor.Execute`, is re-panicked by `DynamicGasPrecompile.RunAndCalculateGas`'s decode-only recover, and is re-panicked again by `msgServer.EVMTransaction`'s deferred recover, propagating further up the call stack than a normal EVM revert would.

func (d DynamicGasPrecompile) RunAndCalculateGas(evm *vm.EVM, caller common.Address, callingContract common.Address, input []byte, suppliedGas uint64, value *big.Int, hooks *tracing.Hooks, readOnly bool, isFromDelegateCall bool) (ret []byte, remainingGas uint64, err error) {
	operation := fmt.Sprintf("%s_unknown", d.name)
	defer func() {
		HandlePrecompileError(err, evm, operation)
		if err != nil {
			fmt.Printf("precompile %s encountered error: %v\n", d.name, err)
			err = vm.ErrExecutionReverted
		}
	}()
	ctxer := state.GetDBImpl(evm.StateDB)
	if ctxer == nil {
		return nil, 0, errors.New("cannot get context from EVM")
	}
	// Resolve the target method from the 4-byte selector only. The argument
	// payload is intentionally NOT decoded yet: ABI decoding of attacker-
	// controlled calldata can cost far more than len(input) (a single string can
	// be referenced by many array/tuple slots), so it must be paid for out of the
	// gas the caller supplied. The static-precompile path charges RequiredGas in
	// vm.RunPrecompiledContract before running; that step is skipped for
	// dynamic-gas precompiles, so we apply the equivalent charge here.
	methodID, err := ExtractMethodID(input)
	if err != nil {
		return nil, 0, err
	}
	method, err := d.MethodById(methodID)
	if err != nil {
		return nil, 0, err
	}
	operation = method.Name

	ctx := ctxer.Ctx()
	// Install the gas meter derived from the supplied EVM gas, then charge for
	// decoding the calldata BEFORE decoding it. A call that cannot afford the
	// decode is rejected here, before the parse/allocation work is performed.
	// chargeDecodeGas scopes the out-of-gas recovery to just these charges, so an
	// executor that later exhausts its gas keeps its normal (propagating)
	// out-of-gas semantics.
	gasLimit := d.executor.EVMKeeper().GetCosmosGasLimitFromEVMGas(ctx.WithGasMeter(sdk.NewInfiniteGasMeterWithMultiplier(ctx)), suppliedGas)
	ctx = ctx.WithGasMeter(sdk.NewGasMeterWithMultiplier(ctx, gasLimit))
	if err = d.chargeDecodeGas(ctx, method, input); err != nil {
		return nil, 0, err
	}

	args, err := method.Inputs.Unpack(input[4:])
	if err != nil {
		return nil, 0, err
	}
	em := ctx.EventManager()
	ctx = ctx.WithEventManager(sdk.NewEventManager())
	ctx = ctx.WithEVMPrecompileCalledFromDelegateCall(isFromDelegateCall)
	ret, remainingGas, err = d.executor.Execute(ctx, method, caller, callingContract, args, value, readOnly, evm, suppliedGas, hooks)
	if err != nil {
		return ret, remainingGas, err
	}
	events := ctx.EventManager().Events()
	if len(events) > 0 {
		em.EmitEvents(ctx.EventManager().Events())
	}
	return ret, remainingGas, err
}

func (d DynamicGasPrecompile) chargeDecodeGas(ctx sdk.Context, method *abi.Method, input []byte) (err error) {
	defer func() {
		if r := recover(); r != nil {
			switch r.(type) {
			case sdk.ErrorOutOfGas, sdk.ErrorGasOverflow:
				err = fmt.Errorf("%v", r)
			default:
				panic(r)
			}
		}
	}()
	scanCost := DefaultGasCost(input, false)
	ctx.GasMeter().ConsumeGas(scanCost, fmt.Sprintf("%s precompile calldata scan", d.name))
	decodeCost, ok := DecodeGasCost(method.Inputs, input)
	if !ok {
		// Calldata is structurally invalid (Unpack would reject it too); reject
		// now, without attempting the decode.
		return fmt.Errorf("invalid calldata encoding for %s", d.name)
	}
	// DecodeGasCost already includes scanCost; charge only the remaining
	// (string-copy) portion so the decode is priced exactly once.
	ctx.GasMeter().ConsumeGas(decodeCost-scanCost, fmt.Sprintf("%s precompile calldata decode", d.name))
	return nil
}
