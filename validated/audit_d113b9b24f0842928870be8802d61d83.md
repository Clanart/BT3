### Title
Stale per-block cached `allowedTokens`/`swapRouter` in `kaiax/gasless` lets a same-block `removeToken`/router-migration cause gas advanced by `LendTxGenerator` to go unrepaid - ([File: kaiax/gasless/impl/getter.go], [File: kaiax/gasless/impl/builder.go])

### Summary
The external report's bug class is: an admin action that instantly removes a trading pair/asset at the contract level, while an off-chain/module-level cache still treats existing user commitments (approvals/positions) as valid, so funds tied to the removed asset are settled incorrectly or not at all. The `kaiax/gasless` module has a structurally identical pattern: it caches `swapRouter`/`allowedTokens` once per block (`updateAddresses`, only invoked in `PostInsertBlock`) and uses that stale snapshot to decide, during the *next* block's construction, whether a `GaslessApproveTx`/`GaslessSwapTx` pair is a valid gasless bundle and therefore whether to prepend a `LendTxGenerator` that unconditionally advances KAIA gas to the sender.

### Finding Description
`GaslessModule.updateAddresses` is only refreshed after a block is inserted: [1](#0-0) [2](#0-1) 

The bundling logic (`ExtractTxBundles`) uses this cached `g.allowedTokens`/`g.swapRouter` (via `IsApproveTx`/`IsSwapTx`/`IsExecutable`) to decide to prepend `GetLendTxGenerator`, which advances KAIA gas to the sender unconditionally, ahead of the actual `GaslessApproveTx`/`GaslessSwapTx` execution: [3](#0-2) [4](#0-3) 

Because this cache is a snapshot from the *previous* block, if a governance/owner-authorized `GaslessSwapRouter.removeToken(token)` (or a `SystemRegistry` router-migration) call is included as an ordinary transaction **earlier in the same block** being built, the on-chain contract state (`allowedTokens` inside `GaslessSwapRouter`) changes mid-block, but the node's `GaslessModule` still has the pre-removal snapshot for the rest of that block's construction. The worker will still classify a pending `GaslessSwapTx` targeting the now-removed token as a legitimate gasless swap, generate the `LendTxGenerator`, and bundle `[LendTxGenerator, ApproveTx, SwapTx]`. When actually executed on-chain, `swapForGas` in `GaslessSwapRouter` will revert (token no longer allowed), but `LendTxGenerator`'s KAIA transfer to the sender is a separate transaction in the bundle and is not conditioned on the swap's success at the module/bundle level (`Bundle.TargetRequired` is set to `false` for this bundle): [5](#0-4) 

This mirrors the reported bug class precisely: the removal action (`removeToken`) is not correlated with settlement/consistency for the exact commitments (lent gas expecting later repayment) that were formed against the *previous* state.

### Impact Explanation
If the lend transaction executes successfully but the subsequent swap transaction reverts (because the token was removed from `allowedTokens` earlier in the same block), the KAIA advanced by the block proposer's `LendTxGenerator` is not recouped from the sender's `amountRepay` inside `swapForGas`, since that function never completes. This is a direct instance of "fee-delegation abuse / gasless settlement theft": value (KAIA) is transferred to an unprivileged sender without the expected repayment, at the expense of the block proposer/protocol that funds `LendTxGenerator`.

### Likelihood Explanation
This requires the specific timing where a `removeToken`/router-migration transaction and a pending `GaslessApprove/GaslessSwap` pair for the removed token land in the same block, with the removal transaction ordered before the gasless bundle. This is plausible whenever token delisting coincides with in-flight gasless transactions from users, and is entirely triggerable by an unprivileged party submitting a swap for a token they know (or suspect) is about to be delisted, racing the removal transaction. Because the gasless module explicitly documents it "reads every block `GaslessSwapRouter` contract to detect any changes in allowed tokens" only after block insertion, the staleness window is guaranteed to exist for one full block, not merely a rare race.

### Recommendation
Re-validate `allowedTokens`/`swapRouter` (and other gasless-bundle preconditions) against the *state as of right before* the bundle is inserted within the same block being assembled, not only the state from the end of the previous block. Alternatively, make the bundle's `LendTxGenerator` transfer conditional (`TargetRequired = true`) on the successful execution of the swap transaction so that a failed/reverted swap causes the whole bundle (including the lend) to be dropped rather than partially applied.

### Proof of Concept
1. Sender submits `GaslessApproveTx` (nonce n) + `GaslessSwapTx` (nonce n+1) for token `T`, which is currently in `GaslessSwapRouter.allowedTokens`.
2. Block N is inserted; `GaslessModule.updateAddresses` caches `allowedTokens[T] = true`.
3. During construction of block N+1, the `GaslessSwapRouter` owner's `removeToken(T)` transaction is included earlier in the block (ordinary tx, not through the gasless module).
4. The worker's `ExtractTxBundles` still uses the stale cached `allowedTokens` from block N and classifies the pending approve/swap pair as a valid gasless bundle, prepending `LendTxGenerator` (unconditional KAIA transfer to sender).
5. Block N+1 executes: `removeToken(T)` runs first, then `LendTxGenerator` (sender receives KAIA), then `GaslessApproveTx` (succeeds, approve is unrelated to allowedTokens), then `GaslessSwapTx` calls `swapForGas`, which now reverts on-chain because `T` is no longer allowed.
6. Result: sender keeps the lent KAIA gas with no repayment executed, at the expense of the block proposer.

func (g *GaslessModule) PostInsertBlock(block *types.Block) error {
	currentState, err := g.Chain.StateAt(block.Header().Root)
	if err != nil {
		return err
	}
	g.setCurrentState(currentState)
	return g.updateAddresses(block.Header())
}

func (g *GaslessModule) isApproveTx(args *ApproveArgs) bool {
	g.gaslessInfoMu.RLock()
	defer g.gaslessInfoMu.RUnlock()

	return g.allowedTokens[args.Token] && // A1
		g.swapRouter == args.Spender && // A3
		args.Amount.Cmp(abi.MaxUint256) == 0 // A4
}

// S1. tx.to is a whitelisted SwapRouter contract.

func (g *GaslessModule) IsSwapTx(tx *types.Transaction) bool {
	args, ok := decodeSwapTx(tx, g.signer)
	return ok && g.isSwapTx(args)

func (g *GaslessModule) isSwapTx(args *SwapArgs) bool {
	g.gaslessInfoMu.RLock()
	defer g.gaslessInfoMu.RUnlock()

	return g.swapRouter == args.Router && // S1
		g.allowedTokens[args.Token] // S3
}

func (g *GaslessModule) updateAddresses(header *types.Header) error {
	g.gaslessInfoMu.Lock()
	defer g.gaslessInfoMu.Unlock()

	swapRouter, tokens, err := getGaslessInfo(g.Chain, header)
	// proceed even if there is something wrong with multicall contract
	if err != nil {
		g.swapRouter = common.Address{}
		g.allowedTokens = map[common.Address]bool{}
		logger.Warn("there is something wrong with multicall contract", "err", err.Error())
		return nil
	}

	g.swapRouter = swapRouter

	g.allowedTokens = map[common.Address]bool{}
	for _, addr := range tokens {
		// all tokens are allowed if nil
		if g.GaslessConfig.AllowedTokens == nil {
			g.allowedTokens[addr] = true
		}
		for _, allowed := range g.GaslessConfig.AllowedTokens {
			if addr == allowed {
				g.allowedTokens[addr] = true
			}
		}
	}

	return nil
}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
}
