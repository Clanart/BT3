### Title
Gasless swap bundle lends gas fees before verifying ApproveTx actually grants the router allowance, allowing loss of proposer-fronted funds - (File: kaiax/gasless/impl/getter.go)

### Summary
The gasless module's swap-check logic (`checkBalanceForSwap`) trusts a preceding, not-yet-executed `ApproveTx` to have granted sufficient allowance and *skips* the on-chain allowance verification whenever an `ApproveTx` immediately precedes the `SwapTx` in the same nonce sequence, while the accompanying `LendTx` unconditionally transfers native KAIA to the sender before the approve/swap outcome is known.

### Finding Description
In `kaiax/gasless/impl/tx_pool.go`, `checkBalanceForSwap` only checks `tokenContract.Allowance(sender, router) >= amountIn` when `noApproveTxPreceeds` is true. When an `ApproveTx` precedes the `SwapTx` (the normal gasless bundle case, verified only by static decoding in `VerifyExecutable`/`isApproveTx` in `kaiax/gasless/impl/getter.go`), the allowance check is skipped entirely, on the assumption that the pending `approve(spender, type(uint256).max)` call will succeed and set the allowance before the swap executes: [1](#0-0) 

Neither `IsApproveTx`/`isApproveTx` nor `VerifyExecutable` inspect the *actual on-chain return value or effect* of the ERC20 `approve()` call; they only statically validate the calldata (`spender`, `amount == MaxUint256`) of the still-unexecuted transaction: [2](#0-1) [3](#0-2) 

Meanwhile, `GetLendTxGenerator` builds an unconditional native-value transfer (`LendTx`) to the swap sender for `lendAmount()` = the fees of the approve/swap transactions, which is placed ahead of the approve/swap pair in the bundle and executes regardless of whether the subsequent `ApproveTx`/`SwapTx` ultimately succeed: [4](#0-3) [5](#0-4) 

This mirrors the reported bug class: an `approve()` call's success is assumed rather than verified. Any ERC20 token admitted to `g.allowedTokens` that can fail to grant the expected allowance without reverting the transaction (e.g., tokens with non-standard `approve` semantics, hooks, blocklists, or that silently return `false`/no-op under certain conditions) will cause the `ApproveTx` to "succeed" as an EVM transaction while the router never receives the expected allowance. The following `SwapTx` (which depends on `transferFrom` via that allowance) then fails on-chain, meaning the repayment (`swapForGas`'s `amountRepay` back to the fee-lender/proposer) never happens — but the `LendTx` funding the user's gas has already been executed and cannot be reversed.

### Impact Explanation
If the swap fails to repay after the lend has already transferred native KAIA to the sender, the block proposer/fee-lender permanently loses the fronted `lendAmount()` (approve + swap tx fees) with no repayment, since the repayment path (`swapForGas` pulling `amountRepay` via the router) is only reachable through a successful `transferFrom`/allowance flow that depends on the unverified `approve()`. This is a concrete value-movement loss (fee-delegation/gasless settlement abuse) reachable by an unprivileged gasless user submitting an ordinary approve+swap transaction pair using a token that is on the allowed list but has non-standard approve semantics, or via griefing by choosing a token/timing that makes the approve a no-op without reverting.

### Likelihood Explanation
Likelihood depends on `g.allowedTokens` containing (or being configured to allow) a token whose `approve()` can succeed as a transaction while not actually setting the expected allowance (e.g., due to internal conditions, hooks, or race conditions with a prior nonzero allowance) — this requires a governance/config decision to admit such a token, which somewhat limits but does not eliminate reachability, since token admission is driven by on-chain registry data (`getGaslessInfo`/`MultiCallGaslessInfo`) rather than rigorous safety vetting of every token's approve implementation. Given kaia targets general ERC20 gas tokens, admission of a non-strictly-standard token is plausible over time.

### Recommendation
Do not skip the allowance verification solely because an `ApproveTx` precedes the `SwapTx` in the bundle. Instead, either (a) simulate/execute the `ApproveTx` against a scratch state and check the resulting on-chain allowance before admitting the bundle and before generating the `LendTx`, or (b) defer/condition the `LendTx` value transfer on the actual post-approve allowance and swap success (e.g., using bundle-level atomicity/rollback so a failed swap does not leave the lend transfer committed), consistent with how `checkBalanceForSwap` already re-reads state in the `noApproveTxPreceeds` branch.

### Proof of Concept
1. Governance/config admits an ERC20 token `T` to `g.allowedTokens` whose `approve()` implementation can return without reverting yet fail to update `allowance(owner, spender)` under some condition (e.g., token has internal pausing, blocklist, or a race against another pending approval) — reachable because token admission source is `MultiCallGaslessInfo`, not a strict ERC20 conformance check: [6](#0-5) 
2. A gasless user submits `ApproveTx` (`approve(router, MaxUint256)` on `T`) immediately followed by `SwapTx` (`swapForGas(T, amountIn, minAmountOut, amountRepay, deadline)`), satisfying all static checks in `VerifyExecutable`: [7](#0-6) 
3. `checkBalanceForSwap` sees `noApproveTxPreceeds == false` and skips the allowance check: [1](#0-0) 
4. The builder bundles `[LendTx, ApproveTx, SwapTx]` per `ExtractTxBundles`/`GetLendTxGenerator`, and the `LendTx` unconditionally sends `lendAmount()` KAIA to the sender: [8](#0-7) [9](#0-8) 
5. On execution, `T.approve()` under the triggering condition fails to grant real allowance (transaction status succeeds), the router's `swapForGas` reverts on `transferFrom` due to insufficient allowance, and no `amountRepay` is ever collected — while the `LendTx` value transfer to the sender has already been committed, resulting in an uncompensated loss to the fee-lending proposer.

// A1. tx.to is a whitelisted ERC20 token.

// A4. amount is MaxUint.
func (g *GaslessModule) IsApproveTx(tx *types.Transaction) bool {
	args, ok := decodeApproveTx(tx, g.signer)
	return ok && g.isApproveTx(args)
}

func (g *GaslessModule) isApproveTx(args *ApproveArgs) bool {
	g.gaslessInfoMu.RLock()
	defer g.gaslessInfoMu.RUnlock()

	return g.allowedTokens[args.Token] && // A1
		g.swapRouter == args.Spender && // A3
		args.Amount.Cmp(abi.MaxUint256) == 0 // A4
}

func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

// MakeLendTx creates a transaction with following properties:
// L1. LendTx.type = 0x7802 (TxTypeEthereumDynamicFee)
// L2. LendTx.from = proposer
// L3. LendTx.to = SwapTx.from
// L4. LendTx.value = LendAmount(approveTxOrNil, swapTx)
func (g *GaslessModule) GetLendTxGenerator(approveTxOrNil, swapTx *types.Transaction) *builder.TxOrGen {
	var src []byte
	if approveTxOrNil != nil {
		src = append(src, approveTxOrNil.Hash().Bytes()...)
	}
	src = append(src, swapTx.Hash().Bytes()...)
	bundleHash := crypto.Keccak256Hash(src)

	gen := func(nonce uint64) (*types.Transaction, error) {
		var (
			chainId = g.InitOpts.ChainConfig.ChainID
			signer  = types.LatestSignerForChainID(chainId)
			key     = g.InitOpts.NodeKey
		)

		to, err := types.Sender(signer, swapTx)
		if err != nil {
			return nil, err
		}

		tx, err := types.NewTransactionWithMap(types.TxTypeEthereumDynamicFee, map[types.TxValueKeyType]interface{}{
			types.TxValueKeyNonce:      nonce,
			types.TxValueKeyTo:         &to,
			types.TxValueKeyAmount:     lendAmount(approveTxOrNil, swapTx),
			types.TxValueKeyData:       common.Hex2Bytes("0x"),
			types.TxValueKeyGasLimit:   params.TxGas,
			types.TxValueKeyGasFeeCap:  swapTx.GasFeeCap(),
			types.TxValueKeyGasTipCap:  swapTx.GasTipCap(),
			types.TxValueKeyAccessList: types.AccessList{},
			types.TxValueKeyChainID:    chainId,
		})
		if err != nil {
			return nil, err
		}

		err = tx.Sign(signer, key)
		return tx, err
	}

	return builder.NewTxOrGenFromGen(gen, bundleHash)
}

func lendAmount(approveTxOrNil, swapTx *types.Transaction) *big.Int {
	r := new(big.Int)

	// R2 = ApproveTx.Fee() if exists
	if approveTxOrNil != nil {
		r.Add(r, approveTxOrNil.Fee())
	}

	// R3 = SwapTx.Fee()
	r.Add(r, swapTx.Fee())

	// LendAmount = R2 + R3
	return r
}

func getGaslessInfo(bc backends.BlockChainForCaller, header *types.Header) (common.Address, []common.Address, error) {
	statedb, err := bc.StateAt(header.Root)
	if err != nil {
		return common.Address{}, nil, err
	}

	// If Registry is not installed, do not query GaslessSwapRouter contract.
	if statedb.GetCode(system.RegistryAddr) == nil || bc.Config().IsRandaoForkBlockParent(header.Number) {
		return common.Address{}, nil, nil
	}

	caller, err := system.NewMultiCallContractCaller(statedb, bc, header)
	if err != nil {
		return common.Address{}, nil, err
	}

	opts := &bind.CallOpts{BlockNumber: header.Number}
	info, err := caller.MultiCallGaslessInfo(opts)

	return info.Gsr, info.Tokens, err
}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
