## Analysis

The `add_missing_files` RPC endpoint in Chia's Data Layer accepts a user-controlled `foldername` parameter and passes it directly into filesystem write operations without validating that it stays within the intended server-files directory — the same bug class as the Flowise `basePath` path-traversal advisory (CWE-22: user-controlled `basePath` → unsanitized `vectorStore.save(basePath)` / `persistDir`).

### Title
Unsanitized `foldername` RPC parameter enables arbitrary filesystem write in DataLayer `add_missing_files` - (File: chia/data_layer/data_layer_rpc_api.py)

### Summary
The `add_missing_files` DataLayer RPC endpoint accepts a `foldername` string from the request body, converts it to a `Path` with no validation, and forwards it to `DataLayer.add_missing_files()`, which uses it as the base directory (`server_files_location`) for writing DataLayer full-tree/delta files to disk.

### Finding Description
The RPC handler reads `foldername` straight from the untrusted request dict and wraps it in a `Path` with no canonicalization or containment check against the configured `server_files_location`: [1](#0-0) 

That path is passed through to `DataLayer.add_missing_files`, where it becomes `server_files_location` for every generation's file write via `write_files_for_root`: [2](#0-1) 

`write_files_for_root` builds the target file names by joining the caller-supplied folder with `store_id`/`node_hash`-derived filenames, creates missing parent directories (`mkdir(parents=True, exist_ok=True)`), and then opens the file for writing (`"wb"` if `overwrite=True`, `"xb"` otherwise): [3](#0-2) 

Unlike the Faiss/SimpleStore report, the leaf filename itself is constrained to a fixed `{store_id}-{node_hash}-{full|delta}-{generation}-v1.0.dat` pattern, but the *base directory* component (`foldername`) is fully attacker-controlled and unsanitized — there is no check that it resolves under `server_files_location` or any other permitted root, and no rejection of `..`, absolute paths, or symlinked directories. This mirrors the root cause identified in the report: a user-supplied base path is passed directly into a filesystem write API.

### Impact Explanation
An authenticated DataLayer RPC caller (i.e., anyone holding a valid RPC client certificate/API access to the Data Layer service, the same trust tier as the Flowise report's "authenticated attacker with API token") can direct DataLayer to write `.dat` files containing serialized tree data to an arbitrary directory on the host filesystem, and — when `overwrite=True` — overwrite existing files at that location. Because directory creation uses `mkdir(parents=True, exist_ok=True)`, the attacker can also force creation of new directory trees outside the intended DataLayer storage area. This is a filesystem-write primitive outside the intended sandbox, consistent with the CWE-22 classification of the source report.

### Likelihood Explanation
Exploitation only requires a single RPC call with a crafted `foldername` value (e.g. an absolute path or a `../../` traversal) to an already-reachable DataLayer RPC endpoint that any authorized local RPC client can call — no additional privilege escalation, race conditions, or complex CLVM crafting are needed.

### Recommendation
Validate and canonicalize the `foldername` request parameter in `DataLayerRpcApi.add_missing_files` (and the corresponding `DataLayer.add_missing_files` service method) against an allow-listed root (e.g. resolve the path and ensure it is a subpath of `server_files_location`, rejecting `..`/absolute overrides unless explicitly intended for local/admin tooling), mirroring the strict filename validation already applied via `is_filename_valid()` in `chia/data_layer/download_data.py`.

### Proof of Concept
1. Start a Chia full node + wallet + DataLayer service with an existing store that has at least one committed root.
2. Using a valid DataLayer RPC client certificate, call the `add_missing_files` RPC with a crafted body:
```json
{
  "ids": ["<store_id_hex>"],
  "overwrite": true,
  "foldername": "/etc/cron.d"
}
```
(or a relative traversal such as `"../../../../tmp/dl-pwned"`).
3. `DataLayerRpcApi.add_missing_files` (chia/data_layer/data_layer_rpc_api.py:401-417) converts this directly to a `Path` and calls `service.add_missing_files(store_id, True, Path("/etc/cron.d"))`.
4. `DataLayer.add_missing_files` (chia/data_layer/data_layer.py:843-866) sets `server_files_location = foldername` and calls `write_files_for_root`, which creates `/etc/cron.d` (if missing) and writes `{store_id}-{node_hash}-full-{gen}-v1.0.dat` / `-delta-` files there, overwriting any pre-existing file with a colliding name.     async def add_missing_files(self, request: dict[str, Any]) -> EndpointResult:
        """
        complete the data server files.
        """
        if "ids" in request:
            store_ids = request["ids"]
            ids_bytes = [bytes32.from_hexstr(id) for id in store_ids]
        else:
            subscriptions: list[Subscription] = await self.service.get_subscriptions()
            ids_bytes = [subscription.store_id for subscription in subscriptions]
        overwrite = request.get("overwrite", False)
        foldername: Path | None = None
        if "foldername" in request:
            foldername = Path(request["foldername"])
        for store_id in ids_bytes:
            await self.service.add_missing_files(store_id, overwrite, foldername)
        return {}

async def write_files_for_root(
    data_store: DataStore,
    store_id: bytes32,
    root: Root,
    foldername: Path,
    full_tree_first_publish_generation: int,
    overwrite: bool = False,
    group_by_store: bool = False,
) -> WriteFilesResult:
    if root.node_hash is not None:
        node_hash = root.node_hash
    else:
        node_hash = bytes32.zeros  # todo change

    filename_full_tree = get_full_tree_filename_path(foldername, store_id, node_hash, root.generation, group_by_store)
    filename_diff_tree = get_delta_filename_path(foldername, store_id, node_hash, root.generation, group_by_store)
    filename_full_tree.parent.mkdir(parents=True, exist_ok=True)

    written = False
    mode: Literal["wb", "xb"] = "wb" if overwrite else "xb"

    written_full_file = False
    if root.generation >= full_tree_first_publish_generation:
        try:
            with open(filename_full_tree, mode) as writer:
                await data_store.write_tree_to_file(root, node_hash, store_id, False, writer)
            written = True
            written_full_file = True
        except FileExistsError:
            pass

    try:
        with open(filename_diff_tree, mode) as writer:
            await data_store.write_tree_to_file(root, node_hash, store_id, True, writer)
        written = True
    except FileExistsError:
        pass

    return WriteFilesResult(written, filename_full_tree if written_full_file else None, filename_diff_tree)
