## Analysis

`WombatPoolHelperV2.harvest()` simply forwards to `IWombatStaking(wombatStaking).harvest(lpToken)`, which internally calls `_toMasterWomAndSendReward`, distributing pending WOM (and bonus) rewards through the fee-split logic in `_sendRewards`, potentially routing an `isMWOM` fee entry through `IConverter(smartWomConverter).smartConvert`. [1](#0-0) [2](#0-1) [3](#0-2) 

The claimed invariant — that "`_liquidity` burned via `burnReceiptToken` must stay reconciled with the deposit-token balance delta paid out by `WombatStaking.withdraw`" — has no connection to `harvest()`. `harvest()` never touches `burnReceiptToken` or `withdraw`; those are exercised only in `WombatPoolHelperV2.withdraw()`, which is a completely separate call path that performs `IWombatStaking.withdraw` → `_unstake` → `burnReceiptToken` in one atomic transaction with no external call to attacker-controlled code in between. [4](#0-3) 

`harvest()`'s only effect is to pull pending WOM/bonus rewards from `masterWombat`, take a protocol-configured fee split (to fixed `feeInfo.to` addresses set only by `onlyOwner`), and queue the remainder into the pool's `rewarder` via `queueNewRewards`, benefiting all stakers of that pool proportionally. The caller receives no funds and cannot redirect any funds to themselves — this is a standard permissionless "poke" pattern common to yield aggregators (harvest can be called by anyone, e.g., keepers, since it merely realizes already-accrued rewards into the reward pool, it does not create or destroy any principal, and the fee destinations/converter address are owner-configured, not attacker-influenced). [5](#0-4) 

There is no mechanism by which an unprivileged caller of `harvest()` extracts value, front-runs a price-sensitive conversion for personal profit, or desynchronizes `burnReceiptToken`/`withdraw` accounting — the two code paths (`harvest` and `withdraw`) don't share state that would let ordering/timing of `harvest()` create an exploitable balance mismatch in `withdraw()`. The `_onlyPoolHelper` modifier further ensures only the registered helper contract can call `withdraw`/`burnReceiptToken`, and those two calls occur atomically within the same transaction, unaffected by a preceding or following `harvest()` call. [6](#0-5) [7](#0-6)

        address[] memory bonusTokens = assetToBonusRewards[_lpToken];
        uint256 bonusTokensLength = bonusTokens.length;

        uint256 womBeforeBalance = IERC20(wom).balanceOf(address(this));

        if(_isStake)

            IMasterWombat(masterWombat).withdraw(poolInfo.pid, lpAmount); // triggers harvest from wombat exchange
        uint256 womRewards = IERC20(wom).balanceOf(address(this)) - womBeforeBalance;
        _sendRewards(_lpToken, wom, poolInfo.rewarder, womRewards);

        for (uint256 i; i < bonusTokensLength; i++) {

            }

    function _sendRewards(
        address _lpToken,
        address _rewardToken,
        address _rewarder,
        uint256 _amount
    ) internal {
        if (_amount == 0) return;
        uint256 originalRewardAmount = _amount;

        if (!isPoolFeeFree[_lpToken]) {
            for (uint256 i = 0; i < feeInfos.length; i++) {
                Fees storage feeInfo = feeInfos[i];

                if (feeInfo.isActive) {
                    address rewardToken = _rewardToken;
                    uint256 feeAmount = (originalRewardAmount * feeInfo.value) / DENOMINATOR;
                    _amount -= feeAmount;
                    uint256 feeTosend = feeAmount;

                    if (feeInfo.isMWOM && rewardToken == wom) {
                        if (smartWomConverter != address(0)) {
                            IERC20(wom).safeApprove(smartWomConverter, feeAmount);
                            uint256 beforeBalnce = IMWom(mWom).balanceOf(address(this));
                            IConverter(smartWomConverter).smartConvert(feeAmount, 0);
                            rewardToken = mWom;
                            feeTosend = IMWom(mWom).balanceOf(address(this)) - beforeBalnce;
                        } else {
                            IERC20(wom).safeApprove(mWom, feeAmount);
                            uint256 beforeBalnce = IMWom(mWom).balanceOf(address(this));
                            IMWom(mWom).deposit(feeAmount);
                            rewardToken = mWom;
                            feeTosend = IMWom(mWom).balanceOf(address(this)) - beforeBalnce;
                        }
                    }

                    if (!feeInfo.isAddress) {
                        IERC20(rewardToken).safeApprove(feeInfo.to, 0);
                        IERC20(rewardToken).safeApprove(feeInfo.to, feeTosend);
                        IBaseRewardPool(feeInfo.to).queueNewRewards(feeTosend, rewardToken);
                    } else {
                        IERC20(rewardToken).safeTransfer(feeInfo.to, feeTosend);
                        emit RewardPaidTo(feeInfo.to, rewardToken, feeTosend);
                    }
                }
            }
        }

        IERC20(_rewardToken).safeApprove(_rewarder, 0);
        IERC20(_rewardToken).safeApprove(_rewarder, _amount);
        IBaseRewardPool(_rewarder).queueNewRewards(_amount, _rewardToken);
