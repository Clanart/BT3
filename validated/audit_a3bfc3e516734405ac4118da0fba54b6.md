### Title
`ReceivedOutput::read` accepts attacker-controlled `(offset, TxOut, OutPoint)` triples verbatim, never verifying the offset actually derives the output's `script_pubkey` or that the claimed outpoint exists — funds can be reported received that are not spendable - ([File: networks/bitcoin/src/wallet/mod.rs])

### Summary
Analogous to `DefaultJmsHeaderMapper` copying unfiltered attacker property names into framework-significant headers, `ReceivedOutput::read` copies attacker-controlled bytes verbatim into the framework-significant fields `offset`, `output`, and `outpoint` without validating the binding between them. `offset` is the security-critical scalar that determines which key can spend the claimed `TxOut`, yet `read` performs no consistency check whatsoever before returning a struct the rest of the wallet treats as a spendable received output. [1](#0-0) 

### Finding Description
`ReceivedOutput` couples three pieces of data with an implicit invariant: `output.script_pubkey` must equal the P2TR script derived from `key + offset*G`, and `outpoint` must identify a real on-chain UTXO carrying that `TxOut`. `Scanner::scan_transaction` establishes this invariant internally, but `ReceivedOutput::read` (reachable on untrusted bytes per the threat model) deserializes all three fields independently with no cross-validation: `offset` is read via `Secp256k1::read_F`, and `output`/`outpoint` via consensus decode, then returned as a trusted `ReceivedOutput`. [2](#0-1) [3](#0-2) 

Downstream, `SignableTransaction::new` consumes these outputs and immediately credits `input.output.value` toward `input_sat`, using it to authorize payments and fee computation. [4](#0-3)  The only integrity check occurs later in `multisig`, where `p2tr_script_buf(offset.group_key())` is compared against `prevouts[i].script_pubkey` — and it silently returns `None` on mismatch. [5](#0-4)  Critically, that check validates only the offset↔script binding; it cannot detect a forged `outpoint` or inflated `output.value`, since an attacker can pair a fabricated `OutPoint`/value with the *real* Serai P2TR script and the corresponding offset `0`, which trivially passes the check. `TransactionSignMachine::sign` then signs a sighash committing to `Prevouts::All` including the fabricated prevout, producing a fully-signed transaction that Bitcoin consensus will reject because the claimed input doesn't exist or carries a different value. [6](#0-5) 

### Impact Explanation
Any consumer that credits balances or builds plans from deserialized `ReceivedOutput`s can be fed a forged output: an attacker claims an outpoint paying to the genuine Serai address with an arbitrary value (e.g., 100 BTC) that was never deposited. `input_sat` counts it, payments are authorized against phantom funds, and the FROST group signs a transaction spending a nonexistent/misvalued input. The signed transaction is invalid on-chain — the funds were "reported received" and committed to a spend plan but are not spendable, and real co-spent inputs in the same transaction are burned as fee contributions to a transaction that can never confirm without a full re-plan. The mismatch path (`script_pubkey` not matching `key + offset*G`) additionally causes `multisig` to return `None` with no error signal, silently stalling signing.

### Likelihood Explanation
Reachable by an unprivileged party whenever serialized `ReceivedOutput` bytes cross a trust boundary (the reachable-API list for this audit explicitly includes `ReceivedOutput::read`). The forgery requires no key material: the attacker needs only the Serai P2TR script (public, from the group key or any prior deposit) and offset `Scalar::ZERO`, both of which pass the `multisig` script check. Constructing the bytes is a trivial serialization of `offset || TxOut || OutPoint`.

### Recommendation
Bind the fields at deserialization rather than trusting them. Options: (a) make `ReceivedOutput::read` take the scanner's base `key` (or `ThresholdKeys`) and reject unless `p2tr_script_buf(key + G*offset) == output.script_pubkey`; (b) restrict construction to `Scanner` and treat `read` output as unverified, requiring a `verify(key)` call before `SignableTransaction::new` accepts it; (c) at minimum, have `multisig`'s mismatch branch return a distinguishing error and document that on-chain existence/value of `outpoint` must be confirmed by the caller before crediting `input_sat`.

### Proof of Concept
```rust
// Attacker knows Serai's group key K (public). P2TR script for offset 0:
let script = p2tr_script_buf(K).unwrap(); // even-Y guaranteed after tweak_keys

// Forge a ReceivedOutput: real script, fabricated outpoint and value
let forged = ReceivedOutput {
    offset: Scalar::ZERO,
    output: TxOut { value: Amount::from_sat(100_0000_0000), script_pubkey: script },
    outpoint: OutPoint::new(Txid::from_raw_hash(/* any hash */), 0),
};
let bytes = forged.serialize();

// Victim deserializes untrusted bytes — no binding check performed
let received = ReceivedOutput::read(&mut &bytes[..]).unwrap();
assert_eq!(received.value(), 100_0000_0000); // phantom 100 BTC credited

// SignableTransaction::new credits input_sat and authorizes payments
let stx = SignableTransaction::new(vec![received], &payments, change, None, fee_rate).unwrap();

// multisig() PASSES: offset 0 yields the real script_pubkey
let machine = stx.multisig(&tweak_keys(keys)).unwrap();

// FROST signs a sighash over Prevouts::All containing the fake prevout.
// Resulting signed tx is rejected by Bitcoin consensus: input does not exist.
```

  /// Read a ReceivedOutput from a generic satisfying Read.
  #[cfg(feature = "std")]
  pub fn read<R: Read>(r: &mut R) -> io::Result<ReceivedOutput> {
    let offset = Secp256k1::read_F(r)?;
    let output;
    let outpoint;
    {
      let mut buf_r = BufReader::with_capacity(0, r);
      output =
        TxOut::consensus_decode(&mut buf_r).map_err(|_| io::Error::other("invalid TxOut"))?;
      outpoint =
        OutPoint::consensus_decode(&mut buf_r).map_err(|_| io::Error::other("invalid OutPoint"))?;
    }
    Ok(ReceivedOutput { offset, output, outpoint })
  }

  pub fn scan_transaction(&self, tx: &Transaction) -> Vec<ReceivedOutput> {
    let mut res = Vec::new();
    for (vout, output) in tx.output.iter().enumerate() {
      // If the vout index exceeds 2**32, stop scanning outputs
      let Ok(vout) = u32::try_from(vout) else { break };

      if let Some(offset) = self.scripts.get(&output.script_pubkey) {
        res.push(ReceivedOutput {
          offset: *offset,
          output: output.clone(),
          outpoint: OutPoint::new(tx.compute_txid(), vout),
        });
      }
    }
    res
  }

  pub fn multisig(self, keys: &ThresholdKeys<Secp256k1>) -> Option<TransactionMachine> {
    let mut sigs = vec![];
    for i in 0 .. self.tx.input.len() {
      let offset = keys.clone().offset(self.offsets[i]);
      if p2tr_script_buf(offset.group_key())? != self.prevouts[i].script_pubkey {
        None?;
      }

      sigs.push(AlgorithmMachine::new(Schnorr::new(), keys.clone().offset(self.offsets[i])));
    }

    Some(TransactionMachine { tx: self, sigs })
  }
