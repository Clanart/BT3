### Title
Silent fee-charge bypass on ISMP Request/Response messages via unverifiable `signer` field — no gas/fee analog to the EVM `gasRemaining == 0` bug - (File: `modules/pallets/ismp/src/fee_handler.rs`)

### Summary
The `WeightFeeHandler::on_executed` implementation mirrors the root cause of the reported minievm bug: an error/negative-verification branch causes the code to silently skip charging, while the underlying operation (message execution) still completes successfully and is treated as fully processed.

### Finding Description
`Pallet::execute` in `modules/pallets/ismp/src/impls.rs` processes a batch of `Message`s via `handle_incoming_message`, collects `events`, and only afterward calls `T::FeeHandler::on_executed(messages_with_weights, events)` to charge fees for the batch that was just executed: [1](#0-0) 

`WeightFeeHandler::on_executed` derives the fee payer ("originator") for `Request`/`Response` messages purely from an optional, self-supplied `signer` field, decoding it as a `Signature` and recovering a public key from it: [2](#0-1) 

Critically, if `Signature::decode` fails, or `verify_and_get_sr25519_pubkey` fails, or the recovered `AccountId::decode` fails, `originator` (or the inner match arms) resolve to `None`, and the `if let Some(originator_bytes) = originator { ... transfer ... }` block is simply skipped — no error is raised, no fee is charged, and the message batch is still reported as successfully executed by `execute()`. Only an actual currency-transfer failure (`Err(_)`) surfaces as a hard error; a missing/garbled signer never does.

This `signer` field is not the cryptographic proof that authenticates the request/response's existence on the source chain (that verification happens independently inside `handle_incoming_message` against the source chain's Merkle/state commitment). It is a separate, self-attested field solely used here to identify who should pay. Because it is attacker-controlled and its failure path is silently ignored rather than treated as an error, any unprivileged caller submitting `handle_unsigned` (which is explicitly `ensure_none`, permissionless, and `Pays::No` at the extrinsic level per `modules/pallets/ismp/src/lib.rs:358-382`) can submit a batch of otherwise-valid `RequestMessage`/`ResponseMessage`s with a corrupted or empty `signer` and have them fully processed — proof verified, events emitted, request/response commitments recorded — without the protocol's fee-charging path ever executing.

This is structurally identical to the reported minievm defect: a special-case branch (`gasRemaining == 0 && err != ErrOutOfGas` there; failed signature decode/verify here) causes the "charge" step to be skipped while the "do the work" step still fully completes, because the two are not atomically bound together — there is no fallback (e.g., "fail the message if fee cannot be attributed" or "charge the treasury/default account") when attribution fails.

### Impact Explanation
The fee model documented at `modules/pallets/ismp/src/fee_handler.rs:98-105` explicitly exists to enforce "prevention of spam and denial-of-service attacks" and economic-incentive alignment for message processing. By supplying a deliberately invalid `signer`, an attacker deterministically and repeatably bypasses this charge for any Request/Response message batch, letting unlimited valid protocol message processing occur fee-free. This is a logic attack on the fee-charging invariant (not a resource-exhaustion/gas-flood DoS) — the on-chain code path meant to always attribute and collect a fee has a codified branch where it silently no-ops instead of erroring or falling back, directly analogous to the audited report's "no gas charged" defect.

### Likelihood Explanation
High for triggering: any unprivileged party can construct a `Message::Request`/`Message::Response` with an intentionally malformed or empty `signer` byte vector — this requires no relayer privilege, no admin/governance role, and no cooperation from any other actor, only a valid underlying request/response commitment proof (which is public, verifiable data once posted on the source chain).

### Recommendation
Do not treat failed signer decode/verification as a silent no-charge case. Either (a) reject the message with a hard error when a fee is due but the originator cannot be attributed (mirroring "consume gas before returning an error" from the referenced fix), or (b) fall back to a well-defined default payer (e.g., charge the relayer/extrinsic submitter, or hold the fee in escrow against the request/response commitment) so that fee collection and message execution are atomically bound and cannot be decoupled by supplying bad signer data.

### Proof of Concept
1. Construct a valid `Message::Request(RequestMessage { requests, proof, signer: vec![] })` (or any bytes that fail `Signature::decode`) referencing a legitimately committed request from a source chain.
2. Submit it via `pallet_ismp::Call::handle_unsigned` (unsigned, permissionless per `ensure_none(origin)?` in `modules/pallets/ismp/src/lib.rs:373-382`).
3. `handle_incoming_message` verifies the request's Merkle/state proof and succeeds; `Pallet::execute` proceeds to `T::FeeHandler::on_executed`.
4. In `WeightFeeHandler::on_executed`, `Signature::decode(&mut &msg.signer[..])` fails, `originator` resolves to `None`, the transfer block at `modules/pallets/ismp/src/fee_handler.rs:203-207` is skipped, and `on_executed` returns `Ok(...)` regardless.
5. Repeat arbitrarily for any number of valid request/response commitments, at zero fee cost each time, despite `fee.is_zero()` at line 183 not being true (a non-zero fee was computed but never collected). [3](#0-2) [4](#0-3) [5](#0-4)

	/// Execute the provided ISMP datagrams, this will short circuit if any messages are invalid.
	/// This also charges fee on valid message delivery
	pub fn execute(messages: Vec<Message>) -> Result<Vec<events::Event>, Error<T>> {
		let host = Pallet::<T>::default();

		let message_results = messages
			.iter()
			.map(|msg| handle_incoming_message(&host, msg.clone()))
			.collect::<Result<Vec<_>, _>>()
			.map_err(|err| {
				log::debug!(target: "ismp", "Handling Error {:#?}", err);
				Pallet::<T>::deposit_event(Event::<T>::Errors { errors: vec![err.into()] });
				Error::<T>::InvalidMessage
			})?;

		let messages_with_weights = message_results
			.iter()
			.zip(messages)
			.map(|(result, message)| MessageWithWeight { message, weight: result.weight() })
			.collect::<Vec<_>>();

		let events = message_results
			.into_iter()
			// check that requests will be successfully dispatched
			// so we can not be spammed with failing txs
			.map(|result| match result {
				MessageResult::Request { events, .. } |
				MessageResult::Response { events, .. } |
				MessageResult::Timeout { events, .. } => events,
				MessageResult::ConsensusMessage(events) => events.into_iter().map(Ok).collect(),
				MessageResult::FrozenClient(_) => vec![],
			})
			.flatten()
			.collect::<Result<Vec<_>, _>>()
			.map_err(|err| {
				log::debug!(target: "ismp", "Handling Error {:#?}", err);
				Pallet::<T>::deposit_event(Event::<T>::Errors { errors: vec![err.into()] });
				Error::<T>::InvalidMessage
			})?;

		T::FeeHandler::on_executed(messages_with_weights, events.clone())
			.map_err(|_| Error::<T>::ErrorChargingFee)?;

		for event in events.clone() {
			// deposit any relevant events
			Pallet::<T>::deposit_event(event.into());
		}

		Ok(events)
	}

	fn on_executed(
		messages: Vec<MessageWithWeight>,
		_events: Vec<Event>,
	) -> DispatchResultWithPostInfo {
		if !POLICY {
			return Ok(PostDispatchInfo { actual_weight: None, pays_fee: Pays::No })
		}
		let mut total_weight = Weight::zero();
		let treasury_account: AccountId = T::get().into_account_truncating();

		for message in &messages {
			let weight = message.weight;
			total_weight.saturating_accrue(weight);
			let fee = W::weight_to_fee(&weight);

			if fee.is_zero() {
				continue
			}

			let originator = match message.message.clone() {
				Message::Request(msg) => {
					let data = sp_io::hashing::keccak_256(&msg.requests.encode());
					Signature::decode(&mut &msg.signer[..])
						.ok()
						.and_then(|sig| sig.verify_and_get_sr25519_pubkey(&data, None).ok())
				},
				Message::Response(msg) => {
					let data = sp_io::hashing::keccak_256(&msg.requests.encode());
					Signature::decode(&mut &msg.signer[..])
						.ok()
						.and_then(|sig| sig.verify_and_get_sr25519_pubkey(&data, None).ok())
				},
				_ => None,
			};

			if let Some(originator_bytes) = originator {
				if let Ok(account) = AccountId::decode(&mut &originator_bytes[..]) {
					C::transfer(&account, &treasury_account, fee, ExistenceRequirement::KeepAlive)
						.map_err(|_| DispatchError::Other("Failed to transfer fee to treasury"))?;
				}
			}
		}

		Ok(PostDispatchInfo { actual_weight: Some(total_weight), pays_fee: Pays::Yes })
	}
}
