### Title
Gasless swap admission relies on manipulable spot-price AMM quote, enabling proposer fee-lending abuse via price manipulation - (File: kaiax/gasless/impl/tx_pool.go)

### Summary
The NUMA incident was a price-manipulation attack where the attacker distorted an AMM pool's spot price to extract value before bridging out. Kaia's KIP-247 gasless-transaction module (`kaiax/gasless`) has an analogous unprotected dependency on live, manipulable AMM spot pricing: it uses the whitelisted `GaslessSwapRouter.getAmountIn()` — which reads current DEX reserves — as the sole economic guard before a block proposer lends real KAIA gas fees to an unprivileged sender.

### Finding Description
`GaslessModule.checkBalanceForSwap` is the only tx-pool-level admission check ensuring a `GaslessSwapTx` is economically sound before the module instructs the proposer to lend gas fees to the sender via `GetLendTxGenerator` [4](#0-3) . It calls the whitelisted `GaslessSwapRouter.GetAmountIn(token, minAmountOut)` to compute the "required" `amountIn` and rejects the swap only if the declared `amountIn` is smaller than that quote [5](#0-4) . This on-chain quote is derived purely from the current spot reserves of the underlying DEX pair returned by `dexAddress`/`getDEXInfo` [6](#0-5) , using the same constant-product formula exposed by `UniswapV2Router02.GetAmountIn(amountOut, reserveIn, reserveOut)` [2](#0-1) .

Because this quote is a live, single-block spot price with no TWAP or manipulation-resistance mechanism, any unprivileged sender who also controls (or can influence in the same block) trades against the token's DEX pool can shift reserves immediately before submitting/having their `GaslessSwapTx` promoted, causing `checkBalanceForSwap`'s `GetAmountIn` quote to reflect an artificially favorable rate. The `amountRepay` that the sender commits to (and that the proposer is guaranteed to recover per `SP4`/`repayAmount`) is fixed independently of the manipulated swap execution price [7](#0-6) , while the actual token-for-KAIA exchange executed inside `swapForGas` happens against the same pool at block-inclusion time. An attacker who manipulates the pool (e.g., by first depleting/inflating one side of the reserve with an ordinary preceding transaction of their own) can pass the mempool's `getAmountIn` check with a smaller `amountIn` than the token is genuinely worth, then have `swapForGas` execute against the distorted pool, extracting `minAmountOut`/`finalUserAmount` far exceeding fair value from the pool's liquidity while the proposer's lent KAIA is repaid at the (manipulated, undervalued) declared `amountRepay`.

### Impact Explanation
This allows an unprivileged attacker to drain value from a whitelisted DEX pool feeding the gasless-swap mechanism, or to obtain excessive KAIA "final user amount" relative to token value actually surrendered, at the expense of the pool's liquidity providers and/or the protocol's gas-lending guarantees — directly analogous to the NUMA price-manipulation loss. Because the KIP-247 flow directly moves proposer-lent KAIA and mints/executes real swaps atomically, incorrect pricing at admission propagates into an actual value-transfer at block-building/execution time.

### Likelihood Explanation
Exploitability requires only a single unprivileged sender to submit ordinary transactions to a public RPC endpoint — no validator or peer privileges are needed — and requires the target token/DEX pool to have thin liquidity (a common condition for newly-listed tokens on `allowedTokens`), matching the profile of the reference incident's target token.

### Recommendation
Do not rely solely on a single-block spot-price quote (`getAmountIn`) for admission or repayment guarantees in `checkBalanceForSwap`/`GaslessSwapRouter`. Incorporate manipulation-resistant pricing (e.g., TWAP oracles, minimum liquidity thresholds, or bounding the allowed deviation between admission-time and execution-time quotes) and re-validate the swap's actual realized rate at execution against a resistant reference price before crediit/lending KAIA.

### Proof of Concept
1. Attacker deploys/uses a thinly-liquid ERC-20 token registered in `GaslessSwapRouter`'s `allowedTokens`/`dexAddress` mapping.
2. Attacker sends an ordinary DEX trade that shifts the pool reserves so that `getAmountIn(token, minAmountOut)` returns an artificially low value.
3. Attacker submits a `GaslessSwapTx` with `amountIn` just above this manipulated quote; `checkBalanceForSwap` in `kaiax/gasless/impl/tx_pool.go:128-141` admits it.
4. Proposer's `GetLendTxGenerator` lends KAIA gas fee to attacker based on `lendAmount`/`repayAmount` fixed by tx fees, unrelated to the true token value [7](#0-6) .
5. `swapForGas` executes against the still-distorted (or attacker-restorable) pool, yielding `finalUserAmount` far above the token's fair value, extracting the difference from pool liquidity while repaying the proposer the pre-fixed `amountRepay`.

func (g *GaslessModule) GetLendTxGenerator(approveTxOrNil, swapTx *types.Transaction) *builder.TxOrGen {
	var src []byte
	if approveTxOrNil != nil {
		src = append(src, approveTxOrNil.Hash().Bytes()...)
	}
	src = append(src, swapTx.Hash().Bytes()...)
	bundleHash := crypto.Keccak256Hash(src)

	gen := func(nonce uint64) (*types.Transaction, error) {
		var (
			chainId = g.InitOpts.ChainConfig.ChainID
			signer  = types.LatestSignerForChainID(chainId)
			key     = g.InitOpts.NodeKey
		)

		to, err := types.Sender(signer, swapTx)
		if err != nil {
			return nil, err
		}

		tx, err := types.NewTransactionWithMap(types.TxTypeEthereumDynamicFee, map[types.TxValueKeyType]interface{}{
			types.TxValueKeyNonce:      nonce,
			types.TxValueKeyTo:         &to,
			types.TxValueKeyAmount:     lendAmount(approveTxOrNil, swapTx),
			types.TxValueKeyData:       common.Hex2Bytes("0x"),
			types.TxValueKeyGasLimit:   params.TxGas,
			types.TxValueKeyGasFeeCap:  swapTx.GasFeeCap(),
			types.TxValueKeyGasTipCap:  swapTx.GasTipCap(),
			types.TxValueKeyAccessList: types.AccessList{},
			types.TxValueKeyChainID:    chainId,
		})
		if err != nil {
			return nil, err
		}

		err = tx.Sign(signer, key)
		return tx, err
	}

	return builder.NewTxOrGenFromGen(gen, bundleHash)

func lendAmount(approveTxOrNil, swapTx *types.Transaction) *big.Int {
	r := new(big.Int)

	// R2 = ApproveTx.Fee() if exists
	if approveTxOrNil != nil {
		r.Add(r, approveTxOrNil.Fee())
	}

	// R3 = SwapTx.Fee()
	r.Add(r, swapTx.Fee())

	// LendAmount = R2 + R3
	return r
}

func repayAmount(approveTxOrNil, swapTx *types.Transaction) *big.Int {
	// R1 = LendTx.Fee() = SwapTx.GasPrice() * TxGas
	r1 := new(big.Int).Mul(swapTx.GasPrice(), new(big.Int).SetUint64(params.TxGas))

	// RepayAmount = R1 + R2 + R3
	return new(big.Int).Add(r1, lendAmount(approveTxOrNil, swapTx))
}
