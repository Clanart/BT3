## Title
Unverified token-type trust during pointer registration allows registering any EVM/CosmWasm token contract under the wrong ERC20/ERC721/ERC1155 standard, enabling selector-collision abuse of `approve`/`transferFrom` - (File: `x/evm/keeper/msg_server.go`)

### Summary
The external report's root cause is that a caller-supplied "asset type" flag is trusted without checking it against the real on-chain standard of the asset, letting an attacker mask one asset type as another and hijack cached, type-specific logic. Sei-chain's pointer-registration path (`MsgRegisterPointer`, handled in `msgServer.RegisterPointer`) has the same class of flaw: the caller supplies `PointerType` (ERC20/ERC721/ERC1155) for an arbitrary `ErcAddress`, and the keeper never verifies that the target contract actually implements that standard before wiring up a CosmWasm pointer that blindly forwards standard-specific calldata to it.

### Finding Description
`RegisterPointer` in [1](#0-0)  switches purely on the user-supplied `msg.PointerType` to decide which pointer-type registry to check and which init payload key (`erc20_address` / `erc721_address` / `erc1155_address`) to instantiate the pointer contract with. There is no call to any interface-detection logic (no ERC165 `supportsInterface` probe, no bytecode inspection, no attempt to call a type-specific read function and require success) to confirm that `msg.ErcAddress` is actually an ERC20, ERC721, or ERC1155 contract. `MsgRegisterPointer.ValidateBasic()` in [2](#0-1)  only checks that the sender/address strings are well-formed, again with no standard verification.

The resulting CosmWasm pointer (e.g. the cw721 pointer in [3](#0-2)  and its `transfer_nft`/`approve` handlers) then encodes and forwards ERC721-shaped calldata (`approve(spender, tokenId)`, `transferFrom(from,to,tokenId)`) directly to the target address via `DelegateCallEvm`. Because ERC20's `approve(address,uint256)` and `transferFrom(address,address,uint256)` share the exact same 4-byte selectors and argument types as ERC721's `approve`/`transferFrom`, a pointer that was registered as "ERC721" against an actual ERC20 contract will still successfully execute against it — with the `tokenId` argument being silently reinterpreted as a token `amount`. The `execute_approve` handler in that contract issues the approve payload without any ownership check at all [3](#0-2) , so it can set/clear allowances on a fungible ERC20 balance while the system (and any downstream integrator/frontend) believes it is dealing with a single non-fungible token.

The Solidity-side pointer (opposite direction, `CW20ERC20Pointer`/`CW721ERC721Pointer`) is comparatively safer because `AddCW20`/`AddCW721` in the pointer precompile query type-specific CosmWasm query messages (`token_info` vs `contract_info`) that will legitimately fail for a mismatched contract type — see [4](#0-3) . But the CW→ERC direction implemented in `RegisterPointer` (`x/evm/keeper/msg_server.go`) performs no equivalent validation whatsoever before wiring the pointer and persisting it via `SetCW20ERC20Pointer`/`SetCW721ERC721Pointer`/`SetCW1155ERC1155Pointer` [5](#0-4) .

### Impact Explanation
Any unprivileged account can submit a single `MsgRegisterPointer` transaction declaring an arbitrary, attacker-chosen `PointerType` for any EVM contract address, including a legitimate high-value ERC20 token, and get a CosmWasm "pointer" registered that treats it as an NFT (or vice versa for ERC1155/ERC20 combinations that also share colliding selectors). Because the pointer's execute handlers forward standard-specific calldata without checking that the target contract truly supports that standard, this creates a persistent, chain-registered artifact (visible via the `Pointer` gRPC query and pointer registry) that silently reinterprets fungible amounts as NFT token IDs (or NFT ids as amounts) whenever anyone (a user, a dApp trusting the registry, or another contract) interacts with the mis-typed pointer, enabling unauthorized `approve`/`transferFrom` semantics confusion against the underlying asset.

### Likelihood Explanation
Reachable directly and permissionlessly by any account submitting one Cosmos SDK transaction (`MsgRegisterPointer`); no privileged role, governance action, or validator collusion is required. The `RegisterPointer` disabled-flag guard is the only gate and is off by default in normal operation.

### Recommendation
Before instantiating a pointer for a given `PointerType`, verify the target contract's real standard: for EVM targets, statically call ERC165 `supportsInterface` (or attempt a canonical, standard-unique call such as `ownerOf(0)`/`decimals()` and require the expected revert/success behavior) and reject registration if it doesn't match the declared `PointerType`, mirroring the type-specific query checks already used in the CW→ERC (`AddCW20`/`AddCW721`) direction at [6](#0-5) .

### Proof of Concept
1. Deploy or pick an existing high-value ERC20 token contract `T` on the Sei EVM.
2. Submit `MsgRegisterPointer{Sender: attacker, PointerType: PointerType_ERC721, ErcAddress: T}` via `x/evm/keeper/msg_server.go`'s `RegisterPointer` [1](#0-0) ; it succeeds and returns a CW721-pointer contract address, with no validation that `T` implements ERC721.
3. Call the new pointer's `approve`/`transfer_nft` execute messages; the cw721 pointer contract encodes ERC721 `approve(address,uint256)`/`transferFrom(address,address,uint256)` calldata and forwards it via `DelegateCallEvm` to `T` [7](#0-6) .
4. Because `T`'s ERC20 `approve`/`transferFrom` share identical selectors/signatures, the call succeeds against the real ERC20 contract, with the "tokenId" argument acting as an ERC20 amount — demonstrating the pointer registry accepted and now propagates a type-confused view of `T` with no interface check.

func (server msgServer) RegisterPointer(goCtx context.Context, msg *types.MsgRegisterPointer) (*types.MsgRegisterPointerResponse, error) {
	ctx := sdk.UnwrapSDKContext(goCtx)
	if server.GetRegisterPointerDisabled(ctx) {
		return nil, fmt.Errorf("registering CW->ERC pointers has been disabled")
	}
	var existingPointer sdk.AccAddress
	var existingVersion uint16
	var currentVersion uint16
	var exists bool
	switch msg.PointerType {
	case types.PointerType_ERC20:
		currentVersion = erc20.CurrentVersion
		existingPointer, existingVersion, exists = server.GetCW20ERC20Pointer(ctx, common.HexToAddress(msg.ErcAddress))
	case types.PointerType_ERC721:
		currentVersion = erc721.CurrentVersion
		existingPointer, existingVersion, exists = server.GetCW721ERC721Pointer(ctx, common.HexToAddress(msg.ErcAddress))
	case types.PointerType_ERC1155:
		currentVersion = erc1155.CurrentVersion
		existingPointer, existingVersion, exists = server.GetCW1155ERC1155Pointer(ctx, common.HexToAddress(msg.ErcAddress))
	default:
		panic("unknown pointer type")
	}
	if exists && existingVersion >= currentVersion {
		return nil, fmt.Errorf("pointer %s already registered at version %d", existingPointer.String(), existingVersion)
	}
	payload := map[string]interface{}{}
	switch msg.PointerType {
	case types.PointerType_ERC20:
		payload["erc20_address"] = msg.ErcAddress
	case types.PointerType_ERC721:
		payload["erc721_address"] = msg.ErcAddress
	case types.PointerType_ERC1155:
		payload["erc1155_address"] = msg.ErcAddress
	default:
		panic("unknown pointer type")
	}

func (msg *MsgRegisterPointer) ValidateBasic() error {
	_, err := sdk.AccAddressFromBech32(msg.Sender)
	if err != nil {
		return sdkerrors.Wrapf(sdkerrors.ErrInvalidAddress, "Invalid sender address (%s)", err)
	}

	if !common.IsHexAddress(msg.ErcAddress) {
		return sdkerrors.ErrInvalidAddress
	}

	return nil
}

pub fn execute_approve(
    deps: DepsMut<EvmQueryWrapper>,
    info: MessageInfo,
    spender: String,
    token_id: String,
    approved: bool,
) -> Result<Response<EvmMsg>, ContractError> {
    let erc_addr = ERC721_ADDRESS.load(deps.storage)?;

    let querier = EvmQuerier::new(&deps.querier);
    let mut payload_spender = spender.clone();
    let mut action = "approve";
    if !approved {
        payload_spender = "".to_string();
        action = "revoke";
    }
    let payload = querier.erc721_approve_payload(payload_spender, token_id.clone())?;
    let msg = EvmMsg::DelegateCallEvm { to: erc_addr, data: payload.encoded_payload };
    let res = Response::new()
        .add_attribute("action", action)
        .add_attribute("token_id", token_id)
        .add_attribute("sender", info.sender)
        .add_attribute("spender", spender.clone())
        .add_message(msg);

    Ok(res)
}

pub fn execute_approve_all(
    deps: DepsMut<EvmQueryWrapper>,
    info: MessageInfo,
    to: String,
    approved: bool,
) -> Result<Response<EvmMsg>, ContractError> {
    let erc_addr = ERC721_ADDRESS.load(deps.storage)?;

    let querier = EvmQuerier::new(&deps.querier);
    let payload = querier.erc721_set_approval_all_payload(to.clone(), approved)?;
    let msg = EvmMsg::DelegateCallEvm { to: erc_addr, data: payload.encoded_payload };
    let mut action = "approve_all";
    if !approved {
        action = "revoke_all";
    }
    let res = Response::new()
        .add_attribute("action", action)
        .add_attribute("operator", to)
        .add_attribute("sender", info.sender)
        .add_attribute("approved", format!("{}", approved))
        .add_message(msg);

    Ok(res)
}

    deps: DepsMut<EvmQueryWrapper>,
    info: &MessageInfo,
    recipient: &str,
    token_id: &str,

    let res = Response::new().add_message(msg);

    Ok(res)

func (p PrecompileExecutor) AddCW20(ctx sdk.Context, method *ethabi.Method, caller common.Address, args []interface{}, value *big.Int, evm *vm.EVM, hooks *tracing.Hooks) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}
	if err := pcommon.ValidateArgsLength(args, 1); err != nil {
		return nil, 0, err
	}
	cwAddr := args[0].(string)
	cwAddress, err := sdk.AccAddressFromBech32(cwAddr)
	if err != nil {
		return nil, 0, err
	}
	res, err := p.wasmdKeeper.QuerySmartSafe(ctx, cwAddress, []byte("{\"token_info\":{}}"))
	if err != nil {
		return nil, 0, err
	}
	formattedRes := map[string]interface{}{}
	if err := json.Unmarshal(res, &formattedRes); err != nil {
		return nil, 0, err
	}
	name := formattedRes["name"].(string)
	symbol := formattedRes["symbol"].(string)
	contractAddr, err := p.evmKeeper.UpsertERCCW20Pointer(ctx, evm, cwAddr, utils.ERCMetadata{Name: name, Symbol: symbol})
	if err != nil {
		return nil, 0, err
	}

	ret, err = method.Outputs.Pack(contractAddr)
	remainingGas = pcommon.GetRemainingGas(ctx, p.evmKeeper)
	return
}
