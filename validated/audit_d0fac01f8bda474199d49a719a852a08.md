### Title
Unauthenticated `ReceivedOutput` bytes can register unspendable funds - (File: networks/bitcoin/src/wallet/mod.rs)

### Summary
Medium severity. `ReceivedOutput::read` accepts an offset, arbitrary `TxOut`, and arbitrary `OutPoint` without proving that the referenced transaction output exists on Bitcoin or was produced by `Scanner`. The wallet then trusts the claimed amount and outpoint when constructing a transaction. [1](#0-0) 

### Finding Description
`Scanner::scan_transaction` creates a legitimate `ReceivedOutput` only after matching `output.script_pubkey` and records the real transaction ID and output index. [2](#0-1)  `ReceivedOutput::read` bypasses that scanner provenance check and deserializes all three fields directly from caller-controlled bytes. [1](#0-0)  `SignableTransaction::new` subsequently trusts the decoded output value and outpoint as inputs. [3](#0-2)  During signing, `SignableTransaction::multisig` validates only that the claimed `prevout.script_pubkey` corresponds to the threshold key and stored offset; it does not validate that the referenced UTXO exists. [4](#0-3) 

### Impact Explanation
An attacker who can supply serialized `ReceivedOutput` data can cause the wallet to report arbitrary Bitcoin value as received and use a nonexistent outpoint as a funding input. If the script is derived from a valid threshold key offset, the signing machine proceeds and generates signatures for a transaction that Bitcoin nodes will reject because the referenced input does not exist. This maps to the incomplete-validation pattern: each object is internally accepted, while the root claim of spendable funds is never authenticated.

### Likelihood Explanation
The attack requires no secret share, validator compromise, malformed curve encoding, or forged signature. It only requires the ability to feed attacker-controlled bytes to `ReceivedOutput::read` in a flow whose result is later used as wallet input. The forged script requirement is public-key-only because `p2tr_script_buf` derives an output script from a public group key. [5](#0-4) 

### Recommendation
Do not construct spendable wallet inputs through unauthenticated deserialization. Bind serialized outputs to the scanner's public key and offset registry, and require chain provenance such as a confirmed block hash, transaction inclusion proof, or fresh lookup against a trusted/full-node source. At minimum, revalidate `outpoint`, `output`, and `script_pubkey` against the chain before accepting the object into `SignableTransaction::new`.

### Proof of Concept
Conceptual reproduction:

```rust
// Victim threshold keys and a previously registered/known scalar offset.
let offset = known_offset;
let spend_key = keys.clone().offset(offset).group_key();
let script = p2tr_script_buf(spend_key).unwrap();

// Serialize:
//   scalar offset ||
//   TxOut { value: claimed_amount, script_pubkey: script } ||
//   OutPoint { txid: attacker_txid_not_on_chain, vout: 0 }
let forged_bytes = encode_received_output(offset, claimed_amount, script, fake_outpoint);

// This succeeds despite the fake UTXO.
let forged = ReceivedOutput::read(&mut forged_bytes.as_slice()).unwrap();
assert_eq!(forged.value(), claimed_amount);

// This also succeeds because only the script/key relationship is checked.
let tx = SignableTransaction::new(
    vec![forged],
    &payments,
    None,
    None,
    fee_per_vbyte,
).unwrap();
let machine = tx.multisig(&keys).unwrap();

// Signing produces witnesses for an input Bitcoin nodes will reject as nonexistent.
```

The decisive issue is that deserialization creates the same `ReceivedOutput` representation as scanner-derived outputs while carrying no proof of on-chain existence. [6](#0-5)

  pub fn scan_transaction(&self, tx: &Transaction) -> Vec<ReceivedOutput> {
    let mut res = Vec::new();
    for (vout, output) in tx.output.iter().enumerate() {
      // If the vout index exceeds 2**32, stop scanning outputs
      let Ok(vout) = u32::try_from(vout) else { break };

      if let Some(offset) = self.scripts.get(&output.script_pubkey) {
        res.push(ReceivedOutput {
          offset: *offset,
          output: output.clone(),
          outpoint: OutPoint::new(tx.compute_txid(), vout),
        });
      }
    }
