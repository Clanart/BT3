### Title
`ReceivedOutput::read` accepts an attacker-controlled scalar `offset` without verifying it actually derives the output's `script_pubkey`, allowing injection of misattributed "received" outputs - (File: `networks/bitcoin/src/wallet/mod.rs`)

### Summary
CVE-2020-15146 is an input-sanitization flaw: an attacker-controlled request parameter was injected into an evaluation context, letting the attacker select unintended behavior. The Serai analog is in `ReceivedOutput::read`, which deserializes three attacker-supplied fields — a scalar `offset`, a `TxOut`, and an `OutPoint` — and returns a `ReceivedOutput` without ever checking that `offset` is the scalar that maps the wallet's scan key to `output.script_pubkey`. The only place this invariant is ever established is inside `Scanner::scan_transaction`, which builds `ReceivedOutput` from a `scripts: HashMap<ScriptBuf, Scalar>` table it controls. The `read` path bypasses that check entirely, so any byte stream accepted as a `ReceivedOutput` can claim an arbitrary (offset, output) pairing.

### Finding Description
`ReceivedOutput::read` calls `Secp256k1::read_F` for `offset`, then `consensus_decode` for the `TxOut` and `OutPoint`, and constructs the struct with no consistency check [1](#0-0) .

Contrast with the trusted construction path: `Scanner::register_offset` records `script -> offset` only after computing `p2tr_script_buf(self.key + GENERATOR * offset)`, and `scan_transaction` emits a `ReceivedOutput` only when `output.script_pubkey` matches a registered script [2](#0-1) [3](#0-2) . The offset is therefore meaningful only relative to (a) the scanner's base key and (b) the output's script; `read` preserves neither guarantee.

Downstream, the injected `offset` is consumed as authority over which key spends the output:

- `SignableTransaction::new` copies `input.offset` into `self.offsets` unconditionally [4](#0-3) .
- `SignableTransaction::multisig` derives the per-input signing key as `keys.clone().offset(self.offsets[i])` and only then checks `p2tr_script_buf(offset.group_key()) == prevouts[i].script_pubkey`, returning `None` on mismatch [5](#0-4) .

The `multisig` check does prevent producing a signature for a mismatched key, so the forged-signature variant fails — but that is precisely what converts the injection into the second accepted impact class: outputs are stored/scheduled as spendable (carrying a seemingly valid `offset`), and every signing attempt aborts with `None` because the claimed offset doesn't reproduce the real `script_pubkey`.

### Impact Explanation
An attacker who can feed bytes to `ReceivedOutput::read` (it is a public `io::Read`-based deserializer over untrusted data) can fabricate a `ReceivedOutput` referencing any real on-chain `TxOut`/`OutPoint` while attaching an arbitrary scalar offset. Any consumer that derives the owning key as `key + G*offset` (or `key - G*offset`, as `Output::key` does) attributes the funds to a key that does not correspond to the output's Taproot script. The wallet reports funds as received, but `SignableTransaction::multisig` refuses to sign (returns `None`), making the reported funds permanently unspendable through this wallet and corrupting balance accounting. This satisfies the "funds reported received that are not spendable" acceptance criterion.

### Likelihood Explanation
Likelihood depends on an integrator persisting or transporting serialized `ReceivedOutput`s where an untrusted party can supply or modify bytes (e.g., relayed scanner data or a compromised store). The format itself invites it: `read` performs no integrity or consistency check, so any 32-byte scalar plus a decodable `TxOut`/`OutPoint` is accepted. No secret material or collusion is required — only the ability to submit bytes to `read`. Severity is Medium: permanent misattribution/lockup of reported funds, but no direct theft or key leakage.

### Recommendation
Make the offset-to-script binding self-verifying. Options: (a) have `ReceivedOutput::read` take the scanner's base key and recompute `p2tr_script_buf(key + GENERATOR * offset) == output.script_pubkey`, rejecting mismatches; or (b) store an index into the scanner's registered-offset table instead of a raw scalar, so deserialized outputs can only reference offsets the scanner itself registered. At minimum, document that `ReceivedOutput` deserialized via `read` must be re-validated against the `Scanner` before use.

### Proof of Concept
```rust
// Attacker crafts bytes: arbitrary offset + a real victim TxOut/OutPoint
let mut bytes = Vec::new();
bytes.extend(Scalar::from(0xdeadbeefu64).to_bytes());   // any offset
bytes.extend(bitcoin::consensus::serialize(&victim_txout));
bytes.extend(bitcoin::consensus::serialize(&victim_outpoint));

// ReceivedOutput::read accepts it with no offset/script consistency check
let forged = ReceivedOutput::read(&mut bytes.as_slice()).unwrap();
assert_eq!(forged.offset(), Scalar::from(0xdeadbeefu64));

// Scanner never registered this offset; the claimed spending key is wrong.
// Wallet records forged as received, then:
let tx = SignableTransaction::new(vec![forged], &payments, change, None, FEE).unwrap();
assert!(tx.multisig(&keys).is_none()); // signing always aborts -> funds unspendable
```

  pub fn register_offset(&mut self, mut offset: Scalar) -> Option<Scalar> {
    // This loop will terminate as soon as an even point is found, with any point having a ~50%
    // chance of being even
    // That means this should terminate within a very small amount of iterations
    loop {
      match p2tr_script_buf(self.key + (ProjectivePoint::GENERATOR * offset)) {
        Some(script) => {
          if self.scripts.contains_key(&script) {
            None?;
          }
          self.scripts.insert(script, offset);
          return Some(offset);
        }
        None => offset += Scalar::ONE,
      }
    }
  }

  pub fn scan_transaction(&self, tx: &Transaction) -> Vec<ReceivedOutput> {
    let mut res = Vec::new();
    for (vout, output) in tx.output.iter().enumerate() {
      // If the vout index exceeds 2**32, stop scanning outputs
      let Ok(vout) = u32::try_from(vout) else { break };

      if let Some(offset) = self.scripts.get(&output.script_pubkey) {
        res.push(ReceivedOutput {
          offset: *offset,
          output: output.clone(),
          outpoint: OutPoint::new(tx.compute_txid(), vout),
        });
      }
    }
    res
  }
