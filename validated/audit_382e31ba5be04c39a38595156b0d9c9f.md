## Title
Unpriced PDA derivation in CPI signer-seed translation allows CU-underpriced hashing amplification - (File: program-runtime/src/cpi.rs)

## Summary
`translate_signers` in `program-runtime/src/cpi.rs` calls `Pubkey::create_program_address` in a loop for every signer-seed group supplied to a CPI, but never charges compute units for these derivations. This contrasts with the direct `sol_create_program_address`/`sol_try_find_program_address` syscalls, which explicitly charge `create_program_address_units` (1500 CU) per derivation before calling the same function.

## Finding Description
`cpi_common` (program-runtime/src/cpi.rs:773-808) charges a single flat `invoke_units` cost (`DEFAULT_INVOCATION_COST` = 946 CU) via `invoke_context.compute_meter.consume_checked(amount)` at line 786, then calls `translate_signers` at line 801 with attacker-controlled `signers_seeds_addr`/`signers_seeds_len`. [1](#0-0) 

Inside `translate_signers`, the function bounds `signers_seeds.len()` to `MAX_SIGNERS` and each `untranslated_seeds.len()` to `MAX_SEEDS`, but for every signer group it directly invokes `Pubkey::create_program_address(&seeds_bytes, program_id)` with **no `compute_meter.consume_checked` call anywhere in this function**. Compare this to the standalone `SyscallCreateProgramAddress`/`SyscallTryFindProgramAddress` syscalls (syscalls/src/lib.rs:821-911), which explicitly charge `create_program_address_units` (1500 CU) via `compute_meter.consume_checked(cost)` before doing the equivalent `Pubkey::create_program_address` work. [2](#0-1) 

Thus an attacker's sBPF program can invoke `sol_invoke_signed` (Rust or C variant, both routed through `cpi_common`) supplying up to `MAX_SIGNERS` signer entries, each with up to `MAX_SEEDS` seeds near `MAX_SEED_LEN` bytes, and the runtime will run the full SHA256-based PDA derivation loop for all of them while charging only the flat 946 CU `invoke_units` fee — the same fee charged for a CPI invocation with zero signers. The per-derivation hashing cost that is deliberately priced at 1500 CU/derivation on the direct syscall path is entirely unpriced on the CPI signer-verification path.

## Impact Explanation
This is a compute-metering underpricing bug: a fixed-cost CPI syscall (`invoke_units`) is made to perform unbounded (up to `MAX_SIGNERS * MAX_SEEDS` `create_program_address` calls, each hashing up to `MAX_SEED_LEN`-sized seeds) real hashing work without proportional CU charge. This violates the invariant that "every CPI charges compute proportional to real cost" and permits a program to extract more actual CPU work per charged CU than intended, i.e. CU-underpriced compute / resource-metering bypass. Because this can be nested within `MAX_INSTRUCTION_STACK_DEPTH` CPI calls (and repeated across the instruction trace up to `MAX_INSTRUCTION_TRACE_LENGTH`), it amplifies CPU cost per unit of billed compute across a transaction, matching Agave's "materially underpriced compute" bounty category.

## Likelihood Explanation
Fully reachable by an unprivileged attacker: deploy an arbitrary sBPF program, invoke `sol_invoke_signed_rust`/`sol_invoke_signed_c` with a `signers_seeds` array populated up to `MAX_SIGNERS` entries, each with `MAX_SEEDS` seeds near `MAX_SEED_LEN`. No special privileges, staked identity, or validator control needed — just normal transaction execution. This is deterministic and 100% reproducible on every call.

## Recommendation
Charge compute proportional to signer-seed derivation work inside `translate_signers`, mirroring the syscall path: consume `create_program_address_units` (or an equivalent cost scaled by number of signers and total seed bytes) for each `Pubkey::create_program_address` call performed while translating CPI signers, before/while iterating `signers_seeds`.

## Proof of Concept
Rust integration test (in `program-runtime/src/cpi.rs` test module, using existing `mock_invoke_context!`/`mock_signers` helpers already present in the file):
```rust
#[test]
fn test_translate_signers_underpriced_cu() {
    // Setup: same mock_invoke_context! harness as test_translate_signers().
    // Case A: 1 signer, 1 short seed.
    // Case B: MAX_SIGNERS signers, each with MAX_SEEDS seeds of length MAX_SEED_LEN.
    let before_a = invoke_context.compute_meter.get_remaining();
    translate_signers(&program_id, vm_addr_a, 1, &invoke_context).unwrap();
    let used_a = before_a - invoke_context.compute_meter.get_remaining();

    let before_b = invoke_context.compute_meter.get_remaining();
    translate_signers(&program_id, vm_addr_b, MAX_SIGNERS as u64, &invoke_context).unwrap();
    let used_b = before_b - invoke_context.compute_meter.get_remaining();

    // Expected (buggy) result: used_a == used_b == 0, i.e. translate_signers itself
    // charges nothing regardless of MAX_SIGNERS * MAX_SEEDS worth of hashing.
    assert_eq!(used_a, 0);
    assert_eq!(used_b, 0); // demonstrates COST_UPPER_BOUND is NOT enforced proportional to work
}
```
A CU-vs-wallclock benchmark (e.g. using `std::time::Instant` around the `translate_signers` call for case A vs case B) would show measured CPU time scaling with `MAX_SIGNERS * MAX_SEEDS` while charged CU stays flat at the `invoke_units` cost from `cpi_common`, confirming the underpricing.

pub fn translate_signers(
    program_id: &Pubkey,
    signers_seeds_addr: u64,
    signers_seeds_len: u64,
    invoke_context: &InvokeContext,
) -> Result<Vec<Pubkey>, Error> {
    let check_aligned = invoke_context.get_check_aligned();
    let memory_mapping = invoke_context.memory_contexts.memory_mapping()?;
    if signers_seeds_len > 0 {
        let signers_seeds = translate_slice::<VmSlice<VmSlice<u8>>>(
            memory_mapping,
            signers_seeds_addr,
            signers_seeds_len,
            check_aligned,
        )?;
        if signers_seeds.len() > MAX_SIGNERS {
            return Err(Box::new(CpiError::TooManySigners));
        }
        Ok(signers_seeds
            .iter()
            .map(|signer_seeds| {
                let untranslated_seeds = translate_slice::<VmSlice<u8>>(
                    memory_mapping,
                    signer_seeds.ptr(),
                    signer_seeds.len(),
                    check_aligned,
                )?;
                if untranslated_seeds.len() > MAX_SEEDS {
                    return Err(Box::new(InstructionError::MaxSeedLengthExceeded) as Error);
                }
                let seeds_bytes = untranslated_seeds
                    .iter()
                    .map(|untranslated_seed| {
                        translate_vm_slice(untranslated_seed, memory_mapping, check_aligned)
                    })
                    .collect::<Result<Vec<_>, Error>>()?;
                Pubkey::create_program_address(&seeds_bytes, program_id)
                    .map_err(|err| Box::new(CpiError::BadSeeds(err)) as Error)
            })
            .collect::<Result<Vec<_>, Error>>()?)
    } else {
        Ok(vec![])
    }
}
