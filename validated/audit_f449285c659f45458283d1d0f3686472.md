### Title
`RegisterPointerDisabled` Parameter Is Not Enforced in the Pointer Precompile, Allowing Bypass of a Disabled Pointer-Registration Feature - ([File: precompiles/pointer/pointer.go])

### Summary
The EVM `pointer` precompile (`addNativePointer`, `addCW20Pointer`, `addCW721Pointer`, `addCW1155Pointer`) lets any EVM caller create CW20/CW721/CW1155→ERC pointer contracts without checking the chain-wide `RegisterPointerDisabled` parameter, while the equivalent Cosmos-native path (`MsgRegisterPointer`) does enforce it. This mirrors CVE-2021-4133/GHSA-83x4-9cwr-5487, where Keycloak enforced "new user registration disabled" on one entry point (the UI) but not on another reachable entry point (the admin REST API), letting any user bypass the intended restriction.

### Finding Description
`x/evm/keeper/msg_server.go`'s `RegisterPointer` handler explicitly checks the `RegisterPointerDisabled` param before creating any pointer: [1](#0-0) 

This parameter is a first-class, governance-settable EVM param, retrieved via `GetRegisterPointerDisabled`: [2](#0-1) 

and there is a dedicated upgrade migration whose sole purpose is to flip this flag on chain-wide (`MigrateDisableRegisterPointer`): [3](#0-2) 

However, the current (non-legacy) `pointer` precompile at address `0x100b` — reachable by any EVM transaction sender, not just Cosmos-message senders — implements the same "create a pointer" functionality (`AddNative`, `AddCW20`, `AddCW721`, `AddCW1155`) but never calls `GetRegisterPointerDisabled` or otherwise consults the param: [4](#0-3) [5](#0-4) 

The same omission exists across every legacy precompile version (v552, v555, v562, v575, v580, v600, v605, v606, v610, v614, v620, v630, v640, v65, v66, v67), e.g.: [6](#0-5) 

So once an operator/governance disables pointer registration (`RegisterPointerDisabled = true`) — presumably to freeze the set of pointer contracts (e.g., after discovering a bug in pointer code, to stop further pointer proliferation, or as part of a deprecation of the CW↔ERC bridge) — any unprivileged EVM caller can still invoke the precompile directly to create new native/CW20/CW721/CW1155 pointer contracts, completely bypassing the intended restriction, exactly as Keycloak's admin REST API let users create accounts while UI registration was disabled.

### Impact Explanation
Bypassing `RegisterPointerDisabled` lets an unprivileged EVM caller keep creating new CW↔ERC pointer contracts (which mint EVM-side proxy contracts controlling native/CW20/CW721/CW1155 assets) after the chain operators have deliberately disabled this capability, e.g. following discovery of a pointer-related bug or as part of controlled migration/deprecation. Since pointer contracts mediate token transfer/mint/burn logic between the Cosmos and EVM state, uncontrolled continued creation defeats an explicit governance-level security control and can be leveraged to (re-)create pointer contracts for tokens whose registration was deliberately frozen, undermining the safety guarantee the disable flag is meant to provide.

### Likelihood Explanation
The bypass requires nothing more than a standard EVM transaction calling the `pointer` precompile at `0x100b` — no special privileges, no CosmWasm access, no consensus-level access. Any address with a small amount of gas can trigger it, and the omission is present in every precompile version, including the current active version, so it is deterministically reachable whenever `RegisterPointerDisabled` is set to `true`.

### Recommendation
Add a check for `evmKeeper.GetRegisterPointerDisabled(ctx)` at the top of `AddNative`, `AddCW20`, `AddCW721`, and `AddCW1155` in `precompiles/pointer/pointer.go` (and if backporting to older precompile versions matters, in the legacy versions as well), returning an error consistent with the Cosmos message path (`"registering CW->ERC pointers has been disabled"`) when the flag is set.

### Proof of Concept
1. Governance/operator sets `RegisterPointerDisabled = true` via a param-change proposal or via the `MigrateDisableRegisterPointer` upgrade handler.
2. Confirm `MsgRegisterPointer` (Cosmos path) is now rejected with `"registering CW->ERC pointers has been disabled"` as shown in `x/evm/keeper/msg_server.go` lines 249-251.
3. From any EVM account, call the `pointer` precompile at `0x100b` method `addCW20Pointer(cwAddr)` (or `addNativePointer`, `addCW721Pointer`, `addCW1155Pointer`).
4. Observe the call succeeds and a new pointer contract is created via `UpsertERCCW20Pointer`/etc., despite `RegisterPointerDisabled` being `true` — demonstrating the authorization control is bypassed via the alternate (precompile) entry path.

func (k *Keeper) GetRegisterPointerDisabled(ctx sdk.Context) bool {
	if !ctx.IsTracing() {
		return k.GetParams(ctx).RegisterPointerDisabled
	}
	switch {
	case semver.Compare(ctx.ClosestUpgradeName(), "v6.0.6") < 0:
		// Not present in pre-5.8.0 params; use default
		return types.DefaultRegisterPointerDisabled
	default:
		return k.GetParams(ctx).RegisterPointerDisabled
	}
}

func (p PrecompileExecutor) AddNative(ctx sdk.Context, method *ethabi.Method, caller common.Address, args []interface{}, value *big.Int, evm *vm.EVM, hooks *tracing.Hooks) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}
	if err := pcommon.ValidateArgsLength(args, 1); err != nil {
		return nil, 0, err
	}
	token := args[0].(string)
	metadata, metadataExists := p.bankKeeper.GetDenomMetaData(ctx, token)
	if !metadataExists {
		return nil, 0, fmt.Errorf("denom %s does not have metadata stored and thus can only have its pointer set through gov proposal", token)
	}
	name := metadata.Name
	symbol := metadata.Symbol
	var decimals uint8
	for _, denomUnit := range metadata.DenomUnits {
		if denomUnit.Exponent > uint32(decimals) && denomUnit.Exponent <= math.MaxUint8 {
			decimals = uint8(denomUnit.Exponent)
			name = denomUnit.Denom
			symbol = denomUnit.Denom
			if len(denomUnit.Aliases) > 0 {
				name = denomUnit.Aliases[0]
			}
		}
	}
	contractAddr, err := p.evmKeeper.UpsertERCNativePointer(ctx, evm, token, utils.ERCMetadata{Name: name, Symbol: symbol, Decimals: decimals})
	if err != nil {
		return nil, 0, err
	}

	ret, err = method.Outputs.Pack(contractAddr)
	remainingGas = pcommon.GetRemainingGas(ctx, p.evmKeeper)
	return
}

func (p PrecompileExecutor) AddNative(ctx sdk.Context, method *ethabi.Method, caller common.Address, args []interface{}, value *big.Int, evm *vm.EVM, suppliedGas uint64, hooks *tracing.Hooks) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}
	if err := pcommon.ValidateArgsLength(args, 1); err != nil {
		return nil, 0, err
	}
	token := args[0].(string)
	existingAddr, existingVersion, exists := p.evmKeeper.GetERC20NativePointer(ctx, token)
	if exists && existingVersion >= 1 {
		return nil, 0, fmt.Errorf("pointer at %s with version %d exists when trying to set pointer for version %d", existingAddr.Hex(), existingVersion, native.CurrentVersion)
	}
	metadata, metadataExists := p.bankKeeper.GetDenomMetaData(ctx, token)
	if !metadataExists {
		return nil, 0, fmt.Errorf("denom %s does not have metadata stored and thus can only have its pointer set through gov proposal", token)
	}
	name := metadata.Name
	symbol := metadata.Symbol
	var decimals uint8
	for _, denomUnit := range metadata.DenomUnits {
		if denomUnit.Exponent > uint32(decimals) && denomUnit.Exponent <= math.MaxUint8 {
			decimals = uint8(denomUnit.Exponent)
			name = denomUnit.Denom
			symbol = denomUnit.Denom
			if len(denomUnit.Aliases) > 0 {
				name = denomUnit.Aliases[0]
			}
		}
	}
	constructorArguments := []interface{}{
		token, name, symbol, decimals,
	}

	packedArgs, err := native.GetParsedABI().Pack("", constructorArguments...)
	if err != nil {
		panic(err)
	}
	bin := append(native.GetBin(), packedArgs...)
	if value == nil {
		value = utils.Big0
	}
	ret, contractAddr, remainingGas, err := evm.Create(caller, bin, suppliedGas, uint256.MustFromBig(value))
	if err != nil {
		return
	}
	err = p.evmKeeper.SetERC20NativePointer(ctx, token, contractAddr)
	if err != nil {
		return
	}

	ctx.EventManager().EmitEvent(sdk.NewEvent(
		types.EventTypePointerRegistered, sdk.NewAttribute(types.AttributeKeyPointerType, "native"),
		sdk.NewAttribute(types.AttributeKeyPointerAddress, contractAddr.Hex()), sdk.NewAttribute(types.AttributeKeyPointee, token),
		sdk.NewAttribute(types.AttributeKeyPointerVersion, fmt.Sprintf("%d", native.CurrentVersion))))
	ret, err = method.Outputs.Pack(contractAddr)
	return
}
