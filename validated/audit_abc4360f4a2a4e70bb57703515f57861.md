### Title
`ReceivedOutput::read` skips the offset↔script binding the `Scanner` enforces, allowing unspendable outputs to be reported as received - (File: networks/bitcoin/src/wallet/mod.rs)

### Summary
The Oxia bug class is "a loader processes only part of a bundle and silently skips the validation performed for the rest." The Serai analog is `ReceivedOutput::read` in `networks/bitcoin/src/wallet/mod.rs`. When `Scanner` *produces* a `ReceivedOutput`, the `offset` is cryptographically bound to `output.script_pubkey`: `register_offset` only accepts offsets for which `p2tr_script_buf(key + offset*G)` returns `Some` (i.e., an even tweaked key) and `scan_transaction` only emits outputs whose `script_pubkey` is in the `scripts` map keyed by that offset. `ReceivedOutput::read` deserializes the three fields from untrusted bytes with no such check — it accepts any `(offset, TxOut, OutPoint)` tuple, skipping the entire key-binding/parity validation the Scanner performs.

### Finding Description
`Scanner::scan_transaction` constructs `ReceivedOutput` only when `output.script_pubkey` matches a registered `p2tr` script derived from `key + offset*G` with even parity:

- `register_offset` loops on `p2tr_script_buf(self.key + GENERATOR*offset)`, which returns `None` for odd points, so every stored offset yields a valid spendable Taproot output bound to the group key (networks/bitcoin/src/wallet/mod.rs:180-195).
- `scan_transaction` only emits outputs matching `self.scripts` (lines 199-213).

`ReceivedOutput::read` (lines 122-134) does none of this:

```rust
pub fn read<R: Read>(r: &mut R) -> io::Result<ReceivedOutput> {
    let offset = Secp256k1::read_F(r)?;
    let output;
    let outpoint;
    {
      let mut buf_r = BufReader::with_capacity(0, r);
      output =
        TxOut::consensus_decode(&mut buf_r).map_err(|_| io::Error::other("invalid TxOut"))?;
      outpoint =
        OutPoint::consensus_decode(&mut buf_r).map_err(|_| io::Error::other("invalid OutPoint"))?;
    }
    Ok(ReceivedOutput { offset, output, outpoint })
}
```

It never (a) verifies `output.script_pubkey == p2tr_script_buf(key + offset*G)` for the group's key, (b) verifies the tweaked key is even (BIP-340/341 requirement), nor (c) verifies the `outpoint` actually references `output`. Like `trustedCertPool()` silently discarding all but the first PEM block, the deserializer silently discards all semantic validation — only byte-level canonicity of each field is checked.

### Impact Explanation
Any component that consumes `ReceivedOutput`s deserialized from a non-Scanner source (DB restore, relayed output data, per-input re-keying at signing time via `offset()`) will treat an attacker-crafted output as spendable multisig funds. An unprivileged party can supply a `ReceivedOutput` claiming an arbitrary `TxOut`/`OutPoint` with a mismatched or odd-parity `offset`: the output is reported as received by the group key yet cannot be signed for — either the offset doesn't correspond to the script at all, or the tweaked key is odd and cannot produce a valid BIP-340 signature. This is the accepted "funds reported received that are not spendable" impact, and it can also feed bad offsets into per-input re-keying during spend construction in `send.rs`.

### Likelihood Explanation
Reachable whenever serialized `ReceivedOutput`s cross a trust boundary (untrusted bytes into `ReceivedOutput::read`, an explicitly in-scope surface). The attacker only needs to control the bytes — a public `TxOut`, a fabricated `OutPoint`, and any scalar. No key material or validator collusion required.

### Recommendation
Either make `ReceivedOutput::read` take the scanner/group key and re-verify `output.script_pubkey == p2tr_script_buf(key + offset*G).unwrap()` plus a sane `outpoint`, or split the type: an unvalidated serialized form distinct from the spendable form produced by `Scanner`, so the binding can only come from `scan_transaction`/`register_offset`.

### Proof of Concept
```rust
// For a group key K, craft a ReceivedOutput not payable to K:
let evil_offset = Scalar::ZERO;                    // any scalar
let fake_output = TxOut {
    value: Amount::from_sat(1_000_000),
    script_pubkey: ScriptBuf::new_p2tr_tweaked(
        TweakedPublicKey::dangerous_assume_tweaked(attacker_xonly_key), // not K-derived
    ),
};
let fake_outpoint = OutPoint::new(attacker_txid, 0);

let mut buf = Vec::new();
buf.extend(evil_offset.to_bytes());
buf.extend(serialize(&fake_output));
buf.extend(serialize(&fake_outpoint));

let ro = ReceivedOutput::read(&mut buf.as_slice()).unwrap(); // accepted
// ro.value() == 1_000_000 reported as group funds, but no offset
// makes this output signable by the group's FROST key.
```
