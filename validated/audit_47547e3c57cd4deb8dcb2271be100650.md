## Title
Unenforced `deadline` Freshness Check for GaslessSwapTx at Bundle-Extraction Time — ([File: kaiax/gasless/impl/getter.go, kaiax/gasless/impl/builder.go])

### Summary
The `EverclearBridge.sendMsg` bug is a case where a safety-critical parameter (`maxFee`/`ttl`) is validated nowhere along the actual execution path before being forwarded to an external call, allowing an unintended/unsafe pathway to be taken. Kaia's gasless-swap module (`kaiax/gasless`) has an analogous gap: the `deadline` freshness check for `GaslessSwapTx` is enforced only once, at initial tx-pool admission, and is never re-validated at the later bundling/promotion step that actually determines whether the swap is executed in a block.

### Finding Description
`GaslessModule.checkBalanceForSwap` is the only place that checks `tx.deadline >= currentTimestamp` for a gasless swap transaction: [1](#0-0) 

This function is wired in as `GetCheckBalance()`, which is invoked exactly once, at initial transaction-pool admission (`validateTx`), and explicitly *replaces* ("skips") the normal sender balance check for recognized module transactions: [2](#0-1) 

However, the logic that actually determines whether a swap is promoted to "ready" and bundled into a block — `IsReady` → `isSwapTxReady`/`isApproveTxReady` → `IsExecutable` → `VerifyExecutable` — and the block-building bundler `ExtractTxBundles` never re-check the `deadline`: [3](#0-2) [4](#0-3) [5](#0-4) 

`VerifyExecutable` only checks structural pattern conditions (Ax/Sx, sender match, token match, approve amount, nonce sequencing, and repay-amount correctness) — no deadline condition is present. The only timing-related pool cleanup is `PreReset`, which drops stale bundle transactions after `QueueTimeout`/`PendingTimeout` (10s each), which is a heuristic housekeeping mechanism, not a deadline re-validation gate: [6](#0-5) 

The `GaslessSwapRouter` contract itself relies on the module's off-chain admission-time check rather than an on-chain `require(deadline >= block.timestamp)` — the revert strings observed on-chain in the integration test (`"insufficient deadline: deadline=1"`, `"insufficient minAmountOut"`, `"insufficient amountIn"`) are the exact Go-side error strings produced by `checkBalanceForSwap`, not Solidity `require` reasons, confirming these safety conditions are enforced solely by the mempool admission gate: [7](#0-6) 

Because this single admission-time check is not repeated at promotion/bundling time, a `GaslessSwapTx` that was valid (deadline in the future) when first submitted can remain in the queue/pending pool (up to the `QueueTimeout`+`PendingTimeout` window, or longer under load/backpressure) and later be bundled and executed by `ExtractTxBundles`/`IsReady` even though its `deadline` has since elapsed on-chain, because nothing on that path re-checks it.

### Impact Explanation
If the on-chain `swapForGas` execution proceeds with a `deadline` that has already passed, the user is effectively locked into swap parameters (`minAmountOut`, `amountRepay`) computed off a stale exchange-rate snapshot. In volatile markets, this allows execution of a swap under conditions the user no longer consented to at execution time — the exact category of "safety parameter checked pre-flight but not enforced at the point of actual execution" that the Everclear report flags, here manifesting as potential unfavorable settlement/value extraction from the gasless-swap flow rather than outright fund loss enforced by hard on-chain invariants (since ERC20 balance/allowance checks and the underlying Uniswap-style router will still revert on hard shortfalls).

### Likelihood Explanation
Reachable by any unprivileged user simply submitting a normal `GaslessApproveTx`/`GaslessSwapTx` pair via the public RPC — no validator or peer collusion needed. It requires timing conditions (tx staying in the pool close to `QueueTimeout`/`PendingTimeout`, or a busy proposer delaying promotion) to actually manifest, which somewhat limits how commonly it triggers in practice, but does not require any privileged position.

### Recommendation
Re-validate the swap `deadline` (and ideally re-check `minAmountOut`/`amountRepay` consistency against current on-chain rates) inside `VerifyExecutable`/`isSwapTxReady`, immediately before a `GaslessSwapTx` is included in a bundle in `ExtractTxBundles`, not only once at initial `validateTx` admission. Additionally, consider enforcing the deadline check on-chain in `GaslessSwapRouter.swapForGas` itself so that the safety invariant does not depend solely on the off-chain module's admission-time gate.

### Proof of Concept
1. Submit a valid `GaslessApproveTx` + `GaslessSwapTx` pair with `deadline = now + 300s`; `checkBalanceForSwap` accepts it and it enters the queue/pending pool.
2. Delay promotion/inclusion (e.g., via congestion or by having the sender's approve/swap sit near `QueueTimeout`/`PendingTimeout`) until wall-clock time exceeds the original `deadline`.
3. When the proposer's `ExtractTxBundles` picks up the pair (via `IsReady`→`IsExecutable`→`VerifyExecutable`, none of which re-check `deadline`), the bundle is built and the swap executes on-chain with a `deadline` that has already elapsed, since neither the bundling logic nor (per observed revert strings) the `GaslessSwapRouter` contract itself re-enforces it.

// Check promotion condition.
func (g *GaslessModule) isReady(txs map[uint64]*types.Transaction, i uint64, ready types.Transactions) bool {
	tx := txs[i]

	if g.IsApproveTx(tx) && i < uint64(math.MaxUint64) {
		return g.isApproveTxReady(tx, txs[i+1])
	}

	if g.IsSwapTx(tx) {
		var prevTx *types.Transaction
		if len(ready) > 0 {
			prevTx = ready[len(ready)-1]
		}
		return g.isSwapTxReady(tx, prevTx)
	}

	return false
}

// isApproveTxReady assumes that the caller checked `g.IsApproveTx(approveTx)`
func (g *GaslessModule) isApproveTxReady(approveTx, nextTx *types.Transaction) bool {
	addr, err := types.Sender(g.signer, approveTx)
	if err != nil {
		return false
	}
	nonce := g.getCurrentStateNonce(addr)

	if approveTx.Nonce() != nonce {
		return false
	}
	if nextTx == nil || !g.IsSwapTx(nextTx) {
		return false
	}

	return g.IsExecutable(approveTx, nextTx)
}

// isSwapTxReady assumes that the caller checked `g.IsSwapTx(swapTx)`
func (g *GaslessModule) isSwapTxReady(swapTx, prevTx *types.Transaction) bool {
	addr, err := types.Sender(g.signer, swapTx)
	if err != nil {
		return false
	}
	nonce := g.getCurrentStateNonce(addr)

	var approveTx *types.Transaction
	if swapTx.Nonce() == nonce {
		approveTx = nil
	} else if swapTx.Nonce() == nonce+1 {
		if prevTx == nil || !g.IsApproveTx(prevTx) {
			return false
		}
		approveTx = prevTx
	} else {
		return false
	}

	return g.IsExecutable(approveTx, swapTx)
}

// PreReset removes timed out tx from the tx pool and knownTxs.
func (g *GaslessModule) PreReset(oldHead, newHead *types.Header) []common.Hash {
	g.knownTxsMu.Lock()
	defer g.knownTxsMu.Unlock()

	drops := make([]common.Hash, 0)

	for hash, knownTx := range *g.knownTxs {
		// remove pending timed out tx from tx pool
		if knownTx.status == TxStatusPending && knownTx.elapsedPromotedTime() >= PendingTimeout {
			drops = append(drops, hash)
		}
		// remove queue timed out tx from tx pool
		if knownTx.status == TxStatusQueue && knownTx.elapsedAddedTime() >= QueueTimeout {
			drops = append(drops, hash)
		}
		// remove known timed out tx from knownTxs
		if knownTx.elapsedPromotedOrAddedTime() >= KnownTxTimeout {
			g.knownTxs.delete(hash)
		}
	}

	return drops
}

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
}
