### Title
Pointer Precompile Bypasses the Governance `RegisterPointerDisabled` Policy Gate - (File: precompiles/pointer/pointer.go)

### Summary
The `RegisterPointer` Cosmos message handler enforces a governance-controlled policy flag, `RegisterPointerDisabled`, before allowing any new CW↔ERC pointer to be created or migrated. The EVM-facing `pointer` precompile (`0x100b`), which reaches the exact same pointer-creation keeper functionality, never checks this flag. Any unprivileged EVM transaction sender can therefore keep registering native/CW20/CW721/CW1155 pointers through the precompile even after the chain operator/governance has disabled pointer registration.

### Finding Description
`x/evm/keeper/msg_server.go`'s `RegisterPointer` handler is explicitly gated by the param: [1](#0-0) 

This param exists specifically so operators/governance can permanently shut off pointer creation — there is a dedicated migration that flips it on: [2](#0-1) 

However, the `pointer` precompile's `Execute` dispatcher and its four handlers (`AddNative`, `AddCW20`, `AddCW721`, `AddCW1155`) — which call the same underlying `UpsertERCNativePointer` / `UpsertERCCW20Pointer` / `UpsertERCCW721Pointer` / `UpsertERCCW1155Pointer` keeper methods that back `RegisterPointer` — contain no reference to `RegisterPointerDisabled` at all: [3](#0-2) [4](#0-3) [5](#0-4) 

Only `readOnly`/`delegatecall` guards are enforced; the authorization/policy check ("is pointer registration currently allowed") that the Cosmos-message path enforces is entirely absent from the EVM precompile wrapper. This is structurally identical to the reported bug class: a policy/authorization check implemented in one install/action wrapper is skipped by an alternate, lower-trust-reachable wrapper that performs the same privileged action.

### Impact Explanation
Any EVM transaction sender (an unprivileged, public caller) can call `addNativePointer`, `addCW20Pointer`, `addCW721Pointer`, or `addCW1155Pointer` on the pointer precompile to create/upsert CW↔ERC pointer contracts regardless of the `RegisterPointerDisabled` governance flag. Because this flag is specifically used to freeze pointer creation chain-wide (per the dedicated `MigrateDisableRegisterPointer` migration), the precompile path completely defeats that governance decision. This lets a lower-trust caller persist state (new pointer contracts / pointer registry entries) that the chain operators/governance explicitly intended to be blocked, which can be leveraged to squat on or race pointer addresses for tokens/contracts after the feature was supposed to be locked down — undermining the integrity guarantee the flag was created to provide.

### Likelihood Explanation
High likelihood of exploitation once the flag is set: the precompile is on the standard public EVM JSON-RPC surface, reachable by any account with gas, requiring no special privileges — the only precondition is that `RegisterPointerDisabled` is set (the exact scenario the flag exists for).

### Recommendation
Add the same `if server.GetRegisterPointerDisabled(ctx) { return error }` (or an equivalent keeper-level check inside `UpsertERC*Pointer`) to `precompiles/pointer/pointer.go`'s `Execute`/`AddNative`/`AddCW20`/`AddCW721`/`AddCW1155` handlers, or move the check into the shared keeper `UpsertERC*Pointer` functions so both the Cosmos `MsgRegisterPointer` path and the EVM precompile path share one enforcement point.

### Proof of Concept
1. Governance/operator runs the `MigrateDisableRegisterPointer` upgrade handler, setting `params.RegisterPointerDisabled = true` [6](#0-5) .
2. Submitting `MsgRegisterPointer` via the Cosmos message path now correctly fails with `"registering CW->ERC pointers has been disabled"` [7](#0-6) .
3. Any EVM account instead calls the `pointer` precompile at `0x100b` with `addCW20Pointer(cwAddr)` (or `addNativePointer`/`addCW721Pointer`/`addCW1155Pointer`) in an ordinary transaction.
4. `PrecompileExecutor.Execute` dispatches straight to `AddCW20`, which queries the CW20 contract and calls `p.evmKeeper.UpsertERCCW20Pointer` with no `RegisterPointerDisabled` check anywhere in the call path [5](#0-4) , successfully creating a new pointer contract despite the flag being set.

func (p PrecompileExecutor) AddNative(ctx sdk.Context, method *ethabi.Method, caller common.Address, args []interface{}, value *big.Int, evm *vm.EVM, hooks *tracing.Hooks) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}
	if err := pcommon.ValidateArgsLength(args, 1); err != nil {
		return nil, 0, err
	}
	token := args[0].(string)
	metadata, metadataExists := p.bankKeeper.GetDenomMetaData(ctx, token)
	if !metadataExists {
		return nil, 0, fmt.Errorf("denom %s does not have metadata stored and thus can only have its pointer set through gov proposal", token)
	}
	name := metadata.Name
	symbol := metadata.Symbol
	var decimals uint8
	for _, denomUnit := range metadata.DenomUnits {
		if denomUnit.Exponent > uint32(decimals) && denomUnit.Exponent <= math.MaxUint8 {
			decimals = uint8(denomUnit.Exponent)
			name = denomUnit.Denom
			symbol = denomUnit.Denom
			if len(denomUnit.Aliases) > 0 {
				name = denomUnit.Aliases[0]
			}
		}
	}
	contractAddr, err := p.evmKeeper.UpsertERCNativePointer(ctx, evm, token, utils.ERCMetadata{Name: name, Symbol: symbol, Decimals: decimals})
	if err != nil {
		return nil, 0, err
	}

	ret, err = method.Outputs.Pack(contractAddr)
	remainingGas = pcommon.GetRemainingGas(ctx, p.evmKeeper)
	return
}

func (p PrecompileExecutor) AddCW20(ctx sdk.Context, method *ethabi.Method, caller common.Address, args []interface{}, value *big.Int, evm *vm.EVM, hooks *tracing.Hooks) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}
	if err := pcommon.ValidateArgsLength(args, 1); err != nil {
		return nil, 0, err
	}
	cwAddr := args[0].(string)
	cwAddress, err := sdk.AccAddressFromBech32(cwAddr)
	if err != nil {
		return nil, 0, err
	}
	res, err := p.wasmdKeeper.QuerySmartSafe(ctx, cwAddress, []byte("{\"token_info\":{}}"))
	if err != nil {
		return nil, 0, err
	}
	formattedRes := map[string]interface{}{}
	if err := json.Unmarshal(res, &formattedRes); err != nil {
		return nil, 0, err
	}
	name := formattedRes["name"].(string)
	symbol := formattedRes["symbol"].(string)
	contractAddr, err := p.evmKeeper.UpsertERCCW20Pointer(ctx, evm, cwAddr, utils.ERCMetadata{Name: name, Symbol: symbol})
	if err != nil {
		return nil, 0, err
	}

	ret, err = method.Outputs.Pack(contractAddr)
	remainingGas = pcommon.GetRemainingGas(ctx, p.evmKeeper)
	return
}
