### Title
Unchecked type assertion on attacker-controlled CosmWasm query response causes precompile panic - (File: `precompiles/pointer/pointer.go`)

### Summary
The `pointer` precompile's `AddCW20`, `AddCW721`, and `AddCW1155` handlers query an arbitrary, caller-supplied CosmWasm contract address and blindly type-assert the `name`/`symbol` fields of the JSON response as Go `string` without the safe `, ok` form, mirroring the RPyC class of bug where a trusted component invokes a well-known interface/attribute on attacker-supplied data without validating its type/shape first.

### Finding Description
`AddCW20`, `AddCW721`, and `AddCW1155` in [1](#0-0)  and [2](#0-1)  accept an arbitrary `cwAddr` string supplied by the EVM caller, run `p.wasmdKeeper.QuerySmartSafe(ctx, cwAddress, []byte("{\"token_info\":{}}"))` (or `contract_info`) against that address, unmarshal the JSON into `map[string]interface{}`, and then do:
```go
name := formattedRes["name"].(string)
symbol := formattedRes["symbol"].(string)
``` [3](#0-2) 
There is no ownership or shape validation of the target contract — any deployed CosmWasm contract, including one authored entirely by the attacker, can be pointed at. If the attacker's contract's `token_info`/`contract_info` query handler returns a JSON value for `name` or `symbol` that is not a string (e.g. a number, bool, array, object, or omits the field so the map lookup yields `nil`), the single-value type assertion panics instead of returning an error, because Go's `x.(T)` form panics on mismatch when the `, ok` form is not used.

This panic path bypasses the transaction's normal error handling: the dispatch entry point for dynamic-gas precompiles, `DynamicGasPrecompile.RunAndCalculateGas`, only wraps error normalization in its `defer`, and its only `recover()` is scoped narrowly to the gas-charging step in `chargeDecodeGas`, not to the `Execute` call itself. [4](#0-3) [5](#0-4)  Consequently a panic raised from `AddCW20`/`AddCW721`/`AddCW1155` propagates unrecovered out of the precompile dispatch layer.

### Impact Explanation
This is analogous to the RPyC issue in that a trusted execution context (the EVM/pointer precompile) invokes a fixed operation (type-coercing a field from a remote/untrusted response) without a security check on the untrusted data's actual shape, and the missing check turns attacker-controlled input into an uncontrolled fault in the trusted process. If this panic is not recovered anywhere further up the call stack (e.g., in the message handler / ante pipeline that ultimately invokes the EVM), it can crash the node process handling the transaction, which for a validator or default-configuration RPC node constitutes a liveness/availability issue (crash of a node, potential chain halt if it hits enough validators simultaneously via a broadcast transaction).

### Likelihood Explanation
Reachable by any unprivileged user: deploy a CosmWasm contract that responds to `token_info`/`contract_info` queries with non-string `name`/`symbol` fields, then call `addCW20Pointer`/`addCW721Pointer`/`addCW1155Pointer` on the `pointer` precompile (address `0x000000000000000000000000000000000000100b`) with that contract's address. This requires no special privileges beyond deploying a wasm contract and sending one EVM transaction.

### Recommendation
Replace the unchecked type assertions with the safe two-value form and return a proper error instead of panicking, e.g.:
```go
name, ok := formattedRes["name"].(string)
if !ok {
    return nil, 0, fmt.Errorf("invalid name field in contract response")
}
symbol, ok := formattedRes["symbol"].(string)
if !ok {
    return nil, 0, fmt.Errorf("invalid symbol field in contract response")
}
```
Apply the same fix across all versions (`precompiles/pointer/legacy/v605`, `v640`, `v65`, `v66`, and the current `precompiles/pointer/pointer.go`), and add a `recover()` guard around `Execute` invocation in `RunAndCalculateGas`/`Run` as defense in depth against any similar unchecked type assertions elsewhere in the precompile suite.

### Proof of Concept
1. Deploy a CosmWasm contract whose `QueryMsg::TokenInfo {}` (or `ContractInfo {}`) handler returns `{"name": 12345, "symbol": "X", ...}` (numeric `name` instead of string), or omits `name` entirely.
2. From an EVM account, call `addCW20Pointer(cwAddr)` (or the CW721/CW1155 equivalent) on precompile address `0x000000000000000000000000000000000000100b` with the malicious contract's Sei address.
3. Execution reaches `formattedRes["name"].(string)` in `AddCW20`, which panics because the underlying value is not a `string`.
4. Because `RunAndCalculateGas`'s `defer` does not `recover()` around `Execute`, the panic propagates out of the precompile call unhandled.

func (d DynamicGasPrecompile) RunAndCalculateGas(evm *vm.EVM, caller common.Address, callingContract common.Address, input []byte, suppliedGas uint64, value *big.Int, hooks *tracing.Hooks, readOnly bool, isFromDelegateCall bool) (ret []byte, remainingGas uint64, err error) {
	operation := fmt.Sprintf("%s_unknown", d.name)
	defer func() {
		HandlePrecompileError(err, evm, operation)
		if err != nil {
			fmt.Printf("precompile %s encountered error: %v\n", d.name, err)
			err = vm.ErrExecutionReverted
		}
	}()
	ctxer := state.GetDBImpl(evm.StateDB)
	if ctxer == nil {
		return nil, 0, errors.New("cannot get context from EVM")
	}
	// Resolve the target method from the 4-byte selector only. The argument
	// payload is intentionally NOT decoded yet: ABI decoding of attacker-
	// controlled calldata can cost far more than len(input) (a single string can
	// be referenced by many array/tuple slots), so it must be paid for out of the
	// gas the caller supplied. The static-precompile path charges RequiredGas in
	// vm.RunPrecompiledContract before running; that step is skipped for
	// dynamic-gas precompiles, so we apply the equivalent charge here.
	methodID, err := ExtractMethodID(input)
	if err != nil {
		return nil, 0, err
	}
	method, err := d.MethodById(methodID)
	if err != nil {
		return nil, 0, err
	}
	operation = method.Name

	ctx := ctxer.Ctx()
	// Install the gas meter derived from the supplied EVM gas, then charge for
	// decoding the calldata BEFORE decoding it. A call that cannot afford the
	// decode is rejected here, before the parse/allocation work is performed.
	// chargeDecodeGas scopes the out-of-gas recovery to just these charges, so an
	// executor that later exhausts its gas keeps its normal (propagating)
	// out-of-gas semantics.
	gasLimit := d.executor.EVMKeeper().GetCosmosGasLimitFromEVMGas(ctx.WithGasMeter(sdk.NewInfiniteGasMeterWithMultiplier(ctx)), suppliedGas)
	ctx = ctx.WithGasMeter(sdk.NewGasMeterWithMultiplier(ctx, gasLimit))
	if err = d.chargeDecodeGas(ctx, method, input); err != nil {
		return nil, 0, err
	}

	args, err := method.Inputs.Unpack(input[4:])
	if err != nil {
		return nil, 0, err
	}
	em := ctx.EventManager()
	ctx = ctx.WithEventManager(sdk.NewEventManager())
	ctx = ctx.WithEVMPrecompileCalledFromDelegateCall(isFromDelegateCall)
	ret, remainingGas, err = d.executor.Execute(ctx, method, caller, callingContract, args, value, readOnly, evm, suppliedGas, hooks)
	if err != nil {
		return ret, remainingGas, err
	}
	events := ctx.EventManager().Events()
	if len(events) > 0 {
		em.EmitEvents(ctx.EventManager().Events())
	}
	return ret, remainingGas, err
}

func (d DynamicGasPrecompile) chargeDecodeGas(ctx sdk.Context, method *abi.Method, input []byte) (err error) {
	defer func() {
		if r := recover(); r != nil {
			switch r.(type) {
			case sdk.ErrorOutOfGas, sdk.ErrorGasOverflow:
				err = fmt.Errorf("%v", r)
			default:
				panic(r)
			}
		}
	}()
	scanCost := DefaultGasCost(input, false)
	ctx.GasMeter().ConsumeGas(scanCost, fmt.Sprintf("%s precompile calldata scan", d.name))
	decodeCost, ok := DecodeGasCost(method.Inputs, input)
	if !ok {
		// Calldata is structurally invalid (Unpack would reject it too); reject
		// now, without attempting the decode.
		return fmt.Errorf("invalid calldata encoding for %s", d.name)
	}
	// DecodeGasCost already includes scanCost; charge only the remaining
	// (string-copy) portion so the decode is priced exactly once.
	ctx.GasMeter().ConsumeGas(decodeCost-scanCost, fmt.Sprintf("%s precompile calldata decode", d.name))
	return nil
}
