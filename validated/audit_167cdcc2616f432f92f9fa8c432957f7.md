### Title
Gasless swap admission relies on a stale, manipulable AMM spot-price check that is never re-validated before the unconditional gas-fee lend is executed - ([File: kaiax/gasless/impl/tx_pool.go])

### Summary
The Hegic report's bug class is: a protocol values a user-supplied position using a live/spot AMM price read at one point in time, and that value is used to authorize a large financial commitment (borrowing) without ever re-checking the price against the value actually realized, letting the attacker manipulate the spot price around the check to extract undercollateralized value. The Kaia `kaiax/gasless` module (KIP-247) has an analogous split-check pattern: sufficiency of a gasless swap is verified with a live-AMM spot price query at tx-pool admission time, but the value transfer that depends on that swap succeeding (the proposer-funded "lend" of gas fee) is authorized separately and is not re-validated against the swap's actual on-chain execution outcome.

### Finding Description
`GaslessModule.checkBalanceForSwap` is the only place that checks a `GaslessSwapTx` is economically sound: it calls the swap router's `GetAmountIn(token, minAmountOut)` — described in-code as "the current exchange rate" (a live spot query) — and rejects the tx only if `AmountIn < requiredAmountIn` at that instant: [1](#0-0) 

This check is wired in only through `GetCheckBalance`, which is invoked when a tx is admitted to the pool: [2](#0-1) 

However, the function that actually gates whether a `GaslessTx` bundle is built and its `LendTx` (block proposer fronting the KAIA gas fee to the sender) is generated — `VerifyExecutable`/`IsExecutable`, used by both `IsReady` (promotion) and `ExtractTxBundles` (block building) — never re-invokes the spot-price/balance check. It only re-verifies static structural conditions (sender match, token match, approved amount, nonce ordering, declared repay amount arithmetic): [3](#0-2) 

The `LendTx` itself unconditionally transfers `lendAmount` (the gas fee) from the proposer's key to the swap sender, with no dependency on the swap's eventual success or on-chain AMM state at execution time: [4](#0-3) 

Because the only economic soundness check (`checkBalanceForSwap`'s `GetAmountIn` spot-price query) runs once at pool-admission time and is not repeated at bundle-build/execution time, an attacker can:
1. Submit an `ApproveTx`+`SwapTx` pair when the AMM spot price makes `AmountIn >= requiredAmountIn`, passing `checkBalanceForSwap`.
2. Manipulate the swap router's underlying AMM spot price (a normal DEX swap) between admission and the block in which the bundle is finally built/executed (transactions can sit in the pool for up to `PendingTimeout`/`QueueTimeout` — up to 10s — per [5](#0-4) ), or via a same-block preceding transaction.
3. When the bundle finally executes, `LendTx` (unconditional transfer) still lands and pays out the proposer's KAIA to the sender. If the manipulated price causes the actual `swapForGas` call to no longer meet `minAmountOut`/`amountRepay` (and thus revert, or repay less than intended), the sender keeps the lent KAIA without the proposer being made whole, because nothing ties `LendTx`'s success to `SwapTx`'s actual settlement outcome beyond independent EVM transaction ordering within the same block.

This mirrors the SharwaMarginTrading root cause precisely: a single spot-price read is trusted to authorize a value transfer, and the same protocol never re-derives/re-checks that price against the real settlement, so the check can be satisfied by a transient, attacker-controlled price that no longer holds by the time value actually moves.

### Impact Explanation
If the bundle-inclusion guarantee is not perfectly atomic (i.e., if `LendTx`'s success is not strictly conditioned on `SwapTx` fully succeeding and repaying `amountRepay`), this allows an unprivileged gasless-tx sender to have the block proposer front real KAIA that is never repaid — a direct fee-delegation/gasless-lending theft, matching the "gasless... settlement theft" category explicitly listed as in-scope impact. Even in the best case where bundle atomicity exists, the reliance on a bare spot-price call with no staleness/re-validation is the architectural analog of the reported bug class and represents unnecessary residual risk for a value-transferring subsystem.

### Likelihood Explanation
Reachable entirely from a public, unprivileged actor: any address can submit an `ApproveTx`/`SwapTx` gasless pair and can also submit ordinary swap transactions against the same AMM pool used by the `GaslessSwapRouter` to move its spot price, since `GetAmountIn` reflects live reserves. No special privilege, node access, or governance role is required — only normal transaction submission capability, which satisfies the "unprivileged transaction sender" reachability requirement.

### Recommendation
- Re-validate `checkBalanceForSwap` (or an equivalent spot-price/repay sufficiency check) immediately before/at the point `LendTx` is generated in `GetLendTxGenerator`/`ExtractTxBundles`, using the state at the block currently being built, not only at pool-admission time.
- Make `LendTx`'s payout conditional on (or atomically bundled with, with proposer-side reimbursement/rollback guarantees) the `SwapTx` succeeding and transferring at least `amountRepay` back to the proposer; do not treat structural checks in `VerifyExecutable` as sufficient proxies for economic soundness.
- Consider requiring the router to use a manipulation-resistant price reference (e.g., TWAP or a minimum-liquidity/slippage bound enforced on-chain at `swapForGas` execution time) rather than trusting a spot `GetAmountIn` at admission.

### Proof of Concept
Not independently reproducible from the indexed Go/node code alone, since the `GaslessSwapRouter`'s Solidity implementation (its `swapForGas`/`getAmountIn` internal accounting) is not present in the indexed repository content — only its ABI bindings are available (`contracts/bindings/kip247/GaslessSwapRouter.go`). The reachable path (submit approve+swap gasless pair → manipulate AMM spot price before block inclusion → LendTx pays out regardless) is demonstrated structurally via the cited `checkBalanceForSwap`, `VerifyExecutable`, and `GetLendTxGenerator` code, but confirming whether bundle inclusion is fully atomic (blocking `LendTx` if `SwapTx` reverts) would require inspecting the block-builder's bundle-simulation/inclusion logic, which was not available within the remaining investigation budget. This should be verified in a full checkout before treating the impact as fully confirmed.

func (g *GaslessModule) GetCheckBalance() func(tx *types.Transaction) error {
	return func(tx *types.Transaction) error {
		if approveArgs, ok := decodeApproveTx(tx, g.signer); ok {
			return g.checkBalanceForApprove(approveArgs)
		}
		if swapArgs, ok := decodeSwapTx(tx, g.signer); ok {
			return g.checkBalanceForSwap(swapArgs, tx.Nonce())
		}
		return errors.New("not a gasless transaction") // should not happen because IsModuleTx is called before GetCheckBalance
	}
}

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

// MakeLendTx creates a transaction with following properties:
// L1. LendTx.type = 0x7802 (TxTypeEthereumDynamicFee)
// L2. LendTx.from = proposer
// L3. LendTx.to = SwapTx.from
// L4. LendTx.value = LendAmount(approveTxOrNil, swapTx)
func (g *GaslessModule) GetLendTxGenerator(approveTxOrNil, swapTx *types.Transaction) *builder.TxOrGen {
	var src []byte
	if approveTxOrNil != nil {
		src = append(src, approveTxOrNil.Hash().Bytes()...)
	}
	src = append(src, swapTx.Hash().Bytes()...)
	bundleHash := crypto.Keccak256Hash(src)

	gen := func(nonce uint64) (*types.Transaction, error) {
		var (
			chainId = g.InitOpts.ChainConfig.ChainID
			signer  = types.LatestSignerForChainID(chainId)
			key     = g.InitOpts.NodeKey
		)

		to, err := types.Sender(signer, swapTx)
		if err != nil {
			return nil, err
		}

		tx, err := types.NewTransactionWithMap(types.TxTypeEthereumDynamicFee, map[types.TxValueKeyType]interface{}{
			types.TxValueKeyNonce:      nonce,
			types.TxValueKeyTo:         &to,
			types.TxValueKeyAmount:     lendAmount(approveTxOrNil, swapTx),
			types.TxValueKeyData:       common.Hex2Bytes("0x"),
			types.TxValueKeyGasLimit:   params.TxGas,
			types.TxValueKeyGasFeeCap:  swapTx.GasFeeCap(),
			types.TxValueKeyGasTipCap:  swapTx.GasTipCap(),
			types.TxValueKeyAccessList: types.AccessList{},
			types.TxValueKeyChainID:    chainId,
		})
		if err != nil {
			return nil, err
		}

		err = tx.Sign(signer, key)
		return tx, err
	}

	return builder.NewTxOrGenFromGen(gen, bundleHash)
}
