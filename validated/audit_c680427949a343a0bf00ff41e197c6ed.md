## Finding [1](#0-0) 

The `json` precompile at address `0x0000000000000000000000000000000000001003` decodes attacker-controlled EVM calldata with Go's standard `encoding/json` (locally aliased `gjson`) directly into `map[string]json.RawMessage` / `[]json.RawMessage`: [2](#0-1) [3](#0-2) 

### Title
Unbounded-recursion JSON decode in the `json` precompile causes node-crashing stack exhaustion - (File: `precompiles/json/json.go`)

### Summary
`extractAsBytes`, `extractAsBytesList`, `ExtractAsUint256`, and `extractAsBytesFromArray` all call `gjson.Unmarshal` (Go's `encoding/json`) on the raw `body` bytes supplied as an EVM precompile argument, with no bound on JSON nesting depth. Go's `encoding/json` decoder walks nested arrays/objects with a recursive descent parser even when decoding into `json.RawMessage`, because it must still find the matching closing bracket for every nested value. A calldata payload consisting of deeply nested arrays (e.g. `[[[[...]]]]`) forces recursion depth proportional to nesting depth, which is only ~2 bytes per level, so a multi‑megabyte payload can drive the decoder millions of levels deep.

### Finding Description
- Gas metering for this precompile is a flat `GasCostPerByte * len(payload)` charge computed once up front in `Execute`, proportional only to payload length, not to nesting depth or decode work: [4](#0-3) 
- There is no depth check anywhere in the precompile before calling `gjson.Unmarshal`, unlike the ABI gas-estimation walker in `precompiles/common/decode_cost.go`, which explicitly caps traversal via `maxDecodeWalkOps` for exactly this class of risk: [5](#0-4) 
- Unlike several other precompiles (`addr`, `solo`, `wasmd`) whose `Execute`/`execute` methods install a `recover()` to convert panics into reverts, `PrecompileExecutor.Execute` in `precompiles/json/json.go` has no such recover: [6](#0-5)  Compare with the pattern used elsewhere: [7](#0-6) 
- Even where `recover()` is present, it cannot catch a genuine Go runtime stack-overflow fatal error (`runtime: goroutine stack exceeds … limit`), which terminates the whole process rather than raising a recoverable panic.
- The same unguarded pattern is repeated in every historical/legacy version of the JSON precompile (`v552`…`v67`), so the exposure spans the precompile's entire history, e.g. [8](#0-7) 

### Impact Explanation
This precompile is reachable by any unprivileged EVM transaction sender or contract making a `CALL`/`STATICCALL` to `0x1003` with attacker-chosen calldata. A specially crafted deeply-nested JSON payload passed as the `body` argument can drive `encoding/json`'s recursive parser to a stack depth sufficient to trigger a fatal, unrecoverable Go runtime stack-overflow, crashing the node process executing the transaction — this applies uniformly to validators applying the block and to full/RPC nodes replaying or simulating it (e.g. via `eth_call`/`eth_estimateGas`), producing a validator halt / RPC node crash and potentially a chain-wide denial of service if enough validators process the same transaction deterministically.

### Likelihood Explanation
The bug is trivially triggerable: any address can send a normal EVM transaction (or make an internal call from a contract) invoking `extractAsBytes`/`extractAsBytesList`/`extractAsBytesFromArray`/`extractAsUint256` with a deeply nested JSON body, well within the mempool's `max-tx-bytes` allowance (`20485760` bytes in the shipped node configs), which is more than enough calldata to reach recursion depths that exhaust a goroutine's stack. No special privileges, precompile allowlisting, or governance action are required.

### Recommendation
Enforce a maximum JSON nesting depth (and/or use an iterative/bounded-depth JSON scanner) before or during `gjson.Unmarshal` calls in `precompiles/json/json.go` (and its legacy variants), mirroring the `maxDecodeWalkOps` defensive cap already used in `precompiles/common/decode_cost.go`, and price/reject payloads whose structural depth exceeds the bound rather than only capping by flat byte length. Wrapping `Execute` with a `recover()` (as done in `addr`, `solo`, `wasmd`) is a partial mitigation for ordinary panics but does not address true stack-overflow fatal errors, so a hard depth limit is required.

### Proof of Concept
1. Construct calldata for `json.extractAsBytesFromArray(bytes body, uint16 index)` where `body` is `N` repetitions of `[` followed by `N` repetitions of `]` (e.g. `N ≈ 5,000,000`, ~10 MB, under the ~20 MB tx size cap).
2. Submit this as calldata to the `json` precompile address `0x0000000000000000000000000000000000001003` via a normal `eth_sendRawTransaction`/`eth_call`.
3. `gjson.Unmarshal(bz, &decoded)` in `extractAsBytesFromArray` (`precompiles/json/json.go` lines 213-216) recurses once per array nesting level while scanning for the matching `]`, driving the goroutine stack to the runtime limit and crashing the node process with a fatal, unrecoverable error before the flat per-byte gas charge in `Execute` (line 79) provides any throttling based on actual work performed.

func (p PrecompileExecutor) Execute(ctx sdk.Context, method *abi.Method, caller common.Address, callingContract common.Address, args []interface{}, value *big.Int, readOnly bool, evm *vm.EVM, suppliedGas uint64, hooks *tracing.Hooks) (bz []byte, remainingGas uint64, err error) {
	// The precompile is stateless (in-memory JSON parsing), so no gas would be
	// charged via state access. Charge for the parse work up front, proportional
	// to the payload being parsed (args[0]); this is the dominant cost of every
	// method below.
	if len(args) > 0 {
		if payload, ok := args[0].([]byte); ok {
			ctx.GasMeter().ConsumeGas(uint64(GasCostPerByte*len(payload)), "json parse") //nolint:gosec
		}
	}

	switch method.Name {
	case ExtractAsBytesMethod:
		bz, err = p.extractAsBytes(ctx, method, args, value)
	case ExtractAsBytesListMethod:
		bz, err = p.extractAsBytesList(ctx, method, args, value)
	case ExtractAsUint256Method:
		var uint_ *big.Int
		if uint_, err = p.ExtractAsUint256(ctx, method, args, value); err == nil {
			if uint_.BitLen() > 256 {
				err = errors.New("value does not fit in 32 bytes")
			} else {
				byteArr := make([]byte, 32)
				uint_.FillBytes(byteArr)
				bz = byteArr
			}
		}
	case ExtractAsBytesFromArrayMethod:
		bz, err = p.extractAsBytesFromArray(ctx, method, args, value)
	}
	if err != nil {
		return nil, 0, err
	}
	return bz, pcommon.GetRemainingGas(ctx, p.evmKeeper), nil
}

func (p PrecompileExecutor) extractAsBytes(_ sdk.Context, method *abi.Method, args []interface{}, value *big.Int) ([]byte, error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, err
	}

	if err := pcommon.ValidateArgsLength(args, 2); err != nil {
		return nil, err
	}

	// type assertion will always succeed because it's already validated in p.Prepare call in Run()
	bz := args[0].([]byte)
	decoded := map[string]gjson.RawMessage{}
	if err := gjson.Unmarshal(bz, &decoded); err != nil {
		return nil, err
	}
	key := args[1].(string)
	result, ok := decoded[key]
	if !ok {
		return nil, fmt.Errorf("input does not contain key %s", key)
	}
	// in the case of a string value, remove the quotes
	if len(result) >= 2 && result[0] == '"' && result[len(result)-1] == '"' {
		result = result[1 : len(result)-1]
	}

	return method.Outputs.Pack([]byte(result))
}

func (p PrecompileExecutor) extractAsBytesFromArray(_ sdk.Context, method *abi.Method, args []interface{}, value *big.Int) ([]byte, error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, err
	}

	if err := pcommon.ValidateArgsLength(args, 2); err != nil {
		return nil, err
	}

	// type assertion will always succeed because it's already validated in p.Prepare call in Run()
	bz := args[0].([]byte)
	var decoded []gjson.RawMessage
	if err := gjson.Unmarshal(bz, &decoded); err != nil {
		return nil, err
	}
	if len(decoded) > 1<<16 {
		return nil, errors.New("input array is larger than 2^16")
	}
	index, ok := args[1].(uint16)
	if !ok {
		return nil, errors.New("index must be uint16")
	}
	if int(index) >= len(decoded) {
		return nil, fmt.Errorf("index %d is out of bounds", index)
	}
	result := decoded[index]

	// in the case of a string value, remove the quotes
	if len(result) >= 2 && result[0] == '"' && result[len(result)-1] == '"' {
		result = result[1 : len(result)-1]
	}

	return method.Outputs.Pack([]byte(result))
}
