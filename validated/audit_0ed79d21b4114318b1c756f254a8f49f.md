### Title
Front-run/flash-stake before `harvestAll()` dilutes earlier voters' unclaimed bribe rewards in `DelegateVoteRewardPool` - (File: rewards/DelegateVoteRewardPool.sol)

### Summary
`DelegateVoteRewardPool` distributes harvested bribe rewards as a lump-sum increment to `rewardPerTokenStored`, divided by `totalSupply` at the moment `harvestAll()` executes [1](#0-0) . Because voting (`vote()` → `stakeFor`) instantly increases `totalSupply`/`_balances` with no cooldown or time-weighting, an attacker can vote into `delegatedPool` immediately before a pending `harvestAll()`/`castVotes()` transaction and claim a pro-rata share of rewards that accrued entirely before their deposit.

### Finding Description
`getReward` and `harvestAll` are both unrestricted public/external functions [2](#0-1) . Staking into the pool happens through `WombatBribeManager.vote()`, which any vlMGP holder can call permissionlessly to increase their `userVotedForPoolInVlmgp[msg.sender][delegatedPool]` and call `stakeFor` on the rewarder [3](#0-2) . `stakeFor` runs the `updateRewards` modifier which snapshots `userRewardPerTokenPaid` at the *current* `rewardPerTokenStored` before crediting the new balance [4](#0-3) , so the newly staked amount begins participating in *all future* reward-per-token increases despite having accrued zero time in the pool.

`harvestAll()` pulls the bribes that `delegatedPool` (this contract, acting as a single voter proxy) has accrued in the underlying per-LP `BribeRewardPool`s since the last harvest, via `WombatBribeManager.claimAllBribes(address(this))` [5](#0-4)  and [6](#0-5) . That harvested amount is a fixed pot determined by prior voting history in the underlying pools — it is independent of `DelegateVoteRewardPool`'s own `totalSupply` at harvest time. `_queueNewRewardsWithoutTransfer` then divides this pot by `totalSupply` *at the moment of the call* to compute the `rewardPerTokenStored` increment [7](#0-6) .

Consequently, any address can:
1. Call `vote(delegatedPool, +X)` right before a pending `harvestAll()`/`castVotes()` transaction is mined (mempool front-running), instantly inflating `totalSupply` and their own `_balances`.
2. Let `harvestAll()` execute (callable by anyone, or as part of `castVotes()`), which distributes the pre-accrued bribe pot across the now-inflated `totalSupply`.
3. Call `getReward(attacker)` to claim a share of the pot proportional to `X / totalSupply_after`, even though `X` was staked for zero time during the accrual period.

No modifier, cooldown, or checkpoint prevents this: `updateRewards` only protects per-user accounting correctness, not the fairness of the lump-sum distribution across stake duration. This dilutes the earned-but-unclaimed rewards of voters who held their position throughout the accrual window, transferring value to the newly-deposited attacker.

### Impact Explanation
This is a theft of unclaimed yield: pre-existing `delegatedPool` voters lose a portion of bribe rewards that economically belong to them (accrued proportional to their stake over time), which is instead captured by an attacker who deposits capital for a single block/transaction window. This matches the "theft or permanent freezing of unclaimed yield" impact class.

### Likelihood Explanation
- Preconditions: attacker only needs vlMGP that is votable (already lockable/purchasable by any user) and the ability to submit a transaction — no privileged role required.
- The attack is repeatable every time `harvestAll()`/`castVotes()` is triggered (whether by the attacker themselves or by front-running someone else's pending harvest transaction in the mempool).
- Capital is only needed transiently (can be withdrawn immediately after via `unvote()`, since no lock/cooldown was found on vote deltas in `WombatBribeManager.vote`/`unvote`), making this a low-cost, high-repeatability MEV-style extraction.
- Feasibility is high on any chain with a public mempool; even without front-running, the attacker gains a strictly positive expected value merely by depositing right before any expected harvest.

### Recommendation
Remove the incentive to flash-stake before a harvest:
- Checkpoint/settle pending external bribes (call the equivalent of `harvestAll()`'s internal logic) as part of `stakeFor`/`vote`, before `totalSupply` is increased, so that new deposits cannot capture rewards accrued prior to their entry, or
- Introduce continuous/time-weighted reward accrual (e.g., accrue `rewardPerTokenStored` based on elapsed time and a reward rate rather than an instantaneous lump-sum divide), or
- Add a minimum holding/vesting period before newly staked vote-weight becomes eligible for reward distribution (e.g., only count balances that existed as of the last harvest checkpoint when computing that harvest's distribution).

### Proof of Concept
Foundry test plan:
1. Deploy `DelegateVoteRewardPool`, `WombatBribeManager`, mock `IWombatBribeManager`/underlying `BribeRewardPool`, and mock reward token; set `delegatedPool`.
2. Let "Voter A" call `vote(delegatedPool, +100e18)` and hold for N blocks/time while bribes accrue in the underlying pool for `delegatedPool`'s vote.
3. Just before calling `harvestAll()` (simulate mempool front-run), have "Attacker" call `vote(delegatedPool, +100e18)` (doubling `totalSupply`).
4. Call `harvestAll()`, which pulls the fixed accrued bribe pot `P` and increments `rewardPerTokenStored` based on `totalSupply = 200e18`.
5. Call `getReward(attacker)` and `getReward(voterA)`, and assert:
   - `attackerReward ≈ P/2` even though attacker staked for 0 elapsed time,
   - `voterAReward ≈ P/2`, less than the `P` they should have received had `totalSupply` remained `100e18` during accrual,
   - Delta measured via `earned()` calls before/after `harvestAll()` shows attacker capturing reward growth attributable entirely to the pre-deposit accrual period.
6. Optionally show attacker can `unvote()` immediately after `getReward()` to fully recover principal, completing a risk-free extraction.

    function _queueNewRewardsWithoutTransfer(
        uint256 _amountReward,
        address _rewardToken
    ) internal {
        if (!isRewardToken[_rewardToken]) {
            rewardTokens.push(_rewardToken);
            isRewardToken[_rewardToken] = true;
        }
        Reward storage rewardInfo = rewards[_rewardToken];
        rewardInfo.historicalRewards =
            rewardInfo.historicalRewards +
            _amountReward;
        if (totalSupply == 0) {
            rewardInfo.queuedRewards += _amountReward;
        } else {
            if (rewardInfo.queuedRewards > 0) {
                _amountReward += rewardInfo.queuedRewards;
                rewardInfo.queuedRewards = 0;
            }
            rewardInfo.rewardPerTokenStored =
                rewardInfo.rewardPerTokenStored +
                (_amountReward * 10 ** this.stakingDecimals()) /
                totalSupply;
        }
        emit RewardAdded(_amountReward, _rewardToken);
    }

    function vote(address[] calldata _lps, int256[] calldata _deltas) override public {
        if (_lps.length != _deltas.length)
            revert LengthMismatch();

        uint256 length = _lps.length;
        int256 totalUserVote;

        for (uint256 i; i < length; i++) {
            Pool storage pool = poolInfos[_lps[i]];
            if (!pool.isActive)
                revert PoolNotActive();
            int256 delta = _deltas[i];
            totalUserVote += delta;
            if (delta != 0) {
                if (delta > 0) {
                    pool.totalVoteInVlmgp += uint256(delta);
                    userVotedForPoolInVlmgp[msg.sender][pool.poolAddress] += uint256(delta);
                    IBribeRewardPool(pool.rewarder).stakeFor(msg.sender, uint256(delta));
                } else {
                    pool.totalVoteInVlmgp -= uint256(-delta);
                    userVotedForPoolInVlmgp[msg.sender][pool.poolAddress] -= uint256(-delta);
                    IBribeRewardPool(pool.rewarder).withdrawFor(msg.sender, uint256(-delta), false);
                }
            }
        }

        if (msg.sender != delegatedPool) {
            if (totalUserVote > 0) {
                userTotalVotedInVlmgp[msg.sender] += uint256(totalUserVote);
                totalVlMgpInVote += uint256(totalUserVote);
            } else {
                userTotalVotedInVlmgp[msg.sender] -= uint256(-totalUserVote);
                totalVlMgpInVote -= uint256(-totalUserVote);
            }
        }

        if (userTotalVotedInVlmgp[msg.sender] > getUserVotable(msg.sender))
            revert NotEnoughVote();
    }

    function claimAllBribes(address _for)
        override public
        returns (address[] memory rewardTokens, uint256[] memory earnedRewards)
    {
        address[] memory delegatePoolRewardTokens;
        uint256[] memory delegatePoolRewardAmounts;
        if (userVotedForPoolInVlmgp[_for][delegatedPool] > 0) {
            (delegatePoolRewardTokens, delegatePoolRewardAmounts) = IDelegateVoteRewardPool(delegatedPool)
                .getReward(_for);
        }

        uint256 length = pools.length;
        rewardTokens = new address[](length + delegatePoolRewardTokens.length);
        earnedRewards = new uint256[](length + delegatePoolRewardTokens.length);

        for (uint256 i; i < length; i++) {
            Pool storage pool = poolInfos[pools[i]];
            address lp = pool.poolAddress;
            address bribesContract = address(voter.infos(lp).bribe);
            if (bribesContract != address(0)) {
                rewardTokens[i] = address(IWombatBribe(bribesContract).rewardTokens()[0]);
                // skip the which pool not in voting to save gas
                if (userVotedForPoolInVlmgp[_for][lp] > 0) {
                    earnedRewards[i] = IBribeRewardPool(pool.rewarder).earned(_for, rewardTokens[i]);
                    if (earnedRewards[i] > 0) {
                        IBribeRewardPool(pool.rewarder).getReward(_for, _for);
                    }
                }
            }
        }

        uint256 delegatePoolRewardsLength = delegatePoolRewardTokens.length;
        for (uint256 i = length; i < length + delegatePoolRewardsLength; i++) {
            rewardTokens[i] = delegatePoolRewardTokens[i - length];
            earnedRewards[i] = delegatePoolRewardAmounts[i - length];
        }
    }
