Confirmed: header governance's `checkConsistency()` in `kaiax/gov/headergov/impl/header.go` enforces `LowerBoundBaseFee <= UpperBoundBaseFee` when votes are cast via header (block-proposer) voting, but this cross-field consistency check is entirely absent from the contract-governance (`contractgov`) path — a `grep` for `LowerBoundBaseFee`/`UpperBoundBaseFee` in `kaiax/gov/contractgov/**` returned no matches. The `contractGovModule.GetParamSet()` in `kaiax/gov/contractgov/impl/getter.go` blindly applies every on-chain parameter via `ret.Set(k, v)` [1](#0-0)  with no bounds/consistency validation, and the per-parameter `FormatChecker` for `Kip71LowerBoundBaseFee`/`Kip71UpperBoundBaseFee` is a `noopFormatChecker` that always returns true [2](#0-1) .

### Title
Unbounded KIP-71 base fee governance parameters via GovParam contract enable permanent transaction-inclusion denial-of-service - (File: kaiax/gov/contractgov/impl/getter.go)

### Summary
The `FixedInterestRateModel` bug allowed an owner to set an interest rate so high that `UToken.borrowRatePerBlock()`'s "absurdly high" guard would revert every `repayBorrow` call, permanently freezing borrower funds until the owner chose to lower it again. Kaia's `kaiax/gov` module has the structurally identical flaw for the KIP-71 base-fee bounds (`LowerBoundBaseFee`, `UpperBoundBaseFee`) when set through the on-chain `GovParam` contract governance path, instead of the header-vote path.

### Finding Description
Governance parameters in Kaia are aggregated from two sources with different validation guarantees:
- **Header governance** (`kaiax/gov/headergov`): votes go through `VerifyVote` → `checkConsistency()`, which explicitly rejects a `Kip71LowerBoundBaseFee` vote greater than the current `UpperBoundBaseFee`, and vice versa [3](#0-2) .
- **Contract governance** (`kaiax/gov/contractgov`): parameters read from the `GovParam` contract are applied without any such cross-field check. `GetParamSet()` simply iterates the contract's raw map and calls `ParamSet.Set(k, v)` for each entry [1](#0-0) , and `ParamSet.Set()` performs only a type assertion, not a range/consistency check [4](#0-3) . The parameter table's `FormatChecker` for both `Kip71LowerBoundBaseFee` and `Kip71UpperBoundBaseFee` is `noopFormatChecker`, which unconditionally returns `true` [2](#0-1) .

Once merged into the effective `ParamSet` (post-Kore, contract governance is merged on top of header governance: `GetParamSet` merges Fallback → HeaderGov → ContractGov [5](#0-4) ), these unchecked values become `params.KIP71Config.LowerBoundBaseFee`/`UpperBoundBaseFee`, which directly drive `NextMagmaBlockBaseFee()` [6](#0-5) . If `LowerBoundBaseFee > UpperBoundBaseFee` (or `LowerBoundBaseFee` is set to an extremely large value), the computed base fee is clamped to the (nonsensical) bound, and every subsequent block's `baseFee` becomes that extreme value.

### Impact Explanation
`tx_pool.go`'s `validateTx()` rejects any transaction whose `gasPrice`/`gasFeeCap` is below `pool.gasPrice` (the current base fee) once Magma is active [7](#0-6) , and `state_transition.go`'s `preCheck()` likewise rejects a tx whose `GasFeeCap` is below `BaseFee` [8](#0-7) . If the base fee is pushed to an absurdly high value (e.g., near `uint64` max) via an unchecked `GovParam` contract update, no ordinary account can afford `gas * baseFee`, so essentially all normal transactions (including fee-delegated transactions, gasless relays, and auction settlement transactions) are rejected from the pool and from block inclusion — a chain-wide transaction-inclusion denial-of-service, exactly analogous to the original "repay disabled" scenario, but affecting the entire network rather than a single UToken market. This can also be used adversarially by the party controlling the `GovParam` contract to freeze the network's transaction throughput and later relax the bound, extracting value from anyone forced to wait or pay according to the attacker's timeline.

### Likelihood Explanation
This requires control of the on-chain `GovParam` contract (the same actor class the report treats as "governance parameters," an explicitly allowed analog in scope). Given the header-vote code path clearly demonstrates the developers know this consistency invariant must hold (`ErrLowerBoundBaseFee`/`ErrUpperBoundBaseFee` in `kaiax/gov/headergov/impl/error.go`), the omission of the equivalent check on the contract-governance path is very likely an oversight rather than an intentional trust boundary, making this a realistic, low-complexity path once the actor can write to `GovParam`.

### Recommendation
Enforce the same `LowerBoundBaseFee <= UpperBoundBaseFee` (and sane absolute bounds) invariant uniformly wherever KIP-71 parameters are ingested — either in `ParamSet.Set`/`Params[...].FormatChecker` (replacing `noopFormatChecker` for `Kip71LowerBoundBaseFee`/`Kip71UpperBoundBaseFee` with a check against the current param set, mirroring `checkConsistency()`), or by validating in `contractGovModule.GetParamSet()` before merging contract-sourced values into the effective `ParamSet`.

### Proof of Concept
1. An actor controlling the `GovParam` contract (`governance.govparamcontract`) sets `kip71.lowerboundbasefee` to a very large `uint64` value (e.g., `2^63`) with no accompanying update to `kip71.upperboundbasefee`.
2. After the Kore hardfork, `GovModule.GetParamSet()` merges this contract-governance value on top of header governance without any bounds check [9](#0-8) .
3. `NextMagmaBlockBaseFee()` computes/clamps the next block's `baseFee` using this inconsistent `LowerBoundBaseFee`/`UpperBoundBaseFee` pair [10](#0-9) , producing an extreme base fee.
4. From this point, `TxPool.validateTx()` rejects nearly all incoming transactions for having `gasFeeCap`/`gasPrice` below the new `pool.gasPrice` [7](#0-6) , and any transaction that does reach `StateTransition.preCheck()` fails the `GasFeeCap < BaseFee` check [8](#0-7) , halting normal transaction processing network-wide until the `GovParam` contract owner reverses the change.

func (m *GovModule) GetParamSet(blockNum uint64) gov.ParamSet {
	ret := gov.GetDefaultGovernanceParamSet()

	p0 := m.Fallback
	for k, v := range p0 {
		err := ret.Set(k, v)
		if err != nil {
			logger.CritWithStack("Failed to add param from Fallback", "name", k, "value", v, "error", err)
		}
	}

	p1 := m.Hgm.GetPartialParamSet(blockNum)
	for k, v := range p1 {
		err := ret.Set(k, v)
		if err != nil {
			logger.CritWithStack("Failed to add param from HeaderGov", "name", k, "value", v, "error", err)
		}
	}

	if m.isKoreHF(blockNum) {
		p2 := m.Cgm.GetPartialParamSet(blockNum)
		for k, v := range p2 {
			err := ret.Set(k, v)
			if err != nil {
				logger.CritWithStack("Failed to add param from ContractGov", "name", k, "value", v, "error", err)
			}
		}
	}

	return *ret
}

	lowerBoundBaseFee := new(big.Int).SetUint64(kc.LowerBoundBaseFee)
	upperBoundBaseFee := new(big.Int).SetUint64(kc.UpperBoundBaseFee)
	makeEvenByCeil(lowerBoundBaseFee)
	makeEvenByFloor(upperBoundBaseFee)

	if parentHeaderNumber.Cmp(new(big.Int).SetUint64(0)) == 0 || parentHeaderBaseFee == nil {
		return makeEvenByFloor(lowerBoundBaseFee)
	}
