### Title
Gasless swap balance/allowance checks are TOCTOU-vulnerable, letting a sender drain a proposer's lent gas fee - (File: kaiax/gasless/impl/tx_pool.go, kaiax/gasless/impl/builder.go)

### Summary
The Astera report flags that `executeMiniPoolBorrow` skips checks (reserve frozen/borrowable) that are performed elsewhere in the normal flow, allowing state to be assumed valid when it isn't. Kaia's `gasless` module has an analogous "checked here, trusted later" pattern: token balance/allowance sufficiency for a `GaslessSwapTx` is validated once at tx-pool admission time via `GetCheckBalance()`/`checkBalanceForSwap` [1](#0-0) , but the block builder unconditionally prepends a `LendTx` that pays out KAIA from the block proposer to the sender before the swap is re-verified against current state at execution time [2](#0-1) .

### Finding Description
`ExtractTxBundles` builds a bundle `[LendTx, ApproveTx?, SwapTx]` for every pending swap tx that satisfied `IsExecutable` at the point it was accepted into the pool, and generates a `LendTx` that unconditionally transfers `lendAmount(...)` of native KAIA from the proposer's key to the sender [3](#0-2) . This `LendTx` is placed first in the bundle, ahead of the actual swap transaction [4](#0-3) .

The balance/allowance sufficiency guarantee that is supposed to make the loan safe (`tx.token.allowance(sender, router) >= tx.amountIn` and `tx.token.balanceOf(sender) >= tx.amountIn`) is only checked at tx-pool admission and at `IsReady`/promotion time via `checkBalanceForSwap` [5](#0-4) . Nothing in `ExtractTxBundles` (called at block-building time, potentially much later, and using potentially stale pool state) re-verifies the sender's on-chain token balance/allowance immediately before minting the bundle. A sender who has a valid pending `GaslessSwapTx` can move or spend the token (or revoke the router's allowance) via an ordinary transaction executed in an earlier block/position, so that by the time the bundle actually executes, the swap transaction reverts (insufficient balance/allowance inside the DEX router) while the `LendTx` — which precedes the swap in the bundle and pays out unconditionally — has already transferred real KAIA out of the proposer's balance.

This mirrors the Astera "unbacked borrow" pattern precisely: the value-releasing operation (`LendTx` / `executeMiniPoolBorrow`) is not gated by a fresh, execution-time check of the same invariant (token balance/allowance / collateral & health) that was validated in a different code path at admission time.

### Impact Explanation
If exploitable, this allows an unprivileged transaction sender (the gasless swap requester) to cause the block proposer (a CN) to lose the lent KAIA amount without repayment, since the accompanying `GaslessSwapTx` — which is supposed to repay the lend via the swap output — fails to execute successfully. This is a direct value-movement/fee-delegation abuse against a system actor (the proposer acting as fee-delegation counterparty for gasless users), which the rules explicitly call in scope (gasless module, fee-delegation-like value movement).

### Likelihood Explanation
Requires the checked balance state to diverge between admission-time verification and the time the bundle is actually assembled/executed by the proposer, which is plausible on a live chain (multiple blocks may pass between promotion into "ready"/pending and actual block inclusion, and a malicious sender fully controls their own token transfers/approvals). However, I was not able to fully trace how frequently/at what exact point `IsReady`/`checkBalanceForSwap` is re-invoked relative to `ExtractTxBundles` within a single block-building cycle (e.g., whether it's re-run per-block versus cached), so I cannot conclusively confirm there's no re-check immediately before bundle extraction in the current code path — this is the main uncertainty in this analog.

### Recommendation
Re-validate `checkBalanceForSwap` (token balance, allowance, exchange-rate-derived `amountIn`, and deadline) against the state snapshot used for block building immediately inside `ExtractTxBundles`/`GetLendTxGenerator`, rejecting the bundle (and skipping the `LendTx`) if the swap is no longer executable, rather than relying solely on the earlier tx-pool admission check.

### Proof of Concept
Conceptual PoC (not fully verified end-to-end due to tool/iteration limits):
1. Sender submits `ApproveTx` + `GaslessSwapTx` pair that pass `VerifyExecutable`/`checkBalanceForSwap` and are promoted to pending.
2. Before the proposer includes the bundle in a block, sender sends a separate ordinary transaction transferring away the approved token balance (or revoking allowance to the swap router) in an earlier-processed transaction/block.
3. Proposer's `ExtractTxBundles` still builds `[LendTx, ApproveTx, SwapTx]` for the (now stale) swap tx since no re-check occurs at bundle-build time [2](#0-1) .
4. `LendTx` executes first and transfers KAIA from the proposer to the sender [3](#0-2) ; `SwapTx` subsequently reverts inside the DEX router due to insufficient balance/allowance, and the sender keeps the lent KAIA without repaying it.

func (g *GaslessModule) GetCheckBalance() func(tx *types.Transaction) error {
	return func(tx *types.Transaction) error {
		if approveArgs, ok := decodeApproveTx(tx, g.signer); ok {
			return g.checkBalanceForApprove(approveArgs)
		}
		if swapArgs, ok := decodeSwapTx(tx, g.signer); ok {
			return g.checkBalanceForSwap(swapArgs, tx.Nonce())
		}
		return errors.New("not a gasless transaction") // should not happen because IsModuleTx is called before GetCheckBalance
	}
}

func (g *GaslessModule) checkBalanceForSwap(swapArgs *SwapArgs, swapNonce uint64) error {
	token := swapArgs.Token
	bc := backends.NewBlockchainContractBackend(g.Chain, nil, nil)

	g.gaslessInfoMu.RLock()
	swapRouter := g.swapRouter
	g.gaslessInfoMu.RUnlock()

	// tx.minAmountOut >= tx.amountRepay
	minAmountOut := swapArgs.MinAmountOut
	amountRepay := swapArgs.AmountRepay
	if minAmountOut.Cmp(amountRepay) < 0 {
		return fmt.Errorf("insufficient minAmountOut: minAmountOut=%s, amountRepay=%s", minAmountOut.String(), amountRepay.String())
	}

	if g.GaslessConfig.ShouldCheckSenderCode() {
		if g.getCurrentHasCode(swapArgs.Sender) {
			return errors.New("sender with code is not allowed")
		}
	}

	if g.GaslessConfig.ShouldCheckSwapAmount() {
		// tx.amountIn >= gsr.getAmountIn(minAmountOut)
		routerContract, err := kip247.NewGaslessSwapRouterCaller(swapRouter, bc)
		if err != nil {
			return err
		}
		// Required token amountIn, given the current exchange rate and the declared minAmountOut.
		requiredAmountIn, err := routerContract.GetAmountIn(nil, token, minAmountOut)
		if err != nil {
			return err
		}
		if swapArgs.AmountIn.Cmp(requiredAmountIn) < 0 {
			return fmt.Errorf("insufficient amountIn: have=%s, want=%s", swapArgs.AmountIn.String(), requiredAmountIn.String())
		}
	}

	if g.GaslessConfig.ShouldCheckToken() {

		tokenContract, err := sc_erc20.NewERC20(token, bc)
		if err != nil {
			return err
		}

		// If SwapTx.nonce is the sender's next nonce, then there is no room for ApproveTx proceeding SwapTx.
		senderNonce := g.getCurrentStateNonce(swapArgs.Sender)
		noApproveTxPreceeds := swapNonce == senderNonce
		if noApproveTxPreceeds {
			// tx.token.allowance(sender, router) >= tx.amountIn
			approval, err := tokenContract.Allowance(nil, swapArgs.Sender, swapRouter)
			if err != nil {
				return err
			}
			if approval.Cmp(swapArgs.AmountIn) < 0 {
				return fmt.Errorf("insufficient approval: approval=%s, want=%s", approval.String(), swapArgs.AmountIn.String())
			}
		}

		// tx.token.balanceOf(sender) >= tx.amountIn
		balance, err := tokenContract.BalanceOf(nil, swapArgs.Sender)
		if err != nil {
			return err
		}
		if balance.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("insufficient balance: balance=%s, want=%s", balance.String(), swapArgs.AmountIn.String())
		}
	}

// L1. LendTx.type = 0x7802 (TxTypeEthereumDynamicFee)
// L2. LendTx.from = proposer
// L3. LendTx.to = SwapTx.from
// L4. LendTx.value = LendAmount(approveTxOrNil, swapTx)
func (g *GaslessModule) GetLendTxGenerator(approveTxOrNil, swapTx *types.Transaction) *builder.TxOrGen {
	var src []byte
	if approveTxOrNil != nil {
		src = append(src, approveTxOrNil.Hash().Bytes()...)
	}
	src = append(src, swapTx.Hash().Bytes()...)
	bundleHash := crypto.Keccak256Hash(src)

	gen := func(nonce uint64) (*types.Transaction, error) {
		var (
			chainId = g.InitOpts.ChainConfig.ChainID
			signer  = types.LatestSignerForChainID(chainId)
			key     = g.InitOpts.NodeKey
		)

		to, err := types.Sender(signer, swapTx)
		if err != nil {
			return nil, err
		}

		tx, err := types.NewTransactionWithMap(types.TxTypeEthereumDynamicFee, map[types.TxValueKeyType]interface{}{
			types.TxValueKeyNonce:      nonce,
			types.TxValueKeyTo:         &to,
			types.TxValueKeyAmount:     lendAmount(approveTxOrNil, swapTx),
			types.TxValueKeyData:       common.Hex2Bytes("0x"),
			types.TxValueKeyGasLimit:   params.TxGas,
			types.TxValueKeyGasFeeCap:  swapTx.GasFeeCap(),
			types.TxValueKeyGasTipCap:  swapTx.GasTipCap(),
			types.TxValueKeyAccessList: types.AccessList{},
			types.TxValueKeyChainID:    chainId,
		})
		if err != nil {
			return nil, err
		}

		err = tx.Sign(signer, key)
		return tx, err
