### Title
Identity encryption keys make PedPoP secret shares publicly decryptable - ([File: crypto/dkg/pedpop/src/encryption.rs](crypto/dkg/pedpop/src/encryption.rs))

### Summary
`EncryptedMessage::read` accepts the group identity as the sender’s ephemeral ECDH public key, and the attached Schnorr proof can be satisfied with `(R = identity, s = 0)` without knowing a private key. [1](#0-0)  Because ECDH with the identity always produces the identity, the ChaCha20 key is derived from publicly known transcript inputs and a fixed IV, exposing the encrypted `SecretShare`. [2](#0-1) [3](#0-2) 

### Finding Description
`EncryptedMessage::read` parses `key` with `C::read_G` but performs no non-identity check before later using it as the ECDH public key. [1](#0-0)  The generic `Ciphersuite::read_G` only verifies canonical point encoding and does not reject the identity element. [4](#0-3) 

The Schnorr verifier checks `R + cA - sG == identity`; consequently, when the claimed public key `A` is the identity, `R = identity` and `s = 0` satisfy the equation for every challenge. [5](#0-4) [6](#0-5)  Therefore, the message’s proof-of-possession does not prevent an attacker from supplying the identity encryption key.

After acceptance, `ecdh` calculates `public * private`, so an identity public key always produces the identity shared point regardless of the recipient’s secret. [2](#0-1)  `cipher` derives ChaCha20 from the session context and that shared-point encoding, then uses the fixed `DKG IV v0.2\0` IV. [3](#0-2)  Anyone knowing the public session context can derive the same keystream and decrypt the serialized `SecretShare`.

### Impact Explanation
An attacker can submit a syntactically valid `EncryptedMessage` whose DKG secret share is encrypted under a publicly computable key. [1](#0-0)  If the PedPoP message is visible to other protocol participants, relays, logs, or an observer of the authenticated channel, they can recover the contained participant’s key share, defeating the confidentiality that the encryption layer is intended to provide. [7](#0-6)  This permits unauthorized key-share recovery rather than merely causing a rejected or malformed share.

### Likelihood Explanation
An attacker only needs to serialize a PedPoP `EncryptedMessage` with an identity `key`, an identity Schnorr nonce, scalar `s = 0`, and ciphertext generated using the publicly derived identity-ECDH keystream. [8](#0-7)  The identity point and zero scalar are canonical encodings, while the signature equation passes for every proof challenge when the public key is identity. [4](#0-3) [5](#0-4)  No discrete-logarithm computation, private-key knowledge, broken randomness, or threshold collusion is required.

### Recommendation
Reject the identity element for both `EncryptedMessage::key` and the corresponding Schnorr proof nonce when parsing `EncryptedMessage`. [1](#0-0)  This can be implemented with the same explicit identity check already used by `Curve::read_G`, rather than relying on the generic `Ciphersuite::read_G`. [9](#0-8)  The ECDH result should also be checked so that `public * private != identity` before deriving the cipher. [2](#0-1) 

### Proof of Concept
```rust
// Attacker-controlled EncryptedMessage fields.
let key = C::G::identity();
let pop = SchnorrSignature::<C> {
    R: C::G::identity(),
    s: C::F::ZERO,
};

// pop.verify(key, challenge) reduces to:
// identity + challenge * identity - 0 * G == identity
// and therefore succeeds for every challenge.

// The victim derives:
let ecdh = key * victim_private_key; // == identity

// The attacker derives the same ChaCha20 key from:
// context || shared_key = encode(identity)
// with IV b"DKG IV v0.2\0", and can decrypt the SecretShare.
```

The parsing path accepts all three attacker-controlled fields, and the group operations then deterministically produce a public ECDH result. [8](#0-7) [2](#0-1)  The signature bypass follows directly from `R + cA - sG` evaluating to the identity when `R = A = identity` and `s = 0`. [5](#0-4)

  fn read_G<R: Read>(reader: &mut R) -> io::Result<Self::G> {
    let mut encoding = <Self::G as GroupEncoding>::Repr::default();
    reader.read_exact(encoding.as_mut())?;

    let point = Option::<Self::G>::from(Self::G::from_bytes(&encoding))
      .ok_or_else(|| io::Error::other("invalid point"))?;
    if point.to_bytes().as_ref() != encoding.as_ref() {
      Err(io::Error::other("non-canonical point"))?;
    }
    Ok(point)
