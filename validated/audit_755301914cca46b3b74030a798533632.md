### Title
Governance-settable `Kip71GasTarget=0` causes divide-by-zero panic in base fee calculation - (File: params/kip71_config.go)

### Summary
`KIP71Config.NextMagmaBlockBaseFee` divides the base-fee delta by `gasTarget` without checking it is non-zero, while the governance parameter that sets it, `Kip71GasTarget`, has no format validation preventing a zero value.

### Finding Description
`NextMagmaBlockBaseFee` computes the parent's gas usage relative to `gasTarget` and, when `parentGasUsed != gasTarget`, divides by `gasTarget` twice (once directly, and implicitly through `baseFeeDenominator`) to compute the base fee delta: [3](#0-2) 
Unlike `BaseFeeDenominator`, whose governance `FormatChecker` explicitly rejects zero (`v != 0`) [4](#0-3) , `Kip71GasTarget` uses `noopFormatChecker`, meaning any `uint64` value including `0` passes governance validation [5](#0-4) . If `gasTarget` is set to `0` via governance vote and `parentGasUsed != 0`, `parentGasUsed > gasTarget` is always true (unless `parentGasUsed` is also `0`, in which case `parentGasUsed == gasTarget` short-circuits and avoids the panic). But once any block produces `parentGasUsed > 0`, the division `x.Div(x, new(big.Int).SetUint64(gasTarget))` at line 102 divides by zero, which in Go's `big.Int.Div` triggers a runtime panic ("division by zero"), crashing every node that processes that block header/fee-history computation.

### Impact Explanation
This is directly reachable by governance (chain-parameter voting), which per the scan's threat model can be exercised by governance/validator actors, and its effect is felt by every honest node computing `NextMagmaBlockBaseFee` for header validation (`VerifyMagmaHeader`) or `eth_feeHistory` RPC serving (`processBlock` in `node/cn/gasprice/feehistory.go`), causing a chain-wide node crash/DoS once a block with nonzero gas usage is processed after the parameter changes.

### Likelihood Explanation
Requires governance-level control to change the `kip71.gastarget` parameter to zero, which is a higher barrier than a simple transaction, but the format checker for this parameter provides no protection against it, unlike the sibling `BaseFeeDenominator` parameter which is explicitly guarded. This suggests the omission is likely unintentional rather than a deliberate access-control boundary.

### Recommendation
Add a non-zero `FormatChecker` for `Kip71GasTarget` analogous to the existing `Kip71BaseFeeDenominator` checker, and/or add a defensive `gasTarget == 0` guard inside `NextMagmaBlockBaseFee` (similar to the existing `BaseFeeDenominator == 0` fallback at lines 71-76) that falls back to a safe default instead of dividing by zero.

### Proof of Concept
1. Governance sets `kip71.gastarget = 0` via a governance vote (accepted because `Kip71GasTarget`'s `FormatChecker` is `noopFormatChecker`).
2. Once the parameter takes effect and a subsequent block reports `GasUsed > 0`, `NextMagmaBlockBaseFee` executes the `parentGasUsed > gasTarget` branch with `gasTarget = 0`, calling `x.Div(x, new(big.Int).SetUint64(0))` at `params/kip71_config.go:102`, which panics with "division by zero" in every node computing the block header's base fee or serving `eth_feeHistory`. func (kc *KIP71Config) NextMagmaBlockBaseFee(parentHeaderNumber *big.Int, parentHeaderBaseFee *big.Int, parentHeaderGasUsed uint64) *big.Int {
	// governance parameters
	lowerBoundBaseFee := new(big.Int).SetUint64(kc.LowerBoundBaseFee)
	upperBoundBaseFee := new(big.Int).SetUint64(kc.UpperBoundBaseFee)
	makeEvenByCeil(lowerBoundBaseFee)
	makeEvenByFloor(upperBoundBaseFee)

	// If the parent is the magma disabled block or genesis, then return the lowerBoundBaseFee (default 25ston)
	if parentHeaderNumber.Cmp(new(big.Int).SetUint64(0)) == 0 || parentHeaderBaseFee == nil {
		return makeEvenByFloor(lowerBoundBaseFee)
	}

	var baseFeeDenominator *big.Int
	if kc.BaseFeeDenominator == 0 {
		// To avoid panic, set the fluctuation range small
		baseFeeDenominator = new(big.Int).SetUint64(64)
	} else {
		baseFeeDenominator = new(big.Int).SetUint64(kc.BaseFeeDenominator)
	}
	gasTarget := kc.GasTarget
	upperGasLimit := kc.MaxBlockGasUsedForBaseFee

	// check the case of upper/lowerBoundBaseFee is updated by governance mechanism
	parentBaseFee := parentHeaderBaseFee
	if parentBaseFee.Cmp(upperBoundBaseFee) >= 0 {
		parentBaseFee = upperBoundBaseFee
	} else if parentBaseFee.Cmp(lowerBoundBaseFee) <= 0 {
		parentBaseFee = lowerBoundBaseFee
	}

	// upper gas limit cut off the impulse of used gas to upper bound
	parentGasUsed := min(parentHeaderGasUsed, upperGasLimit)
	if parentGasUsed == gasTarget {
		return makeEvenByFloor(parentBaseFee)
	} else if parentGasUsed > gasTarget {
		// shortcut. If parentBaseFee is already reached upperbound, do not calculate.
		if parentBaseFee.Cmp(upperBoundBaseFee) == 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		// If the parent block used more gas than its target,
		// the baseFee of the next block should increase.
		// baseFeeDelta = max(1, parentBaseFee * (parentGasUsed - gasTarget) / gasTarget / baseFeeDenominator)
		gasUsedDelta := new(big.Int).SetUint64(parentGasUsed - gasTarget)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := math.BigMax(x.Div(y, baseFeeDenominator), common.Big1)

		nextBaseFee := x.Add(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(upperBoundBaseFee) > 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	} else {
		// shortcut. If parentBaseFee is already reached lower bound, do not calculate.
		if parentBaseFee.Cmp(lowerBoundBaseFee) == 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		// Otherwise if the parent block used less gas than its target,
		// the baseFee of the next block should decrease.
		// baseFeeDelta = parentBaseFee * (gasTarget - parentGasUsed) / gasTarget / baseFeeDenominator
		gasUsedDelta := new(big.Int).SetUint64(gasTarget - parentGasUsed)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := x.Div(y, baseFeeDenominator)

		nextBaseFee := x.Sub(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(lowerBoundBaseFee) < 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	}
}
