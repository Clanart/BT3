### Title
Non-anchored `commitMentionUrl` regex lets `CommitMentionLinkFilter` relabel an attacker-host link as a trusted `owner/repo@sha` reference - (`app/src/lib/markdown-filters/commit-mention-link-filter.ts`)

### Summary
`CommitMentionLinkFilter.commitMentionUrl` is built without a `^`/`$` anchor, so `.test(el.href)` succeeds if the required GitHub commit/compare/pull-commit URL pattern occurs *anywhere* in the href string, not only as its full value. Combined with the fact that `filter()` derives the owner/name/sha purely from the real `url.pathname` of the (attacker-controlled) href, an attacker can craft an autolinked URL whose **host is attacker-controlled** but whose real path is `/owner/name/commit/<sha>`, while stuffing a real `https://github.com/owner/name/commit/<sha>` string into the URL fragment (`#...`) purely to satisfy the loose regex test. The filter then rewrites the visible text to the trust-implying `owner/name@sha` label while leaving the actual `href` pointed at the attacker's host.

### Finding Description
`commitMentionUrl` is constructed as: [1](#0-0) 

There is no `^` at the start of the pattern, so `RegExp.test()` matches on any substring occurrence, not just when the href *is* a well-formed GitHub commit URL. The tree-walker acceptance check is: [2](#0-1) 

It only additionally requires `el.href === el.innerText` (both being the full literal autolinked URL) — it does not require the GitHub-URL match to occupy the whole string.

Once accepted, `filter()` re-parses `text` (which equals `href`) with `new URL(text)` and takes the **real** `owner`/`name` from `url.pathname`, then extracts the remaining `path` and matches it against `commitPath`/`comparePath`/`pullCommitPath`: [3](#0-2) 

Because `new URL()` correctly separates the fragment (`#...`) from `pathname`, an attacker can place the literal string `https://github.com/owner/name/commit/<sha>` inside the URL's fragment purely to satisfy the unanchored `commitMentionUrl.test()`, while making the *actual* scheme/host/pathname of the href point to their own domain with a path that also happens to literally be `/owner/name/commit/<sha>`. Example:

```
https://attacker.example/owner/name/commit/6fd7945deadbeef1234#https://github.com/owner/name/commit/6fd7945deadbeef1234
```

- `commitMentionUrl.test(href)` → true (github.com/owner/name/commit/sha appears as a substring inside the fragment).
- `new URL(href).pathname` → `/owner/name/commit/6fd7945deadbeef1234`, so `owner="owner"`, `name="name"`, and the remaining path matches `commitPath`, yielding `ref = "6fd7945"`.
- `filter()` rewrites the anchor's inner HTML to `owner/name@6fd7945` via `getCommitMentionRef`, but the anchor's `href` attribute is untouched and still points to `attacker.example`.

When the user clicks the rendered link, `SandboxedMarkdown.setupLinkInterceptor` reads `a.href` (the real, attacker-controlled absolute URL) and forwards it verbatim: [4](#0-3) 

`onMarkdownLinkClicked` is wired by consumers (e.g. release notes / PR comments) to eventually call `shell.openExternal` with that attacker-controlled URL, while the user saw a label that reads like a legitimate `owner/repo@sha` GitHub commit reference.

### Impact Explanation
This is a link-spoofing / trust-indicator bypass: markdown rendered from untrusted sources (PR/commit comments, release notes, issues) can display a benign-looking, GitHub-style commit reference (`owner/repo@sha`) whose actual navigation target is an attacker-controlled host. This can facilitate phishing / credential-harvesting redirection dressed up as an official GitHub link, executed via the normal `shell.openExternal` flow. It does not achieve code execution or sandbox escape by itself, but it undermines a security-relevant UI trust cue (link text vs. destination) that the filter is specifically designed to provide.

### Likelihood Explanation
Exploitation only requires the attacker to control markdown content that gets autolinked (e.g., a PR description, commit message, or issue/PR comment body) and to embed one specially-crafted URL of the form shown above. No special privileges, local access, or unusual user interaction beyond a normal link click are required, making this straightforward to trigger for any attacker who can post GitHub content that is rendered by `SandboxedMarkdown` in Desktop.

### Recommendation
Anchor `commitMentionUrl` at both ends (`^...$`) against the full href string (or explicitly validate that `new URL(href).origin === getHTMLURL(this.repository.endpoint)` origin and that the whole pathname — not a substring anywhere in the URL — matches the expected commit/compare/pull-commit shape) before allowing `filter()` to relabel the link text.

### Proof of Concept
1. Render markdown (via `SandboxedMarkdown`) containing the raw autolinked URL:
   ```
   https://attacker.example/owner/name/commit/6fd7945deadbeef1234#https://github.com/owner/name/commit/6fd7945deadbeef1234
   ```
2. `CommitMentionLinkFilter.createFilterTreeWalker`'s `acceptNode` accepts the anchor because `commitMentionUrl.test(el.href)` matches the substring in the fragment.
3. `filter()` parses the real pathname (`/owner/name/commit/6fd7945deadbeef1234`), extracts `owner=owner`, `name=name`, `ref=6fd7945`, and rewrites the anchor's visible text to `owner/name@6fd7945`, leaving `href` unchanged.
4. Clicking the link triggers `setupLinkInterceptor` → `onMarkdownLinkClicked(a.href)` with `a.href` equal to `https://attacker.example/...`, confirming the rendered trusted-looking text does not match the actual navigation target.

Note: I was not able to execute this against a live build to directly capture the `onMarkdownLinkClicked` invocation value, so the PoC above is derived from static tracing of the regex/URL-parsing logic and the click-interceptor code; a Devin session with the ability to run the app/test harness could confirm this dynamically if further validation is desired.

  private get commitMentionUrl(): RegExp {
    const gitHubURL = getHTMLURL(this.repository.endpoint)
    return new RegExp(
      escapeRegExp(gitHubURL) +
        '/' +
        this.nameWithOwner.source +
        '/' +
        /(commit|pull|compare)/.source +
        '/' +
        /(\d+\/commits\/)?/.source +
        /([0-9a-f]{7,40})/.source +
        /\b/.source
    )
  }

  public createFilterTreeWalker(doc: Document): TreeWalker {
    return doc.createTreeWalker(doc.body, NodeFilter.SHOW_ELEMENT, {
      acceptNode: (el: Element) => {
        return (el.parentNode !== null &&
          ['CODE', 'PRE', 'A'].includes(el.parentNode.nodeName)) ||
          !isElement(el, 'a') ||
          el.href !== el.innerText ||
          !this.commitMentionUrl.test(el.href)
          ? NodeFilter.FILTER_SKIP
          : NodeFilter.FILTER_ACCEPT
      },
    })
  }

  public async filter(node: Node): Promise<ReadonlyArray<Node> | null> {
    const newNode = node.cloneNode(true)
    const { textContent: text } = newNode
    if (!isElement(newNode, 'a') || text === null) {
      return null
    }

    const url = new URL(text)
    const [, owner, name] = url.pathname.split('/', 3)
    if (owner === undefined || name === undefined) {
      return null
    }
    const slashes = 3
    const path = url.pathname.substring(owner.length + name.length + slashes)

    let ref, filepathToAppend

    const commitComparePathMatch =
      this.getRefFromCommitPath(path) ?? this.getRefFromComparePath(path)
    if (commitComparePathMatch !== null) {
      ;({ ref, filepathToAppend } = commitComparePathMatch)

      filepathToAppend =
        filepathToAppend !== undefined
          ? filepathToAppend + url.search
          : url.search
    } else {
      ref = this.getRefFromPullPath(path)
    }

    if (ref === null || ref === undefined) {
      return null
    }

  private setupLinkInterceptor(doc: Document): void {
    doc.addEventListener('click', ev => {
      if (doc.defaultView && ev.target instanceof doc.defaultView.Element) {
        const a = ev.target.closest('a')
        if (a !== null) {
          ev.preventDefault()

          if (/^https?:/.test(a.protocol)) {
            this.props.onMarkdownLinkClicked?.(a.href)
          }
        }
      }
    })
  }
