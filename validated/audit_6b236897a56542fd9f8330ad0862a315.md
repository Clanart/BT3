## Title
Gasless bundle validation checks token/router "busy" state without holding the readiness lock across the entire admission decision - stale `isApproveTx`/`isSwapTx` classification can be reused after `updateAddresses` mutates `allowedTokens`/`swapRouter` mid-block-build - ([File: kaiax/gasless/impl/getter.go])

## Summary
The CVE describes a V4L2 driver bug where a control that mutates format-critical state (`vivid_update_format_cap/out`) is applied without checking whether the underlying queue is already "busy" (i.e., already committed/in-use), because the busy check exists at stream-start time but not at the time the mutating control is applied. The class of bug is: *a resource's "is this safe to mutate" check is decoupled in time from the actual mutation/consumption of that resource, so a consumer can observe an inconsistent state between decision and use.* [1](#0-0) 

## Finding Description
`GaslessModule.isApproveTx`/`isSwapTx` gate whether a transaction is treated as a gasless-lending transaction based on `g.allowedTokens` and `g.swapRouter`, guarded by `g.gaslessInfoMu.RLock()`: [1](#0-0) 

These fields are mutated in `updateAddresses`, which is invoked from block-processing (`PostInsertBlock`) whenever the `GaslessSwapRouter`/allowed-token set changes on-chain: [2](#0-1) 

The classification result (`IsApproveTx`/`IsSwapTx`/`IsExecutable`) is used at two different, temporally separated points that are not covered by a single consistent lock or snapshot:
1. Pool admission / promotion (`IsReady`, `GetCheckBalance`) — decides if a transaction is a gasless tx and skips the normal balance check for it: [3](#0-2) 
2. Block/bundle building (`ExtractTxBundles`), which re-derives `IsApproveTx`/`IsSwapTx`/`IsExecutable` from the *current* in-memory `g.allowedTokens`/`g.swapRouter` when assembling the actual `[LendTxGenerator, ApproveTx, SwapTx]` bundle that will move real KAIA (the lend) and real token funds (the repay/allowance): [4](#0-3) 

Because `GetCheckBalance()`/`IsModuleTx` decide to *skip the sender-balance check entirely* for any transaction classified as gasless (`shouldSkipBalanceCheck = true` in the tx pool), and this classification depends on the mutable, unlocked-between-calls `allowedTokens`/`swapRouter` state, a transaction that is classified as a gasless swap at admission time (bypassing normal balance checks) can later be re-classified differently — or vice versa — at bundle-extraction time if `updateAddresses` fires in between (e.g., the on-chain registry adds/removes a token or rotates `swapRouter` in the intervening block), similar to how vivid's control-driven format update never re-checked queue "busy" state before mutating shared config that buffers already depend on: [5](#0-4) 

Additionally, `checkBalanceForSwap`/`checkBalanceForApprove` (the "balance/allowance" checks substituted for the normal balance check) read allowance/balance/exchange-rate from `g.Chain`'s *current head state*, not from the state as it will exist after prior bundle transactions in the same block execute, so admission-time approval of a swap does not guarantee the same conditions hold when the bundle actually executes at the front of the block: [6](#0-5) 

## Impact Explanation
If `allowedTokens`/`swapRouter` toggle between the pool-admission check (which skips the normal sender balance check for anything recognized as gasless) and the final bundle-building/execution step, a transaction that no longer satisfies `IsApproveTx`/`IsSwapTx`/`IsExecutable` conditions can still have bypassed the standard balance check at admission (`shouldSkipBalanceCheck`), or conversely a transaction that was gasless-admitted may fail to be recognized as gasless at execution and be dropped/executed under wrong assumptions — producing state divergence between the intended KIP-247 gasless flow and what actually settles on-chain (unauthorized value movement via the block-proposer-funded `LendTxGenerator`, or reward/fee accounting inconsistency for gasless settlement). This maps to the "gasless settlement theft" / "state divergence between honest nodes" categories in scope, since different nodes could build/validate the block with different token/router snapshots (`allowedTokens` update timing depends on each node's local `PostInsertBlock` execution), causing consensus-relevant divergence in which bundles are accepted.

## Likelihood Explanation
Exploitation requires influencing or timing around a change to `GaslessSwapRouter`'s registered token list or router address (which is governance/registry-controlled and normally rare), combined with submitting gasless approve/swap transactions in the same window. This is a narrow timing window and requires the auxiliary condition of a token/router registry change, which is not attacker-controlled from a single unprivileged transaction. This significantly lowers likelihood versus the original vivid case (where an unprivileged local user could always toggle the control between REQBUFS and STREAMON).

## Recommendation
Snapshot `allowedTokens`/`swapRouter` (and any per-tx balance/allowance data) once per admission decision, and reuse that exact snapshot at bundle-extraction time (or re-validate with a WARN/reject if the snapshot has changed), mirroring the vivid fix pattern of adding an explicit "is busy / would this mutate an in-use resource" guard rather than re-reading live mutable module state at two different pipeline stages. Ensure `GetCheckBalance()`'s decision to skip the standard sender-balance check is tied to the same state snapshot that `ExtractTxBundles` uses to build the final bundle.

## Proof of Concept
Conceptual (concrete PoC not verifiable without live network/registry control):
1. Node A has `allowedTokens = {TokenX}`, `swapRouter = R1`.
2. Attacker submits `ApproveTx(TokenX)+SwapTx(TokenX)` gasless pair; `IsModuleTx`/`GetCheckBalance` classify it as gasless and skip normal balance checks in `pool.validateTx` (`shouldSkipBalanceCheck=true`). [5](#0-4) 
3. Before the block is built, a registry transaction changes `GaslessSwapRouter`'s token list (removing `TokenX`) is included, triggering `updateAddresses` via `PostInsertBlock`. [2](#0-1) 
4. `ExtractTxBundles` on the next block re-evaluates `IsSwapTx`/`IsApproveTx` against the *new* `allowedTokens`, producing different bundling behavior than what was assumed when balance checks were skipped at admission — this state mismatch is the direct analog of vivid's missing "busy" check before mutating shared format/config state. [4](#0-3) 

Note: I was not able to fully trace whether `pool.currentState`/`reset()` re-validates already-admitted gasless transactions against the new `allowedTokens` set before block building (which could already mitigate this), due to index size limits on cross-file trace of `promoteExecutables`/`PostReset` interaction with the gasless module's `PostReset` hook. A Devin session with full repo access would be needed to confirm whether `PostReset`/`FilterTxs` re-validates stale gasless classifications before the tx enters a block, which determines whether this is fully mitigated already or genuinely exploitable.

func (g *GaslessModule) isApproveTx(args *ApproveArgs) bool {
	g.gaslessInfoMu.RLock()
	defer g.gaslessInfoMu.RUnlock()

	return g.allowedTokens[args.Token] && // A1
		g.swapRouter == args.Spender && // A3
		args.Amount.Cmp(abi.MaxUint256) == 0 // A4
}

// IsSwapTx checks following conditions:
// S1. tx.to is a whitelisted SwapRouter contract.
// S2. tx.data is `swapForGas(token, amountIn, minAmountOut, amountRepay)`.
// S3. token is a whitelisted ERC20 token.
func (g *GaslessModule) IsSwapTx(tx *types.Transaction) bool {
	args, ok := decodeSwapTx(tx, g.signer)
	return ok && g.isSwapTx(args)
}

func (g *GaslessModule) isSwapTx(args *SwapArgs) bool {
	g.gaslessInfoMu.RLock()
	defer g.gaslessInfoMu.RUnlock()

	return g.swapRouter == args.Router && // S1
		g.allowedTokens[args.Token] // S3
}

func (g *GaslessModule) updateAddresses(header *types.Header) error {
	g.gaslessInfoMu.Lock()
	defer g.gaslessInfoMu.Unlock()

	swapRouter, tokens, err := getGaslessInfo(g.Chain, header)
	// proceed even if there is something wrong with multicall contract
	if err != nil {
		g.swapRouter = common.Address{}
		g.allowedTokens = map[common.Address]bool{}
		logger.Warn("there is something wrong with multicall contract", "err", err.Error())
		return nil
	}

	g.swapRouter = swapRouter

	g.allowedTokens = map[common.Address]bool{}
	for _, addr := range tokens {
		// all tokens are allowed if nil
		if g.GaslessConfig.AllowedTokens == nil {
			g.allowedTokens[addr] = true
		}
		for _, allowed := range g.GaslessConfig.AllowedTokens {
			if addr == allowed {
				g.allowedTokens[addr] = true
			}
		}
	}

	return nil
}

func (g *GaslessModule) GetCheckBalance() func(tx *types.Transaction) error {
	return func(tx *types.Transaction) error {
		if approveArgs, ok := decodeApproveTx(tx, g.signer); ok {
			return g.checkBalanceForApprove(approveArgs)
		}
		if swapArgs, ok := decodeSwapTx(tx, g.signer); ok {
			return g.checkBalanceForSwap(swapArgs, tx.Nonce())
		}
		return errors.New("not a gasless transaction") // should not happen because IsModuleTx is called before GetCheckBalance
	}
}

func (g *GaslessModule) checkBalanceForSwap(swapArgs *SwapArgs, swapNonce uint64) error {
	token := swapArgs.Token
	bc := backends.NewBlockchainContractBackend(g.Chain, nil, nil)

	g.gaslessInfoMu.RLock()
	swapRouter := g.swapRouter
	g.gaslessInfoMu.RUnlock()

	// tx.minAmountOut >= tx.amountRepay
	minAmountOut := swapArgs.MinAmountOut
	amountRepay := swapArgs.AmountRepay
	if minAmountOut.Cmp(amountRepay) < 0 {
		return fmt.Errorf("insufficient minAmountOut: minAmountOut=%s, amountRepay=%s", minAmountOut.String(), amountRepay.String())
	}

	if g.GaslessConfig.ShouldCheckSenderCode() {
		if g.getCurrentHasCode(swapArgs.Sender) {
			return errors.New("sender with code is not allowed")
		}
	}

	if g.GaslessConfig.ShouldCheckSwapAmount() {
		// tx.amountIn >= gsr.getAmountIn(minAmountOut)
		routerContract, err := kip247.NewGaslessSwapRouterCaller(swapRouter, bc)
		if err != nil {
			return err
		}
		// Required token amountIn, given the current exchange rate and the declared minAmountOut.
		requiredAmountIn, err := routerContract.GetAmountIn(nil, token, minAmountOut)
		if err != nil {
			return err
		}
		if swapArgs.AmountIn.Cmp(requiredAmountIn) < 0 {
			return fmt.Errorf("insufficient amountIn: have=%s, want=%s", swapArgs.AmountIn.String(), requiredAmountIn.String())
		}
	}

	if g.GaslessConfig.ShouldCheckToken() {

		tokenContract, err := sc_erc20.NewERC20(token, bc)
		if err != nil {
			return err
		}

		// If SwapTx.nonce is the sender's next nonce, then there is no room for ApproveTx proceeding SwapTx.
		senderNonce := g.getCurrentStateNonce(swapArgs.Sender)
		noApproveTxPreceeds := swapNonce == senderNonce
		if noApproveTxPreceeds {
			// tx.token.allowance(sender, router) >= tx.amountIn
			approval, err := tokenContract.Allowance(nil, swapArgs.Sender, swapRouter)
			if err != nil {
				return err
			}
			if approval.Cmp(swapArgs.AmountIn) < 0 {
				return fmt.Errorf("insufficient approval: approval=%s, want=%s", approval.String(), swapArgs.AmountIn.String())
			}
		}

		// tx.token.balanceOf(sender) >= tx.amountIn
		balance, err := tokenContract.BalanceOf(nil, swapArgs.Sender)
		if err != nil {
			return err
		}
		if balance.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("insufficient balance: balance=%s, want=%s", balance.String(), swapArgs.AmountIn.String())
		}
	}

	// tx.deadline >= currentTimestamp
	deadline := swapArgs.Deadline
	if deadline.Cmp(g.Chain.CurrentBlock().Time()) < 0 {
		return fmt.Errorf("insufficient deadline: deadline=%s, want=%s", deadline.String(), g.Chain.CurrentBlock().Time().String())
	}

	return nil
}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
}
