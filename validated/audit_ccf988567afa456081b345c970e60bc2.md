### Title
Multisig accounts can be created with duplicate public keys, letting one private key satisfy multiple signature slots and defeat the M-of-N threshold - (File: `stacks-common/src/types/mod.rs`, `stacks-common/src/address/mod.rs`, `stacks-codec/src/transaction.rs`)

### Summary
`StacksAddress::from_public_keys` and the `TransactionSpendingCondition` multisig constructors (`new_multisig_p2sh`, `new_multisig_p2wsh`, `new_multisig_order_independent_p2wsh`, etc.) build a multisig account's `signer` hash directly from a caller-supplied `pubkeys: Vec<StacksPublicKey>` without checking that the entries are distinct. This is the direct analog of the reported `VestingSplitter.sol` bug, where an `accounts` array used for an authorization/threshold decision was never checked for duplicates.

### Finding Description
`StacksAddress::from_public_keys` only checks `pubkeys.len() < num_sigs` and, for segwit modes, that keys are compressed; it never verifies uniqueness before hashing: [1](#0-0) 

The hash itself is built by `to_bits_p2sh` / `to_bits_p2sh_p2wsh`, which simply pushes every key in `pubkeys` (duplicates included) into an `OP_CHECKMULTISIG`-style script and hashes it: [2](#0-1) 

At verification time, both `MultisigSpendingCondition::verify` and `OrderIndependentMultisigSpendingCondition::verify` recover a public key for every `TransactionAuthField::Signature` entry, push it into a `pubkeys` vector in field order, and only check `num_sigs` (the *count* of signature fields) against `signatures_required`. They never check that the recovered public keys are pairwise distinct: [3](#0-2) [4](#0-3) 

The reconstructed `pubkeys` vector is then re-hashed with `StacksAddress::from_public_keys(...)` and compared against `self.signer`. Because the hash is a deterministic function of the exact (possibly duplicated) `pubkeys` sequence, this check passes as long as the *same* duplicated sequence that was used to create the account is reproduced by the fields supplied in the transaction.

If a shared M-of-N account is created with one public key appearing twice in the `pubkeys` list (e.g. by a coordinating/setup script, or by a malicious cosigner who supplies their own key twice instead of contributing to the honest N-key set that other cosigners believe they are agreeing to), a single private-key holder can:
1. Sign the sighash once and place that signature (or the recovered public key, if not signing that slot) into both of the fields corresponding to the duplicated key.
2. Satisfy `num_sigs >= signatures_required` (or `== signatures_required` for sequential multisig) using only one real signer, and
3. Reconstruct exactly the same `pubkeys` sequence used at account creation, so `addr.bytes() == self.signer` still holds.

This breaks the equality that the protocol/users rely on: "a transaction requires signatures from `signatures_required` *distinct* authorized keys" — instead it only requires `signatures_required` signature *slots*, which can be filled by fewer unique keys if the account's key list contains duplicates. This is the exact "input array can contain duplicated accounts, no duplication check" class from the reported `VestingSplitter.sol` issue, mapped onto the Stacks multisig spending-condition/account-creation code path.

### Impact Explanation
For a genuinely shared wallet meant to require agreement from `M` distinct parties, an attacker who controls (or tricks the setup flow into including) a duplicate entry of their own key can unilaterally authorize spends that should have required cooperation from other, honest key-holders — i.e., an asset moves without the authorization the account's nominal M-of-N policy is supposed to guarantee. This matches the Critical impact category: "forging ... a transaction so an asset moves without authorization."

### Likelihood Explanation
Exploitation requires that a multisig account be instantiated with a duplicated public key in its `pubkeys`/key list. This is not prevented anywhere in the constructors (`new_multisig_p2sh`, `new_multisig_p2wsh`, `new_multisig_order_independent_p2wsh`) or in `StacksAddress::from_public_keys`, nor is uniqueness re-checked during `verify()`. Any tooling, wallet, or coordination script that builds such an account from user-submitted keys (e.g. a DAO/vault setup flow collecting cosigner keys) is exposed if it does not itself perform a duplicate check — exactly the scenario the original report flags for `VestingSplitter.sol`.

### Recommendation
Add an explicit duplicate check on the `pubkeys` list in `StacksAddress::from_public_keys` (and/or in the `TransactionSpendingCondition::new_multisig_*` constructors) that rejects address/account creation when the same public key appears more than once for a given hash mode. Optionally, also assert pairwise distinctness of recovered public keys inside `MultisigSpendingCondition::verify` / `OrderIndependentMultisigSpendingCondition::verify` as defense in depth.

### Proof of Concept
1. Call `TransactionSpendingCondition::new_multisig_p2sh(2, vec![pubkeyA.clone(), pubkeyA.clone(), pubkeyB])` to create a nominal "2-of-3" account; `from_public_keys` accepts it and returns a valid `signer` hash despite `pubkeyA` appearing twice. [1](#0-0) 
2. The holder of `privkeyA` alone signs the sighash and supplies fields `[Signature(sigA), Signature(sigA_or_same), PublicKey(pubkeyB)]` (or equivalent chained-sighash version for sequential multisig).
3. `MultisigSpendingCondition::verify` (or the order-independent variant) counts `num_sigs == 2`, satisfying `signatures_required`, and reconstructs `pubkeys == [pubkeyA, pubkeyA, pubkeyB]`, whose hash matches `self.signer` from step 1. [5](#0-4) 
4. The transaction is accepted as validly authorized by "2 signatures," even though only one distinct private key ever signed.

    pub fn from_public_keys(
        version: u8,
        hash_mode: &AddressHashMode,
        num_sigs: usize,
        pubkeys: &Vec<StacksPublicKey>,
    ) -> Option<StacksAddress> {
        // must be sufficient public keys
        if pubkeys.len() < num_sigs {
            return None;
        }

        // address hash mode must be consistent with the number of keys
        match *hash_mode {
            AddressHashMode::SerializeP2PKH | AddressHashMode::SerializeP2WPKH
                // must be a single public key, and must require one signature
                if (num_sigs != 1 || pubkeys.len() != 1) => {
                    return None;
                }
            _ => {}
        }

        // if segwit, then keys must all be compressed
        match *hash_mode {
            AddressHashMode::SerializeP2WPKH | AddressHashMode::SerializeP2WSH => {
                for pubkey in pubkeys {
                    if !pubkey.compressed() {
                        return None;
                    }
                }
            }
            _ => {}
        }

        let hash_bits = public_keys_to_address_hash(hash_mode, num_sigs, pubkeys);
        StacksAddress::new(version, hash_bits).ok()
    }

fn to_bits_p2sh<K: PublicKey>(num_sigs: usize, pubkeys: &Vec<K>) -> Hash160 {
    let mut bldr = Builder::new();
    bldr = bldr.push_int(num_sigs as i64);
    for pubk in pubkeys {
        bldr = bldr.push_slice(&pubk.to_bytes());
    }
    bldr = bldr.push_int(pubkeys.len() as i64);
    bldr = bldr.push_opcode(btc_opcodes::OP_CHECKMULTISIG);

    let script = bldr.into_script();
    Hash160::from_data(script.as_bytes())
}

/// Internally, the Stacks blockchain encodes address the same as Bitcoin
/// single-sig address over p2sh (p2h-p2wpkh)
fn to_bits_p2sh_p2wpkh<K: PublicKey>(pubk: &K) -> Hash160 {
    let key_hash = Hash160::from_data(&pubk.to_bytes());

    let bldr = Builder::new().push_int(0).push_slice(key_hash.as_bytes());

    let script = bldr.into_script();
    Hash160::from_data(script.as_bytes())
}

/// Internally, the Stacks blockchain encodes address the same as Bitcoin
/// multisig address over p2sh (p2sh-p2wsh)
fn to_bits_p2sh_p2wsh<K: PublicKey>(num_sigs: usize, pubkeys: &Vec<K>) -> Hash160 {
    let mut bldr = Builder::new();
    bldr = bldr.push_int(num_sigs as i64);
    for pubk in pubkeys {
        bldr = bldr.push_slice(&pubk.to_bytes());
    }
    bldr = bldr.push_int(pubkeys.len() as i64);
    bldr = bldr.push_opcode(btc_opcodes::OP_CHECKMULTISIG);

    let mut digest = Sha256::new();
    let mut d = [0u8; 32];

    digest.update(bldr.into_script().as_bytes());
    d.copy_from_slice(&digest.finalize());

    let ws = Builder::new().push_int(0).push_slice(&d).into_script();
    Hash160::from_data(ws.as_bytes())
}

    pub fn verify(
        &self,
        initial_sighash: &Txid,
        cond_code: &TransactionAuthFlags,
        mode: TransactionAuthVerificationMode,
    ) -> Result<Txid, AuthError> {
        let mut pubkeys = vec![];
        let mut cur_sighash = initial_sighash.clone();
        let mut num_sigs: u16 = 0;
        let mut have_uncompressed = false;
        for field in self.fields.iter() {
            let pubkey = match field {
                TransactionAuthField::PublicKey(ref pubkey) => {
                    if !pubkey.compressed() {
                        have_uncompressed = true;
                    }
                    pubkey.clone()
                }
                TransactionAuthField::Signature(ref pubkey_encoding, ref sigbuf) => {
                    if *pubkey_encoding == TransactionPublicKeyEncoding::Uncompressed {
                        have_uncompressed = true;
                    }

                    let (pubkey, next_sighash) = TransactionSpendingCondition::next_verification(
                        &cur_sighash,
                        cond_code,
                        self.tx_fee,
                        self.nonce,
                        pubkey_encoding,
                        sigbuf,
                        mode,
                    )?;
                    cur_sighash = next_sighash;
                    num_sigs = num_sigs
                        .checked_add(1)
                        .ok_or(AuthError::VerifyingError("Too many signatures".to_string()))?;
                    pubkey
                }
            };
            pubkeys.push(pubkey);
        }

        if num_sigs != self.signatures_required {
            return Err(AuthError::VerifyingError(
                "Incorrect number of signatures".to_string(),
            ));
        }

        if have_uncompressed && self.hash_mode == MultisigHashMode::P2WSH {
            return Err(AuthError::VerifyingError(
                "Uncompressed keys are not allowed in this hash mode".to_string(),
            ));
        }

        let addr = StacksAddress::from_public_keys(
            0,
            &self.hash_mode.to_address_hash_mode(),
            self.signatures_required as usize,
            &pubkeys,
        )
        .ok_or_else(|| {
            AuthError::VerifyingError("Failed to generate address from public keys".to_string())
        })?;

        if addr.bytes() != &self.signer {
            return Err(AuthError::VerifyingError(format!(
                "Signer hash does not equal hash of public key(s): {} != {}",
                addr.bytes(),
                self.signer
            )));
        }

        Ok(cur_sighash)
    }
