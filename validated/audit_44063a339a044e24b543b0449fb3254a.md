## Title
SSRF via unauthenticated/unvalidated mirror URLs in Data Layer subscription download - (File: chia/data_layer/download_data.py)

### Summary
The DataLayer service accepts arbitrary, attacker/caller-supplied URLs through the `subscribe` RPC endpoint and through on-chain mirror coins retrieved via `dl_get_mirrors`, then uses those URLs directly as the target of outbound `aiohttp` GET requests in `http_download()`, with no validation of scheme, host, or IP range (no loopback/private/link-local blocking). This lets a local RPC caller or any Data Layer peer that publishes a mirror coin force the node to issue GET requests to arbitrary internal/loopback/private addresses, matching the SSRF bug class in the referenced LocalAI advisory (unsanitized URL passed straight to a fetch routine).

### Finding Description
`DataLayerRpcApi.subscribe()` takes a raw `urls` list from the RPC request body and forwards it unmodified to `DataLayer.subscribe()`, which stores each URL as a `ServerInfo` with no validation. [1](#0-0) [2](#0-1) 

Separately, `update_subscriptions_from_wallet()` pulls mirror URLs from on-chain mirror coins (via `dl_get_mirrors`) and merges them into the subscription's server list — these URLs originate from arbitrary on-chain coin memos created by `create_new_mirror()`/`add_mirror`, i.e., any party who can spend to create a mirror coin controls the URL string that ends up here. [3](#0-2) [4](#0-3) 

During the periodic sync loop, `fetch_and_validate()` picks a `server_info.url` from the subscription/mirror list and passes it into `insert_from_delta_file()` → `download_file()` → `http_download()`. [5](#0-4) [6](#0-5) 

`http_download()` issues the actual outbound request using `server_info.url + "/" + filename` verbatim, with no scheme allowlist and no check against loopback/private/link-local address ranges: [7](#0-6) 

The only validation present in this module (`is_filename_valid()`) checks the *filename* format, not the URL/host itself. [8](#0-7) 

This mirrors the LocalAI SSRF bug class exactly: an unauthenticated/unsanitized URL field is passed straight into an HTTP fetch routine (`gallery.GetGalleryConfigFromURLWithContext` there, `http_download`/`aiohttp.ClientSession.get` here) without validating that the target is not an internal/private/loopback address.

### Impact Explanation
A local RPC caller (or, via mirror coins, any chain participant who creates a mirror for a store the victim node subscribes to/tracks) can force the victim DataLayer node to issue outbound HTTP GET requests to arbitrary internal endpoints (e.g., cloud metadata services, internal admin APIs, loopback-bound RPC ports). Response handling in `download_file()`/`http_download()` writes the fetched body to disk and, on failure, surfaces exception details through logs — partial content/error leakage is possible, and the request itself can be used to probe or interact with internal-only services reachable from the node's network position. This is a network-boundary violation with confidentiality/availability implications on internal infrastructure, matching CVSS vector emphasis on `SC:H` (subsequent system confidentiality) with no direct chain-state or fund-movement impact.

### Likelihood Explanation
Reachable via two paths that don't require special privileges beyond normal DataLayer usage: (1) the `subscribe` RPC endpoint accepts fully attacker-controlled URLs directly from the local RPC caller, and (2) mirror URLs are attacker-controlled on-chain data (any coin creator can publish a mirror with an arbitrary URL string) that get merged into `update_subscriptions_from_wallet()` for any store a node is subscribed to. Both paths lead deterministically into `http_download()` on the next `periodically_manage_data()` cycle, requiring no race condition or timing dependency.

### Recommendation
Validate mirror/subscription URLs before storing and before use in `http_download()`/`download_file()`: enforce an allowed scheme (`http`/`https`), resolve the host and reject loopback, link-local, private (RFC1918), and other reserved/internal IP ranges, and re-validate at request time (not just at input time) to defend against DNS rebinding. Apply this validation both in `DataLayer.subscribe()` (RPC-supplied URLs) and in `update_subscriptions_from_wallet()` (on-chain mirror URLs) before they reach `fetch_and_validate()`.

### Proof of Concept
1. Start a local DataLayer node and create a data store.
2. Call the `subscribe` RPC with a URL pointing at an internal-only address, e.g. `data_rpc_api.subscribe(request={"id": store_id.hex(), "urls": ["http://169.254.169.254"]})` — this is accepted with no validation, exactly as shown in the existing test using `"http://127.0.0.1/8000"`. [9](#0-8) 
3. Wait for `periodically_manage_data()`'s next cycle (or directly call `fetch_and_validate(store_id)`); the node performs an outbound GET to `http://169.254.169.254/<filename>` via `http_download()`, with response bytes written to `target_filename_path` and errors logged, without ever validating the destination is internal. [7](#0-6)

```python
def is_filename_valid(filename: str, group_by_store: bool = False) -> bool:
    if group_by_store:
        if filename.count("/") != 1:
            return False
        filename = filename.replace("/", "-")

    split = filename.split("-")

    try:
        raw_store_id, raw_node_hash, file_type, raw_generation, raw_version, *rest = split
        store_id = bytes32(bytes.fromhex(raw_store_id))
        node_hash = bytes32(bytes.fromhex(raw_node_hash))
        generation = int(raw_generation)
    except ValueError:
        return False

    if len(rest) > 0:
        return False

    # TODO: versions should probably be centrally defined
    if raw_version != "v1.0.dat":
        return False

    if file_type not in {"delta", "full"}:
        return False

    generate_file_func = get_delta_filename if file_type == "delta" else get_full_tree_filename
    reformatted = generate_file_func(
        store_id=store_id, node_hash=node_hash, generation=generation, group_by_store=False
    )

    return reformatted == filename
```

```python
async def http_download(
    target_filename_path: Path,
    filename: str,
    proxy_url: str | None,
    server_info: ServerInfo,
    timeout: aiohttp.ClientTimeout,
    log: logging.Logger,
    max_delta_file_size: int,
) -> None:
    """
    Download a file from a server using aiohttp.
    Raises exceptions on errors
    """
    async with aiohttp.ClientSession() as session:
        headers = {"accept-encoding": "gzip"}
        async with session.get(
            server_info.url + "/" + filename,
            headers=headers,
            timeout=timeout,
            proxy=proxy_url,
        ) as resp:
            resp.raise_for_status()
            size = int(resp.headers.get("content-length", 0))
            max_delta_file_size_bytes = max_delta_file_size * 1024 * 1024
            if size > max_delta_file_size_bytes:
                raise MaxDeltaFileSizeExceededError(f"Maximum delta file size exceeded: {max_delta_file_size} MiB.")
            log.debug(f"Downloading delta file {filename}. Size {size} bytes.")
```
