### Title
Forged `ReceivedOutput` offsets create unspendable reported funds - ([File: networks/bitcoin/src/wallet/mod.rs])

### Summary
`ReceivedOutput::read` accepts the scalar offset, `TxOut`, and `OutPoint` as independent attacker-controlled fields without verifying that the output script corresponds to the wallet key shifted by that offset. This permits a forged serialized output to enter the spend-construction path while being impossible to sign successfully.

### Finding Description
`Scanner::register_offset` normally establishes the invariant that `output.script_pubkey == P2TR(key + G * offset)` before recording the offset. [1](#0-0)  However, `ReceivedOutput::read` deserializes all three fields and returns the object without reconstructing or comparing that script. [2](#0-1)  `SignableTransaction::new` subsequently trusts the encoded offset and output as spend metadata. [3](#0-2) 

### Impact Explanation
An attacker who can supply serialized `ReceivedOutput` bytes can replace a valid offset with another scalar or combine an unrelated offset, output, and outpoint. The wallet can report the referenced funds as received and construct a transaction input for them, but the resulting signature is made under the wrong tweaked key and cannot authorize the actual output. This produces funds reported received that are not spendable.

### Likelihood Explanation
The attack requires an untrusted party to provide serialized `ReceivedOutput` data or corrupt an untrusted output cache. Within that input model, exploitation is deterministic because no semantic consistency check or authentication is performed during deserialization.

### Recommendation
Bind `ReceivedOutput` to the scanner’s base key during deserialization by recalculating `p2tr_script_buf(key + G * offset)` and rejecting records whose `output.script_pubkey` differs. Alternatively, serialize an authenticated scanner identifier or keyed commitment with each output and verify it before accepting the record.

  #[cfg(feature = "std")]
  pub fn read<R: Read>(r: &mut R) -> io::Result<ReceivedOutput> {
    let offset = Secp256k1::read_F(r)?;
    let output;
    let outpoint;
    {
      let mut buf_r = BufReader::with_capacity(0, r);

    }

  }
