### Title
`CW721ERC721Pointer` only supports unsafe NFT transfers, permanently freezing tokens sent to non-ERC721-aware contracts - (File: contracts/src/CW721ERC721Pointer.sol)

### Summary
`CW721ERC721Pointer` overrides `transferFrom()` to relay the transfer to the underlying CosmWasm CW721 contract via the wasmd precompile, but it never overrides `safeTransferFrom(address,address,uint256)` or `safeTransferFrom(address,address,uint256,bytes)`. Those two functions remain the default OpenZeppelin v5 implementations, which operate purely on the contract's local `_owners`/`_balances` storage rather than proxying to the CW721 contract, since the pointer never calls the inherited `_mint`/`_update` to populate that local storage.

### Finding Description
`transferFrom()` in the pointer contract is fully re-implemented to look up the real owner from the CW721 contract (`ownerOf(tokenId)`, which queries wasmd) and then execute a `transfer_nft` CosmWasm message: [2](#0-1) . However, `approve()` and `setApprovalForAll()` are likewise re-implemented to proxy to the CW721 contract [3](#0-2) , but `safeTransferFrom` is conspicuously absent from the overridden "Transactions" section [4](#0-3) .

Because the contract inherits from OpenZeppelin's `ERC721` (v5.0.1) without ever calling `_mint` to populate the base contract's internal ownership storage, the base `safeTransferFrom` functions (which call `_update`/`_ownerOf` against local storage) operate on state that is never synchronized with the actual CW721 owner tracked in CosmWasm. This causes `safeTransferFrom` calls to either revert unconditionally (due to an owner mismatch between the CW721 real owner and the pointer's local storage, which never reflects a minted token) or otherwise fail to execute the real CW721 transfer at all. In either case, the "safe" ERC721 transfer path — the only path in the ERC721 standard that performs the `onERC721Received` receiver-capability check — is non-functional on the pointer contract. Users and integrators are therefore forced to rely exclusively on the unsafe `transferFrom()` path shown above, which never checks whether the recipient contract is capable of holding or moving the NFT.

This is the same bug class as the external report: use of `transferFrom`/`_transfer`-style unsafe transfer instead of `safeTransferFrom`, but here the impact is stronger because the pointer contract provides *no working safe alternative whatsoever* — any recipient contract that does not have bespoke logic to re-invoke the wasmd precompile's `transfer_nft` on the CW721 contract can never move the NFT back out, since ownership is tracked in CosmWasm state under the CW721 contract's own transfer semantics, not standard ERC721 approval/transfer flows that a generic contract wallet might expect.

### Impact Explanation
Any CW721-backed NFT transferred via the pointer's `transferFrom()` to a smart contract address that is not specifically built to interact with CW721 pointer contracts (e.g., a generic multisig, vault, or DeFi contract expecting standard ERC721 `safeTransferFrom` semantics with `onERC721Received` handling) can become permanently stuck. The receiving contract has no way to detect it received the NFT (no callback fired) and, more importantly, no generic mechanism exists to call back into the specific CW721 `transfer_nft` message via the wasmd precompile to move it out, since that requires custom integration knowledge specific to Sei's CW721 pointer design. This constitutes permanent freezing of the asset, matching the required impact bar (permanent freezing of funds/NFTs).

### Likelihood Explanation
Likelihood is moderate: any user or contract integrating with the ERC721 pointer contract naturally expects `safeTransferFrom` to work as specified by the ERC721 standard and to protect against sending to incompatible receivers. Since that safety net is broken/non-functional, and only the unsafe `transferFrom()` is reliably usable, any transfer to a contract address (marketplace, vault, multisig, etc.) that assumes standard ERC721 recoverability is at risk. This is a normal, permissionless call path — any transaction sender holding a pointer-wrapped CW721 NFT can trigger it.

### Recommendation
Override `safeTransferFrom(address,address,uint256)` and `safeTransferFrom(address,address,uint256,bytes)` in `CW721ERC721Pointer` to route through the same CW721 `transfer_nft` execution path as `transferFrom()`, while additionally performing the `IERC721Receiver.onERC721Received` check on `to` when it is a contract, mirroring the semantics of the reference OpenZeppelin `_safeTransfer` logic (as already done correctly in the plain `ERC721.sol` example implementation elsewhere in this repo) [5](#0-4) .

### Proof of Concept
1. Deploy a `CW721ERC721Pointer` for an existing CW721 collection via `AddCW721` and mint/own a token as EOA `A` [6](#0-5) .
2. Call `pointer.safeTransferFrom(A, B, tokenId)`: this invokes the inherited OpenZeppelin logic which reads the local (never-populated) `_ownerOf(tokenId)` storage instead of querying the CW721 contract, causing an owner mismatch revert or otherwise failing to execute the CW721 `transfer_nft` message — the safe transfer path is unusable.
3. As a consequence, `A` uses `pointer.transferFrom(A, C, tokenId)` instead (the only functional path), where `C` is a smart-contract address (e.g., a vault contract) not specifically designed to call back into the CW721 pointer's custom `transfer_nft`/wasmd-precompile flow.
4. `transferFrom()` succeeds unconditionally (no receiver check) [2](#0-1) , and the underlying CW721 ownership moves to `C`. `C` has no generic mechanism to move the NFT back out (no `onERC721Received` callback ever fired, and no standard `IERC721.transferFrom` from `C`'s own address will succeed unless `C` specifically implements the wasmd-precompile call), permanently freezing the NFT.

    // Transactions
    function transferFrom(address from, address to, uint256 tokenId) public override {
        if (to == address(0)) {
            revert ERC721InvalidReceiver(address(0));
        }
        require(from == ownerOf(tokenId), "`from` must be the owner");
        string memory recipient = _formatPayload("recipient", _doubleQuotes(AddrPrecompile.getSeiAddr(to)));
        string memory tId = _formatPayload("token_id", _doubleQuotes(Strings.toString(tokenId)));
        string memory req = _curlyBrace(_formatPayload("transfer_nft", _curlyBrace(_join(recipient, tId, ","))));
        _execute(bytes(req));
    }

    function approve(address approved, uint256 tokenId) public override {
        string memory spender = _formatPayload("spender", _doubleQuotes(AddrPrecompile.getSeiAddr(approved)));
        string memory tId = _formatPayload("token_id", _doubleQuotes(Strings.toString(tokenId)));
        string memory req = _curlyBrace(_formatPayload("approve", _curlyBrace(_join(spender, tId, ","))));
        _execute(bytes(req));
    }

    function setApprovalForAll(address operator, bool approved) public override {
        string memory op = _curlyBrace(_formatPayload("operator", _doubleQuotes(AddrPrecompile.getSeiAddr(operator))));
        if (approved) {
            _execute(bytes(_curlyBrace(_formatPayload("approve_all", op))));
        } else {
            _execute(bytes(_curlyBrace(_formatPayload("revoke_all", op))));
        }
    }

    function _execute(bytes memory req) internal returns (bytes memory) {
        (bool success, bytes memory ret) = WASMD_PRECOMPILE_ADDRESS.delegatecall(
            abi.encodeWithSignature(
                "execute(string,bytes,bytes)",
                Cw721Address,
                bytes(req),
                bytes("[]")
            )
        );
        require(success, "CosmWasm execute failed");
        return ret;
    }

func (p PrecompileExecutor) AddCW721(ctx sdk.Context, method *ethabi.Method, caller common.Address, args []interface{}, value *big.Int, evm *vm.EVM, suppliedGas uint64, hooks *tracing.Hooks) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}
	if err := pcommon.ValidateArgsLength(args, 1); err != nil {
		return nil, 0, err
	}
	cwAddr := args[0].(string)
	existingAddr, existingVersion, exists := p.evmKeeper.GetERC721CW721Pointer(ctx, cwAddr)
	if exists && existingVersion >= 4 {
		return nil, 0, fmt.Errorf("pointer at %s with version %d exists when trying to set pointer for version %d", existingAddr.Hex(), existingVersion, cw721.CurrentVersion)
	}
	cwAddress, err := sdk.AccAddressFromBech32(cwAddr)
	if err != nil {
		return nil, 0, err
	}
	res, err := p.wasmdKeeper.QuerySmart(ctx, cwAddress, []byte("{\"contract_info\":{}}"))
	if err != nil {
		return nil, 0, err
	}
	formattedRes := map[string]interface{}{}
	if err := json.Unmarshal(res, &formattedRes); err != nil {
		return nil, 0, err
	}
	name := formattedRes["name"].(string)
	symbol := formattedRes["symbol"].(string)
	constructorArguments := []interface{}{
		cwAddr, name, symbol,
	}

	packedArgs, err := cw721.GetParsedABI().Pack("", constructorArguments...)
	if err != nil {
		panic(err)
	}
	bin := append(cw721.GetBin(), packedArgs...)
	if value == nil {
		value = utils.Big0
	}
	ret, contractAddr, remainingGas, err := evm.Create(caller, bin, suppliedGas, uint256.MustFromBig(value))
	if err != nil {
		return
	}
	err = p.evmKeeper.SetERC721CW721Pointer(ctx, cwAddr, contractAddr)
	if err != nil {
		return
	}

	ctx.EventManager().EmitEvent(sdk.NewEvent(
		types.EventTypePointerRegistered, sdk.NewAttribute(types.AttributeKeyPointerType, "cw721"),
		sdk.NewAttribute(types.AttributeKeyPointerAddress, contractAddr.Hex()), sdk.NewAttribute(types.AttributeKeyPointee, cwAddr),
		sdk.NewAttribute(types.AttributeKeyPointerVersion, fmt.Sprintf("%d", cw721.CurrentVersion))))
	ret, err = method.Outputs.Pack(contractAddr)
