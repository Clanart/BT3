### Title
Gasless module's `Disable` kill-switch is never enforced in the transaction-admission and bundling path, allowing gasless swaps to keep executing after the module is disabled - (File: `kaiax/gasless/impl/tx_pool.go`, `kaiax/gasless/impl/builder.go`, `kaiax/gasless/impl/getter.go`)

### Summary
The external report's root cause is a state flag (`sell.islisted`) that is set/updated by one function (`setlistforsell`) but never consulted by the function that actually performs the value-transferring action (`setbidtobuy`). The Kaia `kaiax/gasless` module has the same structural flaw: the `GaslessConfig.Disable` flag - the module's intended kill-switch, settable via the `gasless.disable` CLI flag or automatically when a CN's lending balance drops below `GaslessLenderMinBal` - is read only by the informational RPC (`GaslessAPI.GaslessInfo`/`IsDisabled`) and by the one-time `Init` balance check, but it is never checked by the functions that actually admit, bundle, and execute gasless transactions: `IsModuleTx`/`IsApproveTx`/`IsSwapTx` (`kaiax/gasless/impl/getter.go`), `PreAddTx` (`kaiax/gasless/impl/tx_pool.go`), `isReady`/`isApproveTxReady`/`isSwapTxReady` (`kaiax/gasless/impl/tx_pool.go`), and `ExtractTxBundles` (`kaiax/gasless/impl/builder.go`).

### Finding Description
`GaslessConfig.Disable` is defined and set here: [1](#0-0) 

It is surfaced only through the RPC/API layer: [2](#0-1) 
and through the module's own `IsDisabled()` accessor and the one-time balance check performed in `Init`: [3](#0-2) 

However, the actual transaction-pool admission logic that decides whether a tx is treated as part of a gasless bundle never looks at `Disable`: [4](#0-3) 

Nor does the "ready to promote" logic used to sequence approve/swap pairs in the pool: [5](#0-4) 

Nor does the block-builder logic that actually turns an approve/swap pair into an executable bundle containing a CN-funded `LendTx`: [6](#0-5) 

The pattern-matching predicates `IsApproveTx`/`isApproveTx`/`IsSwapTx` that gate all the above only check the token allow-list and swap-router address, never `Disable`: [7](#0-6) 

By contrast, the sibling `auction` module correctly gates its equivalent hot path (`ExtractTxBundles`) on a runtime state flag (`bidPool.running`): [8](#0-7) 

This asymmetry shows the check is straightforward to add and was simply omitted for `gasless`, exactly mirroring the `setbidtobuy`/`sell.islisted` omission in the external report: a flag meant to gate/kill an economic action is set and exposed for read, but the code path that performs the economic action (bundling+funding a swap via the CN's `LendTx`) never consults it.

### Impact Explanation
When `GaslessConfig.Disable` becomes `true` at runtime - either because an operator restarts/re-configures the CN with `--gasless.disable`, or, more importantly, because the CN's own balance falls under `GaslessLenderMinBal` while gasless is actively lending gas - any already-submitted or newly submitted approve+swap transaction pair from an ordinary, unprivileged sender is still recognized as `IsModuleTx`/`IsSwapTx`/`IsApproveTx`, is still admitted into the bundle-tx tracking structures (`PreAddTx`), still promoted (`isReady`), and is still turned into an on-chain bundle that generates a `LendTx` funded by the CN's own KAIA balance (`GetLendTxGenerator`, referenced in `ExtractTxBundles`). The intended kill-switch — meant to stop the CN from lending funds it can no longer safely afford, or that the operator explicitly wants to halt — has no effect on the actual execution path. This is a direct instance of unauthorized value movement (CN funds paying for third-party gas) proceeding after the responsible party revoked authorization, the same class of harm as the referenced report ("seller loses control over the sale").

### Likelihood Explanation
Any unprivileged party who can submit a legally-formed approve+swap transaction pair to a public RPC endpoint can trigger this path; no special privilege is required on the caller's side. The only precondition is that the CN operator has set (or the code has auto-set) `Disable=true` at some point after the module started operating with `Disable=false`, which is a realistic operational scenario (balance depletion from continuous lending, or an operator trying to pause gasless service without a full node restart).

### Recommendation
Add an explicit `g.IsDisabled()` (or equivalent) check at the start of `IsModuleTx`/`IsApproveTx`/`IsSwapTx` in `kaiax/gasless/impl/getter.go`, and/or gate `PreAddTx`, `isReady`, and `ExtractTxBundles` in `kaiax/gasless/impl/tx_pool.go` and `kaiax/gasless/impl/builder.go` on the current `Disable` state (protected by `gaslessInfoMu`), mirroring the `atomic.LoadUint32(&a.bidPool.running)` guard already used in the `auction` module's `ExtractTxBundles`.

### Proof of Concept
1. Start a CN with the gasless module enabled (`Disable=false`).
2. Have the CN's balance drop below `GaslessLenderMinBal`, or have the operator issue a config change setting `Disable=true` at runtime.
3. As an ordinary user, submit a valid `approve(router, MaxUint)` transaction on an allow-listed token followed by a valid `swapForGas(token, amountIn, minAmountOut, amountRepay)` transaction, satisfying all `IsExecutable`/`VerifyExecutable` conditions in `kaiax/gasless/impl/getter.go`.
4. Observe that `PreAddTx`, `isReady`, and `ExtractTxBundles` still classify and bundle the pair (none of them check `Disable`), so the CN's builder still generates and includes a `LendTx` funding the sender's gas, and the swap still settles — even though `debug_gaslessInfo`/`IsDisabled()` reports the module as disabled.

func (g *GaslessModule) PreAddTx(tx *types.Transaction, local bool) error {
	g.knownTxsMu.RLock()
	defer g.knownTxsMu.RUnlock()

	if knownTx, ok := g.knownTxs.get(tx.Hash()); ok && knownTx.elapsedPromotedOrAddedTime() < KnownTxTimeout {
		return ErrUnableToAddKnownBundleTx
	}

	if g.IsBundleTx(tx) {
		if uint(g.knownTxs.numQueue()) >= g.GetMaxBundleTxsInQueue() {
			return ErrBundleTxQueueFull
		}
		g.knownTxs.add(tx, TxStatusQueue)
	}
	return nil
}

// Check promotion condition.
func (g *GaslessModule) isReady(txs map[uint64]*types.Transaction, i uint64, ready types.Transactions) bool {
	tx := txs[i]

	if g.IsApproveTx(tx) && i < uint64(math.MaxUint64) {
		return g.isApproveTxReady(tx, txs[i+1])
	}

	if g.IsSwapTx(tx) {
		var prevTx *types.Transaction
		if len(ready) > 0 {
			prevTx = ready[len(ready)-1]
		}
		return g.isSwapTxReady(tx, prevTx)
	}

	return false
}

// isApproveTxReady assumes that the caller checked `g.IsApproveTx(approveTx)`
func (g *GaslessModule) isApproveTxReady(approveTx, nextTx *types.Transaction) bool {
	addr, err := types.Sender(g.signer, approveTx)
	if err != nil {
		return false
	}
	nonce := g.getCurrentStateNonce(addr)

	if approveTx.Nonce() != nonce {
		return false
	}
	if nextTx == nil || !g.IsSwapTx(nextTx) {
		return false
	}

	return g.IsExecutable(approveTx, nextTx)
}

// isSwapTxReady assumes that the caller checked `g.IsSwapTx(swapTx)`
func (g *GaslessModule) isSwapTxReady(swapTx, prevTx *types.Transaction) bool {
	addr, err := types.Sender(g.signer, swapTx)
	if err != nil {
		return false
	}
	nonce := g.getCurrentStateNonce(addr)

	var approveTx *types.Transaction
	if swapTx.Nonce() == nonce {
		approveTx = nil
	} else if swapTx.Nonce() == nonce+1 {
		if prevTx == nil || !g.IsApproveTx(prevTx) {
			return false
		}
		approveTx = prevTx
	} else {
		return false
	}

	return g.IsExecutable(approveTx, swapTx)
}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
}

// IsApproveTx checks following conditions:
// A1. tx.to is a whitelisted ERC20 token.
// A2. tx.data is `approve(spender, amount)`.
// A3. spender is a whitelisted SwapRouter contract.
// A4. amount is MaxUint.
func (g *GaslessModule) IsApproveTx(tx *types.Transaction) bool {
	args, ok := decodeApproveTx(tx, g.signer)
	return ok && g.isApproveTx(args)
}

func (g *GaslessModule) isApproveTx(args *ApproveArgs) bool {
	g.gaslessInfoMu.RLock()
	defer g.gaslessInfoMu.RUnlock()

	return g.allowedTokens[args.Token] && // A1
		g.swapRouter == args.Spender && // A3
		args.Amount.Cmp(abi.MaxUint256) == 0 // A4
}

// IsSwapTx checks following conditions:
// S1. tx.to is a whitelisted SwapRouter contract.
// S2. tx.data is `swapForGas(token, amountIn, minAmountOut, amountRepay)`.
// S3. token is a whitelisted ERC20 token.
func (g *GaslessModule) IsSwapTx(tx *types.Transaction) bool {
	args, ok := decodeSwapTx(tx, g.signer)
	return ok && g.isSwapTx(args)
}
