### Title
Unauthenticated `ReceivedOutput` deserialization permits nonexistent UTXOs to be reported as spendable funds - ([File: networks/bitcoin/src/wallet/mod.rs](networks/bitcoin/src/wallet/mod.rs))

### Summary
`ReceivedOutput::read` accepts a scalar offset, complete `TxOut`, and `OutPoint` as independent serialized claims without binding the offset to the output’s Taproot key or proving that the outpoint exists on chain. [1](#0-0)  The resulting object exposes the attacker-selected `TxOut.value` as a received balance. [2](#0-1)  This is analogous to a bad oracle: attacker-controlled bytes describing external chain state are converted into a trusted “spendable output” representation.

### Finding Description
`ReceivedOutput` is defined as “a spendable output,” consisting of an offset, output, and outpoint. [3](#0-2)  Its deserializer only performs scalar and Bitcoin consensus decoding; it does not verify that `output.script_pubkey` corresponds to `key + G * offset`, nor that `outpoint` refers to a confirmed UTXO. [1](#0-0)  Although `Scanner::scan_transaction` normally creates this structure only after matching a registered script and computing the transaction ID, deserialization bypasses those checks entirely. [4](#0-3) 

### Impact Explanation
Any consumer that accepts serialized `ReceivedOutput` values across an untrusted boundary can be induced to account for arbitrary Bitcoin value at a nonexistent or already-spent outpoint. If the supplied `TxOut` uses a scanned Taproot script, downstream balance/accounting logic can report the claimed amount as received even though it cannot be spent. If used as collateral, deposit evidence, scheduler input, or wallet state, this permits overvaluation of the wallet’s available funds.

### Likelihood Explanation
The attack only requires control of the serialized bytes supplied to `ReceivedOutput::read`; no validator privileges, key shares, signatures, or blockchain manipulation are required. The attacker can choose a valid scanned script, an arbitrary offset, a large value, and an arbitrary outpoint. Actual loss depends on the consumer crediting or acting on the decoded output before independently verifying UTXO existence and ownership.

### Recommendation
Do not expose `ReceivedOutput::read` as proof that an output exists or is spendable. Deserialize through an API which receives the expected group key and validates `p2tr_script_buf(key + GENERATOR * offset) == output.script_pubkey`; additionally require chain inclusion and unspentness evidence, such as a trusted UTXO lookup or Merkle/block confirmation, before treating the result as received funds. Prefer making scanner-derived outputs distinct from merely decoded output claims.

### Proof of Concept
```rust
use bitcoin::{
  Amount, OutPoint, ScriptBuf, TxOut, Txid,
  consensus::serialize,
  hashes::Hash,
};
use bitcoin_serai::wallet::{p2tr_script_buf, ReceivedOutput};
use k256::{ProjectivePoint, Scalar};

fn forged_received_output_bytes() -> Vec<u8> {
  // Assume `group_key` is a key whose P2TR script is accepted by the caller.
  let group_key = ProjectivePoint::GENERATOR;
  let script: ScriptBuf = p2tr_script_buf(group_key).unwrap();

  let fake_output = TxOut {
    value: Amount::from_sat(u64::MAX),
    script_pubkey: script,
  };

  // This outpoint need not exist.
  let fake_outpoint = OutPoint {
    txid: Txid::all_zeros(),
    vout: 0,
  };

  let mut bytes = Vec::new();
  bytes.extend(Scalar::ZERO.to_bytes());
  bytes.extend(serialize(&fake_output));
  bytes.extend(serialize(&fake_outpoint));
  bytes
}

let forged = ReceivedOutput::read(&mut forged_received_output_bytes().as_slice()).unwrap();
assert_eq!(forged.value(), u64::MAX);
```

The decoded object reports `u64::MAX` satoshis as received value even though its outpoint is fabricated and no chain state was checked. [5](#0-4)

  #[cfg(feature = "std")]
  pub fn read<R: Read>(r: &mut R) -> io::Result<ReceivedOutput> {
    let offset = Secp256k1::read_F(r)?;
    let output;
    let outpoint;
    {
      let mut buf_r = BufReader::with_capacity(0, r);
      output =
        TxOut::consensus_decode(&mut buf_r).map_err(|_| io::Error::other("invalid TxOut"))?;
      outpoint =
        OutPoint::consensus_decode(&mut buf_r).map_err(|_| io::Error::other("invalid OutPoint"))?;
    }
    Ok(ReceivedOutput { offset, output, outpoint })
  }

  /// Scan a transaction.
  pub fn scan_transaction(&self, tx: &Transaction) -> Vec<ReceivedOutput> {
    let mut res = Vec::new();
    for (vout, output) in tx.output.iter().enumerate() {
      // If the vout index exceeds 2**32, stop scanning outputs
      let Ok(vout) = u32::try_from(vout) else { break };

      if let Some(offset) = self.scripts.get(&output.script_pubkey) {
        res.push(ReceivedOutput {
          offset: *offset,
          output: output.clone(),
          outpoint: OutPoint::new(tx.compute_txid(), vout),
        });
      }
    }
    res
  }
