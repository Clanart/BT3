### Title
Untrusted DataLayer mirror URLs are trusted for outbound HTTP fetches, enabling SSRF - (File: `chia/data_layer/data_layer.py`)

### Summary
The DataLayer mirror mechanism lets **any** spend-bundle submitter attach arbitrary URL strings to a coin sent to the permissionless mirror puzzle. These URLs are later trusted by a victim's DataLayer service and used to issue unauthenticated outbound `HTTP GET` requests, mirroring the CVE-2024-21643 root cause: an external, unauthenticated claim (`jku` URL in the .NET advisory; a mirror URL here) is trusted enough to trigger a network request the application makes on the claim author's behalf.

### Finding Description
Mirror coins are created with `create_mirror_puzzle()` = `P2_PARENT.curry(Program.to(1))`, a generic anyone-can-spend-style puzzle, and the association between a mirror and a `launcher_id`/store is encoded purely in `CREATE_COIN` memos, not cryptographically tied to ownership of the actual DataLayer singleton: [1](#0-0) [2](#0-1) 

Anyone can submit a spend bundle creating a coin with `puzzle_hash = MIRROR_PUZZLE_HASH` and `memos = [launcher_id, url1, url2, ...]` for any `launcher_id`, because `create_new_mirror()`/`dl_new_mirror` RPC just performs a standard `generate_signed_transaction` with attacker-chosen memo bytes and no signature or ownership check tying the memo `launcher_id` to the spender: [3](#0-2) 

These mirror URLs are then pulled unconditionally by any node tracking that `launcher_id` via `update_subscriptions_from_wallet()`: [4](#0-3) 

and subsequently used as real HTTP fetch targets in `fetch_and_validate()` → `insert_from_delta_file()` → `download_file()` → `http_download()`, which issues an unauthenticated `session.get(server_info.url + "/" + filename, ...)` request: [5](#0-4) [6](#0-5) 

No allowlisting, scheme restriction, or private-network filtering is applied to `server_info.url`; only the delta filename is validated (`is_filename_valid`), not the destination host. The `.cursor/context/data-layer.md` doc for this module explicitly notes "Do not treat mirror URLs... as trusted data sources," acknowledging this is a recognized trust boundary, though the code still performs the fetch without sandboxing the destination.

### Impact Explanation
Any wallet operator who is subscribed to (or auto-tracks) a DataLayer store can be coerced into making arbitrary outbound HTTP GET requests to attacker-chosen hosts/ports (`http://internal-host:port/<attacker-controlled-but-format-constrained-filename>`), including RFC1918/loopback/cloud-metadata addresses, since no URL is validated against SSRF protections. This is a classic SSRF (CWE-918), matching the disclosed bug class (trusting a URL claim to make a request) though impact here is confined to a GET request rather than remote code execution — still meaningful for internal network reconnaissance/pivoting from a DataLayer node.

### Likelihood Explanation
Reachable by any unprivileged actor who can fund a standard coin spend to the public mirror puzzle with a chosen `launcher_id`/URL memo pair (`dl_new_mirror` RPC or direct `CREATE_COIN` condition), and requires only that a victim DataLayer node be subscribed to/tracking that store — a normal DataLayer client workflow, not a privileged or malicious-peer path.

### Recommendation
Restrict outbound mirror-fetch destinations (block loopback/link-local/private ranges by default, or require explicit user allowlisting of mirror hosts), and/or require operator confirmation before a newly-announced mirror URL is added to the automatic download rotation in `update_subscriptions_from_wallet()`/`get_available_servers_for_store()`.

### Proof of Concept
1. Attacker calls `dl_new_mirror` (or crafts a spend bundle directly) creating a coin to `MIRROR_PUZZLE_HASH` with `memos=[victim_launcher_id, "http://169.254.169.254/latest/meta-data/"]` and a minimal `amount`/fee, then gets it confirmed on chain.
2. A victim node that tracks `victim_launcher_id` (owner, subscriber, or DataLayer client resolving that store) calls `update_subscriptions_from_wallet()`, which pulls the attacker's URL into its DL store as an available server.
3. On the next `fetch_and_validate()` cycle, `http_download()` performs `session.get("http://169.254.169.254/latest/meta-data//" + filename, ...)`, causing the victim's DataLayer process to issue the attacker-directed request.

def create_mirror_puzzle() -> Program:
    return P2_PARENT.curry(Program.to(1))


MIRROR_PUZZLE_HASH = create_mirror_puzzle().get_tree_hash()


def get_mirror_info(
    parent_puzzle: Program | SerializedProgram, parent_solution: Program | SerializedProgram
) -> tuple[bytes32, list[bytes]]:
    assert type(parent_puzzle) is type(parent_solution)
    _, conditions = run_with_cost(parent_puzzle, INFINITE_COST, parent_solution)
    for condition in conditions.as_iter():
        if (
            condition.first().as_python() == ConditionOpcode.CREATE_COIN
            and condition.at("rf").as_python() == create_mirror_puzzle().get_tree_hash()
        ):
            memos: list[bytes] = condition.at("rrrf").as_python()
            launcher_id = bytes32(memos[0])
            return launcher_id, [url for url in memos[1:]]

async def http_download(
    target_filename_path: Path,
    filename: str,
    proxy_url: str | None,
    server_info: ServerInfo,
    timeout: aiohttp.ClientTimeout,
    log: logging.Logger,
    max_delta_file_size: int,
) -> None:
    """
    Download a file from a server using aiohttp.
    Raises exceptions on errors
    """
    async with aiohttp.ClientSession() as session:
        headers = {"accept-encoding": "gzip"}
        async with session.get(
            server_info.url + "/" + filename,
            headers=headers,
            timeout=timeout,
            proxy=proxy_url,
        ) as resp:
            resp.raise_for_status()
            size = int(resp.headers.get("content-length", 0))
            max_delta_file_size_bytes = max_delta_file_size * 1024 * 1024
            if size > max_delta_file_size_bytes:
                raise MaxDeltaFileSizeExceededError(f"Maximum delta file size exceeded: {max_delta_file_size} MiB.")
            log.debug(f"Downloading delta file {filename}. Size {size} bytes.")
