### Title
Unauthenticated `ReceivedOutput` deserialization enables fabricated Bitcoin inputs to reach transaction signing - ([File: networks/bitcoin/src/wallet/mod.rs](networks/bitcoin/src/wallet/mod.rs))

### Summary

`ReceivedOutput::read` accepts an offset, claimed previous output, and outpoint entirely from untrusted bytes without authenticating that the outpoint exists, has the encoded value, or was produced by `Scanner`. [1](#0-0) 

### Finding Description

An attacker can serialize a `ReceivedOutput` containing the wallet's known P2TR script but a fabricated `TxOut` value and arbitrary `OutPoint`. `SignableTransaction::new` trusts that value as spendable input and converts the supplied outpoint into a transaction input. [2](#0-1) 

During `multisig`, the only consistency check is that the encoded previous output's `script_pubkey` equals the key after applying the encoded offset; it does not verify that the referenced UTXO exists or that its amount is authentic. [3](#0-2) 

The transaction machine then signs each attacker-supplied input using `Prevouts::All`, causing the fabricated amount and script to be committed into the Taproot sighash. [4](#0-3) 

### Impact Explanation

Fabricated bytes can be reported as received funds and can drive the threshold wallet to sign a transaction whose inputs are not spendable. This maps to an unrestricted-upload-style flaw: the deserializer constructs a security-sensitive “received output” object from unrestricted attacker bytes rather than requiring an authenticated scanner result.

Because Taproot sighashes commit to every supplied prevout when `Prevouts::All` is used, inclusion of a forged input changes the signed sighashes for the transaction. [5](#0-4) 

### Likelihood Explanation

The attacker only needs control over bytes passed to `ReceivedOutput::read` and knowledge of the wallet's public P2TR script. The parsing path accepts canonical scalar and Bitcoin consensus encodings without requiring a block, merkle proof, scanner result, or UTXO lookup. [1](#0-0) 

### Recommendation

Do not expose `ReceivedOutput::read` as a way to mint spendable outputs from untrusted data. Mark it trusted-only, authenticate serialized outputs, or replace it with a constructor that derives `ReceivedOutput` exclusively from `Scanner::scan_transaction`/`Scanner::scan_block` and a verified chain transaction. [6](#0-5) 

`SignableTransaction::new` or `multisig` should additionally require authenticated UTXO data, not merely a matching `script_pubkey`, before producing signing machines. [3](#0-2) 

### Proof of Concept

Conceptually, construct forged serialized bytes as:

```text
offset       = 32-byte secp256k1 encoding of Scalar::ZERO
output       = consensus TxOut {
                 value: attacker-claimed value,
                 script_pubkey: wallet's P2TR script
               }
outpoint     = consensus OutPoint {
                 txid: arbitrary 32-byte txid,
                 vout: 0
               }
```

Then feed those bytes to `ReceivedOutput::read`. Because the wallet's base P2TR script corresponds to offset zero, the script check in `SignableTransaction::multisig` succeeds. [3](#0-2) 

Use the resulting object as the only input to `SignableTransaction::new` with payments below the fabricated amount. The input sum is derived from the attacker-encoded `TxOut`, while the fabricated `OutPoint` becomes the transaction input. [2](#0-1) 

Calling `preprocess`, `sign`, and `complete` causes participants to sign a transaction spending the nonexistent or falsely valued outpoint; `complete` inserts the completed Schnorr signatures into the witnesses. [7](#0-6)

  /// Scan a transaction.
  pub fn scan_transaction(&self, tx: &Transaction) -> Vec<ReceivedOutput> {
    let mut res = Vec::new();
    for (vout, output) in tx.output.iter().enumerate() {
      // If the vout index exceeds 2**32, stop scanning outputs
      let Ok(vout) = u32::try_from(vout) else { break };

      if let Some(offset) = self.scripts.get(&output.script_pubkey) {
        res.push(ReceivedOutput {
          offset: *offset,
          output: output.clone(),
          outpoint: OutPoint::new(tx.compute_txid(), vout),
        });
      }
    }
    res
  }
