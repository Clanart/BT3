### Title
Unhandled `UnicodeDecodeError` when decoding attacker-controlled NFT metadata URIs crashes wallet RPC processing - ([File: chia/wallet/nft_wallet/nft_puzzle_utils.py])

### Summary
`get_nft_info_from_puzzle` decodes NFT metadata fields (`data_uris`, `meta_uris`, `license_uris`) taken directly from the on-chain NFT puzzle's curried metadata with `str(uri, "utf-8")` and no exception handling. Since these byte strings are fully attacker-controlled (any NFT minter can set the metadata `"u"`, `"mu"`, `"lu"` key/value pairs to arbitrary bytes), a malformed/non-UTF-8 URI causes an unhandled `UnicodeDecodeError`. This mirrors the comrak bug class: application code assumes an internally-produced/derived data structure (here, puzzle-derived metadata) is well-formed, when in fact it can be attacker-supplied and malformed, leading to a crash when the "AST"-like structure is rendered/processed.

### Finding Description
`UncurriedNFT.uncurry()` extracts `data_uris`, `meta_uris`, and `license_uris` directly from the curried metadata program of an NFT puzzle without validating their content — they are simply the raw atoms under keys `b"u"`, `b"mu"`, `b"lu"` [1](#0-0) .

`get_nft_info_from_puzzle` then converts each of these URI atoms to Python strings by calling `str(uri, "utf-8")` with no `try/except`, unlike the sibling CAT memo-decoding path elsewhere in the codebase (`compute_memos`/`run_block.py`) which explicitly catches `UnicodeError` and falls back to an empty value [2](#0-1) . Because NFT metadata originates from the minter's chosen puzzle solution (fully attacker-controlled bytes, not validated by consensus to be valid UTF-8), any NFT whose metadata contains non-UTF-8 bytes in the `u`/`mu`/`lu` fields will make this function raise an unhandled `UnicodeDecodeError` instead of gracefully skipping/ignoring the bad value.

This function is reachable from wallet-facing entry points: `chia/wallet/wallet_rpc_api.py` (`nft_get_info`) and `chia/wallet/wallet_state_manager.py`'s `manual_nft_search` — both of which are invoked when a wallet inspects/looks up an NFT it holds (e.g., after receiving an NFT transfer or offer settlement from any unprivileged counterparty) [3](#0-2) .

### Impact Explanation
An unprivileged attacker can mint (or send via offer/transfer) an NFT whose puzzle-curried metadata contains non-UTF-8 byte sequences in the `u`, `mu`, or `lu` metadata keys. Once that NFT lands in a victim wallet and the wallet (or its RPC client/UI) calls `nft_get_info` or otherwise triggers `get_nft_info_from_puzzle`/`manual_nft_search` to display NFT details, the RPC call raises an uncaught exception. This is a spend/transfer-triggered halt of a specific wallet-facing operation (transaction-processing/RPC-handling halt on attacker-chosen data), matching the "spend-triggered transaction-processing halt" impact category. It does not directly enable fund theft or supply inflation, keeping severity at Medium, consistent with the CVSS `A:L` characterization of the original comrak advisory.

### Likelihood Explanation
Likelihood is high for triggering: any party can mint an NFT with arbitrary metadata bytes and send/offer it to a target wallet with no special privileges, matching the "wallet user / NFT ownership flow" reachable actor set. The only precondition is that the victim wallet (or an integrator's tooling) calls the affected RPC/API path against the malicious NFT, which is a normal, expected user action (viewing NFT details).

### Recommendation
Wrap the `str(uri, "utf-8")` conversions in `get_nft_info_from_puzzle` in `try/except UnicodeDecodeError` (mirroring the pattern already used in `compute_memos_for_spend`/`run_block.py`), skipping or substituting a safe placeholder for undecodable URIs instead of propagating the exception. More generally, audit other places that treat curried/uncurried puzzle-derived byte fields (metadata, memos, hints) as guaranteed-valid UTF-8 and add the same defensive handling.

### Proof of Concept
1. Mint an NFT (using standard NFT minting flow) whose metadata program includes a key `b"u"` (or `b"mu"`/`b"lu"`) mapped to a byte string containing an invalid UTF-8 sequence, e.g. `b"\xff\xfe"`.
2. Transfer or offer this NFT to a victim wallet; the victim's wallet syncs and stores the coin normally (storage of `UncurriedNFT`/`Program` does not require UTF-8 validity) [4](#0-3) .
3. Victim (or victim's UI/RPC client) calls the `nft_get_info` RPC (or any code path reaching `get_nft_info_from_puzzle`/`manual_nft_search`) for that NFT.
4. `str(uri, "utf-8")` raises `UnicodeDecodeError`, which is not caught, causing the RPC call handling that NFT to fail/crash instead of returning NFT info [5](#0-4) .

    @classmethod
    def uncurry(cls, mod: Program, curried_args: Program) -> Self | None:
        """
        Try to uncurry a NFT puzzle
        :param cls UncurriedNFT class
        :param mod: uncurried Puzzle program
        :param uncurried_args: uncurried arguments to program
        :return Uncurried NFT
        """
        if mod != SINGLETON_TOP_LAYER_MOD:
            log.debug("Cannot uncurry NFT puzzle, failed on singleton top layer: Mod %s", mod)
            return None
        try:
            (singleton_struct, nft_state_layer) = curried_args.as_iter()
            singleton_mod_hash = singleton_struct.first()
            singleton_launcher_id = singleton_struct.rest().first()
            launcher_puzhash = singleton_struct.rest().rest()
        except ValueError as e:
            log.debug("Cannot uncurry singleton top layer: Args %s error: %s", curried_args, e)
            return None

        mod, curried_args = curried_args.rest().first().uncurry()
        if mod != NFT_MOD:
            log.debug("Cannot uncurry NFT puzzle, failed on NFT state layer: Mod %s", mod)
            return None
        try:
            # Set nft parameters
            nft_mod_hash, metadata, metadata_updater_hash, inner_puzzle = curried_args.as_iter()
            data_uris = Program.to([])
            data_hash = Program.to(0)
            meta_uris = Program.to([])
            meta_hash = Program.to(0)
            license_uris = Program.to([])
            license_hash = Program.to(0)
            edition_number = Program.to(1)
            edition_total = Program.to(1)
            # Set metadata
            for kv_pair in metadata.as_iter():
                if kv_pair.first().as_atom() == b"u":
                    data_uris = kv_pair.rest()
                if kv_pair.first().as_atom() == b"h":
                    data_hash = kv_pair.rest()
                if kv_pair.first().as_atom() == b"mu":
                    meta_uris = kv_pair.rest()
                if kv_pair.first().as_atom() == b"mh":
                    meta_hash = kv_pair.rest()
                if kv_pair.first().as_atom() == b"lu":
                    license_uris = kv_pair.rest()
                if kv_pair.first().as_atom() == b"lh":
                    license_hash = kv_pair.rest()
                if kv_pair.first().as_atom() == b"sn":
                    edition_number = kv_pair.rest()
                if kv_pair.first().as_atom() == b"st":
                    edition_total = kv_pair.rest()
            current_did: bytes32 | None = None
            transfer_program = None
            transfer_program_args = None
            royalty_address: bytes32 | None = None
            royalty_percentage: uint16 | None = None
            nft_inner_puzzle_mod = None
            mod, ol_args = inner_puzzle.uncurry()
            supports_did = False
            if mod == NFT_OWNERSHIP_LAYER:
                supports_did = True
                log.debug("Parsing ownership layer")
                _, current_did_p, transfer_program, p2_puzzle = ol_args.as_iter()
                _, transfer_program_args = transfer_program.uncurry()
                _, royalty_address_p, royalty_percentage_p = transfer_program_args.as_iter()
                royalty_percentage = uint16(royalty_percentage_p.as_int())
                royalty_address = bytes32(royalty_address_p.as_atom())
                current_did_atom = current_did_p.as_atom()
                if current_did_atom == b"":
                    # For unassigned NFT, set owner DID to None
                    current_did = None
                else:
                    current_did = bytes32(current_did_atom)
            else:
                log.debug("Creating a standard NFT puzzle")
                p2_puzzle = inner_puzzle
        except Exception as e:
            log.debug("Cannot uncurry NFT state layer: Args %s Error: %s", curried_args, e)
            return None

        return cls(

            nft_state_layer=nft_state_layer,

            metadata=metadata,

            p2_puzzle=p2_puzzle,
            metadata_updater_hash=metadata_updater_hash,
            meta_uris=meta_uris,
            meta_hash=meta_hash,
            license_uris=license_uris,
            license_hash=license_hash,
            edition_number=edition_number,
            edition_total=edition_total,
            inner_puzzle=inner_puzzle,
            owner_did=current_did,
            supports_did=supports_did,
            transfer_program=transfer_program,
            transfer_program_curry_params=transfer_program_args,
            royalty_address=royalty_address,
            trade_price_percentage=royalty_percentage,
            nft_inner_puzzle_hash=nft_inner_puzzle_mod,
        )

    async def manual_nft_search(self, coin_id: bytes32, latest: bool = True) -> ManualNFTSearchResults:
        # Get coin state
        peer = self.wallet_node.get_full_node_peer()
        coin_spend, coin_state = await self.get_latest_singleton_coin_spend(peer, coin_id, latest)
        # convert to NFTInfo
        # Check if the metadata is updated
        full_puzzle: Program = Program.from_bytes(bytes(coin_spend.puzzle_reveal))

        uncurried_nft: UncurriedNFT | None = UncurriedNFT.uncurry(*full_puzzle.uncurry())
        if uncurried_nft is None:
            raise ValueError("The coin is not a NFT.")
        metadata, p2_puzzle_hash = get_metadata_and_phs(uncurried_nft, coin_spend.solution)
        # Note: This is not the actual unspent NFT full puzzle.
        # There is no way to rebuild the full puzzle in a different wallet.
        # But it shouldn't have impact on generating the NFTInfo, since inner_puzzle is not used there.
        if uncurried_nft.supports_did:
            inner_puzzle = nft_puzzle_utils.recurry_nft_puzzle(
                uncurried_nft, Program.from_serialized(coin_spend.solution), uncurried_nft.p2_puzzle
            )
        else:
            inner_puzzle = uncurried_nft.p2_puzzle

        full_puzzle = nft_puzzle_utils.create_full_puzzle(
            uncurried_nft.singleton_launcher_id,
            metadata,
            bytes32(uncurried_nft.metadata_updater_hash.as_atom()),
            inner_puzzle,
        )

        # Get launcher coin
        launcher_coin: list[CoinState] = await self.wallet_node.get_coin_state(
            [uncurried_nft.singleton_launcher_id], peer=peer
        )
        if len(launcher_coin) < 1 or launcher_coin[0].spent_height is None:
            raise ValueError(f"Launcher coin record 0x{uncurried_nft.singleton_launcher_id.hex()} not found")
        minter_did = await self.get_minter_did(launcher_coin[0].coin, peer)

        return ManualNFTSearchResults(
            nft_info=await nft_puzzle_utils.get_nft_info_from_puzzle(
                NFTCoinInfo(
                    uncurried_nft.singleton_launcher_id,
                    coin_state.coin,
                    None,
                    full_puzzle,
                    uint32(launcher_coin[0].spent_height),
                    minter_did,
                    uint32(coin_state.created_height) if coin_state.created_height else uint32(0),
                ),
                self.config,
            ),
            next_p2_puzzle_hash=p2_puzzle_hash,
        )
