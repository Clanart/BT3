### Title
Missing deadline (and other swap-parameter) revalidation in `VerifyExecutable` allows gasless bundles to be built and lent against expired/invalid swaps - (File: kaiax/gasless/impl/getter.go)

### Summary
The `kaiax/gasless` module lets an unprivileged sender submit a gasless swap (optionally preceded by an approve tx). Kaia's block-builder "lends" the gas fee to the user in a `LendTx` that is unconditionally included ahead of the approve/swap transactions in the same bundle, expecting the swap to later repay that fee. The decision of whether a swap is "executable" (and therefore whether to build the lending bundle) is made by `VerifyExecutable`, which validates sender-matching, token-matching, approve amount, nonce sequencing, and repay amount — but never re-checks `SwapArgs.Deadline` against the current time.

### Finding Description
`decodeSwapTx` extracts a user-controlled `deadline` parameter from the swap calldata [1](#0-0) , and this deadline is only checked once, at mempool admission time, inside `checkBalanceForSwap` (`GetCheckBalance`) [2](#0-1) .

However, the function that actually gates bundle construction and lending, `VerifyExecutable` (called via `IsExecutable` from both `ExtractTxBundles` and `isReady`/`isSwapTxReady`), performs several checks (sender match, token match, approve amount, nonce sequencing, repay-amount correctness) but does not re-validate `swapArgs.Deadline` at all [3](#0-2) . There is a time-of-check/time-of-use gap: a swap tx can sit in the pool (subject to `PendingTimeout`/`QueueTimeout` of up to 10 seconds, `KnownTxTimeout` up to 30 seconds [4](#0-3) ) and be re-evaluated for readiness/bundling at a later block without the deadline being re-checked.

When a bundle is formed, `GetLendTxGenerator` unconditionally creates a `LendTx` that pays out `LendAmount` (covering the fees of both the approve and swap transactions) to the sender before the swap actually executes on-chain [5](#0-4) , and the bundle places the `LendTx` first, followed by the approve/swap transactions [6](#0-5) . If the on-chain `swapForGas` call reverts (e.g., because its own deadline check fails, since the ABI includes a `deadline` parameter passed on-chain [7](#0-6) ), the module has still produced and included a `LendTx` that pays out KAIA to the swap sender, since `VerifyExecutable`/`IsExecutable` did not fail this bundle solely due to an outdated view of the deadline.

### Impact Explanation
This is a fee-delegation/gasless settlement abuse: the block-proposer/gasless subsidy funds (`LendAmount`) can be paid out to a swap sender whose swap the module itself would no longer consider valid if it re-checked the input at bundling time, creating a path for the repay mechanism to fail while the lend has already occurred, i.e., an economic loss to the party funding `LendTx` (unauthorized value movement analogous to the "CASH tokens emptied" class of missing-validation bugs). This directly maps to the reachable category "gasless and auction modules" called out in the prompt.

### Likelihood Explanation
Reachable by any unprivileged gasless-tx submitter: an attacker only needs to submit an approve+swap pair with a near-expiry deadline and rely on normal pool timing (queue/pending timeouts of 10–30 seconds) to have the swap re-evaluated as "ready"/"executable" after the deadline has passed, without needing any validator, peer, or privileged access.

### Recommendation
Add an explicit deadline check inside `VerifyExecutable` (not only in the one-time mempool admission check `checkBalanceForSwap`), comparing `swapArgs.Deadline` against the current chain time before generating/including the `LendTx`, and reject/drop the bundle if expired. Consider also re-validating the other admission-only checks (token balance, allowance, minAmountOut/AmountIn consistency) at bundling time to close the general TOCTOU gap between pool admission and block assembly.

### Proof of Concept
1. Attacker crafts a valid `approve` tx (nonce N) and `swapForGas` tx (nonce N+1) with `deadline = now + 5s`, satisfying `checkBalanceForSwap` at submission.
2. Both txs are accepted into the pool; `PreAddTx`/`GetCheckBalance` pass since deadline is still valid at admission [8](#0-7) .
3. Due to normal network/pool delay (well within the 10–30s `QueueTimeout`/`PendingTimeout`/`KnownTxTimeout` windows), block assembly happens after `deadline` has elapsed.
4. `ExtractTxBundles`/`isReady` calls `IsExecutable`→`VerifyExecutable`, which does not check `Deadline`, so the bundle (LendTx + approve + swap) is built and included [9](#0-8) [10](#0-9) .
5. On-chain, `swapForGas` reverts due to expired `deadline`, but the `LendTx` transferring `LendAmount` to the attacker's address has already executed unconditionally, resulting in an uncompensated fund outflow from the lending mechanism.

Note: I could not fully trace the on-chain `GaslessSwapRouter` (`kip247`) contract's own deadline-revert behavior or confirm whether any downstream safety net (e.g., a batch/atomic revert of the whole bundle) exists to negate the loss — this would need to be verified by inspecting `contracts/bindings/kip247` and the `work/builder` bundle execution/revert semantics, which were not fully available in the indexed context.

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

// MakeLendTx creates a transaction with following properties:
// L1. LendTx.type = 0x7802 (TxTypeEthereumDynamicFee)
// L2. LendTx.from = proposer
// L3. LendTx.to = SwapTx.from
// L4. LendTx.value = LendAmount(approveTxOrNil, swapTx)
func (g *GaslessModule) GetLendTxGenerator(approveTxOrNil, swapTx *types.Transaction) *builder.TxOrGen {
	var src []byte
	if approveTxOrNil != nil {
		src = append(src, approveTxOrNil.Hash().Bytes()...)
	}
	src = append(src, swapTx.Hash().Bytes()...)
	bundleHash := crypto.Keccak256Hash(src)

	gen := func(nonce uint64) (*types.Transaction, error) {
		var (
			chainId = g.InitOpts.ChainConfig.ChainID
			signer  = types.LatestSignerForChainID(chainId)
			key     = g.InitOpts.NodeKey
		)

		to, err := types.Sender(signer, swapTx)
		if err != nil {
			return nil, err
		}

		tx, err := types.NewTransactionWithMap(types.TxTypeEthereumDynamicFee, map[types.TxValueKeyType]interface{}{
			types.TxValueKeyNonce:      nonce,
			types.TxValueKeyTo:         &to,
			types.TxValueKeyAmount:     lendAmount(approveTxOrNil, swapTx),
			types.TxValueKeyData:       common.Hex2Bytes("0x"),
			types.TxValueKeyGasLimit:   params.TxGas,
			types.TxValueKeyGasFeeCap:  swapTx.GasFeeCap(),
			types.TxValueKeyGasTipCap:  swapTx.GasTipCap(),
			types.TxValueKeyAccessList: types.AccessList{},
			types.TxValueKeyChainID:    chainId,
		})
		if err != nil {
			return nil, err
		}

		err = tx.Sign(signer, key)
		return tx, err
	}

	return builder.NewTxOrGenFromGen(gen, bundleHash)
}

func (g *GaslessModule) PreAddTx(tx *types.Transaction, local bool) error {
	g.knownTxsMu.RLock()
	defer g.knownTxsMu.RUnlock()

	if knownTx, ok := g.knownTxs.get(tx.Hash()); ok && knownTx.elapsedPromotedOrAddedTime() < KnownTxTimeout {
		return ErrUnableToAddKnownBundleTx
	}

	if g.IsBundleTx(tx) {
		if uint(g.knownTxs.numQueue()) >= g.GetMaxBundleTxsInQueue() {
			return ErrBundleTxQueueFull
		}
		g.knownTxs.add(tx, TxStatusQueue)
	}
	return nil
}

func (g *GaslessModule) IsModuleTx(tx *types.Transaction) bool {
	if tx == nil {
		return false
	}
	return g.IsApproveTx(tx) || g.IsSwapTx(tx)
}

func (g *GaslessModule) GetCheckBalance() func(tx *types.Transaction) error {
	return func(tx *types.Transaction) error {
		if approveArgs, ok := decodeApproveTx(tx, g.signer); ok {
			return g.checkBalanceForApprove(approveArgs)
		}
		if swapArgs, ok := decodeSwapTx(tx, g.signer); ok {
			return g.checkBalanceForSwap(swapArgs, tx.Nonce())
		}
		return errors.New("not a gasless transaction") // should not happen because IsModuleTx is called before GetCheckBalance
	}
}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
}
