### Title
Gasless SwapTx deadline is validated only at tx-pool admission and never re-checked when the transaction is bundled and included in a block - ([File: kaiax/gasless/impl/getter.go])

### Summary
The `deposit`/`whenPoolIsOpen` report is a class of bug where a state-gating check (an "is this action still allowed right now" check) exists on some code paths but is missing from the actual authorization path that performs the state-changing action. The same bug class exists in `kaiax/gasless`: the swap deadline is enforced only when the tx is first accepted into the tx pool (`checkBalanceForSwap`), but the function that is actually used to authorize inclusion of the swap into a block (`VerifyExecutable`/`IsExecutable`, called from `ExtractTxBundles`) never re-checks the deadline.

### Finding Description
`checkBalanceForSwap` in `kaiax/gasless/impl/tx_pool.go` enforces `tx.deadline >= currentTimestamp`: [1](#0-0) 

This function is only reachable through `GetCheckBalance()`, which is used as a tx-pool admission-time balance/validity check: [2](#0-1) 

However, the function that the block builder actually calls to decide whether a `GaslessApproveTx`/`GaslessSwapTx` pair is executable and should be bundled into a block, `VerifyExecutable` (via `IsExecutable`), performs none of the deadline validation: [3](#0-2) 

`ExtractTxBundles`, which is invoked by the block builder to build bundles for inclusion, relies solely on `IsExecutable`: [4](#0-3) 

Because a pending transaction can sit in the tx pool for a period of time (queue/pending timeouts of up to `PendingTimeout`/`QueueTimeout` = 10s, and potentially longer under `PreReset`/`PostReset` re-categorization across multiple blocks), and because `GetCheckBalance` is invoked only when the transaction is (re-)validated by the generic tx pool machinery rather than at every block-building attempt, there is a window where a `GaslessSwapTx` whose `deadline` has already elapsed can still be selected by `ExtractTxBundles` and bundled/executed, since the sole authorization path (`IsExecutable`/`VerifyExecutable`) does not re-verify the deadline at bundling time. This mirrors the reported pattern precisely: a state/validity condition ("is it still within the valid window to act") is enforced on one code path but omitted from the function that is the actual gate for performing the on-chain state-changing action.

### Impact Explanation
Accepting and executing a `GaslessSwapTx` whose signed `deadline` has already passed is acceptance of a transaction the sender explicitly declared invalid past that timestamp (KIP-247 `swapForGas(token, amountIn, minAmountOut, amountRepay, deadline)` semantics). This can result in the sender's swap being force-executed at a block/time they did not intend or authorize (loss of a time-bound guarantee), and the associated `LendTx`/`repayAmount` settlement being finalized for a transaction that should have been rejected — a form of accepting an invalid transaction into the block for value-moving purposes (lend/repay of gas fee and token swap execution).

### Likelihood Explanation
The gasless tx pool already builds in delay via `QueueTimeout`/`PendingTimeout` (10s) and multi-block promotion/demotion cycles (`PreReset`/`PostReset`), so it's plausible for a swap tx to remain pending across several blocks/seconds — a realistic window in which a short deadline could elapse before the builder actually calls `IsExecutable` to bundle it. Any public transaction sender submitting a `GaslessSwapTx` with an aggressive deadline can trigger this path; no privileged access is required.

### Recommendation
Add the deadline check (and ideally reuse the full `checkBalanceForSwap`/`checkBalanceForApprove` validity checks or at minimum the deadline condition) inside `VerifyExecutable` in `kaiax/gasless/impl/getter.go`, so that `IsExecutable`, `ExtractTxBundles`, and any other consumer of the bundling decision cannot include a `GaslessSwapTx` whose deadline has already elapsed, consistent with how the pool-admission check already enforces it.

### Proof of Concept
1. Attacker/user submits a `GaslessApproveTx` (nonce N) and `GaslessSwapTx` (nonce N+1) with `deadline = currentBlockTime + 2` seconds.
2. `checkBalanceForSwap` passes at admission time since `deadline >= currentTimestamp` at that moment.
3. Due to normal pending-pool latency (transactions can remain pending for up to `PendingTimeout` = 10s per `kaiax/gasless/impl/tx_pool.go`), several seconds elapse before the block builder calls `ExtractTxBundles`.
4. `ExtractTxBundles` calls `g.IsExecutable(approveTx, swapTx)` → `VerifyExecutable`, which never re-checks `swapArgs.Deadline` against the current block time. [5](#0-4) 
5. The swap is bundled with a `LendTxGenerator` and included on-chain even though its declared deadline has already passed, i.e., acceptance of a transaction the sender considered invalid past that time.

func (g *GaslessModule) GetCheckBalance() func(tx *types.Transaction) error {
	return func(tx *types.Transaction) error {
		if approveArgs, ok := decodeApproveTx(tx, g.signer); ok {
			return g.checkBalanceForApprove(approveArgs)
		}
		if swapArgs, ok := decodeSwapTx(tx, g.signer); ok {
			return g.checkBalanceForSwap(swapArgs, tx.Nonce())
		}
		return errors.New("not a gasless transaction") // should not happen because IsModuleTx is called before GetCheckBalance
	}
}

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
}
