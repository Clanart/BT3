### Title
SSRF in DataLayer via on-chain mirror URLs fetched with no destination validation - (File: chia/data_layer/download_data.py)

### Summary
Any unprivileged user who can create and confirm a spend can mint an on-chain "mirror" coin that associates an arbitrary attacker-chosen URL with *any* DataLayer store id, even one they don't own. Every DataLayer node subscribed to that store id will read the URL from the wallet, store it as a subscription server, and later issue an outbound `aiohttp` GET request to that URL when syncing delta files — with no validation of scheme, host, or destination (no private-IP/loopback/link-local blocklist). This is a server-side request forgery (SSRF) reachable purely from a spend bundle plus a normal RPC subscribe call, directly analogous to the reported `TrueLayer.Client` SSRF where attacker-controlled input reaches the destination of an `HttpClient` call.

### Finding Description
`create_mirror_puzzle()` is a fixed puzzle (`P2_PARENT.curry(Program.to(1))`) that anyone can spend a coin to, with memos of the form `[launcher_id, *urls]`: [1](#0-0) 

`DataLayerWallet.create_new_mirror()` builds exactly such a spend and never checks that the caller owns `launcher_id`: [2](#0-1) 

When any wallet observes a coin with the mirror puzzle hash on chain, `coin_added()` decodes `launcher_id` and `urls` from the parent spend via `get_mirror_info()` and persists them as a `Mirror` record for that `launcher_id` if the launcher is tracked — with no check that the mirror creator owns/controls the singleton: [3](#0-2) 

The DataLayer service periodically pulls these wallet-recorded mirror URLs and copies them straight into its local subscription table used for downloads: [4](#0-3) [5](#0-4) 

During each sync cycle, `fetch_and_validate()` selects one of these URLs and passes it down into `insert_from_delta_file()` → `download_file()` → `http_download()`: [6](#0-5) [7](#0-6) 

`http_download()` performs an unrestricted `aiohttp` GET to `server_info.url + "/" + filename` with no scheme allowlist and no check against loopback/link-local/RFC1918/cloud-metadata address ranges: [8](#0-7) 

The `.cursor/context/data-layer.md` design notes explicitly acknowledge that "Plugin and mirror URLs are external trust inputs," but the guard that exists (`download_data.is_filename_valid()`) only validates filenames/content shape, not the destination host itself: [9](#0-8) 

### Impact Explanation
An attacker who only needs to be able to submit a standard coin spend (no ownership of the target DataLayer singleton, no special privileges) can force any other node's DataLayer service — as soon as it subscribes to / tracks the targeted store id — to issue outbound HTTP requests to attacker-chosen destinations. This enables:
- Probing/attacking internal network services and cloud metadata endpoints (e.g. `169.254.169.254`) reachable from the victim's DataLayer host, potentially leaking credentials if the response is logged or partially processed.
- Port scanning of internal infrastructure by observing timing/behavior differences (connect success/failure, timeouts) surfaced through DataLayer logs (`Server {url} unavailable`).
- Abuse as a request amplification/DoS vector against arbitrary third-party hosts, since a single malicious mirror record causes repeated periodic download attempts (`periodically_manage_data` loop) from every subscribing node.

This matches the CWE-918 class in the report: destination URL for an internal HTTP client is attacker-controlled without validation, exposed through a legitimately reachable data path (Data Layer subscription/mirror sync), which the analog rules explicitly list as in scope ("Data Layer roots and proofs" / "Data Layer client").

### Likelihood Explanation
High likelihood of reachability: creating a mirror coin requires only a standard XCH spend (fee + mirror amount) and does not require any relationship to the target store's singleton — `create_new_mirror()` performs no ownership check. Any node that tracks/subscribes to the targeted `store_id` (which DataLayer users commonly do to replicate public/shared stores) will automatically ingest the malicious URL via `update_subscriptions_from_wallet()` and attempt to fetch from it on every management cycle without operator interaction.

### Recommendation
- Validate mirror URLs before persisting them as subscription servers: enforce an allowed scheme (`http`/`https`), and resolve/reject destinations that resolve to loopback, link-local, private (RFC1918), or other non-routable/metadata address ranges, both at insertion (`coin_added`) and at fetch time (`http_download`) since DNS can change between insertion and fetch.
- Consider requiring explicit user opt-in/allowlisting of mirror URLs per store rather than automatically trusting any mirror coin found on chain for a tracked launcher id.
- Apply the same destination validation to plugin/uploader/downloader URLs (`get_downloader`, `get_uploaders`) since they are also externally configurable and hit similarly unrestricted `aiohttp` calls.

### Proof of Concept
1. Attacker runs `dl_new_mirror` (or the CLI `chia data add_mirror`) targeting a `launcher_id` belonging to a victim's store they do not own, with `urls=["http://169.254.169.254/latest/meta-data/"]`: [2](#0-1) 
2. This produces a coin with puzzle hash `create_mirror_puzzle().get_tree_hash()` and gets confirmed on chain — no ownership check is performed anywhere in this path.
3. Victim's DataLayer node, already tracking that `launcher_id` (e.g. because it subscribed to replicate the public store), picks up the mirror via `coin_added()`/`update_subscriptions_from_wallet()`: [4](#0-3) 
4. On the next `periodically_manage_data()` cycle, `fetch_and_validate()` selects the attacker's server and `http_download()` issues an outbound GET to the attacker-controlled URL: [8](#0-7)

def create_mirror_puzzle() -> Program:
    return P2_PARENT.curry(Program.to(1))


MIRROR_PUZZLE_HASH = create_mirror_puzzle().get_tree_hash()


def get_mirror_info(
    parent_puzzle: Program | SerializedProgram, parent_solution: Program | SerializedProgram
) -> tuple[bytes32, list[bytes]]:
    assert type(parent_puzzle) is type(parent_solution)
    _, conditions = run_with_cost(parent_puzzle, INFINITE_COST, parent_solution)
    for condition in conditions.as_iter():
        if (
            condition.first().as_python() == ConditionOpcode.CREATE_COIN
            and condition.at("rf").as_python() == create_mirror_puzzle().get_tree_hash()
        ):
            memos: list[bytes] = condition.at("rrrf").as_python()
            launcher_id = bytes32(memos[0])
            return launcher_id, [url for url in memos[1:]]

        self, coin: Coin, height: uint32, peer: WSChiaConnection, coin_data: object | None, sync_scope: WalletSyncScope

            parent_state: CoinState = (

            )[0]
            parent_spend = await fetch_coin_spend(height, parent_state.coin, peer)

                        coin.name(),
                        launcher_id,
                        uint64(coin.amount),
                        Mirror.decode_urls(urls),
                        ours,
                        height,
                    )
                )
                await self.wallet_state_manager.add_interested_coin_ids([coin.name()])

    async def update_subscriptions_from_wallet(self, store_id: bytes32, new_urls: list[str]) -> None:
        async with self.db_wrapper.writer() as writer:
            cursor = await writer.execute(
                "SELECT * FROM subscriptions WHERE from_wallet == 1 AND tree_id == :tree_id",
                {
                    "tree_id": store_id,
                },
            )
            old_urls = [row["url"] async for row in cursor]
            cursor = await writer.execute(
                "SELECT * FROM subscriptions WHERE from_wallet == 0 AND tree_id == :tree_id",
                {
                    "tree_id": store_id,
                },
            )
            from_subscriptions_urls = {row["url"] async for row in cursor}
            additions = {url for url in new_urls if url not in old_urls}
            removals = [url for url in old_urls if url not in new_urls]
            for url in removals:
                await writer.execute(
                    "DELETE FROM subscriptions WHERE url == :url AND tree_id == :tree_id",
                    {
                        "url": url,
                        "tree_id": store_id,
                    },
                )
            for url in additions:
                if url not in from_subscriptions_urls:
                    await writer.execute(
                        "INSERT INTO subscriptions(tree_id, url, ignore_till, num_consecutive_failures, from_wallet) "
                        "VALUES (:tree_id, :url, 0, 0, 1)",
                        {
                            "tree_id": store_id,
                            "url": url,
                        },
                    )

async def download_file(
    data_store: DataStore,
    target_filename_path: Path,
    store_id: bytes32,
    root_hash: bytes32,
    generation: int,
    server_info: ServerInfo,
    proxy_url: str | None,
    downloader: PluginRemote | None,
    timeout: aiohttp.ClientTimeout,
    client_foldername: Path,
    timestamp: int,
    log: logging.Logger,
    grouped_by_store: bool,
    group_downloaded_files_by_store: bool,
    max_delta_file_size: int,
) -> bool:
    if target_filename_path.exists():
        return True
    filename = get_delta_filename(store_id, root_hash, generation, grouped_by_store)

    if downloader is None:
        # use http downloader - this raises on any error
        try:
            await http_download(
                target_filename_path, filename, proxy_url, server_info, timeout, log, max_delta_file_size
            )
        except (asyncio.TimeoutError, aiohttp.ClientError, MaxDeltaFileSizeExceededError):
            new_server_info = await data_store.server_misses_file(store_id, server_info, timestamp)
            log.info(
                f"Failed to download {filename} from {new_server_info.url}."
                f"Miss {new_server_info.num_consecutive_failures}."
            )
            log.info(f"Next attempt from {new_server_info.url} in {new_server_info.ignore_till - timestamp}s.")
            return False
        return True
```

async def http_download(
    target_filename_path: Path,
    filename: str,
    proxy_url: str | None,
    server_info: ServerInfo,
    timeout: aiohttp.ClientTimeout,
    log: logging.Logger,
    max_delta_file_size: int,
) -> None:
    """
    Download a file from a server using aiohttp.
    Raises exceptions on errors
    """
    async with aiohttp.ClientSession() as session:
        headers = {"accept-encoding": "gzip"}
        async with session.get(
            server_info.url + "/" + filename,
            headers=headers,
            timeout=timeout,
            proxy=proxy_url,
        ) as resp:
            resp.raise_for_status()
```
