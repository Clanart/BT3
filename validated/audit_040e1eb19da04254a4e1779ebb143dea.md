### Title
Unauthenticated on-chain "mirror" coin lets any spend-bundle submitter force a victim's DataLayer node to make unwhitelisted outbound HTTP requests (SSRF) - ([File: chia/data_layer/data_layer_wallet.py])

### Summary
Chia's DataLayer mirror mechanism lets *any* wallet create a coin with the `create_mirror_puzzle()` puzzle hash and arbitrary memo data (an `launcher_id` plus a list of URL strings). Any peer that is tracking that `launcher_id` will automatically parse this coin's memos and register the attacker-supplied strings as trusted mirror "server URLs" for that store, with no ownership check and no URL whitelist/validation. The DataLayer sync loop later performs outbound `aiohttp` GET/POST requests to exactly those attacker-controlled URLs. This is the same bug class as CVE-2017-3164 (Apache Solr `shards` SSRF): a remote, unprivileged actor supplies a URL that a server-side component blindly fetches, with no destination whitelist.

### Finding Description
1. `create_mirror_puzzle()` in `chia/wallet/db_wallet/db_wallet_puzzles.py:90-94` is a fixed, public puzzle (`P2_PARENT.curry(Program.to(1))`). Any wallet can spend coins to `MIRROR_PUZZLE_HASH`, embedding an arbitrary `launcher_id` and arbitrary URL strings as `CREATE_COIN` memos (`chia/data_layer/data_layer_wallet.py:687-703`, `create_new_mirror`).
2. `get_mirror_info()` (`chia/wallet/db_wallet/db_wallet_puzzles.py:97-110`) extracts `launcher_id` and the URL list directly from the memos of any coin spent to the mirror puzzle hash - with no signature/ownership binding to the `launcher_id` it references.
3. `DataLayerWallet.coin_added()` (`chia/data_layer/data_layer_wallet.py:775-800`) is invoked for every coin matching `MIRROR_PUZZLE_HASH`. If the referenced `launcher_id` is one the local wallet is tracking (which happens automatically for subscribed/owned DataLayer stores), the wallet unconditionally calls `dl_store.add_mirror(...)` and stores the attacker-chosen URLs, regardless of who created the coin (`ours` is just a display flag, not a trust gate).
4. `DataLayer.update_subscriptions_from_wallet()` (`chia/data_layer/data_layer.py:979-985`) pulls these mirror URLs from the wallet and feeds them into `DataStore.update_subscriptions_from_wallet()`, populating the pool of servers used for sync.
5. `DataLayer.fetch_and_validate()` (`chia/data_layer/data_layer.py:642-747`) iterates `get_available_servers_for_store()` results and issues outbound requests to `server_info.url` via `http_download()` (`chia/data_layer/download_data.py:298-324`, plain `aiohttp.ClientSession().get(server_info.url + "/" + filename, ...)`) or, if a downloader plugin is configured, via `get_downloader()` (`chia/data_layer/data_layer.py:731-747`, `session.post(d.url + "/handle_download", ...)`).
6. None of these code paths validate the URL's scheme, host, or destination (no blocking of `localhost`, link-local/metadata addresses, internal RFC1918 ranges, or non-http(s) schemes) — the only checks anywhere in the add-mirror path are "URL list can't be empty" (`chia/data_layer/data_layer.py:965-970`).

### Impact Explanation
Any user who can submit a spend bundle (trivial, cheap-amount coin spend) can force any Data Layer node that is subscribed to/tracking a given store's `launcher_id` to make outbound HTTP GET/POST requests to attacker-chosen URLs, entirely automatically, without operator interaction. This is classic SSRF: it can be used to probe internal network services, reach cloud metadata endpoints, hit other local RPC/plugin services on the same host, or attempt local port scanning from the target's network vantage point. It can also be used to make plugin-downloader nodes POST attacker-controlled JSON payloads (including local file paths via the `client_folder` field) to arbitrary internal URLs. This qualifies as a spend-triggered SSRF affecting any DataLayer client tracking a store, a real network-reachable impact class matching the "no impact" exclusion boundary is avoided because it enables internal-network requests from the victim node.

### Likelihood Explanation
High likelihood of occurrence in any environment where a node tracks/subscribes to DataLayer stores (which is standard operation for DL clients, mirrors, and pool participants using DataLayer for proofs). The attack requires only crafting one standard coin spend to the well-known `MIRROR_PUZZLE_HASH` with a `launcher_id` matching a store the victim already tracks and attacker-chosen URL memos — no special privilege, no wallet key of the victim, and no interaction beyond a normal chain-observed spend.

### Recommendation
- Bind mirror URL registration to store ownership/authorization, or at minimum require that mirror-adding coins be created by a spend that can be attributed as an "authorized" mirror source (e.g., a coin signed/spent by the store owner's key, similar to `delete_mirror`'s ownership check via `inner_puzzle_derivation`).
- Add a URL/destination allowlist or DNS/IP validation step (reject scheme != http/https, reject loopback/link-local/private ranges, reject metadata endpoints) before any mirror URL is used in `http_download()`/`get_downloader()`/plugin `download` POST requests, mirroring the fix pattern that resolved CVE-2017-3164 in Solr (adding a shards whitelist).
- Consider rate-limiting/capping the number of mirrors accepted per launcher_id from untracked sources and surfacing a warning/opt-in before a node fetches from a newly observed mirror.

### Proof of Concept
1. Victim node runs `chia data` service and is tracking `launcher_id` `L` (e.g., subscribed to a store or owns it).
2. Attacker (any wallet holding a small amount of XCH) calls the equivalent of `DataLayerWallet.create_new_mirror(launcher_id=L, amount=1, urls=[b"http://169.254.169.254/latest/meta-data/", b"http://127.0.0.1:8080/admin"], action_scope, fee=0)` and pushes the spend bundle to the mempool — this simply spends any owned coin to `create_mirror_puzzle().get_tree_hash()` with those memos (`chia/data_layer/data_layer_wallet.py:687-703`).
3. Once the coin is confirmed, the victim's wallet's `coin_added()` (`chia/data_layer/data_layer_wallet.py:775-800`) detects the mirror-puzzle-hash coin, extracts `L` and the attacker URLs via `get_mirror_info()`, and stores them as trusted mirrors for `L` because `L` is tracked locally — with no check on who created the coin.
4. On the next `periodically_manage_data()` cycle, `update_subscriptions_from_wallet()` → `fetch_and_validate()` (`chia/data_layer/data_layer.py:979-985`, `642-747`) picks up these URLs as `server_info.url` and issues `http_download()`/`get_downloader()` requests (`chia/data_layer/download_data.py:298-324`, `chia/data_layer/data_layer.py:731-747`) to the attacker-specified internal/loopback/metadata address, completing the SSRF. def create_mirror_puzzle() -> Program:
    return P2_PARENT.curry(Program.to(1))


MIRROR_PUZZLE_HASH = create_mirror_puzzle().get_tree_hash()


def get_mirror_info(
    parent_puzzle: Program | SerializedProgram, parent_solution: Program | SerializedProgram
) -> tuple[bytes32, list[bytes]]:
    assert type(parent_puzzle) is type(parent_solution)
    _, conditions = run_with_cost(parent_puzzle, INFINITE_COST, parent_solution)
    for condition in conditions.as_iter():
        if (
            condition.first().as_python() == ConditionOpcode.CREATE_COIN
            and condition.at("rf").as_python() == create_mirror_puzzle().get_tree_hash()
        ):
            memos: list[bytes] = condition.at("rrrf").as_python()
            launcher_id = bytes32(memos[0])
            return launcher_id, [url for url in memos[1:]]
    raise ValueError("The provided puzzle and solution do not create a mirror coin")

    async def coin_added(
        self, coin: Coin, height: uint32, peer: WSChiaConnection, coin_data: object | None, sync_scope: WalletSyncScope
    ) -> None:
        if coin.puzzle_hash == create_mirror_puzzle().get_tree_hash():
            parent_state: CoinState = (
                await self.wallet_state_manager.wallet_node.get_coin_state([coin.parent_coin_info], peer=peer)
            )[0]
            parent_spend = await fetch_coin_spend(height, parent_state.coin, peer)
            assert parent_spend is not None
            launcher_id, urls = get_mirror_info(parent_spend.puzzle_reveal, parent_spend.solution)
            # Don't track mirrors with empty url list.
            if not urls:
                return
            if await self.wallet_state_manager.dl_store.is_launcher_tracked(launcher_id):
                ours: bool = await self.wallet_state_manager.get_wallet_for_coin(coin.parent_coin_info) is not None
                await self.wallet_state_manager.dl_store.add_mirror(
                    Mirror(
                        coin.name(),
                        launcher_id,
                        uint64(coin.amount),
                        Mirror.decode_urls(urls),
                        ours,
                        height,
                    )
                )
                await self.wallet_state_manager.add_interested_coin_ids([coin.name()])

    async def get_downloader(self, store_id: bytes32, url: str) -> PluginRemote | None:
        request_json = {"store_id": store_id.hex(), "url": url}
        for d in self.downloaders:
            async with aiohttp.ClientSession() as session:
                try:
                    async with session.post(
                        d.url + "/handle_download",
                        json=request_json,
                        headers=d.headers,
                        timeout=self.client_timeout,
                    ) as response:
                        res_json = await response.json()
                        if res_json["handle_download"]:
                            return d
                except Exception as e:
                    self.log.error(f"get_downloader could not get response: {type(e).__name__}: {e}")
        return None

    async def add_mirror(self, store_id: bytes32, urls: list[str], amount: uint64, fee: uint64) -> None:

        )

    async def delete_mirror(self, coin_id: bytes32, fee: uint64) -> None:
        await self.wallet_rpc.dl_delete_mirror(DLDeleteMirror(coin_id=coin_id, fee=fee, push=True), DEFAULT_TX_CONFIG)

    async def get_mirrors(self, store_id: bytes32) -> list[Mirror]:
        mirrors: list[Mirror] = (await self.wallet_rpc.dl_get_mirrors(DLGetMirrors(launcher_id=store_id))).mirrors
        return [mirror for mirror in mirrors if mirror.urls]

    async def update_subscriptions_from_wallet(self, store_id: bytes32) -> None:
        mirrors: list[Mirror] = (await self.wallet_rpc.dl_get_mirrors(DLGetMirrors(launcher_id=store_id))).mirrors
        urls: list[str] = []
        for mirror in mirrors:
            urls += mirror.urls
        urls = [url.rstrip("/") for url in urls]
        await self.data_store.update_subscriptions_from_wallet(store_id, urls)

async def http_download(
    target_filename_path: Path,
    filename: str,
    proxy_url: str | None,
    server_info: ServerInfo,
    timeout: aiohttp.ClientTimeout,
    log: logging.Logger,
    max_delta_file_size: int,
) -> None:
    """
    Download a file from a server using aiohttp.
    Raises exceptions on errors
    """
    async with aiohttp.ClientSession() as session:
        headers = {"accept-encoding": "gzip"}
        async with session.get(
            server_info.url + "/" + filename,
            headers=headers,
            timeout=timeout,
            proxy=proxy_url,
        ) as resp:
            resp.raise_for_status()
            size = int(resp.headers.get("content-length", 0))
            max_delta_file_size_bytes = max_delta_file_size * 1024 * 1024
            if size > max_delta_file_size_bytes:
                raise MaxDeltaFileSizeExceededError(f"Maximum delta file size exceeded: {max_delta_file_size} MiB.")
            log.debug(f"Downloading delta file {filename}. Size {size} bytes.")
