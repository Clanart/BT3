## Finding: Missing contract-existence check in `EvmHost.dispatchIncoming(GetResponse)` / `dispatchTimeOut` allows vacuous delivery to no-code addresses

### Title
Missing `extcodesize` guard on GetResponse/Timeout delivery lets calls to code-less addresses vacuously succeed, unlike the audited PostRequest path - (evm/src/core/EvmHost.sol)

### Summary
`EvmHost.dispatchIncoming(PostRequest, address)` explicitly checks `extcodesize(destination) == 0` and returns early *before* writing the request receipt or emitting `PostRequestHandled`, specifically to avoid treating delivery to an undeployed/no-code address as a success. [1](#0-0)  The sibling functions `dispatchIncoming(GetResponse, address)`, `dispatchTimeOut(GetRequestTimeout, ...)`, and `dispatchTimeOut(PostRequestTimeout, ...)` omit this check entirely and go straight to a low-level `.call()` against `_bytesToAddress(...)`. [2](#0-1) [3](#0-2)  This is the exact broken invariant from the external report: a low-level call to an address with no deployed contract always returns `success = true` on the EVM, so the code treats "no one executed anything" the same as "the app processed the message correctly."

### Finding Description
`dispatchIncoming(GetResponse)` writes `_responseReceipts[commitment]` *before* calling the destination, then calls `IApp.onGetResponse` via low-level `.call`. [4](#0-3)  Because Solidity's low-level `.call` to an address with zero code always reports `success = true`, if `response.request.from` resolves to a code-less address, the branch that would normally revert the receipt (`if (!success) { delete ... }`) is never taken, and execution proceeds to `emit GetRequestHandled` and to release the relayer fee: `IERC20(feeToken()).safeTransfer(relayer, fee);`. [5](#0-4)  The same pattern repeats for both `dispatchTimeOut` overloads, where the commitment is deleted and the fee/refund path executes even though the vacuous call performed no real app-side timeout handling. [6](#0-5) [7](#0-6) 

The developers evidently know this class of bug and fixed it specifically for `dispatchIncoming(PostRequest)`, which computes `extcodesize(destination)` and returns before any receipt is set or fee logic runs. [8](#0-7)  The same guard is present in the unrelated `CallDispatcher.dispatch`, which reverts with `NotContract` if `extcodesize(to) == 0`. [9](#0-8)  Its absence on the GetResponse/Timeout paths is an inconsistency, not an intentional design choice.

### Impact Explanation
Every one of these functions is reachable only via `restrict(_hostParams.handler)`, i.e. invoked by the protocol's message handler as part of processing a relayer-submitted, cryptographically verified proof — so this is not gated by any additional application-level integrity check on the destination. Once a valid state/consensus proof for a `GetResponse` or timeout is accepted, `EvmHost` unconditionally treats delivery to a code-less `from`/`to` as successful: it commits the replay-protection receipt/deletes the pending commitment and releases escrowed relayer fees or sender refunds, exactly mirroring the BeaconDS scenario where "all calls to an address with no contract deployed succeed and return true." This lets protocol-held fee funds move (to the relayer, or as a refund) on the basis of a no-op call, silently diverging from the guarded behavior that `dispatchIncoming(PostRequest)` deliberately implements to prevent this.

### Likelihood Explanation
The condition is trivial to trigger without any privileged access: any account (including a plain EOA) can be the `from`/originating module of a `GetRequest` dispatched through the public `IDispatcher.dispatch` entrypoint, and EOAs by definition have zero code. No relayer collusion, governance action, or malicious peer is required — an ordinary relayer submitting an otherwise legitimate proof for a `GetResponse`/timeout whose associated module address is code-less will automatically hit the vacuous-success branch on every occurrence, since the guard that exists for `PostRequest` was never added here.

### Recommendation
Add the same `extcodesize` (or `.code.length`) existence check used in `dispatchIncoming(PostRequest)` to `dispatchIncoming(GetResponse)` and both `dispatchTimeOut` overloads, returning/skipping receipt writes and fee transfers before any low-level `.call` when the destination has no code, exactly mirroring lines 794-803 of `EvmHost.sol`.

### Proof of Concept
1. An account (EOA or self-destructing contract, if pre-EIP-6780 same-tx destruct is possible) dispatches a `GetRequest` via `IDispatcher.dispatch(DispatchGet)`, becoming `request.from`.
2. A relayer obtains and submits a valid state proof for the corresponding `GetResponse`; the handler calls `EvmHost.dispatchIncoming(GetResponse, relayer)`.
3. Inside, `_bytesToAddress(response.request.from)` resolves to the code-less `from` address; `.call(...)` returns `success = true` vacuously (no `extcodesize` guard exists here, unlike the `PostRequest` path). [10](#0-9) 
4. `_responseReceipts[commitment]` remains set, `GetRequestHandled` is emitted, and `IERC20(feeToken()).safeTransfer(relayer, fee)` executes — even though no application logic ever ran to validate or use the returned state.

    function dispatchIncoming(PostRequest memory request, address relayer) external restrict(_hostParams.handler) {
        address destination = _bytesToAddress(request.to);
        uint256 size;
        assembly {
            size := extcodesize(destination)
        }
        if (size == 0) {
            // instead of reverting the entire batch, early return here.
            return;
        }

        // replay protection
        bytes32 commitment = request.hash();
        _requestReceipts[commitment] = relayer;

        (bool success,) = address(destination)
            .call(abi.encodeWithSelector(IApp.onAccept.selector, IncomingPostRequest(request, relayer)));

        if (!success) {
            // so that it can be retried
            delete _requestReceipts[commitment];
            return;
        }
        emit PostRequestHandled({commitment: commitment, relayer: relayer});
    }

     * @dev Dispatch an incoming GET response to source module
     * @param response - get response

    function dispatchIncoming(GetResponse memory response, address relayer) external restrict(_hostParams.handler) {
        // replay protection
        bytes32 commitment = response.request.hash();
        _responseReceipts[commitment] = ResponseReceipt({
            relayer: relayer,
            responseCommitment: response.hash()
        });

        (bool success,) = _bytesToAddress(response.request.from)
            .call(abi.encodeWithSelector(IApp.onGetResponse.selector, IncomingGetResponse(response, relayer)));

        if (!success) {
            // so that it can be retried
            delete _responseReceipts[commitment];
            return;
        }

        // reward the relayer fee

        if (fee != 0) {
            IERC20(feeToken()).safeTransfer(relayer, fee);
        }
        emit GetRequestHandled({commitment: commitment, relayer: relayer});
    }
