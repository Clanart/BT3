### Title
`ReceivedOutput::read` deserializes attacker-claimed spendable outputs without binding the offset to the output's script_pubkey - (File: networks/bitcoin/src/wallet/mod.rs)

### Summary
`Scanner::scan_transaction` enforces a strict whitelist: an output is only reported as `ReceivedOutput` if its `script_pubkey` is in the `scripts` map, i.e. it was provably derived as `key + offset*G` via `register_offset`. `ReceivedOutput::read` performs no such check — it accepts an arbitrary `offset`, arbitrary `TxOut`, and arbitrary `OutPoint` from untrusted bytes. Any output reconstructed through `read` bypasses the script-derivation whitelist entirely, so an unprivileged party can cause the system to treat an output as spendable-by-the-multisig when it is not — the analog of `execute`'s checks being bypassed by the arbitrary `_executeSwap` payload.

### Finding Description
`Scanner::new` / `register_offset` build `scripts: HashMap<ScriptBuf, Scalar>` where every entry is a P2TR script derived from `self.key + G*offset`, with collision handling and even-Y enforcement ( [1](#0-0) ). `scan_transaction` only produces a `ReceivedOutput` when `self.scripts.get(&output.script_pubkey)` hits — the whitelist check ( [2](#0-1) ). In contrast, `ReceivedOutput::read` reads `offset`, `output` (a `TxOut` containing `script_pubkey` and `value`), and `outpoint` verbatim and returns them without verifying `p2tr_script_buf(key + G*offset) == output.script_pubkey` or that the outpoint/script pairing is one the `Scanner` would ever emit ( [3](#0-2) ). The private fields and constructor-less API mean callers assume the invariant that `offset` spends `output`, an invariant only `scan_transaction` establishes and `read` silently drops.

### Impact Explanation
A forged `ReceivedOutput` yields funds reported received that are not spendable, in both directions:

- **Phantom deposits**: an attacker encodes an output paying to a script they control (or any unspendable script) plus an arbitrary `offset`. Deserialization succeeds, downstream accounting credits `output.value` to the multisig, and later the signer derives `key + offset*G` to spend it — which does not control the actual `script_pubkey`. The credited balance is unspendable.
- **Bricked real deposits**: attacker pairs a genuine multisig `TxOut`/`OutPoint` with a wrong `offset`. The output counts as received but the signing path produces a key that cannot satisfy the script, freezing real funds (effectively a fund-loss/DoS on the treasury, not just a crash).

Both violate the security invariant the `Scanner` whitelist exists to enforce: only outputs whose script was derived inside `register_offset` may be treated as spendable.

### Likelihood Explanation
Reachable by any unprivileged party who can cause `ReceivedOutput::read` to consume attacker-controlled bytes (a listed sink in scope). The parse itself cannot fail-check the inconsistency since the deserialization context carries no expected key/script set, and `read_F`/`consensus_decode` happily accept the well-formed encodings — no malformed bytes required, just a dishonest combination of valid fields.

### Recommendation
Bind the deserialized fields cryptographically, matching the whitelist enforced at scan time:

- Re-derive the script and reject if mismatched: `if p2tr_script_buf(key + G*offset) != Some(output.script_pubkey) { Err(...) }`. This requires `read` to take the multisig `key` (or a `&Scanner`) as a parameter, mirroring how `Commitments::read` takes `ThresholdParams` ( [4](#0-3) ).
- Alternatively, treat `ReceivedOutput` deserialization as untrusted and re-run it through `Scanner`-equivalent validation before crediting it.

### Proof of Concept
```rust
// Given a multisig key `key` with registered scripts S = { p2tr(key + o_i*G) }.
// An honest scan can only yield ReceivedOutput where output.script_pubkey in S.
// Attacker crafts:
let mut buf = vec![];
buf.extend(attacker_offset.to_bytes());            // any scalar
buf.extend(serialize(&TxOut {
    value: Amount::from_sat(1_000_000),
    script_pubkey: attacker_controlled_p2tr_script, // not in S
}));
buf.extend(serialize(&OutPoint { txid: fake_txid, vout: 0 }));
let forged = ReceivedOutput::read(&mut buf.as_slice()).unwrap(); // succeeds
// forged.value() == 1_000_000 credited as received, yet no registered offset
// produces a key able to spend `output.script_pubkey` — funds unspendable.
```
The critical divergence: `read_G`/`read_F` enforce canonicality of each field individually ( [5](#0-4) ) but nothing enforces the cross-field `offset ↔ script_pubkey` relation that `scan_transaction` guarantees ( [6](#0-5) ).

    let mut scripts = HashMap::new();

    Some(Scanner { key, scripts })
  }

  /// Register an offset to scan for.
  ///
  /// Due to Bitcoin's requirement that points are even, not every offset may be used.
  /// If an offset isn't usable, it will be incremented until it is. If this offset is already
  /// present, None is returned. Else, Some(offset) will be, with the used offset.
  ///
  /// This means offsets are surjective, not bijective, and the order offsets are registered in
  /// may determine the validity of future offsets.
  ///
  /// The offsets registered must be securely generated. Arbitrary offsets may introduce a script
  /// path into the output, allowing the output to be spent by satisfaction of an arbitrary script
  /// (not by the signature of the key).
  pub fn register_offset(&mut self, mut offset: Scalar) -> Option<Scalar> {
    // This loop will terminate as soon as an even point is found, with any point having a ~50%
    // chance of being even
    // That means this should terminate within a very small amount of iterations
    loop {
      match p2tr_script_buf(self.key + (ProjectivePoint::GENERATOR * offset)) {
        Some(script) => {
          if self.scripts.contains_key(&script) {
            None?;
          }
          self.scripts.insert(script, offset);
          return Some(offset);
        }
        None => offset += Scalar::ONE,
      }
    }
  }

  pub fn scan_transaction(&self, tx: &Transaction) -> Vec<ReceivedOutput> {
    let mut res = Vec::new();
    for (vout, output) in tx.output.iter().enumerate() {
      // If the vout index exceeds 2**32, stop scanning outputs
      let Ok(vout) = u32::try_from(vout) else { break };

      if let Some(offset) = self.scripts.get(&output.script_pubkey) {
        res.push(ReceivedOutput {
          offset: *offset,
          output: output.clone(),
          outpoint: OutPoint::new(tx.compute_txid(), vout),
        });
      }
    }
    res
  }

  fn read_G<R: Read>(reader: &mut R) -> io::Result<Self::G> {
    let mut encoding = <Self::G as GroupEncoding>::Repr::default();
    reader.read_exact(encoding.as_mut())?;

    let point = Option::<Self::G>::from(Self::G::from_bytes(&encoding))

      Err(io::Error::other("non-canonical point"))?;
