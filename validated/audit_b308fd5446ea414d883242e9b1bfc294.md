### Title
Non-atomic Gasless bundle allows the lent gas fee to go unrepaid when the whitelisted swap token becomes paused/non-transferable - (File: kaiax/gasless/impl/builder.go)

### Summary
The Sherlock report describes `CollateralManager.sol` failing to account for collateral tokens that can be paused or made non-transferrable, leading to loans that cannot be liquidated. The same bug class — a protocol crediting/lending value up-front and relying on a later ERC20 transfer that can be blocked by the token issuer — is reachable in Kaia's `kaiax/gasless` module (KIP-247 gasless transactions), where a block proposer unconditionally lends KAIA to a user before the user's ERC20-based repayment swap executes.

### Finding Description
The gasless flow works by having the block builder prepend a `LendTxGenerator` transaction that unconditionally transfers KAIA from the proposer to the gasless sender, followed by the (optional) `GaslessApproveTx` and the `GaslessSwapTx` that is supposed to swap the user's ERC20 token for KAIA and repay the proposer: [1](#0-0) 

The three transactions are wrapped into a `builder.Bundle` with the atomicity flag explicitly set to `false`: [2](#0-1) 

Because the bundle is not atomic, a revert of the trailing `GaslessSwapTx` does not roll back the preceding `LendTxGenerator` transaction — the proposer's KAIA transfer to the sender stands even if the token-based repayment fails.

Pre-admission checks in the tx pool (`checkBalanceForSwap`) validate balance/allowance/exchange-rate against the ERC20 token contract at pool-admission time: [3](#0-2) 

These checks only query `Allowance`/`BalanceOf`/`GetAmountIn` via `ERC20`/router callers — they do not (and cannot generically) detect that a token is pausable, blacklistable, or otherwise capable of blocking `transferFrom` at execution time. `IsApproveTx`/`IsSwapTx` only verify that `token` is in the operator-controlled `allowedTokens` whitelist, `A1`/`S3`: [4](#0-3) 

If the whitelisted token supports pausing or blacklisting (a common ERC20 extension, as seen in this very codebase's `ERC20Pausable`): [5](#0-4) 
then between the moment the `GaslessSwapTx` passes mempool admission (unpaused) and the moment it is actually executed inside `GaslessSwapRouter.swapForGas` during block building, the token can become paused/blacklisted (e.g., the token owner pauses it, or the sender's address gets blacklisted). The `swapForGas` call then reverts, and — because the bundle is non-atomic — only the swap transaction fails; the KAIA the proposer already lent via `LendTxGenerator` remains transferred to the sender, unrepaid.

### Impact Explanation
This is a direct unauthorized value transfer from the block proposer (who funds `LendTxGenerator`) to the gasless transaction sender. A sender (or any actor who controls/colludes with the whitelisted token's pause/blacklist authority) can repeatedly submit valid-looking gasless approve/swap pairs, pass admission checks, and then have the swap intentionally fail at execution time, extracting free KAIA from proposers on every occurrence. This is a concrete "fee-delegation/gasless settlement theft" scenario matching the required impact categories (unauthorized value movement / gasless settlement theft), reachable purely from a submitted transaction pair by an unprivileged gasless sender.

### Likelihood Explanation
Likelihood depends on a whitelisted ERC20 token in `allowedTokens` supporting pause/blacklist functionality and that capability being exercised (by the token owner, or by an attacker gaming their own blacklist status) at a moment that straddles pool-admission and block-building. Given `allowedTokens` is presumably permissioned/governance-controlled, the practical likelihood is Medium — it requires either a malicious/compromised token owner or a token whose pause/blacklist state the sender can influence (e.g., self-blacklisting via a compliant/permissioned stablecoin), but it is fully achievable without validator or node-level privileges once such a token is whitelisted.

### Recommendation
- Make the gasless bundle atomic (`enforceAtomic = true`) so that if the trailing `GaslessSwapTx` reverts, the preceding `LendTxGenerator` is also rolled back, ensuring the proposer never bears the lent amount without repayment.
- Alternatively, verify at execution time (not only at mempool admission) that the swap succeeded and, if not, revert or reclaim the lent KAIA within the same block.
- Add a policy on `allowedTokens` to exclude pausable/blacklistable tokens, or perform a fresh state check for pause/blacklist status immediately before block inclusion.

### Proof of Concept
1. Governance/whitelist admin adds a pausable or blacklistable ERC20 token `T` to `GaslessSwapRouter`'s `allowedTokens`.
2. Attacker (holder of `T`, with a valid balance/allowance at admission time) submits `GaslessApproveTx` + `GaslessSwapTx` for token `T`; both pass `checkBalanceForApprove`/`checkBalanceForSwap` in `kaiax/gasless/impl/tx_pool.go` and get promoted.
3. During block building, `ExtractTxBundles` (kaiax/gasless/impl/builder.go:28-72) creates a non-atomic bundle `[LendTxGenerator, ApproveTx, SwapTx]`.
4. Immediately before/at the time the proposer includes the bundle, `T` is paused (or attacker's address is blacklisted) by the token's admin/owner (which could be the attacker in a permissioned or self-issued token scenario).
5. `LendTxGenerator` executes and unconditionally sends KAIA to the attacker.
6. `ApproveTx` may succeed (approve doesn't move tokens) but `SwapTx`'s internal `transferFrom` inside `GaslessSwapRouter.swapForGas` reverts due to the pause/blacklist.
7. Because the bundle's atomicity flag is `false`, the `LendTxGenerator` transaction is not reverted — the attacker keeps the lent KAIA with no repayment to the proposer.

func (g *GaslessModule) checkBalanceForSwap(swapArgs *SwapArgs, swapNonce uint64) error {
	token := swapArgs.Token
	bc := backends.NewBlockchainContractBackend(g.Chain, nil, nil)

	g.gaslessInfoMu.RLock()
	swapRouter := g.swapRouter
	g.gaslessInfoMu.RUnlock()

	// tx.minAmountOut >= tx.amountRepay
	minAmountOut := swapArgs.MinAmountOut
	amountRepay := swapArgs.AmountRepay
	if minAmountOut.Cmp(amountRepay) < 0 {
		return fmt.Errorf("insufficient minAmountOut: minAmountOut=%s, amountRepay=%s", minAmountOut.String(), amountRepay.String())
	}

	if g.GaslessConfig.ShouldCheckSenderCode() {
		if g.getCurrentHasCode(swapArgs.Sender) {
			return errors.New("sender with code is not allowed")
		}
	}

	if g.GaslessConfig.ShouldCheckSwapAmount() {
		// tx.amountIn >= gsr.getAmountIn(minAmountOut)
		routerContract, err := kip247.NewGaslessSwapRouterCaller(swapRouter, bc)
		if err != nil {
			return err
		}
		// Required token amountIn, given the current exchange rate and the declared minAmountOut.
		requiredAmountIn, err := routerContract.GetAmountIn(nil, token, minAmountOut)
		if err != nil {
			return err
		}
		if swapArgs.AmountIn.Cmp(requiredAmountIn) < 0 {
			return fmt.Errorf("insufficient amountIn: have=%s, want=%s", swapArgs.AmountIn.String(), requiredAmountIn.String())
		}
	}

	if g.GaslessConfig.ShouldCheckToken() {

		tokenContract, err := sc_erc20.NewERC20(token, bc)
		if err != nil {
			return err
		}

		// If SwapTx.nonce is the sender's next nonce, then there is no room for ApproveTx proceeding SwapTx.
		senderNonce := g.getCurrentStateNonce(swapArgs.Sender)
		noApproveTxPreceeds := swapNonce == senderNonce
		if noApproveTxPreceeds {
			// tx.token.allowance(sender, router) >= tx.amountIn
			approval, err := tokenContract.Allowance(nil, swapArgs.Sender, swapRouter)
			if err != nil {
				return err
			}
			if approval.Cmp(swapArgs.AmountIn) < 0 {
				return fmt.Errorf("insufficient approval: approval=%s, want=%s", approval.String(), swapArgs.AmountIn.String())
			}
		}

		// tx.token.balanceOf(sender) >= tx.amountIn
		balance, err := tokenContract.BalanceOf(nil, swapArgs.Sender)
		if err != nil {
			return err
		}
		if balance.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("insufficient balance: balance=%s, want=%s", balance.String(), swapArgs.AmountIn.String())
		}
	}

// IsApproveTx checks following conditions:
// A1. tx.to is a whitelisted ERC20 token.
// A2. tx.data is `approve(spender, amount)`.
// A3. spender is a whitelisted SwapRouter contract.
// A4. amount is MaxUint.
func (g *GaslessModule) IsApproveTx(tx *types.Transaction) bool {
	args, ok := decodeApproveTx(tx, g.signer)
	return ok && g.isApproveTx(args)
}

func (g *GaslessModule) isApproveTx(args *ApproveArgs) bool {
	g.gaslessInfoMu.RLock()
	defer g.gaslessInfoMu.RUnlock()

	return g.allowedTokens[args.Token] && // A1
		g.swapRouter == args.Spender && // A3
		args.Amount.Cmp(abi.MaxUint256) == 0 // A4
}

// IsSwapTx checks following conditions:
// S1. tx.to is a whitelisted SwapRouter contract.
// S2. tx.data is `swapForGas(token, amountIn, minAmountOut, amountRepay)`.
// S3. token is a whitelisted ERC20 token.
func (g *GaslessModule) IsSwapTx(tx *types.Transaction) bool {
	args, ok := decodeSwapTx(tx, g.signer)
	return ok && g.isSwapTx(args)
}

func (g *GaslessModule) isSwapTx(args *SwapArgs) bool {
	g.gaslessInfoMu.RLock()
	defer g.gaslessInfoMu.RUnlock()

	return g.swapRouter == args.Router && // S1
		g.allowedTokens[args.Token] // S3
}
