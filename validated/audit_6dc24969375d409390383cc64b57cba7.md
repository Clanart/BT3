Based on the investigation, I found a real analog in the deep-link ("Open in Desktop" / `x-github-client://openRepo`) pull-request handling flow.

### Title
Deep-link PR checkout silently switches an existing local repository to an attacker-controlled branch without confirmation - (File: `app/src/ui/dispatcher/dispatcher.ts`)

### Summary
GitHub Desktop registers a custom URL protocol handler that is parsed by `parseAppURL` [1](#0-0) . When the action is `openrepo` with a `pr` query parameter, `Dispatcher.openRepositoryFromUrl` routes to `openPullRequestFromUrl(url, pr)` [2](#0-1) . This function fetches the pull request from the API and then, if a locally-tracked repository can be found whose origin/upstream remote matches either the PR's `head` or `base` `clone_url`, it silently fetches and checks out the PR's head ref into that repository via `appStore._checkoutPullRequest` — with no user confirmation dialog for this URL-triggered path [3](#0-2) .

### Finding Description
The matching logic in `getRepositoryFromPullRequest`/`doesRepositoryMatchUrl` only performs a loose URL-string comparison (`urlsMatch`) between the PR's `head`/`base` clone URLs and the origin/upstream remote of any repository the user has open in Desktop [4](#0-3) . It performs no check on who created the PR, whether the head repository is a fork under attacker control, or whether the user actually intended to review/checkout that specific PR — the only "identity" check is a string-equality match on clone URL, exactly analogous to the original report's core flaw: an operation trusts a caller-supplied identifier (NFT collection there, PR head/base repo URL here) instead of verifying it against the asset the victim actually owns/expects.

Since any GitHub user can open a pull request against any public repository, an attacker can:
1. Fork a public repo that the victim already has cloned in Desktop.
2. Open a PR from the fork against the base repo.
3. Send the victim a link `x-github-client://openRepo/<base-repo-url>?pr=<PR-number>` (or `?branch=pr/<number>`, which `parseAppURL` explicitly permits via its regex `^pr\/\d+$` [5](#0-4) ).
4. When the victim clicks the link, Desktop matches the existing local clone of the base repo purely by URL and silently fetches + checks out the attacker's fork branch into it, with no confirmation prompt in this code path.

### Impact Explanation
This lets an attacker-controlled remote object (a PR they created) silently determine what code ends up checked out in the victim's working directory of an existing, trusted repository — corrupting what the victim will subsequently build, review, commit, or push, without any explicit confirmation step gating the action. If the victim's tooling or editor auto-runs scripts/hooks on branch switch, this expands to code execution; at minimum it silently substitutes the working tree contents the user believes they are working on, mirroring the "maker ends up with the wrong/cheaper asset without their knowledge" pattern from the original report.

### Likelihood Explanation
The only prerequisites are that the victim has the target repository already added in Desktop (a very common developer scenario for maintainers/frequent contributors) and clicks a link — no local access, credentials, or malware are required, satisfying the valid-impact criteria (attacker-controlled GitHub API object + a link the user clicks).

### Recommendation
Before performing the fetch/checkout for a URL-triggered PR action, require explicit user confirmation identifying the PR's head repository/owner, and/or verify that the matched repository's account/permission context is consistent with the PR before silently mutating the working directory — analogous to enforcing a "collection" check before substituting the asset.

### Proof of Concept
1. Victim has `https://github.com/target/repo` cloned locally and open in Desktop.
2. Attacker forks `target/repo`, pushes a modified/malicious branch, and opens PR #123 from the fork against `target/repo`.
3. Attacker sends victim: `x-github-client://openRepo/https://github.com/target/repo?pr=123&branch=pr/123`.
4. Victim clicks the link. `parseAppURL` accepts it [6](#0-5) , `openPullRequestFromUrl` matches the existing local `target/repo` clone by URL [7](#0-6) , and Desktop silently fetches and checks out the attacker's branch into the victim's existing repository without a confirmation prompt [8](#0-7) .

**Note:** I was not able to view the full body of `AppStore._checkoutPullRequest` in `app/src/lib/stores/app-store.ts` (only its call sites were indexed), so I cannot fully confirm whether any additional confirmation/guard exists deeper inside that method beyond what's shown in `dispatcher.ts`. Given index size limits, some file contents may not be available — starting a Devin session would allow direct inspection of `app-store.ts` to confirm whether a confirmation dialog exists elsewhere in that call chain.

export function parseAppURL(url: string): URLActionType {
  const parsedURL = URL.parse(url, true)
  const hostname = parsedURL.hostname
  const unknown: IUnknownAction = { name: 'unknown', url }
  if (!hostname) {
    return unknown
  }

  const query = parsedURL.query

  const actionName = hostname.toLowerCase()
  if (actionName === 'oauth') {
    const code = getQueryStringValue(query, 'code')
    const state = getQueryStringValue(query, 'state')
    if (code != null && state != null) {
      return { name: 'oauth', code, state }
    } else {
      return unknown
    }
  }

  // we require something resembling a URL first
  // - bail out if it's not defined
  // - bail out if you only have `/`
  const pathName = parsedURL.pathname
  if (!pathName || pathName.length <= 1) {
    return unknown
  }

  // Trim the trailing / from the URL
  const parsedPath = pathName.substring(1)

  if (actionName === 'openrepo') {
    const pr = getQueryStringValue(query, 'pr')
    const branch = getQueryStringValue(query, 'branch')
    const filepath = getQueryStringValue(query, 'filepath')

    if (pr != null) {
      if (!/^\d+$/.test(pr)) {
        return unknown
      }

      // we also expect the branch for a forked PR to be a given ref format
      if (branch != null && !/^pr\/\d+$/.test(branch)) {
        return unknown
      }
    }

    if (branch != null && testForInvalidChars(branch)) {
      return unknown
    }

    return {
      name: 'open-repository-from-url',
      url: parsedPath,
      branch,
      pr,
      filepath,
    }
  }

  private getRepositoryFromPullRequest(
    pullRequest: IAPIPullRequest
  ): RepositoryWithGitHubRepository | null {
    const state = this.appStore.getState()
    const repositories = state.repositories
    const headUrl = pullRequest.head.repo?.clone_url
    const baseUrl = pullRequest.base.repo?.clone_url

    // This likely means that the base repository has been deleted
    // and we don't support checking out from refs/pulls/NNN/head
    // yet so we'll bail for now.
    if (headUrl === undefined || baseUrl === undefined) {
      return null
    }

    for (const repository of repositories) {
      if (this.doesRepositoryMatchUrl(repository, headUrl)) {
        return repository
      }
    }

    for (const repository of repositories) {
      if (this.doesRepositoryMatchUrl(repository, baseUrl)) {
        return repository
      }
    }

    return null
  }

  private doesRepositoryMatchUrl(
    repo: Repository | CloningRepository,
    url: string
  ): repo is RepositoryWithGitHubRepository {
    if (repo instanceof Repository && isRepositoryWithGitHubRepository(repo)) {
      const originRepoUrl = repo.gitHubRepository.htmlURL
      const upstreamRepoUrl = repo.gitHubRepository.parent?.htmlURL ?? null

      if (originRepoUrl !== null && urlsMatch(originRepoUrl, url)) {
        return true
      }

      if (upstreamRepoUrl !== null && urlsMatch(upstreamRepoUrl, url)) {
        return true
      }
    }

    return false
  }

  private async openPullRequestFromUrl(
    url: string,
    pr: string
  ): Promise<RepositoryWithGitHubRepository | null> {
    const pullRequest = await this.appStore.fetchPullRequest(url, pr)

    if (pullRequest === null) {
      return null
    }

    // Find the repository where the PR is created in Desktop.
    let repository: Repository | null =
      this.getRepositoryFromPullRequest(pullRequest)

    if (repository !== null) {
      await this.selectRepository(repository)
    } else {
      repository = await this.openOrCloneRepository(url)
    }

    if (repository === null) {
      log.warn(
        `Open Repository from URL failed, did not find or clone repository: ${url}`
      )
      return null
    }
    if (!isRepositoryWithGitHubRepository(repository)) {
      log.warn(
        `Received a non-GitHub repository when opening repository from URL: ${url}`
      )
      return null
    }

    // ensure a fresh clone repository has it's in-memory state
    // up-to-date before performing the "Clone in Desktop" steps
    await this.appStore._refreshRepository(repository)

    if (pullRequest.head.repo === null) {
      return null
    }

    await this.appStore._checkoutPullRequest(
      repository,
      pullRequest.number,
      pullRequest.head.repo.owner.login,
      pullRequest.head.repo.clone_url,
      pullRequest.head.ref
    )

    return repository
  }
