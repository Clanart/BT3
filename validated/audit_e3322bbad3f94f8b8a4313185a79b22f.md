### Title
Data Layer mirror URLs allow attacker-controlled SSRF via automatic on-chain mirror fetch - ([File: chia/data_layer/download_data.py])

### Summary
Any unprivileged wallet user can create a "mirror" coin that publishes arbitrary URL strings on-chain for a Data Layer store via `dl_new_mirror` / `create_new_mirror`, without any URL validation. Every other node subscribed to that store's mirrors automatically fetches from the published URL using `aiohttp` with default redirect-following and no restriction on internal/link-local addresses, exactly matching the CWE-918 SSRF bug class in the external report (attacker-controlled URL + automatic redirect following + no internal-IP filtering).

### Finding Description
`DataLayerWallet.create_new_mirror()` creates a coin with puzzle `create_mirror_puzzle()` and stores the caller-supplied `urls: list[bytes]` (unvalidated strings) as memos on the `CREATE_COIN` condition, reachable through the standard wallet RPC `dl_new_mirror` (`chia/wallet/wallet_rpc_api.py` lines 3255-3274) or CLI `add_mirror` (`chia/cmds/data.py` 474-511). No scheme, hostname, or IP-range validation is applied to the URLs. [1](#0-0) [2](#0-1) 

Any full node/wallet that observes the mirror coin being created decodes the memo URLs via `get_mirror_info()` and stores them as a tracked `Mirror` for the store, with zero validation of the URL content. [3](#0-2) [4](#0-3) 

Any DataLayer service subscribed to the store (a local RPC caller invoking `subscribe`/`add_mirror`-published sync) pulls these URLs into `get_available_servers_for_store()` and iterates them in `fetch_and_validate()`, calling `insert_from_delta_file()` → `download_file()` → `http_download()`, which performs an unrestricted `aiohttp.ClientSession().get(server_info.url + "/" + filename, ...)` request with no allow-list, no private/link-local IP blocking, and default aiohttp redirect-following behavior: [5](#0-4) [6](#0-5) 

The same unvalidated URL is also forwarded to any registered downloader plugin via `get_downloader()`, and can itself return arbitrary redirects that libcurl-equivalent aiohttp will follow transparently. [7](#0-6) 

No `urlparse`/private-IP/redirect-restriction logic exists anywhere under `chia/data_layer/`, confirming there is no mitigation for this class of SSRF in the codebase (only `s3_plugin_service.py` has unrelated URL parsing for S3, not for SSRF protection).

### Impact Explanation
A single spend bundle submitted by any wallet user (no special privileges, no operator access) can plant a URL such as `http://169.254.169.254/latest/meta-data/` or `http://127.0.0.1:<internal-port>/...` as a store mirror. Any other node that subscribes to that Data Layer store (a normal, unprivileged Data Layer client action) will automatically issue outbound HTTP requests to that URL from its own process/network context during routine sync (`fetch_and_validate`), and will follow any redirect the attacker's endpoint or a compromised/attacker-run mirror returns. This can be used to probe or reach internal services, cloud metadata endpoints, or other hosts reachable only from the victim's network, and to bypass simple allow-list controls that only checked the initially-configured URL rather than the final destination. This matches the "reachable-by-unprivileged-actor SSRF via redirect" class from the reference advisory, though the underlying HTTP client differs (`aiohttp` here vs. `curl_cffi` in the report).

### Likelihood Explanation
High feasibility: creating a mirror coin only requires a small XCH amount and a standard spend, no special coin ownership or on-chain permission is enforced on the URL contents (`test_mirrors` test in `chia/_tests/core/data_layer/test_data_rpc.py` even demonstrates arbitrary loopback URLs being accepted: `urls = ["http://127.0.0.1/8000", "http://127.0.0.1/8001"]`). Any node that subscribes to the affected store will trigger the fetch automatically without a human clicking anything, and the sync loop retries periodically, giving the attacker repeated probing opportunities. [8](#0-7) 

### Recommendation
Validate mirror/server URLs before storing and before use in `create_new_mirror`, `add_mirror`, and at fetch time in `fetch_and_validate`/`http_download`/`get_downloader`: enforce an allow-listed scheme (e.g., https-only), resolve and reject requests to loopback, link-local (169.254.0.0/16), private (RFC1918), and other reserved ranges, and disable or strictly re-validate redirect targets (`allow_redirects=False` plus manual, re-validated redirect handling) in the `aiohttp.ClientSession` calls used for mirror/plugin downloads.

### Proof of Concept
1. Attacker wallet calls `dl_new_mirror` (or `chia data add_mirror`) for a store with `urls=["http://169.254.169.254/latest/meta-data/"]`, or a URL pointing at an attacker-controlled HTTP server that returns a 301/302 redirect to `http://127.0.0.1:<port>/...`.
2. The mirror coin spend is broadcast and confirmed like any normal transaction; no validation of the URL content or of the amount/fee bars this.
3. Any other node/DataLayer service subscribed to this store observes the coin via `coin_added()` in `chia/data_layer/data_layer_wallet.py`, decodes the URL via `get_mirror_info()`, and stores it as a `Mirror`/`ServerInfo`.
4. During its periodic `fetch_and_validate()` cycle, that node's `DataLayer` calls `http_download()`/`get_downloader()`, which performs the unrestricted `aiohttp` GET/POST to the attacker-controlled or redirect-pointed internal URL, exfiltrating whatever response content is returned into the node's own process (visible in logs/exceptions) and confirming SSRF against its internal network.

```python
def get_mirror_info(
    parent_puzzle: Program | SerializedProgram, parent_solution: Program | SerializedProgram
) -> tuple[bytes32, list[bytes]]:
    assert type(parent_puzzle) is type(parent_solution)
    _, conditions = run_with_cost(parent_puzzle, INFINITE_COST, parent_solution)
    for condition in conditions.as_iter():
        if (
            condition.first().as_python() == ConditionOpcode.CREATE_COIN
            and condition.at("rf").as_python() == create_mirror_puzzle().get_tree_hash()
        ):
            memos: list[bytes] = condition.at("rrrf").as_python()
            launcher_id = bytes32(memos[0])
            return launcher_id, [url for url in memos[1:]]
    raise ValueError("The provided puzzle and solution do not create a mirror coin")
```

```python
    async def get_downloader(self, store_id: bytes32, url: str) -> PluginRemote | None:
        request_json = {"store_id": store_id.hex(), "url": url}
        for d in self.downloaders:
            async with aiohttp.ClientSession() as session:
                try:
                    async with session.post(
                        d.url + "/handle_download",
                        json=request_json,
                        headers=d.headers,
                        timeout=self.client_timeout,
                    ) as response:
                        res_json = await response.json()
                        if res_json["handle_download"]:
                            return d
                except Exception as e:
                    self.log.error(f"get_downloader could not get response: {type(e).__name__}: {e}")
        return None
```

```python
async def http_download(
    target_filename_path: Path,
    filename: str,
    proxy_url: str | None,
    server_info: ServerInfo,
    timeout: aiohttp.ClientTimeout,
    log: logging.Logger,
    max_delta_file_size: int,
) -> None:
    """
    Download a file from a server using aiohttp.
    Raises exceptions on errors
    """
    async with aiohttp.ClientSession() as session:
        headers = {"accept-encoding": "gzip"}
        async with session.get(
            server_info.url + "/" + filename,
            headers=headers,
            timeout=timeout,
            proxy=proxy_url,
        ) as resp:
            resp.raise_for_status()
            size = int(resp.headers.get("content-length", 0))
            max_delta_file_size_bytes = max_delta_file_size * 1024 * 1024
            if size > max_delta_file_size_bytes:
                raise MaxDeltaFileSizeExceededError(f"Maximum delta file size exceeded: {max_delta_file_size} MiB.")
            log.debug(f"Downloading delta file {filename}. Size {size} bytes.")
```
