### Title
Gas griefing of block proposer via stale gasless-tx pool admission checks causing wasted bundle execution - ([File: kaiax/gasless/impl/tx_pool.go])

### Summary
The `kaiax/gasless` module admits `GaslessApproveTx`/`GaslessSwapTx` pairs into the tx pool based on a one-time balance/allowance check (`GetCheckBalance`), and later re-validates only structural readiness (`IsReady`/`isApproveTxReady`/`isSwapTxReady`) without re-checking on-chain balance/allowance before the transaction is bundled and executed at block-building time. An unprivileged sender can get a gasless bundle admitted while balance/allowance is sufficient, then drain/revoke it before the proposer commits the block, forcing the proposer to fully execute (and then discard) the `[LendTxGenerator, ApproveTx, SwapTx]` bundle for every such stale transaction — the same "cheap admission, costly settlement, state can drift in between" pattern described in the source report about `FundingRateArbitrage.requestWithdraw`/`permitWithdrawRequests`.

### Finding Description
`GetCheckBalance()` performs the balance/allowance/deadline checks for gasless transactions only at admission time: [1](#0-0) 

These checks are gated by `BalanceCheckLevel` and, even at the strictest level, are only evaluated once (`checkBalanceForSwap` reads current on-chain balance/allowance at admission): [2](#0-1) 

Subsequent promotion/readiness checks (`isApproveTxReady`, `isSwapTxReady`) only validate nonce sequencing and structural executability (`IsExecutable`/`VerifyExecutable`), never re-checking balance or allowance: [3](#0-2) [4](#0-3) 

When the transaction is finally selected for a block, `ExtractTxBundles` builds a bundle of `[LendTxGenerator, ApproveTx(optional), SwapTx]`: [5](#0-4) 

`commitBundleTransaction` in the worker then actually executes each tx in the bundle. If the swap reverts on-chain (e.g., because the attacker moved the tokens out or revoked the allowance after admission), the whole bundle — including the already-executed LendTx and ApproveTx — is discarded via a state restore, and the transaction is marked unexecutable: [6](#0-5) 

The proposer still paid for evaluating readiness, generating/signing the LendTx, and running the EVM for ApproveTx/SwapTx up to the revert, all of which is wasted work with no compensating fee (the LendTx amount, meant to be repaid by the swap, is never realized since the state is rolled back).

### Impact Explanation
An attacker can cheaply create many gasless approve+swap tx pairs, get them admitted with sufficient (even minimal) token balance/allowance, then transfer the tokens away or revoke approval before the block is built. Because there is no re-check of balance/allowance at block-building time, the proposer will repeatedly attempt to execute doomed bundles (wasting EVM computation and block-building time) across many blocks/attempts, mirroring the original report's root cause: state (index/balance) drifting between a cheap admission check and an expensive settlement/batch step, causing the privileged executor (Owner in the report; block proposer/CN here) to waste resources and potentially delay legitimate gasless users' transactions competing for the same `MaxBundleTxsInPending`/`MaxBundleTxsInQueue` slots.

### Likelihood Explanation
Reachable purely through normal transaction submission (approve tx + swap tx) by any unprivileged RPC caller; no special privileges are required. The attack is bounded by `MaxBundleTxsInQueue`/`MaxBundleTxsInPending` limits, and severity depends on the configured `BalanceCheckLevel` and how much genuine balance/allowance manipulation costs the attacker versus the wasted EVM execution cost to the proposer — this reduces but does not eliminate the exposure, since even a minimal real balance is enough to pass admission before draining it.

### Recommendation
Re-validate balance and allowance immediately before including the gasless bundle in a block (or as part of `commitBundleTransaction`'s pre-check, before spending gas on the LendTx), and/or drop/deprioritize gasless bundle transactions whose sender's on-chain balance/allowance has changed unfavorably since admission, similar to how nonce is re-checked. Consider charging or penalizing repeated failed gasless bundle attempts from the same sender.

### Proof of Concept
1. Attacker acquires a small amount of an allowed ERC20 token and submits `ApproveTx` (approve SwapRouter for max) + `SwapTx` (`swapForGas`) as a gasless pair; both pass `GetCheckBalance` at admission (`kaiax/gasless/impl/tx_pool.go:107-182`).
2. Bundle is promoted to pending via `IsReady`, which does not re-check balance (`kaiax/gasless/impl/tx_pool.go:184-290`).
3. Before the proposer builds a block containing this bundle, attacker transfers away the token balance or revokes the ERC20 allowance in a separate transaction.
4. When the proposer's worker builds a block, `ExtractTxBundles` still includes the stale bundle (`kaiax/gasless/impl/builder.go:28-72`); `commitBundleTransaction` executes `LendTxGenerator` then `ApproveTx`, then `SwapTx`, which reverts on-chain due to insufficient balance/allowance, causing the entire bundle to be discarded and state rolled back (`work/worker.go:877-936`).
5. Repeat with many attacker-controlled addresses/tokens to force the proposer to repeatedly waste EVM execution on doomed bundles across multiple blocks, at minimal repeated cost to the attacker (just moving small token amounts back and forth).

func (g *GaslessModule) GetCheckBalance() func(tx *types.Transaction) error {
	return func(tx *types.Transaction) error {
		if approveArgs, ok := decodeApproveTx(tx, g.signer); ok {
			return g.checkBalanceForApprove(approveArgs)
		}
		if swapArgs, ok := decodeSwapTx(tx, g.signer); ok {
			return g.checkBalanceForSwap(swapArgs, tx.Nonce())
		}
		return errors.New("not a gasless transaction") // should not happen because IsModuleTx is called before GetCheckBalance
	}
}

// isApproveTxReady assumes that the caller checked `g.IsApproveTx(approveTx)`
func (g *GaslessModule) isApproveTxReady(approveTx, nextTx *types.Transaction) bool {
	addr, err := types.Sender(g.signer, approveTx)
	if err != nil {
		return false
	}
	nonce := g.getCurrentStateNonce(addr)

	if approveTx.Nonce() != nonce {
		return false
	}
	if nextTx == nil || !g.IsSwapTx(nextTx) {
		return false
	}

	return g.IsExecutable(approveTx, nextTx)
}

// isSwapTxReady assumes that the caller checked `g.IsSwapTx(swapTx)`
func (g *GaslessModule) isSwapTxReady(swapTx, prevTx *types.Transaction) bool {
	addr, err := types.Sender(g.signer, swapTx)
	if err != nil {
		return false
	}
	nonce := g.getCurrentStateNonce(addr)

	var approveTx *types.Transaction
	if swapTx.Nonce() == nonce {
		approveTx = nil
	} else if swapTx.Nonce() == nonce+1 {
		if prevTx == nil || !g.IsApproveTx(prevTx) {
			return false
		}
		approveTx = prevTx
	} else {
		return false
	}

	return g.IsExecutable(approveTx, swapTx)
}

func (g *GaslessModule) IsExecutable(approveTxOrNil, swapTx *types.Transaction) bool {
	err := g.VerifyExecutable(approveTxOrNil, swapTx)
	if err != nil {
		return false
	}
	return true
}

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
}
