Confirmed: `AddCW20`/`AddCW721`/`AddCW1155` in the pointer precompile are fully permissionless — any caller can register a pointer for any wasm contract address that merely returns a `token_info`/`contract_info` query successfully, with no verification of the contract's actual `execute` logic.

### Title
Forged Wasm Events from Attacker-Controlled Pointer Targets Are Trusted as Real ERC20/721/1155 Transfer Logs in EVM Receipts - (File: app/receipt.go)

### Summary
`app.AddCosmosEventsToEVMReceiptIfApplicable` and its helpers (`translateCW20Event`, `translateCW721Event`, `translateCW1155Event`, `GetActionsFromWasmEvent`) synthesize ERC20/ERC721/ERC1155 `Transfer`/`Approval` EVM logs directly from the `action`/`amount`/`from`/`to`/`recipient` attributes of a Cosmos `wasm` module event, without validating that a corresponding balance/ownership state change actually occurred. Because `precompiles/pointer/pointer.go`'s `AddCW20`/`AddCW721`/`AddCW1155` allow **any** caller to register **any** wasm contract as a CW20/CW721/CW1155 pointer target (the only check is that a `token_info`/`contract_info` query succeeds), an attacker can deploy a minimal wasm contract that emits `wasm` events with a fabricated `action` (e.g. `transfer`), `amount`, `from`, and `to` attributes without moving any tokens, register it as a pointer, and produce EVM receipts/logs indistinguishable from a genuine ERC20/721/1155 transfer.

### Finding Description
`AddCosmosEventsToEVMReceiptIfApplicable` [1](#0-0)  looks for `wasm` events whose `contract_addr` attribute matches a registered CW20/CW721/CW1155 pointer [2](#0-1) . The registration check itself (`GetERC20CW20Pointer`/`GetERC721CW721Pointer`/`GetERC1155CW1155Pointer`) is populated by the permissionless `pointer` precompile, whose `AddCW20`/`AddCW721`/`AddCW1155` methods only validate that a `token_info`/`contract_info` query on the target contract succeeds — they perform no check that the target contract's `execute` entrypoint actually performs the state-changing operations it claims to via its emitted attributes [3](#0-2) .

`GetActionsFromWasmEvent` then blindly parses whatever `action`, `amount`, `from`, `to`, `recipient`, `owner`, `spender`, `operator`, `token_id` attributes are present in the wasm event emitted by the (attacker-controlled) contract [4](#0-3) , and `translateCW20Event`/`translateCW721Event`/`translateCW1155Event` unconditionally convert these self-reported attributes into `ERC20TransferTopic`/`ERC721TransferTopic`/`ERC1155TransferSingleTopic` EVM logs [5](#0-4) [6](#0-5) [7](#0-6) . These synthetic logs are written into the transient receipt and bloom that any EVM JSON-RPC client (`eth_getLogs`, `eth_getTransactionReceipt`) will see [8](#0-7) .

This is directly analogous to the reported bug class: an event ("transfer occurred") is emitted/reported regardless of whether the underlying operation was truthfully performed, because the emitting code trusts a self-reported flag/attribute instead of verifying the actual outcome.

### Impact Explanation
Any unprivileged EVM/CosmWasm user can call the permissionless `pointer` precompile (`0x000000000000000000000000000000000000100b`) to register their own malicious wasm contract as a CW20/CW721/CW1155 pointer, then execute arbitrary messages against that contract to emit fabricated `wasm` events with a fake `transfer`/`mint` `action` and arbitrary `from`/`to`/`amount`/`token_id` values. The chain will faithfully synthesize corresponding ERC20/ERC721/ERC1155 `Transfer` logs into the pointer address's EVM receipt/bloom, even though no real token balance or NFT ownership changed either in the underlying CW20/CW721/CW1155 contract or via the pointer's `balanceOf`/`ownerOf`. Any downstream system that trusts logs/receipts as ground truth for token movement (custodial exchanges crediting deposits, bridges, indexers, other on-chain contracts reading logs) can be deceived into crediting value that was never actually transferred — a form of fund-loss/unauthorized-transfer-via-pointer attack, since the RPC surface is public and the pointer registration and event forgery require only normal transaction sends.

### Likelihood Explanation
High reachability: pointer registration is fully permissionless (no admin/allowlist check beyond a successful `token_info`/`contract_info` query), and emitting arbitrary wasm event attributes from a self-authored CW20-shaped contract is trivial. The only constraint is that a victim system must trust EVM logs/receipts for the pointer's token without independently verifying actual balances via `balanceOf`/`ownerOf` — a common pattern for automated systems that watch `Transfer` events for deposit detection.

### Recommendation
- Do not synthesize ERC20/721/1155 transfer/approval logs purely from self-reported wasm event attributes. Cross-check the claimed state change against the actual contract state (e.g., query `balance`/`owner_of` before and after, or require the amount/ownership delta to match) before emitting the synthetic log, mirroring the fix pattern of only emitting the event once the true outcome is confirmed.
- Alternatively, restrict/gate CW20/721/1155 pointer registration (e.g., require code-ID allowlisting or a stricter conformance check of the contract's actual execute behavior) so arbitrary attacker-authored contracts cannot become pointer targets whose wasm events are automatically translated into trusted EVM logs.

### Proof of Concept
1. Attacker deploys a wasm contract `Evil` that:
   - Responds to `{"token_info":{}}"` with a valid `{name, symbol, ...}` JSON (satisfying `AddCW20`'s only check).
   - On any `execute` call, emits a `wasm` event with attributes `action=transfer`, `from=<victim_or_arbitrary>`, `to=<attacker_deposit_address>`, `amount=<large_value>`, without performing any real balance change.
2. Attacker calls the `pointer` precompile's `addCW20Pointer(EvilAddr)` (permissionless) — `AddCW20` succeeds and registers `Evil` as a CW20 pointer with a fresh ERC20 contract address `P` [3](#0-2) .
3. Attacker sends any Cosmos tx invoking `Evil`'s execute entrypoint, which emits the forged `wasm` transfer event.
4. `AddCosmosEventsToEVMReceiptIfApplicable` detects the event as belonging to the registered pointer `P`, and `translateCW20Event`/`GetActionsFromWasmEvent` synthesize an `ERC20TransferTopic` log on `P` with `from`/`to`/`amount` taken verbatim from the forged attributes, and store it in the tx's EVM receipt/bloom [9](#0-8) [8](#0-7) .
5. Any off-chain consumer watching `Transfer` events on `P` via `eth_getLogs`/receipts (e.g., a deposit-monitoring service) observes an apparent transfer of `amount` tokens to the attacker's address and credits value, while `P.balanceOf`/the underlying CW20 balance never actually changed.

func (app *App) translateCW20Event(ctx sdk.Context, wasmEvent abci.Event, pointerAddr common.Address, contractAddr string) (res []*ethtypes.Log) {
	defer func() {
		if r := recover(); r != nil {
			fmt.Printf("[Error] Panic caught during translateCW20Event: type=%T, value=%+v\n", r, r)
		}
	}()

	for _, action := range app.GetActionsFromWasmEvent(ctx, wasmEvent) {
		switch action.Type {
		case "mint", "burn", "send", "transfer", "transfer_from", "send_from", "burn_from":
			if action.Amount == nil {
				continue
			}
			res = append(res, &ethtypes.Log{
				Address: pointerAddr,
				Topics: []common.Hash{
					ERC20TransferTopic,
					action.From,
					action.To,
				},
				Data: common.BigToHash(action.Amount).Bytes(),
			})
		case "increase_allowance", "decrease_allowance":
			topics := []common.Hash{
				ERC20ApprovalTopic,
				action.Owner,
				action.Spender,
			}
			ret, err := app.WasmKeeper.QuerySmart(
				ctx,
				sdk.MustAccAddressFromBech32(contractAddr),
				[]byte(fmt.Sprintf(
					"{\"allowance\":{\"owner\":\"%s\",\"spender\":\"%s\"}}",
					app.EvmKeeper.GetSeiAddressOrDefault(ctx, common.BytesToAddress(action.Owner[:])).String(),
					app.EvmKeeper.GetSeiAddressOrDefault(ctx, common.BytesToAddress(action.Spender[:])).String())),
			)
			if err != nil {
				continue
			}
			allowanceResponse := &AllowanceResponse{}
			if err := json.Unmarshal(ret, allowanceResponse); err != nil {
				continue
			}
			res = append(res, &ethtypes.Log{
				Address: pointerAddr,
				Topics:  topics,
				Data:    common.BigToHash(allowanceResponse.Allowance.BigInt()).Bytes(),
			})
		}
	}
	return
}

func (app *App) translateCW1155Event(ctx sdk.Context, wasmEvent abci.Event, pointerAddr common.Address, contractAddr string) (res []*ethtypes.Log) {
	for _, action := range app.GetActionsFromWasmEvent(ctx, wasmEvent) {
		switch action.Type {
		case "transfer_single", "mint_single", "burn_single":
			fromHash := EmptyHash
			toHash := EmptyHash
			if action.Type != "mint_single" {
				fromHash = action.Owner
			}
			if action.Type != "burn_single" {
				toHash = action.Recipient
			}
			if action.TokenId == nil {
				continue
			}
			if action.Amount == nil {
				continue
			}
			dataHash1 := common.BigToHash(action.TokenId).Bytes()
			dataHash2 := common.BigToHash(action.Amount).Bytes()
			res = append(res, &ethtypes.Log{
				Address: pointerAddr,
				Topics: []common.Hash{
					ERC1155TransferSingleTopic,
					action.Sender,
					fromHash,
					toHash,
				},
				Data: append(dataHash1, dataHash2...),
			})
		case "transfer_batch", "mint_batch", "burn_batch":
			fromHash := EmptyHash
			toHash := EmptyHash
			if action.Type != "mint_batch" {
				fromHash = action.Owner
			}
			if action.Type != "burn_batch" {
				toHash = action.Recipient
			}
			if len(action.TokenIds) == 0 {
				continue
			}
			if len(action.Amounts) == 0 {
				continue
			}
			dataArgs := cw1155.GetParsedABI().Events["TransferBatch"].Inputs.NonIndexed()
			value, err := dataArgs.Pack(action.TokenIds, action.Amounts)
			if err != nil {
				logger.Error("Failed to parse TransferBatch event data", "err", err)
				continue
			}
			res = append(res, &ethtypes.Log{
				Address: pointerAddr,
				Topics: []common.Hash{
					ERC1155TransferBatchTopic,
					action.Sender,
					fromHash,
					toHash,
				},
				Data: value,
			})
		case "approve_all":
			res = append(res, &ethtypes.Log{
				Address: pointerAddr,
				Topics: []common.Hash{
					ERC1155ApprovalForAllTopic,
					action.Sender,
					action.Operator,
				},
				Data: TrueHash.Bytes(),
			})
		case "revoke_all":
			res = append(res, &ethtypes.Log{
				Address: pointerAddr,
				Topics: []common.Hash{
					ERC1155ApprovalForAllTopic,
					action.Sender,
					action.Operator,
				},
				Data: EmptyHash.Bytes(),
			})
		}
	}
	return
}

func (app *App) GetActionsFromWasmEvent(ctx sdk.Context, event abci.Event) (actions []*Action) {
	for _, attr := range event.Attributes {
		key := string(attr.Key)
		value := string(attr.Value)
		if key == "action" {
			actions = append(actions, &Action{Type: value})
			continue
		}
		if len(actions) == 0 {
			continue
		}
		curAction := actions[len(actions)-1]
		switch key {
		case "amount":
			curAction.Amount = safeBigIntFromString(value)
		case "amounts":
			curAction.Amounts = utils.Map(strings.Split(value, ","), safeBigIntFromString)
		case "token_id":
			curAction.TokenId = safeBigIntFromString(value)
		case "token_ids":
			curAction.TokenIds = utils.Map(strings.Split(value, ","), safeBigIntFromString)
		case "sender":
			curAction.Sender = app.GetEvmAddressHash(ctx, value)
		case "recipient":
			curAction.Recipient = app.GetEvmAddressHash(ctx, value)
		case "spender":
			curAction.Spender = app.GetEvmAddressHash(ctx, value)
		case "operator":
			curAction.Operator = app.GetEvmAddressHash(ctx, value)
		case "owner":
			curAction.Owner = app.GetEvmAddressHash(ctx, value)
		case "from":
			curAction.From = app.GetEvmAddressHash(ctx, value)
		case "to":
			curAction.To = app.GetEvmAddressHash(ctx, value)
		}
	}
	return
}

func (p PrecompileExecutor) AddCW20(ctx sdk.Context, method *ethabi.Method, caller common.Address, args []interface{}, value *big.Int, evm *vm.EVM, hooks *tracing.Hooks) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}
	if err := pcommon.ValidateArgsLength(args, 1); err != nil {
		return nil, 0, err
	}
	cwAddr := args[0].(string)
	cwAddress, err := sdk.AccAddressFromBech32(cwAddr)
	if err != nil {
		return nil, 0, err
	}
	res, err := p.wasmdKeeper.QuerySmartSafe(ctx, cwAddress, []byte("{\"token_info\":{}}"))
	if err != nil {
		return nil, 0, err
	}
	formattedRes := map[string]interface{}{}
	if err := json.Unmarshal(res, &formattedRes); err != nil {
		return nil, 0, err
	}
	name := formattedRes["name"].(string)
	symbol := formattedRes["symbol"].(string)
	contractAddr, err := p.evmKeeper.UpsertERCCW20Pointer(ctx, evm, cwAddr, utils.ERCMetadata{Name: name, Symbol: symbol})
	if err != nil {
		return nil, 0, err
	}

	ret, err = method.Outputs.Pack(contractAddr)
	remainingGas = pcommon.GetRemainingGas(ctx, p.evmKeeper)
	return
}
