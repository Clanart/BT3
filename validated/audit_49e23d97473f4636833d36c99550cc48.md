Based on my research, the strongest reachable analog to the Allbridge swap-price-manipulation incident is the `kaiax/gasless` module's admission-time price check, which is a spot-price read from the Uniswap-style pool that a swap-tx sender can manipulate at execution time.

### Title
Gasless swap admission relies on a manipulable spot price from the swap router, allowing repayment-amount bypass / proposer fee-lending loss - ([File: kaiax/gasless/impl/tx_pool.go])

### Summary
The Allbridge incident exploited that a swap's execution price was derived from the pool's spot reserves, letting an attacker who is both LP and trader manipulate the price within a single sequence of transactions to drain value. The Kaia gasless (KIP-247) module has an analogous pattern: `checkBalanceForSwap` validates a `GaslessSwapTx`'s `AmountIn` against a `minAmountOut` by querying `routerContract.GetAmountIn(nil, token, minAmountOut)` [1](#0-0)  — a live, spot-price read off the on-chain AMM (Uniswap V2-style) pool the module wires up in tests [2](#0-1) .

### Finding Description
The gasless flow works as: the proposer prepends a `LendTxGenerator` transaction that advances the user's gas fee, then bundles `[Lend, (Approve), Swap]` [3](#0-2) . The user's `SwapForGas` transaction is expected to swap tokens for enough output to cover `amountRepay` (the lent gas), enforced only by `swapArgs.MinAmountOut.Cmp(swapArgs.AmountRepay) >= 0` and by cross-checking `AmountIn` against the *current* router-quoted `GetAmountIn` [4](#0-3) . Because `GetAmountIn`/pool reserves are read live from the pool contract that any unprivileged trader can move (via ordinary swaps, flash loans, or sandwiching) between the transaction-pool admission check and the block-building/execution point, the sender who controls the sequence of transactions (or an unrelated third party trading against the same pool) can shift the spot price so that the swap executes at a much worse rate than assumed at admission time, or vice versa, so that a swap that was rejected/accepted at admission produces a different real outcome at execution. `VerifyExecutable`, which is also exposed via the public `gasless_isGaslessTx` RPC, performs the identical repay-amount check using the same spot-derived values [5](#0-4) , so it does not add any TWAP, minimum-liquidity, or manipulation-resistance protection beyond the on-chain AMM's own `minAmountOut` slippage floor enforced inside `swapForGas`. Since `ShouldCheckSwapAmount()` is a governance-configurable toggle [6](#0-5) , and the whole admission-time amountIn sizing is based on momentary reserves, a searcher/bidder that can manipulate the pool immediately before or during the target block (e.g., through an ordinary swap included in the same block by the auction/bundling logic) can cause the gasless flow to either (a) let a swap be admitted with insufficient real output to cover `amountRepay`, causing the proposer's pre-lent gas fee not to be recouped, or (b) force excess token extraction from the user beyond what a non-manipulated price would require.

### Impact Explanation
If price manipulation allows a gasless swap to under-repay the block proposer's advanced gas fee, this is a direct fee/gasless-settlement theft: the proposer (via `LendTxGenerator`) has already paid out actual KAIA gas on behalf of the user, and repayment is contingent on the AMM swap producing at least `amountRepay` in output token, which is itself governed by a manipulable spot price at execution time rather than by the frozen state that was checked at admission. This matches "gasless or auction settlement theft" in the analog policy scope and could result in concrete unauthorized value loss to proposers or the gasless subsidy pool at Medium severity, scoped per swap size and pool liquidity.

### Likelihood Explanation
Reaching this path requires only submitting ordinary transactions: a gasless approve/swap transaction pair plus an unprivileged trade against the same underlying Uniswap-style pool (or via the same block's bundle) to shift reserves — all reachable by any transaction sender with no special privileges, matching the pool-admission / gasless reachability constraints in scope. However, the actual on-chain `GaslessSwapRouter.swapForGas` bytecode (not present as readable Solidity source in this index) is what ultimately enforces `minAmountOut` at execution, so the real exploitability depends on exact contract logic not fully visible here; that part could not be independently verified from the indexed contents.

### Recommendation
Use a manipulation-resistant price source (e.g., TWAP oracle or block-boundary reserve snapshot) rather than the live `GetAmountIn` spot quote for gasless admission checks, and re-validate `AmountRepay` coverage post-execution (or fail the whole bundle atomically) so a manipulated swap cannot leave the proposer's lent gas fee unrecovered.

### Proof of Concept
1. Attacker (or colluding party) holds LP position and trade access to the token/WKAIA pool wired to `GaslessSwapRouter` (as set up in `setupLiquidity`) [7](#0-6) .
2. Attacker submits a `GaslessApproveTx` + `GaslessSwapTx` pair sized against the pool's current reserves, satisfying `checkBalanceForSwap`'s `GetAmountIn` check at admission time [1](#0-0) .
3. Before the bundle executes on-chain (in the same or a following block), attacker executes an ordinary swap against the same pool to shift reserves/spot price.
4. When the bundle (`Lend, Approve, Swap`) executes, the proposer has already advanced `amountRepay` in gas fees via the lend transaction, but the manipulated pool price causes the real swap output to fall short of `amountRepay`, since the admission-time `GetAmountIn`/`MinAmountOut` check no longer reflects the reserves at execution time.

Note: the exact enforcement inside `GaslessSwapRouter.swapForGas` (whether it reverts on insufficient output, and how it settles repayment to the proposer) is implemented in compiled bytecode bindings only [8](#0-7)  — no on-chain Solidity source for this system contract was found in the index, so full confirmation of exploitability requires reviewing that contract's source directly (consider starting a Devin session with full repo/tooling access if this level of certainty is required).

func (g *GaslessModule) checkBalanceForSwap(swapArgs *SwapArgs, swapNonce uint64) error {
	token := swapArgs.Token
	bc := backends.NewBlockchainContractBackend(g.Chain, nil, nil)

	g.gaslessInfoMu.RLock()
	swapRouter := g.swapRouter
	g.gaslessInfoMu.RUnlock()

	// tx.minAmountOut >= tx.amountRepay
	minAmountOut := swapArgs.MinAmountOut
	amountRepay := swapArgs.AmountRepay
	if minAmountOut.Cmp(amountRepay) < 0 {
		return fmt.Errorf("insufficient minAmountOut: minAmountOut=%s, amountRepay=%s", minAmountOut.String(), amountRepay.String())
	}

	if g.GaslessConfig.ShouldCheckSenderCode() {
		if g.getCurrentHasCode(swapArgs.Sender) {
			return errors.New("sender with code is not allowed")
		}
	}

	if g.GaslessConfig.ShouldCheckSwapAmount() {
		// tx.amountIn >= gsr.getAmountIn(minAmountOut)
		routerContract, err := kip247.NewGaslessSwapRouterCaller(swapRouter, bc)
		if err != nil {
			return err
		}
		// Required token amountIn, given the current exchange rate and the declared minAmountOut.
		requiredAmountIn, err := routerContract.GetAmountIn(nil, token, minAmountOut)
		if err != nil {
			return err
		}
		if swapArgs.AmountIn.Cmp(requiredAmountIn) < 0 {
			return fmt.Errorf("insufficient amountIn: have=%s, want=%s", swapArgs.AmountIn.String(), requiredAmountIn.String())
		}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
}

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}
