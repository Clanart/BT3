### Title
Message-map `MergeFrom` mutates the underlying `MapFieldBase` without invalidating cached `CMessage` wrappers for overwritten entries, creating a stale-wrapper / potential use-after-free analogous to the ERC20Pods stale-balance reentrancy bug - ([File: python/google/protobuf/pyext/map_container.cc])

### Summary
The ERC20Pods bug caches `balance` once before a loop, and a hostile pod callback mid-loop mutates state, so the loop continues to operate on stale data and hands out value inconsistent with true balances. The transferable invariant is: *"a value cached before an operation that can trigger nested mutation must be re-validated/invalidated before it is used again."* In `MapReflectionFriend::MergeFrom` (`python/google/protobuf/pyext/map_container.cc:307-327`), a message map is merged via `field->MergeFrom(message->GetArena(), *other_field)`, which for keys already present overwrites the destination map entry's message in place (this is explicitly called out for the whole-message `MergeFrom` code path in `python/google/protobuf/pyext/message.cc:774-789`: *"For message map with same keys, it is overwrite"*). Unlike the sibling, already-hardened path for non-repeated oneof message fields (`MaybeReleaseOneofBeforeMerge` / `FixupMessageAfterMerge`, `message.cc:757-840`), the map `MergeFrom` path performs no equivalent step to detach/refresh any previously cached Python `CMessage` wrapper object that still points at the map-value message being overwritten.

### Finding Description
`MapReflectionFriend::MergeFrom` (`python/google/protobuf/pyext/map_container.cc:307-327`) does:
```
internal::MapFieldBase* field = reflection->MutableMapData(message, self->parent_field_descriptor);
const internal::MapFieldBase* other_field = other_reflection->GetMapData(*other_message, other_map->parent_field_descriptor);
field->MergeFrom(message->GetArena(), *other_field);
self->version++;
```
This directly calls into the C++ `MapFieldBase::MergeFrom`, which for a message-valued map "overwrites" (per the design comment in `message.cc`) any entry whose key exists in both maps. Overwriting an existing map value can invalidate the memory previously returned by `MessageMapGetItem` (`map_container.cc:675-706`), which builds a `CMessage` Python wrapper pointing directly at the C++ submessage pointer inside the map (`GetCMessage` -> `BuildSubMessageFromPointer`). If application code holds such a cached wrapper (e.g., `sub = msg.my_map[key]`) and then calls `msg.my_map.MergeFrom(other)` (directly, or transitively via `msg.MergeFrom(other)` for a message that contains a map field), the C++-side value the wrapper's raw pointer refers to can be freed/reused by the overwrite, while the Python wrapper is not detected/detached the way `MaybeReleaseOneofBeforeMerge`/`FixupMessageAfterMerge` explicitly do for non-repeated oneof submessage fields. The `MessageMapSetItem` deletion path (`map_container.cc:620-668`) shows the pattern the codebase itself uses to safely handle this (`MaybeReleaseSubMessage` + `Swap` into a freshly allocated message) precisely because dangling wrappers are a known concrete hazard for this data structure — but that safe-release logic is not invoked from the map `MergeFrom` overwrite path.

This mirrors the reentrancy analog exactly: a value is computed/cached (the wrapper's raw `Message*`) before an operation (`MergeFrom`) that is known (per the code's own comments) to mutate/replace state for matching keys, and the caching is not re-validated afterward for that specific mutation path, even though the surrounding code demonstrates awareness of, and a fix pattern for, the identical class of bug in the sibling oneof-merge and map-delete code paths.

### Impact Explanation
If confirmed reachable, this is a memory-safety bug (use-after-free / stale-pointer dereference) in the CPython C-extension bindings, reachable purely through the public, documented `MergeFrom` API on message-valued Protobuf maps with attacker-controlled overlapping keys in the "other" message. Depending on allocator reuse this can range from a crash (denial of service in the hosting Python process) up to memory corruption/information disclosure if the freed slot is reused by attacker-influenced data before the stale wrapper is read. This would be Critical/High severity for any Python service that parses untrusted Protobuf messages into map fields and merges them into long-lived caches while holding references to prior map entries — a common pattern for accumulating/aggregating protobuf state.

### Likelihood Explanation
Medium-to-Low confidence of exploitability without live execution, because I could not fully trace `internal::MapFieldBase::MergeFrom`'s exact overwrite mechanics (arena ownership, whether it swaps/deletes/reuses the destination submessage's underlying `Message*` versus updating in place) or definitively confirm through this read-only environment that `CMessage::BuildSubMessageFromPointer` wrappers are not otherwise protected (e.g., via arena lifetime guarantees that make the pointer merely stale-but-still-valid until arena reset, rather than immediately freed). The design comment in `message.cc` ("For message map with same keys, it is overwrite") strongly suggests real mutation of existing entries occurs, and the contrast with the deliberate, comment-documented fixes for the structurally identical oneof-merge case and map-delete case is the strongest evidence that this map-merge overwrite path was not given the same treatment. This should be verified with a live build/repro (see PoC) before treating as confirmed.

### Recommendation
Before calling `field->MergeFrom(...)` in `MapReflectionFriend::MergeFrom`, walk the destination map for keys that also exist in `other_field` and, for message-valued maps, use the same safe-release pattern already implemented in `MessageMapSetItem` (`MaybeReleaseSubMessage` + allocate a replacement + `Swap`) to detach any live Python wrapper for that key before the underlying `MapFieldBase::MergeFrom` overwrites it; alternatively, extend `FixupMessageAfterMerge`-style re-validation to walk `composite_fields` entries owned by `MessageMapContainer` wrappers after the merge and refresh/repoint them exactly as is done for oneof submessages.

PyObject* MapReflectionFriend::MergeFrom(PyObject* _self, PyObject* arg) {
  MapContainer* self = GetMap(_self);
  if (!PyObject_TypeCheck(arg, ScalarMapContainer_Type) &&
      !PyObject_TypeCheck(arg, MessageMapContainer_Type)) {
    PyErr_SetString(PyExc_AttributeError, "Not a map field");
    return nullptr;
  }
  MapContainer* other_map = GetMap(arg);
  Message* message = self->GetMutableMessage();
  if (message == nullptr) return nullptr;
  const Message* other_message = other_map->parent->message;
  const Reflection* reflection = message->GetReflection();
  const Reflection* other_reflection = other_message->GetReflection();
  internal::MapFieldBase* field =
      reflection->MutableMapData(message, self->parent_field_descriptor);
  const internal::MapFieldBase* other_field = other_reflection->GetMapData(
      *other_message, other_map->parent_field_descriptor);
  field->MergeFrom(message->GetArena(), *other_field);
  self->version++;
  Py_RETURN_NONE;
}

int MapReflectionFriend::MessageMapSetItem(PyObject* _self, PyObject* key,
                                           PyObject* v) {
  if (v) {
    PyErr_Format(PyExc_ValueError,
                 "Direct assignment of submessage not allowed");
    return -1;
  }

  // Now we know that this is a delete, not a set.

  MessageMapContainer* self = GetMessageMap(_self);
  Message* message = self->GetMutableMessage();
  if (message == nullptr) return -1;
  const Reflection* reflection = message->GetReflection();
  MapKey map_key;

  self->version++;

  if (!PythonToMapKey(self, key, &map_key)) {
    return -1;
  }

  // Delete key from map.
  if (reflection->ContainsMapKey(*message, self->parent_field_descriptor,
                                 map_key)) {
    // Delete key from CMessage dict.
    MapValueRef value;
    reflection->InsertOrLookupMapValue(message, self->parent_field_descriptor,
                                       map_key, &value);
    Message* sub_message = value.MutableMessageValue();
    // If there is a living weak reference to an item, we "Release" it,
    // otherwise we just discard the C++ value.
    if (CMessage* released =
            self->parent->MaybeReleaseSubMessage(sub_message)) {
      Message* msg = cmessage::AssureWritable(released);
      if (msg == nullptr) return 0;
      Message* new_msg = msg->New();
      released->message = new_msg;
      msg->GetReflection()->Swap(msg, new_msg);
    }

    // Delete key from map.
    reflection->DeleteMapValue(message, self->parent_field_descriptor, map_key);
    return 0;
  } else {
    PyErr_Format(PyExc_KeyError, "Key not present in map");
    return -1;
  }
}

PyObject* MapReflectionFriend::MessageMapGetItem(PyObject* _self,
                                                 PyObject* key) {
  MessageMapContainer* self = GetMessageMap(_self);

  MapKey map_key;

  if (!PythonToMapKey(self, key, &map_key)) {
    return nullptr;
  }

  // Mutable path: insert-or-lookup and return mutable submessage wrapper.
  if (Message* message = self->GetMutableMessage(); message != nullptr) {
    const Reflection* reflection = message->GetReflection();
    MapValueRef value;
    if (reflection->InsertOrLookupMapValue(
            message, self->parent_field_descriptor, map_key, &value)) {
      self->version++;
    }
    return GetCMessage(self, value.MutableMessageValue(), MESSAGE_MUTABLE);
  }

  // Frozen path: read-only lookup without mutation.
  PyErr_Clear();
  const Message* message = self->GetReadOnlyMessage();
  const Reflection* reflection = message->GetReflection();
  MapValueConstRef value;
  if (!reflection->LookupMapValue(*message, self->parent_field_descriptor,
                                  map_key, &value)) {
    return SetMessageFrozenError();
  }
  return GetCMessage(self, &value.GetMessageValue(), MESSAGE_FROZEN);
}

int MaybeReleaseOneofBeforeMerge(CMessage* self, const Message& other) {
  CMessage::CompositeFieldsMap* composite_fields =
      self->composite_fields.TryGet();
  if (!composite_fields) {
    return 0;
  }

  Message* message = AssureWritable(self);
  if (message == nullptr) return -1;
  const Reflection* reflection = message->GetReflection();
  PyMessageFactory* factory = GetFactoryForMessage(self);
  std::vector<const FieldDescriptor*> fields_to_release;
  std::vector<std::pair<const FieldDescriptor*, ScopedPyObjectPtr>>
      nested_message_fields;
  composite_fields->ForEach([&](const void* key, PyObject* value) {
    const FieldDescriptor* descriptor =
        reinterpret_cast<const FieldDescriptor*>(key);
    if (descriptor->cpp_type() == FieldDescriptor::CPPTYPE_MESSAGE &&
        // For normal repeated message, MergeFrom will append the messages.
        // For message map with same keys, it is overwrite
        !descriptor->is_repeated() &&
        reflection->HasField(*message, descriptor)) {
      if (reflection->HasField(other, descriptor)) {
        Py_INCREF(value);
        nested_message_fields.emplace_back(descriptor, value);
      } else {
        // Release oneof message if the other message has set a different oneof
        const OneofDescriptor* oneof = descriptor->containing_oneof();
        if (oneof && reflection->HasOneof(other, oneof)) {
          fields_to_release.push_back(descriptor);
        }
      }
    }
  });

  for (const auto& [field, value] : nested_message_fields) {
    if (MaybeReleaseOneofBeforeMerge(
            reinterpret_cast<CMessage*>(value.get()),
            reflection->GetMessage(other, field, factory->message_factory)) <
        0) {
      return -1;
    }
  }

  for (const FieldDescriptor* field : fields_to_release) {
    if (InternalReleaseFieldByDescriptor(self, field) < 0) {
      return -1;
    }
  }
  return 0;
}
// After a Merge, visit every sub-message that was read-only, and
// eventually update their pointer if the Merge operation modified them.
void FixupMessageAfterMerge(CMessage* self) {
  CMessage::CompositeFieldsMap* composite_fields =
      self->composite_fields.TryGet();
  if (!composite_fields) {
    return;
  }
  PyMessageFactory* factory = GetFactoryForMessage(self);
  composite_fields->ForEach([&](const void* key, PyObject* value) {
    const FieldDescriptor* descriptor =
        reinterpret_cast<const FieldDescriptor*>(key);
    if (descriptor->cpp_type() == FieldDescriptor::CPPTYPE_MESSAGE &&
        !descriptor->is_repeated()) {
      CMessage* cmsg = reinterpret_cast<CMessage*>(value);
      if (cmsg->state != MESSAGE_UNPROMOTED) {
        return;
      }
      Message* message = AssureWritable(self);
      if (message == nullptr) return;
      const Reflection* reflection = message->GetReflection();
      if (reflection->HasField(*message, descriptor)) {
        // Message used to be a default instance, but is no longer. Get the new
        // pointer and record it.
        Message* mutable_message = reflection->MutableMessage(
            message, descriptor, factory->message_factory);
        cmsg->message = mutable_message;
        cmsg->state = MESSAGE_MUTABLE;
        FixupMessageAfterMerge(cmsg);
      }
    }
  });
}
