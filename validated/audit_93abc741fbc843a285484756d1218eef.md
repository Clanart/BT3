## Finding: Slashing precompile does not reject `msg.value`, permanently locking ETH sent via low‑level `CALL`

### Summary
The `slashing` precompile's `Execute` function never checks `contract.Value()` before dispatching to a query/transaction handler, unlike the `erc20` precompile which explicitly guards against this. An attacker contract can perform a low-level `call{value: X}(...)` to the slashing precompile address (`0x0000...0806`), which — per standard go-ethereum EVM semantics — transfers `X` wei from the caller to the precompile address as part of the `CALL` opcode *before* the precompile logic runs. Because the slashing precompile has no balance-check guard and no withdrawal mechanism, and address `0x806` is not an EOA (no private key) nor a contract with any code path to move funds out, the value becomes permanently unrecoverable.

### Finding Description
`Precompile.Execute` in [1](#0-0)  dispatches directly to `GetSigningInfo`, `GetSigningInfos`, `GetParams`, or `Unjail` based on the ABI method selector, without ever inspecting `contract.Value()`.

Contrast this with the `erc20` precompile, which explicitly performs this check as a documented "safety measure": [2](#0-1) 

The comment there makes the framework-level gap explicit: *"ERC20 precompiles cannot receive funds because they are not managed by an EOA and will not be possible to recover funds sent to an instance of them... This check is a safety measure because currently funds cannot be received due to the lack of a fallback handler."* This confirms that nothing at the shared `RunNativeAction`/`SetupABI` layer [3](#0-2)  performs this rejection generically — each precompile is individually responsible for guarding against value transfers, and the slashing precompile does not do so.

The EVM's `CALL` opcode moves `value` from caller to callee balance unconditionally before invoking the callee's code (precompile or otherwise) — this is standard go-ethereum behavior and is exactly what the ERC20 comment above describes needing to guard against. Since the slashing precompile omits this guard, any `getSigningInfo`, `getSigningInfos`, `getParams`, or even `unjail` call made with `value > 0` will succeed, silently absorbing the transferred value into the precompile's on-chain balance with no method to retrieve it.

### Impact Explanation
This meets the "Critical permanent freezing ... of user funds" bar: any unprivileged EOA or contract that sends native value alongside a call to the slashing precompile address permanently loses that value — it is not refunded, not credited anywhere retrievable, and there is no governance/keeper method shown in this precompile to sweep or return balances held at `0x806`. This can be triggered by a simple low-level `.call{value: x}(...)` from any contract, entirely bypassing Solidity's own `view`/non-payable compile-time protection (which only applies to high-level typed calls through the interface, not raw low-level calls).

### Likelihood Explanation
High likelihood: no privileged access is required. Any user or contract can call the fixed, well-known precompile address `0x0000000000000000000000000000000000000806` with attached value using a raw `call`, exactly as illustrated by the referenced Solidity ABI/interface [4](#0-3) . It requires no special preconditions — accidental misuse (e.g., a wallet mis-encoding a payable call) or deliberate griefing/attack against a victim contract that forwards `msg.value` are both realistic vectors.

### Recommendation
Add the same guard used in `precompiles/erc20/erc20.go` to `precompiles/slashing/slashing.go`'s `Execute` (and audit other non-ERC20/werc20 precompiles for the same omission): reject any call where `contract.Value().Sign() == 1` with an explicit revert, e.g.:
```go
if value := contract.Value(); value.Sign() == 1 {
    return nil, fmt.Errorf(cmn.ErrCannotReceiveFunds, contract.Value().String())
}
```
placed at the top of `Execute` before `cmn.SetupABI` is called.

### Proof of Concept
A minimal attacking contract:
```solidity
contract SlashingValueGriefer {
    function attack(address consAddr) external payable {
        (bool ok, ) = address(0x0000000000000000000000000000000000000806).call{value: msg.value}(
            abi.encodeWithSignature("getSigningInfo(address)", consAddr)
        );
        require(ok, "call failed");
        // msg.value is now stuck at 0x...0806 permanently
    }
}
```
An integration test analogous to the existing `TestGetSigningInfo` suite [5](#0-4)  could deploy this contract, call `attack{value: 1 ether}(consAddr)`, and assert:
1. The call succeeds (`ok == true`), returning valid signing info.
2. The caller contract's balance decreased by 1 ether.
3. The `0x806` precompile address's balance increased by 1 ether with no way to reduce it.

**Note:** I could not directly inspect the core `x/vm` EVM `Call`/`RunPrecompiledContract` dispatch code in this index to show the exact line performing the value transfer before invoking precompile `Run`; this is inferred from standard go-ethereum `Call` semantics and is strongly corroborated by the `erc20` precompile's own explicit guard and comment describing exactly this risk. If deeper confirmation of the exact transfer-before-dispatch code path is needed, a full Devin session with repository access would allow tracing `x/vm/keeper` and `core/vm` integration directly.

	}

	return bz, err
}

func (p Precompile) RunNativeAction(evm *vm.EVM, contract *vm.Contract, action NativeAction) ([]byte, error) {
	bz, err := p.runNativeAction(evm, contract, action)
	if err != nil {
		return ReturnRevertError(evm, err)
	}

	return bz, nil

func (p Precompile) runNativeAction(evm *vm.EVM, contract *vm.Contract, action NativeAction) (bz []byte, err error) {
	stateDB, ok := evm.StateDB.(*statedb.StateDB)
	if !ok {
		return nil, errors.New(ErrNotRunInEvm)
	}

	// get the stateDB cache ctx
	ctx, err := stateDB.GetCacheContext()
	if err != nil {
		return nil, err
	}

	// take a snapshot of the current state before any changes
	// to be able to revert the changes
	snapshot := stateDB.MultiStoreSnapshot()
	events := ctx.EventManager().Events()

	// add precompileCall entry on the stateDB journal
	// this allows to revert the changes within an evm tx
	if err := stateDB.AddPrecompileFn(snapshot, events); err != nil {
		return nil, err
	}

	// commit the current changes in the cache ctx
	// to get the updated state for the precompile call
	if err := stateDB.CommitWithCacheCtx(); err != nil {
		return nil, err
	}

	initialGas := ctx.GasMeter().GasConsumed()

	defer HandleGasError(ctx, contract, initialGas, &err)()

	// set the default SDK gas configuration to track gas usage
	// we are changing the gas meter type, so it panics gracefully when out of gas
	ctx = ctx.WithGasMeter(storetypes.NewGasMeter(contract.Gas)).
		WithKVGasConfig(p.KvGasConfig).
		WithTransientKVGasConfig(p.TransientKVGasConfig)

	// we need to consume the gas that was already used by the EVM
	ctx.GasMeter().ConsumeGas(initialGas, "creating a new gas meter")

	var balanceHandler *BalanceHandler
	if p.BalanceHandlerFactory != nil {
		balanceHandler = p.BalanceHandlerFactory.NewBalanceHandler()
	}

	if balanceHandler != nil {
		balanceHandler.BeforeBalanceChange(ctx)
	}

	bz, err = action(ctx)
	if err != nil {
		return bz, err
	}

	cost := ctx.GasMeter().GasConsumed() - initialGas

	if !contract.UseGas(cost, nil, tracing.GasChangeCallPrecompiledContract) {
		return nil, vm.ErrOutOfGas
	}

	if balanceHandler != nil {
		if err := balanceHandler.AfterBalanceChange(ctx, stateDB); err != nil {
			return nil, err
		}
	}

	return bz, nil
}

func (s *PrecompileTestSuite) TestGetSigningInfo() {
	method := s.precompile.Methods[slashing.GetSigningInfoMethod]

	valSigners := s.network.GetValidators()
	val0ConsAddr, _ := valSigners[0].GetConsAddr()

	consAddr := types.ConsAddress(val0ConsAddr)
	testCases := []struct {
		name        string
		malleate    func() []interface{}
		postCheck   func(signingInfo *slashing.SigningInfo)
		gas         uint64
		expError    bool
		errContains string
	}{
		{
			"fail - empty input args",
			func() []interface{} {
				return []interface{}{}
			},
			func(_ *slashing.SigningInfo) {},
			200000,
			true,
			fmt.Sprintf(cmn.ErrInvalidNumberOfArgs, 1, 0),
		},
		{
			"fail - invalid consensus address",
			func() []interface{} {
				return []interface{}{
					common.Address{},
				}
			},
			func(_ *slashing.SigningInfo) {},
			200000,
			true,
			"invalid consensus address",
		},
		{
			"success - get signing info for validator",
			func() []interface{} {
				err := s.network.App.GetSlashingKeeper().SetValidatorSigningInfo(
					s.network.GetContext(),
					consAddr,
					slashingtypes.ValidatorSigningInfo{
						Address:             consAddr.String(),
						StartHeight:         1,
						IndexOffset:         2,
						MissedBlocksCounter: 1,
						Tombstoned:          false,
					},
				)
				s.Require().NoError(err)
				return []interface{}{
					common.BytesToAddress(consAddr.Bytes()),
				}
			},
			func(signingInfo *slashing.SigningInfo) {
				s.Require().Equal(consAddr.Bytes(), signingInfo.ValidatorAddress.Bytes())
				s.Require().Equal(int64(1), signingInfo.StartHeight)
				s.Require().Equal(int64(2), signingInfo.IndexOffset)
				s.Require().Equal(int64(1), signingInfo.MissedBlocksCounter)
				s.Require().False(signingInfo.Tombstoned)
			},
			200000,
			false,
			"",
		},
	}

	for _, tc := range testCases {
		s.Run(tc.name, func() {
			s.SetupTest()

			contract, ctx := testutil.NewPrecompileContract(s.T(), s.network.GetContext(), s.keyring.GetAddr(0), s.precompile.Address(), tc.gas)

			bz, err := s.precompile.GetSigningInfo(ctx, &method, contract, tc.malleate())

			if tc.expError {
				s.Require().Error(err)
				s.Require().Contains(err.Error(), tc.errContains)

				s.Require().NoError(err)
				var out slashing.SigningInfoOutput
				err = s.precompile.UnpackIntoInterface(&out, slashing.GetSigningInfoMethod, bz)
				s.Require().NoError(err)
				tc.postCheck(&out.SigningInfo)
			}
		})
	}
}
