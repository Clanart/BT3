### Title
Gasless swap admission checks are stale-state (before-only) and lack post-execution repayment verification, allowing an unprivileged sender to drain proposer-lent KAIA via a non-conforming or manipulable ERC20 token - ([File: kaiax/gasless/impl/tx_pool.go], [File: kaiax/gasless/impl/getter.go])

### Summary
Kaia's `kaiax/gasless` module implements a flash-loan-like pattern (KIP-247): the block proposer lends the swap sender real KAIA up front via a generated `LendTx` (`GetLendTxGenerator`), expecting the sender's subsequent `GaslessSwapTx` (a call to `GaslessSwapRouter.swapForGas`) to swap an arbitrary allowed ERC20 token and repay the loan plus commission. All the correctness guarantees enforced by the Kaia client are computed from a `balanceOf`/`allowance`/`GetAmountIn` snapshot taken **before** the swap is admitted to a block (`checkBalanceForSwap` in `kaiax/gasless/impl/tx_pool.go`), and the bundle mechanism (`GetLendTxGenerator` + `[LendTx, ApproveTx, SwapTx]` in `kaiax/gasless/impl/builder.go`) has no client-side, post-swap check that the proposer was actually repaid `amountRepay`. This mirrors exactly the audited flash-loan bug class: checks are performed only "before" the value-moving operation, with no "after" balance/repayment assertion, and the correctness of the swap execution is fully delegated to an external, arbitrary ERC20 token's `transferFrom`/`transfer` semantics.

### Finding Description
For a `GaslessSwapTx` to be admitted into a block-building bundle, the tx pool performs the following stale, before-only checks in `checkBalanceForSwap`: [1](#0-0) [2](#0-1) 

These checks (`amountIn >= gsr.getAmountIn(minAmountOut)`, `allowance(sender, router) >= amountIn`, `balanceOf(sender) >= amountIn`) are evaluated against a `nil` (latest-state) call context at admission time, and are also individually feature-flagged off by `GaslessConfig.ShouldCheckSwapAmount()` / `ShouldCheckToken()` [3](#0-2) . Meanwhile, the sender's native KAIA balance check is explicitly **omitted** for gasless transactions, as documented: [4](#0-3) 

The block-building path constructs a bundle `[LendTxGenerator, GaslessApproveTx, GaslessSwapTx]`, where `LendTxGenerator` unconditionally transfers real KAIA from the proposer to the sender computed as `lendAmount = ApproveTx.Fee() + SwapTx.Fee()`: [5](#0-4) [6](#0-5) 

The only client-side guarantee that the proposer is repaid is the pre-declared value `swapArgs.AmountRepay`, verified only for **numeric consistency** with the expected formula (`SP4` in `VerifyExecutable`) — never against the actual amount the router contract transfers back to `block.coinbase`/proposer after execution: [7](#0-6) [8](#0-7) 

Because `allowedTokens` can include **any ERC20 contract** approved through governance/registry updates (`updateAddresses` reads the `MultiCall` contract's gasless info with no additional token-standard validation) [9](#0-8) , and because the actual value transfer inside `swapForGas` is delegated entirely to the token's `transfer`/`transferFrom` implementation (the router's Solidity source is not present in the indexed repo — only compiled bytecode bindings in `contracts/bindings/kip247/GaslessSwapRouter.go` were available, so its internal before/after balance accounting could not be directly verified), a token that:
- returns `true` without actually moving the declared amount (non-compliant/mock-like token), or
- applies a transfer fee / rebases balances (fee-on-transfer token), or
- allows the sender to front-run/manipulate the AMM pool price between the tx-pool admission check and actual execution within the same block (no re-check occurs at execution time, only at admission)

could cause the `swapForGas` call to succeed with less value delivered to the router/proposer than the `LendTx` amount already paid out, without the Kaia client ever re-verifying that the proposer was made whole. This is the exact "no before/after balance assertion" root cause described in the external report, applied to the `LendTx → SwapTx` repayment flow instead of a pool's flash-loan flow.

### Impact Explanation
This is reachable by any unprivileged transaction sender: constructing and submitting a valid-looking `GaslessApproveTx` + `GaslessSwapTx` pair referencing an allowed-but-non-conforming ERC20 token (or exploiting AMM price movement within the swap) can cause the block proposer to unconditionally pay out real KAIA via `LendTx` without receiving full repayment, directly draining proposer funds — a concrete unauthorized value movement enabled by admission-time-only ("before") checks with no execution-time ("after") balance/repayment assertion, matching the Medium-severity flash-loan bug class in the external report.

### Likelihood Explanation
Likelihood is bounded by governance's control over the `allowedTokens` list — an attacker would need either (a) a maliciously/non-standard listed token to become allowed, or (b) to exploit legitimate AMM price slippage/manipulation within the single swap execution that the pre-check (computed moments earlier from stale state) failed to anticipate, since `checkBalanceForSwap`'s `GetAmountIn` snapshot and the actual execution price are not guaranteed identical. Given `ShouldCheckToken`/`ShouldCheckSwapAmount` are configurable and can be disabled, and given the full router contract logic performing the actual balance movement is not verifiable from the code available in this repository, the likelihood cannot be fully confirmed without access to the `GaslessSwapRouter` Solidity source, but the client-side architecture provides no independent safety net regardless of the router's internal behavior.

### Recommendation
Add a client-side execution-time invariant check (e.g., in state transition processing of `GaslessSwapTx`, or as part of `IsExecutable`/bundle validation before block finalization) asserting that the proposer's (lender's) KAIA balance after the `SwapTx` is at least the pre-`LendTx` balance plus intended commission, reverting or excluding the bundle otherwise. Additionally, restrict `allowedTokens` registration to tokens verified to be standard-compliant (no fee-on-transfer/rebasing), and re-validate `amountIn`/`minAmountOut` against current state immediately before block inclusion rather than solely at tx-pool admission time.

### Proof of Concept
1. Governance/registry lists a non-standard ERC20 token (or an attacker-influenced pool experiencing price movement) as an allowed gasless swap token via `updateAddresses`/`MultiCallGaslessInfo` [9](#0-8) .
2. Attacker submits `GaslessApproveTx` + `GaslessSwapTx` with `amountRepay` computed to satisfy `SP4` numerically [8](#0-7) , passing the stale-state `checkBalanceForSwap` admission checks [10](#0-9) .
3. The block builder prepends `LendTxGenerator`, transferring real KAIA from the proposer to the attacker before the swap executes [11](#0-10) .
4. `SwapForGas` executes against the non-conforming token/manipulated pool such that less value (or none) is actually returned to the proposer, while no client-side code re-checks the proposer's post-swap balance.
5. Proposer's `LendTx` payout is not fully recovered, resulting in a net loss per exploited swap — repeatable across blocks where the attacker is again selected/admitted.

func (g *GaslessModule) checkBalanceForSwap(swapArgs *SwapArgs, swapNonce uint64) error {
	token := swapArgs.Token
	bc := backends.NewBlockchainContractBackend(g.Chain, nil, nil)

	g.gaslessInfoMu.RLock()
	swapRouter := g.swapRouter
	g.gaslessInfoMu.RUnlock()

	// tx.minAmountOut >= tx.amountRepay
	minAmountOut := swapArgs.MinAmountOut
	amountRepay := swapArgs.AmountRepay
	if minAmountOut.Cmp(amountRepay) < 0 {
		return fmt.Errorf("insufficient minAmountOut: minAmountOut=%s, amountRepay=%s", minAmountOut.String(), amountRepay.String())
	}

	if g.GaslessConfig.ShouldCheckSenderCode() {
		if g.getCurrentHasCode(swapArgs.Sender) {
			return errors.New("sender with code is not allowed")
		}
	}

	if g.GaslessConfig.ShouldCheckSwapAmount() {
		// tx.amountIn >= gsr.getAmountIn(minAmountOut)
		routerContract, err := kip247.NewGaslessSwapRouterCaller(swapRouter, bc)
		if err != nil {
			return err
		}
		// Required token amountIn, given the current exchange rate and the declared minAmountOut.
		requiredAmountIn, err := routerContract.GetAmountIn(nil, token, minAmountOut)
		if err != nil {
			return err
		}
		if swapArgs.AmountIn.Cmp(requiredAmountIn) < 0 {
			return fmt.Errorf("insufficient amountIn: have=%s, want=%s", swapArgs.AmountIn.String(), requiredAmountIn.String())
		}
	}

	if g.GaslessConfig.ShouldCheckToken() {

		tokenContract, err := sc_erc20.NewERC20(token, bc)
		if err != nil {
			return err
		}

		// If SwapTx.nonce is the sender's next nonce, then there is no room for ApproveTx proceeding SwapTx.
		senderNonce := g.getCurrentStateNonce(swapArgs.Sender)
		noApproveTxPreceeds := swapNonce == senderNonce
		if noApproveTxPreceeds {
			// tx.token.allowance(sender, router) >= tx.amountIn
			approval, err := tokenContract.Allowance(nil, swapArgs.Sender, swapRouter)
			if err != nil {
				return err
			}
			if approval.Cmp(swapArgs.AmountIn) < 0 {
				return fmt.Errorf("insufficient approval: approval=%s, want=%s", approval.String(), swapArgs.AmountIn.String())
			}
		}

		// tx.token.balanceOf(sender) >= tx.amountIn
		balance, err := tokenContract.BalanceOf(nil, swapArgs.Sender)
		if err != nil {
			return err
		}
		if balance.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("insufficient balance: balance=%s, want=%s", balance.String(), swapArgs.AmountIn.String())
		}
	}

	// tx.deadline >= currentTimestamp
	deadline := swapArgs.Deadline
	if deadline.Cmp(g.Chain.CurrentBlock().Time()) < 0 {
		return fmt.Errorf("insufficient deadline: deadline=%s, want=%s", deadline.String(), g.Chain.CurrentBlock().Time().String())
	}

	return nil
}

// MakeLendTx creates a transaction with following properties:
// L1. LendTx.type = 0x7802 (TxTypeEthereumDynamicFee)
// L2. LendTx.from = proposer
// L3. LendTx.to = SwapTx.from
// L4. LendTx.value = LendAmount(approveTxOrNil, swapTx)
func (g *GaslessModule) GetLendTxGenerator(approveTxOrNil, swapTx *types.Transaction) *builder.TxOrGen {
	var src []byte
	if approveTxOrNil != nil {
		src = append(src, approveTxOrNil.Hash().Bytes()...)
	}
	src = append(src, swapTx.Hash().Bytes()...)
	bundleHash := crypto.Keccak256Hash(src)

	gen := func(nonce uint64) (*types.Transaction, error) {
		var (
			chainId = g.InitOpts.ChainConfig.ChainID
			signer  = types.LatestSignerForChainID(chainId)
			key     = g.InitOpts.NodeKey
		)

		to, err := types.Sender(signer, swapTx)
		if err != nil {
			return nil, err
		}

		tx, err := types.NewTransactionWithMap(types.TxTypeEthereumDynamicFee, map[types.TxValueKeyType]interface{}{
			types.TxValueKeyNonce:      nonce,
			types.TxValueKeyTo:         &to,
			types.TxValueKeyAmount:     lendAmount(approveTxOrNil, swapTx),
			types.TxValueKeyData:       common.Hex2Bytes("0x"),
			types.TxValueKeyGasLimit:   params.TxGas,
			types.TxValueKeyGasFeeCap:  swapTx.GasFeeCap(),
			types.TxValueKeyGasTipCap:  swapTx.GasTipCap(),
			types.TxValueKeyAccessList: types.AccessList{},
			types.TxValueKeyChainID:    chainId,
		})
		if err != nil {
			return nil, err
		}

		err = tx.Sign(signer, key)
		return tx, err
	}

	return builder.NewTxOrGenFromGen(gen, bundleHash)
}

func (g *GaslessModule) updateAddresses(header *types.Header) error {
	g.gaslessInfoMu.Lock()
	defer g.gaslessInfoMu.Unlock()

	swapRouter, tokens, err := getGaslessInfo(g.Chain, header)
	// proceed even if there is something wrong with multicall contract
	if err != nil {
		g.swapRouter = common.Address{}
		g.allowedTokens = map[common.Address]bool{}
		logger.Warn("there is something wrong with multicall contract", "err", err.Error())
		return nil
	}

	g.swapRouter = swapRouter

	g.allowedTokens = map[common.Address]bool{}
	for _, addr := range tokens {
		// all tokens are allowed if nil
		if g.GaslessConfig.AllowedTokens == nil {
			g.allowedTokens[addr] = true
		}
		for _, allowed := range g.GaslessConfig.AllowedTokens {
			if addr == allowed {
				g.allowedTokens[addr] = true
			}
		}
	}

	return nil
}

func lendAmount(approveTxOrNil, swapTx *types.Transaction) *big.Int {
	r := new(big.Int)

	// R2 = ApproveTx.Fee() if exists
	if approveTxOrNil != nil {
		r.Add(r, approveTxOrNil.Fee())
	}

	// R3 = SwapTx.Fee()
	r.Add(r, swapTx.Fee())

	// LendAmount = R2 + R3
	return r
}

func repayAmount(approveTxOrNil, swapTx *types.Transaction) *big.Int {
	// R1 = LendTx.Fee() = SwapTx.GasPrice() * TxGas
	r1 := new(big.Int).Mul(swapTx.GasPrice(), new(big.Int).SetUint64(params.TxGas))

	// RepayAmount = R1 + R2 + R3
	return new(big.Int).Add(r1, lendAmount(approveTxOrNil, swapTx))
}
