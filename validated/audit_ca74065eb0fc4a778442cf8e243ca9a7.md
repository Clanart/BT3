**Reasoning:** `setMostRecentSSHKeyPassphrase` in [1](#0-0)  does not perform any host matching at all — there is no host/URL comparison, substring check, or scheme/port validation in this function. It simply computes a SHA-256 hash of the local SSH private key file (`getHashForSSHKey`, using `getFileHash`) and stores that hash as the lookup key in an in-memory map alongside the trampoline `operationGUID`, via `setMostRecentSSHCredential` [2](#0-1) .

The `keyPath` passed into this function comes from parsing the literal `ssh` client's own askpass prompt text (`Enter passphrase for key '<path>': `) in `handleSSHKeyPassphrase` [3](#0-2) , which is invoked by the local `ssh` binary that git spawns — not something an attacker-controlled remote host, redirect, or proxy response can directly supply. The actual decision of *which* private key file to use for a given remote host is made by the OS/`ssh` client itself (via `ssh_config`, `known_hosts`, agent, etc.), a mechanism external to this code path; Desktop's role here is only to cache/retrieve a passphrase for a specific local key file (identified by content hash), so there is no "authorized host" string being compared loosely, substring-matched, or missing a port/scheme check as the question presumes.

Because there is no host-based authorization check in this function to bypass, the premise of the question does not hold against the actual implementation, and this does not constitute a valid credential-exfiltration vulnerability per the stated invariant.

```typescript
async function handleSSHKeyPassphrase(
  operationGUID: string,
  prompt: string
): Promise<string | undefined> {
  const promptRegex = /^Enter passphrase for key '(.+)': $/

  const matches = promptRegex.exec(prompt)
  if (matches === null || matches.length < 2) {
    return undefined
  }

  let keyPath = matches[1]

  // The ssh bundled with Desktop on Windows, for some reason, provides Unix-like
  // paths for the keys (e.g. /c/Users/.../id_rsa). We need to convert them to
  // Windows-like paths (e.g. C:\Users\...\id_rsa).
  if (__WIN32__ && /^\/\w\//.test(keyPath)) {
    const driveLetter = keyPath[1]
    keyPath = keyPath.slice(2)
    keyPath = `${driveLetter}:${keyPath}`
  }

  const storedPassphrase = await getSSHKeyPassphrase(keyPath)
  if (storedPassphrase !== null) {
    // Keep this stored passphrase around in case it's not valid and we need to
    // delete it if the git operation fails to authenticate.
    await setMostRecentSSHKeyPassphrase(operationGUID, keyPath)
    return storedPassphrase
  }
```
