## Analysis Summary

Reducing the Llama finding to its core invariant: **a "not yet acted upon" precondition was checked against a stale window instead of the live/current state, letting an action fire after the precondition it depends on had already become false.** In Hyperbridge, the exact analog exists in the EVM `GetRequest` timeout path: the "no response yet" precondition is proven via a **non-membership proof against an arbitrary, caller-chosen historical `StateCommitment` height** rather than against the host's own live `responseReceipts` mapping — and nothing in `dispatchTimeOut` re-checks the live receipt either.

### Title
Permissionless double-settlement of `GetRequest`: stale non-membership proof lets `handleGetRequestTimeouts` fire `onGetTimeout` after `onGetResponse` already executed - (File: `evm/src/core/HandlerV2.sol`)

### Summary

### Finding Description
`handleGetRequestTimeouts` verifies that a `GetResponse` was never received by checking a non-membership proof of the `RESPONSE_RECEIPTS_STORAGE_PREFIX` key against `state.stateRoot`, where `state = host.stateMachineCommitment(message.height)` [1](#0-0) . `message.height` is fully caller-controlled and any historical height whose commitment has been stored and whose challenge period has elapsed qualifies — `EvmHost.storeStateMachineCommitment` never prunes or invalidates older per-height commitments [2](#0-1) , and `stateMachineCommitment(height)` is a plain lookup with no recency requirement.

Meanwhile, `dispatchIncoming(GetResponse ...)` (called from `handleGetResponses`) delivers the response, sets `_responseReceipts[commitment]`, pays the relayer fee, and invokes `onGetResponse` on the app — but it never deletes `_requestCommitments[commitment]` [3](#0-2) . Later, `dispatchTimeOut(GetRequestTimeout ...)` only deletes `_requestCommitments[commitment]` and calls `onGetTimeout` — it never consults the current `_responseReceipts[commitment]` value at all [4](#0-3) .

Because the sole "response not yet received" guard is a proof against a stale, attacker-chosen height rather than the host's live receipt state, a request that has already been fully responded to (and whose app-side effects from `onGetResponse` have already executed) can still be timed out: any permissionless caller submits `handleGetRequestTimeouts` referencing an older height H (from before the response arrived, still stored and past its challenge period) together with a valid non-membership proof for that height. All checks pass — `meta.sender != address(0)` (request commitment still exists), `request.timeout() > state.timestamp` is satisfiable for old H, and the non-membership proof is genuinely valid for that stale height — and `onGetTimeout` fires for a request the app already fulfilled via `onGetResponse`.

This is the precise structural analog of the Llama bug: a guard meant to gate an action only while a certain condition holds ("not yet responded"/"not yet executed") is checked against an outdated snapshot instead of current truth, letting the guarded action execute in a window where it should be blocked.

The corrupted/misused value is `state.stateRoot` at attacker-chosen `message.height` in `handleGetRequestTimeouts` — it is treated as authoritative "current" knowledge of whether a response exists, when it is only a snapshot from before the response was delivered.

### Impact Explanation
Any `IApp` module receiving `GetRequest`s can be forced to process both `onGetResponse` and `onGetTimeout` for the same request/commitment. Depending on app logic (e.g., escrow release, fee refund, intent settlement, paymaster crediting keyed off `GetRequest` outcomes) this yields double-settlement: the app applies its "success" state transition once from the response, and then a second, contradictory "failure/refund" state transition from the belated timeout — a direct double-claim/double-settlement and potential fund-loss/logic-corruption path, matching the bounty's explicit "replay/double-claim/double-settlement" and "false proof/state acceptance" categories. No colluding relayer, prover, or admin is required — the caller of `handleGetRequestTimeouts` is explicitly permissionless.

### Likelihood Explanation
High. Historical `StateCommitment`s per height are retained indefinitely by `EvmHost` (no pruning), so an attacker only needs to have observed (or itself relayed) any state commitment for the destination chain at a height that predates the response's inclusion, plus wait out that height's challenge period — both trivially satisfiable in normal operation, since consensus updates for a chain are stored incrementally and challenge periods elapse for each height as time passes. No special privileges, front-running, or malicious relayer/prover assumptions are needed; the attacker just calls the permissionless handler with an old, otherwise-legitimate proof after a legitimate response has already landed.

### Recommendation
In `handleGetRequestTimeouts` (and symmetrically `handlePostRequestTimeouts`), require the non-membership proof height to be the *latest known* height for that state machine (`host.latestStateMachineHeight(...)`), or add an explicit live check against `host.responseReceipts(commitment)`/`host.requestReceipts(...)` in `dispatchTimeOut` before deleting the commitment and invoking the app callback, so that a timeout can never be dispatched once a response/receipt already exists in current host storage, regardless of which historical height's proof is presented.

### Proof of Concept
1. App dispatches `GetRequest` on chain A via `EvmHost`; `_requestCommitments[commitment]` is stored with fee metadata.
2. Chain B's state advances; at height `H1` (captured/stored on A via `handleConsensus`), no `GetResponse` for `commitment` exists yet. `H1`'s challenge period elapses, so `stateMachineCommitment(H1)` is queryable and a valid non-membership proof for `RESPONSE_RECEIPTS_STORAGE_PREFIX||commitment` can be built against it.
3. A relayer legitimately calls `handleGetResponses` with a state proof at a later height `H2 > H1` where the queried key exists, per [5](#0-4) . This triggers `EvmHost.dispatchIncoming(GetResponse, relayer)`: `_responseReceipts[commitment]` is set, the relayer fee is paid, and `onGetResponse` executes on the app, applying its success-path state changes [6](#0-5) . Note `_requestCommitments[commitment]` is left untouched.
4. Any unprivileged actor now calls `handleGetRequestTimeouts` with `message.height = H1` and the previously valid non-membership proof from step 2. Checks pass: `state = host.stateMachineCommitment(H1)` still exists; `meta.sender != address(0)` (request commitment never deleted in step 3); `request.timeout() > state.timestamp` is false for a request whose timeout predates `H1`; the non-membership proof against `H1`'s root is genuinely valid (no response existed at `H1`).
5. `host.dispatchTimeOut(GetRequestTimeout, meta, commitment)` executes: `_requestCommitments[commitment]` is deleted and `onGetTimeout` fires on the same app that already processed `onGetResponse` for this exact `commitment` in step 3 — producing a double-settlement of the same GET request.

    function handleGetResponses(IHost host, GetResponseMessage calldata message) external notFrozen(host) {
        uint256 timestamp = block.timestamp;
        uint256 delay = timestamp - host.stateMachineCommitmentUpdateTime(message.proof.height);
        uint256 challengePeriod = host.challengePeriod();
        if (challengePeriod != 0 && challengePeriod > delay) revert ChallengePeriodNotElapsed();

        uint256 responsesLength = message.responses.length;
        MerkleMountainRange.Leaf[] memory leaves = new MerkleMountainRange.Leaf[](responsesLength);

        for (uint256 i = 0; i < responsesLength; ++i) {
            GetResponseLeaf memory leaf = message.responses[i];
            // don't check for timeouts because it's checked on Hyperbridge

            // known request? also serves as source check
            FeeMetadata memory meta = host.requestCommitments(leaf.response.request.hash());
            if (meta.sender == address(0)) revert UnknownMessage();
            leaves[i] = MerkleMountainRange.Leaf(leaf.index, leaf.response.hash());
        }

        bytes32 root = host.stateMachineCommitment(message.proof.height).overlayRoot;
        if (root == bytes32(0)) revert StateCommitmentNotFound();
        bool valid = MerkleMountainRange.VerifyProof(root, message.proof.multiproof, leaves, message.proof.leafCount);
        if (!valid) revert InvalidProof();

        for (uint256 i = 0; i < responsesLength; ++i) {
            GetResponseLeaf memory leaf = message.responses[i];
            // duplicate response?
            if (host.responseReceipts(leaf.response.request.hash()).relayer != address(0)) revert DuplicateMessage();
            host.dispatchIncoming(leaf.response, _msgSender());
        }
    }

    function handleGetRequestTimeouts(IHost host, GetTimeoutMessage calldata message) external notFrozen(host) {
        uint256 delay = block.timestamp - host.stateMachineCommitmentUpdateTime(message.height);
        uint256 challengePeriod = host.challengePeriod();
        if (challengePeriod != 0 && challengePeriod > delay) revert ChallengePeriodNotElapsed();

        // fetch the state commitment
        StateCommitment memory state = host.stateMachineCommitment(message.height);
        if (state.stateRoot == bytes32(0)) revert StateCommitmentNotFound();
        uint256 timeoutsLength = message.timeouts.length;

        for (uint256 i = 0; i < timeoutsLength; ++i) {
            GetRequest memory request = message.timeouts[i];
            // timed-out?
            if (request.timeout() > state.timestamp) revert MessageNotTimedOut();

            bytes32 commitment = request.hash();
            FeeMetadata memory meta = host.requestCommitments(commitment);
            if (meta.sender == address(0)) revert UnknownMessage();

            bytes[] memory keys = new bytes[](1);
            keys[0] = bytes.concat(RESPONSE_RECEIPTS_STORAGE_PREFIX, commitment);

            // verify state trie non-membership proofs
            PolkadotTrie.StorageValue memory entry = PolkadotTrie.VerifyProof(state.stateRoot, message.proof, keys)[0];
            if (entry.value.length != 0) revert InvalidProof();

            host.dispatchTimeOut(GetRequestTimeout(request, _msgSender()), meta, commitment);
        }

    /**
     * @dev Dispatch an incoming GET response to source module
     * @param response - get response
     */
    function dispatchIncoming(GetResponse memory response, address relayer) external restrict(_hostParams.handler) {
        // replay protection
        bytes32 commitment = response.request.hash();
        _responseReceipts[commitment] = ResponseReceipt({
            relayer: relayer,
            responseCommitment: response.hash()
        });

        (bool success,) = _bytesToAddress(response.request.from)
            .call(abi.encodeWithSelector(IApp.onGetResponse.selector, IncomingGetResponse(response, relayer)));

        if (!success) {
            // so that it can be retried
            delete _responseReceipts[commitment];
            return;
        }

        // reward the relayer fee
        uint256 fee = _requestCommitments[commitment].fee;
        if (fee != 0) {
            IERC20(feeToken()).safeTransfer(relayer, fee);
        }
        emit GetRequestHandled({commitment: commitment, relayer: relayer});
    }
