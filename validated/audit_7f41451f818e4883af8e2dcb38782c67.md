### Title
Unauthenticated OP_RETURN in Payout transactions lets a withdrawer credit any operator (or none) with a fronted payout it never made - (File: `core/src/builder/transaction/operator_reimburse.rs`, `core/src/verifier.rs`)

### Summary
The `Payout` tx's OP_RETURN output (which names the operator who "fronted" the withdrawal) is not covered by the user's `SinglePlusAnyoneCanPay` signature, so anyone who can spend the withdrawal UTXO — including the withdrawer themselves — can attach an arbitrary xonly public key to it. `Verifier::update_finalized_payouts` blindly trusts whichever transaction is first observed on-chain spending the withdrawal outpoint and records its OP_RETURN content as `payout_payer_operator_xonly_pk` with no check that the named operator actually funded anything.

### Finding Description
The claimed binding is:
`withdrawals.payout_payer_operator_xonly_pk` (credited operator for withdrawal `i`) == xonly_pk of the operator who actually paid `out_amount` to the withdrawer for withdrawal `i`.

`create_payout_txhandler` builds the `Payout` tx with a `KeySpend` input over the withdrawal UTXO and appends an OP_RETURN containing `operator_xonly_pk`, but only the input and output-0 are signed by the user (`SpendPath::KeySpend`, sighash `SinglePlusAnyoneCanPay`): [1](#0-0) 

The user's Schnorr signature is produced/verified over a sighash that (per `SinglePlusAnyoneCanPay`) only commits to input 0 and the output at index 0 — the OP_RETURN output (index 2) is unsigned and can be set to any value: [2](#0-1) 

Because the withdrawal UTXO is the withdrawer's own coin (they generated this exact signature themselves to call Citrea's `withdraw`), they can independently construct a payout-shaped transaction reusing this signature, with the same output 0 (paying themselves, since that's what the signature commits to), but an OP_RETURN of their choosing (an arbitrary/unrelated xonly_pk, garbage bytes, or nothing) - and broadcast it before any operator does.

On the verifier/bitcoin-sync side, `update_finalized_payouts` finds any transaction that spends the tracked withdrawal outpoint (`get_payout_txs_for_withdrawal_utxos` simply joins on `bitcoin_syncer_spent_utxos` by txid/vout, with no notion of "who" or "which operator" broadcast it), and extracts whatever OP_RETURN key is present: [3](#0-2) [4](#0-3) 

This value is persisted unconditionally, even if `None`: [5](#0-4) 

Downstream, `get_first_unhandled_payout_by_operator_xonly_pk` only filters by whatever xonly_pk ended up in the column, and `PayoutCheckerTask`/`is_kickoff_malicious` never re-derive or verify that the named operator actually broadcast/funded the payout - they only check that the OP_RETURN key matches the kickoff's operator and that the committed blockhash matches: [6](#0-5) [7](#0-6) [8](#0-7) 

None of the listed guards (`is_deposit_valid`, `SECP.verify_schnorr`, `only_aggregator_and_self`, `SPV::verify`, `lc_proof_verifier`) address this, because `SECP.verify_schnorr` only checks the input-0/output-0 commitment (which the attacker satisfies trivially, since it's their own signature over their own output), and none of the others touch OP_RETURN authenticity.

### Impact Explanation
Two concrete outcomes are reachable, both Critical:
1. If the withdrawer puts a real operator's public xonly_pk in the OP_RETURN, `get_first_unhandled_payout_by_operator_xonly_pk` surfaces this withdrawal to that operator, whose automation (`PayoutCheckerTask`) will call `handle_finalized_payout` and proceed through kickoff/Reimburse to claim the move-to-vault deposit UTXO — reimbursing an operator for a payout it never funded, moving bridge BTC out of the vault UTXO with no genuine fronted withdrawal behind it.
2. If the withdrawer puts garbage/no OP_RETURN, `payout_payer_operator_xonly_pk` is `NULL`; no operator's `get_first_unhandled_payout_by_operator_xonly_pk` will ever return this withdrawal (the UTXO is already spent), permanently denying any operator the ability to be reimbursed for that withdrawal slot.

This is repeatable per withdrawal and requires no special access beyond calling Citrea's `withdraw` and broadcasting one Bitcoin transaction, and it corrupts the operator-attribution binding the reimbursement/BitVM process depends on.

### Likelihood Explanation
Preconditions are minimal: an unprivileged withdrawer only needs to (a) call Citrea's `withdraw` with a UTXO they control and a `SinglePlusAnyoneCanPay` signature (which they generate themselves as part of the normal flow), and (b) win the race to broadcast their own payout-shaped transaction before an operator's. Cost is a single transaction fee; no operator, verifier, or aggregator privileges are needed. Feasibility is high since the withdrawer is guaranteed to be first-mover (they hold the signature before any operator receives/acts on it) and can simply broadcast immediately after calling `withdraw`.

### Recommendation
Bind the OP_RETURN operator commitment to the user's signature (e.g., include it in the sighash by switching to `SIGHASH_ALL`/covering all outputs for the payout tx's input, or by having the user separately co-sign an operator-selection message that verifiers check), so a third party cannot alter which operator/whether an operator is credited without invalidating the signature. Alternatively, require verifiers to independently confirm (e.g., via an operator-signed off-chain attestation, matched against the on-chain payout tx) that the credited operator actually broadcast/funded the specific payout before crediting `payout_payer_operator_xonly_pk`.

pub fn create_payout_txhandler(
    input_utxo: UTXO,
    output_txout: TxOut,
    operator_xonly_pk: XOnlyPublicKey,
    user_sig: taproot::Signature,
    _network: bitcoin::Network,
) -> Result<TxHandler<Signed>, BridgeError> {
    let txin = SpendableTxIn::new_partial(input_utxo.outpoint, input_utxo.txout);

    let output_txout = UnspentTxOut::from_partial(output_txout.clone());

    let op_return_txout = op_return_txout(PushBytesBuf::from(operator_xonly_pk.serialize()));

    let mut txhandler = TxHandlerBuilder::new(TransactionType::Payout)
        .with_version(NON_STANDARD_V3)
        .add_input(
            NormalSignatureKind::NotStored,
            txin,
            SpendPath::KeySpend,
            DEFAULT_SEQUENCE,
        )
        .add_output(output_txout)
        .add_output(UnspentTxOut::from_partial(anchor_output(
            NON_EPHEMERAL_ANCHOR_AMOUNT,
        )))
        .add_output(UnspentTxOut::from_partial(op_return_txout))
        .finalize();
    txhandler.set_p2tr_key_spend_witness(&user_sig, 0)?;
    txhandler.promote()
}

        let results = execute_query_with_tx!(self.connection, tx, query, fetch_all)?;

        results
            .into_iter()
            .map(|(idx, txid)| {
                Ok((
                    u32::try_from(idx).wrap_err("Failed to convert withdrawal index to u32")?,
                    txid.0,
                ))
            })
            .collect()
    }

        if payout_txs_and_payer_operator_xonly_pk.is_empty() {
            return Ok(());
        }
        // Convert all values first, propagating any errors
        let converted_values: Result<Vec<_>, BridgeError> = payout_txs_and_payer_operator_xonly_pk
            .iter()
            .map(|(idx, txid, operator_xonly_pk, block_hash)| {
                Ok((
                    i32::try_from(*idx).wrap_err("Failed to convert payout index to i32")?,
                    TxidDB(*txid),
                    operator_xonly_pk.map(XOnlyPublicKeyDB),
                    BlockHashDB(*block_hash),
                ))
            })
            .collect();
        let converted_values = converted_values?;

        let mut query_builder = QueryBuilder::new(
            "UPDATE withdrawals AS w SET
                payout_txid = c.payout_txid,
                payout_payer_operator_xonly_pk = c.payout_payer_operator_xonly_pk,
                payout_tx_blockhash = c.payout_tx_blockhash
                FROM (",
        );

        query_builder.push_values(
            converted_values.into_iter(),
            |mut b, (idx, txid, operator_xonly_pk, block_hash)| {
                b.push_bind(idx)
                    .push_bind(txid)
                    .push_bind(operator_xonly_pk)
                    .push_bind(block_hash);
            },
        );

        query_builder
            .push(") AS c(idx, payout_txid, payout_payer_operator_xonly_pk, payout_tx_blockhash) WHERE w.idx = c.idx");

        let query = query_builder.build();
        execute_query_with_tx!(self.connection, tx, query, execute)?;

        Ok(())

    /// Checks if the operator who sent the kickoff matches the payout data saved in our db
    /// Payout data in db is updated during citrea sync.
    async fn is_kickoff_malicious(
        &self,
        kickoff_witness: Witness,
        deposit_data: &mut DepositData,
        kickoff_data: KickoffData,
        dbtx: DatabaseTransaction<'_>,
    ) -> Result<bool, BridgeError> {
        let move_txid =
            create_move_to_vault_txhandler(deposit_data, self.config.protocol_paramset())?
                .get_cached_tx()
                .compute_txid();

        let payout_info = self
            .db
            .get_payout_info_from_move_txid(Some(dbtx), move_txid)
            .await?;
        let Some((operator_xonly_pk_opt, payout_blockhash, _, _)) = payout_info else {
            tracing::warn!(
                "No payout info found in db for move txid {move_txid}, assuming malicious"
            );
            return Ok(true);
        };

        let Some(operator_xonly_pk) = operator_xonly_pk_opt else {
            tracing::warn!("No operator xonly pk found in payout tx OP_RETURN, assuming malicious");
            return Ok(true);
        };

        if operator_xonly_pk != kickoff_data.operator_xonly_pk {
            tracing::warn!("Operator xonly pk for the payout does not match with the kickoff_data");
            return Ok(true);
        }

        let wt_derive_path = WinternitzDerivationPath::Kickoff(
            kickoff_data.round_idx,
            kickoff_data.kickoff_idx,
            self.config.protocol_paramset(),
        );
        let commits = extract_winternitz_commits(
            kickoff_witness,
            &[wt_derive_path],
            self.config.protocol_paramset(),
        )?;
        let blockhash_data = commits.first();
        // only last 20 bytes of the blockhash is committed
        let truncated_blockhash = &payout_blockhash[12..];
        if let Some(committed_blockhash) = blockhash_data {
            if committed_blockhash != truncated_blockhash {
                tracing::warn!("Payout blockhash does not match committed hash: committed: {:?}, truncated payout blockhash: {:?}",
                        blockhash_data, truncated_blockhash);
                return Ok(true);
            }
        } else {
            return Err(eyre::eyre!("Couldn't retrieve committed data from witness").into());
        }
        Ok(false)
    }

    async fn update_finalized_payouts(
        &self,
        dbtx: DatabaseTransaction<'_>,
        block_id: u32,
        block_cache: &block_cache::BlockCache,
    ) -> Result<(), BridgeError> {
        let payout_txids = self
            .db
            .get_payout_txs_for_withdrawal_utxos(Some(dbtx), block_id)
            .await?;

        let block = &block_cache.block;

        let block_hash = block.block_hash();

        let mut payout_txs_and_payer_operator_idx = vec![];
        for (idx, payout_txid) in payout_txids {
            let payout_tx_idx = block_cache.txids.get(&payout_txid);
            if payout_tx_idx.is_none() {
                tracing::error!(
                    "Payout tx not found in block cache: {:?} and in block: {:?}",
                    payout_txid,
                    block_id
                );
                tracing::error!("Block cache: {:?}", block_cache);
                return Err(eyre::eyre!("Payout tx not found in block cache").into());
            }
            let payout_tx_idx = payout_tx_idx.expect("Payout tx not found in block cache");
            let payout_tx = &block.txdata[*payout_tx_idx];
            // Find the first output that contains OP_RETURN
            let circuit_payout_tx = CircuitTransaction::from(payout_tx.clone());
            let op_return_output = get_first_op_return_output(&circuit_payout_tx);

                .and_then(|output| parse_op_return_data(&output.script_pubkey))
                .and_then(|bytes| XOnlyPublicKey::from_slice(bytes).ok());

            if operator_xonly_pk.is_none() {
                tracing::info!(
                    "No valid operator xonly pk found in payout tx {:?} OP_RETURN. Either it is an optimistic payout or the operator constructed the payout tx wrong",

                "A new payout tx detected for withdrawal {}, payout txid: {:?}, operator xonly pk: {:?}",
                idx,

                operator_xonly_pk

                idx,
                payout_txid,
