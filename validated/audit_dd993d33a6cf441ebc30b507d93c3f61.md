### Title
Unvalidated serialized `ReceivedOutput` fields permit fake, unspendable balances and threshold-signing requests - ([File: networks/bitcoin/src/wallet/mod.rs](crypto/dkg/../wallet/mod.rs))

### Summary
`ReceivedOutput::read` accepts the attacker-controlled offset, `TxOut`, and outpoint without proving that the output exists on-chain or that its script is derived from the wallet’s threshold key and claimed offset. [1](#0-0)  The resulting object exposes its unverified `output.value` as received funds through `value()`. [2](#0-1) 

### Finding Description
`Scanner::scan_transaction` creates trustworthy records by matching an on-chain output script to a registered offset and binding the record to the transaction ID and output index. [3](#0-2)  `ReceivedOutput::read` bypasses those checks and directly reconstructs all three authority-bearing fields from untrusted bytes. [4](#0-3) 

`SignableTransaction::new` then trusts the supplied `output.value` as spendable input value and the supplied `outpoint` as the transaction input. [5](#0-4)  Signing checks only that the claimed offset derives the forged `TxOut.script_pubkey`; it does not check that the outpoint exists or that the forged `TxOut` equals the actual prevout. [6](#0-5)  The signature hash commits to `Prevouts::All(&self.tx.prevouts)`, so the forged prevout data is directly included in the threshold-signing request. [7](#0-6) 

### Impact Explanation
An unauthenticated party that can submit serialized `ReceivedOutput` records can cause an application to report arbitrary balances or construct a threshold-signing operation for a nonexistent or mismatched Bitcoin input. [4](#0-3)  By choosing the victim multisig’s P2TR script and a matching claimed offset, the forged record passes the only ownership check performed by `SignableTransaction::multisig`. [6](#0-5)  The completed Bitcoin transaction is rejected by consensus because its outpoint or prevout data is false, meaning the wallet reported received funds that were never spendable and may have consumed a threshold-signing attempt for an invalid spend. [8](#0-7) 

### Likelihood Explanation
The attack requires only control over bytes passed to `ReceivedOutput::read`, an explicitly untrusted-input API in scope. [1](#0-0)  The forged script is feasible because the victim’s Taproot script is public and can be paired with offset zero or another known offset. [9](#0-8)  Exploitation depends on the integration treating deserialized records as authoritative instead of requiring them to be regenerated by `Scanner` and confirmed against chain state. [3](#0-2) 

### Recommendation
Do not allow `ReceivedOutput::read` to establish ownership or spendability. [1](#0-0)  Re-derive the expected script from the wallet key and claimed offset, compare it to `output.script_pubkey`, resolve `outpoint` against confirmed chain state, and verify that the returned prevout exactly equals the serialized `TxOut`. [6](#0-5)  Prefer deserializing only an opaque scanner output identifier and reconstructing the `ReceivedOutput` from confirmed blockchain data. [3](#0-2)

use bitcoin_serai::wallet::{p2tr_script_buf, ReceivedOutput, SignableTransaction};

fn forged_received_output(group_key: ProjectivePoint) -> Vec<u8> {
  let txid = bitcoin::Txid::from_raw_hash(bitcoin::hashes::sha256d::Hash::hash(b"fake"));
  let forged = TxOut {
    value: Amount::from_sat(1_000_000),
    script_pubkey: p2tr_script_buf(group_key).unwrap(),
  };

  let mut bytes = Vec::new();
  bytes.extend(Scalar::ZERO.to_bytes());
  bytes.extend(serialize(&forged));
  bytes.extend(serialize(&OutPoint::new(txid, 0)));
  bytes
}

let bytes = forged_received_output(victim_group_key);
let output = ReceivedOutput::read(&mut bytes.as_slice()).unwrap();
assert_eq!(output.value(), 1_000_000);

let signable = SignableTransaction::new(
  vec![output],
  &[(victim_address_script, 100_000)],
  None,
  None,
  10,
).unwrap();

// Passes because the forged script corresponds to `group_key + G * 0`,
// even though the supplied outpoint and prevout are fake.
assert!(signable.multisig(&victim_threshold_keys).is_some());

/// If the key is odd, this will return None.
pub fn p2tr_script_buf(key: ProjectivePoint) -> Option<ScriptBuf> {
  if key.to_encoded_point(true).tag() != Tag::CompressedEvenY {
    return None;
  }

  Some(ScriptBuf::new_p2tr_tweaked(TweakedPublicKey::dangerous_assume_tweaked(x_only(&key))))
}
