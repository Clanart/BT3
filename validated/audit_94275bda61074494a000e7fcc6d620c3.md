### Title
MuSig accepts identity public keys, allowing a publicly computable zero-secret signer - ([File: crypto/dkg/musig/src/lib.rs](crypto/dkg/musig/src/lib.rs))

### Summary
`musig` and `musig_key` do not reject the identity point as a participant public key, even though identity corresponds to the universally known scalar `0`. [1](#0-0)  An attacker can therefore enroll a synthetic participant whose public key is `G * 0` and produce that participant’s signature share without any private key. [2](#0-1) 

### Finding Description
`check_keys` validates only that the key list is non-empty, fits in `u16`, and has no duplicate canonical encodings; it never checks `key.is_identity()`. [1](#0-0)  `musig` then accepts a caller-controlled `keys: &[C::G]`, locates the local public key, and builds `ThresholdKeys` using the submitted points as verification shares. [3](#0-2)  This differs from FROST’s explicit point validation, which rejects identity before accepting encoded points for signing. [4](#0-3) 

### Impact Explanation
If an application admits an identity public key into the signer set, anyone can satisfy that participant’s share because its discrete logarithm is publicly known to be zero. This turns an `n`-of-`n` MuSig set containing identity into a forgery primitive against the stated signer count: the attacker controls both their own key and the identity “participant.” The resulting aggregate key is produced by `musig_key`, which multiplies the identity contribution by a binding factor but still adds the group identity. [5](#0-4) 

### Likelihood Explanation
The API accepts decoded group elements directly, and public keys are normally attacker-controlled enrollment or message inputs. Because the identity is a valid curve point encoding rather than a malformed byte string, input paths that deserialize points without a separate identity check can admit it. The missing validation is in the MuSig helper itself, so every consumer must independently compensate to remain safe. [1](#0-0) 

### Recommendation
Reject identity in `check_keys` before duplicate checking, ideally by treating `key.is_identity()` as `MusigError::InvalidParticipant` or a dedicated error. Apply the same rule in `musig_key`/`musig_key_vartime` through the shared `musig_key_multiexp` path so aggregate-key computation cannot silently include a zero-secret participant. [5](#0-4) 

### Proof of Concept
```rust
use zeroize::Zeroizing;
use rand_core::OsRng;
use ciphersuite::Ciphersuite;
use dkg_musig::{musig, musig_key};

fn forge_with_identity_signer<C: Ciphersuite>(context: [u8; 32], msg: &[u8]) {
  let attacker_secret = Zeroizing::new(C::F::random(&mut OsRng));
  let attacker_pub = C::generator() * attacker_secret.deref();
  let identity = C::G::identity();

  // A two-"participant" signer set where participant 2 has publicly known secret 0.
  let keys = vec![attacker_pub, identity];
  let group_key = musig_key(context, &keys).unwrap();

  // Both machines are locally constructible: identity's secret is zero.
  let attacker_keys = musig(context, attacker_secret, &keys).unwrap();
  let identity_keys =
    musig(context, Zeroizing::new(C::F::ZERO), &keys).unwrap();

  // Run the normal FROST signing machines for both ThresholdKeys over `msg`.
  // The identity participant produces a valid share without private-key material.
}
```
`musig` accepts the zero secret because `C::generator() * 0` equals the submitted identity public key, and the resulting `ThresholdKeys` is constructed normally. [2](#0-1)

fn check_keys<C: Ciphersuite>(keys: &[C::G]) -> Result<u16, MusigError<C>> {
  if keys.is_empty() {
    Err(MusigError::NoKeysProvided)?;
  }

  let keys_len = u16::try_from(keys.len())
    .map_err(|_| MusigError::TooManyKeysProvided { max: u16::MAX, provided: keys.len() })?;

  let mut set = HashSet::with_capacity(keys.len());
  for key in keys {
    let bytes = key.to_bytes().as_ref().to_vec();
    if !set.insert(bytes) {
      Err(MusigError::DuplicatedParticipant(*key))?;
    }
  }

  Ok(keys_len)
}

fn musig_key_multiexp<C: Ciphersuite>(
  context: [u8; 32],
  keys: &[C::G],
) -> Result<Vec<(C::F, C::G)>, MusigError<C>> {
  let keys_len = check_keys::<C>(keys)?;
  let transcript = binding_factor_transcript::<C>(context, keys_len, keys);
  let mut multiexp = Vec::with_capacity(keys.len());
  for i in 1 ..= keys_len {
    multiexp.push((binding_factor::<C>(transcript.clone(), i), keys[usize::from(i - 1)]));
  }
  Ok(multiexp)
}

/// A n-of-n non-interactive DKG which does not guarantee the usability of the resulting key.
pub fn musig<C: Ciphersuite>(
  context: [u8; 32],
  private_key: Zeroizing<C::F>,
  keys: &[C::G],
) -> Result<ThresholdKeys<C>, MusigError<C>> {
  let our_pub_key = C::generator() * private_key.deref();
  let Some(our_i) = keys.iter().position(|key| *key == our_pub_key) else {
    Err(MusigError::DkgError(DkgError::NotParticipating))?
  };

  let keys_len: u16 = check_keys::<C>(keys)?;

  let params = ThresholdParams::new(
    keys_len,
    keys_len,
    // The `+ 1` won't fail as `keys.len() <= u16::MAX`, so any index is `< u16::MAX`
    Participant::new(
      u16::try_from(our_i).expect("keys.len() <= u16::MAX yet index of keys > u16::MAX?") + 1,
    )
    .expect("i + 1 != 0"),
  )
  .map_err(MusigError::DkgError)?;

  let transcript = binding_factor_transcript::<C>(context, keys_len, keys);
  let mut binding_factors = Vec::with_capacity(keys.len());
  let mut multiexp = Vec::with_capacity(keys.len());
  let mut verification_shares = HashMap::with_capacity(keys.len());
  for (i, key) in (1 ..= keys_len).zip(keys.iter().copied()) {
    let binding_factor = binding_factor::<C>(transcript.clone(), i);
    binding_factors.push(binding_factor);
    multiexp.push((binding_factor, key));

    let i = Participant::new(i).expect("non-zero u16 wasn't a valid Participant index?");
    verification_shares.insert(i, key);
  }
  let group_key = multiexp::multiexp(&multiexp);
  debug_assert_eq!(our_pub_key, verification_shares[&params.i()]);
  debug_assert_eq!(musig_key_vartime::<C>(context, keys), Ok(group_key));

  ThresholdKeys::new(
    params,
    Interpolation::Constant(binding_factors),
    private_key,
    verification_shares,
  )
