### Title
Missing contract-existence check in CosmWasm `call_evm` binding can permanently strand native funds sent to a non-existent/typo'd EVM address - (File: `x/evm/keeper/evm.go`)

### Summary
The `call_evm` CosmWasm custom message lets any CosmWasm contract forward native value (usei→wei) and calldata to an arbitrary EVM address via `HandleInternalEVMCall` → `CallEVM`. Like `Anchor#execute()` in the original report, this code path performs a low-level EVM call/value-transfer to a caller-supplied address without verifying that a contract actually exists at that address, so funds intended for contract logic can end up parked at a dead or unassociated address with no way to recover them.

### Finding Description
`HandleInternalEVMCall` takes the raw `to` string from the CW message, converts it to an `common.Address`, and passes it straight into `CallEVM`, which builds an EVM `core.Message` and executes it via `applyEVMMessage` — the only checks performed are on init-code size (when `to == nil`) and a hard-coded block on the Solo precompile address; there is no `GetCode`/`extcodesize`-style check that `to` actually points to a deployed contract: [1](#0-0) [2](#0-1) 

The encoder that builds this message from wasm JSON performs no destination validation either — it just base64-decodes the payload and forwards `to`/`value`/`data` verbatim into `MsgInternalEVMCall`: [3](#0-2) 

Any CosmWasm contract can trigger this via the generic Sei wasm-message encoder: [4](#0-3) 

Because Sei's EVM enforces a dual address model (associated vs. "cast" addresses with limited receiving semantics, per `x/evm/AGENTS.md`), sending value to an EVM address that has no code and no explicit association is functionally equivalent to the Sherlock report's scenario of calling a self-destructed contract or a typo'd EOA: the `call` succeeds (standard EVM semantics — a plain value transfer to a non-contract address never reverts), the sender/pool contract believes the operation succeeded, but no receiving logic executes and the value is credited to an address the CW contract has no further way to interact with or recover it from.

### Impact Explanation
A CosmWasm contract (e.g. a vault/router pattern that forwards user deposits to an EVM-side contract via `call_evm`) can lose user funds permanently if the destination address is mistyped, refers to a contract that self-destructed, or otherwise has no code/receiving logic, exactly mirroring the "loss of funds" impact called out in the original report. Because there is no existence check and no revert path, the transaction reports success even though the intended contract-side effect never happens.

### Likelihood Explanation
Likelihood is moderate: it requires a CW contract author (or an attacker who can influence the `to` argument of a `call_evm` message, e.g., through unsanitized user input in a vault/router contract) to supply a bad address, but the primitive itself is unrestricted — `call_evm` is callable by any wasm contract with no allow-list or destination validation, so the sole precondition is a bad/incorrect `to` value reaching the message, which is a realistic operational/bug-class risk (typos, upgraded/self-destructed target contracts, or malicious relayer-supplied destinations in composed contracts).

### Recommendation
Before executing `CallEVM`, verify contract existence when the call carries native value and/or calldata intended for contract logic — e.g., check `k.GetCode(ctx, *to)` is non-empty (or that `to` is a known/associated address) and reject the call (or require an explicit "send-to-EOA" flag) otherwise, analogous to adding an `extcodesize` check before `Anchor#execute()`'s low-level `call()`.

### Proof of Concept
1. Deploy/simulate a CosmWasm contract that issues the custom Sei wasm message `{"call_evm": {"to": "<address-with-no-code>", "value": "<nonzero>", "data": "<base64>"}}`.
2. This is routed through `CustomEncoder` → `EncodeCallEVM` → `MsgInternalEVMCall` → `HandleInternalEVMCall` → `CallEVM` in `x/evm/keeper/evm.go`.
3. Because `to` has no deployed bytecode, `applyEVMMessage` performs a bare value transfer with no code execution — the transaction succeeds (`res.Err == nil`), the CW contract's `usei` balance is debited and converted to `wei` at `to`, and the calldata intended to trigger receiving-contract logic is silently discarded.
4. If `to` is a self-destructed contract, a typo, or otherwise unassociated/unrecoverable address, the transferred value cannot be retrieved by the sending contract or its users.

func (k *Keeper) HandleInternalEVMCall(ctx sdk.Context, req *types.MsgInternalEVMCall) (*sdk.Result, error) {
	var to *common.Address
	if req.To != "" {
		addr := common.HexToAddress(req.To)
		to = &addr
	}
	senderAddr, err := sdk.AccAddressFromBech32(req.Sender)
	if err != nil {
		return nil, err
	}
	ret, err := k.CallEVM(ctx, k.GetEVMAddressOrDefault(ctx, senderAddr), to, req.Value, req.Data)
	if err != nil {
		return nil, err
	}
	return &sdk.Result{Data: ret}, nil
}

func (k *Keeper) CallEVM(ctx sdk.Context, from common.Address, to *common.Address, val *sdk.Int, data []byte) (retdata []byte, reterr error) {
	if ctx.IsEVM() && !ctx.EVMEntryViaWasmdPrecompile() {
		return nil, errors.New("sei does not support EVM->CW->EVM call pattern")
	}
	if to == nil && len(data) > params.MaxInitCodeSize {
		return nil, fmt.Errorf("%w: code size %v, limit %v", core.ErrMaxInitCodeSizeExceeded, len(data), params.MaxInitCodeSize)
	}
	if to != nil && to.Cmp(common.HexToAddress(solo.SoloAddress)) == 0 {
		return nil, errors.New("cannot call Solo precompile via CosmWasm")
	}
	value := utils.Big0
	if val != nil {
		if val.IsNegative() {
			return nil, sdkerrors.ErrInvalidCoins
		}
		value = val.BigInt()
	}
	// This call was not part of an existing StateTransition, so it should trigger one
	executionCtx := ctx.WithGasMeter(sdk.NewInfiniteGasMeterWithMultiplier(ctx)).WithEVMEntryViaWasmdPrecompile(false)
	stateDB := state.NewDBImpl(executionCtx, k, false)
	gp := k.GetGasPool()
	evmMsg := &core.Message{
		Nonce:     stateDB.GetNonce(from), // replay attack is prevented by the AccountSequence number set on the CW transaction that triggered this call
		GasLimit:  k.getEvmGasLimitFromCtx(ctx),
		GasPrice:  utils.Big0, // fees are already paid on the CW transaction
		GasFeeCap: utils.Big0,
		GasTipCap: utils.Big0,
		To:        to,
		Value:     value,
		Data:      data,
		From:      from,
	}
	// should not increment nonce since this isn't a transaction
	res, err := k.applyEVMMessage(ctx, evmMsg, stateDB, gp, false)
	if err != nil {
		return nil, err
	}
	k.consumeEvmGas(ctx, res.UsedGas)
	if res.Err != nil {
		return nil, res.Err
	}

func EncodeCallEVM(rawMsg json.RawMessage, sender sdk.AccAddress, info wasmvmtypes.MessageInfo) ([]sdk.Msg, error) {
	encodedCallEVM := bindings.CallEVM{}
	if err := json.Unmarshal(rawMsg, &encodedCallEVM); err != nil {
		return []sdk.Msg{}, err
	}
	decodedData, err := base64.StdEncoding.DecodeString(encodedCallEVM.Data)
	if err != nil {
		return []sdk.Msg{}, err
	}
	internalCallEVMMsg := types.MsgInternalEVMCall{
		Sender: sender.String(),
		To:     encodedCallEVM.To,
		Value:  encodedCallEVM.Value,
		Data:   decodedData,
	}
	return []sdk.Msg{&internalCallEVMMsg}, nil
}

type SeiWasmMessage struct {
	CreateDenom     json.RawMessage `json:"create_denom,omitempty"`
	MintTokens      json.RawMessage `json:"mint_tokens,omitempty"`
	BurnTokens      json.RawMessage `json:"burn_tokens,omitempty"`
	ChangeAdmin     json.RawMessage `json:"change_admin,omitempty"`
	SetMetadata     json.RawMessage `json:"set_metadata,omitempty"`
	CallEVM         json.RawMessage `json:"call_evm,omitempty"`
	DelegateCallEVM json.RawMessage `json:"delegate_call_evm,omitempty"`
}

func CustomEncoder(sender sdk.AccAddress, msg json.RawMessage, info wasmvmtypes.MessageInfo, codeInfo wasmtypes.CodeInfo) ([]sdk.Msg, error) {
	var parsedMessage SeiWasmMessage
	if err := json.Unmarshal(msg, &parsedMessage); err != nil {
		return []sdk.Msg{}, sdkerrors.Wrap(err, "Error parsing Sei Wasm Message")
	}
	switch {
	case parsedMessage.CreateDenom != nil:
		return tokenfactorywasm.EncodeTokenFactoryCreateDenom(parsedMessage.CreateDenom, sender)
	case parsedMessage.MintTokens != nil:
		return tokenfactorywasm.EncodeTokenFactoryMint(parsedMessage.MintTokens, sender)
	case parsedMessage.BurnTokens != nil:
		return tokenfactorywasm.EncodeTokenFactoryBurn(parsedMessage.BurnTokens, sender)
	case parsedMessage.ChangeAdmin != nil:
		return tokenfactorywasm.EncodeTokenFactoryChangeAdmin(parsedMessage.ChangeAdmin, sender)
	case parsedMessage.SetMetadata != nil:
		return tokenfactorywasm.EncodeTokenFactorySetMetadata(parsedMessage.SetMetadata, sender)
	case parsedMessage.CallEVM != nil:
		return evmwasm.EncodeCallEVM(parsedMessage.CallEVM, sender, info)
	case parsedMessage.DelegateCallEVM != nil:
		return evmwasm.EncodeDelegateCallEVM(parsedMessage.DelegateCallEVM, sender, info, codeInfo)
	default:
		return []sdk.Msg{}, wasmvmtypes.UnsupportedRequest{Kind: "Unknown Sei Wasm Message"}
	}
