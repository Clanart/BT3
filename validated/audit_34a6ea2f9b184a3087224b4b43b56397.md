## Finding: Orders can be placed with an unregistered/arbitrary `destination` chain, permanently locking escrowed funds

The Derive report's core broken invariant is: **an entity is created with an attacker/user-chosen identifier that is never validated against a whitelist at creation time, but a later mandatory check on that same identifier can never succeed — leaving escrowed assets permanently unrecoverable.** The direct analog in this repo is in `IntentGatewayV2.placeOrder()`.

### Finding Description
`placeOrder()` in `evm/src/apps/IntentGatewayV2.sol` accepts a user-supplied `order.destination` (an arbitrary `bytes` state-machine identifier) and escrows the user's `inputs` against `commitment` without ever validating that `destination` corresponds to a registered `IntentGatewayV2` deployment: [1](#0-0) 

The only place `order.destination` is checked against the registry is inside `_instance()`/`instance()`, which is called from `cancelOrder()` on the **source** chain to build the cross-chain storage-proof key: [2](#0-1) 

If `order.destination` does not resolve to a value present in `_instances` (populated only via governance-driven `_addDeployment`), `instance()` unconditionally reverts with `UnknownInstance`: [3](#0-2) 

Since `_instances[keccak256(destination)]` is empty for any non-deployed/arbitrary destination string, the source-chain cancellation path (`cancelOrder` → `instance(order.destination)`) always reverts, and the destination-chain cancellation path is physically unreachable because no `IntentGatewayV2` instance exists on that "chain" to call `cancelOrder` against. The escrowed `inputs` recorded in `_orders[commitment][token]` (see the escrow-crediting step at placement) therefore have no reachable withdrawal path — the same terminal state as the Derive report's "SubAccount can no longer change its manager / can no longer be liquidated."

### Impact Explanation
Funds escrowed via `placeOrder()` can become permanently locked in the gateway contract if `order.destination` is not (yet, or ever) a chain with a registered gateway instance. There is no on-chain guard preventing this at order-placement time, and no path exists once the tokens are escrowed to recover them for such a destination — `withdraw()`/`_withdraw()` can only be reached through `cancelOrder()`, which is gated on `instance()` succeeding on the source chain, or through the destination-chain refund flow, which requires an actual deployed instance. This matches "loss/lock of funds" under the impact gate.

### Likelihood Explanation
This is reachable by any unprivileged caller of the public `placeOrder()` entry point with no special preconditions — no malicious relayer, prover, or governance actor is required. It can occur accidentally (a client-side bug encoding an unsupported/legacy `StateMachine` string) or be deliberately triggered by a griefer directing another integrator's front-end into a bad state, but critically it requires no privileged actor and no proof forgery — the loss condition is purely the absence of an early-return validation in `placeOrder`.

### Recommendation
Validate `order.destination` in `placeOrder()` (e.g., call `_instance(order.destination)` and require it to succeed, mirroring the check already performed later in `cancelOrder`) before escrowing any input tokens, so an order can never be placed against a destination that has no registered `IntentGatewayV2` instance.

### Proof of Concept
1. Call `placeOrder(order, graffiti)` with `order.destination` set to an arbitrary `bytes` value that has never been registered via `_addDeployment` (i.e., `_instances[keccak256(order.destination)] == address(0)`).
2. Tokens are transferred into escrow and `_orders[commitment][token]` is populated as shown in the escrow-crediting code.
3. Call `cancelOrder(order, options)` after the deadline on the source chain — this reaches the cross-chain branch, which calls `instance(order.destination)` and reverts with `UnknownInstance`, per `_instance()`'s implementation.
4. No destination-chain `IntentGatewayV2` exists to invoke the alternate cancellation branch (`_filled[commitment] = user` + `RefundEscrow`), because `order.destination` was never a real deployed chain.
5. The escrowed `inputs` for `commitment` remain in `_orders` indefinitely with no reachable code path to release them. [4](#0-3) [5](#0-4)

        if (order.inputs.length == 0) revert InvalidInput();

        address hostAddr = host();
        // fill out the order preludes
        order.user = bytes32(uint256(uint160(msg.sender)));
        order.source = IDispatcher(hostAddr).host();
        order.nonce = _nonce++;

        // Calculate reduced inputs (after protocol fees) for commitment and escrow
        uint256 inputsLen = order.inputs.length;
        // Use destination-specific protocol fee, fallback to source chain fee if zero
        bytes32 destinationHash = keccak256(order.destination);
        uint256 protocolFeeBps = _destinationProtocolFees[destinationHash];
        if (protocolFeeBps == 0) {
            protocolFeeBps = _params.protocolFeeBps;
        }
        TokenInfo[] memory reducedInputs;
        bytes32 commitment;

        if (protocolFeeBps > 0) {
            reducedInputs = new TokenInfo[](inputsLen);
            for (uint256 i; i < inputsLen;) {
                uint256 originalAmount = order.inputs[i].amount;
                uint256 protocolFee = (originalAmount * protocolFeeBps) / 10_000;
                uint256 reducedAmount = originalAmount - protocolFee;
                address token = address(uint160(uint256(order.inputs[i].token)));

                // Emit DustCollected for protocol fee if non-zero
                if (protocolFee > 0) emit DustCollected(token, protocolFee);

                    ++i;
                }

            order.inputs = reducedInputs;
            commitment = keccak256(abi.encode(order));
            order.inputs = originalInputs;
        } else {
            // No protocol fees, use order.inputs directly
            reducedInputs = order.inputs;
            commitment = keccak256(abi.encode(order));

    function cancelOrder(Order calldata order, CancelOptions calldata options) public payable {
        bytes32 commitment = keccak256(abi.encode(order));

        // order has already been filled
        if (_filled[commitment] != address(0)) revert Filled();

        address hostAddr = host();
        bytes32 currentChain = keccak256(IDispatcher(hostAddr).host());
        bytes32 orderSource = keccak256(order.source);
        bytes32 orderDest = keccak256(order.destination);
        bool isSameChain = orderSource == orderDest;

        if (isSameChain) {
            // Same-chain: validate locally and refund immediately
            // only owner can cancel
            if (order.user != bytes32(uint256(uint160(msg.sender)))) revert Unauthorized();

            // Verify we're on the correct chain
            if (orderSource != currentChain) revert WrongChain();

            WithdrawalRequest memory body =
                WithdrawalRequest({commitment: commitment, tokens: order.inputs, beneficiary: order.user});

            withdraw(body, true);
        } else if (currentChain == orderSource) {
            // source chain: fetch storage proof from destination
            // only owner can cancel order
            if (order.user != bytes32(uint256(uint160(msg.sender)))) revert Unauthorized();

            // order has not yet expired
            if (options.height <= order.deadline) revert NotExpired();

            // Cross-chain: fetch storage proof
            uint256 inputsLen = order.inputs.length;
            for (uint256 i; i < inputsLen;) {
                // check for order existence
                if (_orders[commitment][address(uint160(uint256(order.inputs[i].token)))] == 0) revert UnknownOrder();

                unchecked {
                    ++i;
                }
            }

            bytes memory context =
                abi.encode(WithdrawalRequest({commitment: commitment, tokens: order.inputs, beneficiary: order.user}));

            bytes[] memory keys = new bytes[](1);
            keys[0] = bytes.concat(
                // contract address
                abi.encodePacked(instance(order.destination)),
                // storage slot hash
                calculateCommitmentSlotHash(commitment)
            );
