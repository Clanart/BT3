## Analog Found

### Title
Memory-consumption DoS via aliased ABI array offsets in legacy Cosmos precompile calldata decoding, reachable via historical `debug_traceCall`/`eth_call` - ([File: precompiles/common/legacy/v552/precompiles.go])

### Summary
CVE-2016-2109 is a memory-consumption DoS caused by parsing a short, crafted length-prefixed ASN.1 encoding that forces disproportionate memory allocation relative to input size. Sei-chain's legacy Cosmos precompile calldata path has the same bug class: Go's `accounts/abi.Arguments.Unpack` can be driven, via aliased offset pointers in dynamic-array/tuple ABI encodings, to copy `O(k*s)` bytes of string payload from only `O(k+s)` bytes of wire calldata. The currently-active precompile version fixes this with a pre-decode `DecodeGasCost`/`chargeDecodeGas` charge, but every legacy precompile version (`v5.5.2` through `v6.6`) still calls `method.Inputs.Unpack(argsBz)` directly with no size/cost bound, and legacy versions remain reachable today through the EVM JSON-RPC tracing surface (`debug_traceCall`, `debug_traceBlockByNumber`, etc.) targeting historical block heights.

### Finding Description
The generic legacy precompile entry point unconditionally unpacks calldata before any method-specific logic runs: [1](#0-0) 

This same unguarded pattern is repeated in every other legacy precompile package (`v555`…`v640`, `v65`, `v66`), e.g.: [2](#0-1) 

Only the newest ("latest") precompile version wraps `Unpack` with a pre-charge that estimates the decoder's string-copy amplification and reverts before decoding if the cost is unaffordable: [3](#0-2) [4](#0-3) 

The amplification itself is validated in the repo's own tests: with an aliased `voteWeighted` tuple array, `k=18432` array offsets all pointing at one shared string of length `s=602592` produce `k*s ≈ 11 GB` of copied string data from roughly 1.2 MB of calldata: [5](#0-4) 

The fix (`chargeDecodeGas`/`DecodeGasCost`) only exists in the current precompile version; the pre-fix `voteWeighted` implementation in every legacy version unpacks unconditionally and only rejects after decoding (`maxOptions` check), e.g.: [6](#0-5) 

Legacy precompile versions are not dead code — they are selected by block height whenever `ctx.IsTracing()` is true: [7](#0-6) 

and the RPC layer explicitly supports supplying fresh, attacker-controlled calldata against a historical block number via `debug_traceCall`, which resolves to the precompile version active at that height — proven directly by the repo's own integration test: [8](#0-7) 

`debug_traceCall`/`debug_traceBlockByNumber` only reject historical requests beyond a configurable lookback window (`MaxTraceLookbackBlocks`, and the CHANGELOG documents an "unlimited lookback" option): [9](#0-8) 

Since every precompile version prior to the current one (`v5.5.2` through `v6.6`) lacks the decode-cost guard, any chain whose lookback window covers a block from that range — which by default includes essentially the chain's entire pre-fix history unless an operator explicitly shrank `MaxTraceLookbackBlocks` — remains exploitable today by any unauthenticated RPC caller.

### Impact Explanation
An unauthenticated RPC client can submit `debug_traceCall` (or `debug_traceBlockByNumber`/`TraceBlockByHash` containing a tx to the gov precompile with attacker-supplied calldata via state overrides/`eth_call`-style simulation) against a historical block number, targeting the gov (or any other) precompile's dynamic array/tuple/string method. The crafted calldata causes `Unpack` to allocate tens of gigabytes of memory from a sub-2 MB request, with no gas-based rejection in the legacy code path, driving the RPC node process to OOM and crash — satisfying the "crash of default-configuration RPC nodes" impact bar.

### Likelihood Explanation
This requires no privileges beyond calling a public JSON-RPC endpoint, no fee payment (query-side calls are effectively free besides the request itself), and no cooperation from validators or governance. The only gating factor is `MaxTraceLookbackBlocks`; many operators configure "unlimited" lookback per the changelog entry, and even a bounded default window will include the several legacy-precompile upgrade epochs on a long-lived chain. The exploit is deterministic and reproducible — the repo's own test (`TestDecodeStringCopyBytes_AliasedVoteWeighted`) is essentially the exact proof-of-concept.

### Recommendation
Backport the `DecodeGasCost`/`chargeDecodeGas` pre-decode cost-estimation guard (or an equivalent hard cap on decoded string/array payload size) into every legacy precompile version's `Prepare`/`Unpack` call path, not just the latest version. Alternatively, cap `debug_trace*` execution memory/time more aggressively for historical blocks that predate the fix, or disable historical precompile-version selection for arbitrary attacker-supplied calldata in tracing/simulation RPCs (only permit it for already-committed on-chain transactions, whose calldata was already bounded by the original block's gas limit at inclusion time).

### Proof of Concept
1. Start a node (or use any live sei-chain node) whose `debug_trace*` `MaxTraceLookbackBlocks` covers a height where the gov precompile's `v6.6`-or-earlier version is active (`k.GetCustomPrecompilesVersions` selects it per `x/evm/keeper/keeper.go:171-196`).
2. Build calldata for `voteWeighted(uint64, WeightedVoteOption[])` using aliased array-element offsets so all `k` tuple slots point at one shared `(option, weight)` body whose `weight` string has length `s` (see `craftAliasedVoteWeightedArgs`/`newAliasedVoteWeightedArgs` in `precompiles/gov/gov_test.go:1268-1282` and `precompiles/common/decode_cost_test.go:145-165`), choosing `k≈18432`, `s≈602592` for ~1.2 MB calldata that decodes to ~11 GB.
3. Call `debug_traceCall` with this calldata, `To: gov precompile address`, and `blockNrOrHash` set to the historical height selected in step 1.
4. Observe the legacy precompile's `Prepare`/`Unpack` (`precompiles/gov/legacy/v640/gov.go` et al.) attempt to materialize the aliased string payload, driving multi-gigabyte allocation and crashing the RPC node process, matching the CVE-2016-2109 memory-consumption-DoS pattern.

// chargeDecodeGas charges the (already-installed) gas meter for decoding the
// calldata, before it is decoded: a length-proportional scan cost that also
// bounds the DecodeGasCost scan, then the string-copy surcharge from
// DecodeGasCost. Its out-of-gas / overflow recovery is deliberately scoped to
// just these charges — a call that cannot afford the decode reverts here, while
// an executor that later exhausts its gas keeps its normal propagating
// out-of-gas semantics. Anything other than a gas-meter panic is re-raised.
func (d DynamicGasPrecompile) chargeDecodeGas(ctx sdk.Context, method *abi.Method, input []byte) (err error) {
	defer func() {
		if r := recover(); r != nil {
			switch r.(type) {
			case sdk.ErrorOutOfGas, sdk.ErrorGasOverflow:
				err = fmt.Errorf("%v", r)
			default:
				panic(r)
			}
		}
	}()
	scanCost := DefaultGasCost(input, false)
	ctx.GasMeter().ConsumeGas(scanCost, fmt.Sprintf("%s precompile calldata scan", d.name))
	decodeCost, ok := DecodeGasCost(method.Inputs, input)
	if !ok {
		// Calldata is structurally invalid (Unpack would reject it too); reject
		// now, without attempting the decode.
		return fmt.Errorf("invalid calldata encoding for %s", d.name)
	}
	// DecodeGasCost already includes scanCost; charge only the remaining
	// (string-copy) portion so the decode is priced exactly once.
	ctx.GasMeter().ConsumeGas(decodeCost-scanCost, fmt.Sprintf("%s precompile calldata decode", d.name))
	return nil
}

// DecodeGasCost returns the gas to charge for ABI-decoding a dynamic precompile
// call's calldata (the full input, including the 4-byte selector) given the
// method's argument list. ok is false when the calldata is structurally invalid
// (or too deeply nested to price cheaply); the caller should reject such input
// rather than decode it, since the real decoder would reject it too.
//
// The Go ABI decoder's cost is dominated by copying `string` payloads: it
// materializes each string via string(output[begin:end]), and because a single
// string can be referenced by many array/tuple slots, the copied volume can be
// super-linear in len(input) (worst case ~len(input)^2). `bytes` values are
// excluded because the decoder reslices them without copying. The charge is
// therefore a linear pass over the input (DefaultGasCost) plus the string-copy
// volume the decoder would produce, priced at the KV read-per-byte rate.
func DecodeGasCost(args abi.Arguments, input []byte) (uint64, bool) {
	base := DefaultGasCost(input, false)
	if len(input) < 4 {
		return base, true
	}
	strBytes, ok := decodeStringCopyBytes(args, input[4:])
	if !ok {
		return 0, false
	}
	return satAdd(base, satMul(storetypes.KVGasConfig().ReadCostPerByte, strBytes)), true
}

func TestDecodeStringCopyBytes_AliasedVoteWeighted(t *testing.T) {
	const (
		k = uint64(18432)
		s = uint64(602592)
	)
	args := abi.Arguments{
		{Type: mustABIType(t, "uint64", nil)},
		{Type: mustABIType(t, "tuple[]", []abi.ArgumentMarshaling{
			{Name: "option", Type: "int32"},
			{Name: "weight", Type: "string"},
		})},
	}
	data := newAliasedVoteWeightedArgs(k, s)

	n, ok := decodeStringCopyBytes(args, data)
	require.True(t, ok)
	require.Equal(t, k*s, n)

	// DecodeGasCost must price the amplified copy volume, not just len(input).
	input := append([]byte{0x59, 0x63, 0x4a, 0x88}, data...)
	gas, ok := DecodeGasCost(args, input)
	require.True(t, ok)
	base := DefaultGasCost(input, false)
	require.Equal(t, satAdd(base, satMul(storetypes.KVGasConfig().ReadCostPerByte, k*s)), gas)
	require.Greater(t, gas, uint64(12_500_000))
	require.Less(t, uint64(len(input)), uint64(2<<20)) // compact calldata, ~1.2MiB
}

func (k *Keeper) CustomPrecompiles(ctx sdk.Context) map[common.Address]vm.PrecompiledContract {
	if !ctx.IsTracing() {
		return k.latestCustomPrecompiles
	}
	versions := k.GetCustomPrecompilesVersions(ctx)
	cp := make(map[common.Address]vm.PrecompiledContract, len(k.customPrecompiles))
	for addr, versioned := range k.customPrecompiles {
		cp[addr] = versioned[versions[addr]]
	}
	return cp

func (api *DebugAPI) guardHistoricalDebugTraceHeight(ctx context.Context, endpoint string, blockHeight int64) error {
	latest := api.ctxProvider(LatestCtxHeight).BlockHeight()
	if !isHistoricalDebugTraceBlock(blockHeight, latest, api.maxBlockLookback) {
		return nil
	}
	recordHistoricalDebugTraceAttempt(ctx, endpoint, string(api.connectionType))
	return fmt.Errorf("block number %d is beyond max lookback of %d", blockHeight, api.maxBlockLookback)
}

func isHistoricalDebugTraceBlock(blockHeight, latestHeight, maxBlockLookback int64) bool {
	if maxBlockLookback < 0 || blockHeight < 0 || latestHeight < blockHeight {
		return false
	}
	return blockHeight < latestHeight-maxBlockLookback
}
