### Title
Malicious/compromised KIP-149 `Registry` admin can register a rogue `GaslessSwapRouter`, causing every block proposer to auto-lend real KAIA to attacker-controlled accounts with no on-chain repayment enforcement - (File: kaiax/gasless/impl/getter.go)

### Summary
The `kaiax/gasless` module trusts whatever address is currently registered under the `GaslessSwapRouterName` key in the KIP-149 `Registry` system contract as the canonical `swapRouter`. Any transaction pair (`approve` + `swapForGas`) addressed to that registered router is treated as a valid `GaslessTx`, which causes the block proposer itself to generate and sign a `LendTx` that unconditionally transfers real KAIA out of the proposer's own account to the swap sender - exactly analogous to the original report's pattern where a `Registry`/`Factory` admin-listed "market" address is unconditionally trusted to call `Vault.borrowValue()` and move funds to an arbitrary recipient.

### Finding Description
`GaslessModule.updateAddresses` reads the active `GaslessSwapRouter` address straight from the `Registry`/multicall contract every block and overwrites `g.swapRouter` with whatever is currently registered there, with no additional restriction: [1](#0-0) 

Registration of this address is a single privileged call to the KIP-149 `Registry.Register(name, addr, activationBlock)` function, as exercised in the test suite (`registry.Register(owner, GaslessSwapRouterName, anotherGSR, targetBlock)` / `contract.Register(sender, GaslessSwapRouterName, anotherGSR, big.NewInt(2))`): [2](#0-1) [3](#0-2) 

Once the malicious address becomes `g.swapRouter`, `isApproveTx`/`isSwapTx` accept `approve(maliciousRouter, MaxUint)` and `maliciousRouter.swapForGas(...)` as a legitimate `GaslessTx` pair purely by address match, with no code/behavior verification of the router: [4](#0-3) 

`VerifyExecutable`'s only repayment check (`SP4`) is a numeric equality between the `amountRepay` field supplied in the calldata and the formula-derived expected value - it never verifies that the router contract actually transferred anything back to the proposer on-chain: [5](#0-4) 

Based on this unverified bundle, the block proposer's own client code (`GetLendTxGenerator`) constructs and signs a `LendTx` from the proposer's key (`g.InitOpts.NodeKey`) that sends real KAIA (`lendAmount`) directly to the sender of the swap transaction: [6](#0-5) 

Sender balance checks are explicitly skipped for these flows per design, further removing friction against repeated abuse: [7](#0-6) 

### Impact Explanation
Every CN/proposer node in the network is coerced into unconditionally transferring its own KAIA to any address that submits an `approve`+`swapForGas` pair against the rogue router. Because the malicious router fully controls the execution of `swapForGas`, it can simply keep the user's `MaxUint`-approved tokens and/or never route anything back to `block.coinbase`, so the proposer's lent KAIA is never repaid. This is a direct, repeatable drain of proposer funds network-wide - the same "unconditionally trust the Registry-listed address to move real value to an arbitrary recipient" root cause as the original Vault/`borrowValue` finding, just realized through the `GaslessSwapRouter` registry entry instead of the `Registry.supportMarket` market list.

### Likelihood Explanation
Requires a malicious or compromised `Registry` admin (governance) to register a hostile router address - identical privilege assumption to the original report ("malicious/compromised Registry or Factory admin"). Once that one privileged action occurs, exploitation of the resulting drain is fully reachable by any unprivileged transaction sender simply by broadcasting ordinary signed `approve`/`swapForGas` transaction pairs; no further admin action is needed per drain event.

### Recommendation
1. Add a timelock/delay and multi-party approval or on-chain allow-list constraints around registering the `GaslessSwapRouterName` entry in the `Registry`, similar to the original report's recommendation for `Registry#supportMarket()`.
2. Do not rely solely on the calldata-declared `amountRepay` field for `SP4`; verify actual on-chain repayment to the proposer (e.g., via balance-delta checks or trace simulation) before signing/broadcasting the `LendTx`.
3. Bound the total/lend-per-block exposure of proposer funds to gasless transactions so a single malicious router registration cannot drain unlimited proposer balance.

### Proof of Concept
1. Compromised/malicious `Registry` admin calls `Registry.Register(GaslessSwapRouterName, maliciousRouterAddr, targetBlock)` as shown in [2](#0-1) , deploying `maliciousRouterAddr` whose `swapForGas` implementation ignores the swap and simply keeps any approved tokens.
2. After `targetBlock`, `GaslessModule.updateAddresses` (`kaiax/gasless/impl/getter.go:315-344`) picks up `maliciousRouterAddr` as `g.swapRouter`.
3. Any attacker-controlled account (unprivileged sender) submits `approve(maliciousRouterAddr, MaxUint)` on a whitelisted token followed by `maliciousRouterAddr.swapForGas(token, amountIn, minAmountOut, amountRepay, deadline)` with `amountRepay` matching the `repayAmount()` formula in `kaiax/gasless/impl/getter.go:361-367` so `VerifyExecutable` passes.
4. The proposer's `GetLendTxGenerator` (`kaiax/gasless/impl/getter.go:268-312`) signs and sends a `LendTx` transferring `lendAmount` KAIA from the proposer's own account to the attacker's account.
5. `maliciousRouterAddr.swapForGas` executes without repaying `block.coinbase`, keeping the attacker's approved tokens (or simply doing nothing useful) while the proposer's KAIA is already sent - net drain of proposer funds, repeatable per transaction.

	g.gaslessInfoMu.RLock()

	return g.allowedTokens[args.Token] && // A1
		g.swapRouter == args.Spender && // A3
		args.Amount.Cmp(abi.MaxUint256) == 0 // A4

	g.gaslessInfoMu.RLock()
	defer g.gaslessInfoMu.RUnlock()

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

// MakeLendTx creates a transaction with following properties:
// L1. LendTx.type = 0x7802 (TxTypeEthereumDynamicFee)
// L2. LendTx.from = proposer
// L3. LendTx.to = SwapTx.from
// L4. LendTx.value = LendAmount(approveTxOrNil, swapTx)
func (g *GaslessModule) GetLendTxGenerator(approveTxOrNil, swapTx *types.Transaction) *builder.TxOrGen {
	var src []byte
	if approveTxOrNil != nil {
		src = append(src, approveTxOrNil.Hash().Bytes()...)
	}
	src = append(src, swapTx.Hash().Bytes()...)
	bundleHash := crypto.Keccak256Hash(src)

	gen := func(nonce uint64) (*types.Transaction, error) {
		var (
			chainId = g.InitOpts.ChainConfig.ChainID
			signer  = types.LatestSignerForChainID(chainId)
			key     = g.InitOpts.NodeKey
		)

		to, err := types.Sender(signer, swapTx)
		if err != nil {
			return nil, err
		}

		tx, err := types.NewTransactionWithMap(types.TxTypeEthereumDynamicFee, map[types.TxValueKeyType]interface{}{
			types.TxValueKeyNonce:      nonce,
			types.TxValueKeyTo:         &to,
			types.TxValueKeyAmount:     lendAmount(approveTxOrNil, swapTx),
			types.TxValueKeyData:       common.Hex2Bytes("0x"),
			types.TxValueKeyGasLimit:   params.TxGas,
			types.TxValueKeyGasFeeCap:  swapTx.GasFeeCap(),
			types.TxValueKeyGasTipCap:  swapTx.GasTipCap(),
			types.TxValueKeyAccessList: types.AccessList{},
			types.TxValueKeyChainID:    chainId,
		})
		if err != nil {
			return nil, err
		}

		err = tx.Sign(signer, key)
		return tx, err
	}

	return builder.NewTxOrGenFromGen(gen, bundleHash)

func (g *GaslessModule) updateAddresses(header *types.Header) error {
	g.gaslessInfoMu.Lock()
	defer g.gaslessInfoMu.Unlock()

	swapRouter, tokens, err := getGaslessInfo(g.Chain, header)
	// proceed even if there is something wrong with multicall contract
	if err != nil {
		g.swapRouter = common.Address{}
		g.allowedTokens = map[common.Address]bool{}
		logger.Warn("there is something wrong with multicall contract", "err", err.Error())
		return nil
	}

	g.swapRouter = swapRouter

	g.allowedTokens = map[common.Address]bool{}
	for _, addr := range tokens {
		// all tokens are allowed if nil
		if g.GaslessConfig.AllowedTokens == nil {
			g.allowedTokens[addr] = true
		}
		for _, allowed := range g.GaslessConfig.AllowedTokens {
			if addr == allowed {
				g.allowedTokens[addr] = true
			}
		}
	}

	return nil
}
