### Title
Unauthenticated JSON-RPC `send_citrea_tx` Allows Wallet Exhaustion via Unbounded SequencerCommitment Insertion - (`crates/clementine-tx-sender/src/jsonrpc/server.rs`)

### Summary
The tx-sender JSON-RPC server exposes `send_citrea_tx` with no authentication and no rate limiting. An attacker who can reach the socket can submit an unbounded number of `CitreaTxRequest::SequencerCommitment` payloads with distinct bodies. Each distinct body bypasses the `body_hash` deduplication guard, is inserted as a new row with a unique `insertion_id`, and on the next `sync_citrea_txs` tick causes `create_commit_outpoints_for_rows` to call `fund_raw_transaction` against the operator's Bitcoin wallet. The wallet is exhausted, and legitimate sequencer-commitment commit transactions can no longer be funded.

### Finding Description

**Step 1 – Unauthenticated entrypoint.**
`start_jsonrpc_server` builds the server with `ServerBuilder::default()` and only sets `max_request_body_size`. No authentication middleware, no IP allowlist enforcement beyond the bind address, and no rate-limit layer is applied to the `send_citrea_tx` method. [1](#0-0) [2](#0-1) 

**Step 2 – Deduplication only prevents exact-body duplicates.**
`insert_citrea_raw_tx_single` computes `body_hash = SHA256(body)` and inserts with `ON CONFLICT (body_hash) DO NOTHING`. N payloads with N distinct bodies produce N distinct SHA-256 hashes, each of which passes the conflict check and is stored as a new row with a fresh `insertion_id`. [3](#0-2) [4](#0-3) [5](#0-4) 

**Step 3 – Every distinct `insertion_id` triggers a wallet-funded commit transaction.**
`sync_citrea_txs` fetches all rows with `commit_outpoint IS NULL`, groups them by `insertion_id`, and calls `create_commit_outpoints_for_rows` once per group. That function calls `fund_raw_transaction` on the Bitcoin RPC, which selects UTXOs from the operator's wallet and broadcasts a signed commit transaction. N distinct `insertion_id` groups → N `fund_raw_transaction` calls → N commit transactions spending from the operator's wallet. [6](#0-5) [7](#0-6) 

### Impact Explanation
The operator's Bitcoin wallet is the sole funding source for all Citrea DA commit transactions. Once the wallet is exhausted, `fund_raw_transaction` fails for every subsequent call. Rows with `commit_outpoint IS NULL` are retried on every `sync_citrea_txs` tick, so the attacker's rows permanently compete with legitimate sequencer-commitment rows for the remaining wallet balance. Legitimate sequencer commitments cannot be inscribed on Bitcoin, breaking bridge liveness and potentially permanently locking bridged BTC that depends on timely DA publication.

### Likelihood Explanation
The JSON-RPC server can be bound to `0.0.0.0` (explicitly supported by the config), making it reachable from any network peer. Even when bound to the default `127.0.0.1`, any co-located process or SSRF vector on the same host can reach it. The attack requires only the ability to send HTTP POST requests; no credentials, keys, or privileged access are needed. The cost to the attacker is negligible (CPU to generate distinct byte strings); the cost to the operator is real BTC. [8](#0-7) 

### Recommendation
1. **Authentication**: Add a shared-secret or mTLS layer to `start_jsonrpc_server` so only the legitimate Citrea sequencer can call `send_citrea_tx`.
2. **Rate limiting**: Apply a per-connection or global request-rate limit to the JSON-RPC server (analogous to the `RateLimitLayer` already used on gRPC servers).
3. **Payload validation**: Validate that submitted `SequencerCommitment` bodies are well-formed borsh-encoded `SequencerCommitment` structs before insertion, rejecting arbitrary byte blobs.
4. **Queue depth cap**: Enforce a maximum number of pending (unfunded) rows per `transaction_kind` so a flood of insertions cannot grow the queue unboundedly.

    pub async fn sync_citrea_txs(&self, fee_rate: FeeRateKvb) -> Result<(), eyre::Report> {
        // First, check existing commit txids for eviction.
        self.check_evicted_commit_txs().await?;

        // First get all citrea rows (except aggregate tx) with commit_outpoint IS NULL.
        // For all of these we will try to fund and create a tx that creates commit utxos.
        let citrea_rows = self
            .db
            .get_citrea_txs_with_null_commit_outpoint(None)
            .await?;

        // Group rows by insertion_id since all chunk rows share the same eventual commit tx/outpoint.
        let mut by_insertion_id: BTreeMap<i64, Vec<CitreaRawTxRow>> = BTreeMap::new();

        for row in citrea_rows {
            by_insertion_id
                .entry(row.insertion_id)
                .or_default()
                .push(row);
        }

        if !by_insertion_id.is_empty() {
            tracing::info!(
                "Found {} pending non-aggregate citrea rows across {} insertion_id groups",
                by_insertion_id.values().map(|v| v.len()).sum::<usize>(),
                by_insertion_id.len()
            );
        }

        // For each insertion_id group, create a single commit tx/outpoint shared by all rows.
        for (insertion_id, rows) in by_insertion_id {
            tracing::debug!(insertion_id, group_len = rows.len(), "Pending citrea group");

            // Build reveal scripts and collect commit addresses for all rows in this group.
            let mut rows_with_scripts = Vec::with_capacity(rows.len());

            for row in rows {
                let signing_data = self.create_reveal_script(row.transaction_kind, &row.body);
                rows_with_scripts.push((row, signing_data));
            }

            let _ = self
                .create_commit_outpoints_for_rows(fee_rate, insertion_id, rows_with_scripts)
                .await?;
        }

    async fn create_commit_outpoints_for_rows(
        &self,
        fee_rate: FeeRateKvb,
        insertion_id: i64,
        rows_with_scripts: Vec<(CitreaRawTxRow, CitreaSigningData)>,
    ) -> Result<Option<bitcoin::Txid>, eyre::Report> {
        if rows_with_scripts.is_empty() {
            return Ok(None);
        }

        let recipients: Vec<_> = rows_with_scripts
            .iter()
            .map(|(_row, signing_data)| signing_data.commit_address.clone())
            .collect();

        let unsigned_commit_tx = crate::citrea::build_commit_transaction(&recipients);
        let raw_bytes = crate::serialize_tx_for_fund_raw(&unsigned_commit_tx);

        let funded_hex = match self
            .rpc
            .fund_raw_transaction(
                &raw_bytes,
                Some(&FundRawTransactionOptions {
                    add_inputs: Some(true),
                    include_unsafe: Some(self.include_unsafe),
                    change_address: None,
                    change_position: Some(unsigned_commit_tx.output.len() as u32),
                    change_type: None,
                    include_watching: None,
                    lock_unspents: None,
                    fee_rate: Some(Amount::from_sat(fee_rate.to_sat_per_kvb())),
                    subtract_fee_from_outputs: None,
                    replaceable: Some(true),
                    conf_target: None,
                    estimate_mode: None,
                }),
                None,
            )
            .await
        {
            Ok(result) => result.hex,
            Err(e) => {
                tracing::error!(
                    insertion_id,
                    error = %e,
                    "Failed to fund commit transaction, skipping group"
                );
                return Ok(None);
            }
        };
