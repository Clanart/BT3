### Title
Unbounded token list in `GaslessSwapRouter` causes O(n²) work every block in `GaslessModule.updateAddresses`, risking DoS of the gasless subsystem - ([File: kaiax/gasless/impl/getter.go])

### Summary
The `GaslessSwapRouter` system contract's `addToken` function (bound via [1](#0-0) ) has no limit on the number of tokens that can be registered. Every node executes `updateAddresses` on every block, which fetches the full supported-token list from the contract and then performs a nested loop over that list against the locally configured `AllowedTokens` list ( [2](#0-1) ). If the token list grows large (analogous to `addPool` being called too many times in the referenced report), this per-block, per-node computation grows unbounded, mirroring the `[M-03]` bug class: an admin-controlled array with no cap that is iterated by core per-block logic.

### Finding Description
`GaslessModule` reads the `GaslessSwapRouter` contract on every processed block to detect changes to the allowed-token set: [3](#0-2) 

The relevant code path is `updateAddresses`, called from block execution, which:
1. Calls `getGaslessInfo` to fetch `swapRouter` and `tokens` from the `GaslessSwapRouter` contract via a `MultiCallContractCaller` ( [4](#0-3) ).
2. Iterates over every returned token, and for each token iterates over the configured `g.GaslessConfig.AllowedTokens` list to check membership — an O(n·m) nested loop that runs once per block on every node running the gasless module: [2](#0-1) 

The token list itself is populated by the owner-controlled `addToken` function on the `GaslessSwapRouter` contract, which has no enforced cap on the number of entries, mirroring the `poolInfo.push()` pattern in the referenced report: [5](#0-4) [6](#0-5) 

Because this logic runs unconditionally for every block on every full/endpoint node (`Execution` module hook), an unbounded token list directly increases per-block CPU cost network-wide, rather than being confined to a single contract call's gas budget.

### Impact Explanation
If the number of registered tokens grows large enough (through repeated `addToken` calls, whether by a misconfigured or malicious admin), the per-block `updateAddresses` computation cost grows without bound. Because this runs on every node for every block (not only inside a bounded EVM call), it can degrade or stall block processing for the gasless module network-wide, bricking core gasless functionality — the same "brick core functionality" impact class described in the referenced report for `addPool`.

### Likelihood Explanation
Low, since it requires the `GaslessSwapRouter` owner (an admin role) to call `addToken` an excessive number of times, either maliciously or by a significant configuration error — the same precondition described in the original report ("malicious admin or a big admin error").

### Recommendation
Enforce a maximum cap on the number of tokens that can be registered in `GaslessSwapRouter` (e.g., limit `addToken` to a fixed maximum list size), and/or refactor `updateAddresses` in `kaiax/gasless/impl/getter.go` to avoid the O(n·m) nested-loop membership check (e.g., using a set/map lookup) so that per-block cost scales linearly with the token count rather than quadratically, bounding worst-case per-block overhead.

### Proof of Concept
1. Deploy `GaslessSwapRouter` and, as owner, call `addToken` repeatedly (e.g., thousands of times) with distinct token/factory/router addresses — there is no cap preventing this ( [5](#0-4) ).
2. On the next block, every node's `GaslessModule.updateAddresses` fetches the full token list and performs the nested membership loop against `AllowedTokens` ( [7](#0-6) ).
3. As the token count grows, this per-block computation cost increases without bound, degrading block-processing performance for the gasless subsystem across the network.

func (g *GaslessModule) updateAddresses(header *types.Header) error {
	g.gaslessInfoMu.Lock()
	defer g.gaslessInfoMu.Unlock()

	swapRouter, tokens, err := getGaslessInfo(g.Chain, header)
	// proceed even if there is something wrong with multicall contract
	if err != nil {
		g.swapRouter = common.Address{}
		g.allowedTokens = map[common.Address]bool{}
		logger.Warn("there is something wrong with multicall contract", "err", err.Error())
		return nil
	}

	g.swapRouter = swapRouter

	g.allowedTokens = map[common.Address]bool{}
	for _, addr := range tokens {
		// all tokens are allowed if nil
		if g.GaslessConfig.AllowedTokens == nil {
			g.allowedTokens[addr] = true
		}
		for _, allowed := range g.GaslessConfig.AllowedTokens {
			if addr == allowed {
				g.allowedTokens[addr] = true
			}
		}
	}

	return nil
}

func getGaslessInfo(bc backends.BlockChainForCaller, header *types.Header) (common.Address, []common.Address, error) {
	statedb, err := bc.StateAt(header.Root)
	if err != nil {
		return common.Address{}, nil, err
	}

	// If Registry is not installed, do not query GaslessSwapRouter contract.
	if statedb.GetCode(system.RegistryAddr) == nil || bc.Config().IsRandaoForkBlockParent(header.Number) {
		return common.Address{}, nil, nil
	}

	caller, err := system.NewMultiCallContractCaller(statedb, bc, header)
	if err != nil {
		return common.Address{}, nil, err
	}

	opts := &bind.CallOpts{BlockNumber: header.Number}
	info, err := caller.MultiCallGaslessInfo(opts)

	return info.Gsr, info.Tokens, err
}
