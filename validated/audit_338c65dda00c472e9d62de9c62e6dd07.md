### Title
MGP rewards claimed via `ManualCompound.compound()` for mWOM staking pools can become permanently stuck in the `ManualCompound` contract - ([File: rewards/ManualCompound.sol])

### Summary
`ManualCompound.compound()` calls `MasterMagpie.multiclaimOnBehalf`, which routes the pending MGP reward for the caller's `mWOmPoolAmount` bucket directly to `msg.sender` (i.e., the `ManualCompound` contract itself) via a raw `IERC20(mgp).safeTransfer(_receiver, _amount)` call, instead of crediting it to the actual user or forwarding it through an explicit hand-off interface. [1](#0-0) [2](#0-1)  `compound()` only forwards balances of tokens that are explicitly registered in the admin-maintained `rewards` array (via `addReward`) or that appear in the caller-supplied `_rewards[i][j]` list for non-compoundable sweep-back. [3](#0-2)  MGP delivered through the `mWOmPoolAmount` code path is not part of either loop unless an admin has separately registered the `mgp` token as a `Reward` entry. If that registration is missing (or is later removed via `removeReward`), MGP delivered to the contract on every `compound()` call for an mWOM staking pool has no code path that transfers it back out, and it accumulates permanently in `ManualCompound`.

### Finding Description
In `MasterMagpie._multiClaim`, for staking tokens flagged `MPGRewardPool[_stakingToken]` (mWOM-type pools), the pending MGP is aggregated into `mWOmPoolAmount` and sent via `_sendMGP(_user, _receiver, mWOmPoolAmount)`, which is a direct `IERC20(mgp).safeTransfer(_receiver, _amount)`. [4](#0-3) [2](#0-1)  This differs from the other two buckets (`vlMGPPoolAmount` and `defaultPoolAmount`), which are routed via `queueMGP(..., _account, _receiver)` or `vlmgp.lockFor(_amount, _account)` — both of which explicitly credit the end-user `_account`, not merely the transaction's `_receiver`. [5](#0-4) 

When `ManualCompound.compound()` calls `multiclaimOnBehalf(_lps, _rewards, msg.sender)`, `_receiver` inside `_multiClaim` resolves to `msg.sender` at the `MasterMagpie` call site, i.e. the `ManualCompound` contract address, not the original end user who called `compound()`. [6](#0-5) [7](#0-6)  The MGP therefore lands in `ManualCompound`'s own balance.

`compound()`'s only mechanisms to move tokens back out are: (1) forwarding tokens listed in the caller-supplied `_rewards[i][j]` array that are *not* in `compoundableRewards`, and (2) processing the fixed, owner-curated `rewards` array (added via `addReward`, only owner-callable) which converts/locks/deposits or falls back to `safeTransfer(msg.sender, receivedBalance)`. [8](#0-7)  MGP arriving through the `mWOmPoolAmount` path is not part of the caller-supplied `_rewards[i][j]` array (that array only enumerates each pool's *base-rewarder* bonus tokens, not the protocol-native MGP emission), so the only way for MGP to be swept is if `mgp` has been registered as an entry in the `rewards` array via `addReward`. There is no compile-time or constructor-level guarantee of this — `ManualCompound`'s constructor only stores `masterMagpie`, with no reference to the MGP token address, and `addReward`/`removeReward` are separate owner-gated calls. [9](#0-8) [10](#0-9)  Because MGP emission for mWOM-classified pools happens unconditionally on every claim (it is not something the caller can opt out of, unlike the reward-token array), any period during which `mgp` is not present in `rewards` (before initial setup, or after an owner mistakenly calls `removeReward` on it, or if it is simply never added) causes every ordinary user's compounded MGP for mWOM pools to be transferred into `ManualCompound` with zero code path to return it — mirroring the reported `NFTManager.decomposeAndMint` pattern where fees pulled by a subordinate contract land in an intermediary contract that has no logic to relay them onward.

### Impact Explanation
Any unprivileged user calling `ManualCompound.compound()` for an mWOM-classified staking pool loses their claimed MGP reward permanently to the `ManualCompound` contract if MGP is not registered in the `rewards` list at that time — this is a genuine, non-recoverable freeze of user yield, since there is no other public/external function in `ManualCompound` to sweep out non-listed token balances.

### Likelihood Explanation
This can be triggered by any regular user's normal, legitimate use of `compound()` for pools flagged `MPGRewardPool` — no privileged action or malicious admin behavior is required to trigger the loss itself; the precondition is only that the `mgp` token is not (yet, or no longer) present as a registered `Reward` entry, a state that is entirely plausible during initial deployment/rollout or reconfiguration windows, given that MGP flows through this contract via a code path (`_sendMGP`) distinct from the standard bonus-reward-token flow that the contract's design otherwise anticipates.

### Recommendation
In `MasterMagpie._sendMGP`, route mWOM-pool MGP rewards to `_account` (the actual user) rather than `_receiver` (the calling contract), consistent with `_sendMGPForVlMGPPool` and `_sendVlMGPFor`; alternatively, have `ManualCompound.compound()` explicitly track and forward the MGP token balance unconditionally (independent of the owner-curated `rewards` list), e.g., by hardcoding an MGP address lookup and always sweeping it to `msg.sender` at the end of `compound()`.

### Proof of Concept
1. Deploy `ManualCompound` pointing at `masterMagpie`; do not yet call `addReward` for the `mgp` token address.
2. A regular user stakes into an mWOM pool (`MPGRewardPool[_stakingToken] == true`) via `MasterMagpie`/pool helper and accrues MGP rewards over time.
3. User calls `ManualCompound.compound(_lps, _rewards, _convertRatio, _minRec, _lockMgp)` specifying the mWOM pool.
4. Internally, `multiclaimOnBehalf` → `_multiClaim` computes `mWOmPoolAmount` and calls `_sendMGP(user, address(ManualCompound), mWOmPoolAmount)`, transferring MGP into `ManualCompound`. [4](#0-3) 
5. In `compound()`, the loop over `rewards` never processes `mgp` (not registered), and the loop over `_rewards[i][j]` does not include `mgp` (it only contains the base-rewarder bonus tokens the user specified for that pool). [11](#0-10) 
6. Function completes; the MGP balance remains permanently in `ManualCompound` with no external function capable of retrieving it for the user.

    function _multiClaim(address[] calldata _stakingTokens, address _user, address _receiver, address[][] memory _rewardTokens) internal nonReentrant {
        uint256 length = _stakingTokens.length;
        if (length != _rewardTokens.length) revert LengthMismatch();

        uint256 vlMGPPoolAmount;
        uint256 mWOmPoolAmount;
        uint256 defaultPoolAmount;

        for (uint256 i = 0; i < length; ++i) {
            address _stakingToken = _stakingTokens[i];
            UserInfo storage user = userInfo[_stakingToken][_user];
            
            updatePool(_stakingToken);
            uint256 claimableMgp = _calNewMGP(_stakingToken, _user) + unClaimedMgp[_stakingToken][_user];

            if (_stakingToken == address(vlmgp)) {
                vlMGPPoolAmount += claimableMgp;
            } else if (MPGRewardPool[_stakingToken]) {
                mWOmPoolAmount += claimableMgp;
            } else {
                defaultPoolAmount += claimableMgp;
            }

            unClaimedMgp[_stakingToken][_user] = 0;
            user.rewardDebt = (user.amount * tokenToPoolInfo[_stakingToken].accMGPPerShare) / 1e12;
            _claimBaseRewarder(_stakingToken, _user, _receiver, _rewardTokens[i]);
        }

        if (vlMGPPoolAmount > 0) {
            _sendMGPForVlMGPPool(_user, _receiver, vlMGPPoolAmount);
        }

        if (mWOmPoolAmount > 0) {
            _sendMGP(_user, _receiver, mWOmPoolAmount);
        }

        if (defaultPoolAmount > 0) {
            _sendVlMGPFor(_user, _receiver, defaultPoolAmount);
        }

        uint256 totalReward = vlMGPPoolAmount + mWOmPoolAmount + defaultPoolAmount;

        if (totalReward > 0 && referral != address(0)) {
            IReferralStorage(referral).trigger(_user, totalReward);
        }
    }

    function addReward(address _tokenAddress, address _tokenHelper, address _convertor, address _locker) external onlyOwner {
        rewards.push(Reward({
            tokenAddress : _tokenAddress,
            tokenHelper : _tokenHelper,
            convertor : _convertor,
            locker : _locker
        }));

        compoundableRewards[_tokenAddress] = true;
        emit RewardAdded(_tokenAddress);
    }

    function removeReward(uint256 _index, address _tokenAddress) validRewardIndex(_index) external onlyOwner {
        if(rewards[_index].tokenAddress != _tokenAddress) revert InvalidReward();
        for (uint i = _index; i < rewards.length - 1; i++) {
           rewards[i] = rewards[i+1];
        }
        rewards.pop();

        compoundableRewards[_tokenAddress] = false;
        emit RewardRemoved(_index, _tokenAddress);
    }

    function compound(address[] calldata _lps, address[][] calldata _rewards, uint256 _convertRatio, uint256 _minRec, bool _lockMgp) external {
        uint256 rewardTokensLength = rewards.length;        
        IMasterMagpie(masterMagpie).multiclaimOnBehalf(_lps, _rewards, msg.sender);
        // send none compoundable reward back to caller
        for(uint256 i; i < _lps.length; i++) {
            uint256 rewardLength = _rewards[i].length;
            if (rewardLength > 0) {
                for (uint j; j < rewardLength; j++) {
                    if (!compoundableRewards[_rewards[i][j]]) {
                        uint256 rewardBalance = IERC20(_rewards[i][j]).balanceOf(address(this));
                        if (rewardBalance > 0)
                            IERC20(_rewards[i][j]).safeTransfer(msg.sender, rewardBalance);
                    }
                }
            }
        }
        for (uint256 i; i< rewardTokensLength; i++) {
            address _tokenAddress = rewards[i].tokenAddress;
            address _helperAddress = rewards[i].tokenHelper;
            address _convertor = rewards[i].convertor;
            address _locker = rewards[i].locker;
            uint256 receivedBalance = IERC20(_tokenAddress).balanceOf(address(this));

            if (receivedBalance > 0) {
                if (_convertor != address(0)) {
                    IERC20(_tokenAddress).safeApprove(_convertor, receivedBalance);
                    IConverter(_convertor).convertFor(receivedBalance, _convertRatio, _minRec, msg.sender, 2);
                } else if (_locker != address(0) && _lockMgp) {
                    IERC20(_tokenAddress).safeApprove(_locker, receivedBalance);
                    ILocker(_locker).lockFor(receivedBalance, msg.sender);                        
                } else if (_helperAddress != address(0)) { 
                    IERC20(_tokenAddress).safeApprove(_helperAddress, receivedBalance);
                    ISimpleHelper(_helperAddress).depositFor(receivedBalance, msg.sender);
                } else {
                    IERC20(_tokenAddress).safeTransfer(msg.sender, receivedBalance);
                }
            }
        }

        emit Compounded(msg.sender, rewardTokensLength, _lockMgp);
    }
