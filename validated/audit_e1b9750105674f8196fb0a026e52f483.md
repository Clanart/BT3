### Title
Log message injection via unescaped `Any.type_url` in `TextFormat::Printer::PrintAny` - (File: `src/google/protobuf/text_format.cc`)

### Summary
Jenkins' log formatter failed to restrict or transform user-controlled content before writing it to console/log output, letting attackers inject CR/LF characters followed by forged log lines (CWE-117). The Protobuf C++ analog is in `TextFormat::Printer::PrintAny()`, which extracts the attacker-controlled `type_url` string from a parsed `google.protobuf.Any` submessage and writes it *verbatim* to `ABSL_LOG(WARNING)` when the embedded type cannot be resolved or its payload fails to parse — bypassing the very escaping logic (`HardenedPrintString`/`FastFieldValuePrinterUtf8Escaping`) that the same file uses for every other string field it prints.

### Finding Description
`PrintAny` reads the `type_url` field directly via reflection from an untrusted, attacker-supplied message: [1](#0-0) 
When the resolved type is unknown or the embedded value fails to parse, the code logs the raw string with no sanitization: [2](#0-1) 
This is the same file that implements `HardenedPrintString`/`ContainsCharactersToCEscape`, which correctly escape control characters (`\n`, `\r`, etc.) before writing ordinary `STRING`/`BYTES` field values into text-format output: [3](#0-2) [4](#0-3) 
The `type_url` value, however, is never passed through this escaping path before being handed to `ABSL_LOG`. `Any.type_url` is a normal `string` field with no length/character restriction other than the ordinary bounded-message limits, so a client can set it to any byte sequence, including `\n`/`\r`, and have it embedded in a message that a consuming application later calls `TextFormat::Print`/`DebugString`/`PrintToString` on — a common, "trusted" debugging/logging pattern for protobuf messages. The failed invariant transferring from the Jenkins report is: *user-controlled content must not reach a log sink without stripping/escaping line-break characters.* Protobuf's own escaping machinery exists and is applied consistently to all field values it serializes into TextFormat, but this specific diagnostic path bypasses it.

### Impact Explanation
An attacker who controls the contents of an `Any` field (a common, legitimately attacker-reachable scenario, e.g. via a gRPC request body containing `google.protobuf.Any`) can craft a `type_url` value containing embedded newlines and fabricated log-looking text (e.g. `"type.googleapis.com/Foo\n[ERROR] admin: rotate credentials now"`). When any application code calls `DebugString()`/`TextFormat::PrintToString()` on that message — which is extremely common for logging/error reporting — the forged lines are written into the log stream, potentially misleading administrators or log-based intrusion-detection tooling, matching the confidentiality/integrity profile of CWE-117 (Improper Output Neutralization for Logs). This is a Medium-severity issue: it does not allow memory corruption or code execution, only log content forgery, mirroring the impact rating of the source Jenkins advisory (CVSS C:N/I:L/A:N).

### Likelihood Explanation
Likelihood is moderate-to-high in exposure terms: `TextFormat::Print`/`DebugString` are extremely commonly invoked on received messages for logging/tracing purposes, and any message embedding a `google.protobuf.Any` with attacker-controlled `type_url` triggers this path whenever the type is unresolvable in the local `TypeRegistry`/pool (a condition trivially reachable by using a bogus or unregistered type URL) or when the embedded bytes fail to parse as the resolved type.

### Recommendation
Apply the same escaping used for ordinary string fields (`HardenedPrintString` / `absl::CEscape`) to `type_url` before it is included in any `ABSL_LOG` statement inside `PrintAny`, or at minimum strip/escape control characters (`\r`, `\n`) before logging externally-supplied strings anywhere in the codebase. Consider a repo-wide audit for other `ABSL_LOG`/`logger.warning` call sites that interpolate attacker-controlled string field values (e.g., Java `TextFormat`'s `logger.warning` calls) to ensure none echo raw untrusted bytes into log sinks.

### Proof of Concept
1. Define/obtain a message `M` containing a `google.protobuf.Any any_field`.
2. Construct `M` with `any_field.type_url = "type.googleapis.com/Bogus\n[ERROR] Fake admin log line"` and arbitrary `any_field.value` bytes (type deliberately left unresolvable, e.g. not registered in the `TypeRegistry`/`DescriptorPool` used at print time).
3. Serialize `M` to bytes and parse it back with `M::ParseFromString` (ordinary bounded binary parse — no special permissions needed).
4. Call `TextFormat::PrintToString(M, &out)` (or `M.DebugString()`), which invokes `PrintAny`.
5. Observe that the resulting `ABSL_LOG(WARNING)` output at line ~2552 (`"Can't print proto content: proto type " << type_url << " not found"`) contains the injected line break and forged `[ERROR]` text verbatim in the log stream, while the same string, if placed in an ordinary `string` field of `M` and printed normally, would have been escaped to `\n` by `HardenedPrintString`/`ContainsCharactersToCEscape`. void TextFormat::Printer::HardenedPrintString(
    absl::string_view src, TextFormat::BaseTextGenerator* generator) {
  // Print as UTF-8, while guarding against any invalid UTF-8 in the string
  // field.
  //
  // If in the future we have a guaranteed invariant that invalid UTF-8 will
  // never be present, we could avoid the UTF-8 check here.

  generator->PrintLiteral("\"");
  while (!src.empty()) {
    size_t n = SkipPassthroughBytes(src);
    if (n != 0) {
      generator->PrintString(src.substr(0, n));
      src.remove_prefix(n);
      if (src.empty()) break;
    }

    // If repeated calls to CEscape() and PrintString() are expensive, we could
    // consider batching them, at the cost of some complexity.
    generator->PrintString(absl::CEscape(src.substr(0, 1)));
    src.remove_prefix(1);
  }
  generator->PrintLiteral("\"");
}

bool ContainsCharactersToCEscape(absl::string_view val) {
  bool needs_escape = false;
  for (unsigned char c : val) {
    needs_escape |=
        ((c < 32) | (c > 126) | (c == '"') | (c == '\'') | (c == '\\'));
  }
  return needs_escape;
}

void TextFormat::FastFieldValuePrinter::PrintString(
    const std::string& val, BaseTextGenerator* generator) const {
  generator->PrintLiteral("\"");
  if (!val.empty()) {
    if (ABSL_PREDICT_FALSE(ContainsCharactersToCEscape(val))) {
      generator->PrintString(absl::CEscape(val));
    } else {
      generator->PrintString(val);
    }
  }
  generator->PrintLiteral("\"");
}

bool TextFormat::Printer::PrintAny(const Message& message,
                                   BaseTextGenerator* generator) const {
  const FieldDescriptor* type_url_field;
  const FieldDescriptor* value_field;
  if (!internal::GetAnyFieldDescriptors(message, &type_url_field,
                                        &value_field)) {
    return false;
  }

  const Reflection* reflection = message.GetReflection();

  // Extract the full type name from the type_url field.
  const std::string& type_url = reflection->GetString(message, type_url_field);
  std::string url_prefix;
  std::string full_type_name;

  if (!internal::ParseAnyTypeUrl(type_url, &url_prefix, &full_type_name)) {
    return false;
  }

  // Print the "value" in text.
  const Descriptor* value_descriptor =
      finder_ ? finder_->FindAnyType(message, url_prefix, full_type_name)
              : DefaultFinderFindAnyType(message, url_prefix, full_type_name);
  if (value_descriptor == nullptr) {
    ABSL_LOG(WARNING) << "Can't print proto content: proto type " << type_url
                      << " not found";
    return false;
  }
  DynamicMessageFactory factory;
  std::unique_ptr<Message> value_message(
      factory.GetPrototype(value_descriptor)->New());
  std::string serialized_value = reflection->GetString(message, value_field);
  if (!value_message->ParseFromString(serialized_value)) {
    ABSL_LOG(WARNING) << type_url << ": failed to parse contents";
    return false;
  }
  generator->PrintLiteral("[");
  generator->PrintString(type_url);
  generator->PrintLiteral("]");
  const FastFieldValuePrinter* printer = GetFieldPrinter(value_field);
  printer->PrintMessageStart(message, -1, 0, single_line_mode_, generator);
  generator->Indent();
  Print(*value_message, generator);
  generator->Outdent();
  printer->PrintMessageEnd(message, -1, 0, single_line_mode_, generator);
  return true;
}
