### Title
Unbounded CW20/CW721 name/symbol strings cause unbounded, ungassed work in pointer-migration upgrade handlers - ([File: x/evm/migrations/migrate_all_pointers.go])

### Summary
The pointer-registration precompiles accept `name`/`symbol` strings returned by an attacker-controlled CosmWasm contract's `token_info`/`contract_info` query with no length validation, and bake them into deployed pointer-contract bytecode. When the chain later runs a pointer-migration upgrade handler that iterates over *all* registered pointers and redeploys them, each redeploy queries and re-embeds these attacker-chosen strings **under an infinite gas meter**, so an attacker can pre-register many pointers with maximal-size name/symbol strings to inflate the work every validator must perform, deterministically, in the single upgrade block.

### Finding Description
`AddCW20`/`AddCW721` in `precompiles/pointer/pointer.go` (and all its legacy variants) take `name`/`symbol` straight from a CW20/CW721 contract's smart-query response with no length check: [1](#0-0) 
This is directly analogous to `CultureIndex::createPiece` accepting attacker-controlled, unbounded-length metadata with only a non-empty check — here the "art piece" is the attacker-deployed CW20/CW721 contract's declared `name`/`symbol`, and the "field nobody validates the length of" is exactly that string.

These strings are packed into ABI constructor args and become part of the deployed pointer contract's bytecode via `k.UpsertERCPointer` / `evm.Create`: [2](#0-1) 

Later, pointer-migration logic (`x/evm/migrations/migrate_all_pointers.go`, invoked from `x/evm/module.go` upgrade handlers) iterates over **every** stored pointer of each type via a raw KV iterator and re-deploys each one: [3](#0-2) [4](#0-3) 
For each entry it queries the pointer's own `name()`/`symbol()` (which will now return the attacker's arbitrarily large string, since it was embedded at registration time) and then calls `k.RunWithOneOffEVMInstance` with `ctx.WithGasMeter(sdk.NewInfiniteGasMeterWithMultiplier(ctx))` — i.e., **no gas metering** — to redeploy the contract: [5](#0-4) 
`RunWithOneOffEVMInstance` itself also uses `gp := core.GasPool(math.MaxUint64)`, confirming the redeploy path is effectively ungassed: [6](#0-5) 

This is the "fetched/processed multiple times, unbounded size, no gas discipline" pattern from the external report: instead of `verbs.getArtPieceById` being called repeatedly on a winning auction piece, here `QueryERCSingleOutput`/`UpsertERC*Pointer` are called once per registered pointer, for every pointer that exists on chain, at upgrade time, with no gas limit protecting the operation.

### Impact Explanation
Registering pointers is permissionless: any unprivileged EVM transaction sender can deploy a malicious CW20/CW721 contract whose `token_info`/`contract_info` query returns a very large `name`/`symbol` string, then call the pointer precompile's `addCW20Pointer`/`addCW721Pointer` to register it once (paid for by the attacker's own gas at registration time). An attacker can repeat this to register many such pointers.

When Sei later ships a pointer-migration upgrade (as `x/evm/module.go`'s upgrade handlers already do via `MigrateERCNativePointers`/`MigrateERCCW20Pointers`/`MigrateERCCW721Pointers`/`MigrateERCCW1155Pointers`), every validating node deterministically iterates over all pointers of the affected type(s) and re-deploys each with an unmetered EVM instance. A sufficiently large set of maximal-size, attacker-planted `name`/`symbol` strings inflates the real wall-clock CPU/memory/IO cost of this single-block, consensus-critical operation for every node simultaneously (bytecode construction, ABI packing, `SetCode` writes, state commits), which can push block production for that upgrade block well past the network's block-time budget or exhaust node resources — a deterministic, network-wide block delay/halt at the upgrade boundary, not merely a self-inflicted cost to the attacker.

This differs from the ordinary "attacker pays their own gas" case seen in `AddCW20`/`AddCW721` registration itself (bounded by `suppliedGas`) precisely because the *migration* redeploy path is deliberately ungassed and iterates over the attacker's entire pre-planted set at once.

### Likelihood Explanation
Likelihood is Medium: it requires (a) an attacker to spend gas registering many pointers to CW20/CW721 contracts with maximal-length metadata strings ahead of time, and (b) the chain to execute one of the existing pointer-migration upgrade handlers (`MigrateERCNativePointers`/`MigrateERCCW20Pointers`/`MigrateERCCW721Pointers`/`MigrateERCCW1155Pointers`) at a future upgrade. These handlers already exist in `x/evm/module.go`, so any future upgrade that triggers them (or a similar future one) would be affected without additional attacker interaction at upgrade time. The cost to the attacker (bulk-registering many oversized-metadata pointers) is nontrivial but bounded and controllable, similar to the C4 report's acknowledged "costly for the attacker" caveat.

### Recommendation
- Enforce a maximum length on `name`/`symbol` (and any other string) returned from CW20/CW721 `token_info`/`contract_info` queries before accepting them in `AddNative`/`AddCW20`/`AddCW721` (`precompiles/pointer/pointer.go`) and in `UpsertERCPointer` (`x/evm/keeper/pointer_upgrade.go`).
- Replace the infinite/unmetered gas meters used in the pointer-migration path (`x/evm/migrations/migrate_all_pointers.go`, `x/evm/keeper/pointer_upgrade.go:RunWithOneOffEVMInstance`) with a bounded meter, and/or cap and paginate/batch the number of pointers migrated per block so a single upgrade cannot be forced to redeploy an attacker-controlled unbounded set of oversized contracts in one block.
- Reject or truncate metadata at pointer-creation time so it can never be re-embedded at unbounded size during future migrations.

### Proof of Concept
Not executable against this codebase from the index alone (requires a running node, a CosmWasm contract deployment, and triggering an actual chain upgrade). Conceptual PoC:
1. Deploy N CW20 contracts whose `token_info` query returns `name`/`symbol` strings of maximal practical length (e.g., hundreds of KB each, limited only by CosmWasm message/query size limits).
2. For each, call the EVM pointer precompile's `addCW20Pointer(cwAddr)` (`precompiles/pointer/pointer.go` `AddCW20`) to register a pointer; each such string gets embedded into the deployed pointer contract's bytecode via `UpsertERCPointer`/`evm.Create`.
3. Trigger (or wait for) a chain upgrade that runs `MigrateERCCW20Pointers` (`x/evm/migrations/migrate_all_pointers.go`), which iterates all registered CW20 pointers, queries each pointer's `name()`/`symbol()` (returning the attacker's oversized strings), and redeploys each with `RunWithOneOffEVMInstance` under an infinite gas meter, all within the single upgrade block.
4. Measure the wall-clock time/resources consumed by the migration relative to N and string size, to demonstrate it scales with attacker-controlled, unbounded input and can be driven past the block-time budget.

func (p PrecompileExecutor) AddCW20(ctx sdk.Context, method *ethabi.Method, caller common.Address, args []interface{}, value *big.Int, evm *vm.EVM, hooks *tracing.Hooks) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}
	if err := pcommon.ValidateArgsLength(args, 1); err != nil {
		return nil, 0, err
	}
	cwAddr := args[0].(string)
	cwAddress, err := sdk.AccAddressFromBech32(cwAddr)
	if err != nil {
		return nil, 0, err
	}
	res, err := p.wasmdKeeper.QuerySmartSafe(ctx, cwAddress, []byte("{\"token_info\":{}}"))
	if err != nil {
		return nil, 0, err
	}
	formattedRes := map[string]interface{}{}
	if err := json.Unmarshal(res, &formattedRes); err != nil {
		return nil, 0, err
	}
	name := formattedRes["name"].(string)
	symbol := formattedRes["symbol"].(string)
	contractAddr, err := p.evmKeeper.UpsertERCCW20Pointer(ctx, evm, cwAddr, utils.ERCMetadata{Name: name, Symbol: symbol})
	if err != nil {
		return nil, 0, err
	}

	ret, err = method.Outputs.Pack(contractAddr)
	remainingGas = pcommon.GetRemainingGas(ctx, p.evmKeeper)
	return
}

func (k *Keeper) RunWithOneOffEVMInstance(
	ctx sdk.Context, runner func(*vm.EVM) error, logger func(string, string),
) error {
	stateDB := state.NewDBImpl(ctx, k, false)
	evmModuleAddress := k.GetEVMAddressOrDefault(ctx, k.AccountKeeper().GetModuleAddress(types.ModuleName))
	gp := core.GasPool(math.MaxUint64)
	blockCtx, err := k.GetVMBlockContext(ctx, gp)
	if err != nil {
		logger("get block context", err.Error())
		return err
	}
	sstore := k.GetSstoreSetGasEIP2200(ctx)
	cfg := types.DefaultChainConfig().EthereumConfigWithSstore(k.ChainID(ctx), &sstore)
	txCtx := core.NewEVMTxContext(&core.Message{From: evmModuleAddress, GasPrice: utils.Big0})
	evmInstance := vm.NewEVM(*blockCtx, stateDB, cfg, vm.Config{}, k.CustomPrecompiles(ctx))
	evmInstance.SetTxContext(txCtx)
	err = runner(evmInstance)
	if err != nil {
		logger("upserting pointer", err.Error())
		return err
	}
	surplus, err := stateDB.Finalize()
	if err != nil {
		logger("finalizing", err.Error())
		return err
	}
	if !surplus.IsZero() {
		logger("non-zero surplus", surplus.String())
	}
	return nil
}

func (k *Keeper) UpsertERCPointer(
	ctx sdk.Context, evm *vm.EVM, typ string, args []interface{}, getter PointerGetter, setter PointerSetter,
) (contractAddr common.Address, err error) {
	pointee := args[0].(string)
	evmModuleAddress := k.GetEVMAddressOrDefault(ctx, k.AccountKeeper().GetModuleAddress(types.ModuleName))

	var bin []byte
	bin, err = artifacts.GetParsedABI(typ).Pack("", args...)
	if err != nil {
		panic(err)
	}
	bin = append(artifacts.GetBin(typ), bin...)
	// GetDeploymentCode / Create take EVM snapshots that Freeze() Multistore layers.
	// Exists-lookup and commits must use the live unfrozen top (sdb.Ctx): cachekv
	// forbids writing a frozen layer, and same-tx readers that skip frozen-empty
	// parents would miss those writes. The precompile Prepare `ctx` is that top at
	// Prepare time, but is frozen once this Upsert snapshots. Always attach the
	// caller's gas meter (finite precompile meter in deliver) — sdb.Ctx() alone
	// carries the infinite EVM meter.
	sdb := state.GetDBImpl(evm.StateDB)
	liveCtx := func() sdk.Context {
		if sdb == nil {
			return ctx
		}
		return sdb.Ctx().WithGasMeter(ctx.GasMeter())
	}
	existingAddr, _, exists := getter(liveCtx(), pointee)
	suppliedGas := k.getEvmGasLimitFromCtx(ctx)
	var remainingGas uint64
	if exists {
		var ret []byte
		contractAddr = existingAddr
		ret, remainingGas, err = evm.GetDeploymentCode(evmModuleAddress, bin, suppliedGas, utils.Big0, existingAddr)
		if err != nil {
			return
		}
		// Only write on success: a failed GetDeploymentCode can leave ret as nil or
		// revert data, which must not clobber live pointer bytecode (even transiently).
		writeCtx := liveCtx()
		k.SetCode(writeCtx, contractAddr, ret)
		if sdb != nil {
			sdb.RefreshCodeCache(contractAddr, ret)
		}
	} else {
		_, contractAddr, remainingGas, err = evm.Create(evmModuleAddress, bin, suppliedGas, uint256.NewInt(0))
	}

func MigrateERCNativePointers(ctx sdk.Context, k *keeper.Keeper) error {
	iter := prefix.NewStore(ctx.KVStore(k.GetStoreKey()), append(types.PointerRegistryPrefix, types.PointerERC20NativePrefix...)).ReverseIterator(nil, nil)
	defer func() { _ = iter.Close() }()
	seen := map[string]struct{}{}
	for ; iter.Valid(); iter.Next() {
		token := string(iter.Key()[:len(iter.Key())-2]) // last two bytes are version
		if _, ok := seen[token]; ok {
			continue
		}
		seen[token] = struct{}{}
		addr := common.BytesToAddress(iter.Value())
		oName, err := k.QueryERCSingleOutput(ctx, "native", addr, "name")
		if err != nil {
			logger.Error("Failed to upgrade pointer for token due to failed name query", "token", token, "err", err)
			continue
		}
		oSymbol, err := k.QueryERCSingleOutput(ctx, "native", addr, "symbol")
		if err != nil {
			logger.Error("Failed to upgrade pointer for token due to failed symbol query", "token", token, "err", err)
			continue
		}
		oDecimals, err := k.QueryERCSingleOutput(ctx, "native", addr, "decimals")
		if err != nil {
			logger.Error("Failed to upgrade pointer for token due to failed decimal query", "token", token, "err", err)
			continue
		}
		_ = k.RunWithOneOffEVMInstance(ctx, func(e *vm.EVM) error {
			_, err := k.UpsertERCNativePointer(ctx.WithGasMeter(sdk.NewInfiniteGasMeterWithMultiplier(ctx)), e, token, utils.ERCMetadata{
				Name:     oName.(string),
				Symbol:   oSymbol.(string),
				Decimals: oDecimals.(uint8),
			})
			return err
		}, func(s1, s2 string) {
			logger.Error("Failed to upgrade pointer for token at step", "token", token, "from-step", s1, "to-step", s2)
		})
	}
	return nil
}
