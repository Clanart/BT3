### Title
Missing lower-bound validation of the `kip71.gastarget` governance parameter leads to a division-by-zero panic in base fee computation - ([File: params/kip71_config.go])

### Summary
The KIP-71 governance parameter `Kip71GasTarget` is registered with a `noopFormatChecker` (no bounds validation), allowing it to be set to `0`. The value is then used unguarded as a divisor in `KIP71Config.NextMagmaBlockBaseFee`, causing a division-by-zero panic that is triggered deterministically by every node validating or building any block whose gas usage differs from the (zero) gas target.

### Finding Description
`Kip71GasTarget` is defined in the governance parameter table with no format/bounds checker at all: [1](#0-0) 

Compare this with `Kip71BaseFeeDenominator`, which explicitly rejects zero (`v != 0`): [2](#0-1) 

No such protection exists for `GasTarget`. The value flows into `KIP71Config.GasTarget` and is consumed directly in `NextMagmaBlockBaseFee`: [3](#0-2) 

Specifically, when `parentGasUsed != gasTarget` (which happens on almost any real block once `gasTarget == 0`, since any nonzero gas usage exceeds it), the code computes:
```
gasUsedDelta := new(big.Int).SetUint64(parentGasUsed - gasTarget)
x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
y := x.Div(x, new(big.Int).SetUint64(gasTarget))   // division by zero if gasTarget == 0
```
`big.Int.Div` panics on division by zero. Unlike `BaseFeeDenominator`, there is no zero-guard fallback for `GasTarget`.

This function, `NextMagmaBlockBaseFee`/`VerifyMagmaHeader`, is invoked during block header verification (`blockchain/block_validator.go`), block construction (`work/worker.go`, `blockchain/chain_makers.go`), transaction pool base-fee checks (`blockchain/tx_pool.go`), and the `eth_feeHistory`/gas price oracle RPC path (`node/cn/gasprice/feehistory.go`, `node/cn/gasprice/gasprice.go`). All of these are executed by every full/consensus node processing the chain, not merely by an operator.

The parallel to the external report is direct: just as `createVestingSchedule` accepted an unconstrained `_slicePeriodSeconds` that could break the vesting math via rounding/division issues, `kip71.gastarget` accepts an unconstrained value (including `0`) that breaks the KIP-71 base-fee math via an outright division-by-zero panic — a strictly worse outcome than a rounding error.

### Impact Explanation
Once `kip71.gastarget` is set to `0` (a value the `FormatChecker` accepts because it is a no-op), the very next block whose gas usage is nonzero (virtually guaranteed) causes `NextMagmaBlockBaseFee` to panic when computing the expected base fee. Because this function executes inside header verification/block-building code paths that every node runs deterministically, this is a network-wide denial-of-service: every node crashes or fails to validate/produce blocks, halting the chain. This is a High severity impact — a governance parameter update (whether malicious/compromised governance or an honest operator mistake) can brick the entire network's block processing.

### Likelihood Explanation
Low-to-medium likelihood, matching the external report's characterization: it requires a governance vote to set `kip71.gastarget` to `0` (or another degenerate value), which requires control of/error by the governing node/council under `governance.governancemode == "single"` or sufficient voting power otherwise. However, unlike a value merely "too big," there is zero validation at all here (not even a sanity `!= 0` check), so the bar for triggering it is a single bad governance transaction rather than a carefully crafted edge case — lower likelihood of malice needed than most other governance params (which do have some checks), higher likelihood of accidental misconfiguration.

### Recommendation
Add a `FormatChecker` for `Kip71GasTarget` (and audit `Kip71MaxBlockGasUsedForBaseFee`/`Kip71LowerBoundBaseFee`/`Kip71UpperBoundBaseFee`, which also use `noopFormatChecker`) that enforces `v > 0` at minimum, mirroring the existing `Kip71BaseFeeDenominator` check (`v != 0`). Additionally, add a defensive zero-guard directly in `NextMagmaBlockBaseFee` (similar to the existing `baseFeeDenominator == 0` fallback) so that even if an invalid value slips through governance, the node does not panic.

### Proof of Concept
1. Via governance vote (header-based governance or contract-based `GovParamContract`), set `kip71.gastarget` to `0`. Note `checkConsistency` in `kaiax/gov/headergov/impl/header.go` does not special-case `Kip71GasTarget`, and `Params[Kip71GasTarget].FormatChecker` is `noopFormatChecker`, so the vote is accepted: [4](#0-3) [1](#0-0) 
2. Once the parameter activates at the target block, the next block that uses any nonzero amount of gas (i.e., contains at least one transaction) triggers, on every node, in `NextMagmaBlockBaseFee`:
```go
gasUsedDelta := new(big.Int).SetUint64(parentGasUsed - gasTarget) // gasTarget = 0
x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
y := x.Div(x, new(big.Int).SetUint64(gasTarget)) // panic: division by zero
``` [5](#0-4) 
3. This call is reached from `blockchain/block_validator.go` (header verification during import) and `work/worker.go` (block building), so all full nodes panic when they attempt to verify or produce the next block, halting block production network-wide.

```go
func (kc *KIP71Config) NextMagmaBlockBaseFee(parentHeaderNumber *big.Int, parentHeaderBaseFee *big.Int, parentHeaderGasUsed uint64) *big.Int {
	// governance parameters
	lowerBoundBaseFee := new(big.Int).SetUint64(kc.LowerBoundBaseFee)
	upperBoundBaseFee := new(big.Int).SetUint64(kc.UpperBoundBaseFee)
	makeEvenByCeil(lowerBoundBaseFee)
	makeEvenByFloor(upperBoundBaseFee)

	// If the parent is the magma disabled block or genesis, then return the lowerBoundBaseFee (default 25ston)
	if parentHeaderNumber.Cmp(new(big.Int).SetUint64(0)) == 0 || parentHeaderBaseFee == nil {
		return makeEvenByFloor(lowerBoundBaseFee)
	}

	var baseFeeDenominator *big.Int
	if kc.BaseFeeDenominator == 0 {
		// To avoid panic, set the fluctuation range small
		baseFeeDenominator = new(big.Int).SetUint64(64)
	} else {
		baseFeeDenominator = new(big.Int).SetUint64(kc.BaseFeeDenominator)
	}
	gasTarget := kc.GasTarget
	upperGasLimit := kc.MaxBlockGasUsedForBaseFee

	// check the case of upper/lowerBoundBaseFee is updated by governance mechanism
	parentBaseFee := parentHeaderBaseFee
	if parentBaseFee.Cmp(upperBoundBaseFee) >= 0 {
		parentBaseFee = upperBoundBaseFee
	} else if parentBaseFee.Cmp(lowerBoundBaseFee) <= 0 {
		parentBaseFee = lowerBoundBaseFee
	}

	// upper gas limit cut off the impulse of used gas to upper bound
	parentGasUsed := min(parentHeaderGasUsed, upperGasLimit)
	if parentGasUsed == gasTarget {
		return makeEvenByFloor(parentBaseFee)
	} else if parentGasUsed > gasTarget {
		// shortcut. If parentBaseFee is already reached upperbound, do not calculate.
		if parentBaseFee.Cmp(upperBoundBaseFee) == 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		// If the parent block used more gas than its target,
		// the baseFee of the next block should increase.
		// baseFeeDelta = max(1, parentBaseFee * (parentGasUsed - gasTarget) / gasTarget / baseFeeDenominator)
		gasUsedDelta := new(big.Int).SetUint64(parentGasUsed - gasTarget)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := math.BigMax(x.Div(y, baseFeeDenominator), common.Big1)

		nextBaseFee := x.Add(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(upperBoundBaseFee) > 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	} else {
		// shortcut. If parentBaseFee is already reached lower bound, do not calculate.
		if parentBaseFee.Cmp(lowerBoundBaseFee) == 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		// Otherwise if the parent block used less gas than its target,
		// the baseFee of the next block should decrease.
		// baseFeeDelta = parentBaseFee * (gasTarget - parentGasUsed) / gasTarget / baseFeeDenominator
		gasUsedDelta := new(big.Int).SetUint64(gasTarget - parentGasUsed)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := x.Div(y, baseFeeDenominator)

		nextBaseFee := x.Sub(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(lowerBoundBaseFee) < 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	}
}
