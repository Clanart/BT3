### Title
Gasless swap deadline is validated only at tx-pool admission (`GetCheckBalance`), not re-checked at block-building/execution time, allowing execution of expired KIP-247 gasless swaps - ([File: kaiax/gasless/impl/getter.go])

### Summary
This is the same bug class as the reported issue: a time-bound (`endTime` / `deadline`) is defined in the protocol but the code path that actually performs the state-changing action does not re-validate that the deadline has not passed. In `MeritDutchAuction`, `mint()` never checks `endTime`. In Kaia's `kaiax/gasless` module, the equivalent `deadline` check (`tx.deadline >= currentTimestamp`) exists only in `checkBalanceForSwap` [1](#0-0)  which is wired up as `GetCheckBalance()` and invoked when a transaction is first added to the tx pool [2](#0-1) . The actual "mint"-equivalent function — the code path that decides whether a gasless swap is executable and bundles it for on-chain execution — is `VerifyExecutable`/`IsExecutable`, which is called from `ExtractTxBundles` during block building [3](#0-2) . That function performs sender/token/nonce/repay-amount checks but never re-checks `swapArgs.Deadline` against the current block time [4](#0-3) .

### Finding Description
`SwapArgs.Deadline` is decoded from the swap transaction's calldata [5](#0-4) . The only place this deadline is compared against the current time is in `checkBalanceForSwap`, called via `GetCheckBalance()` on `PreAddTx`/admission to the pool [1](#0-0) . That check happens once, at the moment the transaction enters the pool.

However, a swap transaction can legitimately remain in the pool for a period of time before being included in a block (bounded by `PendingTimeout`/`QueueTimeout`/`KnownTxTimeout`, each up to 10–30 seconds, or longer under specific conditions) [6](#0-5) . When the block proposer actually builds a block, it calls `ExtractTxBundles`, which determines execution eligibility purely through `IsExecutable`/`VerifyExecutable` [7](#0-6) . `VerifyExecutable` validates sender match, token match, approve amount, nonce ordering, and repay amount — but not the deadline [8](#0-7) . The bundle is then executed on-chain via `commitBundleTransaction` without any additional deadline re-check [9](#0-8) .

Thus, exactly like the reported analog (mint allowed after `endTime` because `mint()` omits the check that only exists elsewhere/at a different point), a KIP-247 gasless swap can be executed after its user-declared `deadline` has elapsed, because the deadline check is not part of the authoritative execution-eligibility function (`VerifyExecutable`) that gates actual state-changing inclusion in a block.

### Impact Explanation
This allows a swap to be lent gas and executed after the user intended it to expire. Since the router's exchange-rate/slippage protection (`minAmountOut`, `amountIn`) was computed against a price at the time of signing, executing after the deadline can force the user into an unfavorable swap rate, or allow a searcher/proposer to strategically delay inclusion of a swap to a more favorable moment for themselves, at the signer's expense — a form of value-extraction/deadline-bypass. Because the block proposer funds gas via `LendTxGenerator` and is repaid via the swap, an expired-deadline swap being force-executed is a real fee/value-movement issue reachable from a public gasless-tx submission, not merely a resource/no-impact issue.

### Likelihood Explanation
Likelihood is moderate: it requires the tx to sit in the pool/queue past the block-inclusion moment relative to its `deadline`, which is plausible given `PendingTimeout`/`QueueTimeout` windows of up to 10s and network/mempool propagation delays, or a proposer intentionally delaying inclusion of a known swap tx that is close to expiring. No special privilege is needed beyond being a normal gasless-swap submitter; the block proposer (any CN) controls timing of inclusion.

### Recommendation
Add an explicit deadline check inside `VerifyExecutable` (or immediately before/at the point of bundling/`ApplyTransaction` in `ExtractTxBundles`/`commitBundleTransaction`), comparing `swapArgs.Deadline` against the current block's timestamp (`env.header.Time` or `bc.CurrentBlock().Time()`), mirroring the check already present in `checkBalanceForSwap`, so the deadline is authoritatively enforced at the moment of actual execution rather than only once at pool admission.

### Proof of Concept
1. Submit a valid `GaslessApproveTx` + `GaslessSwapTx` pair with `Deadline = currentTime + 1`. `PreAddTx`/`checkBalanceForSwap` accepts it since `deadline >= currentTimestamp` at admission time [1](#0-0) .
2. The transaction sits in `pending`/`queue` (allowed up to `PendingTimeout`/`QueueTimeout` = 10s) without being picked up immediately [6](#0-5) .
3. Once block time advances past the declared `Deadline`, the proposer calls `ExtractTxBundles` → `IsExecutable` → `VerifyExecutable`, which passes because it never checks `Deadline` [8](#0-7) .
4. The bundle (`LendTx`, `ApproveTx`, `SwapTx`) is committed on-chain via `commitBundleTransaction`, successfully executing the swap after its intended deadline [9](#0-8) .

Note: I was unable to fully trace the exact upstream time source used during `ApplyTransaction`/EVM execution (e.g., whether the router contract itself enforces `deadline` on-chain independent of the kaiax module) — this would need verification against the `kip247.GaslessSwapRouter` contract implementation, which was not found in the indexed content. If the on-chain router contract independently enforces the deadline, the impact of this specific client-side gap would be reduced to a wasted-lend/DoS-on-proposer issue rather than value theft; that determination requires reading the router contract source, which is outside the indexed content available here.

func (g *GaslessModule) GetCheckBalance() func(tx *types.Transaction) error {
	return func(tx *types.Transaction) error {
		if approveArgs, ok := decodeApproveTx(tx, g.signer); ok {
			return g.checkBalanceForApprove(approveArgs)
		}
		if swapArgs, ok := decodeSwapTx(tx, g.signer); ok {
			return g.checkBalanceForSwap(swapArgs, tx.Nonce())
		}
		return errors.New("not a gasless transaction") // should not happen because IsModuleTx is called before GetCheckBalance
	}
}

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

func (env *Task) commitBundleTransaction(bundle *builder.Bundle, bc BlockChain, nodeAddr common.Address, vmConfig *vm.Config) (error, *types.Transaction, []*types.Log) {
	lastSnapshot := env.state.Copy()
	gasUsedSnapshot := env.header.GasUsed
	blobGasUsedSnapshot := env.header.BlobGasUsed
	blobsSnapshot := env.blobs
	tcountSnapshot := env.tcount
	txs := []*types.Transaction{}
	receipts := []*types.Receipt{}
	logs := []*types.Log{}

	markAllTxUnexecutable := func() {
		for _, txOrGen := range bundle.BundleTxs {
			if txOrGen.IsConcreteTx() {
				tx, _ := txOrGen.GetTx(0)
				tx.MarkUnexecutable(true)
			}
		}
	}

	restoreEnv := func() {
		env.state.Set(lastSnapshot)
		env.header.GasUsed = gasUsedSnapshot
		env.tcount = tcountSnapshot
		// blob related env are restored to the snapshot
		env.header.BlobGasUsed = blobGasUsedSnapshot
		env.blobs = blobsSnapshot
	}

	var totalTxSize uint64 = 0
	for _, txOrGen := range bundle.BundleTxs {
		tx, err := txOrGen.GetTx(env.state.GetNonce(nodeAddr))
		if err != nil {
			logger.Error("TxGenerator error", "error", err)
			markAllTxUnexecutable()
			restoreEnv()
			return kerrors.ErrTxGeneration, nil, nil
		}

		env.state.SetTxContext(tx.Hash(), common.Hash{}, env.tcount)
		receipt, _, err := bc.ApplyTransaction(env.config, &nodeAddr, env.state, env.header, tx, &env.header.GasUsed, vmConfig)
		// Bundled tx will be rejected with any receipt.Status other than success.
		// There may be cases where a revert occurs within the EVM, which could result in an attack on a tx sender in an already executed bundle.
		if err != nil || receipt.Status != types.ReceiptStatusSuccessful {
			if err != vm.ErrInsufficientBalance && err != vm.ErrTotalTimeLimitReached {
				markAllTxUnexecutable()
			}
			receiptStatus := ""
			if receipt != nil {
				receiptStatus = strconv.FormatUint(uint64(receipt.Status), 10)
			}
			logger.Warn("ApplyTransaction error, restoring env",
				"blockNum", env.header.Number.String(), "txHash", tx.Hash().String(),
				"error", err, "receiptStatus", receiptStatus,
			)
			restoreEnv()
			if err == nil {
				err = kerrors.ErrRevertedBundleByVmErr
			}
			return err, tx, nil
		}

		env.tcount++
		totalTxSize += uint64(tx.Size())
		txs = append(txs, tx)
		receipts = append(receipts, receipt)
		logs = append(logs, receipt.Logs...)
		if tx.Type() == types.TxTypeEthereumBlob {
			env.blobs += len(tx.BlobHashes())
			*env.header.BlobGasUsed += tx.BlobGas()
		}
	}
