## Title
`associatePubKey` precompile allows account takeover via unverified public-key claim, no proof-of-possession required - (File: `precompiles/addr/addr.go`)

### Summary
The `addr` precompile's `associatePubKey` method (and its identical logic replicated across every `precompiles/addr/legacy/vNNN/addr.go`) derives a Sei address and EVM address from a caller-supplied public key and permanently binds them via `AssociateAddresses`, without requiring any signature that proves the caller possesses the corresponding private key. This is the same bug class as the reported OIDC issue: a self-asserted identity claim (public key ⇒ address, analogous to an unverified "email" claim) is trusted and used to bind/associate an identity, with no cryptographic proof of ownership.

### Finding Description
`associatePublicKey` takes a single argument — a hex-encoded compressed public key — parses it, and derives `evmAddr`/`seiAddr`/`pubkey` purely from the bytes supplied by the caller: [1](#0-0) 

Unlike the sibling `associate` method, which requires an ECDSA signature (`v, r, s`) over a message and recovers the public key via `crypto.Ecrecover` (i.e., proves the caller controls the private key for the address being associated): [2](#0-1) 

`associatePublicKey` performs no such proof — it only checks that the input hex-decodes and parses as a valid secp256k1 point: [3](#0-2) 

The only guard in `associateAddresses` is that the target Sei address isn't *already* associated — there is no check that `msg.sender`/`tx.origin` corresponds to the pubkey being associated: [4](#0-3) 

The existing unit test explicitly demonstrates this "caller vs. target" pattern is by design: a `callerPrivKey` invokes the precompile while supplying an unrelated `targetPubKey`, and the association succeeds for the target, not the caller: [5](#0-4) 

Once bound via `AssociateAddresses`, the helper migrates the direct-cast account's balance and installs the pubkey on the associated account: [6](#0-5) 

Since ECDSA public keys are trivially recoverable from any prior on-chain signature (both Ethereum and Cosmos secp256k1 signatures reveal the signer's public key), **any address that has ever transacted is a valid target for `associatePubKey`** by anyone who extracts that public key — no private key, no signature over a Sei-specific message, and no interaction from the victim is required.

### Impact Explanation
This can cause **permanent freezing/loss of funds and unauthorized transfer via a precompile**: an attacker calls `associatePubKey` with a victim's known public key before the victim ever associates their own addresses. Per `MigrateBalance` in `utils/helpers/associate.go`, any spendable balance and wei balance sitting at the victim's direct-cast EVM address is force-migrated to the (now attacker-triggered) associated Sei address, and the cast account may be removed: [7](#0-6) 

Because `associateAddresses` rejects re-association once a Sei address is associated (`"address %s is already associated..."`), the attacker's front-run association also permanently blocks the legitimate owner from ever cleanly re-associating through the normal flow, and it hijacks the account-number/sequence continuity (`SetAccount` with the target's derived pubkey, but triggered/timed by an attacker) — a form of unauthorized account/fund manipulation reachable by any unprivileged EVM caller.

### Likelihood Explanation
High likelihood: extracting a public key from any historical Ethereum-style signature (`r,s,v`) or Cosmos secp256k1 signature is standard `ecrecover`/pubkey-recovery, publicly available on any Sei RPC/explorer. No special privileges, precompile whitelisting, or governance access is required — a single `associatePubKey` EVM transaction from any account suffices, and it is gas-cheap (only 50000 gas per `RequiredGas`): [8](#0-7) 

### Recommendation
Require proof-of-possession before honoring `associatePubKey`: either remove the method entirely (rely only on `associate`, which requires a signature) or require the caller to submit a signature (over a domain-separated message, similar to `associate`) generated with the private key corresponding to the supplied public key, and verify `ecrecover(sig) == pubkey` before calling `associateAddresses`. Apply the same fix uniformly across all legacy precompile versions (`precompiles/addr/legacy/v6*/addr.go`) since each duplicates the same vulnerable logic.

### Proof of Concept
1. Observe any historical transaction (Ethereum-style or Cosmos-style) signed by victim address `V` on Sei; extract `V`'s uncompressed/compressed secp256k1 public key from the signature via standard `ecrecover`.
2. As attacker `A` (any funded EVM account), call the `addr` precompile at `0x0000000000000000000000000000000000001004`, method `associatePubKey(bytes)`, passing `V`'s compressed public key hex — no signature is required, and the transaction is sent/signed by `A`, not `V`: [1](#0-0) 
3. The precompile derives `V`'s `evmAddr`/`seiAddr` from the supplied pubkey and calls `associateAddresses`, which succeeds because `V`'s addresses were not previously associated: [4](#0-3) 
4. `AssociateAddresses`/`MigrateBalance` then moves any balance sitting at `V`'s cast address into the newly bound Sei account and can remove the cast account, all without `V`'s consent or knowledge: [7](#0-6) 
5. `V` can no longer associate through the legitimate `associate` (signature-verified) path, since the address pairing is already marked associated.

func (p PrecompileExecutor) associate(ctx sdk.Context, method *abi.Method, args []interface{}, value *big.Int) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}

	if err := pcommon.ValidateArgsLength(args, 4); err != nil {
		return nil, 0, err
	}

	// v, r and s are components of a signature over the customMessage sent.
	// We use the signature to construct the user's pubkey to obtain their addresses.
	v := args[0].(string)
	r := args[1].(string)
	s := args[2].(string)
	customMessage := args[3].(string)

	rBytes, err := decodeHexString(r)
	if err != nil {
		return nil, 0, err
	}
	sBytes, err := decodeHexString(s)
	if err != nil {
		return nil, 0, err
	}
	vBytes, err := decodeHexString(v)
	if err != nil {
		return nil, 0, err
	}

	vBig := new(big.Int).SetBytes(vBytes)
	rBig := new(big.Int).SetBytes(rBytes)
	sBig := new(big.Int).SetBytes(sBytes)

	// Derive addresses
	vBig = new(big.Int).Add(vBig, utils.Big27)

	evmAddr, seiAddr, pubkey, err := helpers.GetAddresses(vBig, rBig, sBig, customMessageHash)
	if err != nil {
		return nil, 0, err
	}

	return p.associateAddresses(ctx, method, evmAddr, seiAddr, pubkey)

func (p PrecompileExecutor) associatePublicKey(ctx sdk.Context, method *abi.Method, args []interface{}, value *big.Int) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}

	if err := pcommon.ValidateArgsLength(args, 1); err != nil {
		return nil, 0, err
	}

	// Takes a single argument, a compressed pubkey in hex format, excluding the '0x'
	pubKeyHex := args[0].(string)

	pubKeyBytes, err := hex.DecodeString(pubKeyHex)
	if err != nil {
		return nil, 0, err
	}

	// Parse the compressed public key
	pubKey, err := btcec.ParsePubKey(pubKeyBytes)
	if err != nil {
		return nil, 0, err
	}

	// Convert to uncompressed public key
	uncompressedPubKey := pubKey.SerializeUncompressed()

	evmAddr, seiAddr, pubkey, err := helpers.GetAddressesFromPubkeyBytes(uncompressedPubKey)
	if err != nil {
		return nil, 0, err
	}

	return p.associateAddresses(ctx, method, evmAddr, seiAddr, pubkey)

func (p PrecompileExecutor) associateAddresses(ctx sdk.Context, method *abi.Method, evmAddr common.Address, seiAddr sdk.AccAddress, pubkey cryptotypes.PubKey) (ret []byte, remainingGas uint64, err error) {
	// Check that address is not already associated
	_, found := p.evmKeeper.GetEVMAddress(ctx, seiAddr)
	if found {
		return nil, 0, fmt.Errorf("address %s is already associated with evm address %s", seiAddr, evmAddr)
	}

	// Associate Addresses:
	associationHelper := helpers.NewAssociationHelper(p.evmKeeper, p.bankKeeper, p.accountKeeper)
	err = associationHelper.AssociateAddresses(ctx, seiAddr, evmAddr, pubkey, false)
	if err != nil {
		return nil, 0, err
	}

	ret, err = method.Outputs.Pack(seiAddr.String(), evmAddr)
	return ret, pcommon.GetRemainingGas(ctx, p.evmKeeper), err
}

func (p AssociationHelper) AssociateAddresses(ctx sdk.Context, seiAddr sdk.AccAddress, evmAddr common.Address, pubkey cryptotypes.PubKey, migrateUseiOnly bool) error {
	castAddr := sdk.AccAddress(evmAddr[:])
	if !castAddr.Equals(seiAddr) && p.accountKeeper.GetAccount(ctx, seiAddr) == nil {
		castAcc := p.accountKeeper.GetAccount(ctx, castAddr)
		castBaseAcc, ok := castAcc.(*authtypes.BaseAccount)
		if ok && castBaseAcc.GetPubKey() == nil && p.bankKeeper.LockedCoins(ctx, castAddr).IsZero() {
			p.accountKeeper.SetAccount(ctx, authtypes.NewBaseAccount(seiAddr, pubkey, castBaseAcc.GetAccountNumber(), castBaseAcc.GetSequence()))
		}
	}
	p.evmKeeper.SetAddressMapping(ctx, seiAddr, evmAddr)
	acc := p.accountKeeper.GetAccount(ctx, seiAddr)
	if acc == nil {
		acc = p.accountKeeper.NewAccountWithAddress(ctx, seiAddr)
	}
	if acc.GetPubKey() == nil {
		if err := acc.SetPubKey(pubkey); err != nil {
			return err
		}
		p.accountKeeper.SetAccount(ctx, acc)
	}
	return p.MigrateBalance(ctx, evmAddr, seiAddr, migrateUseiOnly)
}

func (p AssociationHelper) MigrateBalance(ctx sdk.Context, evmAddr common.Address, seiAddr sdk.AccAddress, migrateUseiOnly bool) error {
	castAddr := sdk.AccAddress(evmAddr[:])
	if castAddr.Equals(seiAddr) {
		return nil
	}
	var castAddrBalances sdk.Coins
	if migrateUseiOnly {
		castAddrBalances = sdk.Coins{p.bankKeeper.GetBalance(ctx, castAddr, "usei")}
	} else {
		castAddrBalances = p.bankKeeper.SpendableCoins(ctx, castAddr)
	}
	if !castAddrBalances.IsZero() {
		if err := p.bankKeeper.SendCoins(ctx, castAddr, seiAddr, castAddrBalances); err != nil {
			return err
		}
	}
	castAddrWei := p.bankKeeper.GetWeiBalance(ctx, castAddr)
	if !castAddrWei.IsZero() {
		if err := p.bankKeeper.SendCoinsAndWei(ctx, castAddr, seiAddr, sdk.ZeroInt(), castAddrWei); err != nil {
			return err
		}
	}
	if p.bankKeeper.LockedCoins(ctx, castAddr).IsZero() {
		p.accountKeeper.RemoveAccount(ctx, authtypes.NewBaseAccountWithAddress(castAddr))
	}
	return nil
}
