### Title
Use-After-Free via cached Python map-value wrapper invalidated by C++ map-entry replacement on `MergeFrom` with duplicate keys - (File: python/google/protobuf/pyext/map_container.cc)

### Summary
The PHP SOAP report's failed invariant is: a pointer to a heap object is cached (deduplication/reference map) without any ownership/refcount tie to the object's real lifetime; when the underlying entry is overwritten (duplicate key), the original object is freed while the stale cached pointer is later dereferenced. The Protobuf C++/pyext analog is the `MessageMapContainer` (Python C-extension `python/google/protobuf/pyext/message.cc`), which caches raw `const Message*` pointers into Python wrapper objects (`CMessage`) keyed by their C++ address, independent of the C++ `Map<K,V>` node lifetime. When a message-valued map field is merged with a `MapFieldBase::MergeFrom` and the source map has a key that duplicates a destination key, the destination's `Message` node for that key is destroyed and replaced in place, while an existing Python wrapper object retains and can still return the freed pointer.

### Finding Description
`MapReflectionFriend::MergeFrom` (`python/google/protobuf/pyext/map_container.cc:307-327`) is the entry point exposed to `MessageMap.MergeFrom()` (bound at line 821). It calls:
```cpp
internal::MapFieldBase* field = reflection->MutableMapData(message, self->parent_field_descriptor);
const internal::MapFieldBase* other_field = other_reflection->GetMapData(*other_message, other_map->parent_field_descriptor);
field->MergeFrom(message->GetArena(), *other_field);
```
`MapFieldBase::MergeFrom` (`src/google/protobuf/map_field.cc:36-38`) delegates to `UntypedMapBase::UntypedMergeFrom` (`src/google/protobuf/map.cc:38-93`), which for each key in the source map allocates a brand-new node, copies/merges the value into it, and then calls `InsertOrReplaceNode` — i.e. for a duplicate key the **old node (and the `Message` it holds) is destroyed/replaced entirely**, not merged into the existing node.

Separately, `CMessage::BuildSubMessageFromPointer` (`python/google/protobuf/pyext/message.cc:2934-2958`) caches Python wrapper objects for message pointers by identity: `this->child_submessages.Get()->Get(sub_message, ...)`, and `MessageMapGetItem` (`map_container.cc:675-706`) returns such a wrapper (`GetCMessage`) built directly from the map entry's `const Message*`. This wrapper (`CMessage::message`) stores that raw pointer with no ownership over the underlying `Map` node — ownership is entirely with the arena-less/heap `Map<K, Message>` storage. There is no mechanism that walks existing wrapper objects to invalidate/reparent them when `MapFieldBase::MergeFrom` replaces a node for a key that already has a live Python wrapper — unlike `InternalReleaseFieldByDescriptor`/`InternalReparentFields` (`message.cc:1703-1733`), which exists for `ClearField`/`Release` semantics but is not invoked from `MapReflectionFriend::MergeFrom`.

This exact hazard is explicitly documented and reproduced in the project's own test suite as a **known, unfixed defect** of the C++ implementation:
```python
# python/google/protobuf/internal/message_test.py:3153-3161
if api_implementation.Type() != 'cpp':
  # During the call to MergeFrom(), the C++ implementation will have
  # deallocated the underlying message, but this is very difficult to detect
  # properly. The line below is likely to cause a segmentation fault.
  ...
  self.assertEqual(15, old_map_value.c)
```
The comment confirms: for the `cpp` implementation, `MergeFrom()` on a `TestMap` whose `map_int32_foreign_message` has an overlapping key (`222`) frees the `Message` object backing a previously obtained Python wrapper (`old_map_value = msg2.map_int32_foreign_message[222]`), and touching `old_map_value.c` afterward is a use-after-free that the test intentionally skips asserting for the C++ backend because it is "likely to cause a segmentation fault."

This transfers the external bug's invariant directly: the "apache map" dedup table stored a pointer without incrementing a refcount, and an overwrite of a duplicate key freed the object behind a stale reference held elsewhere in the structure (`href` back-reference). Here, the "back-reference" is the long-lived Python `CMessage` wrapper object obtained via `msg[key]` before `MergeFrom`, and the "overwrite of a duplicate key" is exactly `UntypedMapBase::InsertOrReplaceNode` during `MapFieldBase::MergeFrom`.

### Impact Explanation
Attacker-controlled input reaching this path: a consuming application that (a) parses one `TestMap`-like message containing an attacker-controlled `map<K, Message>` field from untrusted bytes, (b) retains a Python reference to one of its message-map values (a common, ordinary usage pattern, e.g., iterating `msg.map_field.values()` and keeping references), and (c) subsequently calls `.MergeFrom()` with another attacker-influenced map containing a colliding key — will free the C++ `Message` object while the Python object still exists and is reachable to user code. Subsequent attribute access on the stale wrapper reads/writes freed heap memory, which is a memory-safety violation with potential for information disclosure or corruption, matching the report's "Critical" UAF class (though full RCE would require additional heap-grooming, which is plausible given generic C++ heap reuse, similar to the PHP case).

### Likelihood Explanation
The trigger conditions are not exotic: message-valued map fields with duplicate keys across two merged maps are ordinary, valid protobuf input (the wire format explicitly permits duplicate map-entry submessages, and "last one wins" merging is documented, standard behavior — see `DuplicatedKeyWireFormat`/`DuplicateEntriesInWireFormatLastOneWins` tests in `map_test.inc`). Any application that keeps a Python-level handle to a value obtained from a message map, then merges another message into the same field, hits this exact path. This is only in the Python **C++ implementation** (`api_implementation.Type() == 'cpp'`); pure-Python and non-Python (Java/Go) implementations use different ownership models and are not affected the same way. The upb-backed Python API (`python/map.c`, `PyUpb_MapContainer_*`) uses arena-based ownership and `PyUpb_Arena_CacheUniqueAdd`, which is architecturally different and likely not vulnerable in the same way — but this was not independently verified against the same test-case codepath (the test skip is keyed on `api_implementation.Type() != 'cpp'`, implying the legacy `pyext` C++ Python API is the specifically documented target).

### Recommendation
- In `MapReflectionFriend::MergeFrom` (`map_container.cc:307`), before delegating to `MapFieldBase::MergeFrom`, walk `self->parent->child_submessages`/`composite_fields` for entries with the same map key as those present in `other_map`, and either (a) release/reparent existing Python wrappers analogous to `InternalReleaseFieldByDescriptor`/`InternalReparentFields`, or (b) change `UntypedMapBase::UntypedMergeFrom`'s duplicate-key handling for message values to merge in-place (`MergeFrom` on the existing node) rather than allocate-and-replace, when reflection-visible wrappers might exist.
- At minimum, invalidate/detach any live Python wrapper for a map value whose backing node is about to be replaced, mirroring the `MaybeReleaseSubMessage`/`Swap`-to-new-message pattern already used in `MessageMapSetItem` (`map_container.cc:649-659`) for deletion, but currently missing from the `MergeFrom` path.
- Promote the currently-skipped test assertion (`message_test.py:3153-3161`) into an explicit regression test/CI gate for the `cpp` implementation instead of silently excluding it, so the fix is verifiable.

```text
PyObject* MapReflectionFriend::MergeFrom(PyObject* _self, PyObject* arg) {
  MapContainer* self = GetMap(_self);
  if (!PyObject_TypeCheck(arg, ScalarMapContainer_Type) &&
      !PyObject_TypeCheck(arg, MessageMapContainer_Type)) {
    PyErr_SetString(PyExc_AttributeError, "Not a map field");
    return nullptr;
  }
  MapContainer* other_map = GetMap(arg);
  Message* message = self->GetMutableMessage();
  if (message == nullptr) return nullptr;
  const Message* other_message = other_map->parent->message;
  const Reflection* reflection = message->GetReflection();
  const Reflection* other_reflection = other_message->GetReflection();
  internal::MapFieldBase* field =
      reflection->MutableMapData(message, self->parent_field_descriptor);
  const internal::MapFieldBase* other_field = other_reflection->GetMapData(
      *other_message, other_map->parent_field_descriptor);
  field->MergeFrom(message->GetArena(), *other_field);
  self->version++;
  Py_RETURN_NONE;
}
```

```text
int MapReflectionFriend::MessageMapSetItem(PyObject* _self, PyObject* key,
                                           PyObject* v) {
  if (v) {
    PyErr_Format(PyExc_ValueError,
                 "Direct assignment of submessage not allowed");
    return -1;
  }

  // Now we know that this is a delete, not a set.

  MessageMapContainer* self = GetMessageMap(_self);
  Message* message = self->GetMutableMessage();
  if (message == nullptr) return -1;
  const Reflection* reflection = message->GetReflection();
  MapKey map_key;

  self->version++;

  if (!PythonToMapKey(self, key, &map_key)) {
    return -1;
  }

  // Delete key from map.
  if (reflection->ContainsMapKey(*message, self->parent_field_descriptor,
                                 map_key)) {
    // Delete key from CMessage dict.
    MapValueRef value;
    reflection->InsertOrLookupMapValue(message, self->parent_field_descriptor,
                                       map_key, &value);
    Message* sub_message = value.MutableMessageValue();
    // If there is a living weak reference to an item, we "Release" it,
    // otherwise we just discard the C++ value.
    if (CMessage* released =
            self->parent->MaybeReleaseSubMessage(sub_message)) {
      Message* msg = cmessage::AssureWritable(released);
      if (msg == nullptr) return 0;
      Message* new_msg = msg->New();
      released->message = new_msg;
      msg->GetReflection()->Swap(msg, new_msg);
    }

    // Delete key from map.
    reflection->DeleteMapValue(message, self->parent_field_descriptor, map_key);
    return 0;
  } else {
    PyErr_Format(PyExc_KeyError, "Key not present in map");
    return -1;
  }
```

```text
PyObject* MapReflectionFriend::MessageMapGetItem(PyObject* _self,
                                                 PyObject* key) {
  MessageMapContainer* self = GetMessageMap(_self);

  MapKey map_key;

  if (!PythonToMapKey(self, key, &map_key)) {
    return nullptr;
  }

  // Mutable path: insert-or-lookup and return mutable submessage wrapper.
  if (Message* message = self->GetMutableMessage(); message != nullptr) {
    const Reflection* reflection = message->GetReflection();
    MapValueRef value;
    if (reflection->InsertOrLookupMapValue(
            message, self->parent_field_descriptor, map_key, &value)) {
      self->version++;
    }
    return GetCMessage(self, value.MutableMessageValue(), MESSAGE_MUTABLE);
  }

  // Frozen path: read-only lookup without mutation.
  PyErr_Clear();
  const Message* message = self->GetReadOnlyMessage();
  const Reflection* reflection = message->GetReflection();
  MapValueConstRef value;
  if (!reflection->LookupMapValue(*message, self->parent_field_descriptor,
                                  map_key, &value)) {
    return SetMessageFrozenError();
  }
  return GetCMessage(self, &value.GetMessageValue(), MESSAGE_FROZEN);
}
```

```text
void UntypedMapBase::UntypedMergeFrom(Arena* arena,
                                      const UntypedMapBase& other) {
  ABSL_DCHECK_EQ(arena, this->arena());
  if (other.empty()) return;

  // Do the merging in steps to avoid Key*Value number of instantiations and
  // reduce code duplication per instantation.
  NodeBase* nodes = nullptr;

  // First, allocate all the nodes without types.
  for (size_t i = 0; i < other.num_elements_; ++i) {
    NodeBase* new_node = AllocNode(arena);
    new_node->next = nodes;
    nodes = new_node;
  }

  // Then, copy the values.
  VisitValueType([&](auto value_type) {
    using Value = typename decltype(value_type)::type;
    NodeBase* out_node = nodes;

    // Get the ClassData once to avoid redundant virtual function calls.
    const internal::ClassData* class_data =
        std::is_same_v<MessageLite, Value>
            ? GetClassData(*other.GetValue<MessageLite>(other.begin().node_))
            : nullptr;

    for (auto it = other.begin(); !it.Equals(EndIterator()); it.PlusPlus()) {
      Value* out = GetValue<Value>(out_node);
      out_node = out_node->next;
      auto& in = *other.GetValue<Value>(it.node_);
      if constexpr (std::is_same_v<MessageLite, Value>) {
        class_data->PlacementNew(out, arena)->CheckTypeAndMergeFrom(in);
      } else {
        Arena::CreateInArenaStorage(out, arena, in);
      }
    }
  });

  // Finally, copy the keys and insert the nodes.
  VisitKeyType([&](auto key_type) {
    using Key = typename decltype(key_type)::type;
    for (auto it = other.begin(); !it.Equals(EndIterator()); it.PlusPlus()) {
      NodeBase* node = nodes;
      nodes = nodes->next;
      const Key& in = *other.GetKey<Key>(it.node_);
      Key* out = GetKey<Key>(node);
      if (!internal::InitializeMapKey(out, in, arena)) {
        Arena::CreateInArenaStorage(out, arena, in);
      }

      static_cast<KeyMapBase<Key>*>(this)->InsertOrReplaceNode(
          arena, static_cast<typename KeyMapBase<Key>::KeyNode*>(node));
    }
  });
}
```

```text
int InternalReleaseFieldByDescriptor(CMessage* self,
                                     const FieldDescriptor* field_descriptor) {
  if (!field_descriptor->is_repeated() &&
      field_descriptor->cpp_type() != FieldDescriptor::CPPTYPE_MESSAGE) {
    // Single scalars are not in any cache.
    return 0;
  }
  std::vector<ScopedPyObjectPtr> messages_to_release;
  std::vector<ScopedPyObjectPtr> containers_to_release;
  if (CMessage::SubMessagesMap* subs = self->child_submessages.TryGet();
      subs && field_descriptor->is_repeated() &&
      field_descriptor->cpp_type() == FieldDescriptor::CPPTYPE_MESSAGE) {
    subs->ForEach([&](const void* key, PyObject* value) {
      CMessage* child = reinterpret_cast<CMessage*>(value);
      if (child->parent_field_descriptor == field_descriptor) {
        Py_INCREF(value);
        messages_to_release.emplace_back(value);
      }
    });
  }

  if (CMessage::CompositeFieldsMap* fields = self->composite_fields.TryGet();
      fields) {
    if (PyObject* value = fields->Get(field_descriptor, nullptr)) {
      containers_to_release.emplace_back(value);
    }
  }

  return InternalReparentFields(self, messages_to_release,
                                containers_to_release);
}
```

```text
CMessage* CMessage::BuildSubMessageFromPointer(
    const FieldDescriptor* field_descriptor, const Message* sub_message,
    CMessageClass* message_class, MessageMutabilityState state) {
  if (PyObject* value =
          this->child_submessages.Get()->Get(sub_message, nullptr)) {
    return reinterpret_cast<CMessage*>(value);
  }

  CMessage* cmsg = cmessage::NewEmptyMessage(message_class);

  if (cmsg == nullptr) {
    return nullptr;
  }
  cmsg->message = sub_message;
  Py_INCREF(this);
  cmsg->parent = this;
  cmsg->parent_field_descriptor = field_descriptor;
  cmsg->state = this->state == MESSAGE_FROZEN ? MESSAGE_FROZEN : state;
  cmessage::SetSubmessage(this, cmsg);
  if (state == MESSAGE_MUTABLE) {
    cmsg->has_mutable_map_ancestor =
        this->has_mutable_map_ancestor || field_descriptor->is_map();
  }
  return cmsg;
}
```
