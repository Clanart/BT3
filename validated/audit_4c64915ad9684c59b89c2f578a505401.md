### Title
Forged `ReceivedOutput` credits unspendable/nonexistent Bitcoin deposits via `ReceivedOutput::read` - (File: networks/bitcoin/src/wallet/mod.rs)

### Summary
The analog of "the vault executes an arbitrary message without verifying tokens were actually received" is `ReceivedOutput::read` in `networks/bitcoin/src/wallet/mod.rs:122-134`: it deserializes `(offset, TxOut, outpoint)` from untrusted bytes with zero consistency or provenance checks, letting an attacker fabricate a "received" output that the wallet will treat as spendable funds and sign transactions spending — the signature-side equivalent of executing an operation for a deposit that never happened.

### Finding Description
`ReceivedOutput::read` performs purely syntactic deserialization:

```rust
pub fn read<R: Read>(r: &mut R) -> io::Result<ReceivedOutput> {
  let offset = Secp256k1::read_F(r)?;
  output = TxOut::consensus_decode(&mut buf_r) ...;
  outpoint = OutPoint::consensus_decode(&mut buf_r) ...;
  Ok(ReceivedOutput { offset, output, outpoint })
}
``` [1](#0-0) 

No field is validated: the `outpoint` need not exist on-chain, the `output.value` is attacker-chosen, and nothing ties the three fields together. The legitimate constructor is `Scanner::scan_transaction`, which binds `output`/`outpoint` to a real transaction output and derives `offset` from its own `scripts` map keyed on `script_pubkey` [2](#0-1)  — a check the deserialization path entirely bypasses. The only downstream validation, `SignableTransaction::multisig`, checks `p2tr_script_buf(offset.group_key()) == prevouts[i].script_pubkey` [3](#0-2) , which the attacker trivially satisfies by copying the real Serai P2TR script into the forged `TxOut`. `SignableTransaction::new` then trusts `input.output.value` for the funds/fee check [4](#0-3)  and `TransactionSignMachine::sign` signs a `Prevouts::All` sighash committing to the forged prevout data [5](#0-4) .

### Impact Explanation
Like the vault being induced to `swap` without ever receiving tokens, Serai's wallet can be induced to (a) account for deposits that were never received on-chain (attacker declares an arbitrary `value` at an arbitrary `outpoint`) and (b) produce a fully signed threshold transaction spending a nonexistent, already-spent, or attacker-owned prevout. The signed transaction is invalid on-chain, so credited funds are unspendable in reality — a direct accounting/forgery impact and a fee/DoS vector whenever the fabricated value is also used for real outflows' fee budgeting. If `ReceivedOutput` bytes cross a trust boundary (network-synced state, RPC, DB restored from untrusted input), an unprivileged party reaches this with public inputs only.

### Likelihood Explanation
Medium. Exploitation requires the integrator to feed `ReceivedOutput::read` attacker-influenced bytes rather than only outputs from `Scanner` — but the type exposes `read`/`serialize` as a public wire/storage codec with no documentation stating it must only carry scanner-produced data, and the scanner path is the only place consistency is ever established. Within the codebase's own threat model (untrusted bytes into `read` APIs), the missing validation is unconditional.

### Recommendation
- Short term: treat `ReceivedOutput` as untrusted — add a verification step (or a `verify` method) that recomputes `p2tr_script_buf(group_key + offset*G)` and compares it to `output.script_pubkey`, and require the caller to confirm the `outpoint`/`TxOut` against the chain (e.g., via `gettxout` or merkle proof) before `SignableTransaction::new` consumes it — mirroring the report's "dedicated notification contract" isolation: separate *trusted* scanner-produced outputs from *parsed* untrusted bytes with a distinct type.
- Long term: make `ReceivedOutput::read` crate-private or return an `UnverifiedOutput` type that cannot be passed to `SignableTransaction::new`/`multisig` without explicit chain verification, so no code path permits arbitrary bytes to become spendable inputs.

  pub fn scan_transaction(&self, tx: &Transaction) -> Vec<ReceivedOutput> {
    let mut res = Vec::new();
    for (vout, output) in tx.output.iter().enumerate() {
      // If the vout index exceeds 2**32, stop scanning outputs
      let Ok(vout) = u32::try_from(vout) else { break };

      if let Some(offset) = self.scripts.get(&output.script_pubkey) {
        res.push(ReceivedOutput {
          offset: *offset,
          output: output.clone(),
          outpoint: OutPoint::new(tx.compute_txid(), vout),
        });
      }
    }
    res
  }
