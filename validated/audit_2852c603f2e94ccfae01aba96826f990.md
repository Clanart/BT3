### Title
Gasless-module classification blindness to `tx.Value()` bypasses tx-pool balance/fee-solvency check - (File: kaiax/gasless/impl/tx_pool.go, kaiax/gasless/impl/getter.go)

### Summary
The Kaia tx pool delegates balance validation to a registered `TxPoolModule` whenever `IsModuleTx(tx)` returns true, entirely skipping its own default sender-balance check [3](#0-2) [4](#0-3) . For the gasless module, `IsModuleTx` is satisfied by `IsApproveTx`/`IsSwapTx`, which pattern-match only on `tx.To()`, the 4-byte selector, and ABI-decoded calldata fields (spender/amount, token/amounts) via `decodeFunctionCall` [5](#0-4) [1](#0-0) . Crucially, this classification — analogous to fickling's AST-emission special-case for `builtins` — never inspects `tx.Value()`. Once classified as a "module tx," `GetCheckBalance()` fully replaces the standard `senderBalance.Cmp(tx.Cost()) < 0` solvency check with `checkBalanceForApprove`/`checkBalanceForSwap`, which validate only token balance/allowance/router quote and explicitly never check `tx.Value()` or that the sender can afford it [6](#0-5) [7](#0-6) . The same blind spot is repeated in `txList.Filter`, which uses `module.IsModuleTx`/`GetCheckBalance` in place of the sender-cost check when evicting stale/underfunded transactions [8](#0-7) .

### Finding Description
The security invariant "a transaction admitted to/kept in the pool must be payable by its sender" is enforced generically in `TxPool.validateTx` and `txList.Filter`, except for transactions a registered module claims via `IsModuleTx`. The gasless module's classifier only certifies that the calldata is a well-formed `approve`/`swapForGas` call to whitelisted contracts — it never asserts `tx.Value() == 0`. Because the classifier is blind to `Value`, the pool's fee/value-solvency guarantee silently disappears for any legacy transaction whose `to`/calldata happens to match the gasless pattern, regardless of what `Value` field the sender attaches. This mirrors the fickling flaw exactly: a special-cased "known-safe" category (builtins imports / gasless module txs) is exempted from the general analysis path (AST import emission / balance check), but the exemption logic itself doesn't account for the dangerous attribute (`__import__` / non-zero `Value`) that the excluded category can still carry.

### Impact Explanation
An attacker holding a nonzero balance of a whitelisted gasless token (satisfying `tokenBalance.Sign() > 0`, a cheap/low bar) but with little or no KAIA can craft legacy transactions that are valid ERC-20 `approve`/`swapForGas` calls to whitelisted contracts while setting an arbitrary large `Value`. These transactions bypass the pool's normal `ErrInsufficientFundsFrom` rejection and `txList.Filter` eviction entirely, letting the sender flood pending/queue slots (subject only to the gasless-specific queue caps) with transactions that are economically unbacked. This degrades tx-pool integrity and the fairness of the gasless-bundle admission path (KIP-247), and — since these transactions can be selected by `ExtractTxBundles`/`GetLendTxGenerator` for bundling — can cause bundles that were expected to be gas-solvent to fail during block building/state transition, wasting block-building cycles and potentially colliding with legitimate gasless swap bundles for the same sender.

### Likelihood Explanation
High likelihood of triggering: constructing such a transaction requires only knowledge of the public whitelisted token/router addresses (obtainable via `debug_isGaslessTx`/README) and a normal signed legacy transaction with a non-zero `Value` field — no special privileges, timing, or race condition needed. It is directly reachable by any unprivileged public-RPC caller submitting a transaction.

### Recommendation
In `IsApproveTx`/`IsSwapTx` (or in `decodeFunctionCall`), reject any transaction with `tx.Value().Sign() != 0`, since legitimate gasless approve/swap calls never transfer KAIA. Additionally, `checkBalanceForApprove`/`checkBalanceForSwap` should assert that `senderBalance.Cmp(tx.Value())` (and ideally the KAIA-denominated portion of `tx.Cost()` not covered by the lending mechanism) is non-negative before granting the balance-check override, so that the module-specific check never becomes strictly weaker than the default `tx.Cost()` check it replaces.

### Proof of Concept
1. Attacker acquires a small amount of a whitelisted gasless ERC-20 token (`allowedTokens[token] == true`) but keeps KAIA balance at 0.
2. Attacker signs a legacy transaction: `to = token`, `data = approve(swapRouterAddr, MaxUint256)`, `value = 10_000 KAIA` (or any amount far exceeding actual balance), `gasPrice/gasLimit` set normally.
3. Submit via `eth_sendRawTransaction`. In `TxPool.validateTx`, `pool.modules` iterates and `GaslessModule.IsModuleTx(tx)` returns true because `decodeApproveTx` only checks selector/whitelisted token/spender/`MaxUint` amount [9](#0-8) ; `GetCheckBalance()` is then invoked and succeeds as long as `tokenBalance.Sign() > 0`, ignoring the unpayable `Value` [10](#0-9) .
4. The transaction is accepted into the pool (`shouldSkipBalanceCheck = true` short-circuits the `ErrInsufficientFundsFrom` path) [4](#0-3) , despite the sender being unable to ever cover the declared `Value`, demonstrating the classification's blindness to a field that would otherwise disqualify the transaction under standard rules.

// A1. tx.to is a whitelisted ERC20 token.
// A2. tx.data is `approve(spender, amount)`.
// A3. spender is a whitelisted SwapRouter contract.

func (g *GaslessModule) IsApproveTx(tx *types.Transaction) bool {
	args, ok := decodeApproveTx(tx, g.signer)
	return ok && g.isApproveTx(args)
}

func (g *GaslessModule) isApproveTx(args *ApproveArgs) bool {
	g.gaslessInfoMu.RLock()
	defer g.gaslessInfoMu.RUnlock()

	return g.allowedTokens[args.Token] && // A1
		g.swapRouter == args.Spender && // A3
		args.Amount.Cmp(abi.MaxUint256) == 0 // A4
}

// IsSwapTx checks following conditions:
// S1. tx.to is a whitelisted SwapRouter contract.
// S2. tx.data is `swapForGas(token, amountIn, minAmountOut, amountRepay)`.
// S3. token is a whitelisted ERC20 token.
func (g *GaslessModule) IsSwapTx(tx *types.Transaction) bool {
	args, ok := decodeSwapTx(tx, g.signer)
	return ok && g.isSwapTx(args)
}

func (g *GaslessModule) isSwapTx(args *SwapArgs) bool {
	g.gaslessInfoMu.RLock()
	defer g.gaslessInfoMu.RUnlock()

	return g.swapRouter == args.Router && // S1
		g.allowedTokens[args.Token] // S3
}

func decodeFunctionCall(tx *types.Transaction, method abi.Method) (common.Address, map[string]interface{}, bool) {
	if tx.Type() != types.TxTypeLegacyTransaction || // not legacy tx: unable to statically determine the max gas fee.
		tx.To() == nil || // not a contract call.
		len(tx.Data()) < 4 || // too short to be a contract call.
		!bytes.Equal(tx.Data()[:4], method.ID) { // not the target function.
		return common.Address{}, nil, false
	}

	inputs := make(map[string]interface{})
	err := method.Inputs.UnpackIntoMap(inputs, tx.Data()[4:])
	return *tx.To(), inputs, err == nil
}

func (g *GaslessModule) GetCheckBalance() func(tx *types.Transaction) error {
	return func(tx *types.Transaction) error {
		if approveArgs, ok := decodeApproveTx(tx, g.signer); ok {
			return g.checkBalanceForApprove(approveArgs)
		}
		if swapArgs, ok := decodeSwapTx(tx, g.signer); ok {
			return g.checkBalanceForSwap(swapArgs, tx.Nonce())
		}
		return errors.New("not a gasless transaction") // should not happen because IsModuleTx is called before GetCheckBalance
	}
}

func (g *GaslessModule) checkBalanceForApprove(approveArgs *ApproveArgs) error {
	token := approveArgs.Token
	bc := backends.NewBlockchainContractBackend(g.Chain, nil, nil)

	if g.GaslessConfig.ShouldCheckSenderCode() {
		if g.getCurrentHasCode(approveArgs.Sender) {
			return errors.New("sender with code is not allowed")
		}
	}

	if g.GaslessConfig.ShouldCheckToken() {
		tokenContract, err := sc_erc20.NewERC20(token, bc)
		if err != nil {
			return err
		}

		// tx.token.balanceOf(sender) > 0
		tokenBalance, err := tokenContract.BalanceOf(nil, approveArgs.Sender)
		if err != nil {
			return err
		}
		if tokenBalance.Sign() <= 0 {
			return fmt.Errorf("insufficient sender token balance: token=%s, have=%s, want=nonzero", token.Hex(), tokenBalance.String())
		}
	}
	return nil
}

func (g *GaslessModule) checkBalanceForSwap(swapArgs *SwapArgs, swapNonce uint64) error {
	token := swapArgs.Token
	bc := backends.NewBlockchainContractBackend(g.Chain, nil, nil)

	g.gaslessInfoMu.RLock()
	swapRouter := g.swapRouter
	g.gaslessInfoMu.RUnlock()

	// tx.minAmountOut >= tx.amountRepay
	minAmountOut := swapArgs.MinAmountOut
	amountRepay := swapArgs.AmountRepay
	if minAmountOut.Cmp(amountRepay) < 0 {
		return fmt.Errorf("insufficient minAmountOut: minAmountOut=%s, amountRepay=%s", minAmountOut.String(), amountRepay.String())
	}

	if g.GaslessConfig.ShouldCheckSenderCode() {
		if g.getCurrentHasCode(swapArgs.Sender) {
			return errors.New("sender with code is not allowed")
		}
	}

	if g.GaslessConfig.ShouldCheckSwapAmount() {
		// tx.amountIn >= gsr.getAmountIn(minAmountOut)
		routerContract, err := kip247.NewGaslessSwapRouterCaller(swapRouter, bc)
		if err != nil {
			return err
		}
		// Required token amountIn, given the current exchange rate and the declared minAmountOut.
		requiredAmountIn, err := routerContract.GetAmountIn(nil, token, minAmountOut)
		if err != nil {
			return err
		}
		if swapArgs.AmountIn.Cmp(requiredAmountIn) < 0 {
			return fmt.Errorf("insufficient amountIn: have=%s, want=%s", swapArgs.AmountIn.String(), requiredAmountIn.String())
		}
	}

	if g.GaslessConfig.ShouldCheckToken() {

		tokenContract, err := sc_erc20.NewERC20(token, bc)
		if err != nil {
			return err
		}

		// If SwapTx.nonce is the sender's next nonce, then there is no room for ApproveTx proceeding SwapTx.
		senderNonce := g.getCurrentStateNonce(swapArgs.Sender)
		noApproveTxPreceeds := swapNonce == senderNonce
		if noApproveTxPreceeds {
			// tx.token.allowance(sender, router) >= tx.amountIn
			approval, err := tokenContract.Allowance(nil, swapArgs.Sender, swapRouter)
			if err != nil {
				return err
			}
			if approval.Cmp(swapArgs.AmountIn) < 0 {
				return fmt.Errorf("insufficient approval: approval=%s, want=%s", approval.String(), swapArgs.AmountIn.String())
			}
		}

		// tx.token.balanceOf(sender) >= tx.amountIn
		balance, err := tokenContract.BalanceOf(nil, swapArgs.Sender)
		if err != nil {
			return err
		}
		if balance.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("insufficient balance: balance=%s, want=%s", balance.String(), swapArgs.AmountIn.String())
		}
	}

	// tx.deadline >= currentTimestamp
	deadline := swapArgs.Deadline
	if deadline.Cmp(g.Chain.CurrentBlock().Time()) < 0 {
		return fmt.Errorf("insufficient deadline: deadline=%s, want=%s", deadline.String(), g.Chain.CurrentBlock().Time().String())
	}

	return nil
