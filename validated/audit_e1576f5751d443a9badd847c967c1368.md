### Title
Gasless swap admission relies solely on a manipulable single-DEX spot price with no secondary sanity check - (File: kaiax/gasless/impl/tx_pool.go)

### Summary
The gasless module's mempool admission check for `GaslessSwapTx` (KIP-247) validates that the declared `amountIn` is sufficient by querying a single price source — `GaslessSwapRouter.getAmountIn()`, which is itself backed by a single Uniswap-V2-style pool's on-chain reserves — with no secondary oracle, TWAP, or bounds check. This mirrors the reported bug class ("missing second oracle price sanity check"): a sole spot-price source can be manipulated within the same block/bundle to corrupt the fee/value accounting for gasless swap settlement.

### Finding Description
`GaslessModule.checkBalanceForSwap` in [1](#0-0)  validates `swapArgs.AmountIn` against a `requiredAmountIn` obtained from a single call:
```go
requiredAmountIn, err := routerContract.GetAmountIn(nil, token, minAmountOut)
```
`GetAmountIn` is a view function on the `GaslessSwapRouter` contract [2](#0-1) , and the router internally resolves DEX venue info per token via `GetDEXInfo`/`DexAddress` [3](#0-2) , and the price comes from the Uniswap-V2-fork `getReserves`/`quote`/`getAmountsOut` mechanism used elsewhere in the codebase for swap-amount calculation [4](#0-3) . This is a single, unauthenticated, spot AMM-reserve price — there is no chainlink-style oracle, no TWAP averaging window, and no fallback/secondary source check anywhere in the gasless flow.

The gasless swap-amount check is optional and configurable via `BalanceCheckLevel` (`ShouldCheckSwapAmount()`), gated at `BalanceCheckLevelSwapAmount` [5](#0-4) , and is the *only* validation ensuring `amountIn` is economically sufficient before the protocol prepends a `LendTxGenerator` that fronts KAIA gas fees for the user, expecting to be repaid via the swap [6](#0-5) . The reward/repayment mechanic (`lendAmount`/`repayAmount`) is calculated purely from tx fee fields and does not re-verify the swap's real economic value against a second, harder-to-manipulate reference price [7](#0-6) .

### Impact Explanation
Because the balance/amount check is evaluated using a live, single-pool spot price at tx-pool admission time (and is not re-validated against a secondary sanity bound), an attacker who also controls (or can influence within the same block/bundle, e.g. via front-running or a colluding searcher/proposer) the underlying AMM pool's reserves can manipulate the `getAmountIn` result. This can allow a gasless swap to be admitted/executed with insufficient real collateral (in terms of true market value) to cover the gas fee lent by the block proposer via `GetLendTxGenerator`, and/or lets a malicious sender obtain a wrong quoted output, causing proposer-fronted gas fees not to be economically covered by the token swap. This maps to "acceptance of an invalid transaction" / fee-delegation-style theft (proposer-fronted lend not properly collateralized) under a bug class directly analogous to "missing second oracle sanity check."

### Likelihood Explanation
Reachable purely from unprivileged transactions: an attacker submits ordinary swap transactions against the pool referenced by `GaslessSwapRouter` (potentially bundled/sandwiched around their own `GaslessApproveTx`/`GaslessSwapTx`) to move the single pool's reserves before their gasless swap is evaluated by `checkBalanceForSwap`, and the check only runs if `BalanceCheckLevel >= BalanceCheckLevelSwapAmount` is configured (it's not enforced as a protocol-level invariant, only a node-operator CLI flag) [8](#0-7) . This makes exploitation feasible for any user capable of submitting transactions and interacting with the DEX pool feeding the router.

### Recommendation
Add a secondary, harder-to-manipulate price check for gasless swap admission and settlement — e.g., a TWAP requirement over the referenced pool, a bounded deviation check between spot price and a longer-window average, or cross-checking `getAmountIn` against an independent oracle/price feed before accepting the swap as sufficient collateral for the lent gas fee. This check should be enforced independent of `BalanceCheckLevel` configuration for a baseline of safety, not opt-in only.

### Proof of Concept
Not directly reproducible from the available index — the on-chain Solidity source for `GaslessSwapRouter` (`getAmountIn` internal pricing logic) was not present in this repo (only Go bindings and precompiled bytecode were found), so the exact AMM-reserve manipulation path (single pool vs. multi-hop, fee-on-transfer handling, etc.) could not be fully traced end-to-end. This is a known limitation of the current index; a Devin session with full repository/contract source access would be needed to construct and validate a concrete exploit transaction sequence (e.g., simulate reserve manipulation via a preceding swap in the same block then submit `GaslessApproveTx`+`GaslessSwapTx`) against `checkBalanceForSwap`.

func (g *GaslessModule) checkBalanceForSwap(swapArgs *SwapArgs, swapNonce uint64) error {
	token := swapArgs.Token
	bc := backends.NewBlockchainContractBackend(g.Chain, nil, nil)

	g.gaslessInfoMu.RLock()
	swapRouter := g.swapRouter
	g.gaslessInfoMu.RUnlock()

	// tx.minAmountOut >= tx.amountRepay
	minAmountOut := swapArgs.MinAmountOut
	amountRepay := swapArgs.AmountRepay
	if minAmountOut.Cmp(amountRepay) < 0 {
		return fmt.Errorf("insufficient minAmountOut: minAmountOut=%s, amountRepay=%s", minAmountOut.String(), amountRepay.String())
	}

	if g.GaslessConfig.ShouldCheckSenderCode() {
		if g.getCurrentHasCode(swapArgs.Sender) {
			return errors.New("sender with code is not allowed")
		}
	}

	if g.GaslessConfig.ShouldCheckSwapAmount() {
		// tx.amountIn >= gsr.getAmountIn(minAmountOut)
		routerContract, err := kip247.NewGaslessSwapRouterCaller(swapRouter, bc)
		if err != nil {
			return err
		}
		// Required token amountIn, given the current exchange rate and the declared minAmountOut.
		requiredAmountIn, err := routerContract.GetAmountIn(nil, token, minAmountOut)
		if err != nil {
			return err
		}
		if swapArgs.AmountIn.Cmp(requiredAmountIn) < 0 {
			return fmt.Errorf("insufficient amountIn: have=%s, want=%s", swapArgs.AmountIn.String(), requiredAmountIn.String())
		}
	}

// MakeLendTx creates a transaction with following properties:
// L1. LendTx.type = 0x7802 (TxTypeEthereumDynamicFee)
// L2. LendTx.from = proposer
// L3. LendTx.to = SwapTx.from
// L4. LendTx.value = LendAmount(approveTxOrNil, swapTx)
func (g *GaslessModule) GetLendTxGenerator(approveTxOrNil, swapTx *types.Transaction) *builder.TxOrGen {
	var src []byte
	if approveTxOrNil != nil {
		src = append(src, approveTxOrNil.Hash().Bytes()...)
	}
	src = append(src, swapTx.Hash().Bytes()...)
	bundleHash := crypto.Keccak256Hash(src)

	gen := func(nonce uint64) (*types.Transaction, error) {
		var (
			chainId = g.InitOpts.ChainConfig.ChainID
			signer  = types.LatestSignerForChainID(chainId)
			key     = g.InitOpts.NodeKey
		)

		to, err := types.Sender(signer, swapTx)
		if err != nil {
			return nil, err
		}

		tx, err := types.NewTransactionWithMap(types.TxTypeEthereumDynamicFee, map[types.TxValueKeyType]interface{}{
			types.TxValueKeyNonce:      nonce,
			types.TxValueKeyTo:         &to,
			types.TxValueKeyAmount:     lendAmount(approveTxOrNil, swapTx),
			types.TxValueKeyData:       common.Hex2Bytes("0x"),
			types.TxValueKeyGasLimit:   params.TxGas,
			types.TxValueKeyGasFeeCap:  swapTx.GasFeeCap(),
			types.TxValueKeyGasTipCap:  swapTx.GasTipCap(),
			types.TxValueKeyAccessList: types.AccessList{},
			types.TxValueKeyChainID:    chainId,
		})
		if err != nil {
			return nil, err
		}

		err = tx.Sign(signer, key)
		return tx, err
	}

	return builder.NewTxOrGenFromGen(gen, bundleHash)
}

func lendAmount(approveTxOrNil, swapTx *types.Transaction) *big.Int {
	r := new(big.Int)

	// R2 = ApproveTx.Fee() if exists
	if approveTxOrNil != nil {
		r.Add(r, approveTxOrNil.Fee())
	}

	// R3 = SwapTx.Fee()
	r.Add(r, swapTx.Fee())

	// LendAmount = R2 + R3
	return r
}

func repayAmount(approveTxOrNil, swapTx *types.Transaction) *big.Int {
	// R1 = LendTx.Fee() = SwapTx.GasPrice() * TxGas
	r1 := new(big.Int).Mul(swapTx.GasPrice(), new(big.Int).SetUint64(params.TxGas))

	// RepayAmount = R1 + R2 + R3
	return new(big.Int).Add(r1, lendAmount(approveTxOrNil, swapTx))
}
