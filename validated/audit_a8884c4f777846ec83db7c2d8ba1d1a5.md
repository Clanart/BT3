### Title
DataLayer `subscribe` RPC lets a local RPC caller register mirror URLs (including cloud metadata / internal-service addresses) that the sync loop then fetches over unauthenticated outbound HTTP with no scheme/IP filtering - ([File: chia/data_layer/download_data.py])

### Summary
This is the same bug class as the Claircore SSRF (CWE-918): a component makes outbound HTTP GET requests to a caller-supplied URI with no scheme allow-list and no IP/host filtering (no protection against `169.254.169.254`, loopback, `file://`, link-local, or RFC1918 ranges). In Chia's DataLayer, `DataLayer.subscribe()`/the `subscribe` RPC accepts an arbitrary list of `urls` for a store id and persists them as `ServerInfo.url`. The periodic sync loop (`update_subscription()` → `fetch_and_validate()` → `insert_from_delta_file()` → `download_file()` → `http_download()`) later performs `session.get(server_info.url + "/" + filename, ...)` against that stored URL with only a `MaxDeltaFileSizeExceededError` size check — no destination validation.

### Finding Description
- `http_download()` in `chia/data_layer/download_data.py` builds the request directly from `server_info.url` and issues `session.get(server_info.url + "/" + filename, ...)` with no scheme allow-list and no check against internal/loopback/link-local/cloud-metadata address ranges: [1](#0-0) 
- `download_file()` is the entry point that either calls `http_download()` directly (when no plugin downloader is configured) or forwards to a plugin over HTTP — again using the caller-controlled `server_info.url`: [2](#0-1) 
- `DataLayer.fetch_and_validate()` is the periodic driver: it pulls `server_info` (whose `url` field originates from subscribed mirror URLs) from `self.data_store.get_available_servers_for_store()` and passes it straight into `insert_from_delta_file()`, which calls `download_file()`/`http_download()`: [3](#0-2) 
- Mirror/server URLs are explicitly documented as untrusted external inputs that the service must not treat as trust anchors — the intended mitigation is validating downloaded *content* against wallet-advertised roots, not validating the *destination* being contacted: [4](#0-3) [5](#0-4) 
- Tests confirm arbitrary/loopback URLs are accepted as subscription server URLs without validation, e.g. `subscribe(request={"id": store_id.hex(), "urls": ["http://127.0.0.1/8000"]})` and `ServerInfo("http://127.0.0.1/8003", 0, 0)`: [6](#0-5) [7](#0-6) 
- The `get_downloader()` plugin-selection path has the same shape (a `session.post()` built from `d.url`) but that URL set comes from the operator's own `downloaders` config, not from RPC input, so it is out of scope for an unprivileged-caller analog: [8](#0-7) 

### Impact Explanation
A Data Layer RPC caller (a "local RPC caller" role explicitly in scope) who can invoke `subscribe` on their own node can register a URL such as an internal service address or a cloud metadata endpoint (e.g. `http://169.254.169.254/...`) as a mirror server for a store id. The background `periodically_manage_data()`/`update_subscription()` loop will then have the node itself issue outbound HTTP GET requests to that address on a repeating interval, with the delta filename appended to the path. Response handling in `download_file()`/`insert_from_delta_file()` distinguishes success/failure and file-size-exceeded conditions and logs/propagates exception details (`ClientConnectorError`, generic `Exception` with `traceback.format_exc()`), which is analogous to the reflective error-body leakage described in the advisory. This is primarily a same-machine SSRF: it lets the DataLayer service (running with the node's network position/credentials) be used as a proxy to probe or reach services not otherwise reachable by the RPC caller, and it can leak partial internal responses through DataLayer logs/RPC error surfaces.

### Likelihood Explanation
Likelihood is limited by the fact that `subscribe` is a DataLayer-service RPC, which typically requires local RPC/API-key access rather than being reachable by an arbitrary unauthenticated wallet/mempool peer — this narrows it relative to Claircore's fully unauthenticated network-facing case. However, within the allowed threat model ("local RPC caller"), no additional authorization or destination filtering exists beyond RPC access itself, and the URL is stored and reused indefinitely by the periodic sync loop until unsubscribed, so any RPC-capable caller (including lower-privileged local tooling or a compromised co-located process using the API key) can trigger repeated outbound requests to arbitrary internal targets.

### Recommendation
Add destination validation before making outbound HTTP requests in `http_download()`/`download_file()` (and at `subscribe()`/`data_layer_rpc_api.py` intake time): enforce an `http`/`https` scheme allow-list, resolve and reject loopback/link-local/private/cloud-metadata IP ranges (unless explicitly permitted via config for trusted test/dev use), and avoid logging/returning raw response bodies or verbose exception text for failed mirror fetches to prevent reflective information leakage.

### Proof of Concept
1. Start a node with DataLayer enabled and call `create_data_store`.
2. Call the `subscribe` RPC with `urls=["http://169.254.169.254/latest/meta-data/"]` for the created `store_id`, mirroring the pattern used in tests: [6](#0-5) 
3. Wait for the periodic `update_subscription()`/`fetch_and_validate()` cycle; the DataLayer service issues `GET http://169.254.169.254/latest/meta-data/<generated-filename>` via `http_download()`: [9](#0-8) 
4. Observe DataLayer logs / exception text for the fetch result, revealing whether the metadata endpoint responded and any partial error content surfaced through `log.warning`/`traceback.format_exc()` in `fetch_and_validate()`: [10](#0-9)

async def download_file(
    data_store: DataStore,
    target_filename_path: Path,
    store_id: bytes32,
    root_hash: bytes32,
    generation: int,
    server_info: ServerInfo,
    proxy_url: str | None,
    downloader: PluginRemote | None,
    timeout: aiohttp.ClientTimeout,
    client_foldername: Path,
    timestamp: int,
    log: logging.Logger,
    grouped_by_store: bool,
    group_downloaded_files_by_store: bool,
    max_delta_file_size: int,
) -> bool:
    if target_filename_path.exists():
        return True
    filename = get_delta_filename(store_id, root_hash, generation, grouped_by_store)

    if downloader is None:
        # use http downloader - this raises on any error
        try:
            await http_download(
                target_filename_path, filename, proxy_url, server_info, timeout, log, max_delta_file_size
            )
        except (asyncio.TimeoutError, aiohttp.ClientError, MaxDeltaFileSizeExceededError):
            new_server_info = await data_store.server_misses_file(store_id, server_info, timestamp)
            log.info(
                f"Failed to download {filename} from {new_server_info.url}."
                f"Miss {new_server_info.num_consecutive_failures}."
            )
            log.info(f"Next attempt from {new_server_info.url} in {new_server_info.ignore_till - timestamp}s.")
            return False
        return True

async def http_download(
    target_filename_path: Path,
    filename: str,
    proxy_url: str | None,
    server_info: ServerInfo,
    timeout: aiohttp.ClientTimeout,
    log: logging.Logger,
    max_delta_file_size: int,
) -> None:
    """
    Download a file from a server using aiohttp.
    Raises exceptions on errors
    """
    async with aiohttp.ClientSession() as session:
        headers = {"accept-encoding": "gzip"}
        async with session.get(
            server_info.url + "/" + filename,
            headers=headers,
            timeout=timeout,
            proxy=proxy_url,
        ) as resp:
            resp.raise_for_status()
            size = int(resp.headers.get("content-length", 0))
            max_delta_file_size_bytes = max_delta_file_size * 1024 * 1024
            if size > max_delta_file_size_bytes:
                raise MaxDeltaFileSizeExceededError(f"Maximum delta file size exceeded: {max_delta_file_size} MiB.")
```

    async def get_downloader(self, store_id: bytes32, url: str) -> PluginRemote | None:
        request_json = {"store_id": store_id.hex(), "url": url}
        for d in self.downloaders:
            async with aiohttp.ClientSession() as session:
                try:
                    async with session.post(
                        d.url + "/handle_download",
                        json=request_json,
                        headers=d.headers,
                        timeout=self.client_timeout,
                    ) as response:
                        res_json = await response.json()
                        if res_json["handle_download"]:
                            return d
                except Exception as e:
                    self.log.error(f"get_downloader could not get response: {type(e).__name__}: {e}")
        return None
```
