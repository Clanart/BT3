### Title
Send-on-closed-channel panic in auction BidPool due to TOCTOU race between `AddBid`/`HandleBid` and `stop()` - ([File: kaiax/auction/impl/bid_pool.go])

### Summary
`auction_submitBid` (JSON-RPC, called by any auction bidder/searcher) and peer-relayed bids both funnel into `BidPool.AddBid` / `BidPool.HandleBid`, which check the `running` flag and then push the bid onto `bp.newBidCh` / `bp.bidMsgCh`. Concurrently, `BidPool.stop()` — invoked every block from `PostInsertBlock` whenever the node is syncing, Randao is not enabled, or the auctioneer/entry-point address becomes unset — clears the `running` flag and then unconditionally closes those same channels. The running-flag check and the channel send are not atomic with the close, so a bidder can win the race and send on an already-closed channel, causing a Go runtime panic (fatal, unrecoverable) — the direct analog of the QEMU assertion triggered by the async hot-unplug race (backend cleared while the frontend still assumes it is present).

### Finding Description
`BidPool.stop()`:
```
kaiax/auction/impl/bid_pool.go:127-138
func (bp *BidPool) stop() {
	atomic.CompareAndSwapUint32(&bp.running, 1, 0)
	bp.clearBidPool()
	if atomic.CompareAndSwapUint32(&bp.stopped, 0, 1) {
		close(bp.bidMsgCh)
		close(bp.newBidCh)
	}
	bp.wg.Wait()
}
```
`AddBid` (reached from the public RPC `auction_submitBid` via `kaiax/auction/impl/api.go:140`) and `HandleBid` (reached from peer-relayed bid messages) both do a **check-then-act** on the same flag/channel pair without holding any lock that also protects `close()`:
```
kaiax/auction/impl/bid_pool.go:252-274 (AddBid)
	if atomic.LoadUint32(&bp.running) == 0 {
		return common.Hash{}, auction.ErrAuctionPaused
	}
	...
	bp.newBidCh <- bid

kaiax/auction/impl/bid_pool.go:421-437 (HandleBid)
	if atomic.LoadUint32(&bp.running) == 0 || bid == nil {
		return
	}
	...
	select {
	case bp.bidMsgCh <- bid:
	default:
	}
```
Because `atomic.LoadUint32(&bp.running)` is checked, and then later, non-atomically, `bp.newBidCh <- bid` / `bp.bidMsgCh <- bid` are executed, there is a time window between the load and the send during which `stop()` can run to completion on another goroutine: it flips `running` to 0 and immediately `close()`s both channels. If the RPC-handling goroutine (or the goroutine processing a peer bid) is inside that window when it reaches the send statement, it performs a send on a closed channel, which is a Go runtime panic — unrecoverable by the caller and fatal to the process unless caught by a `recover()` elsewhere (none is present in this call path). `stop()` is driven by `PostInsertBlock` (`kaiax/auction/impl/execution.go:29-50`), so this condition is reachable simply by block processing (e.g., syncing state changes, or auctioneer/entry-point address changing) — no privileged/attacker-controlled peer or validator action is needed to trigger the *stop* side; only ordinary block processing and a submitted bid via the always-reachable public RPC/gossip path are required.

### Impact Explanation
A `send on closed channel` panic in Go is fatal to the goroutine and, without a `recover`, crashes the entire node process. Since `stop()`/`start()` cycle routinely (any time the node briefly desyncs, or the auctioneer/AuctionEntryPoint address is updated via governance/system contract), and `AddBid`/`HandleBid` are reachable by any external bidder over public JSON-RPC or gossip, an attacker (or even benign concurrent load) can crash the CN process, causing denial of service to the auction subsystem and (because it's a fatal Go panic) the entire node. This matches the CVSS-Medium "AC:H" characterization of the CVE analog — the race window is narrow but deterministically reachable with repeated bid submissions timed around block boundaries.

### Likelihood Explanation
`PostInsertBlock` calls `stop()`/`start()` transitions on every processed block under sync/Randao/auctioneer-unset conditions, so the race window opens routinely in production operation, not just under adversarial control. Combined with a bidder flooding `auction_submitBid` calls (a publicly reachable RPC any auction participant can call) or peers relaying `HandleBid` gossip messages, the probability of hitting the narrow TOCTOU window is non-trivial over time, especially under load or during sync flapping.

### Recommendation
Protect the `running` check, the channel send, and the channel `close()` under a single mutex (or use a done-channel/context pattern instead of `close()` on a live producer channel), so that no send can be issued after (or concurrently with) the close. Alternatively, wrap the send in a `recover()`-guarded helper, or use a "closed" flag checked with the same lock used for closing, ensuring senders atomically observe closed state before attempting the send.

### Proof of Concept
1. Start a CN node with the auction module enabled and `running=1` (auctioneer/AuctionEntryPoint set, Randao enabled, not syncing).
2. From a separate goroutine/process, continuously call `auction_submitBid` RPC with a validly signed bid (or continuously call `HandleBid` via peer message injection).
3. Concurrently trigger repeated `PostInsertBlock` transitions that flip `running` 1→0→1 rapidly (e.g., toggle the `AuctionEntryPoint`/`Auctioneer` registry addresses each block, or force `Downloader.Synchronising()` to flap), causing `bp.stop()`/`bp.start()` to be invoked back-to-back.
4. Given enough iterations, the RPC-handling goroutine will observe `running==1` in `AddBid`/`HandleBid`, then attempt `bp.newBidCh <- bid` / `bp.bidMsgCh <- bid` after `stop()` has already executed `close(bp.newBidCh)`/`close(bp.bidMsgCh)` on another goroutine, producing the fatal runtime panic `send on closed channel` and crashing the node. func (bp *BidPool) start() {
	// Start the bid pool.
	// running will be set 1 once it's ready in the PostInsertBlock.

	// If channels are closed, recreate them
	if atomic.CompareAndSwapUint32(&bp.stopped, 1, 0) {
		bp.bidMsgCh = make(chan *auction.Bid, bidChSize)
		bp.newBidCh = make(chan *auction.Bid, bidChSize)
	}

	bp.wg.Add(2)
	go bp.handleBidMsg()
	go bp.handleNewBid()
}

func (bp *BidPool) stop() {
	// Stop the bid pool.
	atomic.CompareAndSwapUint32(&bp.running, 1, 0)
	bp.clearBidPool()

	// Only close channels if they haven't been closed before
	if atomic.CompareAndSwapUint32(&bp.stopped, 0, 1) {
		close(bp.bidMsgCh)
		close(bp.newBidCh)
	}
	bp.wg.Wait()
}

// AddBid adds a bid to the bid pool.
// Required mutex is locked in each function.
func (bp *BidPool) AddBid(bid *auction.Bid) (common.Hash, error) {
	if atomic.LoadUint32(&bp.running) == 0 {
		return common.Hash{}, auction.ErrAuctionPaused
	}

	if err := bp.validateBid(bid); err != nil {
		return common.Hash{}, err
	}

	if err := bp.insertBid(bid); err != nil {
		return common.Hash{}, err
	}

	gasLimit, err := bp.getBidTxGasLimit(bid)
	if err != nil {
		return common.Hash{}, err
	}
	bid.SetGasLimit(gasLimit)

	bp.newBidCh <- bid

	return bid.Hash(), nil
}

func (bp *BidPool) HandleBid(peerID string, bid *auction.Bid) {
	if atomic.LoadUint32(&bp.running) == 0 || bid == nil {
		return
	}

	// Check rate limit for this peer
	if !bp.checkRateLimit(peerID) {
		logger.Trace("Rate limit exceeded for peer", "peerID", peerID)
		return
	}

	select {
	case bp.bidMsgCh <- bid:
	default:
		logger.Trace("Bid queue is full, dropping bid", "peerID", peerID)
	}
}

func (a *AuctionModule) PostInsertBlock(block *types.Block) error {
	if a.Downloader.Synchronising() || !a.ChainConfig.IsRandaoForkEnabled(block.Number()) {
		atomic.CompareAndSwapUint32(&a.bidPool.running, 1, 0)
		return nil
	}

	if !a.updateAuctionInfo(block.Number()) {
		logger.Debug("stop auction since auctioneer or auction entry point is not set")
		atomic.CompareAndSwapUint32(&a.bidPool.running, 1, 0)
		return nil
	}

	atomic.CompareAndSwapUint32(&a.bidPool.running, 0, 1)

	txHashMap := make(map[common.Hash]struct{})
	for _, tx := range block.Transactions() {
		txHashMap[tx.Hash()] = struct{}{}
	}
	a.bidPool.removeOldBids(block.Number().Uint64(), txHashMap)

	return nil
}

func (api *AuctionAPI) SubmitBid(ctx context.Context, bidInput BidInput) RPCOutput {
	numBidRequestCounter.Inc(1)
	if api.a.IsDisabled() {
		return makeRPCOutput(EMPTY_HASH, auction.ErrAuctionDisabled)
	}

	//  1. directly send target transaction
	targetTx, errTxDecode := toTx(bidInput.TargetTxRaw)
	if errTxDecode != nil {
		return makeRPCOutput(EMPTY_HASH, errTxDecode)
	}
	if targetTx.Hash() != bidInput.TargetTxHash {
		return makeRPCOutput(EMPTY_HASH, auction.ErrInvalidTargetTxHash)
	}
	errTargetTxSend := api.a.Backend.SendTx(ctx, targetTx)
	// ignore known transaction related errors against target tx validation
	if errTargetTxSend != nil && !(strings.HasPrefix(errTargetTxSend.Error(), "known transaction:") || errors.Is(errTargetTxSend, gasless_impl.ErrUnableToAddKnownBundleTx)) {
		return makeRPCOutput(EMPTY_HASH, errTargetTxSend)
	}

	// 2. add bid
	bid := ToBid(bidInput)
	bidHash, errValidateBid := api.a.bidPool.AddBid(bid)
	return makeRPCOutput(bidHash, errValidateBid)
}
