### Title
Zero-Threshold `SecurityCouncil` Multisig Creates Anyone-Spendable Replacement Deposit Script — (`core/src/deposit.rs`)

---

### Summary

`SecurityCouncil::from_str` accepts `threshold = 0` without error. When this value flows into `Multisig::from_security_council` and then into `to_script_buf`, the resulting Bitcoin script uses `OP_NUMEQUAL 0`, which evaluates to `TRUE` with an all-empty witness — no security council signatures required. Any party can then spend the replacement deposit UTXO and steal the bridged BTC locked in it.

---

### Finding Description

`SecurityCouncil::from_str` in `core/src/deposit.rs` validates two conditions:

1. `pks.is_empty()` → error
2. `threshold > pks.len()` → error

It does **not** check `threshold >= 1`. [1](#0-0) 

A caller can therefore supply `"0:<pk1>,<pk2>"` and obtain a `SecurityCouncil { threshold: 0, pks: [pk1, pk2] }` that passes all validation.

`Multisig::from_security_council` copies the threshold verbatim: [2](#0-1) 

`Multisig::to_script_buf` then emits:

```
<pk1> OP_CHECKSIG
<pk2> OP_CHECKSIGADD
...
OP_0          ← threshold pushed as integer
OP_NUMEQUAL
``` [3](#0-2) 

With `threshold = 0`, every `OP_CHECKSIG` / `OP_CHECKSIGADD` call receives an empty-byte witness element, returns `0`, and the running accumulator stays `0`. `OP_NUMEQUAL 0` then evaluates to `TRUE`. The script is satisfied with a witness consisting entirely of empty byte vectors — no valid signature from any security council member is needed.

This script is embedded as a taproot leaf in `ReplacementDeposit` transactions: [4](#0-3) 

---

### Impact Explanation

A `ReplacementDeposit` is the mechanism used to rescue bridged BTC when a bug is found in the bridge. Its taproot address includes the security council multisig leaf precisely so that only the council can unlock it. With `threshold = 0`, that leaf is spendable by anyone who can construct a transaction spending the UTXO with an all-empty witness. The full bridge amount locked in the replacement deposit UTXO is at risk of theft.

---

### Likelihood Explanation

The `SecurityCouncil` is parsed from a string via `FromStr` / `serde::Deserialize`. It appears in both operator configuration (env vars) and in the gRPC deposit request path (the parser and aggregator modules both reference `security_council`). [5](#0-4) 

If the security council is part of the `Deposit` proto message that any caller of `new_deposit` can supply, the trigger is fully unprivileged. Even if it is operator-only, the missing lower-bound check means a single misconfiguration silently produces an anyone-spendable output with no runtime warning.

---

### Recommendation

Add a minimum-threshold guard in `SecurityCouncil::from_str` immediately after parsing the threshold value:

```rust
if threshold == 0 {
    return Err(eyre::eyre!("Threshold must be at least 1"));
}
```

Additionally, add the same check in any direct constructor path (`SecurityCouncil { threshold, pks }`) to prevent the invariant from being bypassed via struct literal construction.

---

1. Construct a `SecurityCouncil` string with threshold 0:

   ```
2. Parse it — `SecurityCouncil::from_str` returns `Ok(SecurityCouncil { threshold: 0, pks: [pk1, pk2] })`.
3. Call `Multisig::from_security_council(council).to_script_buf()`. The resulting script ends with `OP_0 OP_NUMEQUAL`.
4. This script is embedded as a taproot leaf in the replacement deposit address.
5. Spend the replacement deposit UTXO by providing a witness of `[b"", b""]` (one empty element per pubkey). Bitcoin script evaluates: CHECKSIG(empty) → 0, CHECKSIGADD(empty) → 0, NUMEQUAL(0, 0) → TRUE. The spend succeeds without any security council signature, draining the bridged BTC. [6](#0-5) [3](#0-2)

impl std::str::FromStr for SecurityCouncil {
    type Err = eyre::Report;

    fn from_str(s: &str) -> Result<Self, Self::Err> {
        let mut parts = s.split(':');
        let threshold_str = parts
            .next()
            .ok_or_else(|| eyre::eyre!("Missing threshold"))?;
        let pks_str = parts
            .next()
            .ok_or_else(|| eyre::eyre!("Missing public keys"))?;

        if parts.next().is_some() {
            return Err(eyre::eyre!("Too many parts in security council string"));
        }

        let threshold = threshold_str
            .parse::<u32>()
            .map_err(|e| eyre::eyre!("Invalid threshold: {}", e))?;

        let pks: Result<Vec<XOnlyPublicKey>, _> = pks_str
            .split(',')
            .map(|pk_str| {
                let bytes = hex::decode(pk_str)
                    .map_err(|e| eyre::eyre!("Invalid hex in public key: {}", e))?;
                XOnlyPublicKey::from_slice(&bytes)
                    .map_err(|e| eyre::eyre!("Invalid public key: {}", e))
            })
            .collect();

        let pks = pks?;

        if pks.is_empty() {
            return Err(eyre::eyre!("No public keys provided"));
        }

        if threshold > pks.len() as u32 {
            return Err(eyre::eyre!(
                "Threshold cannot be greater than number of public keys"
            ));
        }

        Ok(SecurityCouncil { pks, threshold })
    }

    fn to_script_buf(&self) -> ScriptBuf {
        let mut script_builder = Builder::new()
            .push_x_only_key(&self.pubkeys[0])
            .push_opcode(OP_CHECKSIG);
        for pubkey in self.pubkeys.iter().skip(1) {
            script_builder = script_builder.push_x_only_key(pubkey);
            script_builder = script_builder.push_opcode(OP_CHECKSIGADD);
        }
        script_builder = script_builder.push_int(self.threshold as i64);
        script_builder = script_builder.push_opcode(OP_NUMEQUAL);
        script_builder.into_script()
    }
