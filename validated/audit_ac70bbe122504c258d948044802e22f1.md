### Title
Missing validation that a token added to the gasless allowlist actually pairs with the configured GaslessSwapRouter's DEX - ([File: kaiax/gasless/impl/getter.go])

### Summary
The `GaslessSwapRouter` contract's `addToken(token, factory, router)` (an owner-privileged setter, mirrored in `contracts/bindings/kip247/GaslessSwapRouter.go:470-489`) associates an arbitrary `token` address with an arbitrary `factory`/`router` pair with no on-chain check that a real liquidity pair actually exists between `token` and the router's base asset. This is the same bug class as the Sherlock report: `Dispatcher.add()` stores `_token0`/`_token1` for a `_multipool` with no validation that those tokens match the multipool's actual underlying pair.

### Finding Description
The kaiax gasless module trusts the `GaslessSwapRouter` registry contract state (`swapRouter`, `allowedTokens`) that it reads via `updateAddresses`/`GetSupportedTokens`/`GetDEXInfo` and caches into `g.allowedTokens` (`kaiax/gasless/impl/init.go:44-72`, `kaiax/gasless/impl/getter.go:69-103`). A gasless swap transaction is accepted as valid purely because:
- `IsApproveTx` checks that `args.Token` is in `g.allowedTokens` and the spender is `g.swapRouter` [1](#0-0) 
- `IsSwapTx`/`VerifyExecutable` checks that `args.Router == g.swapRouter` and `args.Token` is in `g.allowedTokens`, then computes the required repay amount, without independently verifying that `token` actually has liquidity/a valid pair on-chain matching the router's expectations [2](#0-1) [3](#0-2) 

Because `allowedTokens`/`swapRouter` membership is entirely determined by whatever the owner of `GaslessSwapRouter` recorded via `addToken`, an incorrectly (or maliciously) registered token/factory/router triple — exactly the missing-validation pattern flagged in the Dispatcher report — flows straight into the node's gasless tx-pool/execution admission logic (`kaiax/gasless/impl/tx_pool.go`, `execution.go:26-32`) with no independent sanity check performed by the kaia node itself.

### Impact Explanation
If `addToken` is called (whether by mistake or by a compromised/malicious owner key) with a `token` that isn't actually paired with the recorded `factory`/`router`, any unprivileged user can submit `approve`+`swapForGas` transactions that the node classifies as legitimate "gasless" transactions and fee-delegate/prioritize accordingly, while the underlying DEX call may revert, behave unexpectedly, or be exploited to drain the router/lender's advanced gas funds since `VerifyExecutable`'s repay-amount check (`SP4`, `kaiax/gasless/impl/getter.go:260-263`) relies on assumptions about the swap that are invalid for a mismatched pair.

### Likelihood Explanation
Low-to-medium: it requires the `GaslessSwapRouter` owner to add a bad token entry (an admin action), but once done, every subsequent unprivileged transaction sender can trigger the flawed path without any special privilege, matching the original report's threat model (unprivileged sender exploiting an admin's unvalidated registration).

### Recommendation
Before trusting a `token` returned from `GaslessSwapRouter.getDEXInfo`/`getSupportedTokens`, the kaiax gasless module (or the `GaslessSwapRouter` contract itself in `addToken`) should verify on-chain that a genuine liquidity pair exists between `token` and the router's base asset (e.g., via `factory.getPair(token, WKAIA) != address(0)`), analogous to validating `_token0`/`_token1` against the multipool's actual pair in the original Dispatcher finding.

### Proof of Concept
1. `GaslessSwapRouter` owner calls `addToken(maliciousToken, factory, router)` where `maliciousToken` has no real pair with the router's base asset (bindings: `contracts/bindings/kip247/GaslessSwapRouter.go:470-475`).
2. The node's `updateAddresses` picks this up into `g.allowedTokens[maliciousToken] = true` (`kaiax/gasless/impl/init.go`, `getter.go`).
3. An unprivileged sender submits `approve(router, MaxUint)` on `maliciousToken` followed by `swapForGas(maliciousToken, amountIn, minAmountOut, amountRepay, deadline)`.
4. `IsApproveTx`/`IsSwapTx`/`VerifyExecutable` all pass because they only check allowlist membership and internal argument consistency, not real pair existence [3](#0-2) , letting the malformed gasless bundle be processed/fee-delegated by the node.

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}
