### Title
Use of `.transfer()` for ETH refunds in the canonical WSEI contract permanently freezes funds for contract-based recipients - (File: `contracts/src/WSEI.sol`)

### Summary
The canonical `WSEI` (Wrapped Sei) contract shipped and deployable via the sei-chain EVM tooling uses the low-level `.transfer()` opcode to return native SEI/wei to callers in `withdraw()`. Because `.transfer()` hard-caps the forwarded gas at 2300, any caller whose address is a smart contract (multisig, proxy, or any contract with non-trivial `receive`/`fallback` logic) will have its `withdraw()` call permanently revert, freezing the wrapped balance it deposited.

### Finding Description
`contracts/src/WSEI.sol` implements the wrapped-native-token pattern (`deposit`/`withdraw`), and its `withdraw` function sends the native SEI refund with the `.transfer()` opcode: [1](#0-0) 

This is the exact bug class from the external report: `.transfer()` forwards a fixed 2300 gas stipend to the recipient's `receive`/`fallback`. If `msg.sender` is a contract (e.g., a Safe, a vault, or any contract executing bookkeeping logic on receipt of value) that requires more than 2300 gas in its `receive`/`fallback`, the transfer will always revert with an out-of-gas error, and `withdraw()` can never succeed for that address.

This is not a test-only artifact — `WSEI.sol` is compiled and embedded as the canonical WSEI bytecode/ABI in `x/evm/artifacts/wsei/artifacts.go` (loading `WSEI.bin`/`WSEI.abi`), and is directly deployable by any unprivileged EVM transaction sender via the CLI command: [2](#0-1) 

Any account (EOA or contract) can call `deposit()` (or send value directly, since `receive`/`fallback` both call `deposit`) to lock native SEI as WSEI balance, then call `withdraw()` to unwrap it. If the caller is a contract without a bare/cheap fallback, the unwrap path is permanently blocked with no alternative recovery mechanism in the contract (no `call`-based withdrawal, no admin rescue function).

### Impact Explanation
Any contract-based holder of WSEI (a common ERC-20-like wrapped asset used across DeFi integrations on Sei) that deposits native SEI can have their funds permanently frozen inside the WSEI contract once they attempt to withdraw, since there is no other function in the contract to redeem the underlying balance for value. This constitutes a permanent freezing of funds for a broad, unprivileged class of users (any smart-contract wallet, vault, or integrating protocol contract with a non-trivial `receive`/`fallback`).

### Likelihood Explanation
Likelihood is at least Medium: it triggers deterministically and permanently whenever the caller of `withdraw()` is a contract requiring >2300 gas in its `receive`/`fallback` — a common pattern for multisigs (e.g., Safe with guards/modules) and protocol contracts that update accounting state on receiving native value. No attacker action or race condition is needed; it's a functional dead-end reachable by ordinary interaction with the canonical WSEI contract.

### Recommendation
Replace `payable(msg.sender).transfer(wad)` in `WSEI.withdraw` with a low-level `.call{value: wad}("")` and check the boolean return value, reverting on failure. Add reentrancy protection (checks-effects-interactions is already followed here since balance is decremented before the external call, but a nonReentrant guard is still recommended for defense in depth) before regenerating/redeploying the canonical WSEI artifact bytecode used by `x/evm/artifacts/wsei`.

### Proof of Concept
1. Deploy a simple contract `Locker` whose `receive() external payable` performs any operation costing more than 2300 gas (e.g., writes to a storage slot).
2. From `Locker`, call `deposit()` on the canonical `WSEI` contract (deployed via `CmdDeployWSEI`) with some native SEI value, or send value directly (triggers `receive` → `deposit`).
3. From `Locker`, call `WSEI.withdraw(wad)` for the deposited amount.
4. Observe the transaction reverts every time due to out-of-gas in `Locker.receive()`, because `.transfer()` only forwards 2300 gas — `Locker`'s WSEI balance is now permanently unwithdrawable through the contract's only exit path. [3](#0-2) [4](#0-3)

pragma solidity ^0.8.0;

contract WSEI {
    string public name     = "Wrapped Sei";
    string public symbol   = "WSEI";
    uint8  public decimals = 18;

    event  Approval(address indexed src, address indexed guy, uint wad);
    event  Transfer(address indexed src, address indexed dst, uint wad);
    event  Deposit(address indexed dst, uint wad);
    event  Withdrawal(address indexed src, uint wad);

    mapping (address => uint)                       public  balanceOf;
    mapping (address => mapping (address => uint))  public  allowance;

    fallback() external payable {
        deposit();
    }
    receive() external payable {
        deposit();
    }
    function deposit() public payable {
        balanceOf[msg.sender] += msg.value;
        emit Deposit(msg.sender, msg.value);
    }
    function withdraw(uint wad) public {
        require(balanceOf[msg.sender] >= wad);
        balanceOf[msg.sender] -= wad;
        payable(msg.sender).transfer(wad);
        emit Withdrawal(msg.sender, wad);
    }

    function totalSupply() public view returns (uint) {
        return address(this).balance;
    }

    function approve(address guy, uint wad) public returns (bool) {
        allowance[msg.sender][guy] = wad;
        emit Approval(msg.sender, guy, wad);
        return true;
    }

    function transfer(address dst, uint wad) public returns (bool) {
        return transferFrom(msg.sender, dst, wad);
    }

    function transferFrom(address src, address dst, uint wad)
        public
        returns (bool)
    {
        require(balanceOf[src] >= wad);

        if (src != msg.sender && allowance[src][msg.sender] != type(uint).max) {
            require(allowance[src][msg.sender] >= wad);
            allowance[src][msg.sender] -= wad;
        }

        balanceOf[src] -= wad;
        balanceOf[dst] += wad;

        emit Transfer(src, dst, wad);

        return true;
    }
}

package wsei

import (
	"embed"
	"encoding/hex"
	"strings"

	"github.com/ethereum/go-ethereum/accounts/abi"
)

const CurrentVersion uint16 = 1

//go:embed WSEI.abi
//go:embed WSEI.bin
var f embed.FS

var cachedBin []byte
var cachedABI *abi.ABI

func GetABI() []byte {
	bz, err := f.ReadFile("WSEI.abi")
	if err != nil {
		panic("failed to read WSEI contract ABI")
	}
	return bz
}

func GetParsedABI() *abi.ABI {
	if cachedABI != nil {
		return cachedABI
	}
	parsedABI, err := abi.JSON(strings.NewReader(string(GetABI())))
	if err != nil {
		panic(err)
	}
	cachedABI = &parsedABI
	return cachedABI
}

func GetBin() []byte {
	if cachedBin != nil {
		return cachedBin
	}
	code, err := f.ReadFile("WSEI.bin")
	if err != nil {
		panic("failed to read WSEI contract binary")
	}
	bz, err := hex.DecodeString(string(code))
	if err != nil {
		panic("failed to decode WSEI contract binary")
	}
	cachedBin = bz
	return bz
}
