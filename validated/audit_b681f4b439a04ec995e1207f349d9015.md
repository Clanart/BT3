Found it: `dispatchIncoming(GetResponse, address)` in `EvmHost.sol` handles an incoming GET response by setting `_responseReceipts[commitment]` and paying out the relayer fee from `_requestCommitments[commitment].fee`, but it **never deletes `_requestCommitments[commitment]`** after successfully processing the response. [1](#0-0) 

### Title
GET response processing leaves `_requestCommitments` intact, allowing a later timeout to double-refund/double-dispatch on the same GET request - (File: evm/src/core/EvmHost.sol)

### Summary
`dispatchIncoming(GetResponse, address)` stores the response receipt and pays the relayer fee but does not clear `_requestCommitments[commitment]`. `HandlerV2.handleGetRequestTimeouts` only checks a *remote* non-membership proof of the response receipt on the destination chain's state trie at a caller-supplied historical height — it never re-checks the local `_responseReceipts` mapping on the EVM host itself before calling `host.dispatchTimeOut(...)`. [2](#0-1) [3](#0-2) 

### Finding Description
This mirrors the reported bug class: two mutually-exclusive outcomes ("response processed" vs. "timed out") are documented/expected to never both succeed for the same request, but the code path lacks an explicit local check enforcing that invariant. On the Substrate/pallet-ismp side, the equivalent GET timeout handler explicitly guards against this: `if host.response_receipt(&response).is_some() { Err(Error::GetResponseAlreadyReceived ...) }` in `modules/ismp/core/src/handlers/timeout.rs`, confirmed by the test `get_response_already_received_check` in `modules/ismp/testsuite/src/lib.rs`. [4](#0-3) [5](#0-4) 

On the EVM side no such local guard exists. `handleGetRequestTimeouts` fetches `FeeMetadata memory meta = host.requestCommitments(commitment)` (which is still populated because `dispatchIncoming` for `GetResponse` never deletes it) and verifies only a non-membership proof of `RESPONSE_RECEIPTS_STORAGE_PREFIX` against a *remote* state commitment at an arbitrary height chosen by the caller (any previously stored, valid `StateCommitment` for that state machine, which could predate the actual response inclusion on the remote chain). Since the proof target is a historical remote root rather than the local `_responseReceipts` mapping that `dispatchIncoming` already populated, a relayer can present a valid non-membership proof from a height *before* the response was recorded on the destination chain, even though the GET response has since been fully processed locally on this EVM host (`onGetResponse` invoked and relayer fee already paid out). [6](#0-5) 

`dispatchTimeOut` for `GetRequestTimeout` then unconditionally deletes `_requestCommitments[commitment]` and calls `onGetTimeout` on the source module, refunding `meta.fee` to `meta.sender` a second time. [3](#0-2) 

Since `meta.fee` was already paid out to the relayer in `dispatchIncoming` and `_requestCommitments[commitment]` was never cleared, this second call pays the fee a second time to `meta.sender`, and additionally fires `onGetTimeout` on a module that already received `onGetResponse` for the same request — violating the "response and timeout must never both fire" invariant and causing loss of protocol funds (double fee payout) plus inconsistent application state (module sees both a successful response and a timeout for the same commitment).

### Impact Explanation
This is a direct fund-loss / double-settlement bug reachable by any permissionless caller of `handleGetRequestTimeouts` (marked permissionless in the docs), causing the `IHost` fee token balance to be drained via a duplicate refund, and application modules to receive contradictory callbacks (`onGetResponse` then `onGetTimeout`) for the same commitment — matching the bounty's "stealing or loss of funds" and "logic attacks / double-claim" categories. [7](#0-6) 

### Likelihood Explanation
Likelihood depends on whether a stale/older valid `StateCommitment` height for the destination state machine (one preceding the response's actual inclusion) remains queryable via `host.stateMachineCommitment(message.height)` after the response has already been delivered to the EVM host — if any earlier finalized height with a non-membership proof is still accepted (nothing in `handleGetRequestTimeouts` requires the height to be the *latest*), this is straightforwardly triggerable by any relayer holding an old proof, without needing a malicious node, prover, or admin.

### Recommendation
Add a local guard in `EvmHost.dispatchTimeOut(GetRequestTimeout, ...)` (or in `HandlerV2.handleGetRequestTimeouts`) that reverts if `_responseReceipts[commitment]` is already populated, mirroring pallet-ismp's `GetResponseAlreadyReceived` check, and ensure `dispatchIncoming(GetResponse, ...)` deletes `_requestCommitments[commitment]` upon successful processing so a stale/older non-membership proof cannot be replayed to trigger a duplicate timeout payout.

### Proof of Concept
1. Attacker/relayer dispatches a GET request from a source app on `EvmHost`; `_requestCommitments[commitment]` is stored with `fee = F`, `sender = payer`.
2. A relayer submits a valid `GetResponseMessage` via `handleGetResponses` → `EvmHost.dispatchIncoming(GetResponse,...)`: sets `_responseReceipts[commitment]`, calls `onGetResponse` successfully, pays fee `F` to relayer. `_requestCommitments[commitment]` is left unchanged (not deleted). [1](#0-0) 
3. The same (or another) relayer later submits `GetTimeoutMessage` via `handleGetRequestTimeouts`, using a non-membership proof against an earlier `StateCommitment` height for the destination chain at which the response had not yet been included there — that proof verifies successfully since it targets a stale height. [8](#0-7) 
4. `host.dispatchTimeOut(GetRequestTimeout, meta, commitment)` executes: deletes `_requestCommitments[commitment]`, calls `onGetTimeout` on the module (which already got `onGetResponse`), and refunds `meta.fee = F` to `meta.sender` again — a duplicate payout of `F`. [3](#0-2)

    function dispatchIncoming(GetResponse memory response, address relayer) external restrict(_hostParams.handler) {
        // replay protection
        bytes32 commitment = response.request.hash();
        _responseReceipts[commitment] = ResponseReceipt({
            relayer: relayer,
            responseCommitment: response.hash()
        });

        (bool success,) = _bytesToAddress(response.request.from)
            .call(abi.encodeWithSelector(IApp.onGetResponse.selector, IncomingGetResponse(response, relayer)));

        if (!success) {
            // so that it can be retried
            delete _responseReceipts[commitment];
            return;
        }

        // reward the relayer fee
        uint256 fee = _requestCommitments[commitment].fee;
        if (fee != 0) {
            IERC20(feeToken()).safeTransfer(relayer, fee);
        }
        emit GetRequestHandled({commitment: commitment, relayer: relayer});
    }

    function dispatchTimeOut(
        GetRequestTimeout memory timeout,
        FeeMetadata memory meta,
        bytes32 commitment
    ) external restrict(_hostParams.handler) {
        // replay protection
        delete _requestCommitments[commitment];
        (bool success,) = _bytesToAddress(timeout.request.from)
            .call(abi.encodeWithSelector(IApp.onGetTimeout.selector, timeout));

        if (!success) {
            // so that it can be retried
            _requestCommitments[commitment] = meta;
            return;
        }

        if (meta.fee != 0) {
            // refund relayer fee
            IERC20(feeToken()).safeTransfer(meta.sender, meta.fee);
        }
        emit GetRequestTimeoutHandled({commitment: commitment, dest: string(timeout.request.dest)});
    }

    function handleGetRequestTimeouts(IHost host, GetTimeoutMessage calldata message) external notFrozen(host) {
        uint256 delay = block.timestamp - host.stateMachineCommitmentUpdateTime(message.height);
        uint256 challengePeriod = host.challengePeriod();
        if (challengePeriod != 0 && challengePeriod > delay) revert ChallengePeriodNotElapsed();

        // fetch the state commitment
        StateCommitment memory state = host.stateMachineCommitment(message.height);
        if (state.stateRoot == bytes32(0)) revert StateCommitmentNotFound();
        uint256 timeoutsLength = message.timeouts.length;

        for (uint256 i = 0; i < timeoutsLength; ++i) {
            GetRequest memory request = message.timeouts[i];
            // timed-out?
            if (request.timeout() > state.timestamp) revert MessageNotTimedOut();

            bytes32 commitment = request.hash();
            FeeMetadata memory meta = host.requestCommitments(commitment);
            if (meta.sender == address(0)) revert UnknownMessage();

            bytes[] memory keys = new bytes[](1);
            keys[0] = bytes.concat(RESPONSE_RECEIPTS_STORAGE_PREFIX, commitment);

            // verify state trie non-membership proofs
            PolkadotTrie.StorageValue memory entry = PolkadotTrie.VerifyProof(state.stateRoot, message.proof, keys)[0];
            if (entry.value.length != 0) revert InvalidProof();

            host.dispatchTimeOut(GetRequestTimeout(request, _msgSender()), meta, commitment);
        }
    }

/// Reject a GET timeout when the request has already received a response. The request's timeout
/// hasn't elapsed either, so without the response-receipt guard the handler would have failed
/// with `RequestTimeoutNotElapsed` — proving the response check runs first.
pub fn get_response_already_received_check<H>(host: &H) -> Result<(), &'static str>
where
	H: IsmpHost + IsmpDispatcher,
	H::Account: From<[u8; 32]>,
	H::Balance: From<u32> + Default,
{
	let intermediate_state = setup_mock_client(host);
	let get =
		dispatch_get_request(host, &intermediate_state, host.timestamp().as_secs() + 1_000_000);

	let response = GetResponse { get: get.clone(), values: Default::default() };
	host.store_response_receipt(&response, &vec![0u8; 32]).unwrap();

	let timeout_message = Message::Timeout(TimeoutMessage::Get { requests: vec![get] });

	let res = handle_incoming_message(host, timeout_message).map_err(|e| e.downcast().unwrap());
	assert!(matches!(res, Err(Error::GetResponseAlreadyReceived { .. })));
	Ok(())
}
