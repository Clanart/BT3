### Title
Unbounded on-chain pagination loop in the CW721→ERC721 pointer's `balanceOf()` lets a routine, non-malicious admin/minter action on the wrapped CosmWasm NFT contract permanently break gas-bound callers of the pointer - ([File: contracts/src/CW721ERC721Pointer.sol])

### Summary
The Zivoe report's root cause is that a "RESTRICTED" third-party admin can take a normal, non-malicious administrative action (adding reward tokens) that grows an array the protocol is *forced* to fully iterate as a prerequisite to a core operation, and once that iteration's gas cost exceeds what the caller can supply, the operation becomes permanently unreachable. The Sei analog is the `balanceOf()` implementation of the `CW721ERC721Pointer` contract, which is forced to paginate through the *entire* list of tokens the CosmWasm NFT contract's owner holds via repeated CosmWasm queries, with no cap on how many pages it may need to traverse.

### Finding Description
`CW721ERC721Pointer.balanceOf()` implements ERC721 `balanceOf` by repeatedly querying the wrapped CW721 contract's `tokens` endpoint in pages of 1000 and looping until an empty-page terminator is returned: [1](#0-0) 

```solidity

    ...
    string memory qb = ...limit":1000,"owner":...
    bytes32 terminator = keccak256("{\"tokens\":[]}");
    bytes[] memory tokens;
    ...
    bytes memory response = WasmdPrecompile.query(Cw721Address, bytes(req));
    while (keccak256(response) != terminator) {
        tokens = JsonPrecompile.extractAsBytesList(response, "tokens");
        ...
        startAfter = ...;
        req = ...;
        response = WasmdPrecompile.query(Cw721Address, bytes(req));
    }
    return numTokens;

```

The number of loop iterations is entirely controlled by the CosmWasm NFT contract's admin/minter — an entity the pointer/bridge integrates with and that is RESTRICTED per the same rationale used in the Zivoe report (Convex's `rewardManager` admin). Minting a large number of NFTs to a single owner (a completely ordinary, expected admin/minter action — no different than Convex's admin adding a reward token) causes `balanceOf()`'s required number of `WasmdPrecompile.query` round-trips (and associated JSON parsing) to grow linearly and unboundedly with that owner's token count.

Unlike the pure "eth_call read-only" case, `balanceOf()` is a standard ERC721 interface method that other on-chain contracts (lending/marketplace/aggregator contracts built on top of the pointer, or any contract composing with `CW721ERC721Pointer` inside a state-changing transaction) are expected to call from within gas-metered execution. Once the number of tokens held by an owner grows large enough that the full pagination loop's gas cost exceeds the block gas limit, `balanceOf()` for that owner can never complete inside any transaction — regardless of how much gas the caller supplies — exactly mirroring the Convex `extraRewards` scenario where `claimRewards()` becomes uncompletable once the admin appends enough entries.

### Impact Explanation
Any on-chain contract that must call `balanceOf()` on this pointer as part of a state-changing operation (e.g. a lending protocol checking collateral, a marketplace verifying holdings, or any composing contract relying on the ERC721 interface) becomes permanently unable to complete that operation once the wrapped CW721 owner's holdings grow past the gas-affordable pagination threshold. This is a permanent freezing of functionality/funds for any protocol built on top of the pointer for that owner, triggered purely by ordinary CW721 minter activity rather than malice — the same "restricted but not malicious, still harmful" pattern accepted as valid Medium in the referenced Zivoe judging (`escalate`d and accepted by `WangSecurity`/`Evert0x`).

### Likelihood Explanation
The CW721 contract's minter is explicitly a RESTRICTED external admin under the same reasoning applied in the Zivoe report to Convex. No attacker action is required beyond the minter performing routine minting to a single owner (or an owner naturally accumulating enough NFTs through normal transfers) — this can happen without any intent to harm the protocol, exactly as `panprog`/`WangSecurity` accepted for "an external admin's actions leading to harm" even when the actions are "normal" and irreversible once triggered.

### Recommendation
Do not implement `balanceOf()` (and any other pointer function that must fully enumerate CW721 holdings) via unbounded server-side pagination inside gas-metered EVM execution. Either cap the number of pages traversed and revert/return a sentinel beyond the cap, track balances incrementally in pointer contract storage (updated on each mint/transfer event) rather than recomputing from a live paginated query, or explicitly document/gas-limit this as an off-chain/view-only operation not suitable for composition within other transactions.

### Proof of Concept
1. Deploy a `CW721ERC721Pointer` for a CosmWasm NFT contract via the pointer precompile's `AddCW721`.
2. As the CW721 contract's minter/admin, mint a very large number of NFTs (e.g., hundreds of thousands) to a single owner address — an entirely permitted, non-malicious minter action.
3. Have another contract call `CW721ERC721Pointer.balanceOf(owner)` from within a state-changing transaction (or attempt to call it with any realistic gas limit).
4. Observe that the call requires `ceil(tokenCount / 1000)` sequential `WasmdPrecompile.query` + JSON-extraction round trips; once `tokenCount` is large enough, the cumulative gas required exceeds the block gas limit, and the call can never succeed regardless of gas supplied, permanently breaking any on-chain consumer of `balanceOf()` for that owner.

    function balanceOf(address owner_) public view override returns (uint256) {
        if (owner_ == address(0)) {
            revert ERC721InvalidOwner(address(0));
        }
        uint256 numTokens = 0;
        string memory startAfter;
        string memory qb = string.concat(
            string.concat("\"limit\":1000,\"owner\":\"", AddrPrecompile.getSeiAddr(owner_)),
            "\""
        );
        bytes32 terminator = keccak256("{\"tokens\":[]}");

        bytes[] memory tokens;
        uint256 tokensLength;
        string memory req = string.concat(string.concat("{\"tokens\":{", qb), "}}");
        bytes memory response = WasmdPrecompile.query(Cw721Address, bytes(req));
        while (keccak256(response) != terminator) {
            tokens = JsonPrecompile.extractAsBytesList(response, "tokens");
            tokensLength = tokens.length;
            numTokens += tokensLength;
            startAfter = string.concat(",\"start_after\":", string(tokens[tokensLength-1]));
            req = string.concat(
                string.concat("{\"tokens\":{", string.concat(qb, startAfter)),
                "}}"
            );
            response = WasmdPrecompile.query(Cw721Address, bytes(req));
        }
        return numTokens;
    }
