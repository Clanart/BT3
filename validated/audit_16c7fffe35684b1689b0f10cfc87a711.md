### Title
Permissionless `RegisterPointer` Trusts Unverified/Arbitrary ERC Addresses as Canonical CW Tokens - (File: x/evm/keeper/msg_server.go)

### Summary
The external report flags that `PoolManager.sol` blindly trusts a transient, unverified `FuseAdminProxy` contract to deploy and control derived tokens, and recommends that dependent logic only ever call into verified, trusted contracts. The Sei analog is `msgServer.RegisterPointer`, reachable by any unprivileged EVM/Cosmos transaction sender, which instantiates an officially-labeled CW20/721/1155 "pointer" wrapper around an arbitrary, attacker-supplied `ErcAddress` without ever verifying that address holds real, non-malicious contract code implementing the expected ERC interface.

### Finding Description
`MsgRegisterPointer.ValidateBasic` only checks that `ErcAddress` is a syntactically valid hex address [1](#0-0) . The message handler `RegisterPointer` then takes this fully unverified address, embeds it in a CW instantiate payload (`erc20_address`/`erc721_address`/`erc1155_address`), and instantiates it with the module account as both admin and creator, giving it a trust-inspiring label `"Pointer of %s"`: [2](#0-1) 

There is no check that `ErcAddress` has any code deployed (`evm.StateDB.GetCodeSize`), that it implements the ERC20/721/1155 interface it is being registered for, or that its logic is safe/non-malicious — the only defensive check that exists is `evmAddressIsPointer`, which merely prevents chaining pointer-of-pointer registrations [3](#0-2) .

Once registered, this pointer contract becomes a chain-recognized bridge: any CosmWasm caller that wants to move the underlying "ERC" balance must go through `MsgInternalEVMDelegateCall`, which is authorized purely by checking that the calling contract is *the* registered pointer for that target address — not that the target address itself is a legitimate, safe contract: [4](#0-3) 

Because `RegisterPointer` is fully permissionless (guarded only by a global `RegisterPointerDisabled` param, not per-address vetting) [5](#0-4) , an attacker can register a pointer for any address they control, including one containing arbitrary/malicious EVM bytecode (fake `balanceOf`/`transfer` responses, reentrant callbacks, or logic that changes behavior over time), and the resulting CW wrapper carries the same on-chain legitimacy markers (event `pointer_registered`, `"Pointer of %s"` label, standard query interface) as pointers for genuine, audited tokens.

### Impact Explanation
Any Cosmos-side integrator (DEX, lending market, IBC-enabled contract) that treats a registered pointer as a trustworthy CW20/721/1155 token — which is the entire purpose of the pointer registry — has no way to distinguish a pointer backed by a real, audited ERC20 from one backed by attacker-controlled, ever-changeable EVM bytecode. This mirrors the report's exact risk: dependent logic makes calls into a contract whose implementation is not verified and can behave maliciously at the operator's discretion, enabling unauthorized transfers or fake balance/allowance reporting that leads to fund loss for counterparties who trust the pointer's reported state.

### Likelihood Explanation
The path is trivially reachable by any unprivileged account: submit `MsgRegisterPointer` with `PointerType_ERC20/721/1155` and any hex address (no code check, no interface check). No special privilege, governance action, or validator collusion is required — only the `RegisterPointerDisabled` param must be false, which is the default operating mode.

### Recommendation
Before instantiating a pointer, verify that `ErcAddress` has deployed code and correctly implements the expected ERC interface (e.g., static-call `balanceOf`/`ownerOf`/`totalSupply` and validate return shapes, or require an allow-list/governance-gated registration for pointer targets), so that the "Pointer of %s" designation cannot be granted to arbitrary or transient/malicious bytecode.

### Proof of Concept
1. Attacker deploys an EVM contract at address `X` that implements `balanceOf`/`transfer` with arbitrary (fabricated) return values, or with logic that can be swapped by the attacker later (e.g., via `SELFDESTRUCT` + `CREATE2` redeploy, or delegatecall-based upgradeability under attacker control).
2. Attacker submits `MsgRegisterPointer{PointerType: ERC20, ErcAddress: X}` from any unprivileged account — this succeeds because `ValidateBasic` only checks hex format [1](#0-0)  and `RegisterPointer` performs no code/interface verification [6](#0-5) .
3. The chain instantiates and labels a CW pointer contract "Pointer of X", registers it in the pointer registry, and emits the standard `pointer_registered` event, making it indistinguishable on-chain from a pointer to a genuine, verified ERC20.
4. Any third-party CW contract or user that discovers this pointer via the registry and treats it as a legitimate token can be deceived by fabricated balances or have transfers manipulated through the underlying malicious/upgradeable bytecode at `X`.

func (server msgServer) RegisterPointer(goCtx context.Context, msg *types.MsgRegisterPointer) (*types.MsgRegisterPointerResponse, error) {
	ctx := sdk.UnwrapSDKContext(goCtx)
	if server.GetRegisterPointerDisabled(ctx) {
		return nil, fmt.Errorf("registering CW->ERC pointers has been disabled")
	}
	var existingPointer sdk.AccAddress
	var existingVersion uint16
	var currentVersion uint16
	var exists bool
	switch msg.PointerType {
	case types.PointerType_ERC20:
		currentVersion = erc20.CurrentVersion
		existingPointer, existingVersion, exists = server.GetCW20ERC20Pointer(ctx, common.HexToAddress(msg.ErcAddress))
	case types.PointerType_ERC721:
		currentVersion = erc721.CurrentVersion
		existingPointer, existingVersion, exists = server.GetCW721ERC721Pointer(ctx, common.HexToAddress(msg.ErcAddress))
	case types.PointerType_ERC1155:
		currentVersion = erc1155.CurrentVersion
		existingPointer, existingVersion, exists = server.GetCW1155ERC1155Pointer(ctx, common.HexToAddress(msg.ErcAddress))
	default:
		panic("unknown pointer type")
	}
	if exists && existingVersion >= currentVersion {
		return nil, fmt.Errorf("pointer %s already registered at version %d", existingPointer.String(), existingVersion)
	}
	payload := map[string]interface{}{}
	switch msg.PointerType {
	case types.PointerType_ERC20:
		payload["erc20_address"] = msg.ErcAddress
	case types.PointerType_ERC721:
		payload["erc721_address"] = msg.ErcAddress
	case types.PointerType_ERC1155:
		payload["erc1155_address"] = msg.ErcAddress
	default:
		panic("unknown pointer type")
	}
	codeID := server.GetStoredPointerCodeID(ctx, msg.PointerType)
	moduleAcct := server.accountKeeper.GetModuleAddress(types.ModuleName)
	var err error
	var pointerAddr sdk.AccAddress
	if exists {
		bz, _ := json.Marshal(map[string]interface{}{})
		pointerAddr = existingPointer
		_, err = server.wasmKeeper.Migrate(ctx, existingPointer, moduleAcct, codeID, bz)
	} else {
		bz, jerr := json.Marshal(payload)
		if jerr != nil {
			return nil, jerr
		}
		pointerAddr, _, err = server.wasmKeeper.Instantiate(ctx, codeID, moduleAcct, moduleAcct, bz, fmt.Sprintf("Pointer of %s", msg.ErcAddress), sdk.NewCoins())
	}

// CW20 -> ERC20
func (k *Keeper) SetCW20ERC20PointerWithVersion(ctx sdk.Context, erc20Address common.Address, addr string, version uint16) error {
	if k.evmAddressIsPointer(ctx, erc20Address) {
		return ErrorPointerToPointerNotAllowed
	}
	err := k.setPointerInfo(ctx, types.PointerCW20ERC20Key(erc20Address), []byte(addr), version)
	if err != nil {
		return err
	}
	return k.setPointerInfo(ctx, types.PointerReverseRegistryKey(common.BytesToAddress([]byte(addr))), erc20Address[:], version)
}

func (k *Keeper) HandleInternalEVMDelegateCall(ctx sdk.Context, req *types.MsgInternalEVMDelegateCall) (*sdk.Result, error) {
	var to *common.Address
	if req.To != "" {
		addr := common.HexToAddress(req.To)
		to = &addr
	} else {
		return nil, errors.New("cannot use a CosmWasm contract to delegate-create an EVM contract")
	}
	addr, _, exists := k.GetAnyPointerInfo(ctx, types.PointerReverseRegistryKey(common.BytesToAddress([]byte(req.FromContract))))
	if !exists || common.BytesToAddress(addr).Cmp(*to) != 0 {
		return nil, errors.New("only pointer contract can make delegatecalls")
	}
	zeroInt := sdk.ZeroInt()
	senderAddr, err := sdk.AccAddressFromBech32(req.Sender)
	if err != nil {
		return nil, err
	}
	// delegatecall caller must be associated; otherwise any state change on EVM contract will be lost
	// after they asssociate.
	senderEvmAddr, found := k.GetEVMAddress(ctx, senderAddr)
	if !found {
		err := types.NewAssociationMissingErr(req.Sender)
		evmKeeperMetrics.associationError.Add(ctx.Context(), 1, otelmetric.WithAttributes(attribute.String("scenario", "evm_handle_internal_evm_delegate_call"), attribute.String("type", err.AddressType())))
		return nil, err
	}
	ret, err := k.CallEVM(ctx, senderEvmAddr, to, &zeroInt, req.Data)
	if err != nil {
		return nil, err
	}
	return &sdk.Result{Data: ret}, nil
}
