Audit Report

## Title
Stale vote/stake accounts remain in Bank's `StakesCache` after owner reassignment, allowing forged data to inherit prior stake weight - (File: runtime/src/stakes.rs)

## Summary
`StakesCache::check_and_store` only evicts a cached vote/stake account when the account has zero lamports and the owner still matches the vote/stake program, or when deserialization fails while the owner still matches. If a currently-cached vote or stake account has its owner reassigned to an arbitrary program while retaining nonzero lamports, neither branch fires, so the stale `VoteAccount`/`StakeAccount` entry and its associated stake weight remain in the cache used for consensus-relevant accounting even though accounts-db no longer recognizes the pubkey as a vote/stake account.

## Finding Description
`check_and_store` keys eviction purely on the *current* `owner` field, with an explicit acknowledged TODO stating the gap. When lamports are nonzero and the owner is neither the vote program nor the stake program, the function falls through both `if`/`else if` branches and returns without touching the cache, leaving whatever `VoteAccount`/`StakeAccount` was previously upserted for that pubkey intact in `Stakes<StakeAccount>`. The dedicated `evict_invalid_stakes_cache_entries` feature gate is declared in `feature-set/src/lib.rs` but is not referenced anywhere else in the codebase (not in `stakes.rs`, not in `bank.rs`), confirming the intended fix was never wired in. This function is called from `Bank::update_stakes_cache`, invoked for every committed transaction, making it a live path reachable by any unprivileged transaction that reassigns ownership of a previously vote/stake-owned account (e.g., via the system program's `Assign` instruction or any CPI reassigning owner).

## Impact Explanation
`StakesCache` backs `Bank::vote_accounts()`/`Bank::stakes()`, which feed leader-schedule computation, consensus vote-weighting, and reward/inflation calculations. A stale cache entry means a pubkey no longer owned by the vote/stake program can continue contributing its previously-cached stake weight to these consensus-relevant computations, creating a divergence between the authoritative account state (accounts-db) and the Bank's cached stake view — a false-acceptance condition in stake/vote accounting.

## Likelihood Explanation
Reaching the no-op branch requires only an ordinary, unprivileged owner-reassignment transaction on a pubkey currently tracked in the stakes cache — no malicious validator, trusted plugin, or privileged access is needed. The repository's own test, `check_stake_vote_account_validity` invoked via `test_stake_vote_account_validity` with `check_owner_change = false`, already demonstrates and explicitly tolerates exactly this scenario for both a vote account and a stake account.

## Recommendation
Wire eviction logic into `check_and_store`: when the account's current owner no longer matches the vote or stake program, and the pubkey is still present in `stakes.vote_accounts()` / `stakes.stake_delegations()`, call `remove_vote_account`/`remove_stake_delegation` regardless of the new owner. Gate this behind the already-declared `evict_invalid_stakes_cache_entries` feature, and once activated, update `check_stake_vote_account_validity` to assert `check_owner_change = true`.

## Proof of Concept
1. Create a vote account and a delegated stake account and cache them via `StakesCache::check_and_store`, as done in `check_stake_vote_account_validity` (`runtime/src/bank/tests.rs`, lines 8521-8546).
2. Reassign the owner of the vote account (and/or stake account) to an arbitrary pubkey while keeping lamports nonzero, e.g. `vote_account.set_owner(bogus_vote_program)` (lines 8559-8567), and similarly for the stake account (lines 8571-8581).
3. Observe `bank.vote_accounts().len() == 1` (line 8569) and the final `load_vote_and_stake_accounts(&bank).len()` equal to `usize::from(!check_owner_change)` (lines 8584-8588) — i.e., with `check_owner_change = false` as in `test_stake_vote_account_validity`, one stale entry survives instead of being evicted to `0`.

fn check_stake_vote_account_validity<F>(check_owner_change: bool, load_vote_and_stake_accounts: F)
where
    F: Fn(&Bank) -> StakeDelegationsMap,
{
    let validator_vote_keypairs0 = ValidatorVoteKeypairs::new_rand();
    let validator_vote_keypairs1 = ValidatorVoteKeypairs::new_rand();
    let validator_keypairs = vec![&validator_vote_keypairs0, &validator_vote_keypairs1];
    let GenesisConfigInfo { genesis_config, .. } = create_genesis_config_with_vote_accounts(
        1_000_000_000,
        &validator_keypairs,
        vec![LAMPORTS_PER_SOL; 2],
    );
    let bank = Arc::new(Bank::new_from_genesis(
        &genesis_config,
        Arc::<RuntimeConfig>::default(),
        Vec::new(),
        None,
        ACCOUNTS_DB_CONFIG_FOR_TESTING,
        None,
        None,
        Arc::default(),
        None,
        None,
    ));
    let vote_and_stake_accounts = load_vote_and_stake_accounts(&bank);
    assert_eq!(vote_and_stake_accounts.len(), 2);

    let mut vote_account = bank
        .get_account(&validator_vote_keypairs0.vote_keypair.pubkey())
        .unwrap_or_default();
    let original_lamports = vote_account.lamports();
    vote_account.set_lamports(0);
    // Simulate vote account removal via full withdrawal
    bank.store_account(
        &validator_vote_keypairs0.vote_keypair.pubkey(),
        &vote_account,
    );

    // Modify staked vote account owner; a vote account owned by another program could be
    // freely modified with malicious data
    let bogus_vote_program = Pubkey::new_unique();
    vote_account.set_lamports(original_lamports);
    vote_account.set_owner(bogus_vote_program);
    bank.store_account(
        &validator_vote_keypairs0.vote_keypair.pubkey(),
        &vote_account,
    );

    assert_eq!(bank.vote_accounts().len(), 1);

    // Modify stake account owner; a stake account owned by another program could be freely
    // modified with malicious data
    let bogus_stake_program = Pubkey::new_unique();
    let mut stake_account = bank
        .get_account(&validator_vote_keypairs1.stake_keypair.pubkey())
        .unwrap_or_default();
    stake_account.set_owner(bogus_stake_program);
    bank.store_account(
        &validator_vote_keypairs1.stake_keypair.pubkey(),
        &stake_account,
    );

    // Accounts must be valid stake and vote accounts
    let vote_and_stake_accounts = load_vote_and_stake_accounts(&bank);
    assert_eq!(
        vote_and_stake_accounts.len(),
        usize::from(!check_owner_change)
    );
}
