### Title
`CW721ERC721Pointer` inherits OpenZeppelin's `ERC721` without overriding `safeTransferFrom`, breaking transfers routed through it (analog of wrong-inherited-base-class pause bug) - (File: `contracts/src/CW721ERC721Pointer.sol`)

### Summary
`CW721ERC721Pointer` overrides `transferFrom`, `approve`, `setApprovalForAll`, `ownerOf`, `getApproved`, and `isApprovedForAll` to redirect state-changing/queries to the underlying CW721 contract via the wasmd precompile, but it never overrides `safeTransferFrom` (either the 3-arg or 4-arg variant) or the internal OZ storage-backed helpers (`_ownerOf`, `_getApproved`, `_update`, `_checkAuthorized`) that OZ's `safeTransferFrom` relies on. [1](#0-0) [2](#0-1) 

### Finding Description
`CW721ERC721Pointer` is `is ERC721, ERC2981`, inheriting OpenZeppelin's `ERC721Upgradeable/ERC721` implementation whose internal ownership/approval bookkeeping lives in private storage (`_owners`/`_tokenApprovals` or equivalent internal mappings depending on OZ version), accessed through the internal helpers `_ownerOf`, `_getApproved`, `_isAuthorized`, `_checkAuthorized`, and `_update`. [3](#0-2) 

The pointer contract correctly overrides the *public* entry points `ownerOf`, `getApproved`, `isApprovedForAll`, `transferFrom`, `approve`, and `setApprovalForAll` to proxy reads/writes to the real CW721 contract on the Cosmos side via `WasmdPrecompile.query`/`_execute`. [4](#0-3) [5](#0-4) 

However, it never overrides `safeTransferFrom(address,address,uint256)` / `safeTransferFrom(address,address,uint256,bytes)`, so calls to these functions execute OZ's stock implementation, which internally calls `_update`/`_checkAuthorized`/`_ownerOf` — the private-storage-backed internal helpers — rather than the pointer's overridden public `transferFrom`. Because `_mint`/`_approve` are never invoked on the pointer (all real state lives in the CW721 contract, not in the pointer's own storage), these internal mappings are always empty, so `_ownerOf(tokenId)` returns `address(0)` for every token even though the token has a genuine owner on the CW721 side. This is directly analogous to the Footium bug: a state-changing entry point (`safeTransferFrom`) is inherited unchanged from a base class whose internal invariants are not kept consistent with the child's actual state/permission model (there, `whenNotPaused` was only applied to `safeMint` and not the inherited transfer path; here, the CW721-aware authorization/ownership logic is applied only to `transferFrom` and not the inherited `safeTransferFrom` path). [6](#0-5) 

### Impact Explanation
Any caller (marketplace, wallet, or dApp) that uses the standard-compliant `safeTransferFrom` entry point — which is the interface most NFT marketplaces (e.g., OpenSea-style contracts) and safe-transfer-aware receiver contracts call by default — will have every call revert (via `ERC721NonexistentToken`/`ERC721InsufficientApproval`-style checks failing because the pointer's internal `_ownerOf` storage never reflects the real CW721 owner) or otherwise fail to move actual CW721 ownership, since state is never routed through `_execute`/the wasmd precompile. This makes CW721-backed ERC721 pointers unusable through `safeTransferFrom`, permanently locking out a standard and widely-used transfer path for these tokenized assets and breaking marketplace integrations, which constitutes a functional/asset-freezing defect for any NFT collection pointed via `CW721ERC721Pointer`.

### Likelihood Explanation
Any user or unprivileged contract holding a CW721-backed pointer NFT and attempting a standard `safeTransferFrom` call (a normal action, e.g., listing/selling on marketplaces that always call `safeTransferFrom` rather than `transferFrom`) will trigger this immediately — no special privileges or conditions are required, making the likelihood high whenever `safeTransferFrom` is used instead of `transferFrom`.

### Recommendation
Override both `safeTransferFrom(address,address,uint256)` and `safeTransferFrom(address,address,uint256,bytes)` in `CW721ERC721Pointer` to replicate the same CW721-proxying logic as `transferFrom` (i.e., call the overridden `transferFrom`, then perform the ERC721 receiver-check), instead of relying on OZ's default implementation which depends on internal, never-populated storage.

### Proof of Concept
1. Register a CW721 pointer for an existing CW721 collection via the `AddCW721` pointer precompile flow. [7](#0-6) 
2. Mint/own a token on the real CW721 contract, verify `pointer.ownerOf(tokenId)` correctly reflects the CW721 owner via the overridden query path. [8](#0-7) 
3. Call `pointer.safeTransferFrom(owner, recipient, tokenId)` — because this function is not overridden, it resolves to OZ's default implementation using `_ownerOf(tokenId)` from unset internal storage, causing the authorization check to fail (owner appears as `address(0)`) and the call to revert, even though `transferFrom(owner, recipient, tokenId)` on the same token succeeds via the overridden path. [6](#0-5) 

Note: the existing pointer test suite (`contracts/test/CW721ERC721PointerTest.t.sol`, `contracts/test/ERC721toCW721PointerTest.js`) exercises `transferFrom`, `approve`, and `setApprovalForAll` but does not include a `safeTransferFrom` test case for `CW721ERC721Pointer`, consistent with this gap not being covered. [9](#0-8)

    function ownerOf(uint256 tokenId) public view override returns (address) {
        string memory tId = _formatPayload("token_id", _doubleQuotes(Strings.toString(tokenId)));
        string memory req = _curlyBrace(_formatPayload("owner_of", _curlyBrace(tId)));
        bytes memory response = WasmdPrecompile.query(Cw721Address, bytes(req));
        bytes memory owner_ = JsonPrecompile.extractAsBytes(response, "owner");
        return AddrPrecompile.getEvmAddr(string(owner_));
    }

    function getApproved(uint256 tokenId) public view override returns (address) {
        string memory tId = _formatPayload("token_id", _doubleQuotes(Strings.toString(tokenId)));
        string memory req = _curlyBrace(_formatPayload("approvals", _curlyBrace(tId)));
        bytes memory response = WasmdPrecompile.query(Cw721Address, bytes(req));
        bytes[] memory approvals = JsonPrecompile.extractAsBytesList(response, "approvals");
        if (approvals.length > 0) {
            bytes memory res = JsonPrecompile.extractAsBytes(approvals[0], "spender");
            return AddrPrecompile.getEvmAddr(string(res));
        }
        return address(0);
    }

    function transferFrom(address from, address to, uint256 tokenId) public override {
        if (to == address(0)) {
            revert ERC721InvalidReceiver(address(0));
        }
        require(from == ownerOf(tokenId), "`from` must be the owner");
        string memory recipient = _formatPayload("recipient", _doubleQuotes(AddrPrecompile.getSeiAddr(to)));
        string memory tId = _formatPayload("token_id", _doubleQuotes(Strings.toString(tokenId)));
        string memory req = _curlyBrace(_formatPayload("transfer_nft", _curlyBrace(_join(recipient, tId, ","))));
        _execute(bytes(req));
    }

    function approve(address approved, uint256 tokenId) public override {
        string memory spender = _formatPayload("spender", _doubleQuotes(AddrPrecompile.getSeiAddr(approved)));
        string memory tId = _formatPayload("token_id", _doubleQuotes(Strings.toString(tokenId)));
        string memory req = _curlyBrace(_formatPayload("approve", _curlyBrace(_join(spender, tId, ","))));
        _execute(bytes(req));
    }

    function setApprovalForAll(address operator, bool approved) public override {
        string memory op = _curlyBrace(_formatPayload("operator", _doubleQuotes(AddrPrecompile.getSeiAddr(operator))));
        if (approved) {
            _execute(bytes(_curlyBrace(_formatPayload("approve_all", op))));
        } else {
            _execute(bytes(_curlyBrace(_formatPayload("revoke_all", op))));
        }
    }

func (p Precompile) AddCW721(ctx sdk.Context, method *ethabi.Method, caller common.Address, args []interface{}, value *big.Int, evm *vm.EVM, suppliedGas uint64, hooks *tracing.Hooks) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}
	if err := pcommon.ValidateArgsLength(args, 1); err != nil {
		return nil, 0, err
	}
	cwAddr := args[0].(string)
	existingAddr, existingVersion, exists := p.evmKeeper.GetERC721CW721Pointer(ctx, cwAddr)
	if exists && existingVersion >= 4 {
		return nil, 0, fmt.Errorf("pointer at %s with version %d exists when trying to set pointer for version %d", existingAddr.Hex(), existingVersion, cw721.CurrentVersion)
	}
	cwAddress, err := sdk.AccAddressFromBech32(cwAddr)
	if err != nil {
		return nil, 0, err
	}
	res, err := p.wasmdKeeper.QuerySmart(ctx, cwAddress, []byte("{\"contract_info\":{}}"))
	if err != nil {
		return nil, 0, err
	}
	formattedRes := map[string]interface{}{}
	if err := json.Unmarshal(res, &formattedRes); err != nil {
		return nil, 0, err
	}
	name := formattedRes["name"].(string)
	symbol := formattedRes["symbol"].(string)
	constructorArguments := []interface{}{
		cwAddr, name, symbol,
	}

	packedArgs, err := cw721.GetParsedABI().Pack("", constructorArguments...)
	if err != nil {
		panic(err)
	}
	bin := append(cw721.GetBin(), packedArgs...)
	if value == nil {
		value = utils.Big0
	}
	ret, contractAddr, remainingGas, err := evm.Create(caller, bin, suppliedGas, uint256.MustFromBig(value))
	if err != nil {
		return
	}
	err = p.evmKeeper.SetERC721CW721Pointer(ctx, cwAddr, contractAddr)
	if err != nil {
		return
	}

	ctx.EventManager().EmitEvent(sdk.NewEvent(
		types.EventTypePointerRegistered, sdk.NewAttribute(types.AttributeKeyPointerType, "cw721"),
		sdk.NewAttribute(types.AttributeKeyPointerAddress, contractAddr.Hex()), sdk.NewAttribute(types.AttributeKeyPointee, cwAddr),
		sdk.NewAttribute(types.AttributeKeyPointerVersion, fmt.Sprintf("%d", cw721.CurrentVersion))))
	ret, err = method.Outputs.Pack(contractAddr)
	return
