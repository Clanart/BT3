## Title
Gasless swap `Deadline` is validated only once at tx-pool admission, never re-checked at block-building time - (File: `kaiax/gasless/impl/getter.go`)

### Summary
In the KIP-247 gasless module, `SwapArgs.Deadline` is the on-chain equivalent of authentik's invitation expiry: it is meant to bound how long a `GaslessSwapTx` remains valid before it should be treated as expired. Exactly like the authentik bug — where expiry was checked once (or relied on a periodic sweep) instead of being re-validated at time of use — the gasless module checks `Deadline` only in `checkBalanceForSwap`, which runs at transaction-pool admission time, and never re-checks it when the transaction is later pulled from the pool and bundled into a block.

### Finding Description
`checkBalanceForSwap` is the only place in the module that compares the swap's deadline against a current timestamp: [1](#0-0) 

This function is wired up as `GetCheckBalance()`, which is invoked by the tx pool at add-time only: [2](#0-1) 

However, the function that actually decides whether a swap/approve pair is *executable* and gets bundled into a block — `VerifyExecutable` (aliased by `IsExecutable`) — never inspects `swapArgs.Deadline` at all: [3](#0-2) 

`ExtractTxBundles`, which runs at block-assembly time (potentially many blocks after the tx was admitted to the pool, since a gasless tx can sit in `queue`/`pending` waiting on nonce ordering, gas price competition, or simply block space), calls exactly this deadline-blind `IsExecutable`: [4](#0-3) 

The public `gasless_isGaslessTx` RPC path has the same gap — it calls `VerifyExecutable` directly without ever revalidating the deadline: [5](#0-4) 

So the only "expiry enforcement" is a single check performed when the transaction first enters the pool. If the block containing the swap is produced at a different, later time (a stale/expired swap tx remaining in the pool due to txpool congestion, low gas price, waiting for a preceding approve tx, or simply being re-broadcast/re-added), the deadline is never re-validated before the proposer builds the lend+approve+swap bundle and executes it on-chain.

### Impact Explanation
An expired `GaslessSwapTx` (per its own declared `Deadline`) can still be selected, bundled with a proposer-funded `LendTx`, and executed at block-building time, because the proposer's bundling logic (`ExtractTxBundles`/`IsExecutable`) performs no deadline check. This directly undermines the deadline guarantee that gasless swap parties (and the swap router contract's callers) rely on for price/quote validity — the same trust violation pattern as the authentik advisory, where an expired grant remained honored past its intended validity window due to relying on a single stale check instead of re-validating at time of use. Since the lend transaction transfers proposer-funded KAIA to the sender before repayment via the swap, an expired swap being honored can result in unintended value movement (lending against a swap whose price/deadline assumptions are stale), i.e., fee-delegation/gasless settlement abuse.

### Likelihood Explanation
This is reachable by any unprivileged public-RPC caller/gasless user: they only need to submit (or leave sitting in the pool) a `GaslessApproveTx`/`GaslessSwapTx` pair whose `Deadline` has since elapsed relative to the block being built. No special privileges, validator/consensus roles, or peer compromise are required — this is a pure transaction-pool timing condition, well within the disclosed scope (gasless module, reachable from a submitted transaction).

### Recommendation
Add a `swapArgs.Deadline` check to `VerifyExecutable` in `kaiax/gasless/impl/getter.go`, comparing against the current block time (`g.Chain.CurrentBlock().Time()`), mirroring the check already present in `checkBalanceForSwap`. This ensures the deadline is enforced at the actual point of use (block building / bundle execution and RPC validation), not only at pool admission time.

### Proof of Concept
1. Submit `GaslessApproveTx` (A) then `GaslessSwapTx` (S) with `Deadline = D` to the tx pool; at admission time `D >= currentBlock.Time()`, so `checkBalanceForSwap` accepts them into the pool.
2. Due to normal pool dynamics (fee competition, nonce gaps, congestion), the pair remains in `pending`/`queue` until block time `T > D` (deadline has elapsed).
3. When the proposer builds a block, `ExtractTxBundles` (`kaiax/gasless/impl/builder.go:28`) calls `g.IsExecutable(approveTxs[addr], tx)` → `VerifyExecutable` (`kaiax/gasless/impl/getter.go:214`), which validates sender/token/nonce/repay-amount but never checks `swapArgs.Deadline` against `T`.
4. The bundle `[LendTxGenerator, ApproveTx, SwapTx]` is accepted and executed even though the swap's declared deadline has passed, honoring an expired gasless swap exactly as authentik honored expired invitations.

func (g *GaslessModule) GetCheckBalance() func(tx *types.Transaction) error {
	return func(tx *types.Transaction) error {
		if approveArgs, ok := decodeApproveTx(tx, g.signer); ok {
			return g.checkBalanceForApprove(approveArgs)
		}
		if swapArgs, ok := decodeSwapTx(tx, g.signer); ok {
			return g.checkBalanceForSwap(swapArgs, tx.Nonce())
		}
		return errors.New("not a gasless transaction") // should not happen because IsModuleTx is called before GetCheckBalance
	}
}

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
}
