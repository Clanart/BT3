### Title
`aptos move verify-package` never compares actual on-chain module bytecode, only package metadata, letting on-chain modules diverge from the "verified" source - (File: `aptos-move/cli/src/stored_package.rs`)

### Summary
The CLI's `verify-package` command is meant to prove that the bytecode published under an account matches a local compilation of the claimed source. In practice `VerifyPackage::execute` fetches the registry with `with_bytecode = false` and calls `CachedPackageMetadata::verify`, which only compares `PackageMetadata` fields (`name`, `deps`, `modules` (the `ModuleMetadata` list of name/zipped-source/source_map/extension), `manifest`, `upgrade_policy`, `extension`, `source_digest`). It never fetches or diffs the actual `.mv` module bytecode stored on-chain against the bytecode produced by the local build. This is analogous to the report's root cause pattern: a value that should always be kept in sync with a critical invariant is skipped along a code path, silently breaking the guarantee callers rely on.

### Finding Description
`VerifyPackage::execute` in [1](#0-0)  builds the package locally, extracts `compiled_metadata`, then creates `CachedPackageRegistry::create(client, self.account, false)` — the third argument `with_bytecode` is hardcoded `false` — and calls `package.verify(&compiled_metadata)`.

`CachedPackageRegistry::create` only downloads per-module bytecode via `get_account_module` when `with_bytecode` is `true` [2](#0-1) . Since `verify-package` passes `false`, no on-chain bytecode is ever retrieved during verification.

`CachedPackageMetadata::verify` then only checks equality of `PackageMetadata` sub-fields [3](#0-2) . The `modules` field being compared is `Vec<ModuleMetadata>`, which (per `save_package_to_disk`/`zipped_source` accessors) only carries `name`, zipped `source`, zipped `source_map`, and `extension` — not the compiled `.mv` bytes that the VM will actually execute [4](#0-3) . `source_digest` is a hash the publisher self-declares inside `PackageMetadata` at publish time (via `code::publish_package_txn`), not something independently derived by the chain from the actual bytecode bytes, so a publisher can submit `metadata_serialized` whose `source_digest`/`modules.source` matches one program while the accompanying `code: vector<vector<u8>>` (the real bytecode passed to `code::publish_package`) is a different program — nothing in `code.move`'s `publish_package` cross-checks that the bytecode matches the declared source metadata [5](#0-4) .

Consequently `aptos move verify-package` can print "Successfully verified source of package" even though the deployed bytecode differs from the bytecode that would be produced by compiling the "verified" source, because the command structurally never inspects the deployed bytecode.

### Impact Explanation
Third parties, auditors, and governance voters rely on `verify-package` (and the analogous `download_package --bytecode` path is separate and not used here) as the mechanism to confirm on-chain code matches published/audited source before depending on or interacting with a package. Because the verification step is metadata-only and does not fetch/compare bytecode, any package (self-declared metadata is attacker-controlled at publish time) can present source that looks benign while running different, malicious bytecode at the same address — verification will still succeed. This affects code-safety trust and dependency verification, i.e., a mismatch between "verified bytes" and "committed module bytes," matching the required publish/code-safety impact category. The severity depends on how heavily downstream tooling/users trust `verify-package`'s success as an authoritative bytecode attestation; if used as a security gate (e.g., before adding a dependency or granting trust to a package), this is a high-impact gap since it provides false assurance.

### Likelihood Explanation
This triggers on every normal invocation of `aptos move verify-package` — it is not a rare edge case, it is the command's default and only behavior. No special preconditions are needed beyond a malicious/careless publisher crafting `metadata_serialized` that doesn't correspond to the actually-submitted `code` bytes, which is fully within a permissionless publisher's control at publish time.

### Recommendation
`VerifyPackage::execute` should call `CachedPackageRegistry::create(client, self.account, true)` to fetch on-chain bytecode, and `verify` should additionally compare each module's downloaded bytecode against the bytecode produced by the local `BuiltPackage` (e.g., `pack.extract_code()`), failing verification if any module's bytes differ, in addition to the existing metadata checks.

### Proof of Concept
1. Compile package `Foo` locally with legitimate source `A`; extract metadata `meta_A` (whose `source_digest`/`ModuleMetadata.source` describe `A`).
2. Craft a modified/malicious bytecode `code_B` compiled from different source `B` but keep `meta_A` as the metadata payload.
3. Publish via `code::publish_package_txn(signer, bcs(meta_A), code_B)` — `code.move` does not check that `code_B` matches `meta_A`'s declared source/digest [6](#0-5) .
4. Run `aptos move verify-package --account <addr>` against source `A`. Because `execute()` never downloads bytecode (`with_bytecode=false`) and `verify()` only compares metadata fields, all checks pass and the tool reports "Successfully verified source of package" [1](#0-0) [3](#0-2) , despite the on-chain module actually running `code_B`.

Note: I could not execute this PoC in a live environment (no filesystem/terminal access), so this is a structural code-path analysis based on the cited source, not an empirically reproduced exploit. This should be confirmed with an actual e2e test/CLI run before treating it as fully verified.

    async fn execute(self) -> CliTypedResult<&'static str> {
        // First build the package locally to get the package metadata
        let build_options = BuildOptions {
            install_dir: self.move_options.output_dir.clone(),
            bytecode_version: fix_bytecode_version(
                self.move_options.bytecode_version,
                self.move_options.language_version,
            ),
            ..self.included_artifacts.build_options(&self.move_options)?
        };
        let w = self.env.writer();
        let pack = BuiltPackage::build_to(&w, self.move_options.get_package_path()?, build_options)
            .map_err(|e| CliError::MoveCompilationError(format!("{:#}", e)))?;
        let compiled_metadata = pack.extract_metadata()?;

        // Now pull the compiled package
        let client = self.rest_options.client(&self.profile_options)?;
        let registry = CachedPackageRegistry::create(client, self.account, false).await?;
        let package = registry
            .get_package(pack.name())
            .await
            .map_err(|s| CliError::CommandArgumentError(s.to_string()))?;

        // We can't check the arbitrary, because it could change on us
        if package.upgrade_policy() == UpgradePolicy::arbitrary() {
            return Err(CliError::CommandArgumentError(
                "A package with upgrade policy `arbitrary` cannot be downloaded \
                since it is not safe to depend on such packages."
                    .to_owned(),
            ));
        }

        // Verify that the source digest matches
        package.verify(&compiled_metadata)?;

        Ok("Successfully verified source of package")
    }

impl CachedPackageRegistry {
    /// Creates a new registry.
    pub async fn create(
        client: Client,
        addr: AccountAddress,
        with_bytecode: bool,
    ) -> anyhow::Result<Self> {
        // Need to use a different type to deserialize JSON
        let inner = client
            .get_account_resource_bcs::<PackageRegistry>(addr, "0x1::code::PackageRegistry")
            .await?
            .into_inner();
        let mut bytecode = BTreeMap::new();
        if with_bytecode {
            for pack in &inner.packages {
                for module in &pack.modules {
                    let bytes = client
                        .get_account_module(addr, &module.name)
                        .await?
                        .into_inner()
                        .bytecode
                        .0;
                    bytecode.insert(module.name.clone(), bytes);
                }
            }
        }
        Ok(Self { inner, bytecode })
    }

    pub fn verify(&self, package_metadata: &PackageMetadata) -> anyhow::Result<()> {
        let self_metadata = self.metadata;

        if self_metadata.name != package_metadata.name {
            bail!(
                "Package name doesn't match {} : {}",
                package_metadata.name,
                self_metadata.name
            )
        } else if self_metadata.deps != package_metadata.deps {
            bail!(
                "Dependencies don't match {:?} : {:?}",
                package_metadata.deps,
                self_metadata.deps
            )
        } else if self_metadata.modules != package_metadata.modules {
            bail!(
                "Modules don't match {:?} : {:?}",
                package_metadata.modules,
                self_metadata.modules
            )
        } else if self_metadata.manifest != package_metadata.manifest {
            bail!(
                "Manifest doesn't match {:?} : {:?}",
                package_metadata.manifest,
                self_metadata.manifest
            )
        } else if self_metadata.upgrade_policy != package_metadata.upgrade_policy {
            bail!(
                "Upgrade policy doesn't match {:?} : {:?}",
                package_metadata.upgrade_policy,
                self_metadata.upgrade_policy
            )
        } else if self_metadata.extension != package_metadata.extension {
            bail!(
                "Extensions doesn't match {:?} : {:?}",
                package_metadata.extension,
                self_metadata.extension
            )
        } else if self_metadata.source_digest != package_metadata.source_digest {
            bail!(
                "Source digests doesn't match {:?} : {:?}",
                package_metadata.source_digest,
                self_metadata.source_digest
            )
        }

        Ok(())
    }

    /// Publishes a package at the given signer's address. The caller must provide package metadata describing the
    /// package.
    public fun publish_package(owner: &signer, pack: PackageMetadata, code: vector<vector<u8>>) acquires PackageRegistry {
        // Disallow incompatible upgrade mode. Governance can decide later if this should be reconsidered.
        assert!(
            pack.upgrade_policy.policy > upgrade_policy_arbitrary().policy,
            error::invalid_argument(EINCOMPATIBLE_POLICY_DISABLED),
        );

        let addr = signer::address_of(owner);
        if (!exists<PackageRegistry>(addr)) {
            move_to(owner, PackageRegistry { packages: vector::empty() })
        };

        // Checks for valid dependencies to other packages
        let allowed_deps = check_dependencies(addr, &pack);

        // Check package against conflicts
        // To avoid prover compiler error on spec
        // the package need to be an immutable variable
        let module_names = get_module_names(&pack);

        // Record, per module in this package, the object's transitive root owner at (re)publish, so
        // lazy self-init can detect a later transfer of the object or an ancestor since that module
        // was published (see `init::internal_maybe_initialize`). Objects only; feature-gated.
        if (features::is_lazy_module_initialization_enabled() && object::is_object(addr)) {
            let owner = object::address_to_object<object::ObjectCore>(addr).root_owner();
            module_names.for_each_ref(|name| {
                init::record_deploy_owner(addr, *name.bytes(), owner);
            });
        };
        let package_immutable = &borrow_global<PackageRegistry>(addr).packages;
        let len = package_immutable.length();
        let index = len;
        let upgrade_number = 0;
        package_immutable.enumerate_ref(|i, old| {
            let old: &PackageMetadata = old;
            if (old.name == pack.name) {
                upgrade_number = old.upgrade_number + 1;
                check_upgradability(old, &pack, &module_names);
                index = i;
            } else {
                check_coexistence(old, &module_names)
            };
        });

        // Assign the upgrade counter.
        pack.upgrade_number = upgrade_number;

        let packages = &mut borrow_global_mut<PackageRegistry>(addr).packages;
        // Update registry
        let policy = pack.upgrade_policy;
        if (index < len) {
            pack.modules.for_each_ref(|m| {
                let m: &ModuleMetadata = m;
                init::reset_initialized(addr, *m.name.bytes());
            });
            *packages.borrow_mut(index) = pack
        } else {
            packages.push_back(pack)
        };

        event::emit(PublishPackage {
            code_address: addr,
            is_upgrade: upgrade_number > 0
        });

        // Request publish
        if (features::code_dependency_check_enabled())
            request_publish_with_allowed_deps(addr, module_names, allowed_deps, code, policy.policy)
        else
        // The new `request_publish_with_allowed_deps` has not yet rolled out, so call downwards
        // compatible code.
            request_publish(addr, module_names, code, policy.policy)
    }
