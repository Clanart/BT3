### Title
Empty deserialized Schnorr aggregate verifies as valid - ([File: crypto/schnorr/src/aggregate.rs](crypto/schnorr/src/aggregate.rs))

### Summary
`SchnorrAggregate::read` accepts an aggregate containing zero nonces, while `SchnorrAggregate::verify` accepts the corresponding empty statement list as valid whenever `s` is zero. [1](#0-0) [2](#0-1) 

### Finding Description
The deserializer reads a four-byte nonce count and permits that count to be zero. [3](#0-2)  Verification only checks that the aggregate’s nonce count equals the supplied key/challenge count, then builds a verification equation with one remaining term, `-s * G`. [2](#0-1)  For an empty statement list and `s = 0`, that equation is the identity and verification returns `true`. [4](#0-3) 

The aggregation API explicitly refuses to produce an empty aggregate, establishing that zero signatures are not intended to be a valid aggregate. [5](#0-4)  The deserializer does not enforce the same invariant.

### Impact Explanation
An attacker can provide a serialized aggregate that represents no signatures and have it accepted by `verify` whenever the verifier is asked to validate an empty key/challenge list. This produces a forged aggregate signature object that passes the public verification API despite containing no signer authorization.

### Likelihood Explanation
The payload is only 36 bytes for a 32-byte scalar field: a zero nonce count followed by the canonical encoding of scalar zero. Exploitation requires a calling protocol to submit attacker-controlled aggregate bytes to `SchnorrAggregate::read` and to permit an empty claimed signer set; the library itself does not reject that condition.

### Recommendation
Reject zero-length aggregates in `SchnorrAggregate::read`, matching the existing `SchnorrAggregator::complete` check. Defense in depth should also make `SchnorrAggregate::verify` return `false` when `keys_and_challenges` is empty.

### Proof of Concept
```rust
use ciphersuite::Ciphersuite;
use dalek_ff_group::Ed25519;
use schnorr::aggregate::SchnorrAggregate;

// u32 nonce-count = 0, followed by a canonical 32-byte zero scalar.
let mut encoded = vec![0u8; 4 + 32];

let aggregate =
  SchnorrAggregate::<Ed25519>::read(&mut encoded.as_slice()).unwrap();

assert_eq!(aggregate.Rs().len(), 0);

// An empty aggregate must not verify, but currently does.
assert!(aggregate.verify(b"example-domain", &[]));
```
