Chia's pool/plotnft reward mechanisms are fundamentally different from the Solidity `AbstractRewarder` pattern in the report. The report's bug is specific to a streaming/rate-based reward accrual model (`rewardRate`, `periodInBlockFinish`, `totalSupply()`-weighted distribution) used in ERC-20 staking rewarders.

In chia-blockchain, pool/farmer rewards are fixed, consensus-defined amounts per block computed by `calculate_pool_reward()` and `calculate_base_farmer_reward()` [1](#0-0) , not accrued via a rate multiplied by elapsed blocks divided among a variable `totalSupply()` of stakers. Reward coins are absorbed via singleton spends (`PoolWallet.claim_pool_rewards`, `PlotNFT.claim_pool_rewards`) [2](#0-1) [3](#0-2) , with amounts fixed by height and hard-coded in the coinbase rules — there is no analogous "leftover reward" recalculation, no `rewardRate`/`periodFinish` state, and no dependency on a mutable `totalSupply()` that could cause incorrect leftover accounting.

Since chia-blockchain has no equivalent reward-streaming/staking-pool construct reachable by an unprivileged spend-bundle submitter or wallet user, there is no valid analog for this bug class in this codebase.

def calculate_pool_reward(height: uint32) -> uint64:
    """
    Returns the pool reward at a certain block height. The pool earns 7/8 of the reward in each block. If the farmer
    is solo farming, they act as the pool, and therefore earn the entire block reward.
    These halving events will not be hit at the exact times
    (3 years, etc), due to fluctuations in difficulty. They will likely come early, if the network space and VDF
    rates increase continuously.
    """

    if height == 0:
        return uint64((7 / 8) * 21000000 * _mojo_per_chia)
    elif height < 3 * _blocks_per_year:
        return uint64((7 / 8) * 2 * _mojo_per_chia)
    elif height < 6 * _blocks_per_year:
        return uint64((7 / 8) * 1 * _mojo_per_chia)
    elif height < 9 * _blocks_per_year:
        return uint64((7 / 8) * 0.5 * _mojo_per_chia)
    elif height < 12 * _blocks_per_year:
        return uint64((7 / 8) * 0.25 * _mojo_per_chia)
    else:
        return uint64((7 / 8) * 0.125 * _mojo_per_chia)
