Based on my research, I found a concrete quadratic-complexity gas-pricing gap in the precompile calldata decoding path, directly analogous to the Suricata krb5 buffering bug (a cost the parser incurs that is not linear in the metered/charged size).

### Title
Static (non-dynamic-gas) precompiles decode calldata without pricing the quadratic string-copy cost, enabling a cheap CPU-amplification DoS - (File: precompiles/common/precompiles.go)

### Summary
`precompiles/common/precompiles.go` implements two execution paths for Cosmos precompiles: the standard `Precompile.Run`/`Prepare` path and the `DynamicGasPrecompile.RunAndCalculateGas` path. The dynamic-gas path explicitly charges `DecodeGasCost` (which prices the ABI decoder's potentially quadratic string-copy volume) before calling `method.Inputs.Unpack` [1](#0-0) . The standard path, used by every non-dynamic-gas precompile, calls `method.Inputs.Unpack(argsBz)` directly in `Prepare()` with no equivalent charge [2](#0-1) . The only cost paid beforehand is `RequiredGas`, which delegates to a per-executor flat/linear gas function [3](#0-2) .

### Finding Description
`precompiles/common/decode_cost.go` documents that go-ethereum's ABI `Unpack` cost is dominated by copying `string` payloads, and because a single string can be referenced by many array/tuple slots via aliased offsets, "the copied volume can be super-linear in len(input) (worst case ~len(input)^2)" [4](#0-3) . `DecodeGasCost`/`decodeStringCopyBytes` were built specifically to price this out-of-band cost by walking the ABI structure and summing the string-copy volume the real decoder will perform [5](#0-4) .

This mitigation is wired into `DynamicGasPrecompile.RunAndCalculateGas` via `chargeDecodeGas`, which explicitly notes: "ABI decoding of attacker-controlled calldata can cost far more than len(input) ... so it must be paid for out of the gas the caller supplied," and states the equivalent charge is needed because "the static-precompile path charges `RequiredGas` in `vm.RunPrecompiledContract` before running" [6](#0-5) . However, that referenced static-precompile charge (`Precompile.RequiredGas` → `executor.RequiredGas(input[4:], method)`) is a per-precompile, typically length/flat-based gas amount — it is not derived from `DecodeGasCost` and does not walk the ABI structure to detect aliased/amplifying string references. After that flat charge is paid, `Precompile.Run` calls `Prepare`, which performs the full, unpriced `method.Inputs.Unpack(argsBz)` [7](#0-6) .

Consequently, any precompile registered through `NewPrecompile` (the static path) that accepts a dynamic argument shape containing strings/arrays/tuples is exposed to the same "aliased dynamic-tuple offsets" amplification the test suite itself validates for the dynamic-gas path, e.g. `newAliasedVoteWeightedArgs`, which builds calldata of size `O(k+s)` that produces `O(k*s)` decoded copy volume [8](#0-7) . An attacker submitting such calldata to a static precompile pays gas proportional only to `len(input)` (via `RequiredGas`/`DefaultGasCost`), while the node performs `O(len(input)^2)`-scale copying work inside `Unpack` during `Run`.

### Impact Explanation
This is a direct analog of the Suricata krb5 quadratic-buffering bug class: parsing/decoding work that is quadratic in a bounded input is not accounted for by the resource charge that gates admission, allowing a cheap request to consume disproportionate CPU. Here the "buffering" is the ABI decoder's string materialization, and the gate is EVM gas metering via `RequiredGas`. A single crafted EVM transaction targeting any static-gas Cosmos precompile with a string-bearing dynamic argument can force disproportionate CPU time relative to the gas charged, which — if the amplification factor is large enough within calldata-size/gas-limit bounds — can degrade or delay block processing for all validators executing that transaction, i.e. a validator-halt/block-delay class of impact.

### Likelihood Explanation
Reachable by any unprivileged EVM transaction sender/contract caller: the attacker only needs to call a static-gas precompile whose ABI includes a `string`, `string[]`, or nested tuple/array containing a string, with crafted (but standards-permitted, if non-canonical) offset aliasing so multiple slots reference the same underlying string payload — exactly the technique already used in the repository's own `decode_cost_test.go` to validate the *other* code path. No special privileges, governance, or validator cooperation are required; it is triggerable via a single public JSON-RPC `eth_sendRawTransaction`/`eth_call`.

### Recommendation
Apply the same `chargeDecodeGas`/`DecodeGasCost` accounting used in `DynamicGasPrecompile.RunAndCalculateGas` to the standard `Precompile.RequiredGas`/`Prepare` path — i.e., have `Precompile.RequiredGas` (or `Prepare`, before calling `Unpack`) walk the method's argument types with `decodeStringCopyBytes` and require the EVM-supplied gas to cover the resulting string-copy surcharge, rejecting or charging appropriately before decoding untrusted calldata for every precompile registered via `NewPrecompile`.

### Proof of Concept
1. Pick any static-gas precompile (`NewPrecompile`, not `NewDynamicGasPrecompile`) whose ABI has a method taking a dynamic array of tuples containing a `string` field (analogous to the `voteWeighted`-shaped example in the test suite).
2. Build calldata reusing `newAliasedVoteWeightedArgs`-style encoding: `k` array-head offsets all pointing at one shared dynamic tuple whose `string` field has length `s`, keeping total calldata size `O(k+s)` [9](#0-8) .
3. Choose `k` and `s` such that `k*s` is large (bounded by calldata-size/gas-limit constraints) while `len(input)` (and thus the flat `RequiredGas`/`DefaultGasCost` charge) stays comparatively small.
4. Submit this as calldata to the precompile via `eth_sendRawTransaction`. `Precompile.RequiredGas` charges only the flat/linear cost; `Precompile.Run`→`Prepare`→`method.Inputs.Unpack` then performs `O(k*s)` string-copy work unpriced, consuming CPU disproportionate to the gas paid.

func (p Precompile) RequiredGas(input []byte) uint64 {
	methodID, err := ExtractMethodID(input)
	if err != nil {
		return UnknownMethodCallGas
	}

	method, err := p.MethodById(methodID)
	if err != nil {
		// This should never happen since this method is going to fail during Run
		return UnknownMethodCallGas
	}
	return p.executor.RequiredGas(input[4:], method)
}

func (p Precompile) Run(evm *vm.EVM, caller common.Address, callingContract common.Address, input []byte, value *big.Int, readOnly bool, isFromDelegateCall bool, hooks *tracing.Hooks) (bz []byte, err error) {
	operation := fmt.Sprintf("%s_unknown", p.name)
	defer func() {
		HandlePrecompileError(err, evm, operation)
		if err != nil {
			err = vm.ErrExecutionReverted
		}
	}()
	ctx, method, args, err := p.Prepare(evm, input)
	if err != nil {
		return nil, err
	}

	operation = method.Name
	em := ctx.EventManager()
	ctx = ctx.WithEventManager(sdk.NewEventManager())
	ctx = ctx.WithEVMPrecompileCalledFromDelegateCall(isFromDelegateCall)
	bz, err = p.executor.Execute(ctx, method, caller, callingContract, args, value, readOnly, evm, hooks)
	if err != nil {
		return bz, err
	}
	events := ctx.EventManager().Events()
	if len(events) > 0 {
		em.EmitEvents(ctx.EventManager().Events())
	}
	return bz, err
}

func (p Precompile) Prepare(evm *vm.EVM, input []byte) (sdk.Context, *abi.Method, []interface{}, error) {
	ctxer := state.GetDBImpl(evm.StateDB)
	if ctxer == nil {
		return sdk.Context{}, nil, nil, errors.New("cannot get context from EVM")
	}
	methodID, err := ExtractMethodID(input)
	if err != nil {
		return sdk.Context{}, nil, nil, err
	}
	method, err := p.MethodById(methodID)
	if err != nil {
		return sdk.Context{}, nil, nil, err
	}

	argsBz := input[4:]
	args, err := method.Inputs.Unpack(argsBz)
	if err != nil {
		return sdk.Context{}, nil, nil, err
	}

	return ctxer.Ctx(), method, args, nil
}

func DecodeGasCost(args abi.Arguments, input []byte) (uint64, bool) {
	base := DefaultGasCost(input, false)
	if len(input) < 4 {
		return base, true
	}
	strBytes, ok := decodeStringCopyBytes(args, input[4:])
	if !ok {
		return 0, false
	}
	return satAdd(base, satMul(storetypes.KVGasConfig().ReadCostPerByte, strBytes)), true
}

// decodeStringCopyBytes returns the total number of string-payload bytes the ABI
// decoder would copy while unpacking data as args, mirroring go-ethereum's
// unpack traversal. It follows offsets and reads length prefixes but never
// copies payloads, so it runs in time proportional to the number of type nodes
// visited rather than the number of bytes referenced. ok is false when the
// input is structurally inconsistent or hits the traversal cap.
func decodeStringCopyBytes(args abi.Arguments, data []byte) (uint64, bool) {
	w := &decodeWalker{}
	index := 0
	virtualArgs := 0
	for _, arg := range args {
		if arg.Indexed {
			continue
		}
		if abiContainsString(arg.Type) {
			w.walk(data, (index+virtualArgs)*32, arg.Type)
			if w.failed {
				return 0, false
			}
		}
		if (arg.Type.T == abi.ArrayTy || arg.Type.T == abi.TupleTy) && !abiIsDynamic(arg.Type) {
			virtualArgs += abiTypeSize(arg.Type)/32 - 1
		}
		index++
	}
	return w.strBytes, true
}

func TestDecodeStringCopyBytes_AliasedVoteWeighted(t *testing.T) {
	const (
		k = uint64(18432)
		s = uint64(602592)
	)
	args := abi.Arguments{
		{Type: mustABIType(t, "uint64", nil)},
		{Type: mustABIType(t, "tuple[]", []abi.ArgumentMarshaling{
			{Name: "option", Type: "int32"},
			{Name: "weight", Type: "string"},
		})},
	}
	data := newAliasedVoteWeightedArgs(k, s)

	n, ok := decodeStringCopyBytes(args, data)
	require.True(t, ok)
	require.Equal(t, k*s, n)

	// DecodeGasCost must price the amplified copy volume, not just len(input).
	input := append([]byte{0x59, 0x63, 0x4a, 0x88}, data...)
	gas, ok := DecodeGasCost(args, input)
	require.True(t, ok)
	base := DefaultGasCost(input, false)
	require.Equal(t, satAdd(base, satMul(storetypes.KVGasConfig().ReadCostPerByte, k*s)), gas)
	require.Greater(t, gas, uint64(12_500_000))
	require.Less(t, uint64(len(input)), uint64(2<<20)) // compact calldata, ~1.2MiB
}

// newAliasedVoteWeightedArgs builds non-canonical voteWeighted argument
// bytes: k dynamic-tuple offsets all point at one shared (option, weight) body
// whose weight string has length s. Calldata stays O(k+s); decoded copy volume
// is O(k*s).
func newAliasedVoteWeightedArgs(k, s uint64) []byte {
	tupleRel := 32 * k // offset within the array payload (after the length word)
	arrayPayload := make([]byte, 0, int(32*k+64+s))
	for range k {
		arrayPayload = append(arrayPayload, abiWord(tupleRel)...)
	}
	// Shared dynamic tuple: word0 = s (option / string length via offset 0),
	// word1 = 0 (string offset), then s payload bytes starting at tuple+32.
	arrayPayload = append(arrayPayload, abiWord(s)...)
	arrayPayload = append(arrayPayload, abiWord(0)...)
	arrayPayload = append(arrayPayload, make([]byte, s)...)

	data := append(abiWord(1), abiWord(64)...) // proposalID, options offset
	data = append(data, abiWord(k)...)
	data = append(data, arrayPayload...)
	return data
}
