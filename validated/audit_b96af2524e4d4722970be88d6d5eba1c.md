### Title
`aptos move verify-package` never compares on-chain bytecode to local compilation, so it cannot detect a bytecode/source mismatch it claims to verify - (File: aptos-move/cli/src/stored_package.rs)

### Summary
The `VerifyPackage` CLI command advertises that it "verifies the bytecode matches a local compilation of the Move code" [1](#0-0) , but its actual implementation only fetches the on-chain `PackageMetadata` (with `with_bytecode=false`) and compares self-reported metadata fields (`name`, `deps`, `modules` (source text/source-map), `manifest`, `upgrade_policy`, `extension`, `source_digest`) against a locally rebuilt package's metadata [2](#0-1) [3](#0-2) . None of these compared fields is the actual deployed `.mv` bytecode; the on-chain `code::publish_package` function accepts `PackageMetadata` and `code: vector<vector<u8>>` as two independent, uncorrelated parameters with no on-chain assertion that the code bytes were compiled from the embedded metadata source [4](#0-3) .

### Finding Description
`PackageMetadata` stores `source_digest` as "the sha256 of each individual source... sorted alphabetically... sha256 again" [5](#0-4)  — this is a hash over *declared source text*, not over the compiled bytecode that is actually stored and executed. `publish_package` never checks that `code` (the bytecode bundle) corresponds to `pack.modules[i].source` or `pack.source_digest`; it simply records the metadata and forwards `code` to `request_publish[_with_allowed_deps]` for loading/verification of well-formedness only [6](#0-5) , and the native handler only performs structural bookkeeping (destination, expected module names, allowed deps) with no source/bytecode correspondence check [7](#0-6) .

Given this, the on-chain link between "declared source" and "actual bytecode" is purely a convention that any publisher can break — a publisher can submit metadata whose `ModuleMetadata.source` field contains benign, reviewable source code while the actual `code` bundle contains different (e.g., backdoored) bytecode.

The `VerifyPackage` CLI command is the tool users are expected to rely on to confirm "the on-chain bytecode matches a local compilation of the Move code" before trusting/depending on a package [1](#0-0) . Its implementation:
1. Locally builds the package to get `compiled_metadata` (`pack.extract_metadata()`), not the compiled bytecode units, for comparison [8](#0-7) .
2. Fetches only the on-chain `PackageRegistry`/metadata via `CachedPackageRegistry::create(client, self.account, false)` — the `false` disables bytecode retrieval entirely [9](#0-8) .
3. Calls `package.verify(&compiled_metadata)`, which only diffs metadata struct fields (`name`, `deps`, `modules`, `manifest`, `upgrade_policy`, `extension`, `source_digest`) [10](#0-9) .

Because the embedded `source` inside `ModuleMetadata` is attacker-controlled at publish time (just like the on-chain `code` bytes are), an attacker who fully controls the publish transaction can make the embedded source metadata equal to the exact source a downstream reviewer/verifier will locally recompile, while the actual bytecode differs and contains different logic. `verify()` will report all fields equal (since `pack.extract_metadata()` from the "expected" source text will match the attacker-embedded source text) and print `"Successfully verified source of package"` [11](#0-10)  even though the deployed, executing bytecode was never checked.

### Impact Explanation
This breaks the code-safety guarantee that "verified bytes, package metadata, dependency declarations, and committed module bytes" are consistent, one of the explicit publish-path invariants in scope. Any Aptos ecosystem tooling, wallet, auditor, or integrator relying on `aptos move verify-package` to attest that on-chain code matches audited/reviewed source (a common integration/trust workflow before allowing a dependency, listing a contract, or approving an upgrade) can be misled into trusting malicious bytecode that was never actually compared. This is a high-impact code-safety/trust issue because it defeats the entire purpose of the verification feature without requiring any privileged access — any account that can publish a package (permissionless) can exploit downstream verifiers of that package.

### Likelihood Explanation
Likelihood is high for any workflow that depends on `verify-package` as an assurance mechanism, since:
- Publishing packages is permissionless on Aptos.
- Nothing in the Move framework (`code.move`, `object_code_deployment.move`, native `request_publish*`) ties the declared `ModuleMetadata.source`/`source_digest` to the actual `code` bytes.
- The CLI never downloads bytecode (`with_bytecode=false`) or calls `extract_code()` for comparison in the verify path, so the mismatch is systemic rather than a rare edge case.

### Recommendation
Update `VerifyPackage`/`CachedPackageMetadata::verify` to additionally fetch on-chain bytecode per module (`CachedPackageRegistry::create(..., true)` / `get_bytecode`) and byte-for-byte compare it against the locally compiled `BuiltPackage::extract_code()` output, in addition to the existing metadata comparison. Consider also having the framework compute and check a digest over the actual bytecode (not just source) at publish time so metadata cannot silently diverge from the executed code.

### Proof of Concept
1. Attacker writes `evil.move` with backdoor logic and `innocent.move` with the same public API/benign-looking source that a would-be verifier expects.
2. Attacker compiles `evil.move` to get bytecode `code_evil`, and separately builds `innocent.move`'s package metadata (`extract_metadata()`), producing `metadata_innocent` whose `ModuleMetadata.source` embeds the innocent-looking source.
3. Attacker calls `code::publish_package_txn(owner, bcs(metadata_innocent), vec![code_evil])` (or via `object_code_deployment::publish`); nothing in `code.move`/native `request_publish` checks that `code_evil` was compiled from `metadata_innocent.modules[0].source` [12](#0-11) .
4. A reviewer runs `aptos move verify-package --account <attacker_addr>` against the innocent source tree. The CLI rebuilds `innocent.move` locally, fetches only the on-chain metadata (not bytecode) [9](#0-8) , and `package.verify()` reports success because all compared metadata fields match [10](#0-9) , even though `code_evil` (the real running bytecode) is entirely different from `innocent.move`.

    async fn execute(self) -> CliTypedResult<&'static str> {
        // First build the package locally to get the package metadata
        let build_options = BuildOptions {
            install_dir: self.move_options.output_dir.clone(),
            bytecode_version: fix_bytecode_version(
                self.move_options.bytecode_version,
                self.move_options.language_version,
            ),
            ..self.included_artifacts.build_options(&self.move_options)?
        };
        let w = self.env.writer();
        let pack = BuiltPackage::build_to(&w, self.move_options.get_package_path()?, build_options)
            .map_err(|e| CliError::MoveCompilationError(format!("{:#}", e)))?;
        let compiled_metadata = pack.extract_metadata()?;

        // Now pull the compiled package
        let client = self.rest_options.client(&self.profile_options)?;
        let registry = CachedPackageRegistry::create(client, self.account, false).await?;
        let package = registry
            .get_package(pack.name())
            .await
            .map_err(|s| CliError::CommandArgumentError(s.to_string()))?;

        // We can't check the arbitrary, because it could change on us
        if package.upgrade_policy() == UpgradePolicy::arbitrary() {
            return Err(CliError::CommandArgumentError(
                "A package with upgrade policy `arbitrary` cannot be downloaded \
                since it is not safe to depend on such packages."
                    .to_owned(),
            ));
        }

        // Verify that the source digest matches
        package.verify(&compiled_metadata)?;

        Ok("Successfully verified source of package")
    }

    pub fn verify(&self, package_metadata: &PackageMetadata) -> anyhow::Result<()> {
        let self_metadata = self.metadata;

        if self_metadata.name != package_metadata.name {
            bail!(
                "Package name doesn't match {} : {}",
                package_metadata.name,
                self_metadata.name
            )
        } else if self_metadata.deps != package_metadata.deps {
            bail!(
                "Dependencies don't match {:?} : {:?}",
                package_metadata.deps,
                self_metadata.deps
            )
        } else if self_metadata.modules != package_metadata.modules {
            bail!(
                "Modules don't match {:?} : {:?}",
                package_metadata.modules,
                self_metadata.modules
            )
        } else if self_metadata.manifest != package_metadata.manifest {
            bail!(
                "Manifest doesn't match {:?} : {:?}",
                package_metadata.manifest,
                self_metadata.manifest
            )
        } else if self_metadata.upgrade_policy != package_metadata.upgrade_policy {
            bail!(
                "Upgrade policy doesn't match {:?} : {:?}",
                package_metadata.upgrade_policy,
                self_metadata.upgrade_policy
            )
        } else if self_metadata.extension != package_metadata.extension {
            bail!(
                "Extensions doesn't match {:?} : {:?}",
                package_metadata.extension,
                self_metadata.extension
            )
        } else if self_metadata.source_digest != package_metadata.source_digest {
            bail!(
                "Source digests doesn't match {:?} : {:?}",
                package_metadata.source_digest,
                self_metadata.source_digest
            )
        }

        Ok(())
    }

    public fun publish_package(owner: &signer, pack: PackageMetadata, code: vector<vector<u8>>) acquires PackageRegistry {
        // Disallow incompatible upgrade mode. Governance can decide later if this should be reconsidered.
        assert!(
            pack.upgrade_policy.policy > upgrade_policy_arbitrary().policy,
            error::invalid_argument(EINCOMPATIBLE_POLICY_DISABLED),
        );

        let addr = signer::address_of(owner);
        if (!exists<PackageRegistry>(addr)) {
            move_to(owner, PackageRegistry { packages: vector::empty() })
        };

        // Checks for valid dependencies to other packages
        let allowed_deps = check_dependencies(addr, &pack);

        // Check package against conflicts
        // To avoid prover compiler error on spec
        // the package need to be an immutable variable
        let module_names = get_module_names(&pack);

        // Record, per module in this package, the object's transitive root owner at (re)publish, so
        // lazy self-init can detect a later transfer of the object or an ancestor since that module
        // was published (see `init::internal_maybe_initialize`). Objects only; feature-gated.
        if (features::is_lazy_module_initialization_enabled() && object::is_object(addr)) {
            let owner = object::address_to_object<object::ObjectCore>(addr).root_owner();
            module_names.for_each_ref(|name| {
                init::record_deploy_owner(addr, *name.bytes(), owner);
            });
        };
        let package_immutable = &borrow_global<PackageRegistry>(addr).packages;
        let len = package_immutable.length();
        let index = len;
        let upgrade_number = 0;
        package_immutable.enumerate_ref(|i, old| {
            let old: &PackageMetadata = old;
            if (old.name == pack.name) {
                upgrade_number = old.upgrade_number + 1;
                check_upgradability(old, &pack, &module_names);
                index = i;
            } else {
                check_coexistence(old, &module_names)
            };
        });

        // Assign the upgrade counter.
        pack.upgrade_number = upgrade_number;

        let packages = &mut borrow_global_mut<PackageRegistry>(addr).packages;
        // Update registry
        let policy = pack.upgrade_policy;
        if (index < len) {
            pack.modules.for_each_ref(|m| {
                let m: &ModuleMetadata = m;
                init::reset_initialized(addr, *m.name.bytes());
            });
            *packages.borrow_mut(index) = pack
        } else {
            packages.push_back(pack)
        };

        event::emit(PublishPackage {
            code_address: addr,
            is_upgrade: upgrade_number > 0
        });

        // Request publish
        if (features::code_dependency_check_enabled())
            request_publish_with_allowed_deps(addr, module_names, allowed_deps, code, policy.policy)
        else
        // The new `request_publish_with_allowed_deps` has not yet rolled out, so call downwards
        // compatible code.
            request_publish(addr, module_names, code, policy.policy)
    }

fn native_request_publish(
    context: &mut SafeNativeContext,
    _ty_args: &[Type],
    mut args: VecDeque<Value>,
) -> SafeNativeResult<SmallVec<[Value; 1]>> {
    debug_assert!(matches!(args.len(), 4 | 5));
    let with_allowed_deps = args.len() == 5;

    context.charge(CODE_REQUEST_PUBLISH_BASE)?;

    let policy = safely_pop_arg!(args, u8);
    let mut code = vec![];
    for module in safely_pop_arg!(args, Vec<Value>) {
        let module_code = module.value_as::<Vec<u8>>()?;

        context.charge(CODE_REQUEST_PUBLISH_PER_BYTE * NumBytes::new(module_code.len() as u64))?;
        code.push(module_code);
    }

    let allowed_deps = if with_allowed_deps {
        let mut allowed_deps: BTreeMap<AccountAddress, BTreeSet<String>> = BTreeMap::new();

        for dep in safely_pop_arg!(args, Vec<Value>) {
            let (account, module_name) = unpack_allowed_dep(dep)?;

            let entry = allowed_deps.entry(account);

            if let Entry::Vacant(_) = &entry {
                // TODO: Is the 32 here supposed to indicate the length of an account address in bytes?
                context.charge(CODE_REQUEST_PUBLISH_PER_BYTE * NumBytes::new(32))?;
            }

            context
                .charge(CODE_REQUEST_PUBLISH_PER_BYTE * NumBytes::new(module_name.len() as u64))?;
            entry.or_default().insert(module_name);
        }

        Some(allowed_deps)
    } else {
        None
    };

    let mut expected_modules = BTreeSet::new();
    for name in safely_pop_arg!(args, Vec<Value>) {
        let str = get_move_string(name)?;

        // TODO(Gas): fine tune the gas formula
        context.charge(CODE_REQUEST_PUBLISH_PER_BYTE * NumBytes::new(str.len() as u64))?;
        expected_modules.insert(str);
    }

    let destination = safely_pop_arg!(args, AccountAddress);

    // Add own modules to allowed deps
    let allowed_deps = allowed_deps.map(|mut allowed| {
        allowed
            .entry(destination)
            .or_default()
            .extend(expected_modules.clone());
        allowed
    });

    let code_context = context.extensions_mut().get_mut::<NativeCodeContext>();
    if code_context.requested_module_bundle.is_some() || !code_context.enabled {
        // Can't request second time or if publish requests are not allowed.
        return Err(SafeNativeError::abort(EALREADY_REQUESTED));
    }
    code_context.requested_module_bundle = Some(PublishRequest {
        destination,
        bundle: ModuleBundle::new(code),
        expected_modules,
        allowed_deps,
        check_compat: policy != ARBITRARY_POLICY,
    });

    Ok(smallvec![])
}
