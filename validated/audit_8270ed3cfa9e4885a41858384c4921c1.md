**Reasoning:** `Verifier::update_finalized_payouts` (which writes `payout_tx_blockhash` into the `withdrawals` table, later read by `is_kickoff_malicious` via `get_payout_info_from_move_txid`) is only ever invoked from `Verifier::handle_finalized_block` [1](#0-0) , which is itself only called through `FinalizedBlockFetcherTask::run_once`'s `BlockHandler::handle_new_block` path, gated by `self.paramset.is_block_finalized(expected_next_finalized, new_block_height)` [2](#0-1) . `is_block_finalized` requires `chain_tip_height - block_height + 1 >= self.finality_depth` [3](#0-2) , meaning the block whose hash gets written into the DB has already accumulated `finality_depth` confirmations at write time. For the attacker's described exploit — reorging away that specific block strictly after the DB write but before `is_kickoff_malicious` runs — the attacker would need to reorg out a block that already has at least `finality_depth` confirmations, which requires sustained majority hashrate. That attack class is explicitly excluded by the threat model ("Reject malicious peers or nodes, key compromise, majority hashrate..."). Shallower reorgs (below `finality_depth`) are handled by `handle_reorg_events` marking blocks non-canonical before the block is ever considered "finalized" and processed by `update_finalized_payouts`, so no stale value can leak into the DB from an unprivileged attacker's reorg. `is_kickoff_malicious` itself just re-reads this already-finality-gated DB value [4](#0-3) ; since the value is finality-depth-gated at the point of write, there's no reachable window for an attacker without majority hashrate to make it diverge from the true canonical chain.

    /// Checks if a block is finalized. In clementine and citrea, finality depth means the amount of confirmations needed for a block to be considered finalized.
    /// The chain tip has 1 confirmation.
    pub fn is_block_finalized(&self, block_height: u32, chain_tip_height: u32) -> bool {
        if block_height > chain_tip_height {
            return false;
        }

        chain_tip_height - block_height + 1 >= self.finality_depth
    }
