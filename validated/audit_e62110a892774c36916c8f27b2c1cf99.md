## Title
Stake snapshot cached for lifetime of a QUIC connection lets a validator's identity retain elevated TPU stream quota after its stake drops - (File: `streamer/src/nonblocking/swqos.rs`, `streamer/src/nonblocking/quic.rs`)

## Summary
The report describes a class of bug where a configuration/state change (`setRegistry`) is applied globally, but previously-installed entities (modules) are never re-validated against the new state, so they keep operating with stale, now-incorrect security parameters. The Agave analog is in the QUIC TPU streamer's stake-weighted QoS layer: a connection's `peer_type`/`total_stake` is looked up **once**, at connection establishment (`SwQos::build_connection_context` / `get_connection_stake`), from the periodically-refreshed `StakedNodes` map. That single snapshot is then used to compute the connection's `max_uni_streams` limit and per-throttling-interval stream budget for the **entire lifetime of the connection** (`context.clone()` is carried through `handle_connection`'s stream-accept loop). If the peer's stake subsequently drops (stake deactivation, delegation withdrawal, epoch-boundary stake change, or an admin removing a `staked-nodes-overrides` entry via `admin_rpc_service::set_staked_nodes_overrides`), the already-open connection is never re-evaluated and keeps its stake-derived allowance until the connection itself is torn down.

## Finding Description
`StakedNodes` (the authoritative stake table used by the QUIC server) is refreshed every `STAKE_REFRESH_CYCLE` (5s) by `StakedNodesUpdaterService`: [1](#0-0) 

When a new QUIC connection is accepted, `SwQos::build_connection_context` performs a single lookup of the peer's current stake via `get_connection_stake` and bakes the resulting `peer_type`/`total_stake` into `SwQosConnectionContext`: [2](#0-1) 

That `total_stake`/`peer_type` is then used to compute `max_uni_streams` for the connection (`compute_max_allowed_uni_streams_with_rtt`) and the per-throttling-interval budget (`max_streams_per_throttling_interval`) purely as a function of the cached values, not a fresh stake lookup: [3](#0-2) [4](#0-3) [5](#0-4) 

The context is cloned once and carried through the connection's whole stream-processing loop in `handle_connection`, which never re-derives `peer_type`/stake from the live `StakedNodes` table again — it only re-reads cached RTT for stats purposes, explicitly noting staleness there is "not the end of the world," but no equivalent staleness tolerance analysis is made for the stake-derived QoS quota: [6](#0-5) 

This mirrors the report's broken invariant exactly: the "registry" (here, `StakedNodes`) is the single source of truth for whether a "module" (here, a peer connection) should be trusted/limited, but once a module (connection) is admitted, subsequent changes to the registry (stake changes, admin override edits) are never propagated to it. The `_configureRegistry`-style guard the report recommends ("iterate through each module and re-check against the registry") has no counterpart in the streamer: there is no mechanism that walks the `staked_connection_table` and demotes/re-throttles connections whose backing stake has fallen since admission.

## Impact Explanation
This falls into the "non-RPC remote exhaustion/crash" category for an unprivileged path: a connection admitted while its identity held meaningful stake is granted a disproportionately large concurrent-uni-stream limit and throttling budget (`QUIC_MAX_STAKED_CONCURRENT_STREAMS`-scale, vs. `QUIC_MAX_UNSTAKED_CONCURRENT_STREAMS` for unstaked peers) via `compute_max_allowed_uni_streams_with_rtt`. If that stake is later withdrawn/deactivated (which the connecting party fully controls — nothing prevents deactivating a stake account after opening TPU connections), the connection keeps consuming TPU resources (streams, worker threads/CPU in `handle_connection`, packet queue capacity) as if it were still highly staked, for as long as the QUIC connection stays alive (bounded only by idle timeouts/handshake keepalive, which an attacker can maintain indefinitely). This lets a formerly-staked identity sustain a stream/packet load on the TPU far beyond what its current (near-zero) stake would otherwise permit, degrading TPU capacity for legitimately staked traffic.

## Likelihood Explanation
Moderate-to-high likelihood: staking/deactivating a stake account is a normal, permissionless, unprivileged operation available to any accountholder; opening and holding open a long-lived QUIC connection is trivial. No malicious validator/node/admin collusion is required — the attacker only needs to control a stake account and a TPU client identity, both of which are ordinary user capabilities. The 5-second `StakedNodesUpdaterService` refresh cycle for the underlying map further confirms stake is expected to be dynamic and can legitimately change while connections remain open for far longer than 5 seconds.

## Recommendation
Periodically re-validate each open connection's stake against the live `StakedNodes` table (e.g., on a timer or on each `on_stream_accepted`/`on_new_stream` call) and recompute `peer_type`, `max_uni_streams`, and throttling eligibility accordingly, demoting or closing connections whose backing stake has fallen below the threshold used at admission — analogous to the report's recommendation to re-check every "module" against the registry whenever the registry's underlying trust parameters change.

## Proof of Concept
1. Stake an identity sufficiently to be treated as `ConnectionPeerType::Staked` by `SwQos::build_connection_context` (stake_ratio above `min_stake_ratio`).
2. Open a QUIC TPU connection from that identity; `SwQos::try_add_connection` admits it into `staked_connection_table` and `cache_new_connection` sets `max_uni_streams` based on the (large) stake, per [7](#0-6) .
3. Deactivate/withdraw the stake so the identity's current stake in `StakedNodes` drops to (near) zero — this table is refreshed independently every 5 seconds by `StakedNodesUpdaterService`.
4. Keep the already-open QUIC connection alive and continue opening unidirectional streams; `handle_connection`'s loop ( [8](#0-7) ) keeps using the original `context` (with the stale, high `peer_type`/`total_stake`), so the connection continues to be granted the elevated stream quota/throttle budget it received while staked, undiminished by the stake withdrawal.

const STAKE_REFRESH_CYCLE: Duration = Duration::from_secs(5);

pub struct StakedNodesUpdaterService {
    thread_hdl: JoinHandle<()>,
}

impl StakedNodesUpdaterService {
    pub fn new(
        exit: Arc<AtomicBool>,
        bank_forks: Arc<RwLock<BankForks>>,
        staked_nodes: Arc<RwLock<StakedNodes>>,
        staked_nodes_overrides: Arc<RwLock<HashMap<Pubkey, u64>>>,
    ) -> Self {
        let thread_hdl = Builder::new()
            .name("solStakedNodeUd".to_string())
            .spawn(move || {
                while !exit.load(Ordering::Relaxed) {
                    let stakes = {
                        let root_bank = bank_forks.read().unwrap().root_bank();
                        root_bank.current_epoch_staked_nodes()
                    };
                    let overrides = staked_nodes_overrides.read().unwrap().clone();
                    *staked_nodes.write().unwrap() = StakedNodes::new(stakes, overrides);
                    std::thread::sleep(STAKE_REFRESH_CYCLE);
                }
            })
            .unwrap();

        Self { thread_hdl }
    }

fn compute_max_allowed_uni_streams_with_rtt(
    rtt_millis: u32,
    peer_type: ConnectionPeerType,
    total_stake: u64,
) -> u32 {
    let streams = match peer_type {
        ConnectionPeerType::Staked(peer_stake) => {
            // No checked math for f64 type. So let's explicitly check for 0 here
            if total_stake == 0 || peer_stake > total_stake {
                warn!(
                    "Invalid stake values: peer_stake: {peer_stake:?}, total_stake: \
                     {total_stake:?}"
                );

                QUIC_MIN_STAKED_CONCURRENT_STREAMS
            } else {
                let delta = (QUIC_TOTAL_STAKED_CONCURRENT_STREAMS
                    - QUIC_MIN_STAKED_CONCURRENT_STREAMS) as f64;

                (((peer_stake as f64 / total_stake as f64) * delta) as u32
                    + QUIC_MIN_STAKED_CONCURRENT_STREAMS)
                    .clamp(
                        QUIC_MIN_STAKED_CONCURRENT_STREAMS,
                        QUIC_MAX_STAKED_CONCURRENT_STREAMS,
                    )
            }
        }
        ConnectionPeerType::Unstaked => QUIC_MAX_UNSTAKED_CONCURRENT_STREAMS,
    };
    // scale amount of streams based on RTT if RTT is larger than REFERENCE_RTT_MS
    // multiply first then divide to avoid rounding errors.
    (streams.saturating_mul(rtt_millis.clamp(REFERENCE_RTT_MS, MAX_RTT_MS))) / REFERENCE_RTT_MS
}

impl QosController<SwQosConnectionContext> for SwQos {
    fn build_connection_context(&self, connection: &Connection) -> SwQosConnectionContext {
        let remote_address = connection.remote_address();
        get_connection_stake(connection, &self.staked_nodes).map_or(
            SwQosConnectionContext {
                peer_type: ConnectionPeerType::Unstaked,
                total_stake: 0,
                remote_pubkey: None,
                in_staked_table: false,
                remote_address,
                stream_counter: None,
                last_update: Arc::new(AtomicU64::new(timing::timestamp())),
            },
            |(pubkey, stake, total_stake)| {
                // The heuristic is that the stake should be large enough to have 1 stream pass through within one throttle
                // interval during which we allow max (MAX_STREAMS_PER_MS * STREAM_THROTTLING_INTERVAL_MS) streams.

                let peer_type = {
                    let max_streams_per_ms = self.staked_stream_load_ema.max_streams_per_ms();
                    let min_stake_ratio =
                        1_f64 / (max_streams_per_ms * STREAM_THROTTLING_INTERVAL_MS) as f64;
                    let stake_ratio = stake as f64 / total_stake as f64;
                    if stake_ratio < min_stake_ratio {
                        // If it is a staked connection with ultra low stake ratio, treat it as unstaked.
                        ConnectionPeerType::Unstaked
                    } else {
                        ConnectionPeerType::Staked(stake)
                    }
                };

                SwQosConnectionContext {
                    peer_type,
                    total_stake,
                    remote_pubkey: Some(pubkey),
                    in_staked_table: false,
                    remote_address,
                    last_update: Arc::new(AtomicU64::new(timing::timestamp())),
                    stream_counter: None,
                }
            },
        )
    }

async fn handle_connection<Q, C>(
    packet_sender: Sender<PacketBatch>,
    remote_address: SocketAddr,
    connection: Connection,
    stats: Arc<StreamerStats>,
    wait_for_chunk_timeout: Duration,
    max_stream_data_bytes: u32,
    context: C,
    qos: Arc<Q>,
    cancel: CancellationToken,
) where
    Q: QosController<C> + Send + Sync + 'static,
    C: ConnectionContext + Send + Sync + 'static,
{
    let peer_type = context.peer_type();
    debug!(
        "quic new connection {} streams: {} connections: {}",
        remote_address,
        stats.active_streams.load(Ordering::Relaxed),
        stats.total_connections.load(Ordering::Relaxed),
    );
    stats.total_connections.fetch_add(1, Ordering::Relaxed);

    // cache the RTT to avoid grabbing lock for every stream.
    // we only use that for some stats here, so if it gets stale during connection lifetime
    // it is not the end of the world.
    let rtt = connection.rtt();
    'conn: loop {
        // Wait for new streams. If the peer is disconnected we get a cancellation signal and stop
        // the connection task.
        let mut stream = select! {
            stream = connection.accept_uni() => match stream {
                Ok(stream) => stream,
                Err(e) => {
                    debug!("stream error: {e:?}");
                    break;
                }
            },
            _ = cancel.cancelled() => break,
        };

        qos.on_new_stream(&context).await;
        qos.on_stream_accepted(&context);
        stats.active_streams.fetch_add(1, Ordering::Relaxed);
        stats.total_new_streams.fetch_add(1, Ordering::Relaxed);

        let mut meta = Meta::default();
        meta.set_socket_addr(&remote_address);
        meta.set_from_staked_node(matches!(peer_type, ConnectionPeerType::Staked(_)));
