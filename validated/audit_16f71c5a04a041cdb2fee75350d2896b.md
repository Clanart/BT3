### Title
Unbounded Python-Level Recursion in Wallet Outer-Puzzle/Driver Matching Enables Offer/Spend-Triggered Denial of Service - ([File: chia/wallet/outer_puzzles.py])

### Summary
The CVE-2024-25111 bug class is an uncontrolled-recursion Denial of Service triggered by attacker-supplied nested input that a decoder recursively unwinds without a depth bound. The wallet's outer-puzzle/driver matching pipeline (`match_puzzle` and each outer-puzzle driver's `match`/`get_inner_puzzle`/`construct`/`solve` implementations) recurses once per curried puzzle "layer" with no depth limit, and puzzle curry-nesting is essentially free to construct (near-zero CLVM cost), letting a counterparty supply a puzzle reveal or offer with an attacker-chosen number of layers.

### Finding Description
`match_puzzle()` dispatches to the driver for an `UnknownPuzzle` and each driver recurses into its `also()`/inner-puzzle chain to walk arbitrarily many CAT/singleton/metadata/ownership/transfer-program/CR/revocation layers: [1](#0-0) 

`PuzzleInfo.also()` and `check_type()` recurse through an unbounded "also" chain to reconstruct a driver dictionary: [2](#0-1) 

The NFT `MetadataOuterPuzzle` driver recurses into `self._match`, `self._construct`, `self._get_inner_puzzle`, and `self._get_inner_solution` for each nested "also" layer with no depth guard: [3](#0-2) 

`debug_spend_bundle.recursive_uncurry_dump()` similarly recurses per curry layer of an arbitrary puzzle with no bound: [4](#0-3) 

None of these paths run through CLVM execution cost accounting — `curry()` produces `(2 (1 . self) fixed_args)` structural wrapping that is cheap to nest arbitrarily deep, and `uncurry()`/`match()` calls operate purely in Python on the resulting `Program` tree: [5](#0-4) 

By contrast, the codebase explicitly recognizes this recursion-depth risk elsewhere and has deliberately eliminated it: `sha256_treehash()` is implemented iteratively "to avoid Python recursion limits on deeply nested CLVM" and the Rust-backed Data Layer insertion path raises `chia_rs.datalayer.RecursionDepthExceededError` rather than blowing the native stack: [6](#0-5) [7](#0-6) 

The outer-puzzle/driver-matching code has no equivalent protection: it is genuinely recursive Python code, gated only by the interpreter's default recursion limit, and reachable from untrusted, attacker-controlled puzzle structure delivered via an offer file, a coin spend's puzzle reveal, or synced coin-state data (e.g. `NFTWallet.puzzle_solution_received()` uncurrying an incoming puzzle via `UncurriedNFT.uncurry()`/`nft_puzzle_utils.recurry_nft_puzzle()`): [8](#0-7) [9](#0-8) 

Offers are decoded and their driver dictionary reconstructed from spend-bundle data supplied by the counterparty, exercising exactly this recursive matching machinery: [10](#0-9) 

### Impact Explanation
A malicious offer counterparty (or a peer relaying a crafted coin spend/puzzle reveal to a syncing wallet) can construct a puzzle with a very large number of curried/"also" layers. When the receiving wallet attempts to parse/match that puzzle to identify the asset type (offer summary, NFT/CAT/DID recognition, `puzzle_solution_received`), the unbounded Python recursion in `match_puzzle`, `PuzzleInfo.also()`/`check_type()`, `MetadataOuterPuzzle`, and `UncurriedNFT.uncurry()` can exceed Python's recursion limit and raise an unhandled `RecursionError`, crashing the wallet's processing of that transaction/offer — a spend/offer-triggered transaction-processing halt for the victim wallet.

### Likelihood Explanation
Constructing deeply nested curried puzzles is inexpensive: `curry()` is pure structural wrapping with negligible CLVM execution cost, so an attacker can cheaply produce puzzle reveals with thousands of nesting layers well within normal size/cost limits enforced at the mempool/consensus layer (those limits gate CLVM execution cost, not Python-side driver-matching recursion depth). Any wallet user who takes an offer, or any wallet syncing coin states/spends from an untrusted or semi-trusted peer, can trigger the vulnerable code path without any special privileges.

### Recommendation
Convert the outer-puzzle/driver matching recursion (`match_puzzle`, `PuzzleInfo.also()`/`check_type()`, and each driver's `match`/`get_inner_puzzle`/`get_inner_solution`/`construct`/`solve` implementations, plus `UncurriedNFT.uncurry()`'s chained uncurrying and `recursive_uncurry_dump()`) to iterative implementations with an explicit maximum layer-depth bound, following the same pattern already used for `sha256_treehash()`. Reject or gracefully error on puzzles/offers exceeding the bound instead of allowing unbounded recursion, and add regression tests analogous to the existing `test_insert_into_data_store_from_file_line_graph_depth` deep-recursion test.

### Proof of Concept
Conceptual PoC (cannot be executed without filesystem/terminal access in this session):
1. Programmatically build an inner puzzle and wrap it with `NFT_STATE_LAYER_MOD.curry(...)`/`NFT_OWNERSHIP_LAYER.curry(...)` (or nested `PuzzleInfo` "also" dictionaries) tens of thousands of times to produce a `Program` with deep curry/"also" nesting.
2. Embed this puzzle as an offered/requested asset's puzzle reveal in a `WalletSpendBundle` and encode it as a bech32 offer via `Offer.to_bech32()`, or deliver it as a coin spend puzzle reveal to a syncing wallet.
3. Have the victim wallet call `Offer.from_bech32()` / `offer.summary()` (which invokes `match_puzzle`) or have `NFTWallet.puzzle_solution_received()` process the incoming coin, triggering the deep recursive `match`/`uncurry` chain and causing a `RecursionError` that halts processing of that transaction.

Note: I was not able to execute or fully trace every intermediate driver call site (e.g., the exact call chain from `WalletStateManager` into `match_puzzle` for arbitrary incoming coin states) within the available tool budget; this should be verified end-to-end in a running environment before treating the depth bound as confirmed absent everywhere in the pipeline.

    def curry(self, *args) -> Program:
        fixed_args: Any = 1
        for arg in reversed(args):
            fixed_args = [4, (1, arg), fixed_args]
        return Program.to([2, (1, self), fixed_args])

    def uncurry(self) -> tuple[Program, Program]:
        def match(o: CLVMStorage, expected: bytes) -> None:
            if o.atom != expected:
                raise ValueError(f"expected: {expected.hex()}")

        try:
            # (2 (1 . <mod>) <args>)
            ev, quoted_inner, args_list = self.as_iter()
            match(ev, b"\x02")
            if TYPE_CHECKING:
                # this being False is presently handled in the TypeError exception handler below
                assert quoted_inner.pair is not None
            match(quoted_inner.pair[0], b"\x01")
            mod = quoted_inner.pair[1]
            args = []
            while args_list.pair is not None:
                # (4 (1 . <arg>) <rest>)
                cons, quoted_arg, rest = args_list.as_iter()
                match(cons, b"\x04")
                if TYPE_CHECKING:
                    # this being False is presently handled in the TypeError exception handler below
                    assert quoted_arg.pair is not None
                match(quoted_arg.pair[0], b"\x01")
                args.append(quoted_arg.pair[1])
                args_list = rest
            match(args_list, b"\x01")
            return Program.to(mod), Program.to(args)
        except ValueError:  # too many values to unpack
            # when unpacking as_iter()
            # or when a match() fails
            return self, self.to(0)
        except TypeError:  # NoneType not subscriptable
            # when an object is not a pair or atom as expected
            return self, self.to(0)
        except EvalError:  # first of non-cons
            # when as_iter() fails
            return self, self.to(0)

    def uncurry(cls, mod: Program, curried_args: Program) -> Self | None:
        """
        Try to uncurry a NFT puzzle
        :param cls UncurriedNFT class
        :param mod: uncurried Puzzle program
        :param uncurried_args: uncurried arguments to program
        :return Uncurried NFT
        """
        if mod != SINGLETON_TOP_LAYER_MOD:
            log.debug("Cannot uncurry NFT puzzle, failed on singleton top layer: Mod %s", mod)
            return None
        try:
            (singleton_struct, nft_state_layer) = curried_args.as_iter()
            singleton_mod_hash = singleton_struct.first()
            singleton_launcher_id = singleton_struct.rest().first()
            launcher_puzhash = singleton_struct.rest().rest()
        except ValueError as e:
            log.debug("Cannot uncurry singleton top layer: Args %s error: %s", curried_args, e)
            return None

        mod, curried_args = curried_args.rest().first().uncurry()
        if mod != NFT_MOD:
            log.debug("Cannot uncurry NFT puzzle, failed on NFT state layer: Mod %s", mod)
            return None
        try:
            # Set nft parameters
            nft_mod_hash, metadata, metadata_updater_hash, inner_puzzle = curried_args.as_iter()
            data_uris = Program.to([])
            data_hash = Program.to(0)
            meta_uris = Program.to([])
            meta_hash = Program.to(0)
            license_uris = Program.to([])
            license_hash = Program.to(0)
            edition_number = Program.to(1)
            edition_total = Program.to(1)
            # Set metadata
            for kv_pair in metadata.as_iter():
                if kv_pair.first().as_atom() == b"u":
                    data_uris = kv_pair.rest()
                if kv_pair.first().as_atom() == b"h":
                    data_hash = kv_pair.rest()
                if kv_pair.first().as_atom() == b"mu":
                    meta_uris = kv_pair.rest()
                if kv_pair.first().as_atom() == b"mh":
                    meta_hash = kv_pair.rest()
                if kv_pair.first().as_atom() == b"lu":
                    license_uris = kv_pair.rest()
                if kv_pair.first().as_atom() == b"lh":
                    license_hash = kv_pair.rest()
                if kv_pair.first().as_atom() == b"sn":
                    edition_number = kv_pair.rest()
                if kv_pair.first().as_atom() == b"st":
                    edition_total = kv_pair.rest()
            current_did: bytes32 | None = None
            transfer_program = None
            transfer_program_args = None

                current_did_atom = current_did_p.as_atom()
