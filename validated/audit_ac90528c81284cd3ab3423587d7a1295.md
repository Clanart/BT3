### Title
`retryPayload` in `HyperbridgeLzEndpoint` bypasses the pause guard enforced on `onAccept`, allowing inbound message delivery while the endpoint is paused - (File: `sdk/packages/lz-endpoint/contracts/HyperbridgeLzEndpoint.sol`)

### Summary
`HyperbridgeLzEndpoint.onAccept()` is the primary inbound delivery path from ISMP and is protected by `whenNotPaused`, ensuring the owner's pause halts new cross-chain message delivery to OApps. However, when an OApp's `lzReceive` reverts inside `onAccept`, the payload hash is stored for later recovery, and it can be replayed via `retryPayload()`. That retry function contains no `whenNotPaused` check, so a stored (previously failed) inbound payload can still be delivered to the destination OApp even while the endpoint is paused — mirroring exactly the `retryMessage`/`_nonblockingLzReceive` gap in the referenced report.

### Finding Description
`onAccept` gates all inbound delivery with `whenNotPaused`: [1](#0-0) 

When the OApp's `lzReceive` call reverts inside the `try/catch`, the payload hash is stored in `_inboundPayloadHashes` for later recovery rather than reverting the whole transaction: [2](#0-1) 

`retryPayload` is the designated recovery path for these stored payloads. It validates the payload hash, clears it, and directly calls `lzReceive` on the destination OApp — but it carries no `whenNotPaused` modifier at all: [3](#0-2) 

This is the same broken invariant as the report: the "front door" (`onAccept`/`_blockingLzReceive`) enforces the pause, but the actual state-mutating delivery logic reachable through the retry path (`retryPayload`/`_nonblockingLzReceive`) does not. Since `retryPayload` is explicitly documented as permissionless ("anyone may push a stuck payload through"), any address can call it while the contract is paused as long as a stored payload hash exists.

### Impact Explanation
When the owner pauses the endpoint (e.g., during an incident, a suspected bad relay, or a migration), the expectation communicated by both the contract's `whenNotPaused` guard and the docs ("This is a full stop on all token movement — use it for emergency situations") is that no further inbound message delivery/token minting can occur. Because `retryPayload` skips this check, an attacker or anyone holding a stored failed payload can still force delivery of that message into the destination OApp (e.g., minting tokens in `HyperFungibleToken.onAccept`-derived flows, or executing arbitrary composed calls) during the paused window, defeating the emergency stop and enabling unauthorized execution/fund movement precisely when it was meant to be blocked.

### Likelihood Explanation
Exploitation requires no privileged role: any unprivileged account can call `retryPayload` once a payload hash is present in `_inboundPayloadHashes` (created naturally whenever a destination OApp's `lzReceive` reverts, which can happen for many benign reasons, e.g., an OApp being paused itself or a transient revert). All the attacker needs is for the endpoint to be paused while such a stored payload exists — a state entirely under the control of ordinary message-failure conditions plus the owner's own pause action, not requiring any peer/relayer/prover compromise.

### Recommendation
Add the `whenNotPaused` modifier to `retryPayload` (and audit `clear`, `skip`, `nilify`, and `burn` for the same gap, since they too mutate inbound-delivery state without a pause check), so that pausing the endpoint reliably halts all inbound delivery paths, not just the initial `onAccept` call.

### Proof of Concept
1. OApp `A` on the destination chain is registered normally; the endpoint owner has not yet paused.
2. A cross-chain message arrives via `onAccept`; `A.lzReceive` reverts for any reason (e.g., transient issue), so the payload hash is stored in `_inboundPayloadHashes[A][srcEid][sender][nonce]`.
3. The endpoint owner calls `pause()`, expecting all message delivery to halt.
4. An attacker (or anyone) calls `retryPayload(A, origin, guid, message)` with the matching stored payload — this succeeds because `retryPayload` has no `whenNotPaused` check, and `A.lzReceive` is invoked directly, delivering the message (e.g., minting tokens) despite the pause. [3](#0-2)

    function onAccept(IncomingPostRequest calldata incoming) external override onlyHost whenNotPaused {
        PostRequest calldata request = incoming.request;

        // Verify source is this adapter on another chain
        if (keccak256(request.from) != keccak256(abi.encodePacked(address(this)))) revert UnknownSource();

        // Decode the LZ message from the ISMP body
        (
            bytes32 guid,
            uint32 srcEid,
            bytes32 sender,
            uint64 nonce,
            bytes32 receiver,
            bytes memory message
        ) = abi.decode(request.body, (bytes32, uint32, bytes32, uint64, bytes32, bytes));

        // Reject `expectedEid == 0` so unconfigured sources don't collide with `srcEid = 0`.
        uint32 expectedEid = _stateMachineToEid[keccak256(request.source)];
        if (expectedEid == 0 || expectedEid != srcEid) revert UnknownSource();

        // Validate and advance the nonce. The nonce is committed BEFORE (and independently of)
        // OApp execution: a reverting `lzReceive` must not roll back this write. Otherwise the
        // message would be retried forever at the same nonce and every later nonce would be
        // permanently rejected, bricking the (receiver, srcEid, sender) channel.
        address receiverAddr = address(uint160(uint256(receiver)));
        uint64 expectedNonce = _inboundNonce[receiverAddr][srcEid][sender] + 1;
        if (nonce != expectedNonce) revert InvalidNonce(expectedNonce, nonce);
        _inboundNonce[receiverAddr][srcEid][sender] = nonce;

        // Deliver to the OApp. Isolate the external call so a deterministic revert (zero
        // recipient, over-cap mint, blocklisted recipient, malformed payload, paused OApp, etc.)
        // does not revert `onAccept`. On failure the payload is retained for later retry/recovery
        // via retryPayload/clear/skip/nilify/burn.
        Origin memory origin = Origin({srcEid: srcEid, sender: sender, nonce: nonce});
        try ILayerZeroReceiver(receiverAddr).lzReceive(origin, guid, message, address(0), "") {
            // delivered successfully
        } catch {
            bytes32 payloadHash = keccak256(abi.encode(guid, message));
            _inboundPayloadHashes[receiverAddr][srcEid][sender][nonce] = payloadHash;
            emit InboundPayloadStored(receiverAddr, srcEid, sender, nonce, payloadHash);
        }
    }

    function retryPayload(
        address receiver,
        Origin calldata origin,
        bytes32 guid,
        bytes calldata message
    ) external payable {
        bytes32 stored = _inboundPayloadHashes[receiver][origin.srcEid][origin.sender][origin.nonce];
        if (stored == bytes32(0) || stored == NIL_PAYLOAD_HASH || stored != keccak256(abi.encode(guid, message))) {
            revert InvalidPayloadHash();
        }

        // Clear first; if the retry reverts, this deletion rolls back with the rest of the tx and
        // the payload remains recoverable.
        delete _inboundPayloadHashes[receiver][origin.srcEid][origin.sender][origin.nonce];

        ILayerZeroReceiver(receiver).lzReceive{value: msg.value}(origin, guid, message, msg.sender, "");
        emit InboundPayloadResolved(receiver, origin.srcEid, origin.sender, origin.nonce);
    }
