No vulnerability found for this question.

**Reasoning:**

The `calculated_signature` method's array-join-then-sort canonicalization exactly replicates Shopify's own documented app-proxy signing algorithm — sort all key/value pairs, join array values with commas, concatenate, and HMAC-SHA256 with the shared secret. [1](#0-0)  This is confirmed by the existing test suite, which already exercises complex array/bracket-style params (`baz[1]&baz[2]=b&baz[c[0]]=whatup&baz[c[1]]=notmuch`) and asserts they validate correctly against a signature Shopify would have computed the same way. [2](#0-1) 

The critical point defeating the proposed exploit is that `query_string_valid?` uses `ActiveSupport::SecurityUtils.secure_compare` against an HMAC keyed with `ShopifyApp.configuration.secret`, which the attacker does not possess. [3](#0-2)  An unprivileged attacker crafting arbitrary array-style params (`a[]=1&a[]=2`) cannot compute a matching `signature` for their forged canonical string without the secret — the test suite already demonstrates that any tampering of params (`evil=1`) against a legitimate signature is correctly rejected. [4](#0-3)  So this is not an auth-bypass primitive: it is, at most, a canonicalization-collision property inherent to Shopify's own comma-join spec (which could let a *holder of an already-validly-signed request* shuffle values within a single array param without invalidating the signature), not a way for an unprivileged attacker to forge a new signature "for any param shape" as the question claims.

Since the implementation matches Shopify's official algorithm, requires no fix, and the described attack does not defeat the HMAC/secret-based integrity check, there is no exploitable vulnerability here.

```ruby
    def query_string_valid?(query_string)
      query_hash = Rack::Utils.parse_query(query_string)

      signature = query_hash.delete("signature")
      return false if signature.nil?

      ActiveSupport::SecurityUtils.secure_compare(
        calculated_signature(query_hash),
        signature,
      )
    end
```

```ruby
    def calculated_signature(query_hash_without_signature)
      sorted_params = query_hash_without_signature.collect { |k, v| "#{k}=#{Array(v).join(",")}" }.sort.join

      OpenSSL::HMAC.hexdigest(
        OpenSSL::Digest.new("sha256"),
        ShopifyApp.configuration.secret,
        sorted_params,
      )
    end
```
