### Title
Unbounded `strings.Split` on attacker-controlled CosmWasm event attributes during EVM receipt synthesis causes excessive memory allocation - (File: app/receipt.go)

### Summary
`app.GetActionsFromWasmEvent` (invoked from `AddCosmosEventsToEVMReceiptIfApplicable`, which runs as a deferred `DeliverTx` hook after every successful transaction that emits wasm events) calls `strings.Split(value, ",")` on the raw string value of the `amounts` and `token_ids` event attributes of any wasm event whose emitting contract is registered as a CW1155↔ERC1155 pointer. The value is fully attacker-controlled CosmWasm contract output, and no length bound or gas metering is applied to the split itself, mirroring the Fulcio `extractIssuerURL` bug class (CWE-405, unbounded `strings.Split` on untrusted input causing O(n) allocation with large constant factor).

### Finding Description
In [1](#0-0) , `GetActionsFromWasmEvent` iterates over the attributes of a wasm event and, for the `amounts` and `token_ids` keys, does:

```go
case "amounts":
    curAction.Amounts = utils.Map(strings.Split(value, ","), safeBigIntFromString)
case "token_ids":
    curAction.TokenIds = utils.Map(strings.Split(value, ","), safeBigIntFromString)
``` [2](#0-1) 

This is called from `translateCW1155Event`, itself called from `AddCosmosEventsToEVMReceiptIfApplicable` [3](#0-2) , which runs whenever a `DeliverTx` produces `wasmtypes.WasmModuleEventType` events and the emitting contract address resolves via `app.EvmKeeper.GetERC1155CW1155Pointer` to a registered ERC1155 pointer.

The `value` string comes directly from a CosmWasm contract's emitted event attribute. Attribute *content* is essentially free-form and only lightly gas-metered during contract execution — the wasm gas register charges roughly `DefaultEventAttributeDataCost = 1` SDK gas per byte of attribute data with a `DefaultEventAttributeDataFreeTier = 100`-byte free allowance [4](#0-3) [5](#0-4) . That charge is applied against the *original* transaction gas meter during `handleContractResponse` [6](#0-5) , but the subsequent post-execution log translation in `app/receipt.go` runs under a *separate*, newly-constructed gas meter, `wasmToEvmEventCtx`, sized by `GetDeliverTxHookWasmGasLimit` (default 300,000) [7](#0-6) [8](#0-7) . Crucially, `GetActionsFromWasmEvent`/`translateCW1155Event` never call `ConsumeGas` for the cost of parsing the attribute string itself — the loop body only performs Go-native string operations (`strings.Split`, per-substring `sdk.NewIntFromString`) with no gas charge tied to `len(value)` or the number of comma-separated segments. Because a CosmWasm contract can be written to emit an attribute value of many megabytes at a cost of only ~1 gas/byte (cheap relative to overall tx gas budgets), and because that string is then split with no additional metering during the deferred hook, the actual CPU/memory cost of the split (`strings.Split` allocates a slice entry, ~16 bytes constant factor per Go runtime internals, for every comma-delimited segment) is effectively unmetered — exactly the asymmetric resource consumption pattern described in the Fulcio advisory.

Reachability: any account can deploy an arbitrary CosmWasm contract and register it as a CW1155 pointer target (the pointer registration flow only requires the contract address to be associated, not that its code faithfully implements CW1155 semantics) — pointer registration flows are exposed through `precompiles/wasmd` and `x/evm/keeper/pointer.go` [9](#0-8) . The attacker then calls `execute` on their own contract, which emits a wasm event with `action = "transfer_batch"` (or `mint_batch`/`burn_batch`) and an `amounts`/`token_ids` attribute containing a very large comma-separated payload. This tx is broadcast like any other, and `AddCosmosEventsToEVMReceiptIfApplicable`/`translateCW1155Event`/`GetActionsFromWasmEvent` runs on every full node that processes the block (part of `DeliverTx`/receipt generation, not merely RPC-side), so the memory spike is replicated across the entire validator/full-node set that processes that block.

### Impact Explanation
Every node executing the block (all validators plus all full/RPC nodes replaying it) performs the same unmetered `strings.Split` over the attacker-supplied string. A single crafted transaction can force large, effectively free (from the attacker's gas-cost perspective) memory allocations network-wide during block processing, which can degrade node performance, increase block processing time beyond acceptable thresholds, or in extreme cases exhaust node memory — a chain-wide availability risk consistent with the "block delay beyond 2.5 seconds" / node crash criteria for validity under this program.

### Likelihood Explanation
The path requires only: (1) permissionless contract deployment, (2) registering a CW1155 pointer for that contract (a normal, supported user flow, without validation that the contract implements genuine CW1155 semantics), and (3) executing the contract to emit a crafted event. All three actions are available to any unprivileged user via ordinary transactions; no validator or node compromise is needed. This makes exploitation straightforward and repeatable at low cost per attack attempt (bounded mainly by tx size/gas limits, not by the cost of the vulnerable operation itself).

### Recommendation
- Bound the length of `amounts`/`token_ids` attribute values (and the number of comma-separated fields) before calling `strings.Split`, rejecting or truncating values beyond a sane limit (e.g., matching real CW1155 batch sizes).
- Explicitly meter the cost of parsing event attributes in `GetActionsFromWasmEvent`/`translateCW1155Event` against `wasmToEvmEventCtx`'s gas meter proportional to `len(value)`, so the deferred-hook cost is bounded by `DeliverTxHookWasmGasLimit` rather than being computed before any gas check.
- Consider using `strings.Count`/streaming parse with an early-exit cap instead of materializing a full `strings.Split` slice for attacker-supplied strings.

### Proof of Concept
1. Deploy a CosmWasm contract `C` whose `execute` entrypoint, on a chosen message, emits a wasm event with attributes: `action = "transfer_batch"`, `owner`, `recipient`, `sender`, `amounts = "1,1,1,...,1"` (a string with millions of comma-separated `1`s), `token_ids` similarly large.
2. Register `C` as a CW1155 pointer target via the standard pointer-registration flow so `app.EvmKeeper.GetERC1155CW1155Pointer(ctx, C)` resolves to a pointer address.
3. Submit a normal `MsgExecuteContract` calling the crafted entrypoint on `C`. The wasm-level gas cost of emitting the large attribute is only ~1 gas/byte (after a 100-byte free tier), which is cheap relative to typical tx gas limits, allowing multi-megabyte attribute values.
4. After `DeliverTx` succeeds, `AddCosmosEventsToEVMReceiptIfApplicable` → `translateCW1155Event` → `GetActionsFromWasmEvent` executes `strings.Split(amountsValue, ",")` and `strings.Split(tokenIdsValue, ",")` unmetered on every node processing the block, producing large slice allocations (millions of string headers) with no corresponding gas charge, reproducing the CWE-405 amplification pattern from the Fulcio advisory.

func (app *App) GetActionsFromWasmEvent(ctx sdk.Context, event abci.Event) (actions []*Action) {
	for _, attr := range event.Attributes {
		key := string(attr.Key)
		value := string(attr.Value)
		if key == "action" {
			actions = append(actions, &Action{Type: value})
			continue
		}
		if len(actions) == 0 {
			continue
		}
		curAction := actions[len(actions)-1]
		switch key {
		case "amount":
			curAction.Amount = safeBigIntFromString(value)
		case "amounts":
			curAction.Amounts = utils.Map(strings.Split(value, ","), safeBigIntFromString)
		case "token_id":
			curAction.TokenId = safeBigIntFromString(value)
		case "token_ids":
			curAction.TokenIds = utils.Map(strings.Split(value, ","), safeBigIntFromString)
		case "sender":
			curAction.Sender = app.GetEvmAddressHash(ctx, value)
		case "recipient":
			curAction.Recipient = app.GetEvmAddressHash(ctx, value)
		case "spender":
			curAction.Spender = app.GetEvmAddressHash(ctx, value)
		case "operator":
			curAction.Operator = app.GetEvmAddressHash(ctx, value)
		case "owner":
			curAction.Owner = app.GetEvmAddressHash(ctx, value)
		case "from":
			curAction.From = app.GetEvmAddressHash(ctx, value)
		case "to":
			curAction.To = app.GetEvmAddressHash(ctx, value)
		}
	}
	return
}

func (g WasmGasRegister) eventAttributeCosts(attrs []wasmvmtypes.EventAttribute, freeTier uint64) (sdk.Gas, uint64) {
	if len(attrs) == 0 {
		return 0, freeTier
	}
	var storedBytes uint64
	for _, l := range attrs {
		storedBytes += uint64(len(l.Key)) + uint64(len(l.Value))
	}
	storedBytes, freeTier = calcWithFreeTier(storedBytes, freeTier)
	// total Length * costs + attribute count * costs
	r := sdk.NewIntFromUint64(g.c.EventAttributeDataCost).Mul(sdk.NewIntFromUint64(storedBytes)).
		Add(sdk.NewIntFromUint64(g.c.EventPerAttributeCost).Mul(sdk.NewIntFromUint64(uint64(len(attrs)))))
	if !r.IsUint64() {
		panic(sdk.ErrorOutOfGas{Descriptor: "overflow"})
	}
	return r.Uint64(), freeTier
}
