### Title
Empty aggregate Schnorr signature verifies as authentic - ([File: crypto/schnorr/src/aggregate.rs](crypto/schnorr/src/aggregate.rs))

### Summary
`SchnorrAggregate::read` accepts a signature containing zero nonce points, and `SchnorrAggregate::verify` accepts it whenever the caller-supplied `keys_and_challenges` list is also empty. [1](#0-0) [2](#0-1) 

### Finding Description
`SchnorrAggregate::verify` only checks that `Rs.len() == keys_and_challenges.len()` before building verification pairs. [2](#0-1)  With an empty aggregate and an empty key/challenge list, the per-signature loop never executes, leaving only the `(-s)G` term. [3](#0-2)  A canonical zero scalar is accepted by the scalar decoder, so `s = 0` makes the entire multiexp equal the identity and verification succeeds. [4](#0-3) 

`SchnorrAggregator::complete` explicitly refuses to emit an aggregate when no signatures were added, so the empty aggregate accepted by `verify` is unreachable through the honest aggregation API. [5](#0-4) 

### Impact Explanation
An unauthenticated party can forge a serialized aggregate signature that verifies without any public key, nonce, challenge, or private key. Any protocol using `SchnorrAggregate::verify` as evidence that at least one valid signature was included can be bypassed with the empty aggregate.

### Likelihood Explanation
The attack is deterministic and requires only public input bytes fed to `SchnorrAggregate::read` followed by `verify(dst, &[])`. No secret material, malformed point, race, or protocol participant is required.

### Recommendation
Reject empty aggregates in both `SchnorrAggregate::read` and `SchnorrAggregate::verify`. At minimum, `verify` must return `false` when `keys_and_challenges.is_empty()`; enforcing the same rule during deserialization prevents an invalid object from propagating.

### Proof of Concept
Against `crypto/schnorr/src/aggregate.rs`:

```rust
use ciphersuite::{group::ff::PrimeField, Ciphersuite};
use schnorr::aggregate::SchnorrAggregate;

fn forge_empty_aggregate<C: Ciphersuite>() {
    // u32 little-endian Rs length = 0, followed by canonical scalar s = 0.
    let mut encoded = Vec::from(0u32.to_le_bytes());
    encoded.extend(C::F::ZERO.to_repr().as_ref());

    let forged = SchnorrAggregate::<C>::read(&mut encoded.as_slice()).unwrap();

    // No public keys or challenges are supplied, yet verification succeeds.
    assert!(forged.verify(b"example-dst", &[]));
}
```
