### Title
Gasless swap exchange rate derived from live DEX spot price allows block-proposer sandwich/arbitrage extraction - (File: `kaiax/gasless/impl/tx_pool.go`)

### Summary
The `kaiax/gasless` module lets any unprivileged account submit a `swapForGas` transaction that trades an ERC-20 token for KAIA to pay for gas, using `GaslessSwapRouter.getAmountIn(token, minAmountOut)` as the exchange-rate oracle. This function derives the rate directly from the live reserves of an underlying AMM pool (Uniswap-style `getReserves`), the same anti-pattern flagged in the reported rsETH issue: using a spot AMM price as an authoritative "oracle" for a privileged swap path. The block proposer — who both assembles the block (deciding transaction order) and is paid a `commission`/`SwappedForGas.commission` for facilitating the swap — is functionally analogous to the `MANAGER` role in the report: a privileged, trusted actor for whom a single price-dependent operation is enough to realize deterministic, uncompetitive profit at the expense of the gasless user or the DEX pool, by controlling the pool state at execution time.

### Finding Description
`GaslessModule.checkBalanceForSwap` validates a swap transaction at tx-pool admission time by calling the router's `getAmountIn(token, minAmountOut)`, described in code as "the current exchange rate": [1](#0-0) 

This required amount is computed from `GaslessSwapRouter`'s on-chain `getAmountIn`, which reads `dexAddress(token)`/`getDEXInfo(token)` and the underlying Uniswap pair's live reserves: [2](#0-1) 

The actual `swapForGas` execution happens later, when the block proposer builds the block and calls `GetTx`/bundles the approve+swap (+lend) transactions together: [3](#0-2) 

Because the swap price is read from the DEX pool's spot reserves at execution time (not a TWAP, and not fixed at admission), and because the entity that decides final transaction ordering within the block is the proposer itself (who is also the beneficiary of `SwappedForGas.commission`/`CommissionClaimed`): [4](#0-3) 

the proposer can insert its own trades on the referenced DEX pool immediately before the user's gasless `SwapTx` within the same block it assembles, shifting reserves so that the router's `getAmountIn`-derived rate is worse for the user (while remaining barely compliant with the pre-declared `minAmountOut`/`amountRepay` checked in `checkBalanceForSwap` and `VerifyExecutable`), then reverse the trade after, capturing the spread as guaranteed, oracle-driven arbitrage profit — mirroring the reported pattern where a privileged role uses a swap function whose rate is sourced from a manipulable price rather than from a collateral-debt or two-sided liquidity mechanism.

### Impact Explanation
This allows the block proposer to reliably extract value from gasless users' token-for-gas swaps by manipulating the DEX price within its own block, without needing any additional permission beyond ordinary block-production rights. This is unauthorized value movement from users to the proposer, analogous to the reported arbitrage extraction via a privileged, oracle-priced swap function.

### Likelihood Explanation
Every gasless `SwapTx` is a candidate: the proposer already controls block assembly for the gasless module's bundling (approve/swap/lend sequencing), and the DEX price check happens against live state rather than a manipulation-resistant reference, so the proposer needs only ordinary trading capability on the relevant DEX pool plus proposer privileges — both of which are available on any given block it produces.

### Recommendation
Do not source the gasless swap's exchange rate from a single spot AMM reading. Use a manipulation-resistant reference (e.g., TWAP with sufficient window, or a committed/attested off-chain rate with strict staleness and deviation bounds), and/or bound the allowed slippage between the rate quoted at tx-pool admission and the rate realized at execution, rejecting the swap if it deviates beyond a small tolerance instead of only checking `amountIn >= requiredAmountIn` against whatever the live pool reports at execution time.

### Proof of Concept
1. Proposer observes a pending `SwapTx` (token → KAIA) in `checkBalanceForSwap`'s admitted queue, referencing `dexAddress(token)`.
2. When building the block, proposer inserts its own large trade against the same pool immediately before the gasless bundle, moving reserves so `getAmountIn(token, minAmountOut)` yields a rate still satisfying `swapArgs.AmountIn >= requiredAmountIn` (checked in `checkBalanceForSwap`) but worse for the user than the pre-trade price.
3. `swapForGas` executes at the manipulated rate; proposer collects `commission` (per `SwappedForGas` event) reflecting the widened spread.
4. Proposer reverses its own trade later in the same or a subsequent block, retaining the arbitrage profit extracted from the user/pool.

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}
