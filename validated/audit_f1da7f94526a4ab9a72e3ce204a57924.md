## Finding

### Title
Consensus-incentive rewards are misattributed to the first message's signer for the entire batch's state-machine advance - (File: `modules/pallets/consensus-incentives/src/impls.rs`)

### Summary
`pallet-consensus-incentives::on_executed` computes a relayer reward as `(latest_height - baseline) * cost_per_block` for every state machine whose commitment advanced in a batch, but it recovers the *payee* identity only from `messages[0]`'s signature — not from whichever message actually produced each `StateMachineUpdated` event. Because `Ismp::handle_unsigned` is a fully permissionless, unsigned extrinsic that accepts an attacker-chosen `Vec<Message>` in attacker-chosen order, any unprivileged party can place their own trivially-signed consensus message first and bundle a larger, independently valid consensus proof afterward, collecting the reward for the *entire* batch's height advance regardless of who actually delivered the substantive proof.

### Finding Description
`Pallet::execute` in `modules/pallets/ismp/src/impls.rs` processes every message in the caller-supplied `Vec<Message>` sequentially, flattens all resulting events, and hands the full `messages_with_weights` and `events` vector to `T::FeeHandler::on_executed` in one call: [1](#0-0) 

`handle_unsigned` is `ensure_none`-gated (i.e., permissionless/unsigned) and simply forwards whatever `messages` the caller supplies to `execute`: [2](#0-1) 

`pallet-consensus-incentives::on_executed` then:
1. Recovers a relayer identity **only from `messages.get(0)`**.
2. Collapses **all** `StateMachineUpdated` events in the batch (from any message, any signer) into a per-`state_machine_id` highest-height map.
3. Pays the entire span `(latest_height - baseline)` to the identity recovered from message 0, for every state machine that advanced anywhere in the batch. [3](#0-2) 

The `LastRewardedHeight` watermark (see `calculate_reward`) only prevents *re-paying the same span twice across calls* — it does nothing to verify that the paid-out identity actually produced the proof responsible for the span being paid: [4](#0-3) 

Since a `Message::Consensus`'s embedded `signer`/`consensus_proof` signature is independent of who submits the `handle_unsigned` extrinsic (it's unsigned), and consensus proofs are public once broadcast/observed, any address can craft a cheap, self-signed, valid consensus message (e.g. a minimal single-block advance) to occupy slot 0, then append a second, independently-valid consensus message (their own for a different/larger advance, or one they observed elsewhere) that drives the real `StateMachineUpdated` height jump. The payout logic pays the *slot-0 signer* for the *whole batch's* advance.

### Impact Explanation
This is a direct fund-misattribution / theft-of-reward vulnerability against the `TreasuryAccount`: an unprivileged party can redirect treasury-funded consensus-relayer rewards to themselves by controlling batch composition/ordering, without having produced the proof responsible for the bulk of the paid height span. This falls squarely under "stealing or loss of funds" and "wrong beneficiary or amount" in the impact gate — reachable through a public, permissionless entrypoint (`Ismp::handle_unsigned`) with no compromised relayer, prover, or admin required.

### Likelihood Explanation
High for any active deployment with `StateMachinesCostPerBlock` configured and treasury funded: `handle_unsigned` is explicitly documented as "permit[ting] anyone execute ISMP messages for free," and batching/ordering is entirely attacker-controlled. The only requirement is producing (or observing) one additional valid consensus message beyond the attacker's own trivial one — a low bar since valid consensus proofs are cryptographic and not secret once produced.

### Recommendation
Attribute reward per triggering message rather than per batch: track which specific `Message::Consensus` entry produced each `StateMachineUpdated` event (e.g., by running the fee-handler logic per-message inside `execute`, or by having `handle_incoming_message`/`MessageResult::ConsensusMessage` carry the recovered signer alongside its events) and pay only the signer whose own proof advanced that state machine's height, rather than defaulting to `messages[0]` for the whole batch.

### Proof of Concept
1. Attacker crafts `msg_a`: a trivially valid `Message::Consensus` for `state_machine_id = X`, self-signed with their own sr25519 key, advancing the height by the minimum possible amount (or a benign no-op resubmission that still returns `Ok`).
2. Attacker obtains `msg_b`: any other independently-valid `Message::Consensus` for the same `state_machine_id = X` (their own second proof, or one observed from the network) that legitimately advances the height by a large span `N`.
3. Attacker submits `Ismp::handle_unsigned(messages = [msg_a, msg_b])`.
4. `execute` processes both, producing a single `StateMachineUpdated { state_machine_id: X, latest_height }` reflecting the combined advance.
5. `on_executed` recovers the relayer identity solely from `msg_a` (message index 0) and pays `(latest_height - baseline) * cost_per_block` — covering the *entire* span including `msg_b`'s contribution — to the attacker's account.
6. The attacker collects a reward disproportionate to (or entirely unrelated to) the proof they actually contributed, at the treasury's and/or honest relayer's expense.

	/// Calculate the reward for a message based on the state machine id
	fn calculate_reward(
		state_machine_id: &StateMachineId,
		block_cost: <T as pallet_ismp::Config>::Balance,
	) -> Result<<T as pallet_ismp::Config>::Balance, Error<T>> {
		let host = <T::IsmpHost>::default();
		let latest_height = host
			.latest_commitment_height(state_machine_id.clone())
			.map_err(|_| Error::<T>::CouldNotGetStateMachineHeight)?;
		let previous_height =
			host.previous_commitment_height(state_machine_id.clone()).unwrap_or_default();

		// Use the rewarded watermark as the baseline and fall back to the previous height until
		// the first reward is recorded for this chain. The watermark only moves forward, so a
		// height that is rolled back and later resubmitted is not paid for a second time.
		let baseline = LastRewardedHeight::<T>::get(state_machine_id).unwrap_or(previous_height);

		let blocks = latest_height.saturating_sub(baseline);

		let blocks_as_balance: <T as pallet_ismp::Config>::Balance = blocks.saturated_into();
		let reward = blocks_as_balance.saturating_mul(block_cost);

		Ok(reward)
	}

	fn on_executed(
		messages: Vec<MessageWithWeight>,
		events: Vec<IsmpEvent>,
	) -> DispatchResultWithPostInfo {
		let maybe_relayer_account = messages.get(0).and_then(|first_message| {
			if let Message::Consensus(consensus_msg) = &first_message.message {
				let data = sp_io::hashing::keccak_256(&consensus_msg.consensus_proof);
				Signature::decode(&mut &consensus_msg.signer[..])
					.ok()
					.and_then(|sig| sig.verify_and_get_sr25519_pubkey(&data, None).ok())
					.map(|pub_key| pub_key.into())
			} else {
				None::<[u8; 32]>
			}
		});

		if let Some(relayer_account) = maybe_relayer_account {
			// When a batch contains multiple `StateMachineUpdated` events for the
			// same `state_machine_id` (sequential consensus updates for the same
			// chain), `calculate_reward` reads the same persisted
			// `(latest_commitment_height, previous_commitment_height)` pair on
			// every iteration and pays the same block-span reward N times.
			// Collapse the per-state-machine event stream to the single highest
			// `latest_height` so each state machine receives one reward per
			// batch, sized by the actual span of its commitment advance.
			let mut highest_per_state_machine: BTreeMap<StateMachineId, u64> = BTreeMap::new();
			for event in events {
				if let IsmpEvent::StateMachineUpdated(update) = event {
					highest_per_state_machine
						.entry(update.state_machine_id)
						.and_modify(|h| {
							if update.latest_height > *h {
								*h = update.latest_height;
							}
						})
						.or_insert(update.latest_height);
				}
			}

			for (state_machine_id, latest_height) in highest_per_state_machine {
				let state_machine_height =
					StateMachineHeight { id: state_machine_id.clone(), height: latest_height };

				let _ = Self::process_message(
					state_machine_height,
					state_machine_id,
					relayer_account.clone().into(),
				);
			}
		}
