### Title
Gasless module trusts static `balanceOf`/`allowance` checks on whitelisted ERC20 tokens without accounting for fee-on-transfer, rebasing, or upgradable/proxy token behavior - ([File: kaiax/gasless/impl/tx_pool.go])

### Summary
The `kaiax/gasless` module admits `approve`+`swapForGas` transaction pairs into the tx pool and pre-funds (lends) KAIA gas to the sender based on a single point-in-time snapshot of the whitelisted ERC20 token's `balanceOf`/`allowance`/router-quoted `amountIn`. This mirrors the reported bug class: code that assumes standard, non-deflationary, non-upgradable ERC20 semantics can be broken by tokens whose transfer/balance behavior differs from the snapshot taken at validation time (fee-on-transfer, rebasing, or upgradable/proxy tokens like TUSD).

### Finding Description
`GaslessModule.checkBalanceForApprove` and `checkBalanceForSwap` validate a swap-for-gas transaction pair purely with static `eth_call`s to the token contract at admission time: `tokenContract.BalanceOf`, `tokenContract.Allowance`, and `routerContract.GetAmountIn` [1](#0-0) [2](#0-1) . These checks assume that `balanceOf(sender) >= amountIn` at check time guarantees the router will actually receive `amountIn` tokens during on-chain execution, and that a token whitelisted once (`AllowedTokens`, `BalanceCheckLevel`) will keep behaving as a standard fixed-supply ERC20 [3](#0-2) .

`GaslessModule.VerifyExecutable`/`IsExecutable` further compute a fixed `amountRepay` value off-chain (`repayAmount(approveTxOrNil, swapTx)`) that the sender's swap tx must exactly match [4](#0-3) , and the actual gas lending to the user is generated separately as a fixed-amount transaction based on `tx.Fee()` (see `GetLendTxGenerator`/`TestGetLendTxGenerator`, which computes `lendAmount` from the approve/swap tx fees independent of what the router will actually receive) [5](#0-4) .

If the whitelisted token is a proxy/upgradable token (e.g., TUSD-style), or later becomes a fee-on-transfer / rebasing / deflationary token via a legitimate governance-approved upgrade of its implementation, the amount actually transferred to the `GaslessSwapRouter` during `swapForGas` can be lower than `amountIn` computed and checked at tx-pool admission time. Because none of the module's checks re-verify the *received* amount post-transfer (only pre-transfer `balanceOf`), the on-chain swap can under-deliver against the `amountRepay` the CN already computed and pre-funded for.

### Impact Explanation
Since the CN advances real KAIA to the gasless user before/alongside the swap settles (`GetLendTxGenerator`), and the module's admission-time solvency checks are based on static balance/allowance snapshots rather than the token's actual transfer semantics, a whitelisted token whose logic changes (upgrade, fee-on-transfer activation, rebase) can cause the swap to deliver less value than assumed. This risks the CN's advanced gas not being fully repaid from the swap proceeds — a fee-delegation/gas-lending value loss for the block proposer, i.e. concrete unauthorized value movement away from the CN.

### Likelihood Explanation
Medium. `AllowedTokens` is governance/operator-curated, so triggering this requires a whitelisted token to actually be, or become (via upgrade), non-standard in its transfer semantics. I was not able to fully verify in-repo whether the "lend" transaction and the swap transaction are bundled atomically (such that a failed/short swap would roll back the lend), which would materially affect exploitability — this remains unverified due to running out of investigation iterations, so the exact loss mechanism (partial repayment accepted vs. full atomic revert) should be confirmed by a deeper review of the bundle/builder execution path (`kaiax/gasless/impl/builder.go`).

### Recommendation
- After the swap executes, verify the router/CN's actual received/repaid amount on-chain rather than only trusting the pre-computed `amountRepay` and pre-transfer `balanceOf` snapshot.
- Consider disallowing rebasing/fee-on-transfer/proxy-upgradable tokens from `AllowedTokens`, or re-validate token bytecode/behavior periodically.
- Ensure the lend-and-repay flow is atomic (single bundle that reverts entirely if actual repayment is insufficient) so that CN funds cannot be lent without guaranteed repayment.

### Proof of Concept
Not independently executable from the indexed context; the concrete PoC would require reproducing a fee-on-transfer/upgraded ERC20 token whitelisted in `GaslessConfig.AllowedTokens`, then submitting an approve+swap gasless bundle where `balanceOf(sender) >= amountIn` and `allowance >= amountIn` pass admission checks in `checkBalanceForSwap` [6](#0-5) , but the token's `transfer`/`transferFrom` implementation delivers less than `amountIn` to the `GaslessSwapRouter`, causing the on-chain swap to under-repay the CN relative to the already-computed `amountRepay` [7](#0-6) .

func (g *GaslessModule) checkBalanceForApprove(approveArgs *ApproveArgs) error {
	token := approveArgs.Token
	bc := backends.NewBlockchainContractBackend(g.Chain, nil, nil)

	if g.GaslessConfig.ShouldCheckSenderCode() {
		if g.getCurrentHasCode(approveArgs.Sender) {
			return errors.New("sender with code is not allowed")
		}
	}

	if g.GaslessConfig.ShouldCheckToken() {
		tokenContract, err := sc_erc20.NewERC20(token, bc)
		if err != nil {
			return err
		}

		// tx.token.balanceOf(sender) > 0
		tokenBalance, err := tokenContract.BalanceOf(nil, approveArgs.Sender)
		if err != nil {
			return err
		}
		if tokenBalance.Sign() <= 0 {
			return fmt.Errorf("insufficient sender token balance: token=%s, have=%s, want=nonzero", token.Hex(), tokenBalance.String())
		}
	}
	return nil
}

func (g *GaslessModule) checkBalanceForSwap(swapArgs *SwapArgs, swapNonce uint64) error {
	token := swapArgs.Token
	bc := backends.NewBlockchainContractBackend(g.Chain, nil, nil)

	g.gaslessInfoMu.RLock()
	swapRouter := g.swapRouter
	g.gaslessInfoMu.RUnlock()

	// tx.minAmountOut >= tx.amountRepay
	minAmountOut := swapArgs.MinAmountOut
	amountRepay := swapArgs.AmountRepay
	if minAmountOut.Cmp(amountRepay) < 0 {
		return fmt.Errorf("insufficient minAmountOut: minAmountOut=%s, amountRepay=%s", minAmountOut.String(), amountRepay.String())
	}

	if g.GaslessConfig.ShouldCheckSenderCode() {
		if g.getCurrentHasCode(swapArgs.Sender) {
			return errors.New("sender with code is not allowed")
		}
	}

	if g.GaslessConfig.ShouldCheckSwapAmount() {
		// tx.amountIn >= gsr.getAmountIn(minAmountOut)
		routerContract, err := kip247.NewGaslessSwapRouterCaller(swapRouter, bc)
		if err != nil {
			return err
		}
		// Required token amountIn, given the current exchange rate and the declared minAmountOut.
		requiredAmountIn, err := routerContract.GetAmountIn(nil, token, minAmountOut)
		if err != nil {
			return err
		}
		if swapArgs.AmountIn.Cmp(requiredAmountIn) < 0 {
			return fmt.Errorf("insufficient amountIn: have=%s, want=%s", swapArgs.AmountIn.String(), requiredAmountIn.String())
		}
	}

	if g.GaslessConfig.ShouldCheckToken() {

		tokenContract, err := sc_erc20.NewERC20(token, bc)
		if err != nil {
			return err
		}

		// If SwapTx.nonce is the sender's next nonce, then there is no room for ApproveTx proceeding SwapTx.
		senderNonce := g.getCurrentStateNonce(swapArgs.Sender)
		noApproveTxPreceeds := swapNonce == senderNonce
		if noApproveTxPreceeds {
			// tx.token.allowance(sender, router) >= tx.amountIn
			approval, err := tokenContract.Allowance(nil, swapArgs.Sender, swapRouter)
			if err != nil {
				return err
			}
			if approval.Cmp(swapArgs.AmountIn) < 0 {
				return fmt.Errorf("insufficient approval: approval=%s, want=%s", approval.String(), swapArgs.AmountIn.String())
			}
		}

		// tx.token.balanceOf(sender) >= tx.amountIn
		balance, err := tokenContract.BalanceOf(nil, swapArgs.Sender)
		if err != nil {
			return err
		}
		if balance.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("insufficient balance: balance=%s, want=%s", balance.String(), swapArgs.AmountIn.String())
		}
	}

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}
