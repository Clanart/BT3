This confirms the analog: the `GaslessSwapRouter.getAmountIn()` derives its price directly from the underlying UniswapV2-style DEX's `getAmountIn(amountOut, reserveIn, reserveOut)` spot-reserve formula [1](#0-0) , and this value is trusted both by the mempool admission check `checkBalanceForSwap` (`ShouldCheckSwapAmount`) [2](#0-1)  and by the on-chain `swapForGas` execution itself, with no TWAP or external price reference — exactly the single-block spot-price trust model PancakeBunny's attacker exploited.

### Title
Gasless swap admission and settlement trust a manipulable single-block DEX spot price, enabling proposer-fund drain via price manipulation before `swapForGas` - ([File: kaiax/gasless/impl/tx_pool.go])

### Summary
The KIP-247 gasless module lets a proposer pre-fund (lend) a user's gas via `GetLendTxGenerator`/`lendAmount` [3](#0-2) , expecting the user's bundled `SwapForGas` call to repay that exact amount by swapping ERC-20 tokens through `GaslessSwapRouter` at the DEX's current price. Both the mempool admission check (`checkBalanceForSwap`) and the on-chain `GaslessSwapRouter.getAmountIn`/`swapForGas` rely on the underlying UniswapV2-style pool's live reserve ratio as the sole price reference, with no time-weighted average or external oracle.

### Finding Description
`checkBalanceForSwap` validates `swapArgs.AmountIn >= routerContract.GetAmountIn(nil, token, minAmountOut)` using a live call to the whitelisted DEX pair [2](#0-1) . This function, per the `GaslessSwapRouter` binding, ultimately resolves to the UniswapV2 constant-product formula `getAmountIn(amountOut, reserveIn, reserveOut)` operating on the pair's current on-chain reserves [1](#0-0) . Because `reserveIn`/`reserveOut` are simply the pool's current balances, any transaction sequenced earlier in the same block that swaps a large amount through that same pool shifts the reserve ratio and therefore the reported "required amountIn" and effective exchange rate — precisely the spot-price manipulation vector used against PancakeBunny (large flash-borrowed swaps distorting AMM price before a dependent settlement executes on the manipulated rate). The user (attacker) fully controls `AmountIn`, `MinAmountOut`, and `AmountRepay` in the `swapForGas` call, and the repay amount the proposer expects is fixed by `repayAmount` = gas fee only [4](#0-3) , independent of the swap's actual value — so the attacker's real economic gain comes from whatever the DEX pool pays out for `AmountIn` tokens, which the attacker can inflate by first pushing the pool's price in their favor.

### Impact Explanation
An attacker who also controls (or bribes) the block proposer/sequencer, or who can otherwise get a preceding swap included in the same block against the whitelisted DEX pair, can manipulate the reserve ratio so that a subsequent `swapForGas` call yields far more native KAIA than the token's fair market value, draining the router's/proposer's liquidity used to fund gasless repayment. This is a concrete unauthorized value movement/fee-delegation abuse against the gasless settlement flow described in the KIP-247 module.

### Likelihood Explanation
Exploitability depends on the attacker being able to sequence a manipulating swap immediately before their own `GaslessApproveTx`/`SwapTx` bundle within the same block (e.g., by controlling the proposer, via MEV bundle submission, or if `ExtractTxBundles`' ordering permits interleaved non-gasless transactions from the same or colluding senders before the bundle) [5](#0-4) . It also requires sufficient capital or leverage to move the specific whitelisted pool's price, and the pool's liquidity depth bounds the practical profit — so likelihood is moderate and liquidity-dependent rather than trivial.

### Recommendation
Do not trust a single-block spot AMM price for either mempool admission (`checkBalanceForSwap`'s `GetAmountIn` check) or on-chain `swapForGas` settlement. Use a TWAP or multi-block-averaged price source, cap per-block price deviation, and/or bound `AmountRepay`/`MinAmountOut` against a governance-configured price ceiling independent of the live pool reserves for the whitelisted gasless tokens.

### Proof of Concept
1. Attacker identifies a whitelisted gasless token/DEX pair with limited liquidity (`allowedTokens`, `swapRouter` per `getGaslessInfo`) [6](#0-5) .
2. In the same block, attacker (as proposer or via a bribed/colluding proposer) submits a large swap against that pair to shift `reserveIn`/`reserveOut` favorably.
3. Attacker then submits `GaslessApproveTx` + `SwapForGas(token, amountIn, minAmountOut, amountRepay, deadline)` where `amountIn`/`minAmountOut` are chosen to satisfy `checkBalanceForSwap`'s `GetAmountIn` check against the now-manipulated reserves [2](#0-1) .
4. The bundle executes: proposer's `LendTxGenerator` fronts gas fee only [3](#0-2) , while attacker's swap settles at the manipulated rate, extracting excess value from the DEX pool/router relative to fair price, repaying only the fixed gas fee amount regardless of the manipulated swap's real value.

func lendAmount(approveTxOrNil, swapTx *types.Transaction) *big.Int {
	r := new(big.Int)

	// R2 = ApproveTx.Fee() if exists
	if approveTxOrNil != nil {
		r.Add(r, approveTxOrNil.Fee())
	}

	// R3 = SwapTx.Fee()
	r.Add(r, swapTx.Fee())

	// LendAmount = R2 + R3
	return r
}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
}
