### Title
Daemon debug-log redaction misses the `entropy` field, leaking mnemonic seed material in log files - (File: chia/daemon/server.py)

### Summary
The daemon's message-logging redaction routine, `redact_sensitive_data()`, hides any dict key containing `pass`, `key`, `secret`, or `mnemonic`, but the local keychain RPC responses carry raw seed bytes under the key `entropy`, which is not covered by any trigger substring.

### Finding Description
`redact_sensitive_data()` is applied to debug-log output of websocket daemon messages, matching only `("pass", "key", "secret", "mnemonic")` [1](#0-0) . However, `KeychainServer.get_all_private_keys`, `get_first_private_key`, and `get_key_for_fingerprint` place the private-key seed material in a field literally named `entropy` [2](#0-1) . `entropy` is exactly equivalent to the mnemonic (24-word seed): `KeychainProxy.get_key_for_fingerprint` reconstructs the mnemonic and private key directly from this hex value via `bytes_to_mnemonic()`/`mnemonic_to_seed()` [3](#0-2) . Because the string `entropy` does not contain `pass`, `key`, `secret`, or `mnemonic` as a substring, it passes through `redact_sensitive_data()` unmodified and would be written verbatim to the daemon's debug log whenever these commands are dispatched (matching the same log-masking bug class as CVE-2021-22219: sensitive values not registered for masking).

### Impact Explanation
If daemon debug logging is enabled (as validated by the existing test `test_message_logging_redaction`), any local wallet/GUI operation that triggers `get_all_private_keys`, `get_first_private_key`, or `get_key_for_fingerprint` over the daemon websocket would write the plaintext seed entropy to the log file, from which the full private key/mnemonic can be trivially reconstructed. Anyone with read access to the log file (e.g., support diagnostics, log shipping, or a lower-privileged local user/process with log access) gains full custody of the wallet's keys — equivalent to unauthorized private-key disclosure and complete compromise of one or more wallets.

### Likelihood Explanation
Requires debug-level logging to be enabled for `chia.daemon.server`, which is not the default but is a supported operational configuration (as exercised directly by the repository's own redaction test). No attacker interaction with the network is needed — the leak occurs purely from normal, locally-authorized keychain proxy usage (e.g., wallet startup, CLI `chia keys show`/derivation flows that go through the daemon-mediated keychain).

### Recommendation
Add `"entropy"` (and any other seed-equivalent field names such as `"ent"`) to the `redaction_triggers` collection passed to `redact_sensitive_data()` in `chia/daemon/server.py`, or switch to an explicit allow-list of loggable fields for keychain commands rather than a deny-list of substrings.

### Proof of Concept
1. Start the daemon with debug logging enabled for `chia.daemon.server` (as in `chia/_tests/core/daemon/test_daemon.py::test_message_logging_redaction`).
2. From a local client, send a `get_key_for_fingerprint` (or `get_all_private_keys`) command over the daemon websocket with `private=True`.
3. Observe the daemon log entry for the response message: the `entropy` field appears as a raw hex string rather than `***<redacted>***`, unlike `password`/`mnemonic`/`secret_value`/`private_key` fields which are correctly redacted per the existing test's `expected_redacted_data` [4](#0-3) .
4. Convert the logged `entropy` hex to bytes and run `bytes_to_mnemonic()` to recover the full 24-word mnemonic, proving complete key material disclosure via the log file.

def redact_sensitive_data(obj: Any, redaction_triggers: Collection[str] = ("pass", "key", "secret", "mnemonic")) -> Any:
    """Recursively redact sensitive data from nested dictionaries."""
    if isinstance(obj, dict):
        return {
            key: "***<redacted>***"
            if any(trigger.casefold() in key.casefold() for trigger in redaction_triggers)
            else redact_sensitive_data(value, redaction_triggers)
            for key, value in obj.items()
        }
    else:
        return obj

    async def get_all_private_keys(self, request: dict[str, Any]) -> dict[str, Any]:
        all_keys: list[dict[str, Any]] = []
        if self.get_keychain_for_request(request).is_keyring_locked():
            return {"success": False, "error": KEYCHAIN_ERR_LOCKED}

        private_keys = self.get_keychain_for_request(request).get_all_private_keys()
        for sk, entropy in private_keys:
            all_keys.append({"pk": bytes(sk.get_g1()).hex(), "entropy": entropy.hex()})

        return {"success": True, "private_keys": all_keys}

    async def get_first_private_key(self, request: dict[str, Any]) -> dict[str, Any]:
        key: dict[str, Any] = {}
        if self.get_keychain_for_request(request).is_keyring_locked():
            return {"success": False, "error": KEYCHAIN_ERR_LOCKED}

        sk_ent = self.get_keychain_for_request(request).get_first_private_key()
        if sk_ent is None:
            return {"success": False, "error": KEYCHAIN_ERR_NO_KEYS}

        pk_str = bytes(sk_ent[0].get_g1()).hex()
        ent_str = sk_ent[1].hex()
        key = {"pk": pk_str, "entropy": ent_str}

        return {"success": True, "private_key": key}

    async def get_key_for_fingerprint(self, request: dict[str, Any]) -> dict[str, Any]:
        keychain = self.get_keychain_for_request(request)
        if keychain.is_keyring_locked():
            return {"success": False, "error": KEYCHAIN_ERR_LOCKED}

        private = request.get("private", True)
        keys = keychain.get_keys(include_secrets=private)
        if len(keys) == 0:
            return {"success": False, "error": KEYCHAIN_ERR_NO_KEYS}

        try:
            if request["fingerprint"] is None:
                key_data = keys[0]
            else:
                key_data = keychain.get_key(request["fingerprint"], include_secrets=private)
        except KeychainFingerprintNotFound:
            return {"success": False, "error": KEYCHAIN_ERR_KEY_NOT_FOUND}

        return {
            "success": True,
            "pk": bytes(key_data.public_key).hex(),
            "entropy": key_data.entropy.hex() if private else None,
        }
