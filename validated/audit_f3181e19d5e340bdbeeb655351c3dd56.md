### Title
Static (non-dynamic-gas) EVM precompiles skip the ABI decode-cost surcharge, allowing gas-underpriced super-linear `Unpack` work - ([File: precompiles/common/precompiles.go])

### Summary
`Precompile.RequiredGas()` / `Precompile.Prepare()` (the static-precompile path used by precompiles registered via `NewPrecompile`, e.g. `precompiles/bank/bank.go`, `precompiles/auth/auth.go`, `precompiles/authz/authz.go`, `precompiles/addr/addr.go`, `precompiles/evidence/evidence.go`) charge gas via `p.executor.RequiredGas(input[4:], method)` and then unconditionally call `method.Inputs.Unpack(argsBz)` in `Prepare()`, with no decode-cost surcharge. This is the exact bug class in the external report: go-ethereum's ABI decoder materializes every `string`/`bytes`-bearing dynamic value via `string(output[begin:end])`, and because a single shared payload can be pointed to by many array/tuple head offsets, the copy volume it produces can be `O(len(input)^2)` even though `len(input)` (and hence any length-proportional gas charge) is small.

### Finding Description
The `precompiles/common` package itself documents and fixes this exact defect for the *dynamic-gas* precompile family: [1](#0-0) . The fix works by computing `DecodeGasCost`, which walks the ABI type tree without copying and accounts for the string-copy volume the real decoder would produce [2](#0-1) , and charging it via `chargeDecodeGas` *before* `method.Inputs.Unpack` is ever called [3](#0-2) [4](#0-3) . The in-repo test `TestVoteWeightedAliasedOptionsRejectedBeforeUnpack` explicitly demonstrates the attack this defends against: calldata of ~40 KiB whose array-of-tuples offsets all alias one shared dynamic string, producing decoded copy volume that would otherwise be many times larger than the supplied gas would normally buy [5](#0-4) .

However, the *static* precompile path — `Precompile.RequiredGas` / `Precompile.Prepare` — has no equivalent step: it resolves the method, then calls `method.Inputs.Unpack(argsBz)` directly with no pre-charge for the decode's copy cost [6](#0-5) , and `RequiredGas` simply forwards to the individual executor's `RequiredGas(input[4:], method)` [7](#0-6) . Grep across the precompile packages shows that `bank.go`, `auth.go`, `authz.go`, `addr.go`, and `evidence.go` each reference `DefaultGasCost` exactly once in their `RequiredGas` implementation (a linear, length-proportional charge only), with no corresponding `DecodeGasCost` call — unlike `gov`, whose ABI-decode surcharge is applied for free by being registered as a `DynamicGasPrecompile`. Any static precompile method whose ABI signature contains a dynamic array of strings or dynamic tuples (the shape needed for the aliasing trick: many array/tuple head offsets pointing at one shared dynamic payload) would therefore have its true `Unpack` cost dramatically underpriced by `RequiredGas`, exactly mirroring the commonmark report's "each closing bracket costs O(1) more but is priced at O(1)" imbalance.

### Impact Explanation
`vm.RunPrecompiledContract` checks `RequiredGas(input)` against the caller's supplied gas before invoking `Run`/`Prepare`/`Unpack`. If `RequiredGas` only reflects `len(input)` and not the decoder's actual copy volume, an attacker can craft a small, cheaply-gas-priced calldata blob for an affected static precompile method that nevertheless forces every executing/validating full node to perform disproportionate CPU work unpacking it. Since precompile execution happens during ordinary EVM transaction processing (not just RPC simulation), this reproduces on every validator that processes the block, which can slow block production/validation across the network — a resource-exhaustion / block-delay impact, not merely a local RPC issue.

### Likelihood Explanation
Reachability is straightforward: any unprivileged EVM transaction sender can call any of these public precompiles at their fixed addresses with attacker-chosen calldata; no privileged role or governance action is required. The only gating factor is whether at least one exposed static-precompile method's ABI signature actually contains a dynamic array of strings/tuples that permits offset aliasing — I was not able to fully enumerate every method signature across `bank`, `auth`, `authz`, `addr`, and `evidence` (and their many `legacy/vNNN` snapshots) within the available search budget, so this should be treated as a structural/architectural gap proven at the `Precompile.Prepare`/`RequiredGas` level rather than a fully instantiated exploit against a named method. Confirming or ruling out exploitability requires enumerating each static precompile's ABI for a vulnerable argument shape.

### Recommendation
Apply the same `DecodeGasCost`/`chargeDecodeGas` pre-charge that `DynamicGasPrecompile` already uses to the static `Precompile.RequiredGas`/`Prepare` path (or migrate every static precompile whose ABI can contain dynamic arrays of strings/tuples to the dynamic-gas family), so that `Unpack` is never invoked before its true string-copy cost has been paid for.

### Proof of Concept
Not independently reproduced against a specific static precompile method in this pass; the concrete PoC pattern is the one already exercised in-repo for the dynamic-gas path — `craftAliasedVoteWeightedArgs`/`newAliasedVoteWeightedArgs`, which builds a `k`-element array of tuple offsets that all point at one shared `(option, weight)` body so that calldata stays `O(k+s)` while decoded copy volume is `O(k*s)` [8](#0-7) . The same construction against any static-precompile method accepting a dynamic array of strings/tuples would need to be located and exercised through `Precompile.Prepare` (not `DynamicGasPrecompile.RunAndCalculateGas`) to confirm exploitability end-to-end.

// decodeStringCopyBytes returns the total number of string-payload bytes the ABI
// decoder would copy while unpacking data as args, mirroring go-ethereum's
// unpack traversal. It follows offsets and reads length prefixes but never
// copies payloads, so it runs in time proportional to the number of type nodes
// visited rather than the number of bytes referenced. ok is false when the
// input is structurally inconsistent or hits the traversal cap.
func decodeStringCopyBytes(args abi.Arguments, data []byte) (uint64, bool) {
	w := &decodeWalker{}
	index := 0
	virtualArgs := 0
	for _, arg := range args {
		if arg.Indexed {
			continue
		}
		if abiContainsString(arg.Type) {
			w.walk(data, (index+virtualArgs)*32, arg.Type)
			if w.failed {
				return 0, false
			}
		}
		if (arg.Type.T == abi.ArrayTy || arg.Type.T == abi.TupleTy) && !abiIsDynamic(arg.Type) {
			virtualArgs += abiTypeSize(arg.Type)/32 - 1
		}
		index++
	}
	return w.strBytes, true
}

func (p Precompile) RequiredGas(input []byte) uint64 {
	methodID, err := ExtractMethodID(input)
	if err != nil {
		return UnknownMethodCallGas
	}

	method, err := p.MethodById(methodID)
	if err != nil {
		// This should never happen since this method is going to fail during Run
		return UnknownMethodCallGas
	}
	return p.executor.RequiredGas(input[4:], method)

func (p Precompile) Prepare(evm *vm.EVM, input []byte) (sdk.Context, *abi.Method, []interface{}, error) {
	ctxer := state.GetDBImpl(evm.StateDB)
	if ctxer == nil {
		return sdk.Context{}, nil, nil, errors.New("cannot get context from EVM")
	}
	methodID, err := ExtractMethodID(input)
	if err != nil {
		return sdk.Context{}, nil, nil, err
	}
	method, err := p.MethodById(methodID)
	if err != nil {
		return sdk.Context{}, nil, nil, err
	}

	argsBz := input[4:]
	args, err := method.Inputs.Unpack(argsBz)
	if err != nil {
		return sdk.Context{}, nil, nil, err
	}

	return ctxer.Ctx(), method, args, nil
}

// bounds the DecodeGasCost scan, then the string-copy surcharge from
// DecodeGasCost. Its out-of-gas / overflow recovery is deliberately scoped to
// just these charges — a call that cannot afford the decode reverts here, while
// an executor that later exhausts its gas keeps its normal propagating
// out-of-gas semantics. Anything other than a gas-meter panic is re-raised.
func (d DynamicGasPrecompile) chargeDecodeGas(ctx sdk.Context, method *abi.Method, input []byte) (err error) {
	defer func() {
		if r := recover(); r != nil {
			switch r.(type) {
			case sdk.ErrorOutOfGas, sdk.ErrorGasOverflow:
				err = fmt.Errorf("%v", r)
			default:
				panic(r)
			}
		}
	}()
	scanCost := DefaultGasCost(input, false)
	ctx.GasMeter().ConsumeGas(scanCost, fmt.Sprintf("%s precompile calldata scan", d.name))
	decodeCost, ok := DecodeGasCost(method.Inputs, input)
	if !ok {
		// Calldata is structurally invalid (Unpack would reject it too); reject
		// now, without attempting the decode.
		return fmt.Errorf("invalid calldata encoding for %s", d.name)
	}
	// DecodeGasCost already includes scanCost; charge only the remaining
	// (string-copy) portion so the decode is priced exactly once.
	ctx.GasMeter().ConsumeGas(decodeCost-scanCost, fmt.Sprintf("%s precompile calldata decode", d.name))
	return nil
}

	// Dimensions chosen so calldata stays small (~40KiB) while decoded copy
	// volume (options*weightBytes) prices above the 12.5M gas cap used in the
	// original reproduction. If Unpack ran, allocation would be only ~8MiB —
	// CI-safe — and the error would be the post-decode max-options message
	// instead.
	const (
		options     = uint64(1024)
		weightBytes = uint64(8192)
		suppliedGas = uint64(12_500_000)
	)
	args := craftAliasedVoteWeightedArgs(options, weightBytes)
	input := append(append([]byte{}, method.ID...), args...)

	decodeGas, ok := pcommon.DecodeGasCost(method.Inputs, input)
	require.True(t, ok)

	statedb := state.NewDBImpl(ctx, k, true)
	evm := vm.EVM{StateDB: statedb}
	ret, remaining, runErr := p.RunAndCalculateGas(&evm, evmAddr, evmAddr, input, suppliedGas, big.NewInt(0), nil, false, false)

	require.NotNil(t, precompileErr)

	// stringifies to "{<descriptor>}"; the descriptor names the decode charge.
	require.Contains(t, precompileErr.Error(), "gov precompile calldata decode")

	_, found := testApp.GovKeeper.GetVote(statedb.Ctx(), 1, seiAddr)
	require.False(t, found)

// newAliasedVoteWeightedArgs builds non-canonical voteWeighted argument
// bytes: k dynamic-tuple offsets all point at one shared (option, weight) body
// whose weight string has length s. Calldata stays O(k+s); decoded copy volume
// is O(k*s).
func newAliasedVoteWeightedArgs(k, s uint64) []byte {
	tupleRel := 32 * k // offset within the array payload (after the length word)
	arrayPayload := make([]byte, 0, int(32*k+64+s))
	for range k {
		arrayPayload = append(arrayPayload, abiWord(tupleRel)...)
	}
	// Shared dynamic tuple: word0 = s (option / string length via offset 0),
	// word1 = 0 (string offset), then s payload bytes starting at tuple+32.
	arrayPayload = append(arrayPayload, abiWord(s)...)
	arrayPayload = append(arrayPayload, abiWord(0)...)
	arrayPayload = append(arrayPayload, make([]byte, s)...)

	data := append(abiWord(1), abiWord(64)...) // proposalID, options offset
	data = append(data, abiWord(k)...)
	data = append(data, arrayPayload...)
	return data
}
