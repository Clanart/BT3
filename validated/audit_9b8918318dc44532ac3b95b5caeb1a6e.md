### Title
Local vlMGP voting share can be adjusted between `castVotes()` calls, letting users earn bribes disproportionate to the voting power actually broadcast to Wombat's `Voter` - ([File: wombat/WombatBribeManager.sol])

### Summary
`WombatBribeManager` maintains a local record of each user's vlMGP vote allocation per pool and immediately stakes/unstakes that amount into the pool's `BribeRewardPool`, which begins accruing bribe rewards to the user right away. However, the actual vote weight sent to Wombat's `Voter` contract (which determines gauge emissions to the underlying pool/protocol) is only synced when the permissionless `castVotes()` function is called. This creates the same class of desync described in the external report: a user's locally-recorded voting share (which earns bribes) can diverge from the voting power that actually influenced/will influence emissions distributed by the external `Voter`.

### Finding Description
`vote()` lets any vlMGP holder freely reallocate `_deltas` across pools at any time. Any positive delta calls `IBribeRewardPool(pool.rewarder).stakeFor(msg.sender, uint256(delta))` immediately, updating `totalSupply`/`_balances` in `BribeRewardPool` (a `BaseRewardPoolV2`), which begins the time-weighted `accTokenPerShare` accrual for that user right away: [1](#0-0) 

The user's *effective* vote in Wombat's `Voter` (`getVoteForLp` -> `voter.getUserVotes(address(wombatStaking), lp)`) is only actually pushed on-chain to Wombat when someone calls `castVotes()`, which computes the delta between the currently-cast vote and the locally aggregated `pool.totalVoteInVlmgp` and forwards it to `wombatStaking.vote(...)`: [2](#0-1) 

Because `castVotes()` is permissionless and gas-intensive (hence only sporadically called, incentivized by a fee), there is no guarantee it is called every time a user's local vote changes, nor synchronized with the exact moment Wombat's gauge/emission snapshot for the epoch is taken externally. In the interim, `BribeRewardPool.stakeFor`/`withdrawFor` immediately change the user's share of the bribe pot: [3](#0-2) 

This mirrors exactly the reported bug class: a party can adjust their recorded voting weight to capture bribe rewards for a pool during a period when their weight was not (or will not be) reflected in the actual gauge vote that determines the pool's/protocol's emissions, because the local "bribe accounting" snapshot (immediate `stakeFor`/`withdrawFor`) is desynced from the external emission/vote-weight snapshot (only updated on `castVotes()`).

### Impact Explanation
Bribing protocols can pay bribes without receiving the corresponding vote weight/emissions they were paying for, and users can earn bribe yield for periods where their voting power did not actually support the bribed pool's gauge — a theft-of-yield situation for bribers and an unfair/inflated yield capture by voters, consistent with a "theft or permanent freezing of unclaimed yield" class of impact.

### Likelihood Explanation
Likelihood is medium: it requires no privileged access, just ordinary use of `vote()`/`unvote()` (unprivileged wallet functions) combined with the natural, expected latency between local vote reallocation and the permissionless `castVotes()` synchronization, similar to the epoch-boundary timing window described in the source report.

### Recommendation
Align the bribe-earning window with the actually-cast vote weight rather than the locally recorded intent: e.g., only start/stop bribe accrual (`stakeFor`/`withdrawFor`) at the time `castVotes()` actually pushes the new weight to Wombat's `Voter`, or introduce a similar post-vote grace/lock period preventing `vote()`/`unvote()` from taking immediate effect on bribe share until the next `castVotes()` sync, so a user's bribe-earning weight always matches the vote weight that influenced the corresponding emissions period.

### Proof of Concept
1. Bribing protocol funds bribes for `pool.rewarder` for pool `X`.
2. Attacker calls `vote(["X"], [+delta])`, which immediately calls `BribeRewardPool.stakeFor` and starts accruing bribe rewards for the attacker in `X`'s `BribeRewardPool`. See `wombat/WombatBribeManager.sol` lines 182-220 and `rewards/BribeRewardPool.sol` lines 57-67.
3. `castVotes()` is not called immediately afterward (it is permissionless/opportunistic and gas-costly, so it may lag by any amount of time, and is not guaranteed to align with Wombat's own emissions snapshot).
4. Before `castVotes()` next runs (i.e., before the attacker's `delta` is ever actually forwarded to `wombatStaking.vote(...)` and thus to Wombat's `Voter`), the attacker calls `unvote()`/`vote()` with a negative delta to withdraw, claiming accrued bribe rewards via `withdrawFor(..., true)` (line 236, triggering `_getReward`).
5. The attacker has earned bribes for the entire window while their locally-recorded vote existed, despite that vote weight never being reflected in the on-chain Wombat vote/emissions that the bribe was paid to influence.

    /// @notice Vote on pools. Need to compute the delta prior to casting this.
    /// @param _deltas delta amount in vlMGP
    function vote(address[] calldata _lps, int256[] calldata _deltas) override public {
        if (_lps.length != _deltas.length)
            revert LengthMismatch();

        uint256 length = _lps.length;
        int256 totalUserVote;

        for (uint256 i; i < length; i++) {
            Pool storage pool = poolInfos[_lps[i]];
            if (!pool.isActive)
                revert PoolNotActive();
            int256 delta = _deltas[i];
            totalUserVote += delta;
            if (delta != 0) {
                if (delta > 0) {
                    pool.totalVoteInVlmgp += uint256(delta);
                    userVotedForPoolInVlmgp[msg.sender][pool.poolAddress] += uint256(delta);
                    IBribeRewardPool(pool.rewarder).stakeFor(msg.sender, uint256(delta));
                } else {
                    pool.totalVoteInVlmgp -= uint256(-delta);
                    userVotedForPoolInVlmgp[msg.sender][pool.poolAddress] -= uint256(-delta);
                    IBribeRewardPool(pool.rewarder).withdrawFor(msg.sender, uint256(-delta), false);
                }
            }
        }

        if (msg.sender != delegatedPool) {
            if (totalUserVote > 0) {
                userTotalVotedInVlmgp[msg.sender] += uint256(totalUserVote);
                totalVlMgpInVote += uint256(totalUserVote);
            } else {
                userTotalVotedInVlmgp[msg.sender] -= uint256(-totalUserVote);
                totalVlMgpInVote -= uint256(-totalUserVote);
            }
        }

        if (userTotalVotedInVlmgp[msg.sender] > getUserVotable(msg.sender))
            revert NotEnoughVote();
    }

    function castVotes(bool swapForBnb)
        override public
        returns (address[][] memory finalRewardTokens, uint256[][] memory finalFeeAmounts)
    {
        lastCastTime = block.timestamp;
        uint256 length = pools.length;
        address[] memory _pools = new address[](length);
        int256[] memory votes = new int256[](length);
        address[] memory rewarders = new address[](length);

        for (uint256 i; i < length; i++) {
            Pool storage pool = poolInfos[pools[i]];
            _pools[i] = pool.poolAddress;
            rewarders[i] = pool.rewarder;

            uint256 currentVote = getVoteForLp(pool.poolAddress);
            uint256 targetVoteInLMGP = pool.totalVoteInVlmgp;
            uint256 targetVote = 0;

            if (totalVlMgpInVote != 0) {
                targetVote = targetVoteInLMGP * totalVotes() / totalVlMgpInVote;
            }

            if (targetVote >= currentVote) {
                votes[i] = int256(targetVote - currentVote);
            } else {
                votes[i] = int256(targetVote) - int256(currentVote);
            }
        }

        (address[][] memory rewardTokens, uint256[][] memory feeAmounts) = wombatStaking.vote(
            _pools,
            votes,
            rewarders,
            msg.sender
        );

    function stakeFor(address _for, uint256 _amount)
        external
        virtual
        onlyOperator
        updateRewards(_for, rewardTokens)
    {
        totalSupply = totalSupply + _amount;
        _balances[_for] = _balances[_for] + _amount;

        emit Staked(_for, _amount);
    }

    /// @notice Updates informaiton for a user in case of a withdraw. Can only be called by the Masterchief operator
    /// @param _for Address account
    /// @param _amount Amount of withdrawed tokens by the user on masterchief
    function withdrawFor(
        address _for,
        uint256 _amount,
        bool claim
    ) external virtual onlyOperator updateRewards(_for, rewardTokens) {
        totalSupply = totalSupply - _amount;
        _balances[_for] = _balances[_for] - _amount;

        emit Withdrawn(_for, _amount);

        if (claim) {
            _getReward(_for);
        }
    }
