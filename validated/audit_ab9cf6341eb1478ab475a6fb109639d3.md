## Title
Gasless module trusts external GaslessSwapRouter's stale/manipulable price quote instead of validating actual on-chain balance delta - (File: kaiax/gasless/impl/tx_pool.go)

### Summary
The `kaiax/gasless` module (Kaia's gasless-transaction facility) validates a user-submitted `swapForGas` transaction at mempool-admission/bundling time by querying the third-party `GaslessSwapRouter` contract's own view function `GetAmountIn(token, minAmountOut)` and comparing it against the sender-declared `AmountIn`, rather than computing the actually-guaranteed post-execution balance delta. This mirrors the audited Yearn adapter issue: trusting an external/third-party contract's returned value for a security-relevant admission check instead of querying the real balance state, which is unsafe when that external quote can shift between admission-time and execution-time.

### Finding Description
`checkBalanceForSwap` in [1](#0-0)  performs the following relevant checks when `BalanceCheckLevel >= BalanceCheckLevelSwapAmount`:

```go
requiredAmountIn, err := routerContract.GetAmountIn(nil, token, minAmountOut)
...
if swapArgs.AmountIn.Cmp(requiredAmountIn) < 0 {
    return fmt.Errorf("insufficient amountIn: ...")
}
```

This call reads `GetAmountIn` on the `GaslessSwapRouter` (an external/untrusted-price AMM-adjacent contract, see the ABI in [2](#0-1) ) at the *current* chain head state (`bc := backends.NewBlockchainContractBackend(g.Chain, nil, nil)`), not at the state the transaction will actually execute in. The admission check is only used to gate tx-pool promotion/bundling (`GetCheckBalance`, wired into `blockchain/tx_pool.go` and `blockchain/tx_list.go`): [3](#0-2)  and [4](#0-3) .

Because the check level is configurable (`BalanceCheckLevelSwapAmount` is optional, gated by `ShouldCheckSwapAmount()`), operators running with a lower `BalanceCheckLevel` (e.g., `BalanceCheckLevelTokenBalanceAndAllowance` or `BalanceCheckLevelStatic`) skip this quote check entirely: [5](#0-4) . Even when enabled, the check reads a value the router itself computes from its own (spoofable/AMM-dependent) internal state, exactly the "using values returned by the call to the third-party contract" pattern flagged in the audit as risky unless that third party is "fully trusted." No corresponding post-execution reconciliation (query the real token balance delta of the sender before/after the swap) is performed by the Go-side module; the actual value-safety net is delegated entirely to the (out-of-repo) on-chain `GaslessSwapRouter.sol` logic, which is not verifiable from this codebase.

### Impact Explanation
If the router's pool state can be temporarily distorted (e.g., by a preceding transaction the attacker includes in the same block/bundle, or by low liquidity), a sender can construct a `swapForGas` call whose `AmountIn`/`MinAmountOut` pair passes the mempool-time `GetAmountIn` quote check but does not correspond to the token amount that will actually be received when the underlying swap executes. Because the CN (block proposer) fronts gas via the `LendTx` in the same atomic bundle (`GetLendTxGenerator`, [6](#0-5) ), a mismatch between the admission-time quote and execution-time settlement undermines the trust assumption that the router's declared numbers reflect the true value being moved, i.e., the same "checkCollateralChange amounts must represent the actual state" concern from the audit.

### Likelihood Explanation
Medium. The `GetAmountIn` quote is read from live, mutable, price-bearing state of the swap router, and the security check depends entirely on that read being representative of what will happen at inclusion time — this is the definition of the TOCTOU/trust-model gap called out in the source finding. Exploitability is bounded by the atomic-bundle execution model (`commitBundleTransaction` reverts the whole bundle including the `LendTx` if the swap reverts, per [7](#0-6) ), which is a partial mitigation the audit's own report doesn't have visibility into; this repo's mempool-admission code does not itself perform the "query balance before/after" pattern the audit recommends, so the likelihood assessment is based on the admission-check design alone, and full exploitability cannot be verified because the on-chain `GaslessSwapRouter.sol` source (which enforces final `amountRepay`/slippage) is not present in this repository and its actual guarantees are unknown from static review.

### Recommendation
Adopt the audit's corrected pattern in the gasless module: instead of (or in addition to) trusting `GaslessSwapRouter.GetAmountIn`'s returned quote in `checkBalanceForSwap`, compute the check using values that can't be independently manipulated by the tx sender or shifted between admission and inclusion — e.g., re-validate the swap's minimum-output guarantee against actual post-execution token balances during block building (before finalizing the bundle), not just via a pre-execution external quote. Explicitly document and audit the trust assumptions placed on `GaslessSwapRouter`'s returned values, consistent with the audit's recommendation to document/assess third-party return-value trust, and prefer balance-delta verification wherever gas gate-keeping decisions are fund-relevant.

### Proof of Concept
Not independently reproducible from this repository alone because the on-chain `GaslessSwapRouter.sol` enforcement logic (which ultimately decides whether value theft is possible) is not present in the codebase — only its compiled bindings are available ( [2](#0-1) ). The reachable code path is: a public sender submits a `swapForGas` transaction; `checkBalanceForSwap` ( [1](#0-0) ) is invoked via `blockchain/tx_pool.go`'s `validateTx` ( [3](#0-2) ) using a router-supplied quote rather than a verified balance delta, demonstrating the trust-model gap; whether this is exploitable for actual value movement depends on unverified on-chain contract logic outside this repo's indexed contents.

func (g *GaslessModule) checkBalanceForSwap(swapArgs *SwapArgs, swapNonce uint64) error {
	token := swapArgs.Token
	bc := backends.NewBlockchainContractBackend(g.Chain, nil, nil)

	g.gaslessInfoMu.RLock()
	swapRouter := g.swapRouter
	g.gaslessInfoMu.RUnlock()

	// tx.minAmountOut >= tx.amountRepay
	minAmountOut := swapArgs.MinAmountOut
	amountRepay := swapArgs.AmountRepay
	if minAmountOut.Cmp(amountRepay) < 0 {
		return fmt.Errorf("insufficient minAmountOut: minAmountOut=%s, amountRepay=%s", minAmountOut.String(), amountRepay.String())
	}

	if g.GaslessConfig.ShouldCheckSenderCode() {
		if g.getCurrentHasCode(swapArgs.Sender) {
			return errors.New("sender with code is not allowed")
		}
	}

	if g.GaslessConfig.ShouldCheckSwapAmount() {
		// tx.amountIn >= gsr.getAmountIn(minAmountOut)
		routerContract, err := kip247.NewGaslessSwapRouterCaller(swapRouter, bc)
		if err != nil {
			return err
		}
		// Required token amountIn, given the current exchange rate and the declared minAmountOut.
		requiredAmountIn, err := routerContract.GetAmountIn(nil, token, minAmountOut)
		if err != nil {
			return err
		}
		if swapArgs.AmountIn.Cmp(requiredAmountIn) < 0 {
			return fmt.Errorf("insufficient amountIn: have=%s, want=%s", swapArgs.AmountIn.String(), requiredAmountIn.String())
		}
	}

		}
	}

func (env *Task) commitBundleTransaction(bundle *builder.Bundle, bc BlockChain, nodeAddr common.Address, vmConfig *vm.Config) (error, *types.Transaction, []*types.Log) {
	lastSnapshot := env.state.Copy()
	gasUsedSnapshot := env.header.GasUsed
	blobGasUsedSnapshot := env.header.BlobGasUsed
	blobsSnapshot := env.blobs
	tcountSnapshot := env.tcount
	txs := []*types.Transaction{}
	receipts := []*types.Receipt{}
	logs := []*types.Log{}

	markAllTxUnexecutable := func() {
		for _, txOrGen := range bundle.BundleTxs {
			if txOrGen.IsConcreteTx() {
				tx, _ := txOrGen.GetTx(0)
				tx.MarkUnexecutable(true)
			}
		}
	}

	restoreEnv := func() {
		env.state.Set(lastSnapshot)
		env.header.GasUsed = gasUsedSnapshot
		env.tcount = tcountSnapshot
		// blob related env are restored to the snapshot
		env.header.BlobGasUsed = blobGasUsedSnapshot
		env.blobs = blobsSnapshot
	}

	var totalTxSize uint64 = 0
	for _, txOrGen := range bundle.BundleTxs {
		tx, err := txOrGen.GetTx(env.state.GetNonce(nodeAddr))
		if err != nil {
			logger.Error("TxGenerator error", "error", err)
			markAllTxUnexecutable()
			restoreEnv()
			return kerrors.ErrTxGeneration, nil, nil
		}

		env.state.SetTxContext(tx.Hash(), common.Hash{}, env.tcount)
		receipt, _, err := bc.ApplyTransaction(env.config, &nodeAddr, env.state, env.header, tx, &env.header.GasUsed, vmConfig)
		// Bundled tx will be rejected with any receipt.Status other than success.
		// There may be cases where a revert occurs within the EVM, which could result in an attack on a tx sender in an already executed bundle.
		if err != nil || receipt.Status != types.ReceiptStatusSuccessful {
			if err != vm.ErrInsufficientBalance && err != vm.ErrTotalTimeLimitReached {
				markAllTxUnexecutable()
			}
			receiptStatus := ""
			if receipt != nil {
				receiptStatus = strconv.FormatUint(uint64(receipt.Status), 10)
			}
			logger.Warn("ApplyTransaction error, restoring env",
				"blockNum", env.header.Number.String(), "txHash", tx.Hash().String(),
				"error", err, "receiptStatus", receiptStatus,
			)
			restoreEnv()
			if err == nil {
				err = kerrors.ErrRevertedBundleByVmErr
			}
			return err, tx, nil
		}
