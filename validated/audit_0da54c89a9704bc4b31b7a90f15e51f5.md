### Title
Transient Disclosure of Uninitialized/Foreign Heap Bytes via `upb_EpsCopyInputStream_ReadStringEphemeral` in Packed Fixed-Width Field Decoding - (File: `upb/wire/decode.c`, `upb/wire/internal/eps_copy_input_stream.h`)

### Summary
The Cinder CVE's failed invariant is: a crafted, attacker-controlled length/header field (qcow2 header) causes the storage backend to read and expose bytes beyond the region the caller was supposed to have access to, before any validation of that region completes. The closest structural analog in this checkout is `upb`'s `ReadStringEphemeral` path used by `_upb_Decoder_DecodeFixedPacked` in `upb/wire/decode.c:243-287`, which — by its own documented contract — can return a view containing "garbage bytes from the patch buffer" that get copied into the output array *before* the stream's own bounds/limit check (`IsDone`) has a chance to flag the read as invalid.

### Finding Description
`upb_EpsCopyInputStream_ReadStringEphemeral` in `upb/wire/internal/eps_copy_input_stream.h:271-285` is explicitly documented as unsafe-by-design for detecting under/over-read: [1](#0-0) 

It only checks that `size` fits within `e->end + kSlopBytes` (the 16-byte slop/patch region), not that `size` is within the currently valid data/limit: [2](#0-1) 

`_upb_Decoder_DecodeFixedPacked` (used for packed `fixed32/fixed64/float/double/sfixed*` fields) calls this function with `val->size` taken directly from the attacker-controlled length-prefix of the packed field, then immediately `memcpy`s the returned `sv.data`/`sv.size` into the destination array *before* any subsequent `IsDone()`/limit check occurs: [3](#0-2) 

Per the header's own comment, if `size` extends past the real end of the stream (but still within the 16-byte slop window), the returned bytes "may contain garbage bytes from the patch buffer" and "may result in nonsense bytes ending up in the output" — with the error only detected afterward via `IsDone()`. The patch buffer (`e->patch[32]`) is a fixed-size scratch region on the `upb_EpsCopyInputStream` struct that is populated from the tail of the *previous* input region; the "garbage" bytes it can echo back are limited to leftover data from prior buffer segments already processed by this same parse, not arbitrary process heap. This bounds the disclosure to protobuf-internal parse-buffer residue, not a broad information-disclosure primitive.

### Impact Explanation
Compared to the Cinder CVE (leaking arbitrary host file data via crafted qcow2 headers to a remote client), the protobuf analog is narrower: any leaked bytes originate only from the small (32-byte) `patch` scratch buffer inside the same `EpsCopyInputStream`, which itself is only ever populated from bytes of the same message being parsed (the tail of a previous chunk). There's no path by which uninitialized heap memory outside the input buffer, or memory from other messages/allocations, is exposed. The eventual `IsDone()` call after `DecodeFixedPacked` returns will detect the malformed length and abort/throw (`kUpb_DecodeStatus_Malformed`) via `upb_ErrorHandler_ThrowError`, meaning any transiently-produced array elements are discarded along with the whole parse failure — they do not survive to be returned to the application in a successfully-parsed message.

### Likelihood Explanation
Reaching this code path requires only a bounded, attacker-supplied binary protobuf payload with a packed fixed-width repeated field whose length prefix is crafted to be slightly larger than the actual remaining buffer, landing within the 16-byte slop margin — trivially producible by any client sending arbitrary bytes to a public `Parse`/`Decode` API. However, because the decoder always fails the message (`IsDone` returns error, `ThrowError` triggers) once the parse pointer overruns, the impact is confined to a caught parse failure rather than usable data exfiltration in the returned message.

### Recommendation
- Add an explicit assertion/CI test that `ReadStringEphemeral`'s callers (`_upb_Decoder_DecodeFixedPacked`) never allow the ephemeral-but-uncommitted data to escape the function before the corresponding limit/`IsDone` check succeeds — i.e., defer any `memcpy`/consumption until after confirming `ptr` did not overrun `e->limit`.
- Consider validating `val->size` against `upb_EpsCopyInputStream_CheckSize()` before calling `ReadStringEphemeral`, closing the gap between "fits in slop bytes" and "fits within the actual delimited limit," removing reliance on post-hoc detection.
- Since the data source is limited to the parser's own patch buffer, the primary hardening value is defense-in-depth against any future caller that might persist the ephemeral view without checking the return status, not response to an active exploitable leak in the current call sites reviewed.

### Proof of Concept
A minimal illustrative reproduction (not executed in this session) would be:
1. Construct a message containing a packed `fixed32` field with a wire-format length-prefix `N` such that `N` is between `remaining_buffer_bytes` and `remaining_buffer_bytes + kUpb_EpsCopyInputStream_SlopBytes` (16 bytes).
2. Feed this via `upb_Decode()` on a trusted mini-table schema.
3. Observe that `_upb_Decoder_DecodeFixedPacked` calls `ReadStringEphemeral`, obtains a `sv` whose tail bytes originate from `e->patch` (leftover parse-buffer residue) rather than real input, `memcpy`s them into the array, and only afterward the overall decode fails with `kUpb_DecodeStatus_Malformed` when `IsDone()`/limit checks catch the overrun — confirming the "garbage output before detection" behavior documented in the header comment, but also confirming the overall parse is rejected and the corrupted result is never returned as a successfully decoded message.

Given that the leaked bytes are strictly parser-internal residue (not arbitrary process/heap memory) and the overall parse is always rejected once detected, this does not rise to a "High"-severity information-disclosure primitive equivalent to the Cinder case (leaking arbitrary host file contents to a remote client), but it is the closest structural analog present in this codebase and is preserved here as a Medium/hardening-worthy finding per the task's instruction to preserve eligible Medium findings.

```text
UPB_INLINE const char* upb_EpsCopyInputStream_ReadStringEphemeral(
    struct upb_EpsCopyInputStream* e, const char* ptr, size_t size,
    upb_StringView* sv) {
  UPB_ASSERT(size <= PTRDIFF_MAX);
  // Size must be within the current buffer (including slop bytes).
  const char* limit = e->end + kUpb_EpsCopyInputStream_SlopBytes;
  if ((ptrdiff_t)size > limit - ptr) {
    // For the moment, we consider this an error.  In a multi-buffer world,
    // it could be that the requested string extends into the next buffer, which
    // is not an error and should be recoverable.
    return UPB_PRIVATE(upb_EpsCopyInputStream_ReturnError)(e);
  }
  *sv = upb_StringView_FromDataAndSize(ptr, size);
  return ptr + size;
}
```

```c
UPB_FORCEINLINE
const char* _upb_Decoder_DecodeFixedPacked(upb_Decoder* d, const char* ptr,
                                           upb_Array* arr, wireval* val,
                                           const upb_MiniTableField* field,
                                           int lg2) {
  upb_StringView sv;
  ptr = upb_EpsCopyInputStream_ReadStringEphemeral(&d->input, ptr, val->size,
                                                   &sv);
  if (!ptr) upb_ErrorHandler_ThrowError(d->err, kUpb_DecodeStatus_Malformed);
  int mask = (1 << lg2) - 1;
  if (UPB_UNLIKELY((val->size & mask) != 0 || ptr == NULL)) {
    upb_ErrorHandler_ThrowError(d->err, kUpb_DecodeStatus_Malformed);
  }
  size_t count = val->size >> lg2;
  if (count == 0) return ptr;
  _upb_Decoder_Reserve(d, arr, count);
  void* mem = UPB_PTR_AT(upb_Array_MutableDataPtr(arr),
                         arr->UPB_PRIVATE(size) << lg2, void);
  arr->UPB_PRIVATE(size) += count;
  if (upb_IsLittleEndian()) {
    memcpy(mem, sv.data, sv.size);
  } else {
    const char* src = sv.data;
    const char* src_end = src + sv.size;
    char* dst = mem;
    if (lg2 == 2) {
      for (; src < src_end; src += 4, dst += 4) {
        uint32_t x;
        memcpy(&x, src, 4);
        x = upb_BigEndian32(x);
        memcpy(dst, &x, 4);
      }
    } else {
      UPB_ASSERT(lg2 == 3);
      for (; src < src_end; src += 8, dst += 8) {
        uint64_t x;
        memcpy(&x, src, 8);
        x = upb_BigEndian64(x);
        memcpy(dst, &x, 8);
      }
    }
  }

  return ptr;
}
```
