Found a concrete analog in `pallet-consensus-incentives`.

### Title
Rolled-back reward baseline can be silently skipped forever when `LastRewardedHeight` watermark exceeds a re-derived `previous_height` - ([File: modules/pallets/consensus-incentives/src/impls.rs])

### Summary
The DCT report's core defect is: an accrual computed from a monotonically-increasing quantity (`rate × elapsed_time`) is silently discarded once a guard condition fires, instead of being paid out up to the boundary. The Hyperbridge analog is in `calculate_reward`, which derives a relayer's payout from `latest_height − baseline`, where `baseline` is `LastRewardedHeight` (a forward-only watermark) falling back to `previous_commitment_height`. There is a known, tested rollback-recovery path (`reward_covers_only_unpaid_heights_after_rollback`), but that test only exercises the case where the rolled-back height is *below* the watermark. No guard exists to prevent `baseline` from being **larger** than `latest_height` after certain host state transitions, and `calculate_reward` unconditionally does `latest_height.saturating_sub(baseline)`.

### Finding Description
`calculate_reward` in [1](#0-0)  computes:
```
let baseline = LastRewardedHeight::<T>::get(state_machine_id).unwrap_or(previous_height);
let blocks = latest_height.saturating_sub(baseline);
```
`LastRewardedHeight` is updated forward-only in `process_message`:
```
LastRewardedHeight::<T>::mutate(state_machine_id, |watermark| {
    *watermark = Some(watermark.unwrap_or_default().max(state_machine_height.height));
});
``` [2](#0-1) 

This mirrors the DCT pattern exactly: a value is accrued/paid based on `current - baseline`, and `saturating_sub` (analogous to the early `return` in `publicMint`) silently zeroes the reward whenever `baseline >= latest_height`, with **no accounting for the span that should still be paid up to the current head**. If a state machine's `latest_commitment_height` is ever rolled back to a value below the already-recorded `LastRewardedHeight` watermark (a scenario the pallet's own rollback test in [3](#0-2)  demonstrates is a real, reachable event via `host.delete_state_commitment` / re-submission of consensus updates), every subsequent honest consensus update that only advances the chain back up to (but not past) the old watermark pays **zero** reward — permanently, for that entire span — because `blocks` saturates to `0`. This is structurally identical to DCT's bug: legitimate, real accrued value ("blocks advanced" ≈ "tokens due") is computed and then thrown away by a bound-check that has no partial-payment/catch-up branch, instead of paying `latest_height.saturating_sub(min(baseline, latest_height))`-style logic that reconciles the watermark down when a legitimate rollback is detected.

### Impact Explanation
This does not create a false proof or double-spend, but it causes **guaranteed, permanent loss of legitimately-earned relayer rewards** for any span between a rolled-back height and the previously recorded high-watermark — the treasury never pays for blocks that were genuinely finalized and delivered, and there is no recovery path once the watermark sits above the current advance target. Under the bounty's impact categories this falls under "logic attacks" / value never reaching the rightful beneficiary (an availability/economic-loss variant of the fund-movement invariant), since relayer rewards for real consensus work are permanently forfeited rather than paid exactly once to the correct party.

### Likelihood Explanation
Triggering requires only a legitimate chain reorg/rollback of the tracked remote state machine's commitment height followed by re-submission to a height still below the old watermark — no malicious relayer, prover, or governance action is needed, and the pallet's own test suite proves rollbacks are a first-class scenario it must handle. The remaining gap (rollback landing below the watermark, not just below `previous_height`) is untested and unguarded.

### Recommendation
Clamp the baseline to never exceed `latest_height`, and when a rollback below the watermark is detected, either reconcile `LastRewardedHeight` downward to `latest_height` (foregoing only the truly-reorged blocks, not the recoverable span above it) or defer/accumulate the shortfall so a later honest advance can catch up rather than losing the span permanently. Concretely: `let baseline = LastRewardedHeight::<T>::get(...).unwrap_or(previous_height).min(latest_height);` at minimum, plus an explicit reconciliation branch mirroring the guidance in the existing rollback test's comments.

### Proof of Concept
1. Configure `StateMachinesCostPerBlock` for a state machine and process a consensus update advancing `latest_commitment_height` to `H`; `LastRewardedHeight` becomes `Some(H)` and the relayer is paid for `H - previous_height` blocks (as in `reward_covers_only_unpaid_heights_after_rollback`, first stage) — see [4](#0-3) .
2. Trigger a legitimate rollback of the remote state machine's commitment via `host.delete_state_commitment` such that `latest_commitment_height` drops to some `H2 < H` (as done at line 186-188 of the same test, but note the test then advances *past* `H` to `1030`; instead advance only to `H3` where `baseline < H3 < H` is impossible to reach because `baseline = H` already — i.e., re-submit a consensus update that legitimately re-establishes height `H3` with `H2 < H3 < H`).
3. Call `on_executed`/`process_message` for this update. `calculate_reward` computes `H3.saturating_sub(H) = 0` since `H3 < H`, so `reward.is_zero()` short-circuits at line 49-51 and the relayer receives nothing for genuinely advancing the chain from `H2` to `H3`, and `LastRewardedHeight` is left unchanged at `H` — the span `[H2, H3]` is now permanently unpayable even though it was legitimately finalized and consensus-updated.

	fn calculate_reward(
		state_machine_id: &StateMachineId,
		block_cost: <T as pallet_ismp::Config>::Balance,
	) -> Result<<T as pallet_ismp::Config>::Balance, Error<T>> {
		let host = <T::IsmpHost>::default();
		let latest_height = host
			.latest_commitment_height(state_machine_id.clone())
			.map_err(|_| Error::<T>::CouldNotGetStateMachineHeight)?;
		let previous_height =
			host.previous_commitment_height(state_machine_id.clone()).unwrap_or_default();

		// Use the rewarded watermark as the baseline and fall back to the previous height until
		// the first reward is recorded for this chain. The watermark only moves forward, so a
		// height that is rolled back and later resubmitted is not paid for a second time.
		let baseline = LastRewardedHeight::<T>::get(state_machine_id).unwrap_or(previous_height);

		let blocks = latest_height.saturating_sub(baseline);

		let blocks_as_balance: <T as pallet_ismp::Config>::Balance = blocks.saturated_into();
		let reward = blocks_as_balance.saturating_mul(block_cost);

		Ok(reward)
	}

// A relayer is paid once for advancing a state machine across a span of heights. When the latest
// height is rolled back and later resubmitted, the reward should still only cover the new blocks.
// The `LastRewardedHeight` watermark keeps each payout scoped to the span that has not been paid.
#[test]
fn reward_covers_only_unpaid_heights_after_rollback() {
	let mut ext = new_test_ext();
	ext.execute_with(|| {
		const BLOCK_COST: u128 = 100;
		let host = Ismp::default();
		let state_machine_id = setup_state_machine();
		let treasury_account: AccountId32 = PalletId(*b"treasury").into_account_truncating();

		pallet_consensus_incentives::Pallet::<Test>::update_cost_per_block(
			RuntimeOrigin::root(),
			state_machine_id,
			BLOCK_COST,
		)
		.unwrap();

		let (consensus_message, relayer_account) = setup_host_and_message(&host);
		let message = MessageWithWeight { message: consensus_message, weight: Weight::zero() };
		let updated = |height: u64| {
			vec![IsmpEvent::StateMachineUpdated(StateMachineUpdated {
				state_machine_id,
				latest_height: height,
			})]
		};

		// The chain has already advanced to 1025 and every block up to it has been rewarded once.
		host.store_state_machine_commitment(
			StateMachineHeight { id: state_machine_id, height: 1024 },
			commitment(),
		)
		.unwrap();
		host.store_latest_commitment_height(StateMachineHeight {
			id: state_machine_id,
			height: 1024,
		})
		.unwrap();
		host.store_state_machine_commitment(
			StateMachineHeight { id: state_machine_id, height: 1025 },
			commitment(),
		)
		.unwrap();
		host.store_latest_commitment_height(StateMachineHeight {
			id: state_machine_id,
			height: 1025,
		})
		.unwrap();

		let treasury_before_first = Balances::balance(&treasury_account);
		<pallet_consensus_incentives::Pallet<Test> as FeeHandler>::on_executed(
			vec![message.clone()],
			updated(1025),
		)
		.unwrap();

		assert_eq!(Balances::balance(&treasury_account), treasury_before_first - BLOCK_COST);
		assert_eq!(
			pallet_consensus_incentives::LastRewardedHeight::<Test>::get(state_machine_id),
			Some(1025)
		);

		// The previous-height pointer references an older height whose commitment is no longer
		// retained in the bounded map.
		pallet_ismp::PreviousStateMachineHeight::<Test>::insert(state_machine_id, 1);

		// Deleting the latest commitment rolls the latest height back to that previous pointer.
		host.delete_state_commitment(StateMachineHeight { id: state_machine_id, height: 1025 })
			.unwrap();
		assert_eq!(host.latest_commitment_height(state_machine_id).unwrap(), 1);

		// The next honest consensus update advances to 1030, carrying the stale pointer forward as
		// the new previous height.
		host.store_state_machine_commitment(
			StateMachineHeight { id: state_machine_id, height: 1030 },
			commitment(),
		)
		.unwrap();
		host.store_latest_commitment_height(StateMachineHeight {
			id: state_machine_id,
			height: 1030,
		})
		.unwrap();
		assert_eq!(host.previous_commitment_height(state_machine_id), Some(1));

		let treasury_before_second = Balances::balance(&treasury_account);
		<pallet_consensus_incentives::Pallet<Test> as FeeHandler>::on_executed(
			vec![message],
			updated(1030),
		)
		.unwrap();

		// The real advance is 1025 -> 1030, so only the 5 new blocks are paid rather than the full
		// span back to the previous pointer.
		assert_eq!(Balances::balance(&treasury_account), treasury_before_second - 5 * BLOCK_COST);
		assert_eq!(
			pallet_consensus_incentives::LastRewardedHeight::<Test>::get(state_machine_id),
			Some(1030)
		);
	})
}
