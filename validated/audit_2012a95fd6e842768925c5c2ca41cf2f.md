### Title
Gasless swap settlement is not atomic with lend-tx payout, allowing non-compliant/fee-on-transfer ERC-20 tokens to permanently drain proposer-lent KAIA - (File: kaiax/gasless/impl/builder.go, kaiax/gasless/impl/getter.go)

### Summary
The `kaiax/gasless` module implements KIP-247 gasless transactions by having a block proposer front (lend) the gas fee to a user via an unconditional `LendTx`, expecting the user's subsequent `GaslessSwapTx` to repay that exact amount out of an ERC-20→KAIA swap. The repayment guarantee relies entirely on static, non-atomic checks performed at tx-pool admission time; it does not protect against ERC-20 tokens whose real transfer/swap behavior diverges from a naive fixed-amount model (fee-on-transfer, deflationary, blocklist, or otherwise non-standard tokens) — precisely the token class the external report warns about. If such a token is allowlisted (or a listed token later behaves unexpectedly), the proposer's lent KAIA is paid out unconditionally while the swap that is supposed to repay it can revert or under-deliver, causing an unrecoverable loss of proposer funds.

### Finding Description
The gasless flow bundles up to three independent transactions: `LendTx` (generated by the proposer, unconditionally transferring KAIA to the user), an optional `GaslessApproveTx`, and a `GaslessSwapTx` that calls `swapForGas` on the `GaslessSwapRouter`, expecting it to swap `amountIn` of `token` for KAIA and repay `amountRepay` to the proposer.

The bundle is built in `ExtractTxBundles`: [1](#0-0) 

`GetLendTxGenerator` constructs the `LendTx` to unconditionally send `lendAmount(...)` KAIA to the sender before the swap is known to succeed: [2](#0-1) 

The only guarantees that the swap will actually repay this amount are the static checks in `VerifyExecutable`/`checkBalanceForSwap`, which validate `amountIn`, `minAmountOut`, allowance, and balance against a snapshot state, and via the DEX's `GetAmountIn` view call: [3](#0-2) [4](#0-3) 

These checks assume that `token.balanceOf`, `token.allowance`, and the DEX quote accurately predict the on-chain outcome of an actual `transferFrom`/swap. This assumption is exactly the one identified as broken by "not compatible ERC-20 tokens" in the external report: tokens with transfer fees, deflationary/rebasing supply, blocklists, or non-standard mint/burn/transfer semantics can make the real balance movement differ from the value computed by static `balanceOf`/`allowance`/quote calls, or can make the transfer/swap itself revert unpredictably (e.g., a blocklisted router address, or an AMM output shrinking below `minAmountOut` due to the token's own transfer fee eating into the swapped amount).

Tokens are added to the router's allowlist by a privileged `AddToken` call, and the module also supports an "allow all" configuration (`gasless.allowed-tokens=all`, the default): [5](#0-4) [6](#0-5) 

Because the `LendTx` is a separate, unconditionally-signed transaction from the `SwapTx` rather than an atomic all-or-nothing state transition, if the `GaslessSwapTx` reverts on execution (or delivers less KAIA than `amountRepay` due to token misbehavior) after the `LendTx` has already been included and executed, the block proposer's advanced KAIA is permanently lost with no repayment — the same "accounting mismatch causing blocked/lost funds" root cause as the reported bridge bug, but here it drains the block proposer instead of a bridge contract.

### Impact Explanation
Any unprivileged transaction sender who can submit a `GaslessApproveTx`/`GaslessSwapTx` pair referencing an allowlisted (or "allow all") non-compliant ERC-20 token can cause a guaranteed, unrecoverable loss of KAIA lent by the block proposer, since the `LendTx` payout is not contingent on the swap succeeding or repaying the expected amount. This is a direct, repeatable value-extraction/fee-delegation abuse vector against block proposers, matching the "fee or fee-delegation abuse" and "unauthorized value movement" categories.

### Likelihood Explanation
Exploitability depends on at least one non-compliant ERC-20 token (fee-on-transfer, blocklist, deflationary, or one that simply reverts under adversarial conditions) being present in the router's allowed token set, or on the default "allow all tokens" configuration being used by a node operator/proposer — both realistic operational states given that `gasless.allowed-tokens` defaults to `all` and `AddToken` is a normal governance/owner action without protocol-level enforcement of ERC-20 compliance. Once such a token exists, exploitation only requires a single crafted `GaslessSwapTx` from any wallet holding that token, with no special privileges needed.

### Recommendation
1. Make the lend/repay flow atomic (e.g., use a single transaction or precompiled/protocol-level settlement that reverts the `LendTx` payout if the swap fails to deliver `amountRepay`), rather than relying on separately signed, independently-executed transactions.
2. Verify actual post-transfer balance deltas (not just pre-transfer `balanceOf`/allowance snapshots) before crediting the lend amount, to detect fee-on-transfer/deflationary behavior.
3. Restrict `AddToken` to only ERC-20 tokens that have been vetted for standard-compliant, non-fee, non-blocklisting behavior, and document/enforce this as a hard requirement rather than relying on governance discretion, especially given the `all`-allowed default configuration.

### Proof of Concept
1. A governance/owner account calls `GaslessSwapRouter.AddToken` (or the node operator runs with the default `gasless.allowed-tokens=all`) to allow a non-standard ERC-20 token `T` that charges a transfer fee or can be blocklisted.
2. An attacker holding `T` submits `GaslessApproveTx` + `GaslessSwapTx` for `T`, computed to pass `VerifyExecutable`/`checkBalanceForSwap` (using `T.balanceOf`, `T.allowance`, and the DEX's `GetAmountIn` quote, which do not account for `T`'s real transfer-fee behavior).
3. The proposer's `worker`/`ExtractTxBundles` builds the bundle `[LendTx, GaslessApproveTx, GaslessSwapTx]` per `kaiax/gasless/impl/builder.go` `ExtractTxBundles`, and `LendTx` unconditionally transfers `lendAmount(...)` KAIA to the attacker.
4. When `GaslessSwapTx` executes, `T`'s fee-on-transfer or blocklist logic causes the AMM swap to revert or return less than `amountRepay` to the router/proposer.
5. The attacker keeps the lent KAIA from `LendTx`, while the proposer never receives `amountRepay`, resulting in a permanent loss to the proposer for every such swap.

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

// MakeLendTx creates a transaction with following properties:
// L1. LendTx.type = 0x7802 (TxTypeEthereumDynamicFee)
// L2. LendTx.from = proposer
// L3. LendTx.to = SwapTx.from
// L4. LendTx.value = LendAmount(approveTxOrNil, swapTx)
func (g *GaslessModule) GetLendTxGenerator(approveTxOrNil, swapTx *types.Transaction) *builder.TxOrGen {
	var src []byte
	if approveTxOrNil != nil {
		src = append(src, approveTxOrNil.Hash().Bytes()...)
	}
	src = append(src, swapTx.Hash().Bytes()...)
	bundleHash := crypto.Keccak256Hash(src)

	gen := func(nonce uint64) (*types.Transaction, error) {
		var (
			chainId = g.InitOpts.ChainConfig.ChainID
			signer  = types.LatestSignerForChainID(chainId)
			key     = g.InitOpts.NodeKey
		)

		to, err := types.Sender(signer, swapTx)
		if err != nil {
			return nil, err
		}

		tx, err := types.NewTransactionWithMap(types.TxTypeEthereumDynamicFee, map[types.TxValueKeyType]interface{}{
			types.TxValueKeyNonce:      nonce,
			types.TxValueKeyTo:         &to,
			types.TxValueKeyAmount:     lendAmount(approveTxOrNil, swapTx),
			types.TxValueKeyData:       common.Hex2Bytes("0x"),
			types.TxValueKeyGasLimit:   params.TxGas,
			types.TxValueKeyGasFeeCap:  swapTx.GasFeeCap(),
			types.TxValueKeyGasTipCap:  swapTx.GasTipCap(),
			types.TxValueKeyAccessList: types.AccessList{},
			types.TxValueKeyChainID:    chainId,
		})
		if err != nil {
			return nil, err
		}

		err = tx.Sign(signer, key)
		return tx, err
	}

	return builder.NewTxOrGenFromGen(gen, bundleHash)
}

func (g *GaslessModule) updateAddresses(header *types.Header) error {
	g.gaslessInfoMu.Lock()
	defer g.gaslessInfoMu.Unlock()

	swapRouter, tokens, err := getGaslessInfo(g.Chain, header)
	// proceed even if there is something wrong with multicall contract
	if err != nil {
		g.swapRouter = common.Address{}
		g.allowedTokens = map[common.Address]bool{}
		logger.Warn("there is something wrong with multicall contract", "err", err.Error())
		return nil
	}

	g.swapRouter = swapRouter

	g.allowedTokens = map[common.Address]bool{}
	for _, addr := range tokens {
		// all tokens are allowed if nil
		if g.GaslessConfig.AllowedTokens == nil {
			g.allowedTokens[addr] = true
		}
		for _, allowed := range g.GaslessConfig.AllowedTokens {
			if addr == allowed {
				g.allowedTokens[addr] = true
			}
		}
	}

	return nil
}

func (g *GaslessModule) checkBalanceForSwap(swapArgs *SwapArgs, swapNonce uint64) error {
	token := swapArgs.Token
	bc := backends.NewBlockchainContractBackend(g.Chain, nil, nil)

	g.gaslessInfoMu.RLock()
	swapRouter := g.swapRouter
	g.gaslessInfoMu.RUnlock()

	// tx.minAmountOut >= tx.amountRepay
	minAmountOut := swapArgs.MinAmountOut
	amountRepay := swapArgs.AmountRepay
	if minAmountOut.Cmp(amountRepay) < 0 {
		return fmt.Errorf("insufficient minAmountOut: minAmountOut=%s, amountRepay=%s", minAmountOut.String(), amountRepay.String())
	}

	if g.GaslessConfig.ShouldCheckSenderCode() {
		if g.getCurrentHasCode(swapArgs.Sender) {
			return errors.New("sender with code is not allowed")
		}
	}

	if g.GaslessConfig.ShouldCheckSwapAmount() {
		// tx.amountIn >= gsr.getAmountIn(minAmountOut)
		routerContract, err := kip247.NewGaslessSwapRouterCaller(swapRouter, bc)
		if err != nil {
			return err
		}
		// Required token amountIn, given the current exchange rate and the declared minAmountOut.
		requiredAmountIn, err := routerContract.GetAmountIn(nil, token, minAmountOut)
		if err != nil {
			return err
		}
		if swapArgs.AmountIn.Cmp(requiredAmountIn) < 0 {
			return fmt.Errorf("insufficient amountIn: have=%s, want=%s", swapArgs.AmountIn.String(), requiredAmountIn.String())
		}
	}

	if g.GaslessConfig.ShouldCheckToken() {

		tokenContract, err := sc_erc20.NewERC20(token, bc)
		if err != nil {
			return err
		}

		// If SwapTx.nonce is the sender's next nonce, then there is no room for ApproveTx proceeding SwapTx.
		senderNonce := g.getCurrentStateNonce(swapArgs.Sender)
		noApproveTxPreceeds := swapNonce == senderNonce
		if noApproveTxPreceeds {
			// tx.token.allowance(sender, router) >= tx.amountIn
			approval, err := tokenContract.Allowance(nil, swapArgs.Sender, swapRouter)
			if err != nil {
				return err
			}
			if approval.Cmp(swapArgs.AmountIn) < 0 {
				return fmt.Errorf("insufficient approval: approval=%s, want=%s", approval.String(), swapArgs.AmountIn.String())
			}
		}

		// tx.token.balanceOf(sender) >= tx.amountIn
		balance, err := tokenContract.BalanceOf(nil, swapArgs.Sender)
		if err != nil {
			return err
		}
		if balance.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("insufficient balance: balance=%s, want=%s", balance.String(), swapArgs.AmountIn.String())
		}
	}
