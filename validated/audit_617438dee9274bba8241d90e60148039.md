## Title
Retroactive reward re-pricing in `pallet-consensus-incentives` lets any relayer collect a windfall payout for a stale backlog of blocks priced at the *new* `CostPerBlock` rate - ([File: modules/pallets/consensus-incentives/src/impls.rs])

### Summary
`pallet-consensus-incentives` pays relayers `Reward = (LatestHeight - LastRewardedHeight) * CostPerBlock`, where `CostPerBlock` is read live from the global `StateMachinesCostPerBlock` map at the moment the reward is computed, exactly the same "global mutable parameter used at settlement time instead of being locked at accrual time" pattern as the reported `setTgeDate` bug. Whenever `update_cost_per_block` changes the rate, the *entire outstanding unpaid height span* for that state machine, including any blocks that advanced long before the rate change, is settled at the new rate the instant any permissionless relayer next submits a consensus proof for it.

### Finding Description
`calculate_reward` in [1](#0-0)  computes the payout as `blocks * block_cost`, where `blocks = latest_height - baseline` (`baseline` is `LastRewardedHeight`, i.e. the last watermark ever paid) and `block_cost` is fetched fresh via `StateMachinesCostPerBlock::<T>::get(state_machine_id)` inside `process_message` at [2](#0-1) . The rate is never snapshotted per height or per accrual period - it is read as of the moment the reward is realized.

`update_cost_per_block` is a normal governance-facing extrinsic that simply overwrites this single global value: [3](#0-2) . Nothing ties a rate change to a height boundary; the storage holds one current number that applies to whatever unpaid span is realized next, no matter how old that span is or under what economic assumptions it accrued.

The trigger path is fully permissionless: `on_executed` runs on every processed `ConsensusMessage` and pays whoever's signature is on it [4](#0-3) , and `pallet_ismp` accepts unsigned consensus messages from anyone (`handle_unsigned`) as shown by the pallet's own test harness [5](#0-4) . So delivering the pending consensus proof for a lagging state machine requires no special privilege at all.

Concretely: if a state machine's `LastRewardedHeight` is stuck far behind `LatestHeight` (e.g. because nobody bothered relaying it, or the reward wasn't previously configured for it) and governance later raises `CostPerBlock` for legitimate forward-looking reasons (fee market changes, decimals adjustment, etc.), the very next relayer to submit the outstanding consensus proof collects the *entire* backlog priced at the new, higher rate — not the rate that was in force while those blocks were actually produced. The existing rollback-protection watermark (`LastRewardedHeight`) only prevents double-payment of the same height range; it does nothing to bind the *rate* used to the time the blocks occurred.

### Impact Explanation
This is a fund-loss bug against the treasury: `T::Currency::transfer(&TreasuryAccount, &relayer_account, reward, ...)` [6](#0-5)  moves treasury funds using an amount that can be wildly larger than what was ever economically intended for that historical block span, and any permissionless caller who signs and submits the consensus message captures it. Repeated across every state machine with a backlog, this is unauthorized, unbounded value extraction from the treasury account triggered purely by a routine rate update plus a permissionless message submission — no compromised relayer, prover, or malicious governance vote is required.

### Likelihood Explanation
`update_cost_per_block` is expected to be called periodically as normal chain operations (not an attack), and consensus-message delivery lag for less-active state machines is common and expected (the pallet's own rollback test shows spans of thousands of blocks accruing unpaid [7](#0-6) ). Any relayer merely needs to watch for a `StateMachineCostPerBlockUpdated` event and then submit (or simply be first to submit) the pending proof for a lagging chain to realize the reward at the new rate — an easily automatable, unprivileged strategy.

### Recommendation
Do not let a single live `CostPerBlock` value price an arbitrarily old, already-accrued backlog. Options:
- Snapshot/checkpoint the rate at each `StateMachineUpdated` height (or at minimum on every `update_cost_per_block` call, force-settle/checkpoint the outstanding span at the old rate before the new rate takes effect), so `calculate_reward` blends historical spans across rate boundaries instead of applying one rate to the whole gap.
- Alternatively, cap the unpaid span eligible for reward (a "grace window") so backlogs cannot silently balloon, and require timely relaying to keep the reward tied to the rate in force when blocks were produced.

### Proof of Concept
1. Governance sets `StateMachinesCostPerBlock[X] = 1` via `update_cost_per_block`.
2. State machine `X` advances from height 1,000 to height 50,000 over time (49,000 unpaid blocks); no one relays a consensus proof, so `LastRewardedHeight[X]` stays at 1,000 (or unset).
3. Governance later raises the rate for legitimate reasons: `update_cost_per_block(X, 1000)`.
4. Any unprivileged relayer submits the (permissionless, unsigned-origin) consensus proof advancing `X` to height 50,000.
5. `on_executed` → `process_message` → `calculate_reward` computes `blocks = 50,000 - 1,000 = 49,000`, `block_cost = 1000` (the just-updated live value), reward `= 49,000,000` — paid out of the treasury to that relayer in a single message, even though the 49,000 blocks were produced while the rate was `1`.

	fn process_message(
		state_machine_height: StateMachineHeight,
		state_machine_id: StateMachineId,
		relayer_account: T::AccountId,
	) -> Result<(), Error<T>> {
		if let Some(block_cost) = StateMachinesCostPerBlock::<T>::get(state_machine_id) {
			let reward = Self::calculate_reward(&state_machine_id, block_cost)?;

			if reward.is_zero() {
				return Ok(());
			}

			T::Currency::transfer(
				&T::TreasuryAccount::get().into_account_truncating(),
				&relayer_account,
				reward,
				Preservation::Expendable,
			)
			.map_err(|_| Error::<T>::RewardTransferFailed)?;

	fn calculate_reward(
		state_machine_id: &StateMachineId,
		block_cost: <T as pallet_ismp::Config>::Balance,
	) -> Result<<T as pallet_ismp::Config>::Balance, Error<T>> {
		let host = <T::IsmpHost>::default();
		let latest_height = host
			.latest_commitment_height(state_machine_id.clone())
			.map_err(|_| Error::<T>::CouldNotGetStateMachineHeight)?;
		let previous_height =
			host.previous_commitment_height(state_machine_id.clone()).unwrap_or_default();

		// Use the rewarded watermark as the baseline and fall back to the previous height until
		// the first reward is recorded for this chain. The watermark only moves forward, so a
		// height that is rolled back and later resubmitted is not paid for a second time.
		let baseline = LastRewardedHeight::<T>::get(state_machine_id).unwrap_or(previous_height);

		let blocks = latest_height.saturating_sub(baseline);

		let blocks_as_balance: <T as pallet_ismp::Config>::Balance = blocks.saturated_into();
		let reward = blocks_as_balance.saturating_mul(block_cost);

		Ok(reward)
	}

	fn on_executed(
		messages: Vec<MessageWithWeight>,
		events: Vec<IsmpEvent>,
	) -> DispatchResultWithPostInfo {
		let maybe_relayer_account = messages.get(0).and_then(|first_message| {
			if let Message::Consensus(consensus_msg) = &first_message.message {
				let data = sp_io::hashing::keccak_256(&consensus_msg.consensus_proof);
				Signature::decode(&mut &consensus_msg.signer[..])
					.ok()
					.and_then(|sig| sig.verify_and_get_sr25519_pubkey(&data, None).ok())
					.map(|pub_key| pub_key.into())
			} else {
				None::<[u8; 32]>
			}
		});

		if let Some(relayer_account) = maybe_relayer_account {
			// When a batch contains multiple `StateMachineUpdated` events for the
			// same `state_machine_id` (sequential consensus updates for the same
			// chain), `calculate_reward` reads the same persisted
			// `(latest_commitment_height, previous_commitment_height)` pair on
			// every iteration and pays the same block-span reward N times.
			// Collapse the per-state-machine event stream to the single highest
			// `latest_height` so each state machine receives one reward per
			// batch, sized by the actual span of its commitment advance.
			let mut highest_per_state_machine: BTreeMap<StateMachineId, u64> = BTreeMap::new();
			for event in events {
				if let IsmpEvent::StateMachineUpdated(update) = event {
					highest_per_state_machine
						.entry(update.state_machine_id)
						.and_modify(|h| {
							if update.latest_height > *h {
								*h = update.latest_height;
							}
						})
						.or_insert(update.latest_height);
				}
			}

			for (state_machine_id, latest_height) in highest_per_state_machine {
				let state_machine_height =
					StateMachineHeight { id: state_machine_id.clone(), height: latest_height };

				let _ = Self::process_message(
					state_machine_height,
					state_machine_id,
					relayer_account.clone().into(),
				);
			}
		}

// A relayer is paid once for advancing a state machine across a span of heights. When the latest
// height is rolled back and later resubmitted, the reward should still only cover the new blocks.
// The `LastRewardedHeight` watermark keeps each payout scoped to the span that has not been paid.
#[test]
fn reward_covers_only_unpaid_heights_after_rollback() {
	let mut ext = new_test_ext();
	ext.execute_with(|| {
		const BLOCK_COST: u128 = 100;
		let host = Ismp::default();
		let state_machine_id = setup_state_machine();
		let treasury_account: AccountId32 = PalletId(*b"treasury").into_account_truncating();

		pallet_consensus_incentives::Pallet::<Test>::update_cost_per_block(
			RuntimeOrigin::root(),
			state_machine_id,
			BLOCK_COST,
		)
		.unwrap();

		let (consensus_message, relayer_account) = setup_host_and_message(&host);
		let message = MessageWithWeight { message: consensus_message, weight: Weight::zero() };
		let updated = |height: u64| {
			vec![IsmpEvent::StateMachineUpdated(StateMachineUpdated {
				state_machine_id,
				latest_height: height,
			})]
		};

		// The chain has already advanced to 1025 and every block up to it has been rewarded once.
		host.store_state_machine_commitment(
			StateMachineHeight { id: state_machine_id, height: 1024 },
			commitment(),
		)
		.unwrap();
		host.store_latest_commitment_height(StateMachineHeight {
			id: state_machine_id,
			height: 1024,
		})
		.unwrap();
		host.store_state_machine_commitment(
			StateMachineHeight { id: state_machine_id, height: 1025 },
			commitment(),
		)
		.unwrap();
		host.store_latest_commitment_height(StateMachineHeight {
			id: state_machine_id,
			height: 1025,
		})
		.unwrap();

		let treasury_before_first = Balances::balance(&treasury_account);
		<pallet_consensus_incentives::Pallet<Test> as FeeHandler>::on_executed(
			vec![message.clone()],
			updated(1025),
		)
		.unwrap();

		assert_eq!(Balances::balance(&treasury_account), treasury_before_first - BLOCK_COST);
		assert_eq!(
			pallet_consensus_incentives::LastRewardedHeight::<Test>::get(state_machine_id),
			Some(1025)
		);
