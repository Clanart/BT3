### Title
`LastRewardedHeight` watermark is skipped when `block_cost` is temporarily zero, causing retroactive over-reward once a positive cost is set - (File: `modules/pallets/consensus-incentives/src/impls.rs`)

### Summary
`process_message` in `pallet-consensus-incentives` only advances the `LastRewardedHeight` watermark inside the "reward paid" branch. If governance sets `StateMachinesCostPerBlock` to `0` (a valid, explicit configuration, distinct from "unset"), every consensus update during that window computes `reward = blocks * 0 = 0`, hits `if reward.is_zero() { return Ok(()); }`, and returns **before** the watermark mutation at line 70-72 runs. The state machine's `latest_height` keeps advancing via the ISMP host in the meantime, but `LastRewardedHeight` stays frozen at the old value. When governance later raises `block_cost` back to a positive value, the very next `on_executed` call computes `blocks = latest_height - baseline` over the *entire* frozen-window span and pays it out in one shot at the new (positive) rate — a direct treasury drain for blocks that were explicitly configured to be free.

### Finding Description [1](#0-0) 

`calculate_reward` computes `blocks = latest_height.saturating_sub(baseline)` where `baseline` comes from `LastRewardedHeight` (falling back to `previous_height` only if never set): [2](#0-1) 

The watermark update is gated behind the non-zero-reward branch:
```rust
if reward.is_zero() {
    return Ok(());
}
...
LastRewardedHeight::<T>::mutate(state_machine_id, |watermark| {
    *watermark = Some(watermark.unwrap_or_default().max(state_machine_height.height));
});
```
`update_cost_per_block` is a governance-only extrinsic, but it explicitly allows setting `cost_per_block = 0` (there is no zero-check), which is a legitimate operational state — distinct from "not configured" (`None`), which is handled by the outer `if let Some(block_cost) = ...` and is the case the existing rollback test (`reward_covers_only_unpaid_heights_after_rollback`) exercises. That test only covers the height-rollback scenario, not the zero-cost-then-raised scenario, so the gap is untested. [3](#0-2) 

Sequence:
1. Governance sets `cost_per_block = 0` for a state machine (e.g., to temporarily pause incentives without fully disabling the pallet's tracking).
2. Relayers keep submitting consensus proofs; `StateMachineUpdated` events keep firing, `latest_commitment_height` keeps climbing in `IsmpHost`, but `reward = blocks * 0 = 0` every time, so `LastRewardedHeight` never moves.
3. Governance re-enables incentives by setting `cost_per_block` back to a positive value.
4. The next relayer-submitted consensus update triggers `process_message`, and `blocks = latest_height - stale_baseline` now spans the entire zero-cost window (which could be very large — governance intervals, or extended periods, are not bounded).
5. The full historical span is paid out in one transfer from `TreasuryAccount` to whichever relayer happens to submit the first proof after re-enabling — an unearned lump-sum payment that was never intended to be rewarded.

### Impact Explanation
This is a direct treasury fund-loss vector: `T::Currency::transfer` moves an inflated amount from the Hyperbridge treasury to a relayer account for work (block-span advancement) that occurred while the reward rate was explicitly set to zero. It fits the bounty's "stealing or loss of funds" / "logic attacks" category — funds move to a recipient in an amount that does not match the intended emission schedule, exactly the invariant break described in the seed report (`emissionRate`/`cost_per_block` transitioning 0 → positive with a stale watermark).

### Likelihood Explanation
Requires only a governance action sequence (set cost to 0, then later back to non-zero) — both `update_cost_per_block` calls are legitimate, expected governance operations (e.g., pausing incentives for one chain during an incident, then resuming). No malicious relayer, prover, or admin key compromise is needed — the relayer that happens to submit the reactivating proof is a normal, permissionless first-mover and receives the windfall automatically. The bug is latent and will trigger the first time an operator pauses-then-resumes incentives for any state machine, which is a plausible operational pattern.

### Recommendation
Move the watermark update outside the zero-reward early return so `LastRewardedHeight` always tracks the chain's advancement regardless of the configured cost:
```rust
let reward = Self::calculate_reward(&state_machine_id, block_cost)?;

// Always advance the watermark so a temporarily-zero cost_per_block
// does not leave a stale baseline that gets paid out in full once
// the cost is raised again.
LastRewardedHeight::<T>::mutate(state_machine_id, |watermark| {
    *watermark = Some(watermark.unwrap_or_default().max(state_machine_height.height));
});

if reward.is_zero() {
    return Ok(());
}
// ... proceed with transfer/mint/event as before
```
This mirrors the seed report's fix of always updating `lastUpdateBlock` regardless of `amountToMint`.

### Proof of Concept
1. Governance: `update_cost_per_block(state_machine_id, 0)`.
2. Relayer submits consensus proofs advancing `latest_commitment_height` from height `H0` to `H1` over several updates — each call to `on_executed`/`process_message` computes `reward = 0`, returns early, `LastRewardedHeight` stays at whatever it was before step 1 (say `H_prev < H0`).
3. Governance: `update_cost_per_block(state_machine_id, 100)`.
4. Relayer submits one more consensus proof advancing to `H2`.
5. `calculate_reward` computes `blocks = H2 - H_prev` (spanning the entire zero-cost window plus the new update), `reward = (H2 - H_prev) * 100` — paid in full to the relayer submitting this single proof, even though most of that span was configured to earn zero reward.
6. Compare treasury balance before/after step 4 to observe the inflated one-time payout, analogous to the `assertEq(Balances::balance(...), treasury_before - 5 * BLOCK_COST)` pattern already used in `reward_covers_only_unpaid_heights_after_rollback`, but here the multiplier would be the full zero-cost window's block count instead of the intended handful of new blocks. 	fn process_message(
		state_machine_height: StateMachineHeight,
		state_machine_id: StateMachineId,
		relayer_account: T::AccountId,
	) -> Result<(), Error<T>> {
		if let Some(block_cost) = StateMachinesCostPerBlock::<T>::get(state_machine_id) {
			let reward = Self::calculate_reward(&state_machine_id, block_cost)?;

			if reward.is_zero() {
				return Ok(());
			}

			T::Currency::transfer(
				&T::TreasuryAccount::get().into_account_truncating(),
				&relayer_account,
				reward,
				Preservation::Expendable,
			)
			.map_err(|_| Error::<T>::RewardTransferFailed)?;

			Self::deposit_event(Event::<T>::RelayerRewarded {
				relayer: relayer_account.clone(),
				amount: reward,
				state_machine_height,
			});

			T::ReputationAsset::mint_into(&relayer_account, reward.saturated_into())
				.map_err(|_| Error::<T>::ReputationMintFailed)?;

			LastRewardedHeight::<T>::mutate(state_machine_id, |watermark| {
				*watermark = Some(watermark.unwrap_or_default().max(state_machine_height.height));
			});
		}
		Ok(())
	}

	/// Calculate the reward for a message based on the state machine id
	fn calculate_reward(
		state_machine_id: &StateMachineId,
		block_cost: <T as pallet_ismp::Config>::Balance,
	) -> Result<<T as pallet_ismp::Config>::Balance, Error<T>> {
		let host = <T::IsmpHost>::default();
		let latest_height = host
			.latest_commitment_height(state_machine_id.clone())
			.map_err(|_| Error::<T>::CouldNotGetStateMachineHeight)?;
		let previous_height =
			host.previous_commitment_height(state_machine_id.clone()).unwrap_or_default();

		// Use the rewarded watermark as the baseline and fall back to the previous height until
		// the first reward is recorded for this chain. The watermark only moves forward, so a
		// height that is rolled back and later resubmitted is not paid for a second time.
		let baseline = LastRewardedHeight::<T>::get(state_machine_id).unwrap_or(previous_height);

		let blocks = latest_height.saturating_sub(baseline);

		let blocks_as_balance: <T as pallet_ismp::Config>::Balance = blocks.saturated_into();
		let reward = blocks_as_balance.saturating_mul(block_cost);

		Ok(reward)
	}

#[test]
fn reward_covers_only_unpaid_heights_after_rollback() {
	let mut ext = new_test_ext();
	ext.execute_with(|| {
		const BLOCK_COST: u128 = 100;
		let host = Ismp::default();
		let state_machine_id = setup_state_machine();
		let treasury_account: AccountId32 = PalletId(*b"treasury").into_account_truncating();

		pallet_consensus_incentives::Pallet::<Test>::update_cost_per_block(
			RuntimeOrigin::root(),
			state_machine_id,
			BLOCK_COST,
		)
		.unwrap();

		let (consensus_message, relayer_account) = setup_host_and_message(&host);
		let message = MessageWithWeight { message: consensus_message, weight: Weight::zero() };
		let updated = |height: u64| {
			vec![IsmpEvent::StateMachineUpdated(StateMachineUpdated {
				state_machine_id,
				latest_height: height,
			})]
		};

		// The chain has already advanced to 1025 and every block up to it has been rewarded once.
		host.store_state_machine_commitment(
			StateMachineHeight { id: state_machine_id, height: 1024 },
			commitment(),
		)
		.unwrap();
		host.store_latest_commitment_height(StateMachineHeight {
			id: state_machine_id,
			height: 1024,
		})
		.unwrap();
		host.store_state_machine_commitment(
			StateMachineHeight { id: state_machine_id, height: 1025 },
			commitment(),
		)
		.unwrap();
		host.store_latest_commitment_height(StateMachineHeight {
			id: state_machine_id,
			height: 1025,
		})
		.unwrap();

		let treasury_before_first = Balances::balance(&treasury_account);
		<pallet_consensus_incentives::Pallet<Test> as FeeHandler>::on_executed(
			vec![message.clone()],
			updated(1025),
		)
		.unwrap();

		assert_eq!(Balances::balance(&treasury_account), treasury_before_first - BLOCK_COST);
		assert_eq!(
			pallet_consensus_incentives::LastRewardedHeight::<Test>::get(state_machine_id),
			Some(1025)
		);

		// The previous-height pointer references an older height whose commitment is no longer
		// retained in the bounded map.
		pallet_ismp::PreviousStateMachineHeight::<Test>::insert(state_machine_id, 1);

		// Deleting the latest commitment rolls the latest height back to that previous pointer.
		host.delete_state_commitment(StateMachineHeight { id: state_machine_id, height: 1025 })
			.unwrap();
		assert_eq!(host.latest_commitment_height(state_machine_id).unwrap(), 1);

		// The next honest consensus update advances to 1030, carrying the stale pointer forward as
		// the new previous height.
		host.store_state_machine_commitment(
			StateMachineHeight { id: state_machine_id, height: 1030 },
			commitment(),
		)
		.unwrap();
		host.store_latest_commitment_height(StateMachineHeight {
			id: state_machine_id,
			height: 1030,
		})
		.unwrap();
		assert_eq!(host.previous_commitment_height(state_machine_id), Some(1));

		let treasury_before_second = Balances::balance(&treasury_account);
		<pallet_consensus_incentives::Pallet<Test> as FeeHandler>::on_executed(
			vec![message],
			updated(1030),
		)
		.unwrap();

		// The real advance is 1025 -> 1030, so only the 5 new blocks are paid rather than the full
		// span back to the previous pointer.
		assert_eq!(Balances::balance(&treasury_account), treasury_before_second - 5 * BLOCK_COST);
		assert_eq!(
			pallet_consensus_incentives::LastRewardedHeight::<Test>::get(state_machine_id),
			Some(1030)
		);
	})
}
