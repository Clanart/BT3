### Title
Gasless SwapTx admission uses manipulable AMM spot price (`GaslessSwapRouter.getAmountIn`) allowing proposer's lent-gas repayment to be griefed/stolen - (File: kaiax/gasless/impl/tx_pool.go)

### Summary
The `kaiax/gasless` module lets a proposer/consensus node pre-lend KAIA gas to a token-holding user via a `LendTx`, expecting to be repaid `amountRepay` when the user's `SwapForGas` transaction executes and swaps ERC20 tokens for KAIA on a whitelisted DEX (via `GaslessSwapRouter`). The tx-pool admission check `checkBalanceForSwap` validates the declared `amountIn`/`minAmountOut` against `GaslessSwapRouter.GetAmountIn(token, minAmountOut)` [1](#0-0) , a view call whose result is derived purely from the DEX pool's current instantaneous reserves (Uniswap-V2-style spot price), exactly the manipulable "quoter" pattern described in the external report.

### Finding Description
`checkBalanceForSwap` is the sole economic sanity check performed before a `SwapTx` is admitted/promoted in the tx pool and before the proposer commits to lending gas:

```go
requiredAmountIn, err := routerContract.GetAmountIn(nil, token, minAmountOut)
...
if swapArgs.AmountIn.Cmp(requiredAmountIn) < 0 {
    return fmt.Errorf("insufficient amountIn...")
}
``` [1](#0-0) 

`GetAmountIn` is implemented by `GaslessSwapRouter` (bound in `contracts/bindings/kip247/GaslessSwapRouter.go`) as a pure function of the underlying DEX pair reserves (analogous to `UniswapV2Router02.GetAmountIn(amountOut, reserveIn, reserveOut)` [2](#0-1) ), which is a raw, single-block spot price with no TWAP or oracle protection — the exact manipulable-quoter bug class from the external report.

The protocol flow that depends on this price:
1. The proposer computes `LendAmount = ApproveTx.Fee() + SwapTx.Fee()` and sends a `LendTx` transferring that many KAIA to the sender before the bundle executes [3](#0-2) [4](#0-3) .
2. `SwapTx.amountRepay` must equal `RepayAmount = LendTx.Fee() + LendAmount`, enforced only structurally (equality check), not against actual on-chain swap output [5](#0-4) [6](#0-5) .
3. `SwapTx` is only admitted into the pool if the declared `amountIn` clears the spot-price-derived `requiredAmountIn` bar at the moment of admission [1](#0-0) , and eligibility for bundling/lending (`IsExecutable`/`VerifyExecutable`) never re-checks DEX reserves at inclusion time [7](#0-6) .

Because the reserve-derived quote can be moved arbitrarily within the same block (e.g., a large swap or flash-loan-funded trade against the whitelisted pool immediately before the gasless bundle is executed), an attacker (any unprivileged token holder able to submit ordinary swap transactions on the same DEX pool) can:
- Manipulate the pool so `GetAmountIn` momentarily reports a favorable (low) required `amountIn`, letting a `SwapTx` with an artificially small `amountIn`/inflated `minAmountOut` pass admission, while the actual reserves at execution time (after the manipulation is reversed or shifts further) make the real swap output fall short of `minAmountOut`. In UniswapV2-style routers this reverts the whole `swapForGas` call.
- Because the `LendTx` (which unconditionally transfers KAIA to the sender) is a separate transaction from `SwapTx` in the bundle, and gas for the reverted `SwapTx` is still consumed from the lent balance, the proposer's lent KAIA is not recovered through the (reverted) swap-and-repay logic, resulting in a net loss to the block proposer/lender for every such bundle.
- Repeating this against many bundles in the same block that proposer builds drains the proposer's `GaslessLenderMinBal` reserve and can force gasless service into a degraded/disabled state, and, more importantly, constitutes direct value transfer away from the honest proposer to the attacker (who can also simply be the gasless sender themselves, self-manipulating the pool they control funds in).

This satisfies the required reachability path (unpriv gasless user reachable through ordinary transactions) and the required impact category (gasless settlement theft / unauthorized value movement from the lender).

### Impact Explanation
High. The exploit requires no special privilege — only the ability to hold tokens in the whitelisted DEX pool and submit ordinary transactions plus a crafted `SwapForGas` call. It directly causes the block proposer to lend KAIA that is never repaid, i.e., concrete unauthorized value extraction from the consensus node operating the gasless lending service. Repeated abuse can also degrade/disable the gasless feature network-wide by depleting the lender balance guard (`GaslessLenderMinBal`).

### Likelihood Explanation
High. AMM spot-price manipulation within a single block is a well-known, cheap, and repeatable attack (flash loans, back-to-back swaps), and nothing in `checkBalanceForSwap` or `VerifyExecutable` re-validates the swap's realized on-chain output against actual reserves at inclusion time — the check is purely a point-in-time view call performed at admission.

### Recommendation
- Do not rely on a single-block AMM view call (`GetAmountIn`) for economic admission decisions or lending sizing; use a TWAP-based or otherwise manipulation-resistant price source for the DEX pool used by `GaslessSwapRouter`.
- Re-validate `amountIn`/`minAmountOut` against current reserves immediately before generating the `LendTx`/bundling for inclusion, not only at initial tx-pool admission.
- Ensure the `LendTx` and `SwapTx` settlement are atomic (i.e., structure so that if `SwapForGas` reverts, the lent KAIA is clawed back within the same block/bundle, or require the swap's minimum-output slippage bound to include margin large enough to absorb realistic intra-block price movement) so that a reverted swap cannot leave the proposer's loan unrepaid.

### Proof of Concept
Conceptual PoC (analogous to the report's `test_priceManipulation`), unverifiable end-to-end without running a devnet since the `GaslessSwapRouter.sol` and DEX pair source are not present in the indexed codebase (only Go bindings) — noted as a limitation:
1. Attacker holds funds and swaps a large amount against the whitelisted DEX pool (`token`/KAIA pair) referenced by `GaslessSwapRouter.DexAddress(token)`, skewing reserves so `GetAmountIn(token, minAmountOut)` momentarily returns a low `requiredAmountIn`.
2. Attacker (or a colluding gasless user) submits `ApproveTx` + `SwapTx` with `amountIn` just above this manipulated `requiredAmountIn` and `minAmountOut == amountRepay` (minimum allowed by `checkBalanceForSwap`'s `minAmountOut >= amountRepay` check) [8](#0-7) , so the bundle passes admission (`checkBalanceForSwap`) and is deemed executable (`VerifyExecutable`) [7](#0-6) .
3. The proposer, believing the bundle valid, issues `LendTx` transferring `LendAmount` KAIA to the sender [3](#0-2) .
4. Before/at execution of `SwapTx`, the attacker reverses or further shifts the pool reserves (e.g., withdraws the earlier large swap, or another actor trades against the pool), causing the real swap inside `SwapForGas` to yield less than `minAmountOut`, reverting the transaction.
5. The `LendTx` KAIA transfer stands (already mined), but the repayment inside `SwapForGas` never executes due to revert — net loss of `LendAmount` KAIA to the proposer, gained by the attacker who never had to give up equivalent value.

func (g *GaslessModule) IsExecutable(approveTxOrNil, swapTx *types.Transaction) bool {
	err := g.VerifyExecutable(approveTxOrNil, swapTx)
	if err != nil {
		return false
	}
	return true
}

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

// MakeLendTx creates a transaction with following properties:
// L1. LendTx.type = 0x7802 (TxTypeEthereumDynamicFee)
// L2. LendTx.from = proposer
// L3. LendTx.to = SwapTx.from
// L4. LendTx.value = LendAmount(approveTxOrNil, swapTx)
func (g *GaslessModule) GetLendTxGenerator(approveTxOrNil, swapTx *types.Transaction) *builder.TxOrGen {
	var src []byte
	if approveTxOrNil != nil {
		src = append(src, approveTxOrNil.Hash().Bytes()...)
	}
	src = append(src, swapTx.Hash().Bytes()...)
	bundleHash := crypto.Keccak256Hash(src)

	gen := func(nonce uint64) (*types.Transaction, error) {
		var (
			chainId = g.InitOpts.ChainConfig.ChainID
			signer  = types.LatestSignerForChainID(chainId)
			key     = g.InitOpts.NodeKey
		)

		to, err := types.Sender(signer, swapTx)
		if err != nil {
			return nil, err
		}

		tx, err := types.NewTransactionWithMap(types.TxTypeEthereumDynamicFee, map[types.TxValueKeyType]interface{}{
			types.TxValueKeyNonce:      nonce,
			types.TxValueKeyTo:         &to,
			types.TxValueKeyAmount:     lendAmount(approveTxOrNil, swapTx),
			types.TxValueKeyData:       common.Hex2Bytes("0x"),
			types.TxValueKeyGasLimit:   params.TxGas,
			types.TxValueKeyGasFeeCap:  swapTx.GasFeeCap(),
			types.TxValueKeyGasTipCap:  swapTx.GasTipCap(),
			types.TxValueKeyAccessList: types.AccessList{},
			types.TxValueKeyChainID:    chainId,
		})
		if err != nil {
			return nil, err
		}

		err = tx.Sign(signer, key)
		return tx, err
	}

	return builder.NewTxOrGenFromGen(gen, bundleHash)
}

func lendAmount(approveTxOrNil, swapTx *types.Transaction) *big.Int {
	r := new(big.Int)

	// R2 = ApproveTx.Fee() if exists
	if approveTxOrNil != nil {
		r.Add(r, approveTxOrNil.Fee())
	}

	// R3 = SwapTx.Fee()
	r.Add(r, swapTx.Fee())

	// LendAmount = R2 + R3
	return r
}

func repayAmount(approveTxOrNil, swapTx *types.Transaction) *big.Int {
	// R1 = LendTx.Fee() = SwapTx.GasPrice() * TxGas
	r1 := new(big.Int).Mul(swapTx.GasPrice(), new(big.Int).SetUint64(params.TxGas))

	// RepayAmount = R1 + R2 + R3
	return new(big.Int).Add(r1, lendAmount(approveTxOrNil, swapTx))
}
