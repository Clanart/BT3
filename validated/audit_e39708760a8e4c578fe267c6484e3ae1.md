### Title
Data Layer mirror/subscription URLs enable SSRF via unrestricted outbound `http_download` requests - (File: `chia/data_layer/data_layer.py`, `chia/data_layer/download_data.py`)

### Summary
The Data Layer RPC methods `subscribe` and `add_mirror` accept arbitrary, attacker-controlled URL strings with no scheme/host allow-listing or private-network filtering. These URLs are persisted and later dereferenced by the DataLayer service's background sync loop, which issues outbound HTTP GET requests to them via `aiohttp` in `http_download()`. This is a server-side request forgery (SSRF) sink reachable by any local Data Layer client able to call `subscribe`/`add_mirror` (and by any store owner adding mirrors on-chain, whose URLs are pulled in via `update_subscriptions_from_wallet`).

### Finding Description
`DataLayer.subscribe()` only strips trailing slashes from user-supplied URLs before storing them as `ServerInfo` records — there is no validation of scheme, host, or destination network: [1](#0-0) 

Mirror URLs added via `add_mirror()` are pushed on-chain and later pulled back by `update_subscriptions_from_wallet()`, which likewise performs no filtering beyond `rstrip("/")` before feeding them into the same subscription table: [2](#0-1) 

The periodic sync loop (`periodically_manage_data()` → `update_subscription()` → `fetch_and_validate()`) iterates these stored `ServerInfo.url` values and calls `insert_from_delta_file()`, which in turn calls `download_file()`: [3](#0-2) 

When no plugin `downloader` is configured (the default, plain-HTTP path), `download_file()` calls `http_download()`, which opens an `aiohttp.ClientSession` and issues a GET request directly to `server_info.url + "/" + filename` with no restriction on the resolved host or IP range (no blocking of loopback, link-local, RFC1918 private ranges, or cloud metadata addresses such as `169.254.169.254`): [4](#0-3) [5](#0-4) 

Tests confirm arbitrary URLs (including plain `http://127.0.0.1/...`) are accepted end-to-end through `add_mirror`/`subscribe`, demonstrating no host restriction is enforced: [6](#0-5) [7](#0-6) 

The project's own internal documentation acknowledges mirror/plugin URLs as "external trust inputs" for *data content* verification, but does not address SSRF of the destination itself: [8](#0-7) 

### Impact Explanation
A local/authorized Data Layer RPC caller (or a store owner who can add on-chain mirrors that get synced into any subscribing node) can direct the DataLayer service process to make outbound HTTP requests to arbitrary internal or restricted network destinations — e.g., internal RPC ports (wallet/full-node RPC bound to localhost), other services on the node's internal network, or cloud metadata endpoints. Because responses are parsed as delta files (and errors/timeouts are logged with content details), this can be used for internal network reconnaissance/port-scanning and, depending on deployment (cloud instance metadata, internal admin endpoints without auth), for further compromise. This matches the CWE-918 SSRF pattern from the reported advisory, scoped here to the Data Layer client/mirror-URL trust boundary explicitly listed as in-scope.

### Likelihood Explanation
Likelihood is significant: the `subscribe` and `add_mirror` RPC endpoints are ordinary Data Layer functionality intended to be called by any client with data-layer RPC access, and mirror URLs added by one store owner propagate automatically to any node that subscribes to that store via `update_subscriptions_from_wallet()` and the periodic sync loop — no special privilege beyond normal Data Layer usage is required to plant a malicious URL that another node's DataLayer service will fetch.

### Recommendation
Add SSRF hardening at the URL-acceptance boundary in `DataLayer.subscribe()`, `DataLayer.add_mirror()`, and `update_subscriptions_from_wallet()`: enforce an allow-listed scheme (e.g., `http`/`https` only), resolve and reject destinations in loopback/link-local/private/reserved IP ranges (including cloud metadata addresses) unless explicitly configured for trusted/test environments, and apply the same checks again at request time in `http_download()` (in case of DNS rebinding) before issuing the `aiohttp` request in `chia/data_layer/download_data.py`.

### Proof of Concept
1. Start a DataLayer service node with a store owned locally.
2. Call the `subscribe` RPC with `urls=["http://169.254.169.254/latest/meta-data/"]` (or `http://127.0.0.1:<internal-rpc-port>/...`), mirroring the exact flow used in `test_subscriptions`/`test_mirrors`: [9](#0-8) 
3. Wait for the periodic `periodically_manage_data()` cycle; the service's `fetch_and_validate()` will select this `ServerInfo` and call `http_download()`, causing the DataLayer process to issue an HTTP GET to the attacker-chosen internal/metadata address with no destination validation.

async def download_file(
    data_store: DataStore,
    target_filename_path: Path,
    store_id: bytes32,
    root_hash: bytes32,
    generation: int,
    server_info: ServerInfo,
    proxy_url: str | None,
    downloader: PluginRemote | None,
    timeout: aiohttp.ClientTimeout,
    client_foldername: Path,
    timestamp: int,
    log: logging.Logger,
    grouped_by_store: bool,
    group_downloaded_files_by_store: bool,
    max_delta_file_size: int,
) -> bool:
    if target_filename_path.exists():
        return True
    filename = get_delta_filename(store_id, root_hash, generation, grouped_by_store)

    if downloader is None:
        # use http downloader - this raises on any error
        try:
            await http_download(
                target_filename_path, filename, proxy_url, server_info, timeout, log, max_delta_file_size
            )
        except (asyncio.TimeoutError, aiohttp.ClientError, MaxDeltaFileSizeExceededError):
            new_server_info = await data_store.server_misses_file(store_id, server_info, timestamp)
            log.info(
                f"Failed to download {filename} from {new_server_info.url}."
                f"Miss {new_server_info.num_consecutive_failures}."
            )
            log.info(f"Next attempt from {new_server_info.url} in {new_server_info.ignore_till - timestamp}s.")
            return False
        return True
```

async def http_download(
    target_filename_path: Path,
    filename: str,
    proxy_url: str | None,
    server_info: ServerInfo,
    timeout: aiohttp.ClientTimeout,
    log: logging.Logger,
    max_delta_file_size: int,
) -> None:
    """
    Download a file from a server using aiohttp.
    Raises exceptions on errors
    """
    async with aiohttp.ClientSession() as session:
        headers = {"accept-encoding": "gzip"}
        async with session.get(
            server_info.url + "/" + filename,
            headers=headers,
            timeout=timeout,
            proxy=proxy_url,
        ) as resp:
            resp.raise_for_status()
            size = int(resp.headers.get("content-length", 0))
            max_delta_file_size_bytes = max_delta_file_size * 1024 * 1024
            if size > max_delta_file_size_bytes:
                raise MaxDeltaFileSizeExceededError(f"Maximum delta file size exceeded: {max_delta_file_size} MiB.")
            log.debug(f"Downloading delta file {filename}. Size {size} bytes.")
```
