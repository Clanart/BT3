### Title
Unauthenticated CosmWasm event attributes are trusted to synthesize ERC20/721/1155 Transfer logs, letting a pointee-contract owner forge fake token-transfer receipts - (File: app/receipt.go)

### Summary
`AddCosmosEventsToEVMReceiptIfApplicable` scans every `wasm` module event emitted during a Cosmos tx and, for any contract address that has a registered CW20/CW721/CW1155 EVM pointer, calls `translateCW20Event`/`translateCW721Event`/`translateCW1155Event` to build synthetic EVM logs. These functions build `ERC20TransferTopic`/`ERC721TransferTopic` logs directly from attribute keys (`action`, `amount`, `sender`, `recipient`, `owner`, `spender`, `token_id`) parsed by `GetActionsFromWasmEvent`, without verifying the attribute values correspond to an actual bank/CW20/CW721 state transition that occurred in that same execution.

### Finding Description
`x/wasm/keeper/events.go`'s `contractSDKEventAttributes` only rejects attribute keys with the reserved `_` prefix; it does not filter or authenticate the `action`, `amount`, `sender`, `recipient`, `owner`, `spender`, `token_id` keys that a contract chooses to emit — these are exactly the keys `GetActionsFromWasmEvent` consumes to synthesize logs. Any CosmWasm contract that has been (or can be) registered with an ERC20/ERC721/ERC1155 pointer (via the permissionless `pointer` precompile `AddCW20Pointer`/`AddCW721Pointer`/`AddCW1155Pointer`, or via `wasmd` precompile execute calls) can, inside its own `execute` entry point, emit a crafted custom event with `action=transfer`, `amount=<huge>`, `sender=<victim>`, `recipient=<attacker>` (or `mint`/`transfer_nft` variants) without performing any real CW20/CW721 balance change. Because the mapping in `translateCW20Event`/`translateCW721Event` treats these attribute values as ground truth, `AddCosmosEventsToEVMReceiptIfApplicable` (invoked from the `DeliverTxHookInput` after any Cosmos deliver-tx) will append a fabricated `ERC20TransferTopic`/`ERC721TransferTopic` log to that transaction's synthetic (or real) EVM receipt, exactly mirroring the Camel CVE's root cause: inbound "control" data (here, event attributes used to construct authoritative EVM log topics/data) is copied into a trusted-consumer artifact (the tx receipt/log) without any filtering/authentication step analogous to a missing inbound `HeaderFilterStrategy`.

### Impact Explanation
Downstream systems (bridges, CEX/DEX indexers, wallets, and any EVM-JSON-RPC client using `eth_getLogs`/`eth_getTransactionReceipt`) treat ERC20/721/1155 `Transfer` events in receipts as authoritative proof of an asset movement. A contract owner can therefore mint arbitrary fake deposit/transfer events attributed to any pointer contract they control, to defraud automated systems that credit balances or trigger payouts based on observed on-chain Transfer logs — this is a receipt/log integrity violation reachable purely from a normal CosmWasm `execute` call, matching the "unauthorized transfer via precompile/pointer" impact class since the forged log is indistinguishable, at the RPC surface, from a genuine pointer-mediated transfer.

### Likelihood Explanation
High: any account can deploy/instantiate a CW20/CW721/CW1155-shaped contract and add a permissionless pointer for it (or already-pointed contracts may be controlled by an attacker with `execute` rights), then simply emit a custom event with the right attribute keys from `execute` — no special privilege, gas cost, or contract logic constraint beyond ordinary message execution is required.

### Recommendation
In `translateCW20Event`/`translateCW721Event`/`translateCW1155Event` (and `GetActionsFromWasmEvent`) in `app/receipt.go`, do not trust contract-supplied `wasm` event attributes as sufficient evidence of a transfer. Instead, cross-check the synthesized log against actual keeper-level state effects for that execution (e.g., verify a corresponding bank/CW20 balance delta or NFT ownership change actually occurred for the referenced pointer contract, or use protocol-controlled event types/attributes that only the wasm module itself — not the contract — can set, mirroring the upstream fix of adding an authoritative inbound filter rather than trusting attacker-controlled fields).

### Proof of Concept
1. Instantiate a minimal CosmWasm contract and add a CW20 pointer for it via the `pointer` precompile's `AddCW20Pointer` (or execute against an existing pointed contract you control).
2. Implement an `execute` handler that, regardless of real logic, emits `Response::new().add_attribute("action","transfer").add_attribute("amount","1000000000000").add_attribute("sender","<victim_cw_addr>").add_attribute("recipient","<attacker_cw_addr>")` without performing any bank/CW20 transfer.
3. Send the execute message; observe via `eth_getTransactionReceipt`/`eth_getLogs` on the associated EVM tx hash that a synthetic `ERC20TransferTopic` log for the pointer's ERC20 address is created reflecting the fabricated `sender`/`recipient`/`amount`, even though no real token balance changed. func contractSDKEventAttributes(customAttributes []wasmvmtypes.EventAttribute, contractAddr sdk.AccAddress) ([]sdk.Attribute, error) {
	attrs := []sdk.Attribute{sdk.NewAttribute(types.AttributeKeyContractAddr, contractAddr.String())}
	// append attributes from wasm to the sdk.Event
	for _, l := range customAttributes {
		// ensure key and value are non-empty (and trim what is there)
		key := strings.TrimSpace(l.Key)
		if len(key) == 0 {
			return nil, sdkerrors.Wrap(types.ErrInvalidEvent, fmt.Sprintf("Empty attribute key. Value: %s", l.Value))
		}
		value := strings.TrimSpace(l.Value)
		// TODO: check if this is legal in the SDK - if it is, we can remove this check
		if len(value) == 0 {
			return nil, sdkerrors.Wrap(types.ErrInvalidEvent, fmt.Sprintf("Empty attribute value. Key: %s", key))
		}
		// and reserve all _* keys for our use (not contract)
		if strings.HasPrefix(key, types.AttributeReservedPrefix) {
			return nil, sdkerrors.Wrap(types.ErrInvalidEvent, fmt.Sprintf("Attribute key starts with reserved prefix %s: '%s'", types.AttributeReservedPrefix, key))
		}
		attrs = append(attrs, sdk.NewAttribute(key, value))
	}
	return attrs, nil

func (app *App) translateCW20Event(ctx sdk.Context, wasmEvent abci.Event, pointerAddr common.Address, contractAddr string) (res []*ethtypes.Log) {
	defer func() {
		if r := recover(); r != nil {
			fmt.Printf("[Error] Panic caught during translateCW20Event: type=%T, value=%+v\n", r, r)
		}
	}()

	for _, action := range app.GetActionsFromWasmEvent(ctx, wasmEvent) {
		switch action.Type {
		case "mint", "burn", "send", "transfer", "transfer_from", "send_from", "burn_from":
			if action.Amount == nil {
				continue
			}
			res = append(res, &ethtypes.Log{
				Address: pointerAddr,
				Topics: []common.Hash{
					ERC20TransferTopic,
					action.From,
					action.To,
				},
				Data: common.BigToHash(action.Amount).Bytes(),
			})
		case "increase_allowance", "decrease_allowance":
			topics := []common.Hash{
				ERC20ApprovalTopic,
				action.Owner,
				action.Spender,
			}
			ret, err := app.WasmKeeper.QuerySmart(
				ctx,
				sdk.MustAccAddressFromBech32(contractAddr),
				[]byte(fmt.Sprintf(
					"{\"allowance\":{\"owner\":\"%s\",\"spender\":\"%s\"}}",
					app.EvmKeeper.GetSeiAddressOrDefault(ctx, common.BytesToAddress(action.Owner[:])).String(),
					app.EvmKeeper.GetSeiAddressOrDefault(ctx, common.BytesToAddress(action.Spender[:])).String())),
			)
			if err != nil {
				continue
			}
			allowanceResponse := &AllowanceResponse{}
			if err := json.Unmarshal(ret, allowanceResponse); err != nil {
				continue
			}
			res = append(res, &ethtypes.Log{
				Address: pointerAddr,
				Topics:  topics,
				Data:    common.BigToHash(allowanceResponse.Allowance.BigInt()).Bytes(),
			})
		}
	}
	return
}

func (app *App) GetActionsFromWasmEvent(ctx sdk.Context, event abci.Event) (actions []*Action) {
	for _, attr := range event.Attributes {
		key := string(attr.Key)
		value := string(attr.Value)
		if key == "action" {
			actions = append(actions, &Action{Type: value})
			continue
		}
		if len(actions) == 0 {
			continue
		}
		curAction := actions[len(actions)-1]
		switch key {
		case "amount":
			curAction.Amount = safeBigIntFromString(value)
		case "amounts":
			curAction.Amounts = utils.Map(strings.Split(value, ","), safeBigIntFromString)
		case "token_id":
			curAction.TokenId = safeBigIntFromString(value)
		case "token_ids":
			curAction.TokenIds = utils.Map(strings.Split(value, ","), safeBigIntFromString)
		case "sender":
			curAction.Sender = app.GetEvmAddressHash(ctx, value)
		case "recipient":
			curAction.Recipient = app.GetEvmAddressHash(ctx, value)
		case "spender":
			curAction.Spender = app.GetEvmAddressHash(ctx, value)
		case "operator":
			curAction.Operator = app.GetEvmAddressHash(ctx, value)
		case "owner":
			curAction.Owner = app.GetEvmAddressHash(ctx, value)
		case "from":
			curAction.From = app.GetEvmAddressHash(ctx, value)
		case "to":
			curAction.To = app.GetEvmAddressHash(ctx, value)
		}
	}
	return
}
