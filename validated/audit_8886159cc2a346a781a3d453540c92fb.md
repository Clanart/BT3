### No vulnerability found for this question.

**Rationale:** `redirect_uri_for_embedded` always redirects to a fixed, developer-configured destination — `ShopifyApp.configuration.embedded_redirect_url` — with the attacker-controlled `host`/`shop` values only appended as query-string parameters, not used to construct the redirect's scheme/host/authority. The `shop` param is passed through `sanitize_shop_param`/`ShopifyApp::Utils.sanitize_shop_domain` before being placed in `redirect_query_params[:shop]`, and the `redirectUri` nested value is built from `ShopifyAPI::Context.host` (server-controlled), not attacker input. [1](#0-0) [2](#0-1) 

The raw, un-sanitized `host` param is indeed forwarded verbatim into the query string (`redirect_query_params[:host]` at line 39, and via `sanitized_params` at line 42, which only sanitizes `:shop`, not `:host`), but since it can only ever land as a query parameter on the fixed `embedded_redirect_url` (a same-origin/developer-configured URL) rather than change the redirect's target origin, this does not constitute an open redirect to an attacker-chosen domain. This matches the general Shopify embedded-app design where the `host` param is not treated as a secret or security boundary — it originates from the Shopify Admin iframe URL in normal legitimate flows and is expected to be attacker/merchant-suppliable; the actual authentication/session boundary is enforced elsewhere (session-token verification in `ShopifyApp::LoginProtection#activate_shopify_session` and related concerns), not in this redirect-URL-building helper. [3](#0-2) 

No path here allows an attacker to redirect the browser to an arbitrary external domain, leak session/access-token secrets, or bypass any authentication check, since no authentication decision is made by this concern and the destination host is fixed by app configuration.

```ruby
    def redirect_uri_for_embedded
      redirect_query_params = {}
      redirect_uri = "#{ShopifyAPI::Context.host}#{ShopifyApp.configuration.login_url}"
      redirect_query_params[:shop] = sanitized_shop_name
      redirect_query_params[:shop] ||= referer_sanitized_shop_name if referer_sanitized_shop_name.present?
      redirect_query_params[:host] ||= params[:host] if params[:host].present?
      redirect_uri = "#{redirect_uri}?#{redirect_query_params.to_query}" if redirect_query_params.present?

      query_params = sanitized_params.except(:redirect_uri)
      query_params[:redirectUri] = redirect_uri

      "#{ShopifyApp.configuration.embedded_redirect_url}?#{query_params.to_query}"
    end
```

```ruby
    def sanitize_shop_param(params)
      return unless params[:shop].present?

      ShopifyApp::Utils.sanitize_shop_domain(params[:shop])
    end

    def sanitized_params
      parameters = request.post? ? request.request_parameters : request.query_parameters
      parameters.clone.tap do |params_copy|
        if params[:shop].is_a?(String)
          params_copy[:shop] = sanitize_shop_param(params)
        end
      end
    end
```
