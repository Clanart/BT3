### Title
Coinbase outputs are reported as spendable before maturity - ([File: networks/bitcoin/src/wallet/mod.rs](networks/bitcoin/src/wallet/mod.rs))

### Summary
`Scanner::scan_block` accepts every transaction in a block, including `block.txdata[0]`, and returns matching outputs as `ReceivedOutput` values without retaining or enforcing coinbase maturity. Because `ReceivedOutput` only stores an offset, `TxOut`, and `OutPoint`, downstream spending code cannot distinguish a newly created coinbase output from a normally spendable UTXO. This is analogous to an overly permissive bound: the scan accepts a value whose early state makes it invalid for the operation for which it is later consumed.

### Finding Description
`Scanner::scan_block` iterates over all `block.txdata` entries without excluding the coinbase transaction. [1](#0-0)  For each transaction, `scan_transaction` accepts an output solely because its `script_pubkey` is present in the scanner's script map, then constructs a `ReceivedOutput` containing only the output and its outpoint. [2](#0-1)  The returned type has no field indicating coinbase status, block height, confirmations, or maturity. [3](#0-2) 

`SignableTransaction::new` treats any supplied `ReceivedOutput` as an immediately spendable input and converts its `outpoint` into a `TxIn`. [4](#0-3)  The signing path then commits to all supplied prevouts and produces a Taproot signature for the transaction. [5](#0-4)  No code in this reachable path rejects the input for being an immature coinbase output.

### Impact Explanation
A block producer can place a coinbase output paying to a scanner-registered script. An application that calls `scan_block` receives a `ReceivedOutput` that appears spendable, and `SignableTransaction` can construct and coordinate signing for a transaction spending it. Until the coinbase has matured for 100 blocks, the resulting transaction is consensus-invalid. This can cause unavailable funds to be accounted as received and can burn signing rounds or trigger downstream retry/error handling on an unspendable input.

### Likelihood Explanation
Likelihood is low to medium: exploitation requires a miner or another party able to place the relevant output in a block's coinbase transaction, and an application must consume `scan_block` results without a separate maturity filter. The code's own comment acknowledges that an additional post-processing pass is required when immediately spendable outputs are expected. [6](#0-5) 

### Recommendation
Represent maturity in `ReceivedOutput` or make `scan_block` enforce it by default. For example, return a richer scanned-output type containing `is_coinbase`, block height, or required confirmation count; alternatively, skip `block.txdata[0]` in `scan_block` and expose coinbase scanning through a separately named API that requires maturity-aware handling. `SignableTransaction::new` should reject inputs whose metadata does not prove they are spendable.

### Proof of Concept
```rust
// A miner constructs a block whose coinbase pays to `scanner_script`.
let mut block = mined_block;
block.txdata[0].output[0].script_pubkey = scanner_script;

// The scanner reports the immature coinbase output as received.
let received = scanner.scan_block(&block);
assert_eq!(received.len(), 1);
assert_eq!(received[0].outpoint().vout, 0);

// The wallet API accepts it as a normal input and builds a transaction.
let spend = SignableTransaction::new(
    received,
    &[(recipient_script, 50_000)],
    Some(change_script),
    None,
    10,
).unwrap();

// The resulting signed transaction spends an immature coinbase and is
// rejected by Bitcoin consensus until 100 confirmations have elapsed.
```

  pub fn scan_transaction(&self, tx: &Transaction) -> Vec<ReceivedOutput> {
    let mut res = Vec::new();
    for (vout, output) in tx.output.iter().enumerate() {
      // If the vout index exceeds 2**32, stop scanning outputs
      let Ok(vout) = u32::try_from(vout) else { break };

      if let Some(offset) = self.scripts.get(&output.script_pubkey) {
        res.push(ReceivedOutput {
          offset: *offset,
          output: output.clone(),
          outpoint: OutPoint::new(tx.compute_txid(), vout),
        });
      }
    }
