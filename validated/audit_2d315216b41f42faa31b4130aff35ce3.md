### Title
Commit Transaction Broadcast Without Atomic DB Update Causes Permanent Fund Lock in Citrea DA Sync - (File: `crates/clementine-tx-sender/src/citrea/sync.rs`)

### Summary

In `create_commit_outpoints_for_rows`, a Bitcoin commit transaction is broadcast to the network **before** the DB is updated with the resulting commit outpoints. If any DB write fails after the broadcast (transient connection error, pool exhaustion, etc.), the commit transaction is confirmed or in-mempool but the system has no record of it. On the next `sync_citrea_txs` cycle the rows still show `commit_outpoint IS NULL`, so a second commit transaction is created and broadcast. The original commit transaction's P2TR outputs — which can only be spent by the matching reveal transaction — are permanently locked with no recovery path.

---

### Finding Description

`sync_citrea_txs` calls `create_commit_outpoints_for_rows` for every group of Citrea DA rows whose `commit_outpoint` is `NULL` in the database. [1](#0-0) 

The sequence inside that function is:

1. **Fund and sign** the commit transaction (lines 467–508).
2. **Broadcast** it unconditionally (line 512). On success the transaction enters the Bitcoin mempool.
3. **Iterate** over every row and write its commit outpoint to the DB one-by-one, each with `None` (no enclosing DB transaction) (lines 522–530).

```rust
// line 512 – tx is now in the mempool
if let Err(e) = self.rpc.send_raw_transaction(&signed_commit_tx).await { … }

// lines 522-530 – DB writes happen AFTER broadcast, outside any transaction
for (vout, (row, _signing_data)) in rows_with_scripts.into_iter().enumerate() {
    let outpoint = bitcoin::OutPoint { txid: commit_txid, vout: vout as u32 };
    self.db
        .set_citrea_commit_outpoint(None, row.id, outpoint)  // <-- can fail
        .await?;                                              // <-- propagates error
}
```

If `set_citrea_commit_outpoint` returns an error for **any** row (including the very first), the `?` operator unwinds the function. The commit transaction is already in the Bitcoin network; the DB still shows `commit_outpoint = NULL` for every row that was not yet written.

On the next invocation of `sync_citrea_txs`:

```rust
// line 70 – re-fetches all rows with null commit_outpoint
let citrea_rows = self.db.get_citrea_txs_with_null_commit_outpoint(None).await?;
``` [2](#0-1) 

The rows appear again as if no commit transaction was ever created. A **new** commit transaction is funded, signed, and broadcast. The original commit transaction's outputs — P2TR script-path addresses that can only be spent by the corresponding reveal transaction — are now permanently unspendable because:

- The reveal transaction is built from the **new** commit outpoint (different txid/vout).
- `check_evicted_commit_txs` only inspects commit outpoints that are **recorded** in the DB; the original commit tx is invisible to it.
- There is no blockchain-scan recovery path in the codebase. [3](#0-2) 

---

### Impact Explanation

The tx-sender's Bitcoin wallet funds the commit transaction. Each P2TR output in that transaction (one per DA row in the group) holds at least the dust threshold in BTC. Because no reveal transaction is ever constructed for the original commit tx, those outputs are permanently locked. The loss repeats on every occurrence of a post-broadcast DB failure, and the amount grows with the number of rows per group and the fee rate at the time.

This satisfies the gate criterion: **permanent lock of tx-sender-managed balances**.

---

### Likelihood Explanation

The trigger is a transient PostgreSQL connection error, pool timeout, or network blip that occurs in the narrow window between `send_raw_transaction` returning `Ok` and the first `set_citrea_commit_outpoint` completing. This is uncommon under normal operation but is a realistic failure mode during DB restarts, connection-pool exhaustion under load, or infrastructure maintenance. No privileged access or adversarial action is required.

---

### Recommendation

Invert the write order: **record the commit outpoint in the DB before broadcasting the commit transaction**.

```rust
// 1. Compute the commit txid deterministically (it is known before broadcast).
let commit_txid = signed_commit_tx.compute_txid();

// 2. Write all commit outpoints to the DB first (inside a single DB transaction).
let mut dbtx = self.db.begin_transaction().await?;
for (vout, (row, _)) in rows_with_scripts.iter().enumerate() {
    let outpoint = bitcoin::OutPoint { txid: commit_txid, vout: vout as u32 };
    self.db.set_citrea_commit_outpoint(Some(&mut dbtx), row.id, outpoint).await?;
}
self.db.commit_transaction(dbtx).await?;

// 3. Only then broadcast.
if let Err(e) = self.rpc.send_raw_transaction(&signed_commit_tx).await { … }
```

If the broadcast fails after the DB write, the existing `check_evicted_commit_txs` logic will detect that the commit outpoint is not in the mempool and can reset it. If the DB write fails, the transaction was never broadcast, so no funds are lost.

---

### Proof of Concept

1. A group of Citrea DA rows with `commit_outpoint IS NULL` is picked up by `sync_citrea_txs`.
2. `create_commit_outpoints_for_rows` funds, signs, and broadcasts the commit transaction — it enters the Bitcoin mempool.
3. The DB connection drops (or the pool is exhausted) immediately after `send_raw_transaction` returns `Ok`.
4. `set_citrea_commit_outpoint` returns a connection error; `?` propagates it; the function exits without writing any outpoint.
5. On the next `sync_citrea_txs` tick, `get_citrea_txs_with_null_commit_outpoint` returns the same rows.
6. A second commit transaction is created, funded from the wallet, and broadcast.
7. The first commit transaction's P2TR outputs (one per row) are confirmed on-chain with no corresponding reveal transaction ever submitted — those satoshis are permanently unspendable.

```rust
    async fn create_commit_outpoints_for_rows(
        &self,
        fee_rate: FeeRateKvb,
        insertion_id: i64,
        rows_with_scripts: Vec<(CitreaRawTxRow, CitreaSigningData)>,
    ) -> Result<Option<bitcoin::Txid>, eyre::Report> {
        if rows_with_scripts.is_empty() {
            return Ok(None);
        }

        let recipients: Vec<_> = rows_with_scripts
            .iter()
            .map(|(_row, signing_data)| signing_data.commit_address.clone())
            .collect();

        let unsigned_commit_tx = crate::citrea::build_commit_transaction(&recipients);
        let raw_bytes = crate::serialize_tx_for_fund_raw(&unsigned_commit_tx);

        let funded_hex = match self
            .rpc
            .fund_raw_transaction(
                &raw_bytes,
                Some(&FundRawTransactionOptions {
                    add_inputs: Some(true),
                    include_unsafe: Some(self.include_unsafe),
                    change_address: None,
                    change_position: Some(unsigned_commit_tx.output.len() as u32),
                    change_type: None,
                    include_watching: None,
                    lock_unspents: None,
                    fee_rate: Some(Amount::from_sat(fee_rate.to_sat_per_kvb())),
                    subtract_fee_from_outputs: None,
                    replaceable: Some(true),
                    conf_target: None,
                    estimate_mode: None,
                }),
                None,
            )
            .await
        {
            Ok(result) => result.hex,
            Err(e) => {
                tracing::error!(
                    insertion_id,
                    error = %e,
                    "Failed to fund commit transaction, skipping group"
                );
                return Ok(None);
            }
        };

        let signed_commit_tx = self
            .rpc
            .sign_raw_transaction_with_wallet(&funded_hex, None, None)
            .await
            .wrap_err("Failed to sign commit transaction")?
            .transaction()
            .wrap_err(
                "Failed to convert result of sign_raw_transaction_with_wallet to btc transaction",
            )?;

        let commit_txid = signed_commit_tx.compute_txid();

        if let Err(e) = self.rpc.send_raw_transaction(&signed_commit_tx).await {
            tracing::warn!(
                insertion_id,
                commit_txid = %commit_txid,
                error = %e,
                "Failed to broadcast commit transaction, skipping group"
            );
            return Ok(None);
        }

        for (vout, (row, _signing_data)) in rows_with_scripts.into_iter().enumerate() {
            let outpoint = bitcoin::OutPoint {
                txid: commit_txid,
                vout: vout as u32,
            };

            self.db
                .set_citrea_commit_outpoint(None, row.id, outpoint)
                .await?;
        }

        Ok(Some(commit_txid))
    }
