### Title
Empty DLEq statement list allows forged proofs - (File: crypto/dleq/src/lib.rs)

### Summary
`DLEqProof::verify` accepts equal-length `generators` and `points` slices without rejecting the case where both are empty. A proof containing the challenge for an empty DLEq transcript and an arbitrary `s` value then verifies without proving any discrete-log equality.

### Finding Description
The verifier only checks that `generators.len() == points.len()`, then iterates over their zipped entries. When both slices are empty, the loop performs no verification statements and the function only compares `self.c` with the challenge derived from the empty transcript. [1](#0-0)  Publicly supplied proof bytes can be decoded into the `c` and `s` fields through `DLEqProof::read`. [2](#0-1) 

### Impact Explanation
An unprivileged party can create a DLEq proof that is accepted while proving no statement at all. If a caller uses `verify` to establish equality across a caller-provided list of generators and points, malformed or empty metadata can turn that proof into a valid-looking assertion for no actual points.

### Likelihood Explanation
The attack requires the verifier to evaluate a proof against an empty `generators`/`points` pair, but it does not require secret material, network privileges, malformed curve encodings, or control of another participant. The required challenge is deterministic and publicly reproducible from the verifier transcript. [3](#0-2) 

### Recommendation
Reject zero-length DLEq statement sets in `DLEqProof::verify`, for example by returning `InvalidProof` when `generators.is_empty()`. Apply the same check to `MultiDLEqProof::verify`, which has the same equal-length checks and vacuous verification behavior when all statement collections are empty. [4](#0-3) 

### Proof of Concept
```rust
// Serialize a proof whose `c` equals the challenge obtained after
// `transcript.domain_separate(b"dleq")` with zero appended statements.
// `s` may be any canonical scalar.
let forged_bytes = c.to_repr().as_ref().iter()
    .chain(s.to_repr().as_ref())
    .copied()
    .collect::<Vec<_>>();

let proof = DLEqProof::<G>::read(&mut forged_bytes.as_slice()).unwrap();

let mut transcript = verifier_supplied_transcript();
assert!(proof.verify(&mut transcript, &[], &[]).is_ok());
```

The call succeeds because `verify` skips every statement and only compares the supplied `c` to the empty-statement transcript challenge. [5](#0-4)
