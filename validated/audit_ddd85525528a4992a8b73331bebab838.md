### Title
Public `txpool_content` RPC leaks full pending-transaction calldata and sender addresses for all mempool transactions, enabling front-running / MEV against any unprivileged user - (File: evmrpc/txpool.go)

### Summary
The `txpool` namespace is registered on the EVM JSON-RPC HTTP server without any allowlist gating (unlike the `sei_*` legacy namespace, which is deny-listed by default via `enabled_legacy_sei_apis`). `TxPoolAPI.Content` (`evmrpc/txpool.go`) reads every unconfirmed transaction currently sitting in the local mempool and returns full transaction contents — sender, nonce, `to`, `value`, `gas`, `gasPrice`/`maxFeePerGas`, and raw `input` calldata — to any anonymous caller of the public JSON-RPC endpoint.

### Finding Description
`TxPoolAPI.Content` is wired into the HTTP RPC server's `apis` slice under the `txpool` namespace: [1](#0-0) 

Unlike the `sei_*` legacy namespace, which is explicitly gated by `wrapSeiLegacyHTTP`/`SeiLegacyAllowlist` based on `[evm].enabled_legacy_sei_apis`, the `txpool` namespace has no equivalent allowlist or deny-list gate applied by default — the AGENTS.md spec for `evmrpc/` states that "Any exported method added to a registered API struct is automatically a live, unaudited RPC endpoint — with no request validation, no rate-limit review, and no `sei_*`-style gating unless someone deliberately adds it." [2](#0-1) 

The implementation itself pulls every unconfirmed transaction from the mempool and decodes/returns its full contents, keyed by sender and nonce: [3](#0-2) 

This includes the transaction's `input` (raw calldata), `to`, `value`, gas parameters, and `from` (recovered via `RecoverEVMSenderWithContext`) for every pending transaction in the local mempool — confirmed by the integration test, which asserts non-zero `input`, `to`, `value`, `gas`, etc. are all returned: [4](#0-3) 

Any unprivileged, unauthenticated public-RPC client can poll `txpool_content` to observe the exact calldata of transactions submitted by other users before they are included in a block (Sei has instant finality, so the mempool window is brief, but non-zero — transactions are checked and gossiped before being sequenced). This is a direct information-exposure surface: transaction intent (e.g. token swap parameters, arbitrage strategy, liquidation targets, contract-call arguments) that a user reasonably expects to be private until execution is broadcast to any anonymous requester.

### Impact Explanation
Exposure of pending transaction contents through a public, unauthenticated endpoint is the direct enabler of front-running/MEV extraction: an adversary can observe another user's pending swap, liquidation, or arbitrage transaction (calldata + sender + gas price) via `txpool_content` and race a competing transaction with higher priority fee ahead of it, extracting value from the original submitter. This falls squarely into the fee/refund and unauthorized-value-extraction impact category, since it allows systematic extraction of economic value that rightfully belongs to the original transaction sender, and is reachable by any public-RPC client without any privileges — matching the class of "Exposure of Sensitive Information to an Unauthorized Actor" from the reference CVE, adapted to the reachable EVM JSON-RPC surface.

### Likelihood Explanation
Likelihood is high: `txpool_content` requires no authentication, no special role, and no rate-limited/gated method name (unlike `sei_*` methods) to invoke; it is exposed by default whenever the EVM HTTP RPC server is enabled, which is the standard configuration for any Sei full/RPC node. A caller only needs to be a public RPC client sending a single JSON-RPC POST — the exact "public-RPC client" reachability the review scope calls out as first-class.

### Recommendation
Gate the `txpool` namespace (or at minimum `txpool_content`) behind the same kind of allowlist/deny-list mechanism used for `sei_*` legacy methods, or reduce the information disclosed (e.g., strip `input`/calldata, or omit `from`/full transaction detail, exposing only counts) on public/default-configuration RPC nodes. Consider requiring the `[evm].deny_list` to include `txpool_content` by default, or restrict it to trusted/JWT-authenticated RPC endpoints only, since exposing raw pending calldata is fundamentally incompatible with a permissionless public RPC surface without inviting front-running.

### Proof of Concept
1. Submit an EVM transaction with sensitive calldata (e.g., a swap with a large `to`/`value`/`input` payload) via `eth_sendRawTransaction` to a Sei RPC node, without waiting for it to be mined.
2. Concurrently, from an unrelated, unauthenticated client, call:
```json
{"jsonrpc":"2.0","id":1,"method":"txpool_content","params":[]}
```
3. Observe the response includes the pending transaction's full `from`, `to`, `value`, `gas`, `gasPrice`/`maxFeePerGas`, `input`, `nonce`, `v`/`r`/`s`, exactly as validated by the existing test `TestTxPoolContent` [5](#0-4) , confirming that any anonymous caller can extract the private transaction intent of another user before it is included in a block, enabling a front-run with a higher-fee competing transaction submitted immediately after observation.

// Content returns the content of the txpool.
// for now, we put all unconfirmed txs in pending and none in queued.
func (t *TxPoolAPI) Content(ctx context.Context) (result map[string]map[string]map[string]*export.RPCTransaction, returnErr error) {
	startTime := time.Now()
	defer func() {
		recordMetricsWithError(ctx, "sei_content", t.connectionType, startTime, returnErr, recover())
	}()
	content := map[string]map[string]map[string]*export.RPCTransaction{
		"pending": make(map[string]map[string]*export.RPCTransaction),
		"queued":  make(map[string]map[string]*export.RPCTransaction),
	}

	total := t.txPoolConfig.maxNumTxs
	resUnconfirmedTxs, err := t.tmClient.UnconfirmedTxs(ctx, nil, &total)
	if err != nil {
		return nil, err
	}

	sdkCtx := t.ctxProvider(LatestCtxHeight)
	for _, tx := range resUnconfirmedTxs.Txs {
		ethTx := getEthTxForTxBz(tx, t.txConfigProvider(LatestCtxHeight).TxDecoder())
		if ethTx == nil { // not an evm tx
			continue
		}
		fromAddr, err := rpcutils.RecoverEVMSenderWithContext(sdkCtx, ethTx)
		if err != nil {
			return nil, err
		}
		nonce := ethTx.Nonce()
		chainConfig := types.DefaultChainConfig().EthereumConfig(t.keeper.ChainID(sdkCtx))
		res := export.NewRPCPendingTransaction(ethTx, nil, chainConfig)
		nonceStr := strconv.FormatUint(nonce, 10)
		if content["pending"][fromAddr.String()] == nil {
			content["pending"][fromAddr.String()] = map[string]*export.RPCTransaction{
				nonceStr: res,
			}
		} else {
			content["pending"][fromAddr.String()][nonceStr] = res
		}
	}
	return content, nil

func TestTxPoolContent(t *testing.T) {
	body := "{\"jsonrpc\": \"2.0\",\"method\": \"txpool_content\",\"params\":[],\"id\":\"test\"}"
	req, err := http.NewRequest(http.MethodGet, fmt.Sprintf("http://%s:%d", TestAddr, TestPort), strings.NewReader(body))
	require.Nil(t, err)
	req.Header.Set("Content-Type", "application/json")
	res, err := http.DefaultClient.Do(req)
	require.Nil(t, err)
	resBody, err := io.ReadAll(res.Body)
	require.Nil(t, err)

	// check pending has 1 txn in it
	resObj := map[string]interface{}{}
	require.Nil(t, json.Unmarshal(resBody, &resObj))
	resObj = resObj["result"].(map[string]interface{})
	pendingMap := resObj["pending"].(map[string]interface{})
	require.Equal(t, 1, len(pendingMap))

	// check that txn
	for fromAddr, txns := range pendingMap {
		for nonce, txn := range txns.(map[string]interface{}) {
			require.NotZero(t, nonce)
			tx := txn.(map[string]interface{})
			require.Nil(t, tx["blockNumber"])
			require.Nil(t, tx["blockHash"])
			require.Equal(t, strings.ToLower(tx["from"].(string)), strings.ToLower(fromAddr))
			requireNotZeroHex(t, tx["gas"].(string))
			requireNotZeroHex(t, tx["gasPrice"].(string))
			// maxFeePerGas
			requireNotZeroHex(t, tx["maxFeePerGas"].(string))
			// maxPriorityFeePerGas
			// hash
			requireNotZeroHex(t, tx["hash"].(string))
			// input
			requireNotZeroHex(t, tx["input"].(string))
			// nonce -- can be 0
			// to
			requireNotZeroHex(t, tx["to"].(string))
			// transactionIndex -- not set yet for pending
			// value
			requireNotZeroHex(t, tx["value"].(string))
			// type -- can be 0
			// acccesslist-- can be any array value
			require.Equal(t, tx["chainId"], "0xae3f2") // 713714
			requireNotZeroHex(t, tx["v"].(string))
			requireNotZeroHex(t, tx["r"].(string))
			requireNotZeroHex(t, tx["s"].(string))
		}
	}

	// check queued has nothing in it
	queuedMap := resObj["queued"].(map[string]interface{})
	require.Equal(t, 0, len(queuedMap))
