### Title
Unrecovered `sdk.Dec` overflow panic in `Tally()` reward-spread calculation can halt oracle `MidBlocker` - (File: x/oracle/tally.go)

### Summary
`x/oracle/tally.go`'s `Tally()` function computes `rewardSpread := weightedMedian.Mul(rewardBand.QuoInt64(2))` without any panic recovery, unlike the two other overflow-prone `sdk.Dec` computations in the same package (`ToCrossRate` and `StandardDeviation`), which are explicitly wrapped in `defer/recover()` to guard against exactly this class of bug (`sdk.Dec.Mul`/`Quo` calling `assertInValidRange()` which panics on overflow of the 315-bit `Dec` range). [1](#0-0) [2](#0-1) [3](#0-2) 

### Finding Description
`sdk.Dec.Mul`/`Quo`/`QuoTruncate`/`QuoRoundUp` all call `result.assertInValidRange()`, which panics when the internal `big.Int` exceeds the 315-bit maximum decimal value. [4](#0-3) 

`weightedMedian` returned by `pb.WeightedMedianWithAssertion()` is directly one of the submitted vote exchange rates (no arithmetic reduction is applied), so a validator (or a feeder holding a validator's delegated feed key) can submit an `AggregateExchangeRateVote` with an extremely large `ExchangeRate` value close to the maximum valid `Dec`. If that vote becomes the weighted median for a denom's ballot, `Tally()` then executes `weightedMedian.Mul(rewardBand.QuoInt64(2))`, which can overflow the 315-bit bound and panic. [5](#0-4) [1](#0-0) 

This call happens inside `MidBlocker`, invoked once per vote period for every whitelisted denom's ballot, with no `defer/recover` around it or around the call site in `abci.go`. [6](#0-5) 

Notably, the codebase already demonstrates awareness of this exact overflow-panic bug class: `ToCrossRate` and `StandardDeviation` in the same file both wrap their `Quo`/`Mul` calls in `defer/recover()` specifically to survive `sdk.Dec` overflow, and there is a dedicated regression test (`TestOverflowAndDivByZero`, `TestTallyOverflow`) asserting `MidBlocker`/`EndBlocker` "should not panic" on overflowing votes. [7](#0-6) [8](#0-7) [9](#0-8) 

However, those tests only exercise the path up to and including `WeightedMedianWithAssertion`/`StandardDeviation`; they do not cover the subsequent unguarded `weightedMedian.Mul(rewardBand.QuoInt64(2))` line in `Tally()`, which remains unprotected.

### Impact Explanation
A panic thrown inside `MidBlocker` is not caught anywhere in the oracle module or (as far as this analysis could determine) by the module manager's `MidBlock` dispatch, since no recover wraps the `Tally()` call chain in `abci.go`. Because `MidBlocker`/`EndBlocker` execute deterministically and identically on every validator node processing the same block, an unrecovered panic here would deterministically crash every full node and validator simultaneously — a chain halt — rather than being contained to a single failed transaction. This is a Medium/High-severity validator-halt condition reachable purely through the standard oracle vote submission transaction path.

### Likelihood Explanation
Triggering this requires control of a delegated oracle feeder key for at least one active validator (needed to submit `MsgAggregateExchangeRateVote`) and crafting an exchange-rate value near the `Dec` overflow boundary such that it becomes the ballot's weighted median. This is a normal, unprivileged-with-respect-to-consensus transaction type (`oracle vote admission`), not a byzantine consensus/p2p attack, making it a plausible-but-nontrivial griefing vector for any account with feeder rights.

### Recommendation
Wrap the `rewardSpread := weightedMedian.Mul(rewardBand.QuoInt64(2))` computation in `x/oracle/tally.go`'s `Tally()` in the same `defer/recover()` pattern already used in `ToCrossRate` and `StandardDeviation`, or clamp/validate submitted exchange rates against a sane maximum before they can become part of a ballot's weighted median.

### Proof of Concept
1. Register/whitelist a denom and have a validator's feeder submit `MsgAggregateExchangeRateVote` (via the standard prevote/vote reveal flow) with `ExchangeRate` set close to the maximum valid `Dec` (`sdk.NewDecFromBigIntWithPrec` boundary, ~2^315), i.e. a value similar to that used in `TestTallyOverflow`. [10](#0-9) 
2. Ensure this vote achieves majority (or is the sole vote) for the denom's ballot so `WeightedMedianWithAssertion()` returns this large value. [11](#0-10) 
3. On `MidBlocker` execution, `Tally()` computes `weightedMedian.Mul(rewardBand.QuoInt64(2))`, which is unguarded and can panic due to `assertInValidRange()` in `Dec.Mul`, crashing the node processing the block. [1](#0-0) [12](#0-11)

// WeightedMedian returns the median weighted by the power of the ExchangeRateVote.
// CONTRACT: ballot must be sorted
func (pb ExchangeRateBallot) WeightedMedian() sdk.Dec {
	totalPower := pb.Power()
	if pb.Len() > 0 {
		pivot := int64(0)
		for _, v := range pb {
			votePower := v.Power

			pivot += votePower
			if pivot >= (totalPower / 2) {
				return v.ExchangeRate
			}
		}
	}
	return sdk.ZeroDec()
}

func (pb ExchangeRateBallot) WeightedMedianWithAssertion() sdk.Dec {
	if !sort.IsSorted(pb) {
		panic("ballot must be sorted")
	}

	totalPower := pb.Power()
	if pb.Len() > 0 {
		pivot := int64(0)
		for _, v := range pb {
			votePower := v.Power

			pivot += votePower
			if pivot >= (totalPower / 2) {
				return v.ExchangeRate
			}
		}
	}
	return sdk.ZeroDec()
}

// StandardDeviation returns the standard deviation by the power of the ExchangeRateVote.
func (pb ExchangeRateBallot) StandardDeviation(median sdk.Dec) (standardDeviation sdk.Dec) {
	if len(pb) == 0 {
		return sdk.ZeroDec()
	}

	defer func() {
		if e := recover(); e != nil {
			standardDeviation = sdk.ZeroDec()
		}
	}()

	sum := sdk.ZeroDec()
	for _, v := range pb {
		deviation := v.ExchangeRate.Sub(median)
		sum = sum.Add(deviation.Mul(deviation))
	}

	variance := sum.QuoInt64(int64(len(pb)))

	floatNum, _ := strconv.ParseFloat(variance.String(), 64)
	floatNum = math.Sqrt(floatNum)
	standardDeviation, _ = sdk.NewDecFromStr(fmt.Sprintf("%f", floatNum))

	return
}

func TestOverflowAndDivByZero(t *testing.T) {
	input := setup(t)
	params := input.OracleKeeper.GetParams(input.Ctx)
	params.Whitelist = types.DenomList{
		{Name: utils.MicroAtomDenom},
		{Name: utils.MicroEthDenom},
	}
	input.OracleKeeper.SetParams(input.Ctx, params)

	// Set vote targets
	input.OracleKeeper.ClearVoteTargets(input.Ctx)
	input.OracleKeeper.SetVoteTarget(input.Ctx, utils.MicroAtomDenom)
	input.OracleKeeper.SetVoteTarget(input.Ctx, utils.MicroEthDenom)

	// Test overflow case
	overflowRate := sdk.MustNewDecFromStr("7896044618658097711785492504343953926634992332820282019728792003956564819967.999999999999999999")
	smallRate := sdk.MustNewDecFromStr("0.000000000000000001")
	overflowVote := sdk.DecCoins{
		sdk.NewDecCoinFromDec(utils.MicroAtomDenom, overflowRate),
		sdk.NewDecCoinFromDec(utils.MicroEthDenom, smallRate),
	}
	makeAggregateVote(t, input, overflowVote, 0)
	makeAggregateVote(t, input, overflowVote, 1)
	makeAggregateVote(t, input, overflowVote, 2)

	// This should not panic
	oracle.MidBlocker(input.Ctx, input.OracleKeeper)
	oracle.EndBlocker(input.Ctx, input.OracleKeeper)

	// Verify no exchange rates were set for overflowed one
	rate, _, _, err := input.OracleKeeper.GetBaseExchangeRate(input.Ctx, utils.MicroAtomDenom)
	require.NoError(t, err)
	require.Equal(t, overflowRate, rate)
	_, _, _, err = input.OracleKeeper.GetBaseExchangeRate(input.Ctx, utils.MicroEthDenom)
	require.Error(t, err)

	input.Ctx = input.Ctx.WithBlockHeight(1)

	// Test divide by zero case
	zeroVote := sdk.DecCoins{
		sdk.NewDecCoinFromDec(utils.MicroAtomDenom, smallRate),
		sdk.NewDecCoinFromDec(utils.MicroEthDenom, overflowRate),
	}
	makeAggregateVote(t, input, zeroVote, 0)
	makeAggregateVote(t, input, zeroVote, 1)
	makeAggregateVote(t, input, zeroVote, 2)

	// This should not panic
	oracle.MidBlocker(input.Ctx, input.OracleKeeper)
	oracle.EndBlocker(input.Ctx, input.OracleKeeper)

	// Verify no exchange rates were set for either case
	rate, height, _, err := input.OracleKeeper.GetBaseExchangeRate(input.Ctx, utils.MicroAtomDenom)
	require.NoError(t, err)
	require.Equal(t, smallRate, rate)
	require.Equal(t, int64(1), height.Int64())
	_, _, _, err = input.OracleKeeper.GetBaseExchangeRate(input.Ctx, utils.MicroEthDenom)
	require.Error(t, err)
}
