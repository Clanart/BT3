### Title
Gasless swap deadline is not enforced at bundling/execution time, only advisory at mempool entry - ([File: kaiax/gasless/impl/getter.go], [File: kaiax/gasless/impl/tx_pool.go])

### Summary
The `GaslessModule`'s `VerifyExecutable`/`IsExecutable` functions, which gate whether a `GaslessSwapTx` (and its optional `GaslessApproveTx`) is bundled and executed in a block via `ExtractTxBundles`, never check `SwapArgs.Deadline` against the current time, even though the `SwapArgs` struct carries a `Deadline` field decoded straight from the swap calldata.

### Finding Description
`VerifyExecutable` in [1](#0-0)  validates conditions S1-S3, AP1, SP1-SP4 (sender match, token match, allowance sufficiency, nonce sequencing, repay amount correctness) but contains no check comparing `swapArgs.Deadline` to the current block time. This function backs `IsExecutable`, which is the sole gate used by `ExtractTxBundles` in [2](#0-1)  to decide whether to build a `[LendTxGenerator, ApproveTx?, SwapTx]` bundle for block inclusion, and is also used by `isApproveTxReady`/`isSwapTxReady` in [3](#0-2)  to decide pending-pool promotion.

The only place that actually checks `swapArgs.Deadline` against `g.Chain.CurrentBlock().Time()` is `checkBalanceForSwap`, exposed via `GetCheckBalance()` in [4](#0-3)  and [5](#0-4) . This is a separate, independently-gated check controlled by `GaslessConfig.ShouldCheckToken()`-style flags used at initial `AddLocal`/pool-admission time, not at the moment a proposer selects and re-verifies transactions for bundling into a block via `ExtractTxBundles`/`IsExecutable`.

This mirrors the ULTI report's root cause exactly: a "deadline" parameter that flows deep into the value-moving logic (`swapForGas`) is validated in only one narrow code path (pool admission / `checkBalanceForSwap`) while the path that actually triggers value movement and bundle construction (`VerifyExecutable` → `ExtractTxBundles` → `GetLendTxGenerator`) omits the check entirely.

### Impact Explanation
Because `IsExecutable`/`VerifyExecutable` never re-validates the deadline, a `GaslessSwapTx` with an expired `Deadline` that was somehow queued (e.g., a long-queued transaction whose deadline elapses while it sits in the pool, or a transaction submitted directly to a proposer bypassing the initial `checkBalanceForSwap` admission gate) can still be judged "executable" and get bundled with a `LendTxGenerator` that pays out gas-fee KAIA to the user upfront (`GetLendTxGenerator`, referenced in `builder.go`/README). If the underlying `GaslessSwapRouter.swapForGas` call reverts on-chain due to the expired deadline (assuming the router enforces the deadline itself, consistent with the ABI signature `swapForGas(token, amountIn, minAmountOut, amountRepay, deadline)` in [6](#0-5) ), the lend transaction that already transferred KAIA to the user could still succeed while the repayment swap fails, resulting in fee-delegation/lend-fund loss for the block proposer — a direct analog to the "malicious actor grief" pattern where a stale deadline causes downstream value-moving logic to diverge from expectations while earlier steps already committed value.

### Likelihood Explanation
Likelihood is low-to-moderate: it requires either (a) a swap transaction sitting in the pool long enough for its deadline to lapse before promotion/bundling (plausible under network congestion, since `PendingTimeout`/`QueueTimeout` in `PreReset` are the only cleanup mechanisms and are not tied to `Deadline`), or (b) a user/attacker crafting a transaction with a deliberately near-expired deadline to grief lend/repay accounting. This matches the report's own "High impact / Low likelihood" characterization.

### Recommendation
Add an explicit deadline check inside `VerifyExecutable` (or `IsExecutable`) in `kaiax/gasless/impl/getter.go`, comparing `swapArgs.Deadline` against `g.Chain.CurrentBlock().Time()` (consistent with the check already present in `checkBalanceForSwap`), so that a swap transaction with a lapsed deadline is never selected for bundling or lending regardless of which entry path (pool admission vs. builder-time re-verification) is exercised.

### Proof of Concept
1. Submit a valid `GaslessApproveTx` + `GaslessSwapTx` pair where `SwapArgs.Deadline` is set to a near-future timestamp that will elapse before the swap is promoted to `ready`/bundled (e.g., pool is congested or the tx sits in queue).
2. Once `block.timestamp > Deadline`, call `ExtractTxBundles` (as invoked by the block-building worker); `IsExecutable`/`VerifyExecutable` in [7](#0-6)  returns `true`/`nil` because it never inspects `Deadline`.
3. The bundle `[LendTxGenerator, ApproveTx, SwapTx]` is included in a block; `LendTxGenerator` pays the user KAIA up front.
4. If `GaslessSwapRouter.swapForGas` enforces the deadline on-chain, the swap reverts, leaving the lent KAIA unrecovered while the module's off-chain logic reported the transaction as valid and executable.

	err := g.VerifyExecutable(approveTxOrNil, swapTx)
	if err != nil {
		return false
	}
	return true
}

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
}

func (g *GaslessModule) GetCheckBalance() func(tx *types.Transaction) error {
	return func(tx *types.Transaction) error {
		if approveArgs, ok := decodeApproveTx(tx, g.signer); ok {
			return g.checkBalanceForApprove(approveArgs)
		}
		if swapArgs, ok := decodeSwapTx(tx, g.signer); ok {
			return g.checkBalanceForSwap(swapArgs, tx.Nonce())
		}
		return errors.New("not a gasless transaction") // should not happen because IsModuleTx is called before GetCheckBalance
	}
}

// isApproveTxReady assumes that the caller checked `g.IsApproveTx(approveTx)`
func (g *GaslessModule) isApproveTxReady(approveTx, nextTx *types.Transaction) bool {
	addr, err := types.Sender(g.signer, approveTx)
	if err != nil {
		return false
	}
	nonce := g.getCurrentStateNonce(addr)

	if approveTx.Nonce() != nonce {
		return false
	}
	if nextTx == nil || !g.IsSwapTx(nextTx) {
		return false
	}

	return g.IsExecutable(approveTx, nextTx)
}

// isSwapTxReady assumes that the caller checked `g.IsSwapTx(swapTx)`
func (g *GaslessModule) isSwapTxReady(swapTx, prevTx *types.Transaction) bool {
	addr, err := types.Sender(g.signer, swapTx)
	if err != nil {
		return false
	}
	nonce := g.getCurrentStateNonce(addr)

	var approveTx *types.Transaction
	if swapTx.Nonce() == nonce {
		approveTx = nil
	} else if swapTx.Nonce() == nonce+1 {
		if prevTx == nil || !g.IsApproveTx(prevTx) {
			return false
		}
		approveTx = prevTx
	} else {
		return false
	}

	return g.IsExecutable(approveTx, swapTx)
}
