## Analysis Result [1](#0-0) 

I found a valid analog: an unchecked division by a governance-controllable parameter (`GasTarget`) in the KIP-71 base fee calculation, which is executed by every node on every block after the Magma hardfork.

### Title
Division by zero in `KIP71Config.NextMagmaBlockBaseFee` when governance sets `GasTarget` to 0 - (File: `params/kip71_config.go`)

### Summary
`NextMagmaBlockBaseFee` divides by the governance parameter `GasTarget` without ever checking it is non-zero. Unlike the sibling `BaseFeeDenominator` parameter, `GasTarget`'s governance `FormatChecker` is a no-op that accepts `0`, so a single governance vote can set `GasTarget = 0` and crash every node computing the next block's base fee.

### Finding Description
`NextMagmaBlockBaseFee` computes the delta needed to move the base fee toward or away from `gasTarget`: [2](#0-1) 

When `parentGasUsed > gasTarget` (or `<`), the code does:
```go
gasUsedDelta := new(big.Int).SetUint64(parentGasUsed - gasTarget)
x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
y := x.Div(x, new(big.Int).SetUint64(gasTarget))  // divides by gasTarget
```
`big.Int.Div` panics on a zero divisor. There is no zero-guard on `gasTarget`, unlike `baseFeeDenominator`, which explicitly falls back to `64` when zero: [3](#0-2) 

The `GasTarget` governance parameter (`Kip71GasTarget`) uses `noopFormatChecker`, i.e., no validation preventing `0`, whereas the sibling `BaseFeeDenominator` parameter explicitly requires `v != 0`: [4](#0-3) 

This inconsistency shows the zero-check was consciously added for `BaseFeeDenominator` but omitted for `GasTarget`, even though both are used as divisors in the exact same function.

### Impact Explanation
`NextMagmaBlockBaseFee` (via `ToKip71Config()` populated from the live governance `ParamSet`) is invoked on the hot path of block header validation for every single block after Magma, by every full node, in `VerifyMagmaHeader`: [5](#0-4) 

and also in RPC fee history / gas price estimation used by public RPC callers: [6](#0-5) 

If `GasTarget` is set to `0` (a legitimate, unguarded governance vote outcome) and any subsequent block's `parentGasUsed != 0` (essentially guaranteed on a live chain), every node that verifies the next header, computes fee history, or estimates gas price will panic on division by zero. This effectively halts consensus / crashes nodes network-wide — a severe denial-of-service far more impactful than the "Medium" original report, since it is a single governance-parameter update that can take down the entire network rather than a contract-local revert.

### Likelihood Explanation
Setting a governance parameter such as `Kip71GasTarget` requires a governance vote/transaction from an authorized governance actor (validator/governing node), which is one of the explicitly in-scope reachable categories ("governance parameters"). No additional validation anywhere else in the vote-canonicalization/format-checking pipeline (`kaiax/gov/param.go`, `paramset.go`) rejects `0` for this specific parameter, so the unsafe value can be committed via the normal governance flow.

### Recommendation
Add a zero-check for `GasTarget` analogous to the `BaseFeeDenominator` fallback in `NextMagmaBlockBaseFee` (e.g., fall back to the default `30000000` or reject the division safely when `gasTarget == 0`), and/or update the `Kip71GasTarget` `FormatChecker` in `kaiax/gov/param.go` to reject `0`, matching the treatment already given to `Kip71BaseFeeDenominator`.

### Proof of Concept
1. A governance vote sets `governance.kip71.gastarget = 0` (accepted because `FormatChecker: noopFormatChecker` at `kaiax/gov/param.go:324-334`).
2. On the next block after the vote takes effect, any block with `parentGasUsed != 0` triggers the `else if parentGasUsed > gasTarget` (or `else`) branch in `NextMagmaBlockBaseFee`.
3. `y := x.Div(x, new(big.Int).SetUint64(gasTarget))` executes `big.Int.Div(x, 0)`, which panics.
4. Because `VerifyMagmaHeader`/`NextMagmaBlockBaseFee` runs in every node's header-validation path (`blockchain/block_validator.go`) and in `feehistory.go`'s public RPC handler, all nodes attempting to validate or serve fee data for this block panic, causing a chain-wide denial of service.

func (kc *KIP71Config) NextMagmaBlockBaseFee(parentHeaderNumber *big.Int, parentHeaderBaseFee *big.Int, parentHeaderGasUsed uint64) *big.Int {
	// governance parameters
	lowerBoundBaseFee := new(big.Int).SetUint64(kc.LowerBoundBaseFee)
	upperBoundBaseFee := new(big.Int).SetUint64(kc.UpperBoundBaseFee)
	makeEvenByCeil(lowerBoundBaseFee)
	makeEvenByFloor(upperBoundBaseFee)

	// If the parent is the magma disabled block or genesis, then return the lowerBoundBaseFee (default 25ston)
	if parentHeaderNumber.Cmp(new(big.Int).SetUint64(0)) == 0 || parentHeaderBaseFee == nil {
		return makeEvenByFloor(lowerBoundBaseFee)
	}

	var baseFeeDenominator *big.Int
	if kc.BaseFeeDenominator == 0 {
		// To avoid panic, set the fluctuation range small
		baseFeeDenominator = new(big.Int).SetUint64(64)
	} else {
		baseFeeDenominator = new(big.Int).SetUint64(kc.BaseFeeDenominator)
	}
	gasTarget := kc.GasTarget
	upperGasLimit := kc.MaxBlockGasUsedForBaseFee

	// check the case of upper/lowerBoundBaseFee is updated by governance mechanism
	parentBaseFee := parentHeaderBaseFee
	if parentBaseFee.Cmp(upperBoundBaseFee) >= 0 {
		parentBaseFee = upperBoundBaseFee
	} else if parentBaseFee.Cmp(lowerBoundBaseFee) <= 0 {
		parentBaseFee = lowerBoundBaseFee
	}

	// upper gas limit cut off the impulse of used gas to upper bound
	parentGasUsed := min(parentHeaderGasUsed, upperGasLimit)
	if parentGasUsed == gasTarget {
		return makeEvenByFloor(parentBaseFee)
	} else if parentGasUsed > gasTarget {
		// shortcut. If parentBaseFee is already reached upperbound, do not calculate.
		if parentBaseFee.Cmp(upperBoundBaseFee) == 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		// If the parent block used more gas than its target,
		// the baseFee of the next block should increase.
		// baseFeeDelta = max(1, parentBaseFee * (parentGasUsed - gasTarget) / gasTarget / baseFeeDenominator)
		gasUsedDelta := new(big.Int).SetUint64(parentGasUsed - gasTarget)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := math.BigMax(x.Div(y, baseFeeDenominator), common.Big1)

		nextBaseFee := x.Add(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(upperBoundBaseFee) > 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	} else {
		// shortcut. If parentBaseFee is already reached lower bound, do not calculate.
		if parentBaseFee.Cmp(lowerBoundBaseFee) == 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		// Otherwise if the parent block used less gas than its target,
		// the baseFee of the next block should decrease.
		// baseFeeDelta = parentBaseFee * (gasTarget - parentGasUsed) / gasTarget / baseFeeDenominator
		gasUsedDelta := new(big.Int).SetUint64(gasTarget - parentGasUsed)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := x.Div(y, baseFeeDenominator)

		nextBaseFee := x.Sub(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(lowerBoundBaseFee) < 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	}
}
