### Title
Pointer precompile's `AddCW20`/`AddCW721`/`AddCW1155`/`AddNative` bypass the `RegisterPointerDisabled` governance kill-switch enforced by `RegisterPointer` - ([File: precompiles/pointer/pointer.go])

### Summary
`x/evm/keeper/msg_server.go`'s `RegisterPointer` handler guards all CW→ERC pointer creation/migration behind `server.GetRegisterPointerDisabled(ctx)` [1](#0-0)  — this is the chain's designated "emergency lock" for pointer registration, analogous to `whenNotLocked()` in the Notional report. However, the pointer precompile at address `0x...100b`, which is directly callable from any EVM transaction, implements the sibling functionality (`AddNative`, `AddCW20`, `AddCW721`, `AddCW1155`) without ever consulting this flag [2](#0-1) .

### Finding Description
The pointer precompile's `Execute` dispatches to `AddNative`, `AddCW20`, `AddCW721`, and `AddCW1155` based on method name, each of which directly calls `p.evmKeeper.UpsertERCNativePointer` / `UpsertERCCW20Pointer` / `UpsertERCCW721Pointer` / `UpsertERCCW1155Pointer` [3](#0-2) . None of these four functions check `GetRegisterPointerDisabled`, unlike the `MsgRegisterPointer` handler which is the "sanctioned" governance-controlled pointer-creation path [4](#0-3) . This means governance (or an operator responding to an incident) can disable pointer registration via the `RegisterPointerDisabled` param, believing all pointer-creation surfaces are frozen, while an attacker or ordinary user can still create/upsert pointers for arbitrary CW20/CW721/CW1155 contracts or native denoms by calling the EVM precompile directly with a plain transaction.

### Impact Explanation
`RegisterPointerDisabled` exists specifically to let the chain halt new pointer creation (e.g., during an incident involving malicious/duplicate pointer contracts, a broken pointer code template, or an ongoing pointer-migration process). Because the precompile path is unguarded, this safety switch is incomplete: unauthorized/uncontrolled pointer contracts can still be created and used to bridge CW assets into the EVM (or vice versa) while the chain believes registration is frozen. Pointers directly affect balance/ownership representation for CW20/CW721/CW1155 assets on the EVM side, so bypassing the freeze can lead to bridging of assets through unintended/duplicate pointer contracts, undermining the incident-response guarantee the flag is meant to provide.

### Likelihood Explanation
High reachability: any unprivileged EVM transaction sender can call the pointer precompile at `0x...100b` with `addNativePointer`, `addCW20Pointer`, `addCW721Pointer`, or `addCW1155Pointer` — no special privileges, wasm access, or governance approval required. The only gating condition needed to trigger the bug is that governance has set `RegisterPointerDisabled = true` expecting the pointer surface to be fully frozen.

### Recommendation
Add a check for `p.evmKeeper.GetRegisterPointerDisabled(ctx)` (mirroring `x/evm/keeper/msg_server.go` line 249) at the top of `AddNative`, `AddCW20`, `AddCW721`, and `AddCW1155` in `precompiles/pointer/pointer.go`, returning an error consistent with `"registering CW->ERC pointers has been disabled"` when the flag is set, so both entry points (message-server `RegisterPointer` and the EVM precompile) share the same governance-controlled freeze.

### Proof of Concept
1. Governance (or an authorized param-change) sets `RegisterPointerDisabled = true` via `x/evm` params, intending to stop all new CW↔ERC pointer creation.
2. An attacker submits a plain EVM transaction calling `addCW20Pointer(cwAddr)` (or `addCW721Pointer`/`addCW1155Pointer`/`addNativePointer`) on the pointer precompile at `0x000000000000000000000000000000000000100b`.
3. `PrecompileExecutor.Execute` dispatches to `AddCW20`, which performs the CW20 `token_info` query and calls `UpsertERCCW20Pointer` without ever checking `RegisterPointerDisabled` — the pointer contract is created successfully, contrary to the governance-intended freeze [5](#0-4) .
4. Compare against the `RegisterPointer` message handler, which would have rejected the same operation with `"registering CW->ERC pointers has been disabled"` [6](#0-5) .

func (server msgServer) RegisterPointer(goCtx context.Context, msg *types.MsgRegisterPointer) (*types.MsgRegisterPointerResponse, error) {
	ctx := sdk.UnwrapSDKContext(goCtx)
	if server.GetRegisterPointerDisabled(ctx) {
		return nil, fmt.Errorf("registering CW->ERC pointers has been disabled")
	}
	var existingPointer sdk.AccAddress
	var existingVersion uint16
	var currentVersion uint16
	var exists bool
	switch msg.PointerType {
	case types.PointerType_ERC20:
		currentVersion = erc20.CurrentVersion
		existingPointer, existingVersion, exists = server.GetCW20ERC20Pointer(ctx, common.HexToAddress(msg.ErcAddress))
	case types.PointerType_ERC721:
		currentVersion = erc721.CurrentVersion
		existingPointer, existingVersion, exists = server.GetCW721ERC721Pointer(ctx, common.HexToAddress(msg.ErcAddress))
	case types.PointerType_ERC1155:
		currentVersion = erc1155.CurrentVersion
		existingPointer, existingVersion, exists = server.GetCW1155ERC1155Pointer(ctx, common.HexToAddress(msg.ErcAddress))
	default:
		panic("unknown pointer type")
	}
	if exists && existingVersion >= currentVersion {
		return nil, fmt.Errorf("pointer %s already registered at version %d", existingPointer.String(), existingVersion)
	}

func (p PrecompileExecutor) AddNative(ctx sdk.Context, method *ethabi.Method, caller common.Address, args []interface{}, value *big.Int, evm *vm.EVM, hooks *tracing.Hooks) (ret []byte, remainingGas uint64, err error) {
	if err := pcommon.ValidateNonPayable(value); err != nil {
		return nil, 0, err
	}
	if err := pcommon.ValidateArgsLength(args, 1); err != nil {
		return nil, 0, err
	}
	token := args[0].(string)
	metadata, metadataExists := p.bankKeeper.GetDenomMetaData(ctx, token)
	if !metadataExists {
		return nil, 0, fmt.Errorf("denom %s does not have metadata stored and thus can only have its pointer set through gov proposal", token)
	}
	name := metadata.Name
	symbol := metadata.Symbol
	var decimals uint8
	for _, denomUnit := range metadata.DenomUnits {
		if denomUnit.Exponent > uint32(decimals) && denomUnit.Exponent <= math.MaxUint8 {
			decimals = uint8(denomUnit.Exponent)
			name = denomUnit.Denom
			symbol = denomUnit.Denom
			if len(denomUnit.Aliases) > 0 {
				name = denomUnit.Aliases[0]
			}
		}
	}
	contractAddr, err := p.evmKeeper.UpsertERCNativePointer(ctx, evm, token, utils.ERCMetadata{Name: name, Symbol: symbol, Decimals: decimals})
	if err != nil {
		return nil, 0, err
	}

	ret, err = method.Outputs.Pack(contractAddr)
	remainingGas = pcommon.GetRemainingGas(ctx, p.evmKeeper)
	return
}
